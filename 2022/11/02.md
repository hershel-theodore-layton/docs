# 2022-11-02

## Highlights

- `hh --remove-dead-fixmes` no longer consumes the character immediately following an inline `HH_FIXME`. [92fd112e0e](https://github.com/hershel-theodore-layton/hhvm/commit/92fd112e0e3886454c2f3f333d41a458e7fb7bcb)
- `__toString()` declarations in the bundled HHI files now explicitly return `string`. [700bee0a4f](https://github.com/hershel-theodore-layton/hhvm/commit/700bee0a4fb288e44c9b8639d297768d9eb45fc4)
- `SplFileObject` has more accurate iterator declarations: `current()` is a like-string because CSV mode and end-of-file can produce other values, while `getChildren()` is nullable. [1ab6c0cebd](https://github.com/hershel-theodore-layton/hhvm/commit/1ab6c0cebd3f46a081fa2ad4bbf6c71e4b52bde6) [c4a85bee88](https://github.com/hershel-theodore-layton/hhvm/commit/c4a85bee8808dde72bf67344108d6a825bb63b71)

## Future Changes

- Untyped built-in declarations are beginning to use `HH\FIXME\MISSING_RETURN_TYPE` instead of the unsound internal `Tany` type. This is preparatory work toward treating such results as `dynamic`. [0c5aa56b30](https://github.com/hershel-theodore-layton/hhvm/commit/0c5aa56b300692e7a2ddb92c2953feef642ce1f4)
