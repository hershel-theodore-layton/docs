# 2022-11-03

## Highlights

- Most previously untyped bundled HHI functions now have the transitional return type `HH\FIXME\MISSING_RETURN_TYPE`. This still behaves like `Tany` for compatibility, but is intended to become `dynamic` in the future. [7ecc475674](https://github.com/hershel-theodore-layton/hhvm/commit/7ecc475674dd076d1e0040a8ed637c09638335f2)
- Assignment through `Map` and `Vector` indexing no longer widens an already inferred element type. In particular, code that starts with an untyped empty collection may now need explicit generic arguments. [a56d5cfefa](https://github.com/hershel-theodore-layton/hhvm/commit/a56d5cfefafb9d28032a0d66693ffa272dd9cb01)
- In sound-dynamic mode, the result of a dynamic static method call such as `ClassName::$method()` is inferred as `dynamic` rather than the unsound `Tany`. [17f03a1a34](https://github.com/hershel-theodore-layton/hhvm/commit/17f03a1a34f7a75b159cbc237030df52bb1f68de)
