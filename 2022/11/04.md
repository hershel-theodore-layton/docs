# 2022-11-04

## Highlights

- Sound-dynamic checking now permits static calls through a value typed as `string`, matching the rule that `string` can flow to `dynamic` in this mode. [668b6893f5](https://github.com/hershel-theodore-layton/hhvm/commit/668b6893f54d5d92a1ba66ad33fe1f41661c5eb1)
- A typechecker soundness regression involving intersection types has been fixed. [1adee5934a](https://github.com/hershel-theodore-layton/hhvm/commit/1adee5934ad4acc31fa9e5e14d6976cecb8abf4a)
- Hack lint now reports redundant `HH\FIXME\UNSAFE_CAST` calls as lint 5647 and offers an autofix that replaces the cast with its input expression. [d02adc3a29](https://github.com/hershel-theodore-layton/hhvm/commit/d02adc3a29769be2cc0baab15a6e3eb24914f0e6)
