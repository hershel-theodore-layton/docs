# 2022-11-07

## Highlights

- Redundant `?mixed` and `?null` type hints are now lint warnings (5008 and 5009) instead of type errors. [04b4d0f60b](https://github.com/hershel-theodore-layton/hhvm/commit/04b4d0f60b2f37318d0d2a84ebefa1e0fd551fba)
- Type-alias expansion now detects cycles instead of repeatedly expanding a cyclic alias. [57491cc735](https://github.com/hershel-theodore-layton/hhvm/commit/57491cc735bcb0d712320cb90dc0584614960504)
- Sound-dynamic checking handles partially enforced intersection return types and nullable-dynamic array operations more consistently. [17c37dd75a](https://github.com/hershel-theodore-layton/hhvm/commit/17c37dd75a522353f09873e8cb1c0d644d16b3cc) [a7241d4077](https://github.com/hershel-theodore-layton/hhvm/commit/a7241d4077beb253b44cefbca9aaf48d51975097)
- `<<__MethodTraitDiamond>>` is no longer gated as an experimental Hack feature. [7abe512898](https://github.com/hershel-theodore-layton/hhvm/commit/7abe512898024289eb7e56293b7aa2ec6d213e70)

## Breaking Changes

- Indexed assignment no longer widens inferred Hack array types. Code that builds a `vec` or `dict` from an empty value may need an explicit type annotation. [5143993e38](https://github.com/hershel-theodore-layton/hhvm/commit/5143993e389b466fb6683241d976836cb929da46)
