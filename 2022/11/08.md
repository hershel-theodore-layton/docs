# 2022-11-08

## Highlights

- `hhstc` gained `--remove-dead-unsafe-casts`, which removes `HH\FIXME\UNSAFE_CAST` calls whose input already satisfies the destination type. [391d947075](https://github.com/hershel-theodore-layton/hhvm/commit/391d94707548066321caed2dce91012f9da8a77d)
- Bundled declarations now specify that `Countable::count()` returns `int`, and several `ReflectionMethod` predicates and modifier APIs now have concrete `bool` or `int` return types. [ac1286cb39](https://github.com/hershel-theodore-layton/hhvm/commit/ac1286cb3960738e15ffac9e8234fb1d93be91e4) [9761e022e3](https://github.com/hershel-theodore-layton/hhvm/commit/9761e022e308e787f15f1f85d1af5f378e139c42)
- Mutable collection `clear()` methods now return `this`, allowing their fluent behavior to be represented by the typechecker. [28e3aaa9cf](https://github.com/hershel-theodore-layton/hhvm/commit/28e3aaa9cf69fb795ebbcea15029804a7feed603)
