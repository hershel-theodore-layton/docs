# 2022-11-09

## Breaking Changes

- Accessing a known-absent field on a nullable closed shape is now a type error even when using `Shapes::idx()` or `??`. Previously, adding nullability could reduce this to a lint or suppress it. [9e49acc366](https://github.com/hershel-theodore-layton/hhvm/commit/9e49acc366a744eaf0dd7c199c938542e2438f82)
- `SplPriorityQueue<T>` is now declared as an iterator over `~T`, reflecting that its extraction flags can make `current()` return a priority or a value/priority pair instead of `T`. [4110107aae](https://github.com/hershel-theodore-layton/hhvm/commit/4110107aae954fcc77661724be80578d85480796)
