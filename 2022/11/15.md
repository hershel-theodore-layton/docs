# 2022-11-15

## Highlights

- Expression-tree type inference no longer passes pessimised like-types to `makeTree` when the virtual expression calls a pessimised function. [6f9d9ad3bc](https://github.com/hershel-theodore-layton/hhvm/commit/6f9d9ad3bcbdc93423fe999719550569dcd5b777)
- The bundled `Set` declarations now preserve their element type across iteration and common operations such as `map`, `filter`, `values`, and conversions. This should improve inference for projects using legacy Hack collections. [f5ea07c6fa](https://github.com/hershel-theodore-layton/hhvm/commit/f5ea07c6faee10bed08b67992c2bc6812bf5c977)
- Dead `HH\FIXME\UNSAFE_CAST` removal is now integrated with `hh_server`, including repeated analysis until no further redundant casts can be removed. [097f3c19ad](https://github.com/hershel-theodore-layton/hhvm/commit/097f3c19adbd64e88d3f15b772404b5845bd9341) [6ebee6b689](https://github.com/hershel-theodore-layton/hhvm/commit/6ebee6b68966be196d8e363e1a43cbc927037fa9)
- An `internal` type alias may now refer to another internal type from the same module. [61917d4bf0](https://github.com/hershel-theodore-layton/hhvm/commit/61917d4bf00286785b47cb9dcfdd146e1a7c9ae8)
- `HH\classname_from_string_unsafe()` is now declared in the HHI files. It converts a string to `classname<mixed>` without eager validity or module checks and is intended only for exceptional migration cases. [385ddd879a](https://github.com/hershel-theodore-layton/hhvm/commit/385ddd879a9b8eb1b2495989b50ed447aea8441e)

## Breaking Changes

- Class-level user attributes are typechecked outside the class context, so `self` is no longer available in their arguments. Module-internal names remain usable there when the attribute is evaluated inside the same module. [a83ac0b2c2](https://github.com/hershel-theodore-layton/hhvm/commit/a83ac0b2c2fcce81bc56da606b3e6d66c8407819)
- `DirectoryIterator` and `FilesystemIterator` now iterate over `~SplFileInfo`, since extraction flags can make `FilesystemIterator::current()` return a string or the iterator itself. [7380211047](https://github.com/hershel-theodore-layton/hhvm/commit/7380211047e294e70fbb2dc606253d1b60e63b75)
