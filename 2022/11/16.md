# 2022-11-16

## Highlights

- `get_defined_functions()` now preserves the declared capitalization of function names instead of lowercasing every result. Reflection calls with those names continue to work case-insensitively. [e15e774b91](https://github.com/hershel-theodore-layton/hhvm/commit/e15e774b91bc7cbd705d9c28c7be898e522abf2e)

## Breaking Changes

- Stale HHI declarations for runtime classes and class constants that do not exist have been removed. Several method declarations were also corrected, including `ReflectionClass::getTraitAliases()`, `ReflectionFunctionAbstract::getStaticVariables()`, and capitalization/finality mismatches in built-ins. Projects relying on the nonexistent declarations will now receive type errors. [f4bc1485be](https://github.com/hershel-theodore-layton/hhvm/commit/f4bc1485be9b187c85f1a19941f1529b8b31fb0d) [74f2d68eda](https://github.com/hershel-theodore-layton/hhvm/commit/74f2d68eda619633ba6eb04fa9445d24d8cc8390) [759eb8b13d](https://github.com/hershel-theodore-layton/hhvm/commit/759eb8b13de0e3b4ee11c5618a7717f1ad466945)

## Future Changes

- Lint 5624 no longer incorrectly labels generics used in pre-stable exact type refinements as redundant. [044f44601d](https://github.com/hershel-theodore-layton/hhvm/commit/044f44601d3e1ee4fb2e9ab59d64b96d6185c535)
