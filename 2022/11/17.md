# 2022-11-17

## Highlights

- Incremental typechecking now correctly fans out changes that add inherited XHP special attributes such as `:aria-*` and `:data-*`. Projects should see the same XHP attribute errors without needing a full typecheck. [d615fbde45](https://github.com/hershel-theodore-layton/hhvm/commit/d615fbde45381187c6acf15253e14a0b93c69867)
- HHI global and class constants with an explicit type may now omit their placeholder value. Initializers have been removed from the bundled handwritten declarations and are no longer copied into generated HSL HHIs. This syntax is specific to HHI declaration files and does not change the constants' runtime values. [824ac81dc9](https://github.com/hershel-theodore-layton/hhvm/commit/824ac81dc9a63e1e188dcb1aaa84e6eb687851ac) [833f6d5fe7](https://github.com/hershel-theodore-layton/hhvm/commit/833f6d5fe7dd6da8ccc3df35ff32b897500404e2) [0a1f30494a](https://github.com/hershel-theodore-layton/hhvm/commit/0a1f30494ab0cda722ca57a960fd2d21981617de) [80fb463a49](https://github.com/hershel-theodore-layton/hhvm/commit/80fb463a4904c60c5b92023b74a9d155b9b7258c) [f5f90c7cad](https://github.com/hershel-theodore-layton/hhvm/commit/f5f90c7cad0e2295240a1c7c252e0339bcd64c1a)
- `hh_server` now tolerates duplicated and out-of-order Watchman state notifications during source-control updates, reducing the chance of an incorrect server state after an update or transaction. [cea00244a1](https://github.com/hershel-theodore-layton/hhvm/commit/cea00244a173167e08f31fd56b070160c0493d64)
- When code such as `$object->$name` attempts dynamic access on a non-`dynamic` value, naming error 2011 now explains the restriction and offers a quick-fix to ordinary property access such as `$object->name`. [82df50f9da](https://github.com/hershel-theodore-layton/hhvm/commit/82df50f9da163c1738c0dcc8f2c675159c6392d4)
