# 2022-11-21

## Highlights

- Short enum-class labels such as `#X` can now be inferred when the expected parameter type is a nullable `HH\EnumClass\Label`. Invalid labels and labels with the wrong value type continue to produce the usual diagnostics. [153cf04a0d](https://github.com/hershel-theodore-layton/hhvm/commit/153cf04a0dffdf3155782a869550c17a3c666993)

## Future Changes

- Type constants in enum classes have moved from unstable to preview status. The syntax remains opt-in through `<<file:__EnableUnstableFeatures('enum_class_type_constants')>>`, but preview status permits explicitly enabled code to run in production. [810ea41057](https://github.com/hershel-theodore-layton/hhvm/commit/810ea41057a11456ac8e6dc804cdfb73dcb6db21)
