# 2022-11-22

## Highlights

- Sound Dynamic checking now preserves `supportdyn` when `type_structure()` examines a type constant bounded by an open shape. It also permits valid reads and appends through nullable containers while performing the additional `__SupportDynamicType` function-body check, avoiding false-positive errors in code that has already initialized or refined the container. [e467b3f779](https://github.com/hershel-theodore-layton/hhvm/commit/e467b3f779dc4151c23a34dbf1579e454b9f4be1) [4f3e8fbfaa](https://github.com/hershel-theodore-layton/hhvm/commit/4f3e8fbfaae00abdc636c2573a35ccf9a67519c8)
- Hover text no longer mistakes class or namespace names beginning with `HH_` for members of the `HH` namespace. A class named `HH_FOO`, for example, is now displayed without losing its prefix. [90d00b469a](https://github.com/hershel-theodore-layton/hhvm/commit/90d00b469a77f56822e3e8e6f6d0b27ce75c5c0b)
