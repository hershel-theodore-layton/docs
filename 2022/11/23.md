# 2022-11-23

## Highlights

- Sound Dynamic function-body checking now permits mutation after a value has been refined to `AnyArray`, including flows using `HH\is_any_array()`. These writes can be safely treated as an implicit upcast to `dynamic`. [3f1cef23f7](https://github.com/hershel-theodore-layton/hhvm/commit/3f1cef23f72267ea0cf7eb745edcfabc5c9a0d2d)

## Future Changes

- Enforceability analysis can now resolve type-constant accesses through concrete, abstract, and inherited definitions while safely terminating on cycles. This prepares Sound Dynamic signatures for future runtime enforcement of type constants. [e92a9672ce](https://github.com/hershel-theodore-layton/hhvm/commit/e92a9672ce85d125a9992806fe59776f6345c401)
