# 2022-11-29

## Highlights

- Sound Dynamic enforceability checks now resolve `this` against the enclosing class when interpreting types such as `this::T`, improving the treatment of method returns, parameters, properties, and class constants that use type constants. [9beeec27c0](https://github.com/hershel-theodore-layton/hhvm/commit/9beeec27c012bcac075f5e803906ea34d08f58af)

## Breaking Changes

- Accessing `$this` where it is not defined now produces naming error 2050 instead of silently receiving an unconstrained type. This closes holes in enum-class member expressions and expression-tree contexts; affected code should pass or reference an explicit value instead. [8ca873e222](https://github.com/hershel-theodore-layton/hhvm/commit/8ca873e222c5513caee1e0d6b51cdaa037b83c3a)
