# 2022-11-30

## Highlights

- Generic-arity errors are no longer redundantly produced during subtyping after the type has already been localized, reducing duplicate diagnostics. [f9c1cb34c4](https://github.com/hershel-theodore-layton/hhvm/commit/f9c1cb34c4e5b5ea00ebd2c9d8f47d3dc33e9738)
- Sound Dynamic inheritance checks now model runtime enforcement from a method's declaring signature rather than its instantiated inherited signature. This avoids treating a generic return such as `T` as runtime-enforced merely because a subclass inherits it as `int`. [7ff98a81d3](https://github.com/hershel-theodore-layton/hhvm/commit/7ff98a81d35b83ddbb166a89f7087aefad30d07a)
- Symbol-info export now always emits facts for namespace aliases defined in `.hhconfig`, even when `gen_sym_hash` is disabled. [59ea67ffd4](https://github.com/hershel-theodore-layton/hhvm/commit/59ea67ffd4a7838ff47c36ac34c74fdb56954a8d)

## Breaking Changes

- The internal `hphp_create_object()` declaration has been removed from the bundled HHI files. Projects that called it directly will no longer typecheck and should use `newv()` instead. [0b947ff90f](https://github.com/hershel-theodore-layton/hhvm/commit/0b947ff90f16e8cd6ce8aedf5a02354cd766fb1a)

## Future Changes

- Loose type refinements now participate in variance checking: `as` bounds are covariant, `super` bounds are contravariant, and exact refinements remain invariant. Code using preview type refinements may receive new variance diagnostics when a class type parameter appears in one of these bounds. [5a9139188b](https://github.com/hershel-theodore-layton/hhvm/commit/5a9139188b581b090c0c4de8a8c73f10651f80a8)
- Autocomplete inside traits now suggests the preview `require class` constraint alongside `require extends` and `require implements`. [6052c0bcdf](https://github.com/hershel-theodore-layton/hhvm/commit/6052c0bcdff292d4fc60cfa6dbd1dbed2361ccea)
