# 2022-12-01

## Highlights

- Sound-dynamic checking now treats values captured by a `<<__SupportDynamicType>>` closure as like-types. This makes nested closures dynamically callable without repeatedly checking every nesting level, though hover and TAST output inside the closure may now show captured `T` values as `~T`. [53d4897785](https://github.com/hershel-theodore-layton/hhvm/commit/53d4897785988b16037210b225c4d591eba0f8f7)
- The missing-`<<__Override>>` lint now offers a quick-fix, either adding a new attribute block or inserting `__Override` into an existing one. [624e58033f](https://github.com/hershel-theodore-layton/hhvm/commit/624e58033f8b0c3ed0f7c413815027051a44a7db)
- Go-to-definition and hover now distinguish a callable property from a method with the same name in expressions such as `($object->callback)()`. [77fdfabcc6](https://github.com/hershel-theodore-layton/hhvm/commit/77fdfabcc61c6ab6735ec4996364c4da0ef2d0b9)
- `DOMElement::$attributes` is no longer redeclared as non-null in the bundled HHI. It now inherits the nullable `?DOMNamedNodeMap<DOMAttr>` declaration from `DOMNode`, so callers must handle `null`. [d2bd42ae6c](https://github.com/hershel-theodore-layton/hhvm/commit/d2bd42ae6c9092586644a892e766a0472b320a24)
