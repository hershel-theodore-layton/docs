# 2022-12-03

## Highlights

- Bidirectional inference for `keyset` and `dict` literals now respects the `arraykey` bound when the expected type is `(Keyed)Traversable` or `(Keyed)Container`. Invalid expected key types no longer cause an out-of-bounds type to be inferred. [833436d8b6](https://github.com/hershel-theodore-layton/hhvm/commit/833436d8b69a6e01569e1ebba8026142ede6f60e)

## Breaking Changes

- Static properties must now declare `public`, `protected`, or `private` explicitly; Hack no longer silently treats a declaration such as `static int $count` as public. [dc2a79087b](https://github.com/hershel-theodore-layton/hhvm/commit/dc2a79087b6eed23d7d5c9e906833b7a192e0bb1)
