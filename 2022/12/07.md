# 2022-12-07

## Highlights

- The typechecker now rejects trait composition that makes a static member overlap an instance member of the same name. Such code would already fatal in HHVM; the error is now caught during typechecking. [4f5f028f38](https://github.com/hershel-theodore-layton/hhvm/commit/4f5f028f385048eda60106e44d01fa2678c282a5)
- Module names may now contain non-reserved keywords, matching the names accepted for classes. Reserved keywords and XHP-style names remain invalid. [669b93bd1b](https://github.com/hershel-theodore-layton/hhvm/commit/669b93bd1bd6a152c3f59836b3c040438f45e9e9)
- Deployments using native Facts can set `Autoload.UpdateSuppressionPath` to a sentinel file. While that file exists, Facts skips Watchman-driven updates; relative paths are resolved from the repository root. [5f4a1ae19b](https://github.com/hershel-theodore-layton/hhvm/commit/5f4a1ae19be23ae8470b20a3d10782f60e106070)
