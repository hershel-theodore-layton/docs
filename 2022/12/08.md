# 2022-12-08

## Highlights

- A new lint reports casts whose target type is already identical to the expression's inferred type. [a070d39d1f](https://github.com/hershel-theodore-layton/hhvm/commit/a070d39d1ff9ea3387b8fbb0f32f572d77ec68fd)
- When an enum declaration omits its base type, the parser error now offers a quick-fix that inserts `: arraykey`. [c60763014e](https://github.com/hershel-theodore-layton/hhvm/commit/c60763014e80d9d7d30dcfc842df5539dd078d55)
- Reflection no longer converts enum-class labels found in arbitrary user-attribute arguments as though they were memoization metadata. The special conversion is now limited to memoization attributes. [8ba321326d](https://github.com/hershel-theodore-layton/hhvm/commit/8ba321326daac8fbcc9d7ef44648dd5ad41db27d)

## Breaking Changes

- `Iterable::map()` and `KeyedIterable::mapWithKey()` have been removed from their interfaces because their signatures were unsound. Calls through those interface types must use an appropriate concrete collection API or an HSL traversal function. [899d46019f](https://github.com/hershel-theodore-layton/hhvm/commit/899d46019f064a37788c9f56fa2273447957004a)

## Future Changes

- Diagnostics for pre-stable type refinements now print refinement syntax with source-like spacing, making displayed types easier to read and copy. [418ef35a32](https://github.com/hershel-theodore-layton/hhvm/commit/418ef35a328769962c9bc27ac53ac2098151892a)
