# 2022-12-12

## Highlights

- Missing method visibility errors now offer a quick-fix that inserts a visibility modifier. [2b4eb0ad20](https://github.com/hershel-theodore-layton/hhvm/commit/2b4eb0ad20b38fe8245c279a1ea7925893987b24)

## Breaking Changes

- Hack command-line tools now distinguish `--error-format raw` from the former plain-text rendering. Scripts that consume the old output from `hh_single_type_check` or related single-file tools should request the new `--error-format plain`; `raw` now consistently selects the structured raw formatter. [d9f4bc6e0c](https://github.com/hershel-theodore-layton/hhvm/commit/d9f4bc6e0cbe751eab4697c22ea12d82d77a6844)

## Future Changes

- Type refinements are now accepted by HHVM itself. Source files still need `<<file:__EnableUnstableFeatures('type_refinements')>>`, but no separate HHVM-side feature gate is required. [32b5df2753](https://github.com/hershel-theodore-layton/hhvm/commit/32b5df2753ec12226d0558f770014245a6bb47f8)
- Experimental module-reference checks were temporarily disabled because of their cost in projects using modules. They are restored on December 15 after the cache path was corrected. [694d3b9b2e](https://github.com/hershel-theodore-layton/hhvm/commit/694d3b9b2ef27b5bd23f74c1b48afeeaf2e98940)
