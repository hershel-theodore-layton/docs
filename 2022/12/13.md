# 2022-12-13

## Highlights

- Missing required-XHP-attribute errors now point to the attribute declaration rather than the containing XHP class. [df7da6ed99](https://github.com/hershel-theodore-layton/hhvm/commit/df7da6ed992739572716325b46738cad96ed1b0f)
- An unbounded generic is now treated like a generic explicitly bounded by `mixed` when accessing type structures. Class-specific fields such as `classname` require a classish bound. [eb806ee50a](https://github.com/hershel-theodore-layton/hhvm/commit/eb806ee50acb04787c65364f98d98284e2524564)
- Several `HH\TypeStructure` fields have more accurate bundled declarations: `return_type` and `value` are `mixed`, while `access_list` is `?varray<string>`. [7926fe9c9d](https://github.com/hershel-theodore-layton/hhvm/commit/7926fe9c9d2828669cf50a7420cf3733b55a2e22)
- Native Facts now coalesces simultaneous update requests behind an already-pending Watchman query instead of scheduling one query per caller. [3db59e7600](https://github.com/hershel-theodore-layton/hhvm/commit/3db59e7600a66ad6a6021fb1b07b6521efa4b763)

## Future Changes

- Calling `HH\autoload_set_paths()` while native autoloading is active now raises a deprecation notice. Deployments can set `Autoload.UserlandEnabled=false` to turn such calls into `InvalidOperationException`s and find code that must migrate to native autoloading. [0e45a0afae](https://github.com/hershel-theodore-layton/hhvm/commit/0e45a0afae51c565efd806425718a72112b3e77c)
