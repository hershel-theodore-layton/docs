# 2022-12-15

## Highlights

- Member find-references now narrows its dependency-graph search to descendants that can contain the named member. Results should be unchanged, with substantially less unrelated code searched in large hierarchies. [aaf403a3e5](https://github.com/hershel-theodore-layton/hhvm/commit/aaf403a3e589f0dbf014db26a6aa054ef5455551)
- Hover information is now available for keywords used inside classes, including `static`, `use`, and `const type`. [b2e88973ff](https://github.com/hershel-theodore-layton/hhvm/commit/b2e88973ffb5c84e6ea4c5d9d1082c5964fcbb7e)
- Experimental module-reference checking has been restored after fixing the module cache path that made it expensive. Projects using the feature once again receive its cross-module reference diagnostics. [9345a32382](https://github.com/hershel-theodore-layton/hhvm/commit/9345a32382775306f4eca2de511a302c512eb0a2)
