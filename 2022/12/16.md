# 2022-12-16

## Future Changes

- Under `everything_sdt`, `UNSAFE_CAST<TFrom, TTo>` is now represented as an upcast to `~TTo`, including in the TAST. Tools consuming the TAST should expect the like-type, which reflects that the cast does not provide a runtime guarantee. [90a13f5252](https://github.com/hershel-theodore-layton/hhvm/commit/90a13f5252f6448225e0493dbb60b4204baf07c8)
- Private methods in sound-dynamic classes are now checked as dynamically callable, just like non-private methods, because they can still be reached through `dynamic` or like-typed receivers. This can expose previously missed sound-dynamic errors. [822346b50c](https://github.com/hershel-theodore-layton/hhvm/commit/822346b50c1d35059716cd56131429e3d0b21669)
- Implicit pessimisation no longer treats type constants as runtime-enforced by default. Projects experimenting with sound dynamic typing should not rely on a type-constant access alone to enforce the resulting value. [f598a1f437](https://github.com/hershel-theodore-layton/hhvm/commit/f598a1f4379490ac6a4b23ae87558ca3bd854ae5)
