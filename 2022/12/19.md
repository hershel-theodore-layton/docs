# 2022-12-19

## Breaking Changes

- `SplPriorityQueue` now takes separate value and priority type parameters: `SplPriorityQueue<TValue, TPriority>`. Its bundled HHI also gives concrete types to `compare()`, `insert()`, `extract()`, `top()`, and the iterator methods. Existing one-argument annotations must add the priority type. [b55314d75a](https://github.com/hershel-theodore-layton/hhvm/commit/b55314d75aa40ae1ea3ac909a0d3adaa0b9c1f19)
- Constant-expression validation now recursively rejects `static::*` and `parent::class` inside collection and shape literals used for constants or property initializers. These accesses were already rejected at the top level; nesting them no longer bypasses the check. [3edc239bad](https://github.com/hershel-theodore-layton/hhvm/commit/3edc239badd7aa8d367062e0f93994f46b39302f)
