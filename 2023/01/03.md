# 2023-01-03

## Highlights

- HHVM no longer reports a false `Cannot declare self-referencing constant` fatal when an interval-timer callback interrupts the initialization of a large global or class constant. Genuine recursive constants remain invalid. [bc6c72f81a](https://github.com/hershel-theodore-layton/hhvm/commit/bc6c72f81aeeaf173f872ecfba1eecf97db25153)
- The diagnostic for using `#MakeICInaccessible` or `#SoftMakeICInaccessible` with an incompatible context now correctly refers to `leak_safe_shallow`, rather than the incompatible `leak_safe` context. [9592c3ee4d](https://github.com/hershel-theodore-layton/hhvm/commit/9592c3ee4d91b5870587f45fbf481382ebab5d21)
