# 2023-01-06

## Highlights

- Hack modules no longer require `<<file:__EnableUnstableFeatures('modules')>>`. The separate `module_references` experiment still requires its own unstable-feature opt-in. [d3bdad4f2f](https://github.com/hershel-theodore-layton/hhvm/commit/d3bdad4f2fc5be6bbbaf6e9c3b50a219c19a2d43)
- `HH\ImplicitContext\run_with_soft_inaccessible_state()` and its async counterpart can run a callable in the soft-inaccessible implicit-context state during migrations. They accept a blame key, may only be entered from a null implicit-context state, and should be removed once the logged violations have been addressed. [402b7ded0e](https://github.com/hershel-theodore-layton/hhvm/commit/402b7ded0e0fbca8d096bebbd416cd9e2b1873fb)
- Hover and typed-AST data can now distinguish anonymous functions from named functions instead of assigning synthetic names to closures. [e18be7371b](https://github.com/hershel-theodore-layton/hhvm/commit/e18be7371b3388b501d098f14b7d47a8ea5906c8)

## Breaking Changes

- The Thrift extension no longer implements or registers `RpcOptions::setFaultToInject()`. Projects using this fault-injection API must remove those calls. [64a89b91a6](https://github.com/hershel-theodore-layton/hhvm/commit/64a89b91a6da25dd42330a3d01de0ad4f3236935)
