# 2023-01-09

## Highlights

- Lint 5649 now warns when `::class` is taken from an `internal` class, since the resulting raw string can escape its module without visibility checks. Keep such classnames inside the declaring module or avoid producing them. [ac5b19049b](https://github.com/hershel-theodore-layton/hhvm/commit/ac5b19049b7fbc232d4dd7750cfc3879141e4c85)
- Bundled SPL and system-class declarations now give iterator methods more precise types: implementations of `valid()` and `hasChildren()` return `bool`, while several `current()` and `getChildren()` declarations preserve their iterator type parameters. This should reduce `mixed` propagation when consuming built-in iterators.
