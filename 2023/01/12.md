# 2023-01-12

## Highlights

- Incremental typechecking now rechecks dependents when an inherited XHP attribute becomes required or a new required attribute is added. Projects should receive the same missing-attribute errors without needing a full check. [3fba663915](https://github.com/hershel-theodore-layton/hhvm/commit/3fba663915e013e60cf802435d5715c8e1667ed0)
- The bundled HHI for `pcntl_waitpid()` now types its status parameter as `inout ?int`, and `Serializable::unserialize()` now requires a `string`. Callers of `pcntl_waitpid()` must account for the variable remaining nullable after the call. [ece17c0698](https://github.com/hershel-theodore-layton/hhvm/commit/ece17c06984d261dc222e5b627090cb1822312ce) [050792ec94](https://github.com/hershel-theodore-layton/hhvm/commit/050792ec94478ea2df2e5ae9078af1ef1da2fe40)
- HHBBC now treats the `classname` field in runtime type structures as case-sensitive, matching the shape-key semantics used by type structures. [b9b1d9f2ef](https://github.com/hershel-theodore-layton/hhvm/commit/b9b1d9f2ef32c35b5d916eb3e4466a156791de53)

## Breaking Changes

- Dumping or calling `__debugInfo()` on a closure no longer reveals captured variables, parameters, or the bound `$this`; it now produces an empty dictionary. Code must not use closure debug output as a reflection API. [d2cfc9b74d](https://github.com/hershel-theodore-layton/hhvm/commit/d2cfc9b74dbd2355c4aa3aeb82d0c18bfdccd4de)
