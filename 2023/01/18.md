# 2023-01-18

## Highlights

- Expression-tree lambdas are now fully inferred during sound-dynamic checking. This fixes spurious constraint errors on expression trees whose inferred type parameter cannot be `dynamic`. [e6189ec286](https://github.com/hershel-theodore-layton/hhvm/commit/e6189ec286c9ba0b84a92ba3caa4025785ad3fac)
- More HHI output parameters now describe their results: `pcntl_wait()` uses `?int`, `exec()` and `preg_match_with_error()` use `dynamic`, and the resource collections used by `proc_open()` and `stream_select()` are nullable `vec_or_dict<resource>`. Existing variables passed by `inout` may need matching annotations. [14b294fef6](https://github.com/hershel-theodore-layton/hhvm/commit/14b294fef6ed514b1a291b1936e86eec089a339d)
