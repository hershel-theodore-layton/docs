# 2023-01-20

## Highlights

- Array-access errors now retain the actual base and index types in typed-AST holes, and inferred `KeyedContainer` key types are constrained to `arraykey`. IDE fixes and type-error explanations should no longer suggest impossible types such as `KeyedContainer<bool, nothing>`. [5519413eb5](https://github.com/hershel-theodore-layton/hhvm/commit/5519413eb5bf284d9042b60f979e4f0cf9a90838) [01bddda586](https://github.com/hershel-theodore-layton/hhvm/commit/01bddda5869becf471ecc93ccebea4769515a5ec) [59a15c7f27](https://github.com/hershel-theodore-layton/hhvm/commit/59a15c7f2773b29cb36ec2e8f860d5e2413aaced)
- The dead-`UNSAFE_CAST` codemod now omits redundant parentheses for expressions that cannot be captured by surrounding syntax, producing smaller and more idiomatic patches. [952e984837](https://github.com/hershel-theodore-layton/hhvm/commit/952e984837ca498828e3269a79c0e8c1795288f9)

## Breaking Changes

- `tls://` stream sockets no longer negotiate TLS 1.0 and instead use the modern TLS client or server method. Connections to endpoints that only support TLS 1.0 will now fail and should be migrated to a current protocol. [083f5ffdee](https://github.com/hershel-theodore-layton/hhvm/commit/083f5ffdee661f61512909d16f9a5b98cff3cf0b)
