# 2023-01-23

## Highlights

- Incremental typechecking now correctly rechecks both files involved in a duplicate module-name collision, avoiding stale module diagnostics after edits. [0021cf60bb](https://github.com/hershel-theodore-layton/hhvm/commit/0021cf60bb1b473c87d903bf846604ff2e185f17)
- `<<__SoftInternal>>` is now accepted on constructor-promoted properties with `internal` visibility and rejected on ordinary constructor parameters or properties with other visibility. [2c2ac6d2d3](https://github.com/hershel-theodore-layton/hhvm/commit/2c2ac6d2d305a72a83a5d8be7eadf4830a54b892)
- `hphp_get_stats('units')` and `hphp_get_stats('funcs')` can now report the number of loaded units and allocated function IDs, respectively, which is useful for auditing how much code a script loads. [f62641e738](https://github.com/hershel-theodore-layton/hhvm/commit/f62641e738be3f6393d700c49713d47a2849f1b0)

## Breaking Changes

- The stale systemlib declaration of `RpcOptions::setFaultToInject()` has been removed, completing the earlier runtime removal. Calls now fail typechecking as well as at runtime. [084d422844](https://github.com/hershel-theodore-layton/hhvm/commit/084d4228442db4dc501f5f9b8e4ad28438ddd063)

## Future Changes

- The typechecker now accepts `<<__SoftInternal>>` on enums and enum classes ahead of runtime support. Treat this as migration groundwork rather than a fully available runtime feature. [e373f377f5](https://github.com/hershel-theodore-layton/hhvm/commit/e373f377f5e4e967be658df5a75a7bb5f7160966)
