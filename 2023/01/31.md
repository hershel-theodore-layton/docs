# 2023-01-31

## Highlights

- Sound-dynamic hierarchy checks now consider all ancestors, including interfaces inherited through used traits. A class that transitively acquires an SDT interface requirement must itself support dynamic. [810c57c82f](https://github.com/hershel-theodore-layton/hhvm/commit/810c57c82f798217aea22bbdf5b37448d953ec0c)
- A trait is now considered to support dynamic only when it is marked `<<__SupportDynamicType>>` and one of its requirements restricts it to SDT classes. This fixes both false acceptance and false rejection around SDT traits and their consumers. [c07151edf9](https://github.com/hershel-theodore-layton/hhvm/commit/c07151edf950fb717e6d4c25984355065d30af0a)
