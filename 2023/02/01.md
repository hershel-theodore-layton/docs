# 2023-02-01

## Highlights

- Several APC declarations now have narrower capability requirements than their former implicit `[defaults]`: read operations such as `apc_exists()` require `[read_globals]`, mutations require `[globals]`, and `apc_sma_info()` is pure. This allows callers with correspondingly restricted contexts to use these APIs. [2aaa02ccf6](https://github.com/hershel-theodore-layton/hhvm/commit/2aaa02ccf62311fbf72075da60b582c95d59f7a2)
- The Rust `.hhconfig` reader now recognizes `union_intersection_type_hints`, so projects using that parser can enable union and intersection type-hint syntax consistently. [229121c557](https://github.com/hershel-theodore-layton/hhvm/commit/229121c5577cbeb25d1532c0972bc509e8cac04c)
