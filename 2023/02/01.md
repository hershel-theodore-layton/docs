# 2023-02-01

## Highlights

- Several APC runtime declarations now have narrower capability requirements: `apc_exists()`, `apc_size()`, and `apc_cache_info()` require `[read_globals]`; operations such as `apc_delete()` and `apc_inc()` require `[globals]`; and `apc_sma_info()` is pure. Ordinary `apc_add()`, `apc_store()`, and `apc_fetch()` retain `[defaults]`. Matching HHI changes for typechecking arrive on March 7. [2aaa02ccf6](https://github.com/hershel-theodore-layton/hhvm/commit/2aaa02ccf62311fbf72075da60b582c95d59f7a2)
- The Rust `.hhconfig` reader now recognizes `union_intersection_type_hints`, so projects using that parser can enable union and intersection type-hint syntax consistently. [229121c557](https://github.com/hershel-theodore-layton/hhvm/commit/229121c5577cbeb25d1532c0972bc509e8cac04c)
