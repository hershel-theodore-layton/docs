# 2023-02-03

## Highlights

- Sound Dynamic pessimisation now honors `<<__NoAutoDynamic>>` on top-level functions and no longer adds inappropriate dynamic bounds to `classname<T>`, `typename<T>`, or common generic container declarations. Types such as `Vector<string>` can therefore support dynamic without requiring their type argument to be exactly `dynamic`. - `cpu_get_count()` and `cpu_get_model()` now require only `[read_globals]` rather than implicit `[defaults]`, making them callable from functions with a narrower capability set. [26cae71480](https://github.com/hershel-theodore-layton/hhvm/commit/26cae7148066abacf09e962a206fd0e97ed65683)
