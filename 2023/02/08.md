# 2023-02-08

## Highlights

- Exact class types no longer use a class's declared variance to establish subtyping. This closes an unsoundness where incompatible exact generic instantiations could be accepted. [7b326d1b8b](https://github.com/hershel-theodore-layton/hhvm/commit/7b326d1b8b7bf79c7aa6a175bc26a5fc36038a99)
- `DateTime` HHI declarations now describe their actual capability requirements. Pure getters, property-writing mutators, and global-reading methods can be called from appropriately narrow contexts instead of all implicitly requiring `[defaults]`. [49b10540ed](https://github.com/hershel-theodore-layton/hhvm/commit/49b10540ed9ec4520b01da0a31c246993ba8ccc4)
- Sound Dynamic union simplification now preserves `supportdyn` wrappers instead of immediately merging separate wrapped union members back into one wrapper, avoiding incorrect type acceptance. [cd49bf2e54](https://github.com/hershel-theodore-layton/hhvm/commit/cd49bf2e547932e17aea74650e1e8de015b19e76)
- Runtime failures while converting a throwable to text now include the underlying failure details instead of returning an uninformative placeholder. [0309a310b5](https://github.com/hershel-theodore-layton/hhvm/commit/0309a310b5960fe262a43e3f0fc6e905b4bfd469)
