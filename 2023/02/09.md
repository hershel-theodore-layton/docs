# 2023-02-09

## Highlights

- An async lambda passed where `dynamic` is expected now infers its omitted return type normally, rather than assuming a `dynamic` return and rejecting ordinary returns such as `return 1`. [e2a1356eeb](https://github.com/hershel-theodore-layton/hhvm/commit/e2a1356eeb21c88c1661b90f5e7958cb0e9df3df)
- Large shape types now spend type-printer fuel per field and are explicitly truncated when the budget is exhausted, keeping diagnostics and hover output readable. [452112ed92](https://github.com/hershel-theodore-layton/hhvm/commit/452112ed9235f34870d6a33327b6376659386ff7)
- `<<__NoAutoDynamic>>` is now supported on individual methods in both explicit and implicit Sound Dynamic pessimisation. It prevents `~` and `supportdyn` from being added to that method's signature without disabling dynamic calls to an otherwise Sound Dynamic class. [7da433acc8](https://github.com/hershel-theodore-layton/hhvm/commit/7da433acc8bdea572279cdd068b436ecea2b54ef)
- Exception rendering retains the original class, file, and line when an overridden `Exception::getMessage()` itself throws, making secondary failures substantially easier to diagnose. [0a6378d03a](https://github.com/hershel-theodore-layton/hhvm/commit/0a6378d03a4bc64020067fb6284dcd820506ac6b)

## Future Changes

- Pre-stable class refinements now distinguish `type` members from `ctx` members. Refining a type constant with `ctx`, or a context constant with `type`, produces typing error 4471. [f04bef3304](https://github.com/hershel-theodore-layton/hhvm/commit/f04bef3304685575583bd5c0f19f4eb461d1f0f1)
