# 2023-02-13

## Highlights

- Enum-class labels in attribute arguments are now preserved through naming, enabling typechecking, hover, and completion for forms such as `<<__Memoize(#Key)>>`. [b9dd041059](https://github.com/hershel-theodore-layton/hhvm/commit/b9dd041059eb4fb2afe214efac82e6191a5e5fb0)
- In `--everything-sdt` mode, method return expressions are now checked against a `supportdyn`-wrapped return type, matching explicitly Sound Dynamic methods. [82c7fcccc7](https://github.com/hershel-theodore-layton/hhvm/commit/82c7fcccc7c94a001670955d718fc474943fd293)

## Breaking Changes

- The `fun()`, `class_meth()`, and `inst_meth()` pseudo-function-pointer forms are now rejected by default. Migrate to first-class pointers such as `function_name<>`, `ClassName::method<>`, and `$object->method<>`. [4c7ba8532f](https://github.com/hershel-theodore-layton/hhvm/commit/4c7ba8532fe188b6b49e632960ac6f3eaf18da69)
- Unimplemented and obsolete `STREAM_CRYPTO_METHOD_*` constants have been removed, including the protocol-version-specific TLS and legacy SSL constants. Use `STREAM_CRYPTO_METHOD_TLS_CLIENT`, `STREAM_CRYPTO_METHOD_TLS_SERVER`, or the corresponding `ANY` constants. [a5ce6b07f0](https://github.com/hershel-theodore-layton/hhvm/commit/a5ce6b07f0327455206c1017c097d502381f2677)
- String arguments such as `<<__Memoize("foo")>>` are now rejected where a memoize option enum-class label is required. Use the appropriate label syntax instead. [b9dd041059](https://github.com/hershel-theodore-layton/hhvm/commit/b9dd041059eb4fb2afe214efac82e6191a5e5fb0)
