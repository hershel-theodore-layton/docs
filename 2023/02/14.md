# 2023-02-14

## Highlights

- `hh --tast-holes-batch` accepts a newline-separated list of source files and reports TAST holes across the batch, making type-precision analysis easier to automate. [c41d55d42c](https://github.com/hershel-theodore-layton/hhvm/commit/c41d55d42c89ae60cfb7a19561494c8e39f23cf3)
- Invalid `__Memoize` arguments now distinguish wrong arity from an invalid option and report the expected number of arguments. [fa4f4eb1ef](https://github.com/hershel-theodore-layton/hhvm/commit/fa4f4eb1ef5df98e42c46d673263dc8433ed692e)
- Partially written methods are lowered far enough for IDE features to work, `__Override` diagnostics retain complete positions, and autocomplete can suggest overridden method names after an incomplete `<<__Override>>` declaration. [80775a8a36](https://github.com/hershel-theodore-layton/hhvm/commit/80775a8a3608b30247933d2035837ad95fdcd4e9) [f25f7d4b3e](https://github.com/hershel-theodore-layton/hhvm/commit/f25f7d4b3e81b5f499fc54a9afd5c07fc67f9e34) [dabbec63a9](https://github.com/hershel-theodore-layton/hhvm/commit/dabbec63a9b33666eb052b85d0cfb805be278c49)

## Future Changes
