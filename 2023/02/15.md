# 2023-02-15

## Breaking Changes

- HHVM now defaults `Autoload.Enabled` to `true`. Deployments that need the previous behavior should explicitly set `Autoload.Enabled = false`. [a714af2744](https://github.com/hershel-theodore-layton/hhvm/commit/a714af2744b0ef5c6f42bbcc7ee42c32c7f9f4ca)
- Thrift stream and sink failures are now delivered as `ThriftApplicationException` rather than `TApplicationException`. Code catching the older concrete class should catch the new exception or a shared base such as `Exception`. [0e2f06e781](https://github.com/hershel-theodore-layton/hhvm/commit/0e2f06e78102d20063a967916caf4c459e9ca563)
