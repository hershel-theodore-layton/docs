# 2023-02-16

## Highlights

- The command form `hh --json check .` works again after an argument-parsing regression. [dd5ab56163](https://github.com/hershel-theodore-layton/hhvm/commit/dd5ab5616325887d51fb8818ef711793e0cb7d41)

## Breaking Changes

- Hack now rejects prohibited uses of `this` in class type parameters, class-variable hints, `extends`, and `require extends`. Type accesses rooted at `this`, such as `this::T`, remain available; affected declarations should otherwise use an explicit class or type parameter. [150429e923](https://github.com/hershel-theodore-layton/hhvm/commit/150429e923a60dbe8441a3c89b5024f01da091ff)
- `ZipArchive::getFromIndex()` now returns `null`, rather than `false`, on failure and is typed as `?string`. Callers checking strictly for `false` must migrate to a null check. [8ac98e8a21](https://github.com/hershel-theodore-layton/hhvm/commit/8ac98e8a2149e01e3ef417fe54ab90f620ad3b86)

## Future Changes

- Opt-in expression-tree blocks allow statements directly inside ``Code`{ ... }` `` syntax and lower them to an immediately invoked lambda. The ongoing-release feature currently requires `<<file:__EnableUnstableFeatures('expression_tree_blocks')>>` for typechecking. [60a7b62d04](https://github.com/hershel-theodore-layton/hhvm/commit/60a7b62d043aee9a56b4d11e474f70ab8719a771)
