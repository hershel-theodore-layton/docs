# 2023-02-17

## Highlights

- Sound Dynamic subtyping can now push `supportdyn` through built-in containers and through safe promotions to `Traversable`, while expected-type inference retains more useful like-type information. This removes several false-positive errors around refined and nested container types. [f9fe075c21](https://github.com/hershel-theodore-layton/hhvm/commit/f9fe075c21bec3961098a42394666c0033fcd63d) [972106d560](https://github.com/hershel-theodore-layton/hhvm/commit/972106d560e7a4be75add1ae16d6243bccce5b5e) [61ab0e31c7](https://github.com/hershel-theodore-layton/hhvm/commit/61ab0e31c7281a6a109c4057f2644fbf46c65b4e)
- Autocomplete now works in generic type-argument positions such as `vec<string>` without mistaking the angle brackets for XHP syntax. [480b384688](https://github.com/hershel-theodore-layton/hhvm/commit/480b384688cc081354ad8957e576b04249d219c1)
- `hh_single_type_check --sdt-analysis` can now identify top-level functions that need `__SupportDynamicType`, including dynamically callable functions and call sites that require dynamic-aware checking.
