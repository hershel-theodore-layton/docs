# 2023-02-20

## Highlights

- Sound Dynamic union, intersection, and subtype processing no longer accumulates recursive `supportdyn` wrappers that can overflow the typechecker's stack, and it now retains the wrapper while comparing two `supportdyn` types. [0e60e722c7](https://github.com/hershel-theodore-layton/hhvm/commit/0e60e722c7d5e5b7d1b7a4cd91caded92625614e) [de66255762](https://github.com/hershel-theodore-layton/hhvm/commit/de6625576237afaf22bb3a2800fa552be89d42c1)
- Hover in Sound Dynamic projects can show an expression's type under dynamic assumptions when it differs from the ordinary type. The additional TAST is generated on demand for hover rather than for every typecheck. [f0ad1da10f](https://github.com/hershel-theodore-layton/hhvm/commit/f0ad1da10f5d180b63fb4e77e084be3ec1a9d138) [bdad09d3c0](https://github.com/hershel-theodore-layton/hhvm/commit/bdad09d3c0ad623df5e91abfd4ce6930198b1a19)
- Sound Dynamic generic inference now removes like-types in safe covariant positions before solving a type variable, and tuple reads and writes are no longer unnecessarily pessimised. [4d6992a5db](https://github.com/hershel-theodore-layton/hhvm/commit/4d6992a5db3d993318c3ce83b4e0751463619e49) [76d4a7b435](https://github.com/hershel-theodore-layton/hhvm/commit/76d4a7b435cbea9312f45a3c9816e9eb60f5a59e)
- The experimental SDT analyzer now propagates `NeedsSDT` constraints from dynamic instance and static method calls to classes. [da198e2d89](https://github.com/hershel-theodore-layton/hhvm/commit/da198e2d89b7f7844d559d8b51c8a75f3cb687cd)
