# 2023-02-22

## Highlights

- Runtime module-boundary errors now correctly describe an internal top-level function called from a method, rather than misreporting it as a method on the caller's class. [3d6bddce49](https://github.com/hershel-theodore-layton/hhvm/commit/3d6bddce4980176b3023fb23d285642b5b1bc2e1)
- Sound Dynamic checking avoids another stack overflow while solving `supportdyn` bounds, supplies dynamic bounds for class-level generics during the additional method-body check, and correctly wraps methods fetched through intersection receivers. [4de931af81](https://github.com/hershel-theodore-layton/hhvm/commit/4de931af8171b5fe5a9c90435b5bdd8d406b854f) [12856381c5](https://github.com/hershel-theodore-layton/hhvm/commit/12856381c5adbc22a3fc27f0cfbbf859de0a9008) [46a1c1580b](https://github.com/hershel-theodore-layton/hhvm/commit/46a1c1580ba3ab136959ee27d327881498bf030e)
- Redundant-cast lints now warn that removing a runtime cast can change behavior, instead of presenting removal as unconditionally safe. [30abe736a4](https://github.com/hershel-theodore-layton/hhvm/commit/30abe736a4e3ab43566b5d2ddeb44290fbb996ad)
- Optimized code no longer assumes that a value checked by a soft return-type constraint is non-null, preserving the runtime semantics of soft type hints. [7dccf227c0](https://github.com/hershel-theodore-layton/hhvm/commit/7dccf227c0e9c26ad156397167961e40fec5af03)

## Breaking Changes

- Deprecated `AwaitAllWaitHandle::fromVector()`, `fromMap()`, and `fromContainer()` have been removed. Use `fromVec()` or `fromDict()` after an appropriate constant-time collection cast. [e0d354d015](https://github.com/hershel-theodore-layton/hhvm/commit/e0d354d01594378d45fb2b0d5dfbd153576507ab)
- `AwaitAllWaitHandle::setOnCreateCallback()` now passes a `vec` rather than a `Vector`. Callbacks that only iterate can accept `Traversable<Awaitable<mixed>>` to remain compatible. [75f849cc74](https://github.com/hershel-theodore-layton/hhvm/commit/75f849cc74ea4835997a9a06b8519bf9e2c9e06b)

## Future Changes

- Initial TOML parsing support has landed for package configuration, including source spans that later diagnostics can map to line numbers. The active package integration remains experimental. [00899f4f76](https://github.com/hershel-theodore-layton/hhvm/commit/00899f4f761f91cc1530d8854c95fa176d06e328)
