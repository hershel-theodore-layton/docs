# 2023-02-27

## Highlights

- Sound Dynamic subtype inference now applies the intersection-to-union heuristic when the union contains an optional type variable, improving refinements involving nullable like-types. [389adc3c78](https://github.com/hershel-theodore-layton/hhvm/commit/389adc3c783c07d5c2cc5479f822fe0b06b0b8c8)
- Hover and outline information now includes the `internal` modifier for methods. [20464398b2](https://github.com/hershel-theodore-layton/hhvm/commit/20464398b245136939df3267faedaa1e7961480b)

## Future Changes

- Opt-in package-aware typechecking now rejects access to public symbols from an unrelated package, permits access through declared package `includes`, and points cross-package diagnostics back to the relevant package declaration. `hh_single_type_check` can accept a package configuration for the same checks.
