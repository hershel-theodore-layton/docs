Methods that do support dynamic retain the stub; behavior is unchanged when Sound Dynamic is disabled. [ae21dcb1bd](https://github.com/hershel-theodore-layton/hhvm/commit/ae21dcb1bd51c38dcad0eff29b862d8fa36ff810)
- `hh_server` now restarts when `__PACKAGES__.php` changes, just as it does for `.hhconfig`, so package membership and include changes are not left stale. [a7e3c34ae9](https://github.com/hershel-theodore-layton/hhvm/commit/a7e3c34ae97d9f0d3653b7a838190556cbe93cb0)
