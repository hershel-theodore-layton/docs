# 2023-03-01

## Highlights

- JSON output from `--tast-holes-batch` now includes each hole's filename, allowing callers to safely combine results from multiple input files. [738e1b8a3d](https://github.com/hershel-theodore-layton/hhvm/commit/738e1b8a3d4061f0b62c4a02e4c7311cbbaa6e99)

## Future Changes

- Pre-stable class refinements now allow multiple upper or lower bounds without requiring each later bound to be a subtype of the earlier one. The typechecker still verifies that the refined constant exists and has the correct type-or-context kind, validates every hint inside the refinement, and rejects recursive refinement types.
