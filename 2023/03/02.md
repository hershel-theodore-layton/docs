# 2023-03-02

## Highlights

- Sound-dynamic inference can now solve variables with `supportdyn<T>` on both sides, push `supportdyn` through `Traversable` and `KeyedTraversable`, and use safe dynamic-aware variance when checking overrides. This accepts more valid SDT collection and override patterns without permitting unrelated like types to override one another. [ccbed68c5c](https://github.com/hershel-theodore-layton/hhvm/commit/ccbed68c5ccb54e2790a7a4cfd363be3860e46ba) [58073f2561](https://github.com/hershel-theodore-layton/hhvm/commit/58073f25616e5823a1a70f58d57f3bf271ba7ae8) [7aec7bc986](https://github.com/hershel-theodore-layton/hhvm/commit/7aec7bc986fae2a37ec87c1cf305fc6f352ccf29)
- `HH\ImplicitContext\get_state_unsafe()` can report whether the current implicit-context state is null, value, soft-set, inaccessible, or soft-inaccessible. Observing this state can undermine memoization guarantees, so the API is intended only for controlled migrations and diagnostics. [9b41b6f14c](https://github.com/hershel-theodore-layton/hhvm/commit/9b41b6f14c861f31acf484fc5232b46cb5327903)
- A constructor declared `final` may no longer be overridden merely because its hierarchy uses `<<__ConsistentConstruct>>`; Hack now reports the override that HHVM would fatal on while loading the class. [7100e0a74a](https://github.com/hershel-theodore-layton/hhvm/commit/7100e0a74ae72bc652ad8fa4f0382fe0200eb5a7)
