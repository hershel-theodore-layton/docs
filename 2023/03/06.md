# 2023-03-06

## Highlights

- Standalone IDE mode now publishes fresh diagnostics after files are opened or changed, without waiting for a persistent `hh_server` connection. [735edbcea0](https://github.com/hershel-theodore-layton/hhvm/commit/735edbcea01cb50bde871406d824bdaf45843d31)
- A deployment in `PACKAGES.toml` may now select multiple domains, and each domain is interpreted as a regular expression. HHVM's package information now carries deployments so server requests can select the active package set from the host name. [8a423bfd07](https://github.com/hershel-theodore-layton/hhvm/commit/8a423bfd07548c5b93e58323442a907cc2072d8c) [44443ec5d4](https://github.com/hershel-theodore-layton/hhvm/commit/44443ec5d46865ea247f4ee120f1e353a622efcc)
- File attributes are now attached to module declarations. A file containing only `new module` declarations will no longer skip validation of an invalid or misspelled file attribute. [833db87aae](https://github.com/hershel-theodore-layton/hhvm/commit/833db87aae2966d9b64c4ab9a4af6d4c00d5da10)

## Security

- Blowfish password hashing now handles short salts correctly instead of returning an invalid result, addressing CVE-2023-0567. [8497459de0](https://github.com/hershel-theodore-layton/hhvm/commit/8497459de04deb21132e1282b3160bb3506bab73)
