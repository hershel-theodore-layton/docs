# 2023-03-07

## Highlights

- Refining a generic or variable of type `supportdyn<T>` with `as C<_>` now preserves the outer `supportdyn`, allowing it to push into supported containers. [2df43ba6d8](https://github.com/hershel-theodore-layton/hhvm/commit/2df43ba6d88f777d2219737ac0d54607d3201134)
- The capability requirements of several built-ins are now more precise. `cpu_get_count()` and `cpu_get_model()` require only `[read_globals]`; read-only APC queries also require `[read_globals]`, mutating APC operations require `[globals]`, and `apc_sma_info()` is `[]`. These are backwards-compatible relaxations from implicit `[defaults]`, so the functions are callable from more restricted contexts that still provide the stated capabilities. [190f4646d7](https://github.com/hershel-theodore-layton/hhvm/commit/190f4646d7f06e8b535e4bfe97f85644a6074689) [a7332ca5ba](https://github.com/hershel-theodore-layton/hhvm/commit/a7332ca5ba7c81a3275a9e1168e4962e1848feb0)
- Frames passed to an `fb_setprofile()` callback now include the call site's file and line, avoiding a separate `debug_backtrace()` solely to recover that information. [c09a67aaa0](https://github.com/hershel-theodore-layton/hhvm/commit/c09a67aaa016b093148069cb20b8f85dd4eed69f)

## Breaking Changes

- Source-level package definitions have been removed from Hack's lowerer. Define packages and their relationships in `PACKAGES.toml` instead. [cf1180f7eb](https://github.com/hershel-theodore-layton/hhvm/commit/cf1180f7eb821e70e7831005bf89dadda0e75155)
