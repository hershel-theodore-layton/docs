# 2023-03-08

## Highlights

- Sound-dynamic typing of `Shapes::idx()`, `Shapes::at()`, and `Shapes::keyExists()` now follows their transformed HHI declarations. Shape and `Pair` operations are no longer automatically pessimised, and Hack-array element bounds rely on `supportdyn` pushing instead. Projects should see more precise element types and errors that consistently enforce SDT arguments. - `<<__NoAutoDynamic>>` is now honored when a trait is parsed directly; annotated traits are no longer incorrectly treated as supporting dynamic under implicit pessimization. [d48859c686](https://github.com/hershel-theodore-layton/hhvm/commit/d48859c6869534648cd905ba6808d2ee70390c5a)
- Enum classes now participate in implicit sound-dynamic pessimization like ordinary classes. [53a512f6d9](https://github.com/hershel-theodore-layton/hhvm/commit/53a512f6d9b85a9e91ad13f022f1038ad683cad2)
