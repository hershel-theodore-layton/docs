# 2023-03-09

## Highlights

- Class type refinements such as `Box with { type T = int }` no longer require `<<file:__EnableUnstableFeatures('type_refinements')>>`. [4fc409a7f6](https://github.com/hershel-theodore-layton/hhvm/commit/4fc409a7f6d35f4cc972b5c6ba32ccb84e482e5f)
- Under sound dynamic, an `as` refinement from an integer to a string-backed enum—or the reverse—is now weakened to `~Enum`. This reflects the runtime coercion hazard instead of treating the result as a fully trusted enum value. [57bdb70e4f](https://github.com/hershel-theodore-layton/hhvm/commit/57bdb70e4fa882f4f8cb8bb6d3e5f1efffb6363a)
