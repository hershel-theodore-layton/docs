# 2023-03-10

## Highlights

- The right side of `??` is now treated as conditional when updating local refinements. Assignments performed only in that branch no longer incorrectly refine the environment as though the branch always ran. [d59878c0d8](https://github.com/hershel-theodore-layton/hhvm/commit/d59878c0d8a780dad4da1836254b893ebf4b360b)
- `hh check --ide-go-to-impl FILE:LINE,COLUMN` exposes go-to-implementation results through the command-line client. [ac050ce4d5](https://github.com/hershel-theodore-layton/hhvm/commit/ac050ce4d548f80f8e65f025bfce1f0134f2a130)

## Breaking Changes

- Function and lambda default arguments are now required to be constant expressions by default. This temporary default change was reverted on March 17. [9bc8be6524](https://github.com/hershel-theodore-layton/hhvm/commit/9bc8be6524f5dc6b4b5030eac1579139953a7ac3)

## Future Changes

- Trait hierarchy checks with pre-stable `require class` now report method conflicts that HHVM will encounter while flattening traits, while still allowing an interface conflict resolved by the required class. [cef6a2bef9](https://github.com/hershel-theodore-layton/hhvm/commit/cef6a2bef92a4b7f10bf274cdba6d2091f9f4960)
