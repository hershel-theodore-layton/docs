# 2023-03-12

## Highlights

- The new `package_exists(string): bool` built-in reports whether a package is available in the active deployment. In server mode the deployment is selected from the request host; CLI and repo-authoritative mode use the configured active deployment. With no active deployment, it reports whether the package is defined at all. [fdd040c474](https://github.com/hershel-theodore-layton/hhvm/commit/fdd040c4743ea09a1ef92810f95d312fa6324ef4)
