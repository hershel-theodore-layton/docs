# 2023-03-13

## Highlights

- Invalid `PACKAGES.toml` relationships now produce parsing error 1009. The checker reports references to undefined packages and module globs assigned to more than one package. [fbc8e0d7bb](https://github.com/hershel-theodore-layton/hhvm/commit/fbc8e0d7bb09d00728e3036aa9888c8cc1c91fe7)
- Implicit pessimization of an async function returning an enforced enum now applies the enum's base-type intersection inside `Awaitable<...>`, rather than intersecting the awaitable itself down to `nothing`. [95dae7a057](https://github.com/hershel-theodore-layton/hhvm/commit/95dae7a0571053eda4336aef3f33ca5abd0d272a)
- Enum classes may now carry the internal SDT marker used by implicit sound-dynamic mode, avoiding recursive subtype failures for pessimised enum classes. [4ff56661ca](https://github.com/hershel-theodore-layton/hhvm/commit/4ff56661ca780309ddf6d4baa491180ea6112212)
