# 2023-03-20

## Highlights

- Missing-required-XHP-attribute diagnostics no longer prefix the attribute name with `:`, avoiding the misleading suggestion that ordinary XML attribute syntax requires a colon. [3b174001fe](https://github.com/hershel-theodore-layton/hhvm/commit/3b174001fe79588197dfecb04becea4c708a0ed7)
- `hh --codemod-sdt JSONL cumulative-groups|independent-groups` can now apply an SDT analysis result by adding `<<__NoAutoDynamic>>`. Cumulative mode keeps groups that introduce no new type errors; independent mode evaluates and reverts each group separately. [4e986b3a3f](https://github.com/hershel-theodore-layton/hhvm/commit/4e986b3a3fe1121dfff1735c07edb8772779818f)
