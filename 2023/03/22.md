# 2023-03-22

## Highlights

- `PACKAGES.toml` now accepts `soft_includes`. Access across a soft include still produces a package diagnostic, but uses the distinct error code 4473 rather than hard cross-package error 4472, so migrations can suppress the soft boundary without hiding a later hard violation. [484aecd02c](https://github.com/hershel-theodore-layton/hhvm/commit/484aecd02c3f911d41eac115bed266fc64ce0a81) [4f27d55a1f](https://github.com/hershel-theodore-layton/hhvm/commit/4f27d55a1f9707dd6c2d4d2a5fa2c41af2308f9c)
- For `$base[$key] = $value`, Hack now checks `$key` before `$base`, matching HHVM's evaluation order. This fixes both unsound refinements and valid programs rejected because the old checker assumed the reverse order. [a993d20925](https://github.com/hershel-theodore-layton/hhvm/commit/a993d20925c78ca7d7cb01ab9af9bfa253b4c881)
