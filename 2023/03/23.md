# 2023-03-23

## Highlights

- Collection constructors with explicit type arguments can now infer like types from their values. For example, a `Pair<int, string>` built with a `~int` value is inferred as `Pair<~int, string>` instead of being rejected. [2b9cfa4290](https://github.com/hershel-theodore-layton/hhvm/commit/2b9cfa42901ab50b535f28cece2954ba840b01df)
- `vec` is no longer treated as an automatically pessimised built-in. A `vec<int>` indexes to `int`, while constructing a vector from `~int` values produces `vec<~int>` and preserves the dynamic boundary explicitly. [3beca4465d](https://github.com/hershel-theodore-layton/hhvm/commit/3beca4465d79f1c4da67079b10371fc4a6753386)
- HHVM now computes the package cache key after reading `PACKAGES.toml` and uses the correct file metadata, fixing cases where package edits failed to invalidate repository options. [c4f8aca11a](https://github.com/hershel-theodore-layton/hhvm/commit/c4f8aca11a949ca5de2a08ddc198f090ae0bf845)
