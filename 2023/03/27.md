# 2023-03-27

## Highlights

- `dict` is no longer automatically pessimised. Direct construction and indexing preserve value types such as `dict<string, int>`, while like-typed values produce an explicit type such as `dict<string, ~int>`. [73c97aac94](https://github.com/hershel-theodore-layton/hhvm/commit/73c97aac94bd703cd1bf23db0ce51f1b94911663)
- In autocomplete, typing `->` after a `vec`, `dict`, `keyset`, or `string` now offers compatible HSL functions and rewrites the expression into a function call with argument placeholders. [73284d7d46](https://github.com/hershel-theodore-layton/hhvm/commit/73284d7d46d1d7971acba3322e41dc09317f56ce)
- Package validation now requires each deployment's package set to be transitively closed over `includes` and reports the packages missing from an incomplete deployment. [43bcd2a962](https://github.com/hershel-theodore-layton/hhvm/commit/43bcd2a96284ba3b8ca5087bde5a56e5e0c00e71)

## Future Changes

- Symbol identification now sees method calls through a preview `readonly` expression, restoring navigation and references for those calls. [857047246c](https://github.com/hershel-theodore-layton/hhvm/commit/857047246c23b0718dc3e4f5c29987a8afc26d74)
