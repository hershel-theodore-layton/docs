# 2023-03-31

## Highlights

- HSL adds `Vec\map_with_key_async()`, which invokes an async callback with each original key and value in parallel and returns an `Awaitable<vec<_>>`. [c2341d38b1](https://github.com/hershel-theodore-layton/hhvm/commit/c2341d38b1c27f1da5871b30019179b03e0f98c9)
- Nested collection constructors with explicit types now keep precise inner types—for example, `vec<vec<int>>[vec[2, 3]]` remains `vec<vec<int>>` rather than acquiring an unnecessary like type. Mutable collection classes are now always treated as pessimised built-ins; the configuration flag no longer disables that behavior. [5ad92d1c7a](https://github.com/hershel-theodore-layton/hhvm/commit/5ad92d1c7a515f040bbed22e147ebb779c7b5575) [103067848a](https://github.com/hershel-theodore-layton/hhvm/commit/103067848a9e4be3ba1755fb40fa4a4de7c2e0a8)
- Lint 5650 recommends `async ... ==> await ...` when a synchronous lambda directly returns an `Awaitable`, improving stack traces. Lint 5651 warns about lambdas inferred as `Awaitable<Awaitable<_>>`, where an inner `await` was likely omitted. [328976bc0a](https://github.com/hershel-theodore-layton/hhvm/commit/328976bc0af15e8e08b2f3ffe8018f5cf1def8e3) [642ca62d90](https://github.com/hershel-theodore-layton/hhvm/commit/642ca62d9084e20135751032436476f842d7283a)
- The experimental `package NAME` expression now has type `bool`, and an undefined package name produces a naming error based on `PACKAGES.toml`. [480031f13c](https://github.com/hershel-theodore-layton/hhvm/commit/480031f13c9a3d7706496110d9cd25de169a3a58)
- Capability checks are now skipped for virtualized expression-tree calls, which are typechecked but never executed. Pure code can therefore construct DSL expressions whose virtual methods have `[defaults]` without receiving a false call-capability error. [9e6d3f539b](https://github.com/hershel-theodore-layton/hhvm/commit/9e6d3f539bb1b0c74286f0749fc72be264897f5d)
- Local-variable completion items now display the variable's inferred type instead of the generic label “local variable.” [4f8762d581](https://github.com/hershel-theodore-layton/hhvm/commit/4f8762d58175a5cc9c03fd99ca57db3b16065c9d)
- `HH\Lib\Async\Poll` and `BasePoll` no longer recurse through long already-satisfied awaitable chains, avoiding stack overflows in large polling workloads. [2033efe304](https://github.com/hershel-theodore-layton/hhvm/commit/2033efe3049156e17db788f94ffd0fa7409451a7)

## Breaking Changes

- Sound-dynamic function-call checking now evaluates each argument once instead of exploring exponentially many static/dynamic combinations. Some previously accepted generic calls can now require an explicit type argument when inference commits to a like type too early. [9f106c6329](https://github.com/hershel-theodore-layton/hhvm/commit/9f106c6329ea219beea2c0c6fe86fcae17f9dd9f)
