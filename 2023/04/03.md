# 2023-04-03

## Highlights

- A new lint reports casts such as `(int) new C()` where a non-primitive value is cast to a primitive in a way that is unlikely to be meaningful. [593f41db78](https://github.com/hershel-theodore-layton/hhvm/commit/593f41db7843d84ac2783d6a7da4d0dd6692980b)
- Nested type parameters in higher-kinded types no longer produce a false naming error for not beginning with `T`. [9b5699d6ee](https://github.com/hershel-theodore-layton/hhvm/commit/9b5699d6eef9a2f2f0862db5a5dd17dfe6432407)
- Watchman-backed status checks now qualify root-relative filenames correctly and keep the server's Watchman clock current. This fixes stale “No errors” results and indefinite `hh_server sync` waits after a file changes. [a084e13751](https://github.com/hershel-theodore-layton/hhvm/commit/a084e1375198f8ab2adb176febd6d3d0ca084c03) [a3f47f498e](https://github.com/hershel-theodore-layton/hhvm/commit/a3f47f498e682af49e814199fec9fe07b54ad76d)
- The missing-method diagnostic now offers one quick-fix that generates all required method stubs, rather than a separate fix for each method. [8dfff9994e](https://github.com/hershel-theodore-layton/hhvm/commit/8dfff9994e5170d3f1dbb330c8cf65d2e03bfe46)
- Invalid expression-tree splices now describe the DSL, the expected splice type, the actual Hack value, and the DSL's documentation link instead of reporting only generic expression-tree terminology. [833661e119](https://github.com/hershel-theodore-layton/hhvm/commit/833661e119bfdc3bfecc63a85f6b894e848dcb1e)

## Breaking Changes

- `HH\autoload_set_paths()` now always throws, as part of the migration to native autoloading. This change is backed out on April 10 while remaining callers are migrated. [d419828855](https://github.com/hershel-theodore-layton/hhvm/commit/d419828855998fc7c1f9e93647b6a4091647d956)
