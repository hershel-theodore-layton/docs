# 2023-04-04

## Highlights

- Failed nullsafe property access now prefers the actual missing or inaccessible-member error instead of the misleading message that a non-null receiver was expected to be `null`. [21cd44f60c](https://github.com/hershel-theodore-layton/hhvm/commit/21cd44f60cc47998992dadd44f83f388e59d3736)
- Sound-dynamic subtyping now accepts compatible open shapes on both sides of `supportdyn`, including when the right-hand shape adds optional fields. [6886c8cb21](https://github.com/hershel-theodore-layton/hhvm/commit/6886c8cb2116bec725878325a377f1835355496f)

## Future Changes

- Package-existence conditions now refine the typechecking environment. `if (package foo && package bar)` treats both packages as loaded inside the branch, while `invariant(package foo, ...)` treats the package as loaded for the rest of the block. [01178c77bd](https://github.com/hershel-theodore-layton/hhvm/commit/01178c77bd0ba96a64e7529de6d96964f4b9f6cd) [0b7729bf54](https://github.com/hershel-theodore-layton/hhvm/commit/0b7729bf54e693682f81eedb70c57d04501e114e)
- `PACKAGES.toml` can now parse soft deployments. This initial change only establishes the configuration representation; application and runtime support follows in later commits. [0cc3871280](https://github.com/hershel-theodore-layton/hhvm/commit/0cc38712808c43e9a5eb012758741faa7dd343fa)
