# 2023-04-05

## Highlights

- XHP completion now inserts required attributes, with snippet placeholders when the client supports them. [65e5432943](https://github.com/hershel-theodore-layton/hhvm/commit/65e543294384276fd13b0637addfad8331de2abb)
- “Extract into variable” is no longer offered for expression selections that cannot be extracted safely. [355e174dce](https://github.com/hershel-theodore-layton/hhvm/commit/355e174dcef782438d657a0ff5a583174909f7b7)
- Referencing an outer local directly inside an expression tree now produces a contextual diagnostic and a quick-fix that splices the variable into the tree. [2635c40267](https://github.com/hershel-theodore-layton/hhvm/commit/2635c4026766b4cb4075bc5acd3732250ab79f4e)
- Soft-package and soft-deployment validation now follows transitive soft relationships and reports invalid configurations more precisely. [657f4986f1](https://github.com/hershel-theodore-layton/hhvm/commit/657f4986f18fef5616d7b68b287a78701f38e1e4)

## Future Changes

- Under implicit pessimisation, `inout` parameters in function-type and lambda hints now receive like-types even when their runtime types are unenforced. [3be0d658a1](https://github.com/hershel-theodore-layton/hhvm/commit/3be0d658a18339fd9734f3e3b7decc17dd8d42c1)
- Abstract context constants no longer receive an implicit `as supportdyn<mixed>` bound. An unbounded context constant can therefore still be instantiated with `[]`, which is the context equivalent of `mixed`. [639c0f130a](https://github.com/hershel-theodore-layton/hhvm/commit/639c0f130af7168876fd66939e7dfb339234238f)
