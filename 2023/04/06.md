# 2023-04-06

## Highlights

- A lambda nested inside a `finally` block may return normally; it is no longer treated as though its own body were part of the enclosing `finally`. [52c136dd3a](https://github.com/hershel-theodore-layton/hhvm/commit/52c136dd3aa4de79ae2643627faccd48a31a8393)
- Rust elaboration now reports more accurate positions and error kinds for reading from `[]`, invalid `<<__Deprecated>>` strings, generic entry points, duplicate class constants, and wildcard type parameters. [e25f032cde](https://github.com/hershel-theodore-layton/hhvm/commit/e25f032cdee7d715a0b8436fd50cf1ad26ee8e0b) [a0b5a2c4a4](https://github.com/hershel-theodore-layton/hhvm/commit/a0b5a2c4a4e14b54d7801d76e14eb690c2df7539) [c681a172f8](https://github.com/hershel-theodore-layton/hhvm/commit/c681a172f89991c5504b0c8c3d2e9a2b961c0b13) [93930d39c8](https://github.com/hershel-theodore-layton/hhvm/commit/93930d39c8a50cdafdcbd4018c6bff9484fbab65) [fcab758a8c](https://github.com/hershel-theodore-layton/hhvm/commit/fcab758a8cc61d2c918247f5fe32c0f4ec18df11)

## Future Changes

- Implicit pessimisation now rejects a bare or implicit return from a function whose declared return type is non-`void`; it no longer accepts the missing value through `dynamic`. [6f9c0e2cb3](https://github.com/hershel-theodore-layton/hhvm/commit/6f9c0e2cb39dc57675cfa5723c394582e481d6e0)
- The experimental `newtype_super_bounds` feature now honors class-typed lower bounds such as `newtype T super C = mixed`. [b87d8ce093](https://github.com/hershel-theodore-layton/hhvm/commit/b87d8ce093d9e0c43d114d8d98cbeaad9ab0938d)
