# 2023-04-10

## Highlights

- The April 3 change that made `HH\autoload_set_paths()` always throw has been backed out, and the userland autoload map has been restored. Calls work again subject to the existing native-autoload deprecation controls. [6a00b1447e](https://github.com/hershel-theodore-layton/hhvm/commit/6a00b1447eb7c047e1d58e583a8d914f4676a905)
- Hover and go-to-definition now work on locals listed in a lambda's `use ($x, $y)` capture clause and display their inferred types. [5953957e90](https://github.com/hershel-theodore-layton/hhvm/commit/5953957e902b991690ad91958839609cb79bf805) [9e1a66f49f](https://github.com/hershel-theodore-layton/hhvm/commit/9e1a66f49f3304501b4dc9c2c1213392bb59fbda)

## Future Changes

- The package feature now recognizes `<<__CrossPackage('name')>>` on functions and methods. The named package is considered loaded within the callable, and unknown package names are rejected. [d60543f58b](https://github.com/hershel-theodore-layton/hhvm/commit/d60543f58b59e49cbdddca5e18bd9fdfe6cfa2a0) [eb96979d36](https://github.com/hershel-theodore-layton/hhvm/commit/eb96979d366fe8ed2d072c5a65d783b7e8314811)
- Soft includes and soft deployments are now carried through the package FFI and exposed to HHVM's package reflection. [126c7ce712](https://github.com/hershel-theodore-layton/hhvm/commit/126c7ce7125faaccdc3fc3cd7cc6ef75f9007177)
