# 2023-04-13

## Highlights

- Expression-tree blocks are now a stable syntax feature and no longer require `<<__EnableUnstableFeatures('expression_tree_blocks')>>`. [e1aa7c4ce7](https://github.com/hershel-theodore-layton/hhvm/commit/e1aa7c4ce715b357c721eb0c5f9485a8afea670f)
- Local-variable find-references and rename operations can now be served by the standalone IDE daemon, avoiding a dependency on a fully ready `hh_server`. [d4fc2e39a8](https://github.com/hershel-theodore-layton/hhvm/commit/d4fc2e39a8f0592b3fd84d2db219fddd3567e6be) [b3161a24dc](https://github.com/hershel-theodore-layton/hhvm/commit/b3161a24dc1d0252f20531ac664077534bbc2235)
- Code in the default package is now callable from every package, while still being allowed to use `package foo` checks before calling into optional packages. Related diagnostics now point to the originating module. [0a77e5cbc1](https://github.com/hershel-theodore-layton/hhvm/commit/0a77e5cbc17f7419ac2fca0144bc0056c899a0db)

## Future Changes

- Updating a `supportdyn<shape(...)>` with a value that does not support dynamic now drops the `supportdyn` wrapper instead of retaining an unsound guarantee. [d3b455e436](https://github.com/hershel-theodore-layton/hhvm/commit/d3b455e4367eab90f24a619d01955c69112e61c6)
- Sound-dynamic error output now omits redundant `as supportdyn<mixed>` bounds and internal references to `supportdynamic.hhi`. [1dc8673888](https://github.com/hershel-theodore-layton/hhvm/commit/1dc8673888cf5efa809bad4454302674caaa02b8) [f3a4cb122f](https://github.com/hershel-theodore-layton/hhvm/commit/f3a4cb122f2793c1767d20f21d0f33d34661d892)
