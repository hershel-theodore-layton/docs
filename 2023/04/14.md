# 2023-04-14

## Highlights

- `DateTime::format()` is now declared with an empty capability list. Because it previously had the implicit `[defaults]` requirement, this is a backwards-compatible relaxation that permits calls from pure contexts. [9137fefeb3](https://github.com/hershel-theodore-layton/hhvm/commit/9137fefeb3feef6ba5b0e8fe843975796b7debf6)
- Failed calls to sound-dynamic functions now prefer the ordinary static argument error when both static and like-typed checks fail, avoiding confusing diagnostics involving `~_`. [814812d3a3](https://github.com/hershel-theodore-layton/hhvm/commit/814812d3a3c33d5c36e7b4e2ed8f9b4f29eb1bd1)

## Breaking Changes

- The boolean `Autoload.UserlandEnabled` option has been replaced by `Autoload.UserlandDisabled` and `Autoload.UserlandDisabledSampleRate`. A disabled value greater than 1 makes `HH\autoload_set_paths()` throw; a positive value emits the native-autoload deprecation notice and sampled migration logging. Deployment configuration should move to the new option names. [908ec46200](https://github.com/hershel-theodore-layton/hhvm/commit/908ec462008ff7b6e1803a6219ac77d39afd94e6)

## Future Changes

- The unstable case-type feature now has parser, declaration, and subtyping support. Syntax such as `case type C<T> as Bound = int | vec<T>;` defines an opaque type whose variants are accepted as subtypes; unlike a `newtype`, it remains opaque even in its defining file.
