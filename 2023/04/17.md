# 2023-04-17

## Highlights

- The invalid-comparison lint now uses the typechecker's disjointness rules, reports the concrete compared types, and covers `==` and `!=`. It no longer warns merely because two opaque enums or interface types differ when they could still compare equal at runtime. [43eb4c87ef](https://github.com/hershel-theodore-layton/hhvm/commit/43eb4c87efe749e78cadfc352153c101818cab6b)

## Future Changes

- Package expressions are now executable: HackC lowers `package foo` to `package_exists('foo')`, matching the type refinements already performed for package conditions. [5d67079833](https://github.com/hershel-theodore-layton/hhvm/commit/5d67079833bd249ded8bca140fb328bcf32e6998)
