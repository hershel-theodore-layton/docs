# 2023-04-18

## Highlights

- An unbounded generic and one explicitly bounded by `mixed` now receive the same class-access diagnostics, including for calls through `classname<T>`. [e6d63d29f3](https://github.com/hershel-theodore-layton/hhvm/commit/e6d63d29f3d1dcec51c0ea4dbb5199025b86ffff)
- Renaming an interface method no longer attempts to add a deprecated forwarding method with a body, which is invalid in an interface. [34d935ebce](https://github.com/hershel-theodore-layton/hhvm/commit/34d935ebce6826d1a513deae29209a31b1454c3c)

## Future Changes

- The default `Autoload.UserlandDisabledSampleRate` is now 1, so deprecated `HH\autoload_set_paths()` use is recorded for every call while migration logging is enabled. [5a779620cd](https://github.com/hershel-theodore-layton/hhvm/commit/5a779620cd553dc6eeec91f086024a97c63cb0cd)
