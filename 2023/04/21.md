# 2023-04-21

## Highlights

- Hover, type-at-position, and go-to-definition now recognize source-level `invariant()` calls instead of exposing the internal desugared `invariant_violation()` call. [466134e155](https://github.com/hershel-theodore-layton/hhvm/commit/466134e155f4ef6e018a038d23c31c31fca4ed5f)

## Future Changes

- Open shape types now retain the type of unknown fields internally and may print it as `shape('known' => int, _ => nonnull)`. Ordinary `...` remains equivalent to unknown fields of type `mixed`; the richer form primarily supports sound-dynamic inference. [a5993a5a69](https://github.com/hershel-theodore-layton/hhvm/commit/a5993a5a699b01f552903d766beab6b7ef342c6e)
