# 2023-04-26

## Highlights

- The Ed25519 primitives added to the Sodium runtime on April 19 are now present in the bundled HHI, so Hack code can call them without local declarations. [f977a1702b](https://github.com/hershel-theodore-layton/hhvm/commit/f977a1702bc9d45f026cbdbafeb07107365214eb)
- Standalone IDE diagnostics are now refreshed after closing a modified file, restoring squiggles for the version on disk instead of leaving diagnostics for discarded editor contents.
