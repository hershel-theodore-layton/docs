# 2023-04-27

## Highlights

- `hh_single_type_check` now accepts general `.hhconfig` overrides as `--config key=value`, for example `--config timeout=4`. [ee8d8d5657](https://github.com/hershel-theodore-layton/hhvm/commit/ee8d8d56572fd543a721e64a4aa6f2e274f95e35)
- Opening or closing an unchanged file in the IDE no longer cancels a running full check, and a check interrupted by an actual edit now resumes after five seconds even when the client consumes streaming errors. [c99b489259](https://github.com/hershel-theodore-layton/hhvm/commit/c99b489259993fca8f62a015b8db9c6701912ba2) [3f8a4ee77f](https://github.com/hershel-theodore-layton/hhvm/commit/3f8a4ee77fc68b01ec4ef2c12b9845cd17a5bdce)

## Future Changes

- Explicitly typed nested `dict` and `vec` literals no longer acquire unnecessary like-types solely from their expected outer collection type. [2159d75c1a](https://github.com/hershel-theodore-layton/hhvm/commit/2159d75c1aa7455f0b7673a0eeddc8ebbc7e0bbf)
