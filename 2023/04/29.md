# 2023-04-29

## Highlights

- New `HH\stdin()`, `HH\stdout()`, and `HH\stderr()` functions replace the magic `STDIN`, `STDOUT`, and `STDERR` constants. They return the corresponding resource and throw `RuntimeException` in server mode, where standard streams are unavailable. [f89adc0d2b](https://github.com/hershel-theodore-layton/hhvm/commit/f89adc0d2b9d9a1f18ba825034da140e58a8adbe)
- Standalone IDE diagnostics now refresh lazily on code-action requests, hide typing errors while a parse error is present to match `hh`, and remain visible when an in-progress full check restarts. [98c35d4bbb](https://github.com/hershel-theodore-layton/hhvm/commit/98c35d4bbbba8d122a993f44785a43ebc0dfbdfb) [276933c9b7](https://github.com/hershel-theodore-layton/hhvm/commit/276933c9b75887952960fb22dcea6347531a58f1) [1e6f53b906](https://github.com/hershel-theodore-layton/hhvm/commit/1e6f53b90696d7dc23b9a109553858d51b83b9fd)
- Repository-authoritative builds with an active deployment now omit files belonging to packages outside that deployment. Builds fail with a clear error when the configured deployment is absent from `PACKAGES.toml`; files that define modules remain included. [b170bd05fa](https://github.com/hershel-theodore-layton/hhvm/commit/b170bd05fa6e5a7a292186e482d1419e6dbf4f81)
