# 2023-05-02

## Highlights

- `Shapes::toDict()` and `Shapes::toArray()` now preserve the unknown-field type of open `supportdyn` shapes instead of losing that information during conversion. [ae1529d007](https://github.com/hershel-theodore-layton/hhvm/commit/ae1529d00758116f76e9bee588e26bd420635925)
- Package-aware function subtyping now reports mismatched `__CrossPackage` requirements in method overrides. A function restricted to one package can only override a function with the same package restriction, while an unrestricted function remains a valid supertype. [a9ec057078](https://github.com/hershel-theodore-layton/hhvm/commit/a9ec0570789ee1318c611574c5c0fe3e72d64fc1)
- Uncaught exceptions from `hh check` once again print their call stack, making failed typechecker invocations actionable without additional logging. [21d9be5ae9](https://github.com/hershel-theodore-layton/hhvm/commit/21d9be5ae9075717c216d07c93c141c2da84f331)

## Security

- Multipart upload handling now uses overflow-safe size calculations. This fixes an integer overflow through which a sufficiently large multibyte upload could cause an out-of-bounds write; deployments accepting uploads should update promptly. [6c8ad0530c](https://github.com/hershel-theodore-layton/hhvm/commit/6c8ad0530c73abcd38f02a954be7e84e6807d2e9)
