# 2023-05-04

## Highlights

- Sound Dynamic subtyping now prefers the concrete type mismatch over a secondary `dynamic` mismatch, and implicit-pessimisation failures choose more useful union branches. Error messages should point closer to the actual incompatible type. [5e765d6794](https://github.com/hershel-theodore-layton/hhvm/commit/5e765d67945cd47787e33a158a61b418fc96fc98) [2523b6b4f0](https://github.com/hershel-theodore-layton/hhvm/commit/2523b6b4f0f338cb31da8ea9f100ecb9c2758f8f)
- Rename now updates references in unsaved open files instead of relying exclusively on positions from the on-disk `hh_server` state. [8f8391cdbd](https://github.com/hershel-theodore-layton/hhvm/commit/8f8391cdbdda8eea4d54f7b2944ca6b750670b8d)
- The debugger now handles captures from both current Hack lambdas and older closure forms, and its REPL can evaluate async expressions and join the resulting wait handle. [cf298fe579](https://github.com/hershel-theodore-layton/hhvm/commit/cf298fe57984779c39e09fc89f7d6f700dde12f5) [66be6e7275](https://github.com/hershel-theodore-layton/hhvm/commit/66be6e72753baa2579511a18cb573b3582c9c6b0)

## Breaking Changes

- Enum supertyping is now fully released and its `.hhconfig` release flag has been removed. Enum `includes` declarations are checked unconditionally. [910382a92e](https://github.com/hershel-theodore-layton/hhvm/commit/910382a92e75b4d927caf7f44d132464b4737665)
