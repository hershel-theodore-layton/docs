# 2023-05-06

## Highlights

- Equality comparisons involving `num` or `arraykey` no longer receive the incorrect diagnostic that the comparison can never succeed. [7c35e3b3c3](https://github.com/hershel-theodore-layton/hhvm/commit/7c35e3b3c34f52030f391f696cba0efd84d3c952)

## Breaking Changes

- `HH\autoload_get_paths()` has been removed. Applications can no longer enumerate every file known to the native autoloader through this API. [fc420c2e7d](https://github.com/hershel-theodore-layton/hhvm/commit/fc420c2e7d361ace2c8459193d3194eeec3b316b)
