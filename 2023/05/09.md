# 2023-05-09

## Highlights

- A new “flip around comma” code action swaps adjacent arguments, parameters, collection elements, shape fields, and similar comma-separated items. [a9aa1df6ee](https://github.com/hershel-theodore-layton/hhvm/commit/a9aa1df6ee18e1d2a7c107c11fd893204b8853ae)

## Breaking Changes

- XHP attribute access now typechecks the underlying `getAttribute()` call, including the method's signature and required capabilities. Custom XHP bases with an incompatible or missing method may receive new errors where the attribute is read. [c6b3bc7f59](https://github.com/hershel-theodore-layton/hhvm/commit/c6b3bc7f59ff379db6b5b12aafc0e3b4f8afa166)

## Future Changes

- Runtime validation for `<<__ModuleLevelTrait>>` requires the annotated trait to be public and permits it to use only other module-level traits. Invalid combinations fail consistently before optimized execution. [d38803e101](https://github.com/hershel-theodore-layton/hhvm/commit/d38803e1012ec02443df61ecca82a0b2c2011318)
