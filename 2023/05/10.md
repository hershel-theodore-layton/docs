# 2023-05-10

## Highlights

- Sound Dynamic hover now handles more expression and declaration forms correctly. Structured JSON from `--type-at-pos` hides migration-only like-type wrappers while the display string retains them, and redundant `HH\FIXME\UNSAFE_CAST_NONNULL` casts can now be removed by the quick-fix and codemod. ## Breaking Changes

- Source use of `<<__NoAutoDynamic>>` now requires `enable_no_auto_dynamic = true`; HHI declarations remain exempt. [da86d4290f](https://github.com/hershel-theodore-layton/hhvm/commit/da86d4290fffd0e69383aabecbb379687d47b6e0)
- Reserved type-name checks now apply uniformly to class, interface, trait, enum, enum-class, and type-alias declarations, including declarations inside namespaces. `varray` and `darray` are explicitly unavailable as alias names, while `classname` is now allowed as a user-defined classish or enum name. Direct HackC users may newly see parse errors for names that `hh` already rejected.
