# 2023-05-15

## Highlights

- Switch-exhaustiveness diagnostics list at most ten missing cases, in declaration order, instead of attempting to render every case and potentially crashing on large enums. [5c78876f00](https://github.com/hershel-theodore-layton/hhvm/commit/5c78876f00c565c7b75813d5e16e9de6697763fa)
- A successful equality comparison now refines each operand with the other's type. For example, inside `$value === 42`, a `?int` value is known to be `int` without a separate non-null assertion. [ec4f5b16e0](https://github.com/hershel-theodore-layton/hhvm/commit/ec4f5b16e01140f3acbd97d8a00bb7cac1340a6c)

## Breaking Changes

- The obsolete `hh --coverage` and `hh --color` commands, along with the old IDE coverage status, have been removed. They predated constraint-based typechecking and no longer represented meaningful type coverage. [10a04c1344](https://github.com/hershel-theodore-layton/hhvm/commit/10a04c1344556aa4b4d076145656a7f856477109)
- Enabling implicit Sound Dynamic no longer implicitly enables the `supportdyn` type-hint syntax. Projects writing `supportdyn<T>` directly must explicitly enable `enable_supportdyn_hint`; generated pessimised declarations are unaffected. [126a09182e](https://github.com/hershel-theodore-layton/hhvm/commit/126a09182e563d16cda8bd42f4e551a030c2b32d)
