# 2023-05-25

## Highlights

- Sound Dynamic type-constant projection now ignores migration-only `supportdyn<mixed>` bounds that could otherwise produce an unconstrained type and accept invalid generic projections. [cd61e02391](https://github.com/hershel-theodore-layton/hhvm/commit/cd61e02391aa8d32189ab09d7197619e546bbfd5)
- Implicit pessimisation no longer emits “not dynamically callable” errors, which indicate an implementation issue rather than an actionable project error. Explicit opt-outs such as `__NoAutoDynamic` continue to receive the check. [c32811a2e4](https://github.com/hershel-theodore-layton/hhvm/commit/c32811a2e4a8d840c8a7853ac4dbf5eb3b2c1e2e)

## Future Changes

- Experimental package checking now rejects code in the default package when it accesses a public symbol from a non-default package that the default package does not include. [3a23391ec7](https://github.com/hershel-theodore-layton/hhvm/commit/3a23391ec713f017da51e87dae1a0998b17c3387)
