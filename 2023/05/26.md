# 2023-05-26

## Breaking Changes

- When deployment enforcement is enabled, HHVM now rejects direct, dynamic, function-pointer, and closure-mediated calls to top-level functions whose module is outside the active deployment. [9ad9cac167](https://github.com/hershel-theodore-layton/hhvm/commit/9ad9cac167fe45de86dc0890b9bdd89be5b3d660)

## Future Changes

- Experimental case types now require conservatively disjoint runtime variants. Variants whose shallow runtime tags may overlap produce a type error; this initially includes all pairs of object types and overlapping primitive unions. [ab1c79066d](https://github.com/hershel-theodore-layton/hhvm/commit/ab1c79066d2d816dc479cc1cbfc17385b4d91c3f)
