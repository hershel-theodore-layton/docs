# 2023-05-30

## Highlights

- When both ordinary and dynamic-aware checks of a Sound Dynamic function call fail, Hack now reports whichever branch produces fewer errors. This suppresses cascades of like-type mismatches in favor of the underlying application error. [ba26aab5fd](https://github.com/hershel-theodore-layton/hhvm/commit/ba26aab5fd8aa7ada32feb4a70387cb64e2ea483)
- All IDE code actions are now resolved lazily after selection, reducing the work required to display the initial lightbulb menu. [07b43be5a5](https://github.com/hershel-theodore-layton/hhvm/commit/07b43be5a58c69deec8edbba19ecd058496eecb2)

## Future Changes

- The experimental `typed_local_variables` feature introduces declarations such as `let $value: int = 1;`. This initial step parses and erases the annotation to an ordinary assignment; full assignment consistency and possible runtime enforcement are still future work. [489986a389](https://github.com/hershel-theodore-layton/hhvm/commit/489986a389b702d353325254cb0ea24fb6bd453a)
