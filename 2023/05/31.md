# 2023-05-31

## Highlights

- Built-in container factory functions now opt out of automatic pessimisation where their implementations guarantee the declared result, removing unnecessary like-types from returned containers. [b24a872b62](https://github.com/hershel-theodore-layton/hhvm/commit/b24a872b6208b3ab90425a2bcc327d0960a39ee7)
- Hover no longer displays the implicit `as mixed` rendering of Sound Dynamic's synthetic `as supportdyn<mixed>` generic bound. [d6f94a7cf1](https://github.com/hershel-theodore-layton/hhvm/commit/d6f94a7cf1eca030e72461aabccfb604d9b52049)

## Breaking Changes

- The legacy `hh --auto-complete` command has been removed. Editor integrations and other consumers should use the IDE autocomplete service. [7ff9a5ae35](https://github.com/hershel-theodore-layton/hhvm/commit/7ff9a5ae35d8eb8da1ec3af635abc17c5c23fc6d)
