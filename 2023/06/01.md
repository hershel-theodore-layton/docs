# 2023-06-01

## Future Changes

- Under implicit pessimisation, readonly array updates now look through `readonly` expressions before handling like-types. This fixes incorrect inferred types for readonly array operations. [6279fa521a](https://github.com/hershel-theodore-layton/hhvm/commit/6279fa521a0b36f14f087d35c7aab828f9de97af)
- The typed-local parser now correctly requires the declaration tokens instead of asserting that they are present, producing syntax errors rather than parser failures for malformed `let $x: T = ...` declarations. [553b4196ef](https://github.com/hershel-theodore-layton/hhvm/commit/553b4196ef1497131b568f319083624a9669e525)
