# 2023-06-02

## Highlights

- Nullable member-access errors now offer an “add null-safe get” action that changes same-line `$value->member` access to `$value?->member`. [9a7621ecd2](https://github.com/hershel-theodore-layton/hhvm/commit/9a7621ecd215b62f694a428e938e8400e497bb2d)

## Breaking Changes

- Runtime type tests such as `$value is dynamic` are now rejected. HHVM cannot test whether an arbitrary value supports dynamic, so using the result to refine `$value` to `dynamic` created a type hole. Test for a concrete runtime type instead. [89bedcf12d](https://github.com/hershel-theodore-layton/hhvm/commit/89bedcf12d1be47f6a2f6ed69fde67e2cdbc700c)

## Future Changes

- The nested-`Awaitable` lint again recognizes `Awaitable<~Awaitable<T>>` under implicit pessimisation, so accidental double-awaitable returns are not hidden by the like-type wrapper. [979f436be9](https://github.com/hershel-theodore-layton/hhvm/commit/979f436be9a894280623b2c14f8324c9f1b02bf1)
