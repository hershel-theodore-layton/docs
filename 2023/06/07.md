# 2023-06-07

## Highlights

- With deployment enforcement enabled, accessing a class, enum, or enum class outside the active deployment now throws `DeploymentBoundaryViolationException`. This covers class pointers, static calls, static properties, and class constants in addition to top-level functions. [f86c18384b](https://github.com/hershel-theodore-layton/hhvm/commit/f86c18384b5547b0e9082b8532f9b79291285946)

## Future Changes

- Unstable case-type variants now undergo a recoverability check using the typechecker's `is`/`as` refinement logic. This initial check rejects variants whose refined type does not recover the declared variant, but does not yet filter every type that is invalid in a runtime type test. [59206db165](https://github.com/hershel-theodore-layton/hhvm/commit/59206db16533850eba295d3c38ac89b4be8cd1f8)
