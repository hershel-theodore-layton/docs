# 2023-06-09

## Highlights

- Projects may add a repository-root `CUSTOM_ERRORS.json` file whose pattern rules attach project-specific explanations to matching Hack errors. The configuration is loaded by `hh_server`, `hh_single_type_check` through `--custom-error-config-path`, and the standalone IDE diagnostic path. [4f14454979](https://github.com/hershel-theodore-layton/hhvm/commit/4f14454979418b117956e7081eb72b65dd05828f) [bc7eeb8c69](https://github.com/hershel-theodore-layton/hhvm/commit/bc7eeb8c6955993dcaa5c4f5aa6a929639e2111a) [5b96c02ea8](https://github.com/hershel-theodore-layton/hhvm/commit/5b96c02ea8054cfefa089cf09aa88e59e287a556) [42214e464a](https://github.com/hershel-theodore-layton/hhvm/commit/42214e464a8626d2b6dbb72152cf5c5cdf876139)
- A new “inline method” refactoring replaces a suitable method call with the method body and removes the method when safe. [dcc03923cb](https://github.com/hershel-theodore-layton/hhvm/commit/dcc03923cb521110201e5f7369cf41c230268e67)
- Autocomplete returns snippets only when placeholders or edits require snippet semantics, reducing unwanted snippet-mode behavior for ordinary completions. [741b3123bf](https://github.com/hershel-theodore-layton/hhvm/commit/741b3123bf8a301342e401d742915ee1be2fdded)
- Standalone IDE diagnostics no longer build up a backlog while typing in large files; obsolete intermediate TAST computations are discarded so squiggles jump to the latest edit. [cad5047300](https://github.com/hershel-theodore-layton/hhvm/commit/cad5047300655142ff65548a4d72cd225cb6a874)
- Moving a module between packages is now treated as a major incremental change, ensuring all affected dependents are rechecked. [ace5a949c7](https://github.com/hershel-theodore-layton/hhvm/commit/ace5a949c78a6d58966be71eaaeb9d9cc04ce1dc)
