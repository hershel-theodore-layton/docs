# 2023-06-12

## Highlights

- The IDE now offers “Extract interface” on suitable classes, creating an interface from selected methods and updating the class to implement it. [80613d1a06](https://github.com/hershel-theodore-layton/hhvm/commit/80613d1a064880c73216efb61499c7644696480b) [a0fab0a144](https://github.com/hershel-theodore-layton/hhvm/commit/a0fab0a144981b48f2713fd9c240015f2583d46d)
- Autocomplete no longer eagerly solves unconstrained type variables to `nothing`, preserving useful candidates when only upper-bound information is available. [130ca5f9f4](https://github.com/hershel-theodore-layton/hhvm/commit/130ca5f9f4487da660082f4fd921fc4939611a3c)
- Shape-indexing diagnostics now mention `??` alongside `Shapes::idx()` when a default value is appropriate for both a missing field and `null`. [5f1622b165](https://github.com/hershel-theodore-layton/hhvm/commit/5f1622b165b805a35c804877e8158ef961b4e502)

## Future Changes

- Typed local variables now have initial typechecking support. A declaration such as `let $x: arraykey = 1` constrains every subsequent assignment to `$x`, while flow-sensitive inference may still refine its current type more narrowly. The syntax remains gated by `typed_local_variables`. [713305f6b3](https://github.com/hershel-theodore-layton/hhvm/commit/713305f6b3972363f8fb3b23bb05f7a898ffdd07)
