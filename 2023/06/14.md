# 2023-06-14

## Highlights

- The Hack status-bar hover now includes the repository root, clarifying which LSP instance is reporting status when several projects are open. [1c740a1b2e](https://github.com/hershel-theodore-layton/hhvm/commit/1c740a1b2e0e7ed21d890b108eeda5b7c251f536)
- Standalone IDE diagnostics appear as soon as the naming table finishes loading, without waiting for a cursor movement or a close-and-reopen cycle. [74f001e588](https://github.com/hershel-theodore-layton/hhvm/commit/74f001e588557caa3a6ca647ae44a0b09a3c5df8)
