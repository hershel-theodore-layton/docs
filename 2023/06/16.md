# 2023-06-16

## Highlights

- Filesystem errors encountered while reading package or custom-error configuration are now reported rather than silently ignored. [73a7fc0d89](https://github.com/hershel-theodore-layton/hhvm/commit/73a7fc0d89d6742df96143b8fe8c9bab82d14f50)
- Rename, find-references, and go-to-implementation requests served through an `hh` shell-out now return errors reliably and honor LSP cancellation. Starting a newer shell-out cancels the displaced request instead of leaving it pending. [e04a247731](https://github.com/hershel-theodore-layton/hhvm/commit/e04a24773108b3b71ce8db157b6ca3eedd8bfd44) [7aaf84b16c](https://github.com/hershel-theodore-layton/hhvm/commit/7aaf84b16c7eef9058c73696706ff49b1d4af171) [6c5ce3afca](https://github.com/hershel-theodore-layton/hhvm/commit/6c5ce3afca1c8f5f571b2c1c2cb8a91f47b035c2)
- A client/server version mismatch no longer makes the client forcibly restart `hh_server`; the monitor handles the mismatch and termination flow. [1c24979190](https://github.com/hershel-theodore-layton/hhvm/commit/1c24979190db9e9d59d3c863376a7c1910dc036a)

## Future Changes

- `hackfmt` now formats typed locals as `let $x: T = expression;`, with appropriate line breaking for long types or initializers. [147008b7f1](https://github.com/hershel-theodore-layton/hhvm/commit/147008b7f103b457cf3ecb840041a062dc8942d4)
- When typed-local syntax is enabled for a file, the IDE offers “Add local type hint” on assignments and names the target variable in the action. It is not offered in files without the feature opt-in. [4c3ab66c12](https://github.com/hershel-theodore-layton/hhvm/commit/4c3ab66c129befe5191522b50fa92fce41a22b89) [d80d3f81c9](https://github.com/hershel-theodore-layton/hhvm/commit/d80d3f81c9beb97860e3e0bfd0b622a6ab4b1c4f) [7987bfc07d](https://github.com/hershel-theodore-layton/hhvm/commit/7987bfc07de925f7c1563ee4e43cd0cb5d036b7d)
- Sound-dynamic array updates hidden by a `FIXME` now preserve `supportdyn` on the value type instead of widening the array to `mixed`. [fb963301e2](https://github.com/hershel-theodore-layton/hhvm/commit/fb963301e20d6841e883fdaed254c06ca241b009)
