# 2023-06-20

## Highlights

- Documentation comments on `type` and `newtype` declarations are now retained in the AST and symbol index, making them available to code browsers and other indexing consumers. [f0d2510328](https://github.com/hershel-theodore-layton/hhvm/commit/f0d2510328a0919a98f1387ea29de222a6f616da) [4ce540d910](https://github.com/hershel-theodore-layton/hhvm/commit/4ce540d910cf9cc0d7f6cf1ac832cddf905c4d6b)
- The bundled HHI now exposes `record_visited_files(): void` and `get_visited_files(): keyset<string>` for applications that need to record which source files a request loads. [46bee8cf1e](https://github.com/hershel-theodore-layton/hhvm/commit/46bee8cf1e365441fde84f991465a91018da3846)

## Future Changes

- Typed-local errors at control-flow joins now point to the join that caused the incompatible assignment and retain the flow-sensitive type after reporting the violation.
