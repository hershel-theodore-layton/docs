# 2023-06-21

## Highlights

- Go-to-implementation now accounts for unsaved editor contents, so results reflect dirty files rather than only the last versions on disk. [9e911b1aaf](https://github.com/hershel-theodore-layton/hhvm/commit/9e911b1aaf2bf4e2d3179a53ab2c3b43d3ef0885)

## Future Changes

- Refining a `vec<T>` to a tuple now preserves both the tuple element intersections and the original `vec<T>` constraint. This retains `supportdyn` information during tuple destructuring. [5eed6b73d3](https://github.com/hershel-theodore-layton/hhvm/commit/5eed6b73d3bf2ed8601d37d37e4668261cb6363c)
- Case-type well-formedness now expands nested case types to their actual variants, so a definition such as `case type B = A | bool` is accepted when `A` itself has a disjoint variant such as `int`. Case types also work correctly as upper bounds on generic parameters. [a23680767d](https://github.com/hershel-theodore-layton/hhvm/commit/a23680767d49ec7f2149d2e5e200b906a19e35c1) [c4f5f83241](https://github.com/hershel-theodore-layton/hhvm/commit/c4f5f83241ff7e7c4c8f7b863b6459a9ef2f0bbb)
