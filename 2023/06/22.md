# 2023-06-22

## Highlights

- The IDE now loads its naming table from disk by default, allowing standalone features to become useful sooner after startup. [1ddca58a12](https://github.com/hershel-theodore-layton/hhvm/commit/1ddca58a12ccb36c25ac2a1172fedb458f626802)

## Breaking Changes

- `Autoload.Enabled` has been removed because native autoloading is always enabled. Configuration that still sets the option should remove it; it no longer controls runtime behavior. [7e2baa2a3d](https://github.com/hershel-theodore-layton/hhvm/commit/7e2baa2a3dcdb6fac64d985b448106f59c9b661f)

## Future Changes

- The explicit sound-dynamic pessimiser now understands case-type declarations and pessimises them using the same rules as opaque `newtype` declarations. [c037d9ebc0](https://github.com/hershel-theodore-layton/hhvm/commit/c037d9ebc07ca3d81c1cb750f0d58e1e2f132c54)
