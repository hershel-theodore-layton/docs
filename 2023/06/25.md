# 2023-06-25

## Highlights

- Custom-error configuration now carries an explicit schema version so the format can evolve without tying configuration migrations to an HHVM release. A malformed `CUSTOM_ERRORS.json` now terminates `hh_server` with a configuration error instead of being silently ignored. [d26d33e721](https://github.com/hershel-theodore-layton/hhvm/commit/d26d33e721cf1025277c3c4d6aec279ef86282b8) [57f963ad90](https://github.com/hershel-theodore-layton/hhvm/commit/57f963ad9032605c44cc9d4afd0cd9fb3a91033f)

## Future Changes

- In `everything_sdt` mode, `<<__NoAutoLikes>>` can suppress automatically introduced like-types on function and method returns, `inout` parameters, properties, lambdas, and promoted constructor properties. It does not disable `supportdyn` bounds or dynamic-callability checking. [fbf8d8aa22](https://github.com/hershel-theodore-layton/hhvm/commit/fbf8d8aa224d9858f7a5ad1ddb0bb64fd82e6585)
- Like-type pushing now resolves type variables with identical upper and lower equality bounds, improving inference around `where type` constraints and type constants. [be102b4bae](https://github.com/hershel-theodore-layton/hhvm/commit/be102b4bae0c41a7c76977df6abcd911fd8c5fd7)
