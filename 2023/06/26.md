# 2023-06-26

## Highlights

- Runtime deployment enforcement now distinguishes soft packages. Accessing a symbol from a soft package outside the hard deployment emits a warning in non-repository mode; hard-package violations still throw. Repository-authoritative builds continue to reject the access because soft-package files are not loaded. [08f82a6cb4](https://github.com/hershel-theodore-layton/hhvm/commit/08f82a6cb4b87cf93dc9b43d2f48e91278452dec)
- Standalone IDE services and batched change processing now default on in configurations without rollout overrides, bringing open-source and direct-build configurations closer to the current IDE path. [e433190c9e](https://github.com/hershel-theodore-layton/hhvm/commit/e433190c9ecfbb6c90178f25ab9b2abaf2fc3a39)
