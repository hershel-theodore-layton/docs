# 2023-06-27

## Highlights

- An async function containing only `yield break` is now recognized as an `AsyncGenerator`, matching functions that yield an actual value. [7e52671c4e](https://github.com/hershel-theodore-layton/hhvm/commit/7e52671c4eeb1f3abd71571dde852984bbc5b52f)

## Breaking Changes

- Dynamic property access such as `$object->{$name}` now requires the receiver to support `dynamic`, and the access result is always `dynamic`. Using it on an ordinary statically typed object is rejected; accidental `$` insertion still receives the existing quick-fix to normal property access. [aade1260bd](https://github.com/hershel-theodore-layton/hhvm/commit/aade1260bd90c5338a935c669beb11ca3f15264b)

## Future Changes

- `require class` trait requirements have advanced to ongoing release and no longer require the `require_class` unstable-feature opt-in. [39ac898932](https://github.com/hershel-theodore-layton/hhvm/commit/39ac8989328752a2dd65dec447faf9316c5981a3)
- Runtime-datatype information is now used when refining case types, allowing assertions such as `$value as vec<_>` to select and preserve the compatible `vec<T>` variant. [47e0a54653](https://github.com/hershel-theodore-layton/hhvm/commit/47e0a546531b064baf10efc9cb179b9c5fec8330)
