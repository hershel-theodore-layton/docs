# 2023-07-05

## Highlights

- The IDE’s “Extract shape type” action now works on shape type hints as well as shape expressions. Its generated alias starts with `T`, and the placeholder name is selected for immediate renaming. [77d0d73508](https://github.com/hershel-theodore-layton/hhvm/commit/77d0d735088d7c5fd8a8267c228e09cb47bc4a0e) [5c1517fe0a](https://github.com/hershel-theodore-layton/hhvm/commit/5c1517fe0a9c74413fd52835e2c0a05e63a95b64)
- Many HSL array, dictionary, keyset, and vector helpers now opt out of automatic like-type insertion under sound dynamic, preserving more precise declared return types. [7d39d37d93](https://github.com/hershel-theodore-layton/hhvm/commit/7d39d37d935df5bcfc4d77cec60a19a3b5acec3a) [2cae1c79ff](https://github.com/hershel-theodore-layton/hhvm/commit/2cae1c79ff7f6bcf436d745a439933f366251b7e) [f0b48d9069](https://github.com/hershel-theodore-layton/hhvm/commit/f0b48d90698e440592088da2db54c3aa11431146)

This avoids spurious failures where the widened element type previously collapsed to `mixed`.
