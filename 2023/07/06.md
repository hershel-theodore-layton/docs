# 2023-07-06

## Highlights

- Type inference now recognizes equivalent nullable bounds of the form `null, T <: #x <: ?T`, improving solutions for otherwise underconstrained type variables. [4e824a897a](https://github.com/hershel-theodore-layton/hhvm/commit/4e824a897adecddb3f404af14140746f8cdd5abd)
- Under implicit sound-dynamic pessimization, `<<__NoAutoLikes>>` suppresses only inserted like types. Generic parameters still receive a `supportdyn<mixed>` bound unless that parameter also has `<<__NoAutoBound>>`. [98b6c9f178](https://github.com/hershel-theodore-layton/hhvm/commit/98b6c9f1781fe72dd081f56eb8b6453a653ad3bc)

## Future Changes

- The experimental typed-local syntax now permits declarations without an initializer, such as `let $x: int;`. Reading the local before a later assignment remains an error. [87d5938fe6](https://github.com/hershel-theodore-layton/hhvm/commit/87d5938fe6f9e5a343ec03201d5ac928fd2a6aae)
