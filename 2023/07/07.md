# 2023-07-07

## Highlights

- Invalid cycles through trait `require class` or `require implements` clauses now produce ordinary diagnostics without overflowing the typechecker’s stack. [dc3b6cfafb](https://github.com/hershel-theodore-layton/hhvm/commit/dc3b6cfafb938fd4c91b16960b00d82314da423e)
- The IDE now returns the LSP `ContentModified` error when a requested code action can no longer be resolved, rather than crashing the language server. “Extract shape type” also survives an internal candidate invariant violation and continues serving later requests. [a1344f26cb](https://github.com/hershel-theodore-layton/hhvm/commit/a1344f26cbe532e8ec418c332f72be5ee3195540) [5c55e0af6f](https://github.com/hershel-theodore-layton/hhvm/commit/5c55e0af6f71d081806ae7e8f5db65c2d3a6b0b5)
- “Extract into method” is now offered for the expression body of a lambda such as `() ==> 3 + 3`. [f5a7a56c92](https://github.com/hershel-theodore-layton/hhvm/commit/f5a7a56c924568a533645112ce9a5348c4c13fc4)
