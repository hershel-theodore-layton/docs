# 2023-07-11

## Highlights

- Command-line symbol renaming no longer applies a replacement twice—for example, renaming `Foo` to `Bar` now produces `Bar`, not `BarBar`. [29daa1ba32](https://github.com/hershel-theodore-layton/hhvm/commit/29daa1ba32d553aa46116f65f130d8e584f257de)
- Another group of HSL functions now uses `<<__NoAutoLikes>>`, keeping precise types under implicit sound-dynamic pessimization. Higher-order helpers remain excluded while lambda inference is being improved. [722cd52156](https://github.com/hershel-theodore-layton/hhvm/commit/722cd5215619d3f914c2fb2579d05486ba99add2)

## Breaking Changes

- The `STDIN`, `STDOUT`, and `STDERR` pseudo-constants have been removed from Hack’s bundled declarations. Replace them with `HH\stdin()`, `HH\stdout()`, and `HH\stderr()` (or their `try_` variants). [d615f24ec4](https://github.com/hershel-theodore-layton/hhvm/commit/d615f24ec40481f9038d5218e4766201fa5031df)

## Future Changes

- A case type may no longer be the base type of an enum or enum class. This is rejected until case-type enforcement in those positions has consistent runtime semantics. [c8befa3337](https://github.com/hershel-theodore-layton/hhvm/commit/c8befa3337f5cdd6496a95a2b444b5f03e5c2526)
