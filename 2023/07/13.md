# 2023-07-13

## Highlights

- `_` may now request inference in nested explicit type arguments, as in `foo<vec<_>>()`. It is still rejected anywhere beneath a type parameter declared `<<__Explicit>>`. [e1811dd241](https://github.com/hershel-theodore-layton/hhvm/commit/e1811dd241b9c831249882729e146c6ad4e88506)

## Future Changes

- A generic name used illegally in a trait’s `require class` clause now yields a normal type error instead of raising an exception in the typechecker. [58855f8577](https://github.com/hershel-theodore-layton/hhvm/commit/58855f85777266628a17bfca1cfed19d75682ac5)
