# 2023-07-14

## Highlights

- “Extract shape type” is now offered only when a shape expression is selected, avoiding an IDE invariant failure for selections that merely contain a shape. [ce1676dece](https://github.com/hershel-theodore-layton/hhvm/commit/ce1676deced596ed84212cc18b3670426ffabc9e)

## Breaking Changes

- `hh --json` now writes JSON to standard output by default. Scripts that previously read the JSON stream from standard error should update their redirection. [647e96e836](https://github.com/hershel-theodore-layton/hhvm/commit/647e96e8366b4341c8851efc42472177df7521f9)
- HHVM has removed the `STDIN`, `STDOUT`, and `STDERR` pseudo-constants at runtime, completing the declaration removal from July 11. Use `HH\stdin()`, `HH\stdout()`, and `HH\stderr()` instead. [b34346b202](https://github.com/hershel-theodore-layton/hhvm/commit/b34346b202ad48f88c9ba4396ae2637a8c6bf12b)

## Future Changes

- Experimental typed locals now enforce their declared types and diagnose redeclaration, shadowing, and incompatible control-flow joins. Typed-local declarations are also supported inside `concurrent` blocks; coverage for further statement and lambda forms continues in later commits. [9055f3104c](https://github.com/hershel-theodore-layton/hhvm/commit/9055f3104c13150ca00a33f0b899637617e4c238) [28e003b54b](https://github.com/hershel-theodore-layton/hhvm/commit/28e003b54b44e05bef1d6348ae57ef5ad6546e4b)
