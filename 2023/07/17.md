# 2023-07-17

## Highlights

- Type displays now consistently render a union of `dynamic | T` as the like type `~T`, even when sound dynamic is not enabled. This affects diagnostics, hover text, typed-AST output, and other pretty-printed types. [1919727869](https://github.com/hershel-theodore-layton/hhvm/commit/1919727869bdbfd9635fdac863bdbb6dac3b7da4)
- When multiple package module globs match, HHVM now assigns the module to the package with the longest, most-specific prefix, matching the typechecker’s interpretation. [79819e903f](https://github.com/hershel-theodore-layton/hhvm/commit/79819e903ffc4026390cf7922127846546ca4a2c)

## Future Changes

- Experimental typed locals are now tracked correctly inside arrow lambdas and PHP-style closures with explicit `use` captures.
