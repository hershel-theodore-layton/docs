# 2023-07-18

## Highlights

- Under sound-dynamic pessimization, `HH\FIXME\UNSAFE_CAST<Tin, Tout>()` is now checked through its declared HHI signature: both source and destination must support dynamic, and the result receives the expected pessimised type. [943dbbf32a](https://github.com/hershel-theodore-layton/hhvm/commit/943dbbf32a43acf2ae6a604b5762889088d388e1)
- Standalone IDE mode now loads `PACKAGES.toml`, so package-access diagnostics stay in sync with a full `hh_server` typecheck. [fbcf2bfbe3](https://github.com/hershel-theodore-layton/hhvm/commit/fbcf2bfbe3222f988b5fb0624dca7faf52dbab94)

## Future Changes

- HackC now understands wildcard types in lambda parameter and return hints and treats `_` itself as unenforced at runtime while retaining the surrounding type check. The typechecker still rejects explicit lambda wildcards at this point; this is groundwork for later accepting forms such as `(vec<_> $x) ==> ...`. [54356672cb](https://github.com/hershel-theodore-layton/hhvm/commit/54356672cb1f6f23751bddf14e3bba5277e5cf8f)
