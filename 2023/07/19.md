# 2023-07-19

## Highlights

- Autocomplete now follows chained method calls through `supportdyn` and like types more reliably, restoring member suggestions under implicit sound-dynamic pessimization. [7eda8da7c3](https://github.com/hershel-theodore-layton/hhvm/commit/7eda8da7c30d1d59e6621b9a66716bf213955555)
- `HH\get_headers_secure()` now declares the precise `[read_globals]` capability instead of implicit `[defaults]`, allowing calls from contexts that grant global reads without granting every default capability. [8e93d5e2a8](https://github.com/hershel-theodore-layton/hhvm/commit/8e93d5e2a85a09ac2a1c8bb6b77d2c4c4a3a8e2c)
- The Facts API adds `HH\Facts\files_with_attribute_and_any_value()`, returning files whose file attribute has a requested value. Query values support booleans, integers, strings, dicts, vecs, and keysets; unsupported values are coerced to `null`. [7935244238](https://github.com/hershel-theodore-layton/hhvm/commit/7935244238772845d6fa9354bcc51711a340b6da)

## Future Changes

- Intersections now expose and filter case-type variants when the other constraints identify a concrete data type. Refinements such as `CT & vec<mixed>` and negative `is` branches can therefore simplify to a usable surviving variant. [ac30c4d792](https://github.com/hershel-theodore-layton/hhvm/commit/ac30c4d79267f2cd6ba8ed7b7bd5280f65f55857)
