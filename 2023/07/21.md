# 2023-07-21

## Highlights

- `hh_single_complete --root ... --naming-table ...` now resolves names from its naming-table fallback correctly instead of producing bogus `==>` parse errors for affected completions. [99f9df3a97](https://github.com/hershel-theodore-layton/hhvm/commit/99f9df3a9769db0e774cb3c4aab6b307df7d3978)

## Breaking Changes

- The obsolete `mbstring.http_input` and `mbstring.http_output` INI settings have been removed. Deployment configurations that still set them should delete those entries. [6a26df2499](https://github.com/hershel-theodore-layton/hhvm/commit/6a26df249940b361d88c6b5de6aa7bcee702f91b)
