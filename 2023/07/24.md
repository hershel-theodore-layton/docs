# 2023-07-24

## Highlights

- The switch-exhaustiveness lint no longer emits a duplicate false positive during the sound-dynamic checking pass. Exhaustive enum switches remain clean under implicit pessimization. [7fbe91a59f](https://github.com/hershel-theodore-layton/hhvm/commit/7fbe91a59f6a3234d9d28ea0edf04847fe28abd8)
- `hh_single_complete` can now use Glean for symbol search, honors `--auto-namespace-map`, and consistently respects `--no-builtins`. [670b9c1b6f](https://github.com/hershel-theodore-layton/hhvm/commit/670b9c1b6f5de6a8251682973f027f5208879f51)

## Breaking Changes

- Runtime type structures no longer contain a boolean `"like"` field, and `HH\TypeStructure\get_like()` has been removed. Rendering a type from a type structure therefore no longer adds `~` based on that field; code inspecting raw type structures must stop depending on it. [367fef24fc](https://github.com/hershel-theodore-layton/hhvm/commit/367fef24fc46843446f75a72d136ee78f1bd8160)
