# 2023-07-25

## Highlights

- Nullsafe method calls now tolerate an inferred `supportdyn<null>` arm, avoiding a spurious sound-dynamic error where the `supportdyn` wrapper is redundant. [b6e37eaff6](https://github.com/hershel-theodore-layton/hhvm/commit/b6e37eaff6334ef08a18d14f2516db29d23acd5a)
- Type errors involving an optional shape field now point to that field’s own definition instead of an unrelated required field. [1b3d6ba915](https://github.com/hershel-theodore-layton/hhvm/commit/1b3d6ba9158210e103e7ff44f4aa4cc92e89af57)
- Under sound dynamic, legacy `varray<T>` and `darray<Tk, Tv>` types no longer implicitly pessimise their type arguments to like types. [fdaedd5885](https://github.com/hershel-theodore-layton/hhvm/commit/fdaedd5885ac969cdba396b63c356abb6f646d62)

## Breaking Changes

- `as ~T` now performs a real runtime check by looking through the like type to `T`; it is no longer treated as a no-op. Like-type `is`/`as` expressions use the same look-through semantics in the typechecker. [a2fadfcddb](https://github.com/hershel-theodore-layton/hhvm/commit/a2fadfcddb9f2c3915de84008d4636a5425e51ee) [1cfe2b1978](https://github.com/hershel-theodore-layton/hhvm/commit/1cfe2b1978aa3aa6628cdda2d2e8d99a8a21b4ea)

## Future Changes

- The parser and `hackfmt` gain an initial experimental `match` statement with variable, type-refinement, and wildcard-constructor patterns. It remains behind the `match` unstable-feature opt-in and is not yet a complete language feature. [33dac5b0df](https://github.com/hershel-theodore-layton/hhvm/commit/33dac5b0df841e8337833d09dfd8563750538552)
