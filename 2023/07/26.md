# 2023-07-26

## Highlights

- “Extract shape type” now raises its type-printing limit substantially, preventing large generated aliases from being truncated into invalid Hack. Extremely large types still retain a finite editor-safety limit. [7a2f7f8b45](https://github.com/hershel-theodore-layton/hhvm/commit/7a2f7f8b458a1ef4e6c74a4bfae9df546311bf5f)
- HHVM now registers the full sodium API consistently, including AES-256-GCM functions that the HHI already promised. Builds and target CPUs must provide a sufficiently recent, fully capable libsodium. [5efda73ea0](https://github.com/hershel-theodore-layton/hhvm/commit/5efda73ea02c7197c5364b556076cedf06350adc)
