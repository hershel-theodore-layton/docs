# 2023-07-28

## Highlights

- An erased or otherwise unenforceable generic may now appear inside a reified class type used by `is`/`as`, such as `C<T>` where `C`’s parameter is reified. A direct `as T` still requires `T` to be enforceable, and wildcard `_` is now correctly rejected as a reified runtime witness. [ef78282fef](https://github.com/hershel-theodore-layton/hhvm/commit/ef78282fefefa2291bbeb4874d4a23d6fc9cb580)

## Future Changes

- Case-type refinement now handles intersections with negated special classes correctly, preserving only variants that can satisfy the negative constraint. [e5b7ccbeab](https://github.com/hershel-theodore-layton/hhvm/commit/e5b7ccbeab2a670a98d61a5250fed359f5b17082)
