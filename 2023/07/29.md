# 2023-07-29

## Future Changes

- A `pessimise_builtins` typechecker option has been reintroduced to control whether built-ins such as `Vector` acquire like-typed arguments under sound dynamic. It defaults to false and prepares for enabling sound-dynamic checking by default without implicitly changing every built-in.
