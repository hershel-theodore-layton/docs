# 2023-07-31

## Highlights

- The JSON representation of a Hack `User_error` now includes rendered custom diagnostic text in a `custom_messages` array, making it available to typed-AST and error-processing tools. [d8c1defb73](https://github.com/hershel-theodore-layton/hhvm/commit/d8c1defb73cb0cb2335adc65a4676140cec1cdb2)
- `<<__CrossPackage("package")>>` now loads the requested package while typechecking methods as well as top-level functions, so permitted cross-package calls from attributed methods no longer fail spuriously. [21c294919f](https://github.com/hershel-theodore-layton/hhvm/commit/21c294919f86a5f3f152d46741b085afbabe89c2)

## Future Changes

- Experimental typed-local enforcement now covers assignments with nontrivial left-hand sides and compound operators such as `+=`.
