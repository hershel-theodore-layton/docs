# 2023-08-01

## Highlights

- Under Sound Dynamic, hovering a method call through a like-typed receiver now shows the method's ordinary signature instead of rendering the whole callable as a like type. [bdfd6dc2e9](https://github.com/hershel-theodore-layton/hhvm/commit/bdfd6dc2e9215e764f370d205bf560b2fbc7f206)
- Exhaustivity checking now recognizes pessimised enum types of the form `bound & ~E`, restoring missing non-exhaustive-switch diagnostics. [21348ec543](https://github.com/hershel-theodore-layton/hhvm/commit/21348ec5432bd0f2cbe38a38e66db53656cd15db)
- Refactoring code actions now honor the client's snippet-edit capability. Clients without it receive ordinary placeholder names such as `method0`, rather than literal snippet syntax such as `${0:method0}`. [0041ad042d](https://github.com/hershel-theodore-layton/hhvm/commit/0041ad042d33d8ab45dbe68280c6b163596ea00f)

## Security

- Malformed Thrift payloads can no longer crash the decoder by declaring an excessive collection capacity; large collections are now reserved incrementally. [3deb3191e0](https://github.com/hershel-theodore-layton/hhvm/commit/3deb3191e00bb6eca9525e35f6f7b9aaf262269b)

## Future Changes

- Experimental typed-local enforcement now treats tuple indexing like shape indexing when checking assignments such as `$x[$i] = $value`. [9fa6b85eea](https://github.com/hershel-theodore-layton/hhvm/commit/9fa6b85eeaf14f8b83cb2084b46dc14bf9e3beb0)
- Parser lowering gained an AAST representation for the in-development `match` statement. [97f0efe6e5](https://github.com/hershel-theodore-layton/hhvm/commit/97f0efe6e5c727e491a5ab7050436679849e2f10)
