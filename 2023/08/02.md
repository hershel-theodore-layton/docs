# 2023-08-02

## Breaking Changes

- `hh_single_type_check` now enables Sound Dynamic by default, making `--enable-sound-dynamic-type` redundant and potentially changing diagnostics and inferred types in scripts that invoke the standalone checker. [d10f4599f1](https://github.com/hershel-theodore-layton/hhvm/commit/d10f4599f1429c346987022cebcb0e363b34cfa3)
- `debug_backtrace()` no longer includes `$this` unless `Eval.EnableArgsInBacktraces` is enabled. [c6d7874d35](https://github.com/hershel-theodore-layton/hhvm/commit/c6d7874d35749dcfab81d628ca8bb1313ae42009)
