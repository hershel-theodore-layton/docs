# 2023-08-07

## Security

- Pagelet-server callers can now detect or reject the unsafe legacy `"Header: value"` array form and collisions with keyed headers. `Eval.PageletServerHeaderCheck` controls warnings or rejection of the legacy form, while `Eval.PageletServerHeaderCollide` controls collision warnings, precedence, or rejection. [724d62be19](https://github.com/hershel-theodore-layton/hhvm/commit/724d62be19449a49e594ae1d85d9728fe7bc88ae)

## Breaking Changes

- `hh_single_type_check` no longer accepts the obsolete `--like-casts` and `--simple-pessimize` options; targeted explicit pessimisation continues to use the `like_casts` configuration. [ae834842e3](https://github.com/hershel-theodore-layton/hhvm/commit/ae834842e3a5b0a1a4ac068b19ceb78d1d502d4d)
- `hh --ide-find-refs-by-symbol` now always emits JSON, and the human-readable `hh_single_type_check --find-refs` format now includes the matching symbol text. Tools parsing either command's old output need updating. [da6d7dba16](https://github.com/hershel-theodore-layton/hhvm/commit/da6d7dba160b394cd7bbbe43cd34e09f6f74f652) [b24518524c](https://github.com/hershel-theodore-layton/hhvm/commit/b24518524ca432a0b1a7ef27bcd2a154bd358f0f)
