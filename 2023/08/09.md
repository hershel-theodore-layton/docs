# 2023-08-09

## Highlights

- Bidirectional inference now uses the upper bound of an expected type variable when typing lambdas. Generic helpers such as `makeSingle($x ==> $x->foo())` can therefore infer the lambda parameter from the surrounding expected type. [6cb17946fa](https://github.com/hershel-theodore-layton/hhvm/commit/6cb17946fa0a9cc3c8b4f95291ec8e99291bc711)
- Typechecking very large argument lists and `vec` literals no longer overflows the typechecker's stack. [265db40acd](https://github.com/hershel-theodore-layton/hhvm/commit/265db40acdec1c161e293e98832138ea81b6325e)
- Targeted explicit pessimisation now honors `<<__NoAutoLikes>>` on return types, function types, and `inout` parameters. [5bc783525a](https://github.com/hershel-theodore-layton/hhvm/commit/5bc783525a34168951dbca181ca66816fe11e517)

## Future Changes

- `require class` has entered an ungated rollout and can now be used without a per-file unstable-feature opt-in, but it remains pre-stable. [ad27a74ee0](https://github.com/hershel-theodore-layton/hhvm/commit/ad27a74ee0cab6f406e8a8576f8629a9a5013a7f)
