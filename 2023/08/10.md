# 2023-08-10

## Highlights

- Symbol-info indexes now include inherited class, interface, and trait members by default, improving the accuracy of tools that consume Hack's symbol index. The behavior can be gated with `symbol_write_index_inherited_members`. [c4ad5562ac](https://github.com/hershel-theodore-layton/hhvm/commit/c4ad5562ac8b4005b501d1d12f699aafcfb9aa01)

## Breaking Changes

- HHVM has removed the `auto_prepend_file` and `auto_append_file` INI settings. Entrypoint setup and teardown must be explicit. [b182e8f63c](https://github.com/hershel-theodore-layton/hhvm/commit/b182e8f63c9b58947404b2935ff281d086126531)
- The `variables_order` and `request_order` settings have been removed; superglobal population order is now fixed. [e258daf596](https://github.com/hershel-theodore-layton/hhvm/commit/e258daf596a93e947c1da3704a37b05b693cd8ce)
- The unused `arg_separator.input` setting and configurable `arg_separator.output` setting have been removed. APIs that used the output default now hard-code `&` unless a separator is supplied directly. [e4ffa04d48](https://github.com/hershel-theodore-layton/hhvm/commit/e4ffa04d4831b370b37789a9236515d6ad913995)
