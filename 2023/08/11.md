# 2023-08-11

- A direct-declaration parsing bug no longer lets `<<__NoAutoLikes>>` on one method leak into methods declared after it. [045457670e](https://github.com/hershel-theodore-layton/hhvm/commit/045457670e43f5b593baf779c6d06350c55afc12)
- Sound Dynamic subtype checking now pushes like types through nested invariant type arguments in both directions, admitting relations such as `Map<string, Vector<~C>> <: ~Map<string, Vector<C>>`. [5919987cd9](https://github.com/hershel-theodore-layton/hhvm/commit/5919987cd9b4d92eb4b013dedc37dd6bc4bad650)
- Soft package-deployment violation warnings can now be sampled with `Eval.DeploymentViolationWarningSampleRate`, reducing log volume during migrations. [38b77e9ac5](https://github.com/hershel-theodore-layton/hhvm/commit/38b77e9ac5e7f368f203c755c6784dba05a2fe7e)
