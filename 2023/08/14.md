# 2023-08-14

## Highlights

- Sound Dynamic no longer adds an unnecessary outer like type to `Vector` methods whose collection-shaped result is already enforced by HHVM. Operations such as `toSet()` now retain their declared container type more precisely. [995317f216](https://github.com/hershel-theodore-layton/hhvm/commit/995317f216a24ec9e44b0e1a1e4c6b02a54eae4d)

## Breaking Changes

- HHVM has removed support for dynamically loaded native extensions, including the `-z` path and the `extension_dir`, `extensions`, `DynamicExtensionPath`, and `DynamicExtensions` settings. Extensions must be linked into the HHVM build. [71e6b01ff5](https://github.com/hershel-theodore-layton/hhvm/commit/71e6b01ff54d7511483626cf964033b71177c630)
