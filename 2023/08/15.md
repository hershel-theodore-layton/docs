# 2023-08-15

## Highlights

- `hh_single_type_check --map-reduce` can now run configured typed-AST analyses and print their reduced JSON result. [0ffd752fc9](https://github.com/hershel-theodore-layton/hhvm/commit/0ffd752fc92642fde7e7b24584f0a49536e9716a)
- The new `hphp_debug_caller_identifier()[leak_safe]: string` runtime helper returns the caller's full function or `Class::method` name without constructing the full `hphp_debug_caller_info()` dictionary. [dfc3cbbaa0](https://github.com/hershel-theodore-layton/hhvm/commit/dfc3cbbaa01c549ffb861906ca15ef3ad1e1c069)
- Package module patterns now use prefix-glob semantics matching the runtime: `foo.*` matches descendants of `foo`, `*` matches every module, and other patterns are exact names. [3ef62b5f28](https://github.com/hershel-theodore-layton/hhvm/commit/3ef62b5f28ea0f110b1bfc4129f9d54af6acf569)

## Security

- `Eval.SetHeadersInServerSuperGlobal` can now prevent request headers from being copied into `$_SERVER`; applications can retrieve the raw protected header map with `HH\get_headers_secure()` instead. The compatibility default remains enabled. [d3b6066fb8](https://github.com/hershel-theodore-layton/hhvm/commit/d3b6066fb8f0fe5e45b8c13bb5fa246e54e2c350)
