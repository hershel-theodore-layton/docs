# 2023-08-21

## Future Changes

- During the ongoing module rollout, files without an explicit module declaration are now assigned to the internal `default` module for runtime module and package enforcement. Reflection continues to return `null` for their module, but boundary errors describe callers as being in the default module rather than outside all modules. [0977c6dffc](https://github.com/hershel-theodore-layton/hhvm/commit/0977c6dffcb28e2ff0b26000ab92d2be6249443d)
- Experimental case types no longer require every variant to be recoverable. Overlap validation instead compares each pair's runtime data types and reports the two conflicting variants directly. [ab94cdfad7](https://github.com/hershel-theodore-layton/hhvm/commit/ab94cdfad77dabe107d6cbff1a471d240476601a) [808d14a22d](https://github.com/hershel-theodore-layton/hhvm/commit/808d14a22d4e657a040fdfd591d306395c5b323a)
