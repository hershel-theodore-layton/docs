# 2023-08-30

## Highlights

- Sound Dynamic function-call checking now retries all parameters against their pessimised types when a mixed static/dynamic pass fails. Calls that require the dynamic interpretation from the first argument are no longer rejected spuriously, and their result remains like-typed. [c613d98c5c](https://github.com/hershel-theodore-layton/hhvm/commit/c613d98c5cbb9e80ceec41c257f204406da72a36)
- Package checking now treats a missing module membership as the `default` module when matching package globs, aligning the typechecker with HHVM's runtime enforcement. [8db8b6b349](https://github.com/hershel-theodore-layton/hhvm/commit/8db8b6b34953008fc1f6c651a0fb66a1c3865e30)
