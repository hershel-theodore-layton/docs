# 2023-08-31

## Highlights

- Sound Dynamic no longer unnecessarily pessimises `$shape['field'] ?? $default`; the null-coalesced result keeps the precise union of the field and default types. [3c10902b53](https://github.com/hershel-theodore-layton/hhvm/commit/3c10902b5322efd207309bd63c09dd7252886556)
- Streaming find-references now flushes all remaining results after the server search completes and reliably includes references from IDE-open files. Temporary result files have also moved out of the project root into the server's temporary directory. [9463755411](https://github.com/hershel-theodore-layton/hhvm/commit/9463755411d55c3dbeebbce3e43d1efc805d9841) [2df5c0ee10](https://github.com/hershel-theodore-layton/hhvm/commit/2df5c0ee107f0faf76a5b83a6f8aac1d9a5ddc3a) [44a3b226d4](https://github.com/hershel-theodore-layton/hhvm/commit/44a3b226d43acdd29279a866ce897fc98ec6be0b)

## Security

- `Eval.DisableParsedCookies` can now stop parsing cookies into `$_COOKIE` and `$_REQUEST`, and removes the `$_COOKIE` superglobal entirely when enabled. Raw headers remain available for application-controlled parsing. The compatibility default remains disabled. [3b831a6deb](https://github.com/hershel-theodore-layton/hhvm/commit/3b831a6debce1e8802ac1242bd249ef8cce436e8)

## Future Changes

- HackC no longer panics when lowering `??=` through a readonly access path while readonly remains a Preview feature. [f17676df4b](https://github.com/hershel-theodore-layton/hhvm/commit/f17676df4bc93c600ffea5a1739f39ef2f1b762d)
- Like-type pushing now composes through pre-stable case types, admitting relationships such as `vec<~string> <: ~CTVec<string>` when `CTVec<T>` wraps `vec<T>`. [3878bd424d](https://github.com/hershel-theodore-layton/hhvm/commit/3878bd424d99dd02ecd95a5361f8ea9c4315464f)
- The unstable `pipe_await` feature now permits `await` directly on the right-hand side of `|>`. [9422600fb2](https://github.com/hershel-theodore-layton/hhvm/commit/9422600fb298eca577bb1b02b0a7fb8d863efc61)
