# 2023-09-01

## Highlights

- Sound Dynamic joins now simplify unions and intersections through `supportdyn` wrappers, avoiding unnecessarily large or imprecise inferred unions after control-flow joins. [55f4a9ddff](https://github.com/hershel-theodore-layton/hhvm/commit/55f4a9ddff54126c1aca1aacf4ad7e9e71245ced)
- Soft-package class access no longer emits a duplicate deployment-boundary warning while resolving the class. [497854503a](https://github.com/hershel-theodore-layton/hhvm/commit/497854503aa05cf37569d64add1a2b58e2d12572)

## Breaking Changes

- Sound Dynamic has backed out the all-dynamic fallback for calls through `supportdyn` function types. Calls that only typechecked after pessimising every parameter may now report argument errors. [349eca7fa1](https://github.com/hershel-theodore-layton/hhvm/commit/349eca7fa11453cd3102b9c998bea260da788ddb)
- A property whose alias or newtype resolves to `nothing` is now rejected at class initialization with an invalid-property-type fatal, rather than slipping through runtime resolution. [57141c389a](https://github.com/hershel-theodore-layton/hhvm/commit/57141c389a132a478735881885233194a5751c2a)
