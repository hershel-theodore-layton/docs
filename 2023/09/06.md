# 2023-09-06

## Highlights

- Projects can opt in to rejecting direct superglobal variables such as `$_SERVER` with `disallow_direct_superglobals_refs=true`; diagnostics direct callers to the corresponding `HH\global_*` APIs. The compatibility default remains disabled. [40a5ae7da0](https://github.com/hershel-theodore-layton/hhvm/commit/40a5ae7da0e9680045ff7804158d88de1bfb23b3) [491c65d3bf](https://github.com/hershel-theodore-layton/hhvm/commit/491c65d3bf8662a45851c87486e989f012e58f3b)
- Package metadata now reaches `hh_distc`, and typechecker glob matching treats `foo.*` as matching both `foo` and its descendants while preferring the most specific exact match. [93d7c2a891](https://github.com/hershel-theodore-layton/hhvm/commit/93d7c2a8912eb4746541f5852c04edf5e086eab3) [2933cd2759](https://github.com/hershel-theodore-layton/hhvm/commit/2933cd27599bd7ba330246fcae234ae1896e8272)

## Breaking Changes

- `hh --search` has been removed. IDE autocomplete and search no longer depend on `hh_server`'s former SQLite symbol index. [edd2b799c5](https://github.com/hershel-theodore-layton/hhvm/commit/edd2b799c5542fe5f58f8a14a4050884f53699dd)
- The typechecker now supplies the built-in `default` module through HHI. Projects must not declare `new module default {}` themselves; package diagnostics can now point to this built-in declaration. [be4229a0c4](https://github.com/hershel-theodore-layton/hhvm/commit/be4229a0c4d30fa01ee75f2f47343a201b9c1d92)

## Future Changes

- Opt-in strict switches now reject impossible case values and redundant defaults for `nothing`/`noreturn` scrutinees. [7497648c8c](https://github.com/hershel-theodore-layton/hhvm/commit/7497648c8cca5e04431a7227c9c3fe34e7e849b2)
- Experimental case-type overlap checking now uses `require extends` constraints on interfaces and traits to reason about their possible implementations. [21693db81f](https://github.com/hershel-theodore-layton/hhvm/commit/21693db81f879528d2158240aafe68820694fb5b)
