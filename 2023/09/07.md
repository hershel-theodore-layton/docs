# 2023-09-07

## Highlights

- Repo-authoritative deployments now include soft packages so accesses can emit deployment-boundary warnings and continue, rather than failing with an undefined function or class. [1171062eb4](https://github.com/hershel-theodore-layton/hhvm/commit/1171062eb4ad6cbf55b0bd83ee376434a7f4569e)
- Class expressions used as attribute arguments no longer trigger internal or cross-package visibility errors. This permits patterns such as sealing a trait to an internal class because the stored attribute value is only a class-name string. [1d2b48aecd](https://github.com/hershel-theodore-layton/hhvm/commit/1d2b48aecd0375f3ac4c81f456f9d023cd627f96)
- The HHI declarations for `HH\get_headers_secure()` and `HH\parse_cookies()` no longer carry `__PHPStdLib`, restoring their intended treatment by Hack tooling. Their capability lists remain `[read_globals]` and `[]`, respectively. [d5ad640290](https://github.com/hershel-theodore-layton/hhvm/commit/d5ad640290f495475a16d142895084818b6c7a87) [12d45c23a5](https://github.com/hershel-theodore-layton/hhvm/commit/12d45c23a5c93d54df18108630f591d4963bbbc8)

## Future Changes

- Opt-in strict switches now model `null`, nullable, `nonnull`, and negative types, diagnosing missing or repeated `case null` arms. [87922666c4](https://github.com/hershel-theodore-layton/hhvm/commit/87922666c49f2df61349fa358702c65736f47699)
- Parser-schema and `hackfmt` groundwork lands for a future `nameof C` expression, but the typechecker still rejects the syntax at this stage. [55c68773cc](https://github.com/hershel-theodore-layton/hhvm/commit/55c68773ccf8702205bf57bdf8a0d529cd357a6c)
