# 2023-09-08

## Highlights

- Reified-generic checking now preserves the most informative type arguments across union receivers and looks through like-typed function signatures. This removes false missing-type-argument errors while restoring real errors for omitted reified arguments. [c3045c650d](https://github.com/hershel-theodore-layton/hhvm/commit/c3045c650d9aa9e7e597e31cb52b01396441cda0) [ed0a6efdfd](https://github.com/hershel-theodore-layton/hhvm/commit/ed0a6efdfd8983448cfa17b3bf962a8cd82c9b91)
- Implicit lazy-class-to-string notices for argument type hints now identify which argument and function triggered the conversion. [e912bbb1e0](https://github.com/hershel-theodore-layton/hhvm/commit/e912bbb1e06e90fb60164d882633e3300676feef)

## Breaking Changes

- Enum-class labels now use a native runtime datatype by default instead of opaque resources. Dumps identify `enum class label (#Name)`, equality compares label names, and relational comparisons throw `InvalidOperationException`; code that inspected labels as resources must migrate. [d044eba3a1](https://github.com/hershel-theodore-layton/hhvm/commit/d044eba3a161791f4a7f6acb22b7ba7ea0649286) [353425f238](https://github.com/hershel-theodore-layton/hhvm/commit/353425f2387a15e2982c10d51394f942760830be) [ab69809ede](https://github.com/hershel-theodore-layton/hhvm/commit/ab69809ede17ae3d6fe270e410e0023512a6c611)

## Future Changes

- Opt-in strict switches now understand boolean scrutinees and can require both `true` and `false` arms. [1e3bf333a0](https://github.com/hershel-theodore-layton/hhvm/commit/1e3bf333a03126b2a11a25f60930b8faf0d1c61d)
- Runtime groundwork for case types now represents primitive and object unions in type constraints, supports properties in repo mode, and keeps property overrides nominal. Case types are still an opt-in language feature at this point.
