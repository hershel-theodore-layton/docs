# 2023-09-12

## Highlights

- Open-source HHVM builds once again parse and enforce `PACKAGES.toml`, and runtime package matching now agrees with the typechecker that `foo.*` includes `foo` itself while exact matches take precedence. [a11552fc4f](https://github.com/hershel-theodore-layton/hhvm/commit/a11552fc4ff8f9f29252d5426a4c09d849ae33c9) [5f0823ca7d](https://github.com/hershel-theodore-layton/hhvm/commit/5f0823ca7da872cbd9abfb679287358be6837a11)
- IDE completion cards for top-level functions now include their parameter and return signatures. [78618a4c42](https://github.com/hershel-theodore-layton/hhvm/commit/78618a4c42403af56a94a721da26c7e6213dd0c1)

## Breaking Changes

- The repo-mode soft-package warning behavior from September 7 has been temporarily backed out. Repo builds once again omit soft packages and can fail with undefined-symbol errors until the corrected reland. [16c8aaf940](https://github.com/hershel-theodore-layton/hhvm/commit/16c8aaf9404656d59115dfce01879e08e190d807)
- The experimental `hh --pause` and `hh --resume` commands have been removed; file changes always trigger the normal full-check workflow. [3bd5161a2c](https://github.com/hershel-theodore-layton/hhvm/commit/3bd5161a2cfeaa3413dffe0e3be364a6944b3b7f)

## Future Changes

- Opt-in strict switches now recognize integer literals, require a `default` for the open-ended `int` domain, and report repeated literal arms. [1fa08641fe](https://github.com/hershel-theodore-layton/hhvm/commit/1fa08641fec8daaed825f8b7b83703cb578efabf)
