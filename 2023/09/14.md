# 2023-09-14

## Highlights

- HHVM's sodium extension adds Ed25519 point validation, addition, subtraction, and unclamped point scalar multiplication through `sodium_crypto_core_ed25519_is_valid_point()`, `sodium_crypto_core_ed25519_add()`, `sodium_crypto_core_ed25519_sub()`, and `sodium_crypto_scalarmult_ed25519_noclamp()`. [123c63cc3f](https://github.com/hershel-theodore-layton/hhvm/commit/123c63cc3ffbbf53770afe36d122a1c81fcb8dbe)

## Breaking Changes

- HHVM's native PostgreSQL extension and its `pg_*` APIs have been removed, along with the libpq build dependency. Applications must use another database client. [dabfb89185](https://github.com/hershel-theodore-layton/hhvm/commit/dabfb89185dd16074a0dab638607f4aab2217a9b)
