# 2023-09-19

## Highlights

- The IDE's “Inline method” refactor now emits a valid `$res` temporary for returned values instead of the invalid bare identifier `res`. [2e1dbf6572](https://github.com/hershel-theodore-layton/hhvm/commit/2e1dbf6572eb632df17401ae10044c65378f3396)
- `hh --rewrite-declarations` can rename repeated declarations for notebook-style Hack input; the functionality has moved from a separately deployed binary into the standard client. [8e60519cb2](https://github.com/hershel-theodore-layton/hhvm/commit/8e60519cb20c47a03234d823129cd22ffc9f84a5)

## Breaking Changes

- `hh_single_type_check --custom-hhi-path` now requires `--no-builtins`, preventing concurrent invocations from truncating generated builtin files in the shared custom directory. [27e9b0384d](https://github.com/hershel-theodore-layton/hhvm/commit/27e9b0384d243e4a62434c2947c4587f6411d1e2)

## Future Changes

- Strict-switch checking is now an explicitly unstable, per-function feature: opt in with `<<file:__EnableUnstableFeatures('strict_switch')>>`, then apply `<<__StrictSwitch>>` to a function or method. The old project-wide `enable_strict_switch` option is removed. String literals and string-valued class constants are also supported.
