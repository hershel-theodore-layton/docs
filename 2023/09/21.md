# 2023-09-21

## Highlights

- Runtime type-structure cache keys now include `typevar_types`, so distinct reified instantiations such as `NT<int>` and `NT<float>` no longer collide during resolution. [2784c2004f](https://github.com/hershel-theodore-layton/hhvm/commit/2784c2004fa39a1ac9f60ce49181254847194e3c)

## Future Changes

- The unstable `pipe_await` lowering now uses properly scoped compiler temporaries for `await` on the right side of `|>`, preventing generated locals from leaking across the transformed statement. [f908a5e42b](https://github.com/hershel-theodore-layton/hhvm/commit/f908a5e42b1c6b1a57fadbb5ed1a6748183a628f)
- Under implicit pessimisation, experimental case types are now correctly rejected as enum and enum-class base types instead of being hidden behind a like type. [38d5661170](https://github.com/hershel-theodore-layton/hhvm/commit/38d5661170727fc7bf887f9df547dea2caf768c2)
