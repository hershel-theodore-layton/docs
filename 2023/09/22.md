# 2023-09-22

## Highlights

- Errors for inaccessible or invalid attribute classes now point to the attribute use site, rather than manufacturing a source position from the attribute class declaration. [0a9d3a9db6](https://github.com/hershel-theodore-layton/hhvm/commit/0a9d3a9db666d64682c2ceb2cb1c6ec163a344bf)

## Breaking Changes

- Abstract methods and type constants inherited from traits no longer silently override concrete inherited members. The typechecker now reports the invalid redeclaration while preserving the correct primary source position. [eb118e9546](https://github.com/hershel-theodore-layton/hhvm/commit/eb118e95464b49dd85bbfdb645cdc3468ce11955)
