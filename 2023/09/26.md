# 2023-09-26

## Highlights

- The typechecker and typed AST now retain `concurrent` blocks instead of first lowering them to generated `awaitall` code. This improves source positions and typed-local checks, and fixes “Extract into method” omitting `async` and `Awaitable` from methods extracted from a concurrent block. [aef6da73ca](https://github.com/hershel-theodore-layton/hhvm/commit/aef6da73ca00662e23cb5fd261df05de191cc291)

## Future Changes

- Unstable strict switches now classify `arraykey`-typed class constants as both possible integer and string cases, improving wrong-type and duplicate-case diagnostics. [39494259ec](https://github.com/hershel-theodore-layton/hhvm/commit/39494259ecd3cbbc605655f09c439723c14ccfff)
