# 2023-09-28

## Highlights

- `preg_get_error_message_if_invalid(string $pattern): ?string` is now available to typechecked Hack. It returns `null` for a valid regex or an error message for an invalid one without emitting malformed-pattern warnings. [ed5c1a754e](https://github.com/hershel-theodore-layton/hhvm/commit/ed5c1a754e1b8c74d1ca40dc4010580b79284a04)
- `hh --find-refs` now accepts `Kind|Symbol`, covering methods, properties, class constants, type constants, functions, classes, explicit classes, and global constants. `ExplicitClass` excludes references through `self`, `static`, and `parent`. [7beb2f1aa9](https://github.com/hershel-theodore-layton/hhvm/commit/7beb2f1aa92cc5fa8f4ddc3cf7f6e057ca479076)
