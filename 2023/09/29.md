# 2023-09-29

## Highlights

- IDE find-references requests can now be cancelled and immediately retried without leaving a stale shellout, and completion of the search reliably flushes its final streamed results. [6772812664](https://github.com/hershel-theodore-layton/hhvm/commit/677281266428a68e21495df539027b938a0b94a5) [cbab9e45ea](https://github.com/hershel-theodore-layton/hhvm/commit/cbab9e45eadcac637eb3381e057506ebf1df4cbb)
- Invalid conversions of reified function pointers, reified class-method pointers, and enum-class labels now throw catchable `InvalidOperationException`s instead of terminating with an uncatchable fatal. Error text also uses Hack names such as “function,” “class method,” and “float.” [fcca69ea4f](https://github.com/hershel-theodore-layton/hhvm/commit/fcca69ea4fd697f60b9ebd04278cb1d9013a9c27)
- `ReflectionMethod::getCanonicalMethod()` and `getCanonicalClassname()` can locate the trait that actually defines an inherited method in non-repo mode. They throw in repo-authoritative mode, where traits have already been flattened. [45c1f1f8e9](https://github.com/hershel-theodore-layton/hhvm/commit/45c1f1f8e9ec0782ed572a388b825a9aecddc687)

## Future Changes

- Case types have moved from Unstable to Preview. They still require the `case_types` file-level opt-in, but Preview status permits opted-in code to run in production now that runtime enforcement is enabled. [942f1c5a74](https://github.com/hershel-theodore-layton/hhvm/commit/942f1c5a74b9ffb02b909a9eafeef34235c8c3fd)
