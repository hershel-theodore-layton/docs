# 2023-10-05

## Highlights

- New `HH\classname_to_class()` and `HH\class_to_classname()` helpers make the runtime representation changes between class names and class pointers explicit. `classname_to_class()` throws when the class cannot be loaded and emits a sampled notice when the target lacks the newly recognized `<<__DynamicallyReferenced>>` class attribute. [2b2d440a35](https://github.com/hershel-theodore-layton/hhvm/commit/2b2d440a3564405ac9141a9c47ad1bc05c8759c4) [336f743c58](https://github.com/hershel-theodore-layton/hhvm/commit/336f743c5899283ce95fef7743aaa44f6b9e562f)
- Invalid debugger-style statements such as `=$x + 1;` now carry a quick-fix that converts the expression to `var_dump($x + 1)`. A range-calculation fix also makes the new and existing quick-fixes appear for the correct IDE selection. [046af76074](https://github.com/hershel-theodore-layton/hhvm/commit/046af76074cfb66ff24e0467c339ca146ea76e5b) [5cd5c75667](https://github.com/hershel-theodore-layton/hhvm/commit/5cd5c7566707326565ff127e44e81f553dee78e1)

## Future Changes

- The annotation-gated strict-switch checker now understands enum classes and `dynamic`. Enum-class arms are checked against the `HH\MemberOf` interface, while a bare `dynamic` subject requires `default` and rejects other arms. [fe2334dfcf](https://github.com/hershel-theodore-layton/hhvm/commit/fe2334dfcfb0f70add8e3c4ad326a534eb366e2f) [5751ee4de9](https://github.com/hershel-theodore-layton/hhvm/commit/5751ee4de9efd24d4ad3f0734275b9f5165e2b7c)
- Code generation now recognizes the experimental `class<T>` type syntax; typechecker support follows later in the month. [e8a4af259d](https://github.com/hershel-theodore-layton/hhvm/commit/e8a4af259db7300149dbc4b9fd7ab15b8c0d3571)
