# 2023-10-09

## Highlights

- HHVM's Proxygen server now includes `Retry-After` when it returns HTTP 503 because a request timed out in the queue or the server is shutting down, allowing clients and proxies to retry deliberately. [70f352a4bb](https://github.com/hershel-theodore-layton/hhvm/commit/70f352a4bbf1f543ecc99be26de4ae76a0e060c7)

## Future Changes

- `ReflectionClass::getRequiredClass()` now returns the class named by a trait's pre-stable `require class` constraint, or `null` when no such constraint exists. [be3c76e346](https://github.com/hershel-theodore-layton/hhvm/commit/be3c76e346edc99769737fbbc1eec9d52f443034)
