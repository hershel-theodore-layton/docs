# 2023-10-09

## Highlights

- HHVM can now include `Retry-After` on HTTP 503 responses for queue timeouts and Proxygen shutdowns. Set `Server.503RetryAfterSeconds` to a nonnegative delay in seconds to enable the header; its default of `-1` disables it. Shutdown responses also require `Server.503OnShutdownAbort=true`. [70f352a4bb](https://github.com/hershel-theodore-layton/hhvm/commit/70f352a4bbf1f543ecc99be26de4ae76a0e060c7)

## Future Changes

- `ReflectionClass::getRequiredClass()` now returns the class name as a string for a trait's pre-stable `require class` constraint, or `null` when no such constraint exists. [be3c76e346](https://github.com/hershel-theodore-layton/hhvm/commit/be3c76e346edc99769737fbbc1eec9d52f443034)
