# 2023-10-10

## Highlights

- The bundled HHI now gives `ReflectionMethod::getDeclaringClass()` and `getPrototype()` their concrete `ReflectionClass` and `ReflectionMethod` return types instead of missing-return-type placeholders. [037cb95228](https://github.com/hershel-theodore-layton/hhvm/commit/037cb952288792f43c94f1ad3cad4fcb06f84087)

## Future Changes

- Implicit pessimisation no longer wraps a declared `this` return type in a like type. Fluent methods that return `$this` therefore retain their precise return type under the rollout. [39873917db](https://github.com/hershel-theodore-layton/hhvm/commit/39873917dbc88f4d004e1440bae8f733de58fbfb)
- HHVM now limits a fully flattened experimental case type to 48 variants by default, with `Eval.MaxCaseTypeVariants` available to configure the ceiling. Definitions that exceed it fail during type-alias resolution. [83d4542659](https://github.com/hershel-theodore-layton/hhvm/commit/83d45426598c5a6e78011fc13c95c51e645c9a07)
