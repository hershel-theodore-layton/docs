# 2023-10-12

## Highlights

- Exception breakpoints now work while HHVM's JIT is enabled. [a225476c97](https://github.com/hershel-theodore-layton/hhvm/commit/a225476c972db94583a2dcf2d9dc0fbf31e8d96a)

## Security

- Proxygen responses no longer send `Content-Length` together with `Transfer-Encoding`. Emitting only the transfer coding avoids ambiguous HTTP response framing and keeps HHVM compliant with RFC 9112. [b1a80d1d3d](https://github.com/hershel-theodore-layton/hhvm/commit/b1a80d1d3d5efd4ed966bf3e905b1c6c24b171d1)

## Future Changes

- Hack now rejects static calls such as `T::foo()` when `T` is a trait with the pre-stable `require class` constraint. Call through the concrete class that satisfies the requirement instead; the new diagnostic is typing error 4476. [66031e6a16](https://github.com/hershel-theodore-layton/hhvm/commit/66031e6a169b3e38e2bcafd427c564183672384b)
