# 2023-10-18

## Highlights

- Memoized functions may now declare `HH\EnumClass\Label` parameters without a typechecker error, completing the runtime support added on October 4. [4cd1bb3fc8](https://github.com/hershel-theodore-layton/hhvm/commit/4cd1bb3fc8006049d1872b3419740e820fb1c9a5)
- A new `debugger_dump(mixed): void` builtin renders a value using the debugger's serializer. In particular, it honors a value's debugger-display customization rather than exposing the ordinary `var_dump()` representation. [22a6b2b3a7](https://github.com/hershel-theodore-layton/hhvm/commit/22a6b2b3a7d43a90847f51e381ed89b4bf7fe3b8)
