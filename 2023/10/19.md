# 2023-10-19

## Highlights

- Enum-class labels now work with the general serializers: `serialize()`-style modes use the dedicated `e:length:label;` representation, while JSON encodes a label as a string. [1b80a55bff](https://github.com/hershel-theodore-layton/hhvm/commit/1b80a55bff2d4da33b048e582be94bc12f0b69c2)
- Shape-key checking now follows every index in nested coalescing expressions such as `$shape['a']['b'] ?? $fallback`, so a missing inner key is no longer overlooked. [24b8ff501c](https://github.com/hershel-theodore-layton/hhvm/commit/24b8ff501c2cc1b371c9aafebe3ff6d74b2673ec)

## Future Changes

- The experimental `class<T>` syntax is now accepted by the typechecker and currently behaves as the migration spelling of `classname<T>`. [bc693532b5](https://github.com/hershel-theodore-layton/hhvm/commit/bc693532b57f5fb1029e98017bad07cd4acf20f1)
