# 2023-10-24

## Breaking Changes

- `HH\classname_from_string_unsafe()` has been removed from the bundled HHI, so project calls no longer typecheck. Prefer `C::class` when the class is statically known; where a typed class name or class pointer is already available, use the explicit conversion helpers introduced on October 5. [e4e180b387](https://github.com/hershel-theodore-layton/hhvm/commit/e4e180b3874b02328cc74973364595949ef3a9ad)
