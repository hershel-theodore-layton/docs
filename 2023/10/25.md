# 2023-10-25

## Highlights

- HTTP requests that expire after being dequeued now include `Retry-After` on their 503 response when `Server.503RetryAfterSeconds` is nonnegative, matching the other queue-timeout path. The header remains disabled by default. [8e43190ec7](https://github.com/hershel-theodore-layton/hhvm/commit/8e43190ec7134c5e03fa630370d226ecdec96a9a)

## Future Changes

- IDE autocomplete inside experimental `nameof` expressions now offers all classish declarations, including interfaces and traits rather than only instantiable classes. [2498045ddc](https://github.com/hershel-theodore-layton/hhvm/commit/2498045ddc4cc7fc3ae30f8504e9a9d10674b015)
