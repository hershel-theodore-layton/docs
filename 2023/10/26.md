# 2023-10-26

## Highlights

- Autocomplete after `new` no longer suggests type aliases, which cannot be instantiated and would produce naming error 2052. [004e06c110](https://github.com/hershel-theodore-layton/hhvm/commit/004e06c11070cfa3a8b67e98c9e7ffca8836cbb5)
- Functions and methods may use `<<__AutocompleteSortText('...')>>` to override their LSP sort key—for example, generated entry points can deliberately appear above their default alphabetical position. The argument must be one static string. [2fce55c0f2](https://github.com/hershel-theodore-layton/hhvm/commit/2fce55c0f23d1c5ae444fd060ef2f76a58465d1d)

## Breaking Changes

- `Eval.EnforceDeployment` now defaults to `true`. Deployments that previously relied on the off-by-default setting may begin warning for soft-package boundary violations and throwing `DeploymentBoundaryViolationException` for hard violations; fix the package/module boundary or explicitly review the runtime setting. [1146464fbf](https://github.com/hershel-theodore-layton/hhvm/commit/1146464fbf887db320974022d4c7982db93725f6)

## Future Changes

- Experimental typed locals now preserve runtime checks across destructuring and compound assignments by checking temporary values before committing them. Their shape and tuple checks intentionally remain shallow rather than validating every nested field or element. [b5fae97e2b](https://github.com/hershel-theodore-layton/hhvm/commit/b5fae97e2beef7b72f52ca6a49d924306eea6df1) [4a23bbba70](https://github.com/hershel-theodore-layton/hhvm/commit/4a23bbba7061728d5b36bc4f5f4ed9c88a6803ca)
