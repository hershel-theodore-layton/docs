# 2023-10-27

## Highlights

- A server may now enable both full and per-file coverage. Each request can select one mode, while attempts to use both modes in the same request fail explicitly. [b3523a4cf0](https://github.com/hershel-theodore-layton/hhvm/commit/b3523a4cf01d17a8439d8ce33dfb061ad50ab9a0)

## Future Changes

- Calls through intersection types are no longer incorrectly rejected under implicit pessimisation. [24c4cd9c79](https://github.com/hershel-theodore-layton/hhvm/commit/24c4cd9c79f3d56152beb725eace5402aea6552a)
- An experimental module-level trait may no longer also be `internal`; the typechecker now catches the combination that HHVM already rejected at runtime. [820766b1d0](https://github.com/hershel-theodore-layton/hhvm/commit/820766b1d0f9262e929d2a0da6d37e03f7f50da4)
