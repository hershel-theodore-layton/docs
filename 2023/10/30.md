# 2023-10-30

## Highlights

- The Hack REPL now warns when a file loaded into its current request has changed on disk, because the already-loaded code will not be refreshed until a new request. [56722eba42](https://github.com/hershel-theodore-layton/hhvm/commit/56722eba423c303499bd1cb0db2ebd9e1aed2d57)
- The quick-fix for debugger-style `=$expression` statements now produces `debugger_dump($expression)` instead of `var_dump()`. The debugger serializer honors custom debug displays, which helps avoid revealing a value's raw representation. [eb224b9d92](https://github.com/hershel-theodore-layton/hhvm/commit/eb224b9d92dc7c993a474b81fa8a8f76a7285974)

## Future Changes

- An experimental module-level trait may use only other traits annotated `<<__ModuleLevelTrait>>`; Hack now reports the invalid hierarchy before HHVM reaches its matching runtime fatal. [79e26d95a2](https://github.com/hershel-theodore-layton/hhvm/commit/79e26d95a2b0d29d6a1a808f78ab92e1ed49a7c6)
