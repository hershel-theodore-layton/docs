# 2023-10-31

## Highlights

- Nullable runtime assertions now refine like types precisely: if `$x` has type `~Base`, then `$x as ?Derived` is inferred as `?Derived` just like the non-nullable assertion. [e9d270eff8](https://github.com/hershel-theodore-layton/hhvm/commit/e9d270eff8c92e73309c84c5e00a1fb6f501d842)
- HHVM no longer intermittently loses an implicit context when only the low byte of its internal pointer is zero. [a7c1d33f17](https://github.com/hershel-theodore-layton/hhvm/commit/a7c1d33f1762b383e15b6614dbf4a28d5e433681)

## Breaking Changes

- Dynamic static calls with a fixed class, such as `C::$method()`, are now parse errors. If both pieces truly need runtime dispatch, the remaining supported form is `$class::$method()`; otherwise call the method by its literal name. [e120477a21](https://github.com/hershel-theodore-layton/hhvm/commit/e120477a2187032304e6b38ebea2c49f299cae09)
- `hh_client lsp` must now be launched with an explicit project-root argument or from the project root (or one of its subdirectories). Editor integrations that started it from an unrelated working directory must set the root or working directory. [773a315692](https://github.com/hershel-theodore-layton/hhvm/commit/773a315692c4f1bf186696ad0a0f041b6d21effe)

## Future Changes

- The unstable nested-await implementation now diagnoses sequential awaits mixed into incompatible concurrent expressions, including sequential awaits inside a `concurrent` block. [13ad012627](https://github.com/hershel-theodore-layton/hhvm/commit/13ad0126275eb1a0c19ca74ebddcb3a09c726e9e)
- Under implicit pessimisation, `HH\Readonly\as_mut()` now retains its declared return type instead of acquiring an automatic outer like type. [5d156974e2](https://github.com/hershel-theodore-layton/hhvm/commit/5d156974e2f8c545ad9bfc70e97ac9a117a063bd)
