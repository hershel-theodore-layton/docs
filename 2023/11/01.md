# 2023-11-01

## Highlights

- The VS debugger's asynchronous pause command now interrupts JIT-compiled loops and branches, so pausing no longer depends on the request reaching interpreted code. [b08759b062](https://github.com/hershel-theodore-layton/hhvm/commit/b08759b062a66beda816dc423f3e9a4183570428)
- `HH\classname_to_class()` now handles nonexistent lazy class values consistently, throwing an `InvalidArgumentException` that identifies whether the failed name came from a lazy class or a string. [fb958936dc](https://github.com/hershel-theodore-layton/hhvm/commit/fb958936dc78d9dd8b919f0a7f9e2be78f6f7d81)

## Future Changes

- Hover documentation for the pre-stable `require class` feature no longer incorrectly claims that a trait can always access private members of its using class. Such access requires an appropriate constraint. [ff0561fc8f](https://github.com/hershel-theodore-layton/hhvm/commit/ff0561fc8f730c7695c42698ec9d7bb589f2afd9)
