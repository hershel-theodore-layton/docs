# 2023-11-03

## Highlights

- Type errors can now trace a suspicious type back through `HH\FIXME\UNSAFE_CAST`, making it clearer when a reported type may be a lie introduced by an unsafe cast. [a250bace2b](https://github.com/hershel-theodore-layton/hhvm/commit/a250bace2b55ef80397be54f105e37faca767639)

## Future Changes

- Closures created inside experimental module-level traits now retain the trait's original module identity after HHBBC copies the trait into a using class, preserving the intended module-boundary behavior. [fc269a6ce4](https://github.com/hershel-theodore-layton/hhvm/commit/fc269a6ce42f4d6fb02a9fe8fa1ed44419df4ac3)
