# 2023-11-06

## Highlights

- `hh --config dump_tasts=file_list.txt` can now dump the named files' typed ASTs to `/tmp/hh_server/tasts` or `/tmp/hh_distc/tasts`, including when typechecking is distributed. [ac3fec9645](https://github.com/hershel-theodore-layton/hhvm/commit/ac3fec9645a6c8e466c955d093d023317592aac8)

## Breaking Changes

- HHVM no longer populates `$_SERVER['REQUEST_START_TIME']`, `REQUEST_TIME`, or `REQUEST_TIME_FLOAT`. Use nanosecond-resolution `$_SERVER['REQUEST_TIME_NS']` instead. [d23fe23887](https://github.com/hershel-theodore-layton/hhvm/commit/d23fe23887494c52f74a1620068226c9a8fcf9a3)

## Future Changes

- Experimental typed locals now use shallow runtime enforcement, checking the outer declared type without recursively validating all nested type arguments. [9212f22d4c](https://github.com/hershel-theodore-layton/hhvm/commit/9212f22d4c635e588383d34d970fc6506b49a5c1)
