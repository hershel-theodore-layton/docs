# 2023-11-08

## Highlights

- Autocomplete now works inside top-level statements, primarily improving Hack notebook editing while leaving the ordinary top-level-statement diagnostic intact. [a0de61cb38](https://github.com/hershel-theodore-layton/hhvm/commit/a0de61cb381b31855e4b79ab6387746f7b47b5ca)
- `hash()` and `hash_copy()` are now declared with the empty capability set `[]` rather than implicit `[defaults]`. This narrows their requirements and permits calls from pure contexts. [60c9fc68eb](https://github.com/hershel-theodore-layton/hhvm/commit/60c9fc68ebf315c2990afcde5bd5b364f79e8dbc)

## Future Changes

- Runtime violations of experimental typed-local declarations now raise a catchable fatal, matching parameter type-hint enforcement, rather than throwing `TypeAssertionException` as an `as` expression does. [15a807f59e](https://github.com/hershel-theodore-layton/hhvm/commit/15a807f59e8ff9101eeed25b947387e1757c4134)
