# 2023-11-10

## Highlights

- `echo` is now represented by a real typed signature, `(readonly arraykey ...)[io]: void`, instead of a `Tany`-based special case. Argument and missing-`[io]` capability errors now point back to that signature. [11bed300da](https://github.com/hershel-theodore-layton/hhvm/commit/11bed300da5db2dd3a6ec0045e8856b971337fc5)
- Consecutive top-level statements now share a typing environment. Notebook hover and completion can therefore understand values assigned by earlier statements in the file. [9e37abd5a1](https://github.com/hershel-theodore-layton/hhvm/commit/9e37abd5a126e3a2399a643cfb9913442e68ba35)
- LSP clients advertising the experimental `autoCloseJsx` capability can now request automatic XHP closing tags. [4697a751c8](https://github.com/hershel-theodore-layton/hhvm/commit/4697a751c8b3216324812319e2be5b48cb32303d)
