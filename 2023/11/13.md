# 2023-11-13

## Highlights

- Accessing an undeclared field on an open shape now uses the shape's `...` value type after reporting the missing-field error, rather than producing an error variable that usually inferred as `nothing`. [54d1903493](https://github.com/hershel-theodore-layton/hhvm/commit/54d1903493915b45ad21a8f9defc3b5f98c14afc)
- Standard math declarations now expose precise, pure signatures: most transcendental functions return `float`, predicates return `bool`, and `pow()` accepts `num` arguments. Hover, autocomplete, and downstream inference no longer see missing placeholder types for these APIs. [c53dbdd62b](https://github.com/hershel-theodore-layton/hhvm/commit/c53dbdd62ba63663abccc597f977b19aea682f5f)
- The “Extract into variable” code action now works in top-level notebook statements. [9f02369148](https://github.com/hershel-theodore-layton/hhvm/commit/9f0236914832342408d425410dd8c7db36a6212e)
