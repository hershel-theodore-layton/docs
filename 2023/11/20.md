# 2023-11-20

## Breaking Changes

- The unused, flag-gated `@Attribute` syntax and its `allow_new_attribute_syntax` configuration have been removed. This does not remove the ordinary `@` error-suppression operator or Hack's `<<Attribute>>` syntax. [00f81dfbb8](https://github.com/hershel-theodore-layton/hhvm/commit/00f81dfbb882bb43807bc248189e575422f52049)

## Future Changes

- Experimental `match` statements gained basic type inference, pattern-based refinement, and exhaustivity errors. Redundant-arm checking is not implemented yet. [9cf43c0d22](https://github.com/hershel-theodore-layton/hhvm/commit/9cf43c0d22004425b4cd864ad5f7ac03700b73c9)
