# 2023-11-27

## Highlights

- `hh_single_fanout` now includes files with stale errors in its recheck set, keeping reported positions current after dependency changes. [85c8967bbd](https://github.com/hershel-theodore-layton/hhvm/commit/85c8967bbdb24fa1effcbc40177fe1500d41e205)
- Invalid compound module names containing reserved `default` now produce a direct parser error instead of malformed AST nodes and confusing follow-on diagnostics. [f390763c64](https://github.com/hershel-theodore-layton/hhvm/commit/f390763c648a1394f97bc8b287582b77b78f3b18)

## Breaking Changes

- `HH\FIXME\UNSAFE_CAST<Tin, Tout>()` now requires both type arguments to support `dynamic` and returns `~Tout`; `UNSAFE_NONNULL_CAST<T>()` similarly returns `~T`. This soundness fix applies even without `everything_sdt` and may expose code that treated unsafe-cast results as trustworthy precise types. [7040cd5beb](https://github.com/hershel-theodore-layton/hhvm/commit/7040cd5beb56b2d4bd3434d3a28a00d6a241caea)
