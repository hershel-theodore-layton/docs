# 2023-11-28

## Highlights

- Standard-library HHI declarations now use real like types such as `~SplFileInfo` and `~int` instead of the internal `HH\FIXME\POISON_MARKER<T>` alias, improving hover and diagnostics for pessimised built-ins. [f18ae44cf3](https://github.com/hershel-theodore-layton/hhvm/commit/f18ae44cf3054677b658de6655d7eb4a6eed4d61)
- Facts attribute-value queries now correctly normalize `Class` and `LazyClass` values to class names. [a814431794](https://github.com/hershel-theodore-layton/hhvm/commit/a814431794295868005ba8e7812a4318cbbd2ddc)
- The language server now unconditionally defers diagnostic recomputation after file opens and edits until it becomes idle, then publishes the results to the editor. The `lsp_pull_diagnostics` rollout flag has been removed. [e152ec6b86](https://github.com/hershel-theodore-layton/hhvm/commit/e152ec6b86ea6a59eafbc25d24839549ffabc94f)
- Hack now accepts and validates `<<__AutocompleteSortText("...")>>` on classes as well as functions and methods. Completion ordering support follows on November 29. [2c09844345](https://github.com/hershel-theodore-layton/hhvm/commit/2c09844345b494255c2b7ad7f9896bf2292bb649)
