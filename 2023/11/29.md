# 2023-11-29

## Highlights

- With the new off-by-default `implicit_inherit_sdt` option, a class or interface can inherit `<<__SupportDynamicType>>` behavior from an SDT parent instead of repeating the attribute. [91e91b246c](https://github.com/hershel-theodore-layton/hhvm/commit/91e91b246cfcd0e89b7de48783acf26e2875c1e3)
- Autocomplete declaration paths now retain `<<__AutocompleteSortText>>` values for methods and class elements, allowing the requested custom ordering to reach completion results. [d093f7148f](https://github.com/hershel-theodore-layton/hhvm/commit/d093f7148f00e6f735136848a3354b35eddce2c0) [6aecbfbc4f](https://github.com/hershel-theodore-layton/hhvm/commit/6aecbfbc4fadd45f7580d3bd50f2ac1fd38231df)
- Top-level-statement validation is now a naming error rather than a parsing error. Normal Hack files still reject the statements, but the IDE and `hh` can continue showing unrelated type errors in the rest of the file, improving notebook feedback. [0e80ee7ded](https://github.com/hershel-theodore-layton/hhvm/commit/0e80ee7ded38406dc72ee701e0c5c2b919d3aeaf)
- The new pure builtin `fb_utf8_decompose(string)[]: vec<string>` splits a UTF-8 string into individual encoded characters. [0f1b5fd248](https://github.com/hershel-theodore-layton/hhvm/commit/0f1b5fd248a0c6e3cae901c45466aead410b81f3)

## Security

- `HH\classname_to_class()` now performs module-boundary checks when resolving a string, closing a path that could otherwise resolve an internal class from another module. [6f6cde3a63](https://github.com/hershel-theodore-layton/hhvm/commit/6f6cde3a635b455c9ef83c9d44563136bd3d0e8a)
