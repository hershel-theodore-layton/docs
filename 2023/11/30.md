# 2023-11-30

## Highlights

- The VS debugger REPL now warns when a source file loaded into the session changes on disk and recommends reloading. The default can be disabled with `hphp_debugger_set_option('warnOnFileChange', false)`. [bc18048e1f](https://github.com/hershel-theodore-layton/hhvm/commit/bc18048e1fe2dd198085d01c394adcc3124ac788)

## Breaking Changes

- `hh_single_type_check` now enables like-type hints by default. Scripts that intentionally test the disabled mode must pass `--config like_type_hints=false`. [50988da888](https://github.com/hershel-theodore-layton/hhvm/commit/50988da888f0c6747378bad49e4d556b447bfd7c)
