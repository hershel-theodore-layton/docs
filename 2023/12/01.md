# 2023-12-01

## Highlights

- `hh_single_type_check --root` can now locate a downloaded naming table automatically and reads `enable_sound_dynamic_type` and `everything_sdt` from the project's `.hhconfig`, reducing differences from a normal `hh` run. [99c4e207d0](https://github.com/hershel-theodore-layton/hhvm/commit/99c4e207d07acad0169589f9527c3765837fba1f)
- The Hack manual now documents `__AutocompleteSortText`, which lets a declaration supply the sort key used for its IDE completion entry. [1785b081e2](https://github.com/hershel-theodore-layton/hhvm/commit/1785b081e2583ba5562b863c0d8e3195ea01659e)

## Breaking Changes

- `hh_single_type_check` no longer accepts the `--like-type-hints` switch and always enables like-type hints by default. Use `--config like_type_hints=false` when the legacy behavior is required. [12e71b4968](https://github.com/hershel-theodore-layton/hhvm/commit/12e71b4968fe9f300ecfbf3ae8a931957f113846)
- The typechecker now rejects `varray[...]` and `darray[...]` initializer syntax. Migrate remaining initializers to `vec[...]` and `dict[...]`. [6e4f4cfed0](https://github.com/hershel-theodore-layton/hhvm/commit/6e4f4cfed0983843aa47e31700942346def24c3d)
- A function marked `__DynamicallyCallable` and a class marked `__DynamicallyReferenced` are now implicitly treated as `__SupportDynamicType`. This removes the need to repeat the latter attribute, but it also checks those declarations under sound-dynamic assumptions and can expose new errors in their bodies or signatures. [f84c931769](https://github.com/hershel-theodore-layton/hhvm/commit/f84c931769bf6d16481e903e89539ea67526cc41) [f81b17b454](https://github.com/hershel-theodore-layton/hhvm/commit/f81b17b45470cf6fb26f1479e8cc91e27db783ab)

## Future Changes

- Typed local variables have moved from Unstable to Preview. They still require `<<file:__EnableUnstableFeatures('typed_local_variables')>>`, but the Preview status permits opted-in code to run in production. [466d390616](https://github.com/hershel-theodore-layton/hhvm/commit/466d39061604a2d5b93a072820e4dd155ffa001f)
