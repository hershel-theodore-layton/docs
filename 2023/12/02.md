# 2023-12-02

## Future Changes

- `nameof` is being changed to bind like a prefix unary operator, so expressions such as `nameof C . 'Suffix'`, `nameof C is string`, and `nameof C |> f($$)` apply the following operator outside `nameof`. The runtime compiler uses the new precedence immediately; the typechecker can opt in with `nameof_precedence=true`, but its default remains on the old parser behavior for this rollout stage.
