# 2023-12-04

## Highlights

- Best-effort notebook support now typechecks top-level statements as the body of a synthetic async function. This restores completions and ordinary type errors around top-level `await`, and initializes the same implicit capability locals as a function instead of reporting `$#capability` as undefined. Normal Hack files still receive the general error that top-level statements are unsupported. [aa87ac15ee](https://github.com/hershel-theodore-layton/hhvm/commit/aa87ac15eea44a5dae978a7b0c42a0c0e8a51511) [d5c48abf18](https://github.com/hershel-theodore-layton/hhvm/commit/d5c48abf18ba7c335d76cf539711363fe0cac9ba)
- `debugger_dump()` is now visible to typechecked notebook code. This removes only its `__PHPStdLib` restriction; its omitted capability list continues to mean `[defaults]`. [8c7dfdb58b](https://github.com/hershel-theodore-layton/hhvm/commit/8c7dfdb58b0f18db30f94d5398f034b900ab2ab2)

## Future Changes

- A trait with the pre-stable `require class C` constraint may now call `parent::`; the call is checked against the required class's parent just as it is for `require extends`. [c2149e9281](https://github.com/hershel-theodore-layton/hhvm/commit/c2149e92816ed70408751c6563e996d65df0d593)
