# 2023-12-05

## Highlights

- HHVM no longer raises a runtime fatal when a trait marked `__ModuleLevelTrait` uses an ordinary trait. Hack's typechecker still rejects this hierarchy at this stage; this commit removes only the runtime restriction. [d1cfeadc32](https://github.com/hershel-theodore-layton/hhvm/commit/d1cfeadc32e8565c1e98f547e7080c9af0735d6a)

## Future Changes

- IDE rename now handles Preview typed-local declarations, and typechecker errors point at the declared local rather than the entire `let` statement. Runtime enforcement failures are also prefixed with “Typed local assignment” to distinguish them from parameter and return-type failures. [1332c3ee42](https://github.com/hershel-theodore-layton/hhvm/commit/1332c3ee4226f1e8b9c6ad042ffd39684d0bfbd2) [a164327813](https://github.com/hershel-theodore-layton/hhvm/commit/a164327813d28e7f5f622da83371167afa6f296d)
