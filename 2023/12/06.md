# 2023-12-06

## Highlights

- Enum-class-label completion now solves refinement-type constraints before filtering candidates, avoiding the fallback that suggested every label when only a constrained subset was valid. [3b57ad1701](https://github.com/hershel-theodore-layton/hhvm/commit/3b57ad1701b6fce0c29b496b1a12c371b7e2b390)
- `HH\FileDecls::getFile()` now returns typedefs and modules under their proper keys instead of accidentally overwriting the file-attributes entry. [15c78d1216](https://github.com/hershel-theodore-layton/hhvm/commit/15c78d1216e27b12e33a5958f8254adc274e3ae1)

## Breaking Changes

- The declaration-inspection extension has moved its global `FileDecls` class, shapes, and constants into the `HH` namespace, and a new HHI makes the API available to the typechecker. Update calls to use `HH\FileDecls` and qualify associated types and constants. [5fe71bb694](https://github.com/hershel-theodore-layton/hhvm/commit/5fe71bb694e53d3691609ee614cfc5b4de05981b)
- Converting a reified function pointer to `bool` now consistently produces `true`. The interpreter previously threw `InvalidOperationException` while JIT-compiled code already returned `true`. [327f2611e6](https://github.com/hershel-theodore-layton/hhvm/commit/327f2611e6100c7789383ea8546cf028f7599bb9)
