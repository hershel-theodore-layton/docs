# 2023-12-07

## Highlights

- Enum-class-label completion no longer resolves a contravariant type variable prematurely to `mixed` or `supportdyn<mixed>`, allowing the IDE to retain the useful label candidates implied by narrower bounds. [ee19abb9a3](https://github.com/hershel-theodore-layton/hhvm/commit/ee19abb9a321ea70f775ebab0d7f06b49c48a155)
- HHVM's sodium extension adds the missing Ristretto255 point operations: `sodium_crypto_core_ristretto255_add()`, `sodium_crypto_core_ristretto255_sub()`, `sodium_crypto_core_ristretto255_is_valid_point()`, and `sodium_crypto_core_ristretto255_random()`. [ed0c96f189](https://github.com/hershel-theodore-layton/hhvm/commit/ed0c96f18999f73c69500463411eed1bc3516ecf)

## Breaking Changes

- Ancestor traversal now gives directly declared `implements` entries precedence over interfaces inherited through `extends`. For a type that reaches the same generic interface at several instantiations, this can change which instantiation wins and can expose type errors that the previous ordering hid. [23ac49c0fa](https://github.com/hershel-theodore-layton/hhvm/commit/23ac49c0fab9ca72263ca564cf06ca63f825f4c1)
