# 2023-12-08

## Highlights

- IDE completion signatures now print declared coeffects, including `[]`, named contexts, and context-polymorphic requirements, instead of silently omitting them. This is a presentation fix: callee requirements and the rule that callers need a superset of those capabilities are unchanged. [b1a1774b1f](https://github.com/hershel-theodore-layton/hhvm/commit/b1a1774b1f3c028843b0674f9a72ce044399f82b)
- Override diagnostics now compare against and describe the instantiated parent member type, producing more useful explanations for failures inherited through generic parents and traits. [3c76b90da3](https://github.com/hershel-theodore-layton/hhvm/commit/3c76b90da3bcc0a71fc4083aff66c240b04787a1)
- The standard hash extension now supports unkeyed BLAKE3 through APIs such as `hash('blake3', $data)`. [d648c1cc26](https://github.com/hershel-theodore-layton/hhvm/commit/d648c1cc26e249633de38af17e79e44eab160a6f)
- The HHI for `debugger_dump()` now gives its argument the real `mixed` type, so arbitrary values no longer need a missing-type workaround. [0c5f03837e](https://github.com/hershel-theodore-layton/hhvm/commit/0c5f03837e4bf39f87a3ec412d79012579eb2425)

## Breaking Changes

- When a class or interface reaches the same generic interface at multiple instantiations, the winning instantiation must now be a subtype of every ignored instantiation. Invalid hierarchies report `Typing[4480]`; `__AllowMultipleInstantiations` is available as an unsafe migration escape hatch. [f61d456473](https://github.com/hershel-theodore-layton/hhvm/commit/f61d45647352081ed1123e714c8d367f0d9e6bb3)

## Future Changes

- The unstable `function_references` feature introduces invariant `HH\FunctionRef<T>` types for APIs that update a named function pointer. Named function pointers receive the wrapper type, lambdas do not, and the wrapper is erased before runtime. Where unstable features are allowed, opt in with `<<file:__EnableUnstableFeatures('function_references')>>`. [5bb1ca7dca](https://github.com/hershel-theodore-layton/hhvm/commit/5bb1ca7dcae446080cc07f058665a67bc27c66c0)
