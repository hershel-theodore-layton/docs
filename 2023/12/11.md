# 2023-12-11

## Highlights

- `nameof` now accepts transparent and opaque type aliases and returns the alias's own name. For example, `type T = int` produces `typename<int>`, while an opaque `newtype U` produces `typename<U>`. [119ec37e14](https://github.com/hershel-theodore-layton/hhvm/commit/119ec37e14f170ae6bf3e7a3a95836562bdeb02e)

## Future Changes

- Runtime type constraints now recognize the explicit `HH\object` type as “any object.” This is groundwork: no builtin or HHI declaration uses the new constraint yet. [93db8b6ada](https://github.com/hershel-theodore-layton/hhvm/commit/93db8b6adac4aaf72808dec7eb9dbee8f3ec5703)
