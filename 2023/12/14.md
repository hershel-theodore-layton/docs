# 2023-12-14

## Highlights

- `hh_single_complete --root` can now locate a downloaded naming table automatically and load project settings from `.hhconfig`, matching the corresponding `hh_single_type_check` workflow. [c1f8037cd1](https://github.com/hershel-theodore-layton/hhvm/commit/c1f8037cd132ec86b39342ae3a91bacc664577ed)
- `hackc verify compile` can compile a set of Hack files solely to report parse, runtime, and compilation errors without retaining bytecode output. [cb15edecd9](https://github.com/hershel-theodore-layton/hhvm/commit/cb15edecd973ccb31c4b72af162a949275307ec2)

## Breaking Changes

- The language's special handling for `die` has been removed. Replace remaining `die(...)` calls with `exit(...)`. [85d879120e](https://github.com/hershel-theodore-layton/hhvm/commit/85d879120e4419f149c317b98b32e42e8e39d8e9)
