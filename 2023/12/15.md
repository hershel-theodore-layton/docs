# 2023-12-15

## Highlights

- An opt-in strict UTF-8 parser mode can reject source files containing invalid byte sequences. Hack uses `strict_utf8=true`; HHVM's `Eval.StrictUtf8Mode` remains off at `0`, rejects source but permits `eval` input at `1`, and rejects both at `2`. [002372fd69](https://github.com/hershel-theodore-layton/hhvm/commit/002372fd69588df6444275312b1ad3fc69469db6)

## Breaking Changes

- Constructors of `__SupportDynamicType` classes are now checked under dynamic assumptions, just like their other methods. Constructors that store or return values incompatible with dynamic construction can therefore gain new sound-dynamic errors. [9004eeeb25](https://github.com/hershel-theodore-layton/hhvm/commit/9004eeeb255e06f2459ea3b5c40e1dc558f3b136)

## Future Changes

- Module-level traits have advanced from Preview to Ongoing Release. The runtime compiler can accept them during the rollout, while typechecked source still needs the `module_level_traits` file-level feature opt-in. [9cd2521478](https://github.com/hershel-theodore-layton/hhvm/commit/9cd2521478441a2aa50efc07a7d9138e57869362)
