# 2023-12-18

## Highlights

- `HH\FileDecls::parsePath()` is now implemented: it reads a Hack file from disk and returns the same declaration view as `parseText()`, throwing `InvalidArgumentException` when the path is missing or cannot be opened. [de1dd54b17](https://github.com/hershel-theodore-layton/hhvm/commit/de1dd54b178d2010e187971dcc13735c39e38c55)
- `HH\class_to_classname()` now retains dynamically constructed string inputs correctly, preventing its returned classname string from becoming invalid after the native wrapper releases the argument. [f4402a8d7a](https://github.com/hershel-theodore-layton/hhvm/commit/f4402a8d7a4ac561dc55cda0bc8577ee2c8a89c1)

## Breaking Changes

- Support for `meth_caller(nameof C, 'method')`, introduced on December 9, has been backed out because the compiler lowering was unsound. Use `meth_caller(C::class, 'method')` again. [420490f6e1](https://github.com/hershel-theodore-layton/hhvm/commit/420490f6e17b4e9df47fad26c31b21cf6234b325)
