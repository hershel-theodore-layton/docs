# 2023-12-19

## Highlights

- Find-references, find-class-references, and refactor requests no longer restart their file iteration after cancellation polling, fixing searches that could run indefinitely. [6808aa6797](https://github.com/hershel-theodore-layton/hhvm/commit/6808aa6797de6e84129c327425c01f4a7ef793fd)
- LSP request cancellation is now enabled by default, so abandoned IDE work can stop rather than delaying the replacement request. [94342a995c](https://github.com/hershel-theodore-layton/hhvm/commit/94342a995cadfe768e6f3970e31c16fd18ce110c)
- Direct-declaration parsing with user attributes retained no longer drops heredoc, nowdoc, or parenthesized expressions. This prevents affected constants from degrading to an unknown type in downstream typechecking. [230809b98e](https://github.com/hershel-theodore-layton/hhvm/commit/230809b98e6ea61e7ee91ae0b8388f103cbc5d45)
- Type errors that refer to expression-dependent types now print stable internal `<expr#…>` identifiers rather than renumbering them for display. The numbers may be larger or nonconsecutive, but repeated runs are deterministic. [65e011a6fd](https://github.com/hershel-theodore-layton/hhvm/commit/65e011a6fd4bfa1fbc2bd692dc0adbafd7888d09)
