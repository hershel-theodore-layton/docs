# 2023-12-20

## Highlights

- The Hack manual now includes a package guide covering package definitions, deployments, cross-package calls, and `PACKAGES.toml` configuration. [77eea71427](https://github.com/hershel-theodore-layton/hhvm/commit/77eea71427755c4bb61b20092b85cbf01541e885)

## Breaking Changes

- `FixDefaultArgReflection` now defaults to mode `2`. If evaluating a parameter's default expression during reflection fails, HHVM emits a warning and reports the reflected default as `null` instead of exposing the evaluator's exception under the old mode. [6adc7b1655](https://github.com/hershel-theodore-layton/hhvm/commit/6adc7b1655cc665725b689b42237d4e8bd674a26)
