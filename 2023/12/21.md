# 2023-12-21

## Highlights

- The VS Code debugger now evaluates a request without an explicit frame ID in the frame selected by the most recent `scopes` request, when execution is paused. [9de19a803e](https://github.com/hershel-theodore-layton/hhvm/commit/9de19a803e83d191449f5513a676328e8b6d6845)
- Repo-authoritative optimization now converts type constraints back to unresolved form when their target class is later found to be missing or uninstantiable, avoiding stale resolved constraints against nonexistent classes. [6de1d23d18](https://github.com/hershel-theodore-layton/hhvm/commit/6de1d23d1854eb09ec5e25af487e99c83a0d866f)

## Breaking Changes

- `hh_single_type_check` no longer accepts `--math-new-code`; the newer arithmetic-checking behavior is always enabled in the tool. [6c1dbdb71d](https://github.com/hershel-theodore-layton/hhvm/commit/6c1dbdb71de7fc8eb32c60ab69160ce53b50eb4a)
