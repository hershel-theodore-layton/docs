# 2023-12-27

## Future Changes

- Package `allow_directories` restrictions can now be parsed from `PACKAGES.toml`, resolved relative to that file, and loaded into the typechecker's package information. Validation and enforcement are not implemented in this stack yet. [4f827c77b1](https://github.com/hershel-theodore-layton/hhvm/commit/4f827c77b145732820781d5c0792d5f3672fe3b2) [4d08d8fb03](https://github.com/hershel-theodore-layton/hhvm/commit/4d08d8fb03f185c04720db3b6178beb72981b6d0) [337f4ebbce](https://github.com/hershel-theodore-layton/hhvm/commit/337f4ebbce1d74012e7bc51ccb00dfdeac057f87)
- A gated IDE invalidation strategy now detects individual class-signature changes and invalidates that class plus cached descendants that depend on it, aiming to avoid both stale IDE errors and full-cache invalidation. The `lsp_invalidation` rollout flag remains off by default.
