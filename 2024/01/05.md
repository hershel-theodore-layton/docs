# 2024-01-05

## Highlights

- Separate Hack notebook kernels can now define declarations with the same source names without colliding, and top-level notebook statements now respect the repository's auto-namespace map. [3475febb1c](https://github.com/hershel-theodore-layton/hhvm/commit/3475febb1c9782b1054653e82d5d94243d0b8371) [33f41836a4](https://github.com/hershel-theodore-layton/hhvm/commit/33f41836a4f1437ef8d850642e4adf056d8a5de1)
- The new pure `HH\FileDecls::parseTypeExpression(string)[]` API parses a standalone type expression into a recursive declaration structure without the cost of runtime `type_structure()`. [96ee1ec4c5](https://github.com/hershel-theodore-layton/hhvm/commit/96ee1ec4c5f5f77d6e47d2ac9ae8d2ca156c2009)

## Security

- The fb303 server can now check and enforce access-control lists using `Fb303Server.EnableAclChecks`, `Fb303Server.EnforceAclChecks`, and `Fb303Server.Identity`. The feature is disabled by default. [de71bf51b0](https://github.com/hershel-theodore-layton/hhvm/commit/de71bf51b0af499587007d9dcd1a7b3e14979465)

## Breaking Changes

- Built-in declarations that accidentally used the nonexistent `object` type now use concrete DOM types or `HH\object`. In particular, `XSLTProcessor::importStylesheet()` now accepts `DOMDocument`, not `SimpleXMLElement`. [3c1e77a511](https://github.com/hershel-theodore-layton/hhvm/commit/3c1e77a511ca3a5fcf4160763b9f41ad41c8ecd0)
- The legacy `fb_set_post_autoload_handler()` API has been removed. [8f0646db1f](https://github.com/hershel-theodore-layton/hhvm/commit/8f0646db1fca843a8f3a8d797ad7f30f733adac4)
