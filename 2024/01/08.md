# 2024-01-08

## Highlights

- Type printers now render empty unions as `nothing` and empty intersections as `mixed`, replacing confusing output such as `|()`. [ac9984d4bf](https://github.com/hershel-theodore-layton/hhvm/commit/ac9984d4bfb3ddc670094fe63cfb5d0592bdc606)
- An overriding method without its own `<<__AutocompleteSortText>>` now inherits the sort key from its parent declaration. [3e5fa6a58a](https://github.com/hershel-theodore-layton/hhvm/commit/3e5fa6a58a358f44d93aff8b59a6e0bb0ba21360)

## Breaking Changes

- Hack's AST no longer has separate `Darray` and `Varray` nodes: legacy `darray[...]` and `varray[...]` syntax is lowered to `dict` and `vec` nodes. Typed-AST and parser tooling that distinguishes the legacy nodes must migrate. [489f6fe405](https://github.com/hershel-theodore-layton/hhvm/commit/489f6fe4055c5f9a8cd1623f4d6fefe5f583d9b8)

## Future Changes

- Experimental module-level traits can now define `internal` methods and properties while preserving the trait's original module for boundary checks. [a1db805b0a](https://github.com/hershel-theodore-layton/hhvm/commit/a1db805b0a3b288f968edfb3f9080e3b83de2df1)
