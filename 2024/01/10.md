# 2024-01-10

## Highlights

- `hh --single file.php --show-tast` now provides a dedicated way to print one file's typed AST. [b4fa8c14db](https://github.com/hershel-theodore-layton/hhvm/commit/b4fa8c14db3528451e33c16f60c33365631a2df7)
- Sound Dynamic call inference now tries a dynamic check first when an argument is already like-typed but its generic parameter is not. This removes false errors for calls that mix lambda arguments with pessimised values. [f544f07cb4](https://github.com/hershel-theodore-layton/hhvm/commit/f544f07cb4a9f88b9202bd69c28de677c037ec43)
- Cross-package calls no longer require the `package` unstable-feature opt-in. Bundled declarations now also expose `HH\module_exists(string, bool)[]: bool` and `HH\package_exists(string)[defaults]: bool`. [6c9d99cc02](https://github.com/hershel-theodore-layton/hhvm/commit/6c9d99cc029eaed2f341e6d006961badb85e8b55)

## Breaking Changes

- The old `<<__AllowMultipleInstantiations>>` spelling has been removed; experimental code must use the explicitly unsafe `<<__UNSAFE_AllowMultipleInstantiations>>` name. [53a31ae7b7](https://github.com/hershel-theodore-layton/hhvm/commit/53a31ae7b7704dffb8bd06110200e8de7e01cdd6)
