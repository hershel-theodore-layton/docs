# 2024-01-16

## Highlights

- Sound Dynamic refinement now treats shapes as enforceable when every field type is enforceable, producing more precise results after `is` checks on like-typed values. [12878d63e8](https://github.com/hershel-theodore-layton/hhvm/commit/12878d63e84c44c790ba45cf5f008afd666fd2ae)

## Breaking Changes

- `HH\classname` is now always handled as the dedicated classname runtime annotation, independent of `Eval.ClassPassesClassname`; string conversion must go through an explicit string position. The pure `HH\class_to_classname()` builtin is also tightened from `mixed -> mixed` to `classname<mixed> -> classname<mixed>`. [f0ec4483d1](https://github.com/hershel-theodore-layton/hhvm/commit/f0ec4483d16cb38e45f8b8417910dc2f3a6a92c3)
