# 2024-01-19

## Highlights

- Lambda compatibility now compares the full accepted argument range when default parameters are present. A lambda is accepted when it can handle every arity promised by the expected function type, rather than requiring identical minimum arities. [98a4a79060](https://github.com/hershel-theodore-layton/hhvm/commit/98a4a79060ef4382f0d7c3de19416a4dd61ceb07)

## Future Changes

- Package configuration parsing now accepts an `allow_directories` field, canonicalizes its relative paths and optional `*` suffixes, and rejects paths that do not exist. Typechecker enforcement follows later in the month. [1e848e45b1](https://github.com/hershel-theodore-layton/hhvm/commit/1e848e45b1c809d92b47e417db5a94bb3df2cde5)
