# 2024-01-22

## Highlights

- `HH\package_exists()` now returns `true` for soft-deployed packages, matching their status as loaded packages whose boundary violations warn rather than throw. [a7f1122c6e](https://github.com/hershel-theodore-layton/hhvm/commit/a7f1122c6e123c35c6a6767756c55f12a03d83d9)
- Virtual lambdas synthesized for expression trees are now pure, so expression trees containing virtualized effects can be constructed inside `[]` functions. Property writes are checked inside an uncalled lambda with the required capability and no longer refine the runtime property. [9abcdf6c65](https://github.com/hershel-theodore-layton/hhvm/commit/9abcdf6c657381ad5a2d0392a1e42581617d90da)

## Breaking Changes

- Runtime upper bounds on generic types are now always fully enforced, and the non-default modes of `Eval.EnforceGenericsUB` have been removed. Code that relied on warning-only or disabled upper-bound checks can now receive catchable fatals. [772702fa69](https://github.com/hershel-theodore-layton/hhvm/commit/772702fa69d240b285e8e022309362a851cac77e)
