# 2024-01-23

## Security

- A function or method carrying `<<__CrossPackage("pkg")>>` now begins with an invariant that the named package is actually loaded. Misconfigured cross-package access fails immediately instead of continuing into boundary violations. [b6593e555d](https://github.com/hershel-theodore-layton/hhvm/commit/b6593e555d8c3f0e5bd3dd8da0bc47fd1eb1f686)

## Breaking Changes

- Standard runtime parameter type checking for C++ builtins is now enabled in soft mode by default through `Eval.CheckBuiltinParamTypeHints=1`. Invalid arguments can emit new type-hint warnings; deployments may use `0` to disable checks or `2` for hard enforcement. [cdc7f67f91](https://github.com/hershel-theodore-layton/hhvm/commit/cdc7f67f917926bbbfaa230afb196140f2b00f51)
