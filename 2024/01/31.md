# 2024-01-31

## Highlights

- The `<<__NonDisjoint>>` linter now checks generic arguments on instance and static method calls, including enclosing class generics connected through `where` constraints. [eba49df195](https://github.com/hershel-theodore-layton/hhvm/commit/eba49df19530a70020f9f16949bceb31d37d2f62)

## Future Changes

- Pre-stable function type hints now support `optional` parameters, for example `(function(int, optional string): void)`. Optional parameters must trail required ones and cannot be `inout` or variadic. [62e76b9785](https://github.com/hershel-theodore-layton/hhvm/commit/62e76b97851b95e82e7e6b6e2fb6852535c411ec)
