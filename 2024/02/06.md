# 2024-02-06

## Security

- `idn_to_ascii()` now passes ICU the correct output-buffer capacity. Oversized malformed domains return `false` instead of overwriting the buffer terminator and crashing HHVM. [e5a0315b88](https://github.com/hershel-theodore-layton/hhvm/commit/e5a0315b8812ea1888d50040048b22bdd18eeb46)

## Breaking Changes

- Runtime parameter type hints on builtins are now enforced by default rather than treated as soft. Calls that relied on passing values of the wrong type to native functions may now fail instead of merely warning. [11164a1fce](https://github.com/hershel-theodore-layton/hhvm/commit/11164a1fced1272af6697fc67ba2beeee8af6362)

## Future Changes

- HHVM gains the runtime type-structure representation needed for recursive experimental case types such as `case type Node = int | shape('next' => Node)`. The typechecker does not support declaring them yet. [504c07dd96](https://github.com/hershel-theodore-layton/hhvm/commit/504c07dd961a0bbaa1529fff3541297389dff228)
