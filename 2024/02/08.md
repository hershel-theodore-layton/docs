# 2024-02-08

## Highlights

- Tier overrides now accept a `tagset` matcher containing multiple regular expressions. A machine matches only when its tags satisfy every expression in the set. [7e0dac1623](https://github.com/hershel-theodore-layton/hhvm/commit/7e0dac16238b75188141fa2916b420b5d1a9f63e)
- The HTTP compression layer now reads the documented `zstd.target_block_size` option; the previous typo caused configured values to be ignored. [81d33dc841](https://github.com/hershel-theodore-layton/hhvm/commit/81d33dc8410e2fa1c0118b967dfda3ef93383fe4)

## Future Changes

- HHBBC now preserves module provenance when a staged module-level trait composes an `internal` trait, so copied methods retain the correct runtime boundary checks after trait flattening. [73357ffc8d](https://github.com/hershel-theodore-layton/hhvm/commit/73357ffc8d5b9ea3ba5ad0f4e836238c496679e9)
- Dynamic-aware subtyping no longer takes an incomplete default path before decomposing a right-hand intersection in constraints of the form `T <: supportdyn<t>`. [4ebf2bc6f1](https://github.com/hershel-theodore-layton/hhvm/commit/4ebf2bc6f179a43183901f3655a9b09831d153f0)
