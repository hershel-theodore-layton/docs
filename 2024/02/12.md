# 2024-02-12

## Highlights

- Generic calls now type explicitly annotated lambda parameters before other arguments. This lets calls such as `any($values, (C $value) ==> ...)` infer `C` before applying like-pushing to a `vec<~C>` argument. [11c6d53343](https://github.com/hershel-theodore-layton/hhvm/commit/11c6d5334331a676dfef12204124cbdbdf89b2a6)
- Repository-authoritative deployments can now execute a configured prelude. A prelude path beginning `${SOURCE_ROOT}/` is resolved relative to the directory containing the applicable `.hhvmconfig.hdf`, and missing preludes produce an actionable log message. [45c319db7d](https://github.com/hershel-theodore-layton/hhvm/commit/45c319db7db5590a5fb6c1c1358b4b16090df101)
