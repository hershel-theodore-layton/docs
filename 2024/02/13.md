# 2024-02-13

## Highlights

- An explicit `hh_server --max-procs` value is now honored up to the machine's processor count rather than being halved a second time. Without an explicit limit, the server continues to default to half the reported logical processors. [dcfcc2cb9d](https://github.com/hershel-theodore-layton/hhvm/commit/dcfcc2cb9d5dc90b050e9b9b30fb362297efc623)

## Breaking Changes

- The IMAP extension has been removed, including functions such as `imap_open()`, `imap_fetchbody()`, and `imap_close()`. Applications still using these APIs need an external mail client or service. [ee0bc2cb00](https://github.com/hershel-theodore-layton/hhvm/commit/ee0bc2cb003a1a6c3b3379da7415852d540c03ba)

## Future Changes

- Sound Dynamic and implicit pessimisation now trust runtime enforcement declared by HHI signatures in the same way as ordinary Hack signatures, removing a legacy exception that affected property assignment. [0507e9f8ad](https://github.com/hershel-theodore-layton/hhvm/commit/0507e9f8ad07848bd4512dd064e3378d6fb75465)
