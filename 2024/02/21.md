# 2024-02-21

## Highlights

- The new “add `await`” action now preserves operator precedence and avoids unnecessary parentheses around the inserted expression. [d23fc11169](https://github.com/hershel-theodore-layton/hhvm/commit/d23fc11169d0d580243af3560c77d9e30c8e9d97) [17801ada76](https://github.com/hershel-theodore-layton/hhvm/commit/17801ada76ea01e6c48e66545d97feeefd98175c)
- The admin status response now includes machine-readable process uptime in seconds. Before the pagelet server starts, its start and uptime values are reported as `-1` rather than a date near the Unix epoch and a nonsensical duration. [0af897ce58](https://github.com/hershel-theodore-layton/hhvm/commit/0af897ce58ed27d47cf4142ea72998a52e6362d3)

## Future Changes

- In the ongoing module-level-traits rollout, public module-level traits may no longer declare `internal` methods. This reverses the short-lived staged allowance while support is redesigned; use an `internal` trait or make the method non-`internal`. [c641788a1a](https://github.com/hershel-theodore-layton/hhvm/commit/c641788a1aa38553b5831075308e42de90599c67)
