# 2024-02-27

## Highlights

- Method autocomplete now filters suggestions whose `where` constraints cannot be satisfied at the call site, instead of offering a completion that immediately produces a type error. [39a6567878](https://github.com/hershel-theodore-layton/hhvm/commit/39a6567878759e17af595ab17be9a7c0ec078944)
- Facts queries now treat method names as case-sensitive, matching Hack method lookup. Attribute queries no longer conflate methods whose names differ only by case. [fbc082a65c](https://github.com/hershel-theodore-layton/hhvm/commit/fbc082a65cc7ce165bb8f62852ab2971cba641e2)

## Future Changes

- The experimental package-existence expression now parses the reserved default package name, allowing checks such as `if (package default)`. [3042a0baa3](https://github.com/hershel-theodore-layton/hhvm/commit/3042a0baa34de0fcd122fb75ea7f264bb4830db9)
