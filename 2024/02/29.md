# 2024-02-29

## Breaking Changes

- `apc_clear_cache()` is no longer available to clear process-wide APC data from server requests: it now returns `false` without clearing the cache in server execution mode. CLI use remains available. [ca246caaa0](https://github.com/hershel-theodore-layton/hhvm/commit/ca246caaa08d42bc2d9cc1abb9c895f8592c24f9)

## Future Changes

- Attempting to nest an experimental expression tree inside a splice now produces a single targeted diagnostic that recommends assigning the inner tree to a local and splicing that variable. [9e9e317ab6](https://github.com/hershel-theodore-layton/hhvm/commit/9e9e317ab6249f50a346cbeb9c50c46478417706)
- Like-pushing through an invariant generic argument no longer special-cases a type-variable argument, removing one source of unsound or incomplete inference under implicit pessimisation. [c3eacf2b2d](https://github.com/hershel-theodore-layton/hhvm/commit/c3eacf2b2da88dc85273cd17729b70c4e92756d0)
