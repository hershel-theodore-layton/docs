# 2024-03-04

## Highlights

- Sound Dynamic method calls can now use like-pushing to satisfy `where` constraints. A receiver such as `ExpectObj<~vec<int>>` can call a method constrained with `T as Container<mixed>`, with the result correctly remaining like-typed. [e6dfdec1be](https://github.com/hershel-theodore-layton/hhvm/commit/e6dfdec1be92fa17748123b0eceeab3655f2fef2)
- The new pure `HH\FileDecls::genParsePath(string)[]: Awaitable<HH\FileDecls>` API supports non-blocking declaration parsing, including implementations backed by remote I/O-bound caches. [b041842c13](https://github.com/hershel-theodore-layton/hhvm/commit/b041842c13320d6d667cae85d1d6ff46d0d5a934)
- Type errors involving shapes reached through aliases now retain the alias definition position, so diagnostics such as error 4108 point to the declaration rather than a later hint. [7e07868621](https://github.com/hershel-theodore-layton/hhvm/commit/7e07868621eb657a6009a2d69d57b29fb0475f23)
- Image metadata detection gained AVIF and HEIC support through libheif, notably for `getimagesize()`. [80f15c3872](https://github.com/hershel-theodore-layton/hhvm/commit/80f15c38721f1839a34414cacb9e8e3e7d93a9b1)
