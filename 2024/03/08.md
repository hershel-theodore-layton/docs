# 2024-03-08

## Highlights

- The false branch of `if ($x)` no longer narrows `$x` to `null`: Hack now accounts for other falsy values such as `false` and the empty string, closing an unsound refinement. [afee63e475](https://github.com/hershel-theodore-layton/hhvm/commit/afee63e475d87af1d9b74d632ade801d5266c393)

## Breaking Changes

- `meth_caller()` no longer accepts a class name as a string. Pass a class value such as `C::class`; stringly typed call sites should use `dynamic_meth_caller()` instead. [159e7c7744](https://github.com/hershel-theodore-layton/hhvm/commit/159e7c77440712e5781a6043f249ce376f353791)
