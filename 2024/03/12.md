# 2024-03-12

## Highlights

- A promoted variadic constructor parameter now declares its property as `vec<T>` rather than `T` in both parser paths. For example, `private string ...$args` produces a `vec<string>` property and no longer causes errors in the lowered constructor body. [a9284326d6](https://github.com/hershel-theodore-layton/hhvm/commit/a9284326d6ab59f59a4d947cbca6ce3ba2b703bd)
- `ReflectionFile::getModule()[]: ?string` is now implemented, returning the module declared by the reflected file when it has one. [25639bc1f5](https://github.com/hershel-theodore-layton/hhvm/commit/25639bc1f5fe4997e79961b5855ba95386ca3124)
