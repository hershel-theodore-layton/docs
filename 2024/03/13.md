# 2024-03-13

## Highlights

- The “add missing method stubs” quickfix now inserts generated methods at the end of the class instead of the beginning. [ddfef7b4a5](https://github.com/hershel-theodore-layton/hhvm/commit/ddfef7b4a51c7b74c1a09c3b698cedde71a30399)
- The new pure `HH\Facts\files_and_attr_args_with_attribute(string)[]: vec<(string, ?string)>` query returns every matching file and file-attribute argument in one call. Files with multiple arguments appear multiple times; integer arguments retain the Facts API's existing behavior of coming back as strings. [bb3c74674d](https://github.com/hershel-theodore-layton/hhvm/commit/bb3c74674dfc6b5880be7f764128cf2de1131b10)

## Future Changes

- Under the ongoing `module_level_traits_extensions` feature, a public `<<__ModuleLevelTrait>>` may now declare `internal` methods. Internal properties remain restricted to internal traits.
