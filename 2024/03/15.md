# 2024-03-15

## Security

- The new off-by-default `Eval.DisableRequestSuperglobal` option prevents `$_REQUEST` from being created or populated, allowing deployments to avoid the superglobal's merged input surface. [d6931f096c](https://github.com/hershel-theodore-layton/hhvm/commit/d6931f096cb3ea5102301bcf2d33d7c85ce1a8a4)

## Breaking Changes

- The implicit class constant is now case-sensitive: only `C::class`, not spellings such as `C::CLASS`, receives the special class-name behavior. [07f75c18d1](https://github.com/hershel-theodore-layton/hhvm/commit/07f75c18d1b604338b17582bf712af231e83c8c3)
- The runtime surface of `meth_caller()` now takes a `classname` value directly, completing the move away from class-name strings. Use `C::class` for statically known classes and `dynamic_meth_caller()` for dynamic strings. [16424edb7c](https://github.com/hershel-theodore-layton/hhvm/commit/16424edb7c135397dff8ea9100402bccbcf16014)
