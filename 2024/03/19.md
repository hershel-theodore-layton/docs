# 2024-03-19

## Highlights

- Autocomplete now recognizes namespace constant declarations, restoring completions at declaration sites inside namespaces. [62ec1f5201](https://github.com/hershel-theodore-layton/hhvm/commit/62ec1f520156ee20d5b0b65ccb7b404ed3ae2fe3)
- Type tests of the form `if ($x is bool)` now use constraint-based partitioning, improving true- and false-branch refinements for unions, intersections, and bounded abstract types. [769012223d](https://github.com/hershel-theodore-layton/hhvm/commit/769012223d9cec6d38e1cf6499a7f4c75461ee97) [26fb5051ac](https://github.com/hershel-theodore-layton/hhvm/commit/26fb5051ac2a7a1bf53481adab4abb757ba9595b) [51ae0e53ef](https://github.com/hershel-theodore-layton/hhvm/commit/51ae0e53ef0f99ce7108f6598fc4ef404b90c4b2)
