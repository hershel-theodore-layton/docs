# 2024-03-20

## Highlights

- Hack's VS Code diagnostics can now render secondary quickfix locations as dotted gray underlines, and the same quickfix is available when the caret is on one of those hinted locations. ## Breaking Changes

- Module existence checks now consistently use the pure `HH\module_exists(string, bool = true)[]: bool` API. The previous global `module_exists()` runtime spelling has been removed. [f397bd3c97](https://github.com/hershel-theodore-layton/hhvm/commit/f397bd3c97e9bfddc5e744fa46e464e455389664)

## Future Changes

- Preview readonly checking now produces type errors for unary increment and decrement, matching its existing checks for compound assignments such as `+=`. [d323321cd0](https://github.com/hershel-theodore-layton/hhvm/commit/d323321cd00421b345081b21741b316f5b3defbb)
