# 2024-03-21

## Future Changes

- Under the preview readonly feature, `meth_caller()` now produces a readonly function value because it captures no mutable state. A readonly target method also gives the generated callable a readonly receiver parameter, e.g. `(readonly function(readonly C, int): bool)`.
