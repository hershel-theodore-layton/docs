# 2024-03-26

## Highlights

- `this` is now considered fully runtime-enforced when it appears in a final, non-generic class, allowing Hack to reason more precisely about those type hints. [ccc7a97603](https://github.com/hershel-theodore-layton/hhvm/commit/ccc7a9760393de6dc8ec25f4840e457a7d7b714b)
- Immediately invoked lambdas with syntactically constant arguments no longer invalidate fake-member refinements. This supports expression-oriented patterns such as async blocks and expression-tree runtime expressions without unnecessary rechecks. [d768a63db0](https://github.com/hershel-theodore-layton/hhvm/commit/d768a63db0692658fac7d20f33d103f21c8165f2)
