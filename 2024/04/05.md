# 2024-04-05

## Highlights

- Lambda arity mismatches now produce TAST holes around the incompatible function value or lambda. Tools that consume typed ASTs can use the expected and actual function types to offer more precise migrations. [7eccda3526](https://github.com/hershel-theodore-layton/hhvm/commit/7eccda35266e8366223ca6a6542922c9896e7e3f)
- `HH\get_executable_lines()` no longer reports generated functions or abstract methods as executable. Coverage and debugger clients will no longer see interface methods or class-closing braces as spurious executable lines. [17236d2daf](https://github.com/hershel-theodore-layton/hhvm/commit/17236d2dafbd5190801d0669639917861e80d8a6)
- Constraint solving now retains the errors from all branches of a disjunction, improving explanations when no branch is valid—particularly for failures involving type-parameter constraints. [85d958bb73](https://github.com/hershel-theodore-layton/hhvm/commit/85d958bb73f17a1dd4e6deada52b1d45efbc8d7f)

## Future Changes

- Expression-tree collection literals moved from Preview to OngoingRelease as part of their staged rollout. Expression trees themselves remain experimental. [eda3f8b79c](https://github.com/hershel-theodore-layton/hhvm/commit/eda3f8b79c8c2c8c1fef839e66c643e7a7aef93a)
