# 2024-04-08

## Highlights

- `debugger_dump(null)` is now a no-op instead of printing `null`. This also keeps null-valued notebook and debugger evaluations from producing a redundant display value. [ced9997e21](https://github.com/hershel-theodore-layton/hhvm/commit/ced9997e2122868488958e80ddb8cf5eb31113ea)
- HHVM now agrees with the typechecker when a variadic method implements a variadic abstract method while declaring additional compatible non-variadic parameters. These implementations no longer fail at class loading. [743fc08410](https://github.com/hershel-theodore-layton/hhvm/commit/743fc08410e6225991de7081c0549d8a0402781b)
- Repo-authoritative builds now stop on directory-open or file-stat errors instead of silently omitting affected Hack files from the compiled repository. [915842a0ce](https://github.com/hershel-theodore-layton/hhvm/commit/915842a0ce3368d07e6b5d9e9ae7512df669c786)
