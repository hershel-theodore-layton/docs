# 2024-04-10

## Highlights

- The typechecker now uses obvious argument types—such as locals and simple literals—to infer the parameter types of an immediately invoked lambda. This accepts more concise calls without requiring redundant lambda annotations. [725364297d](https://github.com/hershel-theodore-layton/hhvm/commit/725364297de7189d406f1fca3f00ac373aa3fdd9)
- `nameof` is now supported as an attribute argument by both the typechecker and runtime, completing the parser-side work from April 2. [5db8d278e2](https://github.com/hershel-theodore-layton/hhvm/commit/5db8d278e2db323d4dabb7bda77d7e8aff24ac29)
