# 2024-04-16

## Highlights

- `hackfmt` now builds its line table tail-recursively, avoiding a stack overflow on unusually large source files. [88edd0b8ac](https://github.com/hershel-theodore-layton/hhvm/commit/88edd0b8ac64966cdf4b8e176ea3edeb896a906b)
- `hackfmt` now keeps an empty module definition on one line as `new module foo {}`, matching other empty braced declarations. [0fff1574c6](https://github.com/hershel-theodore-layton/hhvm/commit/0fff1574c614c6aab48df4d82115ad4d1315b926)

## Breaking Changes

- Inside a module declaration, an `imports` block must now appear before an `exports` block. Reorder declarations that currently export first; the restriction prevents range-formatting from losing the original token order. [2f432af79a](https://github.com/hershel-theodore-layton/hhvm/commit/2f432af79a3cebd47e88128630b709c136debfd7)

## Future Changes

- Repo-authoritative optimization no longer asserts when a case-type union contains an unresolved member. The whole union is conservatively left unresolved, matching non-repo HHVM behavior; case types remain a staged feature. [e01cd5e15a](https://github.com/hershel-theodore-layton/hhvm/commit/e01cd5e15ab5038e8851be5ad45dc74f7313897d)
