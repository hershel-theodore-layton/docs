# 2024-04-18

## Breaking Changes

- `AsyncMysqlErrorResult::mysql_normalize_error()` has been removed from the HHI and runtime extension. Migrate callers to the remaining error information, such as `mysql_error()`, `mysql_errno()`, or `failureType()`, as appropriate. [5a9a946d2d](https://github.com/hershel-theodore-layton/hhvm/commit/5a9a946d2dbf47ac574773105788fcf37eda1402)

## Future Changes

- Experimental expression-tree splices are now typechecked in the same lowered lambda shape used by code generation. An `as` refinement performed inside a splice no longer survives after the enclosing expression tree, and values used by splices are treated as captured variables and may be pessimised. [de35277bac](https://github.com/hershel-theodore-layton/hhvm/commit/de35277bac84639b91589ff017749499e65a6696)
