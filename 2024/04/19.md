# 2024-04-19

## Highlights

- IDE rename now handles the `$` prefix correctly for both static properties and the differing declaration/use spellings of instance properties. [fb8c9ac5b1](https://github.com/hershel-theodore-layton/hhvm/commit/fb8c9ac5b1e3675f03df36206ad6f60872443078)
- Repo-authoritative compilation accepts `--vActiveDeployment=...`, allowing a build invocation to set or override the active package deployment without editing `build_config.hdf`. [1dcd3f2216](https://github.com/hershel-theodore-layton/hhvm/commit/1dcd3f2216f340ba886d0cb55f7e56dabff2f891)

## Breaking Changes

- Accessing a private static member through an object expression, such as `$object::method()`, is now accepted only from that same class when it is `final`. Cross-class access that previously slipped through now reports that private members cannot be accessed dynamically; prefer `self::method()` for same-class calls. [c17d4a0221](https://github.com/hershel-theodore-layton/hhvm/commit/c17d4a02210a8e3ab2a82bdbae248b28f154c6c9)
- `DOMDocument::registerNodeClass()` class mappings are now case-sensitive. The base-class spelling used during registration must exactly match the class name encountered when DOM objects are created. [ecaf3474e9](https://github.com/hershel-theodore-layton/hhvm/commit/ecaf3474e95d600a6f503cad86b51f3dbc574556)
