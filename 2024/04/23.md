# 2024-04-23

## Highlights

- `round()` now handles precision values outside the meaningful range for a `double` directly: extremely high precision returns the input unchanged, while sufficiently low precision returns zero, avoiding invalid intermediate calculations. [a6c87cb4c8](https://github.com/hershel-theodore-layton/hhvm/commit/a6c87cb4c80ca797b57f0a81d5ea3747fb8b8703)

## Future Changes

- Collection literals inside opted-in expression trees no longer require the separate `expression_tree_map` unstable-feature attribute. The enclosing expression-tree feature remains staged. [c13997fb6d](https://github.com/hershel-theodore-layton/hhvm/commit/c13997fb6df974563076ece6165d36fdb1777f9c)
