# 2024-04-24

## Highlights

- TAST holes produced for invalid array access now retain the original outer type of a nullable or `mixed` base instead of incorrectly reporting its non-null inner type. Typed-AST consumers and codemods will see accurate actual types. [be9a7af8b3](https://github.com/hershel-theodore-layton/hhvm/commit/be9a7af8b39e43a8cd7fad015a6e870ffca28e28)

## Future Changes

- The unstable `expression_tree_nest` feature allows an expression tree inside a splice. A nested tree inherits the enclosing DSL and therefore omits its own DSL prefix, except across an ordinary Hack lambda scope; nested trees cannot yet capture client variables from enclosing scopes. [8fd5211674](https://github.com/hershel-theodore-layton/hhvm/commit/8fd5211674693c38f8ed9115540d5e86d3221d55)
