# 2024-04-26

## Highlights

- JSON diagnostics now include a top-level `severity` field. Consumers of `hh --json` can distinguish errors from the new warning severity without parsing rendered text. [e19bd61dd0](https://github.com/hershel-theodore-layton/hhvm/commit/e19bd61dd072a4fa61629e506d7b24a1be8da992)
- While VS Code debugging is paused, newly started request threads are no longer announced until execution resumes, keeping the stopped thread from being displaced in the debugger UI. [e2849902e6](https://github.com/hershel-theodore-layton/hhvm/commit/e2849902e633029455b8a8c21cd0e7b6d73b463b)
- The “override method” code action now inserts a multiline method body and places the cursor inside it, ready for implementation. [4f550b7331](https://github.com/hershel-theodore-layton/hhvm/commit/4f550b7331beee367b0d2595158ebcaa758ee85c) [2298871f36](https://github.com/hershel-theodore-layton/hhvm/commit/2298871f365527c63d356f9353a2297a8a4d164d)

## Future Changes

- When the opt-in Hack warning system is enabled, LSP diagnostics now reach editors with warning severity and are rendered as warnings rather than errors. [43370c7b5f](https://github.com/hershel-theodore-layton/hhvm/commit/43370c7b5f3d09dce0d20de0808100ca2cc27009)
