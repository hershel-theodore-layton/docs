# 2024-05-09

## Highlights

- Relative-path variants are now available for every Facts symbol-to-path query: modules, types, type aliases, functions, constants, and the combined type-or-alias lookup. The existing absolute-path APIs remain available during migration. [7f90612b91](https://github.com/hershel-theodore-layton/hhvm/commit/7f90612b91bed4f5c57e4b4f2d7c4e143ef87229)

## Future Changes

- Nested expression trees have moved from unstable to preview status. They remain pre-stable and continue to require the `expression_tree_nest` feature where preview features are not enabled. [0d9f8f88ad](https://github.com/hershel-theodore-layton/hhvm/commit/0d9f8f88addad37e44539c49c6d6bea5fb4c0af7)
