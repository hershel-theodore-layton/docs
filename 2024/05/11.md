# 2024-05-11

## Breaking Changes

- `HH\ImplicitContext\soft_run_with()` and `soft_run_with_async()` no longer create a soft implicit-context state from their `$key`; they now invoke the callback without changing context. Code that depended on the key creating separate memoization context should migrate to an explicit implicit-context API. [9461b78f48](https://github.com/hershel-theodore-layton/hhvm/commit/9461b78f481c4b09d1dd97572131cb130f09c791)

## Future Changes

- In the staged module-level trait work, public module-level traits may declare `internal` methods without separately enabling `module_level_traits_extensions`. Internal properties on public traits remain invalid. [2b00d0ec8b](https://github.com/hershel-theodore-layton/hhvm/commit/2b00d0ec8be75a013510fbaa15985600f3eed33d)
