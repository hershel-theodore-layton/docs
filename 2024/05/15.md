# 2024-05-15

## Highlights

- The built-in constants `TRUE`, `true`, `FALSE`, `false`, `NULL`, and `null` are now declared in HHI files, so attempts to redefine them receive a naming error instead of surviving until HHVM's runtime fatal. [47c1ae0958](https://github.com/hershel-theodore-layton/hhvm/commit/47c1ae0958a5bc8cfff73936367e3b2068ee2ab3)

## Breaking Changes

- `__clone()` must declare a `void` return type. Returned values were always discarded; implementations that returned `this` or another value must remove the return value and keep mutation in the method body. [50376266b5](https://github.com/hershel-theodore-layton/hhvm/commit/50376266b51002aaa4334be18196d63464f21d59)
