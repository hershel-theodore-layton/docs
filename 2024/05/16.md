# 2024-05-16

## Breaking Changes

- `hh_single_type_check` now enables `everything_sdt` by default and has removed the `--everything-sdt` flag. Tests that need the legacy mode should pass `--config everything_sdt=false`. [50f7db53c0](https://github.com/hershel-theodore-layton/hhvm/commit/50f7db53c0260685ee25dec211f97d71027ebf49)
- Comparison typechecking now constrains both operands even when one begins as an unresolved type variable. Unconstrained generic or nullable comparisons that could resolve outside `int`, `string`, `DateTime`, or `DateTimeImmutable` may now report errors. [d45b3df95f](https://github.com/hershel-theodore-layton/hhvm/commit/d45b3df95f8e908b412e3269d970f7865a2b6d0f)

## Future Changes

- Package-v2 groundwork adds the `package_v2` option, parsing for path-based `include_paths`, and an unstable `<<file:__PackageOverride(...)>>` attribute. The override is syntax-only at this stage; enforcement work follows later.
