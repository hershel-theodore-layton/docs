# 2024-05-20

## Highlights

- Class-pointer migration diagnostics now cover returning `C::class` from a `string` function and assigning it to a `string` property. Use a class-name type or convert explicitly with `HH\class_to_classname()`. [a910b45d23](https://github.com/hershel-theodore-layton/hhvm/commit/a910b45d233c8e108ea0c3f8f4ab5651d433194d)

## Breaking Changes

- Namespace names in `use` declarations may no longer contain `:`. XHP-style names are not valid namespaces and now produce a parser error. [092c46226a](https://github.com/hershel-theodore-layton/hhvm/commit/092c46226a15a94aad7e961b9f9c58f4a423651d)
