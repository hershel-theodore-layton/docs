# 2024-05-23

## Highlights

- The VS Code debugger now displays string variables and string constants in single quotes, making them visually distinct from names and non-string scalar values. [d60b329ad4](https://github.com/hershel-theodore-layton/hhvm/commit/d60b329ad47356709c17dcf20b6fe7c77859d8d2)

## Breaking Changes

- Namespace names and aliases in `use` declarations may no longer contain XHP-style `:` or `-` characters. This completes the namespace validation introduced on May 20. [15efb0012e](https://github.com/hershel-theodore-layton/hhvm/commit/15efb0012e3ec0dcb519a22cd8171bf1ae80e9eb)

## Future Changes

- Every nested expression tree must now repeat its DSL name, and that name must match the enclosing tree. The earlier shorthand that inherited the outer DSL is rejected. [c610bf057f](https://github.com/hershel-theodore-layton/hhvm/commit/c610bf057f0520d54e9c7fccb9a3da41864c2fef)
