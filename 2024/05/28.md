# 2024-05-28

## Highlights

- A new lint warns when code catches a broad exception and neither rethrows nor meaningfully uses the exception object, helping surface silently swallowed failures. Additional type-lie checks for `HH_FIXME`, `UNSAFE_CAST`, assertions, and explicit `dynamic` were added at disabled severity for later rollout. [0184f96d16](https://github.com/hershel-theodore-layton/hhvm/commit/0184f96d16f8abb6374042ddb276a49cdc04397c) [22b0ea2599](https://github.com/hershel-theodore-layton/hhvm/commit/22b0ea2599e50e0e87af1c09bbfa235566f8a6e6)

## Future Changes

- With experimental `package_v2` enabled, the typechecker now maps files to the most specific matching `include_paths` entry and enforces path-based package access for public symbols. Internal-symbol enforcement and `__PackageOverride` support are not included yet. [6cfa1c710a](https://github.com/hershel-theodore-layton/hhvm/commit/6cfa1c710acaa797ffb88d179eff073782666c8d) [e837faa0c8](https://github.com/hershel-theodore-layton/hhvm/commit/e837faa0c842d274ecd2de43706051f2fe90cae5)
- The experimental `sealed_methods` feature allows `<<__Sealed(C1::class, ...)>>` on a method to restrict which classes may override it. Functions cannot use the attribute. [7e28a90a65](https://github.com/hershel-theodore-layton/hhvm/commit/7e28a90a65af8b539ca356e27285e833a2e19ceb)
