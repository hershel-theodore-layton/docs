# 2024-06-03

## Breaking Changes

- Hack now rejects calls to protected methods through an interface-typed receiver. The concrete implementing class might be outside the caller's class hierarchy, making the apparently valid call fail at runtime. [7b9882a0ae](https://github.com/hershel-theodore-layton/hhvm/commit/7b9882a0aef1aec5af80092610b22c88821a09f4)

## Future Changes

- Preview case types now handle nullable unions and bottom cases such as empty or null-only unions without crashing during runtime type-constraint canonicalization.
