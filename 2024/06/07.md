# 2024-06-07

## Highlights

- The redundant-generics linter once again recognizes a generic used only contravariantly when multiple `as` bounds simplify to one effective bound, including bounds introduced by implicit pessimisation. [1ca353c4cb](https://github.com/hershel-theodore-layton/hhvm/commit/1ca353c4cb3ddf5881529a1a48990c65a7c0d0c9)
- Shape refinement no longer causes `Shapes::idx()` on a different optional field to lose its nullable result type after patterns such as `$shape ?? shape()` and `Shapes::keyExists()`. [6254e75cb8](https://github.com/hershel-theodore-layton/hhvm/commit/6254e75cb855abcd967f7ffd9030a17009edeb92)
- The new `HH\Facts\validate(vec<string> $types_to_ignore = vec[])[defaults]: void` API checks the SQLite Facts database for types mapped to multiple paths and throws `UnexpectedValueException` when it finds an unignored conflict. [153ec68b9d](https://github.com/hershel-theodore-layton/hhvm/commit/153ec68b9d26b8bee329bf7d55d4b64d335656fe)
- Hack declarations now expose the pure async CAS helpers `HH\RemoteExecution\gen_upload_file(string, string)[]: Awaitable<string>` and `gen_download_file(string, string, string)[]: Awaitable<bool>`. [0c2cb6acbb](https://github.com/hershel-theodore-layton/hhvm/commit/0c2cb6acbb1cfc0df2dc009f069322cec4058516)

## Breaking Changes

- Hack's invalid-index check now diagnoses non-`int` access to `vec`, including cases hidden behind inferred generic keys. [6a242bdb0d](https://github.com/hershel-theodore-layton/hhvm/commit/6a242bdb0d9feb9e715e7f3fa5f22286b9e567c2)

## Future Changes

- Unstable expression trees now permit `await` inside splices when the tree is constructed in an async function. [3c259b10ef](https://github.com/hershel-theodore-layton/hhvm/commit/3c259b10ef347a47eb74de9fb1ae45c7b939210d)
