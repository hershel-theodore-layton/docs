# 2024-06-12

## Highlights

- `debug_backtrace()[defaults]` now returns `HH\StackTrace`, a `vec` of open `HH\StackFrame` shapes whose fields are explicitly optional. This makes code account for fields such as `'args'`, `'file'`, and `'function'` being absent. [df840cc4bc](https://github.com/hershel-theodore-layton/hhvm/commit/df840cc4bcc7ea91069037857299da1b04195579)
- In repo-authoritative mode, equality and conditional branching now agree when comparing lazy class values with class pointers. A true `$lazy_class === $class_pointer` comparison can no longer be optimized into an unreachable branch. [9884cdfbf2](https://github.com/hershel-theodore-layton/hhvm/commit/9884cdfbf29092d56d5717fbd55258a5e496117b)

## Security

- Public classes and interfaces may no longer extend internal types. This restores a firm module boundary and prevents public APIs from exposing a base type that callers outside the module cannot name. [f971a6634f](https://github.com/hershel-theodore-layton/hhvm/commit/f971a6634fa5375dc0a03ef6046fc63326e9ccf2)
