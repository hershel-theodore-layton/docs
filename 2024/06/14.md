# 2024-06-14

## Highlights

- JIT-compiled `is_a()` and `is_subclass_of()` now honor the `$allow_string` argument and reject trait targets, matching interpreter behavior for class pointers. [c3c428aa95](https://github.com/hershel-theodore-layton/hhvm/commit/c3c428aa95c0244dc1865910fc817a2fa5e09e01)

## Future Changes

- With Packages v2 enabled, `<<file: __PackageOverride('name')>>` no longer needs an `__EnableUnstableFeatures` declaration. The attribute lets a file opt into the named package for access checking. [ff5b55092b](https://github.com/hershel-theodore-layton/hhvm/commit/ff5b55092bf1bee50dbf854290dbf23e53e9c431)
