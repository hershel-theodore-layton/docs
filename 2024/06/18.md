# 2024-06-18

## Breaking Changes

- The obsolete `HH\class_get_class_name()` helper has been removed; use the pure `HH\class_to_classname()` migration helper instead. The internal `__hhvm_intrinsics\create_class_pointer()` spelling was likewise replaced by `HH\classname_to_class()`. [172eb8c361](https://github.com/hershel-theodore-layton/hhvm/commit/172eb8c361dbd3685815bd48bcac5130e9e4767b)

## Future Changes

- Awaiting multiple splices in an expression tree no longer serializes them into sequential assignments; independent splice expressions can now run concurrently. [500e484925](https://github.com/hershel-theodore-layton/hhvm/commit/500e484925714c6c89a8707918fb7cbcc86ef4f6)
