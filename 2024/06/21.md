# 2024-06-21

## Future Changes

- Class-pointer migration checks now cover class and enum-class constant initializers, warning that `C::class` assigned to a `string` constant performs an implicit conversion and recommending `nameof C`. This is controlled by the `const` entry in `class_pointer_levels`. [738d9706a7](https://github.com/hershel-theodore-layton/hhvm/commit/738d9706a74851ba602d01f67402cff4a65c649b)
- Packages v2 now bypasses package-boundary checks for `::class` expressions by default, preserving their transitional string-like use while class-pointer migrations continue. [0fa07a7548](https://github.com/hershel-theodore-layton/hhvm/commit/0fa07a7548da8d2d64ef46f5e359fe71de93f042)
