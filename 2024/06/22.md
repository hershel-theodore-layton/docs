# 2024-06-22

## Future Changes

- The Packages v2 test-file exemption now recognizes `__tests__` anywhere in a path, so test files receive the intended ability to call across package boundaries instead of only matching when the marker begins the full path. [339e8b72ac](https://github.com/hershel-theodore-layton/hhvm/commit/339e8b72ac65dc208882e3550c065c43f24906d8)
- Package overrides now propagate through class kinding, preventing class references from silently falling back to the package inferred from their source path. [4bb06d9a64](https://github.com/hershel-theodore-layton/hhvm/commit/4bb06d9a646490ffc179fbb097e12b13d724f669)
