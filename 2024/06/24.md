# 2024-06-24

## Highlights

- The value type parameter of `HH\EnumClass\Label<-TEnumClass, +TType>` is now covariant rather than invariant, allowing a label's value type to widen safely. [49c68bd4be](https://github.com/hershel-theodore-layton/hhvm/commit/49c68bd4beb8611686e09002e910cd9dd56750b9)

## Future Changes

- Await expressions in expression-tree splices have moved from Unstable to Preview. Multiple awaited splices retain the concurrent execution introduced earlier this month. [a3bf39c601](https://github.com/hershel-theodore-layton/hhvm/commit/a3bf39c601144ec9c5eed5ad6c85ffcbfc636db4)
- Packages v2 now ignores package boundaries while resolving generic type arguments, completing the relaxation for type-only references while retaining checks on value-level symbols. [cc000535ac](https://github.com/hershel-theodore-layton/hhvm/commit/cc000535ac3ebec1450f82bac13cae83df4208f1)
