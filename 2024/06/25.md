# 2024-06-25

## Highlights

- Enum-class labels now use constraint-based typing. Anonymous labels such as `#Name` have their own inferred type and can be used beyond immediate function-argument position, while qualified labels are checked against the enum class's actual constant type. [0bc5384fa2](https://github.com/hershel-theodore-layton/hhvm/commit/0bc5384fa2a2738b5af709901d5a1f3fe31f7006)
- JIT deployment-boundary checks now match the interpreter when the caller is itself outside the active deployment, avoiding a spurious violation on calls from that code. [e8f6d775da](https://github.com/hershel-theodore-layton/hhvm/commit/e8f6d775daeb1a3fb744fd3ab9f9724a7dc55f3d)

## Breaking Changes

- A generic used contravariantly inside `HH\EnumClass\Label` is now an error when covariance leaves it underconstrained. Replace the redundant parameter with its effective bound or redesign the signature so the label actually determines it. [5832019e44](https://github.com/hershel-theodore-layton/hhvm/commit/5832019e44a105c291c3d37f371303b5a2038483)
