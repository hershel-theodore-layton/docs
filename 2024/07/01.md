# 2024-07-01

## Highlights

- `HH\FileDecls::getShapeKeys()` now returns the keys of a shape type alias without recursively expanding nested aliases. Class-constant keys retain their `Class::CONSTANT` spelling. The pure `[]` API is useful to source-analysis tools that need the declaration's written shape rather than a normalized type.
