# 2024-07-03

## Highlights

- Autocomplete now correctly applies `where` constraints when a function type's return type has been pessimised to a like type. This restores valid suggestions whose availability depends on the callback return type. [3ba7478771](https://github.com/hershel-theodore-layton/hhvm/commit/3ba747877180afa6c34440c6eb250769e1564aa1)

## Breaking Changes

- Enum-class labels may no longer refer to type constants. Expressions such as `E#T` or `#T` now produce a type error when `T` is a type constant rather than an enum-class member. [3c9a2a4a23](https://github.com/hershel-theodore-layton/hhvm/commit/3c9a2a4a23cd1f3f084966b985139a7e938cb1c7)
- `HH\ImplicitContext` gained an abstract boolean constant named `IS_MEMO_SENSITIVE`. Subclasses must choose `true` for memo-sensitive contexts or `false` for memo-agnostic contexts. This systemlib change precedes the matching HHI declaration added later in the month. [9fbef64f53](https://github.com/hershel-theodore-layton/hhvm/commit/9fbef64f53f9d8b3f7e55ea9de0e3e2341ceb07d)
