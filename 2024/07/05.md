# 2024-07-05

## Breaking Changes

- `HH\FileDecls` now preserves the exact source spelling of string values, including quote style and escapes, instead of normalizing them to single-quoted strings. Source-analysis tools that compare or parse the former normalized output need to accept raw snippets. [a3e0167a71](https://github.com/hershel-theodore-layton/hhvm/commit/a3e0167a71c38c928386505bd29b1d40eac339b1)

## Future Changes

- Identify-symbol and go-to-definition now resolve enum-class labels through dependent, nullable, and pre-stable case types. [929a95c5b8](https://github.com/hershel-theodore-layton/hhvm/commit/929a95c5b81a23fa0319c29cb9cad8d65a68bbbb)
