# 2024-07-09

## Future Changes

- The opt-in warning formerly reported as code 12002 is now divided into 12009 (`is` always true), 12010 (`is` always false), 12011 (`as` always succeeds), and 12012 (`as` always fails). Projects that enable these warnings should update warning-code suppressions and tooling. [d6e5153e6c](https://github.com/hershel-theodore-layton/hhvm/commit/d6e5153e6c6524413c73a0f88786a451a7f87367)
