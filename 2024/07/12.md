# 2024-07-12

## Breaking Changes

- `HH\ImplicitContext` gained an abstract context constant, `CRun`. Its base `runWith()`, `runWithAsync()`, `get()`, and `exists()` methods now require `[this::CRun]` instead of a fixed `[zoned]` capability, and subclasses must choose a concrete requirement such as `const ctx CRun = [zoned]`. This annotation does not grant the listed capability: it is a requirement on the callee, so a caller must have a capability set that contains the subclass's chosen `CRun`. Both `runWith()` and `runWithAsync()` additionally require the callback's context through `ctx $f`. Choosing a narrower `CRun` relaxes the requirement on callers. The matching HHI declaration follows later in the month. [d36ec6e832](https://github.com/hershel-theodore-layton/hhvm/commit/d36ec6e83214ebb7f42d6f841dec7001d4017cba)
