# 2024-07-15

## Highlights

- Calls with explicit or empty type arguments now associate correctly inside subtraction expressions. For example, `10 - f<int>(1) - 1` is evaluated left-to-right instead of being misparsed into an expression that evaluates to 10. [7d30230a5b](https://github.com/hershel-theodore-layton/hhvm/commit/7d30230a5b2b4f492d2e110d0a97505efac7819a)

## Future Changes

- Package v2 now enforces package access for reified generic arguments to functions and classes. Erased generic arguments remain exempt because their types do not survive at runtime. [92ed59910e](https://github.com/hershel-theodore-layton/hhvm/commit/92ed59910e0b966bd942b72429bcb0008160d540)
