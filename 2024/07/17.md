# 2024-07-17

## Highlights

- Standard collection declarations now annotate `contains()`, `containsKey()`, and `linearSearch()` with `__Overlapping`. `hh --lint` can consequently report calls whose inferred argument and element/key types are disjoint and whose result is always the same. [ac1433f124](https://github.com/hershel-theodore-layton/hhvm/commit/ac1433f124917f312a63b23d89ebb22d7866852c)
- Find-references output from the default parser now uses source XHP spelling such as `:xhp:foo-element` instead of the internal mangled spelling `xhp\foo-element`. [c6db057c8e](https://github.com/hershel-theodore-layton/hhvm/commit/c6db057c8eef2855552e94791696869e8cde4364)

## Future Changes

- Opt-in extended type-error explanations can now describe nullable-type decomposition and point to the declarations of classes, type aliases, and newtypes involved in an error. [b4eefe87a3](https://github.com/hershel-theodore-layton/hhvm/commit/b4eefe87a3231ceb7b24b1e2be2e2f58be07e1f9) [bad36007e0](https://github.com/hershel-theodore-layton/hhvm/commit/bad36007e003126837f385e2204e6f8c5bf0bcb0)
