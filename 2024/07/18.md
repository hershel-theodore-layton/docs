# 2024-07-18

## Future Changes

- With `.hhconfig` option `enable_abstract_method_optional_parameters=true`, interface and abstract-method declarations may mark a parameter `optional` without supplying a default. Implementations must provide a default value; `optional` is rejected on concrete methods and on `inout` or variadic parameters. Reflection reports these parameters as optional. [64be82990a](https://github.com/hershel-theodore-layton/hhvm/commit/64be82990adf07a0f85b1c6a0b38c560fdccc3b9)
- Runtime optimization of experimental case types no longer crashes when resolving an alias that combines an enum with another member type. [9971c4deb3](https://github.com/hershel-theodore-layton/hhvm/commit/9971c4deb31d46de8a6cbbfe28522e8486c87391)
