# 2024-07-19

## Highlights

- `hackfmt --linttool` now emits JSON lint replacements for files named on the command line or supplied through an `@pathsfile`. `--linttool-severity` controls the emitted severity. [54fd999ce3](https://github.com/hershel-theodore-layton/hhvm/commit/54fd999ce3275d1dd9d513d0b1f4393926d89504) [8fdcb93335](https://github.com/hershel-theodore-layton/hhvm/commit/8fdcb93335591ff5692189f06c5a876f78fdac82)

## Future Changes

- Package v2 no longer reports package-access errors for type references nested inside shapes, `vec`, `dict`, or function types, nor for attributes, interfaces, HHIs, and same-file references that do not require a runtime package check. [319dcfe9a3](https://github.com/hershel-theodore-layton/hhvm/commit/319dcfe9a31433a877d5d80b2f6f1b0009910ee1) [5011d0f10d](https://github.com/hershel-theodore-layton/hhvm/commit/5011d0f10de75371ba58aea5ad22b698cccc13db)
- The configuration switch for experimental class-level `where` clauses has been removed. The syntax itself is removed a few days later; projects experimenting with it should migrate toward type refinements. [361365bd93](https://github.com/hershel-theodore-layton/hhvm/commit/361365bd932b6d8361ba8ce69bde349fd58351eb)
