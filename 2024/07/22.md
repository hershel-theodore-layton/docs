# 2024-07-22

## Breaking Changes

- `ConstIndexAccess` and `IndexAccess` now constrain their key type parameter with `as arraykey`; collection `contains()` and `containsKey()` declarations received the same constraint. Custom implementations and calls that explicitly supplied an unconstrained, non-`arraykey` type argument may now fail type checking. [716478479e](https://github.com/hershel-theodore-layton/hhvm/commit/716478479edbfee4697f8cfb96ce85bc56d2a6e8)

## Future Changes

- Experimental class-level `where` clauses have been removed from the language. They were never enabled as a supported feature; use type refinements for constraints on associated types. [46632da404](https://github.com/hershel-theodore-layton/hhvm/commit/46632da40466238ca686c0b66b05d47a17621b56)
