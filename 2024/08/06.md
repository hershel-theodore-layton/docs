# 2024-08-06

## Future Changes

- The redundant-generics check no longer reports valid generics used in pre-stable `as` or `super` type-constant refinements because of an incomplete variance calculation. [b960631c28](https://github.com/hershel-theodore-layton/hhvm/commit/b960631c280bf4d1973114ace0dcc6215546c5a6)
- Conditional-splice detection now looks through client-language expression-tree lambdas instead of treating them like ordinary Hack lambdas, closing a path that still admitted conditionally executed awaits. [803f1ee2f9](https://github.com/hershel-theodore-layton/hhvm/commit/803f1ee2f937f8ca8581994410de4a701d24d3be)
- Preview case types now preserve the current enum context separately for each queued alias while HHBBC flattens nested unions, preventing unrelated class arms from being mistaken for enum members. [63b1647cae](https://github.com/hershel-theodore-layton/hhvm/commit/63b1647cae27a29201b5d6da7dfff8c7416ac43a)
