# 2024-08-07

## Breaking Changes

- The unused `hh --format` command has been removed. Use `hackfmt` or editor formatting instead. [bf408a3876](https://github.com/hershel-theodore-layton/hhvm/commit/bf408a3876f2024faef70b08e462c91f93e02330)
- The deprecated `call_user_func()` pseudofunction is no longer declared or specially lowered by Hack. Invoke a typed callable directly. [e37946a1b1](https://github.com/hershel-theodore-layton/hhvm/commit/e37946a1b108982441ac03c174c1d7ac4a167c35)
- `HH\is_vec_or_varray()` and `HH\is_dict_or_darray()` have been removed from Hack's declarations and refinement logic. Use `is vec<_>` and `is dict<_, _>` checks. [20333fb1c7](https://github.com/hershel-theodore-layton/hhvm/commit/20333fb1c7123d5eb15c14ecacb8f634af4ac752)
