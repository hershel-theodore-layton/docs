# 2024-08-08

## Highlights

- `hh_client` can now filter warnings with `-Wall`, `-Wnone`, `-W CODE`, `-Wno CODE`, and `-Wignore-files REGEXP`. Unknown warning codes are rejected instead of silently ignored. [5304af98f7](https://github.com/hershel-theodore-layton/hhvm/commit/5304af98f7ac15ad891435bbb668d6a033bc8c31)
- Generated Thrift constant references can now navigate back to the original constant declaration recorded in the generated docblock. [abc8d5d7cb](https://github.com/hershel-theodore-layton/hhvm/commit/abc8d5d7cb23c5277213a69576955fb71b87771f)
- Function interception no longer clears the active implicit context, preserving keyed context values across intercepted calls now that the old incompatible-state mechanism is gone. [853f87ce43](https://github.com/hershel-theodore-layton/hhvm/commit/853f87ce43cc3ec2524913d6620d0b3d07a96fa4)

## Future Changes

- Mutually recursive case types no longer recurse indefinitely through localization, union simplification, and subtyping. Cycle diagnostics are also emitted by callers rather than by repeated localization passes.
