# 2024-08-16

## Highlights

- Error streaming now removes warnings already present in the warning saved state before worker batches are written, so LSP and other streaming clients do not redisplay preexisting warnings. [0afd026592](https://github.com/hershel-theodore-layton/hhvm/commit/0afd026592a5114ea2b35283d1f203c947521fc6)

## Future Changes

- Packages v2 now enforces package boundaries for internal top-level symbols as well as public ones, while still treating type-only `is` and `as` references as exempt. Cross-package internal access can now report both its module and package violations.
