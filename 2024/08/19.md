# 2024-08-19

## Highlights

- `ExtDeclMethodParam` now exposes an optional `'is_optional' => bool` field, distinguishing the `optional` keyword on abstract and interface method parameters from a concrete default expression. [4443d834be](https://github.com/hershel-theodore-layton/hhvm/commit/4443d834bea3ddea3644a5df3cdc39565f853af6)

## Future Changes

- Features configured as OngoingRelease are now enabled by the typechecker without a file-level unstable-feature attribute, matching their existing runtime behavior. Per-feature `.hhconfig` status may be stricter than HHVM's status. [c23cdade86](https://github.com/hershel-theodore-layton/hhvm/commit/c23cdade867931ff220612c09316cd456427803d) [d00bf7b468](https://github.com/hershel-theodore-layton/hhvm/commit/d00bf7b468c677d6d4b942d8fc89b0271c44082d)
