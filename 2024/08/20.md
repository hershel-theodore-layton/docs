# 2024-08-20

## Highlights

- Nested debugger expression evaluation now preserves the outer evaluation's stdout hook, so output produced after an inner breakpoint evaluation still reaches the debugger. [62e800fae9](https://github.com/hershel-theodore-layton/hhvm/commit/62e800fae9048532c11c25d932b1da18faea78cf)

## Future Changes

- When `.hhconfig` provides an `experimental_features` list, a file-level `__EnableUnstableFeatures` attribute can now enable only features named in that list; omitted features are rejected. Projects without the list continue to treat all known experimental features as OngoingRelease. [35add40d1c](https://github.com/hershel-theodore-layton/hhvm/commit/35add40d1cf399f48d7e4dde0e9573fb3a89d849)
- `await_in_splice` is now OngoingRelease in HHVM and no longer requires a runtime file-level opt-in. The typechecker continues to use the status configured in `.hhconfig`. [84f088b7a9](https://github.com/hershel-theodore-layton/hhvm/commit/84f088b7a994399b36a1e96cfa2a943ef9ff1503)
- Expression-tree lambdas can now declare `optional` parameters; DSL visitors receive their names and default expressions through `visitOptionalParameter()`. [56f84a9ef8](https://github.com/hershel-theodore-layton/hhvm/commit/56f84a9ef87cd51b04cd7516bd9b85e15baf4fae)
