## Breaking Changes

- The pure `HH\Facts\*_to_path_relative()` query family has been removed, including module, type, function, constant, and type-alias variants. Use the corresponding `*_to_path()` APIs, which return repository paths. [22e1bf9744](https://github.com/hershel-theodore-layton/hhvm/commit/22e1bf97449ce00523d1fb953ac8a0503e2f324d)
