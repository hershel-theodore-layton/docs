# 2024-08-28

## Highlights

- `hackfmt --diff` now resolves files correctly when the Mercurial repository root is above the project root. The new `--diff-root` option can supply an explicit base directory. [72ffd9760d](https://github.com/hershel-theodore-layton/hhvm/commit/72ffd9760d35dc44c04a3137240fca5503051795)
- Extended type explanations now point back to previously shown definitions, reverse projected subtype direction correctly for contravariant parameters, hide internal `supportdyn` steps in non-verbose output, and highlight the right-hand side of type definitions. ## Security

- Binary and compact Thrift deserialization no longer preallocates containers from untrusted oversized length fields. Initial reservation is capped at 16K entries, and sizes above the supported array limit raise a warning instead of attempting a multi-gigabyte allocation. [72771f6bf6](https://github.com/hershel-theodore-layton/hhvm/commit/72771f6bf60b734aeeee989609abe2c3bd4e09ff)

## Future Changes

- `hh_server` now correctly uses the experimental-feature status map from `.hhconfig` instead of falling back to legacy hard-coded statuses, so the configured Preview, OngoingRelease, and Unstable staging rules are actually enforced in full-server checks. [ed7cd08369](https://github.com/hershel-theodore-layton/hhvm/commit/ed7cd083690564a280922e9cf561a71af75144b5)
