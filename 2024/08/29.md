# 2024-08-29

## Future Changes

- Package configuration parse errors are now propagated to repository builds as build-blocking failures instead of appearing only in the typechecker. [4acf613e39](https://github.com/hershel-theodore-layton/hhvm/commit/4acf613e39c210042df0a474feb2c2bb06714b3e)
- With an active deployment, repo builds using `ForceEnableSymbolRefs` now include both deployment files and referenced symbols outside it. Without the option, the build remains limited to the deployment. [c2b16737b1](https://github.com/hershel-theodore-layton/hhvm/commit/c2b16737b117e435241b2c5fbb601ce8b20a2d52)
