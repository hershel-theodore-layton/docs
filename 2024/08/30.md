# 2024-08-30

## Highlights

- Tuple type comparison now preserves element order instead of sorting tuples like unions and intersections, so `(A, B)` is no longer treated as identical to `(B, A)`. [172a6d93c9](https://github.com/hershel-theodore-layton/hhvm/commit/172a6d93c9e0eae27f34ac38e4a61d1b68574f0f)
- The new pure `HH\Facts\transitive_subtypes<T>(classname<T>, ?HH\Facts\DeriveFilters = null)[]: vec<string>` query computes the full transitive closure of types that extend, implement, or use a base type in one native call. [8755851768](https://github.com/hershel-theodore-layton/hhvm/commit/8755851768547f7a04dd67dc2e11163e0c3a9b36)
- The sealed `HH\GenericEnumClass<+TClass, +TValue>` interface is now exposed to Hack, allowing type constants and generic APIs to constrain a value to any concrete enum class without exposing `HH\BuiltinEnumClass` directly. [47687c7eae](https://github.com/hershel-theodore-layton/hhvm/commit/47687c7eaebb1355b8d416a5070d5c1405b005dd)

## Future Changes

- Expression trees now support named instance-method access and calls through the DSL's `visitInstanceMethod()` hook. Nullsafe and dynamically named instance methods remain unsupported. [a84239a02b](https://github.com/hershel-theodore-layton/hhvm/commit/a84239a02b0ecdbb3778a68e834c612967f8cdec)
