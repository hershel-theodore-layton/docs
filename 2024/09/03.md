# 2024-09-03

## Highlights

- `HH\Facts\transitive_subtypes()` now accepts an optional `include_interface_require_extends` boolean. Passing `true` includes interfaces reached through `require extends`; the default remains `false`. The function retains its explicit empty capability list `[]`, so it remains callable from pure contexts. [0f9f4fd043](https://github.com/hershel-theodore-layton/hhvm/commit/0f9f4fd0430d1ec4399a53d11772a329f0f55bec)
- Direct declaration parsing now preserves `nameof C` in user-attribute arguments as a class name, and can constant-fold it inside string concatenations. Attribute metadata no longer loses these arguments when declarations are read without full typechecking. [734b261924](https://github.com/hershel-theodore-layton/hhvm/commit/734b2619248573b6ce60c9e992dcb827b4925401)
- `warnings_generated_files` is now a project setting in `.hhconfig`, so the same path regexes suppress generated-file warnings for the server, command-line client, and LSP. `-Wgenerated` still requests those warnings explicitly. [8b9b903486](https://github.com/hershel-theodore-layton/hhvm/commit/8b9b903486238427965314e1e2a32448963c872c)
