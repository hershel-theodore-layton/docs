# 2024-09-06

## Highlights

- Hovering a constructor call on a generic class now shows the constructor signature after substituting the class's inferred type arguments. [005e99e225](https://github.com/hershel-theodore-layton/hhvm/commit/005e99e2252305d8611e5d06790bb58ffeadd65f)
- The built-in `xbox_tasks_started(): int` is now declared to Hack, so it can be called without a missing-function error. Its omitted capability list is `[defaults]`. [5a731fcb6b](https://github.com/hershel-theodore-layton/hhvm/commit/5a731fcb6b8703d89925ba03f50c17b73ba4b5be)
- `Xbox.ServerInfo.MaxJobQueuingMs` can bound how long an XBOX job waits in the worker queue, preventing recursive XBOX calls from leaving a queue deadlocked until request timeouts. The default `-1` preserves unlimited waiting. [b9d0495662](https://github.com/hershel-theodore-layton/hhvm/commit/b9d049566277114ea8992e11ed455a7849b74e5e)
