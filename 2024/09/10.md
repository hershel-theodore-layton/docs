# 2024-09-10

## Highlights

- HHVM now ships raw LMDB bindings in the `HH\lmdb` namespace, covering environments, transactions, databases, cursors, statistics, copy operations, and key comparison. [ba8cf61e1a](https://github.com/hershel-theodore-layton/hhvm/commit/ba8cf61e1a5e7d8e334381712348c5e1a87bb21e)

## Breaking Changes

- The legacy flat server thread-tuning options have been removed. Rename `ThreadTuneDebug`, `ThreadTuneSkipWarmup`, `ThreadTuneAdjustmentPct`, `ThreadTuneAdjustmentDownPct`, `ThreadTuneStepPct`, `ThreadTuneCPUThreshold`, and `ThreadTuneThreadUtilizationThreshold` to their corresponding `Server.ThreadTune.*` settings. [bf90ee2b60](https://github.com/hershel-theodore-layton/hhvm/commit/bf90ee2b608cceba5a7bf22aaeff44a2a45a7eca)

## Future Changes

- Type refinement now distinguishes tuple and shape runtime tags from the broader `vec` and `dict` tags. Relationships involving these structural tags remain conservatively unknown, so negated tuple and shape predicates no longer rely on special-case handling or incorrectly equate all tuples or shapes. [487190d7ad](https://github.com/hershel-theodore-layton/hhvm/commit/487190d7adb0d4838b515da590c41e0382ba9e21)
