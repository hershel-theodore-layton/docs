# 2024-09-12

## Highlights

- `.hhconfig` can now disable selected warnings with a comma-separated `disabled_warnings` list while leaving `hack_warnings=true`. Setting `hack_warnings=false` still disables every warning. [26a2168843](https://github.com/hershel-theodore-layton/hhvm/commit/26a2168843fa6ea8be6c573af49d2bb5091f47e8)
- Serverless IDE diagnostics now apply the same warning filters as the full server. [ca15b26419](https://github.com/hershel-theodore-layton/hhvm/commit/ca15b264191469a72f6104b89bcf2d7df1b39447)

## Breaking Changes

- Warning suppressions must use `HH_IGNORE[code]`. `HH_FIXME` no longer suppresses warning codes and instead emits guidance to use `HH_IGNORE`; conversely, `HH_IGNORE` cannot suppress an error code. [6f7bc81e65](https://github.com/hershel-theodore-layton/hhvm/commit/6f7bc81e65d9c3f794fec5ee9057535000299381)
