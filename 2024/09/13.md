# 2024-09-13

## Highlights

- Hover information no longer displays generic parameters that were fully substituted while instantiating a function or method. Explicit enum-class-label arguments are shown as their singleton type, such as `#Mul`, rather than the broader label type. [b3efd805cc](https://github.com/hershel-theodore-layton/hhvm/commit/b3efd805cc054a538e6003ec188086f499875059) [fd4f638dee](https://github.com/hershel-theodore-layton/hhvm/commit/fd4f638deeb5e9133661c6ecce92136d927a8743)

## Breaking Changes

- Cyclic type-alias bounds no longer leave a freely solvable type variable behind. Hack conservatively localizes these cycles to `mixed` (or `supportdyn<mixed>` under implicit pessimization), which can reveal invalid calls that previously typechecked unsoundly. [1099f097bf](https://github.com/hershel-theodore-layton/hhvm/commit/1099f097bf6b56502a85b254bc568af5f5eaf7ec)
- The unused `zoned_with<T>` context and `HH\Coeffects\enter_zoned_with()` / `enter_zoned_with_async()` entry points have been removed. Code that still declares or enters a `zoned_with` context must migrate to the remaining implicit-context and coeffect APIs. [42b37a58ae](https://github.com/hershel-theodore-layton/hhvm/commit/42b37a58ae5d834542b86cc5b82a3ba5fe94a1c7)
