# 2024-09-16

## Highlights

- Lambdas may reuse the discard parameter name with different annotations, as in `(int $_, string $_) ==> {}`; Hack no longer compares the discarded parameters with one another and reports a spurious coercion error. [0b59874dd4](https://github.com/hershel-theodore-layton/hhvm/commit/0b59874dd47567e4f27adc18639969ff763ffc92)
- Direct references to constants and type constants declared by a trait now initialize against the trait's own class object, fixing failures for expressions such as `TMyTrait::MY_CONSTANT`. [4752658e59](https://github.com/hershel-theodore-layton/hhvm/commit/4752658e59bebe1f67f2e11d6c6a4ba901d9bd96)
- Method hovers selected through an enum-class label now show the label's singleton type. Dead-suppression cleanup also removes unused `HH_IGNORE` comments alongside unused `HH_FIXME` comments. [9fc76eee71](https://github.com/hershel-theodore-layton/hhvm/commit/9fc76eee7175572cbd969189b3d739b541c19909) [9ba137b426](https://github.com/hershel-theodore-layton/hhvm/commit/9ba137b426f0a28e76d0797fdc4cd126b32a2d25)

## Future Changes

- Staged package-v2 checking now permits a function pointer to a static method in another package, matching the symbol-reference traversal used for deployment boundaries. [38d78565b8](https://github.com/hershel-theodore-layton/hhvm/commit/38d78565b8a1cea605ebe826e34629044f007671)
- Work on `recursive_case_types` now models newtype bounds, enum bounds, and function-type variants when checking recursive case definitions.
