# 2024-09-23

## Future Changes

- The compiler now accepts `nameof C` as a shape field key and represents it with a distinct classname field in the syntax tree so namespace expansion is preserved. Emitted keys remain strings, and the typechecker still rejects `nameof` shape keys at this stage.
