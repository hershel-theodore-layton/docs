# 2024-09-24

## Future Changes

- Under the staged package-v2 checker, the type named on the right-hand side of an `is` or `as` expression is now checked for package-boundary violations. Cross-package tests and casts that relied on this type reference being ignored can now report package-access errors. The exception for `is` is restored on September 30.
