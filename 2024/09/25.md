# 2024-09-25

## Highlights

- Lambda parameter and return annotations may now contain inferred wildcards, including nested forms such as `vec<_>` and `Awaitable<vec<_>>`. Each wildcard is solved from the lambda body and call context; reified arguments remain ineligible. [eaf589aa7e](https://github.com/hershel-theodore-layton/hhvm/commit/eaf589aa7e5c69707e6b3f127ad37b652a2888f5)

## Security

- HHVM's `EnforceDeployment` runtime option now defaults to `false`, so deployment boundaries are not enforced at runtime unless operators explicitly turn the option back on. Applications that treated the previous default as a safety boundary should review their deployment configuration. [d1c1861613](https://github.com/hershel-theodore-layton/hhvm/commit/d1c18616130a514471dcaf34e8ea54cbcd2f5053)
