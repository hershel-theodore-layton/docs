# 2024-09-26

## Highlights

- `extended_reasons=legacy` is now available in `.hhconfig` and command-line configuration. It retains extended provenance while typing but emits the traditional diagnostic presentation, making it useful for measuring rollout differences without changing error text. [bf67242a78](https://github.com/hershel-theodore-layton/hhvm/commit/bf67242a781ee8d93a8178fb6775cafbf205d068)

## Future Changes

- The unstable `type_splat` feature introduces arity-polymorphic parameters such as `...TArgs`, paired with an open-tuple bound like `TArgs as (mixed...)`. It is enabled together with `open_tuples` via `<<file: __EnableUnstableFeatures('open_tuples', 'type_splat')>>`; HackC lowers the resulting tuple parameter through the variadic calling convention. [ee442186bc](https://github.com/hershel-theodore-layton/hhvm/commit/ee442186bce956d10e3f9813dfd7eebf7b2165fb) [547e6436a1](https://github.com/hershel-theodore-layton/hhvm/commit/547e6436a144dc745ef4a7697aeb46ad03db7008)
