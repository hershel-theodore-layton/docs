# 2024-09-30

## Highlights

- `--ignore-hh-version` can now initialize from a saved state even when `.hhconfig` has changed, by requesting a state without constraining its project metadata. [788b1c1349](https://github.com/hershel-theodore-layton/hhvm/commit/788b1c13499d584bcb4f0236b2b8a7f9fb2e7733)
- User-profiler callbacks now retain the current implicit-context value instead of running with that value cleared. [a4a17fac22](https://github.com/hershel-theodore-layton/hhvm/commit/a4a17fac229c57147c9b44dc3030364e3c134112)
- Subtyping can now solve an unsolved type variable against a like type instead of prematurely rejecting that branch, fixing valid generic inference under sound dynamic. [cf76be167a](https://github.com/hershel-theodore-layton/hhvm/commit/cf76be167acb4fdf52d34ce671877b62207dbbe3)

## Future Changes

- Staged package-v2 checks now deliberately ignore types referenced only on the right-hand side of `is` expressions or as generic type arguments, matching the deployment symbol-reference traversal. [10efc91d0b](https://github.com/hershel-theodore-layton/hhvm/commit/10efc91d0befc5112de5804c4494ce09871ec97a) [52e2d3811b](https://github.com/hershel-theodore-layton/hhvm/commit/52e2d3811ba954293b01f0899a867396868374a7)
- Experimental type splats are now typechecked and participate in subtyping, including fixed, optional, and variadic open-tuple components. This makes arity-polymorphic wrappers such as `function call<TArgs as (mixed...)>((function(...TArgs): void) $f, ...TArgs $args)` type-safe. [58d6aa941e](https://github.com/hershel-theodore-layton/hhvm/commit/58d6aa941ef58e7ea2ed4130edadead5ea567ec1) [6b5ac89089](https://github.com/hershel-theodore-layton/hhvm/commit/6b5ac89089fc4f27124ac94b19c1d7542856ba7a)
