# 2024-10-09

## Future Changes

- Explicit like-type hints such as `~int` are now an Unstable syntax feature. Projects using them must enable `like_type_hints` through `enable_experimental_stx_features` or `<<file:__EnableUnstableFeatures('like_type_hints')>>`; the old `like_type_hints` option is gone.
