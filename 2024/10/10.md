# 2024-10-10

## Highlights

- Command-line diagnostics now print warnings before errors, leaving the errors at the bottom of the output where they are easier to find. [a84a03948e](https://github.com/hershel-theodore-layton/hhvm/commit/a84a03948ee7aa1651d24feca312ff3ee20d0ef4)
- `nameof C` and `C::class` are now handled consistently as class-name shape keys, including namespace and `self` resolution. [99e117526a](https://github.com/hershel-theodore-layton/hhvm/commit/99e117526a5d4dc0b432351dfd453f6dc434ecf2)

## Future Changes

- Hovering inside a splice of an Unstable expression tree now reports the original, non-virtualized expression's type. [2bb7ede81c](https://github.com/hershel-theodore-layton/hhvm/commit/2bb7ede81c4b4523428d3f8a1117cd574546dfe7)
- Package configuration is now version-checked: Package v1 rejects `include_paths`, while Package v2 rejects `uses`. HHVM also gained the `Eval.PackageV2` compiler option for the v2 format. [fafd709eab](https://github.com/hershel-theodore-layton/hhvm/commit/fafd709eabe63ddc4cc44957c9dc29cdd0b6387a)
