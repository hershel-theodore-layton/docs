# 2024-10-15

## Highlights

- Errors caused by illegal recursive aliases now explain why the alias was replaced with `mixed`, instead of presenting that `mixed` as an unexplained source type. [bc618c335b](https://github.com/hershel-theodore-layton/hhvm/commit/bc618c335b1963b1b9aa9245818be28ff89394d9)
- Hovering over the generic `this` type now also shows its upper bounds. [bdb90e88e2](https://github.com/hershel-theodore-layton/hhvm/commit/bdb90e88e2d5501ab075cb14d59164f3ff8deea6)

## Breaking Changes

- A `package` expression inside `invariant(...)` no longer establishes package availability for following code. Use an `if (package pkg)` block instead. [7f948abbc0](https://github.com/hershel-theodore-layton/hhvm/commit/7f948abbc086a1862cf98aecb074f4b7a2cd4fa7)

## Future Changes

- Packages v2 introduces the unstable `<<__RequirePackage('pkg')>>` function and method attribute. The checker validates its single literal package argument, uses it to typecheck conditionally available calls, and reports an actionable error when the required package has not been established as loaded.
