# 2024-10-18

## Highlights

- Type inference now assigns the correct source span to `TypeAlias::class` and `nameof TypeAlias` expressions instead of extending the alias token's position over the whole expression. [c31617ee8c](https://github.com/hershel-theodore-layton/hhvm/commit/c31617ee8ced1507783037dfddb1614bd13723c7)

## Breaking Changes

- `enum_exists()` now takes `classname<mixed>` rather than `string`. Literal class names, lazy class values, and class pointers work at runtime, but callers passing an arbitrary `string` variable must first establish that it is a classname. [ac3a1175d5](https://github.com/hershel-theodore-layton/hhvm/commit/ac3a1175d5194cf63124fb87d364af0773461048)
