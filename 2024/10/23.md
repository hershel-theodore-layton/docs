# 2024-10-23

## Breaking Changes

- Cyclic `as` bounds on type aliases and newtypes are now rejected explicitly. These already failed indirectly after cycle recovery produced `mixed`; the checker now points to the unsupported bound itself. Cyclic `super` bounds are unchanged. [82a6a0afae](https://github.com/hershel-theodore-layton/hhvm/commit/82a6a0afae456dbde91669669406367ebf5febb4)

## Future Changes

- Packages v2 no longer applies package-boundary checks to class-constant and global-constant type hints, which are not emitted into runtime constant metadata. [878738dc7d](https://github.com/hershel-theodore-layton/hhvm/commit/878738dc7db65e8e9b6560eb425f87d5baa85f2f)
- Experimental case types with variant `where` clauses now retain their nominal case type through intersections and type-switch refinements instead of being unsafely reduced to the raw variant hints. [a2ad3ec620](https://github.com/hershel-theodore-layton/hhvm/commit/a2ad3ec620938254d242ed793faae2bb53cd2bd5)
