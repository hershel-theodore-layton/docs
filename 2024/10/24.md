# 2024-10-24

## Highlights

- Hack now runs both full-fidelity and lowerer syntax checks even when the first pass already found errors, so a single invocation can report more independent syntax problems. [0e55fbf060](https://github.com/hershel-theodore-layton/hhvm/commit/0e55fbf060c2ce122e59b7e8720381d5fbdcfbc0)
- Notebook conversion is now bidirectional: `hh --hack-to-notebook` reconstructs notebook JSON from generated Hack on standard input, and both conversion directions apply Hack formatting. [1e45a855cb](https://github.com/hershel-theodore-layton/hhvm/commit/1e45a855cb413065f67d0f9fbd81d1cf76faf46d) [30842a482b](https://github.com/hershel-theodore-layton/hhvm/commit/30842a482b4206988f139224169abbbf318d7198)
- The single-class filename linter now says that a file "defines" a class rather than incorrectly claiming the class is its only content when typedefs are also present. [653d1be162](https://github.com/hershel-theodore-layton/hhvm/commit/653d1be16238a2ab907c2762dbaeca23f067f160)

## Future Changes

- Await expressions on the right side of a pipe, and nested awaits, moved from Preview to Ongoing Release and no longer require the `pipe_await` feature opt-in. [d26ca17cef](https://github.com/hershel-theodore-layton/hhvm/commit/d26ca17cef432e3811f8c6904a485c8158f52464)
