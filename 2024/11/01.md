# 2024-11-01

## Breaking Changes

- Hack now detects more impossible shape accesses when the shape is hidden behind an abstract type constant, generic bound, or intersection. `Shapes::idx()`, `Shapes::at()`, `Shapes::keyExists()`, and coalesced indexing can consequently report new errors or always-false checks, with the explanation pointing back to the relevant shape bound. [b006f0e38f](https://github.com/hershel-theodore-layton/hhvm/commit/b006f0e38f1ab3be000f9b558439c90d91dc7253) [25c058fc89](https://github.com/hershel-theodore-layton/hhvm/commit/25c058fc89dfd59316d901228fb9ebf5463a8066)

## Future Changes

- Package v2 now canonicalizes both the project root and the `PACKAGES.toml` parent in strict mode, and neither in non-strict mode. This fixes `include_paths` matching when the two paths previously used inconsistent canonicalization.
