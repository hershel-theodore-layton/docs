# 2024-11-04

## Breaking Changes

- HHVM now enforces every upper-bound constraint on typed properties when an object is unserialized and when a property is unset. Values that satisfied the main property hint but violated a generic upper bound can now throw a property type-hint error during APC/unserialization or `unset()`. [a5b29ce0d7](https://github.com/hershel-theodore-layton/hhvm/commit/a5b29ce0d7d66dc63d0e11c23524498f4c07cc93)

## Future Changes

- The unstable `shape_destructure` feature now handles typed-local enforcement, readonly propagation, and lambda captures for shape destructuring. These commits are supporting pieces of the feature rather than a general release.
