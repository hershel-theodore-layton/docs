# 2024-11-05

## Highlights

- The new `Log.BaseDirectory` runtime option prefixes server error, access, admin, and Xbox log-file paths, allowing separate tasks to use the same relative logging configuration under different directories. [2085abb477](https://github.com/hershel-theodore-layton/hhvm/commit/2085abb477c6281c7355578c7f3112d9376e054e)

## Future Changes

- The unfinished `module_references` feature has been removed, including `imports` and `exports` blocks and `ReflectionModule::getImports()`/`getExports()`. Ordinary Hack modules and package-v2 relationships are unaffected. [9a3740165f](https://github.com/hershel-theodore-layton/hhvm/commit/9a3740165f23f45a7e6790bf1c0cf3707f5cbeeb)
