# 2024-11-06

## Highlights

- The Thrift extension adds `thrift_protocol_write_binary_struct()` and `thrift_protocol_write_compact_struct()`, which serialize a struct without an RPC message envelope. The compact form accepts an optional protocol version, defaulting to 2. [9e49db492b](https://github.com/hershel-theodore-layton/hhvm/commit/9e49db492bbba72ca272cbefbc420a29ccf26582)
- Generated runtime configuration now forwards `Repo.Authoritative` correctly after the configuration-system migration, preventing consumers from observing a stale or incorrect repo-mode value. [67acf766d8](https://github.com/hershel-theodore-layton/hhvm/commit/67acf766d84c30d63d7e93d097ac19b52143bc5d)

## Future Changes

- Unstable shape destructuring can now be used as a `foreach` value pattern, including nested shape and tuple patterns. It still requires `<<file:__EnableUnstableFeatures('shape_destructure')>>`. [394673c13a](https://github.com/hershel-theodore-layton/hhvm/commit/394673c13a660090358c6cd17625f9e4f63d28ec)
- Package v2 active deployments are now honored while building a repo: files are selected from `include_paths` and `__PackageOverride` attributes instead of module membership. This remains part of the staged package-v2 rollout. [0548222340](https://github.com/hershel-theodore-layton/hhvm/commit/0548222340abfff213b4347af8ad49ff4a507233)
- Memoized calls now produce the same key for a class name represented as a string, lazy class, or class pointer. This fixes duplicate cache entries during the class-pointer rollout. [9c245379fd](https://github.com/hershel-theodore-layton/hhvm/commit/9c245379fd7d3d851f80b2185f0a26cfc48e9a1e)
