# 2024-11-07

## Future Changes

- Behind the class-pointer rollout switches, `class<T>` now has its own local type instead of being erased to `classname<T>`. `enable_class_pointer_hint=false` retains the old erasure, while `class_sub_classname` temporarily controls the compatibility subtype relation. The implicit `C::class` constant can likewise be typed as `class<C>` through the staged `class_class_type` option. - Package v2 no longer reports package-access errors for exception types named in `catch` arms. [2b465f3615](https://github.com/hershel-theodore-layton/hhvm/commit/2b465f3615b315e32a8a9973154b8e59b7efc4c3)
