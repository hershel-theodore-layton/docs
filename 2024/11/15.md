# 2024-11-15

## Highlights

- The LMDB extension adds `HH\lmdb\mdb_get_raw()` and `HH\lmdb\mdb_put_raw()` for direct string payload access without Hack serialization. `mdb_put()` and the raw variant now only write back the `inout` value after a successful call with `MDB_NOOVERWRITE`; an error such as `MDB_KEYEXIST` returns without updating it. [1ce27396b3](https://github.com/hershel-theodore-layton/hhvm/commit/1ce27396b3c96b39933eaab7f388bcd9c71e13ac)
- HHVM now publishes `hhvm.select_queue_duration_us.avg.60`, measuring how long messages spend waiting in the server selection queue. [d8e94d74d6](https://github.com/hershel-theodore-layton/hhvm/commit/d8e94d74d66fc11f28f92571fe4d637cc87d2c72)
