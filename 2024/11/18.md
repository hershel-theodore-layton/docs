# 2024-11-18

## Highlights

- The pure `HH\Facts\sha1(string $path)[]: ?string` API returns the SHA-1 already tracked by the active Facts store. It returns `null` when no hash is available; the repo-autoload implementation does not supply one. [690ed8a0cd](https://github.com/hershel-theodore-layton/hhvm/commit/690ed8a0cdf10fc20f9b6143bc94432fd832b4cb)

## Breaking Changes

- `C::class` and `self::class` may no longer be used as shape keys in shape types, literals, `Shapes::idx()`-style calls, or other non-subscript positions because they require an implicit class-pointer-to-string conversion. Replace them with `nameof C` or `nameof self`; ordinary class constants remain valid shape keys. [c0ab10b739](https://github.com/hershel-theodore-layton/hhvm/commit/c0ab10b73979c164d28d83838f6fd741d2d22d10) [9952acc27d](https://github.com/hershel-theodore-layton/hhvm/commit/9952acc27dcc2c289c11738987d273fa1ebe8e0f)

## Future Changes

- The unstable `shape_destructure` feature now typechecks shape and tuple patterns structurally, assigning a fresh type variable to each leaf and checking the resulting pattern against the right-hand side. [2e29a76973](https://github.com/hershel-theodore-layton/hhvm/commit/2e29a769731a2aa439f248221d2eca139a4f4b6b)
