# 2024-11-19

## Highlights

- `json_encode_with_error()` accepts the new `JSON_FB_FULL_FLOAT_PRECISION` flag to emit up to 17 decimal digits for IEEE-754 doubles instead of HHVM's usual 14, allowing a JSON encode/decode round trip without losing representable precision. [09c784c567](https://github.com/hershel-theodore-layton/hhvm/commit/09c784c56724b86be0bcd7cf5a2d389502eb0f8e)

## Security

- The `AdminServer.EnableSSLWithPlainText` option has been removed; the admin server no longer multiplexes TLS onto its plaintext port. Deployments using this option must provide TLS through a separate endpoint or proxy. [f75cdaef50](https://github.com/hershel-theodore-layton/hhvm/commit/f75cdaef50ffa63afa7aa65bbc5cef50dd64ce5f)

## Future Changes

- Opt-in extended type-error explanations now trace values through static-property and class-constant accesses and omit the ordinary CLI error-count footer from the detailed document renderer. [7f936bbcee](https://github.com/hershel-theodore-layton/hhvm/commit/7f936bbceea8b6b93ba0958e50f220f95b21df3a) [944e7951ca](https://github.com/hershel-theodore-layton/hhvm/commit/944e7951ca0546fb797650f6d8233c7d6ee41a46) [4cf06f194f](https://github.com/hershel-theodore-layton/hhvm/commit/4cf06f194f34ba818ff2d9523e79fba3c278126e)
- Experimental tuple splats can now be indexed, and tuples containing a splatted tail support dynamic when both their fixed elements and tail do. [bf35c48456](https://github.com/hershel-theodore-layton/hhvm/commit/bf35c4845697cccd0573d03760f8ed01b11941a3) [b0df8ac785](https://github.com/hershel-theodore-layton/hhvm/commit/b0df8ac78558824e39d50403e65ee4907e5a7f5c)
