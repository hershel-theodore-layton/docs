# 2024-11-25

## Highlights

- `hh` now filters warnings from files whose first 50 lines contain `@generated`. Pass `-Wgenerated` to include those warnings again. [0fb414e697](https://github.com/hershel-theodore-layton/hhvm/commit/0fb414e697fee010374b617106b48f46f96074ec)

## Breaking Changes

- Equality disjointness checking now looks through like types. Projects with the relevant warnings enabled can newly receive Warn[12007] for strict comparisons that can never succeed after removing the dynamic component, such as `(int, string) === int`. [aeb075f9f2](https://github.com/hershel-theodore-layton/hhvm/commit/aeb075f9f22944c25512ec7d5fb00c8a72e04ea9)

## Future Changes

- Beta error streaming now falls back to streaming the current errors file when its Watchman freshness query fails, instead of terminating with an exception. [9f83204614](https://github.com/hershel-theodore-layton/hhvm/commit/9f832046149e2c4f3557663772e8ec9007ca1cd7)
- The in-development notebook converter now preserves notebook and cell metadata, markdown cells, code-cell order, and empty notebooks. Generated Hack wraps top-level cells in an async `gen_notebook_main_*()` function so notebook code can use `await`.
