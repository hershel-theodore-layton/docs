# 2024-11-26

## Highlights

- The new `sb_profile_ser(string $sandbox_root, string $profile_path)` and `sb_profile_deser(...)` APIs serialize and restore sandbox JIT profile data, returning a status string. Each operation is limited to one attempt during an HHVM process's lifetime, and deserialization skips units whose SHA-1 no longer matches. [c773c01184](https://github.com/hershel-theodore-layton/hhvm/commit/c773c01184a83cfbd2f95a78c734aa9cb5375354) [5d05ff52a8](https://github.com/hershel-theodore-layton/hhvm/commit/5d05ff52a88cbece44f8711b624a255c05a7730f)

## Future Changes

- Recursive case-type validation now expands type constants and opaque aliases when checking contractiveness, rejecting indirect cycles such as `case type A = ?B::T` where `B::T` resolves back to `A`. [d3984bcbc6](https://github.com/hershel-theodore-layton/hhvm/commit/d3984bcbc6778b96905c50bd77a6a18b0684b30a)
