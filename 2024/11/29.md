# 2024-11-29

## Highlights

- The diagnostic for a type constant that captures a class type parameter now correctly says that type constants cannot use type parameters, rather than referring to a nonexistent type-parameter list on the type constant. [2096dcf5b6](https://github.com/hershel-theodore-layton/hhvm/commit/2096dcf5b6c4735207fb77203da3fd49a5da0d0c)

## Future Changes

- Beta error streaming now reports the total error count when `--max-errors` truncates output and shows the server's real progress stages instead of a generic `hh_server sync` message. [28ae0a85cd](https://github.com/hershel-theodore-layton/hhvm/commit/28ae0a85cdcb1760c9a772c0cb41d02076837e9b) [e2db79b525](https://github.com/hershel-theodore-layton/hhvm/commit/e2db79b5253fe370ecd93baf21f950d9e5090b4c)
- Recursive case-type subtyping now treats revisiting an already-compared recursive pair as success, enabling sound relationships between contractive recursive definitions while relying on the new contractiveness checks to reject aliases such as `A = A`. [62ca09bb76](https://github.com/hershel-theodore-layton/hhvm/commit/62ca09bb76e484521a7e3faecdfbfd8144f17e74)
