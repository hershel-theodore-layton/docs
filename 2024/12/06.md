# 2024-12-06

## Highlights

- `HH\get_class_from_object(readonly object)[]: class<mixed>` returns an object's class pointer, while `HH\get_parent_class_from_class(readonly class<mixed>)[]: ?class<mixed>` returns its parent or `null`. Both APIs have an explicit empty capability list `[]`, so callers need no ambient capabilities. [c4650b12f7](https://github.com/hershel-theodore-layton/hhvm/commit/c4650b12f72329b34890111966127bdba6ed6d0d)
- Diagnostics involving implicitly pessimised properties and returns now explain why the like type was introduced—for example, an unenforced generic argument, type constant, function type, or call on a dynamic value. [0d45f2066c](https://github.com/hershel-theodore-layton/hhvm/commit/0d45f2066cdea68b4040ead75282fb3986a8e632)

## Future Changes

- The unstable expression-tree implementation now preserves the enclosing async state through generated and explicit client lambdas, so `await` inside nested splices is lowered correctly. Unsupported `yield` expressions also receive a direct diagnostic.
