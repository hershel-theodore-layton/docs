# 2024-12-18

## Future Changes

- The configurable class-pointer migration check now follows values already typed as `class<T>` into `dict`, `keyset`, indexed-access, and collection-key positions. Setting the `arraykey` entry in `class_pointer_levels` to `3` emits warning 12013; level `4` makes it an error. Convert deliberately with `HH\class_to_classname()` when a string key is intended.
