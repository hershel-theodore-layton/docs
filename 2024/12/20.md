# 2024-12-20

## Future Changes

- The unstable `require_constraint` feature adds `require this as C;` to traits. It gives the trait body a `this <: C` assumption without requiring `C` to be final, and—unlike `require extends C`—also permits the using class to be exactly `C`. Enable it with `<<file: __EnableUnstableFeatures('require_constraint')>>`. [aabd163a85](https://github.com/hershel-theodore-layton/hhvm/commit/aabd163a8502b00d528d6f3b6d3288540b26fe11)
