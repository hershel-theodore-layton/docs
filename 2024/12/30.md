# 2024-12-30

## Highlights

- `HH\XReqSync` provides named, cross-request asynchronous locks in non-authoritative mode. `get()` obtains a named lock object, `genLock()` waits with an optional millisecond timeout and resolves to whether the lock was acquired, and `unlock()` releases it; destruction also releases a held lock. All three public methods explicitly declare `[]`, so callers need no ambient capabilities.
