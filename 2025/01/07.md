# 2025-01-07

## Breaking Changes

- `DateTimeZone::listIdentifiers()` and `DateTimeZone::listAbbreviations()` now use the default impure context instead of `[]`. This corrects their dependence on external timezone data, but means they can no longer be called from a pure context.
