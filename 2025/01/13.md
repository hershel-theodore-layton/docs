# 2025-01-13

## Highlights

- Non-repo-authoritative HHVM gained `HH\SimpleLock`, a named cross-request mutex API with asynchronous `lock()`, immediate `try_lock()`, `unlock()`, and a timeout helper. Locks abandoned at request shutdown are released automatically. [ea44027434](https://github.com/hershel-theodore-layton/hhvm/commit/ea4402743440bab143ec0a6555d8ada69ecf452f)

## Future Changes

- Packages v2 now requires every package's `includes` and `soft_includes` sets to contain their full transitive closure, and reports all missing nested packages in one configuration error. [1f4c78a1a3](https://github.com/hershel-theodore-layton/hhvm/commit/1f4c78a1a3bdac088db188db2d9e43ca258f61f9)
