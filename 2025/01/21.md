# 2025-01-21

## Highlights

- Overrides of ordinary class methods marked `<<__NoAutoLikes>>` now inherit that behavior automatically, so their return types are not implicitly widened to like types. Interface implementations still need their own annotation. [7a353344ec](https://github.com/hershel-theodore-layton/hhvm/commit/7a353344ec39816e94ebcdf585854e57f71a6532)

## Future Changes

- Expression-tree lambdas now reject a bare nested splice such as `${$x ==> ${$x}}`; splicing is only valid while the parser is directly inside an expression-tree literal. [d796173ae4](https://github.com/hershel-theodore-layton/hhvm/commit/d796173ae42e73523966f7b487f11b4253c915aa)
