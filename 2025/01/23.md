# 2025-01-23

## Highlights

- Classes using the same trait through many branches of a trait diamond no longer count duplicate imported methods toward HHVM's 65,535-method limit, avoiding a false "Class has more than 65,535 methods" failure. [2566b4e7d8](https://github.com/hershel-theodore-layton/hhvm/commit/2566b4e7d8b52ff200ea9b93434a89e891435332)

## Future Changes

- JSON-encoded type information for open tuples now carries `optional_args`, `variadic_arg`, or `splat_arg` instead of collapsing every open tail into `fields_known: false`. This improves structured type-error and IDE consumers. [ade6c78117](https://github.com/hershel-theodore-layton/hhvm/commit/ade6c781178e4a0e0d413a419c643ede4f885edf)
