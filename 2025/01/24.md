# 2025-01-24

## Highlights

- HHVM now reports a clear error when a non-default `Eval.PackagesTomlFileName` cannot be opened instead of silently continuing with an empty package specification. [f9035ba600](https://github.com/hershel-theodore-layton/hhvm/commit/f9035ba6005d53b4268c07f4747618c9d13abab0)
- The unsurfaced-exception lint no longer produces false positives for exception variables captured by lambdas during the dynamic TAST pass. [527a1dc8e7](https://github.com/hershel-theodore-layton/hhvm/commit/527a1dc8e73e7e1d0015d8e5d650c760f0062731)
- `HH\SimpleLock\is_held()` reports whether any request currently holds a named SimpleLock. [a2466c5ee3](https://github.com/hershel-theodore-layton/hhvm/commit/a2466c5ee3b3141d6d5e664fe029f3b09d9d5a73)
- The new `#ICInaccessibleSpecialCase` memoization option allows specialized functions to read implicit context without sharding their memo cache by it. Like `#MakeICInaccessible`, it is restricted to `defaults`, `leak_safe_shallow`, or `leak_safe_local` contexts. [2e164dc8db](https://github.com/hershel-theodore-layton/hhvm/commit/2e164dc8db462025e2f33fcef24f7b537398d690)
