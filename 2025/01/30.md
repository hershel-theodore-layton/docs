# 2025-01-30

## Highlights

- The VS Code debugger now sets breakpoints on every non-contiguous bytecode block mapped to a source line, fixing missed stops when compiler optimizations duplicate a loop body. Some multiline expressions can consequently produce more than one breakpoint. [2b8ada7314](https://github.com/hershel-theodore-layton/hhvm/commit/2b8ada7314da791c8cea0284f6a1401faf376d10)

## Future Changes

- Expression trees gained Preview support for shape literals and shape-typed parameters behind `expression_tree_shape_creation`. DSLs can virtualize shape construction with proper required, optional, open-field, and nested-shape checking, but shape reads and writes are not included yet. [0783044e49](https://github.com/hershel-theodore-layton/hhvm/commit/0783044e49361c3592e230b029a478da060d2b9d) [5f4cd41fcf](https://github.com/hershel-theodore-layton/hhvm/commit/5f4cd41fcf060f7198bcf8c32bd1a3bdb6fe4da9)
- Hack's `TypeStructure<T>` shape now exposes optional `optional_elem_types` and `variadic_type` fields for tuple types, matching the runtime representation added earlier in the month. [84b51c4165](https://github.com/hershel-theodore-layton/hhvm/commit/84b51c4165ce3dab0f1496cdcb5237a7ba835418)
