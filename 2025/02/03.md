# 2025-02-03

## Highlights

- Under sound-dynamic typing, enum-class constant initializers now accept like-typed values without incorrectly widening the enum class's own base type and inherited API. [a575025b82](https://github.com/hershel-theodore-layton/hhvm/commit/a575025b82056492ddad48631279c8de459f586c)

## Breaking Changes

- The specialized `<<__Memoize(#ICInaccessibleSpecialCase)>>` option has been renamed to `#NotKeyedByICAndLeakIC__DO_NOT_USE`. The new name makes its dangerous behavior explicit: implicit context is omitted from the cache key but remains readable, so callers must migrate the label and should avoid it unless this cache sharing is deliberate. [ad1c155576](https://github.com/hershel-theodore-layton/hhvm/commit/ad1c1555763f96b103ad016bd0dc5615ccd63598)

## Future Changes

- Experimental `require this as` constraints now permit a class to use a trait that requires that same class. Requiring a final class with `require this as` is rejected with guidance to use `require class`, which expresses the only possible implementation more accurately. [e3b0f70eb7](https://github.com/hershel-theodore-layton/hhvm/commit/e3b0f70eb7efbbc800bb670c75e5f3456923d62e)
