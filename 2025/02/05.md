# 2025-02-05

## Breaking Changes

- Open shape type hints now receive the same field-name validity checks as closed shapes, including when the shape is wrapped in `supportdyn`; invalid keys can no longer escape checking merely because the shape permits unknown fields. [7afeeadee3](https://github.com/hershel-theodore-layton/hhvm/commit/7afeeadee34cfd1783bc5908d3bfb5a08affa05c)

## Future Changes

- Two opt-in migration settings were added for plain `<<__Memoize>>`. `disallow_non_annotated_memoize=true` rejects it unless a label such as `#KeyedByIC` is supplied, while `treat_non_annotated_memoize_as_kbic=true` interprets an unlabeled annotation as `#KeyedByIC`; the latter takes precedence when both are enabled. Their HHVM equivalents are `Hack.Lang.DisallowNonAnnotatedMemoize` and `Hack.Lang.TreatNonAnnotatedMemoizeAsKBIC`. [c6c1721348](https://github.com/hershel-theodore-layton/hhvm/commit/c6c17213485a8d6537836d28bb695b2e79d6718f) [ea7256253b](https://github.com/hershel-theodore-layton/hhvm/commit/ea7256253b265158b30391927d74c38f5c276d61)
