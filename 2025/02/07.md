# 2025-02-07

## Highlights

- Type-variable solving no longer performs a redundant, occasionally incomplete `T <: T` check when a union or intersection lower bound contains nothing that can be freshened. This removes false type errors for complex invariant bounds. [a37f19dfe7](https://github.com/hershel-theodore-layton/hhvm/commit/a37f19dfe78e08ce3732c6250adc4b18d9db7cae)

## Future Changes

- `HH\TypeStructureKind` now exposes `OF_CLASS_PTR` and `OF_CLASS_OR_CLASSNAME`, allowing code that inspects runtime type structures to distinguish the staged `class<T>` and class-pointer migration representations. [a96b817878](https://github.com/hershel-theodore-layton/hhvm/commit/a96b81787868092c5b6a14851be9f895f83faea8)
