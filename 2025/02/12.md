# 2025-02-12

## Highlights

- Nested expression-tree literals are now accepted without enabling the old `expression_tree_nest` feature gate. [bbe9d40fce](https://github.com/hershel-theodore-layton/hhvm/commit/bbe9d40fced76ba17a695e02e2b23f6a8f06f3a2)
- The Hack language server can emit a `Fix Hack error inline` code action for diagnostics, using the `code-compose.show-inline-chat` client command and marking the action as AI-assisted. Clients that implement that command can open inline chat with the relevant function and diagnostic prefilled. [89e1b39fa9](https://github.com/hershel-theodore-layton/hhvm/commit/89e1b39fa96addb8a9fabfa5e3c07e46b7dcb12a)
- HHVM can preload units and extensions from a profile whose repository signature is stale, while still refusing to apply the stale JIT profile itself. This preserves safe startup preloading across repository changes. [62ea2d00cb](https://github.com/hershel-theodore-layton/hhvm/commit/62ea2d00cb23376a1b17330ff0bc3cae88fd8d65)

## Security

- Rust dependencies were updated to remove the vulnerable `ruzstd` versions covered by `RUSTSEC-2024-0400`, along with the affected transitive `object` versions. [94474382bc](https://github.com/hershel-theodore-layton/hhvm/commit/94474382bc72e4d5a4b9532f08fec4b6cd1e69c3)
