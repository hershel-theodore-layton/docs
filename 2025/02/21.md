# 2025-02-21

## Highlights

- Distributed typechecks now return the accumulated, already-filtered streamed diagnostics instead of replacing them with the unfiltered final set. This avoids spurious warnings when an `hh_distc` check is interrupted and resumed. [c05ef61c5c](https://github.com/hershel-theodore-layton/hhvm/commit/c05ef61c5cf48fbfceb6dfdbfdfae1ebe2fd841e)
- Hover output no longer duplicates a member signature when its receiver has a like type, and its “Defined in” information is rendered as a separate Markdown section. [1f138ef380](https://github.com/hershel-theodore-layton/hhvm/commit/1f138ef3809944c2513caca5e6d76deb088eaff6) [9afa74e115](https://github.com/hershel-theodore-layton/hhvm/commit/9afa74e11593a8ffc3facdb41b6c13aa94a189db)

## Future Changes

- With `improved_hover=true`, hovering a generic function, method, constructor, or property now shows its declaration-time signature followed by the type substitution at the use site, instead of showing only the instantiated signature. Redundant `as mixed` bounds are omitted. [2a9fdbf6c2](https://github.com/hershel-theodore-layton/hhvm/commit/2a9fdbf6c22cb9655ce4d0b93740778d75d7a4ab)
