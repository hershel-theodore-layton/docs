# 2025-02-24

## Highlights

- `CURLOPT_USERPWD` and `CURLOPT_PROXYUSERPWD` now accept `null`, matching libcurl's way to disable credentials that were configured earlier on the same handle. [dae2facf38](https://github.com/hershel-theodore-layton/hhvm/commit/dae2facf389dc7cdd375d505c6247ba9d6f28ae5)

## Future Changes

- The ongoing `no_disjoint_union` rollout adds `<<__NoDisjointUnion>>` for type parameters. A call or construction now warns when Hack infers a union whose members are pairwise disjoint for an annotated parameter—typically exposing a comparison or helper call that combines unrelated types such as `int` and `string`. [f4e7a9f6f6](https://github.com/hershel-theodore-layton/hhvm/commit/f4e7a9f6f6038a27354f388e95b6310bd2766d47)
- Nested expression-tree work now records free variables and their source positions. Without the unstable `expression_tree_nested_bindings` feature, a nested tree that captures such a variable is rejected; the recorded data prepares splices to bind it from an enclosing tree later. [056565751c](https://github.com/hershel-theodore-layton/hhvm/commit/056565751c4929fdf31680394130de15522d91e1) [886b66684f](https://github.com/hershel-theodore-layton/hhvm/commit/886b66684fb9bfbba1f892a2458ab3eee1bc7111)
- The class-pointer migration exposes `class_or_classname<T>` for APIs that temporarily accept either representation. `HH\classname_to_class()` now returns `class<T>`, while `HH\class_to_classname()` accepts the migration type and returns `classname<T>`. [6d9c06a115](https://github.com/hershel-theodore-layton/hhvm/commit/6d9c06a1154f32f8ba756876e6603a15cc8daeed)
