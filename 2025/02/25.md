# 2025-02-25

## Highlights

- Converting notebook JSON to Hack now restores newlines between source-array entries instead of concatenating every line, preventing generated notebooks from hanging later processing on malformed Hack. [c4274610d9](https://github.com/hershel-theodore-layton/hhvm/commit/c4274610d976ae61913b8ea437e8a2fc29280ef5)
- The renamed `#NotKeyedByICAndLeakIC__DO_NOT_USE` memoization option is now declared in the HHI, so the dangerous opt-out can be recognized by typechecking and autocomplete as well as by the compiler. [2b980a6b20](https://github.com/hershel-theodore-layton/hhvm/commit/2b980a6b20a4c900c070b1daad2397d2392aef08)

## Breaking Changes

- Nested expression trees are fully released and the `expression_tree_nest` experimental-feature name has been removed. Projects that still list that feature in `.hhconfig` should remove the obsolete entry. [28b67ffdf3](https://github.com/hershel-theodore-layton/hhvm/commit/28b67ffdf3042c5e7ec8d078d521f7ba66bb5e76)

## Future Changes

- The Packages v2 escape hatch `package_v2_bypass_package_check_for_class_const` has been renamed to `package_v2_bypass_package_check_for_classptr_migration`. The renamed setting now controls package-check bypasses for type constants as well as `::class`; disabling it enforces both checks. [0ed24678d6](https://github.com/hershel-theodore-layton/hhvm/commit/0ed24678d6a15f6df1707e9ac7caf9f3f2e37cc0) [28e3f58b84](https://github.com/hershel-theodore-layton/hhvm/commit/28e3f58b84c5a073b833d848831dbd9f9a38277d)
