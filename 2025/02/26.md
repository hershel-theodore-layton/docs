# 2025-02-26

## Future Changes

- The staged `class<T>` type is now rejected in `is`/`as` hints and as a reified type argument, matching the existing `classname<T>` restriction. Runtime type structures do not yet retain enough information to enforce the inner `T`; the restriction is intended to be relaxed once they do.
