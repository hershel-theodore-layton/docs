# 2025-02-28

## Highlights

- Hack LSP diagnostics now carry `data.line_agnostic_hash`, a stable error hash that does not change merely because lines moved. Editor integrations can use it to correlate the same diagnostic across edits. [37bb036ddd](https://github.com/hershel-theodore-layton/hhvm/commit/37bb036ddd9638aa9d622a95151bc8c77b6cdb3a) [93277be0de](https://github.com/hershel-theodore-layton/hhvm/commit/93277be0ded35a4b06d1917b48b3fd0389cf212c)
- `Shapes::put($shape, $key, $value)` returns a cloned shape with the field added or replaced and a correspondingly refined return type; the input shape is not mutated. [d4d1771702](https://github.com/hershel-theodore-layton/hhvm/commit/d4d1771702033182bc1fc4125e29273bcad4a80e)

## Breaking Changes

- Runtime type checking now consistently includes all generic upper bounds instead of consulting only the primary hint. Static-property writes and initialization enforce every bound, and property redeclarations must preserve equivalent primary and upper-bound constraints; code that previously violated an overlooked bound can now fail. [8ee0eb6005](https://github.com/hershel-theodore-layton/hhvm/commit/8ee0eb6005185ae58924ab21167d6675c374de58) [fd915fab11](https://github.com/hershel-theodore-layton/hhvm/commit/fd915fab110d86a1909111b3151519b27de353bb)

## Future Changes

- With `safe_abstract=true`, checks now understand unions and intersections nested inside `classname` and `concreteclassname`, report the class-name source in warning reasons, and reliably rerun after incremental declaration changes.
