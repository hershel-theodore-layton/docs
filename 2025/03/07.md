# 2025-03-07

## Highlights

- Truthiness analysis no longer strips the like-type wrapper from `~null`. This avoids false-positive “always truthy” warnings for nullable values commonly produced by operations such as `idx()` on dynamic data. [a59544983a](https://github.com/hershel-theodore-layton/hhvm/commit/a59544983a7701098d123cbd7af1f5e92d57f2b8)
- The bundled `classname<T>` documentation and IDE hover text now describe class-name strings using the `nameof C` spelling. [0a174765d9](https://github.com/hershel-theodore-layton/hhvm/commit/0a174765d92b901adfe442b16a735c84a8f8793f)

## Future Changes

- Experimental nested expression-tree bindings are now typechecked across splices: a nested expression tree may capture locals from the enclosing splice, and those captured types are tracked through control-flow joins. This requires the staged `expression_tree_nested_bindings` feature. [b1fb7f1d52](https://github.com/hershel-theodore-layton/hhvm/commit/b1fb7f1d5248921dfd8db297b1b25b9184b26f10)
- IDE hover for the staged `class<T>` type now distinguishes class pointers from `classname<T>` strings and explains the operations supported by each. [0a174765d9](https://github.com/hershel-theodore-layton/hhvm/commit/0a174765d92b901adfe442b16a735c84a8f8793f)
