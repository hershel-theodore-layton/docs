# 2025-03-10

## Future Changes

- Experimental `__NoDisjointUnion` checking now looks through nullable wrappers, so an inferred `?(A | B)` is checked like `A | B`. Warning 12017 now points separately to each disjoint member and to the annotated type parameter, instead of presenting only a flattened inferred type. The feature remains gated by `no_disjoint_union`.
