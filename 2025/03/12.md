# 2025-03-12

## Highlights

- Intersections of covariant class-name strings now simplify from `classname<U> & classname<V>` to `classname<U & V>`, improving narrowing after equality tests. [b430a5cf86](https://github.com/hershel-theodore-layton/hhvm/commit/b430a5cf86b99804e0c573d70682b2b603999fad)

## Breaking Changes

- Improved IDE hover output is now unconditional, and the `improved_hover` configuration option has been removed. Hover for a referenced function reports its declaration-shaped signature rather than only its result type. [e55c1b27ad](https://github.com/hershel-theodore-layton/hhvm/commit/e55c1b27adc9a69f5cef092b2914995a6d54cf8f)

## Future Changes

- Lambdas checked against a pre-stable polymorphic function type no longer instantiate the expected type too early. Valid implementations are accepted, while implementations that only satisfy one instantiation correctly fail subtyping. [ad85396a28](https://github.com/hershel-theodore-layton/hhvm/commit/ad85396a283ad025de04976f227440524a95151c)
- Pre-stable case-type variants are now validated under their own `where` constraints. A constraint can justify that variant's type arguments and bounds, but its assumptions do not leak into sibling variants. [6e65d7f43b](https://github.com/hershel-theodore-layton/hhvm/commit/6e65d7f43b1ebe55780f00a475f32bcb0fd9fd3f)
- Safe-abstract analysis now understands `class<T>` receivers as well as `classname<T>`, including unions and intersections. Under `safe_abstract=true`, unsafe construction, static calls, and abstract-constant access through class pointers produce the corresponding warnings. [3bd3fcbce1](https://github.com/hershel-theodore-layton/hhvm/commit/3bd3fcbce1aab8eca0219e042ea24b648c8034fa)
- A new `.hhconfig` option, `allow_class_string_cast`, controls whether `(string)$class` is accepted when `$class` has type `class<T>`. It defaults to `true`; projects preparing for stricter class-pointer separation can set it to `false`. [29b5728cd6](https://github.com/hershel-theodore-layton/hhvm/commit/29b5728cd654b74688120fde9582987308aa062e)
