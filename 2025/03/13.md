# 2025-03-13

## Future Changes

- Expression-tree DSLs can provide specially typed static `shapeAt`, `shapePut`, and `shapeIdx` methods. Inside staged expression-tree syntax, the typechecker gives these the field-reading and field-writing semantics of `Shapes::at()`, `Shapes::put()`, and `Shapes::idx()` while generated code still calls the DSL's implementation. Shape creation and expression trees must be enabled, and each DSL remains responsible for the runtime methods.
