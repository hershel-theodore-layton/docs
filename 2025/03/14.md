# 2025-03-14

## Highlights

- After a file is saved, the language server may now replace its standalone diagnostics with fresher `hh_server` diagnostics even while the file remains open. Server diagnostics are still ignored while the editor buffer has unsaved changes. [1858e721fb](https://github.com/hershel-theodore-layton/hhvm/commit/1858e721fb07a6544d034e23b993ed4441b15fd4)
- `HH\Lib\Regex\Pattern<T>` now exposes its `as string` bound in the bundled HHI, matching the typechecker's underlying declaration and allowing APIs constrained to `string` to recognize a pattern value. [e718944d9c](https://github.com/hershel-theodore-layton/hhvm/commit/e718944d9ce22289cb719c194af06ad33ada3d10)

## Future Changes

- During the staged class-pointer migration, the runtime notice for loading an unannotated class from a string now says that the class is missing `__DynamicallyReferenced`. Class resolution and module checks run before string-to-class or missing-attribute notices, so a nonexistent or inaccessible class no longer produces a misleading conversion notice first. [7546273528](https://github.com/hershel-theodore-layton/hhvm/commit/7546273528916c1515e3879db9a0aa2b3dbf9f48) [fa6aa63ebd](https://github.com/hershel-theodore-layton/hhvm/commit/fa6aa63ebd2b5f6aeaf3ec7152b011a4ecb9b8ad)
