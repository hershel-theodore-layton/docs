# 2025-03-18

## Highlights

- Async functions and methods may use `<<__AsioLowPri>>` to suspend eager execution immediately into a low-priority awaitable. Runtime option `Eval.EnableLowPriorityAwaitables` defaults to `true`; disabling it leaves the emitted bytecode in place but makes the initial suspension a no-op. [08153b56f7](https://github.com/hershel-theodore-layton/hhvm/commit/08153b56f7e05655a4324a99afd0f30ede081fbc)

## Breaking Changes

- The second argument of callbacks registered through `ResumableWaitHandle::setOnCreateCallback()` is now `?WaitableWaitHandle<mixed>`, because a newly created low-priority async wait handle has no child yet. Existing callbacks that require a non-null second argument must accept and handle `null`. The HHI method and callback types have no explicit context lists, so they retain the usual default context rather than declaring `[]`. [08153b56f7](https://github.com/hershel-theodore-layton/hhvm/commit/08153b56f7e05655a4324a99afd0f30ede081fbc)
