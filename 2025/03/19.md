# 2025-03-19

## Highlights

- Low-priority async wait handles no longer crash when scheduler cleanup examines a ready handle that does not yet have a child. [046529dc2e](https://github.com/hershel-theodore-layton/hhvm/commit/046529dc2ecd2d9dc2d7dbdebd198d2cc845688e)

## Breaking Changes

- Non-null refinement now intersects a type with `nonnull` instead of rewriting the concrete bounds of abstract types. This closes an unsoundness affecting nullsafe calls, shape access, truthiness checks, and related refinements; code that previously smuggled nullable or `mixed` members into a non-null return type may now fail typechecking. [f4b5b94a09](https://github.com/hershel-theodore-layton/hhvm/commit/f4b5b94a0952d5a5e0fc8cd8fb0b6a9e93f4a82a)
