# 2025-03-20

## Highlights

- IDE and CLI file-change handling now invalidates folded declarations through the in-memory dependency graph, including descendants reached through inheritance edges. This precise behavior is always enabled, reducing stale errors after editing a parent class without invalidating every folded declaration. [53cb992bd3](https://github.com/hershel-theodore-layton/hhvm/commit/53cb992bd3d0de322df0cb165168679c38b436a6)
- `HH\asio_get_current_context_depth(): int` returns the current scheduler-context nesting depth, or zero outside a scheduler context, and supersedes `HH\asio_get_current_context_idx()`. The declaration has no explicit context list, so it uses the default context rather than `[]`. [d3b7081039](https://github.com/hershel-theodore-layton/hhvm/commit/d3b708103904aeff3cd8cc99a50fa85f90f9c138)
