# 2025-03-25

## Future Changes

- The staged `polymorphic_function_hints` feature adds denotable generic function types such as `(function<T as C>(T): T)`. Hint-local type parameters may have upper and lower bounds and parameterless attributes, but may not be variant, reified, higher-kinded, shadow an enclosing type parameter, or use attributes with arguments. Existing polymorphic subtyping rules apply; the change adds syntax rather than a new subtyping relation.
