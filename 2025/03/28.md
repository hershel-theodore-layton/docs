# 2025-03-28

## Highlights

- `HH\mangle_unit_sha1(string $sha1 = '', string $ext = '.php', ?string $repo = null): string` and the convenience wrapper `HH\unit_schema(?string $repo = null): string` are now available to Hack. Both declarations omit an explicit context list and therefore use the default context. [2bb86e7bf2](https://github.com/hershel-theodore-layton/hhvm/commit/2bb86e7bf2eca07af8484806fd7412ff50c99811)

## Future Changes

- Experimental expression-tree splices now evaluate eagerly and pass every spliced expression through the DSL's static `lift()` method before checking it as `Spliceable`. Nested-binding splices use the ordinary `splice()` visitor method with captured variable names as an optional fourth argument; the short-lived `macroSplice()` and `asyncMacroSplice()` protocol is no longer used. A capability-free DSL implementation can declare a helper such as `public static function lift<T>(DslExpression<T> $x)[]: DslExpression<T>`. [f0b3d5104b](https://github.com/hershel-theodore-layton/hhvm/commit/f0b3d5104bf05d8635bae75ae72676e52d9d5df4)
- Preview `__SimpliHack` IDE code actions are gated by the corrected feature name `simpli_hack`. The attribute may take a prompt string directly instead of a promptlet class pointer; clients must still implement the generated inline-chat command. [33e4701f2e](https://github.com/hershel-theodore-layton/hhvm/commit/33e4701f2ea693d3accc3599541122d4d2a5a633) [c6d59c6834](https://github.com/hershel-theodore-layton/hhvm/commit/c6d59c68341e9a5387e2452665d7b3763c4034c6)
- Class-pointer subtyping now clears stale `this` and like-type state while simplifying covariant `class<T>` propositions, avoiding spurious unsimplified unions and downstream diagnostics under sound dynamic. [733c16a23c](https://github.com/hershel-theodore-layton/hhvm/commit/733c16a23cf5bd1c70dd65da7e4b80cc2f1b652a)
