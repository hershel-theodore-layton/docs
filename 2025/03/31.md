# 2025-03-31

## Highlights

- Exceptions while reading the package specification now log a warning and fall back to an empty specification. A missing default `PACKAGES.toml` still falls back silently; a missing explicitly renamed package file now logs a warning instead of an error. Reported parsing and configuration errors are still logged as errors. [01d32e26ad](https://github.com/hershel-theodore-layton/hhvm/commit/01d32e26ad08265f4d918e435301fedde3890edc)

## Breaking Changes

- The HHVM repository compiler has removed `--repo-options-dir`. It now reads `.hhvmconfig.hdf` and `PACKAGES.toml` relative to `--input-dir`, so build scripts that kept source input and repository options in different roots must align or stage those files first. [cbff84ff23](https://github.com/hershel-theodore-layton/hhvm/commit/cbff84ff23bbbadc2dc48a9d7c8d9f6c998d7a35)
