# 2025-04-02

## Highlights

- Constructor arguments are typechecked even when resolving the constructed class yields only `dynamic`, so errors inside those arguments are no longer missed. [b650999cb7](https://github.com/hershel-theodore-layton/hhvm/commit/b650999cb76758366b9f71ac6f7da6c6af56e1c1)
- Changes to enum members now correctly fan out to files whose `switch` exhaustivity depends on that enum. [4a25a14787](https://github.com/hershel-theodore-layton/hhvm/commit/4a25a14787a48814e2a7a5633af92558defecf00)
