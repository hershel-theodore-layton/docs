# 2025-04-04

## Highlights

- Plain `<<__Memoize>>` functions with contexts such as `[leak_safe]` are no longer rejected merely because memoize-policy configuration is enabled. The parser now applies or requires `#KeyedByIC` only when the function's context can actually access implicit context. [a278d85633](https://github.com/hershel-theodore-layton/hhvm/commit/a278d85633f2b36bef3a35ea1b3f76f3857c5356) [6d7717e2e1](https://github.com/hershel-theodore-layton/hhvm/commit/6d7717e2e1c70bbde544d42c4a41a80fd50aaf8c)

## Future Changes

- The staged `__NeedsConcrete` checker now enforces that calls to marked methods have a concrete late-static receiver, while permitting abstract-member access through `static` inside a `__NeedsConcrete` method. [8230cf15b4](https://github.com/hershel-theodore-layton/hhvm/commit/8230cf15b4a951a3fab1213003a91fa6b1d9f272)
- Reflection type-structure kinds now include `OF_UNION` and `OF_RECURSIVE_UNION` for case types. [0ab406eaf4](https://github.com/hershel-theodore-layton/hhvm/commit/0ab406eaf4dfc4c95a02a3c53129532570b7797e)
