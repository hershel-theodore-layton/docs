# 2025-04-07

## Breaking Changes

- Strict `switch` exhaustivity checking is now the default. Switches over types the checker cannot prove finite, such as `int` or `dynamic`, require a `default`; duplicate cases are errors, while redundant defaults on exhaustive finite switches are warnings. [ab72191e86](https://github.com/hershel-theodore-layton/hhvm/commit/ab72191e86ca059de97d8c49bba5f92bc8045eaf)

## Future Changes

- `__SimpliHack` now accepts nonliteral arguments, and its interpreter can evaluate method calls and top-level function calls used to construct a prompt.
