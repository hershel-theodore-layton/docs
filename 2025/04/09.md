# 2025-04-09

## Breaking Changes

- `C::class` is now typed as `class<C>` rather than `classname<C>` by default. Code that stores class constants as strings must convert explicitly with `HH\class_to_classname`. [6afb873297](https://github.com/hershel-theodore-layton/hhvm/commit/6afb87329763b3a2afeba45632ae96e5b36a3515)
- `ReflectionParameter::$info` is now private, and the undeclared `ReflectionParameter::$paramTypeInfo` field has been removed. Use the public reflection methods instead of inspecting these implementation fields dynamically. [2b92c03aec](https://github.com/hershel-theodore-layton/hhvm/commit/2b92c03aecd0f5665da7cad6b21bce23d04e6739)

## Future Changes

- Hack code can now name the case-type reflection kinds `TypeStructureKind::OF_UNION` and `TypeStructureKind::OF_RECURSIVE_UNION`. [e620c21119](https://github.com/hershel-theodore-layton/hhvm/commit/e620c21119be5e4536204a8b8cabdc6e2a14b4d3)
