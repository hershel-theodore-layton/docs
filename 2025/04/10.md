# 2025-04-10

## Highlights

- The compact Thrift helpers `thrift_protocol_write_compact_struct_to_string` and `thrift_protocol_read_compact_struct_from_string` are now declared in the HHI, along with more precise `void` return types for several existing write helpers. [6532008ee1](https://github.com/hershel-theodore-layton/hhvm/commit/6532008ee163ac63b4ad471f357cad649fa15dea)
- `asio_get_current_context_depth` is now autoimported and can be called without the `HH\` prefix. [1c46f2565e](https://github.com/hershel-theodore-layton/hhvm/commit/1c46f2565e6e6530cca3938b37eb12a48bd053df)

## Future Changes

- The direct-declaration parser no longer crashes on type splats in tuple bounds such as `TExtra as (int, ...T)`. [ae8c68cd2b](https://github.com/hershel-theodore-layton/hhvm/commit/ae8c68cd2b770d7d2b6402ea29f8c476686d1639)
- Case-type refinement now carries variant `where` constraints into both true and false branches, including the final branch of an exhaustive chain of type tests. [aadc7f921c](https://github.com/hershel-theodore-layton/hhvm/commit/aadc7f921c2d6221f4cc3ee21e400942ddb2db35)
