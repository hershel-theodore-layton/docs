# 2025-04-11

## Highlights

- Constructing a value through a like-typed generic classname now preserves the generic type instead of falling back to `dynamic`, restoring useful return-type errors at the call site. [a19c19574d](https://github.com/hershel-theodore-layton/hhvm/commit/a19c19574ddd9eb6c24ffb68938d02498cd3c3f6)

## Breaking Changes

- The legacy switch checker and the `new_exhaustivity_check` configuration option have been removed. Strict switch exhaustivity can no longer be disabled through `.hhconfig`. [434b2af668](https://github.com/hershel-theodore-layton/hhvm/commit/434b2af66803059e6b986b16c72ad8f84ed7d4a1)
