# 2025-04-16

## Highlights

- HSL's OS exception dispatch now stores exception class pointers in `vec`s instead of `keyset`s, eliminating the implicit string-to-class notices caused by invoking methods on the converted classname strings when an OS operation throws. [a0698adb2a](https://github.com/hershel-theodore-layton/hhvm/commit/a0698adb2aee2fa88c74fbf12d2346cff95c071e)

## Breaking Changes

- The runtime implementation of reflection's `getAttributeClass` now expects a `class<mixed>` and performs its own explicit classname conversion, beginning the migration away from accepting classname strings. [7a0f146cd3](https://github.com/hershel-theodore-layton/hhvm/commit/7a0f146cd3d36ef4bdb7ccf43df6dd7b5e19801f)
