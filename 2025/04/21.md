# 2025-04-21

## Highlights

- `<<__Reifiable>>` abstract type constants are no longer rejected because their `as` or `super` bounds contain non-reifiable types; only the constant's default or concrete value is relevant. [ef204df70b](https://github.com/hershel-theodore-layton/hhvm/commit/ef204df70baf3f861007c36446876baab4e128cb)
- `HH\IPureMemoizeParam` provides a pure `getInstanceKey()[]`, and the new `MemoAgnosticImplicitContext` and `MemoSensitiveImplicitContext` base classes separate the two implicit-context behaviors. Their `runWith` methods require the context capability plus the callback's capability through `[this::CRun, ctx $f]`. [a45c285415](https://github.com/hershel-theodore-layton/hhvm/commit/a45c2854159bc0ed652f5ea16f96dab7b0462c74) [13fa7c975b](https://github.com/hershel-theodore-layton/hhvm/commit/13fa7c975be8e88527b6baa7badc9d17e5e8730b)

## Future Changes

- The unstable class-pointer API adds `HH\get_class_from_object`, `HH\get_parent_class_from_class`, and `HH\ReifiedGenerics\get_class_from_type`. [048e19045c](https://github.com/hershel-theodore-layton/hhvm/commit/048e19045ccb25dff4463bf6a7ec89597d57acbe)
- SimpliHack promptlets can use `HH\SimpliHack\file()` to read a file relative to the `.hhconfig` root. The callee requires the new `HH\SimpliHack` context; its `as [write_props]` bound means that context requires at least `write_props`, rather than granting property-write access to a caller. [76ebbfc28a](https://github.com/hershel-theodore-layton/hhvm/commit/76ebbfc28a665d3a5bb564c4b332bbd83d3575ce)
