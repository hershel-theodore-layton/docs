# 2025-04-22

## Highlights

- Async functions marked `<<__AsioLowPri>>` now run through a separate scheduler queue. Regular runnable awaitables are drained before low-priority work, while awaiting a child still lifts it into its parent's context. [8b9ebdb953](https://github.com/hershel-theodore-layton/hhvm/commit/8b9ebdb9533cfb7c360970f4d918beaa9c93510e)
- Repeated IDE find-references requests no longer return progressively fewer class-member references as result files become open in the client. [db5c895462](https://github.com/hershel-theodore-layton/hhvm/commit/db5c89546220f122198518da2475ad8e80a2cdc3)
- Native `<<__OutOnly>>` parameters now expose their actual output type in the normal `inout` type position, and HHVM no longer enforces that type against the ignored incoming value. [794f98a7f4](https://github.com/hershel-theodore-layton/hhvm/commit/794f98a7f4453d366861a25724b2c8a2e7318574) [3644d5ed99](https://github.com/hershel-theodore-layton/hhvm/commit/3644d5ed99652d735f265e551669b60c814780d3) [be95fc5529](https://github.com/hershel-theodore-layton/hhvm/commit/be95fc5529311cc777bce41cc3c984e24b5df518) [f4024e274f](https://github.com/hershel-theodore-layton/hhvm/commit/f4024e274f8e38fc02ec4893c2a53176840e8090)

## Future Changes

- Packages v2 no longer checks the right-hand side of `where` constraints for package access, matching symbol-reference build behavior. [c28fd84875](https://github.com/hershel-theodore-layton/hhvm/commit/c28fd84875eefc5b1cf557ac7702e1f0055ff9ea)
