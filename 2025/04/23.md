# 2025-04-23

## Highlights

- `ReflectionFunctionAbstract::getParamTypeVarNames()` returns the type-variable names used by a function or method's parameter hints. [98684268f3](https://github.com/hershel-theodore-layton/hhvm/commit/98684268f39763e85f4582011b2f6558720b17ba)
- The new implicit-context base classes' private context constructors now require `[leak_safe]` rather than implicit `[defaults]`. This weakens their caller requirement, so they can be called from the base class's leak-safe context. [724940306c](https://github.com/hershel-theodore-layton/hhvm/commit/724940306c76df5f0516e596098281745056d69f)

## Breaking Changes

- Reflection `getAttributeClass` methods now accept `class<T>` rather than `classname<T>` in the public HHI. Pass `MyAttribute::class`, not a classname string. [59ef42483e](https://github.com/hershel-theodore-layton/hhvm/commit/59ef42483e221e0f463f63c67e4cf66b485f99ac)
- `HH\dynamic_class_meth` and `HH\dynamic_class_meth_force` now accept class pointers directly; passing a string remains supported through `class_or_classname` but raises an implicit string-to-class notice. [3ab00621de](https://github.com/hershel-theodore-layton/hhvm/commit/3ab00621de5bfb3436802f1f7cfb12d4f25571e5)
