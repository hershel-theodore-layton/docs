# 2025-04-28

## Highlights

- String interpolation with more than two pieces now uses `ConcatN` operations for groups of up to four pieces, reducing generated bytecode. Larger interpolations may emit multiple concatenation operations. [e52b893890](https://github.com/hershel-theodore-layton/hhvm/commit/e52b893890bed64aa7c402be1b0a8e142464431e)
- `BuiltinEnum::coerce()` now converts class inputs to classname strings consistently instead of returning a class value through a declared `?arraykey` result, fixing a crash and disabling the invalid JIT fast path. [bdfd541010](https://github.com/hershel-theodore-layton/hhvm/commit/bdfd541010fb36659fe432343ed43354263cafa9)

## Future Changes

- Type-constant definitions now reject references to type parameters declared by nested polymorphic function hints, because those parameters and their bounds cannot be represented in runtime type structures. [af7eae2a87](https://github.com/hershel-theodore-layton/hhvm/commit/af7eae2a876c1955a6c43d1e5c038b063c979d2b)
