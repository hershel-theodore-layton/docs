# 2025-05-01

## Highlights

- HHVM's CLI client now initializes Folly's singleton registry before extension shutdown, preventing exit-time failures when CLI code or an extension touches a Folly singleton. [6c837a0c48](https://github.com/hershel-theodore-layton/hhvm/commit/6c837a0c48f0f3d9c6b5756e0bc60939ede3a45e)
- Runtime-type predicates now retain the type arguments of fully reified generic classes. This gives `is` refinements and case-type overlap checks enough precision to distinguish, for example, `Box<int>` from `Box<string>` while still detecting equivalent aliases. [f148bd3843](https://github.com/hershel-theodore-layton/hhvm/commit/f148bd384303e2fc7a32e5c738e23e2629eecbd0)
