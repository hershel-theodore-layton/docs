# 2025-05-02

## Highlights

- `debug_backtrace()` and `HH\Asio\backtrace()` accept the new `DEBUG_BACKTRACE_ONLY_METADATA_FRAMES` option, which returns only frames carrying metadata from `HH\set_frame_metadata()`. This avoids collecting file and line data for frames an observability pipeline would discard.
