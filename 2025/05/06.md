# 2025-05-06

## Highlights

- Visibility errors for a `protected` or `private` override of an `internal` member now report the actual narrowing mismatch instead of incorrectly saying that the parent member is inaccessible from its own module. [78719d189d](https://github.com/hershel-theodore-layton/hhvm/commit/78719d189d6cceb3f86cb3251a727e86f01b19dc)

## Breaking Changes

- `HH\TypeStructure<T>` now models `return_type` and `param_types` as optional fields, matching the runtime values. Code that reads either field directly must first test for it or use `??` or `Shapes::idx()`.
