# 2025-05-09

## Breaking Changes

- `HH\TypeStructure<T>` now models `value`, `typevars`, and `alias` as optional fields. Direct indexing that assumed those keys were always present must move to an optional-shape access. [4bd21c5ee9](https://github.com/hershel-theodore-layton/hhvm/commit/4bd21c5ee9cf8d19080a37c10bfb12e533ddd713)

## Future Changes

- The checker now rejects `<<__Memoize>>` and `<<__MemoizeLSB>>` on functions whose parameter list uses the unstable type-splat syntax. Such declarations cannot currently produce a valid memoization wrapper. [c86642dbcc](https://github.com/hershel-theodore-layton/hhvm/commit/c86642dbcc966ff617146fa26a7dbf900a3319a8)
