# 2025-05-14

## Highlights

- Missing reified type-argument errors now point back to the reified type parameter that requires the argument, rather than blaming the enclosing function type or call expression. [d575a67512](https://github.com/hershel-theodore-layton/hhvm/commit/d575a6751250db57b4a90ba1d21992cd0f76af5c)

## Future Changes

- The `class_overrides_all_trait_methods` linter no longer treats a trait's `require this as` constraint like `require class`, eliminating a false warning for valid trait composition. [b8c45182ee](https://github.com/hershel-theodore-layton/hhvm/commit/b8c45182ee3a0757e8755e2bd053aeb8a3f18d6f)
