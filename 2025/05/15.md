# 2025-05-15

## Highlights

- LSP document-symbol ranges for functions and classes now begin on the declaration name instead of on preceding attributes, so IDE sticky-scroll headers show the symbol users are navigating. [535d3fdec2](https://github.com/hershel-theodore-layton/hhvm/commit/535d3fdec260a55787cce4133a72ac57b85407b1)

## Breaking Changes

- `class_parents()` and `class_implements()` now return class-pointer values instead of class-name strings. The result keys remain class names; code that needs string values should convert the class pointers explicitly. [db1c9385fc](https://github.com/hershel-theodore-layton/hhvm/commit/db1c9385fc08c6432316a632b82746d2aea7bdb2)

## Future Changes

- Experimental checked unsafe casts have moved from the compile-time `Hack.Lang.CheckedUnsafeCast` option to the runtime `Eval.CheckedUnsafeCast` option. HackC now always emits the check instruction and HHVM decides whether to enforce it, so deployments testing the feature must rename their configuration. [93a6c2ac23](https://github.com/hershel-theodore-layton/hhvm/commit/93a6c2ac23fbbfe2dbe3cdd2284f959cfd59620c)
- An early `edenfs_file_watcher_enabled` mode can initialize an EdenFS watcher, but notifications still delegate to Watchman and the implementation is explicitly not production-ready. [4ca8b78848](https://github.com/hershel-theodore-layton/hhvm/commit/4ca8b78848d77ffe38fad0f19a8868295dab91e9) [6abf46d85d](https://github.com/hershel-theodore-layton/hhvm/commit/6abf46d85d2197b719b135f8a5543b94762e5248) [6e0807fb23](https://github.com/hershel-theodore-layton/hhvm/commit/6e0807fb23a02c3467efa77086dd201d831942ed)
