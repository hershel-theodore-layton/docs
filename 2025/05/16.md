## Breaking Changes

- Truncated input passed to the compact Thrift `from_string` path now throws `TTransportException` with `END_OF_FILE`, matching `TProtocol`, instead of falling through to a generic `TProtocolException`. Exception handlers that matched only the old type may need updating. [28143ead08](https://github.com/hershel-theodore-layton/hhvm/commit/28143ead080b789d0ca70a1e7704bc3207659528)
