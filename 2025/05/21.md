# 2025-05-21

## Highlights

- `HH\PriorityBridgeWaitHandle` can wrap an awaitable so its child continues at lower priority instead of being promoted by the waiting context, and `prioritize()` can later lift it. `create()` requires `[]`; the initial HHI for `prioritize()` omits a bracket list, so callers initially need the implicit `[defaults]` capability. [ab939a7f4a](https://github.com/hershel-theodore-layton/hhvm/commit/ab939a7f4a3311a4f74fcf7bf69df0e0a7dad5fd) [287b567685](https://github.com/hershel-theodore-layton/hhvm/commit/287b567685d73c5a5edd5406753c59a52480c66c)
- The `class_overrides_all_trait_methods` linter now ignores abstract trait methods that exist to carry user-defined semantic attributes, while continuing to report genuinely dead overrides. [4794a8c906](https://github.com/hershel-theodore-layton/hhvm/commit/4794a8c90639a7830a2bc6162e29c110dd6ac4bd)
- `HH\dynamic_class_meth()` and `HH\dynamic_meth_caller()` now accept `class_or_classname<mixed>` instead of only `string`, adding class-pointer arguments without rejecting existing classname strings. [9da64160bd](https://github.com/hershel-theodore-layton/hhvm/commit/9da64160bdb2b09b01a15f8e69156eec63c9d8d3)

## Breaking Changes

- `HH\meth_caller()` now requires `class<mixed>` rather than `classname<mixed>`. Pass a class pointer such as `C::class`; classname strings and variables no longer satisfy the public signature. [880710ad0c](https://github.com/hershel-theodore-layton/hhvm/commit/880710ad0c06629ac4cf05ec77254d1400434eaa)

## Future Changes

- Nested expression-tree lowering now orders captured free variables deterministically, preventing run-to-run changes in generated lambda parameters and bytecode while the nested-binding implementation evolves. [359704caf9](https://github.com/hershel-theodore-layton/hhvm/commit/359704caf914be1dcaf483d6d428343f505e209f)
