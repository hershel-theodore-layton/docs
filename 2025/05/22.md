# 2025-05-22

## Highlights

- Calling `PriorityBridgeWaitHandle::prioritize()` after the wrapped wait handle has already finished is now a no-op instead of crashing. [dd5cdaf7a4](https://github.com/hershel-theodore-layton/hhvm/commit/dd5cdaf7a4c5c99321b030e3c34cf6f62223b577)

## Future Changes

- Class-pointer diagnostics for dynamic static calls now include the type's definition site, and the unstable `HH\ReifiedGenerics\get_class_from_type()` intrinsic accepts abstract type constants without `<<__Reifiable>>` because it consumes their type structure rather than preserving a reification witness. [497d071296](https://github.com/hershel-theodore-layton/hhvm/commit/497d0712966b384377b9c8cc154ad011dd197e06) [b2082d530e](https://github.com/hershel-theodore-layton/hhvm/commit/b2082d530e04ccf763cd30265ae7ebe62bd93ff6)
- The unstable polymorphic-lambda feature now supports both `function<T>(T $x): T ==> $x` and generic legacy anonymous functions. Parameters and returns must be explicitly typed, and reified, variant, higher-kinded, and shadowing type parameters remain disallowed. [bb4279c923](https://github.com/hershel-theodore-layton/hhvm/commit/bb4279c923ec6cc9eab19a42c0d269e78ed8bb47) [3e1031ad4c](https://github.com/hershel-theodore-layton/hhvm/commit/3e1031ad4c4009cbba551444fadc7c049ceb20a9)
