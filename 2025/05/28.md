# 2025-05-28

## Breaking Changes

- HHVM now rejects `$class::$method()` at runtime as well as in the checker. Code generated or executed without `hh_server` validation must also migrate to a static call or `HH\dynamic_class_meth()`. [a51e712dc0](https://github.com/hershel-theodore-layton/hhvm/commit/a51e712dc0756e0e9d054fcb789504a14e103d3a)
- HHVM also rejects computed static-method forms such as `C::{expr}()`, completing the runtime removal of dynamic static-call syntax. [7a9777a8a7](https://github.com/hershel-theodore-layton/hhvm/commit/7a9777a8a721cb9facde684f5a44a2042b89dfc6)
- `iterator_to_array()` has been removed from both the HHI and HHVM. Replace it with `dict($iterator)` when preserving keys or `vec($iterator)` when collecting values. [1187cf3a01](https://github.com/hershel-theodore-layton/hhvm/commit/1187cf3a01a3a8f5e034362b8bf0e47b161f6925)
