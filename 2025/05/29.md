# 2025-05-29

## Highlights

- `hh --help` now documents `--error-format extended`, making extended type-error reasons discoverable without consulting source or wrapper scripts. [6275ca880a](https://github.com/hershel-theodore-layton/hhvm/commit/6275ca880a2b776c051f4b1e9e7669b125cfc2c4)

## Breaking Changes

- Global constants declared under a nonexistent module now receive the same `Unbound name` error already applied to other top-level declarations. [351328f8b9](https://github.com/hershel-theodore-layton/hhvm/commit/351328f8b9d63829c573e420267ac394d9d13d0b)

## Future Changes

- Hackfmt now preserves the required `function` keyword on unstable polymorphic lambdas, and lambda well-formedness reuses top-level function binding so parameter types can refer to the lambda's own type parameters. [817ea043fe](https://github.com/hershel-theodore-layton/hhvm/commit/817ea043fead078084eeca0cd0ab151c69a1006b) [09e22a92af](https://github.com/hershel-theodore-layton/hhvm/commit/09e22a92af5a8f2caf3f490f670b5ea6de4d5270)
