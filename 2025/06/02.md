# 2025-06-02

## Highlights

- Streaming `hh` checks now pass a configured `watchman_sockname` to both `watch-project` and the Watchman client, avoiding a split where the server and client observe different Watchman instances. [45d6473b90](https://github.com/hershel-theodore-layton/hhvm/commit/45d6473b909aa958d08d96833d24cea21b1595ac)

## Breaking Changes

- `type_structure($class_name, ...)` now participates in implicit string-to-class conversion notices when its class argument is a string. Class pointers, lazy classes, and objects do not raise this notice. Projects using `Eval.RaiseClassConversionNoticeSampleRate` can use the signal to find classes that need `<<__DynamicallyReferenced>>` or callers that should pass a class pointer. [b028e13e25](https://github.com/hershel-theodore-layton/hhvm/commit/b028e13e25c98949252417a0168f3d776d5709cd)

## Future Changes

- Preview type-splat declarations no longer confuse a type-splat parameter with a variadic capture during runtime method-override checks. After `T` is instantiated as `(int, string)`, a method with parameters `(int, string)` can implement one declared with `...T`; ordinary return-type, coeffect, and parameter checks still apply. [23b2e8bd5e](https://github.com/hershel-theodore-layton/hhvm/commit/23b2e8bd5e8fe85021ca3b5027ccb0df5789424b)
