# 2025-06-04

## Breaking Changes

- The legacy resource-backed representation of enum-class labels and the `Eval.EmitNativeEnumClassLabels=false` configuration have been removed; labels are now always native values. Public coeffects are unchanged: `nameOf()` remains `[]`, while `valueOf()` remains `[write_props]`. [ff50cab0ba](https://github.com/hershel-theodore-layton/hhvm/commit/ff50cab0ba8a8b344ebf304cb42e74bc45b20758)

## Future Changes

- Under the unstable `no_disjoint_union` feature, fixpoint class refinements such as `this::TNext` bounded by `I with { type TNext = this::TNext }` now retain their dependent projected type instead of collapsing to `TAny`. [ac0e6a103f](https://github.com/hershel-theodore-layton/hhvm/commit/ac0e6a103f5c279ead5bf365dc46a41882132b38)
