# 2025-06-07

## Breaking Changes

- Reifying the late-static-bound `this` type is now permitted only when its lexical class is final and has no type parameters. A final `C<T>` can no longer hide a non-reified `T` inside a reified type constant through `this`; the typechecker reports Typing[4305].
