# 2025-06-10

## Highlights

- Distributed `hh` checks avoid repeatedly merging large streamed error sets and instead filter the final result. This substantially reduces completion time on warning-heavy repositories. [708f72be89](https://github.com/hershel-theodore-layton/hhvm/commit/708f72be896848c1c91e1bdd2762bd18afa759e0)
- Legacy non-Hack notebook cells no longer lose their first character during conversion back from Hack. Wrapper removal now recognizes the complete comment form rather than blindly trimming the cell. [be786e4c21](https://github.com/hershel-theodore-layton/hhvm/commit/be786e4c21ed751bd6dc3998707ac34974403b39)
- A new `print_debug_display(mixed $value, bool $ret = false): mixed` built-in formats values with the debugger serializer and honors objects' `__toDebugDisplay()` methods. It has no explicit capability list and therefore uses the default capability set. [3ff25b1dfc](https://github.com/hershel-theodore-layton/hhvm/commit/3ff25b1dfcef854c7455374140b7ebe60221d933)

## Breaking Changes

- The JSON-valued `.hhconfig` setting `class_pointer_levels` has been replaced by six default-false booleans: `class_pointer_ban_classname_new`, `class_pointer_ban_classname_type_structure`, `class_pointer_ban_classname_static_prop`, `class_pointer_ban_classname_static_meth`, `class_pointer_ban_classname_class_const`, and `class_pointer_ban_class_array_key`. Literal `C::class` values in string or array-key positions are now errors rather than configurable warnings; use `nameof C` or `HH\class_to_classname()` when a name is intended. [af60977aab](https://github.com/hershel-theodore-layton/hhvm/commit/af60977aab1b0069ffc67f424146d78c9f0d80f7)

## Future Changes

- Expression-tree operation typing now passes the left or unary operand through `Dsl::operationType()` before dispatching operator and implicit-boolean methods. This lets a DSL map virtual values such as `null` onto an object that defines the operation. DSLs using the unstable feature must add the static method; a pure identity implementation should declare `[]` so it does not add a caller capability requirement. [77f1b1105e](https://github.com/hershel-theodore-layton/hhvm/commit/77f1b1105e08b135a1664be6130124928559ae7d)
- With unstable case-type where clauses, a direct or indirect reference from a case type's own where clause is now rejected with Typing[4485]. The invalid clause is excluded from checking to prevent infinite recursion in constraint solving and subtyping. [f696b2fb30](https://github.com/hershel-theodore-layton/hhvm/commit/f696b2fb3070a0c992c5618974416ae83d71c3f2)
