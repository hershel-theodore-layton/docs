# 2025-06-11

## Highlights

- `HH\Lib\Async\LowPri<void>` now works: `run()` no longer assumes that the awaited result is nonnull. Its capability remains `[ctx $action, write_props]`, so callers still need the action's capabilities plus property-write access. [12fc967b7d](https://github.com/hershel-theodore-layton/hhvm/commit/12fc967b7d0593f33985b5d4615633fccc4fcfc8)

## Future Changes

- Preview SimpliHack expressions can request a class's constructor, instance and static methods, or instance and static fields through `HH\SimpliHack\constructor()`, `methods()`, `static_methods()`, `fields()`, and `static_fields()`. Each takes `classname<mixed>`, returns `string`, and requires the `[HH\SimpliHack]` capability. [277597ae53](https://github.com/hershel-theodore-layton/hhvm/commit/277597ae535ef5f00b18e7196ae9ee2ebe790a28)
