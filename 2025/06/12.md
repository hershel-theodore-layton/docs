# 2025-06-12

## Highlights

- XHP attributes declared as `class<C>` now compile and receive the same runtime attribute validation treatment as `classname<C>` attributes. This emitter fix does not introduce a new general subtype relationship between the two types. [72056a5eef](https://github.com/hershel-theodore-layton/hhvm/commit/72056a5eefca43743f2428e9bb04c2c7c8d5a288)
- `hphpd -m notebook` adds a continuation-free notebook mode in which each evaluation streams its output, allowing multiline commands without debugger continuation prompts leaking into notebook output. [cbd1d4510d](https://github.com/hershel-theodore-layton/hhvm/commit/cbd1d4510de195a91b4f272f09f85596163561c9)
