# 2025-06-20

## Highlights

- Direct static method calls on a trait now produce Warn[12020]. Call the method through a using class, or use `self::`/`static::` inside the trait, to avoid accessing the trait's separate runtime state. [b3cc106aee](https://github.com/hershel-theodore-layton/hhvm/commit/b3cc106aee871393bc3878e3be6b09e1911f04f7)

## Breaking Changes

- `HH\Facts\subtypes()`, `transitive_subtypes()`, and `supertypes()` now return class-pointer values instead of bare strings, avoiding dynamic class loads when their results are used as classes. All three functions retain `[]`; code that stores, concatenates, or serializes the returned values as strings must convert them deliberately. [4b4b297617](https://github.com/hershel-theodore-layton/hhvm/commit/4b4b297617993aa34525431494b19547952ef85a)

## Future Changes

- Within an unstable polymorphic lambda's body, wildcard hints are now allowed in refinements such as `$x is A<_>`. Wildcards remain forbidden in the lambda's parameter and return types, including nested lambda signatures. [7c45cf525e](https://github.com/hershel-theodore-layton/hhvm/commit/7c45cf525ea1212eed31754773299a086536c4ba)
