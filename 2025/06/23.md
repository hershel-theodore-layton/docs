# 2025-06-23

## Highlights

- Package-boundary checking no longer reports violations for an enum or enum-class base type or constraint type, matching the fact that those hints do not create symbol-reference dependencies. [d238628006](https://github.com/hershel-theodore-layton/hhvm/commit/d238628006f6acf4b8f7c85a403b3ff40925b200)

## Breaking Changes

- Direct static property access through a trait name is now rejected with Typing[4497]. A trait and each class that uses it have distinct static storage, so access the property through the using class or through `self::`/`static::` as appropriate. [4efd0792f2](https://github.com/hershel-theodore-layton/hhvm/commit/4efd0792f27ed27a428765894848524b9758d0dc)
