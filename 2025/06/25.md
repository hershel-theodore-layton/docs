# 2025-06-25

## Highlights

- Notebook-to-Hack conversion no longer generates an empty async entry-point function when the notebook has no top-level statements. [9a43d12c8d](https://github.com/hershel-theodore-layton/hhvm/commit/9a43d12c8da50334def5f98819e50cb27f4d7d11)
- Development builds of HHVM no longer abort during process shutdown after asynchronous writes through HSL's standard file descriptors. Descriptor sweeping is now a no-op because request shutdown already closes the underlying built-in files. [f32e4281d8](https://github.com/hershel-theodore-layton/hhvm/commit/f32e4281d804f55bca2ff4f877b92c7914529626)

## Breaking Changes

- The HHI signatures for `HH\Facts\subtypes<T>()` and `transitive_subtypes<T>()` now return `vec<class<T>>`; `supertypes()` returns `vec<class<mixed>>`. This exposes the class-pointer runtime change to static typing while preserving subtype information and the APIs' `[]` capability lists. [d81dc7b2f9](https://github.com/hershel-theodore-layton/hhvm/commit/d81dc7b2f933a54bd61a0b518f641d8d83d35109)
