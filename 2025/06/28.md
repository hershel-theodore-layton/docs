# 2025-06-28

## Future Changes

- Under the staged polymorphic function-pointer typing, `meth_caller()` gives polymorphic instance methods a rank-2 polymorphic function type, including an implicit first parameter representing the receiver's `this` type. This prevents one use from prematurely fixing method or receiver type variables and removes false errors when the same caller is used at compatible instantiations. This typing is not yet the default.
