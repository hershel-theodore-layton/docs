# 2025-07-03

## Breaking Changes

- The legacy `apache_request_headers()` and `getallheaders()` declarations have been removed from the HHI, so typechecked Hack code can no longer call either API. The removed `getallheaders()` declaration required `[read_globals]`; this is an API removal, not a narrowing of that capability requirement. [fdbee7ee64](https://github.com/hershel-theodore-layton/hhvm/commit/fdbee7ee64093c2076e7c8f6f2f80e23a721845d)

## Future Changes

- `require this as` constraints are now emitted into HHVM metadata, and HHVM checks trait constraints while loading a class. This extends runtime support for the staged constraint syntax. [7e7567642d](https://github.com/hershel-theodore-layton/hhvm/commit/7e7567642d8ac264b78d554d26f227327e20dc08)
- Experimental `can_index` constraint solving now covers `keyset`. [3b516d94fa](https://github.com/hershel-theodore-layton/hhvm/commit/3b516d94fabca61c9d74bce7a2cb33fc6a1f70b8)
