# 2025-07-05

## Breaking Changes

- Distributed typechecking configuration now uses `hh_distc_fanout_threshold` as the lower activation threshold and replaces `hh_distc_fanout_aware_threshold` with `hh_distc_fanout_full_init_threshold`. Fanout-aware mode also requires the new default-false `enable_fanout_aware_distc` switch, so deployments using the old key must update their server-local configuration.
