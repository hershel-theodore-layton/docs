# 2025-07-07

## Highlights

- HHVM's reflection runtime adds `getTypeVarNames()[]` to `ReflectionClass` and `ReflectionFunctionAbstract`, reporting every declared type parameter rather than only parameters appearing in the callable signature. The runtime signature requires no capabilities, but the public HHI does not expose the methods until later in the month. [844b86e849](https://github.com/hershel-theodore-layton/hhvm/commit/844b86e849ae0cead2df4fbe194e70c8b5878dff)

## Future Changes

- Experimental `can_index` solving now distributes through like, union, and dynamic types and supports fixed tuples. Tuple indexes that are statically out of bounds receive a dedicated diagnostic.
