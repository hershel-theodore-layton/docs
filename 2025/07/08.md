# 2025-07-08

## Highlights

- Truthiness analysis now recognizes closures, function references, and `class<T>` values as always truthy, while `vec_or_dict` remains potentially empty. Conditions such as `if ($closure)` can consequently produce the intended always-truthy warning. [0bf71d4a41](https://github.com/hershel-theodore-layton/hhvm/commit/0bf71d4a41cccfda5e0f823cd612cd049054e2f3)

## Future Changes

- JSON serialization of staged polymorphic function types now includes their type parameters, constraints, and user attributes. [d3c29d2e3f](https://github.com/hershel-theodore-layton/hhvm/commit/d3c29d2e3fa66736ee5566369f6472e8b49c0c3b)
- Experimental `can_index` solving now supports fixed shapes and strings. [8956c8e084](https://github.com/hershel-theodore-layton/hhvm/commit/8956c8e0843d7a93325f32ececd6c0ad6d8b55a4) [4ba6db413d](https://github.com/hershel-theodore-layton/hhvm/commit/4ba6db413d806593ee5b5f5e3cdcc9497f8937a5)
