# 2025-07-10

## Breaking Changes

- `Eval.ForbidDynamicCallsToFunc` now defaults to level `2`. Dynamically calling a top-level function that lacks `<<__DynamicallyCallable>>` throws, while raw string call sites still warn; migrate ordinary calls to function pointers and use `HH\dynamic_fun()` only for deliberately opted-in dynamic targets. [77763d0b69](https://github.com/hershel-theodore-layton/hhvm/commit/77763d0b698fc381d40b8d899b19adf03164c5ed) [950e7c8257](https://github.com/hershel-theodore-layton/hhvm/commit/950e7c82575f552b39f2191a280bc69000f9680a)

## Future Changes

- The experimental EdenFS watcher can now refresh `hh_client` streaming errors from Eden's own clock instead of trusting a potentially stale errors-file clock. [d60254702c](https://github.com/hershel-theodore-layton/hhvm/commit/d60254702c3ac39a782593f61c75d8cc07a413c3)
- Experimental `can_index` solving now handles nullable indexed values and additional sound-dynamic collection flows.
