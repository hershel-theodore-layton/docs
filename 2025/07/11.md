# 2025-07-11

## Highlights

- LSP document-symbol ranges now begin at the symbol's name rather than at the start of its line, improving outline navigation and symbol selection. [0c2b5109ff](https://github.com/hershel-theodore-layton/hhvm/commit/0c2b5109ff94bf9d565039eb02b6dcbe751b9c4f)
- `ReflectionTypeConstant::getCanonicalClassname()[]` reports the class or trait that actually defines a type constant in non-repo-authoritative mode. Repo-authoritative builds flatten traits and therefore throw when that distinction cannot be recovered; the explicit `[]` adds no caller capability requirement. [db653f14e1](https://github.com/hershel-theodore-layton/hhvm/commit/db653f14e10c943b479f847f9f99ba32565de805)

## Breaking Changes

- `ReflectionFunction::invoke()` and `invokeArgs()` now throw `ReflectionException` for named top-level functions. Invocation through a reflection object remains supported for closures. [6e46037c92](https://github.com/hershel-theodore-layton/hhvm/commit/6e46037c9238b2ece68793f16c8913e94d795c5f)
- `Eval.ForbidDynamicCallsToFunc` now defaults to level `3`, so raw-string top-level function calls throw even when the target has `<<__DynamicallyCallable>>`. Use a function pointer, or resolve an explicitly dynamic target through `HH\dynamic_fun()`. [ee7d2b14b1](https://github.com/hershel-theodore-layton/hhvm/commit/ee7d2b14b12ae7a363fd260170cde75f836324f6)

## Future Changes

- Experimental `can_index` solving now supports `Map` and optional indexed values. [037d467b12](https://github.com/hershel-theodore-layton/hhvm/commit/037d467b12afb85e01b8ec3cb646ca465e231bb5) [00c9e19540](https://github.com/hershel-theodore-layton/hhvm/commit/00c9e19540e1bfea68af98d61ca9b03588a35edc)
- Expression trees now give a direct unsupported-syntax error for `is` expressions instead of cascading parse errors. [0a74f2a6a9](https://github.com/hershel-theodore-layton/hhvm/commit/0a74f2a6a979d4f91bbb43932d4bb3bad38c7d74)
