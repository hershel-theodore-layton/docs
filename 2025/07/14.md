# 2025-07-14

## Highlights

- Constructor initialization checking no longer reports a false read-before-write error when an inherited property is initialized by a child's default value. [25fc487bb9](https://github.com/hershel-theodore-layton/hhvm/commit/25fc487bb99daf5b85ab386c064396a3ae21e363)

## Breaking Changes

- Constructor analysis now checks every reachable use of `$this` instead of short-circuiting after the first control-flow result. Premature uses in loop conditions, increments, and thrown expressions can now produce initialization errors that were previously missed. [32d174351d](https://github.com/hershel-theodore-layton/hhvm/commit/32d174351de86ac15298884ba45c21966b1b5fbb)

## Future Changes

- Expression trees add staged support for the null-coalescing operator, allowing DSLs to receive and interpret `??`. [74e9a78898](https://github.com/hershel-theodore-layton/hhvm/commit/74e9a788982b88212d5c5c6930abf232a4895edc)
