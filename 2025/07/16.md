# 2025-07-16

## Highlights

- Hack now gives each built-in pseudoconstant—such as `__FILE__`, `__CLASS__`, and `__METHOD__`—a distinct bounded newtype. Existing string and integer uses remain valid, while APIs can distinguish the pseudoconstant's origin in their signatures. [4b2d2f26d9](https://github.com/hershel-theodore-layton/hhvm/commit/4b2d2f26d99b30c40fe4eb9014fd5ebf98f80684)
- Type-switch refinement now preserves the scrutinee's generic upper bound in both true and false branches, and sealed-interface knowledge is used more consistently when proving types disjoint. [57c703bbf5](https://github.com/hershel-theodore-layton/hhvm/commit/57c703bbf521e18dd54d0bdc31675cd4d1ba6d25) [e76d7a2c00](https://github.com/hershel-theodore-layton/hhvm/commit/e76d7a2c00be63e1075aa9d22de425631b2f86c1)
