# 2025-07-22

## Highlights

- Runtime `is` checks and type verification now treat `<<__Soft>>` constraints as `mixed`, matching the textual bytecode backend and preventing a soft annotation from being accidentally enforced as a hard type. [32c03fcd51](https://github.com/hershel-theodore-layton/hhvm/commit/32c03fcd51a3c7929e6eec8a2ea99410baba494a)

## Future Changes

- `Eval.CheckedUnsafeCastSampleRate` controls runtime checking of staged unsafe casts: `0` disables checks, `1` checks every cast, and larger values sample one in every N casts. [421c0f3788](https://github.com/hershel-theodore-layton/hhvm/commit/421c0f37881c3cd56bccee18ee6280055ca14527)
- Experimental `can_index` solving now handles additional `supportdyn` values and the `anyarray` supertype. [10c6c23233](https://github.com/hershel-theodore-layton/hhvm/commit/10c6c23233d214a89894a23b31b95aab9a4167e0) [797f721dc0](https://github.com/hershel-theodore-layton/hhvm/commit/797f721dc05fcc0f801699fe0f71a4ed5f2ae3dc)
