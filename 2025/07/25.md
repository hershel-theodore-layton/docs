# 2025-07-25

## Breaking Changes

- `SoapServer::addFunction()` now throws `SoapException` when passed a single function-name string. Code using string registration must move to one of the API's supported non-string registration forms or redesign the dispatch path. [eebe7d5a17](https://github.com/hershel-theodore-layton/hhvm/commit/eebe7d5a17776367afe88c9ea201947511c0ce20)

## Future Changes

- Experimental `can_index` solving now understands optional and variadic tuple elements and produces more specific tuple-index diagnostics.
