# 2025-07-29

## Highlights

- `--report-files-in-build` now works for legacy non-Packages-V2 repo builds, and build reports identify why each file was included—for example through package selection, symbol references, autoload roots, or explicit include paths. [40aa523fd5](https://github.com/hershel-theodore-layton/hhvm/commit/40aa523fd5233bc10a6c6fe0ca4b01a80a4b1394) [f4df5c5e47](https://github.com/hershel-theodore-layton/hhvm/commit/f4df5c5e477409206cb3ed70def5ff1e0fe42634)
- HHVM now defines the built-in pseudoconstant newtypes in systemlib as well as in the HHI, preventing values such as `__METHOD__` from being mistaken for class names at runtime. [49f2d63ded](https://github.com/hershel-theodore-layton/hhvm/commit/49f2d63deddfa0c4588d784bd6154b161b4977f7)
- Public-API rendering through `HH\FileDecls` now includes constructors. [d6cd4b01f2](https://github.com/hershel-theodore-layton/hhvm/commit/d6cd4b01f2848ee2fd671ea23980f029b958d56b)

## Future Changes

- Staged polymorphic function-pointer types now simplify type parameters that occur only covariantly or only contravariantly by substituting the appropriate bound. [15e374473c](https://github.com/hershel-theodore-layton/hhvm/commit/15e374473ca392632349a05eb08e637c75a1cea4)
- Case-type `where` clauses have moved to Preview on the HHVM side, but are not yet generally released. [6bebd36a39](https://github.com/hershel-theodore-layton/hhvm/commit/6bebd36a3913bb984e0a7e48e29ea873592b026b)
