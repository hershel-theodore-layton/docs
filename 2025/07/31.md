# 2025-07-31

## Highlights

- HHVM no longer attempts to load Package V1 deployment data when deployment enforcement is disabled, fixing commands such as `hphpd -h` that run without an active deployment. [90fc996b29](https://github.com/hershel-theodore-layton/hhvm/commit/90fc996b294d9f6a5f832a42bfac60bb6c6e1775)
- Hack notebooks now run the legacy debugger in server mode, enabling clients to connect to their evaluation process. [4b5791d1ba](https://github.com/hershel-theodore-layton/hhvm/commit/4b5791d1ba8934977f4acd314c1b8654a8df7b83)

## Breaking Changes

- HPHPD no longer supports creating, listing, clearing, enabling, or disabling breakpoints. Projects that still use HPHPD for debugging should migrate breakpoint workflows to the VS Code debugger. [4b5791d1ba](https://github.com/hershel-theodore-layton/hhvm/commit/4b5791d1ba8934977f4acd314c1b8654a8df7b83)
