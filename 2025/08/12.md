# 2025-08-12

## Breaking Changes

- `hphpd` no longer implements the `down`, `up`, `next`, `frame`, `step`, or `out` commands. Command-line debugging is no longer supported; the remaining tool is primarily useful as a REPL. [86676af0f4](https://github.com/hershel-theodore-layton/hhvm/commit/86676af0f47ac96c009e1fe7b2444d9de726bd17)

## Future Changes

- The opt-in warning system now reports warning 12023 when `e1 ?? e2` has a left operand known to be always null or never null. Array-subscript forms are excluded because their null behavior is intentional and common. [bd805a1455](https://github.com/hershel-theodore-layton/hhvm/commit/bd805a1455e2ba7744145502704d2f5ef6a36911)
