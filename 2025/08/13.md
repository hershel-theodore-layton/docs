# 2025-08-13

## Highlights

- The JIT now has a dedicated implementation for `HH\Lib\PseudoRandom\int()`, avoiding the pessimization associated with a generic native call while preserving its inclusive range behavior. [d51a44a881](https://github.com/hershel-theodore-layton/hhvm/commit/d51a44a881e11b165c506b52b7566bb110348a72)

## Future Changes

- Named arguments are now lowered from the concrete syntax tree into the Hack AST, continuing the pre-MVP implementation begun earlier in the week. [9063a1301e](https://github.com/hershel-theodore-layton/hhvm/commit/9063a1301e18c9b157022524750dd69fd9557181)
- The class-pointer migration adds `HH\type_structure_class($class_or_object, $type_constant)[]`, a `NoDoc` helper that loads and returns the `class<mixed>` named by a type constant. Its empty coeffect list means it can be called from capability-free contexts. [6123f3b736](https://github.com/hershel-theodore-layton/hhvm/commit/6123f3b736242ae56a0bdb0ae149d3070f62d028)
