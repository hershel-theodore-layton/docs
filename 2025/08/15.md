# 2025-08-15

## Highlights

- Dependency tracking now covers more static members, XHP checks, switch exhaustivity, constructors, and IDE member lookups. Incremental checks should miss fewer affected files, though some changes may produce larger recheck fanout. [46ce64d386](https://github.com/hershel-theodore-layton/hhvm/commit/46ce64d38659ba8855859aba69a6d8b1496e3e6f) [967773dd8a](https://github.com/hershel-theodore-layton/hhvm/commit/967773dd8a995800003c273546ceb07775731f30)

## Future Changes

- The ongoing `no_disjoint_union` rollout now applies `<<__NoDisjointUnion>>` to the key type of `HH\idx()` and `HH\idx_readonly()`. Calls that infer incompatible key types, such as a `string` key for a vector-like container, can now produce warning 12017. [c5f6c4171e](https://github.com/hershel-theodore-layton/hhvm/commit/c5f6c4171ef544335edc98fad807280d2d06638e)
- Named parameter declarations are now represented in the AST, but the named-argument feature remains pre-MVP and unavailable for general use. [98bc300a62](https://github.com/hershel-theodore-layton/hhvm/commit/98bc300a621d27f71a177b91adf35d1b2dcb403a)
