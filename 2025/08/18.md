# 2025-08-18

## Future Changes

- Under the staged module-visibility rules, a `protected internal` abstract member may now mention an internal type from its module, matching the behavior already used for private and internal members. [eee1367660](https://github.com/hershel-theodore-layton/hhvm/commit/eee1367660d262e1f3f812b430f11b44e0740296)
- Experimental polymorphic static-method pointers now retain an implicit class type parameter, so class generics are instantiated when the pointer is called rather than prematurely fixed when it is created. [7a1bd49156](https://github.com/hershel-theodore-layton/hhvm/commit/7a1bd49156ff250828fb7c64251c613b3a1540a0)
