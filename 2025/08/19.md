# 2025-08-19

## Breaking Changes

- The Rust-backed diagnostic JSON serializer now emits one top-level `severity` field per diagnostic instead of repeating it on every message and reason. Consumers of that output schema must read `"error"` or `"warning"` alongside the diagnostic's `message` array. [a27f9d7320](https://github.com/hershel-theodore-layton/hhvm/commit/a27f9d732069029dbccfbc35ea9127b73520c1ef)
- Shape-field validation now recursively unwraps nested nullable and `supportdyn` types. Accessing a field known not to exist through a nullable nested shape can therefore surface a type error that was previously missed. [1a4fa7d197](https://github.com/hershel-theodore-layton/hhvm/commit/1a4fa7d197c843f726c0424c344361d34cc2e03c)

## Future Changes

- The Hack typecheck test suite now runs with the experimental `constraint_array_index` solver enabled by default. This is rollout progress for the new indexing rules, not a change to the default project configuration yet. [4abaf39c7b](https://github.com/hershel-theodore-layton/hhvm/commit/4abaf39c7b96cfc6913a2fe177a60e863f4814ea)
