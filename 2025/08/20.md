# 2025-08-20

## Highlights

- `hphpd` has a multiline REPL mode entered with `k`; a single `.` or `?>` evaluates the block, while Ctrl-C followed by Enter aborts it. Literal blank lines in multiline strings are now preserved. [fdb1d4e54b](https://github.com/hershel-theodore-layton/hhvm/commit/fdb1d4e54b38ab457745792b29e0808a81059d57) [fbee79abfd](https://github.com/hershel-theodore-layton/hhvm/commit/fbee79abfda0a4fb54cf75f58c524b6aea14b3a8) [1439bbfbc0](https://github.com/hershel-theodore-layton/hhvm/commit/1439bbfbc0d9aa007f75f5822c9f7c36039ae69d)

## Breaking Changes

- In `hphpd`, `c` now abbreviates `constant` rather than `continue`, and the exception/continue debugging commands are no longer recognized. [fdb1d4e54b](https://github.com/hershel-theodore-layton/hhvm/commit/fdb1d4e54b38ab457745792b29e0808a81059d57)
- `SoapVar` and `SoapHeader` now declare the properties populated by the SOAP extension instead of creating them dynamically. Reflection and object dumps consequently include declared-but-unset properties as `null`. [901fa02a5b](https://github.com/hershel-theodore-layton/hhvm/commit/901fa02a5bfd0716ae83a7f09c1d871ddae7760a)
