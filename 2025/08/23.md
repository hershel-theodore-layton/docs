## Security

- Projects can set `check_packages=false` in `.hhconfig` to disable static package-boundary enforcement, including validation of package overrides and package names. Enforcement remains enabled by default for both Package v1 and Package v2. [abfbbb11b2](https://github.com/hershel-theodore-layton/hhvm/commit/abfbbb11b208c69c1ce067799bc5c55913f5e4a9)
