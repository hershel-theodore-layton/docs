# 2025-08-25

## Highlights

- The JIT can now specialize `is resource` and `is_resource()` checks, including folding the result when the input type cannot be a resource. [c423c90fed](https://github.com/hershel-theodore-layton/hhvm/commit/c423c90fedc745f4bcb16964a1bedff84a624942)
- A bad atomic compare-exchange memory order in the out-of-memory request killer has been corrected, preventing a runtime crash when HHVM attempts to terminate memory-heavy requests. [a18050d29e](https://github.com/hershel-theodore-layton/hhvm/commit/a18050d29e2b1762954dae952dd8f87e64c7ab09)
