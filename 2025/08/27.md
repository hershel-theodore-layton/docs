# 2025-08-27

## Highlights

- More class inheritance checks now register the declarations they consult, reducing another source of incremental typechecking results that differ from clean checks. [b1bc7e8c74](https://github.com/hershel-theodore-layton/hhvm/commit/b1bc7e8c748186e820ba97bad559b9057dec3f90)
- Type errors involving an instantiated generic now point at the type application in user code rather than the generic's declaration. [e313daa0c5](https://github.com/hershel-theodore-layton/hhvm/commit/e313daa0c50d89e2ea90fc7ad8b5a1727e116f0f)
- Thrift's `TClientBufferedStream` adds `disable16KBBufferingPolicy()`, allowing clients with roughly 16 KiB chunks to avoid sending a credit after every payload. The new method has the ordinary `[defaults]` capability requirement. [f2b84c2d04](https://github.com/hershel-theodore-layton/hhvm/commit/f2b84c2d04e6177ca07bf9877796de6b3287f206)

## Breaking Changes

- Hack now reports the existing “generic parameter cannot be used in the type of a static property” error when that property comes from a trait, including a trait declared in another file. Code that relied on the previously missed case will need a non-generic static-property type. [ef55469df9](https://github.com/hershel-theodore-layton/hhvm/commit/ef55469df98eaca05aeb93e7867bf929655b2663)
