# 2025-08-27

## Highlights

- Constructor property-initialization checks now register the class and property declarations they consult, reducing another source of incremental typechecking results that differ from clean checks. [b1bc7e8c74](https://github.com/hershel-theodore-layton/hhvm/commit/b1bc7e8c748186e820ba97bad559b9057dec3f90)
- Type errors involving an instantiated generic now point at the type application in user code rather than the generic's declaration. [e313daa0c5](https://github.com/hershel-theodore-layton/hhvm/commit/e313daa0c50d89e2ea90fc7ad8b5a1727e116f0f)
- Thrift's `TClientBufferedStream` adds `disable16KBBufferingPolicy()`, allowing clients with roughly 16 KiB chunks to avoid sending a credit after every payload. The new method has the ordinary `[defaults]` capability requirement. [f2b84c2d04](https://github.com/hershel-theodore-layton/hhvm/commit/f2b84c2d04e6177ca07bf9877796de6b3287f206)
