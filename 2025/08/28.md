# 2025-08-28

## Future Changes

- The experimental `constraint_array_index_assign` option now routes indexed updates through the new `can_index_assign` constraint path. The solver is still a rejecting stub in this commit; container support arrives later. [0d4289debc](https://github.com/hershel-theodore-layton/hhvm/commit/0d4289debc41600c3cc3150a9812c5106f3158f7)
- Case-type subtyping no longer eagerly creates a disjunction when the subtype is an unresolved type variable or union. This avoids premature choices and improves inference for the experimental case-type implementation. [3ad3b0f3fc](https://github.com/hershel-theodore-layton/hhvm/commit/3ad3b0f3fcd4237075461f66a21506695760d34b)
