# 2025-08-29

## Highlights

- `await` now looks through `supportdyn`, so `supportdyn<Awaitable<T>>`, `Awaitable<supportdyn<T>>`, and dynamically typed awaitables work under sound-dynamic and implicit-pessimization modes. [a4b3e14491](https://github.com/hershel-theodore-layton/hhvm/commit/a4b3e14491daddfc626fb7480a2fffe2a7f8c49c)
- Hack's built-in declarations now expose `SimpleXMLElement::isTruthy()[]` and `HH\legacy_is_truthy(mixed)[]` for code that must preserve legacy boolean-coercion behavior explicitly. Both require no capabilities, so they remain callable from `[]` contexts. [98e73e75fe](https://github.com/hershel-theodore-layton/hhvm/commit/98e73e75fe3058a4af807aa1b6ac57ed19e84281) [298dae45eb](https://github.com/hershel-theodore-layton/hhvm/commit/298dae45eb7d706994bd53de363334d2e4c51435)

## Breaking Changes

- The Hack symbol indexer now skips files that are 5 MiB or larger, and also skips files whose size cannot be read. Typechecking is unaffected, but symbol-index consumers will not receive definitions or references from those files. [60a17f4a0e](https://github.com/hershel-theodore-layton/hhvm/commit/60a17f4a0e6cd35be62dea0c886edc8673f104b5)

## Future Changes

- Under Package v2, `HH\get_all_packages()` now includes each package's `soft_includes` alongside `includes` and `include_paths`. [2fea51f549](https://github.com/hershel-theodore-layton/hhvm/commit/2fea51f549f4955f0437bbf57f8f17469f404f2e)
