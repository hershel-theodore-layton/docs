# 2025-08-31

## Future Changes

- Nested expression-tree metadata now carries a `lexically_enclosing_tree` source range; the outermost tree records `null`. DSLs can use this to relate a nested tree to the tree that lexically contains it. [478fe4801a](https://github.com/hershel-theodore-layton/hhvm/commit/478fe4801ac3b1365569b6722a051915474dbb2d)
- The experimental `can_index_assign` solver now handles vector and keyed containers, generic types, unions, unresolved type variables, shapes, and fixed tuples. This broadens the kinds of nested updates that can be checked through `constraint_array_index_assign`.
