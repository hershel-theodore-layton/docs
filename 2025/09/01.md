# 2025-09-01

## Breaking Changes

- Objprof now visits each reachable object or array value only once per root, preventing exponentially slow heap scans when a value is reachable through many paths. As a consequence, `objprof_get_paths()` reports one representative path rather than attempting to enumerate every path to the same value.
