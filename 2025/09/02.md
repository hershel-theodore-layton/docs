# 2025-09-02

## Highlights

- A reified generic marked `<<__Newable>>` may now make a static call such as `T::f()` even when the method is abstract on `T`'s upper bound. Newability proves that the runtime class is concrete; the called method's ordinary parameter, return, and coeffect checks still apply. [fe174ae69f](https://github.com/hershel-theodore-layton/hhvm/commit/fe174ae69f1ed8418d5b3811b0f763eb5133f88a)
- `CUSTOM_ERRORS.json` rules can now match missing-member errors by static versus instance access, member kind, class name, member name, and visibility. This covers methods, properties, class constants, and type constants. [b7d5fc5c01](https://github.com/hershel-theodore-layton/hhvm/commit/b7d5fc5c010ae49ec2d1732501c2f1e83533c8fc)

## Future Changes

- Packages v2's unstable `<<__RequirePackage('foo')>>` attribute is now enforced at runtime when an active deployment is configured. Entering an annotated function or method fatals if the required package is not deployed; without an active deployment, the check is not enforced. [d19f80681a](https://github.com/hershel-theodore-layton/hhvm/commit/d19f80681a9db111169aaa9dda33d6537ed91fc4)
- A `PACKAGES.toml` include path may belong to only one package. Duplicate `include_paths` now produce a configuration error rather than making file-to-package assignment depend on package order. [1dec51cc16](https://github.com/hershel-theodore-layton/hhvm/commit/1dec51cc163873454ee0034b91dc731c97fec785)
