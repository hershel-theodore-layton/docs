# 2025-09-03

## Breaking Changes

- Constraint-based array-index inference is now enabled by default through `constraint_array_index=true`. This improves inference when the container or key is generic, but can change accepted programs and diagnostics—for example, some specialized index errors become ordinary Typing[4110] subtype errors. Projects can temporarily set the option to `false` while migrating. [cb6c796386](https://github.com/hershel-theodore-layton/hhvm/commit/cb6c79638611e151bd70a52dc776a7ec022134ca)
