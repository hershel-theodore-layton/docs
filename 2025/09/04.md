# 2025-09-04

## Breaking Changes

- The optional `HH\ExtDeclSignature` shape field `'cross_package'` has been renamed to `'require_package'`, reflecting the replacement of `<<__CrossPackage>>` with `<<__RequirePackage>>`. Tools consuming the ExtDecl API must read the new field name. [5b56df5697](https://github.com/hershel-theodore-layton/hhvm/commit/5b56df569703bd766440a52c78fc4cc0b19829e3)
