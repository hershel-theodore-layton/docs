# 2025-09-05

## Highlights

- Facts/autoload configuration now supports the Eden-compatible `Autoload.IncludePaths`, `Autoload.ExcludePaths`, and `Autoload.FileExtensions` lists, plus `Autoload.UseEden`. When the path and extension lists are present, HHVM also derives an equivalent Watchman query for backward compatibility; these lists take precedence over `Autoload.Query`. [f71b97f6d9](https://github.com/hershel-theodore-layton/hhvm/commit/f71b97f6d9a145ad01b65c9887c35e717a3457fd)

## Security

- Hack's `tracing-subscriber` dependency has been updated from 0.3.19 to 0.3.20, escaping ANSI control characters in logged untrusted input and addressing RUSTSEC-2025-0055. [59180f0c9a](https://github.com/hershel-theodore-layton/hhvm/commit/59180f0c9a24bdb44b4acf7cbdae07293e81c78b)
