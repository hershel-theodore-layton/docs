# 2025-09-09

## Highlights

- HEIF and AVIF decoding through the GD extension now reports whether a requested read position is available, beyond end-of-file, or failed, while restoring the stream cursor after checking. This fixes decoding behavior needed by newer libheif releases. [98c14764fe](https://github.com/hershel-theodore-layton/hhvm/commit/98c14764febcd54214b5664b613809c24a936a12)

## Breaking Changes

- Legacy dynamic typing has been removed. The `.hhconfig` option `enable_sound_dynamic_type` no longer exists, and Hack now always uses sound-dynamic coercion, subtyping, and TAST generation. [0eb895abd4](https://github.com/hershel-theodore-layton/hhvm/commit/0eb895abd4264c65057ac57409ea57b8d25f9bd9)

## Future Changes

- Opt-in `constraint_array_index_assign` inference now understands writes through `dynamic` containers and string offsets, extending the constraint-based read path to more indexed assignments. The option remains disabled by default. [2aaede9d97](https://github.com/hershel-theodore-layton/hhvm/commit/2aaede9d97bc27e8af3afabf7d6c42600a791ee9) [bae68aa2ae](https://github.com/hershel-theodore-layton/hhvm/commit/bae68aa2ae0a9da55b9c24d176add478b3a01467)
- Experimental `<<__Const>>` may no longer annotate an entire class, interface, trait, or enum. The staged const-object work is narrowing to explicitly const properties instead of implicitly making every property const. [ee81f08f04](https://github.com/hershel-theodore-layton/hhvm/commit/ee81f08f047504f53e9a64d244d7f9d85889ee87)
