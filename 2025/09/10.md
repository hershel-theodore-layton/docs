# 2025-09-10

## Highlights

- Packages v2 is now Hack and HHVM's only package model and no longer requires an unstable-feature opt-in. `<<__RequirePackage>>` is the released attribute for declaring a function or method's package requirement. [4ed554f36f](https://github.com/hershel-theodore-layton/hhvm/commit/4ed554f36f4fafb904892682148db903dfea6b54)

## Breaking Changes

- Packages v1 and `<<__CrossPackage>>` have been removed. The `Eval.PackageV2`, `Eval.EnforceDeployment`, and `.hhconfig` `package_v2` switches are gone, and migration options formerly prefixed `package_v2_` have been renamed to `package_` equivalents, such as `package_exclude_patterns`. [4ed554f36f](https://github.com/hershel-theodore-layton/hhvm/commit/4ed554f36f4fafb904892682148db903dfea6b54)
- `hh_server` no longer verifies by default that every `PACKAGES.toml` include path exists on the local filesystem. Malformed paths and paths assigned to multiple packages remain configuration errors. [1b6a11ff14](https://github.com/hershel-theodore-layton/hhvm/commit/1b6a11ff14073fd3d83ec74ee2d93acf4fc2049e)
