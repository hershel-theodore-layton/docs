# 2025-09-15

## Breaking Changes

- HHVM now raises a runtime notice when a non-async method overrides an async parent method, even if the overriding method returns an `Awaitable`. This is a notice rather than the hard rejection that was previously backed out, but it may affect logs and user error handlers.
