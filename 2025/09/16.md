# 2025-09-16

## Highlights

- Redundant and impossible `is`/`as` analysis no longer produces false positives from wildcard tests or unsolved constrained types. Nullable `?as` assertions now receive the same always-succeeds or always-fails warnings as ordinary `as` assertions. [9374196892](https://github.com/hershel-theodore-layton/hhvm/commit/937419689224169e4c0244a288864b2d6de91379) [0b4c942af5](https://github.com/hershel-theodore-layton/hhvm/commit/0b4c942af5287382b4cbba1a7596aecdfc9b013c)
- `meth_caller()` no longer wraps references to methods without `__SupportDynamicType` in `supportdyn`. The resulting callable now reflects the method's actual dynamic support while retaining its declared parameter, return, and coeffect information. [3788c4ad24](https://github.com/hershel-theodore-layton/hhvm/commit/3788c4ad242d3fa8e07902b83a8cdc1a45a165da)
- `hphpd` print-expression commands now permit assignments, so expressions such as `= $value = compute()` can update a debugger variable and display the result in one command. [6b677a3e2c](https://github.com/hershel-theodore-layton/hhvm/commit/6b677a3e2cedbb9508432d30de4f34e11101d0ab)
