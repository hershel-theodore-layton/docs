# 2025-09-18

## Highlights

- `PHP\pack()` and `PHP\unpack()` now support `g`/`G` for little-/big-endian floats and `e`/`E` for little-/big-endian doubles, matching the formats added in PHP 7.2. [f855f97526](https://github.com/hershel-theodore-layton/hhvm/commit/f855f97526945a6550334e91ff9b5f0c03d9c83f)

## Future Changes

- Under staged `poly_function_pointers`, a static method pointer no longer quantifies over an unused class-level generic, even when that generic is reified. For example, a static method that does not mention `Wibble<reify T>`'s `T` can produce an ordinary `HH\FunctionRef<(readonly function(): TResult)>`; its declared coeffect bracket is preserved. [dd7e7c2480](https://github.com/hershel-theodore-layton/hhvm/commit/dd7e7c248034b160f66cf39e5ac447c723a314cc)
- Experimental recursive case types now report Typing[4498] instead of the general cyclic-alias Typing[4014]. Update targeted suppressions or diagnostic tooling that distinguishes these errors by code. [655c4925aa](https://github.com/hershel-theodore-layton/hhvm/commit/655c4925aa3ff5b80e52e52332dc041fb1395434)
