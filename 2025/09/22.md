# 2025-09-22

## Highlights

- `hh --tast-holes` now preserves like types in its JSON rendering of actual and expected types, giving unsafe-cast codemods the precision needed to retain sound-dynamic boundaries. [01c2d1d968](https://github.com/hershel-theodore-layton/hhvm/commit/01c2d1d968cb842ae0c3cdc80e7225d07de159e0)
- A parameter declared as `dynamic` now remains `dynamic` inside the function even when its default expression has a narrower like type. Defaults no longer cause false downstream errors when that parameter is passed to other dynamic-aware code. [f3a9352a5a](https://github.com/hershel-theodore-layton/hhvm/commit/f3a9352a5a182ab6508449eb3a82d280cdf9af84)
- Sound-dynamic subtyping can now push like types through contravariant positions nested beneath invariant types. Valid relationships such as `Box<Contra<~int>> <: ~Box<Contra<int>>` no longer fail because like-pushing happened at the wrong variance. [b90d86fd9a](https://github.com/hershel-theodore-layton/hhvm/commit/b90d86fd9aafcf37ce164cbd9e0a350258b25055)
