# 2025-09-25

## Highlights

- GADT-style `is` refinements now preserve class type-constant refinements while learning constraints on an enclosing generic. Checks such as `$x is IChild<_>` can refine both an inherited generic and `with { type T = ... }` information without producing false errors. [3ce3fe0a57](https://github.com/hershel-theodore-layton/hhvm/commit/3ce3fe0a577e7ffe6aad82478bcfbdad001bcb42)

## Future Changes

- Increment and decrement operations on an experimental `<<__Const>>` property now produce Typing[4196], matching direct assignment. The check currently applies at a mutating helper method's declaration; moving it to calls made outside construction is follow-up work. [8adb7b6e42](https://github.com/hershel-theodore-layton/hhvm/commit/8adb7b6e42aca8f8cb5b28d06f90a68951ceb98a)
