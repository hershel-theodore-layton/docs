# 2025-09-29

## Highlights

- Sound-dynamic inference now carries `supportdyn` through indexed container element types and through intersections whose type variables have dynamic-supporting upper bounds. This removes false errors around generic array access and constraints such as `CanTraverse`. [6dbec9f7df](https://github.com/hershel-theodore-layton/hhvm/commit/6dbec9f7dfde195d0996616c58778e7d047e0dfa) [679954de6d](https://github.com/hershel-theodore-layton/hhvm/commit/679954de6da217f3ca4679ed01f9756206cdf80f)
- With checked unsafe casts disabled, `HH\FIXME\UNSAFE_CAST<TFrom, TTo>(await $value)` now goes through the same await-lifting path as a bare `await $value`. Unsafe-cast unwrapping happens during AST elaboration, avoiding bytecode differences caused by a later compiler pass. [9e9c5e8ba1](https://github.com/hershel-theodore-layton/hhvm/commit/9e9c5e8ba1d8b2ed662840efa9154ea03fa791c3)
- The new per-type autoload ordering correctly handles re-entry from a user error handler while loading a unit, preventing the handler's own class loads from observing a paused autoloader. [24a6049013](https://github.com/hershel-theodore-layton/hhvm/commit/24a60490138094ed75f03cdf4be6a657820208fd)

## Future Changes

- Experimental expression trees can reference enum members and named class constants directly, desugaring them through the DSL's new `visitClassConstant()` hook instead of requiring `${...}` splices. Dynamic class names remain unsupported; the hook's declared coeffects participate in normal caller-superset checking and are not implicitly granted. [1ad2b8920b](https://github.com/hershel-theodore-layton/hhvm/commit/1ad2b8920b36d58a1b3fbe01240e6ea3c4072982)
- Opt-in `constraint_method_call=true` uses function-type parameter contravariance to infer simple instance calls, including previously underconstrained lambda parameters. The path currently excludes explicit type arguments and unpacked arguments and synthesizes a `[defaults]` callable target; callers must therefore provide the default capability set, even if the concrete method is purer. Diagnostics now point to the missing method or mismatched argument rather than the whole call. [75142ebf79](https://github.com/hershel-theodore-layton/hhvm/commit/75142ebf79ee6dc1360812f28ddff7a529d7ff3b) [eab5021b17](https://github.com/hershel-theodore-layton/hhvm/commit/eab5021b17f727475d51dfde51674d3731b6507f)
