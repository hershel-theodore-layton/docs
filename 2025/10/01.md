# 2025-10-01

## Highlights

- The required-shape-field lint no longer recommends direct indexing when the shape itself is optional. Calls such as `Shapes::idx($optional_shape, 'field')` no longer receive a false Lint[5005]. [65985eea5e](https://github.com/hershel-theodore-layton/hhvm/commit/65985eea5e36650e38f5c209beb992bd3f4ae953)
- `enum<T>` hints now validate the enum's base type instead of treating `T` as a class name. Valid generic enum hints no longer receive Typing[4148], while incompatible enum bases receive the ordinary subtype error. [2e533742f9](https://github.com/hershel-theodore-layton/hhvm/commit/2e533742f9e909215ec9a205bc40df49b9a51fed)

## Future Changes

- Under the preview readonly feature, HHVM's runtime declaration of `HH\legacy_is_truthy()` now accepts `readonly mixed`, allowing readonly values to be inspected without a cast. Its explicit `[]` capability list is unchanged, so callers still need no ambient capabilities; the public HHI follows on October 20. [3df24d5bf5](https://github.com/hershel-theodore-layton/hhvm/commit/3df24d5bf5ffa5b202a6b967d78a09f72ec75ffa)
- Nested experimental expression trees no longer have a separate `expression_tree_nested_bindings` gate. They may capture bindings from an outer expression tree once expression trees themselves are enabled. [5b90e946d6](https://github.com/hershel-theodore-layton/hhvm/commit/5b90e946d63737cde09053cc7b9764f84f5bee7e)
