# 2025-10-06

## Highlights

- Sound-dynamic typing for integer operations is more precise. Binary `&`, `|`, and `^` return `~int` only when both operands may hide strings; `%`, `<<`, and `>>` accept like/dynamic integer operands but return `int`; unary `~` over a like/dynamic integer returns `~int`. Invalid operands now receive Typing[4110]. - `Eval.WarnOnBitwiseOpInvalidType` provides a migration path away from runtime bitwise operations on strings. The default `0` preserves them, `1` raises a warning, and `2` raises an error. [0d19dfbb13](https://github.com/hershel-theodore-layton/hhvm/commit/0d19dfbb1330bded2b1ed6b792031ff060c84f8d)

## Future Changes

- Unstable named parameters are now parsed in lambdas and function-type hints, compared by name during function subtyping, and supported after one splatted argument. Diagnostics distinguish missing `named` markers and multiple splats, with quickfixes and narrower source positions.
