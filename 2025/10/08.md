# 2025-10-08

## Highlights

- `CUSTOM_ERRORS.json` rules can now match `Module_cross_package_access` by the use, declaration, module, and package files and by the current and target module/package names. File patterns support path segments, filename/extension matching, wildcards, and captures. [9243b11d8a](https://github.com/hershel-theodore-layton/hhvm/commit/9243b11d8ac554384d608ab5d113d95a0d7e159f)
- Bad array-index diagnostics now point at the index expression, and Lint[5654] flags `?->` when the receiver is statically exactly `null`. [9b6a914f00](https://github.com/hershel-theodore-layton/hhvm/commit/9b6a914f005778ff3d085f21b76f6a4c584536d2) [a9a26055e5](https://github.com/hershel-theodore-layton/hhvm/commit/a9a26055e59620f9578f64fb18176b117acc6101)
- HackC unit-compilation exceptions crossing the Rust/C++ boundary are now rendered as meaningful emitter errors instead of opaque bridge-class failures. [c776cb5c3a](https://github.com/hershel-theodore-layton/hhvm/commit/c776cb5c3a5d46458753010405cca6fd3ee90216)
- Thrift streaming now credits a request when response payload memory is freed on its I/O thread, reducing false per-request out-of-memory failures. Credit is applied when control next returns to the request thread, so several in-flight payloads must still fit within the limit. [6f2c4027de](https://github.com/hershel-theodore-layton/hhvm/commit/6f2c4027dea2196ea374eafbac3282346f085b59)

## Breaking Changes

- The `.hhconfig` option `disallow_invalid_arraykey` has been removed. Hack has enforced this behavior unconditionally for years, so removing the stale setting does not relax invalid array-key checks, but project configuration must stop declaring it. [642bb4521d](https://github.com/hershel-theodore-layton/hhvm/commit/642bb4521d066512649eb088fa5ed13ba1896022)
