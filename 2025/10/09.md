# 2025-10-09

## Highlights

- `protected internal` visibility is released and no longer requires `<<file: __EnableUnstableFeatures('protected_internal')>>`. The old unstable-feature name has been removed. [3b6cd30fac](https://github.com/hershel-theodore-layton/hhvm/commit/3b6cd30facc2ce99c7fa3961e0a6bcdebaa84276)
- Compact Thrift string serialization and deserialization now rethrow Hack exception objects unchanged. User exceptions retain their original class and message instead of being wrapped as a generic Thrift error. [5ba682b8b8](https://github.com/hershel-theodore-layton/hhvm/commit/5ba682b8b8b80252952bae98bc204e47ca521b44)

## Future Changes

- Opt-in `constraint_method_call` inference now compares a method's required capabilities with the caller's actual provided capability instead of a synthesized `[defaults]`. Capability requirements are caller obligations and function capabilities are contravariant: the method may require the same or a smaller set than the caller provides, while a requirement outside that set is rejected. [ee31ebee65](https://github.com/hershel-theodore-layton/hhvm/commit/ee31ebee65b8bd3088b924f62f4a13d3644dd8c2)
- Experimental case-type disjointness now expands sealed classes as well as sealed interfaces. This admits unions such as `I | Awaitable<I>` when the sealed `Awaitable` hierarchy proves that the variants cannot overlap. [707dd89d81](https://github.com/hershel-theodore-layton/hhvm/commit/707dd89d81cf7fc62e409051ac52d072864abc0e)
