# 2025-10-20

## Future Changes

- Under the preview readonly feature, Hack's public declaration of `HH\legacy_is_truthy()` now accepts `readonly mixed`, completing the runtime change from October 1. The change widens the accepted parameter type; its `[]` capability requirement remains unchanged. [ba5dfba433](https://github.com/hershel-theodore-layton/hhvm/commit/ba5dfba433d9bdf3766559fb2d40da12c22bd1a8)
- Opt-in constraint-based method-call inference now preserves readonly receivers and arguments and a surrounding `readonly` return context. It can require a readonly method for a readonly receiver while accepting readonly parameters or returns where function subtyping permits them. [7b1fa8acc1](https://github.com/hershel-theodore-layton/hhvm/commit/7b1fa8acc1097b5b6dc801ab5dfb28fdfd52a0f7)
