# 2025-10-22

## Highlights

- New `HH\Facts\path_to_package(string)[]: ?string` returns a known file's package. A per-file package override wins; otherwise Facts chooses the package with the longest matching `include_paths` prefix. The explicit `[]` means callers need no ambient capabilities. [e1415fca71](https://github.com/hershel-theodore-layton/hhvm/commit/e1415fca7142064b980062a3f04cae684ac67b6c)
- Moving only a package override's source position no longer makes the file's declarations appear to have changed, avoiding unnecessary incremental rechecks after whitespace edits. [08cd63f125](https://github.com/hershel-theodore-layton/hhvm/commit/08cd63f125659c9f0b196043b763ee2e877f74cf)

## Future Changes

- Experimental expression trees can now lower `static::` class constants and static method calls where the corresponding late-bound reference is valid. `self::` and `parent::` remain unsupported in these forms. [f1f2029527](https://github.com/hershel-theodore-layton/hhvm/commit/f1f2029527a15166b451e9ef3129a5ff0419f604)
- The default-off `fanout_strip_class_location` rollout option treats a class moved within the same file as unchanged when comparing declaration order inputs. Moving the class to another file still triggers fanout. [08cd63f125](https://github.com/hershel-theodore-layton/hhvm/commit/08cd63f125659c9f0b196043b763ee2e877f74cf) [76b64bc6f8](https://github.com/hershel-theodore-layton/hhvm/commit/76b64bc6f8c7b0cfb44ea3683ab9adc2e6e4751b)
