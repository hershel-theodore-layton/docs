# 2025-10-23

## Highlights

- Refining a generic wildcard now retains the generic parameter's substituted bounds. Valid refinements—especially under implicit pessimization—no longer fail because an upper or lower bound disappeared during localization. [fab431c150](https://github.com/hershel-theodore-layton/hhvm/commit/fab431c1508c61aa000bd7f49b6732af30ffa291)

## Security

- Package checking now exempts top-level function-pointer expressions by default, matching SymbolRefs' behavior of not following those pointers. Set `.hhconfig` `package_allow_function_pointers_violations=false` to enforce package boundaries at these expressions. [5c26f88816](https://github.com/hershel-theodore-layton/hhvm/commit/5c26f88816c46d16362c5b4e800ef29b79361cd2)

## Future Changes

- With checked unsafe casts enabled, nested `HH\FIXME\UNSAFE_CAST()` and `UNSAFE_NONNULL_CAST()` expressions are now all traversed. Runtime checks are no longer skipped merely because one unsafe cast is nested inside another. [3fb517842f](https://github.com/hershel-theodore-layton/hhvm/commit/3fb517842fa8639b5175e8219787f3d32b6dbff2)
