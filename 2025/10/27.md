# 2025-10-27

## Highlights

- New auto-imported `objprof_get_data_with_graph_stats()`, `objprof_get_data_extended_with_graph_stats()`, and `objprof_get_paths_with_graph_stats()` can bound traversal with `max_depth` and `max_visits`. They return the usual object statistics plus `nodes_visited` and `max_depth_seen`; omitted capability brackets mean `[defaults]`. [b8a2b2c9d7](https://github.com/hershel-theodore-layton/hhvm/commit/b8a2b2c9d7619aad68d2352aa652ffefe9aca3e7) [5b20747174](https://github.com/hershel-theodore-layton/hhvm/commit/5b20747174b8c886f0ac0260a92d0870fd88ff88) [6663dc9b4e](https://github.com/hershel-theodore-layton/hhvm/commit/6663dc9b4e2fdd8f9d2e4b7b4afb222dc8c82fe7)
- `CUSTOM_ERRORS.json` can now match `Cross_pkg_access` and `Cross_pkg_access_with_requirepackage` by use and declaration file. Missing-member class patterns are also namespace-aware, so top-level names no longer require a leading backslash in a plain string pattern. [bc740ac7e2](https://github.com/hershel-theodore-layton/hhvm/commit/bc740ac7e2875a82723ecf3f00e81ac71e077032) [5b894225af](https://github.com/hershel-theodore-layton/hhvm/commit/5b894225af3259ff91226789d92505c161706ee1)

## Future Changes

- A generic Watcher runtime abstraction has landed as explicit work in progress toward Watchman and Eden backends. It currently has no typechecker HHI, supports only Watchman, and does not yet return its specified output format, so projects should not adopt it yet.
