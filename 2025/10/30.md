# 2025-10-30

## Highlights

- Default-parameter initializer bytecode now uses the parameter's source location. Runtime type errors point to the parameter declaration rather than the function's closing brace, and default-value funclets are excluded from executable-line and coverage results. [3e366bf718](https://github.com/hershel-theodore-layton/hhvm/commit/3e366bf718fd47a6cda35d1e8130cf4de4500e57)

## Breaking Changes

- `Eval.EnableCodeCoveragePerBytecode` now defaults to `true`, so coverage and `HH\get_executable_lines()` count only bytecodes representing meaningful actions such as calls, branches, assignments, and returns. Reports may contain fewer executable or covered lines; set it to `false` temporarily for the legacy all-bytecode behavior. [23b107df3e](https://github.com/hershel-theodore-layton/hhvm/commit/23b107df3e8278753415bcc4a8d6a9ccda156e57)

## Future Changes

- Experimental expression trees no longer support XHP syntax. DSLs using staged expression trees must splice or otherwise construct XHP outside the tree. [576aa124fa](https://github.com/hershel-theodore-layton/hhvm/commit/576aa124fac6fd71b079d60a4b2f3ad3e4fc1303)
