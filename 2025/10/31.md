# 2025-10-31

## Highlights

- Implicit pessimization is more precise for single-parameter functions with enforced return types and for non-overridable methods: top-level functions, non-trait private methods, final methods, and methods in final classes. They accept a like/dynamic argument while retaining the exact enforced return type instead of unnecessarily returning a like type. Custom messages render Markdown styling in terminal and LSP output, and a malformed class name now makes a rule fail to match instead of crashing evaluation.
