# 2025-11-05

## Highlights

- Higher-rank type-parameter escape diagnostics now lead with "Expected a first-class polymorphic function type" and explain which generic would escape its scope. The diagnostic still asks for an explicit type annotation. [801396cf42](https://github.com/hershel-theodore-layton/hhvm/commit/801396cf42716db1f51169ba275368b9b4771a1f)

## Breaking Changes

- `DOMElement::getAttribute()` is now declared to return `string` instead of an untyped result, matching its runtime behavior. Code that null-checks the result or relies on implicit conversion from it may now produce type errors. [bc373ee080](https://github.com/hershel-theodore-layton/hhvm/commit/bc373ee080cade0d9ca4958793c2314e8632c541)

## Future Changes

- Expression trees now accept late-static-bound method calls and class constants written with `static::`; `self::`, `parent::`, and dynamically selected classes remain unsupported. Expression trees are still an ongoing-release feature. [5699d743ec](https://github.com/hershel-theodore-layton/hhvm/commit/5699d743ec357cda64e0de16ed66f78772b468ad)
