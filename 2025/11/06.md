# 2025-11-06

## Highlights

- Custom-error file patterns now support a `**` globstar suffix, which matches zero or more path segments after a fixed prefix, and optional path segments. This makes a single custom-error rule usable across nested or partially optional directory layouts. [de62e41f78](https://github.com/hershel-theodore-layton/hhvm/commit/de62e41f780b67c18c7db38dedceec797dc0f464)
- `get_executable_lines()` no longer repeatedly replaces its line-table cache while walking bytecode offsets, fixing a potentially large per-request memory leak. [80fec6c413](https://github.com/hershel-theodore-layton/hhvm/commit/80fec6c41398aa7dfb3f3492157795e743083df4)
