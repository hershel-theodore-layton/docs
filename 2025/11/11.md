# 2025-11-11

## Highlights

- Function pointers to `<<__Native>>` functions using `<<__TrivialHHVMBuiltinWrapper>>` now resolve to the wrapper's target in the interpreter, matching ordinary calls and JIT execution. [594c8fb627](https://github.com/hershel-theodore-layton/hhvm/commit/594c8fb6276d447b216e6ee3aff31e772c43241e)
- The Hack client adds `hh --log-errors`, an asynchronous mode that type-checks a supplied file list and logs its diagnostics after returning immediately. `--log-to-file PATH` writes those diagnostics to a file, and the mode honors the usual error and warning filters. [78608b1f95](https://github.com/hershel-theodore-layton/hhvm/commit/78608b1f95658e48c2543d1a1a1aafebbe20860b)
