# 2025-11-12

## Security

- Package boundary checks now cover global constants. Accessing a constant from another package without a permitted dependency produces Typing[4472], closing a gap in package access enforcement. [fcd7b5c771](https://github.com/hershel-theodore-layton/hhvm/commit/fcd7b5c7716076d1ff776947a54d5fdc99bfaa6f)

## Breaking Changes

- `hh --package-lint FILE` now uses naming and dependency tables instead of fully type-checking reference files. Its JSON output changes from per-definition reference records to a simple array of absolute paths for files that may be affected by moving the input file. [648d385bc7](https://github.com/hershel-theodore-layton/hhvm/commit/648d385bc7336f016eb974ed02e7954d60a2d9fa)

## Future Changes

- The ongoing-release `sealed_methods` feature adds method-level `<<__Sealed(...)>>`. Its allowlist restricts which classes or traits may directly override a method; constructors, private methods, and interface methods cannot use the attribute. [83a0b8478c](https://github.com/hershel-theodore-layton/hhvm/commit/83a0b8478c1b29679492af43b9587e958bbce66f)
- The new unstable `xhp_type_constants` feature permits type constants such as `A::T` and `this::TData` in XHP attribute declarations. Runtime XHP metadata currently represents these attributes as `mixed`, so the feature still requires `__EnableUnstableFeatures`. [acca24cbe1](https://github.com/hershel-theodore-layton/hhvm/commit/acca24cbe13b7487c3131cdef4c272e49825bea9)
