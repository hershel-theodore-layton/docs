# 2025-11-13

## Future Changes

- Preview readonly checking now treats `$condition ?: $fallback` as readonly when the returned left-hand value or fallback is readonly. Mutating or returning the result in a mutable position can therefore reveal errors that the previous analysis missed. [b2a2b3ea0f](https://github.com/hershel-theodore-layton/hhvm/commit/b2a2b3ea0f218dbbf75e8c510e8a3ee0b825fd5f)
- Under the experimental dynamic-assumptions mode (`everything_sdt=false`), indexing an unknown field of an open shape refined from `dynamic` no longer produces a false error after `Shapes::keyExists()`. [9cef9e19bf](https://github.com/hershel-theodore-layton/hhvm/commit/9cef9e19bf41bcf4bb2eb5dd3ef5f4f9db5f003c)
