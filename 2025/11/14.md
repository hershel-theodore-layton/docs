# 2025-11-14

## Highlights

- Custom-error configuration now validates repeated bindings across all supported pattern kinds, preventing valid rules from being rejected—or incompatible bindings from being accepted—when they use newer pattern types. [44ec7ad20c](https://github.com/hershel-theodore-layton/hhvm/commit/44ec7ad20cf350491a5b598f18d8da5a2a167c9e)
- `Vec\map_with_key_async()` no longer constrains input keys to `arraykey`; it now accepts any `KeyedTraversable<Tk, Tv>`. The callback coeffect remains `[ctx $value_func]`. [171f7923fa](https://github.com/hershel-theodore-layton/hhvm/commit/171f7923facf66605a01bb4c99c73ffde179a41d)
- HHVM's unit cache now records a changed repository-options hash even when recompilation produces identical bytecode. Updating `.hhvmconfig.hdf` or `PACKAGES.toml` therefore no longer makes unchanged files recompile on every request. [506ac2d22c](https://github.com/hershel-theodore-layton/hhvm/commit/506ac2d22c268e72b72a5351c0d6373b60a6a4e5)
