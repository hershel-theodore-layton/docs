# 2025-11-18

## Breaking Changes

- `parent::__construct(...)` is now checked as an ordinary method call. This correctly supports constructors with `<<__SupportDynamicType>>`, but also reports an error when the parent class has no constructor instead of silently accepting the call. [b1f24f75dd](https://github.com/hershel-theodore-layton/hhvm/commit/b1f24f75dd93feeacaae26ac12f4d6468c52f51e)
- With an active deployment, `package foo` and `HH\package_exists('foo')` now return `false` when `foo` is only softly deployed. This also changes whether `<<__RequirePackage('foo')>>` requirements are satisfied. [32f696c3e9](https://github.com/hershel-theodore-layton/hhvm/commit/32f696c3e9a8439d9ff2e29d802312da9f927f51)
