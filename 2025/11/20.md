# 2025-11-20

## Highlights

- The debugger no longer sends a DAP `thread exited` event for a thread whose corresponding `thread started` event was never sent, keeping client thread state balanced. [9cd2be99d3](https://github.com/hershel-theodore-layton/hhvm/commit/9cd2be99d3e27d5c713aa841a648eda0940ef574)

## Security

- HHVM can now enforce `Server.RequestFanoutLimit` for recursively spawned Xbox requests. With the new `Server.EnforceRequestFanout=true` setting, exceeding the limit rolls back the counter and throws `RequestFanoutLimitExceededException`; enforcement is off by default. [a96d874cb8](https://github.com/hershel-theodore-layton/hhvm/commit/a96d874cb872ecabef24684cb79375fb812671b0)
