# 2025-11-24

## Highlights

- `<<__RequirePackage>>` on interface and abstract methods no longer makes `hackc` try to insert a runtime assertion body where no method body can exist, fixing compilation of these declarations. [7850ed7b86](https://github.com/hershel-theodore-layton/hhvm/commit/7850ed7b8631e6420e7065766fa7d31b02f7b907)

## Future Changes

- Named-argument completion snippets now keep `parameter_name=` outside the editable placeholder, so typing the value no longer deletes the parameter name. Optional parameters remain omitted from call completions. Named arguments are still unstable. [c2d246ec9d](https://github.com/hershel-theodore-layton/hhvm/commit/c2d246ec9d63a656c9c26a0036419d061acdf70a)
