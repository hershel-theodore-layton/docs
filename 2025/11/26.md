# 2025-11-26

## Highlights

- Custom-error `**` file-prefix patterns no longer swallow a failed required path segment and match an unintended file. Exact and prefix patterns now share the corrected segment matcher. [95025e2a47](https://github.com/hershel-theodore-layton/hhvm/commit/95025e2a474065721d3dfb9ceb2b82783b127964)

## Breaking Changes

- `HH\Facts\types_with_attribute()` now returns lazy-class values instead of raw strings, statically changing from `vec<string>` to `vec<classname<nonnull>>`. Its attribute parameter changes from `string` to `class_or_classname<ClassLikeAttribute>`, so callers holding an unrefined `string` may need to supply a typed class name. Type aliases remain excluded, and the function remains capability-free (`[]`). [22eba707f3](https://github.com/hershel-theodore-layton/hhvm/commit/22eba707f3e52cc3b1d2903c49e3bf15c1daf257)
