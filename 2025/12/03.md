# 2025-12-03

## Highlights

- `HH\is_any_array($value)` now refines types like `$value is HH\AnyArray<_, _>`. In particular, false branches no longer produce spurious `AnyArray` arity errors. [37cae09f34](https://github.com/hershel-theodore-layton/hhvm/commit/37cae09f341abbb7450d1c836c52a79bff02be56)
- The global, final `RequestFanoutLimitExceededException` is now declared in the bundled HHI files, so Hack code can name and catch the runtime exception without supplying a local stub. [fe93d4bbde](https://github.com/hershel-theodore-layton/hhvm/commit/fe93d4bbdede4654ab8b74a68e7fda9256c4e4ec)

## Breaking Changes

- The void-use check now looks through `supportdyn`, so consuming an expression typed as `supportdyn<void>` is rejected just like consuming `void`. This can reveal previously missed errors in sound-dynamic code. [26e025e493](https://github.com/hershel-theodore-layton/hhvm/commit/26e025e493a06ea005b8b6b5260fcb01b955879e)
