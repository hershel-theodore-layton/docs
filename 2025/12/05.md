# 2025-12-05

## Highlights

- New `<<__SoftRequirePackage('pkg', 100)>>` annotations let functions and concrete methods observe missing deployment requirements without failing the call. The package name and optional sample rate must be literals. A missing package emits a sampled notice identifying the callable; the rate defaults to `1`, while `0` suppresses logging. [233ada2c6f](https://github.com/hershel-theodore-layton/hhvm/commit/233ada2c6f651cffc0699f475bcf78e2d4b30689)

## Breaking Changes

- The HHI model of `HH\string` is now final. User classes can no longer extend the primitive's synthetic class, while types such as `classname<C>` remain meaningful subtypes of `string`. [e71a41b2ba](https://github.com/hershel-theodore-layton/hhvm/commit/e71a41b2ba76f76eae4f3fc838d2729b607f1fa5)

## Future Changes

- XHP type constants have moved to OngoingRelease. XHP attributes may use declarations such as `attribute MyClass::TMyType attr` without a file-level unstable-feature opt-in, but the feature remains pre-stable. [19d0a58e2e](https://github.com/hershel-theodore-layton/hhvm/commit/19d0a58e2e81ca3a7077204816e042626ba9ad58)
