# 2025-12-08

## Highlights

- Hack's line-break map now handles CRLF, LF, and a trailing bare CR without an off-by-one access, improving source positions in tools that consume the map. [b09e3f9d1c](https://github.com/hershel-theodore-layton/hhvm/commit/b09e3f9d1ce119ac212f546b0c09a10a696c39d0)
- Eden-backed `hh_server` file enumeration no longer discards changes that were waiting to be consumed, preventing a full-file query from making subsequent incremental checks miss an edit. [44760b5d3e](https://github.com/hershel-theodore-layton/hhvm/commit/44760b5d3e47f3e78b2b164761c99decb5e4c306)

## Future Changes

- Diagnostics for pre-stable optional function parameters now suggest marking an extra lambda parameter `optional` when a callable supplies too many mandatory positional parameters for the expected function type. This is guidance for the existing contravariant callable check; parameter variance and coeffect compatibility are unchanged. [a9f0befdc6](https://github.com/hershel-theodore-layton/hhvm/commit/a9f0befdc676009119fb729e60c9ac320d152c5c)
