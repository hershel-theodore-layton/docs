# 2025-12-09

## Highlights

- Fresh generic parameters that still occur in local-variable types are no longer discarded from the typing environment during refinement and control-flow analysis. This fixes false errors in code that refines generic predicates and then joins values from the resulting branches. [2ec0bc4566](https://github.com/hershel-theodore-layton/hhvm/commit/2ec0bc4566f9a6a67650df385f17292cdd530fd6)

## Breaking Changes

- The global `boolval()` function has been removed from Hack's HHI files and HHVM's standard extension. Replace calls with `HH\legacy_is_truthy()`, which preserves the legacy conversion behavior and, like the removed function, requires no capabilities (`[]`). [27465dc29d](https://github.com/hershel-theodore-layton/hhvm/commit/27465dc29d848867438aef9808f3ad317e1b6849)

## Future Changes

- Type-constant super bounds have moved from Unstable to Preview. The staged syntax permits lower bounds alongside `as` upper bounds on abstract type constants; it is not yet an OngoingRelease feature. [913a25ea19](https://github.com/hershel-theodore-layton/hhvm/commit/913a25ea19e9f8efff7c3d99003eabd860172959)
