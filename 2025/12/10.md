# 2025-12-10

## Highlights

- The parser now processes long `else if` chains iteratively, avoiding stack growth proportional to the number of branches while preserving the same syntax tree. [794dce91c0](https://github.com/hershel-theodore-layton/hhvm/commit/794dce91c052ba8308ae2e518d7c04ab4670d56d)
- Tools converting Hack's JSON type representation back into local types now map the primitive `string` entry to `HH\string` rather than a class literally named `string`. [0e9e24f115](https://github.com/hershel-theodore-layton/hhvm/commit/0e9e24f115e3d3c2d96c51d53f594ef90e83399d)

## Future Changes

- During the null-safe pipe's OngoingRelease phase, `await` is no longer allowed on the right-hand side of `|?>`, because that branch is conditionally executed. Await the value before the pipe or move the asynchronous operation into explicit control flow. [67afb72ad7](https://github.com/hershel-theodore-layton/hhvm/commit/67afb72ad7ae7ee90cb12d5a06b73fc85c027683)
- With the pre-stable `open_tuples` and `type_splat` features enabled, a `vec<mixed>` can now be unpacked into a function declared with `...(mixed...)` or a generic `...TArgs`. Subtyping treats the unknown-length vec as a variadic sequence rather than a single tuple slot; the callee's capability requirements still undergo the normal caller-superset check. [9dd3259bf2](https://github.com/hershel-theodore-layton/hhvm/commit/9dd3259bf2cf2e9aee0007b85d5a897b10596bc4)
