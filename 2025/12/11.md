# 2025-12-11

## Highlights

- The open-source `implicit_context.hhi` no longer seals `MemoSensitiveImplicitContext` to an internal-only subclass, preventing bundled HHI declarations from producing an impossible subclass error in OSS projects. [a455f079d5](https://github.com/hershel-theodore-layton/hhvm/commit/a455f079d5bc324514bc5740d0fafbd5aef5af9b)

## Future Changes

- Diagnostics for pre-stable optional function parameters now call out when a supplied callable accepts too few positional arguments for the expected function type. This makes the accepted-call-set mismatch clearer without changing parameter contravariance or coeffect subtyping. [65a2637417](https://github.com/hershel-theodore-layton/hhvm/commit/65a2637417307cd0498d40ce18c5ec08a717836c)
