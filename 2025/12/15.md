# 2025-12-15

## Highlights

- The Hack manual now documents package inclusion and cross-package calls in greater depth and adds a migration guide covering `__PackageOverride`, `__RequirePackage`, and the new `__SoftRequirePackage` workflow. [abb3833a49](https://github.com/hershel-theodore-layton/hhvm/commit/abb3833a4938d1dbb16db4b0b38a1ad386f704ba)

## Breaking Changes

- Null-safe pipe syntax has completed its rollout and `nullsafe_pipe` has been removed from the experimental-feature registry. The syntax remains available by default, but projects should remove stale `<<file:__EnableUnstableFeatures('nullsafe_pipe')>>` declarations. [99ff43dd3d](https://github.com/hershel-theodore-layton/hhvm/commit/99ff43dd3d471e74d4ba769d4fc628c04dfa854d)
