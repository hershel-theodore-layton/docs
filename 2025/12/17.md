# 2025-12-17

## Highlights

- A fatal caused by throwing a value that does not implement `Throwable` now includes the value's actual runtime type, making boundary and deserialization failures substantially easier to diagnose. [94bd1abfe1](https://github.com/hershel-theodore-layton/hhvm/commit/94bd1abfe1999c7d4e04392af70470bafdfbdbd3)

## Future Changes

- Pre-stable open-tuple checking now handles projection from tuples with optional elements before a splat. It also reports `Typing[4116]` when null-coalescing access requests an index that can never exist. [5538c39818](https://github.com/hershel-theodore-layton/hhvm/commit/5538c39818feee002b52bfba646702b4d9dc1ef6)
- Unstable named-parameter function types now recognize `function(optional named bool $b): void` as a subtype of `function(): void`. The former accepts a superset of the calls permitted by the latter, which is the contravariant relationship required for parameters; return types and coeffect brackets must still satisfy their ordinary subtype rules. [8039d96fed](https://github.com/hershel-theodore-layton/hhvm/commit/8039d96fedb7c49d65e3775136ce4b5f183ded1d)
