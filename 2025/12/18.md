# 2025-12-18

## Highlights

- HHVM avoids building an expensive JIT region context after losing a translation lease, reducing extreme CPU use when many requests contend to translate the same large function. [5a202ad779](https://github.com/hershel-theodore-layton/hhvm/commit/5a202ad7796f6591b5004f1ddf488c64885cbe10)

## Breaking Changes

- The direct-to-string Binary Thrift APIs added on December 2, `thrift_protocol_write_binary_struct_to_string()` and `thrift_protocol_read_binary_struct_from_string()`, have been removed. The implementation was rolled back because a backend could identify a result as a Thrift exception while supplying a class that was not throwable. [773f486d40](https://github.com/hershel-theodore-layton/hhvm/commit/773f486d40d64fdc0f5fb156e6e69316b3318fe2)

## Future Changes

- Runtime arity errors now say that a callable expects a number of `positional` parameters. This keeps the message accurate for callables that also define named parameters. [7db2c19473](https://github.com/hershel-theodore-layton/hhvm/commit/7db2c19473bceeeb083cc9a04e7664932c0cea62)
