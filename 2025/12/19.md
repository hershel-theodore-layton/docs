# 2025-12-19

## Highlights

- CLI-server deployments can set `Eval.UnixServerNotifySystemd=true` to send `READY=1` after the Unix server has started accepting connections. [fa336b0021](https://github.com/hershel-theodore-layton/hhvm/commit/fa336b0021a71936f149dc8895814c79271c23c6)

## Future Changes

- Staged `__NeedsConcrete` checking now has two independent, default-false controls: `needs_concrete` enables call-site and related checks, while `needs_concrete_override_check` enables the warning for a `__NeedsConcrete` method overriding an unannotated method. Enabling one does not imply the other. [9027820d96](https://github.com/hershel-theodore-layton/hhvm/commit/9027820d960fbe9de782bce3509e765565ba5f9f)
