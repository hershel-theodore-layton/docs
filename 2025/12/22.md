# 2025-12-22

## Breaking Changes

- `zip_entry_read()` now takes only its `resource $zip_entry` argument and always reads up to 1024 bytes. Remove the optional `$length` argument from callers. The HHI return type remains `string`, and the omitted coeffect brackets mean `[defaults]`.
