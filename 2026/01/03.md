# 2026-01-03

## Highlights

- New `thrift_protocol_write_binary_struct_to_string()` and `thrift_protocol_read_binary_struct_from_string()` built-ins serialize and deserialize binary-protocol Thrift structs without constructing a transport object. Both signatures omit coeffect brackets and therefore require `[defaults]`. [3b98248f1e](https://github.com/hershel-theodore-layton/hhvm/commit/3b98248f1e5bd12c322ac002fbc0276d5e5d83c8)
- The obsolete `redundant_id` lint has been removed. It no longer emits lint code 5501 for old `id()` wrappers; use parentheses while removing any remaining deprecated calls. [1d7205fa93](https://github.com/hershel-theodore-layton/hhvm/commit/1d7205fa93554c9c86c2e511e3e8a322c379a8c8)
