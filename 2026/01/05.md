# 2026-01-05

## Future Changes

- Runtime refinements now understand nullable predicates such as `$x is ?T`, including while decomposing variants that use the pre-stable case-type where-clause feature. [abdfbd2d1e](https://github.com/hershel-theodore-layton/hhvm/commit/abdfbd2d1e8681d52a0e1e5e4af99594ae6ee309)
- Optional parameters and parameters with defaults may now precede a type-splat parameter such as `...Targs`. This supports typed-format helpers whose optional format argument is followed by the format tuple. [1128e6a255](https://github.com/hershel-theodore-layton/hhvm/commit/1128e6a255bbc55084f10e6f88f6527985c1d259)
- Experimental constraint-based method-call inference can defer resolving an underconstrained receiver inside expression trees. It is gated by `try_constraint_method_inference`; support for several method features and polished diagnostics is still incomplete. [0000cf2e3e](https://github.com/hershel-theodore-layton/hhvm/commit/0000cf2e3e22a988fcd6454fddb3cf3f1c26488f)
