# 2026-01-06

## Highlights

- The strongly typed `HH\TypedFormatString` implementation introduced on December 23 was temporarily reverted while a memory regression was investigated. This rollback lasted until the corrected reland on January 9. [5b0e3057c1](https://github.com/hershel-theodore-layton/hhvm/commit/5b0e3057c14b81db677b036c1e44ce39f1d9c117)

## Future Changes

- Case types moved from Preview to OngoingRelease, so ordinary case-type declarations no longer need `__EnableUnstableFeatures('case_types')`. Case-type where clauses remain in Preview, and recursive case types are not part of this pre-stable release. [a5022daa7c](https://github.com/hershel-theodore-layton/hhvm/commit/a5022daa7cfff3562d342a5ed0536449f2669e67)
