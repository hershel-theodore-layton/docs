# 2026-01-12

## Breaking Changes

- Package-boundary checking now rejects `enum C { use D; }` when `D` belongs to a package that the current package does not include. This applies to both package configuration versions. [37ec673d69](https://github.com/hershel-theodore-layton/hhvm/commit/37ec673d6915408c83f744f3ccf24bb54c87ea2c)
- Direct access to a class constant in an unrelated package is now an error. Use an allowed package relationship or establish the package through the supported package-checking APIs; dynamic class references and `type_structure()` retain their distinct handling. [e8b8fa9c16](https://github.com/hershel-theodore-layton/hhvm/commit/e8b8fa9c1652b948b020d1a471e94551c72c603f)
