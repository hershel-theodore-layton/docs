# 2026-01-13

## Highlights

- `HH\watcher_get_clock()` now honors an explicitly supplied `repo_root`, and the watcher file metadata declarations now cover Watchman's clocks, timestamps, ownership, inode, type, symlink, and content-hash fields. [f890ffef5a](https://github.com/hershel-theodore-layton/hhvm/commit/f890ffef5abdee904300461fbbcab507b364558b) [3161ba224a](https://github.com/hershel-theodore-layton/hhvm/commit/3161ba224a4dccb7fdfde6c7b5d3d82b34f3599e)

## Breaking Changes

- The declaration of `HH\watcher_query()` now correctly returns `Awaitable<string>`, matching its existing JSON-encoded runtime result, instead of `Awaitable<WatcherResult>`. Decode the returned string before reading result fields; the `WatcherFileResult` shape now uses Watchman's `content.sha1hex` key instead of `sha1hex`. [3161ba224a](https://github.com/hershel-theodore-layton/hhvm/commit/3161ba224a4dccb7fdfde6c7b5d3d82b34f3599e)

## Future Changes

- Files can opt into recursive case-type definitions with `__EnableUnstableFeatures('recursive_case_types')`. The feature remains in preview and is separate from the now-releasing base case-type syntax. [3afc799b42](https://github.com/hershel-theodore-layton/hhvm/commit/3afc799b42871a3f151676d3f9c7da3664504d4f)
