# 2026-01-13

## Highlights

- Watcher options now honor an explicitly supplied `repo_root`, and watcher file metadata covers Watchman's clocks, timestamps, ownership, inode, type, symlink, and content-hash fields. [f890ffef5a](https://github.com/hershel-theodore-layton/hhvm/commit/f890ffef5abdee904300461fbbcab507b364558b) [3161ba224a](https://github.com/hershel-theodore-layton/hhvm/commit/3161ba224a4dccb7fdfde6c7b5d3d82b34f3599e)

## Breaking Changes

- `HH\watcher_query()` now returns `Awaitable<string>` containing JSON instead of `Awaitable<WatcherResult>`. Decode the returned string before reading result fields; the content-hash key is now `content.sha1hex`, not `sha1hex`. [3161ba224a](https://github.com/hershel-theodore-layton/hhvm/commit/3161ba224a4dccb7fdfde6c7b5d3d82b34f3599e)

## Future Changes

- Files can opt into recursive case-type definitions with `__EnableUnstableFeatures('recursive_case_types')`. The feature remains in preview and is separate from the now-releasing base case-type syntax. [3afc799b42](https://github.com/hershel-theodore-layton/hhvm/commit/3afc799b42871a3f151676d3f9c7da3664504d4f)
