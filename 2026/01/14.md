# 2026-01-14

## Highlights

- `AsyncMysqlConnectionOptions` now has getters for connection and TCP timeouts, retry count, total and query timeouts, and connection attributes. The async MySQL extension version was raised to 8.1 for feature guards. [d1e418ade6](https://github.com/hershel-theodore-layton/hhvm/commit/d1e418ade67aff0809e2122fcd3cca0ae4567efd)

## Future Changes

- The unstable extended-await implementation now schedules independent nested awaits concurrently while preserving expression dependencies. It also lays groundwork for awaits in loop conditions and updates. [3b286bd818](https://github.com/hershel-theodore-layton/hhvm/commit/3b286bd81824569715ada11443b914e3da77f062) [8b884ff428](https://github.com/hershel-theodore-layton/hhvm/commit/8b884ff428e3530b00119c5df9c18b8bc7593b2f)
