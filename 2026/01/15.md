# 2026-01-15

## Highlights

- Async return-type enforcement is preserved when the tail-await optimization removes the normal return bytecode, preventing dynamically introduced bad return values from escaping the check and crashing later. [5e6edbd435](https://github.com/hershel-theodore-layton/hhvm/commit/5e6edbd4350b5231816b35bcaaacade17259889b)

## Future Changes

- Open tuple syntax and type splats have entered an ungated rollout and no longer require `__EnableUnstableFeatures('open_tuples')` or `__EnableUnstableFeatures('type_splat')`. This includes optional/open tuple elements, splats in tuple and callable types, and type-splat function parameters; both features remain pre-stable. [dc93244172](https://github.com/hershel-theodore-layton/hhvm/commit/dc93244172fdd9714502bb68fb11b5ee94b54a9c)
- Unstable extended-await syntax now handles conditionally executed awaits in short-circuit operators, ternaries, null coalescing, assignments, loops, and nullsafe calls while preserving their execution conditions. [ec6d2a9b45](https://github.com/hershel-theodore-layton/hhvm/commit/ec6d2a9b45dd87eeded49563b0ac5e0795cea257)
