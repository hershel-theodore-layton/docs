# 2026-01-19

## Highlights

- `HH\Lib\Str\format()` and `format_l()` now preserve a `HH\TypedFormatString<SprintfFormat, Targs>` placeholder tuple through their `...Targs` arguments, so first-class wrappers retain format-argument types without a FIXME. Both functions remain `[]`. [60d4799e1f](https://github.com/hershel-theodore-layton/hhvm/commit/60d4799e1f824278177feb95720392c3a5e6c947)
- The runtime definition of `HH\TypedFormatString` is now present alongside its HHI declaration, so runtime type structures and aliases agree with Hack's typechecker. [e0e9fe6410](https://github.com/hershel-theodore-layton/hhvm/commit/e0e9fe6410d684d707e9f6d6d499c45bc528f5e0)

## Breaking Changes

- Calls to `Str\format()` and `Str\format_l()` now type-check variadic arguments against literal placeholders instead of accepting arbitrary `mixed` arguments. Fix newly reported calls by matching each placeholder's required type or by correcting the format string. [60d4799e1f](https://github.com/hershel-theodore-layton/hhvm/commit/60d4799e1f824278177feb95720392c3a5e6c947)
