# 2026-01-20

## Highlights

- Prefixed string literals such as `re'/foo/'` are now accepted by both the runtime parser and typechecker in constant positions, including class constants, enum values, and default parameters. [d7b2ba9381](https://github.com/hershel-theodore-layton/hhvm/commit/d7b2ba938189a8f689a325da0f6207fb47b74145)

## Breaking Changes

- `hh_client --save-state`, `hh_server --save-state`, and `--gen-saved-ignore-type-errors` have been removed, along with the corresponding server RPC. Generate saved states with `hh_distc`, which can also run locally. [f6cc06f5b6](https://github.com/hershel-theodore-layton/hhvm/commit/f6cc06f5b6e7ea42cc62e69395f9ce09f7b790b2)

## Future Changes

- In the pre-stable readonly feature, `<<__IgnoreReadonlyError>>` on a callable parameter now applies to the callback's return coercion and propagates through nested, bidirectionally typed lambdas. Readonly-returning callbacks no longer produce the suppressed mismatch at either level. [cb714a6040](https://github.com/hershel-theodore-layton/hhvm/commit/cb714a6040c89abcfd801c03d4924fcd1afa3b3a) [2409334bab](https://github.com/hershel-theodore-layton/hhvm/commit/2409334bab2fbe4d122a24c9b955c0b3e33c4865)
- Safe Abstract and `__NeedsConcrete` now have user-facing documentation and tested warning examples ahead of the `needs_concrete` configuration's release. [a50aed61a0](https://github.com/hershel-theodore-layton/hhvm/commit/a50aed61a05af740ab6c9eafb8b7c4c366e44363)
