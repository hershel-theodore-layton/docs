# 2026-01-26

## Highlights

- The language server's formatter no longer deletes content at the top of a file when translating hackfmt output into LSP edits. [1ce73539f3](https://github.com/hershel-theodore-layton/hhvm/commit/1ce73539f38a21caf24a63d47f8c693567434aef)
- An override of a `<<__DynamicallyCallable>>` method no longer has to repeat that annotation. Each dynamically invoked implementation can be annotated independently; the implied `<<__SupportDynamicType>>` requirement remains inherited. [73a415207f](https://github.com/hershel-theodore-layton/hhvm/commit/73a415207f2891ea436a73c646d98c6eea18975f)

## Future Changes

- Errors for `require this as SomeInterface` now suggest the appropriate `require implements SomeInterface` constraint. [036bebf751](https://github.com/hershel-theodore-layton/hhvm/commit/036bebf751efae50edefac8b2a585883a0f64283)
