# 2026-01-30

## Highlights

- Hack can now emit warning 12034 when code reads a `keyset` or `ConstSet` with `$set[$key]`. Such indexing either throws or simply returns the key; prefer `C\contains_key()` or `->contains()`. `isset`, `unset`, and assignment contexts are excluded. [b4c0fda49e](https://github.com/hershel-theodore-layton/hhvm/commit/b4c0fda49e828f2c21dfa6c3416094b877c07b5d)

## Future Changes

- Go-to-definition now follows static methods and properties made visible through the pre-stable `require class` and `require this as` constraints. [db92b9ea66](https://github.com/hershel-theodore-layton/hhvm/commit/db92b9ea668dd4c9dba4a4087051eb1c10958945)
- `require this as` reached ongoing release on the HHVM side and is represented in HackC bytecode and Facts. The typechecker still marks the overall `require_constraint` feature unstable in `.hhconfig`, so this is rollout groundwork rather than a general release.
