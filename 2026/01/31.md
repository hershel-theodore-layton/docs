# 2026-01-31

## Highlights

- New pure `HH\Sandbox\dict_with_capacity()` and `HH\Sandbox\vec_with_capacity()` helpers return empty arrays with a requested capacity hint, reducing reallocations while populating a known-size collection. Capacity must be positive; HHVM may cap or ignore the hint, and repo-authoritative mode returns a normal empty array. [0e7715a0fc](https://github.com/hershel-theodore-layton/hhvm/commit/0e7715a0fc88ebc454f39484fcb8fe0794fa5a17) [c61c8ad0da](https://github.com/hershel-theodore-layton/hhvm/commit/c61c8ad0daba058b91853e07a7b73ce8098cc6f5)

## Future Changes

- `FunctionCredential` instance accessors, `pack()`, and `__debugInfo()` are now `readonly`, so they can be called through readonly credentials when using the pre-stable readonly feature. The accessors and `pack()` retain `[]`; `__debugInfo()` still omits a capability list and therefore requires `[defaults]`. [095cbba3b9](https://github.com/hershel-theodore-layton/hhvm/commit/095cbba3b93380d05e698947a928e950ccfefd9c)
