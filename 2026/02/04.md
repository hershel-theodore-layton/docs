# 2026-02-04

## Security

- The Hack toolchain's Rust `bytes` dependency was updated to 1.11.1, addressing RUSTSEC-2026-0007, an integer overflow in `BytesMut::reserve`. [b99ab4f0c1](https://github.com/hershel-theodore-layton/hhvm/commit/b99ab4f0c161bd2b17ce0de680a6685b49d49669)

## Breaking Changes

- The dynamic-support pass now reports its own typing errors by default, including under `everything_sdt`. It is skipped when ordinary typechecking has already found errors to avoid duplicate noise; `silence_errors_under_dynamic=true` can temporarily restore suppression during a migration. [a48510ac78](https://github.com/hershel-theodore-layton/hhvm/commit/a48510ac787c186292344b35b173e05f4b4f0e38)
- `HH\ImplicitContext\soft_run_with()` and `soft_run_with_async()` have been removed. They were passthrough helpers that no longer changed implicit-context state; call the callback directly. [52fd0cf488](https://github.com/hershel-theodore-layton/hhvm/commit/52fd0cf488603d5b25595bd363ecac8dbed3a232)
