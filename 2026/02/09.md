# 2026-02-09

## Highlights

- `SQLite3`, `SQLite3Stmt`, and `SQLite3Result` now release native SQLite resources during request sweeping. File descriptors no longer leak when objects survive until request end without an explicit `SQLite3::close()`. [52ada4d82d](https://github.com/hershel-theodore-layton/hhvm/commit/52ada4d82d8edc887244ab9f1cdbe6ff65c641b5)
- `openssl_x509_parse()` now frees the owned buffers returned by `X509_NAME_oneline()`, avoiding repeated native-memory growth while parsing certificates. [b1f4009ddb](https://github.com/hershel-theodore-layton/hhvm/commit/b1f4009ddb8f0d167f042c6d4f15aa8cc120526a)

## Breaking Changes

- Package-requirement compatibility is now checked on constructor overrides, including both consistent and inconsistent constructors. A child constructor can no longer introduce a package requirement that would be invalid on an ordinary method override. [5e5abce7a0](https://github.com/hershel-theodore-layton/hhvm/commit/5e5abce7a0c1a04d52feac26363a8036890646bb)
