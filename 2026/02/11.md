# 2026-02-11

## Breaking Changes

- A transparent alias around an opaque newtype no longer exposes the opaque type's constraint when Hack computes enforcement. Under implicit pessimisation this removes an unsound intersection with the hidden constraint, so code that previously relied on the leaked type can now fail typechecking.
