# 2026-02-12

## Highlights

- Top-level statements now inherit the package selected by their file path instead of being typed with no package. This removes spurious package errors in Hack notebooks and other files whose statements are wrapped in a synthesized function. [80ee10b3e1](https://github.com/hershel-theodore-layton/hhvm/commit/80ee10b3e1e32dba582282d52d32e8b8f0364fac)
- HHBBC now detects cycles while speculating through successor blocks, preventing repo-authoritative compilation from hanging on control-flow loops that revisit the same block. [7029bde607](https://github.com/hershel-theodore-layton/hhvm/commit/7029bde607ded75e3534e1ae4fbce8f3bb37d7fc)

## Breaking Changes

- Shape-aware constraint refinement is now unconditional, and the `type_refinement_partition_shapes` configuration option has been removed. Projects that explicitly disabled the option can see more precise refinements and should delete the stale setting. [f1c42be784](https://github.com/hershel-theodore-layton/hhvm/commit/f1c42be7847347a6d02926b2888d75af89346685)
