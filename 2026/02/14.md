# 2026-02-14

## Highlights

- Files matched by `package_exclude_patterns` are now also exempt from `__RequirePackage` and `__SoftRequirePackage` access errors, making those annotations consistent with ordinary package-boundary checks. [d615cebfcf](https://github.com/hershel-theodore-layton/hhvm/commit/d615cebfcfcc4a99b8f8abe339a729c9b5ad67c6)

## Breaking Changes

- `HH\ImplicitContextBase::exists()` has been removed now that `get()` returns `null` when the context is absent. Subclasses should replace `parent::exists()` with `parent::get() is nonnull`, or directly use the nullable value. [bbb221caf5](https://github.com/hershel-theodore-layton/hhvm/commit/bbb221caf5f2ea4df74ae308af3f38a5791fb145)
