# 2026-02-15

## Highlights

- `HH\package_exists()` and the package-definition introspection helpers are now explicitly pure (`[]`). This is a caller-requirement relaxation from omitted brackets, which mean `[defaults]`, so package checks can now be performed from a pure context without acquiring any capability. [483c81b3c7](https://github.com/hershel-theodore-layton/hhvm/commit/483c81b3c7498bbb34c7b2dfbdf114aa30d6b711)

## Future Changes

- `ReflectionClass::getRequiredThisAsClass()[]: ?string` exposes the class named by a trait's pre-stable `require this as` constraint, or `null` for other classishes and unconstrained traits. [ab878bf11c](https://github.com/hershel-theodore-layton/hhvm/commit/ab878bf11c99dea0a5ec72cf5a5a4ae82eb62a99)
