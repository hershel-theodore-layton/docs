# 2026-02-17

## Highlights

- `HH\Facts\type_method_attributes(classname<nonnull>)[]` performs a point query for one type and returns a `dict` from method names to their indexed attribute names. This avoids scanning every method carrying a particular attribute. [632b612e33](https://github.com/hershel-theodore-layton/hhvm/commit/632b612e33d79a34ebeda45e40a80673ba50b416)
- `SQLite3Stmt::execute()` no longer steps a `SELECT`, discards its first row, and executes it again on the first `fetchArray()`. The result buffers the initial row and repeated calls to `execute()` reset the cursor before running. [7f0dba4f01](https://github.com/hershel-theodore-layton/hhvm/commit/7f0dba4f012a2ed95d7c6667486763a281a0443b)
- `Str\replace_ci()` and `Str\replace_ci_l()` are now explicitly pure (`[]`) because their case-insensitive implementation no longer consults global locale. Their caller requirement is therefore narrowed from implicit `[defaults]` to no capabilities. [a7cc885222](https://github.com/hershel-theodore-layton/hhvm/commit/a7cc8852228321dc7fb17c05f3225cf0cfa575e3)
- Lint 5649 no longer flags an `internal` class solely because it appears in a `__Sealed` allowlist. References to the internal class outside that attribute remain linted, so sealed APIs can intentionally enumerate internal implementations without a false positive. [261492cbdd](https://github.com/hershel-theodore-layton/hhvm/commit/261492cbdda612d55a344a24e9309f7231a33d04)
