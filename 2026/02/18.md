# 2026-02-18

## Highlights

- `hh_client --jsonl` streams one machine-readable JSON object per diagnostic followed by a summary object. It is mutually exclusive with `--json` and preserves the ordinary success or type-error exit status. [a79ccef39e](https://github.com/hershel-theodore-layton/hhvm/commit/a79ccef39e9262770050bf57d03b6e1076f2f35c)
- IDE diagnostics for indexing a `keyset` or `ConstSet` now offer direct quick fixes to `C\contains_key($keyset, $key)` or `$set->contains($key)`. [8a0a29c718](https://github.com/hershel-theodore-layton/hhvm/commit/8a0a29c7185ca328e594874b3c9f8502af0121f1)

## Breaking Changes

- Type errors in the first groups of parameters of a lambda with more than five parameters are no longer dropped during error accumulation. Invalid type-constant accesses and similar errors in those positions can now surface. [3a20987e05](https://github.com/hershel-theodore-layton/hhvm/commit/3a20987e051c755f6fdea23bbccb9241c9e73dfa)

## Future Changes

- HHVM gained `.hhvmconfig.hdf` controls for per-feature `Unstable`, `Preview`, `OngoingRelease`, and `Released` status. The new map is used only when `Hack.Lang.UseLegacyExperimentalFeatureConfig=false`; unspecified features remain unreleased unless `Hack.Lang.ConsiderUnspecifiedExperimentalFeaturesReleased=true`. [651c2bef21](https://github.com/hershel-theodore-layton/hhvm/commit/651c2bef21a7858841db745d654441d4b194f9ad)
