# 2026-02-20

## Highlights

- `ReflectionClass::hasProperty()` and `getProperties()` no longer initialize the reflected class merely to obtain declared property names. Reflection over traits and classes with failing initialization can therefore answer these structural queries safely. [7884df7969](https://github.com/hershel-theodore-layton/hhvm/commit/7884df79690a54a5b9f6b672cc6f2a05c9b12f93)

## Breaking Changes

- APC now stores a non-persistent class pointer as a lazy class. If the underlying class is later deleted, fetching that APC entry returns a dead lazy class instead of `null`; callers that used deletion as an existence test must handle the new value. [a259ee456e](https://github.com/hershel-theodore-layton/hhvm/commit/a259ee456eea288203b579d39ba6413ad2764d11)

## Future Changes

- Type-constant access through `self` inside a trait now uses the class selected by pre-stable `require class`. This closes a `Tany` type hole and can expose errors in code that previously escaped checking through an unresolved `this::T`. [17fb0bda04](https://github.com/hershel-theodore-layton/hhvm/commit/17fb0bda0415c8c7ca673454c0bbe54b946c442f)
- The same `self` type-constant fix now covers the pre-stable `require this as` constraint. [c7673ad08e](https://github.com/hershel-theodore-layton/hhvm/commit/c7673ad08e8f8544e8b2e00765791045bfb50ac8)
