# 2026-02-23

## Highlights

- Function-pointer inference now tracks type parameters in other parameters' constraints, class and type-constant refinements, and occurrences of `this` with their precise variance. This removes unnecessary first-class polymorphic types while preserving the correct co- or contravariant bound. [20e6acc12d](https://github.com/hershel-theodore-layton/hhvm/commit/20e6acc12d0ff4ac432f04ad9130b3acbacb3ac2) [9a880e8a6b](https://github.com/hershel-theodore-layton/hhvm/commit/9a880e8a6be895187c4eae733738b18078bccd14) [bf9fc1fc91](https://github.com/hershel-theodore-layton/hhvm/commit/bf9fc1fc91671c4c95e8b60dcda34b9ef23b7c35)
- Lambdas created inside a function protected by `__RequirePackage` or `__SoftRequirePackage` now retain the package availability of their creation continuation. This permits sound higher-order and recursive uses without granting packages that were unavailable outside the lambda. [bec949706c](https://github.com/hershel-theodore-layton/hhvm/commit/bec949706c6b6797e5ec11c625373bbbaf501453)
- `get_active_worker_counts()` is now known to Hack and returns a shape containing pagelet, Xbox, HTTP, and CLI worker counts. The declaration omits coeffect brackets and therefore retains the `[defaults]` caller requirement. [531391b170](https://github.com/hershel-theodore-layton/hhvm/commit/531391b170e5a31bb1f0193604cbf4f9b1ac0c02)

## Breaking Changes

- Lint 5655 now reports references from a file assigned by package rules into a file moved into that same package with `__PackageOverride`. References guarded by an appropriate `__SoftRequirePackage` are exempt; other edges should move the target, add `__RequirePackage`, or be guarded by a package check.
