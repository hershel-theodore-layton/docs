# 2026-02-24

## Highlights

- Reflection parameter APIs now have concrete HHI return types: boolean predicates return `bool`, class lookups return `?ReflectionClass`, and `isDefaultValueConstant()` returns `?bool`. This replaces `HH\FIXME\MISSING_RETURN_TYPE`, so callers gain useful static checking. [bf3d95c54b](https://github.com/hershel-theodore-layton/hhvm/commit/bf3d95c54b0404dea50e1e0e3f00c5a70cd26c21)

## Future Changes

- Dynamic invocation paths can now pass named-argument metadata through `invokeFunc*`, including constructor invocation. This extends the staged named-parameter runtime beyond direct bytecode calls, but does not by itself complete the language feature's release. [9b3e5ec269](https://github.com/hershel-theodore-layton/hhvm/commit/9b3e5ec269b55de73c48b4837269eafa615d3d48)
