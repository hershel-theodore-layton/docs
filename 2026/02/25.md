# 2026-02-25

## Highlights

- `HH\Asio\cancel_sleep_nothrow(SleepWaitHandle $wh): bool` completes a pending sleep successfully with `null` instead of failing it with an exception. It returns whether cancellation occurred; its omitted coeffect brackets mean `[defaults]`. [2a17049a2a](https://github.com/hershel-theodore-layton/hhvm/commit/2a17049a2abc75b3794b62f8264a54fd839ee015)

## Breaking Changes

- Package boundaries are now enforced for function pointers and reified generic arguments, and the `package_allow_function_pointers_violations` and `package_allow_reified_generics_violations` escape hatches have been removed. References such as `OtherPackage\f<>` and cross-package reified type arguments now require that package to be available. [fb27a911ff](https://github.com/hershel-theodore-layton/hhvm/commit/fb27a911ff2f003c6e21e20a77a1703697a481af) [8677c548f3](https://github.com/hershel-theodore-layton/hhvm/commit/8677c548f3f0b23ff98da8f83b84625bb6cf44f6)

## Future Changes

- Lambdas involving expression-dependent type constants with multiple upper bounds no longer make the typechecker recurse indefinitely when a bound refers back to itself. This affects the unstable `type_const_multiple_bounds` feature. [9118df03a0](https://github.com/hershel-theodore-layton/hhvm/commit/9118df03a05cde325cf545db384c3659ab203ec9)
- Recursive case-type expansion now preserves the recursive `Tnewtype` identity underneath constructors such as `vec`, tuples, shapes, functions, and class applications. This closes an unstable-feature soundness hole where `case type CT = vec<CT> | int` could incorrectly accept `vec<string>` as `CT`. [b5903cf3aa](https://github.com/hershel-theodore-layton/hhvm/commit/b5903cf3aa3aa8e9417e5cf2f4d5f1fc367800aa)
