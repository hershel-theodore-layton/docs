# 2026-03-02

## Security

- HHVM operators can set `Eval.AllowUngatedExec=false` to reject `shell_exec()`, `exec()`, `passthru()`, `system()`, `pcntl_exec()`, and `HH\Lib\OS\fork_and_execve()`. `proc_open()` can remain available to exact function or `Class::method` names listed in `Eval.ProcOpenGatedApprovedCallers`. [3f00bd113d](https://github.com/hershel-theodore-layton/hhvm/commit/3f00bd113dfa9f3f8f21cd1f283b5f1564d38c49)

## Breaking Changes

- The `DateInterval` HHI is more precise: `$days` is now `int`, `createFromDateString()` returns `DateInterval`, and `format()` returns `string`. Code that relied on these APIs producing `mixed` may now expose type errors. [f551f0f9fc](https://github.com/hershel-theodore-layton/hhvm/commit/f551f0f9fc87274ebcfeb82d07229db2f18682a9)
