# 2026-03-04

## Highlights

- `hh --help` now shows a curated everyday command set instead of roughly 70 rarely used flags; `hh --ultrahelp` retains the complete option list. [300f886607](https://github.com/hershel-theodore-layton/hhvm/commit/300f886607da532078b512996e2537a6d71d5974)

## Breaking Changes

- An `if (package p)` expression is now rejected unless package `p` includes the package containing the current file, matching the well-formedness rule for `__RequirePackage`. [4986189361](https://github.com/hershel-theodore-layton/hhvm/commit/49861893617bc329743a5bc8c998263d87187941)
- The cross-package migration linter now tracks `C::class` references when `package_allow_classconst_violations=true`; projects using that temporary carveout may see new lint 5656 diagnostics for undeclared package dependencies. [6671f217e0](https://github.com/hershel-theodore-layton/hhvm/commit/6671f217e0e029271d871ec665bcf0f8a0fb4fbc)

## Future Changes

- Symbol information now retains the pre-stable `named` and `readonly` parameter modifiers when rendering function type hints, so tools consuming `displayType` no longer erase them from the displayed function type. [d927c424f2](https://github.com/hershel-theodore-layton/hhvm/commit/d927c424f2e2b151988935290c6f95e3fc9370ab)
- The pre-stable extended-await implementation now supports conditional and sequential awaits inside `concurrent` blocks, preserves `using` statement lifetime correctly, and evaluates `for` initializer and iterator expression lists in source order. [31f3c8b933](https://github.com/hershel-theodore-layton/hhvm/commit/31f3c8b933dc164344a2bbeba0b8f87957c8278f) [4b74fe53e8](https://github.com/hershel-theodore-layton/hhvm/commit/4b74fe53e8048c4e8122b6231ef9357e3d4ce35a) [de3ebf325f](https://github.com/hershel-theodore-layton/hhvm/commit/de3ebf325fa82f6fd72eb62d7b7dd8c0e8d79a18)
- The pre-stable `delay` operator explicitly leaves an `Awaitable<T>` un-awaited while preserving its type. It is a runtime no-op, is permitted only in async functions, and is intended to distinguish deliberate delayed awaiting from accidentally discarded awaitables. [5872d7ec97](https://github.com/hershel-theodore-layton/hhvm/commit/5872d7ec97e2bd2636e7c12a85468a46c5ca7d77)
- Runtime type structures can now represent exact, upper-bound, lower-bound, and context-constant refinements such as `I with { type T = int }`. This is groundwork for using pre-stable class refinements on the right-hand side of type aliases and type constants. [b05c47edf3](https://github.com/hershel-theodore-layton/hhvm/commit/b05c47edf39a366b1e17a0ea0b2b06fadf35dd60)
- Setting `disallow_bool_cast=true` now makes `(bool)` casts a parse error, providing an opt-in migration path away from implicit truthiness conversions. [6479cd2461](https://github.com/hershel-theodore-layton/hhvm/commit/6479cd2461c895c13f4008b8b6fe878007c80e6e)
