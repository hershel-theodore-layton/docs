# 2026-03-05

## Highlights

- HackC no longer crashes while reporting invalid constant initializers that contain local-variable list expressions; it now points the constant-expression error at the offending expression. [de71cec1a5](https://github.com/hershel-theodore-layton/hhvm/commit/de71cec1a5587cb4dbd2bef7b432220c7f8adf03)

## Breaking Changes

- Cyclic abstract type-constant bounds such as `abstract const type T as this::T` no longer introduce an unsound `Tany` bound. The cycle is treated as an absent upper bound (`mixed`) or lower bound (`nothing`), so invalid uses that previously passed through `Tany` can now produce type errors. [97d482d027](https://github.com/hershel-theodore-layton/hhvm/commit/97d482d02781e8e93f55e83b17b4356ab22c596b)
