# 2026-03-06

## Highlights

- `HH\type_structure_classname()` is now understood specially by the typechecker: it resolves the named type constant and returns the corresponding `classname<T>` when the type is classish or an enum, while rejecting non-classish type constants. [9b14e5db5d](https://github.com/hershel-theodore-layton/hhvm/commit/9b14e5db5dadf41fb96d189e7d294f41f2b92a5b)
- `apc_add()`, `apc_store()`, and their `with_pure_sleep` variants gained a final `$guaranteed_acyclic` argument. Setting it to `true` skips APC's cycle-detection walk when the caller can guarantee the stored value contains no cycles. [7fa443e8fa](https://github.com/hershel-theodore-layton/hhvm/commit/7fa443e8faee2193cba5b0a69ac087ab1bd9e4d8)
