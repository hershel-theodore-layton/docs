# 2026-03-11

## Breaking Changes

- The built-in date/time HHI now gives many formerly untyped APIs concrete parameter and return types, including `checkdate(): bool`, timezone getters and setters, `DateTime` mutators returning `this`, and typed `DateTime`/`DateInterval` parameters. Calls that previously flowed through missing HHI types may now report type errors. [7e8a8d7133](https://github.com/hershel-theodore-layton/hhvm/commit/7e8a8d7133a14ea124505739cc44a881584a8333)
