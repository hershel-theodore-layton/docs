# 2026-03-12

## Highlights

- Lambda type-parameter exposure now removes expression-dependent variables from recursive refined builder types instead of retaining them across later lambdas. This avoids cubic typechecking behavior in fluent-builder code with class refinements. [db5234971c](https://github.com/hershel-theodore-layton/hhvm/commit/db5234971c759c47518aefd6db7aa1c7258bd0ec)
- The persistent Hack server no longer gets stuck or returns stale results when one file changes while an earlier recheck is being interrupted. Files left in `disk_needs_parsing` now trigger another typecheck even when no additional filesystem event arrives. [6bfec3705a](https://github.com/hershel-theodore-layton/hhvm/commit/6bfec3705ae9fbd5bcff58efe99c4794b9df7fbd)

## Breaking Changes

- Misspelled script markers such as `<?h`, `<?hx`, or `<?h h` are no longer mistaken for PHP and silently skipped. Hack treats them as source files and reports a parse error directing authors to `<?hh`; valid `<?php` and bare `<?` PHP markers remain skipped. [cffabe0510](https://github.com/hershel-theodore-layton/hhvm/commit/cffabe05108653031ffcd54aa28bca6ab3fccc2f) [b0addbd6a3](https://github.com/hershel-theodore-layton/hhvm/commit/b0addbd6a3c15e1e99073cd05735f39c0507e996)
- Legacy `@T` soft type hints are now unconditionally rejected; the already-default-on `disable_legacy_soft_typehints` setting and CLI flags were removed. Use `<<__Soft>> T` and delete stale configuration overrides. [28379910d0](https://github.com/hershel-theodore-layton/hhvm/commit/28379910d0e73ec2859c87828cda3fef5c2b8394)
