# 2026-03-13

## Breaking Changes

- Date/time declarations were tightened further: procedural functions such as `date_diff()`, `date_format()`, and `date_sub()` now have concrete date/time parameters and returns; `DateTime` mutators return `this`, `diff()` returns `DateInterval`, and `DateTimeZone::getOffset()` returns `int`. Invalid calls and assumptions previously hidden by missing HHI types can now fail typechecking. [9b933e837e](https://github.com/hershel-theodore-layton/hhvm/commit/9b933e837e57074814c01afc7ce1fd45d003a8f7)

## Future Changes

- With `strict_consistent_construct=true`, an abstract class may no longer extend a non-abstract `<<__ConsistentConstruct>>` class. The opt-in rule prevents `new static()` from resolving to an uninstantiable intermediate class. [8c7ea12399](https://github.com/hershel-theodore-layton/hhvm/commit/8c7ea1239941e9ed35905e627c4bdf1b0f2490e5)
