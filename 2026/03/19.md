# 2026-03-19

## Highlights

- Concurrent use of the LMDB extension no longer races while closing environments or cursors, corrupting its handle map and crashing HHVM. LMDB handles are now tracked per request thread. [4a781cffc4](https://github.com/hershel-theodore-layton/hhvm/commit/4a781cffc4f7875658ebb670e401e45b1fdb26bd)

## Breaking Changes

- Conflicting trait-method detection now catches a method re-imported through both a parent class and multiple traits. Hack follows HHVM's trait flattening and reports the ambiguous trait definitions instead of incorrectly retaining the inherited class method. [f316fd38e6](https://github.com/hershel-theodore-layton/hhvm/commit/f316fd38e66fc830d5ee86c00b5c7a699643976a)
