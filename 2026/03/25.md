# 2026-03-25

## Highlights

- Typechecking functions that conditionally add many fields to a closed shape is substantially faster. Closed-shape unions now bypass subtype checks that cannot succeed, and branch joins reuse physically shared fields instead of repeatedly processing the entire growing shape. [ce7e826544](https://github.com/hershel-theodore-layton/hhvm/commit/ce7e826544873ade22ecd3bf2b19e3ea0efc0b6d) [487491f877](https://github.com/hershel-theodore-layton/hhvm/commit/487491f877cf0ed436c0694710b102ab854be9d4)
- Open-source HHBBC compilation no longer deadlocks when its subprocess scheduler is saturated; a worker waiting for capacity no longer holds the lock needed to register and release other subprocesses. [7215c6d4ae](https://github.com/hershel-theodore-layton/hhvm/commit/7215c6d4aead847f8b9a00d53b4b39865a175345)

## Security

- HackC no longer constructs invalid Rust strings from binary Hack literals while emitting shape keys, dynamic method names, or enum-class labels. Invalid UTF-8 bytes are replaced lossily instead of causing undefined behavior in later string operations. [8d729a6bfc](https://github.com/hershel-theodore-layton/hhvm/commit/8d729a6bfc8fefab92c452e74c0af90762c27ae4)
