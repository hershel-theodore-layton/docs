# 2026-03-26

## Highlights

- `date_diff()` once again accepts any `DateTimeInterface` as its first argument, correcting the overly narrow `DateTime` HHI introduced earlier in the month. [c869f6c13d](https://github.com/hershel-theodore-layton/hhvm/commit/c869f6c13def7c6af286a8610f1e37c196f551c6)

## Future Changes

- The pre-stable `HH\Runtime\RepresentableAs<T>` type now exists in HHVM's runtime systemlib as well as the typechecker HHI. `HH\Runtime\reveal<T>()` safely unwraps it to `T`; the operation is an identity at runtime because the newtype's representation is already `T`. [4b854c96a6](https://github.com/hershel-theodore-layton/hhvm/commit/4b854c96a62ceede05782f56438ec467b2fa3918)
