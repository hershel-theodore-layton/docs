# 2026-03-27

## Highlights

- Async lambdas checked against a like-wrapped `Awaitable<T>` return now reuse the expected `T` instead of inventing a fresh return type variable. This improves inference when passing async lambdas into dynamically callable APIs. [05f87d6706](https://github.com/hershel-theodore-layton/hhvm/commit/05f87d6706557fa2cbfe23c434dc4335dfff065c)
- HHBBC no longer takes quadratic time when folding large keyset literals; it now applies the same efficient element-chain handling already used for dicts. [edd801ed44](https://github.com/hershel-theodore-layton/hhvm/commit/edd801ed4464384e2e745d44c3f14cac83804269)

## Breaking Changes

- Lint 5655 now reports `__PackageOverride` dependencies introduced through `as`/`?as`, reifiable type constants, and explicit generic arguments even while their package-boundary carveout settings remain enabled. [90c5cd1df9](https://github.com/hershel-theodore-layton/hhvm/commit/90c5cd1df94432172ea577537630b491bdf0f763)
