# 2026-03-31

## Highlights

- Unrecognized `hh --config key=value` keys are now recorded in the client log, with a spelling suggestion when available. The command remains non-fatal to tolerate mixed-version releases and rollbacks. [1b40943644](https://github.com/hershel-theodore-layton/hhvm/commit/1b4094364400a31827a7bbd6e8fd0274c65c9900)

## Breaking Changes

- `HH\FunctionRef` is fully released: the `enable_function_references` setting and `function_references` unstable-feature name were removed. Function references remain enabled; delete stale configuration and `__EnableUnstableFeatures('function_references')` entries. [020e9dd575](https://github.com/hershel-theodore-layton/hhvm/commit/020e9dd575832173664e60bda6a69e5b3e21d1e1)

## Future Changes

- Calls using pre-stable named arguments no longer need a file-level feature attribute, although defining named parameters still does. This reduces call-site migration friction without completing the feature's rollout. [81144c312a](https://github.com/hershel-theodore-layton/hhvm/commit/81144c312ab904e48775b574e5374359901a4602)
