# 2026-04-13

## Security

- EXIF parsing now clears stale allocation state after an out-of-memory failure, preventing the cleanup-time use-after-free tracked as CVE-2026-23867. The same resynchronization also fixes overflow and pointer-lifetime bugs in `Vector::splice()`, Memcache Unix sockets, IPv6 socket scopes, and stream socket peer addresses. [4242fe4f88](https://github.com/hershel-theodore-layton/hhvm/commit/4242fe4f88a17ab75fd88ccc7decbbd19ab25b56)

## Breaking Changes

- More standard-library declarations now use their concrete runtime types instead of `HH\FIXME\MISSING_*_TYPE`: `apache_setenv()` returns `bool`, and a large set of Intl functions now have concrete return types. Code that relied on these APIs being effectively untyped may gain type errors.
