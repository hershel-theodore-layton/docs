# 2026-04-14

## Highlights

- `hh_client` and `hh_single_type_check` now support `--enforcement-at-pos-batch`, which reports whether HHVM enforces the type at each requested source position and returns the concrete enforced bounds where applicable. It covers declarations as well as call arguments, returns, property assignments, constructors, and array indices. [985a6cb528](https://github.com/hershel-theodore-layton/hhvm/commit/985a6cb528e52380e654db6378026f0bdf832411)

## Breaking Changes

- Built-in declarations for ICU, `IntervalTimer`, OpenSSL, and file APIs now replace many missing parameter and return annotations with concrete types matching their implementations. This improves inference but can expose calls that previously flowed through an effectively untyped signature.
