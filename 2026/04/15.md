# 2026-04-15

## Breaking Changes

- The standard-library HHI cleanup now gives concrete types to process, POSIX, zlib, bzip2, math, cURL, APC, array, output-buffering, multibyte-string, and network APIs. Expect stronger return inference and possible errors where callers passed values that the old `HH\FIXME\MISSING_*_TYPE` placeholders accepted. ## Future Changes

- The experimental `with_refinement_alias` feature now permits `I with { type T = ... }` on the right-hand side of type aliases and type constants. It remains pre-stable and still disallows such refinements in `is` and `as` expressions. [23e4d7e770](https://github.com/hershel-theodore-layton/hhvm/commit/23e4d7e7705fac97f60c2365d7176736ae514494)
