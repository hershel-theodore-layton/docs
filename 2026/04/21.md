# 2026-04-21

## Highlights

- Go-to-definition on `nameof SomeTypeAlias` now navigates to the alias declaration instead of incorrectly resolving through `typename` to the `HH\string` HHI declaration. [f0c1da1d2a](https://github.com/hershel-theodore-layton/hhvm/commit/f0c1da1d2aace11358c9b07de20d517dbe1cc354)

## Future Changes

- Parser and AST support has landed for unstable class and interface aliases such as `class C = D;` and `interface I = D;`, including generic syntax. The feature is gated by `class_aliases_everywhere` and is not yet stable for production use.
