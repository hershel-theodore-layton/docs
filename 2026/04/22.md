# 2026-04-22

## Security

- `popen()` and `pclose()` now obey the same `AllowExec` and `AllowUngatedExec` process-execution gates as `exec()`, `system()`, and `proc_open()`. Deployments that disable either gate will now reject these shell-pipe APIs too. [d33c8c0de0](https://github.com/hershel-theodore-layton/hhvm/commit/d33c8c0de09916159ada8743a08397a7b80bb115)

## Breaking Changes

- Memcached HHI declarations now give concrete types to 27 methods, including boolean operation results, `getResultCode(): int`, `getResultMessage(): string`, and a nullable-string constructor argument. [3b7f6b9fb4](https://github.com/hershel-theodore-layton/hhvm/commit/3b7f6b9fb48804801daf23fbb3ed8b320bfdc417)

- A new `Warn[12042]` reports property access through `dynamic`, including dynamic intersections and `supportdyn` wrappers. This mirrors the existing warning for dynamic method calls and may affect projects that promote warnings to failures. [faa70e09f3](https://github.com/hershel-theodore-layton/hhvm/commit/faa70e09f37c5d21863b42ae2c2700e45b5810e4)

## Future Changes

- The manual now documents Preview-stage recursive case types, including guarded and mutual recursion and the current limitation around single-variant shape definitions. [e2f872bce4](https://github.com/hershel-theodore-layton/hhvm/commit/e2f872bce474cb596bd0fb672a14ddc9807a306c)
