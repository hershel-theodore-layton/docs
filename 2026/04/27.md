# 2026-04-27

## Highlights

- The contexts and capabilities manual now states the key calling rule explicitly: a context list describes the callee's requirements, and the caller must provide a capability set containing them. An omitted list means `[defaults]`; `[globals, ctx $f]` requires both `globals` and whatever the callback requires rather than granting either capability.
