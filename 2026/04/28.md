# 2026-04-28

## Highlights

- The revised coeffects manual now explains capability subtyping in the correct direction: a callable requiring fewer capabilities is usable where one requiring more was accepted. For example, a function requiring `[read_globals]` or `[]` can stand in for `(function()[globals]: void)`, because callers prepared to supply `globals` can satisfy the narrower requirement. [af05be4b70](https://github.com/hershel-theodore-layton/hhvm/commit/af05be4b70151d9d6d58b87c793ef5d015a48351)

## Security

- `ZipArchive::getFromName()` and `getFromIndex()` now reject requested lengths and stored entry sizes above the signed 32-bit range before passing them to a 32-bit string buffer, preventing truncation from becoming a buffer overflow. Oversized reads return an empty string. [d27c559a44](https://github.com/hershel-theodore-layton/hhvm/commit/d27c559a44750e2b3ba37d154ea5640791277aac)

## Future Changes

- The unstable class-alias pipeline now reaches HackC: aliases are emitted as `.class_alias Alias = Original;` records with a corresponding class reference. Generic arguments are parsed but are not propagated to HHVM; only class or interface renaming is supported. [32dff62192](https://github.com/hershel-theodore-layton/hhvm/commit/32dff6219239c732d7b204d8cbd588f3c0c05c49)

- The manual now includes an initial guide for the experimental `require this as` trait constraint. [742d1cba0d](https://github.com/hershel-theodore-layton/hhvm/commit/742d1cba0d0d425eed8c7acb9a29df158b50e4c1)
