# 2026-04-30

## Security

- HHVM's reference-count optimizer now models the reified-generics `vec` passed to `NewRClsMeth` and `NewRFunc` as an ownership transfer. This prevents it from deleting a required increment and causing a use-after-free when the resulting callable is released before another use of the same generics vector. [24fd5d8e9b](https://github.com/hershel-theodore-layton/hhvm/commit/24fd5d8e9b50754fddc5755e37f5790ed5625544)

## Breaking Changes

- Package-boundary checking for non-null `as` expressions now descends into shape field types, including nested shapes and shapes inside tuples. Strict package configurations can therefore report cross-package asserted types that were previously missed; nullable `?as` remains exempt. [879b436c9d](https://github.com/hershel-theodore-layton/hhvm/commit/879b436c9d28f06313636433162f9ed0562db648)

## Future Changes

- A staged package check can now diagnose cross-package type aliases used at runtime-enforced positions such as parameters, returns, properties, regular enum bases, and generic upper bounds. The main `package_allow_enforceable_type_alias_violations` switch still defaults to allowing these uses, so this is rollout groundwork; a secondary relief switch can exempt aliases that resolve to class-like types if needed. [bfa29842f8](https://github.com/hershel-theodore-layton/hhvm/commit/bfa29842f82c45355294505957c396b96603a741) [2433ee724c](https://github.com/hershel-theodore-layton/hhvm/commit/2433ee724c67746c732077867e58f1dc2bec49e5)
