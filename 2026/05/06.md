# 2026-05-06

## Future Changes

- Sealed methods no longer require an unstable-feature declaration at their use site. The feature is still classified as OngoingRelease rather than Released, so projects should continue to treat it as pre-stable. [2017c9b602](https://github.com/hershel-theodore-layton/hhvm/commit/2017c9b60240078a2a27f3c83be301f4af78b72c)
- Named parameters moved from Unstable to Preview in Hack's feature registry. This broadens the intended testing audience but does not make their syntax or behavior stable. [8d1b4f3f5d](https://github.com/hershel-theodore-layton/hhvm/commit/8d1b4f3f5d00157a140f4f0eb892ebdc0bf4beb2)
