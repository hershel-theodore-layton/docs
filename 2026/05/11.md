# 2026-05-11

## Highlights

- Date/time APIs now expose substantially more precise types: `DateTime::add()`, `sub()`, and `setTimezone()` return `DateTime`; `diff()` returns `DateInterval`; `DateTimeZone::getOffset()` returns `int`; and the corresponding procedural helpers no longer return `mixed`. [6d919856b8](https://github.com/hershel-theodore-layton/hhvm/commit/6d919856b8d02ae7d662eb9b4c5b796e326b1de8)

## Breaking Changes

- `DateTime::diff()` now accepts `DateTimeInterface` rather than `mixed`. Calls whose argument is still statically `mixed` must refine or validate it before calling; this aligns Hack's signature with the runtime check that already existed. [6d919856b8](https://github.com/hershel-theodore-layton/hhvm/commit/6d919856b8d02ae7d662eb9b4c5b796e326b1de8)

## Future Changes

- `DateTimeImmutable::createFromFormat()` is now typed as the pre-stable case type `BoolOrDateTimeImmutable`, accurately representing its `false` failure result without falling back to `mixed`. [6d919856b8](https://github.com/hershel-theodore-layton/hhvm/commit/6d919856b8d02ae7d662eb9b4c5b796e326b1de8)
