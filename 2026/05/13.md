# 2026-05-13

## Highlights

- Package lints 5655 and 5656 now report cross-boundary references even when the caller has `__SoftRequirePackage` for the target's original package. Soft loading does not make an override edge or class-pointer edge structurally valid. [34397692a5](https://github.com/hershel-theodore-layton/hhvm/commit/34397692a579b37cb4044b337e5f3b4b2750deed)
- `AsyncMysqlConnection::getSslVersion()` returns the TLS version negotiated for the connection, or an empty string when unavailable. Its declaration omits a capability list and therefore requires `[defaults]`. [6d84b0bce8](https://github.com/hershel-theodore-layton/hhvm/commit/6d84b0bce898b277db74064faa7655e459367562)

## Breaking Changes

- The `package_allow_reifiable_tconst_violations` and `package_allow_all_generics_violations` configuration escape hatches have been removed. Reified type-constant and generic package-boundary violations are now always hard errors. [8a12a927f2](https://github.com/hershel-theodore-layton/hhvm/commit/8a12a927f2965254d20ddfda987323a4bdced38b)

## Future Changes

- The accepted named-parameters HIP is now published with the proposed syntax, ordering and compatibility rules, reflection model, and rationale. Named parameters remain in Preview. [c9337aa404](https://github.com/hershel-theodore-layton/hhvm/commit/c9337aa404e6083b4db435752e7dc1527de95e4a)
- Unstable shape and tuple destructuring can now be typechecked, including its interactions with subtyping, `dynamic`, and like types. Runtime emission was still pending on this date. [4343f5bcae](https://github.com/hershel-theodore-layton/hhvm/commit/4343f5bcae5e1a20d9098a2823ed38120a902d7a)
