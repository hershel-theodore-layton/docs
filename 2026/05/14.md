# 2026-05-14

## Highlights

- When a `foreach` target attempts to reassign a variable used by a dependent capability such as `[$v::C]`, error 4404 now points at the offending target variable rather than the entire `foreach` expression. This is a position fix; it does not change the capability requirement. [584dc969b8](https://github.com/hershel-theodore-layton/hhvm/commit/584dc969b83d5b336d003988b8c6abcead7e5874)

## Breaking Changes

- `package_allow_typedef_violations` has been removed. Transparent type aliases that cross an unavailable package boundary now always produce a hard error, and their referenced symbols count as production-affecting edges. [b96d110f20](https://github.com/hershel-theodore-layton/hhvm/commit/b96d110f204ed125eb720824a4d59ed7e7d71b8f)

## Future Changes

- The `__NeedsConcrete` HIP is now published, documenting the proposed Safe Abstract contract for static methods that may only be called through a concrete class. The checks still require `needs_concrete=true`. [75d4d868bb](https://github.com/hershel-theodore-layton/hhvm/commit/75d4d868bb7fe1e61735397d15f12c377b282a9a)
