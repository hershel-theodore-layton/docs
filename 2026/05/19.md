## Highlights

- `hh --infer-dynamic FUNCTION` and `hh --infer-dynamic-as-data FUNCTION` infer candidate types for local `dynamic` values from how they are called, indexed, traversed, awaited, and refined. The server returns JSON solutions; the `as-data` form favors shapes and vectors for data-like access patterns.
