# 2026-05-27

## Highlights

- Symbol indexing no longer drops static-property references such as `Class::$property`, `self::$property`, and `static::$property`. Target-use queries and tools backed by the Hack index can now find those xrefs. [85d45051d3](https://github.com/hershel-theodore-layton/hhvm/commit/85d45051d36ee0f8d3c0e3bb82c35cf5afb45841)

## Breaking Changes

- `ReflectionParameter::isArray()` has been removed. Inspect `getType()` or `getTypeText()` instead; the old predicate discarded generics and other source-level type information. [0dc0df841c](https://github.com/hershel-theodore-layton/hhvm/commit/0dc0df841c439ad910864672628c233b85e6dc76)
