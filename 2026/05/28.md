# 2026-05-28

## Breaking Changes

- `ReflectionClass::newInstance()` is now deprecated in Hack declarations. Migrate unavoidable reflective construction to `HH_FIXME::reflectionClassNewInstanceForCallsite()` and prefer direct constructors where possible. [0eaf6710f2](https://github.com/hershel-theodore-layton/hhvm/commit/0eaf6710f2229a7d7fe8935585fd0a9852ee7e35)

## Future Changes

- Hack declarations now expose the pre-stable case types `HH\Runtime\BoolOrInt`, `BoolOrString`, `BoolOrFloat`, and `BoolOrNum` for accurately typing legacy PHP APIs that return `false` on failure. [f24aafecb8](https://github.com/hershel-theodore-layton/hhvm/commit/f24aafecb8e86ff3c04f1a031e730995c22a4d53)
