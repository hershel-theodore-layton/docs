# 2026-05-29

## Breaking Changes

- `ReflectionParameter::getClass()` has been removed because it inferred only a partial view of the parameter type and ignored upper bounds. Use `getType()` or parse `getTypeText()` when source-level type syntax is required. [2d70a67585](https://github.com/hershel-theodore-layton/hhvm/commit/2d70a675857797de690b160bcd25a54e3c099697)
