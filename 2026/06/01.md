# 2026-06-01

## Breaking Changes

- More public HHI declarations now expose their concrete return types: `Exception::getTraceOptions()` and `RecursiveIteratorIterator::getDepth()` return `int`, while `HH\asio_get_running()` returns `ResumableWaitHandle<mixed>`. This improves inference but can reject code that used the old missing return types as arbitrary values.
