# 2026-06-02

## Highlights

- `.hhconfig` values can now span several lines. An indented line continues the preceding value with trimmed content and no inserted separator, making JSON-valued settings such as `enable_experimental_stx_features` easier to maintain; blank or unindented comment lines end the continuation. [e9fd08104c](https://github.com/hershel-theodore-layton/hhvm/commit/e9fd08104c9e060b138172bec60bb228f8f92665)

- `FunctionCredential` now provides `getMethodOrFunctionName()`, returning either the top-level function name or `ClassName::methodName`. Credentials for memoized implementation functions retain their `$memoize_impl` suffix. [82312e85e9](https://github.com/hershel-theodore-layton/hhvm/commit/82312e85e943400a21901a4df34feed63eb6666e)

## Breaking Changes

- Shape refinement now distinguishes open shapes from closed shapes and respects required versus optional fields when splitting `is` branches. Open shapes can correctly refine to include a newly tested field instead of collapsing a reachable branch to `nothing`; code in branches previously considered unreachable may now be checked and expose errors. [abe7c91609](https://github.com/hershel-theodore-layton/hhvm/commit/abe7c91609b576e82518ea404f3b128951654c9a)

- Public Asio wait-handle callback setters now return `void` instead of an unspecified missing type. Hack will reject code that tries to use the result of `setOnIOWaitEnterCallback()`, `setOnJoinCallback()`, or the corresponding condition, external-event, resumable, and sleep wait-handle callback setters. [403ca2943f](https://github.com/hershel-theodore-layton/hhvm/commit/403ca2943f42df3e20c7b15263f50249cd246133)

## Future Changes

- Runtime support has landed for `<<__TestsBypassVisibility>>`, allowing configured test-class descendants in non-repo-authoritative mode to reach annotated private, protected, or internal declarations. Hack typechecker integration follows later in the stack, so this is not yet the complete developer-facing feature. [de0877a17d](https://github.com/hershel-theodore-layton/hhvm/commit/de0877a17d7ab7a5e13603fbc6e6104607b70e4b)
