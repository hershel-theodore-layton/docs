# 2026-06-03

## Breaking Changes

- Lint 5655 now reports any cross-package edge that compiles only because the callee has a load-bearing `__PackageOverride`, even when the override targets a package included or dynamically loaded by the caller rather than the caller's own package. It remains suppressed when the caller can already reach the callee's underlying package. [04e9da19bf](https://github.com/hershel-theodore-layton/hhvm/commit/04e9da19bf9e88e6833c3171a069eab8f281bb12)

- `pow()` now has return type `num` instead of `mixed`, matching its runtime behavior of returning only `int` or `float` and throwing for invalid inputs. Code that treated the result as an unrelated type will now fail checking. [ada1e4482c](https://github.com/hershel-theodore-layton/hhvm/commit/ada1e4482ce50cccba7a37740e66b98349473347)

## Future Changes

- Pre-stable open and variadic tuples are no longer mistaken for closed tuples during `is` refinement and disjointness checks. This removes false “always false” warnings and lets an open tuple refine to a compatible closed tuple in the true branch. [edf59ddcca](https://github.com/hershel-theodore-layton/hhvm/commit/edf59ddccaf21575ffa8802e96a141c8937611af)
