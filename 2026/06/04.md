# 2026-06-04

## Highlights

- `hhvm --list-extensions` now emits JSON describing each loaded extension's name, version, and oncall, making runtime capabilities easier to inspect from deployment tooling. [70bb50106d](https://github.com/hershel-theodore-layton/hhvm/commit/70bb50106d54e21fa3e02c0f5dad0649780455d2)

## Security

- The CLI-server handshake now sends and validates a fixed-size magic value before any other data. A non-CLI client can no longer make HHVM interpret attacker-controlled bytes as an arbitrary `size_t` string length and attempt a process-killing allocation. [724ce26e55](https://github.com/hershel-theodore-layton/hhvm/commit/724ce26e558a4c5399200564e77adf25a4d1ea2c)

## Breaking Changes

- A large HHI cleanup replaces missing return types with concrete enforced types across Reflection, DOM, Memcache, PDO, SimpleXML, SOAP, SQLite3, and XMLWriter. Most affected operations now return `bool`, `int`, or `string`; projects that consumed these results as arbitrary values may gain type errors. [d9bb706513](https://github.com/hershel-theodore-layton/hhvm/commit/d9bb7065131b40f197a31f55bf610360ef6b56c8)
