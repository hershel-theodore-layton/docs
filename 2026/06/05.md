# 2026-06-05

## Highlights

- `--package-lint-full` now evaluates each dependent file in its effective package after applying that file's own `__PackageOverride`, while continuing to evaluate the target without its override. This fixes incorrect load-bearing-override results when both sides are overridden. [bfb684cc09](https://github.com/hershel-theodore-layton/hhvm/commit/bfb684cc099526d080ff477a0f7e73dfc68d0290)

- `<<__TestsBypassVisibility>>` is now understood throughout the Hack typechecker. With `permits_bypassing_visibility` configured, descendants of the named test base classes may access annotated private, protected, and internal members or classes, while ordinary callers retain normal visibility. Annotated members cannot be silently shadowed, overrides must preserve the attribute, and an annotated internal member requires its internal class to be annotated too. [d386a0d0d4](https://github.com/hershel-theodore-layton/hhvm/commit/d386a0d0d4c990309db75112ddf12886f18f07c9)

## Breaking Changes

- Refining a `dynamic` value with `is` or `as` against a fully enforceable type now drops the useless `dynamic` intersection and produces the enforced or `supportdyn` form. Operations after a successful check are therefore checked against the asserted type instead of silently routing through `dynamic`, which can reveal invalid calls or property accesses that previously passed. [bee322014e](https://github.com/hershel-theodore-layton/hhvm/commit/bee322014e544405eabf37d3a0076dc330465a4e)

## Future Changes

- A public HIP and Lean formalization now specify the proposed shape-polymorphism and shape-splat typing rules, including field requiredness, splat order, and inference bounds. This is a design artifact rather than a released language feature. [263c872c37](https://github.com/hershel-theodore-layton/hhvm/commit/263c872c37cca6b946c7180ff46ec3a674d751f7)
