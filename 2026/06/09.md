# 2026-06-09

## Breaking Changes

- `ReflectionClass::newInstanceArgs()` is now marked deprecated in the typechecker declarations; its diagnostic recommends `HH_FIXME::reflectionClassNewInstanceArgsForCallsite`. [1656ef0a33](https://github.com/hershel-theodore-layton/hhvm/commit/1656ef0a336ebfef5667c52ba41f1e69dc42bd60)

- Visibility bypass on annotated static properties now requires the additional `tests_bypass_visibility_static_properties=true` opt-in, which defaults to false. Static methods continue to use the existing bypass permission setting. [7dcdc84443](https://github.com/hershel-theodore-layton/hhvm/commit/7dcdc8444396fa2fe19e9870b570ab56f8d94967)
