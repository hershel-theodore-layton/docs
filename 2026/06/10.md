# 2026-06-10

## Highlights

- Strict comparisons between incompatible types, such as `"5" === 5`, now produce `Warn[12001]` instead of the hard `Typing[4118]` error. The corresponding always-true `!==` comparisons receive the same treatment. [97fcd1dfa9](https://github.com/hershel-theodore-layton/hhvm/commit/97fcd1dfa91135884d5d8ea5d2616336a75e03d4)

## Breaking Changes

- `ReflectionParameter::getTypehintText()` has been removed; use `getTypeText()` to read the source-level type hint. Reflection nullability checks now consider all runtime type constraints, and builtin-type detection recognizes Hack primitive types rather than relying on the first constraint. [0f058d8f8a](https://github.com/hershel-theodore-layton/hhvm/commit/0f058d8f8a4e2c1e94cab6759fcbf752b860c272)
