# 2026-06-15

## Highlights

- The repeated-return-value lint no longer recommends collapsing branches when the function body also contains a throwing path, preventing a suggested refactor from discarding an exception. Throws inside nested lambdas do not suppress the lint. [80d93facbc](https://github.com/hershel-theodore-layton/hhvm/commit/80d93facbc80a00bbc1730c9c231e82d979a33fd)

## Future Changes

- Typed open shapes let a hint such as `shape('a' => int, string...)` require all unknown fields to be strings. The initial implementation requires `typed_open_shapes=true` and rejects this syntax in `is`/`as` tests; it is enabled by default later in this release cycle. [fef78a70dd](https://github.com/hershel-theodore-layton/hhvm/commit/fef78a70ddf0c57acd39d12b12aae0239236dfa6)
