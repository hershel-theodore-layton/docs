# 2026-06-30

## Breaking Changes

- The typechecker always rejects `classname<T>` values in dynamic construction, type-structure, and class-constant access positions; use `class<T>` values instead. The three corresponding `class_pointer_ban_classname_*` switches have been removed. [443ccfbfab](https://github.com/hershel-theodore-layton/hhvm/commit/443ccfbfabd8c31f25d5a2b61391a3c948bf0f60)

- `HH_IGNORE_ERROR` comments no longer suppress type errors, and the `disable_hh_ignore_error` option has been removed. Use supported suppression mechanisms such as `HH_FIXME` where permitted. [e89581e3a3](https://github.com/hershel-theodore-layton/hhvm/commit/e89581e3a3dd5a02b82ec390893f96a7e3809e75)
