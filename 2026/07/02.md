# 2026-07-02

## Highlights

- Open-source HHVM no longer collects its low-level per-request JIT and interpreter timing measurements. On platforms where reading current-thread CPU time requires `clock_gettime()`, collecting these measurements consumed about 37% of CPU time during JIT warmup; removing them avoids that overhead. [e412a40b27](https://github.com/hershel-theodore-layton/hhvm/commit/e412a40b27f907f2d9c112fa3a2a2258a818ced1)

## Breaking Changes

- `wordwrap()` now throws `InvalidArgumentException` for an empty break string or a zero width with forced cutting, instead of emitting a warning and returning `false`. [34e33d25f6](https://github.com/hershel-theodore-layton/hhvm/commit/34e33d25f667459665a34605fa975d52bd62585b)
