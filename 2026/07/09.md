# 2026-07-09

## Highlights

- Build support has landed in Hershel's HHVM for Ubuntu 26.04 Resolute. `./build.sh --ubuntu-26.04` selects it, with bundled PCRE and libdwarf compatibility work for the newer distribution; Ubuntu 24.04 remains the default. [0a1acba1cb](https://github.com/hershel-theodore-layton/hhvm/commit/0a1acba1cb9adf2489535d992f0584a62233ed64)

- Incremental typechecking now rechecks descendant classes when a parent member gains or loses `__TestsBypassVisibility`, keeping override and private-shadowing diagnostics up to date. [2d646e5e23](https://github.com/hershel-theodore-layton/hhvm/commit/2d646e5e2353d626795cbb83b33ff9bdd0f046a4)

## Breaking Changes

- The `$_REQUEST` superglobal has been removed, together with `Eval.DisableRequestSuperglobal`. Read request parameters from `$_GET` and `$_POST` as appropriate. [e9cb94b3ae](https://github.com/hershel-theodore-layton/hhvm/commit/e9cb94b3ae8d5f6bd8200b5997bcacf112a8f4a1)

- The `$_COOKIE` superglobal and automatic Cookie-header parsing into it have been removed, together with `Eval.DisableParsedCookies`. The raw request header and `parse_cookies()` remain available. [e6ac19eb7a](https://github.com/hershel-theodore-layton/hhvm/commit/e6ac19eb7afc3d0bcb34e214f6f9652cb62f499f)

- Storing a `meth_caller` in APC now always throws, including when nested in a container. `Eval.ForbidMethCallerAPCSerialize` no longer permits a warning-only or permissive mode. [87298f974e](https://github.com/hershel-theodore-layton/hhvm/commit/87298f974e371e38b49fa4a5c86ad5949c7e3b18)

- `HH\dynamic_fun()` now always throws `InvalidArgumentException` when its target lacks `<<__DynamicallyCallable>>`; `Eval.DynamicFunLevel` no longer permits the call or reduces it to a warning. [70fc6271ce](https://github.com/hershel-theodore-layton/hhvm/commit/70fc6271ce6c1481e263f7bac39f31dd57458b13)
