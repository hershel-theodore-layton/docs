# 2026-07-10

## Breaking Changes

- String concatenation now always throws on disallowed implicit string coercions instead of permitting warning-only or permissive behavior through `Eval.NoticeOnCoerceForStrConcat`. Integers and strings remain supported. [eda918a5d9](https://github.com/hershel-theodore-layton/hhvm/commit/eda918a5d9cc8d0d3dca84cd3b3106a0793cdfa5)

- The left operand of `.=` now always throws on disallowed string coercion; the `Eval.NoticeOnCoerceForStrConcat2` rollout option has been removed. [92c8ae13c2](https://github.com/hershel-theodore-layton/hhvm/commit/92c8ae13c2143179bc0a85bd62e584711d1add05)

- Implicit conversion of an object to a string no longer invokes its `__toString()` method; HHVM throws `TypecastException` instead. Call `__toString()` explicitly when that conversion is intended. [ba521c3324](https://github.com/hershel-theodore-layton/hhvm/commit/ba521c3324950ba824dbde56edac66ddb23de04c)
