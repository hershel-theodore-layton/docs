# 2026-07-21

## Breaking Changes

- `HH\is_vec_or_varray()` and `HH\is_dict_or_darray()` have been removed. Their direct replacements are `HH\is_vec()` and `HH\is_dict()`. [911cd41801](https://github.com/hershel-theodore-layton/hhvm/commit/911cd4180176aee1890ad51c89f12801211b7fb2)

## Future Changes

- Opt-in variadic named parameter types now support call checking and function subtyping. Unexpected argument labels can be absorbed by a named variadic, whose element type is checked, rather than causing spurious missing-argument errors or internal typechecker errors. [adc7faffa3](https://github.com/hershel-theodore-layton/hhvm/commit/adc7faffa35148db9fc46d2abd0f26e3f553a2b6)
