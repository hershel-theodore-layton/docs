# 2026-07-22

## Highlights

- Packages can opt into stronger boundaries with `enable_strict_isolation=true` in `PACKAGES.toml`. Dynamic package observation through package expressions and `__RequirePackage`/`__SoftRequirePackage` is rejected for these packages. [aae1d23bb6](https://github.com/hershel-theodore-layton/hhvm/commit/aae1d23bb6a673f8f2a073fd0b19715e324e54f3)

- Strict-isolation packages enforce their boundaries even for paths covered by `package_exclude_patterns`. Non-excluded code also cannot reference excluded-path code inside the strict package. [8466c8e6b6](https://github.com/hershel-theodore-layton/hhvm/commit/8466c8e6b695e5074c12a00b11db8c6448ae0d62)

- User attribute classes from strict-isolation packages now receive cross-package access checks, including attributes on functions whose effective package must be established before checking them. [cb537175eb](https://github.com/hershel-theodore-layton/hhvm/commit/cb537175ebdc6c376a834f9978eb4fdfdbdb1d0a)
