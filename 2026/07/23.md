# 2026-07-23

## Highlights

- Hershel's HHVM has optimized the implementation of `HH\Lib\Vec\slice`, a hot function in `portable-hack-ast-linters`. This reduces whole project lint latency by ~30%. Improvements scale more than linearly with the size of the file being linted. Projects with larger files may see a greater improvement. This change is included in `hersheltheodorelayton/hhvm-full:26.06.05`. See also [HHVM issue for perf](https://github.com/facebook/hhvm/issues/9821) on the hhvm repo. [b983bd51b1](https://github.com/hershel-theodore-layton/hhvm/commit/b983bd51b1256cd8c3fed53b2eb9970870723e50)

- Strict-isolation package boundaries now apply to class and alias references throughout type hints, including nested type arguments and inheritance declarations. [acdcb7f349](https://github.com/hershel-theodore-layton/hhvm/commit/acdcb7f3496ada9d89308256ee94628594866dc3)

- `C::class` references into strict-isolation packages now produce hard package-boundary errors instead of only migration lints. [1d9d645d5f](https://github.com/hershel-theodore-layton/hhvm/commit/1d9d645d5fdec00532b17b704ad7099650722977)

- `nameof C` and exception-class references in `catch` now respect strict-isolation package boundaries, including excluded-path restrictions. [f39c87984b](https://github.com/hershel-theodore-layton/hhvm/commit/f39c87984b0f37e23a035416484ea6ee68c507e4)

- Predicate-based refinement now understands runtime-checkable reified type parameters, enforceable abstract type constants such as `this::TC`, and `this` itself. [6c2e8cda7f](https://github.com/hershel-theodore-layton/hhvm/commit/6c2e8cda7f42fbd72f7e34278fe57d061fe8eae0)

- `HH\class_or_classname<T>` is now a covariant opaque type accepting both `class<T>` and `classname<T>`. Related Facts APIs use it so callers can pass either representation. [e9914ef5cf](https://github.com/hershel-theodore-layton/hhvm/commit/e9914ef5cf509f6ec6d737a72126562fd1350212)

## Breaking Changes

- Case-type disjointness now treats Hack enums as `arraykey`, rejecting combinations with other integer or string variants that enum `is` checks cannot reliably distinguish. [c38b6f7d06](https://github.com/hershel-theodore-layton/hhvm/commit/c38b6f7d0668ca7baa35af918ea6aaa67f4bb84a)
