# 2026-08-12

## Highlights

- The typechecker now knows that `DOMDocument::createElementTyped()` and `createElementNSTyped()` return `DOMElement`. [130929a5fe](https://github.com/hershel-theodore-layton/hhvm/commit/130929a5fe542efb70099a8b866ab70d5ee376da)

- `hh_client --single` now typechecks explicitly supplied files that the server does not monitor, rather than incorrectly reusing global diagnostics that can make those files appear error-free. [3594deeb46](https://github.com/hershel-theodore-layton/hhvm/commit/3594deeb464e31c5f3dce447e349687fc82e3f9c)

## Future Changes

- The opt-in `check_duplicate_enum_values` setting now reports duplicate values in plain enums, including conflicts introduced through enum `use` inclusions. It remains disabled by default. [ab8c2c1907](https://github.com/hershel-theodore-layton/hhvm/commit/ab8c2c1907c62cd0eff08c7f18f63df8d3534b21)

- The opt-in duplicate-enum-value check now also reports enum values it cannot statically evaluate, rather than silently skipping them. [15b1143598](https://github.com/hershel-theodore-layton/hhvm/commit/15b11435989322b67b88555f498ff2da6f046718)

- `<<__AllowUncheckedEnumValues>>` lets an enum opt out of the experimental duplicate-value and uncheckable-value diagnostics. Enums that include an opted-out enum must also opt out. [41fb35f4ab](https://github.com/hershel-theodore-layton/hhvm/commit/41fb35f4abff55ce0ce0eb58fe395461ceaff9c3)

- The opt-in `Eval.EnableLazyGC` setting, when garbage collection is enabled, raises the default garbage-collection trigger from 50% to 80% of the remaining memory budget and allows a temporary memory grace buffer before collection. It is disabled by default, and explicit trigger and grace settings take precedence. [b41450e50e](https://github.com/hershel-theodore-layton/hhvm/commit/b41450e50e1a76e6db183e899c03944b11fd54db)
