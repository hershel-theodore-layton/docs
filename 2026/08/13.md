# 2026-08-13

## Breaking Changes

- `__PackageOverride` now produces an error when it names the file’s path-derived package itself or a package that the path-derived package neither includes nor soft-includes. [66027d0ebf](https://github.com/hershel-theodore-layton/hhvm/commit/66027d0ebff7e00481785a76fca0d18e17e5c044)

## Future Changes

- The opt-in duplicate-enum-value check now catches collisions between integer values and their canonical integer-string equivalents in `arraykey` enums, such as `0` and `"0"`. [261eb911c4](https://github.com/hershel-theodore-layton/hhvm/commit/261eb911c460e1f93d83f000457b4b18c8fc3738)

- The experimental enum-value check exempts pure aliases of a single enum when all referenced values are statically known and distinct. [84710a4acf](https://github.com/hershel-theodore-layton/hhvm/commit/84710a4acf69f876d5f38966b53f236e46cf87e7)
