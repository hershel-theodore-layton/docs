# 2026-08-17

## Highlights

- `unserialize()` now rejects aggregate values in serialized key positions, preventing use-after-free when later serialized references point into a discarded temporary key. [8ba37ca157](https://github.com/hershel-theodore-layton/hhvm/commit/8ba37ca1577bf53cfb528cff99d6cc366f7a1fee)

- `HH\Facts` now supports function-attribute queries through `functions_with_attribute()`, `function_attributes()`, and `function_attribute_parameters()`. Index the desired attributes with `Autoload.IndexedFunctionAttributes`. [12950b15d1](https://github.com/hershel-theodore-layton/hhvm/commit/12950b15d1d0fabecd95424390970674684029ee)

- A public method overriding an internal or protected method no longer has to propagate `__TestsBypassVisibility`, since the public override does not bypass visibility. [e25704eea5](https://github.com/hershel-theodore-layton/hhvm/commit/e25704eea5cf5e10cc2ea9a8743f8e37393a8891)

- The typechecker now correctly expands recursive type-constant refinements involving `this`, closing a type hole that could silently accept incompatible values. [a60607b184](https://github.com/hershel-theodore-layton/hhvm/commit/a60607b1849f8070146c3d4052bc0389af42f0b8)
