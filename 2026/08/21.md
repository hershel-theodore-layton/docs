# 2026-08-21

## Breaking Changes

- `unset()` now requires an indexed array-access target. Unsetting a local variable or an object property produces `Typing[4521]`. [c0048a4355](https://github.com/hershel-theodore-layton/hhvm/commit/c0048a4355e5ac3bb026a67ca86a281167a3551d)

## Future Changes

- When implicit packages are enabled, Hack files directly under a family path now produce `Naming[2135]`; files must live under a member directory even if they use `__PackageOverride`. [f4f84cbd73](https://github.com/hershel-theodore-layton/hhvm/commit/f4f84cbd733c64184db1017bfa912b5f6552a676)

- When implicit packages are enabled, member directory names must be valid Hack identifiers. Invalid member names now produce `Naming[2136]`. [1dea159d3d](https://github.com/hershel-theodore-layton/hhvm/commit/1dea159d3d9a94b7bae7972eb24a955bd4726201)
