# 2026-08-26

## Highlights

- The typechecker avoids expanding hidden portions of type-error explanations, preventing exponential memory use while preserving the rendered diagnostics. [849605f257](https://github.com/hershel-theodore-layton/hhvm/commit/849605f257272888bd030d6d288ab54858d0744c)

- Hackfmt no longer crashes when formatting typed open shapes such as `shape(string...)`. [f1d80663d8](https://github.com/hershel-theodore-layton/hhvm/commit/f1d80663d83d093cde996720e2fed1df8adf8593)

- `hhvm --version` now includes a `(roar)` marker when the binary was built with ROAR support. [5fd092015c](https://github.com/hershel-theodore-layton/hhvm/commit/5fd092015c1fb73b7bbdc4b368881be06c090671)

## Breaking Changes

- `__PackageOverride` can no longer assign a file to a package with strict isolation enabled, including members of experimental implicit package families. [258c0664f6](https://github.com/hershel-theodore-layton/hhvm/commit/258c0664f65136f5a8133016ffadc28d2d01794f)

## Future Changes

- Experimental shape splats now support type parameters, newtypes, and type constants, with subtyping and field operations that account for the fields those types may provide. Type-parameter splats require the unstable `shape_splat_type_parameters` feature gate. [caef41ad02](https://github.com/hershel-theodore-layton/hhvm/commit/caef41ad022eb60bb92c9c57e95ae9ab6a604931)

- Implicit-package configuration diagnostics now identify conflicting package names and paths and point at the written member reference. [cba11c4c5e](https://github.com/hershel-theodore-layton/hhvm/commit/cba11c4c5e77ebcc804184bcadc0e41d091790be)
