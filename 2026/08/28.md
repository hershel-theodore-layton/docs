# 2026-08-28

## Highlights

- The typechecker now updates module dependencies correctly after an interrupted typecheck, preventing stale unbound-name errors when a module is added. [4e7aa03c40](https://github.com/hershel-theodore-layton/hhvm/commit/4e7aa03c400338fa705b0d8fe5ca3d37612cdf82)

- `hh_client` accepts `--reason` to describe why an invocation was made; the description is recorded in invocation telemetry. [aceaff4c74](https://github.com/hershel-theodore-layton/hhvm/commit/aceaff4c744c196db8635a6dba2284b01b1fbe08)

- HHVM fixes bounds checks in Fileinfo, XML tag skipping, and numeric-string conversion, and an output-buffer overflow in FriBidi, plus allocation-size overflow in `Imagick::exportImagePixels()` and invalid Sodium secretstream header lengths. [0c786cb796](https://github.com/hershel-theodore-layton/hhvm/commit/0c786cb796b0a6383635669d2df7ca00aa826e53)

- HHVM fixes a `curl_getinfo()` linked-list memory leak, integer-key handling in LMDB, temporary-string lifetime in Unix-socket Memcache connections, and temporary parameter-name lifetime during SOAP serialization. [0c786cb796](https://github.com/hershel-theodore-layton/hhvm/commit/0c786cb796b0a6383635669d2df7ca00aa826e53)

## Future Changes

- The opt-in `class_pointer_array_literal_keys` setting infers `classname<T>` for collection-literal keys whose class-pointer type is already resolved, reflecting their runtime conversion to strings. The setting is disabled by default. [fe6dba7d83](https://github.com/hershel-theodore-layton/hhvm/commit/fe6dba7d83225f8c60026ed316e0e359c8a0cb8b)
