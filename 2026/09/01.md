# 2026-09-01

## Highlights

- HHVM avoids a crash when an external-thread task result invokes `HH\Asio\join()` on that same task during deserialization, such as from `__wakeup()`. A task already being processed cannot be re-entered or cancelled as though it were still waiting. [fe5bf06c3c](https://github.com/hershel-theodore-layton/hhvm/commit/fe5bf06c3c69b5ace8e256baca8dfedd96f28576)

- Facts symbol-to-file lookups avoid constructing an unnecessary filesystem path before returning the resolved filename. [1e7673c9fb](https://github.com/hershel-theodore-layton/hhvm/commit/1e7673c9fb0bb013df9a704bad219d798afc88b8)

## Future Changes

- Experimental named parameters may now be optional before required parameters in function-type hints, matching function declarations. Optional positional parameters must still follow required positional parameters. [3e8b127f49](https://github.com/hershel-theodore-layton/hhvm/commit/3e8b127f4944b27ee3b8cdfb9a9de9f4d91de331)
