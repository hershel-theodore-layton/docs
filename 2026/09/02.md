# 2026-09-02

## Highlights

- Uncaught internal failures in `hh_client` now use exit status 221 rather than the type-error status 2. Malformed key-value command-line arguments use status 64 and no longer print a backtrace. [bab52cef3d](https://github.com/hershel-theodore-layton/hhvm/commit/bab52cef3db7d7d1783fbb527c9e4db875aab1a6) [3148255d19](https://github.com/hershel-theodore-layton/hhvm/commit/3148255d19fd6c7145670ad8ea751d256709ce6a)

## Future Changes

- A draft proposal documents limited variadic named parameters for typed mocking, including accepting additional named arguments without exposing them in the function body. This commit changes the proposal only; the prototype remains behind the default-off `named_variadic_type` and `variadic_named_parameters` typechecker options. [46a19fe934](https://github.com/hershel-theodore-layton/hhvm/commit/46a19fe934b9eaaa443d625399f9b67b0964233e)

- Function-type displays now print `optional named` in the order accepted by the parser, making displayed hints easier to copy into source. [c66ce9b3dc](https://github.com/hershel-theodore-layton/hhvm/commit/c66ce9b3dc8ddc175d16ee0ff8488263d090405c)
