# 2026-09-03

## Highlights

- If a saved-state dependency graph disappears before a worker opens it, `hh_server` reports an unavailable graph and the monitor can restart it to restore the graph, instead of panicking through the dependency-query FFI. [838b5ecfe8](https://github.com/hershel-theodore-layton/hhvm/commit/838b5ecfe8849858e5cf1d451b3c218a4ee40020)

## Future Changes

- The default-off `reject_promoted_property_redeclaration` option adds a typechecker diagnostic for constructor parameters that re-promote inherited properties. Private non-LSB ancestor properties remain legal to shadow. [56beee3a0a](https://github.com/hershel-theodore-layton/hhvm/commit/56beee3a0a11da14ecb5e4476112706033aea6ee)

- The variadic-named-parameter proposal now specifies contravariant argument acceptance correctly and documents its memoization and readonly restrictions. These are proposal edits, not newly enabled language features. [b5adffd627](https://github.com/hershel-theodore-layton/hhvm/commit/b5adffd6275338ba4cd4a476cad78556fb5f1fe9) [0044eee66e](https://github.com/hershel-theodore-layton/hhvm/commit/0044eee66ed4ea4f094552534945b5a15b8126ef)

- Experimental named-variadic subtyping now checks an explicit optional parameter against the expected named-variadic type when that parameter shadows the implementation’s variadic, preventing incompatible functions from being accepted. [e41f9dc708](https://github.com/hershel-theodore-layton/hhvm/commit/e41f9dc70810da8017c02ff29d5dcac4e06fb14b)
