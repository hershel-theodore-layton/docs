# 2026-09-07

## Breaking Changes

- Computed property and method access now requires a receiver that is a subtype of `dynamic` under ordinary subtyping. A concrete value merely compatible with dynamic no longer suffices. Nullsafe access permits the nullable arm while checking the non-null receiver; failures use `Typing[4524]` instead of `Naming[2011]`.
