# 2026-09-16

## Future Changes

- With the default-off `use_module_error_for_member_access` option enabled, member-level module boundary violations use `Typing[4444]` instead of the general visibility code 4112. Protected-internal members receive separate module and protected-visibility checks. [38c3759cf4](https://github.com/hershel-theodore-layton/hhvm/commit/38c3759cf4acf903ab6d436677bbdfe6d83fdcb2)

- The runtime and typechecker expose `HH\implicit_package_family_exists()` and `HH\get_all_implicit_package_families()` for configured implicit package families. Family availability follows hard deployment membership, while enumeration returns declared family paths and dependencies without materializing member packages. [1ae3ff4005](https://github.com/hershel-theodore-layton/hhvm/commit/1ae3ff40058ef3e14ed9dfb15bbb6c8310b33e98)
