# 2026-09-21

## Highlights

- HHVM fixes an allocation/free size mismatch for shared logging arrays wrapping arrays with a string-key table, which could pass an interior pointer and incorrect allocation size to jemalloc. [3514f777ed](https://github.com/hershel-theodore-layton/hhvm/commit/3514f777ed2a967ce49690612f4ba04395efba29)

## Breaking Changes

- `__PackageOverride` is also rejected when a file physically belongs to an explicit package with strict isolation, closing the same escape route already blocked for implicit packages. [e48e4b7856](https://github.com/hershel-theodore-layton/hhvm/commit/e48e4b7856ff8a8195173240a664bd6ce178917f)

## Future Changes

- Named callback arguments now participate in the same staged lambda-inference passes as positional arguments, removing inference failures that depended on argument order. Function subtyping also keeps named parameters out of positional variadic and type-splat tails. [e620163247](https://github.com/hershel-theodore-layton/hhvm/commit/e62016324711df2248ca233ac00bdcdb3fb5a04e) [d708f251ce](https://github.com/hershel-theodore-layton/hhvm/commit/d708f251ce33ee930c09d2b7b917cb91da05bc80)

- HHVM now compares named method parameters by label and optionality separately from positional parameters. This accepts implementations with extra optional named parameters and rejects missing parameters or incompatible `inout` positions that combined slot counts could conceal. [7cb12ea0ef](https://github.com/hershel-theodore-layton/hhvm/commit/7cb12ea0effb207a727830f12a7a8631d7f58d05)

- Runtime checks now keep reordered named parameters paired with their original type hints and defaults. Readonly checks also bind passed arguments to the correct parameter when optional named arguments are omitted, fixing both false rejections and missed violations in the interpreter and JIT. [d9825e5b77](https://github.com/hershel-theodore-layton/hhvm/commit/d9825e5b775a723f5fc261e955f5cab764f16cdc) [9fed0ff97f](https://github.com/hershel-theodore-layton/hhvm/commit/9fed0ff97f97d5b5ce7e159c69bd72a2594b3bce)
