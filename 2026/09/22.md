# 2026-09-22

## Future Changes

- Explicit `null` supplied to an optional named parameter is now preserved instead of being replaced by its default, including under repo-authoritative optimization. [3255cabee6](https://github.com/hershel-theodore-layton/hhvm/commit/3255cabee6561c8f56584d0901941edb81ec6f9a)

- Readonly argument flags now follow the same reordering as named argument values, including constructor calls, fixing incorrect acceptance and rejection of calls. [3dac710c75](https://github.com/hershel-theodore-layton/hhvm/commit/3dac710c75a951ff9d37b8e11678a151f367f166)

- Memoization wrappers now order and forward named parameters correctly, fixing runtime failures for memoized functions and methods. The temporary typechecker restriction from September 18 remains active; this commit does not yet make the combination available to normally typechecked code. [d3597e3fe5](https://github.com/hershel-theodore-layton/hhvm/commit/d3597e3fe5770b4c3b95eda4c58db04437c6b4cf)
