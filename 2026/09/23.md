# 2026-09-23

## Breaking Changes

- Dynamic string-to-class references to classes in strict packages now receive an independent strict-package check in the interpreter, JIT, and native class APIs. `raise_dynamic_class_load_error` defaults to true for strict packages; explicit false selects sampled notices. `__DynamicallyReferenced` does not bypass this policy. ## Future Changes

- Renaming a named parameter now counts as a declaration change during saved-state initialization, ensuring callers are rechecked for missing or unexpected argument labels. Positional parameter names remain irrelevant to that comparison. [7ce004b6be](https://github.com/hershel-theodore-layton/hhvm/commit/7ce004b6be921a38ce5b3048f6c93136cff551f9)
