# 2026-09-24

## Future Changes

- Opt-in class-pointer bound widening can infer `classname<T>` when generic constraints coerce a `class<T>` value into a string-like type, preventing overly narrow inferred types. The lower- and upper-bound rollout levels remain zero by default. [d0bdd39d7f](https://github.com/hershel-theodore-layton/hhvm/commit/d0bdd39d7fed5190aecf3d33bacf74313dba27db)

- Readonly values may now be passed as named arguments when the corresponding parameter accepts readonly values. The typechecker binds readonly checks by label, fixing errors caused by omitted or reordered named arguments. [45fa38f59c](https://github.com/hershel-theodore-layton/hhvm/commit/45fa38f59cc7249f53c93b1dcaf6f832c8b20505) [3e1ffa6122](https://github.com/hershel-theodore-layton/hhvm/commit/3e1ffa6122105f186a68ba8b6a38ab86f9e08b36)

- Argument-unpacking checks now count only positional parameters and arguments, fixing spurious arity errors around optional named parameters. Positional variadics followed by named parameters are also identified correctly during lambda checking. [0cf2a094cf](https://github.com/hershel-theodore-layton/hhvm/commit/0cf2a094cf33f75fc73ee95fbaf06f52ef536803) [626c5ea848](https://github.com/hershel-theodore-layton/hhvm/commit/626c5ea84849bce55c0552e86b0c210faefc7f3b)

- `--infer-dynamic` now preserves named labels in suggested callback types; a call such as `$f(n=1)` produces `(function(named int $n): mixed)` instead of a positional function type. [c7a7d272a9](https://github.com/hershel-theodore-layton/hhvm/commit/c7a7d272a9c6f9a02db6ddde62d0a3e883f7f420)

- `meth_caller` now rejects methods with named parameters, including named variadics, with `Typing[4527]` because the runtime cannot call those methods through that helper. [4b05630dab](https://github.com/hershel-theodore-layton/hhvm/commit/4b05630dabf2eff10086ffe8a98b0f07cbcaf9a3)

- Repo-authoritative analysis no longer assigns argument types to incorrect parameter slots when named arguments are omitted, preventing an HHBBC invariant failure. Compiler-generated coeffect rules also skip unemitted nameless variadics when calculating parameter indexes. [1c03d83d74](https://github.com/hershel-theodore-layton/hhvm/commit/1c03d83d74387f7d2027a51b9d0e0d02814bf4f0) [b32892d482](https://github.com/hershel-theodore-layton/hhvm/commit/b32892d48203d4a4484eb353f6059b6800b560dd)
