# 2026-09-25

## Highlights

- Under implicit pessimization, functions and non-overridable methods returning `vec<mixed>`, `dict<arraykey, mixed>`, `vec_or_dict<arraykey, mixed>`, or `keyset<arraykey>` can retain those exact return types as fully runtime-enforced top container types. Overridable methods retain pessimization so narrower element-type overrides remain sound. [1a3b9802b4](https://github.com/hershel-theodore-layton/hhvm/commit/1a3b9802b4053b67ee2c59e273b880c29d0f7190)

- Explicit reified type arguments on parent instance-method calls such as `parent::method<int>()` are now preserved by the typechecker, avoiding false missing-type-argument errors. [ee3fbe441c](https://github.com/hershel-theodore-layton/hhvm/commit/ee3fbe441ce9e3923453f57b026809d4df5aa0f2)
