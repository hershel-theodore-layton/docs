# 2026-09-28

## Highlights

- Typed open shapes are now enabled by default through `typed_open_shapes=true`. Normalizing `supportdyn` over open shape tails also correctly distributes union tails. [b60a3f7001](https://github.com/hershel-theodore-layton/hhvm/commit/b60a3f7001b6a31da44bdfafa0a30a8a8e8b41b7) [5ba371e121](https://github.com/hershel-theodore-layton/hhvm/commit/5ba371e121156c0ea0df1f637a2f5348baae6e1c)

- A new warning detects expressions typed `dynamic` returned through an explicitly declared return type that is not fully enforced at runtime. Fully enforced and like-typed return positions, including async return-value enforcement, are exempt. [64f7043e62](https://github.com/hershel-theodore-layton/hhvm/commit/64f7043e62329803b10a7b28f876538b3136c5c0)

- `--validate-isolation <file>` checks a candidate list of repo-relative file paths against a temporary strict package and reports boundary violations. Exit statuses distinguish a successful check (0), violations (2), and unknown or overridden input paths (10); `--json` provides structured output. [b3a8b8384f](https://github.com/hershel-theodore-layton/hhvm/commit/b3a8b8384f8ac5cbd135e066939196559c776300)

## Future Changes

- Class-pointer bound widening gains separate source-level settings for which class-pointer types are widened, independently of the string-like constraint levels that trigger widening. These settings remain zero by default. [1307864bde](https://github.com/hershel-theodore-layton/hhvm/commit/1307864bdedf111bc0c9adfb0c291188a323af65)

- Experimental shape splats used with `RepresentableAs` now resolve residual polymorphic splats before checking the represented key and value types. The conversion remains one-way; `RepresentableAs` cannot itself be unpacked as a shape. [8e614e9db2](https://github.com/hershel-theodore-layton/hhvm/commit/8e614e9db27545532d2acd2cfc1393a3f71a3e61)

- Experimental shape splats that introduce non-denotable union field types are rejected in aliases, newtypes, parameter hints, and return hints unless `union_intersection_type_hints` is enabled. Redundant singleton `shape(...T)` hints receive a diagnostic and quickfix, with a specialized rewrite for `shape(...dynamic)`. [9407783fdd](https://github.com/hershel-theodore-layton/hhvm/commit/9407783fdd7388b4c458c72f8462214cf8efdba1) [c8419798fb](https://github.com/hershel-theodore-layton/hhvm/commit/c8419798fb82cba1803db29f9588c8a0cff7680c) [c549af8941](https://github.com/hershel-theodore-layton/hhvm/commit/c549af8941e8009a610329c63d5b1b36ffbb3039)
