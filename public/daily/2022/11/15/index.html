Daily digest

Tuesday, November 15, 2022

7 noteworthy changes recorded on this day.

DayWeekMonth
←Previous day→Next day

Highlights

  • Expression-tree type inference no longer passes pessimised like-types to makeTree when the virtual expression calls a pessimised function. 6f9d9ad3bc
  • The bundled Set declarations now preserve their element type across iteration and common operations such as map, filter, values, and conversions. This should improve inference for projects using legacy Hack collections. f5ea07c6fa
  • Dead HH\FIXME\UNSAFE_CAST removal is now integrated with hh_server, including repeated analysis until no further redundant casts can be removed. 097f3c19ad 6ebee6b689
  • An internal type alias may now refer to another internal type from the same module. 61917d4bf0
  • HH\classname_from_string_unsafe() is now declared in the HHI files. It converts a string to classname<mixed> without eager validity or module checks and is intended only for exceptional migration cases. 385ddd879a

Breaking Changes

  • Class-level user attributes are typechecked outside the class context, so self is no longer available in their arguments. Module-internal names remain usable there when the attribute is evaluated inside the same module. a83ac0b2c2
  • DirectoryIterator and FilesystemIterator now iterate over ~SplFileInfo, since extraction flags can make FilesystemIterator::current() return a string or the iterator itself. 7380211047
