Highlights

  • An experimental .hhconfig option, code_agnostic_fixme, makes an HH_FIXME suppress errors at its position regardless of the recorded error code. It is intended as a temporary aid for migrations such as Sound Dynamic pessimisation, where error codes may change; the default remains code-specific suppression. fe4f7ada87
  • Generated hack.TypeInfo symbol facts now contain cross-references for common nested type hints such as Awaitable<?Foo> and vec<Foo>, rather than only for a bare class name. Consumers of symbol-info facts can use these links for more complete type navigation. 0c39bf8718
