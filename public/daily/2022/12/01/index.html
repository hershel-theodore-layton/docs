Thursday, December 1, 2022

Highlights

  • Sound-dynamic checking now treats values captured by a <<__SupportDynamicType>> closure as like-types. This makes nested closures dynamically callable without repeatedly checking every nesting level, though hover and TAST output inside the closure may now show captured T values as ~T. 53d4897785
  • The missing-<<__Override>> lint now offers a quick-fix, either adding a new attribute block or inserting __Override into an existing one. 624e58033f
  • Go-to-definition and hover now distinguish a callable property from a method with the same name in expressions such as ($object->callback)(). 77fdfabcc6
  • DOMElement::$attributes is no longer redeclared as non-null in the bundled HHI. It now inherits the nullable ?DOMNamedNodeMap<DOMAttr> declaration from DOMNode, so callers must handle null. d2bd42ae6c
