Friday, December 2, 2022

4 noteworthy changes recorded on this day.

Highlights

  • Invalid types encountered while localizing where constraints are now reported. This closes a type hole involving generic type-constant accesses and can reveal errors in signatures that previously passed. b614e9be2f
  • Pair<T1, T2> is now typed as a ConstVector<T1 | T2>. Collection operations such as at(), map(), values(), and toImmMap() consequently preserve the union of the two element types instead of widening to mixed. dd7ca5fa24

Future Changes

  • A trait and its required class may declare the same private property without producing a spurious ambiguous-access error in the pre-stable require class feature. In this case the declarations describe the same property rather than shadowing one another. 81231622de
  • The unstable type-refinement implementation now supports loose as and super bounds, including their subtyping rules. Accessing a type member through an inexact refinement is rejected because the member is not known exactly. The feature still requires the type_refinements unstable-feature opt-in. 1eaa4bece4
