Highlights

  • A type structure derived from an unbounded type constant no longer exposes class-specific fields such as classname. Add an appropriate classish bound before accessing those fields; an unbounded type constant is treated consistently with one bounded by mixed. ad69f94600
  • Hovering over declarations now explains the class, interface, trait, enum, enum class, type, and newtype keywords. d079884920

Future Changes

  • Unstable type refinements now use dedicated typing error codes: 4468 for access through an inexact refinement, 4469 for unsupported refinements, and 4470 for invalid class refinements. Suppressions written against the former generic error codes may need updating when adopting the feature. c50044fcc6
