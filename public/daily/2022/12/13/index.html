Tuesday, December 13, 2022

5 noteworthy changes recorded on this day.

DayWeekMonth
←Previous day→Next day

Highlights

  • Missing required-XHP-attribute errors now point to the attribute declaration rather than the containing XHP class. df7da6ed99
  • An unbounded generic is now treated like a generic explicitly bounded by mixed when accessing type structures. Class-specific fields such as classname require a classish bound. eb806ee50a
  • Several HH\TypeStructure fields have more accurate bundled declarations: return_type and value are mixed, while access_list is ?varray<string>. 7926fe9c9d
  • Native Facts now coalesces simultaneous update requests behind an already-pending Watchman query instead of scheduling one query per caller. 3db59e7600

Future Changes

  • Calling HH\autoload_set_paths() while native autoloading is active now raises a deprecation notice. Deployments can set Autoload.UserlandEnabled=false to turn such calls into InvalidOperationExceptions and find code that must migrate to native autoloading. 0e45a0afae
