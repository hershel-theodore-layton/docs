Future Changes

  • Under everything_sdt, UNSAFE_CAST<TFrom, TTo> is now represented as an upcast to ~TTo, including in the TAST. Tools consuming the TAST should expect the like-type, which reflects that the cast does not provide a runtime guarantee. 90a13f5252
  • Private methods in sound-dynamic classes are now checked as dynamically callable, just like non-private methods, because they can still be reached through dynamic or like-typed receivers. This can expose previously missed sound-dynamic errors. 822346b50c
  • Implicit pessimisation no longer treats type constants as runtime-enforced by default. Projects experimenting with sound dynamic typing should not rely on a type-constant access alone to enforce the resulting value. f598a1f437
