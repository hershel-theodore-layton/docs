Highlights

  • Projects using implicit sound-dynamic pessimization can now put the experimental <<__NoAutoDynamic>> attribute on a top-level function or class to disable automatic pessimization within that declaration. This is a local escape hatch: use it where the declaration is deliberately kept outside the dynamic boundary. 5bf4a9604d
  • Disjointness checks now terminate safely when generic upper bounds form a cycle, preventing affected subtype queries from diverging. f298d5f2fe
