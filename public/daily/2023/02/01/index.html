Highlights

  • Several APC declarations now have narrower capability requirements than their former implicit [defaults]: read operations such as apc_exists() require [read_globals], mutations require [globals], and apc_sma_info() is pure. This allows callers with correspondingly restricted contexts to use these APIs. 2aaa02ccf6
  • The Rust .hhconfig reader now recognizes union_intersection_type_hints, so projects using that parser can enable union and intersection type-hint syntax consistently. 229121c557
