Thursday, February 9, 2023

5 noteworthy changes recorded on this day.

DayWeekMonth
←Previous day→Next day

Highlights

  • An async lambda passed where dynamic is expected now infers its omitted return type normally, rather than assuming a dynamic return and rejecting ordinary returns such as return 1. e2a1356eeb
  • Large shape types now spend type-printer fuel per field and are explicitly truncated when the budget is exhausted, keeping diagnostics and hover output readable. 452112ed92
  • <<__NoAutoDynamic>> is now supported on individual methods in both explicit and implicit Sound Dynamic pessimisation. It prevents ~ and supportdyn from being added to that method's signature without disabling dynamic calls to an otherwise Sound Dynamic class. 7da433acc8
  • Exception rendering retains the original class, file, and line when an overridden Exception::getMessage() itself throws, making secondary failures substantially easier to diagnose. 0a6378d03a

Future Changes

  • Pre-stable class refinements now distinguish type members from ctx members. Refining a type constant with ctx, or a context constant with type, produces typing error 4471. f04bef3304
