Breaking Changes

  • HHVM now defaults Autoload.Enabled to true. Deployments that need the previous behavior should explicitly set Autoload.Enabled = false. a714af2744
  • Thrift stream and sink failures are now delivered as ThriftApplicationException rather than TApplicationException. Code catching the older concrete class should catch the new exception or a shared base such as Exception. 0e2f06e781
