Highlights

  • Sound Dynamic union, intersection, and subtype processing no longer accumulates recursive supportdyn wrappers that can overflow the typechecker's stack, and it now retains the wrapper while comparing two supportdyn types. 0e60e722c7 de66255762
  • Hover in Sound Dynamic projects can show an expression's type under dynamic assumptions when it differs from the ordinary type. The additional TAST is generated on demand for hover rather than for every typecheck. f0ad1da10f bdad09d3c0
  • Sound Dynamic generic inference now removes like-types in safe covariant positions before solving a type variable, and tuple reads and writes are no longer unnecessarily pessimised. 4d6992a5db 76d4a7b435
  • The experimental SDT analyzer now propagates NeedsSDT constraints from dynamic instance and static method calls to classes. da198e2d89
