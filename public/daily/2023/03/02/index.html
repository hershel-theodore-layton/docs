Highlights

  • Sound-dynamic inference can now solve variables with supportdyn<T> on both sides, push supportdyn through Traversable and KeyedTraversable, and use safe dynamic-aware variance when checking overrides. This accepts more valid SDT collection and override patterns without permitting unrelated like types to override one another. ccbed68c5c 58073f2561 7aec7bc986
  • HH\ImplicitContext\get_state_unsafe() can report whether the current implicit-context state is null, value, soft-set, inaccessible, or soft-inaccessible. Observing this state can undermine memoization guarantees, so the API is intended only for controlled migrations and diagnostics. 9b41b6f14c
  • A constructor declared final may no longer be overridden merely because its hierarchy uses <<__ConsistentConstruct>>; Hack now reports the override that HHVM would fatal on while loading the class. 7100e0a74a
