Monday, March 6, 2023

4 noteworthy changes recorded on this day.

Highlights

  • Standalone IDE mode now publishes fresh diagnostics after files are opened or changed, without waiting for a persistent hh_server connection. 735edbcea0
  • A deployment in PACKAGES.toml may now select multiple domains, and each domain is interpreted as a regular expression. HHVM's package information now carries deployments so server requests can select the active package set from the host name. 8a423bfd07 44443ec5d4
  • File attributes are now attached to module declarations. A file containing only new module declarations will no longer skip validation of an invalid or misspelled file attribute. 833db87aae

Security

  • Blowfish password hashing now handles short salts correctly instead of returning an invalid result, addressing CVE-2023-0567. 8497459de0
