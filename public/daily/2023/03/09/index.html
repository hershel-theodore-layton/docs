Highlights

  • Class type refinements such as Box with { type T = int } no longer require <<file:__EnableUnstableFeatures('type_refinements')>>. 4fc409a7f6
  • Under sound dynamic, an as refinement from an integer to a string-backed enum—or the reverse—is now weakened to ~Enum. This reflects the runtime coercion hazard instead of treating the result as a fully trusted enum value. 57bdb70e4f
