Highlights

  • PACKAGES.toml now accepts soft_includes. Access across a soft include still produces a package diagnostic, but uses the distinct error code 4473 rather than hard cross-package error 4472, so migrations can suppress the soft boundary without hiding a later hard violation. 484aecd02c 4f27d55a1f
  • For $base[$key] = $value, Hack now checks $key before $base, matching HHVM's evaluation order. This fixes both unsound refinements and valid programs rejected because the old checker assumed the reverse order. a993d20925
