Monday, March 27, 2023

4 noteworthy changes recorded on this day.

DayWeekMonth

Highlights

  • dict is no longer automatically pessimised. Direct construction and indexing preserve value types such as dict<string, int>, while like-typed values produce an explicit type such as dict<string, ~int>. 73c97aac94
  • In autocomplete, typing -> after a vec, dict, keyset, or string now offers compatible HSL functions and rewrites the expression into a function call with argument placeholders. 73284d7d46
  • Package validation now requires each deployment's package set to be transitively closed over includes and reports the packages missing from an incomplete deployment. 43bcd2a962

Future Changes

  • Symbol identification now sees method calls through a preview readonly expression, restoring navigation and references for those calls. 857047246c
