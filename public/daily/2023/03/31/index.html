Friday, March 31, 2023

8 noteworthy changes recorded on this day.

Highlights

  • HSL adds Vec\map_with_key_async(), which invokes an async callback with each original key and value in parallel and returns an Awaitable<vec<_>>. c2341d38b1
  • Nested collection constructors with explicit types now keep precise inner types—for example, vec<vec<int>>[vec[2, 3]] remains vec<vec<int>> rather than acquiring an unnecessary like type. Mutable collection classes are now always treated as pessimised built-ins; the configuration flag no longer disables that behavior. 5ad92d1c7a 103067848a
  • Lint 5650 recommends async ... ==> await ... when a synchronous lambda directly returns an Awaitable, improving stack traces. Lint 5651 warns about lambdas inferred as Awaitable<Awaitable<_>>, where an inner await was likely omitted. 328976bc0a 642ca62d90
  • The experimental package NAME expression now has type bool, and an undefined package name produces a naming error based on PACKAGES.toml. 480031f13c
  • Capability checks are now skipped for virtualized expression-tree calls, which are typechecked but never executed. Pure code can therefore construct DSL expressions whose virtual methods have [defaults] without receiving a false call-capability error. 9e6d3f539b
  • Local-variable completion items now display the variable's inferred type instead of the generic label “local variable.” 4f8762d581
  • HH\Lib\Async\Poll and BasePoll no longer recurse through long already-satisfied awaitable chains, avoiding stack overflows in large polling workloads. 2033efe304

Breaking Changes

  • Sound-dynamic function-call checking now evaluates each argument once instead of exploring exponentially many static/dynamic combinations. Some previously accepted generic calls can now require an explicit type argument when inference commits to a like type too early. 9f106c6329
