Monday, April 3, 2023

6 noteworthy changes recorded on this day.

DayWeekMonth
←Previous day→Next day

Highlights

  • A new lint reports casts such as (int) new C() where a non-primitive value is cast to a primitive in a way that is unlikely to be meaningful. 593f41db78
  • Nested type parameters in higher-kinded types no longer produce a false naming error for not beginning with T. 9b5699d6ee
  • Watchman-backed status checks now qualify root-relative filenames correctly and keep the server's Watchman clock current. This fixes stale “No errors” results and indefinite hh_server sync waits after a file changes. a084e13751 a3f47f498e
  • The missing-method diagnostic now offers one quick-fix that generates all required method stubs, rather than a separate fix for each method. 8dfff9994e
  • Invalid expression-tree splices now describe the DSL, the expected splice type, the actual Hack value, and the DSL's documentation link instead of reporting only generic expression-tree terminology. 833661e119

Breaking Changes

  • HH\autoload_set_paths() now always throws, as part of the migration to native autoloading. This change is backed out on April 10 while remaining callers are migrated. d419828855
