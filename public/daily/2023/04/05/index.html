Daily digest

Wednesday, April 5, 2023

6 noteworthy changes recorded on this day.

DayWeekMonth
←Previous day→Next day

Highlights

  • XHP completion now inserts required attributes, with snippet placeholders when the client supports them. 65e5432943
  • “Extract into variable” is no longer offered for expression selections that cannot be extracted safely. 355e174dce
  • Referencing an outer local directly inside an expression tree now produces a contextual diagnostic and a quick-fix that splices the variable into the tree. 2635c40267
  • Soft-package and soft-deployment validation now follows transitive soft relationships and reports invalid configurations more precisely. 657f4986f1

Future Changes

  • Under implicit pessimisation, inout parameters in function-type and lambda hints now receive like-types even when their runtime types are unenforced. 3be0d658a1
  • Abstract context constants no longer receive an implicit as supportdyn<mixed> bound. An unbounded context constant can therefore still be instantiated with [], which is the context equivalent of mixed. 639c0f130a
