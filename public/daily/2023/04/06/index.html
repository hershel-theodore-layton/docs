Highlights

  • A lambda nested inside a finally block may return normally; it is no longer treated as though its own body were part of the enclosing finally. 52c136dd3a
  • Rust elaboration now reports more accurate positions and error kinds for reading from [], invalid <<__Deprecated>> strings, generic entry points, duplicate class constants, and wildcard type parameters. e25f032cde a0b5a2c4a4 c681a172f8 93930d39c8 fcab758a8c

Future Changes

  • Implicit pessimisation now rejects a bare or implicit return from a function whose declared return type is non-void; it no longer accepts the missing value through dynamic. 6f9c0e2cb3
  • The experimental newtype_super_bounds feature now honors class-typed lower bounds such as newtype T super C = mixed. b87d8ce093
