Highlights

  • New HH\stdin(), HH\stdout(), and HH\stderr() functions replace the magic STDIN, STDOUT, and STDERR constants. They return the corresponding resource and throw RuntimeException in server mode, where standard streams are unavailable. f89adc0d2b
  • Standalone IDE diagnostics now refresh lazily on code-action requests, hide typing errors while a parse error is present to match hh, and remain visible when an in-progress full check restarts. 98c35d4bbb 276933c9b7 1e6f53b906
  • Repository-authoritative builds with an active deployment now omit files belonging to packages outside that deployment. Builds fail with a clear error when the configured deployment is absent from PACKAGES.toml; files that define modules remain included. b170bd05fa
