Highlights

  • A new “flip around comma” code action swaps adjacent arguments, parameters, collection elements, shape fields, and similar comma-separated items. a9aa1df6ee

Breaking Changes

  • XHP attribute access now typechecks the underlying getAttribute() call, including the method's signature and required capabilities. Custom XHP bases with an incompatible or missing method may receive new errors where the attribute is read. c6b3bc7f59

Future Changes

  • Runtime validation for <<__ModuleLevelTrait>> requires the annotated trait to be public and permits it to use only other module-level traits. Invalid combinations fail consistently before optimized execution. d38803e101
