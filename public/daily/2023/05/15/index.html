Daily digest

Monday, May 15, 2023

4 noteworthy changes recorded on this day.

DayWeekMonth
←Previous day→Next day

Highlights

  • Switch-exhaustiveness diagnostics list at most ten missing cases, in declaration order, instead of attempting to render every case and potentially crashing on large enums. 5c78876f00
  • A successful equality comparison now refines each operand with the other's type. For example, inside $value === 42, a ?int value is known to be int without a separate non-null assertion. ec4f5b16e0

Breaking Changes

  • The obsolete hh --coverage and hh --color commands, along with the old IDE coverage status, have been removed. They predated constraint-based typechecking and no longer represented meaningful type coverage. 10a04c1344
  • Enabling implicit Sound Dynamic no longer implicitly enables the supportdyn type-hint syntax. Projects writing supportdyn<T> directly must explicitly enable enable_supportdyn_hint; generated pessimised declarations are unaffected. 126a09182e
