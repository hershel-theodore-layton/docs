Breaking Changes

  • When deployment enforcement is enabled, HHVM now rejects direct, dynamic, function-pointer, and closure-mediated calls to top-level functions whose module is outside the active deployment. 9ad9cac167

Future Changes

  • Experimental case types now require conservatively disjoint runtime variants. Variants whose shallow runtime tags may overlap produce a type error; this initially includes all pairs of object types and overlapping primitive unions. ab1c79066d
