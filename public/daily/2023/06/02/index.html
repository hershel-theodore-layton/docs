Friday, June 2, 2023

3 noteworthy changes recorded on this day.

DayWeekMonth
←Previous day→Next day

Highlights

  • Nullable member-access errors now offer an “add null-safe get” action that changes same-line $value->member access to $value?->member. 9a7621ecd2

Breaking Changes

  • Runtime type tests such as $value is dynamic are now rejected. HHVM cannot test whether an arbitrary value supports dynamic, so using the result to refine $value to dynamic created a type hole. Test for a concrete runtime type instead. 89bedcf12d

Future Changes

  • The nested-Awaitable lint again recognizes Awaitable<~Awaitable<T>> under implicit pessimisation, so accidental double-awaitable returns are not hidden by the like-type wrapper. 979f436be9
