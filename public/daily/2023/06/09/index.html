Highlights

  • Projects may add a repository-root CUSTOM_ERRORS.json file whose pattern rules attach project-specific explanations to matching Hack errors. The configuration is loaded by hh_server, hh_single_type_check through --custom-error-config-path, and the standalone IDE diagnostic path. 4f14454979 bc7eeb8c69 5b96c02ea8 42214e464a
  • A new “inline method” refactoring replaces a suitable method call with the method body and removes the method when safe. dcc03923cb
  • Autocomplete returns snippets only when placeholders or edits require snippet semantics, reducing unwanted snippet-mode behavior for ordinary completions. 741b3123bf
  • Standalone IDE diagnostics no longer build up a backlog while typing in large files; obsolete intermediate TAST computations are discarded so squiggles jump to the latest edit. cad5047300
  • Moving a module between packages is now treated as a major incremental change, ensuring all affected dependents are rechecked. ace5a949c7
