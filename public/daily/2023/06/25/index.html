Highlights

  • Custom-error configuration now carries an explicit schema version so the format can evolve without tying configuration migrations to an HHVM release. A malformed CUSTOM_ERRORS.json now terminates hh_server with a configuration error instead of being silently ignored. d26d33e721 57f963ad90

Future Changes

  • In everything_sdt mode, <<__NoAutoLikes>> can suppress automatically introduced like-types on function and method returns, inout parameters, properties, lambdas, and promoted constructor properties. It does not disable supportdyn bounds or dynamic-callability checking. fbf8d8aa22
  • Like-type pushing now resolves type variables with identical upper and lower equality bounds, improving inference around where type constraints and type constants. be102b4bae
