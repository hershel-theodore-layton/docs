Highlights

  • hh_single_type_check --map-reduce can now run configured typed-AST analyses and print their reduced JSON result. 0ffd752fc9
  • The new hphp_debug_caller_identifier()[leak_safe]: string runtime helper returns the caller's full function or Class::method name without constructing the full hphp_debug_caller_info() dictionary. dfc3cbbaa0
  • Package module patterns now use prefix-glob semantics matching the runtime: foo.* matches descendants of foo, * matches every module, and other patterns are exact names. 3ef62b5f28

Security

  • Eval.SetHeadersInServerSuperGlobal can now prevent request headers from being copied into $_SERVER; applications can retrieve the raw protected header map with HH\get_headers_secure() instead. The compatibility default remains enabled. d3b6066fb8
