Future Changes

  • HHVM now enforces case-type runtime constraints by default instead of treating them as mixed. This completes the runtime side, but source use remains behind the case-types opt-in until its later Preview transition. ed350e54e2
  • The runtime implementation of preg_get_error_message_if_invalid() can validate a regex and return ?string without raising the usual malformed-pattern warning. Its HHI declaration has not landed yet, so typechecked projects cannot use it normally at this stage. 922ca33aa7
