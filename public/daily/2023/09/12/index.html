Tuesday, September 12, 2023

Highlights

  • Open-source HHVM builds once again parse and enforce PACKAGES.toml, and runtime package matching now agrees with the typechecker that foo.* includes foo itself while exact matches take precedence. a11552fc4f 5f0823ca7d
  • IDE completion cards for top-level functions now include their parameter and return signatures. 78618a4c42

Breaking Changes

  • The repo-mode soft-package warning behavior from September 7 has been temporarily backed out. Repo builds once again omit soft packages and can fail with undefined-symbol errors until the corrected reland. 16c8aaf940
  • The experimental hh --pause and hh --resume commands have been removed; file changes always trigger the normal full-check workflow. 3bd5161a2c

Future Changes

  • Opt-in strict switches now recognize integer literals, require a default for the open-ended int domain, and report repeated literal arms. 1fa08641fe
