Breaking Changes

  • Reflection's default-expression text for array access with a class constant, such as $items[C::class], is now emitted like the equivalent string-key expression. Invoking the function is unchanged, but reflective evaluation now follows the same failure behavior as $items["C"] instead of the old special case. e51ba0edb3

Future Changes

  • Opt-in strict switches now accept integer-valued class constants and transparent enum constants, and can diagnose repeated constants where their symbolic names match. d2a05fad8e
