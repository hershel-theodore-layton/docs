Highlights

  • Exception breakpoints now work while HHVM's JIT is enabled. a225476c97

Security

  • Proxygen responses no longer send Content-Length together with Transfer-Encoding. Emitting only the transfer coding avoids ambiguous HTTP response framing and keeps HHVM compliant with RFC 9112. b1a80d1d3d

Future Changes

  • Hack now rejects static calls such as T::foo() when T is a trait with the pre-stable require class constraint. Call through the concrete class that satisfies the requirement instead; the new diagnostic is typing error 4476. 66031e6a16
