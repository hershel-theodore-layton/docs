Highlights

  • The Hack REPL now warns when a file loaded into its current request has changed on disk, because the already-loaded code will not be refreshed until a new request. 56722eba42
  • The quick-fix for debugger-style =$expression statements now produces debugger_dump($expression) instead of var_dump(). The debugger serializer honors custom debug displays, which helps avoid revealing a value's raw representation. eb224b9d92

Future Changes
