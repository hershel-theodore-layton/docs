Daily digest

Tuesday, October 31, 2023

6 noteworthy changes recorded on this day.

DayWeekMonth
←Previous day→Next day

Highlights

  • Nullable runtime assertions now refine like types precisely: if $x has type ~Base, then $x as ?Derived is inferred as ?Derived just like the non-nullable assertion. e9d270eff8
  • HHVM no longer intermittently loses an implicit context when only the low byte of its internal pointer is zero. a7c1d33f17

Breaking Changes

  • Dynamic static calls with a fixed class, such as C::$method(), are now parse errors. If both pieces truly need runtime dispatch, the remaining supported form is $class::$method(); otherwise call the method by its literal name. e120477a21
  • hh_client lsp must now be launched with an explicit project-root argument or from the project root (or one of its subdirectories). Editor integrations that started it from an unrelated working directory must set the root or working directory. 773a315692

Future Changes

  • The unstable nested-await implementation now diagnoses sequential awaits mixed into incompatible concurrent expressions, including sequential awaits inside a concurrent block. 13ad012627
  • Under implicit pessimisation, HH\Readonly\as_mut() now retains its declared return type instead of acquiring an automatic outer like type. 5d156974e2
