Highlights

  • Enum-class-label completion no longer resolves a contravariant type variable prematurely to mixed or supportdyn<mixed>, allowing the IDE to retain the useful label candidates implied by narrower bounds. ee19abb9a3
  • HHVM's sodium extension adds the missing Ristretto255 point operations: sodium_crypto_core_ristretto255_add(), sodium_crypto_core_ristretto255_sub(), sodium_crypto_core_ristretto255_is_valid_point(), and sodium_crypto_core_ristretto255_random(). ed0c96f189

Breaking Changes

  • Ancestor traversal now gives directly declared implements entries precedence over interfaces inherited through extends. For a type that reaches the same generic interface at several instantiations, this can change which instantiation wins and can expose type errors that the previous ordering hid. 23ac49c0fa
