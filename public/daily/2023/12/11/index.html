Highlights

  • nameof now accepts transparent and opaque type aliases and returns the alias's own name. For example, type T = int produces typename<int>, while an opaque newtype U produces typename<U>. 119ec37e14

Future Changes

  • Runtime type constraints now recognize the explicit HH\object type as “any object.” This is groundwork: no builtin or HHI declaration uses the new constraint yet. 93db8b6ada
