Friday, December 15, 2023

3 noteworthy changes recorded on this day.

Highlights

  • An opt-in strict UTF-8 parser mode can reject source files containing invalid byte sequences. Hack uses strict_utf8=true; HHVM's Eval.StrictUtf8Mode remains off at 0, rejects source but permits eval input at 1, and rejects both at 2. 002372fd69

Breaking Changes

  • Constructors of __SupportDynamicType classes are now checked under dynamic assumptions, just like their other methods. Constructors that store or return values incompatible with dynamic construction can therefore gain new sound-dynamic errors. 9004eeeb25

Future Changes

  • Module-level traits have advanced from Preview to Ongoing Release. The runtime compiler can accept them during the rollout, while typechecked source still needs the module_level_traits file-level feature opt-in. 9cd2521478
