Highlights

  • hh --single file.php --show-tast now provides a dedicated way to print one file's typed AST. b4fa8c14db
  • Sound Dynamic call inference now tries a dynamic check first when an argument is already like-typed but its generic parameter is not. This removes false errors for calls that mix lambda arguments with pessimised values. f544f07cb4
  • Cross-package calls no longer require the package unstable-feature opt-in. Bundled declarations now also expose HH\module_exists(string, bool)[]: bool and HH\package_exists(string)[defaults]: bool. 6c9d99cc02

Breaking Changes

  • The old <<__AllowMultipleInstantiations>> spelling has been removed; experimental code must use the explicitly unsafe <<__UNSAFE_AllowMultipleInstantiations>> name. 53a31ae7b7
