Highlights

  • Lambda compatibility now compares the full accepted argument range when default parameters are present. A lambda is accepted when it can handle every arity promised by the expected function type, rather than requiring identical minimum arities. 98a4a79060

Future Changes

  • Package configuration parsing now accepts an allow_directories field, canonicalizes its relative paths and optional * suffixes, and rejects paths that do not exist. Typechecker enforcement follows later in the month. 1e848e45b1
