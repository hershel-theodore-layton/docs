Highlights

  • Under Sound Dynamic, calls through like-typed receivers and like-typed function values now produce like-typed results. For example, calling an int-returning method through ~C yields ~int, closing an unsound path that previously inferred plain int. 2b51ce34b0

Future Changes

  • The experimental sound_enum_class_this_type feature now localizes this in enum-class member types against the enum class being accessed, rather than the surrounding class. 2d28f2b3ba
