Wednesday, March 6, 2024

3 noteworthy changes recorded on this day.

DayWeekMonth
←Previous day→Next day

Security

  • Opaque representations of internal generic classes now preserve their type arguments across module boundaries. Distinct instantiations are no longer treated as compatible outside the defining module. 86f1847927

Future Changes

  • HH\classname_to_class() and HH\class_to_classname() now accept preview readonly classname<T> arguments while remaining pure, allowing readonly class values to pass through the migration helpers without a mutable-value error. 03233e7456
  • Function type hints in ongoing release now support the optional qualifier without a per-file opt-in. Types such as (function(int, optional int): void) can describe functions whose trailing parameter has a default, but the feature remains pre-stable. 6e9dfb645d
