Thursday, April 4, 2024

Highlights

  • HH\Facts\files_with_attribute_and_any_value() now uses the in-memory symbol map by default again, avoiding stale or incorrect DB-only results while files are changing. Deployments that need the old strategy can set Autoload.DB.UseSymbolMapForGetFilesWithAttributeAndAnyVal to false. 70bd28a835

Breaking Changes

  • Variadic parameters must now have a capture variable. Replace bare ... in functions, methods, and lambdas with a named parameter such as ...$args; the runtime parser now rejects the unnamed form that the Hack typechecker already rejected in strict code. 64a98f185b
