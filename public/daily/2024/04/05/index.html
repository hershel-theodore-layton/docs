Friday, April 5, 2024

4 noteworthy changes recorded on this day.

DayWeekMonth

Highlights

  • Lambda arity mismatches now produce TAST holes around the incompatible function value or lambda. Tools that consume typed ASTs can use the expected and actual function types to offer more precise migrations. 7eccda3526
  • HH\get_executable_lines() no longer reports generated functions or abstract methods as executable. Coverage and debugger clients will no longer see interface methods or class-closing braces as spurious executable lines. 17236d2daf
  • Constraint solving now retains the errors from all branches of a disjunction, improving explanations when no branch is valid—particularly for failures involving type-parameter constraints. 85d958bb73

Future Changes

  • Expression-tree collection literals moved from Preview to OngoingRelease as part of their staged rollout. Expression trees themselves remain experimental. eda3f8b79c
