Highlights

  • debugger_dump(null) is now a no-op instead of printing null. This also keeps null-valued notebook and debugger evaluations from producing a redundant display value. ced9997e21
  • HHVM now agrees with the typechecker when a variadic method implements a variadic abstract method while declaring additional compatible non-variadic parameters. These implementations no longer fail at class loading. 743fc08410
  • Repo-authoritative builds now stop on directory-open or file-stat errors instead of silently omitting affected Hack files from the compiled repository. 915842a0ce
