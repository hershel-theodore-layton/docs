Tuesday, April 16, 2024

4 noteworthy changes recorded on this day.

DayWeekMonth
←Previous day→Next day

Highlights

  • hackfmt now builds its line table tail-recursively, avoiding a stack overflow on unusually large source files. 88edd0b8ac
  • hackfmt now keeps an empty module definition on one line as new module foo {}, matching other empty braced declarations. 0fff1574c6

Breaking Changes

  • Inside a module declaration, an imports block must now appear before an exports block. Reorder declarations that currently export first; the restriction prevents range-formatting from losing the original token order. 2f432af79a

Future Changes

  • Repo-authoritative optimization no longer asserts when a case-type union contains an unresolved member. The whole union is conservatively left unresolved, matching non-repo HHVM behavior; case types remain a staged feature. e01cd5e15a
