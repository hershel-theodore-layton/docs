Highlights

  • JSON diagnostics now include a top-level severity field. Consumers of hh --json can distinguish errors from the new warning severity without parsing rendered text. e19bd61dd0
  • While VS Code debugging is paused, newly started request threads are no longer announced until execution resumes, keeping the stopped thread from being displaced in the debugger UI. e2849902e6
  • The “override method” code action now inserts a multiline method body and places the cursor inside it, ready for implementation. 4f550b7331 2298871f36

Future Changes

  • When the opt-in Hack warning system is enabled, LSP diagnostics now reach editors with warning severity and are rendered as warnings rather than errors. 43370c7b5f
