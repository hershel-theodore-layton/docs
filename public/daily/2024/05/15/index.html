Highlights

  • The built-in constants TRUE, true, FALSE, false, NULL, and null are now declared in HHI files, so attempts to redefine them receive a naming error instead of surviving until HHVM's runtime fatal. 47c1ae0958

Breaking Changes

  • __clone() must declare a void return type. Returned values were always discarded; implementations that returned this or another value must remove the return value and keep mutation in the method body. 50376266b5
