Highlights

  • A new lint warns when code catches a broad exception and neither rethrows nor meaningfully uses the exception object, helping surface silently swallowed failures. Additional type-lie checks for HH_FIXME, UNSAFE_CAST, assertions, and explicit dynamic were added at disabled severity for later rollout. 0184f96d16 22b0ea2599

Future Changes

  • With experimental package_v2 enabled, the typechecker now maps files to the most specific matching include_paths entry and enforces path-based package access for public symbols. Internal-symbol enforcement and __PackageOverride support are not included yet. 6cfa1c710a e837faa0c8
  • The experimental sealed_methods feature allows <<__Sealed(C1::class, ...)>> on a method to restrict which classes may override it. Functions cannot use the attribute. 7e28a90a65
