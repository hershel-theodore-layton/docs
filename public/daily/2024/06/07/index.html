Friday, June 7, 2024

6 noteworthy changes recorded on this day.

DayWeekMonth

Highlights

  • The redundant-generics linter once again recognizes a generic used only contravariantly when multiple as bounds simplify to one effective bound, including bounds introduced by implicit pessimisation. 1ca353c4cb
  • Shape refinement no longer causes Shapes::idx() on a different optional field to lose its nullable result type after patterns such as $shape ?? shape() and Shapes::keyExists(). 6254e75cb8
  • The new HH\Facts\validate(vec<string> $types_to_ignore = vec[])[defaults]: void API checks the SQLite Facts database for types mapped to multiple paths and throws UnexpectedValueException when it finds an unignored conflict. 153ec68b9d
  • Hack declarations now expose the pure async CAS helpers HH\RemoteExecution\gen_upload_file(string, string)[]: Awaitable<string> and gen_download_file(string, string, string)[]: Awaitable<bool>. 0c2cb6acbb

Breaking Changes

  • Hack's invalid-index check now diagnoses non-int access to vec, including cases hidden behind inferred generic keys. 6a242bdb0d

Future Changes

  • Unstable expression trees now permit await inside splices when the tree is constructed in an async function. 3c259b10ef
