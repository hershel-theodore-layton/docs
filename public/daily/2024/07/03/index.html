Wednesday, July 3, 2024

3 noteworthy changes recorded on this day.

DayWeekMonth
←Previous day→Next day

Highlights

  • Autocomplete now correctly applies where constraints when a function type's return type has been pessimised to a like type. This restores valid suggestions whose availability depends on the callback return type. 3ba7478771

Breaking Changes

  • Enum-class labels may no longer refer to type constants. Expressions such as E#T or #T now produce a type error when T is a type constant rather than an enum-class member. 3c9a2a4a23
  • HH\ImplicitContext gained an abstract boolean constant named IS_MEMO_SENSITIVE. Subclasses must choose true for memo-sensitive contexts or false for memo-agnostic contexts. This systemlib change precedes the matching HHI declaration added later in the month. 9fbef64f53
