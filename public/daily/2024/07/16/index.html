Highlights

  • A method may use <<__Overlapping('T1', 'T2', ...)>> to tell the disjointness lint which class- and method-level generic parameters are intended to overlap. This lets the lint identify calls whose instantiated types make comparisons or membership checks constant without adding API-shaping where constraints. c94a1e968d
  • Source-analysis tools can query a file's declared module through the pure HH\FileDecls::getFileModuleMembership() and HH\Facts\path_to_module_membership() APIs when module-membership facts are collected and available. The latter accepts a source path and returns the module name, if any. ad00e88510
