Breaking Changes

  • ConstIndexAccess and IndexAccess now constrain their key type parameter with as arraykey; collection contains() and containsKey() declarations received the same constraint. Custom implementations and calls that explicitly supplied an unconstrained, non-arraykey type argument may now fail type checking. 716478479e

Future Changes

  • Experimental class-level where clauses have been removed from the language. They were never enabled as a supported feature; use type refinements for constraints on associated types. 46632da404
