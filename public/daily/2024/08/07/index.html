Breaking Changes

  • The unused hh --format command has been removed. Use hackfmt or editor formatting instead. bf408a3876
  • The deprecated call_user_func() pseudofunction is no longer declared or specially lowered by Hack. Invoke a typed callable directly. e37946a1b1
  • HH\is_vec_or_varray() and HH\is_dict_or_darray() have been removed from Hack's declarations and refinement logic. Use is vec<_> and is dict<_, _> checks. 20333fb1c7
