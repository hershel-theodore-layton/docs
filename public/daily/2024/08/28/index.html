  • Extended type explanations now point back to previously shown definitions, reverse projected subtype direction correctly for contravariant parameters, hide internal supportdyn steps in non-verbose output, and highlight the right-hand side of type definitions. f16ea44b34 9aafe24b2f 303cb33048 fb54ffdd4c

Security

  • Binary and compact Thrift deserialization no longer preallocates containers from untrusted oversized length fields. Initial reservation is capped at 16K entries, and sizes above the supported array limit raise a warning instead of attempting a multi-gigabyte allocation. 72771f6bf6

Future Changes
