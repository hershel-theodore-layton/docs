Friday, August 30, 2024

4 noteworthy changes recorded on this day.

Highlights

  • Tuple type comparison now preserves element order instead of sorting tuples like unions and intersections, so (A, B) is no longer treated as identical to (B, A). 172a6d93c9
  • The new pure HH\Facts\transitive_subtypes<T>(classname<T>, ?HH\Facts\DeriveFilters = null)[]: vec<string> query computes the full transitive closure of types that extend, implement, or use a base type in one native call. 8755851768
  • The sealed HH\GenericEnumClass<+TClass, +TValue> interface is now exposed to Hack, allowing type constants and generic APIs to constrain a value to any concrete enum class without exposing HH\BuiltinEnumClass directly. 47687c7eae

Future Changes

  • Expression trees now support named instance-method access and calls through the DSL's visitInstanceMethod() hook. Nullsafe and dynamically named instance methods remain unsupported. a84239a02b
