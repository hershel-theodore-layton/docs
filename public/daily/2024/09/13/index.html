Friday, September 13, 2024

Highlights

  • Hover information no longer displays generic parameters that were fully substituted while instantiating a function or method. Explicit enum-class-label arguments are shown as their singleton type, such as #Mul, rather than the broader label type. b3efd805cc fd4f638dee

Breaking Changes

  • Cyclic type-alias bounds no longer leave a freely solvable type variable behind. Hack conservatively localizes these cycles to mixed (or supportdyn<mixed> under implicit pessimization), which can reveal invalid calls that previously typechecked unsoundly. 1099f097bf
  • The unused zoned_with<T> context and HH\Coeffects\enter_zoned_with() / enter_zoned_with_async() entry points have been removed. Code that still declares or enters a zoned_with context must migrate to the remaining implicit-context and coeffect APIs. 42b37a58ae
