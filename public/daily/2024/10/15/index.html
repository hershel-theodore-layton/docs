Highlights

  • Errors caused by illegal recursive aliases now explain why the alias was replaced with mixed, instead of presenting that mixed as an unexplained source type. bc618c335b
  • Hovering over the generic this type now also shows its upper bounds. bdb90e88e2

Breaking Changes

  • A package expression inside invariant(...) no longer establishes package availability for following code. Use an if (package pkg) block instead. 7f948abbc0

Future Changes

  • Packages v2 introduces the unstable <<__RequirePackage('pkg')>> function and method attribute. The checker validates its single literal package argument, uses it to typecheck conditionally available calls, and reports an actionable error when the required package has not been established as loaded. 3577dadb29 e3397da7da 9aeaa0b4c7 a19ae73c44
  • Package-version checks reserve __CrossPackage for v1 and __RequirePackage for v2. 595cc60314
