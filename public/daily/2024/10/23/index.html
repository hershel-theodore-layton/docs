Breaking Changes

  • Cyclic as bounds on type aliases and newtypes are now rejected explicitly. These already failed indirectly after cycle recovery produced mixed; the checker now points to the unsupported bound itself. Cyclic super bounds are unchanged. 82a6a0afae

Future Changes

  • Packages v2 no longer applies package-boundary checks to class-constant and global-constant type hints, which are not emitted into runtime constant metadata. 878738dc7d
  • Experimental case types with variant where clauses now retain their nominal case type through intersections and type-switch refinements instead of being unsafely reduced to the raw variant hints. a2ad3ec620
