Highlights

  • Hack now runs both full-fidelity and lowerer syntax checks even when the first pass already found errors, so a single invocation can report more independent syntax problems. 0e55fbf060
  • Notebook conversion is now bidirectional: hh --hack-to-notebook reconstructs notebook JSON from generated Hack on standard input, and both conversion directions apply Hack formatting. 1e45a855cb 30842a482b
  • The single-class filename linter now says that a file "defines" a class rather than incorrectly claiming the class is its only content when typedefs are also present. 653d1be162

Future Changes

  • Await expressions on the right side of a pipe, and nested awaits, moved from Preview to Ongoing Release and no longer require the pipe_await feature opt-in. d26ca17cef
