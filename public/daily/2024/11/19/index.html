Tuesday, November 19, 2024

4 noteworthy changes recorded on this day.

DayWeekMonth

Highlights

  • json_encode_with_error() accepts the new JSON_FB_FULL_FLOAT_PRECISION flag to emit up to 17 decimal digits for IEEE-754 doubles instead of HHVM's usual 14, allowing a JSON encode/decode round trip without losing representable precision. 09c784c567

Security

  • The AdminServer.EnableSSLWithPlainText option has been removed; the admin server no longer multiplexes TLS onto its plaintext port. Deployments using this option must provide TLS through a separate endpoint or proxy. f75cdaef50

Future Changes

  • Opt-in extended type-error explanations now trace values through static-property and class-constant accesses and omit the ordinary CLI error-count footer from the detailed document renderer. 7f936bbcee 944e7951ca 4cf06f194f
  • Experimental tuple splats can now be indexed, and tuples containing a splatted tail support dynamic when both their fixed elements and tail do. bf35c48456 b0df8ac785
