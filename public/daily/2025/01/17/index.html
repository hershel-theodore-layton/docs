Friday, January 17, 2025

4 noteworthy changes recorded on this day.

Highlights

  • The new HH\gc_is_conservative() builtin reports whether HHVM's garbage collector is operating without any conservative type scanners. 3f6dfef71e

Future Changes

  • Runtime type structures for open tuples now preserve required elements in elem_types, optional elements in optional_elem_types, and a variadic tail in variadic_type. Absent optional or variadic parts omit their corresponding fields. 4c9affb24d
  • A type used after the experimental splat operator must now be known to be a tuple—typically through a bound such as T as (mixed...). Unconstrained generics used in tuple or function-type splats now produce a constraint error. 700abe325e
  • Recursive case-type runtime handling now preserves generic arguments, resolves cycles involving aliases more reliably, and refuses recursive is/as enforcement that could recurse without bound. 0d7f21793a
