Highlights

  • HHVM now reports a clear error when a non-default Eval.PackagesTomlFileName cannot be opened instead of silently continuing with an empty package specification. f9035ba600
  • The unsurfaced-exception lint no longer produces false positives for exception variables captured by lambdas during the dynamic TAST pass. 527a1dc8e7
  • HH\SimpleLock\is_held() reports whether any request currently holds a named SimpleLock. a2466c5ee3
  • The new #ICInaccessibleSpecialCase memoization option allows specialized functions to read implicit context without sharding their memo cache by it. Like #MakeICInaccessible, it is restricted to defaults, leak_safe_shallow, or leak_safe_local contexts. 2e164dc8db
