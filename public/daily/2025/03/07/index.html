Friday, March 7, 2025

4 noteworthy changes recorded on this day.

Highlights

  • Truthiness analysis no longer strips the like-type wrapper from ~null. This avoids false-positive “always truthy” warnings for nullable values commonly produced by operations such as idx() on dynamic data. a59544983a
  • The bundled classname<T> documentation and IDE hover text now describe class-name strings using the nameof C spelling. 0a174765d9

Future Changes

  • Experimental nested expression-tree bindings are now typechecked across splices: a nested expression tree may capture locals from the enclosing splice, and those captured types are tracked through control-flow joins. This requires the staged expression_tree_nested_bindings feature. b1fb7f1d52
  • IDE hover for the staged class<T> type now distinguishes class pointers from classname<T> strings and explains the operations supported by each. 0a174765d9
