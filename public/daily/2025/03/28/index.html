Highlights

  • HH\mangle_unit_sha1(string $sha1 = '', string $ext = '.php', ?string $repo = null): string and the convenience wrapper HH\unit_schema(?string $repo = null): string are now available to Hack. Both declarations omit an explicit context list and therefore use the default context. 2bb86e7bf2

Future Changes

  • Experimental expression-tree splices now evaluate eagerly and pass every spliced expression through the DSL's static lift() method before checking it as Spliceable. Nested-binding splices use the ordinary splice() visitor method with captured variable names as an optional fourth argument; the short-lived macroSplice() and asyncMacroSplice() protocol is no longer used. A capability-free DSL implementation can declare a helper such as public static function lift<T>(DslExpression<T> $x)[]: DslExpression<T>. f0b3d5104b
  • Preview __SimpliHack IDE code actions are gated by the corrected feature name simpli_hack. The attribute may take a prompt string directly instead of a promptlet class pointer; clients must still implement the generated inline-chat command. 33e4701f2e c6d59c6834
  • Class-pointer subtyping now clears stale this and like-type state while simplifying covariant class<T> propositions, avoiding spurious unsimplified unions and downstream diagnostics under sound dynamic. 733c16a23c
