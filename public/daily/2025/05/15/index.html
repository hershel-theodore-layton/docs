Thursday, May 15, 2025

4 noteworthy changes recorded on this day.

Highlights

  • LSP document-symbol ranges for functions and classes now begin on the declaration name instead of on preceding attributes, so IDE sticky-scroll headers show the symbol users are navigating. 535d3fdec2

Breaking Changes

  • class_parents() and class_implements() now return class-pointer values instead of class-name strings. The result keys remain class names; code that needs string values should convert the class pointers explicitly. db1c9385fc

Future Changes

  • Experimental checked unsafe casts have moved from the compile-time Hack.Lang.CheckedUnsafeCast option to the runtime Eval.CheckedUnsafeCast option. HackC now always emits the check instruction and HHVM decides whether to enforce it, so deployments testing the feature must rename their configuration. 93a6c2ac23
  • An early edenfs_file_watcher_enabled mode can initialize an EdenFS watcher, but notifications still delegate to Watchman and the implementation is explicitly not production-ready. 4ca8b78848 6abf46d85d 6e0807fb23
