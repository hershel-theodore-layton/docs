Highlights

  • HH\PriorityBridgeWaitHandle can wrap an awaitable so its child continues at lower priority instead of being promoted by the waiting context, and prioritize() can later lift it. create() requires []; the initial HHI for prioritize() omits a bracket list, so callers initially need the implicit [defaults] capability. ab939a7f4a 287b567685
  • The class_overrides_all_trait_methods linter now ignores abstract trait methods that exist to carry user-defined semantic attributes, while continuing to report genuinely dead overrides. 4794a8c906
  • HH\dynamic_class_meth() and HH\dynamic_meth_caller() now accept class_or_classname<mixed> instead of only string, adding class-pointer arguments without rejecting existing classname strings. 9da64160bd

Breaking Changes

  • HH\meth_caller() now requires class<mixed> rather than classname<mixed>. Pass a class pointer such as C::class; classname strings and variables no longer satisfy the public signature. 880710ad0c

Future Changes

  • Nested expression-tree lowering now orders captured free variables deterministically, preventing run-to-run changes in generated lambda parameters and bytecode while the nested-binding implementation evolves. 359704caf9
