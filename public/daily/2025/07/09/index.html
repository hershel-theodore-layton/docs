Wednesday, July 9, 2025

5 noteworthy changes recorded on this day.

Security

  • Hack's Rust dependency lockfile no longer transitively includes the vulnerable owning_ref crate affected by RUSTSEC-2022-0040. b20fefa60c
  • HHVM fixes a heap-use-after-free when mutating bespoke LoggingArray values by constructing the replacement before invalidating the old array. 2dbe10d8a1

Breaking Changes

  • Four class-pointer migration settings—class_pointer_ban_classname_new, _type_structure, _static_meth, and _class_const—now take integer levels: 0 permits the operation, 1 emits Warn[12022], and 2 reports an error. Existing boolean values must be replaced with the corresponding integer. e2bb8738e8
  • Static-property access through classname<T> is now an unconditional type error, and the former class_pointer_ban_classname_static_prop escape hatch has been removed. Migrate the receiver to class<T>. e2bb8738e8

Future Changes

  • Experimental can_index constraint solving now supports Pair and reports more precise string-index errors. 2cb9a00c36 a592d9f30c
