Highlights

  • --report-files-in-build now works for legacy non-Packages-V2 repo builds, and build reports identify why each file was included—for example through package selection, symbol references, autoload roots, or explicit include paths. 40aa523fd5 f4df5c5e47
  • HHVM now defines the built-in pseudoconstant newtypes in systemlib as well as in the HHI, preventing values such as __METHOD__ from being mistaken for class names at runtime. 49f2d63ded
  • Public-API rendering through HH\FileDecls now includes constructors. d6cd4b01f2

Future Changes

  • Staged polymorphic function-pointer types now simplify type parameters that occur only covariantly or only contravariantly by substituting the appropriate bound. 15e374473c
  • Case-type where clauses have moved to Preview on the HHVM side, but are not yet generally released. 6bebd36a39
