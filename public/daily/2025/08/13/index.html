Highlights

  • The JIT now has a dedicated implementation for HH\Lib\PseudoRandom\int(), avoiding the pessimization associated with a generic native call while preserving its inclusive range behavior. d51a44a881

Future Changes

  • Named arguments are now lowered from the concrete syntax tree into the Hack AST, continuing the pre-MVP implementation begun earlier in the week. 9063a1301e
  • The class-pointer migration adds HH\type_structure_class($class_or_object, $type_constant)[], a NoDoc helper that loads and returns the class<mixed> named by a type constant. Its empty coeffect list means it can be called from capability-free contexts. 6123f3b736
