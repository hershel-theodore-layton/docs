Future Changes

  • When the experimental constraint_array_index_assign option is enabled, array and collection updates now use the new can_index_assign constraint solver. Initial support covers mutation through container types, with later work extending inference across more type forms. 0d4289debc
  • Case-type subtyping no longer eagerly creates a disjunction when the subtype is an unresolved type variable or union. This avoids premature choices and improves inference for the experimental case-type implementation. 3ad3b0f3fc
