Wednesday, October 1, 2025

4 noteworthy changes recorded on this day.

Highlights

  • The required-shape-field lint no longer recommends direct indexing when the shape itself is optional. Calls such as Shapes::idx($optional_shape, 'field') no longer receive a false Lint[5005]. 65985eea5e
  • enum<T> hints now validate the enum's base type instead of treating T as a class name. Valid generic enum hints no longer receive Typing[4148], while incompatible enum bases receive the ordinary subtype error. 2e533742f9

Future Changes

  • Under the preview readonly feature, HHVM's runtime declaration of HH\legacy_is_truthy() now accepts readonly mixed, allowing readonly values to be inspected without a cast. Its explicit [] capability list is unchanged, so callers still need no ambient capabilities; the public HHI follows on October 20. 3df24d5bf5
  • Nested experimental expression trees no longer have a separate expression_tree_nested_bindings gate. They may capture bindings from an outer expression tree once expression trees themselves are enabled. 5b90e946d6
