Highlights

  • Sound-dynamic typing for integer operations is more precise. Binary &, |, and ^ return ~int only when both operands may hide strings; %, <<, and >> accept like/dynamic integer operands but return int; unary ~ over a like/dynamic integer returns ~int. Invalid operands now receive Typing[4110]. 8b0a654ad2 cb891dba1b 8ad57d6c36
  • Eval.WarnOnBitwiseOpInvalidType provides a migration path away from runtime bitwise operations on strings. The default 0 preserves them, 1 raises a warning, and 2 raises an error. 0d19dfbb13

Future Changes

  • Unstable named parameters are now parsed in lambdas and function-type hints, compared by name during function subtyping, and supported after one splatted argument. Diagnostics distinguish missing named markers and multiple splats, with quickfixes and narrower source positions. 0dca1d44ca f4ef532fa8 363a3b9bf4 dc806083d8 f3fdea9f10 e6e42516c3
