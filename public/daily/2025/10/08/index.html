Wednesday, October 8, 2025

5 noteworthy changes recorded on this day.

Highlights

  • CUSTOM_ERRORS.json rules can now match Module_cross_package_access by the use, declaration, module, and package files and by the current and target module/package names. File patterns support path segments, filename/extension matching, wildcards, and captures. 9243b11d8a
  • Bad array-index diagnostics now point at the index expression, and Lint[5654] flags ?-> when the receiver is statically exactly null. 9b6a914f00 a9a26055e5
  • HackC unit-compilation exceptions crossing the Rust/C++ boundary are now rendered as meaningful emitter errors instead of opaque bridge-class failures. c776cb5c3a
  • Thrift streaming now credits a request when response payload memory is freed on its I/O thread, reducing false per-request out-of-memory failures. Credit is applied when control next returns to the request thread, so several in-flight payloads must still fit within the limit. 6f2c4027de

Breaking Changes

  • The .hhconfig option disallow_invalid_arraykey has been removed. Hack has enforced this behavior unconditionally for years, so removing the stale setting does not relax invalid array-key checks, but project configuration must stop declaring it. 642bb4521d
