Highlights

  • The debugger no longer sends a DAP thread exited event for a thread whose corresponding thread started event was never sent, keeping client thread state balanced. 9cd2be99d3

Security

  • HHVM can now enforce Server.RequestFanoutLimit for recursively spawned Xbox requests. With the new Server.EnforceRequestFanout=true setting, exceeding the limit rolls back the counter and throws RequestFanoutLimitExceededException; enforcement is off by default. a96d874cb8
