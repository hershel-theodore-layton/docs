Wednesday, December 10, 2025

Highlights

  • The parser now processes long else if chains iteratively, avoiding stack growth proportional to the number of branches while preserving the same syntax tree. 794dce91c0
  • Tools converting Hack's JSON type representation back into local types now map the primitive string entry to HH\string rather than a class literally named string. 0e9e24f115

Future Changes

  • During the null-safe pipe's OngoingRelease phase, await is no longer allowed on the right-hand side of |?>, because that branch is conditionally executed. Await the value before the pipe or move the asynchronous operation into explicit control flow. 67afb72ad7
  • With the pre-stable open_tuples and type_splat features enabled, a vec<mixed> can now be unpacked into a function declared with ...(mixed...) or a generic ...TArgs. Subtyping treats the unknown-length vec as a variadic sequence rather than a single tuple slot; the callee's capability requirements still undergo the normal caller-superset check. 9dd3259bf2
