Breaking Changes

  • Package-boundary checking now rejects enum C { use D; } when D belongs to a package that the current package does not include. This applies to both package configuration versions. 37ec673d69
  • Direct access to a class constant in an unrelated package is now an error. Use an allowed package relationship or establish the package through the supported package-checking APIs; dynamic class references and type_structure() retain their distinct handling. e8b8fa9c16
