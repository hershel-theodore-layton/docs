Highlights

Breaking Changes

  • HH\watcher_query() now returns Awaitable<string> containing JSON instead of Awaitable<WatcherResult>. Decode the returned string before reading result fields; the content-hash key is now content.sha1hex, not sha1hex. 3161ba224a

Future Changes
