Highlights

  • Async return-type enforcement is preserved when the tail-await optimization removes the normal return bytecode, preventing dynamically introduced bad return values from escaping the check and crashing later. 5e6edbd435

Future Changes

  • Open tuple syntax and type splats have entered an ungated rollout and no longer require __EnableUnstableFeatures('open_tuples') or __EnableUnstableFeatures('type_splat'). This includes optional/open tuple elements, splats in tuple and callable types, and type-splat function parameters; both features remain pre-stable. dc93244172
  • Unstable extended-await syntax now handles conditionally executed awaits in short-circuit operators, ternaries, null coalescing, assignments, loops, and nullsafe calls while preserving their execution conditions. ec6d2a9b45
