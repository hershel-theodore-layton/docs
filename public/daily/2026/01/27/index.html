Highlights

  • Hack's diagnostic engine now consistently distinguishes errors from warnings when backtracking and selecting type-checker paths. Enabling a warning can no longer suppress or manufacture a type error merely by changing that control flow. 561e592fd6
  • FunctionCredential::pack() and FunctionCredential::unpack() can transfer an authenticated function credential between threads in the same HHVM process. Packed values expire after five minutes and cannot be reused after a process restart or in another process; both methods require []. 167e437347
  • HH\serialize_with_options() accepts disallowCollections => true, causing serialization of Map, Set, Vector, and Pair values to throw while leaving Hack arrays and ordinary objects unaffected. f999a274c0

Breaking Changes

  • A concrete type constant inherited from a parent is now checked against an <<__Enforceable>> requirement introduced by an interface on the child. Previously this combination could accept an erased, non-enforceable type; it now reports error 4302. 548b917d91
