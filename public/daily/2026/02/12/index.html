Highlights

  • Top-level statements now inherit the package selected by their file path instead of being typed with no package. This removes spurious package errors in Hack notebooks and other files whose statements are wrapped in a synthesized function. 80ee10b3e1
  • HHBBC now detects cycles while speculating through successor blocks, preventing repo-authoritative compilation from hanging on control-flow loops that revisit the same block. 7029bde607

Breaking Changes

  • Shape-aware constraint refinement is now unconditional, and the type_refinement_partition_shapes configuration option has been removed. Projects that explicitly disabled the option can see more precise refinements and should delete the stale setting. f1c42be784
