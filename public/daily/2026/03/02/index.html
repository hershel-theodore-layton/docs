Security

  • HHVM operators can set Eval.AllowUngatedExec=false to reject shell_exec(), exec(), passthru(), system(), pcntl_exec(), and HH\Lib\OS\fork_and_execve(). proc_open() can remain available to exact function or Class::method names listed in Eval.ProcOpenGatedApprovedCallers. 3f00bd113d

Breaking Changes

  • The DateInterval HHI is more precise: $days is now int, createFromDateString() returns DateInterval, and format() returns string. Code that relied on these APIs producing mixed may now expose type errors. f551f0f9fc
