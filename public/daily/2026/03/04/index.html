Wednesday, March 4, 2026

8 noteworthy changes recorded on this day.

Highlights

  • hh --help now shows a curated everyday command set instead of roughly 70 rarely used flags; hh --ultrahelp retains the complete option list. 300f886607

Breaking Changes

  • An if (package p) expression is now rejected unless package p includes the package containing the current file, matching the well-formedness rule for __RequirePackage. 4986189361
  • The cross-package migration linter now tracks C::class references when package_allow_classconst_violations=true; projects using that temporary carveout may see new lint 5656 diagnostics for undeclared package dependencies. 6671f217e0

Future Changes

  • Symbol information now retains the pre-stable named and readonly parameter modifiers when rendering function type hints, so tools consuming displayType no longer erase them from the displayed function type. d927c424f2
  • The pre-stable extended-await implementation now supports conditional and sequential awaits inside concurrent blocks, preserves using statement lifetime correctly, and evaluates for initializer and iterator expression lists in source order. 31f3c8b933 4b74fe53e8 de3ebf325f
  • The pre-stable delay operator explicitly leaves an Awaitable<T> un-awaited while preserving its type. It is a runtime no-op, is permitted only in async functions, and is intended to distinguish deliberate delayed awaiting from accidentally discarded awaitables. 5872d7ec97
  • Runtime type structures can now represent exact, upper-bound, lower-bound, and context-constant refinements such as I with { type T = int }. This is groundwork for using pre-stable class refinements on the right-hand side of type aliases and type constants. b05c47edf3
  • Setting disallow_bool_cast=true now makes (bool) casts a parse error, providing an opt-in migration path away from implicit truthiness conversions. 6479cd2461
