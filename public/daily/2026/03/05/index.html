Highlights

  • HackC no longer crashes while reporting invalid constant initializers that contain local-variable list expressions; it now points the constant-expression error at the offending expression. de71cec1a5

Breaking Changes

  • Cyclic abstract type-constant bounds such as abstract const type T as this::T no longer introduce an unsound Tany bound. The cycle is treated as an absent upper bound (mixed) or lower bound (nothing), so invalid uses that previously passed through Tany can now produce type errors. 97d482d027
