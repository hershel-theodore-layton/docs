Highlights

  • HH\type_structure_classname() is now understood specially by the typechecker: it resolves the named type constant and returns the corresponding classname<T> when the type is classish or an enum, while rejecting non-classish type constants. 9b14e5db5d
  • apc_add(), apc_store(), and their with_pure_sleep variants gained a final $guaranteed_acyclic argument. Setting it to true skips APC's cycle-detection walk when the caller can guarantee the stored value contains no cycles. 7fa443e8fa
