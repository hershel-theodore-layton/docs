Highlights

  • Lambda type-parameter exposure now removes expression-dependent variables from recursive refined builder types instead of retaining them across later lambdas. This avoids cubic typechecking behavior in fluent-builder code with class refinements. db5234971c
  • The persistent Hack server no longer gets stuck or returns stale results when one file changes while an earlier recheck is being interrupted. Files left in disk_needs_parsing now trigger another typecheck even when no additional filesystem event arrives. 6bfec3705a

Breaking Changes

  • Misspelled script markers such as <?h, <?hx, or <?h h are no longer mistaken for PHP and silently skipped. Hack treats them as source files and reports a parse error directing authors to <?hh; valid <?php and bare <? PHP markers remain skipped. cffabe0510 b0addbd6a3
  • Legacy @T soft type hints are now unconditionally rejected; the already-default-on disable_legacy_soft_typehints setting and CLI flags were removed. Use <<__Soft>> T and delete stale configuration overrides. 28379910d0
