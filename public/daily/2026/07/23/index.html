Highlights

  • Hershel's HHVM has optimized the implementation of HH\Lib\Vec\slice, a hot function in portable-hack-ast-linters. This reduces whole project lint latency by ~30%. Improvements scale more than linearly with the size of the file being linted. Projects with larger files may see a greater improvement. This change is included in hersheltheodorelayton/hhvm-full:26.06.05. See also HHVM issue for perf on the hhvm repo. b983bd51b1
  • Strict-isolation package boundaries now apply to class and alias references throughout type hints, including nested type arguments and inheritance declarations. acdcb7f349
  • C::class references into strict-isolation packages now produce hard package-boundary errors instead of only migration lints. 1d9d645d5f
  • nameof C and exception-class references in catch now respect strict-isolation package boundaries, including excluded-path restrictions. f39c87984b
  • Predicate-based refinement now understands runtime-checkable reified type parameters, enforceable abstract type constants such as this::TC, and this itself. 6c2e8cda7f
  • HH\class_or_classname<T> is now a covariant opaque type accepting both class<T> and classname<T>. Related Facts APIs use it so callers can pass either representation. e9914ef5cf

Breaking Changes

  • Case-type disjointness now treats Hack enums as arraykey, rejecting combinations with other integer or string variants that enum is checks cannot reliably distinguish. c38b6f7d06
