Wednesday, August 12, 2026

6 noteworthy changes recorded on this day.

Highlights

  • The typechecker now knows that DOMDocument::createElementTyped() and createElementNSTyped() return DOMElement. 130929a5fe
  • hh_client --single now typechecks explicitly supplied files that the server does not monitor, rather than incorrectly reusing global diagnostics that can make those files appear error-free. 3594deeb46

Future Changes

  • The opt-in check_duplicate_enum_values setting now reports duplicate values in plain enums, including conflicts introduced through enum use inclusions. It remains disabled by default. ab8c2c1907
  • The opt-in duplicate-enum-value check now also reports enum values it cannot statically evaluate, rather than silently skipping them. 15b1143598
  • <<__AllowUncheckedEnumValues>> lets an enum opt out of the experimental duplicate-value and uncheckable-value diagnostics. Enums that include an opted-out enum must also opt out. 41fb35f4ab
  • The opt-in Eval.EnableLazyGC setting, when garbage collection is enabled, raises the default garbage-collection trigger from 50% to 80% of the remaining memory budget and allows a temporary memory grace buffer before collection. It is disabled by default, and explicit trigger and grace settings take precedence. b41450e50e
