Highlights

  • unserialize() now rejects aggregate values in serialized key positions, preventing use-after-free when later serialized references point into a discarded temporary key. 8ba37ca157
  • HH\Facts now supports function-attribute queries through functions_with_attribute(), function_attributes(), and function_attribute_parameters(). Index the desired attributes with Autoload.IndexedFunctionAttributes. 12950b15d1
  • A public method overriding an internal or protected method no longer has to propagate __TestsBypassVisibility, since the public override does not bypass visibility. e25704eea5
  • The typechecker now correctly expands recursive type-constant refinements involving this, closing a type hole that could silently accept incompatible values. a60607b184
