Highlights

  • HHVM fixes an allocation/free size mismatch for shared logging arrays wrapping arrays with a string-key table, which could pass an interior pointer and incorrect allocation size to jemalloc. 3514f777ed

Breaking Changes

  • __PackageOverride is also rejected when a file physically belongs to an explicit package with strict isolation, closing the same escape route already blocked for implicit packages. e48e4b7856

Future Changes

  • Named callback arguments now participate in the same staged lambda-inference passes as positional arguments, removing inference failures that depended on argument order. Function subtyping also keeps named parameters out of positional variadic and type-splat tails. e620163247 d708f251ce
  • HHVM now compares named method parameters by label and optionality separately from positional parameters. This accepts implementations with extra optional named parameters and rejects missing parameters or incompatible inout positions that combined slot counts could conceal. 7cb12ea0ef
  • Runtime checks now keep reordered named parameters paired with their original type hints and defaults. Readonly checks also bind passed arguments to the correct parameter when optional named arguments are omitted, fixing both false rejections and missed violations in the interpreter and JIT. d9825e5b77 9fed0ff97f
