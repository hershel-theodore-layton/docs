Highlights

  • Typed open shapes are now enabled by default through typed_open_shapes=true. Normalizing supportdyn over open shape tails also correctly distributes union tails. b60a3f7001 5ba371e121
  • A new warning detects expressions typed dynamic returned through an explicitly declared return type that is not fully enforced at runtime. Fully enforced and like-typed return positions, including async return-value enforcement, are exempt. 64f7043e62
  • --validate-isolation <file> checks a candidate list of repo-relative file paths against a temporary strict package and reports boundary violations. Exit statuses distinguish a successful check (0), violations (2), and unknown or overridden input paths (10); --json provides structured output. b3a8b8384f

Future Changes

  • Class-pointer bound widening gains separate source-level settings for which class-pointer types are widened, independently of the string-like constraint levels that trigger widening. These settings remain zero by default. 1307864bde
  • Experimental shape splats used with RepresentableAs now resolve residual polymorphic splats before checking the represented key and value types. The conversion remains one-way; RepresentableAs cannot itself be unpacked as a shape. 8e614e9db2
  • Experimental shape splats that introduce non-denotable union field types are rejected in aliases, newtypes, parameter hints, and return hints unless union_intersection_type_hints is enabled. Redundant singleton shape(...T) hints receive a diagnostic and quickfix, with a specialized rewrite for shape(...dynamic). 9407783fdd c8419798fb c549af8941
