Most recent changes

All daily notes →
  1. Jul 31

    HH_TMPDIR now controls the native saved-state cache location, consistently with the typechecker's other temporary files. 08797dc741

  2. Jul 31

    The native saved-state loader now detects incomplete cached states, removes the incomplete cache entry, and downloads a fresh copy instead of failing when a required artifact is missing. d425de3a08

  3. Jul 29

    The bundled libgd GIF decoder initializes its LZW tables correctly, fixing an uninitialized-memory disclosure associated with CVE-2017-7890. 23cfa7784a

  4. Jul 28

    HHVM publishes profiling prologues only after their translation metadata has been installed, fixing crashes during profile-guided prologue regeneration. b679ec1fff

  5. Jul 23

    Case-type disjointness now treats Hack enums as arraykey, rejecting combinations with other integer or string variants that enum is checks cannot reliably distinguish. c38b6f7d06
