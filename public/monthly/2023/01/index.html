January 2023

44 noteworthy changes, organized by the source changelog sections.

Highlights

38 changes
  • W01 · Jan 3
    HHVM no longer reports a false Cannot declare self-referencing constant fatal when an interval-timer callback interrupts the initialization of a large global or class constant. Genuine recursive constants remain invalid. bc6c72f81a
  • W01 · Jan 3
    The diagnostic for using #MakeICInaccessible or #SoftMakeICInaccessible with an incompatible context now correctly refers to leak_safe_shallow, rather than the incompatible leak_safe context. 9592c3ee4d
  • W01 · Jan 4
    Memoized functions and methods may now use <<__Memoize(#Uncategorized)>> or its __MemoizeLSB equivalent. This has ordinary memoization behavior but records the explicit category in reflection. Functions whose contexts cannot access implicit context must continue to omit a memoization option. e2bc6db35d
  • W01 · Jan 4
    Hover information for functions and methods that support dynamic now prints the source-level <<__SupportDynamicType>> attribute instead of exposing its internal supportdyn<...> representation. df90d157ec
  • W01 · Jan 5
    Dynamic-aware checking of indexing and indexed assignment now preserves the dynamic part of supportdyn<T>. This fixes rejected reads, appends, and writes in <<__SupportDynamicType>> code where the operation is valid through dynamic. 3921de4f83
  • W01 · Jan 6
    Hack modules no longer require <<file:__EnableUnstableFeatures('modules')>>. The separate module_references experiment still requires its own unstable-feature opt-in. d3bdad4f2f
  • W01 · Jan 6
    HH\ImplicitContext\run_with_soft_inaccessible_state() and its async counterpart can run a callable in the soft-inaccessible implicit-context state during migrations. They accept a blame key, may only be entered from a null implicit-context state, and should be removed once the logged violations have been addressed. 402b7ded0e
  • W01 · Jan 6
    Hover and typed-AST data can now distinguish anonymous functions from named functions instead of assigning synthetic names to closures. e18be7371b
  • W02 · Jan 9
    Lint 5649 now warns when ::class is taken from an internal class, since the resulting raw string can escape its module without visibility checks. Keep such classnames inside the declaring module or avoid producing them. ac5b19049b
  • W02 · Jan 9
    Bundled SPL and system-class declarations now give iterator methods more precise types: implementations of valid() and hasChildren() return bool, while several current() and getChildren() declarations preserve their iterator type parameters. This should reduce mixed propagation when consuming built-in iterators. 05841133e5 3274d2043b 50314df3fa c58cbdbc79
  • W02 · Jan 10
    Sound-dynamic checking no longer rejects assigning a value of type ~T back to an inout T parameter solely because the function or method is being checked for dynamic calls. fab2e559dd
  • W02 · Jan 11
    Objects created by the DOM extension now use canonical class capitalization such as DOMDocument and DOMElement. DOMDocument::registerNodeClass() remains case-insensitive, but reflection and get_class() now see the correctly cased built-in name. df0d4d2827
  • W02 · Jan 12
    Incremental typechecking now rechecks dependents when an inherited XHP attribute becomes required or a new required attribute is added. Projects should receive the same missing-attribute errors without needing a full check. 3fba663915
  • W02 · Jan 12
    The bundled HHI for pcntl_waitpid() now types its status parameter as inout ?int, and Serializable::unserialize() now requires a string. Callers of pcntl_waitpid() must account for the variable remaining nullable after the call. ece17c0698 050792ec94
  • W02 · Jan 12
    HHBBC now treats the classname field in runtime type structures as case-sensitive, matching the shape-key semantics used by type structures. b9b1d9f2ef
  • W02 · Jan 13
    Missing and extra shape-field errors now point at the individual field, and a missing field in a shape literal offers a quick-fix that inserts a TODO value. 5f0a767ff1 bbff846c01
  • W02 · Jan 13
    HHI declarations now type the output of parse_str() and the arrays passed to Collator::sort() and Collator::asort() as dynamic, accurately representing their heterogeneous results. 083c6643ef 834a393008
  • W02 · Jan 13
    Runtime type-structure helpers now compare the alias and kind fields case-sensitively, like other shape keys. 16acff3a5c
  • W02 · Jan 13
    Only the exactly cased method name __construct is treated as a constructor by runtime method-name checks. A differently cased method such as __Construct remains an ordinary method. 114f38dff3
  • W03 · Jan 17
    Several standard-library HHI output parameters now have concrete nullable types. APC success outputs are inout ?bool, while the error-code outputs of msg_send() and msg_receive() are inout ?int. Variables passed to these functions should use the corresponding nullable type and be checked after the call. ff9df89621
  • W03 · Jan 18
    Expression-tree lambdas are now fully inferred during sound-dynamic checking. This fixes spurious constraint errors on expression trees whose inferred type parameter cannot be dynamic. e6189ec286
  • W03 · Jan 18
    More HHI output parameters now describe their results: pcntl_wait() uses ?int, exec() and preg_match_with_error() use dynamic, and the resource collections used by proc_open() and stream_select() are nullable vec_or_dict<resource>. Existing variables passed by inout may need matching annotations. 14b294fef6
  • W03 · Jan 20
    Array-access errors now retain the actual base and index types in typed-AST holes, and inferred KeyedContainer key types are constrained to arraykey. IDE fixes and type-error explanations should no longer suggest impossible types such as KeyedContainer<bool, nothing>. 5519413eb5 01bddda586 59a15c7f27
  • W03 · Jan 20
    The dead-UNSAFE_CAST codemod now omits redundant parentheses for expressions that cannot be captured by surrounding syntax, producing smaller and more idiomatic patches. 952e984837
  • W03 · Jan 22
    Expressions involving a missing class now receive type nothing instead of an unconstrained fresh type variable. This avoids large, misleading inferred unions and reflects that executing the unresolved class reference will fatal, even if its naming error was suppressed. 1a16e3c578
  • W04 · Jan 23
    Incremental typechecking now correctly rechecks both files involved in a duplicate module-name collision, avoiding stale module diagnostics after edits. 0021cf60bb
  • W04 · Jan 23
    <<__SoftInternal>> is now accepted on constructor-promoted properties with internal visibility and rejected on ordinary constructor parameters or properties with other visibility. 2c2ac6d2d3
  • W04 · Jan 23
    hphp_get_stats('units') and hphp_get_stats('funcs') can now report the number of loaded units and allocated function IDs, respectively, which is useful for auditing how much code a script loads. f62641e738
  • W04 · Jan 24
    Pessimized expression trees now strip like types from inferred virtualized types even when they appear inside unions or supportdyn<...>. This fixes spurious generic-constraint errors passed to makeTree(). 0cb80422c1
  • W04 · Jan 25
    Projects using implicit sound-dynamic pessimization can now put the experimental <<__NoAutoDynamic>> attribute on a top-level function or class to disable automatic pessimization within that declaration. This is a local escape hatch: use it where the declaration is deliberately kept outside the dynamic boundary. 5bf4a9604d
  • W04 · Jan 25
    Disjointness checks now terminate safely when generic upper bounds form a cycle, preventing affected subtype queries from diverging. f298d5f2fe
  • W04 · Jan 26
    Method calls that violate a where constraint now place a typed-AST hole on the receiver. IDE and codemod consumers can identify the receiver as the source of error 4323 instead of receiving an unlocated constraint failure. c788fbc3ec
  • W04 · Jan 26
    Hover cards now show a declaration's documentation URL before its doc comment, keeping the link visible even when the comment is long. dca161bc90
  • W04 · Jan 27
    The experimental <<__NoAutoDynamic>> escape hatch now applies to type aliases as well as functions and classes. Under implicit sound-dynamic mode, an unannotated alias still receives an implicit as supportdyn<mixed> bound; annotating the alias suppresses that transformation. d7f9a9ec91
  • W04 · Jan 28
    <<__NoAutoDynamic>> now disables implicit pessimization while checking function and method return expressions, not only while building their declarations. 7d1201c567
  • W05 · Jan 30
    The bundled implicit-context HHI now exposes HH\MemoizeOption#Uncategorized, completing typechecker support for the memoization category added earlier in the month. 6593d8379b
  • W05 · Jan 31
    Sound-dynamic hierarchy checks now consider all ancestors, including interfaces inherited through used traits. A class that transitively acquires an SDT interface requirement must itself support dynamic. 810c57c82f
  • W05 · Jan 31
    A trait is now considered to support dynamic only when it is marked <<__SupportDynamicType>> and one of its requirements restricts it to SDT classes. This fixes both false acceptance and false rejection around SDT traits and their consumers. c07151edf9

Breaking Changes

5 changes
  • W01 · Jan 6
    The Thrift extension no longer implements or registers RpcOptions::setFaultToInject(). Projects using this fault-injection API must remove those calls. 64a89b91a6
  • W02 · Jan 12
    Dumping or calling __debugInfo() on a closure no longer reveals captured variables, parameters, or the bound $this; it now produces an empty dictionary. Code must not use closure debug output as a reflection API. d2cfc9b74d
  • W03 · Jan 19
    HHI declarations must now provide explicit parameter, return, method, and property types. Authors of project-specific HHIs should add real types where known and use an appropriate placeholder only where the declaration truly cannot be typed. 96f6e5b16f
  • W03 · Jan 20
    tls:// stream sockets no longer negotiate TLS 1.0 and instead use the modern TLS client or server method. Connections to endpoints that only support TLS 1.0 will now fail and should be migrated to a current protocol. 083f5ffdee
  • W04 · Jan 23
    The stale systemlib declaration of RpcOptions::setFaultToInject() has been removed, completing the earlier runtime removal. Calls now fail typechecking as well as at runtime. 084d422844

Future Changes

1 change
  • W04 · Jan 23
    The typechecker now accepts <<__SoftInternal>> on enums and enum classes ahead of runtime support. Treat this as migration groundwork rather than a fully available runtime feature. e373f377f5
