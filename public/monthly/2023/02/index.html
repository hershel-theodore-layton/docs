Highlights

45 changes
  • W05 · Feb 1
    Several APC declarations now have narrower capability requirements than their former implicit [defaults]: read operations such as apc_exists() require [read_globals], mutations require [globals], and apc_sma_info() is pure. This allows callers with correspondingly restricted contexts to use these APIs. 2aaa02ccf6
  • W05 · Feb 1
    The Rust .hhconfig reader now recognizes union_intersection_type_hints, so projects using that parser can enable union and intersection type-hint syntax consistently. 229121c557
  • W05 · Feb 3
    Sound Dynamic pessimisation now honors <<__NoAutoDynamic>> on top-level functions and no longer adds inappropriate dynamic bounds to classname<T>, typename<T>, or common generic container declarations. Types such as Vector<string> can therefore support dynamic without requiring their type argument to be exactly dynamic. a51c285635 936f37edee 0ceb0b7ce4
  • W05 · Feb 3
    cpu_get_count() and cpu_get_model() now require only [read_globals] rather than implicit [defaults], making them callable from functions with a narrower capability set. 26cae71480
  • W05 · Feb 5
    The Rust .hhconfig reader now warns about unrecognized options instead of silently ignoring them. This should expose misspellings and configuration options that are unavailable in the selected typechecker implementation. a19a617ce9
  • W06 · Feb 6
    Local-variable autocomplete is no longer suppressed merely because a function call follows the cursor, and suggestions are now filtered by the prefix already typed. 18aff16dd0 5fd5cf5613
  • W06 · Feb 6
    The bundled MemoizeOption declarations now document each option, improving hover and go-to-definition information for arguments to __Memoize. fb1c9f59e0
  • W06 · Feb 8
    Exact class types no longer use a class's declared variance to establish subtyping. This closes an unsoundness where incompatible exact generic instantiations could be accepted. 7b326d1b8b
  • W06 · Feb 8
    DateTime HHI declarations now describe their actual capability requirements. Pure getters, property-writing mutators, and global-reading methods can be called from appropriately narrow contexts instead of all implicitly requiring [defaults]. 49b10540ed
  • W06 · Feb 8
    Sound Dynamic union simplification now preserves supportdyn wrappers instead of immediately merging separate wrapped union members back into one wrapper, avoiding incorrect type acceptance. cd49bf2e54
  • W06 · Feb 8
    Runtime failures while converting a throwable to text now include the underlying failure details instead of returning an uninformative placeholder. 0309a310b5
  • W06 · Feb 9
    An async lambda passed where dynamic is expected now infers its omitted return type normally, rather than assuming a dynamic return and rejecting ordinary returns such as return 1. e2a1356eeb
  • W06 · Feb 9
    Large shape types now spend type-printer fuel per field and are explicitly truncated when the budget is exhausted, keeping diagnostics and hover output readable. 452112ed92
  • W06 · Feb 9
    <<__NoAutoDynamic>> is now supported on individual methods in both explicit and implicit Sound Dynamic pessimisation. It prevents ~ and supportdyn from being added to that method's signature without disabling dynamic calls to an otherwise Sound Dynamic class. 7da433acc8
  • W06 · Feb 9
    Exception rendering retains the original class, file, and line when an overridden Exception::getMessage() itself throws, making secondary failures substantially easier to diagnose. 0a6378d03a
  • W06 · Feb 10
    Sound Dynamic like-type pushing now handles generic lower bounds, allowing relationships such as vec<~int> <: ~T when vec<int> <: T. 4f90a4b70c
  • W06 · Feb 10
    HHVM now clears the implicit context at every VM entry boundary. Server-mode exceptions from warmup, shutdown, or presend hooks can no longer leak an implicit context into a subsequent request. 4e07ff06fc
  • W06 · Feb 11
    Cloning an object whose properties are still lazily represented in APC no longer triggers an assertion; the lazy property values are copied safely. 8c70fede94
  • W07 · Feb 13
    Enum-class labels in attribute arguments are now preserved through naming, enabling typechecking, hover, and completion for forms such as <<__Memoize(#Key)>>. b9dd041059
  • W07 · Feb 13
    In --everything-sdt mode, method return expressions are now checked against a supportdyn-wrapped return type, matching explicitly Sound Dynamic methods. 82c7fcccc7
  • W07 · Feb 14
    hh --tast-holes-batch accepts a newline-separated list of source files and reports TAST holes across the batch, making type-precision analysis easier to automate. c41d55d42c
  • W07 · Feb 14
    Invalid __Memoize arguments now distinguish wrong arity from an invalid option and report the expected number of arguments. fa4f4eb1ef
  • W07 · Feb 14
    Partially written methods are lowered far enough for IDE features to work, __Override diagnostics retain complete positions, and autocomplete can suggest overridden method names after an incomplete <<__Override>> declaration. 80775a8a36 f25f7d4b3e dabbec63a9
  • W07 · Feb 16
    The command form hh --json check . works again after an argument-parsing regression. dd5ab56163
  • W07 · Feb 17
    Sound Dynamic subtyping can now push supportdyn through built-in containers and through safe promotions to Traversable, while expected-type inference retains more useful like-type information. This removes several false-positive errors around refined and nested container types. f9fe075c21 972106d560 61ab0e31c7
  • W07 · Feb 17
    Autocomplete now works in generic type-argument positions such as vec<string> without mistaking the angle brackets for XHP syntax. 480b384688
  • W07 · Feb 17
    hh_single_type_check --sdt-analysis can now identify top-level functions that need __SupportDynamicType, including dynamically callable functions and call sites that require dynamic-aware checking. 0ae3969f18 582b596f55
  • W08 · Feb 20
    Sound Dynamic union, intersection, and subtype processing no longer accumulates recursive supportdyn wrappers that can overflow the typechecker's stack, and it now retains the wrapper while comparing two supportdyn types. 0e60e722c7 de66255762
  • W08 · Feb 20
    Hover in Sound Dynamic projects can show an expression's type under dynamic assumptions when it differs from the ordinary type. The additional TAST is generated on demand for hover rather than for every typecheck. f0ad1da10f bdad09d3c0
  • W08 · Feb 20
    Sound Dynamic generic inference now removes like-types in safe covariant positions before solving a type variable, and tuple reads and writes are no longer unnecessarily pessimised. 4d6992a5db 76d4a7b435
  • W08 · Feb 20
    The experimental SDT analyzer now propagates NeedsSDT constraints from dynamic instance and static method calls to classes. da198e2d89
  • W08 · Feb 21
    <<__NoAutoDynamic>> is now honored on interfaces by the direct-declaration parser. Implicit pessimisation no longer treats an opted-out interface as Sound Dynamic. fd5a47c16b
  • W08 · Feb 22
    Runtime module-boundary errors now correctly describe an internal top-level function called from a method, rather than misreporting it as a method on the caller's class. 3d6bddce49
  • W08 · Feb 22
    Sound Dynamic checking avoids another stack overflow while solving supportdyn bounds, supplies dynamic bounds for class-level generics during the additional method-body check, and correctly wraps methods fetched through intersection receivers. 4de931af81 12856381c5 46a1c1580b
  • W08 · Feb 22
    Redundant-cast lints now warn that removing a runtime cast can change behavior, instead of presenting removal as unconditionally safe. 30abe736a4
  • W08 · Feb 22
    Optimized code no longer assumes that a value checked by a soft return-type constraint is non-null, preserving the runtime semantics of soft type hints. 7dccf227c0
  • W08 · Feb 23
    Implicit Sound Dynamic mode now pessimises inout parameters as both inputs and outputs. Declarations always receive a like-type, while definitions add it when the parameter type is not runtime-enforced. 5c70475d3d
  • W08 · Feb 24
    hh --json --prefer-stdout sends JSON results to standard output instead of mixing them with diagnostic output on standard error, simplifying scripted use. 69c5614feb
  • W08 · Feb 24
    Autocomplete now offers accessible type constants after SomeClass:: and this:: in type positions, including chained abstract and concrete accesses. 86d5445582
  • W08 · Feb 24
    When HH_SERVER_PATH is set, hh_client launches exactly that hh_server binary instead of relying on a sibling binary or $PATH. This provides deterministic pairing for custom builds, wrappers, and test environments. edcc11a69a
  • W08 · Feb 26
    The VS Code debugger now understands lazy-class values such as Foo::class instead of displaying an unexpected-variable-type error. abd73aac74
  • W09 · Feb 27
    Sound Dynamic subtype inference now applies the intersection-to-union heuristic when the union contains an optional type variable, improving refinements involving nullable like-types. 389adc3c78
  • W09 · Feb 27
    Hover and outline information now includes the internal modifier for methods. 20464398b2
  • W09 · Feb 28
    Safe rename in Sound Dynamic projects no longer generates a deprecated compatibility stub for methods that cannot be called dynamically. Methods that do support dynamic retain the stub; behavior is unchanged when Sound Dynamic is disabled. ae21dcb1bd
  • W09 · Feb 28
    hh_server now restarts when __PACKAGES__.php changes, just as it does for .hhconfig, so package membership and include changes are not left stale. a7e3c34ae9

Breaking Changes

11 changes
  • W05 · Feb 2
    The experimental BigCode autocomplete path and the corresponding hh_client --bigcode option have been removed. Tooling that still passes the option should stop doing so and use the standard autocomplete service. af637e05a1 cdabde25c1
  • W06 · Feb 7
    Runtime module-boundary checks now cover enum and enum-class constants. Accessing an internal enum or enum-class constant from another module raises the same boundary violation as other internal symbols, including in optimized code. 859da9f1c9
  • W07 · Feb 13
    The fun(), class_meth(), and inst_meth() pseudo-function-pointer forms are now rejected by default. Migrate to first-class pointers such as function_name<>, ClassName::method<>, and $object->method<>. 4c7ba8532f
  • W07 · Feb 13
    Unimplemented and obsolete STREAM_CRYPTO_METHOD_* constants have been removed, including the protocol-version-specific TLS and legacy SSL constants. Use STREAM_CRYPTO_METHOD_TLS_CLIENT, STREAM_CRYPTO_METHOD_TLS_SERVER, or the corresponding ANY constants. a5ce6b07f0
  • W07 · Feb 13
    String arguments such as <<__Memoize("foo")>> are now rejected where a memoize option enum-class label is required. Use the appropriate label syntax instead. b9dd041059
  • W07 · Feb 15
    HHVM now defaults Autoload.Enabled to true. Deployments that need the previous behavior should explicitly set Autoload.Enabled = false. a714af2744
  • W07 · Feb 15
    Thrift stream and sink failures are now delivered as ThriftApplicationException rather than TApplicationException. Code catching the older concrete class should catch the new exception or a shared base such as Exception. 0e2f06e781
  • W07 · Feb 16
    Hack now rejects prohibited uses of this in class type parameters, class-variable hints, extends, and require extends. Type accesses rooted at this, such as this::T, remain available; affected declarations should otherwise use an explicit class or type parameter. 150429e923
  • W07 · Feb 16
    ZipArchive::getFromIndex() now returns null, rather than false, on failure and is typed as ?string. Callers checking strictly for false must migrate to a null check. 8ac98e8a21
  • W08 · Feb 22
    Deprecated AwaitAllWaitHandle::fromVector(), fromMap(), and fromContainer() have been removed. Use fromVec() or fromDict() after an appropriate constant-time collection cast. e0d354d015
  • W08 · Feb 22
    AwaitAllWaitHandle::setOnCreateCallback() now passes a vec rather than a Vector. Callbacks that only iterate can accept Traversable<Awaitable<mixed>> to remain compatible. 75f849cc74
