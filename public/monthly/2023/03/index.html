67 noteworthy changes, organized by the source changelog sections.

Highlights

58 changes
  • W09 · Mar 1
    JSON output from --tast-holes-batch now includes each hole's filename, allowing callers to safely combine results from multiple input files. 738e1b8a3d
  • W09 · Mar 2
    Sound-dynamic inference can now solve variables with supportdyn<T> on both sides, push supportdyn through Traversable and KeyedTraversable, and use safe dynamic-aware variance when checking overrides. This accepts more valid SDT collection and override patterns without permitting unrelated like types to override one another. ccbed68c5c 58073f2561 7aec7bc986
  • W09 · Mar 2
    HH\ImplicitContext\get_state_unsafe() can report whether the current implicit-context state is null, value, soft-set, inaccessible, or soft-inaccessible. Observing this state can undermine memoization guarantees, so the API is intended only for controlled migrations and diagnostics. 9b41b6f14c
  • W09 · Mar 2
    A constructor declared final may no longer be overridden merely because its hierarchy uses <<__ConsistentConstruct>>; Hack now reports the override that HHVM would fatal on while loading the class. 7100e0a74a
  • W09 · Mar 3
    PACKAGES.toml is now part of HHVM's repository-options cache key. Changing package definitions invalidates the cached configuration so subsequent compilation or loading sees the new package map. 90d3e33675
  • W09 · Mar 3
    Repeated use of function-coverage collection no longer risks a JIT crash after coverage state is cleared. ced950aa4e
  • W09 · Mar 4
    Errors are now sorted by their exact code before deduplication. hh_server and hh_single_type_check should therefore retain the same error when several diagnostics from one phase share a position. d99aae2f70
  • W10 · Mar 6
    Standalone IDE mode now publishes fresh diagnostics after files are opened or changed, without waiting for a persistent hh_server connection. 735edbcea0
  • W10 · Mar 6
    A deployment in PACKAGES.toml may now select multiple domains, and each domain is interpreted as a regular expression. HHVM's package information now carries deployments so server requests can select the active package set from the host name. 8a423bfd07 44443ec5d4
  • W10 · Mar 6
    File attributes are now attached to module declarations. A file containing only new module declarations will no longer skip validation of an invalid or misspelled file attribute. 833db87aae
  • W10 · Mar 7
    Refining a generic or variable of type supportdyn<T> with as C<_> now preserves the outer supportdyn, allowing it to push into supported containers. 2df43ba6d8
  • W10 · Mar 7
    The capability requirements of several built-ins are now more precise. cpu_get_count() and cpu_get_model() require only [read_globals]; read-only APC queries also require [read_globals], mutating APC operations require [globals], and apc_sma_info() is []. These are backwards-compatible relaxations from implicit [defaults], so the functions are callable from more restricted contexts that still provide the stated capabilities. 190f4646d7 a7332ca5ba
  • W10 · Mar 7
    Frames passed to an fb_setprofile() callback now include the call site's file and line, avoiding a separate debug_backtrace() solely to recover that information. c09a67aaa0
  • W10 · Mar 8
    Sound-dynamic typing of Shapes::idx(), Shapes::at(), and Shapes::keyExists() now follows their transformed HHI declarations. Shape and Pair operations are no longer automatically pessimised, and Hack-array element bounds rely on supportdyn pushing instead. Projects should see more precise element types and errors that consistently enforce SDT arguments. b0c6a3527b 1c3dd600e1 e707d1fd3b 3ffec61090
  • W10 · Mar 8
    <<__NoAutoDynamic>> is now honored when a trait is parsed directly; annotated traits are no longer incorrectly treated as supporting dynamic under implicit pessimization. d48859c686
  • W10 · Mar 8
    Enum classes now participate in implicit sound-dynamic pessimization like ordinary classes. 53a512f6d9
  • W10 · Mar 9
    Class type refinements such as Box with { type T = int } no longer require <<file:__EnableUnstableFeatures('type_refinements')>>. 4fc409a7f6
  • W10 · Mar 9
    Under sound dynamic, an as refinement from an integer to a string-backed enum—or the reverse—is now weakened to ~Enum. This reflects the runtime coercion hazard instead of treating the result as a fully trusted enum value. 57bdb70e4f
  • W10 · Mar 10
    The right side of ?? is now treated as conditional when updating local refinements. Assignments performed only in that branch no longer incorrectly refine the environment as though the branch always ran. d59878c0d8
  • W10 · Mar 10
    hh check --ide-go-to-impl FILE:LINE,COLUMN exposes go-to-implementation results through the command-line client. ac050ce4d5
  • W10 · Mar 12
    The new package_exists(string): bool built-in reports whether a package is available in the active deployment. In server mode the deployment is selected from the request host; CLI and repo-authoritative mode use the configured active deployment. With no active deployment, it reports whether the package is defined at all. fdd040c474
  • W11 · Mar 13
    Invalid PACKAGES.toml relationships now produce parsing error 1009. The checker reports references to undefined packages and module globs assigned to more than one package. fbc8e0d7bb
  • W11 · Mar 13
    Implicit pessimization of an async function returning an enforced enum now applies the enum's base-type intersection inside Awaitable<...>, rather than intersecting the awaitable itself down to nothing. 95dae7a057
  • W11 · Mar 13
    Enum classes may now carry the internal SDT marker used by implicit sound-dynamic mode, avoiding recursive subtype failures for pessimised enum classes. 4ff56661ca
  • W11 · Mar 14
    hh progress is now tracked per repository rather than per server PID, allowing clients to show monitor and server status before connecting. Stale progress from a dead process is ignored, idle servers report ready, and long fanout/typecheck phases provide earlier and more accurate status messages. 98658279b8 8550b0f635 0cd7ddd10c
  • W11 · Mar 15
    Type constants in enum classes are now generally available and no longer require the enum_class_type_constants unstable-feature opt-in. bd5838a61b
  • W11 · Mar 16
    A new quick-fix application tool consumes hh --lint --json output from standard input or --input-file. It prints patched source by default and can update files with --overwrite; overlapping, stale, or otherwise unsafe fixes are dropped. 58c5e14cc8
  • W11 · Mar 16
    Package configuration validation now reports every cycle in the includes graph. 6c97dac720
  • W11 · Mar 17
    hackfmt now keeps expression-tree block braces next to their backticks, formatting them as Dsl`{ ... }` rather than separating the backtick and brace. a665b6d472
  • W11 · Mar 17
    The March 10 default requiring constant function and lambda default arguments has been reverted. Nonconstant defaults are accepted again unless the stricter options are explicitly enabled. 04b49bbdfe
  • W11 · Mar 18
    The redundant-cast linter now reports a cast in sound-dynamic code only when it is redundant under both normal and dynamic assumptions, reducing unsafe suggestions at dynamic boundaries. 13baee84fc cb5f9f9236
  • W11 · Mar 19
    Quick-fixes for redundant casts now preserve expression precedence, adding parentheses when removing a cast would otherwise let an enclosing operator capture part of the expression. a07d4e824a
  • W12 · Mar 20
    Missing-required-XHP-attribute diagnostics no longer prefix the attribute name with :, avoiding the misleading suggestion that ordinary XML attribute syntax requires a colon. 3b174001fe
  • W12 · Mar 20
    hh --codemod-sdt JSONL cumulative-groups|independent-groups can now apply an SDT analysis result by adding <<__NoAutoDynamic>>. Cumulative mode keeps groups that introduce no new type errors; independent mode evaluates and reverts each group separately. 4e986b3a3f
  • W12 · Mar 21
    Redundant as nonnull and always-succeeding as lints now offer precedence-safe quick-fixes that remove the assertion. f8e5cede57
  • W12 · Mar 21
    Incremental checking with the Rust provider backend now invalidates folded declarations for descendant classes after an ancestor changes, preventing stale inherited members and diagnostics. a7e37de3a3
  • W12 · Mar 22
    PACKAGES.toml now accepts soft_includes. Access across a soft include still produces a package diagnostic, but uses the distinct error code 4473 rather than hard cross-package error 4472, so migrations can suppress the soft boundary without hiding a later hard violation. 484aecd02c 4f27d55a1f
  • W12 · Mar 22
    For $base[$key] = $value, Hack now checks $key before $base, matching HHVM's evaluation order. This fixes both unsound refinements and valid programs rejected because the old checker assumed the reverse order. a993d20925
  • W12 · Mar 23
    Collection constructors with explicit type arguments can now infer like types from their values. For example, a Pair<int, string> built with a ~int value is inferred as Pair<~int, string> instead of being rejected. 2b9cfa4290
  • W12 · Mar 23
    vec is no longer treated as an automatically pessimised built-in. A vec<int> indexes to int, while constructing a vector from ~int values produces vec<~int> and preserves the dynamic boundary explicitly. 3beca4465d
  • W12 · Mar 23
    HHVM now computes the package cache key after reading PACKAGES.toml and uses the correct file metadata, fixing cases where package edits failed to invalidate repository options. c4f8aca11a
  • W12 · Mar 24
    keyset is no longer automatically pessimised. Construction and direct indexing now preserve the actual element type; dynamic elements remain intersected with arraykey, for example keyset<(~int & arraykey)>. 48985c4e75
  • W13 · Mar 27
    dict is no longer automatically pessimised. Direct construction and indexing preserve value types such as dict<string, int>, while like-typed values produce an explicit type such as dict<string, ~int>. 73c97aac94
  • W13 · Mar 27
    In autocomplete, typing -> after a vec, dict, keyset, or string now offers compatible HSL functions and rewrites the expression into a function call with argument placeholders. 73284d7d46
  • W13 · Mar 27
    Package validation now requires each deployment's package set to be transitively closed over includes and reports the packages missing from an incomplete deployment. 43bcd2a962
  • W13 · Mar 28
    The IDE now offers an “Extract into variable” refactor for selected expressions. It avoids lvalues and await, but extracting a side-effecting expression can still change evaluation order and should be reviewed before accepting the edit. 4f66c7deb3
  • W13 · Mar 28
    Sound-dynamic subtype solving now retains useful T <: ~#var bounds and correctly strips covariant like types from both arguments and bounds of HH\MemberOf, fixing affected enum-class inference. 291ef8f280 93e36262dd
  • W13 · Mar 29
    “Extract into variable” now works inside single-expression and nested lambdas, and tolerates a selection that extends beyond the exact expression boundaries. ef966ccc4a 24b553703d
  • W13 · Mar 29
    Array assignment and append now restore the local environment before their second typechecking pass. Typed-AST types and local refinements are no longer corrupted merely because the left side was checked twice. 38ca0da32a
  • W13 · Mar 30
    Hover information now prints polymorphic contexts such as [ctx $callback] in source form rather than exposing the lowerer's synthetic type-variable name. afd31289dd
  • W13 · Mar 30
    An opt-in streaming mode can display type errors as hh_server discovers them. Start the server with produce_streaming_errors=true and run the client with ide_standalone=true; JSON output remains on the complete, non-streaming path. Streaming checks can additionally exit with Typecheck_restarted when files change or Typecheck_abandoned when the server terminates. 6af7c50224 fc4279b6b0
  • W13 · Mar 31
    HSL adds Vec\map_with_key_async(), which invokes an async callback with each original key and value in parallel and returns an Awaitable<vec<_>>. c2341d38b1
  • W13 · Mar 31
    Nested collection constructors with explicit types now keep precise inner types—for example, vec<vec<int>>[vec[2, 3]] remains vec<vec<int>> rather than acquiring an unnecessary like type. Mutable collection classes are now always treated as pessimised built-ins; the configuration flag no longer disables that behavior. 5ad92d1c7a 103067848a
  • W13 · Mar 31
    Lint 5650 recommends async ... ==> await ... when a synchronous lambda directly returns an Awaitable, improving stack traces. Lint 5651 warns about lambdas inferred as Awaitable<Awaitable<_>>, where an inner await was likely omitted. 328976bc0a 642ca62d90
  • W13 · Mar 31
    The experimental package NAME expression now has type bool, and an undefined package name produces a naming error based on PACKAGES.toml. 480031f13c
  • W13 · Mar 31
    Capability checks are now skipped for virtualized expression-tree calls, which are typechecked but never executed. Pure code can therefore construct DSL expressions whose virtual methods have [defaults] without receiving a false call-capability error. 9e6d3f539b
  • W13 · Mar 31
    Local-variable completion items now display the variable's inferred type instead of the generic label “local variable.” 4f8762d581
  • W13 · Mar 31
    HH\Lib\Async\Poll and BasePoll no longer recurse through long already-satisfied awaitable chains, avoiding stack overflows in large polling workloads. 2033efe304

Security

Breaking Changes

3 changes
