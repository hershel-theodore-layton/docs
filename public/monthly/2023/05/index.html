Highlights

40 changes
  • W18 · May 1
    Find-references requests from the IDE daemon now recompute results for open files, so unsaved edits are reflected instead of returning only the server's on-disk view. 36d3d923ee
  • W18 · May 2

  • W18 · May 2
    Package-aware function subtyping now reports mismatched __CrossPackage requirements in method overrides. A function restricted to one package can only override a function with the same package restriction, while an unrestricted function remains a valid supertype. a9ec057078
  • W18 · May 2
    Uncaught exceptions from hh check once again print their call stack, making failed typechecker invocations actionable without additional logging. 21d9be5ae9
  • W18 · May 3
    HHVM gained experimental execution recording and replay support, including hhvm_wrapper.php --record and --replay modes for reproducing requests and native-call results. ef45cfd538
  • W18 · May 3
    When the typechecker is occupied while a client connects, hh_client now reports hh_server is busy [connecting] rather than appearing to hang without context. c49bbae52f
  • W18 · May 4
    Sound Dynamic subtyping now prefers the concrete type mismatch over a secondary dynamic mismatch, and implicit-pessimisation failures choose more useful union branches. Error messages should point closer to the actual incompatible type. 5e765d6794 2523b6b4f0
  • W18 · May 4
    Rename now updates references in unsaved open files instead of relying exclusively on positions from the on-disk hh_server state. 8f8391cdbd
  • W18 · May 4

  • W18 · May 5

    Typechecker exit records now include the exception message and call stack for an uncaught server failure, improving diagnostics from wrappers and monitoring systems. 9899d086e9

  • W19 · May 9

  • W19 · May 10

Structured JSON from --type-at-pos hides migration-only like-type wrappers while the display string retains them, and redundant HH\FIXME\UNSAFE_CAST_NONNULL casts can now be removed by the quick-fix and codemod. 9cf23265f2 ccf7af145a 95353318c3

  • W19 · May 12

  • W20 · May 15

  • W20 · May 15

Security

1 change
  • W18 · May 2
    Multipart upload handling now uses overflow-safe size calculations. This fixes an integer overflow through which a sufficiently large multibyte upload could cause an out-of-bounds write; deployments accepting uploads should update promptly. 6c8ad0530c

Breaking Changes

11 changes
  • W18 · May 4
    Enum supertyping is now fully released and its .hhconfig release flag has been removed. Enum includes declarations are checked unconditionally. 910382a92e
  • W18 · May 6
    HH\autoload_get_paths() has been removed. Applications can no longer enumerate every file known to the native autoloader through this API. fc420c2e7d
  • W19 · May 9
    XHP attribute access now typechecks the underlying getAttribute() call, including the method's signature and required capabilities. Custom XHP bases with an incompatible or missing method may receive new errors where the attribute is read. c6b3bc7f59
  • W19 · May 10
    Source use of <<__NoAutoDynamic>> now requires enable_no_auto_dynamic = true; HHI declarations remain exempt. da86d4290f
  • W19 · May 10
    Reserved type-name checks now apply uniformly to class, interface, trait, enum, enum-class, and type-alias declarations, including declarations inside namespaces. varray and darray are explicitly unavailable as alias names, while classname is now allowed as a user-defined classish or enum name. Direct HackC users may newly see parse errors for names that hh already rejected. 3ee812d373 8f41d4f642 76a42d2d94 da292e9950 ade4fad16e
  • W19 · May 11
    <<__NoAutoDynamic>> is no longer accepted on classes. Apply the opt-out to supported declarations such as individual methods or interfaces instead. 60560ff1fd
  • W19 · May 12
    User-defined autoload maps and autoload_set_paths() support have been removed. Sandbox deployments use native Facts autoloading, while repo-authoritative deployments use RepoAutoloadMap. 6bb7530a87
  • W20 · May 15
    The obsolete hh --coverage and hh --color commands, along with the old IDE coverage status, have been removed. They predated constraint-based typechecking and no longer represented meaningful type coverage. 10a04c1344
  • W20 · May 15
    Enabling implicit Sound Dynamic no longer implicitly enables the supportdyn type-hint syntax. Projects writing supportdyn<T> directly must explicitly enable enable_supportdyn_hint; generated pessimised declarations are unaffected. 126a09182e
  • W21 · May 26
    When deployment enforcement is enabled, HHVM now rejects direct, dynamic, function-pointer, and closure-mediated calls to top-level functions whose module is outside the active deployment. 9ad9cac167
  • W22 · May 31
    The legacy hh --auto-complete command has been removed. Editor integrations and other consumers should use the IDE autocomplete service. 7ff9a5ae35

Future Changes

10 changes
  • W19 · May 9
    Runtime validation for <<__ModuleLevelTrait>> requires the annotated trait to be public and permits it to use only other module-level traits. Invalid combinations fail consistently before optimized execution. d38803e101
  • W19 · May 14
    Preview readonly checking now examines every callable in a union of function types. A call is rejected if any possible target is non-readonly, closing a soundness hole that was particularly visible through like-function types. fb3f1c41ca
  • W20 · May 16
    Experimental case types now have runtime type structures. type_structure(), reflection, and is/as checks can distinguish case-type aliases by name while inspecting their variants. Parameter and return enforcement is not yet part of this change. e2f3af435a
  • W20 · May 17
    Preview readonly checks now look through like-types when identifying Hack arrays, and required-XHP-attribute analysis handles compound like-types more completely. 045810ce56 f9a431a880
  • W20 · May 17
    Sound Dynamic no longer enables the experimental upcast expression automatically. Projects using upcast syntax must opt into upcast_expression independently. 0620b140c2
  • W20 · May 20
    Runtime method lookup now preserves the defining module of methods copied from module-level traits, so their internal accesses are checked against the trait's module rather than the consuming class's module. Runtime validation also rejects public traits that declare internal methods or properties, matching the existing Hack check. dd90abb638 dc0a3ac672
  • W21 · May 22
    The unstable module_level_traits feature is now understood by Hack. A public trait annotated <<__ModuleLevelTrait>> keeps its defining module for boundary checks, allowing it to expose controlled behavior that calls internal symbols from that module. 7b8b52235d
  • W21 · May 25
    Experimental package checking now rejects code in the default package when it accesses a public symbol from a non-default package that the default package does not include. 3a23391ec7
  • W21 · May 26
    Experimental case types now require conservatively disjoint runtime variants. Variants whose shallow runtime tags may overlap produce a type error; this initially includes all pairs of object types and overlapping primitive unions. ab1c79066d
  • W22 · May 30
    The experimental typed_local_variables feature introduces declarations such as let $value: int = 1;. This initial step parses and erases the annotation to an ordinary assignment; full assignment consistency and possible runtime enforcement are still future work. 489986a389
