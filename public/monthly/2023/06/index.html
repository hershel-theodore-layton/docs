Future Changes

26 changes
  • W22 · Jun 1
    Under implicit pessimisation, readonly array updates now look through readonly expressions before handling like-types. This fixes incorrect inferred types for readonly array operations. 6279fa521a
  • W22 · Jun 1

  • W22 · Jun 2

    Autocomplete now works with implicit sound dynamic enabled and hides internal supportdyn wrappers from displayed completion types. 3b4e68b142
  • W23 · Jun 6
    Implicit pessimisation now introduces supportdyn correctly within the expression being checked by is and as. fd26322eb2

  • W26 · Jun 27

  • W26 · Jun 29

  • W26 · Jun 30
    Readonly method-call checking now handles function types wrapped with dynamic by implicit pessimisation, avoiding false readonly errors and invariant failures. ab343625af

Breaking Changes

3 changes
  • W22 · Jun 2
    Runtime type tests such as $value is dynamic are now rejected. HHVM cannot test whether an arbitrary value supports dynamic, so using the result to refine $value to dynamic created a type hole. Test for a concrete runtime type instead. 89bedcf12d
  • W25 · Jun 22
    Autoload.Enabled has been removed because native autoloading is always enabled. Configuration that still sets the option should remove it; it no longer controls runtime behavior. 7e2baa2a3d
  • W26 · Jun 27
    Dynamic property access such as $object->{$name} now requires the receiver to support dynamic, and the access result is always dynamic. Using it on an ordinary statically typed object is rejected; accidental $ insertion still receives the existing quick-fix to normal property access. aade1260bd
