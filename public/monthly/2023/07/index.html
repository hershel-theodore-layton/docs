Future Changes

13 changes
  • W26 · Jul 1
    HHVM gains the first runtime implementation for checking case types in parameter and return positions. Default builds still treat case types as mixed while the rest of runtime enforcement is completed, so this commit is groundwork rather than an immediate behavior change. 7d8e1d9dba
  • W27 · Jul 6
    The experimental typed-local syntax now permits declarations without an initializer, such as let $x: int;. Reading the local before a later assignment remains an error. 87d5938fe6
  • W28 · Jul 11
    A case type may no longer be the base type of an enum or enum class. This is rejected until case-type enforcement in those positions has consistent runtime semantics. c8befa3337
  • W28 · Jul 13
    A generic name used illegally in a trait’s require class clause now yields a normal type error instead of raising an exception in the typechecker. 58855f8577
  • W28 · Jul 14
    Experimental typed locals now enforce their declared types and diagnose redeclaration, shadowing, and incompatible control-flow joins. Typed-local declarations are also supported inside concurrent blocks; coverage for further statement and lambda forms continues in later commits. 9055f3104c 28e003b54b
  • W29 · Jul 17
    Experimental typed locals are now tracked correctly inside arrow lambdas and PHP-style closures with explicit use captures. f13f87d992 2f410f33e0
  • W29 · Jul 18
    HackC now understands wildcard types in lambda parameter and return hints and treats _ itself as unenforced at runtime while retaining the surrounding type check. The typechecker still rejects explicit lambda wildcards at this point; this is groundwork for later accepting forms such as (vec<_> $x) ==> .... 54356672cb
  • W29 · Jul 19
    Intersections now expose and filter case-type variants when the other constraints identify a concrete data type. Refinements such as CT & vec<mixed> and negative is branches can therefore simplify to a usable surviving variant. ac30c4d792
  • W29 · Jul 20
    Experimental typed locals now flow correctly through try/catch/finally, switch, and foreach statements. 230741a3e2 c5781f6f1b
  • W30 · Jul 25
    The parser and hackfmt gain an initial experimental match statement with variable, type-refinement, and wildcard-constructor patterns. It remains behind the match unstable-feature opt-in and is not yet a complete language feature. 33dac5b0df
  • W30 · Jul 28
    Case-type refinement now handles intersections with negated special classes correctly, preserving only variants that can satisfy the negative constraint. e5b7ccbeab
  • W30 · Jul 29
    A pessimise_builtins typechecker option has been reintroduced to control whether built-ins such as Vector acquire like-typed arguments under sound dynamic. It defaults to false and prepares for enabling sound-dynamic checking by default without implicitly changing every built-in. c5c9be9976
  • W31 · Jul 31
    Experimental typed-local enforcement now covers assignments with nontrivial left-hand sides and compound operators such as +=. 68bc5f2e54 cda0c7ba09

Highlights

36 changes
  • W27 · Jul 4
    The “extract interface” code action no longer copies an invalid async modifier onto the extracted interface method. 0610faf806
  • W27 · Jul 4
    “Extract into method” now handles a selection whose first line is a comment without generating syntactically invalid Hack. 6b3d7678c0
  • W27 · Jul 5
    The IDE’s “Extract shape type” action now works on shape type hints as well as shape expressions. Its generated alias starts with T, and the placeholder name is selected for immediate renaming. 77d0d73508 5c1517fe0a
  • W27 · Jul 5
    Many HSL array, dictionary, keyset, and vector helpers now opt out of automatic like-type insertion under sound dynamic, preserving more precise declared return types. 7d39d37d93 2cae1c79ff f0b48d9069
  • W27 · Jul 5
    Sound-dynamic typing now preserves a supportdyn element constraint when widening an array-like lower bound to typecheck indexed access. This avoids spurious failures where the widened element type previously collapsed to mixed. 640749cbd4
  • W27 · Jul 6
    Type inference now recognizes equivalent nullable bounds of the form null, T <: #x <: ?T, improving solutions for otherwise underconstrained type variables. 4e824a897a
  • W27 · Jul 6
    Under implicit sound-dynamic pessimization, <<__NoAutoLikes>> suppresses only inserted like types. Generic parameters still receive a supportdyn<mixed> bound unless that parameter also has <<__NoAutoBound>>. 98b6c9f178
  • W27 · Jul 7
    Invalid cycles through trait require class or require implements clauses now produce ordinary diagnostics without overflowing the typechecker’s stack. dc3b6cfafb
  • W27 · Jul 7
    The IDE now returns the LSP ContentModified error when a requested code action can no longer be resolved, rather than crashing the language server. “Extract shape type” also survives an internal candidate invariant violation and continues serving later requests. a1344f26cb 5c55e0af6f
  • W27 · Jul 7
    “Extract into method” is now offered for the expression body of a lambda such as () ==> 3 + 3. f5a7a56c92
  • W28 · Jul 10
    “Extract into method” once again formats the generated method body at the correct indentation after inserting its editor rename placeholder. 07ad225ee4
  • W28 · Jul 11
    Command-line symbol renaming no longer applies a replacement twice—for example, renaming Foo to Bar now produces Bar, not BarBar. 29daa1ba32
  • W28 · Jul 11
    Another group of HSL functions now uses <<__NoAutoLikes>>, keeping precise types under implicit sound-dynamic pessimization. Higher-order helpers remain excluded while lambda inference is being improved. 722cd52156
  • W28 · Jul 13
    _ may now request inference in nested explicit type arguments, as in foo<vec<_>>(). It is still rejected anywhere beneath a type parameter declared <<__Explicit>>. e1811dd241
  • W28 · Jul 14
    “Extract shape type” is now offered only when a shape expression is selected, avoiding an IDE invariant failure for selections that merely contain a shape. ce1676dece
  • W29 · Jul 17
    Type displays now consistently render a union of dynamic | T as the like type ~T, even when sound dynamic is not enabled. This affects diagnostics, hover text, typed-AST output, and other pretty-printed types. 1919727869
  • W29 · Jul 17
    When multiple package module globs match, HHVM now assigns the module to the package with the longest, most-specific prefix, matching the typechecker’s interpretation. 79819e903f
  • W29 · Jul 18
    Under sound-dynamic pessimization, HH\FIXME\UNSAFE_CAST<Tin, Tout>() is now checked through its declared HHI signature: both source and destination must support dynamic, and the result receives the expected pessimised type. 943dbbf32a
  • W29 · Jul 18
    Standalone IDE mode now loads PACKAGES.toml, so package-access diagnostics stay in sync with a full hh_server typecheck. fbcf2bfbe3
  • W29 · Jul 19
    Autocomplete now follows chained method calls through supportdyn and like types more reliably, restoring member suggestions under implicit sound-dynamic pessimization. 7eda8da7c3
  • W29 · Jul 19
    HH\get_headers_secure() now declares the precise [read_globals] capability instead of implicit [defaults], allowing calls from contexts that grant global reads without granting every default capability. 8e93d5e2a8
  • W29 · Jul 19
    The Facts API adds HH\Facts\files_with_attribute_and_any_value(), returning files whose file attribute has a requested value. Query values support booleans, integers, strings, dicts, vecs, and keysets; unsupported values are coerced to null. 7935244238
  • W29 · Jul 20
    HH\parse_cookies() parses a raw Cookie header into the same nested dict/vec shape used by $_COOKIE, without mutating request globals. ad7a65180a
  • W29 · Jul 20
    The splat operator may now contain await directly, enabling calls such as f(...await $args). b62d8f788f
  • W29 · Jul 21
    hh_single_complete --root ... --naming-table ... now resolves names from its naming-table fallback correctly instead of producing bogus ==> parse errors for affected completions. 99f9df3a97
  • W30 · Jul 24
    The switch-exhaustiveness lint no longer emits a duplicate false positive during the sound-dynamic checking pass. Exhaustive enum switches remain clean under implicit pessimization. 7fbe91a59f
  • W30 · Jul 24
    hh_single_complete can now use Glean for symbol search, honors --auto-namespace-map, and consistently respects --no-builtins. 670b9c1b6f
  • W30 · Jul 25
    Nullsafe method calls now tolerate an inferred supportdyn<null> arm, avoiding a spurious sound-dynamic error where the supportdyn wrapper is redundant. b6e37eaff6
  • W30 · Jul 25
    Type errors involving an optional shape field now point to that field’s own definition instead of an unrelated required field. 1b3d6ba915
  • W30 · Jul 25
    Under sound dynamic, legacy varray<T> and darray<Tk, Tv> types no longer implicitly pessimise their type arguments to like types. fdaedd5885
  • W30 · Jul 26
    “Extract shape type” now raises its type-printing limit substantially, preventing large generated aliases from being truncated into invalid Hack. Extremely large types still retain a finite editor-safety limit. 7a2f7f8b45
  • W30 · Jul 26
    HHVM now registers the full sodium API consistently, including AES-256-GCM functions that the HHI already promised. Builds and target CPUs must provide a sufficiently recent, fully capable libsodium. 5efda73ea0
  • W30 · Jul 28
    An erased or otherwise unenforceable generic may now appear inside a reified class type used by is/as, such as C<T> where C’s parameter is reified. A direct as T still requires T to be enforceable, and wildcard _ is now correctly rejected as a reified runtime witness. ef78282fef
  • W30 · Jul 30
    hh --refactor now generates a deprecated forwarding wrapper when a symbol rename requires one, matching the behavior that was previously available only through hh --ide-refactor. 118497e85c
  • W31 · Jul 31
    The JSON representation of a Hack User_error now includes rendered custom diagnostic text in a custom_messages array, making it available to typed-AST and error-processing tools. d8c1defb73
  • W31 · Jul 31
    <<__CrossPackage("package")>> now loads the requested package while typechecking methods as well as top-level functions, so permitted cross-package calls from attributed methods no longer fail spuriously. 21c294919f

Breaking Changes

7 changes
  • W28 · Jul 11
    The STDIN, STDOUT, and STDERR pseudo-constants have been removed from Hack’s bundled declarations. Replace them with HH\stdin(), HH\stdout(), and HH\stderr() (or their try_ variants). d615f24ec4
  • W28 · Jul 12
    Hack’s language server now always runs in standalone IDE mode. The old modes that delegated IDE operations or diagnostics to a persistent hh_server can no longer be selected through local configuration. 24039fc87d
  • W28 · Jul 14
    hh --json now writes JSON to standard output by default. Scripts that previously read the JSON stream from standard error should update their redirection. 647e96e836
  • W28 · Jul 14
    HHVM has removed the STDIN, STDOUT, and STDERR pseudo-constants at runtime, completing the declaration removal from July 11. Use HH\stdin(), HH\stdout(), and HH\stderr() instead. b34346b202
  • W29 · Jul 21
    The obsolete mbstring.http_input and mbstring.http_output INI settings have been removed. Deployment configurations that still set them should delete those entries. 6a26df2499
  • W30 · Jul 24
    Runtime type structures no longer contain a boolean "like" field, and HH\TypeStructure\get_like() has been removed. Rendering a type from a type structure therefore no longer adds ~ based on that field; code inspecting raw type structures must stop depending on it. 367fef24fc
  • W30 · Jul 25
    as ~T now performs a real runtime check by looking through the like type to T; it is no longer treated as a no-op. Like-type is/as expressions use the same look-through semantics in the typechecker. a2fadfcddb 1cfe2b1978

Security

1 change
  • W30 · Jul 27
    HHVM now detects stack exhaustion while releasing deeply nested heap data, addressing CVE-2023-33935. Instead of recursively overflowing, it leaves the remaining objects for garbage collection. 8161b2d53a
