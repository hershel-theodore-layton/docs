Highlights

29 changes
  • W31 · Aug 1
    Under Sound Dynamic, hovering a method call through a like-typed receiver now shows the method's ordinary signature instead of rendering the whole callable as a like type. bdfd6dc2e9
  • W31 · Aug 1
    Exhaustivity checking now recognizes pessimised enum types of the form bound & ~E, restoring missing non-exhaustive-switch diagnostics. 21348ec543
  • W31 · Aug 1
    Refactoring code actions now honor the client's snippet-edit capability. Clients without it receive ordinary placeholder names such as method0, rather than literal snippet syntax such as ${0:method0}. 0041ad042d
  • W31 · Aug 4
    A lone yield break now makes an async function an AsyncGenerator in the typechecker, matching the runtime's existing behavior. 1abdce88b8
  • W31 · Aug 5
    ASIO dependency-cycle exceptions discovered while advancing await all or concurrent work now reconstruct the relevant async stack instead of reporting a scheduler-truncated trace. f03de9132a
  • W32 · Aug 9
    Bidirectional inference now uses the upper bound of an expected type variable when typing lambdas. Generic helpers such as makeSingle($x ==> $x->foo()) can therefore infer the lambda parameter from the surrounding expected type. 6cb17946fa
  • W32 · Aug 9
    Typechecking very large argument lists and vec literals no longer overflows the typechecker's stack. 265db40acd
  • W32 · Aug 9
    Targeted explicit pessimisation now honors <<__NoAutoLikes>> on return types, function types, and inout parameters. 5bc783525a
  • W32 · Aug 10
    Symbol-info indexes now include inherited class, interface, and trait members by default, improving the accuracy of tools that consume Hack's symbol index. The behavior can be gated with symbol_write_index_inherited_members. c4ad5562ac
  • W32 · Aug 11
    A direct-declaration parsing bug no longer lets <<__NoAutoLikes>> on one method leak into methods declared after it. 045457670e
  • W32 · Aug 11
    Sound Dynamic subtype checking now pushes like types through nested invariant type arguments in both directions, admitting relations such as Map<string, Vector<~C>> <: ~Map<string, Vector<C>>. 5919987cd9
  • W32 · Aug 11
    Soft package-deployment violation warnings can now be sampled with Eval.DeploymentViolationWarningSampleRate, reducing log volume during migrations. 38b77e9ac5
  • W33 · Aug 14
    Sound Dynamic no longer adds an unnecessary outer like type to Vector methods whose collection-shaped result is already enforced by HHVM. Operations such as toSet() now retain their declared container type more precisely. 995317f216
  • W33 · Aug 15
    hh_single_type_check --map-reduce can now run configured typed-AST analyses and print their reduced JSON result. 0ffd752fc9
  • W33 · Aug 15
    The new hphp_debug_caller_identifier()[leak_safe]: string runtime helper returns the caller's full function or Class::method name without constructing the full hphp_debug_caller_info() dictionary. dfc3cbbaa0
  • W33 · Aug 15
    Package module patterns now use prefix-glob semantics matching the runtime: foo.* matches descendants of foo, * matches every module, and other patterns are exact names. 3ef62b5f28
  • W33 · Aug 16
    The new type-counter map reducer can audit a codebase for like, non-like, mixed, supportdyn<mixed>, dynamic, and Tany occurrences. It is available through hh_single_type_check --map-reduce --hh-log-level type_counter 1. da3b61a80b f0315270fc 2e8a805e77
  • W33 · Aug 16
    Find-references requests can now stream partial results through LSP $/progress when the client supplies a partial-result token, allowing editors to show references before the full server search finishes. e0a82f5c6c 8f8b4bb55a
  • W33 · Aug 18
    C\contains() now performs constant-time membership checks for Set and ImmSet, matching its existing fast path for keyset. 85252099f6
  • W33 · Aug 18
    Hack's bundled declarations now expose HH\parse_cookies(string)[defaults]: dict<arraykey, mixed>, allowing existing runtime calls to typecheck. ead349e711
  • W33 · Aug 19
    The VS debugger now checks breakpoints around JIT translations and can step from a throw into its matching catch, avoiding missed stops in optimized code. 31ece450ee 5ff8a7a3ce
  • W33 · Aug 19
    hphp_debugger_set_option('disableJit', false) can now re-enable the JIT for an attached debugger, even when Eval.JitDisabledByVSDebug normally disables it. 538ea114cd
  • W34 · Aug 22
    Hack's bundled declarations now expose HH\get_headers_secure()[read_globals]: dict<string, vec<string>>, allowing applications to typecheck use of the runtime's protected request-header API. ea174a9577
  • W34 · Aug 24
    Hack's bundled Facts declarations now include HH\Facts\files_with_attribute_and_any_value(), which finds files by file-attribute class and value when Facts is enabled. cb4f2f43de
  • W34 · Aug 26
    Compact Thrift deserialization no longer corrupts dict keys or values of wire type I08 by incorrectly applying zigzag decoding. 373966e7ab
  • W35 · Aug 30
    Sound Dynamic function-call checking now retries all parameters against their pessimised types when a mixed static/dynamic pass fails. Calls that require the dynamic interpretation from the first argument are no longer rejected spuriously, and their result remains like-typed. c613d98c5c
  • W35 · Aug 30
    Package checking now treats a missing module membership as the default module when matching package globs, aligning the typechecker with HHVM's runtime enforcement. 8db8b6b349
  • W35 · Aug 31
    Sound Dynamic no longer unnecessarily pessimises $shape['field'] ?? $default; the null-coalesced result keeps the precise union of the field and default types. 3c10902b53
  • W35 · Aug 31
    Streaming find-references now flushes all remaining results after the server search completes and reliably includes references from IDE-open files. Temporary result files have also moved out of the project root into the server's temporary directory. 9463755411 2df5c0ee10 44a3b226d4

Security

4 changes
  • W31 · Aug 1
    Malformed Thrift payloads can no longer crash the decoder by declaring an excessive collection capacity; large collections are now reserved incrementally. 3deb3191e0
  • W32 · Aug 7
    Pagelet-server callers can now detect or reject the unsafe legacy "Header: value" array form and collisions with keyed headers. Eval.PageletServerHeaderCheck controls warnings or rejection of the legacy form, while Eval.PageletServerHeaderCollide controls collision warnings, precedence, or rejection. 724d62be19
  • W33 · Aug 15
    Eval.SetHeadersInServerSuperGlobal can now prevent request headers from being copied into $_SERVER; applications can retrieve the raw protected header map with HH\get_headers_secure() instead. The compatibility default remains enabled. d3b6066fb8
  • W35 · Aug 31
    Eval.DisableParsedCookies can now stop parsing cookies into $_COOKIE and $_REQUEST, and removes the $_COOKIE superglobal entirely when enabled. Raw headers remain available for application-controlled parsing. The compatibility default remains disabled. 3b831a6deb

Breaking Changes

8 changes
  • W31 · Aug 2
    hh_single_type_check now enables Sound Dynamic by default, making --enable-sound-dynamic-type redundant and potentially changing diagnostics and inferred types in scripts that invoke the standalone checker. d10f4599f1
  • W31 · Aug 2
    debug_backtrace() no longer includes $this unless Eval.EnableArgsInBacktraces is enabled. c6d7874d35
  • W32 · Aug 7
    hh_single_type_check no longer accepts the obsolete --like-casts and --simple-pessimize options; targeted explicit pessimisation continues to use the like_casts configuration. ae834842e3
  • W32 · Aug 7
    hh --ide-find-refs-by-symbol now always emits JSON, and the human-readable hh_single_type_check --find-refs format now includes the matching symbol text. Tools parsing either command's old output need updating. da6d7dba16 b24518524c
  • W32 · Aug 10
    HHVM has removed the auto_prepend_file and auto_append_file INI settings. Entrypoint setup and teardown must be explicit. b182e8f63c
  • W32 · Aug 10
    The variables_order and request_order settings have been removed; superglobal population order is now fixed. e258daf596
  • W32 · Aug 10
    The unused arg_separator.input setting and configurable arg_separator.output setting have been removed. APIs that used the output default now hard-code & unless a separator is supplied directly. e4ffa04d48
  • W33 · Aug 14
    HHVM has removed support for dynamically loaded native extensions, including the -z path and the extension_dir, extensions, DynamicExtensionPath, and DynamicExtensions settings. Extensions must be linked into the HHVM build. 71e6b01ff5
