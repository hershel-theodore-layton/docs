October 2023

51 noteworthy changes, organized by the source changelog sections.

Highlights

28 changes
  • W40 · Oct 3
    The Hash extension now supports CRC-32C through hash('crc32c', ...) and the corresponding incremental hashing APIs. a0bc5f5044
  • W40 · Oct 4
    HHVM can now serialize enum-class labels for memoization and use them as memo-table keys. The typechecker still rejects these parameters until its matching update on October 18. c1e438cad1
  • W40 · Oct 4
    The debugger no longer resolves unrelated source and function breakpoints while loading units, functions, or classes, avoiding spurious breakpoint binding. cc5e336780
  • W40 · Oct 5
    New HH\classname_to_class() and HH\class_to_classname() helpers make the runtime representation changes between class names and class pointers explicit. classname_to_class() throws when the class cannot be loaded and emits a sampled notice when the target lacks the newly recognized <<__DynamicallyReferenced>> class attribute. 2b2d440a35 336f743c58
  • W40 · Oct 5
    Invalid debugger-style statements such as =$x + 1; now carry a quick-fix that converts the expression to var_dump($x + 1). A range-calculation fix also makes the new and existing quick-fixes appear for the correct IDE selection. 046af76074 5cd5c75667
  • W40 · Oct 6
    The IDE now offers an “Add doc comment” code action for supported declarations and correctly removes snippet placeholders before applying it. 488659d456 9b971b643e
  • W40 · Oct 6
    A statement beginning with debugger-only = syntax now receives a specific parse error instead of a generic unexpected-token error. ba6ea045cb
  • W40 · Oct 6
    Repository-authoritative deployment checks now consistently treat soft-deployed packages as outside the active hard deployment. 70a70f01be
  • W41 · Oct 9
    HHVM's Proxygen server now includes Retry-After when it returns HTTP 503 because a request timed out in the queue or the server is shutting down, allowing clients and proxies to retry deliberately. 70f352a4bb
  • W41 · Oct 10
    The bundled HHI now gives ReflectionMethod::getDeclaringClass() and getPrototype() their concrete ReflectionClass and ReflectionMethod return types instead of missing-return-type placeholders. 037cb95228
  • W41 · Oct 12
    Exception breakpoints now work while HHVM's JIT is enabled. a225476c97
  • W41 · Oct 13
    HackC now records a variadic parameter declared as T ...$args with runtime type metadata vec<T> rather than an erased generic array, matching the value actually presented to the function. 204aaf50aa
  • W42 · Oct 17
    Package diagnostics remain useful when a package mentions an undefined module: Hack now reports the missing module while still using its name to find and explain related package-boundary errors. 866ce8f064
  • W42 · Oct 18
    Memoized functions may now declare HH\EnumClass\Label parameters without a typechecker error, completing the runtime support added on October 4. 4cd1bb3fc8
  • W42 · Oct 18
    A new debugger_dump(mixed): void builtin renders a value using the debugger's serializer. In particular, it honors a value's debugger-display customization rather than exposing the ordinary var_dump() representation. 22a6b2b3a7
  • W42 · Oct 19
    Enum-class labels now work with the general serializers: serialize()-style modes use the dedicated e:length:label; representation, while JSON encodes a label as a string. 1b80a55bff
  • W42 · Oct 19
    Shape-key checking now follows every index in nested coalescing expressions such as $shape['a']['b'] ?? $fallback, so a missing inner key is no longer overlooked. 24b8ff501c
  • W42 · Oct 20
    $_SERVER['REQUEST_TIME_NS'] now exposes the request start time in nanoseconds. 12b5ed858f
  • W43 · Oct 23
    Runtime deployment checks no longer warn when caller and callee are in the same module, or when the caller itself is already outside the active deployment. This removes two sources of false-positive soft-deployment warnings. afc4e864da 09d597f5d8
  • W43 · Oct 25
    HTTP requests that expire after being dequeued now return the same 503 plus Retry-After response as requests rejected while still queued, closing a gap in overload signaling. 8e43190ec7
  • W43 · Oct 26
    Autocomplete after new no longer suggests type aliases, which cannot be instantiated and would produce naming error 2052. 004e06c110
  • W43 · Oct 26
    Functions and methods may use <<__AutocompleteSortText('...')>> to override their LSP sort key—for example, generated entry points can deliberately appear above their default alphabetical position. The argument must be one static string. 2fce55c0f2
  • W43 · Oct 27
    A server may now enable both full and per-file coverage. Each request can select one mode, while attempts to use both modes in the same request fail explicitly. b3523a4cf0
  • W43 · Oct 28
    Hack code actions now encode edited documents as file:// URIs as required by LSP, rather than passing filesystem paths. This preserves VS Code behavior and improves compatibility with stricter language clients. e9411431d2
  • W44 · Oct 30
    The Hack REPL now warns when a file loaded into its current request has changed on disk, because the already-loaded code will not be refreshed until a new request. 56722eba42
  • W44 · Oct 30
    The quick-fix for debugger-style =$expression statements now produces debugger_dump($expression) instead of var_dump(). The debugger serializer honors custom debug displays, which helps avoid revealing a value's raw representation. eb224b9d92
  • W44 · Oct 31
    Nullable runtime assertions now refine like types precisely: if $x has type ~Base, then $x as ?Derived is inferred as ?Derived just like the non-nullable assertion. e9d270eff8
  • W44 · Oct 31
    HHVM no longer intermittently loses an implicit context when only the low byte of its internal pointer is zero. a7c1d33f17

Future Changes

17 changes
  • W40 · Oct 4
    Experimental case types now preserve generic arguments when evaluating reified is checks and retain their nominal identity even when they contain a single variant. 580badd121
  • W40 · Oct 5
    The annotation-gated strict-switch checker now understands enum classes and dynamic. Enum-class arms are checked against the HH\MemberOf interface, while a bare dynamic subject requires default and rejects other arms. fe2334dfcf 5751ee4de9
  • W40 · Oct 5
    Code generation now recognizes the experimental class<T> type syntax; typechecker support follows later in the month. e8a4af259d
  • W40 · Oct 6
    The experimental nameof expression is now typechecked and compiled, including resolution of self, parent, static, and reified class names without relying on an implicit class-to-string conversion. 579290639c
  • W41 · Oct 9
    ReflectionClass::getRequiredClass() now returns the class named by a trait's pre-stable require class constraint, or null when no such constraint exists. be3c76e346
  • W41 · Oct 10
    Implicit pessimisation no longer wraps a declared this return type in a like type. Fluent methods that return $this therefore retain their precise return type under the rollout. 39873917db
  • W41 · Oct 10
    HHVM now limits a fully flattened experimental case type to 48 variants by default, with Eval.MaxCaseTypeVariants available to configure the ceiling. Definitions that exceed it fail during type-alias resolution. 83d4542659
  • W41 · Oct 12
    Hack now rejects static calls such as T::foo() when T is a trait with the pre-stable require class constraint. Call through the concrete class that satisfies the requirement instead; the new diagnostic is typing error 4476. 66031e6a16
  • W42 · Oct 19
    The experimental class<T> syntax is now accepted by the typechecker and currently behaves as the migration spelling of classname<T>. bc693532b5
  • W42 · Oct 20
    The unstable pipe_await feature now permits nested sequential awaits such as await f(await g(), await h()). Hack rejects nestings that would require a concurrent composition of sequential await groups. c2eec8e384
  • W43 · Oct 25
    IDE autocomplete inside experimental nameof expressions now offers all classish declarations, including interfaces and traits rather than only instantiable classes. 2498045ddc
  • W43 · Oct 26
    Experimental typed locals now preserve runtime checks across destructuring and compound assignments by checking temporary values before committing them. Their shape and tuple checks intentionally remain shallow rather than validating every nested field or element. b5fae97e2b 4a23bbba70
  • W43 · Oct 27
    Calls through intersection types are no longer incorrectly rejected under implicit pessimisation. 24c4cd9c79
  • W43 · Oct 27
    An experimental module-level trait may no longer also be internal; the typechecker now catches the combination that HHVM already rejected at runtime. 820766b1d0
  • W44 · Oct 30
    An experimental module-level trait may use only other traits annotated <<__ModuleLevelTrait>>; Hack now reports the invalid hierarchy before HHVM reaches its matching runtime fatal. 79e26d95a2
  • W44 · Oct 31
    The unstable nested-await implementation now diagnoses sequential awaits mixed into incompatible concurrent expressions, including sequential awaits inside a concurrent block. 13ad012627
  • W44 · Oct 31
    Under implicit pessimisation, HH\Readonly\as_mut() now retains its declared return type instead of acquiring an automatic outer like type. 5d156974e2

Breaking Changes

5 changes
  • W41 · Oct 11
    The boolean Eval.ClassnameNotices setting has been replaced by Eval.ClassnameNoticesSampleRate. Use 0 to disable notices, 1 to emit every notice, or a larger value to sample approximately one in that many class-to-classname conversions. 01c1f4e3cb
  • W43 · Oct 24
    HH\classname_from_string_unsafe() has been removed from the bundled HHI, so project calls no longer typecheck. Prefer C::class when the class is statically known; where a typed class name or class pointer is already available, use the explicit conversion helpers introduced on October 5. e4e180b387
  • W43 · Oct 26
    Eval.EnforceDeployment now defaults to true. Deployments that previously relied on the off-by-default setting may begin warning for soft-package boundary violations and throwing DeploymentBoundaryViolationException for hard violations; fix the package/module boundary or explicitly review the runtime setting. 1146464fbf
  • W44 · Oct 31
    Dynamic static calls with a fixed class, such as C::$method(), are now parse errors. If both pieces truly need runtime dispatch, the remaining supported form is $class::$method(); otherwise call the method by its literal name. e120477a21
  • W44 · Oct 31
    hh_client lsp must now be launched with an explicit project-root argument or from the project root (or one of its subdirectories). Editor integrations that started it from an unrelated working directory must set the root or working directory. 773a315692

Security

1 change
  • W41 · Oct 12
    Proxygen responses no longer send Content-Length together with Transfer-Encoding. Emitting only the transfer coding avoids ambiguous HTTP response framing and keeps HHVM compliant with RFC 9112. b1a80d1d3d
