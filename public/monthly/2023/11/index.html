Highlights

34 changes
  • W44 · Nov 1
    The VS debugger's asynchronous pause command now interrupts JIT-compiled loops and branches, so pausing no longer depends on the request reaching interpreted code. b08759b062
  • W44 · Nov 1
    HH\classname_to_class() now handles nonexistent lazy class values consistently, throwing an InvalidArgumentException that identifies whether the failed name came from a lazy class or a string. fb958936dc
  • W44 · Nov 2
    Sound Dynamic errors now explain when an inout parameter, return type, or property became a like type through implicit pessimisation, instead of reporting only that the resulting value is dynamic. 2aa0726c6b
  • W44 · Nov 2
    Large streaming find-references operations no longer block unrelated LSP requests such as hover. Cancellation also avoids crashing hh_server and is checked frequently enough to stop most ongoing worker batches promptly. c3a85f7f49 316f899d14 6be1ff91b5
  • W44 · Nov 3
    Type errors can now trace a suspicious type back through HH\FIXME\UNSAFE_CAST, making it clearer when a reported type may be a lie introduced by an unsafe cast. a250bace2b
  • W45 · Nov 6
    hh --config dump_tasts=file_list.txt can now dump the named files' typed ASTs to /tmp/hh_server/tasts or /tmp/hh_distc/tasts, including when typechecking is distributed. ac3fec9645
  • W45 · Nov 7
    Pending debugger commands after a client disconnects now fail with an exception instead of crashing HHVM. 4b60b22276
  • W45 · Nov 8
    Autocomplete now works inside top-level statements, primarily improving Hack notebook editing while leaving the ordinary top-level-statement diagnostic intact. a0de61cb38
  • W45 · Nov 8
    hash() and hash_copy() are now declared with the empty capability set [] rather than implicit [defaults]. This narrows their requirements and permits calls from pure contexts. 60c9fc68eb
  • W45 · Nov 9
    A static method call through an invalid string receiver still reports the receiver error, but its result is now typed dynamic rather than an unconstrained variable that commonly collapsed to nothing. This keeps code behind a fixme from gaining an unsoundly precise type. 26b37f5439
  • W45 · Nov 9
    Array access through a nullable value now continues with the array's element type after reporting the nullability error. Suppressing that first error no longer causes downstream expressions to infer nothing. d0ff8a66a2
  • W45 · Nov 9
    XHP auto-close edits now place the cursor before the generated closing tag. a9b6c46a54
  • W45 · Nov 9
    The VS debugger's variable command now serializes all remaining HHVM datatypes instead of failing on unsupported values. 92655846f6
  • W45 · Nov 10
    echo is now represented by a real typed signature, (readonly arraykey ...)[io]: void, instead of a Tany-based special case. Argument and missing-[io] capability errors now point back to that signature. 11bed300da
  • W45 · Nov 10
    Consecutive top-level statements now share a typing environment. Notebook hover and completion can therefore understand values assigned by earlier statements in the file. 9e37abd5a1
  • W45 · Nov 10
    LSP clients advertising the experimental autoCloseJsx capability can now request automatic XHP closing tags. 4697a751c8
  • W46 · Nov 13
    Accessing an undeclared field on an open shape now uses the shape's ... value type after reporting the missing-field error, rather than producing an error variable that usually inferred as nothing. 54d1903493
  • W46 · Nov 13
    Standard math declarations now expose precise, pure signatures: most transcendental functions return float, predicates return bool, and pow() accepts num arguments. Hover, autocomplete, and downstream inference no longer see missing placeholder types for these APIs. c53dbdd62b
  • W46 · Nov 13
    The “Extract into variable” code action now works in top-level notebook statements. 9f02369148
  • W46 · Nov 14
    Hack's LSP now defaults to pull diagnostics, allowing the editor to request current diagnostics rather than relying solely on pushed updates. a8624fccda
  • W46 · Nov 16
    nameof has graduated from the nameof_class unstable feature and can now be used without a file-level opt-in. 24c626761e
  • W46 · Nov 16
    The IDE can now initialize repositories that contain duplicate symbol names, consistently using the naming table's selected winner instead of refusing to start. 58ee676404
  • W46 · Nov 16
    hh_show() output no longer corrupts the language server's JSON-RPC stream and shut down editor features. d2da36c105
  • W48 · Nov 27
    hh_single_fanout now includes files with stale errors in its recheck set, keeping reported positions current after dependency changes. 85c8967bbd
  • W48 · Nov 27

  • W48 · Nov 28
    Standard-library HHI declarations now use real like types such as ~SplFileInfo and ~int instead of the internal HH\FIXME\POISON_MARKER<T> alias, improving hover and diagnostics for pessimised built-ins. f18ae44cf3
  • W48 · Nov 28
    Facts attribute-value queries now correctly normalize Class and LazyClass values to class names. a814431794
  • W48 · Nov 28
    LSP pull diagnostics are now unconditional and the rollout flag has been removed. e152ec6b86
  • W48 · Nov 28
    <<__AutocompleteSortText("...")>> may now be applied to classes as well as functions and methods, allowing tools to supply a stable custom ordering key for class completions. 2c09844345
  • W48 · Nov 29
    With the new off-by-default implicit_inherit_sdt option, a class or interface can inherit <<__SupportDynamicType>> behavior from an SDT parent instead of repeating the attribute. 91e91b246c
  • W48 · Nov 29
    Autocomplete declaration paths now retain <<__AutocompleteSortText>> values for methods and class elements, allowing the requested custom ordering to reach completion results. d093f7148f 6aecbfbc4f
  • W48 · Nov 29
    Top-level-statement validation is now a naming error rather than a parsing error. Normal Hack files still reject the statements, but the IDE and hh can continue showing unrelated type errors in the rest of the file, improving notebook feedback. 0e80ee7ded
  • W48 · Nov 29
    The new pure builtin fb_utf8_decompose(string)[]: vec<string> splits a UTF-8 string into individual encoded characters. 0f1b5fd248
  • W48 · Nov 30
    The VS debugger REPL now warns when a source file loaded into the session changes on disk and recommends reloading. The default can be disabled with hphp_debugger_set_option('warnOnFileChange', false). bc18048e1f

Breaking Changes

4 changes
  • W45 · Nov 6
    HHVM no longer populates $_SERVER['REQUEST_START_TIME'], REQUEST_TIME, or REQUEST_TIME_FLOAT. Use nanosecond-resolution $_SERVER['REQUEST_TIME_NS'] instead. d23fe23887
  • W47 · Nov 20
    The unused, flag-gated @Attribute syntax and its allow_new_attribute_syntax configuration have been removed. This does not remove the ordinary @ error-suppression operator or Hack's <<Attribute>> syntax. 00f81dfbb8
  • W48 · Nov 27
    HH\FIXME\UNSAFE_CAST<Tin, Tout>() now requires both type arguments to support dynamic and returns ~Tout; UNSAFE_NONNULL_CAST<T>() similarly returns ~T. This soundness fix applies even without everything_sdt and may expose code that treated unsafe-cast results as trustworthy precise types. 7040cd5beb
  • W48 · Nov 30
    hh_single_type_check now enables like-type hints by default. Scripts that intentionally test the disabled mode must pass --config like_type_hints=false. 50988da888
