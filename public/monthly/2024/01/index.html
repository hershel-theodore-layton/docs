Highlights

24 changes
  • W01 · Jan 2
    XHP required-attribute checking now combines requirements from every side of an intersection type, avoiding false “missing required attribute” errors. 47b213ac59
  • W01 · Jan 2
    The language server now invalidates cached typed ASTs and errors in additional file-change scenarios, preventing stale diagnostics after open files or their dependencies change. 1e8217ee0a
  • W01 · Jan 3
    The new HH\autoload_type_or_type_alias_to_path(string)[defaults]: ?string performs one autoload-map lookup for a name that may denote either a class-like type or a type alias. a35c775051
  • W01 · Jan 3
    Hack's bundled declarations now expose the existing pure Facts API HH\Facts\module_to_path(string)[]: ?string. 17446e19ae
  • W01 · Jan 5
    Separate Hack notebook kernels can now define declarations with the same source names without colliding, and top-level notebook statements now respect the repository's auto-namespace map. 3475febb1c 33f41836a4
  • W01 · Jan 5
    The new pure HH\FileDecls::parseTypeExpression(string)[] API parses a standalone type expression into a recursive declaration structure without the cost of runtime type_structure(). 96ee1ec4c5
  • W02 · Jan 8
    Type printers now render empty unions as nothing and empty intersections as mixed, replacing confusing output such as |(). ac9984d4bf
  • W02 · Jan 8
    An overriding method without its own <<__AutocompleteSortText>> now inherits the sort key from its parent declaration. 3e5fa6a58a
  • W02 · Jan 10
    hh --single file.php --show-tast now provides a dedicated way to print one file's typed AST. b4fa8c14db
  • W02 · Jan 10
    Sound Dynamic call inference now tries a dynamic check first when an argument is already like-typed but its generic parameter is not. This removes false errors for calls that mix lambda arguments with pessimised values. f544f07cb4
  • W02 · Jan 10
    Cross-package calls no longer require the package unstable-feature opt-in. Bundled declarations now also expose HH\module_exists(string, bool)[]: bool and HH\package_exists(string)[defaults]: bool. 6c9d99cc02
  • W02 · Jan 12
    XHP attribute checking no longer leaks refinements from its constructor-style pass into the second attribute-specification pass, eliminating spurious type holes and inaccurate TAST types. 524bddd78f
  • W03 · Jan 15
    Quick fixes now appear whenever the cursor is inside an error span; the editor no longer requires the entire error span to fit inside a selection. 42c3a995ee
  • W03 · Jan 15
    Sound Dynamic like-type pushing now handles nullable generic bounds split into separate null and nonnull lower bounds, removing false subtype failures such as vec<~int> <: ~?vec<int>. 36221d5814
  • W03 · Jan 16
    Sound Dynamic refinement now treats shapes as enforceable when every field type is enforceable, producing more precise results after is checks on like-typed values. 12878d63e8
  • W03 · Jan 17
    Debugger step-over now handles multiple calls on the same source line without incorrectly pausing inside the second callee. 72fbdf973c
  • W03 · Jan 19
    Lambda compatibility now compares the full accepted argument range when default parameters are present. A lambda is accepted when it can handle every arity promised by the expected function type, rather than requiring identical minimum arities. 98a4a79060
  • W04 · Jan 22
    HH\package_exists() now returns true for soft-deployed packages, matching their status as loaded packages whose boundary violations warn rather than throw. a7f1122c6e
  • W04 · Jan 22
    Virtual lambdas synthesized for expression trees are now pure, so expression trees containing virtualized effects can be constructed inside [] functions. Property writes are checked inside an uncalled lambda with the required capability and no longer refine the runtime property. 9abcdf6c65
  • W04 · Jan 24
    The date_format() declaration now accepts DateTimeInterface, matching the runtime and allowing immutable or alternative implementations without a type error. c14b15ffd2
  • W04 · Jan 25
    When a package defines allow_directories, the typechecker now rejects module foo; declarations in files outside those directories. 14b0127365
  • W05 · Jan 30
    hh --lint-all now honors typecheck_sample_rate, making repository-wide lint experiments sample the same files as typechecking. 8dac2e5bcc
  • W05 · Jan 30
    Shape-key diagnostics now explain that a shape cannot mix literal keys with class-constant keys. a7034a9daa
  • W05 · Jan 31
    The <<__NonDisjoint>> linter now checks generic arguments on instance and static method calls, including enclosing class generics connected through where constraints. eba49df195

Security

3 changes
  • W01 · Jan 5
    The fb303 server can now check and enforce access-control lists using Fb303Server.EnableAclChecks, Fb303Server.EnforceAclChecks, and Fb303Server.Identity. The feature is disabled by default. de71bf51b0
  • W02 · Jan 13
    HHBBC no longer treats class-pointer resolution as effect-free or removes class-method calls when doing so could suppress a module or deployment boundary violation. aae991594c
  • W04 · Jan 23
    A function or method carrying <<__CrossPackage("pkg")>> now begins with an invariant that the named package is actually loaded. Misconfigured cross-package access fails immediately instead of continuing into boundary violations. b6593e555d

Breaking Changes

8 changes
  • W01 · Jan 5
    Built-in declarations that accidentally used the nonexistent object type now use concrete DOM types or HH\object. In particular, XSLTProcessor::importStylesheet() now accepts DOMDocument, not SimpleXMLElement. 3c1e77a511
  • W01 · Jan 5
    The legacy fb_set_post_autoload_handler() API has been removed. 8f0646db1f
  • W02 · Jan 8
    Hack's AST no longer has separate Darray and Varray nodes: legacy darray[...] and varray[...] syntax is lowered to dict and vec nodes. Typed-AST and parser tooling that distinguishes the legacy nodes must migrate. 489f6fe405
  • W02 · Jan 10
    The old <<__AllowMultipleInstantiations>> spelling has been removed; experimental code must use the explicitly unsafe <<__UNSAFE_AllowMultipleInstantiations>> name. 53a31ae7b7
  • W02 · Jan 12
    Magic method names are now recognized with their exact Hack casing. A differently cased name is treated as an ordinary method and no longer receives magic-method-specific validation. 64f425c7df
  • W03 · Jan 16
    HH\classname is now always handled as the dedicated classname runtime annotation, independent of Eval.ClassPassesClassname; string conversion must go through an explicit string position. The pure HH\class_to_classname() builtin is also tightened from mixed -> mixed to classname<mixed> -> classname<mixed>. f0ec4483d1
  • W04 · Jan 22
    Runtime upper bounds on generic types are now always fully enforced, and the non-default modes of Eval.EnforceGenericsUB have been removed. Code that relied on warning-only or disabled upper-bound checks can now receive catchable fatals. 772702fa69
  • W04 · Jan 23
    Standard runtime parameter type checking for C++ builtins is now enabled in soft mode by default through Eval.CheckBuiltinParamTypeHints=1. Invalid arguments can emit new type-hint warnings; deployments may use 0 to disable checks or 2 for hard enforcement. cdc7f67f91

Future Changes

4 changes
  • W02 · Jan 8
    Experimental module-level traits can now define internal methods and properties while preserving the trait's original module for boundary checks. a1db805b0a
  • W02 · Jan 9
    Experimental case-type overlap checking now models EnumClass\Label as its own runtime datatype, avoiding incorrect overlap conclusions for label variants. 2a3d2853a0
  • W03 · Jan 19
    Package configuration parsing now accepts an allow_directories field, canonicalizes its relative paths and optional * suffixes, and rejects paths that do not exist. Typechecker enforcement follows later in the month. 1e848e45b1
  • W05 · Jan 31
    Pre-stable function type hints now support optional parameters, for example (function(int, optional string): void). Optional parameters must trail required ones and cannot be inout or variadic. 62e76b9785
