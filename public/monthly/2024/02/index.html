February 2024

35 noteworthy changes, organized by the source changelog sections.

Breaking Changes

4 changes
  • W05 · Feb 1
    array_fill_keys() now always raises a fatal error when a key is not an int or string; the warning and coercion modes are gone. Remove the obsolete Hack.Lang.StrictArrayFillKeys setting from deployment configuration. 57a4503b01
  • W06 · Feb 6
    Runtime parameter type hints on builtins are now enforced by default rather than treated as soft. Calls that relied on passing values of the wrong type to native functions may now fail instead of merely warning. 11164a1fce
  • W07 · Feb 13
    The IMAP extension has been removed, including functions such as imap_open(), imap_fetchbody(), and imap_close(). Applications still using these APIs need an external mail client or service. ee0bc2cb00
  • W09 · Feb 29
    apc_clear_cache() is no longer available to clear process-wide APC data from server requests: it now returns false without clearing the cache in server execution mode. CLI use remains available. ca246caaa0

Future Changes

12 changes
  • W05 · Feb 2
    Hovering over an experimental expression-tree class now shows its expression-tree type instead of an internal name such as TInfer#1. fcfb98165b
  • W06 · Feb 5
    As part of the ongoing module-level-traits rollout, <<__ModuleLevelTrait>> no longer requires the per-file module_level_traits opt-in. The feature is still staged rather than generally released. A module-level trait may also compose an ordinary public, non-internal trait. 0257ed18da 3cff9cd066
  • W06 · Feb 6
    HHVM gains the runtime type-structure representation needed for recursive experimental case types such as case type Node = int | shape('next' => Node). The typechecker does not support declaring them yet. 504c07dd96
  • W06 · Feb 7
    Sound Dynamic now preserves the like-type information inside supportdyn<~T> when stripping dynamic, fixing rejected operations such as arithmetic on ~int. 29bac2a65e
  • W06 · Feb 8
    HHBBC now preserves module provenance when a staged module-level trait composes an internal trait, so copied methods retain the correct runtime boundary checks after trait flattening. 73357ffc8d
  • W06 · Feb 8
    Dynamic-aware subtyping no longer takes an incomplete default path before decomposing a right-hand intersection in constraints of the form T <: supportdyn<t>. 4ebf2bc6f1
  • W06 · Feb 9
    Implicit pessimisation can now push a like type through enum returns whose runtime representation appears as an intersection, avoiding false errors for results such as vec<~E & int>. b8a79a6331
  • W07 · Feb 13
    Sound Dynamic and implicit pessimisation now trust runtime enforcement declared by HHI signatures in the same way as ordinary Hack signatures, removing a legacy exception that affected property assignment. 0507e9f8ad
  • W08 · Feb 21
    In the ongoing module-level-traits rollout, public module-level traits may no longer declare internal methods. This reverses the short-lived staged allowance while support is redesigned; use an internal trait or make the method non-internal. c641788a1a
  • W09 · Feb 27
    The experimental package-existence expression now parses the reserved default package name, allowing checks such as if (package default). 3042a0baa3
  • W09 · Feb 29
    Attempting to nest an experimental expression tree inside a splice now produces a single targeted diagnostic that recommends assigning the inner tree to a local and splicing that variable. 9e9e317ab6
  • W09 · Feb 29
    Like-pushing through an invariant generic argument no longer special-cases a type-variable argument, removing one source of unsound or incomplete inference under implicit pessimisation. c3eacf2b2d

Security

1 change
  • W06 · Feb 6
    idn_to_ascii() now passes ICU the correct output-buffer capacity. Oversized malformed domains return false instead of overwriting the buffer terminator and crashing HHVM. e5a0315b88

Highlights

18 changes
  • W06 · Feb 7
    A new type_alias_exists(string $name, bool $autoload = true)[]: bool builtin checks for a type alias without forcing callers to probe it through an exception. a0e84e265c
  • W06 · Feb 8
    Tier overrides now accept a tagset matcher containing multiple regular expressions. A machine matches only when its tags satisfy every expression in the set. 7e0dac1623
  • W06 · Feb 8
    The HTTP compression layer now reads the documented zstd.target_block_size option; the previous typo caused configured values to be ignored. 81d33dc841
  • W06 · Feb 9
    Debugger breakpoints set in a unit that was loaded after request startup are now installed reliably, even after execution has already paused in another unit. 7af3e78f4d
  • W07 · Feb 12
    Generic calls now type explicitly annotated lambda parameters before other arguments. This lets calls such as any($values, (C $value) ==> ...) infer C before applying like-pushing to a vec<~C> argument. 11c6d53343
  • W07 · Feb 12
    Repository-authoritative deployments can now execute a configured prelude. A prelude path beginning ${SOURCE_ROOT}/ is resolved relative to the directory containing the applicable .hhvmconfig.hdf, and missing preludes produce an actionable log message. 45c319db7d
  • W07 · Feb 13
    An explicit hh_server --max-procs value is now honored up to the machine's processor count rather than being halved a second time. Without an explicit limit, the server continues to default to half the reported logical processors. dcfcc2cb9d
  • W07 · Feb 14
    The IDE now offers “Extract into variable” as a quick-fix when an await is rejected for being conditionally executed. The underlying refactoring is also available inside braceless lambdas and expands them to a block when necessary. 0dbb8a21c6 8f2e2fa5d4
  • W07 · Feb 15
    Known class references now resolve directly while retaining module-boundary checks for object construction and static access. Literal access such as C::$property no longer produces a spurious string-to-class conversion notice, and lazy-class resolution no longer bypasses the corresponding modularity check. 0bd6a0cf1e 3af9a08b53
  • W08 · Feb 19
    A new HH\objprof_get_data_extended() profiler reports ordinary object memory together with memoization-cache memory. Its per-property mode attributes caches to individual instance and static memoized methods, including multi-entry static caches. bfc168e3ee c54a0248e4 bef9514eb3 6b309566ee
  • W08 · Feb 20
    The IDE now offers both a refactoring and an error quick-fix to prepend await to an Awaitable. When required, the complete action also makes the enclosing function, method, or lambda async and changes its return annotation to Awaitable<...>. 7e9ff18df6 675e7b58a5 4f72da9375 0b17bfd5a5 02ab77e706
  • W08 · Feb 20
    The Treadmill's stuck-request detector now accounts for a request-specific timeout as well as Server.RequestTimeoutSeconds. Requests that deliberately extend their timeout are no longer incorrectly terminated with SIGABRT. 8bf8fcf3bf
  • W08 · Feb 21
    The new “add await” action now preserves operator precedence and avoids unnecessary parentheses around the inserted expression. d23fc11169 17801ada76
  • W08 · Feb 21
    The admin status response now includes machine-readable process uptime in seconds. Before the pagelet server starts, its start and uptime values are reported as -1 rather than a date near the Unix epoch and a nonsensical duration. 0af897ce58
  • W08 · Feb 23
    Expressions with built-in vec and dict types no longer acquire unnecessary expression-dependent wrappers. Their inferred unions and error messages now show ordinary types such as vec<C> instead of <expr#N> as vec<C>. 51b81f12ac
  • W09 · Feb 27
    Method autocomplete now filters suggestions whose where constraints cannot be satisfied at the call site, instead of offering a completion that immediately produces a type error. 39a6567878
  • W09 · Feb 27
    Facts queries now treat method names as case-sensitive, matching Hack method lookup. Attribute queries no longer conflate methods whose names differ only by case. fbc082a65c
  • W09 · Feb 28
    Reflection-class helper failures now include the unresolved class name in InvalidArgumentException, replacing the context-free “Unable to find class” message. d3758273c3
