Breaking Changes

6 changes
  • W23 · Jun 3
    Hack now rejects calls to protected methods through an interface-typed receiver. The concrete implementing class might be outside the caller's class hierarchy, making the apparently valid call fail at runtime. 7b9882a0ae
  • W23 · Jun 4
    The pure HH\darray() and HH\varray() conversion functions are now deprecated. Use dict() and vec() respectively. 4330501899
  • W23 · Jun 7
    Hack's invalid-index check now diagnoses non-int access to vec, including cases hidden behind inferred generic keys. 6a242bdb0d
  • W24 · Jun 11
    get_class() and get_parent_class() now require an explicit argument; the implicit current-class form has been removed. get_class() also enforces an object argument through its builtin type hint and returns a classname rather than mixed. aa31bd583b
  • W25 · Jun 18
    The obsolete HH\class_get_class_name() helper has been removed; use the pure HH\class_to_classname() migration helper instead. The internal __hhvm_intrinsics\create_class_pointer() spelling was likewise replaced by HH\classname_to_class(). 172eb8c361
  • W26 · Jun 25
    A generic used contravariantly inside HH\EnumClass\Label is now an error when covariance leaves it underconstrained. Replace the redundant parameter with its effective bound or redesign the signature so the label actually determines it. 5832019e44

Future Changes

14 changes

  • W24 · Jun 14

  • W25 · Jun 17

  • W25 · Jun 17
    Packages v2 now diagnoses an unknown package named by __PackageOverride, catching misspelled or stale package overrides at typechecking time. 02462c0d87
  • W25 · Jun 18
    Awaiting multiple splices in an expression tree no longer serializes them into sequential assignments; independent splice expressions can now run concurrently. 500e484925
  • W25 · Jun 21
    Class-pointer migration checks now cover class and enum-class constant initializers, warning that C::class assigned to a string constant performs an implicit conversion and recommending nameof C. This is controlled by the const entry in class_pointer_levels. 738d9706a7
  • W25 · Jun 21
    Packages v2 now bypasses package-boundary checks for ::class expressions by default, preserving their transitional string-like use while class-pointer migrations continue. 0fa07a7548
  • W25 · Jun 22
    The Packages v2 test-file exemption now recognizes __tests__ anywhere in a path, so test files receive the intended ability to call across package boundaries instead of only matching when the marker begins the full path. 339e8b72ac
  • W25 · Jun 22
    Package overrides now propagate through class kinding, preventing class references from silently falling back to the package inferred from their source path. 4bb06d9a64
  • W25 · Jun 23
    Packages v2 no longer applies boundary checks to type-only references in type constants and type hints. Cross-package runtime value access remains checked. 4ccc16f888 eee2daea89
  • W26 · Jun 24
    Await expressions in expression-tree splices have moved from Unstable to Preview. Multiple awaited splices retain the concurrent execution introduced earlier this month. a3bf39c601
  • W26 · Jun 24
    Packages v2 now ignores package boundaries while resolving generic type arguments, completing the relaxation for type-only references while retaining checks on value-level symbols. cc000535ac

Highlights

20 changes
  • W23 · Jun 5
    Failed union and intersection subtype checks now retain the errors from every invalid branch. Diagnostics no longer disappear when a disjunction is deferred or collapse to only the last failed alternative. b92226235f 608d6b4b07 b24c0c1751 0c7f97fbe8
  • W23 · Jun 6
    json_encode() accepts the new JSON_FB_SORT_KEYS flag for deterministic object and dictionary output. Integer keys sort numerically before string keys, which sort lexicographically, making the resulting JSON suitable for stable hashing and cache keys. df9fc19be0
  • W23 · Jun 7
    The redundant-generics linter once again recognizes a generic used only contravariantly when multiple as bounds simplify to one effective bound, including bounds introduced by implicit pessimisation. 1ca353c4cb
  • W23 · Jun 7
    Shape refinement no longer causes Shapes::idx() on a different optional field to lose its nullable result type after patterns such as $shape ?? shape() and Shapes::keyExists(). 6254e75cb8
  • W23 · Jun 7
    The new HH\Facts\validate(vec<string> $types_to_ignore = vec[])[defaults]: void API checks the SQLite Facts database for types mapped to multiple paths and throws UnexpectedValueException when it finds an unignored conflict. 153ec68b9d
  • W23 · Jun 7
    Hack declarations now expose the pure async CAS helpers HH\RemoteExecution\gen_upload_file(string, string)[]: Awaitable<string> and gen_download_file(string, string, string)[]: Awaitable<bool>. 0c2cb6acbb
  • W23 · Jun 9
    Runtime-enforceable is checks now accept wildcard arguments through generic type aliases, so checks such as $x is Alias<_> no longer produce a false error merely because the alias has a type parameter. fb09a02486
  • W24 · Jun 10
    Extended type errors now include the primary claim's source snippet and position, including for constructor calls. When combined with JSON output, --error-format extended also supplies a human-readable rendering of the error. 67328c1ec9 e7a9c060ca 59443d6edd
  • W24 · Jun 12
    debug_backtrace()[defaults] now returns HH\StackTrace, a vec of open HH\StackFrame shapes whose fields are explicitly optional. This makes code account for fields such as 'args', 'file', and 'function' being absent. df840cc4bc
  • W24 · Jun 12
    In repo-authoritative mode, equality and conditional branching now agree when comparing lazy class values with class pointers. A true $lazy_class === $class_pointer comparison can no longer be optimized into an unreachable branch. 9884cdfbf2
  • W24 · Jun 13
    Active implicit contexts are now refcounted correctly while entering and resuming calls, async functions, and wait handles, avoiding lifetime errors when context switching replaces the active object. c6f02fdab1
  • W24 · Jun 14
    JIT-compiled is_a() and is_subclass_of() now honor the $allow_string argument and reject trait targets, matching interpreter behavior for class pointers. c3c428aa95
  • W24 · Jun 15
    Subclasses of HH\ImplicitContext can now call the inherited protected exists()[zoned]: bool helper to test whether their keyed context is present without reading its value. 9e3108de07
  • W25 · Jun 19
    Sound Dynamic like-pushing now handles more types containing unsolved variables, avoiding false incompatibility errors for relationships such as Box<~T> <: ~Box<string> while preserving errors for genuinely mismatched inner types. 9968b678ad
  • W25 · Jun 20
    Hack now accepts the empty tuple value tuple(), matching existing HHVM runtime support. The empty tuple type () is still not valid syntax. 9e42bbbc13
  • W25 · Jun 20
    Facts updates now remove file and method attributes that disappeared from source, rather than leaving their old names or argument values in the in-memory attribute maps. 8606084f86
  • W25 · Jun 20
    Hack notebooks now resolve XHP elements correctly in top-level statements, restoring diagnostics, completion, and go-to-definition without duplicate namespace elaboration. fb1dbb43fb
  • W26 · Jun 24
    The value type parameter of HH\EnumClass\Label<-TEnumClass, +TType> is now covariant rather than invariant, allowing a label's value type to widen safely. 49c68bd4be
  • W26 · Jun 25
    Enum-class labels now use constraint-based typing. Anonymous labels such as #Name have their own inferred type and can be used beyond immediate function-argument position, while qualified labels are checked against the enum class's actual constant type. 0bc5384fa2
  • W26 · Jun 25
    JIT deployment-boundary checks now match the interpreter when the caller is itself outside the active deployment, avoiding a spurious violation on calls from that code. e8f6d775da
