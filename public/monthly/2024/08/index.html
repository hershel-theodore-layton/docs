August 2024

47 noteworthy changes, organized by the source changelog sections.

Highlights

23 changes
  • W31 · Aug 2
    The implicit-context primitives for reading, testing, and creating keyed contexts have narrowed their capability requirement from [zoned] to [leak_safe], reducing what callers must provide and allowing memo-agnostic contexts to run in leak-safe code. b31c1e86ac
  • W31 · Aug 2
    Extended type-error explanations now track tuple projections during destructuring and property-access flows explicitly. Their formatter also prints a source position before its snippet, making longer derivations easier to follow. a69db169be 04885b2ab4 6c0058f649
  • W32 · Aug 5
    Hack's symbol indexer now maps constants and enumerators in generated Thrift enums back to their source definitions without crashing during indexing. 780baf4afd
  • W32 · Aug 8
    hh_client can now filter warnings with -Wall, -Wnone, -W CODE, -Wno CODE, and -Wignore-files REGEXP. Unknown warning codes are rejected instead of silently ignored. 5304af98f7
  • W32 · Aug 8
    Generated Thrift constant references can now navigate back to the original constant declaration recorded in the generated docblock. abc8d5d7cb
  • W32 · Aug 8
    Function interception no longer clears the active implicit context, preserving keyed context values across intercepted calls now that the old incompatible-state mechanism is gone. 853f87ce43
  • W32 · Aug 9
    The new .hhconfig option warnings_default_all chooses whether bare hh behaves like hh -Wall or hh -Wnone, including while errors are streamed. Its default is false. d22e238d66
  • W32 · Aug 9
    Constraint-based refinement now handles ~nonnull tested against null correctly by moving dynamic outside only on the false side of a type switch. 90eff9efc1
  • W33 · Aug 13
    Whole-document formatting through the language server now agrees with command-line hackfmt, particularly when edits remove complete lines; range formatting continues to use explicit offsets. 6b196924a2
  • W33 · Aug 13
    Warning filters now apply consistently to LSP results and server-side non-streaming status responses before --max-errors is enforced. The warnings_generated_files config can suppress warnings by path, while -Wgenerated shows them on demand. Ordinary errors in ignored or generated files remain visible. 2081d49c8d 4df6f7ec54 51ae4bc45f eeb5cf3917
  • W33 · Aug 13
    CLI summaries now report error and warning counts separately. Warnings alone preserve the No errors! text and a successful exit status. 1a13d8e083
  • W33 · Aug 14
    HHBBC no longer confuses an async memoized function whose wait handle contains bottom with a completely unreachable memoized result, avoiding the incorrect conclusion that its memo cache is always empty. a4d1b032ce
  • W33 · Aug 15
    Sound Dynamic hover output no longer adds a redundant “dynamic when called dynamically” type when the ordinary displayed type already includes at least as much dynamic behavior, such as ~int. 38ea4ed01f
  • W33 · Aug 16
    Error streaming now removes warnings already present in the warning saved state before worker batches are written, so LSP and other streaming clients do not redisplay preexisting warnings. 0afd026592
  • W34 · Aug 19
    ExtDeclMethodParam now exposes an optional 'is_optional' => bool field, distinguishing the optional keyword on abstract and interface method parameters from a concrete default expression. 4443d834be
  • W34 · Aug 20
    Nested debugger expression evaluation now preserves the outer evaluation's stdout hook, so output produced after an inner breakpoint evaluation still reaches the debugger. 62e800fae9
  • W35 · Aug 27
    Hack's bundled declarations now expose HH\FileDecls::genParsePath(string)[]: Awaitable<HH\FileDecls>, allowing the existing non-blocking, cache-backed declaration parser to typecheck at call sites. 32b2c8952d
  • W35 · Aug 27
    Serverless IDE checks of open files now load the warning saved state and filter preexisting warnings just like full-server and streamed checks. 56a99b43dc
  • W35 · Aug 28
    hackfmt --diff now resolves files correctly when the Mercurial repository root is above the project root. The new --diff-root option can supply an explicit base directory. 72ffd9760d
  • W35 · Aug 28
    Extended type explanations now point back to previously shown definitions, reverse projected subtype direction correctly for contravariant parameters, hide internal supportdyn steps in non-verbose output, and highlight the right-hand side of type definitions. f16ea44b34 9aafe24b2f 303cb33048 fb54ffdd4c
  • W35 · Aug 30
    Tuple type comparison now preserves element order instead of sorting tuples like unions and intersections, so (A, B) is no longer treated as identical to (B, A). 172a6d93c9
  • W35 · Aug 30
    The new pure HH\Facts\transitive_subtypes<T>(classname<T>, ?HH\Facts\DeriveFilters = null)[]: vec<string> query computes the full transitive closure of types that extend, implement, or use a base type in one native call. 8755851768
  • W35 · Aug 30
    The sealed HH\GenericEnumClass<+TClass, +TValue> interface is now exposed to Hack, allowing type constants and generic APIs to constrain a value to any concrete enum class without exposing HH\BuiltinEnumClass directly. 47687c7eae

Breaking Changes

7 changes
  • W31 · Aug 2
    Custom HH\ImplicitContext subclasses must now define CRun with at least the [leak_safe] requirement: the abstract context constant gained an as [leak_safe] bound, so a smaller requirement such as [] no longer satisfies it. [leak_safe], [zoned], and [defaults] definitions remain valid. b31c1e86ac
  • W32 · Aug 7
    The unused hh --format command has been removed. Use hackfmt or editor formatting instead. bf408a3876
  • W32 · Aug 7
    The deprecated call_user_func() pseudofunction is no longer declared or specially lowered by Hack. Invoke a typed callable directly. e37946a1b1
  • W32 · Aug 7
    HH\is_vec_or_varray() and HH\is_dict_or_darray() have been removed from Hack's declarations and refinement logic. Use is vec<_> and is dict<_, _> checks. 20333fb1c7
  • W33 · Aug 12
    The pure HH\varray() and HH\darray() conversion functions have been removed from Hack's declarations after their June deprecation. Use vec() and dict(); calls to the legacy spellings no longer typecheck. 119f607e4b
  • W34 · Aug 23
    self::class, static::class, and parent::class are no longer valid shape field names. Use an explicit string or nameof-based key instead. 3e77c7b213
  • W35 · Aug 26
    The pure HH\Facts\*_to_path_relative() query family has been removed, including module, type, function, constant, and type-alias variants. Use the corresponding *_to_path() APIs, which return repository paths. 22e1bf9744

Future Changes

15 changes
  • W31 · Aug 3
    The variable-name linter no longer reports compiler-generated $0v... names when a pre-stable expression-tree splice contains await. 1b995a4167
  • W32 · Aug 5
    Awaited expression-tree splices are now rejected in conditionally executed positions, matching the ordinary restriction on conditional await expressions. f1a6a2f373
  • W32 · Aug 6
    The redundant-generics check no longer reports valid generics used in pre-stable as or super type-constant refinements because of an incomplete variance calculation. b960631c28
  • W32 · Aug 6
    Conditional-splice detection now looks through client-language expression-tree lambdas instead of treating them like ordinary Hack lambdas, closing a path that still admitted conditionally executed awaits. 803f1ee2f9
  • W32 · Aug 6
    Preview case types now preserve the current enum context separately for each queued alias while HHBBC flattens nested unions, preventing unrelated class arms from being mistaken for enum members. 63b1647cae
  • W32 · Aug 8
    Mutually recursive case types no longer recurse indefinitely through localization, union simplification, and subtyping. Cycle diagnostics are also emitted by callers rather than by repeated localization passes. f597abcaae fdc1cd065c
  • W33 · Aug 16
    Packages v2 now enforces package boundaries for internal top-level symbols as well as public ones, while still treating type-only is and as references as exempt. Cross-package internal access can now report both its module and package violations. 8c0e2322b7 c0f984d874 963be43186
  • W34 · Aug 19
    Features configured as OngoingRelease are now enabled by the typechecker without a file-level unstable-feature attribute, matching their existing runtime behavior. Per-feature .hhconfig status may be stricter than HHVM's status. c23cdade86 d00bf7b468
  • W34 · Aug 20
    When .hhconfig provides an experimental_features list, a file-level __EnableUnstableFeatures attribute can now enable only features named in that list; omitted features are rejected. Projects without the list continue to treat all known experimental features as OngoingRelease. 35add40d1c
  • W34 · Aug 20
    await_in_splice is now OngoingRelease in HHVM and no longer requires a runtime file-level opt-in. The typechecker continues to use the status configured in .hhconfig. 84f088b7a9
  • W34 · Aug 20
    Expression-tree lambdas can now declare optional parameters; DSL visitors receive their names and default expressions through visitOptionalParameter(). 56f84a9ef8
  • W35 · Aug 28
    hh_server now correctly uses the experimental-feature status map from .hhconfig instead of falling back to legacy hard-coded statuses, so the configured Preview, OngoingRelease, and Unstable staging rules are actually enforced in full-server checks. ed7cd08369
  • W35 · Aug 29
    Package configuration parse errors are now propagated to repository builds as build-blocking failures instead of appearing only in the typechecker. 4acf613e39
  • W35 · Aug 29
    With an active deployment, repo builds using ForceEnableSymbolRefs now include both deployment files and referenced symbols outside it. Without the option, the build remains limited to the deployment. c2b16737b1
  • W35 · Aug 30
    Expression trees now support named instance-method access and calls through the DSL's visitInstanceMethod() hook. Nullsafe and dynamically named instance methods remain unsupported. a84239a02b

Security

2 changes
  • W34 · Aug 21
    meth_caller(C::class, 'method') no longer treats a this return type as exact C. The callable may receive a subclass instance, so its result is now conservatively typed as C, closing an unsound narrowing path. 0f0125fa20
  • W35 · Aug 28
    Binary and compact Thrift deserialization no longer preallocates containers from untrusted oversized length fields. Initial reservation is capped at 16K entries, and sizes above the supported array limit raise a warning instead of attempting a multi-gigabyte allocation. 72771f6bf6
