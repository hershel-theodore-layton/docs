Highlights

28 changes
  • W36 · Sep 3
    HH\Facts\transitive_subtypes() now accepts an optional include_interface_require_extends boolean. Passing true includes interfaces reached through require extends; the default remains false. The function retains its explicit empty capability list [], so it remains callable from pure contexts. 0f9f4fd043
  • W36 · Sep 3
    Direct declaration parsing now preserves nameof C in user-attribute arguments as a class name, and can constant-fold it inside string concatenations. Attribute metadata no longer loses these arguments when declarations are read without full typechecking. 734b261924
  • W36 · Sep 3
    warnings_generated_files is now a project setting in .hhconfig, so the same path regexes suppress generated-file warnings for the server, command-line client, and LSP. -Wgenerated still requests those warnings explicitly. 8b9b903486
  • W36 · Sep 5
    The sketchy-null-check warning now explains that a truthiness test also rejects false, numeric zero, empty strings, and empty containers, and suggests $value is nonnull when only null should be excluded. 1dbfb00a69
  • W36 · Sep 6
    Hovering a constructor call on a generic class now shows the constructor signature after substituting the class's inferred type arguments. 005e99e225
  • W36 · Sep 6
    The built-in xbox_tasks_started(): int is now declared to Hack, so it can be called without a missing-function error. Its omitted capability list is [defaults]. 5a731fcb6b
  • W36 · Sep 6
    Xbox.ServerInfo.MaxJobQueuingMs can bound how long an XBOX job waits in the worker queue, preventing recursive XBOX calls from leaving a queue deadlocked until request timeouts. The default -1 preserves unlimited waiting. b9d0495662
  • W37 · Sep 9
    Hover information for enum and enum-class members now includes the member's docblock. 169e8af954
  • W37 · Sep 9
    Autocomplete can now fill enum-class-label arguments with a label literal such as #Member, instead of proposing a temporary variable with the label's underlying singleton type. e0757bb553
  • W37 · Sep 10
    HHVM now ships raw LMDB bindings in the HH\lmdb namespace, covering environments, transactions, databases, cursors, statistics, copy operations, and key comparison. ba8cf61e1a
  • W37 · Sep 11
    Signature help now substitutes inferred generic arguments before displaying parameter and return types, matching the instantiated signature used for hover information. 9f1cd4a298
  • W37 · Sep 12
    .hhconfig can now disable selected warnings with a comma-separated disabled_warnings list while leaving hack_warnings=true. Setting hack_warnings=false still disables every warning. 26a2168843
  • W37 · Sep 12
    Serverless IDE diagnostics now apply the same warning filters as the full server. ca15b26419
  • W37 · Sep 13
    Hover information no longer displays generic parameters that were fully substituted while instantiating a function or method. Explicit enum-class-label arguments are shown as their singleton type, such as #Mul, rather than the broader label type. b3efd805cc fd4f638dee
  • W38 · Sep 16
    Lambdas may reuse the discard parameter name with different annotations, as in (int $_, string $_) ==> {}; Hack no longer compares the discarded parameters with one another and reports a spurious coercion error. 0b59874dd4
  • W38 · Sep 16
    Direct references to constants and type constants declared by a trait now initialize against the trait's own class object, fixing failures for expressions such as TMyTrait::MY_CONSTANT. 4752658e59
  • W38 · Sep 16
    Method hovers selected through an enum-class label now show the label's singleton type. Dead-suppression cleanup also removes unused HH_IGNORE comments alongside unused HH_FIXME comments. 9fc76eee71 9ba137b426
  • W38 · Sep 17
    hh_single_type_check --config hack_warnings=false can now disable warnings for one-off checks; true enables the full warning set. d7fb8b6b4c
  • W38 · Sep 18
    Hack LSP accepts --disable-format-on-save, which stops advertising textDocument/willSaveWaitUntil while leaving explicit document and range formatting available. 77c22fb8c6
  • W38 · Sep 18
    The HH\lmdb API now exposes typed enums for LMDB environment, database, put, copy, and cursor-operation flags. 73bc12842a
  • W38 · Sep 20
    A literal nameof C used as an array key is now folded directly into the member key, matching literal-string access and avoiding the generic expression path. b6fc70430d
  • W39 · Sep 25
    Lambda parameter and return annotations may now contain inferred wildcards, including nested forms such as vec<_> and Awaitable<vec<_>>. Each wildcard is solved from the lambda body and call context; reified arguments remain ineligible. eaf589aa7e
  • W39 · Sep 26
    extended_reasons=legacy is now available in .hhconfig and command-line configuration. It retains extended provenance while typing but emits the traditional diagnostic presentation, making it useful for measuring rollout differences without changing error text. bf67242a78
  • W39 · Sep 27
    Qualified nameof expressions such as nameof N\C are now accepted as constant expressions by the typechecker, including in enum initializers. 7761a6b906
  • W39 · Sep 27
    When initializing from a clean public revision, Hack records its warning hashes and discards those baseline warnings, reducing unrelated warning noise after moving from the saved-state revision to a merge base. 9d511a4f90
  • W40 · Sep 30
    --ignore-hh-version can now initialize from a saved state even when .hhconfig has changed, by requesting a state without constraining its project metadata. 788b1c1349
  • W40 · Sep 30
    User-profiler callbacks now retain the current implicit-context value instead of running with that value cleared. a4a17fac22
  • W40 · Sep 30
    Subtyping can now solve an unsolved type variable against a like type instead of prematurely rejecting that branch, fixing valid generic inference under sound dynamic. cf76be167a

Breaking Changes

7 changes
  • W36 · Sep 4
    Hack warnings are enabled by default, including in development installations that do not supply a local rollout configuration. Projects that are not ready to consume warnings can set hack_warnings=false; otherwise expect warning diagnostics to begin appearing. 38e95029f9
  • W37 · Sep 10
    The legacy flat server thread-tuning options have been removed. Rename ThreadTuneDebug, ThreadTuneSkipWarmup, ThreadTuneAdjustmentPct, ThreadTuneAdjustmentDownPct, ThreadTuneStepPct, ThreadTuneCPUThreshold, and ThreadTuneThreadUtilizationThreshold to their corresponding Server.ThreadTune.* settings. bf90ee2b60
  • W37 · Sep 12
    Warning suppressions must use HH_IGNORE[code]. HH_FIXME no longer suppresses warning codes and instead emits guidance to use HH_IGNORE; conversely, HH_IGNORE cannot suppress an error code. 6f7bc81e65
  • W37 · Sep 13
    Cyclic type-alias bounds no longer leave a freely solvable type variable behind. Hack conservatively localizes these cycles to mixed (or supportdyn<mixed> under implicit pessimization), which can reveal invalid calls that previously typechecked unsoundly. 1099f097bf
  • W37 · Sep 13
    The unused zoned_with<T> context and HH\Coeffects\enter_zoned_with() / enter_zoned_with_async() entry points have been removed. Code that still declares or enters a zoned_with context must migrate to the remaining implicit-context and coeffect APIs. 42b37a58ae
  • W38 · Sep 17
    HH\ImplicitContext\is_inaccessible()[zoned] has been removed. d87f330ce2
  • W38 · Sep 22
    Deprecated implicit-context states and memoization options have been removed. The NULL, SOFT_SET, and SOFT_INACCESSIBLE state members and the SoftMakeICInaccessible and Uncategorized memoization options are no longer available; use the remaining VALUE / INACCESSIBLE states and KeyedByIC / MakeICInaccessible options. 23faf7f107 efdf82e1d3

Future Changes

12 changes
  • W37 · Sep 10
    Pre-stable case-type overlap checking now models tuple and shape variants structurally, avoiding both missed overlaps and overly broad rejections. 487190d7ad
  • W38 · Sep 16
    Staged package-v2 checking now permits a function pointer to a static method in another package, matching the symbol-reference traversal used for deployment boundaries. 38d78565b8
  • W38 · Sep 16
    Work on recursive_case_types now models newtype bounds, enum bounds, and function-type variants when checking recursive case definitions. 99e7aa8229 c8b31f79f2 d34c456b07
  • W38 · Sep 18
    The configurable class-pointer migration check now covers C::class values used as enum members through the enum key in class_pointer_levels, recommending nameof C before implicit class-to-string conversion is removed. dc08ae9cb2
  • W38 · Sep 19
    The unstable open_tuples feature now parses, represents, and subtype-checks tuples with optional elements and variadic tails, such as (int, optional string, arraykey...). Null-coalescing access also understands optional and variadic positions. 084c06ee9f 4cf74b6739 f67f3046ad 7d7f1af223 812d981b81
  • W38 · Sep 19
    The class-pointer migration check's arraykey level now diagnoses C::class when used as a dict, keyset, or collection key, or in indexed access, and recommends nameof C. f34b115e5c
  • W38 · Sep 20
    Recursive case-type checking no longer loops while intersecting recursive variants. With recursive_case_types enabled, case definitions are also exempt from the legacy blanket cyclic-type-alias rejection so valid recursive lists and trees can be checked structurally. 6228f4218f 781cdb1af5
  • W39 · Sep 23
    Shape metadata and bytecode can now distinguish a C::class field key from an ordinary string key, preserving its classname origin for the class-pointer migration instead of flattening both forms immediately. 0e7d274be9 150718487f
  • W39 · Sep 24
    Under the staged package-v2 checker, the type named on the right-hand side of an as expression is now checked for package-boundary violations. Cross-package casts that relied on this type reference being ignored must expose the target through the package relationship or avoid the cast before enabling package v2. ae4edca754
  • W39 · Sep 26
    The unstable type_splat feature introduces arity-polymorphic parameters such as ...TArgs, paired with an open-tuple bound like TArgs as (mixed...). It is enabled together with open_tuples via <<file: __EnableUnstableFeatures('open_tuples', 'type_splat')>>; HackC lowers the resulting tuple parameter through the variadic calling convention. ee442186bc 547e6436a1
  • W40 · Sep 30
    Staged package-v2 checks now deliberately ignore types referenced only on the right-hand side of is expressions or as generic type arguments, matching the deployment symbol-reference traversal. 10efc91d0b 52e2d3811b
  • W40 · Sep 30
    Experimental type splats are now typechecked and participate in subtyping, including fixed, optional, and variadic open-tuple components. This makes arity-polymorphic wrappers such as function call<TArgs as (mixed...)>((function(...TArgs): void) $f, ...TArgs $args) type-safe. 58d6aa941e 6b5ac89089

Security

1 change
  • W39 · Sep 25
    HHVM's EnforceDeployment runtime option now defaults to false, so deployment boundaries are not enforced at runtime unless operators explicitly turn the option back on. Applications that treated the previous default as a safety boundary should review their deployment configuration. d1c1861613
