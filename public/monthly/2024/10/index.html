49 noteworthy changes, organized by the source changelog sections.

Highlights

25 changes
  • W40 · Oct 1
    The Hack manual now documents optional parameters on interface and abstract methods: the declaration omits a default, while each concrete implementation supplies the default its callers will use. 88468f2192
  • W40 · Oct 2
    Hack's subprocess timeout handling now closes its streams after both timeouts and exceptions; the select-based implementation also terminates the child, reducing leaked processes and file descriptors in long-running tooling. 62da22e7c8
  • W40 · Oct 2
    hh_single_type_check --get-some-file-deps --root ... can now derive its naming table from the repository root; --naming-table is no longer mandatory for this mode. bdf41c6516
  • W40 · Oct 4
    Warning filtering now tolerates failures from its Mercurial queries instead of allowing an external VCS error to abort the typecheck. 9b5597b79f
  • W40 · Oct 4
    At positive typing-log levels, hh_show() output now includes numbered type variables such as #1, which makes unresolved relationships easier to follow. ca6767e0a1
  • W41 · Oct 7
    Typechecker diagnostics now have stable ordering by phase, then source position and error code. This keeps naming errors ahead of typing errors without making output depend on worker completion order. 42102418a6
  • W41 · Oct 7
    Extended type-error reasons recover useful claims for sound-dynamic constraints, arithmetic-result flows, and generic types, reducing vague or misplaced primary messages. 7c185b5191 8658ff652b 41ce724047
  • W41 · Oct 7
    Emitted calls of the form $c::foo() now retain the call's source position rather than the class-expression position, improving AST and source-mapping consumers. 2184a6754b
  • W41 · Oct 8
    hh --notebook-to-hack can now read Jupyter notebook JSON from standard input and emit a valid Hack file, preserving cell metadata and wrapping notebook top-level statements in a generated function. 4fffc4133b
  • W41 · Oct 10
    Command-line diagnostics now print warnings before errors, leaving the errors at the bottom of the output where they are easier to find. a84a03948e
  • W41 · Oct 10
    nameof C and C::class are now handled consistently as class-name shape keys, including namespace and self resolution. 99e117526a
  • W42 · Oct 15
    Errors caused by illegal recursive aliases now explain why the alias was replaced with mixed, instead of presenting that mixed as an unexplained source type. bc618c335b
  • W42 · Oct 15
    Hovering over the generic this type now also shows its upper bounds. bdb90e88e2
  • W42 · Oct 16
    Repo builds now follow enum and enum-class inclusion when collecting symbol references, so included parent enums are no longer omitted from the built repository. b0817d9e42
  • W42 · Oct 17
    The JIT's optimized multi-string concatenation now decrements every consumed operand with distinct profiling identifiers, fixing refcount corruption in long concatenations and formatting operations. 3b51bc1872
  • W42 · Oct 18
    Type inference now assigns the correct source span to TypeAlias::class and nameof TypeAlias expressions instead of extending the alias token's position over the whole expression. c31617ee8c
  • W43 · Oct 21
    Extended type-error derivations are now generated during the original check and stored with each error, avoiding a checker restart when detailed reasons are requested. Their rendering also gained clearer step styling and adapts to the current terminal width. 7ba1c0f0d8 5fa7ba8973 cb64df5b12 0119ca86a4
  • W43 · Oct 21
    Notebook top-level statements are now treated as having the [defaults] capability set, which includes write_props, eliminating spurious coeffect errors for operations that require those capabilities. a1d70342fb
  • W43 · Oct 21
    nameof C now has the precise type classname<exact C>, matching C::class. 2009f75002
  • W43 · Oct 24
    Hack now runs both full-fidelity and lowerer syntax checks even when the first pass already found errors, so a single invocation can report more independent syntax problems. 0e55fbf060
  • W43 · Oct 24
    Notebook conversion is now bidirectional: hh --hack-to-notebook reconstructs notebook JSON from generated Hack on standard input, and both conversion directions apply Hack formatting. 1e45a855cb 30842a482b
  • W43 · Oct 24
    The single-class filename linter now says that a file "defines" a class rather than incorrectly claiming the class is its only content when typedefs are also present. 653d1be162
  • W43 · Oct 25
    Notebook conversion now validates both source formats, reports malformed user-edited Hack separately from internal failures, and lets --notebook-to-hack place a supplied header such as a copyright notice after <?hh. 932cbaaf19 019a84b981 a4ac153138
  • W44 · Oct 30
    HHVM now populates $_SERVER['REQUEST_TIME_MONOTONIC_NS'] from the monotonic clock alongside the existing realtime request timestamps, enabling elapsed-time measurements that are not affected by wall-clock adjustments. 5226b11299
  • W44 · Oct 31
    Hack now loads package configuration before server startup and stores it in the original global options, ensuring remote typechecking receives the same package membership information as the local server. b0197966f0

Future Changes

20 changes
  • W40 · Oct 1
    Open tuples and type splats moved to Preview status in HHVM's feature configuration, making them available for broader experimentation. a0e6574d02
  • W40 · Oct 4
    Packages v2 include_paths now use repository-rooted paths beginning with //; directory entries end in /, exact-file entries do not, and ./ or ../ segments are rejected. 9bcaba8f44
  • W40 · Oct 4
    The experimental type-splat syntax can now appear at the end of tuple hints, for example (float, ...T). A tuple may have only one variadic or splat tail, and a splat cannot follow an optional element. 03ed3cc3d6
  • W41 · Oct 7
    Runtime type information now preserves the nullable part of an explicit like-nullable hint, so a value accepted as ~?T can actually be null at runtime. 5743f65f39
  • W41 · Oct 9
    Explicit like-type hints such as ~int are now an Unstable syntax feature. Projects using them must enable like_type_hints through enable_experimental_stx_features or <<file:__EnableUnstableFeatures('like_type_hints')>>; the old like_type_hints option is gone. 0edcd8e498
  • W41 · Oct 10
    Hovering inside a splice of an Unstable expression tree now reports the original, non-virtualized expression's type. 2bb7ede81c
  • W41 · Oct 10
    Package configuration is now version-checked: Package v1 rejects include_paths, while Package v2 rejects uses. HHVM also gained the Eval.PackageV2 compiler option for the v2 format. fafd709eab
  • W41 · Oct 11
    A trait with the pre-stable require class C constraint may now call private static methods of the required class, matching its existing access to private instance methods. c92a23661b
  • W42 · Oct 14
    Experimental case-type variants with where clauses now participate correctly in subtyping and call-site inference: a value must satisfy both the variant hint and that variant's constraints. 39a1d238ee
  • W42 · Oct 15
    Packages v2 introduces the unstable <<__RequirePackage('pkg')>> function and method attribute. The checker validates its single literal package argument, uses it to typecheck conditionally available calls, and reports an actionable error when the required package has not been established as loaded. 3577dadb29 e3397da7da 9aeaa0b4c7 a19ae73c44
  • W42 · Oct 15
    Package-version checks reserve __CrossPackage for v1 and __RequirePackage for v2. 595cc60314
  • W43 · Oct 22
    Packages v2 now permits cross-package type names on the right-hand side of as, matching the existing is exemption. This is only a static-reference exemption: execution can still fail if the target package is not deployed. 9488fb8dd0
  • W43 · Oct 23
    Packages v2 no longer applies package-boundary checks to class-constant and global-constant type hints, which are not emitted into runtime constant metadata. 878738dc7d
  • W43 · Oct 23
    Experimental case types with variant where clauses now retain their nominal case type through intersections and type-switch refinements instead of being unsafely reduced to the raw variant hints. a2ad3ec620
  • W43 · Oct 24
    Await expressions on the right side of a pipe, and nested awaits, moved from Preview to Ongoing Release and no longer require the pipe_await feature opt-in. d26ca17cef
  • W43 · Oct 25
    --type-at-pos-batch now handles a batch containing both expression-tree splice positions and ordinary positions without applying splice virtualization to the whole batch. c546c0f2d0
  • W44 · Oct 28
    The new Unstable shape_destructure feature introduces shape expressions as assignment targets, including shapes nested inside list destructuring. This first step adds feature gating and parser recognition; compiler support follows later in the week. 13cd4d3d36
  • W44 · Oct 29
    Nested expression trees moved from Preview to Ongoing Release, so ordinary nesting no longer needs the expression_tree_nest opt-in. The separate nested-binding feature remains Unstable. 377dbfd786
  • W44 · Oct 29
    Packages v2 exempts both callers in __tests__ paths and symbols defined there from package-boundary checks. 3b5d5ffb29
  • W44 · Oct 30
    HHVM can now execute the Unstable shape-destructuring syntax, including nested list/shape targets, local and indexed destinations, and string, nameof, or class-constant shape keys. 54a4bac107

Breaking Changes

4 changes
  • W40 · Oct 3
    Runtime enforcement of builtin parameter type hints can no longer be disabled with Eval.CheckBuiltinParamTypeHints; builtins now consistently use the strict enforcement behavior that was previously level 2. c2c0564ce9
  • W42 · Oct 15
    A package expression inside invariant(...) no longer establishes package availability for following code. Use an if (package pkg) block instead. 7f948abbc0
  • W42 · Oct 18
    enum_exists() now takes classname<mixed> rather than string. Literal class names, lazy class values, and class pointers work at runtime, but callers passing an arbitrary string variable must first establish that it is a classname. ac3a1175d5
  • W43 · Oct 23
    Cyclic as bounds on type aliases and newtypes are now rejected explicitly. These already failed indirectly after cycle recovery produced mixed; the checker now points to the unsupported bound itself. Cyclic super bounds are unchanged. 82a6a0afae
