Breaking Changes

4 changes
  • W44 · Nov 1
    Hack now detects more impossible shape accesses when the shape is hidden behind an abstract type constant, generic bound, or intersection. Shapes::idx(), Shapes::at(), Shapes::keyExists(), and coalesced indexing can consequently report new errors or always-false checks, with the explanation pointing back to the relevant shape bound. b006f0e38f 25c058fc89
  • W45 · Nov 4
    HHVM now enforces every upper-bound constraint on typed properties when an object is unserialized and when a property is unset. Values that satisfied the main property hint but violated a generic upper bound can now throw a property type-hint error during APC/unserialization or unset(). a5b29ce0d7
  • W47 · Nov 18
    C::class and self::class may no longer be used as shape keys in shape types, literals, Shapes::idx()-style calls, or other non-subscript positions because they require an implicit class-pointer-to-string conversion. Replace them with nameof C or nameof self; ordinary class constants remain valid shape keys. c0ab10b739 9952acc27d
  • W48 · Nov 25
    Equality disjointness checking now looks through like types. Projects with the relevant warnings enabled can newly receive Warn[12007] for strict comparisons that can never succeed after removing the dynamic component, such as (int, string) === int. aeb075f9f2

Future Changes

30 changes
  • W44 · Nov 1
    Package v2 now canonicalizes both the project root and the PACKAGES.toml parent in strict mode, and neither in non-strict mode. This fixes include_paths matching when the two paths previously used inconsistent canonicalization. 966300bf04
  • W45 · Nov 4
    The unstable shape_destructure feature now handles typed-local enforcement, readonly propagation, and lambda captures for shape destructuring. These commits are supporting pieces of the feature rather than a general release. cb09ea0337 313b039506 426e187bb8
  • W45 · Nov 5
    The unfinished module_references feature has been removed, including imports and exports blocks and ReflectionModule::getImports()/getExports(). Ordinary Hack modules and package-v2 relationships are unaffected. 9a3740165f
  • W45 · Nov 6
    Unstable shape destructuring can now be used as a foreach value pattern, including nested shape and tuple patterns. It still requires <<file:__EnableUnstableFeatures('shape_destructure')>>. 394673c13a
  • W45 · Nov 6
    Package v2 active deployments are now honored while building a repo: files are selected from include_paths and __PackageOverride attributes instead of module membership. This remains part of the staged package-v2 rollout. 0548222340
  • W45 · Nov 6
    Memoized calls now produce the same key for a class name represented as a string, lazy class, or class pointer. This fixes duplicate cache entries during the class-pointer rollout. 9c245379fd
  • W45 · Nov 7
    Behind the class-pointer rollout switches, class<T> now has its own local type instead of being erased to classname<T>. enable_class_pointer_hint=false retains the old erasure, while class_sub_classname temporarily controls the compatibility subtype relation. The implicit C::class constant can likewise be typed as class<C> through the staged class_class_type option. 4e3cc786fe f9f4398bdf
  • W45 · Nov 7
    Package v2 no longer reports package-access errors for exception types named in catch arms. 2b465f3615
  • W45 · Nov 8
    Package v2 can select a different hhvm.active_deployment for CLI-server requests than for web-server requests. The typechecker also stops reporting package errors inside opaque newtype definitions and constraints, while transparent aliases continue to be checked. 279d33d3f9 97b8a89659
  • W45 · Nov 8
    The temporary runtime/compiler option Eval.PackagesTomlFileName allows the staged package-v2 rollout to load a TOML filename other than PACKAGES.toml. 2e20fd28e9
  • W46 · Nov 13
    The unstable shape_destructure feature now permits tuple(...) as a destructuring lvalue and deliberately forbids mixing list(...) inside shape/tuple patterns or shape/tuple patterns inside list(...). b315173511
  • W46 · Nov 14
    The in-development notebook-to-Hack converter now preserves comments and whitespace and can emit Hack containing notebook syntax errors so standard Hack tooling can diagnose them. The accompanying notebook integration was not yet complete. c735a7bfe3 a4d2d47e1d
  • W46 · Nov 14
    Package v2 typechecker tools can load an alternate package file with --config packages_config_path=path/to/config; the selected package file is included in the configuration hash. 4f3e29eb01
  • W47 · Nov 18

  • W47 · Nov 19

  • W47 · Nov 19
    Experimental tuple splats can now be indexed, and tuples containing a splatted tail support dynamic when both their fixed elements and tail do. bf35c48456 b0df8ac785
  • W47 · Nov 20
    Typed-local duplicate-definition checks now understand tuple and shape destructuring patterns under the unstable shape_destructure feature. d172d7ab64
  • W47 · Nov 20
    HackC recognizes the new intrinsic HH\ReifiedGenerics\get_class_from_type<T>(), which produces a class pointer directly instead of extracting the classname string from a type structure. This commit does not add the function to the standard HHI, so it is rollout groundwork rather than a portable project API at this point. 60b19782a8
  • W47 · Nov 21
    The class-pointer rollout adds enum<E>, the class-pointer counterpart to enumname<E>; it expands to class<HH\BuiltinEnum<E>>. 624d05698f
  • W47 · Nov 21
    Beta CLI error streaming now starts during the first typecheck after hh_server is launched instead of waiting until that typecheck has completed. 78a3b3138e
  • W47 · Nov 22
    Experimental tuple splats now participate in tuple subtyping: when comparing (T1, T2, ...T) with another tuple, Hack checks the fixed prefix and compares T with the remaining tuple tail. 02b3e770ab
  • W47 · Nov 22
    Recursive case types must now be contractive. Direct or nullable self aliases such as case type A = A and case type A = ?A are rejected, while recursion underneath a constructor such as case type A = vec<A> remains supported. 5748214e09
  • W48 · Nov 25
    Beta error streaming now falls back to streaming the current errors file when its Watchman freshness query fails, instead of terminating with an exception. 9f83204614
  • W48 · Nov 25
    The in-development notebook converter now preserves notebook and cell metadata, markdown cells, code-cell order, and empty notebooks. Generated Hack wraps top-level cells in an async gen_notebook_main_*() function so notebook code can use await. e5a68dc1be cb340dc7fc cc7f465752 5674ee32b3 c652960095
  • W48 · Nov 26
    Recursive case-type validation now expands type constants and opaque aliases when checking contractiveness, rejecting indirect cycles such as case type A = ?B::T where B::T resolves back to A. d3984bcbc6
  • W48 · Nov 27
    The class<T> parser switch is now enabled by default, and HHVM shallowly enforces class<T> hints. Eval.ClassTypeLevel=0 accepts strings, lazy classes, and class pointers with optional string notices, while level 1 rejects strings. As with classname<T>, class<T> is not yet permitted in is/as or reified generics. dfca3a4cbe
  • W48 · Nov 27
    The class-pointer syntax has entered ongoing release, and the compatibility type HH\class_or_classname<T> has been added for APIs that temporarily accept both class pointers and class names while the subtype relationship is separated. It likewise cannot be used in is/as or reified generics. b154e2745f
  • W48 · Nov 28
    Beta error streaming now keeps waiting for a genuinely new errors file after rejecting a stale one, using the file's inode and change time instead of only its Watchman clock. f309c53afb
  • W48 · Nov 29
    Beta error streaming now reports the total error count when --max-errors truncates output and shows the server's real progress stages instead of a generic hh_server sync message. 28ae0a85cd e2db79b525
  • W48 · Nov 29
    Recursive case-type subtyping now treats revisiting an already-compared recursive pair as success, enabling sound relationships between contractive recursive definitions while relying on the new contractiveness checks to reject aliases such as A = A. 62ca09bb76

Highlights

16 changes
  • W45 · Nov 5
    The new Log.BaseDirectory runtime option prefixes server error, access, admin, and Xbox log-file paths, allowing separate tasks to use the same relative logging configuration under different directories. 2085abb477
  • W45 · Nov 6
    The Thrift extension adds thrift_protocol_write_binary_struct() and thrift_protocol_write_compact_struct(), which serialize a struct without an RPC message envelope. The compact form accepts an optional protocol version, defaulting to 2. 9e49db492b
  • W45 · Nov 6
    Generated runtime configuration now forwards Repo.Authoritative correctly after the configuration-system migration, preventing consumers from observing a stale or incorrect repo-mode value. 67acf766d8
  • W46 · Nov 11
    Hack's process, worker, and typechecking-service plumbing now uses poll() instead of select(), avoiding select() file-descriptor limits and failures. This is the repaired, durable re-land after the first implementation was backed out on November 4. ef1068c700 c5d2342e2e 77738c72b0
  • W46 · Nov 13
    Out-of-memory exception messages now include both the request's measured memory usage and its numeric limit, making production OOM reports more actionable. ecb246b358
  • W46 · Nov 13
    JSON produced and consumed for function types by batch type-at-position tooling now preserves readonly receivers, readonly returns, and contexts. The serialized capability is the callee's required context; when the field is omitted it decodes as [defaults], not as an unrestricted or capability-granting function. 210b4af6eb
  • W46 · Nov 13
    Server.RequestMemoryMaxBytesSet is now a recognized runtime setting, so ini_get('hhvm.server.request_memory_max_bytes_set') no longer always returns false. 5c81805ef8
  • W46 · Nov 14
    A JIT store-elimination workaround prevents a required local write from being removed before its metadata update, avoiding crashes caused by unwritten locals. 19fc705f76
  • W46 · Nov 15
    The LMDB extension adds HH\lmdb\mdb_get_raw() and HH\lmdb\mdb_put_raw() for direct string payload access without Hack serialization. mdb_put() and the raw variant now only replace the inout value when MDB_NOOVERWRITE makes LMDB return the existing value. 1ce27396b3
  • W46 · Nov 15
    HHVM now publishes hhvm.select_queue_duration_us.avg.60, measuring how long messages spend waiting in the server selection queue. d8e94d74d6
  • W47 · Nov 18
    The pure HH\Facts\sha1(string $path)[]: ?string API returns the SHA-1 already tracked by the active Facts store. It returns null when no hash is available; the repo-autoload implementation does not supply one. 690ed8a0cd
  • W47 · Nov 19
    json_encode_with_error() accepts the new JSON_FB_FULL_FLOAT_PRECISION flag to emit up to 17 decimal digits for IEEE-754 doubles instead of HHVM's usual 14, allowing a JSON encode/decode round trip without losing representable precision. 09c784c567
  • W47 · Nov 22
    In --everything-sdt mode, <<__NoSupportDynamicType>> suppresses the implicit <<__SupportDynamicType>> on a declaration while retaining signature pessimisation, supportdyn wrapping, and implicit supportdyn<mixed> bounds. 1e83a3bfa7
  • W48 · Nov 25
    hh now filters warnings from files whose first 50 lines contain @generated. Pass -Wgenerated to include those warnings again. 0fb414e697
  • W48 · Nov 26
    The new sb_profile_ser(string $sandbox_root, string $profile_path) and sb_profile_deser(...) APIs serialize and restore sandbox JIT profile data, returning a status string. Each operation is limited to one attempt during an HHVM process's lifetime, and deserialization skips units whose SHA-1 no longer matches. c773c01184 5d05ff52a8
  • W48 · Nov 29
    The diagnostic for a type constant that captures a class type parameter now correctly says that type constants cannot use type parameters, rather than referring to a nonexistent type-parameter list on the type constant. 2096dcf5b6

Security
