Highlights

16 changes
  • W06 · Feb 3
    Under sound-dynamic typing, enum-class constant initializers now accept like-typed values without incorrectly widening the enum class's own base type and inherited API. a575025b82
  • W06 · Feb 7
    Type-variable solving no longer performs a redundant, occasionally incomplete T <: T check when a union or intersection lower bound contains nothing that can be freshened. This removes false type errors for complex invariant bounds. a37f19dfe7
  • W07 · Feb 12
    Nested expression-tree literals are now accepted without enabling the old expression_tree_nest feature gate. bbe9d40fce
  • W07 · Feb 12
    The Hack language server can emit a Fix Hack error inline code action for diagnostics, using the code-compose.show-inline-chat client command and marking the action as AI-assisted. Clients that implement that command can open inline chat with the relevant function and diagnostic prefilled. 89e1b39fa9
  • W07 · Feb 12
    HHVM can preload units and extensions from a profile whose repository signature is stale, while still refusing to apply the stale JIT profile itself. This preserves safe startup preloading across repository changes. 62ea2d00cb
  • W07 · Feb 14
    An is SomeClass test for a non-generic class now participates in general class and GADT-style refinement. Hack can carry relationships learned from the tested class's implemented generic interfaces into the true branch, while improved union, intersection, negative-type, and like-type normalization keeps the resulting refined types usable. b60814dcaf 350e10e9b8 e9f1427c84 01fb380cbc 5eb83042d9
  • W08 · Feb 19
    HHVM now correctly locks a const object while unwinding from a constructor invoked through the interpreter, preserving the object's immutability guarantees on this exception path. e35e12ac41
  • W08 · Feb 19
    hh --dump-config prints the configuration parsed by hh_client, making it easier to diagnose differences between client and server settings. 10dde3aab4
  • W08 · Feb 20
    hhvm --modules no longer crashes while constructing the memory manager before request-local RDS storage has been initialized. 4d53c32e69
  • W08 · Feb 21
    Distributed typechecks now return the accumulated, already-filtered streamed diagnostics instead of replacing them with the unfiltered final set. This avoids spurious warnings when an hh_distc check is interrupted and resumed. c05ef61c5c
  • W08 · Feb 21
    Hover output no longer duplicates a member signature when its receiver has a like type, and its “Defined in” information is rendered as a separate Markdown section. 1f138ef380 9afa74e115
  • W09 · Feb 24
    CURLOPT_USERPWD and CURLOPT_PROXYUSERPWD now accept null, matching libcurl's way to disable credentials that were configured earlier on the same handle. dae2facf38
  • W09 · Feb 25
    Converting notebook JSON to Hack now restores newlines between source-array entries instead of concatenating every line, preventing generated notebooks from hanging later processing on malformed Hack. c4274610d9
  • W09 · Feb 25
    The renamed #NotKeyedByICAndLeakIC__DO_NOT_USE memoization option is now declared in the HHI, so the dangerous opt-out can be recognized by typechecking and autocomplete as well as by the compiler. 2b980a6b20
  • W09 · Feb 28
    Hack LSP diagnostics now carry data.line_agnostic_hash, a stable error hash that does not change merely because lines moved. Editor integrations can use it to correlate the same diagnostic across edits. 37bb036ddd 93277be0de
  • W09 · Feb 28
    Shapes::put($shape, $key, $value) returns a cloned shape with the field added or replaced and a correspondingly refined return type; the input shape is not mutated. d4d1771702

Breaking Changes

5 changes
  • W06 · Feb 3
    The specialized <<__Memoize(#ICInaccessibleSpecialCase)>> option has been renamed to #NotKeyedByICAndLeakIC__DO_NOT_USE. The new name makes its dangerous behavior explicit: implicit context is omitted from the cache key but remains readable, so callers must migrate the label and should avoid it unless this cache sharing is deliberate. ad1c155576
  • W06 · Feb 5
    Open shape type hints now receive the same field-name validity checks as closed shapes, including when the shape is wrapped in supportdyn; invalid keys can no longer escape checking merely because the shape permits unknown fields. 7afeeadee3
  • W07 · Feb 11
    Exception::$previous is now declared private instead of protected. Exception subclasses can no longer access the property directly and should use getPrevious(). 8b94828d59
  • W09 · Feb 25
    Nested expression trees are fully released and the expression_tree_nest experimental-feature name has been removed. Projects that still list that feature in .hhconfig should remove the obsolete entry. 28b67ffdf3
  • W09 · Feb 28
    Runtime type checking now consistently includes all generic upper bounds instead of consulting only the primary hint. Static-property writes and initialization enforce every bound, and property redeclarations must preserve equivalent primary and upper-bound constraints; code that previously violated an overlooked bound can now fail. 8ee0eb6005 fd915fab11

Future Changes

17 changes
  • W06 · Feb 3
    Experimental require this as constraints now permit a class to use a trait that requires that same class. Requiring a final class with require this as is rejected with guidance to use require class, which expresses the only possible implementation more accurately. e3b0f70eb7
  • W06 · Feb 5
    Two opt-in migration settings were added for plain <<__Memoize>>. disallow_non_annotated_memoize=true rejects it unless a label such as #KeyedByIC is supplied, while treat_non_annotated_memoize_as_kbic=true interprets an unlabeled annotation as #KeyedByIC; the latter takes precedence when both are enabled. Their HHVM equivalents are Hack.Lang.DisallowNonAnnotatedMemoize and Hack.Lang.TreatNonAnnotatedMemoizeAsKBIC. c6c1721348 ea7256253b
  • W06 · Feb 7
    HH\TypeStructureKind now exposes OF_CLASS_PTR and OF_CLASS_OR_CLASSNAME, allowing code that inspects runtime type structures to distinguish the staged class<T> and class-pointer migration representations. a96b817878
  • W07 · Feb 10
    Expression-tree DSLs using the shape-creation rollout now receive a shape's type through shapeType(...) rather than as an unwrapped shape literal. This lets the DSL give virtualized shape values a distinct wrapper type. d8cbaaab28
  • W07 · Feb 13
    Behind safe_abstract=true, Hack gained a prototype for preventing unsafe construction and static calls through class names that may denote abstract classes. It introduces concreteclassname<T> and <<__NeedsConcrete>>; a needs-concrete method may only be called through a class known to be concrete, treats static as concrete within its body, and may not override a method that lacks the stronger requirement. 4887d85e59 dc9e5e0dd1 b1f3edf2d7 489869a90c a180b5876e 6f15cf5e35
  • W08 · Feb 17
    Work toward macro-style nested expression trees now includes a control-flow-aware live-variable analysis. It identifies values a nested tree reads before assigning them so a later stage can bind those values from the enclosing tree. e4144f3c5c
  • W08 · Feb 19
    The class-pointer migration gained a classname_class level in class_pointer_levels. At an error level above 1, using a classname<T> variable in new, static method, class-constant, or static-property access is rejected in favor of class<T>. b7d8bb6c32
  • W08 · Feb 20
    Packages v2 now includes each package's include_paths in HHVM's package-specification cache key, preventing a cached repository from being reused after those paths change. 47789215dd
  • W08 · Feb 21
    With improved_hover=true, hovering a generic function, method, constructor, or property now shows its declaration-time signature followed by the type substitution at the use site, instead of showing only the instantiated signature. Redundant as mixed bounds are omitted. 2a9fdbf6c2
  • W09 · Feb 24
    The ongoing no_disjoint_union rollout adds <<__NoDisjointUnion>> for type parameters. A call or construction now warns when Hack infers a union whose members are pairwise disjoint for an annotated parameter—typically exposing a comparison or helper call that combines unrelated types such as int and string. f4e7a9f6f6
  • W09 · Feb 24
    Nested expression-tree work now records free variables and their source positions. Without the unstable expression_tree_nested_bindings feature, a nested tree that captures such a variable is rejected; the recorded data prepares splices to bind it from an enclosing tree later. 056565751c 886b66684f
  • W09 · Feb 24
    The class-pointer migration exposes class_or_classname<T> for APIs that temporarily accept either representation. HH\classname_to_class() now returns class<T>, while HH\class_to_classname() accepts the migration type and returns classname<T>. 6d9c06a115
  • W09 · Feb 25
    The Packages v2 escape hatch package_v2_bypass_package_check_for_class_const has been renamed to package_v2_bypass_package_check_for_classptr_migration. The renamed setting now controls package-check bypasses for type constants as well as ::class; disabling it enforces both checks. 0ed24678d6 28e3f58b84
  • W09 · Feb 26
    The staged class<T> type is now rejected in is/as hints and as a reified type argument, matching the existing classname<T> restriction. Runtime type structures do not yet retain enough information to enforce the inner T; the restriction is intended to be relaxed once they do. 93f09c41e5
  • W09 · Feb 27
    Expression-tree shape creation moved from Preview to Ongoing Release. DSLs can virtualize shape literals and their shape types through the protocol introduced during the preview. 7253f02e70
  • W09 · Feb 27
    HHVM's systemlib declaration of HH\class_to_classname() now accepts the class-pointer migration type class_or_classname<mixed>, aligning runtime compilation with the Hack HHI added earlier in the week. 6b3dbc1849
  • W09 · Feb 28
    With safe_abstract=true, checks now understand unions and intersections nested inside classname and concreteclassname, report the class-name source in warning reasons, and reliably rerun after incremental declaration changes. be44ab1920 6b18f450cb 29eb25acda c18a4a66d8
