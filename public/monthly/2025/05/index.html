47 noteworthy changes, organized by the source changelog sections.

Highlights

17 changes
  • W18 · May 1
    HHVM's CLI client now initializes Folly's singleton registry before extension shutdown, preventing exit-time failures when CLI code or an extension touches a Folly singleton. 6c837a0c48
  • W18 · May 1
    Runtime-type predicates now retain the type arguments of fully reified generic classes. This gives is refinements and case-type overlap checks enough precision to distinguish, for example, Box<int> from Box<string> while still detecting equivalent aliases. f148bd3843
  • W18 · May 2
    debug_backtrace() and HH\Asio\backtrace() accept the new DEBUG_BACKTRACE_ONLY_METADATA_FRAMES option, which returns only frames carrying metadata from HH\set_frame_metadata(). This avoids collecting file and line data for frames an observability pipeline would discard. 5e473c5748
  • W19 · May 6
    Visibility errors for a protected or private override of an internal member now report the actual narrowing mismatch instead of incorrectly saying that the parent member is inaccessible from its own module. 78719d189d
  • W20 · May 14
    Missing reified type-argument errors now point back to the reified type parameter that requires the argument, rather than blaming the enclosing function type or call expression. d575a67512
  • W20 · May 15
    LSP document-symbol ranges for functions and classes now begin on the declaration name instead of on preceding attributes, so IDE sticky-scroll headers show the symbol users are navigating. 535d3fdec2
  • W20 · May 16
    Malformed top-level syntax no longer panics the direct-declaration parser, improving hh_server and IDE recovery while a file is incomplete. b643631580
  • W21 · May 20
    ReflectionClass::getName() is now typed as classname<mixed> rather than plain string, preserving class-name information through reflection without changing the runtime string representation. 87ff635038
  • W21 · May 21
    HH\PriorityBridgeWaitHandle can wrap an awaitable so its child continues at lower priority instead of being promoted by the waiting context, and prioritize() can later lift it. create() requires []; the initial HHI for prioritize() omits a bracket list, so callers initially need the implicit [defaults] capability. ab939a7f4a 287b567685
  • W21 · May 21
    The class_overrides_all_trait_methods linter now ignores abstract trait methods that exist to carry user-defined semantic attributes, while continuing to report genuinely dead overrides. 4794a8c906
  • W21 · May 21
    HH\dynamic_class_meth() and HH\dynamic_meth_caller() now accept class_or_classname<mixed> instead of only string, adding class-pointer arguments without rejecting existing classname strings. 9da64160bd
  • W21 · May 22
    Calling PriorityBridgeWaitHandle::prioritize() after the wrapped wait handle has already finished is now a no-op instead of crashing. dd5cdaf7a4
  • W21 · May 23
    Repo-authoritative builds can use repeatable --static-pattern glob options to include only selected files in file.cache; this mode cannot be combined with --cdir or --cfile. 51c53a7882 bd70a8f60a
  • W21 · May 23
    HSL adds HH\Lib\Async\LowPri<T> for starting non-critical async work at low priority and promoting it later. run() has callee requirements [ctx $action, write_props], and prioritize() requires [write_props], so their callers must provide at least those capabilities. b90e9d07ac
  • W21 · May 23
    The HHI for PriorityBridgeWaitHandle::prioritize() now explicitly uses [] instead of omitted brackets. This weakens its callee requirement from implicit [defaults] to no capabilities and is therefore non-breaking for callers. b90e9d07ac
  • W22 · May 27
    Reified-type validation now recognizes that this inside a final class has no unknown late-static-binding subtype, allowing it where the checker can determine the concrete reified type. 269854f5c6
  • W22 · May 29
    hh --help now documents --error-format extended, making extended type-error reasons discoverable without consulting source or wrapper scripts. 6275ca880a

Breaking Changes

15 changes
  • W19 · May 6
    HH\TypeStructure<T> now models return_type and param_types as optional fields, matching the runtime values. Code that reads either field directly must first test for it or use ?? or Shapes::idx(). 472f99c64d 5e4e71971c
  • W19 · May 7
    HH\TypeStructure<T> now models elem_types, allows_unknown_fields, is_cls_cns, and optional_shape_field as optional fields rather than always-present nullable fields. Use an optional-shape access before consuming them. e042434722 89362e19c3
  • W19 · May 8
    HH\TypeStructure<T> now models nullable and name as optional fields. Their present values are non-null, but callers must account for the keys being absent. 742f8167f1
  • W19 · May 9
    HH\TypeStructure<T> now models value, typevars, and alias as optional fields. Direct indexing that assumed those keys were always present must move to an optional-shape access. 4bd21c5ee9
  • W20 · May 12
    HH\TypeStructure<T> now models generic_types, root_name, and access_list as optional fields. Use ??, Shapes::idx(), or a key-presence check rather than assuming the fields exist. 0e0fb9a62e
  • W20 · May 15
    class_parents() and class_implements() now return class-pointer values instead of class-name strings. The result keys remain class names; code that needs string values should convert the class pointers explicitly. db1c9385fc
  • W20 · May 16
    Truncated input passed to the compact Thrift from_string path now throws TTransportException with END_OF_FILE, matching TProtocol, instead of falling through to a generic TProtocolException. Exception handlers that matched only the old type may need updating. 28143ead08
  • W21 · May 20
    The checker no longer accepts dynamic static-method call syntax such as $class::$method() or C::{expr}(). Use a statically named method or the explicit HH\dynamic_class_meth() API. 458b089989 f5759593e2
  • W21 · May 20
    The legacy HH\ImplicitContext abstract class and its private context-construction path have been removed; the HH\ImplicitContext namespace remains. Projects still using the class should migrate to the memo-sensitive or memo-agnostic API. dc65144f44
  • W21 · May 20
    HH\MemoAgnosticImplicitContext and HH\MemoSensitiveImplicitContext are now sealed to their approved platform subclasses. Direct subclasses outside that hierarchy are no longer accepted. 529cf1661b
  • W21 · May 21
    HH\meth_caller() now requires class<mixed> rather than classname<mixed>. Pass a class pointer such as C::class; classname strings and variables no longer satisfy the public signature. 880710ad0c
  • W22 · May 28
    HHVM now rejects $class::$method() at runtime as well as in the checker. Code generated or executed without hh_server validation must also migrate to a static call or HH\dynamic_class_meth(). a51e712dc0
  • W22 · May 28
    HHVM also rejects computed static-method forms such as C::{expr}(), completing the runtime removal of dynamic static-call syntax. 7a9777a8a7
  • W22 · May 28
    iterator_to_array() has been removed from both the HHI and HHVM. Replace it with dict($iterator) when preserving keys or vec($iterator) when collecting values. 1187cf3a01
  • W22 · May 29
    Global constants declared under a nonexistent module now receive the same Unbound name error already applied to other top-level declarations. 351328f8b9

Security

1 change
  • W19 · May 8
    The Hack toolchain's Tokio dependency has been upgraded from 1.41.0 to 1.45.0 to address SNYK-RUST-TOKIO-9804284. a950001d30

Future Changes

14 changes
  • W19 · May 9
    The checker now rejects <<__Memoize>> and <<__MemoizeLSB>> on functions whose parameter list uses the unstable type-splat syntax. Such declarations cannot currently produce a valid memoization wrapper. c86642dbcc
  • W20 · May 12
    The unstable protected internal visibility modifier is now accepted, as is internal protected. Its access and override rules combine subclass visibility with module-internal visibility. 9a4623425f
  • W20 · May 12
    HHVM's compiler now also rejects memoization attributes on unstable type-splat functions, completing the checker-side restriction added on May 9. 34727f0d85
  • W20 · May 14
    The class_overrides_all_trait_methods linter no longer treats a trait's require this as constraint like require class, eliminating a false warning for valid trait composition. b8c45182ee
  • W20 · May 15
    Experimental checked unsafe casts have moved from the compile-time Hack.Lang.CheckedUnsafeCast option to the runtime Eval.CheckedUnsafeCast option. HackC now always emits the check instruction and HHVM decides whether to enforce it, so deployments testing the feature must rename their configuration. 93a6c2ac23
  • W20 · May 15
    An early edenfs_file_watcher_enabled mode can initialize an EdenFS watcher, but notifications still delegate to Watchman and the implementation is explicitly not production-ready. 4ca8b78848 6abf46d85d 6e0807fb23
  • W21 · May 19
    Declarations using the unstable type-splat syntax are now checked to ensure the splatted parameter type is a subtype of (mixed...). Generic splats therefore need an appropriate tuple bound instead of remaining unchecked at declaration time. 768846af7b
  • W21 · May 21
    Nested expression-tree lowering now orders captured free variables deterministically, preventing run-to-run changes in generated lambda parameters and bytecode while the nested-binding implementation evolves. 359704caf9
  • W21 · May 22
    Class-pointer diagnostics for dynamic static calls now include the type's definition site, and the unstable HH\ReifiedGenerics\get_class_from_type() intrinsic accepts abstract type constants without <<__Reifiable>> because it consumes their type structure rather than preserving a reification witness. 497d071296 b2082d530e
  • W21 · May 22
    The unstable polymorphic-lambda feature now supports both function<T>(T $x): T ==> $x and generic legacy anonymous functions. Parameters and returns must be explicitly typed, and reified, variant, higher-kinded, and shadowing type parameters remain disallowed. bb4279c923 3e1031ad4c
  • W22 · May 26
    Well-formedness checking for unstable polymorphic lambdas now binds the lambda's type parameters before checking their explicit bounds, avoiding spurious errors for bounded generic lambdas. 08dfda4896
  • W22 · May 27
    The experimental EdenFS watcher can now initialize when the Hack project is a subdirectory of an Eden mount, and reports a dedicated error when the project is not on Eden. Notifications still use the temporary Watchman bridge. 2188c6b045
  • W22 · May 27
    Unstable type-splat validation now preserves constraints learned while localizing type-constant projections before checking that the result is a subtype of (mixed...). 1532063bd0
  • W22 · May 29
    Hackfmt now preserves the required function keyword on unstable polymorphic lambdas, and lambda well-formedness reuses top-level function binding so parameter types can refer to the lambda's own type parameters. 817ea043fe 09e22a92af
