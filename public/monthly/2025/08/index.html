Highlights

21 changes
  • W32 · Aug 4
    Arity diagnostics now point at the call subexpression whose argument count is wrong, rather than a broader enclosing expression. ab8c323b64
  • W32 · Aug 4
    Incremental typechecking now records more of the declaration dependencies consulted while checking a file. This closes cases where an incremental check could miss an error found by a clean check, at the possible cost of somewhat larger recheck fanout. 290788b789
  • W32 · Aug 7
    JSON typecheck output containing warnings but no errors now exits successfully instead of reporting that the check failed. f6aaac5641
  • W32 · Aug 7
    More member and constructor lookups now participate in dependency tracking, reducing further cases where incremental typechecking could disagree with a clean check. Some edits may consequently recheck more files. bd0f639422 a51ab4f4c4 6473b0760a
  • W32 · Aug 8
    Enum classes now permit class<T> as their base type, so their members can hold C::class values without an implicit string conversion. Ordinary enums remain restricted to arraykey-compatible values. d34b8772a3
  • W33 · Aug 11
    hh_client check --single now processes batches of ten or more files in parallel. The new --multi FILE form reads one path per line, making large targeted checks easier to script. 8c8f596073 5ca15ac9d8
  • W33 · Aug 11
    The dead-HH_FIXME and dead-unsafe-cast cleanup modes no longer require restarting hh_server with --no-load. e7f422bb80
  • W33 · Aug 13
    The JIT now has a dedicated implementation for HH\Lib\PseudoRandom\int(), avoiding the pessimization associated with a generic native call while preserving its inclusive range behavior. d51a44a881
  • W33 · Aug 15
    Dependency tracking now covers more static members, XHP checks, switch exhaustivity, constructors, and IDE member lookups. Incremental checks should miss fewer affected files, though some changes may produce larger recheck fanout. 46ce64d386 967773dd8a
  • W33 · Aug 16
    HHVM now frees the losing class object when concurrent requests race to define the same class, closing a runtime memory leak in non-repo-authoritative deployments. aefb3fa931
  • W34 · Aug 20
    hphpd has a multiline REPL mode entered with k; a single . or ?> evaluates the block, while Ctrl-C followed by Enter aborts it. Literal blank lines in multiline strings are now preserved. fdb1d4e54b fbee79abfd 1439bbfbc0
  • W34 · Aug 22
    The JIT now distinguishes calls made with concrete function and method pointers, allowing it to inline HSL higher-order helpers such as Vec\map() more aggressively when passed a simple lambda. 80c6ec3c10
  • W35 · Aug 25
    The JIT can now specialize is resource and is_resource() checks, including folding the result when the input type cannot be a resource. c423c90fed
  • W35 · Aug 25
    A bad atomic compare-exchange memory order in the out-of-memory request killer has been corrected, preventing a runtime crash when HHVM attempts to terminate memory-heavy requests. a18050d29e
  • W35 · Aug 26
    The IDE's “Add Override” action is no longer offered for private parent methods, which cannot be overridden. 746aadbaf2
  • W35 · Aug 26
    HH\xenon_set_request_output_file($path) can direct Xenon samples for the current request to a JSON-lines file, including the originating thread ID. fba96d1705
  • W35 · Aug 27
    More class inheritance checks now register the declarations they consult, reducing another source of incremental typechecking results that differ from clean checks. b1bc7e8c74
  • W35 · Aug 27
    Type errors involving an instantiated generic now point at the type application in user code rather than the generic's declaration. e313daa0c5
  • W35 · Aug 27
    Thrift's TClientBufferedStream adds disable16KBBufferingPolicy(), allowing clients with roughly 16 KiB chunks to avoid sending a credit after every payload. The new method has the ordinary [defaults] capability requirement. f2b84c2d04
  • W35 · Aug 29
    await now looks through supportdyn, so supportdyn<Awaitable<T>>, Awaitable<supportdyn<T>>, and dynamically typed awaitables work under sound-dynamic and implicit-pessimization modes. a4b3e14491
  • W35 · Aug 29
    Hack's built-in declarations now expose SimpleXMLElement::isTruthy()[] and HH\legacy_is_truthy(mixed)[] for code that must preserve legacy boolean-coercion behavior explicitly. Both require no capabilities, so they remain callable from [] contexts. 98e73e75fe 298dae45eb

Future Changes

18 changes
  • W32 · Aug 5
    Variance analysis for experimental polymorphic function references now follows typedef parameters. When declaration information is unavailable, it conservatively treats type parameters as invariant instead of silently skipping them. f04fb6b1fe
  • W32 · Aug 6
    The experimental constraint_array_index solver received a set of compatibility fixes: better arity and vector diagnostics, more precise result reasons, support for ConstMap and KeyedContainer, and preservation of dynamic results where required. 9863e5fc70 5666b30336 552fe60a08 c19e1e052b 7034e9c7f6
  • W33 · Aug 11
    Parser support has begun for named parameters and named arguments. These commits only recognize the pre-MVP syntax; full naming and typing behavior is not yet available. f6791eda8f b270ae7302
  • W33 · Aug 12
    The opt-in warning system now reports warning 12023 when e1 ?? e2 has a left operand known to be always null or never null. Array-subscript forms are excluded because their null behavior is intentional and common. bd805a1455
  • W33 · Aug 13
    Named arguments are now lowered from the concrete syntax tree into the Hack AST, continuing the pre-MVP implementation begun earlier in the week. 9063a1301e
  • W33 · Aug 13
    The class-pointer migration adds HH\type_structure_class($class_or_object, $type_constant)[], a NoDoc helper that loads and returns the class<mixed> named by a type constant. Its empty coeffect list means it can be called from capability-free contexts. 6123f3b736
  • W33 · Aug 14
    With the opt-in needs_concrete analysis enabled, unsafe calls and instantiations through abstract classes are now warnings 12024–12026 rather than hard type errors 4490–4492. This makes the safe-abstract migration incremental. 7ae30448ae
  • W33 · Aug 15
    The ongoing no_disjoint_union rollout now applies <<__NoDisjointUnion>> to the key type of HH\idx() and HH\idx_readonly(). Calls that infer incompatible key types, such as a string key for a vector-like container, can now produce warning 12017. c5f6c4171e
  • W33 · Aug 15
    Named parameter declarations are now represented in the AST, but the named-argument feature remains pre-MVP and unavailable for general use. 98bc300a62
  • W34 · Aug 18
    Under the staged module-visibility rules, a protected internal abstract member may now mention an internal type from its module, matching the behavior already used for private and internal members. eee1367660
  • W34 · Aug 18
    Experimental polymorphic static-method pointers now retain an implicit class type parameter, so class generics are instantiated when the pointer is called rather than prematurely fixed when it is created. 7a1bd49156
  • W34 · Aug 19
    The Hack typecheck test suite now runs with the experimental constraint_array_index solver enabled by default. This is rollout progress for the new indexing rules, not a change to the default project configuration yet. 4abaf39c7b
  • W35 · Aug 26
    Package v2 repo builds now include files from soft_includes when the build is fully determined by packages, while keeping them distinguishable from hard-included files. b7941c506e
  • W35 · Aug 28
    When the experimental constraint_array_index_assign option is enabled, array and collection updates now use the new can_index_assign constraint solver. Initial support covers mutation through container types, with later work extending inference across more type forms. 0d4289debc
  • W35 · Aug 28
    Case-type subtyping no longer eagerly creates a disjunction when the subtype is an unresolved type variable or union. This avoids premature choices and improves inference for the experimental case-type implementation. 3ad3b0f3fc
  • W35 · Aug 29
    Under Package v2, HH\get_all_packages() now includes each package's soft_includes alongside includes and include_paths. 2fea51f549
  • W35 · Aug 31
    Nested expression-tree metadata now carries a lexically_enclosing_tree source range; the outermost tree records null. DSLs can use this to relate a nested tree to the tree that lexically contains it. 478fe4801a
  • W35 · Aug 31
    The experimental can_index_assign solver now handles vector and keyed containers, generic types, unions, unresolved type variables, shapes, and fixed tuples. This broadens the kinds of nested updates that can be checked through constraint_array_index_assign. ba83bd0583 ef85dfe3eb d62142862a

Breaking Changes

7 changes
  • W33 · Aug 12
    hphpd no longer implements the down, up, next, frame, step, or out commands. Command-line debugging is no longer supported; the remaining tool is primarily useful as a REPL. 86676af0f4
  • W34 · Aug 19
    The Rust-backed diagnostic JSON serializer now emits one top-level severity field per diagnostic instead of repeating it on every message and reason. Consumers of that output schema must read "error" or "warning" alongside the diagnostic's message array. a27f9d7320
  • W34 · Aug 19
    Shape-field validation now recursively unwraps nested nullable and supportdyn types. Accessing a field known not to exist through a nullable nested shape can therefore surface a type error that was previously missed. 1a4fa7d197
  • W34 · Aug 20
    In hphpd, c now abbreviates constant rather than continue, and the exception/continue debugging commands are no longer recognized. fdb1d4e54b
  • W34 · Aug 20
    SoapVar and SoapHeader now declare the properties populated by the SOAP extension instead of creating them dynamically. Reflection and object dumps consequently include declared-but-unset properties as null. 901fa02a5b
  • W35 · Aug 27
    Hack now reports the existing “generic parameter cannot be used in the type of a static property” error when that property comes from a trait, including a trait declared in another file. Code that relied on the previously missed case will need a non-generic static-property type. ef55469df9
  • W35 · Aug 29
    The Hack symbol indexer now skips files that are 5 MiB or larger, and also skips files whose size cannot be read. Typechecking is unaffected, but symbol-index consumers will not receive definitions or references from those files. 60a17f4a0e

Security

1 change
  • W34 · Aug 23
    Projects can set check_packages=false in .hhconfig to disable static package-boundary enforcement, including validation of package overrides and package names. Enforcement remains enabled by default for both Package v1 and Package v2. abfbbb11b2
