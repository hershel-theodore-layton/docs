Highlights

28 changes
  • W01 · Jan 2
    AsyncMysqlQueryResult now exposes mysqlInfo(), rowsMatched(), and warningsCount(), making the server's query metadata available through the typed API. 28a9e15eca
  • W01 · Jan 3
    New thrift_protocol_write_binary_struct_to_string() and thrift_protocol_read_binary_struct_from_string() built-ins serialize and deserialize binary-protocol Thrift structs without constructing a transport object. Both signatures omit coeffect brackets and therefore require [defaults]. 3b98248f1e
  • W01 · Jan 3
    The obsolete redundant_id lint has been removed. It no longer emits lint code 5501 for old id() wrappers; use parentheses while removing any remaining deprecated calls. 1d7205fa93
  • W02 · Jan 6
    The strongly typed HH\TypedFormatString implementation introduced on December 23 was temporarily reverted while a memory regression was investigated. This rollback lasted until the corrected reland on January 9. 5b0e3057c1
  • W02 · Jan 7
    Hack now provides declarations for HH\watcher_query(), HH\watcher_get_clock(), HH\ext_watcher_version(), and the watcher option/result shapes, eliminating unbound-name errors for the existing watcher extension API. These functions omit coeffect brackets and therefore require [defaults]. 6aab9d86c4
  • W02 · Jan 9
    HH\TypedFormatString<TFormatter, TArgs> durably relanded after the January 6 rollback. Typed format strings can be passed through first-class helpers, string literals infer their placeholder tuple from the expected formatter, and concatenation combines compatible argument tuples. HH\FormatString<T> remains a compatibility alias using (mixed...). aeef5f7ec1
  • W02 · Jan 9
    sprintf(), HH\invariant(), and HH\invariant_violation() retain [] while gaining typed variadic arguments. printf() still omits a capability list and therefore requires [defaults]; the stronger format typing does not relax its caller requirement. aeef5f7ec1
  • W03 · Jan 13
    Watcher options now honor an explicitly supplied repo_root, and watcher file metadata covers Watchman's clocks, timestamps, ownership, inode, type, symlink, and content-hash fields. f890ffef5a 3161ba224a
  • W03 · Jan 14
    AsyncMysqlConnectionOptions now has getters for connection and TCP timeouts, retry count, total and query timeouts, and connection attributes. The async MySQL extension version was raised to 8.1 for feature guards. d1e418ade6
  • W03 · Jan 15
    Async return-type enforcement is preserved when the tail-await optimization removes the normal return bytecode, preventing dynamically introduced bad return values from escaping the check and crashing later. 5e6edbd435
  • W03 · Jan 16
    Package-presence expressions are now accepted in invariant() conditions, preparing invariant(package foo, ...) to establish access to foo after the assertion succeeds. 5bd8bcd723
  • W03 · Jan 18
    Package-presence checks are now flow-sensitive across continuations. Hack carries successful and failed package foo facts through branches, early exits, loops, included-package relationships, and invariant(package foo, ...), allowing cross-package calls precisely where runtime control flow proves the package is present. b1ed57a14a
  • W04 · Jan 19
    HH\Lib\Str\format() and format_l() now preserve a HH\TypedFormatString<SprintfFormat, Targs> placeholder tuple through their ...Targs arguments, so first-class wrappers retain format-argument types without a FIXME. Both functions remain []. 60d4799e1f
  • W04 · Jan 19
    The runtime definition of HH\TypedFormatString is now present alongside its HHI declaration, so runtime type structures and aliases agree with Hack's typechecker. e0e9fe6410
  • W04 · Jan 20
    Prefixed string literals such as re'/foo/' are now accepted by both the runtime parser and typechecker in constant positions, including class constants, enum values, and default parameters. d7b2ba9381
  • W04 · Jan 21
    Package requirements are now modeled as declaration-level access requirements rather than as part of a callable's function type, fixing their interaction with polymorphism. New <<__SoftRequirePackage('pkg')>> support represents a requirement on a softly included package. 4762185971
  • W04 · Jan 23
    Document formatting no longer consumes the last nonblank line when the only required edit is removing trailing newlines. 21784c07ad
  • W05 · Jan 26
    The language server's formatter no longer deletes content at the top of a file when translating hackfmt output into LSP edits. 1ce73539f3
  • W05 · Jan 26
    An override of a <<__DynamicallyCallable>> method no longer has to repeat that annotation. Each dynamically invoked implementation can be annotated independently; the implied <<__SupportDynamicType>> requirement remains inherited. 73a415207f
  • W05 · Jan 27
    Hack's diagnostic engine now consistently distinguishes errors from warnings when backtracking and selecting type-checker paths. Enabling a warning can no longer suppress or manufacture a type error merely by changing that control flow. 561e592fd6
  • W05 · Jan 27
    FunctionCredential::pack() and FunctionCredential::unpack() can transfer an authenticated function credential between threads in the same HHVM process. Packed values expire after five minutes and cannot be reused after a process restart or in another process; both methods require []. 167e437347
  • W05 · Jan 27
    HH\serialize_with_options() accepts disallowCollections => true, causing serialization of Map, Set, Vector, and Pair values to throw while leaving Hack arrays and ordinary objects unaffected. f999a274c0
  • W05 · Jan 28
    debug_backtrace() now accepts DEBUG_BACKTRACE_SKIP_INLINED, which omits the top frame and any inlined frames so exception and profiler stacks do not report misleading optimized call sites. 54a1113c6d
  • W05 · Jan 28
    Hack declarations now expose HH\jit_jumpstarted(), HH\jumpstart_source_host(), and HH\jumpstart_prof_tag() with [read_globals], plus HH\mark_server_health() with implicit [defaults]. 549d2871c8
  • W05 · Jan 29
    The HH\autoload_*_to_path(), HH\autoload_path_to_*(), and HH\autoload_is_native() declarations now explicitly require [] instead of their former implicit [defaults]. This narrows their caller requirements, allowing these deterministic autoload lookups from pure contexts; it is a capability relaxation, not a breaking change. 5c73ddb336
  • W05 · Jan 29
    Runtime is checks against a reified shape or tuple generic now first verify that the value has the matching type-structure kind, preventing a segfault when the actual value has a different kind. 9f0e9f6d43
  • W05 · Jan 30
    Hack can now emit warning 12034 when code reads a keyset or ConstSet with $set[$key]. Such indexing either throws or simply returns the key; prefer C\contains_key() or ->contains(). isset, unset, and assignment contexts are excluded. b4c0fda49e
  • W05 · Jan 31
    New pure HH\Sandbox\dict_with_capacity() and HH\Sandbox\vec_with_capacity() helpers return empty arrays with a requested capacity hint, reducing reallocations while populating a known-size collection. Capacity must be positive; HHVM may cap or ignore the hint, and repo-authoritative mode returns a normal empty array. 0e7715a0fc c61c8ad0da

Future Changes

22 changes
  • W01 · Jan 2
    The Hack manual now documents case-type syntax, runtime-disjoint variants, asymmetric subtyping, and decomposition with is checks. Recursive and conditional case types remain outside this initial guide. 08a5376dac
  • W02 · Jan 5
    Runtime refinements now understand nullable predicates such as $x is ?T, including while decomposing variants that use the pre-stable case-type where-clause feature. abdfbd2d1e
  • W02 · Jan 5
    Optional parameters and parameters with defaults may now precede a type-splat parameter such as ...Targs. This supports typed-format helpers whose optional format argument is followed by the format tuple. 1128e6a255
  • W02 · Jan 5
    Experimental constraint-based method-call inference can defer resolving an underconstrained receiver inside expression trees. It is gated by try_constraint_method_inference; support for several method features and polished diagnostics is still incomplete. 0000cf2e3e
  • W02 · Jan 6
    Case types moved from Preview to OngoingRelease, so ordinary case-type declarations no longer need __EnableUnstableFeatures('case_types'). Case-type where clauses remain in Preview, and recursive case types are not part of this pre-stable release. a5022daa7c
  • W02 · Jan 9
    Case-type refinement with shape predicates now supports optional fields and open shapes. The implementation deliberately favors a bounded-cost, less exhaustive split over combinatorial decomposition. c2b9b24bf5
  • W03 · Jan 13
    Files can opt into recursive case-type definitions with __EnableUnstableFeatures('recursive_case_types'). The feature remains in preview and is separate from the now-releasing base case-type syntax. 3afc799b42
  • W03 · Jan 14
    The unstable extended-await implementation now schedules independent nested awaits concurrently while preserving expression dependencies. It also lays groundwork for awaits in loop conditions and updates. 3b286bd818 8b884ff428
  • W03 · Jan 14
    With the capture_pipe_variables feature enabled, a lambda declared on the right side of |> or |?> may capture that pipe expression's $$. d54988fbe4
  • W03 · Jan 15
    Open tuple syntax and type splats have entered an ungated rollout and no longer require __EnableUnstableFeatures('open_tuples') or __EnableUnstableFeatures('type_splat'). This includes optional/open tuple elements, splats in tuple and callable types, and type-splat function parameters; both features remain pre-stable. dc93244172
  • W03 · Jan 15
    Unstable extended-await syntax now handles conditionally executed awaits in short-circuit operators, ternaries, null coalescing, assignments, loops, and nullsafe calls while preserving their execution conditions. ec6d2a9b45
  • W03 · Jan 18
    The upcoming __NeedsConcrete warnings are suppressed in paths configured by warnings_generated_files, avoiding unactionable Safe Abstract warnings in generated code when the feature is enabled. 68a692a050
  • W04 · Jan 20
    In the pre-stable readonly feature, <<__IgnoreReadonlyError>> on a callable parameter now applies to the callback's return coercion and propagates through nested, bidirectionally typed lambdas. Readonly-returning callbacks no longer produce the suppressed mismatch at either level. cb714a6040 2409334bab
  • W04 · Jan 20
    Safe Abstract and __NeedsConcrete now have user-facing documentation and tested warning examples ahead of the needs_concrete configuration's release. a50aed61a0
  • W04 · Jan 21
    IDE hover text for an argument matched by a pre-stable type-splat parameter now includes the tuple index, such as $args[1], instead of losing the parameter name after the first element. a62607552a
  • W04 · Jan 21
    Safe Abstract now rejects <<__NeedsConcrete>> on final classes, where the annotation would be ineffective or make the method unusable. This affects projects that explicitly enable the not-yet-released needs_concrete checks. 76c06fb06c
  • W04 · Jan 22
    Safe Abstract now rejects <<__NeedsConcrete>> on instance methods and constructors. Such members already require an instantiated—and therefore concrete—class, so the annotation is redundant. 5e8effe259
  • W04 · Jan 23
    For the pre-stable type-splat feature, IDE signature help and autocomplete now expand an instantiated parameter such as ...(int, int) $args into indexed arguments, restoring parameter hints and enum completions for generic splat APIs. a264781a6a
  • W05 · Jan 26
    Errors for require this as SomeInterface now suggest the appropriate require implements SomeInterface constraint. 036bebf751

    Go-to-definition now follows static methods and properties made visible through the pre-stable require class and require this as constraints. db92b9ea66

The accessors and pack() retain []; __debugInfo() still omits a capability list and therefore requires [defaults]. 095cbba3b9

Breaking Changes

8 changes
  • W02 · Jan 9
    Components of a concatenated typed format string must each be valid format fragments. Expressions such as "%" . "d" are rejected even though the resulting plain string would form a valid placeholder. aeef5f7ec1
  • W03 · Jan 12
    Package-boundary checking now rejects enum C { use D; } when D belongs to a package that the current package does not include. This applies to both package configuration versions. 37ec673d69
  • W03 · Jan 12
    Direct access to a class constant in an unrelated package is now an error. Use an allowed package relationship or establish the package through the supported package-checking APIs; dynamic class references and type_structure() retain their distinct handling. e8b8fa9c16
  • W03 · Jan 13
    HH\watcher_query() now returns Awaitable<string> containing JSON instead of Awaitable<WatcherResult>. Decode the returned string before reading result fields; the content-hash key is now content.sha1hex, not sha1hex. 3161ba224a
  • W04 · Jan 19
    Calls to Str\format() and Str\format_l() now type-check variadic arguments against literal placeholders instead of accepting arbitrary mixed arguments. Fix newly reported calls by matching each placeholder's required type or by correcting the format string. 60d4799e1f
  • W04 · Jan 20
    hh_client --save-state, hh_server --save-state, and --gen-saved-ignore-type-errors have been removed, along with the corresponding server RPC. Generate saved states with hh_distc, which can also run locally. f6cc06f5b6
  • W04 · Jan 21
    Hack now validates package-requirement annotations against the declaring file's package and checks their relationships across overrides. A <<__RequirePackage>> or <<__SoftRequirePackage>> target must strictly include the declaring package; remove redundant same-package annotations and correct unrelated or only-soft-included targets. 4762185971
  • W05 · Jan 27
    A concrete type constant inherited from a parent is now checked against an <<__Enforceable>> requirement introduced by an interface on the child. Previously this combination could accept an erased, non-enforceable type; it now reports error 4302. 548b917d91
