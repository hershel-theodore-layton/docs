Highlights

27 changes
  • W06 · Feb 2
    hh_single_type_check --config now rejects unknown configuration keys and suggests a close valid spelling when one exists. This catches mistyped one-off settings instead of silently typechecking with an unintended configuration. 934f2c0cee
  • W06 · Feb 5
    HH\ImplicitContext's protected runWith() and runWithAsync() methods now require [leak_safe, ctx $f] instead of [this::CRun, ctx $f]. This narrows the fixed callee requirement to leak_safe, so callers no longer need to satisfy a subclass's potentially broader CRun; they must still provide a capability set that is a superset of both [leak_safe] and the callback's contextual requirement. 76abaa20a2
  • W06 · Feb 5
    Open-source HHVM builds now use Folly's symbolizer for crash reports and perf maps, replacing raw addresses with C++ symbols when the build provides libunwind. c2909dc0ef
  • W06 · Feb 6
    HH\Facts\all_modules()[]: vec<string> returns every module defined in a Facts-enabled repository and throws InvalidOperationException when Facts is unavailable. 202ce61d20
  • W06 · Feb 6
    The HSL documentation for Str\to_int() now makes its exact round-trip rule explicit: zero-padded strings such as "01" return null; trim the zeros or use Math\from_base() when that input should be accepted. e9d0ce7fe8
  • W07 · Feb 9
    SQLite3, SQLite3Stmt, and SQLite3Result now release native SQLite resources during request sweeping. File descriptors no longer leak when objects survive until request end without an explicit SQLite3::close(). 52ada4d82d
  • W07 · Feb 9
    openssl_x509_parse() now frees the owned buffers returned by X509_NAME_oneline(), avoiding repeated native-memory growth while parsing certificates. b1f4009ddb
  • W07 · Feb 12
    Top-level statements now inherit the package selected by their file path instead of being typed with no package. This removes spurious package errors in Hack notebooks and other files whose statements are wrapped in a synthesized function. 80ee10b3e1
  • W07 · Feb 12
    HHBBC now detects cycles while speculating through successor blocks, preventing repo-authoritative compilation from hanging on control-flow loops that revisit the same block. 7029bde607
  • W07 · Feb 13
    Concurrent parsing of .hhvmconfig.hdf wildcard entries no longer races on a shared name counter. Repository-specific maps such as IndexedMethodAttributes will no longer silently lose an entry when multiple files' options are loaded in parallel. c0164403a5
  • W07 · Feb 14
    Files matched by package_exclude_patterns are now also exempt from __RequirePackage and __SoftRequirePackage access errors, making those annotations consistent with ordinary package-boundary checks. d615cebfcf
  • W07 · Feb 15
    HH\package_exists() and the package-definition introspection helpers are now explicitly pure ([]). This is a caller-requirement relaxation from omitted brackets, which mean [defaults], so package checks can now be performed from a pure context without acquiring any capability. 483c81b3c7
  • W08 · Feb 17
    HH\Facts\type_method_attributes(classname<nonnull>)[] performs a point query for one type and returns a dict from method names to their indexed attribute names. This avoids scanning every method carrying a particular attribute. 632b612e33
  • W08 · Feb 17
    SQLite3Stmt::execute() no longer steps a SELECT, discards its first row, and executes it again on the first fetchArray(). The result buffers the initial row and repeated calls to execute() reset the cursor before running. 7f0dba4f01
  • W08 · Feb 17
    Str\replace_ci() and Str\replace_ci_l() are now explicitly pure ([]) because their case-insensitive implementation no longer consults global locale. Their caller requirement is therefore narrowed from implicit [defaults] to no capabilities. a7cc885222
  • W08 · Feb 17
    Lint 5649 no longer flags an internal class solely because it appears in a __Sealed allowlist. References to the internal class outside that attribute remain linted, so sealed APIs can intentionally enumerate internal implementations without a false positive. 261492cbdd
  • W08 · Feb 18
    hh_client --jsonl streams one machine-readable JSON object per diagnostic followed by a summary object. It is mutually exclusive with --json and preserves the ordinary success or type-error exit status. a79ccef39e
  • W08 · Feb 18
    IDE diagnostics for indexing a keyset or ConstSet now offer direct quick fixes to C\contains_key($keyset, $key) or $set->contains($key). 8a0a29c718
  • W08 · Feb 19
    openssl_pkcs7_read(string $data): vec<string> reads PEM-encoded signed or signed-and-enveloped PKCS#7 data and returns its certificates as PEM strings, throwing when the payload cannot be parsed. Its omitted coeffect brackets mean callers must provide at least [defaults]. 4cd3b1fce0
  • W08 · Feb 20
    ReflectionClass::hasProperty() and getProperties() no longer initialize the reflected class merely to obtain declared property names. Reflection over traits and classes with failing initialization can therefore answer these structural queries safely. 7884df7969
  • W09 · Feb 23
    Function-pointer inference now tracks type parameters in other parameters' constraints, class and type-constant refinements, and occurrences of this with their precise variance. This removes unnecessary first-class polymorphic types while preserving the correct co- or contravariant bound. 20e6acc12d 9a880e8a6b bf9fc1fc91
  • W09 · Feb 23
    Lambdas created inside a function protected by __RequirePackage or __SoftRequirePackage now retain the package availability of their creation continuation. This permits sound higher-order and recursive uses without granting packages that were unavailable outside the lambda. bec949706c
  • W09 · Feb 23
    get_active_worker_counts() is now known to Hack and returns a shape containing pagelet, Xbox, HTTP, and CLI worker counts. The declaration omits coeffect brackets and therefore retains the [defaults] caller requirement. 531391b170
  • W09 · Feb 24
    Reflection parameter APIs now have concrete HHI return types: boolean predicates return bool, class lookups return ?ReflectionClass, and isDefaultValueConstant() returns ?bool. This replaces HH\FIXME\MISSING_RETURN_TYPE, so callers gain useful static checking. bf3d95c54b
  • W09 · Feb 25
    HH\Asio\cancel_sleep_nothrow(SleepWaitHandle $wh): bool completes a pending sleep successfully with null instead of failing it with an exception. It returns whether cancellation occurred; its omitted coeffect brackets mean [defaults]. 2a17049a2a
  • W09 · Feb 27
    New HH\ImplicitContext\PreparedContext values let implicit-context subclasses prepare several assignments in pure code and apply them together with runBatch() or runBatchAsync(). The batch methods require [leak_safe, ctx $f]: callers must already have a capability set containing leak_safe and the callback's requirement; the list does not grant those capabilities. 3252eaa4eb
  • W09 · Feb 28
    JIT-compiled is_scalar() now matches the interpreter's runtime definition for every value type, removing mode-dependent answers caused by an incorrect JIT type test. c7843d7c59

Breaking Changes

15 changes
  • W06 · Feb 3
    A type named in a __Sealed allowlist without being a subtype now produces warning 12035 rather than a lint or optional hard error. The enforce_sealed_subclasses setting has been removed, and the diagnostic now uses the correct extend, implement, or use relationship for each classish kind. 58d208a5ca
  • W06 · Feb 3
    Typedef well-formedness now follows aliases in the same way that runtime type-structure resolution does. Invalid cycles through an opaque newtype are rejected instead of being accepted by hh and potentially failing in HHVM; legal recursion through transparent aliases and an enabled recursive case type remains supported. 281bde125e
  • W06 · Feb 4
    The dynamic-support pass now reports its own typing errors by default, including under everything_sdt. It is skipped when ordinary typechecking has already found errors to avoid duplicate noise; silence_errors_under_dynamic=true can temporarily restore suppression during a migration. a48510ac78
  • W06 · Feb 4
    HH\ImplicitContext\soft_run_with() and soft_run_with_async() have been removed. They were passthrough helpers that no longer changed implicit-context state; call the callback directly. 52fd0cf488
  • W06 · Feb 5
    A class's __Sealed allowlist may no longer contain a trait. Such declarations now report NastCheck[3108]; traits can remain in allowlists on classish kinds where their relationship has defined semantics. 76df11f979
  • W07 · Feb 9
    Package-boundary checks now apply to constructor references, including classes with consistent constructors. Constructing a class protected by __RequirePackage without loading the required package is now rejected like calling any other protected method. 5e5abce7a0
  • W07 · Feb 11
    A transparent alias around an opaque newtype no longer exposes the opaque type's constraint when Hack computes enforcement. Under implicit pessimisation this removes an unsound intersection with the hidden constraint, so code that previously relied on the leaked type can now fail typechecking. c30d4835f8
  • W07 · Feb 12
    Shape-aware constraint refinement is now unconditional, and the type_refinement_partition_shapes configuration option has been removed. Projects that explicitly disabled the option can see more precise refinements and should delete the stale setting. f1c42be784
  • W07 · Feb 14
    HH\ImplicitContextBase::exists() has been removed now that get() returns null when the context is absent. Subclasses should replace parent::exists() with parent::get() is nonnull, or directly use the nullable value. bbb221caf5
  • W08 · Feb 18
    Type errors in the first groups of parameters of a lambda with more than five parameters are no longer dropped during error accumulation. Invalid type-constant accesses and similar errors in those positions can now surface. 3a20987e05
  • W08 · Feb 20
    APC now stores a non-persistent class pointer as a lazy class. If the underlying class is later deleted, fetching that APC entry returns a dead lazy class instead of null; callers that used deletion as an existence test must handle the new value. a259ee456e
  • W09 · Feb 23
    Lint 5655 now reports references from a file assigned by package rules into a file moved into that same package with __PackageOverride. References guarded by an appropriate __SoftRequirePackage are exempt; other edges should move the target, add __RequirePackage, or be guarded by a package check. 216d08b79c 91243638d1
  • W09 · Feb 25
    Package boundaries are now enforced for function pointers and reified generic arguments, and the package_allow_function_pointers_violations and package_allow_reified_generics_violations escape hatches have been removed. References such as OtherPackage\f<> and cross-package reified type arguments now require that package to be available. fb27a911ff 8677c548f3
  • W09 · Feb 26
    Type-constant propagation now skips mixed and supportdyn<mixed> upper bounds instead of expanding mixed::T into Tany. This closes a soundness hole in where-clause inference and can reveal errors that were previously hidden after related type variables collapsed to Tany. e12516a086
  • W09 · Feb 27
    Package checking is now always enabled, package and deployment inclusions are always checked for transitive closure, and __RequirePackage remains allowed on interface methods. The corresponding check_packages, package_config_disable_transitivity_check, and allow_require_package_on_interface_methods settings have been removed; delete stale overrides. 8d391cf433

Future Changes

11 changes
  • W06 · Feb 3
    The unstable shape_field_punning feature adds shape($foo) as shorthand for shape('foo' => $foo) and permits punned and explicit fields in the same literal. It remains gated by <<file:__EnableUnstableFeatures('shape_field_punning')>>; missing-field diagnostics also now say where the field is required. 8aeb30361d
  • W06 · Feb 5
    The named-parameter implementation can now carry named argument metadata from HackC into HHVM and execute basic calls with required named parameters in the interpreter. Written left-to-right argument evaluation is preserved even though named values are arranged before positional values on the VM stack; JIT, inlining, and HHBBC optimizations still deliberately fall back for these calls. 792d13346d 0a27aa989f 3ca68328ff 7710d53043 b210576695
  • W07 · Feb 15
    ReflectionClass::getRequiredThisAsClass()[]: ?string exposes the class named by a trait's pre-stable require this as constraint, or null for other classishes and unconstrained traits. ab878bf11c
  • W08 · Feb 18
    HHVM gained .hhvmconfig.hdf controls for per-feature Unstable, Preview, OngoingRelease, and Released status. The new map is used only when Hack.Lang.UseLegacyExperimentalFeatureConfig=false; unspecified features remain unreleased unless Hack.Lang.ConsiderUnspecifiedExperimentalFeaturesReleased=true. 651c2bef21
  • W08 · Feb 19
    The named-parameter interpreter now supports omitted optional named parameters by validating the supplied names and filling absent slots with their default values. Variadic packing also preserves the preceding named arguments, while HHBBC continues to avoid unsafe folding of these calls. e3840417e9 89a731962f
  • W08 · Feb 20
    Type-constant access through self inside a trait now uses the class selected by pre-stable require class. This closes a Tany type hole and can expose errors in code that previously escaped checking through an unresolved this::T. 17fb0bda04
  • W08 · Feb 20
    The same self type-constant fix now covers the pre-stable require this as constraint. c7673ad08e
  • W09 · Feb 24
    Dynamic invocation paths can now pass named-argument metadata through invokeFunc*, including constructor invocation. This extends the staged named-parameter runtime beyond direct bytecode calls, but does not by itself complete the language feature's release. 9b3e5ec269
  • W09 · Feb 25
    Lambdas involving expression-dependent type constants with multiple upper bounds no longer make the typechecker recurse indefinitely when a bound refers back to itself. This affects the unstable type_const_multiple_bounds feature. 9118df03a0
  • W09 · Feb 25
    Recursive case-type expansion now preserves the recursive Tnewtype identity underneath constructors such as vec, tuples, shapes, functions, and class applications. This closes an unstable-feature soundness hole where case type CT = vec<CT> | int could incorrectly accept vec<string> as CT. b5903cf3aa
  • W09 · Feb 27
    The JIT can now use the normal function-entry calling convention for direct named-argument calls whose named parameters are all required. It validates the argument names at translation time and otherwise generates the same happy-path call shape as positional arguments; optional and repacking cases still fall back. d26c627ba8
