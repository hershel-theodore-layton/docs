Breaking Changes

22 changes
  • W23 · Jun 1
    More public HHI declarations now expose their concrete return types: Exception::getTraceOptions() and RecursiveIteratorIterator::getDepth() return int, while HH\asio_get_running() returns ResumableWaitHandle<mixed>. This improves inference but can reject code that used the old missing return types as arbitrary values. 92f693af87 ea4dc7bf50 b7291dea21
  • W23 · Jun 2
    Shape refinement now distinguishes open shapes from closed shapes and respects required versus optional fields when splitting is branches. Open shapes can correctly refine to include a newly tested field instead of collapsing a reachable branch to nothing; code in branches previously considered unreachable may now be checked and expose errors. abe7c91609
  • W23 · Jun 2
    Public Asio wait-handle callback setters now return void instead of an unspecified missing type. Hack will reject code that tries to use the result of setOnIOWaitEnterCallback(), setOnJoinCallback(), or the corresponding condition, external-event, resumable, and sleep wait-handle callback setters. 403ca2943f
  • W23 · Jun 3
    Lint 5655 now reports any cross-package edge that compiles only because the callee has a load-bearing __PackageOverride, even when the override targets a package included or dynamically loaded by the caller rather than the caller's own package. It remains suppressed when the caller can already reach the callee's underlying package. 04e9da19bf
  • W23 · Jun 4
    A large HHI cleanup replaces missing return types with concrete enforced types across Reflection, DOM, Memcache, PDO, SimpleXML, SOAP, SQLite3, and XMLWriter. Most affected operations now return bool, int, or string; projects that consumed these results as arbitrary values may gain type errors. d9bb706513
  • W23 · Jun 5
    Refining a dynamic value with is or as against a fully enforceable type now drops the useless dynamic intersection and produces the enforced or supportdyn form. Operations after a successful check are therefore checked against the asserted type instead of silently routing through dynamic, which can reveal invalid calls or property accesses that previously passed. bee322014e
  • W24 · Jun 9
    ReflectionClass::newInstanceArgs() is now marked deprecated in the typechecker declarations; its diagnostic recommends HH_FIXME::reflectionClassNewInstanceArgsForCallsite. 1656ef0a33
  • W24 · Jun 9
    Visibility bypass on annotated static properties now requires the additional tests_bypass_visibility_static_properties=true opt-in, which defaults to false. Static methods continue to use the existing bypass permission setting. 7dcdc84443
  • W24 · Jun 10
    ReflectionParameter::getTypehintText() has been removed; use getTypeText() to read the source-level type hint. Reflection nullability checks now consider all runtime type constraints, and builtin-type detection recognizes Hack primitive types rather than relying on the first constraint. 0f058d8f8a
  • W24 · Jun 11
    The native return declarations for bcpowmod(), curl_multi_getcontent(), and ZipArchive::getFromIndex() have been corrected from ?string to mixed, accounting for their non-string failure values. 0860f84302
  • W24 · Jun 13
    ReflectionMethod::getClosure() is now marked deprecated in the typechecker declarations; its diagnostic recommends HH_FIXME::reflectionMethodGetClosureForCallsite. 8568e6ab68
  • W26 · Jun 23
    Hack rejects method pointers from non-final classes when their parameters can supply two or more this values, counting an instance method's implicit receiver. This prevents pointers from relating unrelated subclasses; methods of final classes remain exempt. e8d75e6183
  • W26 · Jun 24
    The normal typechecker now checks required XHP attributes by default. The check_xhp_attribute project configuration override has been removed, and the standalone completion tool no longer accepts --check-xhp-attribute. 8d86d36862
  • W26 · Jun 25
    Cross-package references to non-class-like type aliases are now always checked in runtime-enforced positions, including parameter, return, and property hints and as constraints. The package_allow_enforceable_type_alias_violations escape hatch has been removed. 65c848a477
  • W26 · Jun 26
    The typechecker always rejects (bool) casts; the disallow_bool_cast project option has been removed. 7c19298944
  • W26 · Jun 26
    Function pointers are no longer permitted in constant expressions or property initializers. The disallow_func_ptrs_in_constants and Hack.Lang.DisallowFuncPtrsInConstants options have been removed. 167cdef425
  • W26 · Jun 26
    The @ error-suppression operator is unconditionally rejected by the Hack typechecker; the disallow_silence option has been removed. ead6d41ac8
  • W26 · Jun 26
    The typechecker always reports redundant generic parameters, and the check_redundant_generics option has been removed. 0f73b73373
  • W27 · Jun 29
    Function parameter default values must now be constant expressions, with no const_default_func_args project option to permit arbitrary expressions. 96a438ba6d
  • W27 · Jun 29
    Lambda parameter default values must now be constant expressions, with no const_default_lambda_args project option to permit arbitrary expressions. 5e57216b25
  • W27 · Jun 30
    The typechecker always rejects classname<T> values in dynamic construction, type-structure, and class-constant access positions; use class<T> values instead. The three corresponding class_pointer_ban_classname_* switches have been removed. 443ccfbfab
  • W27 · Jun 30
    HH_IGNORE_ERROR comments no longer suppress type errors, and the disable_hh_ignore_error option has been removed. Use supported suppression mechanisms such as HH_FIXME where permitted. e89581e3a3

Future Changes

5 changes
  • W23 · Jun 1
    Expression-tree support for Hack arrays has moved from Preview to Ongoing Release. It no longer needs per-file unstable-feature enablement, but remains pre-stable while the rollout continues. e846474534
  • W23 · Jun 2
    Runtime support has landed for <<__TestsBypassVisibility>>, allowing configured test-class descendants in non-repo-authoritative mode to reach annotated private, protected, or internal declarations. Hack typechecker integration follows later in the stack, so this is not yet the complete developer-facing feature. de0877a17d
  • W23 · Jun 3
    Pre-stable open and variadic tuples are no longer mistaken for closed tuples during is refinement and disjointness checks. This removes false “always false” warnings and lets an open tuple refine to a compatible closed tuple in the true branch. edf59ddcca
  • W23 · Jun 5
    A public HIP and Lean formalization now specify the proposed shape-polymorphism and shape-splat typing rules, including field requiredness, splat order, and inference bounds. This is a design artifact rather than a released language feature. 263c872c37
  • W25 · Jun 15
    Typed open shapes let a hint such as shape('a' => int, string...) require all unknown fields to be strings. The initial implementation requires typed_open_shapes=true and rejects this syntax in is/as tests; it is enabled by default later in this release cycle. fef78a70dd

Highlights

18 changes
  • W23 · Jun 2
    .hhconfig values can now span several lines. An indented line continues the preceding value with trimmed content and no inserted separator, making JSON-valued settings such as enable_experimental_stx_features easier to maintain; blank or unindented comment lines end the continuation. e9fd08104c
  • W23 · Jun 2
    FunctionCredential now provides getMethodOrFunctionName(), returning either the top-level function name or ClassName::methodName. Credentials for memoized implementation functions retain their $memoize_impl suffix. 82312e85e9
  • W23 · Jun 3
    pow() now has runtime return type num instead of mixed, matching its runtime behavior of returning only int or float and throwing for invalid inputs. Its public HHI return type remains dynamic; this commit does not introduce new static type errors. ada1e4482c
  • W23 · Jun 4
    hhvm --list-extensions now emits JSON describing each loaded extension's name, version, and oncall, making runtime capabilities easier to inspect from deployment tooling. 70bb50106d
  • W23 · Jun 5
    --package-lint-full now evaluates each dependent file in its effective package after applying that file's own __PackageOverride, while continuing to evaluate the target without its override. This fixes incorrect load-bearing-override results when both sides are overridden. bfb684cc09
  • W23 · Jun 5
    <<__TestsBypassVisibility>> is now understood throughout the Hack typechecker. With permits_bypassing_visibility configured, descendants of the named test base classes may access annotated private, protected, and internal members or classes, while ordinary callers retain normal visibility. Concrete private annotated members cannot be shadowed; method overrides must preserve the attribute, and an annotated internal member requires its internal class to be annotated too. d386a0d0d4
  • W23 · Jun 6
    Hack warns when a trait uses require this as C but C does not use that trait, directly or transitively. The warning suggests require extends C. ea950afff1
  • W24 · Jun 8
    AsyncMysqlResult::getSslVersion() exposes the negotiated TLS version on connect and query results, including the connectAndQuery path that does not return a connection object. It returns an empty string for a non-SSL connection. ce7734346c
  • W24 · Jun 10
    Strict comparisons between incompatible types, such as "5" === 5, now produce Warn[12001] instead of the hard Typing[4118] error. The corresponding always-true !== comparisons receive the same treatment. 97fcd1dfa9
  • W24 · Jun 12
    A class may combine require this as C with require extends C or require class C for the same target without HHVM incorrectly reporting conflicting trait requirements. Combining require class with require extends still reports a conflict. 358d0b7f35
  • W24 · Jun 12
    HHVM avoids a race in the file-await destructor caused by reading its event-base-owned file-descriptor map from another thread; this fixes crashes observed on ARM. 93473f0997
  • W24 · Jun 14
    hphp_invoke_callable_named_args() now accepts closures as well as function pointers, including closures with captured variables and mixed positional and named arguments. 050db531b6
  • W25 · Jun 15
    The repeated-return-value lint no longer recommends collapsing branches when the function body also contains a throwing path, preventing a suggested refactor from discarding an exception. Throws inside nested lambdas do not suppress the lint. 80d93facbc
  • W25 · Jun 17
    --error-format plain_highlighted adds a plain-text diagnostic format with ^ underlines for primary and secondary source spans, including multiline spans, without ANSI colors. e44c2066bc
  • W25 · Jun 17
    Native Facts database setup failures now report explanatory exceptions, including missing or invalid Autoload.DB configuration and SQLite opening, schema, or journal errors, instead of aborting on assertions or allowing setup failures to escape without context. 0d1775929d
  • W25 · Jun 18
    IDE hover cards now show class-constant values alongside their type and name, reducing the need to jump to the declaration. e82584e208
  • W26 · Jun 25
    Single-file and IDE typechecking now honor file-level __EnableUnstableFeatures attributes consistently with a full check, avoiding spurious feature-gating errors in opted-in files. 6700457943
  • W26 · Jun 26
    is vec_or_dict<_> now participates in predicate-based refinement, preserving useful information about the vec or dict branches and their inferred key types. e09ba51794

Security

1 change
  • W23 · Jun 4
    The CLI-server handshake now sends and validates a fixed-size magic value before any other data. A non-CLI client can no longer make HHVM interpret attacker-controlled bytes as an arbitrary size_t string length and attempt a process-killing allocation. 724ce26e55
