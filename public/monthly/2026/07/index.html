Highlights

4 changes
  • W27 · Jul 2
    Open-source HHVM no longer collects its low-level per-request JIT and interpreter timing measurements. On platforms where reading current-thread CPU time requires clock_gettime(), collecting these measurements consumed about 37% of CPU time during JIT warmup; removing them avoids that overhead. e412a40b27
  • W28 · Jul 8
    Hershel's HHVM now includes a Ubuntu 24.04 Noble build script. The repository now includes a clean-container build entry point and Debian metadata for regular, nightly, debug-symbol, and development packages; this package build identifies the runtime as HHVM 26.6.5. e8b37975a0
  • W28 · Jul 9
    Build support has landed in Hershel's HHVM for Ubuntu 26.04 Resolute. ./build.sh --ubuntu-26.04 selects it, with bundled PCRE and libdwarf compatibility work for the newer distribution; Ubuntu 24.04 remains the default. 0a1acba1cb
  • W30 · Jul 23
    Hershel's HHVM has optimized the implementation of HH\Lib\Vec\slice, a hot function in portable-hack-ast-linters. This reduces whole project lint latency by ~30%. Improvements scale more than linearly with the size of the file being linted. Projects with larger files may see a greater improvement. This change is included in hersheltheodorelayton/hhvm-full:26.06.05. See also HHVM issue for perf on the hhvm repo. b983bd51b1
