Highlights

29 changes
  • W32 · Aug 3
    HHVM no longer crashes when a failed unit compilation is configured to return a null result. 33e66bebb3
  • W32 · Aug 5
    HHVM now includes the original message from standard C++ exceptions in request failure diagnostics, improving errors such as Native Facts initialization failures. 4d451e6f58
  • W32 · Aug 5
    The typechecker now recognizes HH\get_all_packages() and HH\get_all_deployments(). Their declared shape return types now match the package and deployment metadata already returned at runtime. 9daedec5ab
  • W32 · Aug 7
    DOMDocument now provides createElementTyped() and createElementNSTyped(), which return a DOMElement and throw an invariant violation if element creation fails. 01b830d2c5
  • W33 · Aug 11
    The EXIF parser now clears stale buffers when reallocation fails, preventing use-after-free and double-free errors during subsequent parsing and cleanup. 116eb7f489
  • W33 · Aug 11
    HHBBC now safely retains named-argument names while analyzing compressed bytecode, fixing an ownership bug in whole-program optimization. b3dd86ffdf
  • W33 · Aug 12
    The typechecker now knows that DOMDocument::createElementTyped() and createElementNSTyped() return DOMElement. 130929a5fe
  • W33 · Aug 12
    hh_client --single now typechecks explicitly supplied files that the server does not monitor, rather than incorrectly reusing global diagnostics that can make those files appear error-free. 3594deeb46
  • W33 · Aug 14
    The JIT no longer assumes that an unloaded user type alias denotes an object, preventing incorrect handling of shape or dict values returned synchronously, through await, or through inout parameters. e02dc92e31
  • W34 · Aug 17
    unserialize() now rejects aggregate values in serialized key positions, preventing use-after-free when later serialized references point into a discarded temporary key. 8ba37ca157
  • W34 · Aug 17
    HH\Facts now supports function-attribute queries through functions_with_attribute(), function_attributes(), and function_attribute_parameters(). Index the desired attributes with Autoload.IndexedFunctionAttributes. 12950b15d1
  • W34 · Aug 17
    A public method overriding an internal or protected method no longer has to propagate __TestsBypassVisibility, since the public override does not bypass visibility. e25704eea5
  • W34 · Aug 17
    The typechecker now correctly expands recursive type-constant refinements involving this, closing a type hole that could silently accept incompatible values. a60607b184
  • W34 · Aug 18
    HHVM no longer dereferences a null JIT region when profile-guided region selection produces an empty result, avoiding a crash during offline retranslations. 8539c42f3d
  • W34 · Aug 19
    HHVM now avoids a null-pointer crash in the ExtTSP machine-code layout algorithm. e3136fcde6
  • W35 · Aug 24
    Serialization now clamps the remaining request-memory budget to a nonnegative value when determining its output limit, avoiding integer overflow from negative memory accounting. 7f1182a3c1
  • W35 · Aug 25
    hh_client --type-at-pos now prints named variadic parameter types with three dots instead of six. 320a938303
  • W35 · Aug 25
    The cross-package override lint now also reports references that become illegal when the caller’s __PackageOverride is removed, including references where both endpoints carry an override. b6083be80a
  • W35 · Aug 26
    The typechecker avoids expanding hidden portions of type-error explanations, preventing exponential memory use while preserving the rendered diagnostics. 849605f257
  • W35 · Aug 26
    Hackfmt no longer crashes when formatting typed open shapes such as shape(string...). f1d80663d8
  • W35 · Aug 26
    hhvm --version now includes a (roar) marker when the binary was built with ROAR support. 5fd092015c
  • W35 · Aug 27
    Open-source HHVM builds now include additional x64 and Arm64 portability fixes. ImageMagick OpenMP is disabled to avoid shutdown crashes. 222f52c75b
  • W35 · Aug 27
    hh_client now gives clearer diagnostics for invalid command-line arguments, including malformed --download-saved-state arguments, and avoids unnecessary backtraces in some argument-error cases. 5615eb178a
  • W35 · Aug 28
    The typechecker now updates module dependencies correctly after an interrupted typecheck, preventing stale unbound-name errors when a module is added. 4e7aa03c40
  • W35 · Aug 28
    hh_client accepts --reason to describe why an invocation was made; the description is recorded in invocation telemetry. aceaff4c74
  • W35 · Aug 28
    HHVM fixes a curl_getinfo() linked-list memory leak, integer-key handling in LMDB, temporary-string lifetime in Unix-socket Memcache connections, and temporary parameter-name lifetime during SOAP serialization. 0c786cb796
  • W35 · Aug 28
    HHVM fixes bounds checks in Fileinfo, XML tag skipping, and numeric-string conversion, and an output-buffer overflow in FriBidi, plus allocation-size overflow in Imagick::exportImagePixels() and invalid Sodium secretstream header lengths. 0c786cb796
  • W36 · Aug 31
    The JIT now resumes named-parameter function entries with the correct calling convention when translation is disabled. a105247ec2
  • W36 · Aug 31
    Fileinfo no longer calls qsort() on an empty magic-rule set, avoiding an undefined-behavior sanitizer abort for magic files without named rules. b9c8a5d593

Future Changes

17 changes
  • W32 · Aug 5
    The experimental enable_implicit_packages typechecker option now implements implicit package families: each direct child directory of a configured family path becomes a package without a separate PACKAGES.toml entry. The option is disabled by default. f1d95b65bc
  • W32 · Aug 5
    Experimental named variadic parameters in function, method, and lambda definitions now use an unnamed form such as named int...; the previous named int ...$xs spelling is rejected. The existing named-parameter and variadic-named-parameter gates still apply. a3b29158ba
  • W32 · Aug 7
    Experimental named-parameter definitions now reject multiple named variadic parameters, matching the existing restriction on function types. 2d2abb164e
  • W33 · Aug 10
    Expression trees now preserve literal string and integer subscript keys so shape-field reads and writes can be typechecked correctly. fc26c62910
  • W33 · Aug 12
    The opt-in check_duplicate_enum_values setting now reports duplicate values in plain enums, including conflicts introduced through enum use inclusions. It remains disabled by default. ab8c2c1907
  • W33 · Aug 12
    The opt-in duplicate-enum-value check now also reports enum values it cannot statically evaluate, rather than silently skipping them. 15b1143598
  • W33 · Aug 12
    <<__AllowUncheckedEnumValues>> lets an enum opt out of the experimental duplicate-value and uncheckable-value diagnostics. Enums that include an opted-out enum must also opt out. 41fb35f4ab
  • W33 · Aug 12
    The opt-in Eval.EnableLazyGC setting, when garbage collection is enabled, raises the default garbage-collection trigger from 50% to 80% of the remaining memory budget and allows a temporary memory grace buffer before collection. It is disabled by default, and explicit trigger and grace settings take precedence. b41450e50e
  • W33 · Aug 13
    The opt-in duplicate-enum-value check now catches collisions between integer values and their canonical integer-string equivalents in arraykey enums, such as 0 and "0". 261eb911c4
  • W33 · Aug 13
    The experimental enum-value check exempts pure aliases of a single enum when all referenced values are statically known and distinct. 84710a4acf
  • W33 · Aug 14
    Typed open-shape subtyping now compares the types of unknown fields, rejecting incompatible tails such as shape(string...) where shape(int...) is required. 8bbd0ed223
  • W33 · Aug 14
    Expression-tree subscripting has advanced from Preview to OngoingRelease in the experimental-feature rollout. 72a8b4317f
  • W34 · Aug 21
    When implicit packages are enabled, Hack files directly under a family path now produce Naming[2135]; files must live under a member directory even if they use __PackageOverride. f4f84cbd73
  • W34 · Aug 21
    When implicit packages are enabled, member directory names must be valid Hack identifiers. Invalid member names now produce Naming[2136]. 1dea159d3d
  • W35 · Aug 26
    Experimental shape splats now support type parameters, newtypes, and type constants, with subtyping and field operations that account for the fields those types may provide. Type-parameter splats require the unstable shape_splat_type_parameters feature gate. caef41ad02
  • W35 · Aug 26
    Implicit-package configuration diagnostics now identify conflicting package names and paths and point at the written member reference. cba11c4c5e
  • W35 · Aug 28
    The opt-in class_pointer_array_literal_keys setting infers classname<T> for collection-literal keys whose class-pointer type is already resolved, reflecting their runtime conversion to strings. The setting is disabled by default. fe6dba7d83

Breaking Changes

5 changes
  • W32 · Aug 6
    The parser now rejects $prosecco_tap as a variable name, including parameters and local variables. d01a7126e6
  • W33 · Aug 13
    __PackageOverride now produces an error when it names the file’s path-derived package itself or a package that the path-derived package neither includes nor soft-includes. 66027d0ebf
  • W34 · Aug 20
    Abstract class constants can no longer be used as shape keys in type annotations or shape expressions. The typechecker reports Typing[4129] instead of permitting a reference that can fail at runtime. 0f529ca6c2
  • W34 · Aug 21
    unset() now requires an indexed array-access target. Unsetting a local variable or an object property produces Typing[4521]. c0048a4355
  • W35 · Aug 26
    __PackageOverride can no longer assign a file to a package with strict isolation enabled, including members of experimental implicit package families. 258c0664f6
