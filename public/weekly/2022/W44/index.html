Week 44: Oct 31–Nov 6, 2022

14 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

13 changes
  • Tue, Nov 1
    Module import and export rules now survive compilation and are exposed through reflection. Runtime enforcement is not enabled by this change. a2e15b83bd
  • Tue, Nov 1
    internal methods may now use <<__DynamicallyCallable>>; private and protected methods remain rejected. 235cd7a253
  • Tue, Nov 1
    The typechecker is more reliable when inferring disjunctive subtype constraints, and an internal error involving already-solved type variables has been fixed. e1e756b3f7 4500589618
  • Tue, Nov 1
    HH\execution_context() now declares [read_globals] instead of implicitly requiring [defaults]. A capability list is the callee's requirement, so this narrows the obligation on callers rather than granting the callee extra access: a caller that provides read_globals, or any superset such as defaults or globals, can call it. 0f776c17fd
  • Wed, Nov 2
    hh --remove-dead-fixmes no longer consumes the character immediately following an inline HH_FIXME. 92fd112e0e
  • Wed, Nov 2
    __toString() declarations in the bundled HHI files now explicitly return string. 700bee0a4f
  • Wed, Nov 2
    SplFileObject has more accurate iterator declarations: current() is a like-string because CSV mode and end-of-file can produce other values, while getChildren() is nullable. 1ab6c0cebd c4a85bee88
  • Thu, Nov 3
    Most previously untyped bundled HHI functions now have the transitional return type HH\FIXME\MISSING_RETURN_TYPE. This still behaves like Tany for compatibility, but is intended to become dynamic in the future. 7ecc475674
  • Thu, Nov 3
    Assignment through Map and Vector indexing no longer widens an already inferred element type. In particular, code that starts with an untyped empty collection may now need explicit generic arguments. a56d5cfefa
  • Thu, Nov 3
    In sound-dynamic mode, the result of a dynamic static method call such as ClassName::$method() is inferred as dynamic rather than the unsound Tany. 17f03a1a34
  • Fri, Nov 4
    Sound-dynamic checking now permits static calls through a value typed as string, matching the rule that string can flow to dynamic in this mode. 668b6893f5
  • Fri, Nov 4
    A typechecker soundness regression involving intersection types has been fixed. 1adee5934a
  • Fri, Nov 4
    Hack lint now reports redundant HH\FIXME\UNSAFE_CAST calls as lint 5647 and offers an autofix that replaces the cast with its input expression. d02adc3a29

Future Changes

1 change
  • Wed, Nov 2
    Untyped built-in declarations are beginning to use HH\FIXME\MISSING_RETURN_TYPE instead of the unsound internal Tany type. This is preparatory work toward treating such results as dynamic. 0c5aa56b30
