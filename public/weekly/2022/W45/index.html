Week 45: Nov 7–Nov 13, 2022

11 noteworthy changes, organized by the source changelog sections.

Highlights

8 changes
  • Mon, Nov 7
    Redundant ?mixed and ?null type hints are now lint warnings (5008 and 5009) instead of type errors. 04b4d0f60b
  • Mon, Nov 7
    Type-alias expansion now detects cycles instead of repeatedly expanding a cyclic alias. 57491cc735
  • Mon, Nov 7
    Sound-dynamic checking handles partially enforced intersection return types and nullable-dynamic array operations more consistently. 17c37dd75a a7241d4077
  • Mon, Nov 7
    <<__MethodTraitDiamond>> is no longer gated as an experimental Hack feature. 7abe512898
  • Tue, Nov 8
    hhstc gained --remove-dead-unsafe-casts, which removes HH\FIXME\UNSAFE_CAST calls whose input already satisfies the destination type. 391d947075
  • Tue, Nov 8
    Bundled declarations now specify that Countable::count() returns int, and several ReflectionMethod predicates and modifier APIs now have concrete bool or int return types. ac1286cb39 9761e022e3
  • Tue, Nov 8
    Mutable collection clear() methods now return this, allowing their fluent behavior to be represented by the typechecker. 28e3aaa9cf
  • Fri, Nov 11
    Sound-dynamic pessimisation now handles abstract method return types and inherited intersection return types correctly, avoiding hierarchy errors in affected class trees. 7159fb5c86 e58ddaeeed

Breaking Changes

3 changes
  • Mon, Nov 7
    Indexed assignment no longer widens inferred Hack array types. Code that builds a vec or dict from an empty value may need an explicit type annotation. 5143993e38
  • Wed, Nov 9
    Accessing a known-absent field on a nullable closed shape is now a type error even when using Shapes::idx() or ??. Previously, adding nullability could reduce this to a lint or suppress it. 9e49acc366
  • Wed, Nov 9
    SplPriorityQueue<T> is now declared as an iterator over ~T, reflecting that its extraction flags can make current() return a priority or a value/priority pair instead of T. 4110107aae
