Week 47: Nov 21–Nov 27, 2022

8 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

6 changes
  • Mon, Nov 21
    Short enum-class labels such as #X can now be inferred when the expected parameter type is a nullable HH\EnumClass\Label. Invalid labels and labels with the wrong value type continue to produce the usual diagnostics. 153cf04a0d
  • Tue, Nov 22
    Sound Dynamic checking now preserves supportdyn when type_structure() examines a type constant bounded by an open shape. It also permits valid reads and appends through nullable containers while performing the additional __SupportDynamicType function-body check, avoiding false-positive errors in code that has already initialized or refined the container. e467b3f779 4f3e8fbfaa
  • Tue, Nov 22
    Hover text no longer mistakes class or namespace names beginning with HH_ for members of the HH namespace. A class named HH_FOO, for example, is now displayed without losing its prefix. 90d00b469a
  • Wed, Nov 23
    Sound Dynamic function-body checking now permits mutation after a value has been refined to AnyArray, including flows using HH\is_any_array(). These writes can be safely treated as an implicit upcast to dynamic. 3f1cef23f7
  • Thu, Nov 24
    hh_single_type_check --count-imprecise-types now emits a JSON summary of inferred mixed, nonnull, and dynamic expression types for each function and method in a file. This can help projects identify good starting points for type-precision migrations. 93c754fdb8
  • Sun, Nov 27
    A keyset literal in a context expecting mixed now retains the required arraykey element bound instead of being inferred as the invalid type keyset<mixed>. 2d1262a16e

Future Changes

2 changes
  • Mon, Nov 21
    Type constants in enum classes have moved from unstable to preview status. The syntax remains opt-in through <<file:__EnableUnstableFeatures('enum_class_type_constants')>>, but preview status permits explicitly enabled code to run in production. 810ea41057
  • Wed, Nov 23
    Enforceability analysis can now resolve type-constant accesses through concrete, abstract, and inherited definitions while safely terminating on cycles. This prepares Sound Dynamic signatures for future runtime enforcement of type constants. e92a9672ce
