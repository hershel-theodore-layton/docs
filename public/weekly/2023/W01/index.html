Week 1: Jan 2–Jan 8, 2023

9 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

8 changes
  • Tue, Jan 3
    HHVM no longer reports a false Cannot declare self-referencing constant fatal when an interval-timer callback interrupts the initialization of a large global or class constant. Genuine recursive constants remain invalid. bc6c72f81a
  • Tue, Jan 3
    The diagnostic for using #MakeICInaccessible or #SoftMakeICInaccessible with an incompatible context now correctly refers to leak_safe_shallow, rather than the incompatible leak_safe context. 9592c3ee4d
  • Wed, Jan 4
    Memoized functions and methods may now use <<__Memoize(#Uncategorized)>> or its __MemoizeLSB equivalent. This has ordinary memoization behavior but records the explicit category in reflection. Functions whose contexts cannot access implicit context must continue to omit a memoization option. e2bc6db35d
  • Wed, Jan 4
    Hover information for functions and methods that support dynamic now prints the source-level <<__SupportDynamicType>> attribute instead of exposing its internal supportdyn<...> representation. df90d157ec
  • Thu, Jan 5
    Dynamic-aware checking of indexing and indexed assignment now preserves the dynamic part of supportdyn<T>. This fixes rejected reads, appends, and writes in <<__SupportDynamicType>> code where the operation is valid through dynamic. 3921de4f83
  • Fri, Jan 6
    Hack modules no longer require <<file:__EnableUnstableFeatures('modules')>>. The separate module_references experiment still requires its own unstable-feature opt-in. d3bdad4f2f
  • Fri, Jan 6
    HH\ImplicitContext\run_with_soft_inaccessible_state() and its async counterpart can run a callable in the soft-inaccessible implicit-context state during migrations. They accept a blame key, may only be entered from a null implicit-context state, and should be removed once the logged violations have been addressed. 402b7ded0e
  • Fri, Jan 6
    Hover and typed-AST data can now distinguish anonymous functions from named functions instead of assigning synthetic names to closures. e18be7371b

Breaking Changes

1 change
  • Fri, Jan 6
    The Thrift extension no longer implements or registers RpcOptions::setFaultToInject(). Projects using this fault-injection API must remove those calls. 64a89b91a6
