Week 2: Jan 9–Jan 15, 2023

12 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

11 changes
  • Mon, Jan 9
    Lint 5649 now warns when ::class is taken from an internal class, since the resulting raw string can escape its module without visibility checks. Keep such classnames inside the declaring module or avoid producing them. ac5b19049b
  • Mon, Jan 9
    Bundled SPL and system-class declarations now give iterator methods more precise types: implementations of valid() and hasChildren() return bool, while several current() and getChildren() declarations preserve their iterator type parameters. This should reduce mixed propagation when consuming built-in iterators. 05841133e5 3274d2043b 50314df3fa c58cbdbc79
  • Tue, Jan 10
    Sound-dynamic checking no longer rejects assigning a value of type ~T back to an inout T parameter solely because the function or method is being checked for dynamic calls. fab2e559dd
  • Wed, Jan 11
    Objects created by the DOM extension now use canonical class capitalization such as DOMDocument and DOMElement. DOMDocument::registerNodeClass() remains case-insensitive, but reflection and get_class() now see the correctly cased built-in name. df0d4d2827
  • Thu, Jan 12
    Incremental typechecking now rechecks dependents when an inherited XHP attribute becomes required or a new required attribute is added. Projects should receive the same missing-attribute errors without needing a full check. 3fba663915
  • Thu, Jan 12
    The bundled HHI for pcntl_waitpid() now types its status parameter as inout ?int, and Serializable::unserialize() now requires a string. Callers of pcntl_waitpid() must account for the variable remaining nullable after the call. ece17c0698 050792ec94
  • Thu, Jan 12
    HHBBC now treats the classname field in runtime type structures as case-sensitive, matching the shape-key semantics used by type structures. b9b1d9f2ef
  • Fri, Jan 13
    Missing and extra shape-field errors now point at the individual field, and a missing field in a shape literal offers a quick-fix that inserts a TODO value. 5f0a767ff1 bbff846c01
  • Fri, Jan 13
    HHI declarations now type the output of parse_str() and the arrays passed to Collator::sort() and Collator::asort() as dynamic, accurately representing their heterogeneous results. 083c6643ef 834a393008
  • Fri, Jan 13
    Runtime type-structure helpers now compare the alias and kind fields case-sensitively, like other shape keys. 16acff3a5c
  • Fri, Jan 13
    Only the exactly cased method name __construct is treated as a constructor by runtime method-name checks. A differently cased method such as __Construct remains an ordinary method. 114f38dff3

Breaking Changes

1 change
  • Thu, Jan 12
    Dumping or calling __debugInfo() on a closure no longer reveals captured variables, parameters, or the bound $this; it now produces an empty dictionary. Code must not use closure debug output as a reflection API. d2cfc9b74d
