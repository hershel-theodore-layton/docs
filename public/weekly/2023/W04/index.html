Week 4: Jan 23–Jan 29, 2023

12 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

10 changes
  • Mon, Jan 23
    Incremental typechecking now correctly rechecks both files involved in a duplicate module-name collision, avoiding stale module diagnostics after edits. 0021cf60bb
  • Mon, Jan 23
    <<__SoftInternal>> is now accepted on constructor-promoted properties with internal visibility and rejected on ordinary constructor parameters or properties with other visibility. 2c2ac6d2d3
  • Mon, Jan 23
    hphp_get_stats('units') and hphp_get_stats('funcs') can now report the number of loaded units and allocated function IDs, respectively, which is useful for auditing how much code a script loads. f62641e738
  • Tue, Jan 24
    Pessimized expression trees now strip like types from inferred virtualized types even when they appear inside unions or supportdyn<...>. This fixes spurious generic-constraint errors passed to makeTree(). 0cb80422c1
  • Wed, Jan 25
    Projects using implicit sound-dynamic pessimization can now put the experimental <<__NoAutoDynamic>> attribute on a top-level function or class to disable automatic pessimization within that declaration. This is a local escape hatch: use it where the declaration is deliberately kept outside the dynamic boundary. 5bf4a9604d
  • Wed, Jan 25
    Disjointness checks now terminate safely when generic upper bounds form a cycle, preventing affected subtype queries from diverging. f298d5f2fe
  • Thu, Jan 26
    Method calls that violate a where constraint now place a typed-AST hole on the receiver. IDE and codemod consumers can identify the receiver as the source of error 4323 instead of receiving an unlocated constraint failure. c788fbc3ec
  • Thu, Jan 26
    Hover cards now show a declaration's documentation URL before its doc comment, keeping the link visible even when the comment is long. dca161bc90
  • Fri, Jan 27
    The experimental <<__NoAutoDynamic>> escape hatch now applies to type aliases as well as functions and classes. Under implicit sound-dynamic mode, an unannotated alias still receives an implicit as supportdyn<mixed> bound; annotating the alias suppresses that transformation. d7f9a9ec91
  • Sat, Jan 28
    <<__NoAutoDynamic>> now disables implicit pessimization while checking function and method return expressions, not only while building their declarations. 7d1201c567

Breaking Changes

1 change
  • Mon, Jan 23
    The stale systemlib declaration of RpcOptions::setFaultToInject() has been removed, completing the earlier runtime removal. Calls now fail typechecking as well as at runtime. 084d422844

Future Changes

1 change
  • Mon, Jan 23
    The typechecker now accepts <<__SoftInternal>> on enums and enum classes ahead of runtime support. Treat this as migration groundwork rather than a fully available runtime feature. e373f377f5
