Week 9: Feb 27–Mar 5, 2023

13 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

11 changes
  • Mon, Feb 27
    Sound Dynamic subtype inference now applies the intersection-to-union heuristic when the union contains an optional type variable, improving refinements involving nullable like-types. 389adc3c78
  • Mon, Feb 27
    Hover and outline information now includes the internal modifier for methods. 20464398b2
  • Tue, Feb 28
    Safe rename in Sound Dynamic projects no longer generates a deprecated compatibility stub for methods that cannot be called dynamically. Methods that do support dynamic retain the stub; behavior is unchanged when Sound Dynamic is disabled. ae21dcb1bd
  • Tue, Feb 28
    hh_server now restarts when __PACKAGES__.php changes, just as it does for .hhconfig, so package membership and include changes are not left stale. a7e3c34ae9
  • Wed, Mar 1
    JSON output from --tast-holes-batch now includes each hole's filename, allowing callers to safely combine results from multiple input files. 738e1b8a3d
  • Thu, Mar 2
    Sound-dynamic inference can now solve variables with supportdyn<T> on both sides, push supportdyn through Traversable and KeyedTraversable, and use safe dynamic-aware variance when checking overrides. This accepts more valid SDT collection and override patterns without permitting unrelated like types to override one another. ccbed68c5c 58073f2561 7aec7bc986
  • Thu, Mar 2
    HH\ImplicitContext\get_state_unsafe() can report whether the current implicit-context state is null, value, soft-set, inaccessible, or soft-inaccessible. Observing this state can undermine memoization guarantees, so the API is intended only for controlled migrations and diagnostics. 9b41b6f14c
  • Thu, Mar 2
    A constructor declared final may no longer be overridden merely because its hierarchy uses <<__ConsistentConstruct>>; Hack now reports the override that HHVM would fatal on while loading the class. 7100e0a74a
  • Fri, Mar 3
    PACKAGES.toml is now part of HHVM's repository-options cache key. Changing package definitions invalidates the cached configuration so subsequent compilation or loading sees the new package map. 90d3e33675
  • Fri, Mar 3
    Repeated use of function-coverage collection no longer risks a JIT crash after coverage state is cleared. ced950aa4e
  • Sat, Mar 4
    Errors are now sorted by their exact code before deduplication. hh_server and hh_single_type_check should therefore retain the same error when several diagnostics from one phase share a position. d99aae2f70

Future Changes

2 changes
  • Mon, Feb 27
    Opt-in package-aware typechecking now rejects access to public symbols from an unrelated package, permits access through declared package includes, and points cross-package diagnostics back to the relevant package declaration. hh_single_type_check can accept a package configuration for the same checks. df90eb181b bb4687403d ec97055caf
  • Wed, Mar 1
    Pre-stable class refinements now allow multiple upper or lower bounds without requiring each later bound to be a subtype of the earlier one. The typechecker still verifies that the refined constant exists and has the correct type-or-context kind, validates every hint inside the refinement, and rejects recursive refinement types. fe168082b4 835e676741 68c52d212b
