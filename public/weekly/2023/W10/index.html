Week 10: Mar 6–Mar 12, 2023

19 noteworthy changes, organized by the source changelog sections.

DayWeekMonth

Highlights

14 changes
  • Mon, Mar 6
    Standalone IDE mode now publishes fresh diagnostics after files are opened or changed, without waiting for a persistent hh_server connection. 735edbcea0
  • Mon, Mar 6
    A deployment in PACKAGES.toml may now select multiple domains, and each domain is interpreted as a regular expression. HHVM's package information now carries deployments so server requests can select the active package set from the host name. 8a423bfd07 44443ec5d4
  • Mon, Mar 6
    File attributes are now attached to module declarations. A file containing only new module declarations will no longer skip validation of an invalid or misspelled file attribute. 833db87aae
  • Tue, Mar 7
    Refining a generic or variable of type supportdyn<T> with as C<_> now preserves the outer supportdyn, allowing it to push into supported containers. 2df43ba6d8
  • Tue, Mar 7
    The capability requirements of several built-ins are now more precise. cpu_get_count() and cpu_get_model() require only [read_globals]; read-only APC queries also require [read_globals], mutating APC operations require [globals], and apc_sma_info() is []. These are backwards-compatible relaxations from implicit [defaults], so the functions are callable from more restricted contexts that still provide the stated capabilities. 190f4646d7 a7332ca5ba
  • Tue, Mar 7
    Frames passed to an fb_setprofile() callback now include the call site's file and line, avoiding a separate debug_backtrace() solely to recover that information. c09a67aaa0
  • Wed, Mar 8
    Sound-dynamic typing of Shapes::idx(), Shapes::at(), and Shapes::keyExists() now follows their transformed HHI declarations. Shape and Pair operations are no longer automatically pessimised, and Hack-array element bounds rely on supportdyn pushing instead. Projects should see more precise element types and errors that consistently enforce SDT arguments. b0c6a3527b 1c3dd600e1 e707d1fd3b 3ffec61090
  • Wed, Mar 8
    <<__NoAutoDynamic>> is now honored when a trait is parsed directly; annotated traits are no longer incorrectly treated as supporting dynamic under implicit pessimization. d48859c686
  • Wed, Mar 8
    Enum classes now participate in implicit sound-dynamic pessimization like ordinary classes. 53a512f6d9
  • Thu, Mar 9
    Class type refinements such as Box with { type T = int } no longer require <<file:__EnableUnstableFeatures('type_refinements')>>. 4fc409a7f6
  • Thu, Mar 9
    Under sound dynamic, an as refinement from an integer to a string-backed enum—or the reverse—is now weakened to ~Enum. This reflects the runtime coercion hazard instead of treating the result as a fully trusted enum value. 57bdb70e4f
  • Fri, Mar 10
    The right side of ?? is now treated as conditional when updating local refinements. Assignments performed only in that branch no longer incorrectly refine the environment as though the branch always ran. d59878c0d8
  • Fri, Mar 10
    hh check --ide-go-to-impl FILE:LINE,COLUMN exposes go-to-implementation results through the command-line client. ac050ce4d5
  • Sun, Mar 12
    The new package_exists(string): bool built-in reports whether a package is available in the active deployment. In server mode the deployment is selected from the request host; CLI and repo-authoritative mode use the configured active deployment. With no active deployment, it reports whether the package is defined at all. fdd040c474

Security

1 change
  • Mon, Mar 6
    Blowfish password hashing now handles short salts correctly instead of returning an invalid result, addressing CVE-2023-0567. 8497459de0

Breaking Changes

2 changes
  • Tue, Mar 7
    Source-level package definitions have been removed from Hack's lowerer. Define packages and their relationships in PACKAGES.toml instead. cf1180f7eb
  • Fri, Mar 10
    Function and lambda default arguments are now required to be constant expressions by default. This temporary default change was reverted on March 17. 9bc8be6524

Future Changes

2 changes
  • Wed, Mar 8
    Private-method visibility checks now account for a trait's pre-stable require class constraint. 8fd1d64bb1
  • Fri, Mar 10
    Trait hierarchy checks with pre-stable require class now report method conflicts that HHVM will encounter while flattening traits, while still allowing an interface conflict resolved by the required class. cef6a2bef9
