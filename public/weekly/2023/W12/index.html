Week 12: Mar 20–Mar 26, 2023

11 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

10 changes
  • Mon, Mar 20
    Missing-required-XHP-attribute diagnostics no longer prefix the attribute name with :, avoiding the misleading suggestion that ordinary XML attribute syntax requires a colon. 3b174001fe
  • Mon, Mar 20
    hh --codemod-sdt JSONL cumulative-groups|independent-groups can now apply an SDT analysis result by adding <<__NoAutoDynamic>>. Cumulative mode keeps groups that introduce no new type errors; independent mode evaluates and reverts each group separately. 4e986b3a3f
  • Tue, Mar 21
    Redundant as nonnull and always-succeeding as lints now offer precedence-safe quick-fixes that remove the assertion. f8e5cede57
  • Tue, Mar 21
    Incremental checking with the Rust provider backend now invalidates folded declarations for descendant classes after an ancestor changes, preventing stale inherited members and diagnostics. a7e37de3a3
  • Wed, Mar 22
    PACKAGES.toml now accepts soft_includes. Access across a soft include still produces a package diagnostic, but uses the distinct error code 4473 rather than hard cross-package error 4472, so migrations can suppress the soft boundary without hiding a later hard violation. 484aecd02c 4f27d55a1f
  • Wed, Mar 22
    For $base[$key] = $value, Hack now checks $key before $base, matching HHVM's evaluation order. This fixes both unsound refinements and valid programs rejected because the old checker assumed the reverse order. a993d20925
  • Thu, Mar 23
    Collection constructors with explicit type arguments can now infer like types from their values. For example, a Pair<int, string> built with a ~int value is inferred as Pair<~int, string> instead of being rejected. 2b9cfa4290
  • Thu, Mar 23
    vec is no longer treated as an automatically pessimised built-in. A vec<int> indexes to int, while constructing a vector from ~int values produces vec<~int> and preserves the dynamic boundary explicitly. 3beca4465d
  • Thu, Mar 23
    HHVM now computes the package cache key after reading PACKAGES.toml and uses the correct file metadata, fixing cases where package edits failed to invalidate repository options. c4f8aca11a
  • Fri, Mar 24
    keyset is no longer automatically pessimised. Construction and direct indexing now preserve the actual element type; dynamic elements remain intersected with arraykey, for example keyset<(~int & arraykey)>. 48985c4e75

Future Changes

1 change
  • Sat, Mar 25
    The experimental boolean expression package NAME now passes through parsing, naming, typing placeholders, and emission. Full typechecking and undefined-package diagnostics land later; continue to guard the syntax with its unstable-feature opt-in. 958e20a5b5 bd540076b8
