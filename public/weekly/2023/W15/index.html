Week 15: Apr 10–Apr 16, 2023

19 noteworthy changes, organized by the source changelog sections.

Highlights

10 changes
  • Mon, Apr 10
    The April 3 change that made HH\autoload_set_paths() always throw has been backed out, and the userland autoload map has been restored. Calls work again subject to the existing native-autoload deprecation controls. 6a00b1447e
  • Mon, Apr 10
    Hover and go-to-definition now work on locals listed in a lambda's use ($x, $y) capture clause and display their inferred types. 5953957e90 9e1a66f49f
  • Tue, Apr 11
    hh_server now produces streaming errors by default, including in open-source builds. hh_client can begin displaying errors from an in-progress typecheck instead of waiting for the full check to finish. ac03e5b0fc
  • Thu, Apr 13
    Expression-tree blocks are now a stable syntax feature and no longer require <<__EnableUnstableFeatures('expression_tree_blocks')>>. e1aa7c4ce7
  • Thu, Apr 13
    Local-variable find-references and rename operations can now be served by the standalone IDE daemon, avoiding a dependency on a fully ready hh_server. d4fc2e39a8 b3161a24dc
  • Thu, Apr 13
    Code in the default package is now callable from every package, while still being allowed to use package foo checks before calling into optional packages. Related diagnostics now point to the originating module. 0a77e5cbc1
  • Fri, Apr 14
    DateTime::format() is now declared with an empty capability list. Because it previously had the implicit [defaults] requirement, this is a backwards-compatible relaxation that permits calls from pure contexts. 9137fefeb3
  • Fri, Apr 14
    Failed calls to sound-dynamic functions now prefer the ordinary static argument error when both static and like-typed checks fail, avoiding confusing diagnostics involving ~_. 814812d3a3
  • Sun, Apr 16
    With builtin pessimisation enabled, hh_show, hh_expect, and related type-debugging pseudo-functions retain their original argument signatures rather than unnecessarily requiring arguments that support dynamic. 6f27d00daa
  • Sun, Apr 16
    HHVM and repository compilation now use success, generic failure, and script-fatal exit statuses more consistently. Automation should continue treating any nonzero status as failure rather than depending on older component-specific values. 621cef2a1f

Future Changes

8 changes
  • Mon, Apr 10
    The package feature now recognizes <<__CrossPackage('name')>> on functions and methods. The named package is considered loaded within the callable, and unknown package names are rejected. d60543f58b eb96979d36
  • Mon, Apr 10
    Soft includes and soft deployments are now carried through the package FFI and exposed to HHVM's package reflection. 126c7ce712
  • Wed, Apr 12
    Sound-dynamic checking now permits an implicit upcast to dynamic when assigning the final value of an inout parameter. 35635a1e41
  • Wed, Apr 12
    In everything_sdt mode, diagnostics and ordinary hh_show output now hide the implementation wrapper supportdyn<T> and print the underlying type. Set the show log level to at least 1 when the wrapper itself is needed for debugging. 9c5e8c2136
  • Thu, Apr 13
    Updating a supportdyn<shape(...)> with a value that does not support dynamic now drops the supportdyn wrapper instead of retaining an unsound guarantee. d3b455e436
  • Thu, Apr 13
    Sound-dynamic error output now omits redundant as supportdyn<mixed> bounds and internal references to supportdynamic.hhi. 1dc8673888 f3a4cb122f
  • Fri, Apr 14
    The unstable case-type feature now has parser, declaration, and subtyping support. Syntax such as case type C<T> as Bound = int | vec<T>; defines an opaque type whose variants are accepted as subtypes; unlike a newtype, it remains opaque even in its defining file. e694755a34 bd99dc17eb aa1548dfd4 e53c4cf7b2 4cf9a61e23 ff74345bf8 1ebc834d15
  • Fri, Apr 14
    <<__CrossPackage>> now accepts exactly one package name, preventing ambiguous callables that claim to load several packages. f9edc90293

Breaking Changes

1 change
  • Fri, Apr 14
    The boolean Autoload.UserlandEnabled option has been replaced by Autoload.UserlandDisabled and Autoload.UserlandDisabledSampleRate. A disabled value greater than 1 makes HH\autoload_set_paths() throw; a positive value emits the native-autoload deprecation notice and sampled migration logging. Deployment configuration should move to the new option names. 908ec46200
