Week 16: Apr 17–Apr 23, 2023

10 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

7 changes
  • Mon, Apr 17
    The invalid-comparison lint now uses the typechecker's disjointness rules, reports the concrete compared types, and covers == and !=. It no longer warns merely because two opaque enums or interface types differ when they could still compare equal at runtime. 43eb4c87ef
  • Tue, Apr 18
    An unbounded generic and one explicitly bounded by mixed now receive the same class-access diagnostics, including for calls through classname<T>. e6d63d29f3
  • Tue, Apr 18
    Renaming an interface method no longer attempts to add a deprecated forwarding method with a body, which is invalid in an interface. 34d935ebce
  • Wed, Apr 19
    XHP completion now closes the completed tag based on its children declaration: elements with children empty receive a self-closing tag, while elements that accept children receive matching open and close tags. af22df5d2b
  • Wed, Apr 19
    The Sodium extension now provides Ed25519 scalar reduction, scalar addition and multiplication, and clamped or unclamped base-point scalar multiplication. Bundled Hack declarations follow on April 26. 9c58ed7053
  • Fri, Apr 21
    Hover, type-at-position, and go-to-definition now recognize source-level invariant() calls instead of exposing the internal desugared invariant_violation() call. 466134e155
  • Sat, Apr 22
    Applications can call HH\set_endpoint_name(string) to give a request a more useful endpoint identity than its URL alone. The name is included in server status.json data. ddfe56dfa1

Future Changes

3 changes
  • Mon, Apr 17
    Package expressions are now executable: HackC lowers package foo to package_exists('foo'), matching the type refinements already performed for package conditions. 5d67079833
  • Tue, Apr 18
    The default Autoload.UserlandDisabledSampleRate is now 1, so deprecated HH\autoload_set_paths() use is recorded for every call while migration logging is enabled. 5a779620cd
  • Fri, Apr 21
    Open shape types now retain the type of unknown fields internally and may print it as shape('known' => int, _ => nonnull). Ordinary ... remains equivalent to unknown fields of type mixed; the richer form primarily supports sound-dynamic inference. a5993a5a69
