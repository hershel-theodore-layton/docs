Week 17: Apr 24–Apr 30, 2023

13 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

8 changes
  • Mon, Apr 24
    The misspelled runtime option Preg.BacktraceLimit has been corrected to Preg.BacktrackLimit. The old name remains a fallback during migration, so existing configuration continues to work until it can be updated. 7706006430
  • Wed, Apr 26
    The Ed25519 primitives added to the Sodium runtime on April 19 are now present in the bundled HHI, so Hack code can call them without local declarations. f977a1702b
  • Wed, Apr 26
    Standalone IDE diagnostics are now refreshed after closing a modified file, restoring squiggles for the version on disk instead of leaving diagnostics for discarded editor contents. e6bffdd440 9c48e841bb
  • Thu, Apr 27
    hh_single_type_check now accepts general .hhconfig overrides as --config key=value, for example --config timeout=4. ee8d8d5657
  • Thu, Apr 27
    Opening or closing an unchanged file in the IDE no longer cancels a running full check, and a check interrupted by an actual edit now resumes after five seconds even when the client consumes streaming errors. c99b489259 3f8a4ee77f
  • Sat, Apr 29
    New HH\stdin(), HH\stdout(), and HH\stderr() functions replace the magic STDIN, STDOUT, and STDERR constants. They return the corresponding resource and throw RuntimeException in server mode, where standard streams are unavailable. f89adc0d2b
  • Sat, Apr 29
    Standalone IDE diagnostics now refresh lazily on code-action requests, hide typing errors while a parse error is present to match hh, and remain visible when an in-progress full check restarts. 98c35d4bbb 276933c9b7 1e6f53b906
  • Sat, Apr 29
    Repository-authoritative builds with an active deployment now omit files belonging to packages outside that deployment. Builds fail with a clear error when the configured deployment is absent from PACKAGES.toml; files that define modules remain included. b170bd05fa

Future Changes

5 changes
  • Tue, Apr 25
    hackfmt now formats case-type variants, with a leading | selecting a consistently multiline layout. fb8003152a
  • Tue, Apr 25
    Calls to a <<__CrossPackage('foo')>> method now require package foo to be loaded at the call site. Declaration and inheritance support is still being completed. 2be16db0f1
  • Wed, Apr 26
    When checking T <: ~U, sound-dynamic diagnostics now prefer the concrete failure against U over the less useful outer like-type error. 57e3d1a324
  • Thu, Apr 27
    Explicitly typed nested dict and vec literals no longer acquire unnecessary like-types solely from their expected outer collection type. 2159d75c1a
  • Fri, Apr 28
    JSON type representations produced under implicit pessimisation now omit supportdyn, matching the simplified types already used in human-readable diagnostics. Tools consuming these JSON representations should expect the underlying type directly. 6facad56b7
