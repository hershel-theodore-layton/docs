Week 21: May 22–May 28, 2023

14 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

10 changes
  • Mon, May 22
    Switch-case mismatch and non-primitive-cast lints now account for like-types and use disjointness where appropriate, reducing false positives under implicit Sound Dynamic. ef2c773617 48551c1c0a
  • Tue, May 23
    During Sound Dynamic's additional body check, indexing a supportdyn<shape(...)> now yields dynamic rather than incorrectly returning the entire shape type. 00d5092267
  • Tue, May 23
    Enum-class labels are now accepted as parameters to memoized functions, and typedef expansion recognizes labels and enum-class members during the check. 00dcc616ac
  • Tue, May 23
    Impossible and redundant type-test lints now fire under implicit Sound Dynamic only when the ordinary and dynamic-assumption checks agree, suppressing migration-induced false positives. 923bd26f12
  • Tue, May 23
    Tuple and shape subtyping now reports errors for multiple incompatible elements or fields instead of dropping every failure after the first conjunction. b476fb30cf
  • Wed, May 24
    Implicit Sound Dynamic no longer adds a synthetic supportdyn<mixed> bound when a type parameter already has another upper bound. This prevents where-clause localization from silently introducing unconstrained types. 19ef1db2d8
  • Wed, May 24
    The global-access checker now recognizes memoized functions through supportdyn wrappers and handles like container types without losing object-reference information. 1a8aae3994 ea2318081c
  • Thu, May 25
    Sound Dynamic type-constant projection now ignores migration-only supportdyn<mixed> bounds that could otherwise produce an unconstrained type and accept invalid generic projections. cd61e02391
  • Thu, May 25
    Implicit pessimisation no longer emits “not dynamically callable” errors, which indicate an implementation issue rather than an actionable project error. Explicit opt-outs such as __NoAutoDynamic continue to receive the check. c32811a2e4
  • Sun, May 28
    hphp_debug_caller_info() now reports a closure's surrounding class as its context class, improving attribution for callbacks defined inside methods. c149736c35

Future Changes

3 changes
  • Mon, May 22
    The unstable module_level_traits feature is now understood by Hack. A public trait annotated <<__ModuleLevelTrait>> keeps its defining module for boundary checks, allowing it to expose controlled behavior that calls internal symbols from that module. 7b8b52235d
  • Thu, May 25
    Experimental package checking now rejects code in the default package when it accesses a public symbol from a non-default package that the default package does not include. 3a23391ec7
  • Fri, May 26
    Experimental case types now require conservatively disjoint runtime variants. Variants whose shallow runtime tags may overlap produce a type error; this initially includes all pairs of object types and overlapping primitive unions. ab1c79066d

Breaking Changes

1 change
  • Fri, May 26
    When deployment enforcement is enabled, HHVM now rejects direct, dynamic, function-pointer, and closure-mediated calls to top-level functions whose module is outside the active deployment. 9ad9cac167
