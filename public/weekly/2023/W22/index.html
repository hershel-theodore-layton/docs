Weekly digest

Week 22: May 29–Jun 4, 2023

12 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

5 changes
  • Tue, May 30
    When both ordinary and dynamic-aware checks of a Sound Dynamic function call fail, Hack now reports whichever branch produces fewer errors. This suppresses cascades of like-type mismatches in favor of the underlying application error. ba26aab5fd
  • Tue, May 30
    All IDE code actions are now resolved lazily after selection, reducing the work required to display the initial lightbulb menu. 07b43be5a5
  • Wed, May 31
    Built-in container factory functions now opt out of automatic pessimisation where their implementations guarantee the declared result, removing unnecessary like-types from returned containers. b24a872b62
  • Wed, May 31
    Hover no longer displays the implicit as mixed rendering of Sound Dynamic's synthetic as supportdyn<mixed> generic bound. d6f94a7cf1
  • Fri, Jun 2
    Nullable member-access errors now offer an “add null-safe get” action that changes same-line $value->member access to $value?->member. 9a7621ecd2

Future Changes

5 changes
  • Tue, May 30
    The experimental typed_local_variables feature introduces declarations such as let $value: int = 1;. This initial step parses and erases the annotation to an ordinary assignment; full assignment consistency and possible runtime enforcement are still future work. 489986a389
  • Thu, Jun 1
    Under implicit pessimisation, readonly array updates now look through readonly expressions before handling like-types. This fixes incorrect inferred types for readonly array operations. 6279fa521a
  • Thu, Jun 1
    The typed-local parser now correctly requires the declaration tokens instead of asserting that they are present, producing syntax errors rather than parser failures for malformed let $x: T = ... declarations. 553b4196ef
  • Fri, Jun 2
    The nested-Awaitable lint again recognizes Awaitable<~Awaitable<T>> under implicit pessimisation, so accidental double-awaitable returns are not hidden by the like-type wrapper. 979f436be9
  • Sat, Jun 3
    The unused hh_client --refactor-sound-dynamic mode has been removed. Sound-dynamic-aware behavior is now part of the ordinary refactoring paths; the corresponding single-file experimentation mode remains available. 1f137c6dce

Breaking Changes

2 changes
  • Wed, May 31
    The legacy hh --auto-complete command has been removed. Editor integrations and other consumers should use the IDE autocomplete service. 7ff9a5ae35
  • Fri, Jun 2
    Runtime type tests such as $value is dynamic are now rejected. HHVM cannot test whether an arbitrary value supports dynamic, so using the result to refine $value to dynamic created a type hole. Test for a concrete runtime type instead. 89bedcf12d
