Future Changes

4 changes
  • Tue, Jun 6
    Autocomplete now works with implicit sound dynamic enabled and hides internal supportdyn wrappers from displayed completion types. 3b4e68b142
  • Tue, Jun 6
    Implicit pessimisation now introduces supportdyn correctly within the expression being checked by is and as. fd26322eb2
  • Tue, Jun 6
    Pretty-printing of declaration types now elides supportdyn, matching ordinary type and error rendering under implicit pessimisation. 65d1f5236c
  • Wed, Jun 7
    Every unstable case-type variant must now be recoverable by a runtime type refinement. Variants that cannot be distinguished safely with is or as are rejected. 59206db165

Highlights

7 changes
  • Wed, Jun 7
    With deployment enforcement enabled, accessing a class, enum, or enum class outside the active deployment now throws DeploymentBoundaryViolationException. This covers class pointers, static calls, static properties, and class constants in addition to top-level functions. f86c18384b
  • Thu, Jun 8
    Autocomplete now uses both upper and lower bounds when solving unresolved type variables, avoiding the frequent and unhelpful inference of nothing for invariant and contravariant positions. 1a54df770e
  • Fri, Jun 9
    Projects may add a repository-root CUSTOM_ERRORS.json file whose pattern rules attach project-specific explanations to matching Hack errors. The configuration is loaded by hh_server, hh_single_type_check through --custom-error-config-path, and the standalone IDE diagnostic path. 4f14454979 bc7eeb8c69 5b96c02ea8 42214e464a
  • Fri, Jun 9
    A new “inline method” refactoring replaces a suitable method call with the method body and removes the method when safe. dcc03923cb
  • Fri, Jun 9
    Autocomplete returns snippets only when placeholders or edits require snippet semantics, reducing unwanted snippet-mode behavior for ordinary completions. 741b3123bf
  • Fri, Jun 9
    Standalone IDE diagnostics no longer build up a backlog while typing in large files; obsolete intermediate TAST computations are discarded so squiggles jump to the latest edit. cad5047300
  • Fri, Jun 9
    Moving a module between packages is now treated as a major incremental change, ensuring all affected dependents are rechecked. ace5a949c7
