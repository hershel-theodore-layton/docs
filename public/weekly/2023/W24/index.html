Week 24: Jun 12–Jun 18, 2023

22 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

15 changes
  • Mon, Jun 12
    The IDE now offers “Extract interface” on suitable classes, creating an interface from selected methods and updating the class to implement it. 80613d1a06 a0fab0a144
  • Mon, Jun 12
    Autocomplete no longer eagerly solves unconstrained type variables to nothing, preserving useful candidates when only upper-bound information is available. 130ca5f9f4
  • Mon, Jun 12
    Shape-indexing diagnostics now mention ?? alongside Shapes::idx() when a default value is appropriate for both a missing field and null. 5f1622b165
  • Tue, Jun 13
    Direct-declaration parsing now distinguishes string literals, concatenated strings, integers, enum-class labels, and class names in user-attribute arguments instead of treating every argument as a class name. Facts extraction stores integer and string parameters accordingly. ec223aad37 b2d2424b33
  • Tue, Jun 13
    hh_client --xhp-autocomplete-snippet <component> returns the completion snippet for a named XHP component, including required attributes and tag structure. dfacbc5c7f
  • Wed, Jun 14
    The Hack status-bar hover now includes the repository root, clarifying which LSP instance is reporting status when several projects are open. 1c740a1b2e
  • Wed, Jun 14
    Standalone IDE diagnostics appear as soon as the naming table finishes loading, without waiting for a cursor movement or a close-and-reopen cycle. 74f001e588
  • Wed, Jun 14
    “Extract into variable” and “Extract into method” now start an inline rename session for generated placeholder names. 4ff676cf1f
  • Thu, Jun 15
    Hack now supports type-hierarchy queries through hh_single_type_check --get-type-hierarchy-at-caret and the LSP document/typeHierarchy request. Results include ancestor locations and kinds plus class-member locations and compact signatures. bf06859987 3a8d25f0ba 70d770d24f 797c00dffd a0381200bd ae7e69f6c0
  • Thu, Jun 15
    For new $class(...) where $class has type classname<T>, inference now applies the T constraint before checking constructor arguments, producing more precise argument checking and errors. b9dea446ba
  • Fri, Jun 16
    Filesystem errors encountered while reading package or custom-error configuration are now reported rather than silently ignored. 73a7fc0d89
  • Fri, Jun 16
    Rename, find-references, and go-to-implementation requests served through an hh shell-out now return errors reliably and honor LSP cancellation. Starting a newer shell-out cancels the displaced request instead of leaving it pending. e04a247731 7aaf84b16c 6c5ce3afca
  • Fri, Jun 16
    A client/server version mismatch no longer makes the client forcibly restart hh_server; the monitor handles the mismatch and termination flow. 1c24979190
  • Sun, Jun 18
    Multi-file rename no longer generates duplicate deprecated forwarding-method edits when several references lead back to the same declaration. 75d1f9fdd6
  • Sun, Jun 18
    Distributed typechecking no longer requires a custom-error configuration file when the project does not use custom errors, matching ordinary hh behavior. 901f98bb74

Future Changes

7 changes
  • Mon, Jun 12
    Typed local variables now have initial typechecking support. A declaration such as let $x: arraykey = 1 constrains every subsequent assignment to $x, while flow-sensitive inference may still refine its current type more narrowly. The syntax remains gated by typed_local_variables. 713305f6b3
  • Tue, Jun 13
    Preview readonly modifiers are now included in indexed symbol signatures, improving generated API and code-browser displays. 9021b813aa
  • Wed, Jun 14
    Typed-local bounds now survive control-flow joins and loops, including paths where the local is not yet defined. Assignments that violate the declared bound can no longer escape checking through a branch or repeated loop iteration. 8d691fdb02 d7caa7030f
  • Thu, Jun 15
    Module-level traits have advanced from unstable to preview status for broader experimentation. a01a8cb54e
  • Fri, Jun 16
    hackfmt now formats typed locals as let $x: T = expression;, with appropriate line breaking for long types or initializers. 147008b7f1
  • Fri, Jun 16
    When typed-local syntax is enabled for a file, the IDE offers “Add local type hint” on assignments and names the target variable in the action. It is not offered in files without the feature opt-in. 4c3ab66c12 d80d3f81c9 7987bfc07d
  • Fri, Jun 16
    Sound-dynamic array updates hidden by a FIXME now preserve supportdyn on the value type instead of widening the array to mixed. fb963301e2
