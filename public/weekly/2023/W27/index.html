Week 27: Jul 3–Jul 9, 2023

11 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

10 changes
  • Tue, Jul 4
    The “extract interface” code action no longer copies an invalid async modifier onto the extracted interface method. 0610faf806
  • Tue, Jul 4
    “Extract into method” now handles a selection whose first line is a comment without generating syntactically invalid Hack. 6b3d7678c0
  • Wed, Jul 5
    The IDE’s “Extract shape type” action now works on shape type hints as well as shape expressions. Its generated alias starts with T, and the placeholder name is selected for immediate renaming. 77d0d73508 5c1517fe0a
  • Wed, Jul 5
    Many HSL array, dictionary, keyset, and vector helpers now opt out of automatic like-type insertion under sound dynamic, preserving more precise declared return types. 7d39d37d93 2cae1c79ff f0b48d9069
  • Wed, Jul 5
    Sound-dynamic typing now preserves a supportdyn element constraint when widening an array-like lower bound to typecheck indexed access. This avoids spurious failures where the widened element type previously collapsed to mixed. 640749cbd4
  • Thu, Jul 6
    Type inference now recognizes equivalent nullable bounds of the form null, T <: #x <: ?T, improving solutions for otherwise underconstrained type variables. 4e824a897a
  • Thu, Jul 6
    Under implicit sound-dynamic pessimization, <<__NoAutoLikes>> suppresses only inserted like types. Generic parameters still receive a supportdyn<mixed> bound unless that parameter also has <<__NoAutoBound>>. 98b6c9f178
  • Fri, Jul 7
    Invalid cycles through trait require class or require implements clauses now produce ordinary diagnostics without overflowing the typechecker’s stack. dc3b6cfafb
  • Fri, Jul 7
    The IDE now returns the LSP ContentModified error when a requested code action can no longer be resolved, rather than crashing the language server. “Extract shape type” also survives an internal candidate invariant violation and continues serving later requests. a1344f26cb 5c55e0af6f
  • Fri, Jul 7
    “Extract into method” is now offered for the expression body of a lambda such as () ==> 3 + 3. f5a7a56c92

Future Changes

1 change
  • Thu, Jul 6
    The experimental typed-local syntax now permits declarations without an initializer, such as let $x: int;. Reading the local before a later assignment remains an error. 87d5938fe6
