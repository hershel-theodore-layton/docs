Week 28: Jul 10–Jul 16, 2023

12 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

5 changes
  • Mon, Jul 10
    “Extract into method” once again formats the generated method body at the correct indentation after inserting its editor rename placeholder. 07ad225ee4
  • Tue, Jul 11
    Command-line symbol renaming no longer applies a replacement twice—for example, renaming Foo to Bar now produces Bar, not BarBar. 29daa1ba32
  • Tue, Jul 11
    Another group of HSL functions now uses <<__NoAutoLikes>>, keeping precise types under implicit sound-dynamic pessimization. Higher-order helpers remain excluded while lambda inference is being improved. 722cd52156
  • Thu, Jul 13
    _ may now request inference in nested explicit type arguments, as in foo<vec<_>>(). It is still rejected anywhere beneath a type parameter declared <<__Explicit>>. e1811dd241
  • Fri, Jul 14
    “Extract shape type” is now offered only when a shape expression is selected, avoiding an IDE invariant failure for selections that merely contain a shape. ce1676dece

Breaking Changes

4 changes
  • Tue, Jul 11
    The STDIN, STDOUT, and STDERR pseudo-constants have been removed from Hack’s bundled declarations. Replace them with HH\stdin(), HH\stdout(), and HH\stderr() (or their try_ variants). d615f24ec4
  • Wed, Jul 12
    Hack’s language server now always runs in standalone IDE mode. The old modes that delegated IDE operations or diagnostics to a persistent hh_server can no longer be selected through local configuration. 24039fc87d
  • Fri, Jul 14
    hh --json now writes JSON to standard output by default. Scripts that previously read the JSON stream from standard error should update their redirection. 647e96e836
  • Fri, Jul 14
    HHVM has removed the STDIN, STDOUT, and STDERR pseudo-constants at runtime, completing the declaration removal from July 11. Use HH\stdin(), HH\stdout(), and HH\stderr() instead. b34346b202

Future Changes

3 changes
  • Tue, Jul 11
    A case type may no longer be the base type of an enum or enum class. This is rejected until case-type enforcement in those positions has consistent runtime semantics. c8befa3337
  • Thu, Jul 13
    A generic name used illegally in a trait’s require class clause now yields a normal type error instead of raising an exception in the typechecker. 58855f8577
  • Fri, Jul 14
    Experimental typed locals now enforce their declared types and diagnose redeclaration, shadowing, and incompatible control-flow joins. Typed-local declarations are also supported inside concurrent blocks; coverage for further statement and lambda forms continues in later commits. 9055f3104c 28e003b54b
