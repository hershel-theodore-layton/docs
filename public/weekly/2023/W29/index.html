Week 29: Jul 17–Jul 23, 2023

15 noteworthy changes, organized by the source changelog sections.

DayWeekMonth

Highlights

10 changes
  • Mon, Jul 17
    Type displays now consistently render a union of dynamic | T as the like type ~T, even when sound dynamic is not enabled. This affects diagnostics, hover text, typed-AST output, and other pretty-printed types. 1919727869
  • Mon, Jul 17
    When multiple package module globs match, HHVM now assigns the module to the package with the longest, most-specific prefix, matching the typechecker’s interpretation. 79819e903f
  • Tue, Jul 18
    Under sound-dynamic pessimization, HH\FIXME\UNSAFE_CAST<Tin, Tout>() is now checked through its declared HHI signature: both source and destination must support dynamic, and the result receives the expected pessimised type. 943dbbf32a
  • Tue, Jul 18
    Standalone IDE mode now loads PACKAGES.toml, so package-access diagnostics stay in sync with a full hh_server typecheck. fbcf2bfbe3
  • Wed, Jul 19
    Autocomplete now follows chained method calls through supportdyn and like types more reliably, restoring member suggestions under implicit sound-dynamic pessimization. 7eda8da7c3
  • Wed, Jul 19
    HH\get_headers_secure() now declares the precise [read_globals] capability instead of implicit [defaults], allowing calls from contexts that grant global reads without granting every default capability. 8e93d5e2a8
  • Wed, Jul 19
    The Facts API adds HH\Facts\files_with_attribute_and_any_value(), returning files whose file attribute has a requested value. Query values support booleans, integers, strings, dicts, vecs, and keysets; unsupported values are coerced to null. 7935244238
  • Thu, Jul 20
    HH\parse_cookies() parses a raw Cookie header into the same nested dict/vec shape used by $_COOKIE, without mutating request globals. ad7a65180a
  • Thu, Jul 20
    The splat operator may now contain await directly, enabling calls such as f(...await $args). b62d8f788f
  • Fri, Jul 21
    hh_single_complete --root ... --naming-table ... now resolves names from its naming-table fallback correctly instead of producing bogus ==> parse errors for affected completions. 99f9df3a97

Future Changes

4 changes
  • Mon, Jul 17
    Experimental typed locals are now tracked correctly inside arrow lambdas and PHP-style closures with explicit use captures. f13f87d992 2f410f33e0
  • Tue, Jul 18
    HackC now understands wildcard types in lambda parameter and return hints and treats _ itself as unenforced at runtime while retaining the surrounding type check. The typechecker still rejects explicit lambda wildcards at this point; this is groundwork for later accepting forms such as (vec<_> $x) ==> .... 54356672cb
  • Wed, Jul 19
    Intersections now expose and filter case-type variants when the other constraints identify a concrete data type. Refinements such as CT & vec<mixed> and negative is branches can therefore simplify to a usable surviving variant. ac30c4d792
  • Thu, Jul 20
    Experimental typed locals now flow correctly through try/catch/finally, switch, and foreach statements. 230741a3e2 c5781f6f1b

Breaking Changes

1 change
  • Fri, Jul 21
    The obsolete mbstring.http_input and mbstring.http_output INI settings have been removed. Deployment configurations that still set them should delete those entries. 6a26df2499
