Week 31: Jul 31–Aug 6, 2023

14 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

7 changes
  • Mon, Jul 31
    The JSON representation of a Hack User_error now includes rendered custom diagnostic text in a custom_messages array, making it available to typed-AST and error-processing tools. d8c1defb73
  • Mon, Jul 31
    <<__CrossPackage("package")>> now loads the requested package while typechecking methods as well as top-level functions, so permitted cross-package calls from attributed methods no longer fail spuriously. 21c294919f
  • Tue, Aug 1
    Under Sound Dynamic, hovering a method call through a like-typed receiver now shows the method's ordinary signature instead of rendering the whole callable as a like type. bdfd6dc2e9
  • Tue, Aug 1
    Exhaustivity checking now recognizes pessimised enum types of the form bound & ~E, restoring missing non-exhaustive-switch diagnostics. 21348ec543
  • Tue, Aug 1
    Refactoring code actions now honor the client's snippet-edit capability. Clients without it receive ordinary placeholder names such as method0, rather than literal snippet syntax such as ${0:method0}. 0041ad042d
  • Fri, Aug 4
    A lone yield break now makes an async function an AsyncGenerator in the typechecker, matching the runtime's existing behavior. 1abdce88b8
  • Sat, Aug 5
    ASIO dependency-cycle exceptions discovered while advancing await all or concurrent work now reconstruct the relevant async stack instead of reporting a scheduler-truncated trace. f03de9132a

Future Changes

4 changes
  • Mon, Jul 31
    Experimental typed-local enforcement now covers assignments with nontrivial left-hand sides and compound operators such as +=. 68bc5f2e54 cda0c7ba09
  • Tue, Aug 1
    Experimental typed-local enforcement now treats tuple indexing like shape indexing when checking assignments such as $x[$i] = $value. 9fa6b85eea
  • Tue, Aug 1
    Parser lowering gained an AAST representation for the in-development match statement. 97f0efe6e5
  • Thu, Aug 3
    Experimental expression-tree lowering no longer forms cycles between freshly synthesized generic parameters, preventing stack overflows when a lambda's inferred generic escapes. 1a94612ae3

Security

1 change
  • Tue, Aug 1
    Malformed Thrift payloads can no longer crash the decoder by declaring an excessive collection capacity; large collections are now reserved incrementally. 3deb3191e0

Breaking Changes

2 changes
  • Wed, Aug 2
    hh_single_type_check now enables Sound Dynamic by default, making --enable-sound-dynamic-type redundant and potentially changing diagnostics and inferred types in scripts that invoke the standalone checker. d10f4599f1
  • Wed, Aug 2
    debug_backtrace() no longer includes $this unless Eval.EnableArgsInBacktraces is enabled. c6d7874d35
