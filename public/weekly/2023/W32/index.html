Week 32: Aug 7–Aug 13, 2023

14 noteworthy changes, organized by the source changelog sections.

Security

1 change
  • Mon, Aug 7
    Pagelet-server callers can now detect or reject the unsafe legacy "Header: value" array form and collisions with keyed headers. Eval.PageletServerHeaderCheck controls warnings or rejection of the legacy form, while Eval.PageletServerHeaderCollide controls collision warnings, precedence, or rejection. 724d62be19

Breaking Changes

5 changes
  • Mon, Aug 7
    hh_single_type_check no longer accepts the obsolete --like-casts and --simple-pessimize options; targeted explicit pessimisation continues to use the like_casts configuration. ae834842e3
  • Mon, Aug 7
    hh --ide-find-refs-by-symbol now always emits JSON, and the human-readable hh_single_type_check --find-refs format now includes the matching symbol text. Tools parsing either command's old output need updating. da6d7dba16 b24518524c
  • Thu, Aug 10
    HHVM has removed the auto_prepend_file and auto_append_file INI settings. Entrypoint setup and teardown must be explicit. b182e8f63c
  • Thu, Aug 10
    The variables_order and request_order settings have been removed; superglobal population order is now fixed. e258daf596
  • Thu, Aug 10
    The unused arg_separator.input setting and configurable arg_separator.output setting have been removed. APIs that used the output default now hard-code & unless a separator is supplied directly. e4ffa04d48

Highlights

7 changes
  • Wed, Aug 9
    Bidirectional inference now uses the upper bound of an expected type variable when typing lambdas. Generic helpers such as makeSingle($x ==> $x->foo()) can therefore infer the lambda parameter from the surrounding expected type. 6cb17946fa
  • Wed, Aug 9
    Typechecking very large argument lists and vec literals no longer overflows the typechecker's stack. 265db40acd
  • Wed, Aug 9
    Targeted explicit pessimisation now honors <<__NoAutoLikes>> on return types, function types, and inout parameters. 5bc783525a
  • Thu, Aug 10
    Symbol-info indexes now include inherited class, interface, and trait members by default, improving the accuracy of tools that consume Hack's symbol index. The behavior can be gated with symbol_write_index_inherited_members. c4ad5562ac
  • Fri, Aug 11
    A direct-declaration parsing bug no longer lets <<__NoAutoLikes>> on one method leak into methods declared after it. 045457670e
  • Fri, Aug 11
    Sound Dynamic subtype checking now pushes like types through nested invariant type arguments in both directions, admitting relations such as Map<string, Vector<~C>> <: ~Map<string, Vector<C>>. 5919987cd9
  • Fri, Aug 11
    Soft package-deployment violation warnings can now be sampled with Eval.DeploymentViolationWarningSampleRate, reducing log volume during migrations. 38b77e9ac5

Future Changes

1 change
  • Wed, Aug 9
    require class has entered an ungated rollout and can now be used without a per-file unstable-feature opt-in, but it remains pre-stable. ad27a74ee0
