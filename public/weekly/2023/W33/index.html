Week 33: Aug 14–Aug 20, 2023

12 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

10 changes
  • Mon, Aug 14
    Sound Dynamic no longer adds an unnecessary outer like type to Vector methods whose collection-shaped result is already enforced by HHVM. Operations such as toSet() now retain their declared container type more precisely. 995317f216
  • Tue, Aug 15
    hh_single_type_check --map-reduce can now run configured typed-AST analyses and print their reduced JSON result. 0ffd752fc9
  • Tue, Aug 15
    The new hphp_debug_caller_identifier()[leak_safe]: string runtime helper returns the caller's full function or Class::method name without constructing the full hphp_debug_caller_info() dictionary. dfc3cbbaa0
  • Tue, Aug 15
    Package module patterns now use prefix-glob semantics matching the runtime: foo.* matches descendants of foo, * matches every module, and other patterns are exact names. 3ef62b5f28
  • Wed, Aug 16
    The new type-counter map reducer can audit a codebase for like, non-like, mixed, supportdyn<mixed>, dynamic, and Tany occurrences. It is available through hh_single_type_check --map-reduce --hh-log-level type_counter 1. da3b61a80b f0315270fc 2e8a805e77
  • Wed, Aug 16
    Find-references requests can now stream partial results through LSP $/progress when the client supplies a partial-result token, allowing editors to show references before the full server search finishes. e0a82f5c6c 8f8b4bb55a
  • Fri, Aug 18
    C\contains() now performs constant-time membership checks for Set and ImmSet, matching its existing fast path for keyset. 85252099f6
  • Fri, Aug 18
    Hack's bundled declarations now expose HH\parse_cookies(string)[defaults]: dict<arraykey, mixed>, allowing existing runtime calls to typecheck. ead349e711
  • Sat, Aug 19
    The VS debugger now checks breakpoints around JIT translations and can step from a throw into its matching catch, avoiding missed stops in optimized code. 31ece450ee 5ff8a7a3ce
  • Sat, Aug 19
    hphp_debugger_set_option('disableJit', false) can now re-enable the JIT for an attached debugger, even when Eval.JitDisabledByVSDebug normally disables it. 538ea114cd

Breaking Changes

1 change
  • Mon, Aug 14
    HHVM has removed support for dynamically loaded native extensions, including the -z path and the extension_dir, extensions, DynamicExtensionPath, and DynamicExtensions settings. Extensions must be linked into the HHVM build. 71e6b01ff5

Security

1 change
  • Tue, Aug 15
    Eval.SetHeadersInServerSuperGlobal can now prevent request headers from being copied into $_SERVER; applications can retrieve the raw protected header map with HH\get_headers_secure() instead. The compatibility default remains enabled. d3b6066fb8
