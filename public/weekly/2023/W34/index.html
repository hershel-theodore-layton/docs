Future Changes

2 changes
  • Mon, Aug 21
    During the ongoing module rollout, files without an explicit module declaration are now assigned to the internal default module for runtime module and package enforcement. Reflection continues to return null for their module, but boundary errors describe callers as being in the default module rather than outside all modules. 0977c6dffc
  • Mon, Aug 21
    Experimental case types no longer require every variant to be recoverable. Overlap validation instead compares each pair's runtime data types and reports the two conflicting variants directly. ab94cdfad7 808d14a22d

Highlights

3 changes
  • Tue, Aug 22
    Hack's bundled declarations now expose HH\get_headers_secure()[read_globals]: dict<string, vec<string>>, allowing applications to typecheck use of the runtime's protected request-header API. ea174a9577
  • Thu, Aug 24
    Hack's bundled Facts declarations now include HH\Facts\files_with_attribute_and_any_value(), which finds files by file-attribute class and value when Facts is enabled. cb4f2f43de
  • Sat, Aug 26
    Compact Thrift deserialization no longer corrupts dict keys or values of wire type I08 by incorrectly applying zigzag decoding. 373966e7ab
