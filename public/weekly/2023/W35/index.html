Week 35: Aug 28–Sep 3, 2023

12 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

6 changes
  • Wed, Aug 30
    Sound Dynamic function-call checking now retries all parameters against their pessimised types when a mixed static/dynamic pass fails. Calls that require the dynamic interpretation from the first argument are no longer rejected spuriously, and their result remains like-typed. c613d98c5c
  • Wed, Aug 30
    Package checking now treats a missing module membership as the default module when matching package globs, aligning the typechecker with HHVM's runtime enforcement. 8db8b6b349
  • Thu, Aug 31
    Sound Dynamic no longer unnecessarily pessimises $shape['field'] ?? $default; the null-coalesced result keeps the precise union of the field and default types. 3c10902b53
  • Thu, Aug 31
    Streaming find-references now flushes all remaining results after the server search completes and reliably includes references from IDE-open files. Temporary result files have also moved out of the project root into the server's temporary directory. 9463755411 2df5c0ee10 44a3b226d4
  • Fri, Sep 1
    Sound Dynamic joins now simplify unions and intersections through supportdyn wrappers, avoiding unnecessarily large or imprecise inferred unions after control-flow joins. 55f4a9ddff
  • Fri, Sep 1
    Soft-package class access no longer emits a duplicate deployment-boundary warning while resolving the class. 497854503a

Security

1 change
  • Thu, Aug 31
    Eval.DisableParsedCookies can now stop parsing cookies into $_COOKIE and $_REQUEST, and removes the $_COOKIE superglobal entirely when enabled. Raw headers remain available for application-controlled parsing. The compatibility default remains disabled. 3b831a6deb

Future Changes

3 changes
  • Thu, Aug 31
    HackC no longer panics when lowering ??= through a readonly access path while readonly remains a Preview feature. f17676df4b
  • Thu, Aug 31
    Like-type pushing now composes through pre-stable case types, admitting relationships such as vec<~string> <: ~CTVec<string> when CTVec<T> wraps vec<T>. 3878bd424d
  • Thu, Aug 31
    The unstable pipe_await feature now permits await directly on the right-hand side of |>. 9422600fb2

Breaking Changes

2 changes
  • Fri, Sep 1
    Sound Dynamic has backed out the all-dynamic fallback for calls through supportdyn function types. Calls that only typechecked after pessimising every parameter may now report argument errors. 349eca7fa1
  • Fri, Sep 1
    A property whose alias or newtype resolves to nothing is now rejected at class initialization with an invalid-property-type fatal, rather than slipping through runtime resolution. 57141c389a
