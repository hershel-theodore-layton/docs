Week 36: Sep 4–Sep 10, 2023

20 noteworthy changes, organized by the source changelog sections.

Highlights

9 changes
  • Mon, Sep 4
    Enum-switch exhaustivity checking now recognizes pessimised enum types regardless of whether the enum bound appears before or after its like type in an intersection. This restores missing-case errors after awaiting an enum value and avoids treating intersections of unrelated enums as ordinary enum bounds. d755a2e87b
  • Tue, Sep 5
    Trait-diamond errors now suggest adding <<__EnableMethodTraitDiamond>> when that attribute is the intended migration. ce9619696c
  • Wed, Sep 6
    Projects can opt in to rejecting direct superglobal variables such as $_SERVER with disallow_direct_superglobals_refs=true; diagnostics direct callers to the corresponding HH\global_* APIs. The compatibility default remains disabled. 40a5ae7da0 491c65d3bf
  • Wed, Sep 6
    Package metadata now reaches hh_distc, and typechecker glob matching treats foo.* as matching both foo and its descendants while preferring the most specific exact match. 93d7c2a891 2933cd2759
  • Thu, Sep 7
    Repo-authoritative deployments now include soft packages so accesses can emit deployment-boundary warnings and continue, rather than failing with an undefined function or class. 1171062eb4
  • Thu, Sep 7
    Class expressions used as attribute arguments no longer trigger internal or cross-package visibility errors. This permits patterns such as sealing a trait to an internal class because the stored attribute value is only a class-name string. 1d2b48aecd
  • Thu, Sep 7
    The HHI declarations for HH\get_headers_secure() and HH\parse_cookies() no longer carry __PHPStdLib, restoring their intended treatment by Hack tooling. Their capability lists remain [read_globals] and [], respectively. d5ad640290 12d45c23a5
  • Fri, Sep 8
    Reified-generic checking now preserves the most informative type arguments across union receivers and looks through like-typed function signatures. This removes false missing-type-argument errors while restoring real errors for omitted reified arguments. c3045c650d ed0a6efdfd
  • Fri, Sep 8
    Implicit lazy-class-to-string notices for argument type hints now identify which argument and function triggered the conversion. e912bbb1e0

Future Changes

8 changes
  • Mon, Sep 4
    Work begins on an opt-in strict-switch checker. Its first stage requires default for open-ended types and rejects a redundant default when the scrutinee has no possible values; broader literal and enum coverage is still being built. ece08a97a1
  • Tue, Sep 5
    Experimental case types can now prove more class alternatives disjoint: unrelated classes and final classes may coexist, while ordinary interfaces remain potentially overlapping unless sealing information proves otherwise. 7c71509fa9 f87781d600 dc99216021 69ff482b75
  • Wed, Sep 6
    Opt-in strict switches now reject impossible case values and redundant defaults for nothing/noreturn scrutinees. 7497648c8c
  • Wed, Sep 6
    Experimental case-type overlap checking now uses require extends constraints on interfaces and traits to reason about their possible implementations. 21693db81f
  • Thu, Sep 7
    Opt-in strict switches now model null, nullable, nonnull, and negative types, diagnosing missing or repeated case null arms. 87922666c4
  • Thu, Sep 7
    Parser-schema and hackfmt groundwork lands for a future nameof C expression, but the typechecker still rejects the syntax at this stage. 55c68773cc
  • Fri, Sep 8
    Opt-in strict switches now understand boolean scrutinees and can require both true and false arms. 1e3bf333a0
  • Fri, Sep 8
    Runtime groundwork for case types now represents primitive and object unions in type constraints, supports properties in repo mode, and keeps property overrides nominal. Case types are still an opt-in language feature at this point. 32169a9ad6 a18b5577b7 808fb25912 ee67a83704

Breaking Changes

3 changes
  • Wed, Sep 6
    hh --search has been removed. IDE autocomplete and search no longer depend on hh_server's former SQLite symbol index. edd2b799c5
  • Wed, Sep 6
    The typechecker now supplies the built-in default module through HHI. Projects must not declare new module default {} themselves; package diagnostics can now point to this built-in declaration. be4229a0c4
  • Fri, Sep 8
    Enum-class labels now use a native runtime datatype by default instead of opaque resources. Dumps identify enum class label (#Name), equality compares label names, and relational comparisons throw InvalidOperationException; code that inspected labels as resources must migrate. d044eba3a1 353425f238 ab69809ede
