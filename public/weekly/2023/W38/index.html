Week 38: Sep 18–Sep 24, 2023

14 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

8 changes
  • Mon, Sep 18
    Corrected repo-authoritative support for soft deployments has relanded. Soft-package functions, classes, methods, and constants remain in the repo and emit boundary warnings rather than collapsing into undefined-symbol failures. d786fbef34
  • Mon, Sep 18
    hh_single_complete --resolve now exposes completion signatures, making the IDE's resolved completion data available to command-line tests and tooling. 8a7ff6c02c cc442823ec
  • Tue, Sep 19
    The IDE's “Inline method” refactor now emits a valid $res temporary for returned values instead of the invalid bare identifier res. 2e1dbf6572
  • Tue, Sep 19
    hh --rewrite-declarations can rename repeated declarations for notebook-style Hack input; the functionality has moved from a separately deployed binary into the standard client. 8e60519cb2
  • Wed, Sep 20
    Hack's HHI hover text and manual now explicitly deprecate collection classes in favor of Hack arrays: prefer vec to Vector, dict to Map, keyset to Set, and tuples to Pair. 0fbfe6867e
  • Wed, Sep 20
    Compiler-generated temporaries now have explicit block scope and are unset on both normal and exceptional exits. This also restores readonly checking for top-level await expressions inside concurrent blocks. 19d2d8a7af
  • Thu, Sep 21
    Runtime type-structure cache keys now include typevar_types, so distinct reified instantiations such as NT<int> and NT<float> no longer collide during resolution. 2784c2004f
  • Fri, Sep 22
    Errors for inaccessible or invalid attribute classes now point to the attribute use site, rather than manufacturing a source position from the attribute class declaration. 0a9d3a9db6

Breaking Changes

3 changes
  • Mon, Sep 18
    A source file may now contain at most one new module declaration. Projects that collected several module definitions into one file must split them into standalone files. 21f428203b
  • Tue, Sep 19
    hh_single_type_check --custom-hhi-path now requires --no-builtins, preventing concurrent invocations from truncating generated builtin files in the shared custom directory. 27e9b0384d
  • Fri, Sep 22
    Abstract methods and type constants inherited from traits no longer silently override concrete inherited members. The typechecker now reports the invalid redeclaration while preserving the correct primary source position. eb118e9546

Future Changes

3 changes
  • Tue, Sep 19
    Strict-switch checking is now an explicitly unstable, per-function feature: opt in with <<file:__EnableUnstableFeatures('strict_switch')>>, then apply <<__StrictSwitch>> to a function or method. The old project-wide enable_strict_switch option is removed. String literals and string-valued class constants are also supported. dd6849b13b e172d60f7c 02bd9d5a82
  • Thu, Sep 21
    The unstable pipe_await lowering now uses properly scoped compiler temporaries for await on the right side of |>, preventing generated locals from leaking across the transformed statement. f908a5e42b
  • Thu, Sep 21
    Under implicit pessimisation, experimental case types are now correctly rejected as enum and enum-class base types instead of being hidden behind a like type. 38d5661170
