Week 39: Sep 25–Oct 1, 2023

13 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

9 changes
  • Mon, Sep 25
    HackC no longer constant-folds T::class when T is a reified generic; the emitted code resolves the runtime class supplied for T. 8068a8e3a6
  • Mon, Sep 25
    “Extract into method” now prints the real return type instead of _, including large and currently non-denotable types such as unions. “Add local type hint” likewise stops inserting type-printer fuel messages or truncated types into source. d37dcf933e f2bc2b88cb
  • Tue, Sep 26
    The typechecker and typed AST now retain concurrent blocks instead of first lowering them to generated awaitall code. This improves source positions and typed-local checks, and fixes “Extract into method” omitting async and Awaitable from methods extracted from a concurrent block. aef6da73ca
  • Wed, Sep 27
    The VS Code debugger now steps through async functions correctly with the JIT enabled, including stepping into and out of resumed async frames. 76c6770340
  • Thu, Sep 28
    preg_get_error_message_if_invalid(string $pattern): ?string is now available to typechecked Hack. It returns null for a valid regex or an error message for an invalid one without emitting malformed-pattern warnings. ed5c1a754e
  • Thu, Sep 28
    hh --find-refs now accepts Kind|Symbol, covering methods, properties, class constants, type constants, functions, classes, explicit classes, and global constants. ExplicitClass excludes references through self, static, and parent. 7beb2f1aa9
  • Fri, Sep 29
    IDE find-references requests can now be cancelled and immediately retried without leaving a stale shellout, and completion of the search reliably flushes its final streamed results. 6772812664 cbab9e45ea
  • Fri, Sep 29
    Invalid conversions of reified function pointers, reified class-method pointers, and enum-class labels now throw catchable InvalidOperationExceptions instead of terminating with an uncatchable fatal. Error text also uses Hack names such as “function,” “class method,” and “float.” fcca69ea4f
  • Fri, Sep 29
    ReflectionMethod::getCanonicalMethod() and getCanonicalClassname() can locate the trait that actually defines an inherited method in non-repo mode. They throw in repo-authoritative mode, where traits have already been flattened. 45c1f1f8e9

Future Changes

4 changes
  • Tue, Sep 26
    Unstable strict switches now classify arraykey-typed class constants as both possible integer and string cases, improving wrong-type and duplicate-case diagnostics. 39494259ec
  • Wed, Sep 27
    Case-type runtime checks now handle classname-to-string conversion warnings in the JIT instead of reaching an unimplemented path. 234bc7e5a5
  • Wed, Sep 27
    Case-type analysis now detects cycles through generic bounds, newtypes, sealed lists, requirements, and nested case types, making conservative approximations instead of looping or overflowing the typechecker stack. c49207358d
  • Fri, Sep 29
    Case types have moved from Unstable to Preview. They still require the case_types file-level opt-in, but Preview status permits opted-in code to run in production now that runtime enforcement is enabled. 942f1c5a74
