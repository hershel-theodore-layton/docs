Week 40: Oct 2–Oct 8, 2023

12 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

8 changes
  • Tue, Oct 3
    The Hash extension now supports CRC-32C through hash('crc32c', ...) and the corresponding incremental hashing APIs. a0bc5f5044
  • Wed, Oct 4
    HHVM can now serialize enum-class labels for memoization and use them as memo-table keys. The typechecker still rejects these parameters until its matching update on October 18. c1e438cad1
  • Wed, Oct 4
    The debugger no longer resolves unrelated source and function breakpoints while loading units, functions, or classes, avoiding spurious breakpoint binding. cc5e336780
  • Thu, Oct 5
    New HH\classname_to_class() and HH\class_to_classname() helpers make the runtime representation changes between class names and class pointers explicit. classname_to_class() throws when the class cannot be loaded and emits a sampled notice when the target lacks the newly recognized <<__DynamicallyReferenced>> class attribute. 2b2d440a35 336f743c58
  • Thu, Oct 5
    Invalid debugger-style statements such as =$x + 1; now carry a quick-fix that converts the expression to var_dump($x + 1). A range-calculation fix also makes the new and existing quick-fixes appear for the correct IDE selection. 046af76074 5cd5c75667
  • Fri, Oct 6
    The IDE now offers an “Add doc comment” code action for supported declarations and correctly removes snippet placeholders before applying it. 488659d456 9b971b643e
  • Fri, Oct 6
    A statement beginning with debugger-only = syntax now receives a specific parse error instead of a generic unexpected-token error. ba6ea045cb
  • Fri, Oct 6
    Repository-authoritative deployment checks now consistently treat soft-deployed packages as outside the active hard deployment. 70a70f01be

Future Changes

4 changes
  • Wed, Oct 4
    Experimental case types now preserve generic arguments when evaluating reified is checks and retain their nominal identity even when they contain a single variant. 580badd121
  • Thu, Oct 5
    The annotation-gated strict-switch checker now understands enum classes and dynamic. Enum-class arms are checked against the HH\MemberOf interface, while a bare dynamic subject requires default and rejects other arms. fe2334dfcf 5751ee4de9
  • Thu, Oct 5
    Code generation now recognizes the experimental class<T> type syntax; typechecker support follows later in the month. e8a4af259d
  • Fri, Oct 6
    The experimental nameof expression is now typechecked and compiled, including resolution of self, parent, static, and reified class names without relying on an implicit class-to-string conversion. 579290639c
