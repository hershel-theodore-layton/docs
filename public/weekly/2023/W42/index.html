Week 42: Oct 16–Oct 22, 2023

8 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

6 changes
  • Tue, Oct 17
    Package diagnostics remain useful when a package mentions an undefined module: Hack now reports the missing module while still using its name to find and explain related package-boundary errors. 866ce8f064
  • Wed, Oct 18
    Memoized functions may now declare HH\EnumClass\Label parameters without a typechecker error, completing the runtime support added on October 4. 4cd1bb3fc8
  • Wed, Oct 18
    A new debugger_dump(mixed): void builtin renders a value using the debugger's serializer. In particular, it honors a value's debugger-display customization rather than exposing the ordinary var_dump() representation. 22a6b2b3a7
  • Thu, Oct 19
    Enum-class labels now work with the general serializers: serialize()-style modes use the dedicated e:length:label; representation, while JSON encodes a label as a string. 1b80a55bff
  • Thu, Oct 19
    Shape-key checking now follows every index in nested coalescing expressions such as $shape['a']['b'] ?? $fallback, so a missing inner key is no longer overlooked. 24b8ff501c
  • Fri, Oct 20
    $_SERVER['REQUEST_TIME_NS'] now exposes the request start time in nanoseconds. 12b5ed858f

Future Changes

2 changes
  • Thu, Oct 19
    The experimental class<T> syntax is now accepted by the typechecker and currently behaves as the migration spelling of classname<T>. bc693532b5
  • Fri, Oct 20
    The unstable pipe_await feature now permits nested sequential awaits such as await f(await g(), await h()). Hack rejects nestings that would require a concurrent composition of sequential await groups. c2eec8e384
