Week 43: Oct 23–Oct 29, 2023

12 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

6 changes
  • Mon, Oct 23
    Runtime deployment checks no longer warn when caller and callee are in the same module, or when the caller itself is already outside the active deployment. This removes two sources of false-positive soft-deployment warnings. afc4e864da 09d597f5d8
  • Wed, Oct 25
    HTTP requests that expire after being dequeued now return the same 503 plus Retry-After response as requests rejected while still queued, closing a gap in overload signaling. 8e43190ec7
  • Thu, Oct 26
    Autocomplete after new no longer suggests type aliases, which cannot be instantiated and would produce naming error 2052. 004e06c110
  • Thu, Oct 26
    Functions and methods may use <<__AutocompleteSortText('...')>> to override their LSP sort key—for example, generated entry points can deliberately appear above their default alphabetical position. The argument must be one static string. 2fce55c0f2
  • Fri, Oct 27
    A server may now enable both full and per-file coverage. Each request can select one mode, while attempts to use both modes in the same request fail explicitly. b3523a4cf0
  • Sat, Oct 28
    Hack code actions now encode edited documents as file:// URIs as required by LSP, rather than passing filesystem paths. This preserves VS Code behavior and improves compatibility with stricter language clients. e9411431d2

Breaking Changes

2 changes
  • Tue, Oct 24
    HH\classname_from_string_unsafe() has been removed from the bundled HHI, so project calls no longer typecheck. Prefer C::class when the class is statically known; where a typed class name or class pointer is already available, use the explicit conversion helpers introduced on October 5. e4e180b387
  • Thu, Oct 26
    Eval.EnforceDeployment now defaults to true. Deployments that previously relied on the off-by-default setting may begin warning for soft-package boundary violations and throwing DeploymentBoundaryViolationException for hard violations; fix the package/module boundary or explicitly review the runtime setting. 1146464fbf

Future Changes

4 changes
  • Wed, Oct 25
    IDE autocomplete inside experimental nameof expressions now offers all classish declarations, including interfaces and traits rather than only instantiable classes. 2498045ddc
  • Thu, Oct 26
    Experimental typed locals now preserve runtime checks across destructuring and compound assignments by checking temporary values before committing them. Their shape and tuple checks intentionally remain shallow rather than validating every nested field or element. b5fae97e2b 4a23bbba70
  • Fri, Oct 27
    Calls through intersection types are no longer incorrectly rejected under implicit pessimisation. 24c4cd9c79
  • Fri, Oct 27
    An experimental module-level trait may no longer also be internal; the typechecker now catches the combination that HHVM already rejected at runtime. 820766b1d0
