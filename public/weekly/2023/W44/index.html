Week 44: Oct 30–Nov 5, 2023

16 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

9 changes
  • Mon, Oct 30
    The Hack REPL now warns when a file loaded into its current request has changed on disk, because the already-loaded code will not be refreshed until a new request. 56722eba42
  • Mon, Oct 30
    The quick-fix for debugger-style =$expression statements now produces debugger_dump($expression) instead of var_dump(). The debugger serializer honors custom debug displays, which helps avoid revealing a value's raw representation. eb224b9d92
  • Tue, Oct 31
    Nullable runtime assertions now refine like types precisely: if $x has type ~Base, then $x as ?Derived is inferred as ?Derived just like the non-nullable assertion. e9d270eff8
  • Tue, Oct 31
    HHVM no longer intermittently loses an implicit context when only the low byte of its internal pointer is zero. a7c1d33f17
  • Wed, Nov 1
    The VS debugger's asynchronous pause command now interrupts JIT-compiled loops and branches, so pausing no longer depends on the request reaching interpreted code. b08759b062
  • Wed, Nov 1
    HH\classname_to_class() now handles nonexistent lazy class values consistently, throwing an InvalidArgumentException that identifies whether the failed name came from a lazy class or a string. fb958936dc
  • Thu, Nov 2
    Sound Dynamic errors now explain when an inout parameter, return type, or property became a like type through implicit pessimisation, instead of reporting only that the resulting value is dynamic. 2aa0726c6b
  • Thu, Nov 2
    Large streaming find-references operations no longer block unrelated LSP requests such as hover. Cancellation also avoids crashing hh_server and is checked frequently enough to stop most ongoing worker batches promptly. c3a85f7f49 316f899d14 6be1ff91b5
  • Fri, Nov 3
    Type errors can now trace a suspicious type back through HH\FIXME\UNSAFE_CAST, making it clearer when a reported type may be a lie introduced by an unsafe cast. a250bace2b

Future Changes

5 changes
  • Mon, Oct 30
    An experimental module-level trait may use only other traits annotated <<__ModuleLevelTrait>>; Hack now reports the invalid hierarchy before HHVM reaches its matching runtime fatal. 79e26d95a2
  • Tue, Oct 31
    The unstable nested-await implementation now diagnoses sequential awaits mixed into incompatible concurrent expressions, including sequential awaits inside a concurrent block. 13ad012627
  • Tue, Oct 31
    Under implicit pessimisation, HH\Readonly\as_mut() now retains its declared return type instead of acquiring an automatic outer like type. 5d156974e2
  • Wed, Nov 1
    Hover documentation for the pre-stable require class feature no longer incorrectly claims that a trait can always access private members of its using class. Such access requires an appropriate constraint. ff0561fc8f
  • Fri, Nov 3
    Closures created inside experimental module-level traits now retain the trait's original module identity after HHBBC copies the trait into a using class, preserving the intended module-boundary behavior. fc269a6ce4

Breaking Changes

2 changes
  • Tue, Oct 31
    Dynamic static calls with a fixed class, such as C::$method(), are now parse errors. If both pieces truly need runtime dispatch, the remaining supported form is $class::$method(); otherwise call the method by its literal name. e120477a21
  • Tue, Oct 31
    hh_client lsp must now be launched with an explicit project-root argument or from the project root (or one of its subdirectories). Editor integrations that started it from an unrelated working directory must set the root or working directory. 773a315692
