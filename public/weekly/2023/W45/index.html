Week 45: Nov 6–Nov 12, 2023

15 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

11 changes
  • Mon, Nov 6
    hh --config dump_tasts=file_list.txt can now dump the named files' typed ASTs to /tmp/hh_server/tasts or /tmp/hh_distc/tasts, including when typechecking is distributed. ac3fec9645
  • Tue, Nov 7
    Pending debugger commands after a client disconnects now fail with an exception instead of crashing HHVM. 4b60b22276
  • Wed, Nov 8
    Autocomplete now works inside top-level statements, primarily improving Hack notebook editing while leaving the ordinary top-level-statement diagnostic intact. a0de61cb38
  • Wed, Nov 8
    hash() and hash_copy() are now declared with the empty capability set [] rather than implicit [defaults]. This narrows their requirements and permits calls from pure contexts. 60c9fc68eb
  • Thu, Nov 9
    A static method call through an invalid string receiver still reports the receiver error, but its result is now typed dynamic rather than an unconstrained variable that commonly collapsed to nothing. This keeps code behind a fixme from gaining an unsoundly precise type. 26b37f5439
  • Thu, Nov 9
    Array access through a nullable value now continues with the array's element type after reporting the nullability error. Suppressing that first error no longer causes downstream expressions to infer nothing. d0ff8a66a2
  • Thu, Nov 9
    XHP auto-close edits now place the cursor before the generated closing tag. a9b6c46a54
  • Thu, Nov 9
    The VS debugger's variable command now serializes all remaining HHVM datatypes instead of failing on unsupported values. 92655846f6
  • Fri, Nov 10
    echo is now represented by a real typed signature, (readonly arraykey ...)[io]: void, instead of a Tany-based special case. Argument and missing-[io] capability errors now point back to that signature. 11bed300da
  • Fri, Nov 10
    Consecutive top-level statements now share a typing environment. Notebook hover and completion can therefore understand values assigned by earlier statements in the file. 9e37abd5a1
  • Fri, Nov 10
    LSP clients advertising the experimental autoCloseJsx capability can now request automatic XHP closing tags. 4697a751c8

Breaking Changes

1 change
  • Mon, Nov 6
    HHVM no longer populates $_SERVER['REQUEST_START_TIME'], REQUEST_TIME, or REQUEST_TIME_FLOAT. Use nanosecond-resolution $_SERVER['REQUEST_TIME_NS'] instead. d23fe23887

Future Changes

3 changes
  • Mon, Nov 6
    Experimental typed locals now use shallow runtime enforcement, checking the outer declared type without recursively validating all nested type arguments. 9212f22d4c
  • Tue, Nov 7
    The upcoming nameof operator now follows ::class constexpr rules for parent and static, while uses with reified generic parameters are explicitly rejected. 94a8f45049 5ae441bccc
  • Wed, Nov 8
    Runtime violations of experimental typed-local declarations now raise a catchable fatal, matching parameter type-hint enforcement, rather than throwing TypeAssertionException as an as expression does. 15a807f59e
