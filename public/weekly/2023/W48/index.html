Week 48: Nov 27–Dec 3, 2023

21 noteworthy changes, organized by the source changelog sections.

Highlights

13 changes
  • Mon, Nov 27
    hh_single_fanout now includes files with stale errors in its recheck set, keeping reported positions current after dependency changes. 85c8967bbd
  • Mon, Nov 27
    Invalid compound module names containing reserved default now produce a direct parser error instead of malformed AST nodes and confusing follow-on diagnostics. f390763c64
  • Tue, Nov 28
    Standard-library HHI declarations now use real like types such as ~SplFileInfo and ~int instead of the internal HH\FIXME\POISON_MARKER<T> alias, improving hover and diagnostics for pessimised built-ins. f18ae44cf3
  • Tue, Nov 28
    Facts attribute-value queries now correctly normalize Class and LazyClass values to class names. a814431794
  • Tue, Nov 28
    LSP pull diagnostics are now unconditional and the rollout flag has been removed. e152ec6b86
  • Tue, Nov 28
    <<__AutocompleteSortText("...")>> may now be applied to classes as well as functions and methods, allowing tools to supply a stable custom ordering key for class completions. 2c09844345
  • Wed, Nov 29
    With the new off-by-default implicit_inherit_sdt option, a class or interface can inherit <<__SupportDynamicType>> behavior from an SDT parent instead of repeating the attribute. 91e91b246c
  • Wed, Nov 29
    Autocomplete declaration paths now retain <<__AutocompleteSortText>> values for methods and class elements, allowing the requested custom ordering to reach completion results. d093f7148f 6aecbfbc4f
  • Wed, Nov 29
    Top-level-statement validation is now a naming error rather than a parsing error. Normal Hack files still reject the statements, but the IDE and hh can continue showing unrelated type errors in the rest of the file, improving notebook feedback. 0e80ee7ded
  • Wed, Nov 29
    The new pure builtin fb_utf8_decompose(string)[]: vec<string> splits a UTF-8 string into individual encoded characters. 0f1b5fd248
  • Thu, Nov 30
    The VS debugger REPL now warns when a source file loaded into the session changes on disk and recommends reloading. The default can be disabled with hphp_debugger_set_option('warnOnFileChange', false). bc18048e1f
  • Fri, Dec 1
    hh_single_type_check --root can now locate a downloaded naming table automatically and reads enable_sound_dynamic_type and everything_sdt from the project's .hhconfig, reducing differences from a normal hh run. 99c4e207d0
  • Fri, Dec 1
    The Hack manual now documents __AutocompleteSortText, which lets a declaration supply the sort key used for its IDE completion entry. 1785b081e2

Breaking Changes

5 changes
  • Mon, Nov 27
    HH\FIXME\UNSAFE_CAST<Tin, Tout>() now requires both type arguments to support dynamic and returns ~Tout; UNSAFE_NONNULL_CAST<T>() similarly returns ~T. This soundness fix applies even without everything_sdt and may expose code that treated unsafe-cast results as trustworthy precise types. 7040cd5beb
  • Thu, Nov 30
    hh_single_type_check now enables like-type hints by default. Scripts that intentionally test the disabled mode must pass --config like_type_hints=false. 50988da888
  • Fri, Dec 1
    hh_single_type_check no longer accepts the --like-type-hints switch and always enables like-type hints by default. Use --config like_type_hints=false when the legacy behavior is required. 12e71b4968
  • Fri, Dec 1
    The typechecker now rejects varray[...] and darray[...] initializer syntax. Migrate remaining initializers to vec[...] and dict[...]. 6e4f4cfed0
  • Fri, Dec 1
    A function marked __DynamicallyCallable and a class marked __DynamicallyReferenced are now implicitly treated as __SupportDynamicType. This removes the need to repeat the latter attribute, but it also checks those declarations under sound-dynamic assumptions and can expose new errors in their bodies or signatures. f84c931769 f81b17b454

Security

1 change
  • Wed, Nov 29
    HH\classname_to_class() now performs module-boundary checks when resolving a string, closing a path that could otherwise resolve an internal class from another module. 6f6cde3a63

Future Changes

2 changes
  • Fri, Dec 1
    Typed local variables have moved from Unstable to Preview. They still require <<file:__EnableUnstableFeatures('typed_local_variables')>>, but the Preview status permits opted-in code to run in production. 466d390616
  • Sat, Dec 2
    nameof is being changed to bind like a prefix unary operator, so expressions such as nameof C . 'Suffix', nameof C is string, and nameof C |> f($$) apply the following operator outside nameof. The runtime compiler uses the new precedence immediately; the typechecker can opt in with nameof_precedence=true, but its default remains on the old parser behavior for this rollout stage. 3cc9a258bd
