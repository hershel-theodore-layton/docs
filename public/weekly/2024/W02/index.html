Week 2: Jan 8–Jan 14, 2024

12 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

6 changes
  • Mon, Jan 8
    Type printers now render empty unions as nothing and empty intersections as mixed, replacing confusing output such as |(). ac9984d4bf
  • Mon, Jan 8
    An overriding method without its own <<__AutocompleteSortText>> now inherits the sort key from its parent declaration. 3e5fa6a58a
  • Wed, Jan 10
    hh --single file.php --show-tast now provides a dedicated way to print one file's typed AST. b4fa8c14db
  • Wed, Jan 10
    Sound Dynamic call inference now tries a dynamic check first when an argument is already like-typed but its generic parameter is not. This removes false errors for calls that mix lambda arguments with pessimised values. f544f07cb4
  • Wed, Jan 10
    Cross-package calls no longer require the package unstable-feature opt-in. Bundled declarations now also expose HH\module_exists(string, bool)[]: bool and HH\package_exists(string)[defaults]: bool. 6c9d99cc02
  • Fri, Jan 12
    XHP attribute checking no longer leaks refinements from its constructor-style pass into the second attribute-specification pass, eliminating spurious type holes and inaccurate TAST types. 524bddd78f

Breaking Changes

3 changes
  • Mon, Jan 8
    Hack's AST no longer has separate Darray and Varray nodes: legacy darray[...] and varray[...] syntax is lowered to dict and vec nodes. Typed-AST and parser tooling that distinguishes the legacy nodes must migrate. 489f6fe405
  • Wed, Jan 10
    The old <<__AllowMultipleInstantiations>> spelling has been removed; experimental code must use the explicitly unsafe <<__UNSAFE_AllowMultipleInstantiations>> name. 53a31ae7b7
  • Fri, Jan 12
    Magic method names are now recognized with their exact Hack casing. A differently cased name is treated as an ordinary method and no longer receives magic-method-specific validation. 64f425c7df

Future Changes

2 changes
  • Mon, Jan 8
    Experimental module-level traits can now define internal methods and properties while preserving the trait's original module for boundary checks. a1db805b0a
  • Tue, Jan 9
    Experimental case-type overlap checking now models EnumClass\Label as its own runtime datatype, avoiding incorrect overlap conclusions for label variants. 2a3d2853a0

Security

1 change
  • Sat, Jan 13
    HHBBC no longer treats class-pointer resolution as effect-free or removes class-method calls when doing so could suppress a module or deployment boundary violation. aae991594c
