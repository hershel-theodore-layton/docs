Week 3: Jan 15–Jan 21, 2024

7 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

5 changes
  • Mon, Jan 15
    Quick fixes now appear whenever the cursor is inside an error span; the editor no longer requires the entire error span to fit inside a selection. 42c3a995ee
  • Mon, Jan 15
    Sound Dynamic like-type pushing now handles nullable generic bounds split into separate null and nonnull lower bounds, removing false subtype failures such as vec<~int> <: ~?vec<int>. 36221d5814
  • Tue, Jan 16
    Sound Dynamic refinement now treats shapes as enforceable when every field type is enforceable, producing more precise results after is checks on like-typed values. 12878d63e8
  • Wed, Jan 17
    Debugger step-over now handles multiple calls on the same source line without incorrectly pausing inside the second callee. 72fbdf973c
  • Fri, Jan 19
    Lambda compatibility now compares the full accepted argument range when default parameters are present. A lambda is accepted when it can handle every arity promised by the expected function type, rather than requiring identical minimum arities. 98a4a79060

Breaking Changes

1 change
  • Tue, Jan 16
    HH\classname is now always handled as the dedicated classname runtime annotation, independent of Eval.ClassPassesClassname; string conversion must go through an explicit string position. The pure HH\class_to_classname() builtin is also tightened from mixed -> mixed to classname<mixed> -> classname<mixed>. f0ec4483d1

Future Changes

1 change
  • Fri, Jan 19
    Package configuration parsing now accepts an allow_directories field, canonicalizes its relative paths and optional * suffixes, and rejects paths that do not exist. Typechecker enforcement follows later in the month. 1e848e45b1
