Highlights

3 changes
  • Tue, Jan 30
    hh --lint-all now honors typecheck_sample_rate, making repository-wide lint experiments sample the same files as typechecking. 8dac2e5bcc
  • Tue, Jan 30
    Shape-key diagnostics now explain that a shape cannot mix literal keys with class-constant keys. a7034a9daa
  • Wed, Jan 31
    The <<__NonDisjoint>> linter now checks generic arguments on instance and static method calls, including enclosing class generics connected through where constraints. eba49df195

Future Changes

2 changes
  • Wed, Jan 31
    Pre-stable function type hints now support optional parameters, for example (function(int, optional string): void). Optional parameters must trail required ones and cannot be inout or variadic. 62e76b9785
  • Fri, Feb 2
    Hovering over an experimental expression-tree class now shows its expression-tree type instead of an internal name such as TInfer#1. fcfb98165b

Breaking Changes

1 change
  • Thu, Feb 1
