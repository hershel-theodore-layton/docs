Week 6: Feb 5–Feb 11, 2024

12 noteworthy changes, organized by the source changelog sections.

DayWeekMonth

Future Changes

6 changes
  • Mon, Feb 5
    As part of the ongoing module-level-traits rollout, <<__ModuleLevelTrait>> no longer requires the per-file module_level_traits opt-in. The feature is still staged rather than generally released. A module-level trait may also compose an ordinary public, non-internal trait. 0257ed18da 3cff9cd066
  • Tue, Feb 6
    HHVM gains the runtime type-structure representation needed for recursive experimental case types such as case type Node = int | shape('next' => Node). The typechecker does not support declaring them yet. 504c07dd96
  • Wed, Feb 7
    Sound Dynamic now preserves the like-type information inside supportdyn<~T> when stripping dynamic, fixing rejected operations such as arithmetic on ~int. 29bac2a65e
  • Thu, Feb 8
    HHBBC now preserves module provenance when a staged module-level trait composes an internal trait, so copied methods retain the correct runtime boundary checks after trait flattening. 73357ffc8d
  • Thu, Feb 8
    Dynamic-aware subtyping no longer takes an incomplete default path before decomposing a right-hand intersection in constraints of the form T <: supportdyn<t>. 4ebf2bc6f1
  • Fri, Feb 9
    Implicit pessimisation can now push a like type through enum returns whose runtime representation appears as an intersection, avoiding false errors for results such as vec<~E & int>. b8a79a6331

Security

1 change
  • Tue, Feb 6
    idn_to_ascii() now passes ICU the correct output-buffer capacity. Oversized malformed domains return false instead of overwriting the buffer terminator and crashing HHVM. e5a0315b88

Breaking Changes

1 change
  • Tue, Feb 6
    Runtime parameter type hints on builtins are now enforced by default rather than treated as soft. Calls that relied on passing values of the wrong type to native functions may now fail instead of merely warning. 11164a1fce

Highlights

4 changes
  • Wed, Feb 7
    A new type_alias_exists(string $name, bool $autoload = true)[]: bool builtin checks for a type alias without forcing callers to probe it through an exception. a0e84e265c
  • Thu, Feb 8
    Tier overrides now accept a tagset matcher containing multiple regular expressions. A machine matches only when its tags satisfy every expression in the set. 7e0dac1623
  • Thu, Feb 8
    The HTTP compression layer now reads the documented zstd.target_block_size option; the previous typo caused configured values to be ignored. 81d33dc841
  • Fri, Feb 9
    Debugger breakpoints set in a unit that was loaded after request startup are now installed reliably, even after execution has already paused in another unit. 7af3e78f4d
