Week 7: Feb 12–Feb 18, 2024

7 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

5 changes
  • Mon, Feb 12
    Generic calls now type explicitly annotated lambda parameters before other arguments. This lets calls such as any($values, (C $value) ==> ...) infer C before applying like-pushing to a vec<~C> argument. 11c6d53343
  • Mon, Feb 12
    Repository-authoritative deployments can now execute a configured prelude. A prelude path beginning ${SOURCE_ROOT}/ is resolved relative to the directory containing the applicable .hhvmconfig.hdf, and missing preludes produce an actionable log message. 45c319db7d
  • Tue, Feb 13
    An explicit hh_server --max-procs value is now honored up to the machine's processor count rather than being halved a second time. Without an explicit limit, the server continues to default to half the reported logical processors. dcfcc2cb9d
  • Wed, Feb 14
    The IDE now offers “Extract into variable” as a quick-fix when an await is rejected for being conditionally executed. The underlying refactoring is also available inside braceless lambdas and expands them to a block when necessary. 0dbb8a21c6 8f2e2fa5d4
  • Thu, Feb 15
    Known class references now resolve directly while retaining module-boundary checks for object construction and static access. Literal access such as C::$property no longer produces a spurious string-to-class conversion notice, and lazy-class resolution no longer bypasses the corresponding modularity check. 0bd6a0cf1e 3af9a08b53

Breaking Changes

1 change
  • Tue, Feb 13
    The IMAP extension has been removed, including functions such as imap_open(), imap_fetchbody(), and imap_close(). Applications still using these APIs need an external mail client or service. ee0bc2cb00

Future Changes

1 change
  • Tue, Feb 13
    Sound Dynamic and implicit pessimisation now trust runtime enforcement declared by HHI signatures in the same way as ordinary Hack signatures, removing a legacy exception that affected property assignment. 0507e9f8ad
