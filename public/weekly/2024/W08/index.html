Week 8: Feb 19–Feb 25, 2024

7 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

6 changes
  • Mon, Feb 19
    A new HH\objprof_get_data_extended() profiler reports ordinary object memory together with memoization-cache memory. Its per-property mode attributes caches to individual instance and static memoized methods, including multi-entry static caches. bfc168e3ee c54a0248e4 bef9514eb3 6b309566ee
  • Tue, Feb 20
    The IDE now offers both a refactoring and an error quick-fix to prepend await to an Awaitable. When required, the complete action also makes the enclosing function, method, or lambda async and changes its return annotation to Awaitable<...>. 7e9ff18df6 675e7b58a5 4f72da9375 0b17bfd5a5 02ab77e706
  • Tue, Feb 20
    The Treadmill's stuck-request detector now accounts for a request-specific timeout as well as Server.RequestTimeoutSeconds. Requests that deliberately extend their timeout are no longer incorrectly terminated with SIGABRT. 8bf8fcf3bf
  • Wed, Feb 21
    The new “add await” action now preserves operator precedence and avoids unnecessary parentheses around the inserted expression. d23fc11169 17801ada76
  • Wed, Feb 21
    The admin status response now includes machine-readable process uptime in seconds. Before the pagelet server starts, its start and uptime values are reported as -1 rather than a date near the Unix epoch and a nonsensical duration. 0af897ce58
  • Fri, Feb 23
    Expressions with built-in vec and dict types no longer acquire unnecessary expression-dependent wrappers. Their inferred unions and error messages now show ordinary types such as vec<C> instead of <expr#N> as vec<C>. 51b81f12ac

Future Changes

1 change
  • Wed, Feb 21
    In the ongoing module-level-traits rollout, public module-level traits may no longer declare internal methods. This reverses the short-lived staged allowance while support is redesigned; use an internal trait or make the method non-internal. c641788a1a
