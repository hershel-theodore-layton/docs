Week 12: Mar 18–Mar 24, 2024

9 noteworthy changes, organized by the source changelog sections.

Highlights

3 changes
  • Tue, Mar 19
    Autocomplete now recognizes namespace constant declarations, restoring completions at declaration sites inside namespaces. 62ec1f5201
  • Tue, Mar 19
    Type tests of the form if ($x is bool) now use constraint-based partitioning, improving true- and false-branch refinements for unions, intersections, and bounded abstract types. 769012223d 26fb5051ac 51ae0e53ef
  • Wed, Mar 20
    Hack's VS Code diagnostics can now render secondary quickfix locations as dotted gray underlines, and the same quickfix is available when the caret is on one of those hinted locations. d90eb57776 138bc45288 f1f9295614

Future Changes

3 changes
  • Tue, Mar 19
    Unstable expression trees can now contain keyed collection literals such as Dsl`Collection {'a' => 1}; DSLs receive them through visitKeyedCollection(). 8659f615d5
  • Wed, Mar 20
    Preview readonly checking now produces type errors for unary increment and decrement, matching its existing checks for compound assignments such as +=. d323321cd0
  • Thu, Mar 21
    Under the preview readonly feature, meth_caller() now produces a readonly function value because it captures no mutable state. A readonly target method also gives the generated callable a readonly receiver parameter, e.g. (readonly function(readonly C, int): bool). 34d1278fc9

Breaking Changes

2 changes
  • Wed, Mar 20
    Module existence checks now consistently use the pure HH\module_exists(string, bool = true)[]: bool API. The previous global module_exists() runtime spelling has been removed. f397bd3c97
  • Fri, Mar 22
    Hack source text must now be valid UTF-8. The compatibility configuration for non-strict source decoding has been removed. e768c25fcf

Security

1 change
  • Sun, Mar 24
    Hack now rejects meth_caller() for internal methods, even when the callable is created inside the defining module. Such a callable could escape and fail only when invoked outside the module boundary. 134b288fab
