Week 13: Mar 25–Mar 31, 2024

6 noteworthy changes, organized by the source changelog sections.

Highlights

4 changes
  • Tue, Mar 26
    this is now considered fully runtime-enforced when it appears in a final, non-generic class, allowing Hack to reason more precisely about those type hints. ccc7a97603
  • Tue, Mar 26
    Immediately invoked lambdas with syntactically constant arguments no longer invalidate fake-member refinements. This supports expression-oriented patterns such as async blocks and expression-tree runtime expressions without unnecessary rechecks. d768a63db0
  • Wed, Mar 27
    The new unserialize_slice(string, int, int, darray = dict[])[defaults]: mixed builtin deserializes a byte range without first allocating a substring. Invalid offsets or non-positive lengths throw InvalidArgumentException. c3519b4365
  • Wed, Mar 27
    debugger_dump() now writes exclusively through debugger stdout hooks, so debug-display output reaches the debugger without also entering the application's ordinary output buffer. e5794da899

Breaking Changes

2 changes
  • Thu, Mar 28
    Function names are now case-sensitive at runtime. Legacy mixed-case lookup, its compatibility configuration, and associated logging have been removed; call functions using their declared spelling. 39619a7250
  • Fri, Mar 29
    HackC now also compares function names with exact case, completing the case-sensitive function-name migration for compiled code. 351dd87969
