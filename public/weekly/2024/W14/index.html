Week 14: Apr 1–Apr 7, 2024

9 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

5 changes
  • Mon, Apr 1
    Hack now permits global function declarations whose names differ only by case, matching the language's case-sensitive function lookup. Exact duplicate declarations remain invalid. bf677366a7
  • Thu, Apr 4
    HH\Facts\files_with_attribute_and_any_value() now uses the in-memory symbol map by default again, avoiding stale or incorrect DB-only results while files are changing. Deployments that need the old strategy can set Autoload.DB.UseSymbolMapForGetFilesWithAttributeAndAnyVal to false. 70bd28a835
  • Fri, Apr 5
    Lambda arity mismatches now produce TAST holes around the incompatible function value or lambda. Tools that consume typed ASTs can use the expected and actual function types to offer more precise migrations. 7eccda3526
  • Fri, Apr 5
    HH\get_executable_lines() no longer reports generated functions or abstract methods as executable. Coverage and debugger clients will no longer see interface methods or class-closing braces as spurious executable lines. 17236d2daf
  • Fri, Apr 5
    Constraint solving now retains the errors from all branches of a disjunction, improving explanations when no branch is valid—particularly for failures involving type-parameter constraints. 85d958bb73

Future Changes

3 changes
  • Tue, Apr 2
    The runtime parser now accepts nameof expressions as attribute arguments. This is only the runtime half of the change; typed Hack projects will continue to see a typechecker error until the matching support lands on April 10. 80415702c0
  • Wed, Apr 3
    HackC's expression-tree debug output now gives generated temporaries valid Hack variable names, so the lowered output can be passed through hackfmt. Expression trees remain experimental. adacdb6ddf
  • Fri, Apr 5
    Expression-tree collection literals moved from Preview to OngoingRelease as part of their staged rollout. Expression trees themselves remain experimental. eda3f8b79c

Breaking Changes

1 change
  • Thu, Apr 4
    Variadic parameters must now have a capture variable. Replace bare ... in functions, methods, and lambdas with a named parameter such as ...$args; the runtime parser now rejects the unnamed form that the Hack typechecker already rejected in strict code. 64a98f185b
