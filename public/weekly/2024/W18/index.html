Future Changes

2 changes
  • Tue, Apr 30
    A disabled-by-default strict_switch project option has been added as rollout plumbing for enabling strict switch checking globally. This commit only introduces and loads the option; it does not yet connect the setting to the strict-switch checker. b3f0c2a764
  • Wed, May 1
    The experimental strict switch checker is now selected project-wide by the strict_switch configuration. The per-switch <<__StrictSwitch>> attribute and its unstable-feature opt-in no longer select the implementation. e67c9a80f0

Highlights

3 changes
  • Wed, May 1
    “Add method stub” is now available when the cursor is on whitespace between class-body declarations, and inserts the selected inherited method at that position. 60ebc78364
  • Wed, May 1
    Typechecking cyclic generic upper bounds no longer recurses indefinitely while resolving type-member constraints. bcdba1ecd8
  • Fri, May 3
    Reified generic class values such as T::class no longer trigger the class-pointer migration lint or error; this spelling remains supported while nameof T is intentionally unavailable. e5353501f7
