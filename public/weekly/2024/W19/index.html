Week 19: May 6–May 12, 2024

7 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

3 changes
  • Mon, May 6
    HH\Facts\type_to_path_relative(string)[]: ?string now returns a type's path relative to the Facts repository root, avoiding caller-specific stripping of an absolute root. 41f678c119
  • Tue, May 7
    LSP textDocument/documentSymbol responses now include function and method signatures with parameter names, plus detail text for properties, class constants, and type constants. File outlines also include type aliases and global constants. Editors and coding assistants therefore receive a substantially richer structural view of each Hack file. 06ce20461a 31047fbe1b 9c05e9b175
  • Thu, May 9
    Relative-path variants are now available for every Facts symbol-to-path query: modules, types, type aliases, functions, constants, and the combined type-or-alias lookup. The existing absolute-path APIs remain available during migration. 7f90612b91

Future Changes

3 changes
  • Mon, May 6
    Strict-switch diagnostics now handle negated type predicates directly. A subject described only as “not primitive” still requires default, but no longer produces a misleading exhaustiveness explanation. b04e4a7bc5
  • Thu, May 9
    Nested expression trees have moved from unstable to preview status. They remain pre-stable and continue to require the expression_tree_nest feature where preview features are not enabled. 0d9f8f88ad
  • Sat, May 11
    In the staged module-level trait work, public module-level traits may declare internal methods without separately enabling module_level_traits_extensions. Internal properties on public traits remain invalid. 2b00d0ec8b

Breaking Changes

1 change
  • Sat, May 11
    HH\ImplicitContext\soft_run_with() and soft_run_with_async() no longer create a soft implicit-context state from their $key; they now invoke the callback without changing context. Code that depended on the key creating separate memoization context should migrate to an explicit implicit-context API. 9461b78f48
