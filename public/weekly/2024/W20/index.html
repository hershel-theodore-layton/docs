Week 20: May 13–May 19, 2024

12 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

6 changes
  • Mon, May 13
    Null checks written as is_null($value) or $value === null now use the same type-switch refinement as $value is null. 8d4f00adda d749ee3e5a
  • Tue, May 14
    Referencing $this inside an enum class now produces a direct parser error. HackC and syntax-only checks no longer panic later in compilation. 4f994c02df
  • Tue, May 14
    Shape-key validation now follows a missing field through further indexing on the left of ??; $shape['missing'][0] ?? null is no longer accepted when missing is absent. da7eb6cb73
  • Tue, May 14
    Under Sound Dynamic, the true branch of a null type test now refines precisely to null instead of the unhelpful ~null. 61db97555f
  • Wed, May 15
    The built-in constants TRUE, true, FALSE, false, NULL, and null are now declared in HHI files, so attempts to redefine them receive a naming error instead of surviving until HHVM's runtime fatal. 47c1ae0958
  • Fri, May 17
    Hack now reports top-level break or continue inside a finally block during typechecking, matching the fatal that HackC already emitted. cba8993c7c

Breaking Changes

5 changes
  • Wed, May 15
    __clone() must declare a void return type. Returned values were always discarded; implementations that returned this or another value must remove the return value and keep mutation in the method body. 50376266b5
  • Thu, May 16
    hh_single_type_check now enables everything_sdt by default and has removed the --everything-sdt flag. Tests that need the legacy mode should pass --config everything_sdt=false. 50f7db53c0
  • Thu, May 16
    Comparison typechecking now constrains both operands even when one begins as an unresolved type variable. Unconstrained generic or nullable comparisons that could resolve outside int, string, DateTime, or DateTimeImmutable may now report errors. d45b3df95f
  • Fri, May 17
    The erased UNSAFE_CAST pseudo-function may no longer be captured as a first-class function pointer with UNSAFE_CAST<>. Direct HH\FIXME\UNSAFE_CAST(...) migration calls remain available. 080efb3351
  • Sat, May 18
    Trait names are no longer considered runtime-enforceable types. They cannot be supplied to an <<__Enforceable>> reified parameter or used as the target of is and as; use an interface or concrete class for runtime checks. 9001bd2d40

Future Changes

1 change
  • Thu, May 16
    Package-v2 groundwork adds the package_v2 option, parsing for path-based include_paths, and an unstable <<file:__PackageOverride(...)>> attribute. The override is syntax-only at this stage; enforcement work follows later. 405a8e27b8 f791873cdd 8bd22d74db
