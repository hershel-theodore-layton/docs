Week 23: Jun 3–Jun 9, 2024

13 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Breaking Changes

3 changes
  • Mon, Jun 3
    Hack now rejects calls to protected methods through an interface-typed receiver. The concrete implementing class might be outside the caller's class hierarchy, making the apparently valid call fail at runtime. 7b9882a0ae
  • Tue, Jun 4
    The pure HH\darray() and HH\varray() conversion functions are now deprecated. Use dict() and vec() respectively. 4330501899
  • Fri, Jun 7
    Hack's invalid-index check now diagnoses non-int access to vec, including cases hidden behind inferred generic keys. 6a242bdb0d

Future Changes

3 changes
  • Mon, Jun 3
    Preview case types now handle nullable unions and bottom cases such as empty or null-only unions without crashing during runtime type-constraint canonicalization. 25c4c950e9 7c6ce997e6
  • Tue, Jun 4
    Preview case types now resolve every arm of aliased unions correctly in HHBBC and avoid applying memo-key optimizations that are invalid for union type constraints. 8b910792af 70eab5af40
  • Fri, Jun 7
    Unstable expression trees now permit await inside splices when the tree is constructed in an async function. 3c259b10ef

Highlights

7 changes
  • Wed, Jun 5
    Failed union and intersection subtype checks now retain the errors from every invalid branch. Diagnostics no longer disappear when a disjunction is deferred or collapse to only the last failed alternative. b92226235f 608d6b4b07 b24c0c1751 0c7f97fbe8
  • Thu, Jun 6
    json_encode() accepts the new JSON_FB_SORT_KEYS flag for deterministic object and dictionary output. Integer keys sort numerically before string keys, which sort lexicographically, making the resulting JSON suitable for stable hashing and cache keys. df9fc19be0
  • Fri, Jun 7
    The redundant-generics linter once again recognizes a generic used only contravariantly when multiple as bounds simplify to one effective bound, including bounds introduced by implicit pessimisation. 1ca353c4cb
  • Fri, Jun 7
    Shape refinement no longer causes Shapes::idx() on a different optional field to lose its nullable result type after patterns such as $shape ?? shape() and Shapes::keyExists(). 6254e75cb8
  • Fri, Jun 7
    The new HH\Facts\validate(vec<string> $types_to_ignore = vec[])[defaults]: void API checks the SQLite Facts database for types mapped to multiple paths and throws UnexpectedValueException when it finds an unignored conflict. 153ec68b9d
  • Fri, Jun 7
    Hack declarations now expose the pure async CAS helpers HH\RemoteExecution\gen_upload_file(string, string)[]: Awaitable<string> and gen_download_file(string, string, string)[]: Awaitable<bool>. 0c2cb6acbb
  • Sun, Jun 9
    Runtime-enforceable is checks now accept wildcard arguments through generic type aliases, so checks such as $x is Alias<_> no longer produce a false error merely because the alias has a type parameter. fb09a02486
