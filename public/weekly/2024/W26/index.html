Week 26: Jun 24–Jun 30, 2024

6 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

3 changes
  • Mon, Jun 24
    The value type parameter of HH\EnumClass\Label<-TEnumClass, +TType> is now covariant rather than invariant, allowing a label's value type to widen safely. 49c68bd4be
  • Tue, Jun 25
    Enum-class labels now use constraint-based typing. Anonymous labels such as #Name have their own inferred type and can be used beyond immediate function-argument position, while qualified labels are checked against the enum class's actual constant type. 0bc5384fa2
  • Tue, Jun 25
    JIT deployment-boundary checks now match the interpreter when the caller is itself outside the active deployment, avoiding a spurious violation on calls from that code. e8f6d775da

Future Changes

2 changes
  • Mon, Jun 24
    Await expressions in expression-tree splices have moved from Unstable to Preview. Multiple awaited splices retain the concurrent execution introduced earlier this month. a3bf39c601
  • Mon, Jun 24
    Packages v2 now ignores package boundaries while resolving generic type arguments, completing the relaxation for type-only references while retaining checks on value-level symbols. cc000535ac

Breaking Changes

1 change
  • Tue, Jun 25
    A generic used contravariantly inside HH\EnumClass\Label is now an error when covariance leaves it underconstrained. Replace the redundant parameter with its effective bound or redesign the signature so the label actually determines it. 5832019e44
