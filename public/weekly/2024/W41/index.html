Week 41: Oct 7–Oct 13, 2024

11 noteworthy changes, organized by the source changelog sections.

Highlights

6 changes
  • Mon, Oct 7
    Typechecker diagnostics now have stable ordering by phase, then source position and error code. This keeps naming errors ahead of typing errors without making output depend on worker completion order. 42102418a6
  • Mon, Oct 7
    Extended type-error reasons recover useful claims for sound-dynamic constraints, arithmetic-result flows, and generic types, reducing vague or misplaced primary messages. 7c185b5191 8658ff652b 41ce724047
  • Mon, Oct 7
    Emitted calls of the form $c::foo() now retain the call's source position rather than the class-expression position, improving AST and source-mapping consumers. 2184a6754b
  • Tue, Oct 8
    hh --notebook-to-hack can now read Jupyter notebook JSON from standard input and emit a valid Hack file, preserving cell metadata and wrapping notebook top-level statements in a generated function. 4fffc4133b
  • Thu, Oct 10
    Command-line diagnostics now print warnings before errors, leaving the errors at the bottom of the output where they are easier to find. a84a03948e
  • Thu, Oct 10
    nameof C and C::class are now handled consistently as class-name shape keys, including namespace and self resolution. 99e117526a

Future Changes

5 changes
  • Mon, Oct 7
    Runtime type information now preserves the nullable part of an explicit like-nullable hint, so a value accepted as ~?T can actually be null at runtime. 5743f65f39
  • Wed, Oct 9
    Explicit like-type hints such as ~int are now an Unstable syntax feature. Projects using them must enable like_type_hints through enable_experimental_stx_features or <<file:__EnableUnstableFeatures('like_type_hints')>>; the old like_type_hints option is gone. 0edcd8e498
  • Thu, Oct 10
    Hovering inside a splice of an Unstable expression tree now reports the original, non-virtualized expression's type. 2bb7ede81c
  • Thu, Oct 10
    Package configuration is now version-checked: Package v1 rejects include_paths, while Package v2 rejects uses. HHVM also gained the Eval.PackageV2 compiler option for the v2 format. fafd709eab
  • Fri, Oct 11
    A trait with the pre-stable require class C constraint may now call private static methods of the required class, matching its existing access to private instance methods. c92a23661b
