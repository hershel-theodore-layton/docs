Week 43: Oct 21–Oct 27, 2024

13 noteworthy changes, organized by the source changelog sections.

Highlights

7 changes
  • Mon, Oct 21
    Extended type-error derivations are now generated during the original check and stored with each error, avoiding a checker restart when detailed reasons are requested. Their rendering also gained clearer step styling and adapts to the current terminal width. 7ba1c0f0d8 5fa7ba8973 cb64df5b12 0119ca86a4
  • Mon, Oct 21
    Notebook top-level statements are now treated as having the [defaults] capability set, which includes write_props, eliminating spurious coeffect errors for operations that require those capabilities. a1d70342fb
  • Mon, Oct 21
    nameof C now has the precise type classname<exact C>, matching C::class. 2009f75002
  • Thu, Oct 24
    Hack now runs both full-fidelity and lowerer syntax checks even when the first pass already found errors, so a single invocation can report more independent syntax problems. 0e55fbf060
  • Thu, Oct 24
    Notebook conversion is now bidirectional: hh --hack-to-notebook reconstructs notebook JSON from generated Hack on standard input, and both conversion directions apply Hack formatting. 1e45a855cb 30842a482b
  • Thu, Oct 24
    The single-class filename linter now says that a file "defines" a class rather than incorrectly claiming the class is its only content when typedefs are also present. 653d1be162
  • Fri, Oct 25
    Notebook conversion now validates both source formats, reports malformed user-edited Hack separately from internal failures, and lets --notebook-to-hack place a supplied header such as a copyright notice after <?hh. 932cbaaf19 019a84b981 a4ac153138

Future Changes

5 changes
  • Tue, Oct 22
    Packages v2 now permits cross-package type names on the right-hand side of as, matching the existing is exemption. This is only a static-reference exemption: execution can still fail if the target package is not deployed. 9488fb8dd0
  • Wed, Oct 23
    Packages v2 no longer applies package-boundary checks to class-constant and global-constant type hints, which are not emitted into runtime constant metadata. 878738dc7d
  • Wed, Oct 23
    Experimental case types with variant where clauses now retain their nominal case type through intersections and type-switch refinements instead of being unsafely reduced to the raw variant hints. a2ad3ec620
  • Thu, Oct 24
    Await expressions on the right side of a pipe, and nested awaits, moved from Preview to Ongoing Release and no longer require the pipe_await feature opt-in. d26ca17cef
  • Fri, Oct 25
    --type-at-pos-batch now handles a batch containing both expression-tree splice positions and ordinary positions without applying splice virtualization to the whole batch. c546c0f2d0

Breaking Changes

1 change
  • Wed, Oct 23
    Cyclic as bounds on type aliases and newtypes are now rejected explicitly. These already failed indirectly after cycle recovery produced mixed; the checker now points to the unsupported bound itself. Cyclic super bounds are unchanged. 82a6a0afae
