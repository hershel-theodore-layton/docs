Week 44: Oct 28–Nov 3, 2024

8 noteworthy changes, organized by the source changelog sections.

Future Changes

5 changes
  • Mon, Oct 28
    The new Unstable shape_destructure feature introduces shape expressions as assignment targets, including shapes nested inside list destructuring. This first step adds feature gating and parser recognition; compiler support follows later in the week. 13cd4d3d36
  • Tue, Oct 29
    Nested expression trees moved from Preview to Ongoing Release, so ordinary nesting no longer needs the expression_tree_nest opt-in. The separate nested-binding feature remains Unstable. 377dbfd786
  • Tue, Oct 29
    Packages v2 exempts both callers in __tests__ paths and symbols defined there from package-boundary checks. 3b5d5ffb29
  • Wed, Oct 30
    HHVM can now execute the Unstable shape-destructuring syntax, including nested list/shape targets, local and indexed destinations, and string, nameof, or class-constant shape keys. 54a4bac107
  • Fri, Nov 1
    Package v2 now canonicalizes both the project root and the PACKAGES.toml parent in strict mode, and neither in non-strict mode. This fixes include_paths matching when the two paths previously used inconsistent canonicalization. 966300bf04

Highlights

2 changes
  • Wed, Oct 30
    HHVM now populates $_SERVER['REQUEST_TIME_MONOTONIC_NS'] from the monotonic clock alongside the existing realtime request timestamps, enabling elapsed-time measurements that are not affected by wall-clock adjustments. 5226b11299
  • Thu, Oct 31
    Hack now loads package configuration before server startup and stores it in the original global options, ensuring remote typechecking receives the same package membership information as the local server. b0197966f0

Breaking Changes

1 change
  • Fri, Nov 1
    Hack now detects more impossible shape accesses when the shape is hidden behind an abstract type constant, generic bound, or intersection. Shapes::idx(), Shapes::at(), Shapes::keyExists(), and coalesced indexing can consequently report new errors or always-false checks, with the explanation pointing back to the relevant shape bound. b006f0e38f 25c058fc89
