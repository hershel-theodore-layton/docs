Week 45: Nov 4–Nov 10, 2024

13 noteworthy changes, organized by the source changelog sections.

Breaking Changes

1 change
  • Mon, Nov 4
    HHVM now enforces every upper-bound constraint on typed properties when an object is unserialized and when a property is unset. Values that satisfied the main property hint but violated a generic upper bound can now throw a property type-hint error during APC/unserialization or unset(). a5b29ce0d7

Future Changes

9 changes
  • Mon, Nov 4
    The unstable shape_destructure feature now handles typed-local enforcement, readonly propagation, and lambda captures for shape destructuring. These commits are supporting pieces of the feature rather than a general release. cb09ea0337 313b039506 426e187bb8
  • Tue, Nov 5
    The unfinished module_references feature has been removed, including imports and exports blocks and ReflectionModule::getImports()/getExports(). Ordinary Hack modules and package-v2 relationships are unaffected. 9a3740165f
  • Wed, Nov 6
    Unstable shape destructuring can now be used as a foreach value pattern, including nested shape and tuple patterns. It still requires <<file:__EnableUnstableFeatures('shape_destructure')>>. 394673c13a
  • Wed, Nov 6
    Package v2 active deployments are now honored while building a repo: files are selected from include_paths and __PackageOverride attributes instead of module membership. This remains part of the staged package-v2 rollout. 0548222340
  • Wed, Nov 6
    Memoized calls now produce the same key for a class name represented as a string, lazy class, or class pointer. This fixes duplicate cache entries during the class-pointer rollout. 9c245379fd
  • Thu, Nov 7
    Behind the class-pointer rollout switches, class<T> now has its own local type instead of being erased to classname<T>. enable_class_pointer_hint=false retains the old erasure, while class_sub_classname temporarily controls the compatibility subtype relation. The implicit C::class constant can likewise be typed as class<C> through the staged class_class_type option. 4e3cc786fe f9f4398bdf
  • Thu, Nov 7
    Package v2 no longer reports package-access errors for exception types named in catch arms. 2b465f3615
  • Fri, Nov 8
    Package v2 can select a different hhvm.active_deployment for CLI-server requests than for web-server requests. The typechecker also stops reporting package errors inside opaque newtype definitions and constraints, while transparent aliases continue to be checked. 279d33d3f9 97b8a89659
  • Fri, Nov 8
    The temporary runtime/compiler option Eval.PackagesTomlFileName allows the staged package-v2 rollout to load a TOML filename other than PACKAGES.toml. 2e20fd28e9

Highlights

3 changes
  • Tue, Nov 5
    The new Log.BaseDirectory runtime option prefixes server error, access, admin, and Xbox log-file paths, allowing separate tasks to use the same relative logging configuration under different directories. 2085abb477
  • Wed, Nov 6
    The Thrift extension adds thrift_protocol_write_binary_struct() and thrift_protocol_write_compact_struct(), which serialize a struct without an RPC message envelope. The compact form accepts an optional protocol version, defaulting to 2. 9e49db492b
  • Wed, Nov 6
    Generated runtime configuration now forwards Repo.Authoritative correctly after the configuration-system migration, preventing consumers from observing a stale or incorrect repo-mode value. 67acf766d8
