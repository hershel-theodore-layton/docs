Week 49: Dec 2–Dec 8, 2024

4 noteworthy changes, organized by the source changelog sections.

Highlights

3 changes
  • Mon, Dec 2
    Extended Hack diagnostics can now render source context for positions inside HHI files instead of falling back to “No source found.” This makes errors that point into built-in declarations substantially easier to interpret. ddb28b2550
  • Fri, Dec 6
    HH\get_class_from_object(readonly object)[]: class<mixed> returns an object's class pointer, while HH\get_parent_class_from_class(readonly class<mixed>)[]: ?class<mixed> returns its parent or null. Both APIs have an explicit empty capability list [], so callers need no ambient capabilities. c4650b12f7
  • Fri, Dec 6
    Diagnostics involving implicitly pessimised properties and returns now explain why the like type was introduced—for example, an unenforced generic argument, type constant, function type, or call on a dynamic value. 0d45f2066c

Future Changes

1 change
  • Fri, Dec 6
    The unstable expression-tree implementation now preserves the enclosing async state through generated and explicit client lambdas, so await inside nested splices is lowered correctly. Unsupported yield expressions also receive a direct diagnostic. fa0ef516d2 033b634564
