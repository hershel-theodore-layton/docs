Week 2: Jan 6–Jan 12, 2025

5 noteworthy changes, organized by the source changelog sections.

Breaking Changes

1 change
  • Tue, Jan 7
    DateTimeZone::listIdentifiers() and DateTimeZone::listAbbreviations() now use the default impure context instead of []. This corrects their dependence on external timezone data, but means they can no longer be called from a pure context. f073bea3f4

Highlights

2 changes
  • Thu, Jan 9
    HH\XReqSync now records the next waiter as a mutex's owner before waking it, fixing lock handoff failures when several requests contend for the same mutex. 9e251bb7ae
  • Fri, Jan 10
    "Extract into method" now strips implicit like types throughout generated parameter and return types, avoiding suggestions containing source-level ~T hints that users did not write. ae9f4200f3

Future Changes

1 change
  • Thu, Jan 9
    Experimental recursive case types can now satisfy recursively structured as bounds such as shape(?'a' => nonnull) without the cycle detector prematurely replacing the type with mixed. 72b236ce34

Security

1 change
  • Fri, Jan 10
    Async MySQL certificate callbacks now hold a weak reference to their operation and fail safely if a cancelled or timed-out connection has already released it, preventing a use-after-free during certificate validation. 693eb7f80e
