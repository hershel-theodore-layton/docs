Week 3: Jan 13–Jan 19, 2025

7 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

2 changes
  • Mon, Jan 13
    Non-repo-authoritative HHVM gained HH\SimpleLock, a named cross-request mutex API with asynchronous lock(), immediate try_lock(), unlock(), and a timeout helper. Locks abandoned at request shutdown are released automatically. ea44027434
  • Fri, Jan 17
    The new HH\gc_is_conservative() builtin reports whether HHVM's garbage collector is operating without any conservative type scanners. 3f6dfef71e

Future Changes

5 changes
  • Mon, Jan 13
    Packages v2 now requires every package's includes and soft_includes sets to contain their full transitive closure, and reports all missing nested packages in one configuration error. 1f4c78a1a3
  • Thu, Jan 16
    Open tuple hints with optional, variadic, or splat elements are now rejected in is and as expressions because HHVM does not yet support enforcing those runtime checks. 591fe0ae72
  • Fri, Jan 17
    Runtime type structures for open tuples now preserve required elements in elem_types, optional elements in optional_elem_types, and a variadic tail in variadic_type. Absent optional or variadic parts omit their corresponding fields. 4c9affb24d
  • Fri, Jan 17
    A type used after the experimental splat operator must now be known to be a tuple—typically through a bound such as T as (mixed...). Unconstrained generics used in tuple or function-type splats now produce a constraint error. 700abe325e
  • Fri, Jan 17
    Recursive case-type runtime handling now preserves generic arguments, resolves cycles involving aliases more reliably, and refuses recursive is/as enforcement that could recurse without bound. 0d7f21793a
