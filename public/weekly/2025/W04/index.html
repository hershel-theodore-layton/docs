Week 4: Jan 20–Jan 26, 2025

11 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

9 changes
  • Mon, Jan 20
    Hack's language server now implements the standard $/setTrace notification in addition to VS Code's older $/setTraceNotification, allowing clients to toggle verbose protocol tracing without receiving a method-not-found response. 6ff6878cbd
  • Mon, Jan 20
    The Hack server gained an exhaustive folded-declaration invalidation mode for saved files, favoring correctness when stale folded declarations would otherwise make IDE results disagree with the CLI. 7ef8817196
  • Tue, Jan 21
    Timezone data was updated to the 2025a release, including newly added historical transitions that can change results for old timestamps. e49a2d45dc
  • Tue, Jan 21
    Overrides of ordinary class methods marked <<__NoAutoLikes>> now inherit that behavior automatically, so their return types are not implicitly widened to like types. Interface implementations still need their own annotation. 7a353344ec
  • Thu, Jan 23
    Classes using the same trait through many branches of a trait diamond no longer count duplicate imported methods toward HHVM's 65,535-method limit, avoiding a false "Class has more than 65,535 methods" failure. 2566b4e7d8
  • Fri, Jan 24
    HHVM now reports a clear error when a non-default Eval.PackagesTomlFileName cannot be opened instead of silently continuing with an empty package specification. f9035ba600
  • Fri, Jan 24
    The unsurfaced-exception lint no longer produces false positives for exception variables captured by lambdas during the dynamic TAST pass. 527a1dc8e7
  • Fri, Jan 24
    HH\SimpleLock\is_held() reports whether any request currently holds a named SimpleLock. a2466c5ee3
  • Fri, Jan 24
    The new #ICInaccessibleSpecialCase memoization option allows specialized functions to read implicit context without sharding their memo cache by it. Like #MakeICInaccessible, it is restricted to defaults, leak_safe_shallow, or leak_safe_local contexts. 2e164dc8db

Future Changes

2 changes
  • Tue, Jan 21
    Expression-tree lambdas now reject a bare nested splice such as ${$x ==> ${$x}}; splicing is only valid while the parser is directly inside an expression-tree literal. d796173ae4
  • Thu, Jan 23
    JSON-encoded type information for open tuples now carries optional_args, variadic_arg, or splat_arg instead of collapsing every open tail into fields_known: false. This improves structured type-error and IDE consumers. ade6c78117
