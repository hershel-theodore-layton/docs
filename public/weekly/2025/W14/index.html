Week 14: Mar 31–Apr 6, 2025

11 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

5 changes
  • Mon, Mar 31
    A missing or unreadable PACKAGES.toml, including exceptions raised while opening it, now logs a warning and falls back to an empty package specification instead of terminating ungracefully. Parse errors in a file that was successfully opened remain fatal configuration errors. 01d32e26ad
  • Tue, Apr 1
    Redundant or impossible is and as checks are now detected after stripping the dynamic part of most like types, revealing more always-true and always-false checks without producing false positives for ~null. cb98bf2069
  • Wed, Apr 2
    Constructor arguments are typechecked even when resolving the constructed class yields only dynamic, so errors inside those arguments are no longer missed. b650999cb7
  • Wed, Apr 2
    Changes to enum members now correctly fan out to files whose switch exhaustivity depends on that enum. 4a25a14787
  • Fri, Apr 4
    Plain <<__Memoize>> functions with contexts such as [leak_safe] are no longer rejected merely because memoize-policy configuration is enabled. The parser now applies or requires #KeyedByIC only when the function's context can actually access implicit context. a278d85633 6d7717e2e1

Breaking Changes

1 change
  • Mon, Mar 31
    The HHVM repository compiler has removed --repo-options-dir. It now reads .hhvmconfig.hdf and PACKAGES.toml relative to --input-dir, so build scripts that kept source input and repository options in different roots must align or stage those files first. cbff84ff23

Future Changes

5 changes
  • Tue, Apr 1
    Packages v2 include_paths entries in PACKAGES.toml must now end in /. This prevents a path such as flib/intern from also matching flib/internal_prod. 5f584f16cb
  • Wed, Apr 2
    Packages v2 repo builds can now select files from an active deployment, symbol references, or both. --exclude-file and --exclude-pattern remain absolute exclusions, while package rules or symbol references may pull files back from --exclude-dir. 5bd4e8173b
  • Thu, Apr 3
    Packages v2 repo builds accept --report-files-in-build=<file> to write an exhaustive list of included source files, including files selected without a symbol-reference edge. e23a4e9c4c
  • Fri, Apr 4
    The staged __NeedsConcrete checker now enforces that calls to marked methods have a concrete late-static receiver, while permitting abstract-member access through static inside a __NeedsConcrete method. 8230cf15b4
  • Fri, Apr 4
    Reflection type-structure kinds now include OF_UNION and OF_RECURSIVE_UNION for case types. 0ab406eaf4
