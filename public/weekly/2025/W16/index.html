Future Changes

3 changes
  • Mon, Apr 14
    Packages v2 is tightening boundary checks around class-pointer migration. New compatibility flags can temporarily allow violations from ::class, reifiable type constants, reified or erased generics, and all type constants; strict configurations can now check each of those positions. 5fa8eae5c6 a5c3b02b55 cd924b79dd f11e6f2900 cec831da05
  • Tue, Apr 15
    A type and a tuple containing only that type as a splat are now treated as equivalent: (...T) <: T and T <: (...T). 399bc551e2
  • Thu, Apr 17
    Calls to functions with a type-splat parameter can now pass an expression splat. For example, a final ...$args is checked by comparing the actual tuple, including its splat tail, with the parameter tuple. 830f0a4d73

Highlights

1 change
  • Wed, Apr 16
    HSL's OS exception dispatch no longer uses class pointers as keyset string keys, eliminating a burst of implicit class-to-string notices when an OS operation throws. a0698adb2a

Breaking Changes

3 changes
  • Wed, Apr 16
    The runtime implementation of reflection's getAttributeClass now expects a class<mixed> and performs its own explicit classname conversion, beginning the migration away from accepting classname strings. 7a0f146cd3
  • Fri, Apr 18
    The deprecated HH\asio_get_current_context_idx and HH\asio_get_running_in_context functions have been removed from the HHI and autoimports. Use HH\asio_get_current_context_depth and HH\asio_get_running instead. 13c7313fb1
  • Sat, Apr 19
    The runtime implementations of the deprecated HH\asio_get_current_context_idx and HH\asio_get_running_in_context functions have now been removed as well. bb54bd8f99
