Future Changes

4 changes
  • Mon, May 26
    Well-formedness checking for unstable polymorphic lambdas now binds the lambda's type parameters before checking their explicit bounds, avoiding spurious errors for bounded generic lambdas. 08dfda4896
  • Tue, May 27
    The experimental EdenFS watcher can now initialize when the Hack project is a subdirectory of an Eden mount, and reports a dedicated error when the project is not on Eden. Notifications still use the temporary Watchman bridge. 2188c6b045
  • Tue, May 27
    Unstable type-splat validation now preserves constraints learned while localizing type-constant projections before checking that the result is a subtype of (mixed...). 1532063bd0
  • Thu, May 29
    Hackfmt now preserves the required function keyword on unstable polymorphic lambdas, and lambda well-formedness reuses top-level function binding so parameter types can refer to the lambda's own type parameters. 817ea043fe 09e22a92af

Highlights

2 changes
  • Tue, May 27
    Reified-type validation now recognizes that this inside a final class has no unknown late-static-binding subtype, allowing it where the checker can determine the concrete reified type. 269854f5c6
  • Thu, May 29
    hh --help now documents --error-format extended, making extended type-error reasons discoverable without consulting source or wrapper scripts. 6275ca880a

Breaking Changes

4 changes
  • Wed, May 28
    HHVM now rejects $class::$method() at runtime as well as in the checker. Code generated or executed without hh_server validation must also migrate to a static call or HH\dynamic_class_meth(). a51e712dc0
  • Wed, May 28
    HHVM also rejects computed static-method forms such as C::{expr}(), completing the runtime removal of dynamic static-call syntax. 7a9777a8a7
  • Wed, May 28
    iterator_to_array() has been removed from both the HHI and HHVM. Replace it with dict($iterator) when preserving keys or vec($iterator) when collecting values. 1187cf3a01
  • Thu, May 29
    Global constants declared under a nonexistent module now receive the same Unbound name error already applied to other top-level declarations. 351328f8b9
