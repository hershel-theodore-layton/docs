Future Changes

8 changes
  • Mon, Jun 30
    When the experimental EdenFS-backed file watcher cannot initialize, hh_server now falls back to the next enabled notifier—normally Watchman—instead of failing outright. 6d4cfd4936
  • Mon, Jun 30
    Nested type-parameter declarations used for experimental higher-kinded types, such as class Foo<TC<TX>> {}, are no longer part of Hack's grammar. The --enable-higher-kinded-types single-file checker flag and its internal option have also been removed; projects must express abstractions with supported ordinary generics. b0f3ed5c9c 60adf9a9fb
  • Tue, Jul 1
    Rank-2 typing for polymorphic static- and instance-method pointers is now gated by the default-off poly_function_pointers option. Projects not enabling the staged option retain the earlier monomorphic behavior. 0259359b71
  • Wed, Jul 2
    Incremental dependency tracking no longer drops a method dependency created by staged polymorphic meth_caller() typing, so editing the referenced method correctly schedules affected callers for rechecking. 09093000bd
  • Wed, Jul 2
    With the experimental constraint_array_index option, array access now solves a can_index constraint for vec and dict values. This begins a staged path toward inferring both valid key types and indexed result types. ff4e369a8c bfa476bd72
  • Thu, Jul 3
    require this as constraints are now emitted into HHVM metadata, and HHVM checks trait constraints while loading a class. This extends runtime support for the staged constraint syntax. 7e7567642d
  • Thu, Jul 3
    Experimental can_index constraint solving now covers keyset. 3b516d94fa
  • Fri, Jul 4
    Experimental can_index constraint solving now supports reads and writes on Vector. cd84a52865

Breaking Changes

2 changes
  • Thu, Jul 3
    The legacy apache_request_headers() and getallheaders() declarations have been removed from the HHI, so typechecked Hack code can no longer call either API. The removed getallheaders() declaration required [read_globals]; this is an API removal, not a narrowing of that capability requirement. fdbee7ee64
  • Sat, Jul 5
    Distributed typechecking configuration now uses hh_distc_fanout_threshold as the lower activation threshold and replaces hh_distc_fanout_aware_threshold with hh_distc_fanout_full_init_threshold. Fanout-aware mode also requires the new default-false enable_fanout_aware_distc switch, so deployments using the old key must update their server-local configuration. 0617ce8382
