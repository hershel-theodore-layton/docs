Week 30: Jul 21–Jul 27, 2025

10 noteworthy changes, organized by the source changelog sections.

Highlights

2 changes
  • Mon, Jul 21
    Type refinements for runtime generic-class tests now instantiate wildcard arguments existentially. Checks such as $x is C<_> can therefore partition and refine generic values without inventing a concrete wildcard type. a2835215c6 215bdd8e7e
  • Tue, Jul 22
    Runtime is checks and type verification now treat <<__Soft>> constraints as mixed, matching the textual bytecode backend and preventing a soft annotation from being accidentally enforced as a hard type. 32c03fcd51

Future Changes

7 changes
  • Mon, Jul 21
    protected internal visibility has moved to OngoingRelease. It remains staged rather than generally released. ae83995461
  • Mon, Jul 21
    Hack.Lang.EmitCheckedUnsafeCast again controls whether staged checked HH\FIXME\UNSAFE_CAST operations emit runtime verification bytecode. 510db3d624
  • Tue, Jul 22
    Eval.CheckedUnsafeCastSampleRate controls runtime checking of staged unsafe casts: 0 disables checks, 1 checks every cast, and larger values sample one in every N casts. 421c0f3788
  • Tue, Jul 22
    Experimental can_index solving now handles additional supportdyn values and the anyarray supertype. 10c6c23233 797f721dc0
  • Wed, Jul 23
    The experimental EdenFS watcher adds edenfs_file_watcher_throttle_time_ms, allowing projects to set the minimum interval between change notifications. 5f9013dd55
  • Thu, Jul 24
    Experimental can_index solving now permits dynamic keys in sound-dynamic code and treats the key parameter covariantly, improving inference for indexed generic values. b4e92a8d51 11d432e4d1
  • Fri, Jul 25
    Experimental can_index solving now understands optional and variadic tuple elements and produces more specific tuple-index diagnostics. 65834b5156 532dd723e5

Breaking Changes

1 change
  • Fri, Jul 25
    SoapServer::addFunction() now throws SoapException when passed a single function-name string. Code using string registration must move to one of the API's supported non-string registration forms or redesign the dispatch path. eebe7d5a17
