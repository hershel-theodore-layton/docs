Week 31: Jul 28–Aug 3, 2025

12 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

8 changes
  • Mon, Jul 28
    HH\FileDecls::getPublicApiForClass(string $name)[] returns a source-like rendering of a class's public methods, constants, type constants, inheritance, and implemented interfaces. Its explicit [] means tooling can call it from any capability context. 920bfa05ee
  • Tue, Jul 29
    --report-files-in-build now works for legacy non-Packages-V2 repo builds, and build reports identify why each file was included—for example through package selection, symbol references, autoload roots, or explicit include paths. 40aa523fd5 f4df5c5e47
  • Tue, Jul 29
    HHVM now defines the built-in pseudoconstant newtypes in systemlib as well as in the HHI, preventing values such as __METHOD__ from being mistaken for class names at runtime. 49f2d63ded
  • Tue, Jul 29
    Public-API rendering through HH\FileDecls now includes constructors. d6cd4b01f2
  • Wed, Jul 30
    The Rust full-fidelity syntax tree now computes parentage offsets from each child node's width rather than the parent's width, fixing offset-based parser and IDE queries. 90d676478f
  • Wed, Jul 30
    The Hack assembly parser again accepts multiple space-separated .file_attributes, allowing bytecode containing more than one file attribute to verify and assemble. 3487d1ec02
  • Thu, Jul 31
    HHVM no longer attempts to load Package V1 deployment data when deployment enforcement is disabled, fixing commands such as hphpd -h that run without an active deployment. 90fc996b29
  • Thu, Jul 31
    Hack notebooks now run the legacy debugger in server mode, enabling clients to connect to their evaluation process. 4b5791d1ba

Future Changes

3 changes
  • Mon, Jul 28
    Experimental can_index solving now handles aliases, pessimised types, optional shape keys, constant keys, and TypeStructure values more consistently. 3b66e2c991 1b126653a7 82ed90eceb ab0d241d9c
  • Tue, Jul 29
    Staged polymorphic function-pointer types now simplify type parameters that occur only covariantly or only contravariantly by substituting the appropriate bound. 15e374473c
  • Tue, Jul 29
    Case-type where clauses have moved to Preview on the HHVM side, but are not yet generally released. 6bebd36a39

Breaking Changes

1 change
  • Thu, Jul 31
    HPHPD no longer supports creating, listing, clearing, enabling, or disabling breakpoints. Projects that still use HPHPD for debugging should migrate breakpoint workflows to the VS Code debugger. 4b5791d1ba
