Week 33: Aug 11–Aug 17, 2025

13 noteworthy changes, organized by the source changelog sections.

Highlights

5 changes
  • Mon, Aug 11
    hh_client check --single now processes batches of ten or more files in parallel. The new --multi FILE form reads one path per line, making large targeted checks easier to script. 8c8f596073 5ca15ac9d8
  • Mon, Aug 11
    The dead-HH_FIXME and dead-unsafe-cast cleanup modes no longer require restarting hh_server with --no-load. e7f422bb80
  • Wed, Aug 13
    The JIT now has a dedicated implementation for HH\Lib\PseudoRandom\int(), avoiding the pessimization associated with a generic native call while preserving its inclusive range behavior. d51a44a881
  • Fri, Aug 15
    Dependency tracking now covers more static members, XHP checks, switch exhaustivity, constructors, and IDE member lookups. Incremental checks should miss fewer affected files, though some changes may produce larger recheck fanout. 46ce64d386 967773dd8a
  • Sat, Aug 16
    HHVM now frees the losing class object when concurrent requests race to define the same class, closing a runtime memory leak in non-repo-authoritative deployments. aefb3fa931

Future Changes

7 changes
  • Mon, Aug 11
    Parser support has begun for named parameters and named arguments. These commits only recognize the pre-MVP syntax; full naming and typing behavior is not yet available. f6791eda8f b270ae7302
  • Tue, Aug 12
    The opt-in warning system now reports warning 12023 when e1 ?? e2 has a left operand known to be always null or never null. Array-subscript forms are excluded because their null behavior is intentional and common. bd805a1455
  • Wed, Aug 13
    Named arguments are now lowered from the concrete syntax tree into the Hack AST, continuing the pre-MVP implementation begun earlier in the week. 9063a1301e
  • Wed, Aug 13
    The class-pointer migration adds HH\type_structure_class($class_or_object, $type_constant)[], a NoDoc helper that loads and returns the class<mixed> named by a type constant. Its empty coeffect list means it can be called from capability-free contexts. 6123f3b736
  • Thu, Aug 14
    With the opt-in needs_concrete analysis enabled, unsafe calls and instantiations through abstract classes are now warnings 12024–12026 rather than hard type errors 4490–4492. This makes the safe-abstract migration incremental. 7ae30448ae
  • Fri, Aug 15
    The ongoing no_disjoint_union rollout now applies <<__NoDisjointUnion>> to the key type of HH\idx() and HH\idx_readonly(). Calls that infer incompatible key types, such as a string key for a vector-like container, can now produce warning 12017. c5f6c4171e
  • Fri, Aug 15
    Named parameter declarations are now represented in the AST, but the named-argument feature remains pre-MVP and unavailable for general use. 98bc300a62

Breaking Changes

1 change
  • Tue, Aug 12
    hphpd no longer implements the down, up, next, frame, step, or out commands. Command-line debugging is no longer supported; the remaining tool is primarily useful as a REPL. 86676af0f4
