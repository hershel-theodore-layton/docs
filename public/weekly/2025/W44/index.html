Week 44: Oct 27–Nov 2, 2025

10 noteworthy changes, organized by the source changelog sections.

Highlights

6 changes
  • Mon, Oct 27
    New auto-imported objprof_get_data_with_graph_stats(), objprof_get_data_extended_with_graph_stats(), and objprof_get_paths_with_graph_stats() can bound traversal with max_depth and max_visits. They return the usual object statistics plus nodes_visited and max_depth_seen; omitted capability brackets mean [defaults]. b8a2b2c9d7 5b20747174 6663dc9b4e
  • Mon, Oct 27
    CUSTOM_ERRORS.json can now match Cross_pkg_access and Cross_pkg_access_with_requirepackage by use and declaration file. Missing-member class patterns are also namespace-aware, so top-level names no longer require a leading backslash in a plain string pattern. bc740ac7e2 5b894225af
  • Tue, Oct 28
    The VS Code debugger's stepIn request now records the current stack depth before resuming, fixing cases where stepping entered the wrong function. b991fdf189
  • Thu, Oct 30
    Default-parameter initializer bytecode now uses the parameter's source location. Runtime type errors point to the parameter declaration rather than the function's closing brace, and default-value funclets are excluded from executable-line and coverage results. 3e366bf718
  • Fri, Oct 31
    Implicit pessimization is more precise for single-parameter functions with enforced return types and for non-overridable methods: top-level functions, non-trait private methods, final methods, and methods in final classes. They accept a like/dynamic argument while retaining the exact enforced return type instead of unnecessarily returning a like type. a4a706bc7a
  • Fri, Oct 31
    Custom-error rules can now capture files from package-primary patterns and member names from missing-member patterns. Custom messages render Markdown styling in terminal and LSP output, and a malformed class name now makes a rule fail to match instead of crashing evaluation. 3787483015 8e501c4a0b b0aa1b2428 32524cb34f

Future Changes

3 changes
  • Mon, Oct 27
    A generic Watcher runtime abstraction has landed as explicit work in progress toward Watchman and Eden backends. It currently has no typechecker HHI, supports only Watchman, and does not yet return its specified output format, so projects should not adopt it yet. cdce35b437
  • Tue, Oct 28
    Experimental recursive case-type localization now carries cycle detection across multiple generic upper bounds, preventing infinite recursion when mutually recursive aliases are reached through more than one bound. 2a02549225
  • Thu, Oct 30
    Experimental expression trees no longer support XHP syntax. DSLs using staged expression trees must splice or otherwise construct XHP outside the tree. 576aa124fa

Breaking Changes

1 change
  • Thu, Oct 30
    Eval.EnableCodeCoveragePerBytecode now defaults to true, so coverage and HH\get_executable_lines() count only bytecodes representing meaningful actions such as calls, branches, assignments, and returns. Reports may contain fewer executable or covered lines; set it to false temporarily for the legacy all-bytecode behavior. 23b107df3e
