Week 46: Nov 10–Nov 16, 2025

12 noteworthy changes, organized by the source changelog sections.

Highlights

6 changes
  • Mon, Nov 10
    Awaiting a static method call or class-constant access inside a pipe no longer leaves an unreplaced $$ for the emitter. Expressions such as $value |> await $$::method() now compile correctly. 533fc364b1
  • Tue, Nov 11
    Function pointers to <<__Native>> functions using <<__TrivialHHVMBuiltinWrapper>> now resolve to the wrapper's target in the interpreter, matching ordinary calls and JIT execution. 594c8fb627
  • Tue, Nov 11
    The Hack client adds hh --log-errors, an asynchronous mode that type-checks a supplied file list and logs its diagnostics after returning immediately. --log-to-file PATH writes those diagnostics to a file, and the mode honors the usual error and warning filters. 78608b1f95
  • Fri, Nov 14
    Custom-error configuration now validates repeated bindings across all supported pattern kinds, preventing valid rules from being rejected—or incompatible bindings from being accepted—when they use newer pattern types. 44ec7ad20c
  • Fri, Nov 14
    Vec\map_with_key_async() no longer constrains input keys to arraykey; it now accepts any KeyedTraversable<Tk, Tv>. The callback coeffect remains [ctx $value_func]. 171f7923fa
  • Fri, Nov 14
    HHVM's unit cache now records a changed repository-options hash even when recompilation produces identical bytecode. Updating .hhvmconfig.hdf or PACKAGES.toml therefore no longer makes unchanged files recompile on every request. 506ac2d22c

Security

1 change
  • Wed, Nov 12
    Package boundary checks now cover global constants. Accessing a constant from another package without a permitted dependency produces Typing[4472], closing a gap in package access enforcement. fcd7b5c771

Breaking Changes

1 change
  • Wed, Nov 12
    hh --package-lint FILE now uses naming and dependency tables instead of fully type-checking reference files. Its JSON output changes from per-definition reference records to a simple array of absolute paths for files that may be affected by moving the input file. 648d385bc7

Future Changes

4 changes
  • Wed, Nov 12
    The ongoing-release sealed_methods feature adds method-level <<__Sealed(...)>>. Its allowlist restricts which classes or traits may directly override a method; constructors, private methods, and interface methods cannot use the attribute. 83a0b8478c
  • Wed, Nov 12
    The new unstable xhp_type_constants feature permits type constants such as A::T and this::TData in XHP attribute declarations. Runtime XHP metadata currently represents these attributes as mixed, so the feature still requires __EnableUnstableFeatures. acca24cbe1
  • Thu, Nov 13
    Preview readonly checking now treats $condition ?: $fallback as readonly when the returned left-hand value or fallback is readonly. Mutating or returning the result in a mutable position can therefore reveal errors that the previous analysis missed. b2a2b3ea0f
  • Thu, Nov 13
    Under the experimental dynamic-assumptions mode (everything_sdt=false), indexing an unknown field of an open shape refined from dynamic no longer produces a false error after Shapes::keyExists(). 9cef9e19bf
