Week 47: Nov 17–Nov 23, 2025

10 noteworthy changes, organized by the source changelog sections.

DayWeekMonth

Highlights

5 changes
  • Mon, Nov 17
    Reified type-structure interning now compares semantically equal type structures without depending on dictionary key order, avoiding debug-build assertions for structures assembled through different inheritance and constraint paths. 3688b57f82
  • Mon, Nov 17
    The JIT no longer applies an unsafe dict/keyset offset optimization when a container may be empty or contain tombstones, preventing incorrect optimized execution. 90a4d19894
  • Wed, Nov 19
    HHBBC no longer performs stack-rewinding or stack-shape-changing reductions while speculating through a block, fixing a path that could incorrectly optimize bytecode. 58b4eb518a
  • Thu, Nov 20
    The debugger no longer sends a DAP thread exited event for a thread whose corresponding thread started event was never sent, keeping client thread state balanced. 9cd2be99d3
  • Sun, Nov 23
    HHBBC now preserves the known staticness of nested dict/keyset keys and values when modeling copy-on-write on an otherwise static array, fixing an optimizer monotonicity bug. 3a858a7274

Breaking Changes

3 changes
  • Tue, Nov 18
    parent::__construct(...) is now checked as an ordinary method call. This correctly supports constructors with <<__SupportDynamicType>>, but also reports an error when the parent class has no constructor instead of silently accepting the call. b1f24f75dd
  • Tue, Nov 18
    With an active deployment, package foo and HH\package_exists('foo') now return false when foo is only softly deployed. This also changes whether <<__RequirePackage('foo')>> requirements are satisfied. 32f696c3e9
  • Wed, Nov 19
    The runtime functions apache_request_headers() and its alias getallheaders() have been removed. Their declarations had already been removed from the standard-library HHI files. be51b361e8

Future Changes

1 change
  • Wed, Nov 19
    .hhconfig gains check_bool_for_condition: 0 keeps existing truthiness behavior, 1 emits Warn[12028], and 2 emits Typing[4504] unless conditions are subtypes of ~bool. The opt-in check covers control-flow conditions, !, &&, ||, and ternaries. f2102bc763

Security

1 change
  • Thu, Nov 20
    HHVM can now enforce Server.RequestFanoutLimit for recursively spawned Xbox requests. With the new Server.EnforceRequestFanout=true setting, exceeding the limit rolls back the counter and throws RequestFanoutLimitExceededException; enforcement is off by default. a96d874cb8
