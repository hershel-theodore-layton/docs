Highlights

4 changes
  • Mon, Dec 29
    JIT recovery now selects the oldest worker for termination and stack capture when the main retranslate-all thread is stuck, even if that worker has not independently exceeded the timeout. A larger initial profiling-prologue table also reduces contention during heavily profiled workloads. 8a64b59275 1050ba1a55
  • Fri, Jan 2
    AsyncMysqlQueryResult now exposes mysqlInfo(), rowsMatched(), and warningsCount(), making the server's query metadata available through the typed API. 28a9e15eca
  • Sat, Jan 3
    New thrift_protocol_write_binary_struct_to_string() and thrift_protocol_read_binary_struct_from_string() built-ins serialize and deserialize binary-protocol Thrift structs without constructing a transport object. Both signatures omit coeffect brackets and therefore require [defaults]. 3b98248f1e
  • Sat, Jan 3
    The obsolete redundant_id lint has been removed. It no longer emits lint code 5501 for old id() wrappers; use parentheses while removing any remaining deprecated calls. 1d7205fa93

Future Changes

1 change
  • Fri, Jan 2
    The Hack manual now documents case-type syntax, runtime-disjoint variants, asymmetric subtyping, and decomposition with is checks. Recursive and conditional case types remain outside this initial guide. 08a5376dac
