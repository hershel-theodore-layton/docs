Week 8: Feb 16–Feb 22, 2026

14 noteworthy changes, organized by the source changelog sections.

Highlights

8 changes
  • Tue, Feb 17
    HH\Facts\type_method_attributes(classname<nonnull>)[] performs a point query for one type and returns a dict from method names to their indexed attribute names. This avoids scanning every method carrying a particular attribute. 632b612e33
  • Tue, Feb 17
    SQLite3Stmt::execute() no longer steps a SELECT, discards its first row, and executes it again on the first fetchArray(). The result buffers the initial row and repeated calls to execute() reset the cursor before running. 7f0dba4f01
  • Tue, Feb 17
    Str\replace_ci() and Str\replace_ci_l() are now explicitly pure ([]) because their case-insensitive implementation no longer consults global locale. Their caller requirement is therefore narrowed from implicit [defaults] to no capabilities. a7cc885222
  • Tue, Feb 17
    Lint 5649 no longer flags an internal class solely because it appears in a __Sealed allowlist. References to the internal class outside that attribute remain linted, so sealed APIs can intentionally enumerate internal implementations without a false positive. 261492cbdd
  • Wed, Feb 18
    hh_client --jsonl streams one machine-readable JSON object per diagnostic followed by a summary object. It is mutually exclusive with --json and preserves the ordinary success or type-error exit status. a79ccef39e
  • Wed, Feb 18
    IDE diagnostics for indexing a keyset or ConstSet now offer direct quick fixes to C\contains_key($keyset, $key) or $set->contains($key). 8a0a29c718
  • Thu, Feb 19
    openssl_pkcs7_read(string $data): vec<string> reads PEM-encoded signed or signed-and-enveloped PKCS#7 data and returns its certificates as PEM strings, throwing when the payload cannot be parsed. Its omitted coeffect brackets mean callers must provide at least [defaults]. 4cd3b1fce0
  • Fri, Feb 20
    ReflectionClass::hasProperty() and getProperties() no longer initialize the reflected class merely to obtain declared property names. Reflection over traits and classes with failing initialization can therefore answer these structural queries safely. 7884df7969

Breaking Changes

2 changes
  • Wed, Feb 18
    Type errors in the first groups of parameters of a lambda with more than five parameters are no longer dropped during error accumulation. Invalid type-constant accesses and similar errors in those positions can now surface. 3a20987e05
  • Fri, Feb 20
    APC now stores a non-persistent class pointer as a lazy class. If the underlying class is later deleted, fetching that APC entry returns a dead lazy class instead of null; callers that used deletion as an existence test must handle the new value. a259ee456e

Future Changes

4 changes
  • Wed, Feb 18
    HHVM gained .hhvmconfig.hdf controls for per-feature Unstable, Preview, OngoingRelease, and Released status. The new map is used only when Hack.Lang.UseLegacyExperimentalFeatureConfig=false; unspecified features remain unreleased unless Hack.Lang.ConsiderUnspecifiedExperimentalFeaturesReleased=true. 651c2bef21
  • Thu, Feb 19
    The named-parameter interpreter now supports omitted optional named parameters by validating the supplied names and filling absent slots with their default values. Variadic packing also preserves the preceding named arguments, while HHBBC continues to avoid unsafe folding of these calls. e3840417e9 89a731962f
  • Fri, Feb 20
    Type-constant access through self inside a trait now uses the class selected by pre-stable require class. This closes a Tany type hole and can expose errors in code that previously escaped checking through an unresolved this::T. 17fb0bda04
  • Fri, Feb 20
    The same self type-constant fix now covers the pre-stable require this as constraint. c7673ad08e
