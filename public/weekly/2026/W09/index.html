Week 9: Feb 23–Mar 1, 2026

15 noteworthy changes, organized by the source changelog sections.

Highlights

7 changes
  • Mon, Feb 23
    Function-pointer inference now tracks type parameters in other parameters' constraints, class and type-constant refinements, and occurrences of this with their precise variance. This removes unnecessary first-class polymorphic types while preserving the correct co- or contravariant bound. 20e6acc12d 9a880e8a6b bf9fc1fc91
  • Mon, Feb 23
    Lambdas created inside a function protected by __RequirePackage or __SoftRequirePackage now retain the package availability of their creation continuation. This permits sound higher-order and recursive uses without granting packages that were unavailable outside the lambda. bec949706c
  • Mon, Feb 23
    get_active_worker_counts() is now known to Hack and returns a shape containing pagelet, Xbox, HTTP, and CLI worker counts. The declaration omits coeffect brackets and therefore retains the [defaults] caller requirement. 531391b170
  • Tue, Feb 24
    Reflection parameter APIs now have concrete HHI return types: boolean predicates return bool, class lookups return ?ReflectionClass, and isDefaultValueConstant() returns ?bool. This replaces HH\FIXME\MISSING_RETURN_TYPE, so callers gain useful static checking. bf3d95c54b
  • Wed, Feb 25
    HH\Asio\cancel_sleep_nothrow(SleepWaitHandle $wh): bool completes a pending sleep successfully with null instead of failing it with an exception. It returns whether cancellation occurred; its omitted coeffect brackets mean [defaults]. 2a17049a2a
  • Fri, Feb 27
    New HH\ImplicitContext\PreparedContext values let implicit-context subclasses prepare several assignments in pure code and apply them together with runBatch() or runBatchAsync(). The batch methods require [leak_safe, ctx $f]: callers must already have a capability set containing leak_safe and the callback's requirement; the list does not grant those capabilities. 3252eaa4eb
  • Sat, Feb 28
    JIT-compiled is_scalar() now matches the interpreter's runtime definition for every value type, removing mode-dependent answers caused by an incorrect JIT type test. c7843d7c59

Breaking Changes

4 changes
  • Mon, Feb 23
    Lint 5655 now reports references from a file assigned by package rules into a file moved into that same package with __PackageOverride. References guarded by an appropriate __SoftRequirePackage are exempt; other edges should move the target, add __RequirePackage, or be guarded by a package check. 216d08b79c 91243638d1
  • Wed, Feb 25
    Package boundaries are now enforced for function pointers and reified generic arguments, and the package_allow_function_pointers_violations and package_allow_reified_generics_violations escape hatches have been removed. References such as OtherPackage\f<> and cross-package reified type arguments now require that package to be available. fb27a911ff 8677c548f3
  • Thu, Feb 26
    Type-constant propagation now skips mixed and supportdyn<mixed> upper bounds instead of expanding mixed::T into Tany. This closes a soundness hole in where-clause inference and can reveal errors that were previously hidden after related type variables collapsed to Tany. e12516a086
  • Fri, Feb 27
    Package checking is now always enabled, package and deployment inclusions are always checked for transitive closure, and __RequirePackage remains allowed on interface methods. The corresponding check_packages, package_config_disable_transitivity_check, and allow_require_package_on_interface_methods settings have been removed; delete stale overrides. 8d391cf433

Future Changes

4 changes
  • Tue, Feb 24
    Dynamic invocation paths can now pass named-argument metadata through invokeFunc*, including constructor invocation. This extends the staged named-parameter runtime beyond direct bytecode calls, but does not by itself complete the language feature's release. 9b3e5ec269
  • Wed, Feb 25
    Lambdas involving expression-dependent type constants with multiple upper bounds no longer make the typechecker recurse indefinitely when a bound refers back to itself. This affects the unstable type_const_multiple_bounds feature. 9118df03a0
  • Wed, Feb 25
    Recursive case-type expansion now preserves the recursive Tnewtype identity underneath constructors such as vec, tuples, shapes, functions, and class applications. This closes an unstable-feature soundness hole where case type CT = vec<CT> | int could incorrectly accept vec<string> as CT. b5903cf3aa
  • Fri, Feb 27
    The JIT can now use the normal function-entry calling convention for direct named-argument calls whose named parameters are all required. It validates the argument names at translation time and otherwise generates the same happy-path call shape as positional arguments; optional and repacking cases still fall back. d26c627ba8
