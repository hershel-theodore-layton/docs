Week 11: Mar 9–Mar 15, 2026

10 noteworthy changes, organized by the source changelog sections.

Highlights

4 changes
  • Mon, Mar 9
    Exhaustiveness checking now follows a user-defined newtype's upper bound when that bound is an enum. A complete switch over newtype Wrapped as MyEnum = MyEnum no longer needs a redundant default case. 7849dd4079
  • Thu, Mar 12
    Lambda type-parameter exposure now removes expression-dependent variables from recursive refined builder types instead of retaining them across later lambdas. This avoids cubic typechecking behavior in fluent-builder code with class refinements. db5234971c
  • Thu, Mar 12
    The persistent Hack server no longer gets stuck or returns stale results when one file changes while an earlier recheck is being interrupted. Files left in disk_needs_parsing now trigger another typecheck even when no additional filesystem event arrives. 6bfec3705a
  • Sat, Mar 14
    hh --outline-for-agents FILE emits a compact list of a Hack file's declarations and line ranges while hiding private members. It gives coding tools a cheap map of large or generated files before they read the relevant ranges. a52d4298ea

Future Changes

2 changes
  • Tue, Mar 10
    Mutually recursive pre-stable case-type bounds no longer send the typechecker into an infinite loop; upper-bound localization now avoids recursively simplifying intersections. 7e5b31d920
  • Fri, Mar 13
    With strict_consistent_construct=true, an abstract class may no longer extend a non-abstract <<__ConsistentConstruct>> class. The opt-in rule prevents new static() from resolving to an uninstantiable intermediate class. 8c7ea12399

Breaking Changes

4 changes
  • Wed, Mar 11
    The built-in date/time HHI now gives many formerly untyped APIs concrete parameter and return types, including checkdate(): bool, timezone getters and setters, DateTime mutators returning this, and typed DateTime/DateInterval parameters. Calls that previously flowed through missing HHI types may now report type errors. 7e8a8d7133
  • Thu, Mar 12
    Misspelled script markers such as <?h, <?hx, or <?h h are no longer mistaken for PHP and silently skipped. Hack treats them as source files and reports a parse error directing authors to <?hh; valid <?php and bare <? PHP markers remain skipped. cffabe0510 b0addbd6a3
  • Thu, Mar 12
    Legacy @T soft type hints are now unconditionally rejected; the already-default-on disable_legacy_soft_typehints setting and CLI flags were removed. Use <<__Soft>> T and delete stale configuration overrides. 28379910d0
  • Fri, Mar 13
    Date/time declarations were tightened further: procedural functions such as date_diff(), date_format(), and date_sub() now have concrete date/time parameters and returns; DateTime mutators return this, diff() returns DateInterval, and DateTimeZone::getOffset() returns int. Invalid calls and assumptions previously hidden by missing HHI types can now fail typechecking. 9b933e837e
