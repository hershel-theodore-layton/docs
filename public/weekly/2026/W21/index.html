Highlights

2 changes
  • Tue, May 19
    hh --infer-dynamic FUNCTION and hh --infer-dynamic-as-data FUNCTION infer candidate types for local dynamic values from how they are called, indexed, traversed, awaited, and refined. The server returns JSON solutions; the as-data form favors shapes and vectors for data-like access patterns. e3ecb1cc09 5e30b94a43 4268ce9b9a e766c827f9
  • Wed, May 20
    The VS Code debugger now loads its startup document while the sandbox source root is active. Debugger REPL expressions can therefore resolve classes and class constants from the local checkout instead of accidentally initializing the autoloader against the deployed tree. 1111b878a7

Future Changes

3 changes
  • Tue, May 19
    HackC can now emit bytecode for unstable shape and tuple destructuring. Together with the parser and typechecker work from earlier in the month, the basic staged implementation now spans the frontend and runtime. 4c20e78881
  • Fri, May 22
    Preview RepresentableAs now refines case-type variants correctly across files and accepts structurally compatible generic and dependent types through their bounds. This fixes cases where RepresentableAs<int> or tuple-backed variants previously degraded to mixed or failed subtyping. 0626e4c354 d1836b6ae6
  • Sat, May 23
    ReflectionParameter::isNamed()[] reports whether a parameter uses Preview named-parameter syntax. Positional parameters return false; named parameters, including optional ones, return true. a53d527ec7
