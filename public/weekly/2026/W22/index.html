Week 22: May 25–May 31, 2026

8 noteworthy changes, organized by the source changelog sections.

Highlights

2 changes
  • Tue, May 26
    The Rust declaration provider received correctness fixes for class/type name collisions, trait __Override diagnostic positions, and descendant invalidation. In particular, unchanged shallow declarations are retained so stale remote declarations cannot suppress required fanout. 5f7f1b1004 92a95e3bf4 e40ada60a0
  • Wed, May 27
    Symbol indexing no longer drops static-property references such as Class::$property, self::$property, and static::$property. Target-use queries and tools backed by the Hack index can now find those xrefs. 85d45051d3

Breaking Changes

5 changes
  • Tue, May 26
    hh_server, hh_single_type_check, and hh_single_decl now use the Rust provider backend by default where supported. The positive hh_single_type_check --rust-provider-backend flag has been removed; use hh_single_type_check --config rust_provider_backend=false for a temporary shared-memory fallback, or hh_single_decl --no-rust-provider-backend for that tool. a7830e409b
  • Tue, May 26
    Conditions are now always checked against ~bool, and check_bool_for_condition has been removed. Projects that disabled the check or requested warning-only mode must migrate truthy values to explicit tests such as non-null, non-empty, or non-zero comparisons. 015f0e5ae7
  • Wed, May 27
    ReflectionParameter::isArray() has been removed. Inspect getType() or getTypeText() instead; the old predicate discarded generics and other source-level type information. 0dc0df841c
  • Thu, May 28
    ReflectionClass::newInstance() is now deprecated in Hack declarations. Migrate unavoidable reflective construction to HH_FIXME::reflectionClassNewInstanceForCallsite() and prefer direct constructors where possible. 0eaf6710f2
  • Fri, May 29
    ReflectionParameter::getClass() has been removed because it inferred only a partial view of the parameter type and ignored upper bounds. Use getType() or parse getTypeText() when source-level type syntax is required. 2d70a67585

Future Changes

1 change
  • Thu, May 28
    Hack declarations now expose the pre-stable case types HH\Runtime\BoolOrInt, BoolOrString, BoolOrFloat, and BoolOrNum for accurately typing legacy PHP APIs that return false on failure. f24aafecb8
