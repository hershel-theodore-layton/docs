Future Changes

1 change
  • Tue, Jul 7
    Function type hints can describe variadic named arguments using syntax such as (function(int, named string...): void). The initial implementation requires named_variadic_type=true; call checking and subtyping support follow later in the release cycle. 4315b4c024

Highlights

4 changes
  • Wed, Jul 8
    Hershel's HHVM now includes a Ubuntu 24.04 Noble build script. The repository now includes a clean-container build entry point and Debian metadata for regular, nightly, debug-symbol, and development packages; this package build identifies the runtime as HHVM 26.6.5. e8b37975a0
  • Wed, Jul 8
    Hack enum hints now participate in predicate-based is/as refinement, including the legacy numeric-string behavior of enum checks and sound-dynamic builtin pessimization. 99592e454f
  • Thu, Jul 9
    Build support has landed in Hershel's HHVM for Ubuntu 26.04 Resolute. ./build.sh --ubuntu-26.04 selects it, with bundled PCRE and libdwarf compatibility work for the newer distribution; Ubuntu 24.04 remains the default. 0a1acba1cb
  • Thu, Jul 9
    Incremental typechecking now rechecks descendant classes when a parent member gains or loses __TestsBypassVisibility, keeping override and private-shadowing diagnostics up to date. 2d646e5e23

Breaking Changes

7 changes
  • Thu, Jul 9
    The $_REQUEST superglobal has been removed, together with Eval.DisableRequestSuperglobal. Read request parameters from $_GET and $_POST as appropriate. e9cb94b3ae
  • Thu, Jul 9
    The $_COOKIE superglobal and automatic Cookie-header parsing into it have been removed, together with Eval.DisableParsedCookies. The raw request header and parse_cookies() remain available. e6ac19eb7a
  • Thu, Jul 9
    Storing a meth_caller in APC now always throws, including when nested in a container. Eval.ForbidMethCallerAPCSerialize no longer permits a warning-only or permissive mode. 87298f974e
  • Thu, Jul 9
    HH\dynamic_fun() now always throws InvalidArgumentException when its target lacks <<__DynamicallyCallable>>; Eval.DynamicFunLevel no longer permits the call or reduces it to a warning. 70fc6271ce
  • Fri, Jul 10
    String concatenation now always throws on disallowed implicit string coercions instead of permitting warning-only or permissive behavior through Eval.NoticeOnCoerceForStrConcat. Integers and strings remain supported. eda918a5d9
  • Fri, Jul 10
    The left operand of .= now always throws on disallowed string coercion; the Eval.NoticeOnCoerceForStrConcat2 rollout option has been removed. 92c8ae13c2
  • Fri, Jul 10
    Implicit conversion of an object to a string no longer invokes its __toString() method; HHVM throws TypecastException instead. Call __toString() explicitly when that conversion is intended. ba521c3324
