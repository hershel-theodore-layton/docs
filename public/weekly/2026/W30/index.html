  • Thu, Jul 23
    Hershel's HHVM has optimized the implementation of HH\Lib\Vec\slice, a hot function in portable-hack-ast-linters. This reduces whole project lint latency by ~30%. Improvements scale more than linearly with the size of the file being linted. Projects with larger files may see a greater improvement. This change is included in hersheltheodorelayton/hhvm-full:26.06.05. See also HHVM issue for perf on the hhvm repo. b983bd51b1
