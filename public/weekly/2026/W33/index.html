15 noteworthy changes, organized by the source changelog sections.

Future Changes

9 changes
  • Mon, Aug 10
    Expression trees now preserve literal string and integer subscript keys so shape-field reads and writes can be typechecked correctly. fc26c62910
  • Wed, Aug 12
    The opt-in check_duplicate_enum_values setting now reports duplicate values in plain enums, including conflicts introduced through enum use inclusions. It remains disabled by default. ab8c2c1907
  • Wed, Aug 12
    The opt-in duplicate-enum-value check now also reports enum values it cannot statically evaluate, rather than silently skipping them. 15b1143598
  • Wed, Aug 12
    <<__AllowUncheckedEnumValues>> lets an enum opt out of the experimental duplicate-value and uncheckable-value diagnostics. Enums that include an opted-out enum must also opt out. 41fb35f4ab
  • Wed, Aug 12
    The opt-in Eval.EnableLazyGC setting, when garbage collection is enabled, raises the default garbage-collection trigger from 50% to 80% of the remaining memory budget and allows a temporary memory grace buffer before collection. It is disabled by default, and explicit trigger and grace settings take precedence. b41450e50e
  • Thu, Aug 13
    The opt-in duplicate-enum-value check now catches collisions between integer values and their canonical integer-string equivalents in arraykey enums, such as 0 and "0". 261eb911c4
  • Thu, Aug 13
    The experimental enum-value check exempts pure aliases of a single enum when all referenced values are statically known and distinct. 84710a4acf
  • Fri, Aug 14
    Typed open-shape subtyping now compares the types of unknown fields, rejecting incompatible tails such as shape(string...) where shape(int...) is required. 8bbd0ed223
  • Fri, Aug 14
    Expression-tree subscripting has advanced from Preview to OngoingRelease in the experimental-feature rollout. 72a8b4317f

Highlights

5 changes
  • Tue, Aug 11
    The EXIF parser now clears stale buffers when reallocation fails, preventing use-after-free and double-free errors during subsequent parsing and cleanup. 116eb7f489
  • Tue, Aug 11
    HHBBC now safely retains named-argument names while analyzing compressed bytecode, fixing an ownership bug in whole-program optimization. b3dd86ffdf
  • Wed, Aug 12
    The typechecker now knows that DOMDocument::createElementTyped() and createElementNSTyped() return DOMElement. 130929a5fe
  • Wed, Aug 12
    hh_client --single now typechecks explicitly supplied files that the server does not monitor, rather than incorrectly reusing global diagnostics that can make those files appear error-free. 3594deeb46
  • Fri, Aug 14
    The JIT no longer assumes that an unloaded user type alias denotes an object, preventing incorrect handling of shape or dict values returned synchronously, through await, or through inout parameters. e02dc92e31

Breaking Changes

1 change
  • Thu, Aug 13
    __PackageOverride now produces an error when it names the file’s path-derived package itself or a package that the path-derived package neither includes nor soft-includes. 66027d0ebf
