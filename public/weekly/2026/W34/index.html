Highlights

6 changes
  • Mon, Aug 17
    unserialize() now rejects aggregate values in serialized key positions, preventing use-after-free when later serialized references point into a discarded temporary key. 8ba37ca157
  • Mon, Aug 17
    HH\Facts now supports function-attribute queries through functions_with_attribute(), function_attributes(), and function_attribute_parameters(). Index the desired attributes with Autoload.IndexedFunctionAttributes. 12950b15d1
  • Mon, Aug 17
    A public method overriding an internal or protected method no longer has to propagate __TestsBypassVisibility, since the public override does not bypass visibility. e25704eea5
  • Mon, Aug 17
    The typechecker now correctly expands recursive type-constant refinements involving this, closing a type hole that could silently accept incompatible values. a60607b184
  • Tue, Aug 18
    HHVM no longer dereferences a null JIT region when profile-guided region selection produces an empty result, avoiding a crash during offline retranslations. 8539c42f3d
  • Wed, Aug 19
    HHVM now avoids a null-pointer crash in the ExtTSP machine-code layout algorithm. e3136fcde6

Breaking Changes

2 changes
  • Thu, Aug 20
    Abstract class constants can no longer be used as shape keys in type annotations or shape expressions. The typechecker reports Typing[4129] instead of permitting a reference that can fail at runtime. 0f529ca6c2
  • Fri, Aug 21
    unset() now requires an indexed array-access target. Unsetting a local variable or an object property produces Typing[4521]. c0048a4355

Future Changes

2 changes
  • Fri, Aug 21
    When implicit packages are enabled, Hack files directly under a family path now produce Naming[2135]; files must live under a member directory even if they use __PackageOverride. f4f84cbd73
  • Fri, Aug 21
    When implicit packages are enabled, member directory names must be valid Hack identifiers. Invalid member names now produce Naming[2136]. 1dea159d3d
