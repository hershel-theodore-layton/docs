Week 35: Aug 24–Aug 30, 2026

16 noteworthy changes, organized by the source changelog sections.

DayWeekMonth
←Previous week→Next week

Highlights

12 changes
  • Mon, Aug 24
    Serialization now clamps the remaining request-memory budget to a nonnegative value when determining its output limit, avoiding integer overflow from negative memory accounting. 7f1182a3c1
  • Tue, Aug 25
    hh_client --type-at-pos now prints named variadic parameter types with three dots instead of six. 320a938303
  • Tue, Aug 25
    The cross-package override lint now also reports references that become illegal when the caller’s __PackageOverride is removed, including references where both endpoints carry an override. b6083be80a
  • Wed, Aug 26
    The typechecker avoids expanding hidden portions of type-error explanations, preventing exponential memory use while preserving the rendered diagnostics. 849605f257
  • Wed, Aug 26
    Hackfmt no longer crashes when formatting typed open shapes such as shape(string...). f1d80663d8
  • Wed, Aug 26
    hhvm --version now includes a (roar) marker when the binary was built with ROAR support. 5fd092015c
  • Thu, Aug 27
    Open-source HHVM builds now include additional x64 and Arm64 portability fixes. ImageMagick OpenMP is disabled to avoid shutdown crashes. 222f52c75b
  • Thu, Aug 27
    hh_client now gives clearer diagnostics for invalid command-line arguments, including malformed --download-saved-state arguments, and avoids unnecessary backtraces in some argument-error cases. 5615eb178a
  • Fri, Aug 28
    The typechecker now updates module dependencies correctly after an interrupted typecheck, preventing stale unbound-name errors when a module is added. 4e7aa03c40
  • Fri, Aug 28
    hh_client accepts --reason to describe why an invocation was made; the description is recorded in invocation telemetry. aceaff4c74
  • Fri, Aug 28
    HHVM fixes a curl_getinfo() linked-list memory leak, integer-key handling in LMDB, temporary-string lifetime in Unix-socket Memcache connections, and temporary parameter-name lifetime during SOAP serialization. 0c786cb796
  • Fri, Aug 28
    HHVM fixes bounds checks in Fileinfo, XML tag skipping, and numeric-string conversion, and an output-buffer overflow in FriBidi, plus allocation-size overflow in Imagick::exportImagePixels() and invalid Sodium secretstream header lengths. 0c786cb796

Breaking Changes

1 change
  • Wed, Aug 26
    __PackageOverride can no longer assign a file to a package with strict isolation enabled, including members of experimental implicit package families. 258c0664f6

Future Changes

3 changes
  • Wed, Aug 26
    Experimental shape splats now support type parameters, newtypes, and type constants, with subtyping and field operations that account for the fields those types may provide. Type-parameter splats require the unstable shape_splat_type_parameters feature gate. caef41ad02
  • Wed, Aug 26
    Implicit-package configuration diagnostics now identify conflicting package names and paths and point at the written member reference. cba11c4c5e
  • Fri, Aug 28
    The opt-in class_pointer_array_literal_keys setting infers classname<T> for collection-literal keys whose class-pointer type is already resolved, reflecting their runtime conversion to strings. The setting is disabled by default. fe6dba7d83
