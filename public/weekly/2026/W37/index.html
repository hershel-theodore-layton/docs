Week 37: Sep 7–Sep 13, 2026

6 noteworthy changes, organized by the source changelog sections.

Breaking Changes

1 change
  • Mon, Sep 7
    Computed property and method access now requires a receiver that is a subtype of dynamic under ordinary subtyping. A concrete value merely compatible with dynamic no longer suffices. Nullsafe access permits the nullable arm while checking the non-null receiver; failures use Typing[4524] instead of Naming[2011]. dea7d004c3

Future Changes

2 changes
  • Tue, Sep 8
    The parser now rejects combining inout and named parameter modifiers in either order, closing a validation gap in the experimental named-parameters feature. 53b29e97fa
  • Wed, Sep 9
    Opt-in class-pointer key widening now covers dictionary keys and values appended to keyset or Set, using classname<T> where runtime coercion turns a class<T> value into a string. The class_pointer_array_literal_keys and class_pointer_array_write_keys rollout levels remain zero by default. 2f116d635b 0f74e9d033

Highlights

3 changes
  • Wed, Sep 9
    Setting Eval.AllowManualGC=false makes gc_collect_cycles() skip collection. Manual collection remains enabled by default. bb180afe2e
  • Thu, Sep 10
    The typed AST now records the correct classname<T> or class<T> result on HH\type_structure_classname() and HH\type_structure_class() calls, avoiding spurious invalid-comparison warnings from checks that read the expression annotation. b9e0ca8265
  • Fri, Sep 11
    Outside repo-authoritative mode, inherited private properties annotated with <<__TestsBypassVisibility>> can now resolve correctly on subclass instances when the calling test context is authorized to bypass visibility. 55d22e2551
