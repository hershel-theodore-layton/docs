Commit title: Add @thrift.GenEnumSet
Commit body:
Summary:
This will cause a new typedef to be added to the ast, with whatever adapters are available in each language. Once we support parameterized typedefs, this should be replaced by a single typedef parameterized by the Enum type, for example:

  typedef i32 EnumSet<E>;
  struct MyStruct {
    1: EnumSet<MyEnum> myEnumSet;
  }

until then we can test this out with a macro annotation, which will show up as:

  thrift.GenEnumSet
  enum MyEnum {}

  struct MyStruct {
    1: MyEnumSet myEnumSet;
  }
