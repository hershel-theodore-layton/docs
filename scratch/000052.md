Commit title: Report total number of execs, not work items in extern-worker stats
Commit body:
Summary:
Any given exec call can contain multiple work units, and the
extern-worker stats reports the total number of work items. However,
this is misleading because some jobs use a single work item for all
work, and some multiple. This makes it hard to make sense of aggregate
statistics. Just report total number of execs to keep things
normalized.
