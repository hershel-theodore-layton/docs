Summary:
When we reach make_local() and want to download all data
generated with extern-worker, we're quite aggressive. However, this
can result in excessive memory usage. Limit our max concurrency (live
coroutines) when doing the downloading. This does not affect the time
taken in a meaningful way, but does cap the memory usage.
