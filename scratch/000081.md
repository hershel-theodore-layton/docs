If this is accepted, I'll change D40877889 to make each function return `HH\FIXME\MISSING_RETURN_TYPE` instead of directly returning `HH\FIXME\TANY_MARKER<dynamic>`

Today, there are a bunch of functions declared in `.hhi` files without any return types specified. To Hack, the type returned by these functions is `Tany`, a type which could both be anything and can do anything. We're deprecating `Tany` in favor of `dynamic`. This diff creates a new type, `HH\FIXME\MISSING_RETURN_TYPE`, which can be added as the return type for each function.
