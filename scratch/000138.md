Commit title: Add cpp.template support to type tag
Commit body:
Summary:
Currently we ignores cpp.template when generating type tag. After this diff, we will use cpp_type for cpp.template.

e.g.,

```
struct Foo {
  1: map<i32, i32> (cpp.template = "std::unordered_map") field;
}
```

This generates the following type tag for the `field` changed from

```
type::map<type::i32_t, type::i32_t>
```

to

```
type::cpp_type<std::unordered_map<int32_t, int32_t>, type::map<type::i32_t, type::i32_t>>
```
