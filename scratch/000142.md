Commit title: Thread through dependency state in `unit-cache.cpp`
Commit body:
Summary: The in memory unit cache attempts to re-use units if they exist in the cache and have a SHA1 hash identical to that of the on-disk file. This isn't dependency aware, so it's broken for DDB. What we can do here is thread through _why_ we believe the cache is stale. I've changed `isChanged` to return an enum indicating whether we think there's no change (where we returned `false` before), whether the change is considered due to a `stat` difference, or some other reason (difference in repo options, we're "stressing" the unit cache).
