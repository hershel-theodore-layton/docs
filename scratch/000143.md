Commit body:
Summary:
Add an option to `hh_distc typecheck` and `hh_distc decl` to optionally
write out a naming table. This currently writes ~1.5gb and takes ~55sec
on my devserver's SSD.

To support naming table construction, extend protocol::FileSummary
to include a `names::FileSummary`, the per-file object needed for
populating the naming table. This requires making naming::FileSummary
and DeclSummary serializable.

Note that a hackrs version of FileSummary would be more efficient
because it would reuse interned symbols. names::DeclSummary still
uses plain strings.
