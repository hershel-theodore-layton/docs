Commit title: Constrain returns
Commit body:
Summary:
We model `return` as a param-like entity and get good behavior nearly for free.

After the renaming in D40858457, the types are like this:

```
type param_like_index =
  | Index of int
  | Return

type 'a inter_constraint_ =
  | ArgLike of param_like_entity * 'a
  | ParamLike of param_like_entity
  ...
```

This change gets reasonable results and makes some sense:
- Information flows the right way. In shape_analysis_walker.ml, we generate a new entity at each call site, which is then constrained based on the return hint of the callee.
