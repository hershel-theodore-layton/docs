Commit title: Handle super globals
Commit body:
Summary:
This diff handles super global methods from `www/flib/core/superglobals`, e.g. `GlobalENV::get` and `GlobalVARIABLES::set`. To be more precise, we explicitly list all the existing write/read methods of super global classes (later probably we could move such information to some extra file), then during the TAST checking, if such methods are encountered, the corresponding global write/read error is raised:
- the "global variable" is of the format `$VAR_NAME` (e.g. `$_ENV` for GlobalENV), or `$_` if we cannot infer the exact variable name.
- the "data type" is the corresponding write/read method's type with the prefix "`superglobal`" to distinguish from memoized functions.
- the "error code" is either `DefiniteGlobalWrite` or `DefiniteGlobalRead`.
- the "pattern" is either `SuperGlobalWrite` or `SuperGlobalRead`.
