Commit title: Respect ENABLE_SSE4_2 when building HHVM with non-apple clang (#9219)
Commit body:
Summary:
We have a workaround for clang to unconditionally enable no SSE 4.2 no matter if `ENABLE_SSE4_2` is set, in order to avoid an internal compiler error. The workaround is used for macOS while it would result in link time errors in newer version of Folly. The error log can be found at https://github.com/facebook/hhvm/actions/runs/3101605691/jobs/5023136582

This PR removes the workaround for non-apple clang, fixing the link time errors. I did not encounter the internal compiler error from a non-apple clang, which the original workaround was created for.
