Commit title: Do not install TicketHandler if ticket seeds are empty
Commit body:
Summary:
`SSLContextManager` did not check whether the provided ticket seeds were empty or not before creating a `TLSTicketKeyManager` and installing it in the `folly::SSLContext`. There's no point doing that, connections won't be resumable.

Added a `DCHECK` in `TLSTicketKeyManager::fromSeeds`. The factory method shouldn't be called with empty seeds.
