Summary:
Previously we were doing a bunch of business-logic type translation from Hack -> Textual in the textual.rs file - but really textual.rs should know only about Textual itself and conversions should be done in textual::lower.

Move the type conversions for parameters, return types, and property values to the lower phase and remove the non-Textual types from textual.rs.

This also renames (again) Mixed to HackMixed to match the rest of the primitives (HackInt, HackString, etc).
