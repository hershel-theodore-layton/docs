Commit title: Allow EventBaseManager::getEventBase() to be called during clearEventBase()
Commit body:
Summary:
Some code relies on calling `getEventBase()` from the callbacks ran by the `EventBase` destructor.

Before D40899507 (https://github.com/facebook/hhvm/commit/5365a18dd7a88c50cc12d60d21a4de3e2d2dafdb) this worked due to an implementation detail of `folly::ThreadLocalPtr`. Now, due to an implementation detail of `folly::Optional` (which unsets the `hasValue` bit before destroying the value) it does not work anymore.

This diff supports this behavior explicitly in `clearEventBase()`.
