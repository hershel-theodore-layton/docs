Commit title: Determinism

Summary:
Fix nondeterministic behavior (ND) in `hh_fanout build`:
1. it explicitly used std::collections::hash_map::RandomState to hash
sorted dependents lists into `hhdg` buckets. switch to hash::BuildHasher (fxhash).

2. it used std::collections::HashMap, which uses RandomState - switch to
hash::HashMap (fxhash).

3. The parallel loop that assigns sorted_dependencies to buckets resulted
in ND ordering within each bucket, and ND ordering of each list's dependency hashes.
Fix it by adding a second parallel loop that sorts each bucket and each dependency list,
before assigning offsets. The only sequential loop is the final O(buckets) loop which
computes each bucket's absolute offset.
