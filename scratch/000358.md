Commit title: Optimizations to recover parity with the ND baseline
Commit body:
Summary:
Making hh_fanout build nondeterministic introduced a regression because
it does more sorting work. This diff implements a handful of easy optimizations
to get performance slightly better than where we started.

* HashListsIndices doesn't need to remember bucket_offset behind a mutex,
it can be calculated and returned by make_absolute()
*  combine Edges::structured_edges() and sorted_hashes() into one step,
and using owning iterators to parallelize freeing memory. This also reduces
peak memory by freeing all_edges sooner.
* use par_sort_unstable() to sort hashes
* use owning iterators to consume HashListsIndices while writing data into .hhdg,
which parallelizes freeing memory.
* free structured_edges in parallel.
