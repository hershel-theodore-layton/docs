Commit title: Open enum support
Commit body:
Summary:
Java enums are closed enums, can't add new enums during runtime. They are also singletons, can't store extra data per instance.

When enums are defined as open enum in Java, an object (very similar to java enums) is created.

Changes in this diff:

1. Open enum support in Java. Old legacy enum support is still there.
2. Open enums can be declared in enum or package level.
3. Created a new test-common component to define test objects to use in test adapters. This is to prevent cyclic dependency.
4. Added unit tests for all possible cases. Enums in structs, unions, exceptions. Enums with terse attribute, enums in adapters. Simple and complex type supports (i.e list<enum>).
5. Added new test adapters for enums.
6. Extended adapter and added new marker interfaces for enum/structs/unions etc.

Enum compatibility is defined here
https://fb.quip.com/8G0CAWLPARkB
