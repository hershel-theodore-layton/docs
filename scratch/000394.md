Summary:
This function is extremely hot in the lexer; it is called for every token.

Comparing strings results in calls to `core::str::traits::<impl core::cmp::PartialEq for str>::eq`: https://godbolt.org/z/eEx8xzx9c

But comparing byte strings results in inlined `cmp` operations: https://godbolt.org/z/f4xTsce6x

Which seems to result in a ~1.6% performance improvement in parsing.
