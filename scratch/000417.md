Summary:
Integrates the dead unsafe cast remover with `hh_server`.

The workflow is as follows:
1. Typechecker is invoked with `--no-load` and `--config populate_dead_unsafe_cast_heap` which results in all files to be analysed for dead unsafe casts during TAST checks.
2. Get one patch per file and apply them through `REMOVE_DEAD_UNSAFE_CASTS` RPC call. Fetching the patches deletes entries from the shared heap.
3. Make a `STATUS` RPC call to reanalyse the files for dead `UNSAFE_CAST`s.
4. Go to step 2 until there are no more patches generated.
