Commit title: Aggregate items in make_local before downloading them in HHBBC
Commit body:
Summary:
When HHBBC is done using extern-worker, it must download everything
from the extern-worker framework and proceed locally. Right now it
downloads everything individually, but this can be
inefficient. Instead, run an "aggregate" job beforehand, which serves
to combine multiple items together into one blob. Inside make_local(),
we'll download these blobs instead. This is the same total amount of
data, but fewer overall requests.

With the much fewer requests, there's no longer any need to cap the
make_local() download concurrency.
