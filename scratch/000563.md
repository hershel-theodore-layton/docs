Summary: Add a Rust version of the Measure module which doesn't implement distribution bucketing (which we don't seem to use) or serialization/deserialization. Integrate with the OCaml implementation: when pushing to the global record stack, also push to Rust's stack. When popping, also pop from Rust's stack. Since each MultiWorker worker invokes a push when starting the job and a pop when completing, this causes them to report back the Rust results unioned with the OCaml.
