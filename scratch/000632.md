Commit title: Fix `keyset<mixed>` inference
Commit body:
Summary:
We were wrongly inferring `keyset<mixed>` when a keyset had an ambient mixed expected type (for example through a return).

This was because bidirectional value type logic for value collections forgot about the `arraykey` bound on sets.

This diff threads the value kind and returns `arraykey` expected bound where appropriate.

It matches the behaviour for `dynamic` based on the KeyValCollection's expected treatment.
