Commit title: Parameterize QfPos and Quickfix over pos type
Commit body:
Summary:
oxidized::user_error::UserError<PrimPos,Pos> is generic, which allows
the Pos types to be hackrs::pos, which are Send (shareable across threads).

Unfortunately, oxidized::quickfix::Quickfix hardcodes oxidized::pos,
which is !Send because of RcOc<RelativePath>

Parameterize Quickfix.t, so that:
* Pos.to_absolute also converts positions within the Quickfix to Pos.absolute
* hh_oxidize creates Quickfix<P> so P can be a threadsafe `hackrs::Pos`
