Commit title: Hide hash list address
Commit body:
Summary:
The `HashList::hash_indices` method currently exposes the underlying address
pointing into the memory-mapped `.hhdg` file, but this prevents alternate
implementations that produce those indices lazily.

There's only one place where we needed the identity of the hash list, for
statistics purposes to see how many rows got interned together. Instead, provide
an opaque newtype that uniquely identifies that row storage. For `DepGraph`,
its representation is just the file offset for the underlying list, rather
than its address. For a different implementation it could be some other value.
