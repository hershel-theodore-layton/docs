Summary:
For DepGraph implementation flexibility, we don't want to be forced to
expose a gigantic slice of all 60M 64-bit hashes. Instead, change the
API to provide an iterator (and a parallel iterator).

The iterator provides `Dep` rather than `u64`, which is semantically better.
It's what most callers wanted.
