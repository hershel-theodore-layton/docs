Commit title: Optimize dep_graph_is_subgraph to avoid dependent_dependency_edge_exists
Commit body:
Summary:
`dependent_dependency_edge_exists` is slow because it has to both look up the
hash list from scratch (the same one every time through the loop in this code),
and also look up a hash index within a HashList. When comparing two HashLists
this is very slow. Instead, just fetch each HashList once and use a HashSet
to check each item in O(1) time.
