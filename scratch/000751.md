Commit title: Use lz4 block api
Commit body:
Summary:
Use the `lz4::block` API instead of the streaming API. This corresponds to the lz4 API that hh_server is using via the ocaml_blob crate in shmffi.

It seems like the block API has a [different notion of compression level](https://docs.rs/lz4/latest/lz4/block/enum.CompressionMode.html) than the streaming API. Just disregard our compression level configuration for now (hh_server uses lz4's default, so do the same here by passing `None` to `lz4::block::compress`).
