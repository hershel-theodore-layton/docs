Commit title: Don't allow setIsOverloaded or setPreprocess to drop sanctioned internal requests
Commit body:
Summary:
Certain requests like getCounters), getStatus(), etc are treated specially by thrift server and are not shed. Today we require the isOverloaded() and preprocess() callbacks to do this or else they suffer from poor behavior (counters dropped, cascading failures due to getStatus() drops).

This diff changes it so that user can never accidentally drop getCounters or getStatus even if they are using setIsOverloaded/setPreprocess.
