Commit body:
Summary:
When using the kqueue+fsevents watcher, cookie directories can be added/removed
dynamically, and the current code doesn't protect well against this. For
instance, removing a watch on a directory while adding a cookie directory may
lead to that cookie never being observed. Some of the tests were failing quite
frequently because of this.
