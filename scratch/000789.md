Commit title: kqueue_and_fsevents: let the watcher watch files with fsevents
Commit body:
Summary:
Currently, the kqueue+fsevents watcher uses a directory fsevents watcher for
the top level directories. Unfortunately, if the top level directories are
gigantic, this makes Watchman issue a lot of syscalls for each of the
files/directories contained in these at cookie sync time. In some cases, we've
seen this take upwards of 10s.

To workaround this, we should be using the fsevents_watch_files configuration
so we can configure the fsevents to watch files and thus eliminating the need
to issue all these syscalls.
