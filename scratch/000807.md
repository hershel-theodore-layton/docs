Commit title: Report errors when localizing constrained types
Commit body:
Summary:
I enable errors during
localization of constrained types.

The motivation for flagging these
errors is to prevent bad uses of loose
type refinements in D38861371. Having
localization throw errors is the simplest
approach I found.

Longer term, we will simply make sure
that when a function f is typechecked
ok, all the types in its signature
(possibly substitued with generic params)
localize without errors. This invariant
does not currently hold, as the errors
in www witness.

It actually fixes one type hole!
