Commit title: Require visibility for static class properties
Commit body:
Summary:
Currently Hack allows you to write:
```
class Foobar {
  static mixed $bing;
}
```
We infer a `public` visibility during lowering, if none is set. This is *fine*, honestly, but for clarity's sake we probably want to force the user to write a visibility here.
