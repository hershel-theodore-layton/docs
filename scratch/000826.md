Commit title: Utilize common sub-arrays when serializing arrays
Commit body:
Summary:
Right now serializing an array does not take advantage of any common
sub-arrays. For example, if an array contains two child arrays which
are identical, both children will be serialized as part of the parent
array. For certain pathological arrays, this can cause an array which
only takes O(N) memory to take up O(2^N) space when serialized
(consider a tree where every node has 2 identical children). In
memory, all common children will be represented by the same pointer,
so won't take up extra space.

Both for general efficiency, and to avoid the above mentioned
pathological cases, serializing an array should not destroy any of
this "shared" structure. Instead of serializing an array along with
all of it's children in one unit, only serialize the "top" of the
array. Any children will be encoded using literal array table indices,
like anywhere else. This process will be repeated for every *unique*
array. If two children are identical, they'll have the same pointer,
will get the same index, and be encoded only once.
