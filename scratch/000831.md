Commit title: Multifile parsing: don't add a blank line at the end of files
Commit body:
Summary:
To split the multifile properly,  the delimiter should have a newline character both before and after, otherwise it will add a blank line at the end of files. For such a delimiter to work we also need to add a newline char at the beginning of the file content.

This will matter for fanout tests where properly detecting file changes is important and we don't want random new lines to be detected.
