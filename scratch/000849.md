Commit title: Separate elaboration & validation of `Collection` to `ValCollection` and `KeyValCollection`
Commit body:
Summary:
Collection literals are represented as AST `Collection` data constructors after the lowering phase but elaborated to `ValCollection` and `KeyValCollection` during naming, with errors raised if
- a value without a key is in a key value collection; or
- a key value pair is given in a value collection.

The step also replace any invalid collection literals with the `ignored_error_` expression. For clarity, only the following are valid:
- Value collection: Vector, ImmVector, Set, ImmSet, KeySet, Vec
- Key value collection: Map, ImmMap, Dict
- Pair

Following this step, we no longer expect `Collection` to appear in the AST.

This diff moves this step into a separate visitor making the point at which the invariant should hold clear
