Commit title: Remove tags from diagnostic
Commit body:
Summary:
Recently added diagnostic tags are unused and have a number of issues:

* Hardcoding a Meta-specific and hacky way to convert them into documentation links.
* Not extensible to lints and other tooling that also use diagnostics.
* Apply on a diagnostic instance instead of a diagnostic class.

If we want to add some metadata to diagnostics more thought needs to be put into making it useful and generally applicable. Until then, let's remove this questionable feature.
