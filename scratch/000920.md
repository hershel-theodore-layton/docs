Commit title: Switch to core type definitions on ThriftStructTypes
Commit body:
Summary: We are moving non-abstract type constants out of `IThriftStruct` to a separate utility class that is not extended by all Thrift struct implementations. Currently HHVM does not adequately optimize the type structures for these definitions by de-duping them within the same unit, which is problematic when working with potentially recursive structures.
