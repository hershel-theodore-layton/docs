Commit title: Guard against static members overlapping due to traits
Commit body:
Summary: HHVM will fatal if you attempt to redeclare an instance member as static (or vice versa). We guard against this when you redeclare within a class, but *not* when you implicitly redeclare due to trait inclusion. This is a catch-all soln that looks for the intersection between static and instance methods / properties.
