Commit title: Normalize path to / when setting a valid URL with no path
Commit body:
Summary:
RFC3986 says

```
   In general, a URI that uses the generic syntax for authority with an
   empty path should be normalized to a path of "/".
```

So if parseURL is valid and the path is empty, set the path to /.
