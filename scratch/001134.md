Commit title: don't keep delta open
Commit body:
Summary:
This diff changes the full dep graph `OnceCell` in `HhFanoutImpl` to be just the base dep graph, and makes `HhFanoutImpl` close the RocksDB delta connection after every use.

It turns out that RocksDB only allows one open connection at a time. If another thread or process attempts to open a connection, then it will panic. For now, I've added a `close()` method to the delta to explicitly drop it that must be called before other `HhFanoutImpl` can attempt to open the same delta. Since we're planning on moving to sqlite eventually, I didn't bother thinking of a cleaner solution.

Also, I've refactored `FullDepGraph` so that it only provides API to read edges. Logic to add edges has been moved to `hh_fanout_lib.rs`.
