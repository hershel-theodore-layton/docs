Commit title: Hash shm_store keys using md5
Commit body:
Summary: We've been using rustc_hash here, which is fast, but not particularly concerned with avoiding collisions. We're seeing some erroneous typecheck errors because of collisions in the wild: for instance, the classes `EntDimARCreatorsPrivacyPolicy` and `EntDimIGCreatorsPrivacyPolicy`. Use the first 8 bytes of the md5 (as hh_shared does) instead to avoid collisions.
