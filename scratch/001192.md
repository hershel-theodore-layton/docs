Commit title: Don't write out empty dependent lists in DepGraphDelta
Commit body:
Summary:
`DepGraphDelta::write_to` specifically skips writing out any entries
where the dependents list would be empty, as it's pointless.
"This node points to nothing in particular".

However, `DepGraphDelta::write_sorted`, randomly does not have this check,
so if you write out the same information but canonicalized, you might
end up with an empty list.

Clarify the file invariants by explicitly skipping empty lists here too.

While I was there, I factored out some copypasta that knows the file format
being written in two places.
