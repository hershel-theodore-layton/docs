Commit title: Factor out InputFileProvider (1/2)
Commit body:
Summary:
The hh_distc actions for hackc (aka parsing), decls, and typechecking all
take batches of repo source files as input. This is materialized on RE workers
as a large nested input directory tree and a very long command line that lists
every filename.

The large directory tree requires O(dirs) blobs to encode in CAS, and the large
command line could theoretically overflow CLI limits, although it doesn't seem
to for now. Also, every input filename is listed twice: once on the command line
and again as part of the input directory tree.

As a first step towards fixing & optimizing, factor out all the input file handling
to an InputFileProvider helper struct. Using RelativePath in more places in
typecheck workers simplified & cleaned things up a bit by avoiding the
need to pass around Path and Prefix separately.
