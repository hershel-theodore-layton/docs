Commit title: Traverse typedefs when searching for adapter annotation
Commit body:
Summary:
This fixes a bug in Thrift-python compiler that ignores adapters on the intermediate typedefs.

In particular, when we have following typedefs

```
python.Adapter{
  ...
}
typedef i32 AdaptedInt
typedef AdaptedInt OtherAdaptedInt
```

The compiler would ignore the adapter annotation when using `OtherAdaptedInt` as it only looks up the annotation on the outer typedef (`OtherAdaptedInt`) and then uses the resolved type directly.

With this diff, we start traversing the typedefs to find first adapter annotation.
