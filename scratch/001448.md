Commit title: Introduce AnyRef and AnyConstRef
Commit body:
Summary:
This adds missing support for `AnyRef` and `AnyConstRef` (as per TODO) that can hold references to Thrift values. The new types are interoperable with `AnyValue`, i.e. they can be initialized either directly from Thrift object or from type erased AnyValue.

The interface is minimal and is compatible with `type::Ref` and `type::ConstRef`, in case we eventually want to replace it with those (right now those types are not compatible with AnyValue).
