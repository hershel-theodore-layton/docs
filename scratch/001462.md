Commit title: Anonymous functions should not have names
Commit body:
Summary:
Currently we can't distinguish between named functions (i.e. global functions) and anonymous functions in hover information. This is because `fun_` has a `name` field, even though it can represent anonymous functions.

Move the `name` field to `fun_def`, so anonymous functions no longer have names(!).

This was missed in D25987602 (https://github.com/facebook/hhvm/commit/d89e933eb66523c386b8555a34dfa620529cf54c).
