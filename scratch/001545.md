Commit title: fix backlashes in Python docstrings
Commit body:
Summary:
Update the older Python generator to emit docstrings as `r"""` literals
rather than just `"""`.  This prevents backslashes inside the docstring from
being treated as escapes, possibly causing runtime warnings to be emitted.

This change makes the Python docstring contain exactly the string contents as
they were parsed by the thrift compiler itself.  (Note that it looks like the
thrift compiler does not handle backslash escape sequences at all inside
strings, if I am reading the code in thrift/compiler/parse/lexer.cc correctly.)

This helps avoid Python warnings about invalid escape sequences in docstrings
that contain ascii-art drawings using backslashes for lines.
