Commit title: Add missing param type in HHI for pcntl_waitpid()
Commit body:
Summary: `pctnl_waitpid()` takes an "out" parameter which is marked `inout` since Hack does not have a concept of out-only params. The location is unconditionally overwritten by an `int`, but people sometimes like to pass in `null`, so `?int` seems to be a sensible type. Callers will need to handle the nullability after the call.
