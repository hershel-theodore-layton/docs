Commit body:
Summary:
This implements the balanced graph partitioning algorithm from
https://www.kdd.org/kdd2016/papers/files/rpp0883-dhulipalaAemb.pdf

At a high level, it renumbers nodes in a graph to make it more compressible,
by making edge lists have smaller gaps between node numbers. I made this one
a bit biased towards RLE (i.e. 0-sized gaps) since the upcoming hhdg file
format takes advantage of it.
