Commit title: Introduce new compressed .zhhdg file format and tools
Commit body:
Summary:
This diff introduces a new `.zhhdg` format for compressed depgraphs, a
new format for `.hhdg` files, and tooling around these formats. It
does not actually change any file formats we use, it just adds the
option to use them. After this change, `.hhdg` can be either new or old
format as determined by a file header, and present the same API internally
when loaded.

The high level idea is to renumber graph nodes to make dependency graph
edge lists more compressible.

This diff adds three things:

- `depgraph_compress`: a Rust crate to write out `.zhhdg` files. If you
  use the existing `hh_fanout` build, but give it a `.zhhdg` suffix, it
  uses the new compressor and writer.

- `depgraph_decompress`: a Rust program that decompresses a `.zhhdg` file,
  turning it into a `.hhdg` file suitable for memory-mapping.

- Updates the DepGraph reader to support either old or new format with the same API.
