Commit title: Fix buffer test failures in //folly/io/async/test:async_test
Commit body:
Summary:
* Buffer tests fail due to extremely small send buffer (128 bytes) set on the socket. Sending gets blocked when the kernel runs out of sending buffer. Note, in those buffer tests, the data is not read from server side before the client has finished sending. So the data is totally cached in client's sending buffer and the server's receiving buffer.
* The fix is to set the receiving buffer of the socket on the server side to a large value, i.e. 1MB so sending from client side won't be blocked.
