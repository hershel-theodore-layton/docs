Commit title: Do not shortcut lambda checking in dynamic mode for expression trees
Commit body:
Summary: In dynamic-check mode, we don't recheck lambdas but instead just assume that any lambda has type `dynamic`. Unfortunately, the expression-tree logic relies on lambda inference to determine the `TInfer` explicit generic parameter to expression trees, and inferring `dynamic` produces errors when the generic parameter on an expression tree is constrained. Solution is to use full checking for lambdas when in an expression tree even in dynamic-check mode.
