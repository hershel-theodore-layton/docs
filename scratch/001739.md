Commit title: Make `DynamicHasher` avalanching to avoid F14 bit mixing logic
Commit body:
Summary:
If hash function is not avalanching, F14 will apply additional bit
mixing logic to repair things. Majority applications of `DynamicHasher` are for
`folly::StringPiece` keys, where hash function is already avalanching
(SpookyHashV2), so we do unnesessary work.

Let's mark `DynamicHasher` as avalanching and make `dynamic::hash` avalanching
as well to make `DynamicHasher` avalanching in every possible case.
