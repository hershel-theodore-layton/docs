Commit title: Make dead UNSAFE_CAST removing codemod omit parantheses when not needed
Commit body:
Summary:
We were unconditionally emitting parantheses while removing a dead UNSAFE_CAST in case of capture (say because of a binary expression having a different precedence than its surrounding expression).

This is not possible in many cases such as method calls, variables, etc. This diff implements a helper function to conservatively check if a variable can be captured and use it to omit parantheses during patch generation.
