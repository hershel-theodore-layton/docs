Commit title: stricter noexcept enforcement in Function
Commit body:
Summary: The `Function<R(A...) noexcept>` constructor now accepts only callables which are noexcept-invocable. Previously, it would be possible to construct an instance of this `Function` type with a callable which was not nothrow-invocable. This callable, of course, may throw - in which case the owning `Function` terminates. Let us expose these mismatches at compile time.
