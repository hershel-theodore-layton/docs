Commit title: Correctly extract masks for patchPrior and patchAfter
Commit body:
Summary:
Both patch operations as well as ensure have to have allMask() for read mask
because they require knowledge of existence of the field and its value in the object to be correctly applied.

Before this worked but was inefficient, because ensure operation was always present and contained all the non-optional fields. This resulted in not very efficient read masks, because all the non-optional fields would get added into read mask, even if they are not actually touched by the patch. But everything worked.

With the move to terse fields and EnsureStruct - ensure operation doesn't have all the non-optional fields present in the wire representation anymore. And since we are using protocol::Object to represent patch here - ensure doesn't add fields into the read mask for e.g. patchPrior. As result operations like assign never result in fields added into read mask. This means that parent fields also don't get added into read mask (if only assign op was patched), which results in skipped patchPrior operation for such fields.

This diff makes all patch(Prior|After) operation fields as well as ensure operation fields always be present in the read mask, ensuring that all these patches can be correctly applied by dynamic (using protocol::Object) patch logic.
