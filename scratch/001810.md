Commit title: WeightedEvictingCacheMap
Commit body:
Summary:
Introduces two elaborated variants of EvictingCacheMap that evict entries to maintain a maximum total weight:
* `ImplicitlyWeightedEvictingCacheMap`: A variant of EvictingCacheMap that associates entries with weights implicitly via a function provided as a template parameter. (Implemented on top of EvictingCacheMap.)
* `WeightedEvictingCacheMap`: An explicit weight is stored along with each entry. (Implemented on top of ImplicitlyWeightedEvictingCacheMap)

The weights can be any non-negative integers whose total does not overflow size_t, but a useful weight is estimated memory usage of an entry, so that the maximum total weight corresponds to a rough maximum total memory usage.
