Commit title: derive `map` for aast_defs
Commit body:
Summary:
Add `ppx_deriving.map` to all types defined in `aast_defs`, deriving associated `map_...` functions for each type.

The primary motivation for adding this is a new AAST node, `Invalid of ('ex,'en) expr`, which marks invalid expressions discovered before typing.

During typing we are forced to provide type annotations and `saved_env`s for the contained invalid expression. We cannot (and should not) apply typing since it is invalid. Instead we can simply map over it given all expressions type `Tany` and the dummy `saved_env`.

Deriving `map_expr` makes this straightforward
