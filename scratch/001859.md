Summary:
This flag will be used for saved state creation and mass replays. The values `prod` and `candidate` will be used for saved state creation while `prod_with_flag_on` will be used for mass replays.

The job creating the production (resp. candidate) saved state will pass `--config ss_force=prod` (resp.  `--config ss_force=prod`) to hh.

The jobs creating alternative saved states for mass replay to test for flag `my_flag` will pass `--config ss_force=prod_with_flag_on:my_flag` to hh.

They are intended to be command-line flags.
