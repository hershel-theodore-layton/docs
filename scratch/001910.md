Summary:
When generating a Filecall fact for a method call, we also index the "receiver type" for the receiver of this method call.

This static type is determined as follows
1. find the `SymbolOccurrence.t` value for the method symbol. It was stored in the XRef map when processing xrefs in a previous stage.
2. get the `receiver_class` string from this `SymbolOccurence.t`  (see https://www.internalfb.com/code/fbsource/[3345feefcc47]/fbcode/hphp/hack/src/utils/symbolOccurrence.mli?lines=29)
