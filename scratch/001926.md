Commit title: Move HHBBC interface vtable calculation to use extern-worker
Commit body:
Summary:
Convert HHBBC's interface vtable calculation over to use
extern-worker. The algorithm has two components. The first is
calculating the conflict graph for each interface. This is the set of
interfaces implemented by every class which implements that
interface. This is, by far, the most expensive component of the
algorithm. Luckily it can be easily calculated while building class
subclasses. The second component is using the conflict graph to find
minimum non-conflicting slots. This is quite cheap, but hard to
distribute. We'll still calculate this locally.
