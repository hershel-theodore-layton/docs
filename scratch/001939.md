Commit title: Fix `folly::F14FastMap::eraseInto` crash for empty map
Commit body:
Summary:
When we call `table_.iterToIndex` for a begin iterator of an empty map, that
has some previously allocated values, we might get an overflow, as difference
of `current_ - lowest_` from `VectorContainerIterator::index()` will be
`nullptr - (something > 0)`.

This might happen if we call `eraseInto` on empty map, that wasn't empty before
(for example, all elements were erased or map was reserved).

Seems like generated code will be one more instruction
(see: https://godbolt.org/z/qKqE83rG1)

Before the patch:
```
movq    %rsi, %rdx
testq   %rdi, %rdi
leaq    -4(%rsi,%rdi,4), %rax
cmoveq  %rdi, %rax
retq
```

After the patch:
```
movq    %rsi, %rdx
testq   %rdi, %rdi
leaq    -4(%rsi,%rdi,4), %rax
cmoveq  %rdi, %rdx
cmoveq  %rdi, %rax
retq
```
