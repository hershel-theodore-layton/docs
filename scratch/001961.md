Summary:
ForkJoinPoolExecutor is a work stealing thread pool. Instead of a single queue each thread has a queue. Because each thread has its own queue there will be less contention vs having a single queue like an ThreadPoolExecutor.

To enable this add the flag:
-Dthrift.separate-forkjoin-scheduler=true
