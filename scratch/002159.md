Commit title: Remove Struct Optimization for Terse Write
Commit body:
Summary:
The current terse struct optimization avoid duplicate empty check and rewinds the buffer if the all the nested fields were empty. Sadly, this penalizes the sparse struct since the rewinding buffer is expensive. Meanwhile, empty check is significantly cheaper.

Analysis:
* If a struct is empty and N is small, rollback method is expensive. (a.k.a Thrift Patch)
* If a struct is empty, checking method is always cheaper. (linear)
* For worst case (last element non-empty), rollback is cheaper N >= 32 (quadratic)

Will re-visit with the memoization optimization to  avoid quadratic worst case empty check.
