Commit title: Const-prop classish promotion to string during type verification when possible
Commit body:
Summary:
If EvalClassStringHintNotices is false, then the implicit conversion
of TCls/TLazyCls to string will not cause any side-effects. In that
case, we can mark the type verification as being side-effect
free. This means that if the verification produces a constant, we can
const-prop away the check entirely.
