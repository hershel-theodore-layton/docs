Commit title: Internalize mutable state in `Pass`
Commit body:
Summary:
Moves our mutable state (the 'context') from an associated type, `Ctx`, to be part of the type for which we are implementing `Pass`. This eliminates the associated type `Ctx` from the definition of the `Pass` trait. The `Transform` traits `transform` and `traverse` functions now require `impl Pass<_,_> + Clone` since we clone the pass not the context.

To support sharing of mutable state between the top-down and bottom-up phase of a pass, we now define a top-down and bottom-up method per type, field and ctor.

To support sharing of non-mutable configuration across all passes, i.e. not just between the top-down and bottom-up phases of a single pass, we _add_ a new associate type `Cfg`. This is intended to carry e.g. typechecker options or other config flags. Note that this is passed by shared ref during transform/traverse calls.

To summarise, before we had:

```
struct Context {
    my_context: MyContextType,
    config: Config,
}

 ---

type MyTopDownPass;

impl Pass for MyTopDownPass {
  type Ctx = Context;
  type Err = ...;

  fn on_ty_expr_(
    &self,
    elem: &mut Expr_<Ex, En>,
    ctx: &mut Self::Ctx,
    errs: &mut Vec<Self::Err>,
  ) {
    ...
  }
}

type MyBottomUpPass;

impl Pass for MyTopDownPass {
  type Ctx = Context;
  type Err = ...;

  fn on_ty_expr_(
    &self,
    elem: &mut Expr_<Ex, En>,
    ctx: &mut Self::Ctx,
    errs: &mut Vec<Self::Err>,
  ) {
    ...
  }
}

 ---

let elem = Expr_::...;
let mut ctx = Context::default();
let mut errs = vec![];
let top_down = MyTopDownPass;
let bottom_up = MyBottomUpPass;
elem.transform(&mut ctx, &mut errs, &top_down, &bottom_up);
...
```

and now we have:

```
#[derive(Clone,Default)]
struct MyPass { my_context: MyContextType }

impl Pass for MyPass {
  type Cfg = Config;
  type Err = ...;

  fn on_ty_expr__top_down(
    &mut self,
    elem: &mut Expr_<Ex, En>,
    cfg: &Self::Cfg,
    errs: &mut Vec<Self::Err>,
  ) {
    ...
  }

  fn on_ty_expr__bottom_up(
    &mut self,
    elem: &mut Expr_<Ex, En>,
    cfg: &Self::Cfg,
    errs: &mut Vec<Self::Err>,
  ) {
    ...
  }
}
 ---

let elem = Expr_::...;
let cfg = Config::default();
let mut errs = vec![];
let mut pass = MyPass::default();

elem.transform(&cfg, &mut errs, &mut pass);
...

```
