Commit title: Store EnumClassLabel in attribute arguments
Commit body:
Summary:
Previously, the lowerer would transform `<<__Memoize(#Foo)>>` or `<<__Memoize(Bar#Foo)>>` to `<<__Memoize("Foo")>>`.

This prevented the rest of the toolchain seeing the enum class label, so no type checking or IDE support was offered.

Preserve the enum class label during lowering, and only perform the transformation to `"Foo"` in the emitter.

This preserves the existing parse errors, so `__Memoize(#NoSuchLabel)` is still a parse error. It also now treats `__Memoize("foo")` as a parse error.
