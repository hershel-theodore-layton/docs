Summary:
This diff adds a logger for like types.

It is triggered by setting "like_type" log level to a number greater than 0.

The definition of like type for a type `t` is that `dynamic <: t` and `mixed </: t`.

The logger looks at every expression and also certain decl constructs, i.e., properties, parameters, and returns.
