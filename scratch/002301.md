Commit title: Add `inline` to more header functions definitions used in extensions
Commit body:
Summary:
Currently, these definition-in-headers are emitted as strong symbols
in multiple different compilation units, which works as we currently
always link them into their own DSO (as a native Python extension),
where the runtime loader dedup's them.

However, in other link modes, like native python (where extensions are
statically linked into the main executable), these cause duplicate sym
definition errors.

We already mark a lot of the functions used in thrift py3 native extensions
as `inline`, but a few are missed, so this diff adds `inline` to those cases.
This allows them to be marked as COMDAT, so that the linked can dedup'd
them at link time.  In D43216436, this allows reducing the total size of thrift-
generated Cython py3 extensions by over 60%.
