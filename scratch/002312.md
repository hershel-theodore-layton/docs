Commit title: Support multiple execution observers
Commit body:
Summary:
folly::FiberManager + folly::EventBase support the notion of an execution observer. The execution observer is called before + after a task is run. Only a single observer is supported now. But some libraries would like the ability to plug their own observers in place without clobbering existing observers.

Add the capability to chain observers together in an intrusive linked list to support multiple observers. Intrusive linked list is used to minimize any performance hit. Additionally, autounlink mode is used for the intrusive linked list for safety, so execution observers automatically unlink themselves in the event they're deleted without manually being removed from the list.
