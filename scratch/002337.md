Summary:
This allows elimination of the extra bit mixing F14 does for non-avalanching hashes, and the string hashes are already avalanching, so use them.

This requires D40737811 (https://github.com/facebook/hhvm/commit/d7617c48bbdab25537958581621a20a8ddce0107) so that F14 uses only the lower 32-bits of the hash, but it should still work fine until the updated version of Folly is synced in since we duplicate the lower 32-bits into the upper. F14 then masks away the upper 32-bits, so the extra shift & or operation should get optimized away.
