Commit title: Disallow `this` hint in `require extends`
Commit body:
Summary:
Based on the Hack formalization work, we would like to disallow `this` hints in:
   - _class_ and _abstract class_ type parameters
   - non-late static bound class_var
   - `extends` and `require extends` clauses _unless_ it appears as the top-level root of a type access or, in a final class which invariant in all type params (or not generic at all)

This diff modifies our validation step to generate naming errors for both of these cases and specializes the error messages.

Note that we don't warn in the following _indirect_ case:

```
class C<T> {}

trait Foo<T> {
  require extends C<T>;
}

class A extends C<int> {
  use Foo<this>;
}
```
