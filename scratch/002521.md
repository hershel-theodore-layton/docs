Summary:
In D16139752 (Jul 2019) I had given the "extended" tag to the two watchman_event_watcher tests. At the time it had been documented that extended tests would be run during CI but not otherwise. I had observed these tests to be very flakey.

However, current docs show that in reality the "extended" tests were *never* run in CI! https://www.internalfb.com/intern/wiki/Test_Infra/Internal_&_Historic_Wikis/TestPilot/changing-test-behavior/ "The original purpose was to make it so that that flag was applied automatically for continuous run Sandcastle jobs (but not diff time jobs), letting you have "continuous run only tests". In practice, we never pass this flag in Sandcastle."

Therefore, these tests simply haven't run since 2019, and even before that they were flakey and ignored.

Therefore, I'm just going to delete them.
