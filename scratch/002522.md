Summary:
This test was introduced in D4832020 (https://github.com/facebook/hhvm/commit/b156b2cc5002a845c760e6367ae4c89499443931) (Apr 2017) "a much-needed integration test between a custom Mercurial mergedriver and Hack build." I assume the intent was that watchman events happen during mergedriver, and hh_server shouldn't do the wrong thing during those watchman events. It's well-intentioned!

The test was given the "extended" tag in D15230961 (May 2019) because it kept flaking. The intent behind adding this tag was the hope that it wouldn't run on diffs/land/locally, but would run on CI. However the documentation for the flags indicates this wasn't the case https://www.internalfb.com/intern/wiki/Test_Infra/Internal_&_Historic_Wikis/TestPilot/changing-test-behavior/ "The original purpose was to make it so that that flag was applied automatically for continuous run Sandcastle jobs (but not diff time jobs), letting you have "continuous run only tests". In practice, we never pass this flag in Sandcastle."

Therefore, the test has basically never been run since May 2019.

I'm just going to delete it. No one wants a flakey test.
