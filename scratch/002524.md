Summary:
My goal is to make integration tests less flakey. Currently they are flakey because of the magic of "hh_paths", because sometimes buck1 or buck2 don't place the binaries on the machine running the test.

My plan is to remove the magic from hh_paths. Just use plain normal "env=$(exe)" to pick up dependencies in the unit tests, no code generation, no runtime_deps, no magical hoping that a dependency we needed to build :hh_paths will also end up on machines which consume :hh_paths.

This diff is a minor cleanup along the way. I'm going to consolidate hh_paths to be just the four binaries needed to run heavyweight integration tests (hh_client, hh_server, hackfmt, hh_fanout). This diff moves hh_single_type_check out of it, since hstc is only ever used by test_extract_standalone.
