Commit title: Add dry run support to CPUConcurrencyController
Commit body:
Summary:
Adds support for `DRY_RUN` mode to CPUConcurrencyController. In this mode, CPUConcurrencyController will monitor CPU utilization and calculate concurrency limits. However, unlike `ENABLED` mode, concurrency limits will not be enforced. This mode can be used to identify potential issues with CPUConcurrencyController configuration without affecting server behavior.

Additionally, this change splits the single `mode` parameter into two parameters:
* `mode` - operating mode (DISABLED, DRY_RUN, ENABLED)
* `method` - enforcement method (CONCURRENCY_LIMITS, TOKEN_BUCKET)
