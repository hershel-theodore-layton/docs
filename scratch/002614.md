Summary:
This diff adds two new parser flags: `Hack.Lang.StressShallowDeclDeps` and `Hack.Lang.StressFoldedDeclDeps`. When enabled these flags will cause HackC to pull in dependencies on all symbol refs and all transitive parents, interfaces, and traits of classes defined in the current unit, respectively.

Also added are `Eval.LogDeclDeps`, and `Eval.LogDeclErrors` which when > 0 indicate the rate at which to log decl dependencies (along with any tearing that occurs), and errors (missing and un-parseable decls) found during compilation.

Finally when `Eval.LogAllDeclTearing` is set any tearing that occurred will always be logged regardless of the logging rate specified in `Eval.LogDeclDeps`.
