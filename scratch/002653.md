Summary:
CMake conventions and documentation describe package variables to hold the package's include directories as either <Package>_INCLUDE_DIR or <Package>_INCLUDE_DIRS. Our implementation stores this information in FOLLY_INCLUDE_DIR, but comments document it as FOLLY_INCLUDE_DIRS.

This change aligns the documentation with the implementation, and also copies the value into a variable named FOLLY_INCLUDE_DIRS, so that cmake users expecting either convention will get the correct value.
