Commit title: Remove class member getters
Commit body:
Summary: Remove support for populate_member_heaps=true from rust_provider_backend. Providing separate member getters allows us to have a means of looking up class member types individually from a separate heap. hh_server no longer uses this functionality, though. Additionally, pessimisation makes this more challenging to implement correctly: we'd want to perform pessimisation after the lookup. If we rely on lazy member lookup via the shallow class (as hh_server does in populate_member_heaps=false mode), pessimisation is performed after the lookup already. We could either start performing pessimisation after member lookups in rust_provider_backend.ml, or we can just remove these class member getters (so that non-hh_server backends like the hh_distc backend behave correctly when pessimisation is enabled, by allowing lazy member lookup to kick in).
