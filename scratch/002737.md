Commit title: Use Function instead of FunctionRef in OnDestructionCallback to make things work on MSVC.
Commit body:
Summary:
The first argument of `EventBase::OnDestructionCallback::schedule` is a
`FunctionRef<void(OnDestructionCallback&)>`.

In `EventBase::runOnDestruction`, we invoke `schedule` with a lambda. On
MSVC, we then get an infinite ping-pong between the `FunctionRef` constructor
in Function.h:1095 and the `isEmptyFunction` call in Function.h:1103.

This looks to be a MSVC-specific issue, because it works fine on other platforms/compilers, but it would still be helpful to fix it.
