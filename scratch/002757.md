Summary:
Reimplements `class_tparams_check.ml`; the pass checks that type params with class type constants do no refer to class level type parameters.

The OCaml version makes use of two visitors, the regular `Nast_visitor.handler_base` (which allows applicative sequencing of validation handlers) and `Nast_visitor.iter_with_state`. This appears to be because the `Nast_visitor.handler_base` does not support traversal of `class_typeconst_def`s or `hint`s

This version adds an additional flag to the passes context to ensure we only validate hints within typeconsts and performs the check entirely within the `transform` framework
