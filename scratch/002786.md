Commit title: Improve the IDL reference
Commit body:
Summary:
* Remove the note asking for feedback since it's outdated (IDL reference wasn't released recently), such requests belong to other channels than the documentation text itself (e.g. a post) and users can already provide feedback for any part of the documentation via normal Static Docs mechanisms.
* Add the Notation section with a link to the description of the notation used by the reference. We use Python's modified BNF in the parser and something resembling it in the reference and will make those fully consistent in follow-up diffs.
* Rename Syntactic Elements to Lexical Elements because that's what this section describes.
* Rewrite the Literals section because it's highly inaccurate: literals in Thrift are **not** identical to literals in C++. Instead define the literals as they are actually lexed.
* Clarify that literals don't have exact types.
* Define integers and floating-point numbers which are not literals but simple expressions with unary + and -.
* Replace "Thrift compilers" with "Thrift implementations" because we don't want to encourage people creating new compilers, only backends.
* Remove a note about not supporting binary literals because string literals are compatible with the binary type.
* Minor tweaks elsewhere.
