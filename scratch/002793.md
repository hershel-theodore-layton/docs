Commit title: Do not ignore Xenon events while in error handler
Commit body:
Summary:
D4053435 (https://github.com/facebook/hhvm/commit/b4c0c14886e6104275aae33fc318141cf4b83366) disabled processing of Xenon, MemThreshold and IntervalTimer events
while we are in an error handler. This was done with an assumption that these
events trigger other callbacks that could possibly fail, which would prevent
the original error handler logic from being run.

However, this is not the case for Xenon. Xenon just enqueues the sample
containing the current stacktrace and does not call any userland logic. These
samples are usually retrieved by userland logic at the end of the request, not
interfering with error handling in any way.
