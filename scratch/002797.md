Commit title: supportdyn pushing for Traversable
Commit body:
Summary:
Add supportdyn pushing for KeyedTraversable and for Traversable. That is `supportdyn<Traversable<t>> <: Traversable<supportdyn<t>>`. This is sound because the only way to get a value out of a Traversable is to call no-argument methods, e.g., `current() : T` from Iterator, and if the Traversable was supportdyn, then any method in it must return SDT values when all 0 of the the arguments are SDT.

We don't currently support supportdyn pushing for non-Container subclassese of Traversable/KeyedTraversable. We could add support for some builtins (e.g., Iterator) on a case-by-case basis
