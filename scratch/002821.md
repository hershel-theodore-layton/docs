Summary:
Rename `on_int_literal` and `on_float_literal` to `on_integer` and `on_float` respectively in parser actions for consistency with the grammar:

```
integer ::=  ["+" | "-"] int_literal
float   ::=  ["+" | "-"] float_literal
```

These are not literals but simple expressions with unary + and -.

Group parser actions for actual literals together.

Simplify a few rules while at it by using `[...]` instead of `(...)?`.
