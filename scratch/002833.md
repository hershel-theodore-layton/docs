Summary:
ChannelProcessor currently creates its own set of SequencedExecutors around the user-provided executor. This can use a lot of memory if an application has many ChannelProcessor instances.

This diff allows the user to optionally provide a pool of sequenced executors to use, allowing multiple ChannelProcessors to share the same pool.
