Commit title: Fix bug in __fromShape for Adapted fields
Commit body:
Summary:
For below thrift, the generated code for `__fromShape` doesn't consider the Adapter and will assign the fields as it would without the adapter.
```
struct Bar {}

struct Foo {
	edward-io.Adapter
	1. map<string,string> map_field
	edward-io.Adapter
	2. Bar struct_field
}
```
Generated code :
```

public static function __fromShape($shape): this {
	return new self(
		__stringifyMapKeys($shape['map_field']),
		Bar::fromShape($shape['struct_field'])
	);
}

```

This fixes this bug
