Commit title: Propagate IndexedMethodAttrs to read-only DBs with TrustedAutoloadPaths set
Commit body:
Summary:
D43127936 added an invariant preventing people from querying for method attributes that aren't specified in the `IndexedMethodAttributes` allowlist. Unfortunately, now `IndexedMethodAttributes` is no longer something we only look at when *indexing* facts, it's something we need to look at whenever a *query* happens. We weren't propagating this allowlist into SymbolMap's read-only constructor, and the new requirement that D43127936 imposes led to S327446.

This diff propagates the allowlist into SymbolMap's read-only constructor, and adds a previously-failing test case to the test which exercises read-only mode.
