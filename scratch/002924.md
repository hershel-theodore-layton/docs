Commit title: support generics in adapter name
Commit body:
Summary:
adding functionality to replace `<>` in an adapter name with the underlying Thrift type (for easy adapter reuse).

for example, for this

```
rust.Adapter{ name = "::fbthrift_adapters::DurationSecondsAdapter<>" }
1: i64 seconds,
```

the adapter used will be `::fbthrift_adapters::DurationSecondsAdapter<i64>`.

this mirrors how generics are handled in Python's adapter:
https://www.internalfb.com/intern/wiki/Thrift-Python/User_Guide/Advanced_Usage/Adapter/#generic-type-hint
