Commit title: Type special shapes operations by transforming decl
Commit body:
Summary:
The functions `Shapes::idx`, `Shapes::at`, and `Shapes::keyExists` are treated specially in the Hack typechecker, as though their application had special typing rules. This is clunky, and doesn't extend easily to Sound Dynamic (see for example, the test `supportdyn_shapes_idx.bad.php` which should not be accepted but is).

Instead, we can transform the prototype "decl" for these functions as taken from the hhi file, and use ordinary static method application. Sound Dynamic rules apply automatically.
