Summary:
Ocaml's map has
```
val filter_map : (key -> 'a -> 'b option) -> 'a t -> 'b t
```

Our WrappedMap instead has a version of filter_map which lacks `key`. Our version was introduced in D18854832 (Dec 2019) (but never actually used in that diff; its only uses came subsequently).
```
val filter_map : ('a -> 'b option) -> 'a t -> 'b t
```

In this diff I've renamed our own filter_map to `filter_map_no_key`. In this way, the underlying `Map.filter_map` will be easier to use.

I'm writing this diff because I want to use the underlying Map.filter_map.
