Commit title: Use magic const as placeholder for `--extract-standalone`
Commit body:
Summary:
I'm working on requiring that default parameters for functions / lambdas follow the same rules as constants. Turns out that for `--extract-standalone` we generate code like:
```
function foobar(int $whatever = \extract_standalone_default()): void {
  throw new \Exception();
}
```

This no longer typechecks, which is not good. I've switched us over to constants instead.
```
function foobar(int $whatever = \EXTRACT_STANDALONE_DEFAULT): void {
  throw new \Exception();
}
```

For the implementation I've used my best friend `UNSAFE_CAST`:
```
<?hh

const nothing EXTRACT_STANDALONE_DEFAULT = HH\FIXME\UNSAFE_CAST<mixed, nothing>("");

```
