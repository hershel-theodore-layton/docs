Commit title: query: trim trailing '/' in dirname
Commit body:
Summary:
Leaving a trailing slash is a common mistake when writing queries. When running
on EdenFS, Watchman would then pass a glob that looks like: "path//**" which
EdenFS immediately rejects.

Instead, let's have Watchman simply trim the trailing '/' to avoid this issue
and remove a surprising behavior.
