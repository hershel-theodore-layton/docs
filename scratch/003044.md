Commit title: Add Config::emit_error
Commit body:
Summary:
We currently thread a `&mut Vec<NamingPhaseError>` throughout the transform passes in order to allow passes to emit errors. Unfortunately, this signature allows other behaviors which are undesirable: passes can examine the errors emitted by previous passes or remove them from the list. Instead of threading around a `&mut Vec`, pull the error accumulator into the `Config`, and expose only an `emit_error` function. The error accumulator can only be recovered via `Config::into_errors` once all passes are complete (ending the shared borrow of `Config`)

Add some `From` impls for `NamingPhaseError` so that we need not write `NamingPhaseError::Naming(...)` at each `emit_error` site.
