Commit title: Intersect inside of Awaitable with enum base type
Commit body:
Summary: Under implicit pessimisation, we pessimise an enum of the form `enum E : int as int` as `(~E & int)`. But we get this wrong with `Awaitable<E>`, intersecting the `Awaitable` itself and so producing `nothing`. Fix code so that we pessimise the inside of the `Awaitable` in the case that the element type is enforced (for async functions).
