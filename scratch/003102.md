Commit title: Improve documentation of packages and includes
Commit body:
Summary:
* Improve the package declaration docs:
  * Fix the `package_declaration` grammar. Previously it was using a form of Java's BNF notation (incorrectly) while the rest of IDL reference is using Python's.
  * Document the lexical structure of a package name. Previously it was defined as `"Domain/identifier{/identifier}"` which is wrong even in Java's BNF notation.
  * Merge the Default Namespace section into Package Declarations because it's hard to define one separately from the other and since sections normally correspond to language constructs in the reference.
  * Improve the documentation of how the default namespaces are derived from the package name using the lexical elements introduced earlier and normal(ish) English. Previously it was using a combination of Python and something resembling Java's BNF notation but the result of this exotic fusion didn't make much sense, e.g. it applied list operations to something that was not lists and had missing separators.
  * Make examples more user-friendly by using realistic but simple names instead of placeholders.
  * Replace a list of Thrift namespace directives with a table of namespaces because we don't want to give an impression that this is how the package declaration is actually lowered and discuss how this is reconciled with real namespace directives. We also don't want to define a new feature in terms of a legacy one.
* Document `cpp_include` and `hs_include`.
* Move namespaces from the Thrift file example to the one in Namespace Directives to make the file example follow the recommended practice of using a package declaration instead of explicit namespaces.
* Fix incorrect C++ namespaces in examples: `facebook.peoplesearch` is translated to `facebook::peoplesearch` not `facebook::peoplesearch::cpp2`.
* Remove the note about transitive includes because it is wrong. We might want to disallow transitive includes in the future but Thrift allows them right now.
* Use `java.swift` and `python`, which are the recommended targets for Java and Python respectively, instead of the legacy targets.
* Move sections describing file-level constructs under Thrift Files.
* Break longish lines for readability on smaller devices and to avoid weird line breaks when printing.
* Improve wording in a few other places.
