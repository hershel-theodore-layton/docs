Commit title: Connection fanout feature
Commit body:
Summary:
Mcrouter feature used for test purposes to create connection fanout of up to 32K connections per destination. Useful in proxies to simulate production systems.

It adds a pool option to do this, see connection_fanout below:

```
{
  "pools": {
    "A": {
      "servers": [ "localhost:3000" ],
      "protocol": "thrift",
      "connection_fanout": 65536
    }
  },
  "route": "PoolRoute|A"
}
```
