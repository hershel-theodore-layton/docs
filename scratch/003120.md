Summary:
1. For primitive types, directly setattr so accessing these fields will be faster than accessing a property descriptor
2. use a tuple as `_fbthrift_field_cache` for other fields. Removing the thread lock since the structs are immutable, the set value will always be equal in the unlikely event of a data race.
3. allow list or set of primitive types to directly pass through without calling the to_python_value function
4. Some minor refactoring on the isset bytes array: avoid creating a std::string and then a memory copy.
5. directly set refcnt when adding an element to a frozenset
