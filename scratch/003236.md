Adds the ability to write lint rules using sound types.

Within the lint data structure we now have an optional check status. When it is set, we do the following:

- If the definition was checked once, then we are good and the types are sound.
- If the definition was checked twice, we look for agreement that is the lint was produced both under normal and dynamic assumptions.
