# What

Include paths, here's what the JSON now looks like in our tests for adding `__NoAutoDynamic` to a class  `\\E`:

```lang=json
{
    "entry_kind": "add_no_auto_dynamic_attr",
    "items": [
        {
            "kind": "((Cclass Concrete))",
            "path": "multiple_hierarchies.php",
            "sid": "\\E"
        }
    ]
}
```

# Why+Trade-offs

This change:
- is simple
- will reduce the need for complexity in the codemod json consumer for finding paths, and may help parallelism, too.

Downside:
- bulkier json. However, we generate lazily using `Sequence`, can consume one-line-at-a-time, and will parallelize consumers. So the bulk doesn't seem to be a problem

Alternative considered: The naming table has a reverse mapping from symbols to files, but afaict there's no way to use it without O(repo) traversal.
