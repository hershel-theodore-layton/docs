Commit title: Type adapter support in container element types
Commit body:
Summary:
Changes are:
1. Type adapter support for container types added, i.e list<AdaptedType>, map<AT1, set<AT2>> etc.
2. There is no limit on nested level on container types - other than thrift limit.
3. Container type adapters can be combined with field level type adapter or wrappers. Limit here is 2. Type+Type or Type+Wrapper is supported in all languages. (I will add a compiler rule to throw exception if more than 2 typedefs are defined in a hierachy)
4. Structs, exceptions and unions are supporting it.
5. Binary string, terse, optional, default values and equals for nested adapted types are tested.
6. Added unit tests to cover all corner cases.
7. Existing type adapter mustache and compiler refactored.
