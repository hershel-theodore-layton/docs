Commit title: Update x86 Arch Detection (#1944)
Commit body:
Summary:
The old detection set `IS_X86_ARCH=TRUE` on Apple M1 causing compilation to fail due to the erroneous `-msse4.2` flag. Several reports of this issue can be found here: https://github.com/facebookincubator/velox/issues/3453

This PR uses `CMAKE_SYSTEM_PROCESSOR`  which contains the result of `uname -m` to replace the previous detection mechanism. Additionally it allows users to override the variable should there be any detection issues (e.g. running in rosetta).
