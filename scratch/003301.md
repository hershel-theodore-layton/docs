Summary:
The "preamble" is used for RPC between client and monitor/server. The pattern there is to send the size of a chunk in a five-byte word with parity byte, followed by a marshalled blob of that size.

I want to use the same approach for the errors.bin streaming error file. So I'm exposing `Marshal_tools.preamble`
