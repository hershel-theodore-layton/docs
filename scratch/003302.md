Summary:
`Errors.format_summary errors` is the function which prints text like this:
```
15 errors found
15 errors found (only showing first 12, dropped 3).
```
I am working on streaming errors. With streaming errors, once we hit `--max-errors`, then we stop immediately - we don't know the full `errors` list, hence can't call `Errors.length errors`, and we don't know the dropped count.

This diff therefore changes the function to also be able to print summary when it doesn't know the complete error list nor the drop count:
```
12 errors found (only showing first 12)
```
