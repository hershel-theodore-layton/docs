Commit title: Build test binary for testing lldb scripts
Commit body:
Summary:
To make it easier to test pretty printers and other LLDB helpers automatically, let's create a simple binary that creates some TypedValues and other important HHVM data structures.

The LLDB tests can use this binary rather than an HHVM binary and so not have to worry about HHVM function names used as breakpoints in the unit tests from changing. Also makes the tests faster since we're not loading and parsing arbitrary test Hack files just to test how we print internal data structures.

This test binary will only be used by lldb tests: hence no need for the gdb index to be create in the `hhvm_types_for_lldb_tests` build rule.
