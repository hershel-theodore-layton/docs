Commit title: Open files in binary mode by default on windows when going through folly's portability layer
Commit body:
Summary: Linux has no concept of text vs. binary mode, and folly wasn't written with that distinction either, so things break when Windows opens things in text mode by default. This makes anything that goes through the portability layer for `open` open in binary mode by default, unless text mode has been explicitly specified.
