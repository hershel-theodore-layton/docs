Commit body:
Summary:
Shape type can get huge; however in source code
they are often referred to via aliases. This diff
remembers the aliases to speed up comparison of
shape types. This new information could also be
used to display better error messages.

One could think that D32675495 got most of the
wins to be had here, but that is not the case. I think
that is because comparing types that come from
distinct localize calls does not fall in the physical
equality fast path.
