Commit title: Make vec non-pessimised builtin
Commit body:
Summary:
Now that `vec<T>` has no bounds on the generic parameter, we can make it a non-pessimised builtin. That is, `vec<int>` is a vector whose elements have type `int`, and `vec<~int>` is a vector whose elements have type `~int`.

* Construction of vecs is changed: `vec [ getLikeInt() ]` now produces `vec<~int>`, and `vec [3]` produces `vec<int>`.
* Indexing directly on vecs (not through an interface) gives back the actual element type e.g. if `$x` has type `vec<int>` then `$x[0]` has type `int`.
