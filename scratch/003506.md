Commit title: Make dict non-pessimised builtin
Commit body:
Summary:
Now that `dict<Tk,Tv>` has only an array key bound on the generic parameter `Tk`, we can make it a non-pessimised builtin. That is, `dict<int,bool>` is a dict whose value elements have type `bool`, and `dict<int,~bool>` is a dict whose value elements have type `~bool`.

Construction of dicts is changed: `dict[ "A" => getLikeInt() ]` now produces `dict<string,~int>`. Indexing directly on dicts (not through an interface) gives back the actual element type e.g. if `$x` has type `dict<string,int>` then `$x[0]` has type `int`.
