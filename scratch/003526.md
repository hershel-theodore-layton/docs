Commit title: Implement Unicode escape sequences
Commit body:
Summary:
Implement Unicode escape sequences of the form `\uhhhh` in the lexer. This makes it unnecessary to deal with them in codegens.

This also fixes handling of Unicode escape sequences in Hack which uses a different syntax, `\u{xxxxxx}`. In other supported languages `\uhhhh` already works:

* C++: https://en.cppreference.com/w/cpp/language/escape
* Java: https://docs.oracle.com/javase/specs/jls/se7/html/jls-3.html
* Python: https://docs.python.org/3/reference/lexical_analysis.html#string-and-bytes-literals
