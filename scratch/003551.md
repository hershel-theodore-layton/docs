Commit title: splat support
Commit body:
Summary:
"Splat" is a weird operation:
```
$c = vec[1, 2, 3];
foo($a, $b, ...$c);
```
pretends that we called `foo` with the array values of `$c` unwrapped:
```
foo($a, $b, 1, 2, 3);
```
This has to be done at runtime because `$c` is a runtime value.  For now we'll just let Infer know about it by marking it as:
```
foo($a, $b, __sil_splat($c));
```

Also added support for the ResolveMethCaller instruction.
