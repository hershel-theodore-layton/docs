> D44306402 introduced "Extract into variable" with a few known limitations. This diff fixes two of the limitations.

Add "extract into variable" for single-statement-lambdas.

Implementation required some subtlety:
- peeking at the user's raw source code because the AST doesn't distinguish `() ==> 200` from  `() ==> { return 200; }`
- some ugly state to handle nested lambdas
