Commit title: Simplify string generation in C++
Commit body:
Summary:
Simplify string generation in C++ by removing a special case for multiline strings. This makes string generation more consistent with other languages and internally because multiline strings were only handled specially in constants but not other places like metadata. Remove `value:string_multi_line?` which is no longer used.

Before:

```
  static constexpr char const * const multi_line_string_ = R"__FBTHRIFT_STRL(This
is a
multi line string.
)__FBTHRIFT_STRL";
```

After:

```
  static constexpr char const * const multi_line_string_ = "This\nis a\nmulti line string.\n";
```

As a curious side effect this allows putting `)__FBTHRIFT_STRL"` in a string literal.
