Summary:
These tests were flakey.
```
      (* We want ServerFiles.errors_file to be placed in this test's temp directory *)
      Unix.putenv "HH_TMPDIR" tmp;
```
This code doesn't work for the current process. That's because HH_TMPDIR is read only once, at program startup. Therefore, all the tests were just sharing the same old /tmp/hh_server. It's not surprised they failed the stress test.

Instead, I have to use another testing hook which I recently introduced for integration_ml:server_progress
```
      ServerFiles.set_tmp_FOR_TESTING_ONLY tmp;
```
