Commit title: add structured annotation support for derives and add support for `crate::` substitution
Commit body:
Summary:
this diff makes three changes:
1. Adds a structured annotation for derives. While we already have the unstructured `rust.derive` annotation, but this can't be used transitively with `scope.Transitive`. Plus unstructured annotations are deprecated anyways, so should have a structured version of this anyways.
2. Support substituting `crate::` in adapters and derives when applied with `scope.Transitive`. Since Rust dependencies are isolated between crates (unlike C++ or Python), we need this to be able to properly support `scope.Transitive` across different Thrift modules. The unit tests show how to do this.
3. Change the ordering of structured annotation lookups in `ThriftAnnotations` to match how it's done in the Thrift compiler code. The current code does a form of breadth-first search across annotations, whereas [Thrift compiler code does a form of depth-first search](https://github.com/facebook/fbthrift/blob/2b35a132ad838dbdd0034e32e14d2de59ea18f68/thrift/compiler/ast/t_named.cc#L39). Theoretically, since Thrift doesn't allow duplicate annotations, this should have no effect but for consistency sake, this makes the generated `ThriftAnnotations` code also do a depth-first search across transitive annotations.
