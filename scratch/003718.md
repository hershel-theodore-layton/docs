Commit body:
Summary:
Report an error on surrogates in Unicode escapes because transcoding them would result in invalid UTF-8. We already document this behavior by saying that `hhhh` should be a Unicode scalar value in `\uhhhh`: https://www.internalfb.com/intern/staticdocs/thrift/docs/idl/#literals. Quoting https://www.unicode.org/versions/Unicode10.0.0/ch03.pdf#G7404:

> D76 Unicode scalar value: Any Unicode code point except high-surrogate and low-surrogate code points.
