Commit body:
Summary:
Extend the ocaml ffi for hh_distc to support a notification socket and streaming errors.
* stdio events are handled transparently, not marshalled back to ocaml
* progress events and errors are passed to ocaml

Here's the protocol for OCaml:
1. handle = spawn()
2. fd = handle.sock // get the fd
3. select(fd + other fds)
4. if fd has any data:
    1. read to end without blocking
    2. consume events by calling handle.recv() in a loop
5. if fd has no data, then it was closed:
    1. call handle.join()
6. if some other fd has traffic and we decide to cancel:
    1. call handle.cancel()
    2. call handle.join()
