Summary:
Implement the ocaml side of hh_distc streaming events.

New event type that can be any one of
* a batch of errors
* a message indicating typing has started on N files
* a progress message that D files are done

OCaml needs a file descriptor so it can wait on type checking and handle
other events like cancellation. Implement this with a unix socket pair;
each time some events are ready, a byte will be sent, so OCaml can wake
up and react, while also waiting on other fds.

The notification byte is arbitrary; I made a little spinner so I could tell it was working.
progress is displayed with ServerProgress.write; I would imagine this needs to
be changed to ServerProgress.write_percentage.

This diff only selects on the hh_distc file descriptor. interrupts & cancellation
come later; everything should be ready to go in Rust.
