Commit title: Move property initial value rewriting in HHBBC into extern-worker
Commit body:
Summary:
HHBBC will rewrite the initial values of properties in order to infer
better types. Move this logic over to use extern-worker. It can be
done as part of FlattenJob and BuildSubclassListJob. This means that
BuildSubclassListJob now needs php::Class and not just ClassInfo. It
does not, however, require the bytecode, which lessens the overhead.

Since BuildSubclassListJob now have the php::Class, we no longer need
to mirror the class Attr bits.
