Commit title: Do not add implicit supportdyn bounds for context constants
Commit body:
Summary: We add `as supportdyn<mixed>` to abstract type constants that lack bounds; this makes it so that `this::T` can be upcasted to dynamic by exposure to its supportdyn bound (whereas the trivial top type bound for abstract types cannot). However, this should not happen for context constants where we *do* expect to instantiate the constant with `[] === mixed`.
