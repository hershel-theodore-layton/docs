Commit title: Remove esoteric escape sequences
Commit body:
Summary:
There is little reason to support `\a`, `\b`, `\f` and `\v`. These escape sequences mostly exist for historical reasons and are not a thing in modern programming languages such as Rust and Swift:

* https://doc.rust-lang.org/reference/tokens.html#literals
* https://docs.swift.org/swift-book/documentation/the-swift-programming-language/stringsandcharacters/#Special-Characters-in-String-Literals

Remove them bringing the implementation in line with the documentation: https://github.com/facebook/fbthrift/blob/main/thrift/doc/idl/index.md#literals. Reorder the other cases for easier comparison with the docs.
