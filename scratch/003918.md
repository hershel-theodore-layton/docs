Commit title: Add TypeErasedStorage for type-opaque construction on the stack, similar to `std::any`
Commit body:
Summary:
TLDR: We want to store things that aren't OSS on `Cpp2RequestContext`. To do this, we are introducing `TypeErasedStorage`.

This class allocates `Size` bytes on the stack, where a class can be `emplaced`.

Example API:
```
struct FacebookBuisnessLogicHolder {

    FacebookBuisnessLogicHolder(int, std::string) {}

    std::vector<std::string> components;

};

struct AnotherClass {};

...

using MyStorageType = TypeErasedStorage<1024, folly::cacheline_align_v>;
auto storage = MyStorageType::make<FacebookBuisnessLogicHolder>(5, "hello");

// Safe, slower API
FacebookBuisnessLogicHolder& val = MyStorageType::cast<FacebookBuisnessLogicHolder>(storage);

// Faster, unsafe API
FacebookBuisnessLogicHolder& val = storage.getValueUnsafe<FacebookBuisnessLogicHolder>();

// Throws std::bad_cast
FacebookBuisnessLogicHolder& val = MyStorageType::cast<AnotherClass>(storage);

// Undefined behavior
FacebookBuisnessLogicHolder& val = storage.getValueUnsafe<AnotherClass>();

```

Properties:
- Templated on `Size`, and `Alignment`
- Immutable once constructed.
- Opt-in type safety via `typeid`
