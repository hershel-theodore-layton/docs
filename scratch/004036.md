Commit title: Prefer "hh_client" to "Hack IDE" in user messages
Commit body:
Summary:
Previously, we would "Hack IDE" to refer to the clientIdeDaemon part of hh_client. This was less helpful for us:

(1) Users generally think of Hack IDE services as the whole collection of processes.

(2) Hack team contributors generally think in terms of build targets: hh_client, hh_server, hh_single_type_check. Saying "hh_client" gives them a hint of where to look when something is broken.

(3) In several cases we would explicitly write:

```
Hack IDE: initializing.
hh_server: stopped.
```

This reads better (I think) as:

```
hh_client: initializing.
hh_server: stopped.
```
