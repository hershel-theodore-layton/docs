Commit title: Delete CarbonRouterInstance instance if it fails to be spun up
Commit body:
Summary:
If we get an exception during [the spin-up of CarbonRouterInstance](https://www.internalfb.com/code/fbsource/[b435d76761541d75d863d0b7aa8d1d727e5d2d75]/fbcode/mcrouter/CarbonRouterInstance-inl.h?lines=125-136), [the instance](https://www.internalfb.com/code/fbsource/[b435d76761541d75d863d0b7aa8d1d727e5d2d75]/fbcode/mcrouter/CarbonRouterInstance-inl.h?lines=121) would not be cleaned up, and it may cause a deadlock during shutdown because it holds shared pointers to SR client factories that keep SR-related singletons from being destructed.

This diff makes it delete the `CarbonRouterInstance` instance if it cannot be spun up, which can prevent the dead lock issue described above.
