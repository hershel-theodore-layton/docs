Summary:
This adds LSP integration tests for status and errors, for `--config ide_standalone=true`.
* does it start up showing hh_server status correctly
* if you turn on or off hh_server then does it update status
* does it produce squiggles from standalone
* does it read errors.bin to get further squiggles, but without overwriting those it got recently from standalone

For status, what's new in standalone is that it sends a wide variety of status messages e.g. "typechecking 5/238 (2%)". I therefore needed to add the ability in test_lsp.py to still wait for the status message I'm expecting, but ignore all others.

Pylint was complaining about `f"string that didn't have any holes"` so I fixed that up too.

I really dislike working in test_lsp.py! (1) it's too big. (2) it's declarative everywhere but I'd prefer imperative. (3) it's so hard to figure out what everything means and where things fit.
