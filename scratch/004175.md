I wish to make some systematic changes to clientIdeMessage.ml in future, and in preparation I'm spending some time streamlining it.

BEFORE:
```
type document_location = {
  file_path: Path.t;
  file_contents: string;
  line: int;
  column: int;
}

type document_and_path = {
  file_path: Path.t;
  file_contents: string;
}
```

AFTER:
```

type document = {
  file_path: Path.t;
  file_contents: string;
}

type location = {
  line: int;
  column: int;
}
```

This diff merely removes the duplication. Anything which used to take `document_location` now takes `document * location`. I think this is easier to read. It's also more versatile, e.g. for methods which only want `Path.t * location` because they don't have meaningful file_contents.
