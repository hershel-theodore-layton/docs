# Context
This implements the parsing for the case type feature. See D44810190 for description of desired parsing.

Of particular note is the error recovery for parsing variants. There are various cases I wanted to ensure we recovered gracefully. They are covered in hphp/hack/test/full_fidelity/cases/case_types/case_type_error_variants.php

A few to call out are:
```
case type CT = string |
```
We should report a missing type specifier and colon, but recover by continuing to parse the next structure properly.

```
case type CT = string | int
```
We should report a missing semicolon and recover by continuing to parse the next structure properly.
