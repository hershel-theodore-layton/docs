Commit title: Alleviate race condition in test with sleep
Commit body:
Summary:
`hphp/test/slow/included-enum-modify.php` runs repeatedly 5 times in a loop
(see its .opts file).  It is including the file it writes to, and we cache
includes as long as the filesystems last modified time does not report changes.
This means our include can miss some updates.  Introducing a sleep 1 in the
test guarantees we will get to another filesystem tick before writing the file
again.
