Summary:
We use a variety of exit codes in an inconsistent manner. Standardize
on generally using HPHP_EXIT_FAILURE for error, and 0 for success. Use
1 for a few situations, like for a script failing with a fatal.

This cleanup helps me improve the error recognition in hphp/test/run
as I can more reliably interpret the exit codes (which is not really
possible right now).
