Commit title: Add --repo-options-dir command to compiler entry
Commit body:
Summary:
We read `RepoOptions`, aka`.hhvmconfig.hdf` and `PACKAGES.toml`, from --input-dir.
For unit tests, `--input-dir` ends up being the root directory where hphp folder lives.
Each test folder might declare its own `.hhvmconfig.hdf` and `PACKAGES.toml`.
In order to accomodate for this, we need to add a new option to set the directory where these files live.

Another option would be to set `--input-dir` for each test to its own root directory but then this would break all filepaths for test errors etc.
