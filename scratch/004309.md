Commit title: Small performance improvement for readVarintMediumSlowUnrolled
Commit body:
Summary:
It looks like the check `(len > 0 && !(p[len - 1] & 0x80))` is degrading performance of the `readVarintMediumSlowUnrolled`.
Comparing assembly, with check:
```
        cmp     rcx, 4
        ja      .LBB1_3
        test    rcx, rcx
        je      .LBB1_16
        cmp     byte ptr [rcx + rdx - 1], 0
        js      .LBB1_16
```
Without check:
```
        cmp     rcx, 5
        jb      .LBB1_14
```

Profiling benchmark with perf shows that number of iTLB-load-misses decreased after removing this check.
