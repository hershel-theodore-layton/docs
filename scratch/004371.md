Commit title: Using adapted type for ListPatchIndex
Commit body:
Summary:
If we have `list<string>` field, here is an illustration of generated patch struct

```
struct SomeListPatch {
  1: optional list<i32> assign;
  2: clear;
  4: map<i32, StringPatch> patch;
  // ...
}
```

We can patch element inside `list<string>` by using `patch` field. Here the key (i32) is a zig-zagged index. It should never be used directly without zigzagging. This diff added adapted type `ListPatchIndex` to do the zig-zagging automatically.

```
struct SomeListPatch {
  1: optional list<i32> assign;
  2: clear;
  4: map<patch.ListPatchIndex, StringPatch> patch;
  // ...
}
```
