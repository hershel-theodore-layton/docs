Commit title: Use unknown type nothing for closed shapes
Commit body:
Summary:
Following the change to shape introduced in D45001642, where the type of unknown fields in open shapes is specified explicitly, we now use this type to express *closed* shapes as open shapes in which the unknown fields have type `nothing`. So, for example:
```
shape('a' => int) == shape('a' => int, _ => nothing)
```
This simplifies slightly the representation and logic associated with shapes.
