Commit body:
Summary:
{fmt} is used by both compiler and runtime libraries so find it unconditionally.

Without it building compiler only is broken:

```
$ cmake -Dcompiler_only=ON ..
...
CMake Error at thrift/compiler/CMakeLists.txt:41 (target_link_libraries):
  Target "compiler_ast" links to:

    fmt::fmt

  but the target was not found.  Possible reasons include:

    * There is a typo in the target name.
    * A find_package call is missing for an IMPORTED target.
    * An ALIAS target is missing.
```
