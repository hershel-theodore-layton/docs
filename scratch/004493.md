Commit title: remove HHVM_RC_DYNAMIC
Commit body:
Summary:
This affects 3 legacy PHP "dynamic constants": PHP_BINARY, PHP_BINDIR, and PHP_SAPI. The HHVM_RC_DYNAMIC macro marked these as dynamic, however HHBBC still could constprop their compile-time value if the type was not KindOfUninit (e.g. KindOfPersistentString for these).
All three of these constants could reasonably be expected to have different values between repo compile time and runtime.

It's best to just kill these PHPisms entirely, so that's what this diff does:
* introduce an intrinsic call to replace PHP_BINARY for tests and systemlib functions that need it.
* delete tests for PHP_BINDIR + PHP_SAPI.

There's still quite a bit of "magic dynamic constant" support logic, but only three remaining constants that needed, as far as I can tell: STDIN, STDOUT, and STDERR.  It would be nice to migrate these too but it's out of scope for this diff.
