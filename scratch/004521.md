Summary:
Enable running unit tests remotely by setting appropriate labels in TARGETs
files.

A couple side effects:
- We no longer use system hhvm for running the unit test runner in dbgo build
  modes.  This is because we have no way of naming this artifact in a buck
  target such that it is available in RE.  This means our unit test runner will
  run more slowly, but it will gain the advantage of being run in a distributed
  fashion so its speed is less important.
- We run unit tests with a stripped hhvm binary.  This decreases the upload and
  download size required to get the tests into RE workers.
