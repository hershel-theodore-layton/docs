Commit title: also allow stdio in cli_server mode
Commit body:
Summary:
The old STDIO constants were defined in cli mode one way, and
cli_server mode a different way, so I missed one case. This diff
allows the new HH\stdio() functions to work in cli_server mode.

While I'm here, improve the API so user code can detect whether a
stream is available before trying to access it, by adding `HH\try_stdin()`,
etc, which return null if the stream is not available.

Using try_stdin() (etc) is better than testing whether a constant is defined
or not, e.g. `if (defined('STDIO')) /* do something with STDIO */`
because it avoids using reflection and doesn't rely on runtime dynamic
symbol binding.

This also allows `HH\stdin()`, etc, to be hoisted into Hack while slimming
down the C++ implementation code.
