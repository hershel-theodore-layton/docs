Commit title: Canonicalize repo location (and use a std::fs:path for m_path instead of a string)
Commit body:
Summary: The Autoloader's `requestInit` method calls `getRepoRoot()` multiple times. This is slow because the path is stored as a `string`, then it's converted to a `std::filesystem::path`, and then it's canonicalized. Instead, just store the things as a `std::filesystem::path` to begin with and canonicalize the repo directory (and use the `dir()` method instead of using `path().parent_path()` for the repo root, since that what it is anyway)
