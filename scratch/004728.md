Commit title: Fix AsyncioExecutor destruction bugs
Commit body:
Summary:
Kill ~AsyncioExecutor, and introduce `drop` instead.

`drop` leaks the AsyncioExecutor instance if python is finalizing and there are pending keepalives (so that any subsequent usage of the executor from other threads is OK).

If python is not finalizing, `drop` executes callbacks (it is safe to do so) until the keep-alive count drops to 0, and then frees the instance.
