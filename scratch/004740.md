Commit title: Bring parser grammar in line with the docs
Commit body:
Summary:
Bring the parser grammar for definitions closer to the documented one.

In particular, remove `definition_body` and a weird two-phase parsing of definitions inherited from the old parser. This will allow simplifying AST construction later because we'll be able to construct correct AST nodes instead of constructing them partially and then patching.

This also removes parsing of delimiters after struct and other definitions which is neither documented (see e.g. https://github.com/facebook/fbthrift/blob/main/thrift/doc/idl/index.md#struct-types) nor useful because these are already delimited by braces. There were only a few cases that used such delimiters probably by mistake. All of them fixed now so this is not a breaking change.

Store deprecated annotations in attributes to make signatures simpler and since these are related and uncommon.
