Commit title: support for default params
Commit body:
Summary:
Support default parameters by emitting multiple versions of functions.

A function with 2 default parameters will emit three versions of the function:
- A version which takes all three parameters.
- A version which takes two parameters, computes the third parameter and calls the 3-param version.
- A version which takes one parameter, computes the second parameter and calls the 2-param version.

This relies on the infer support for function overloads in D45091866 to work.
