Commit title: Only analyze the 86init functions when analyzing constants
Commit body:
Summary:
Normally, we should only be analyzing the various 86init functions
during the analyzing constants phase. However, in some situations they
can call other arbitrary functions, which then get pulled into the
worklist. This is inconvenient and makes the conversion to using
extern-worker more complicated. Enforce that we only look at 86init
functions during this phase by excluding anything else from the work
list. This doesn't affect correctness, and doesn't affect analysis
quality either. We'll analyze the functions again during the main
analysis phase anyways and will catch any missing types there.
