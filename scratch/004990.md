Summary:
It used to be that some reserved names were allowed inside namespaces "N\Bool". (even though they were disallowed at top level, and even though other reserved names were disallowed inside namespaces).

The diffstack up to here has made this uniform: now the reserved names are forbidden equally within a namespace as outside it. The within-namespace tests now have no value -- they're not testing any codepaths not already covered. Therefore, I'm deleting them.

(I'm doing this also in anticipation of the next diff, which adopts "FileCheck" as the mechanism verifying output, and I can't be bothered to write it all out for the namespace cases as well as the normal cases...)
