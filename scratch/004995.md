Summary:
This diff makes two changes in RocketServerConnection and the RocketServerConnectionObserver interface:
1. it implements the AsyncWriter callback `writeStarting` to indicate when a write is ready to be written to the socket; it also invokes the `writeStarting` observer notification from `writeStarting` rather than from `flushWrites` as before;
2. it adds two fields to the `RocketServerConnectionObserver::WriteEvent` struct, `batchStartRawByteOffset` and `batchEndRawByteOffset`, to indicate the start and end raw byte offsets of the batched write to which the write event corresponds to.
