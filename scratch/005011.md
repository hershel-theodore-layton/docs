Commit body:
Summary:
Typedef and const definitions may have an optional semicolon as a delimiter, for example:

```
const i32 BIG = 42;
```

The VSCode formatter even automatically adds semicolons at the end of const definitions.

However, the grammar of these constructs in the IDL reference doesn't actually mention these delimiters. Fix it, bringing the documentation closer to the implementation and tooling.
