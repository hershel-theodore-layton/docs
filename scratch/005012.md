Commit body:
Summary:
To minimize risk during roll out of implicit Sound Dynamic, let's not set `like_type_hints`, instead rejecting their use in source code. Although pessimisation introduces likes, it does so in decls, not in AST type hints, so there is no problem rejecting their use in the naming phase.

For pretty printing, we show likes if sound dynamic is enabled at all.
