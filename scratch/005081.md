Commit title: Equality refinement
Commit body:
Summary:
When an equality check succeeds, we can refine each operand based on the other operand's type, giving both intersection types.

This prevents redundant type tests and assertion reducing syntactic clutter and improving static signal, e.g.,

```
function main(?int $i): void {
  if ($i === 42) {
    // The following assumption was necessary before this diff,
    // but not after.
    $i as nonnull; // or `$i is nonnull` in the condition
    takes_int($i);
  }
}
```
