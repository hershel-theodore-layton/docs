Commit title: Add type structure support for case types
Commit body:
Summary:
This diff adds type structure support for case types. As a quick recap, case types are similar to union types but they can only appear at type alias positions, which means you cannot define adhoc types at function parameter positions.

Reified comparison for is/as expressions are done by witness comparison which means that

case type T1 = int | string;
case type T2 = int | string;

T1 and T2 are compared name and not by structure.

With the type structure support, we get support for reflection, is/as expressions and reflection.

As a follow up, I will add support for function parameter and return type verification.

Also as a follow up, we can do more optimizations as constant folding the case type and flattening.
