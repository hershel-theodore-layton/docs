Commit title: Bail out early from spin_pause_until()
Commit body:
Summary:
Many spin_pause_until() use cases like
SaturatingSemaphore::tryWaitSlow() pass deadline = timepoint::min() to indicate
that no timeout should be applied, and any failure to acquire the resource
should fail immediately. Unfortunately SaturatingSemaphore, UnboundedQueue and
other direct and indirect callers tend to pass time_point::min() as the
deadline parameter for *until() variants of the syncronization primatives. This
means that each call to try_*() (without until()) triggers an unnecessary call
to get the clock time which is unconditionally going to fail. Instead, don't
bother checking the clock if the timepoint passed to spin_pause_until() is
time_point::min()
