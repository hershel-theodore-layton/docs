Commit title: make "Extract into method" extracted methods nonstatic by default
Commit body:
Summary:
**Before**: extracted methods using the "Extract into Method" refactor were `static` by default.

**After**: extracted methods are not `static` by default unless called from a `static` method.

**Why**: Some people like to mock, and this choice is more mocking-friendly. The downside is that we are no longer "Principle of Least Privileging" but it's a trade-off.

Note that this mock-friendliness also pushes in the direction of the extracted method having `protected` visibility rather than  `private` but imo quietly creating more inheritance surface area from helper functions is a bridge too far.
