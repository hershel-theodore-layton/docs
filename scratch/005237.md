Summary:
If gathering the stack trace using StackTraceNoHeap fails (segfaults,
for example), then the Optional will remain empty and then we'll
assert at a later stage. Check if the Optional is present before using
it. Furthermore, if StackTraceNoHeap ctor crashes, then try again, but
try to use a "simpler" backtrace function.
