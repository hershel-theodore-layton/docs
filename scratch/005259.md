Commit title: Remove `ListPatch::remove`
Commit body:
Summary:
This API is incompatible with `patchAt(...)`.

In the patch, we always apply `patchAt` first, then `remove`. If user constructed the following Patch

```
patch.remove(element);
patch.patchAt(index) = subPatch;
```

We can't create an equivalent patch that does `patchAt(...)` first. This API needs to be re-designed. Since currently no one actually uses it, I'll just remove it for now.
