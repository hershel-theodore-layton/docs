Commit title: delete AutoloadHandler::getSymbols(path,kind)
Commit body:
Summary:
AutoloadHandler::getSymbols() is used as a convenience function by the `hh`
extension functions autoload_path_to_types, autoload_path_to_functions, etc.

But it implements an anti-pattern: take something known at compile time
(the symbol kind), pass it as a runtime parameter, then later on switch on
that parameter. Since AutoloadMap() already exposes the necessary methods
for each symbol kind, call them directly.
