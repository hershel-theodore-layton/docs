Commit title: fix windows file sizes > 2**31-1
Commit body:
Summary:
We were storing stat.st_size (file byte size) as off_t, but on Windows off_t is a 32 bit signed integer. Any value greater than 2**31-1 was not working.

Instead, store file size as uint64_t so big file support is not platform or architecture dependent. Note that in most other places file size is represented as a size_t, so big files still won't work if size_t is only 4 bytes.
