Commit title: Work-around for soundness issue
Commit body:
Summary: When calling a function like `function set_a_box<TBox as MyBox, TVal>(TBox $b, TVal $v): void where TVal = TBox::TInner` under implicit pessimisation, the `as supportdyn` bound added to `TBox` causes the localisation of the where clause to generate Tanys, which is a soundness bug. This only adds the bound when there isn't another `as` bound present.
