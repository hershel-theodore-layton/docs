Commit title: Account for like types
Commit body:
Summary:
`has_no_object_ref_ty` predicate returns true if the type **might not** allow references to other objects.

With true types, some types that used to definitely return references to other objects such as `dict<string, Bar>` became `~dict<string, Bar>` which overlaps primitives because `~dict<string, Bar> = dynamic \union dict<string, Bar>`.

By stripping like types this diff recovers the old behaviour.
