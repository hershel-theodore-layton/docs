Commit title: Use FOLLY_CPLUSPLUS instead of __cplusplus
Commit body:
Summary:
MSVC does not set the correct version value for `__cplusplus` for compatibility
reasons: https://learn.microsoft.com/en-us/cpp/build/reference/zc-cplusplus?view=msvc-170
However, it has a fallback macro `_MSVC_LANG` that reports the correct C++ language
version. Use `FOLLY_CPLUSPLUS` that checks `_MSVC_LANG` together with `__cplusplus` to
ensure that we have the correct version detection.
