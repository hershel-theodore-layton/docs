Commit title: Add socket sequence number support
Commit body:
Summary:
Add an `int64_t` inside (non-null) `SocketFds`, as well as the associated methods.

The general rationale is described by the method docblock. The specific context that up-stack (D46005254), `rocket::pack*` functions begin to pull "FD sequence numbers" from the `AsyncFdSocket` and inject them into `rocket::Payload::fds` **and** into the serialized message's metadata. This serves to detect and (therefore fail on) the dangerous kind of code bugs where the wrong FDs would otherwise get associated with a Thrift message.

Also move the branchier `SocketFds` methods into a `.cpp` file to improve legibility and also compiled code size, since `SocketFds.h` is now included in a good number of compilation units.
