Commit title: Error when the default package attempts to access a non-default package
Commit body:
Summary:
With package config
```
[packages]

[packages.polaris]
uses=["instagram.polaris.*"]
includes=["default"]

[packages.default]
uses=[".*"]
```
 the following fails to incur a typecheck error when a module-less `IGAliteWWWConfiguration` uses `PolarisErrorRoute` (`instagram.polaris` module)
```
//// IGAliteWWWConfiguration.php
<?hh
class IGAliteWWWConfiguration {
  public function test() : void {
    $x = new PolarisErrorRoute();
  }
}

//// PolarisErrorRoute.php
<?hh
module instagram.polaris;
public class PolarisErrorRoute {}
```
This diff fixes the typechecker behavior such that public members from a non-default package are not accessible to the default package by producing an error
```
Typing[4472] Cannot access a public element in package polaris from the default package [1]
-> This is from module instagram.polaris, which is in package polaris [2]
-> But this is from outside of a module, which belongs to the default package [3]
-> And the default package does not include package polaris [3]

    2 | class IGAliteWWWConfiguration {
    3 |   public function test() : void {
```
