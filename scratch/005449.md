Commit title: Remove the additional `ensure` methods in UnionPatch
Commit body:
Summary:
Currently the following code works for both struct and union patch

```
StructOrUnionPatch patch;
patch.ensure<ident::foo>("foo");
```

However, UnionPatch also provides an additional way to ensure a field

```
UnionPatch patch;
patch.ensure().field_ref() = "foo";
```

This is never used in production and bit over engineering. It's inconsistent with struct patch and it doesn't have 100% test coverage either. Let's remove it.
