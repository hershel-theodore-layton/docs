Summary:
[Overview: there exists only a single Errors.phase, `Errors.Typing`. I'm cleaning up the code by removing all mentions of phases.]

Hulk had a feature (never used) for hh.conf setting `disabled_on_errors = Parsing,Naming`. The idea was that we could disable hulk from running if there were (say) any Parsing or Naming errors.

But the feature was never used. And since direct-decl-parser was introduced parsing errors are generated during remote typechecking in any case (hence the Parsing phase has been eliminated). And since earlier in this diffstack naming errors are also generated during remote typechecking. And also, we've rolled out distc instead of hulk, which uses its own quite different (and better) logic for deciding whether any errors should prevent distc from being used D46121544.

Therefore, this feature is three-fold useless! This diff removes it.
