Summary:
[Overview: there exists only a single Errors.phase, `Errors.Typing`. I'm cleaning up the code by removing all mentions of phases.]

This diff changes the disk format of saved-states-with-errors. If a saved-state was generated for a repo that has errors in it, these are stored in a file called "hh_mini.err" or similar. It is an ocaml marshalled blob with this content, defined in saveStateServiceTypes.ml
```
BEFORE:
type saved_state_errors = (Errors.phase * Relative_path.Set.t) list

AFTER:
type saved_state_errors = Relative_path.Set.t
```
This diff changes the disk format, by changing the type of that ocaml marshalled blob. I'm getting rid of the "phase" part of it. After all, there only now exists a single phase.

Along with it, I'm removing the "phase" argument from a call in Errors.ml which was only ever used by saved-state stuff.

Although both ocaml and rust can generate saved-states, in practice we commonly generate them in rust:
```
BEFORE:
pub fn dump_error_files(output_path: &Path, errors: &Errors) -> Result<()> {
    let errors_in_phases: Vec<(Phase, BTreeSet<&RelativePath>)> = [Phase::Typing]
        .into_iter()
        .map(|phase| {
            let failed_files = (errors.iter())
                .filter_map(|(relpath, by_phase)| match by_phase.contains_key(&phase) {
                    true => Some(relpath),
                    false => None,
                })
                .collect();
            (phase, failed_files)
        })
        .collect();
    let arena = ocamlrep::Arena::new();
    let value = arena.add_root(&errors_in_phases);
    let mut w = std::io::Cursor::new(vec![]);
    ocamlrep_marshal::output_value(&mut w, value, ocamlrep_marshal::ExternFlags::empty())?;
    File::create(output_path)?.write_all(&w.into_inner())?;
    Ok(())
}

AFTER:
pub fn dump_error_files(output_path: &Path, errors: &Errors) -> Result<()> {
    let error_files: BTreeSet<&RelativePath> = errors.keys().collect();
    let arena = ocamlrep::Arena::new();
    let value = arena.add_root(&error_files);
    let mut w = std::io::Cursor::new(vec![]);
    ocamlrep_marshal::output_value(&mut w, value, ocamlrep_marshal::ExternFlags::empty())?;
    File::create(output_path)?.write_all(&w.into_inner())?;
    Ok(())
}
```
