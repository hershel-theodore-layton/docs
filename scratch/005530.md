Commit title: Use internal types for code actions, conform `mli`s
Commit body:
Summary:
noop change to use internal types for code actions rather than Lsp.CodeAction.

Meets these goals:
- use our own internal types for code actions rather than LSP types, which enforces consistency and reduces duplication. Now our standardized code actions can *only* be lazy, and it's harder to accidentally use the wrong code action kind.
- don't expose internal types outside of code actions service. Outside code actions service we use Lsp types, which keeps things consistent and easy to work with for users of code actions service

Note that the `code_action_types` library is a library to avoid a circular library dependency between `extract_method` and `code_actions_service`, which would prevent building

I also took this opportunity to conform the type for all refactors, another way to ensure consistency and avoid repetition
