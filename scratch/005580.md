Commit title: Add ".variadic" attribute to variadic parameters.
Commit body:
Summary:
In Hack a function can take variadic parameters:
```
function foo(int $a, int ...$b) {
```
This means that the function requires at least one parameter but can take any number of parameters.

This is represented in Textual by adding a ".variadic" attribute to the final parameter of the function definition:
```
define $root.foo($a: *HackInt, $b: .variadic *array) : *HackMixed {
```
Other changes:
- Instead of a tuple represent parameters as a structured type.
- Add attributes to the new Param type.
