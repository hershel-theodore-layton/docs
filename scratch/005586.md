Commit title: Add ptr to typedvalue test, dereference pointer types for matching printers
Commit body:
Summary:
Per LLDB [docs](https://lldb.llvm.org/use/variable.html#finding-formatters-101), LLDB will use the pretty printer for a pointee type when it encounters a pointer. Rather than return empty string, allow `SBValue.GetChildMemberWithName` and other functions used by e.g. `utils.get` to proceed, as they already handle dereferencing correctly. Thus we shouldn't be checking for pointer type at the top of the pretty printers.

Also add more tests to verify this is true (pointer to values pretty prints referenced value as expected).

Also adds in more formatting options, for easier changing/debugging.
