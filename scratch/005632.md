Commit title: use ptr-to-type-info in getFiberManager
Commit body:
Summary:
Use `std::type_info const*` v.s. `std::type_index` in the thread-local map keys for fast-path performance.

Under some implementations, equality-comparing `std::type_index` often does a string-compare on the type names, and hashing always hashes the type names. This is expensive in the thread-cached fast-path. Instead, we map all seen `std::type_index` to all matching `std::type_info const*`.

But the global map still needs to have unique entries for unique key types, which `std::type_index` delivers but which `std::type_info const*` may not in some cases. This requires a bit of complexity to track the list of `std::type_info const*` to which each `std::type_index` maps.
