Commit title: Improve parsing of interfaces
Commit body:
Summary:
* Parse a, possibly qualified, identifier instead of a type after `performs` because it should be an interaction name while in Thrift types normally correspond to **data** types. This improves diagnostics and disallows deprecated annotations for performs which has no effect anyway.

* Rename `parse_braced_function_list` to `parse_interface_body` because it parses performs in addition to functions.

* Disallow commas after "performs". This is a new construct so we don't need to complicate the grammar with vestigial syntax forms.
