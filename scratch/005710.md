Commit title: Introduce prefetching for changed files and faster unit lookups for autoloaded units
Commit body:
Summary:
This diff introduces three related optimizations to the unit cache:

 1) When a file is requested from the autoload map we can skip the `resolveVmInclude()` path resolution step as paths in the cache should already be fully resolved relative to the (also resolved) root of the repo.
 2) When native autoloading is enabled and watchman is being used to monitor the repo for changes we can use the `ensureSynced()` synchronization point to also mark any potentially modified units from the unit cache as dirty. After this point we should be able to safely assume any file requested from the unit cache by the autoloader has been modified iff the dirty bit is set.
 3) Under the presumption that it's highly likely units marked as dirty will be requested again in a future request we can use the unit prefetcher to reload them in the background.
