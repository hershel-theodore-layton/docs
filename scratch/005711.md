Commit title: Fix oxidization of mutually recursive types
Commit body:
Summary:
Currently if we have a mutually recursive type like the following in a module named `foo`

```
type t = A of b
and b = C of t | D of b
```

oxidize generates:

```
pub enum Foo {
  A(B)
}

pub enum B {
  C(Box<B>),
  D(Box<B>),
}
```

i.e. it confuses the name of the type `t` for the _current_ type rather than the name of the module when generating the definition of `B`

This diff fixes this so that we get

```
pub enum Foo {
  A(B)
}

pub enum B {
  C(Box<Foo>),
  D(Box<B>),
}
```
