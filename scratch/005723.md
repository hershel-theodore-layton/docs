Summary:
Turn
```
| Call of
      ('ex, 'en) expr
      * 'ex targ list
      * ((Ast_defs.param_kind) * ('ex, 'en) expr) list
      * ('ex, 'en) expr option
```
into
```
type ('ex, 'en) call_expr = {
  func: ('ex, 'en) expr;
  targs: 'ex targ list;
  args: ((Ast_defs.param_kind) * ('ex, 'en) expr) list;
  unpacked_arg: ('ex, 'en) expr option;
}

| Call of ('ex, 'en) call_expr
```
in favor of cleaner match patterns and easier field access
