Summary:
Human-readable snapshot tests for code actions.

The snapshots show:
- What code actions are available (lightbulb menu in VSCode). This is so options don't get out of hand and so we can test interaction of options. For example, we never show both "inline variable" and "extract variable

- LSP JSON corresponding to the `codeAction/resolve` response to exercise the json-generation code

Why this change:
- easier code review
- faster development, since it's possible to experiment with fiddly formatting without starting `hh`
- prevent regressions
