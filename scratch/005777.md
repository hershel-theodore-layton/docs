Summary:
For some APIs we provide 2 versions

1. Process single element
2. Process multiple elements

The first version can be easily re-implemented by the second version via creating a `folly::Range` with only one element. There shouldn't be performance impact since compiler can easily optimize and unroll the loop.

In C++20 this can be replaced with [`std::views::single`](https://en.cppreference.com/w/cpp/ranges/single_view)
