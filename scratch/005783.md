Commit body:
Summary:
Sandbox testing revealed some socket/permission bugs.

First, we need to use the configured watchman socket - fixed.

Next, open question: Should we prefetch when Autoload.DB.CanCreate is false?
HHVM currently only tries to fixup the permissions + group when CanCreate=true.

It turns out that the InitializeFacts www script just does chmod(0666) on the file
it downloaded. HHVM will open it, but then not try to set the configured perms or gid,
but it seems to work because 0666 is very permissive.

The purpose of CanCreate was to prevent an expensive full-sync,
which the prefetch avoids.
