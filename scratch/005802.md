Summary:
This is the first of many diffs implementing efficient marshaling of thrift-python <-> thrift-cpp2.

A `Extractor` converts a `thrift-python` `PyObject*` to the `thrift-cpp2` type. A `Constructor` does the opposite, instantiating `thrift-python` `PyObject*` from its `thrift-cpp2` version. The `native` trait maps from disambiguated `python` type (e.g., `struct String` denotes python `str`) to native c++ type (e.g., `std::string` for both `String` and `Bytes`).

**This diff**: This is probably the meatiest one because it includes both the `native` types trait and `Extractor`. `Extractor` includes:
(1) `typeCheck(PyObject*)` api that is basically the corresponding `_Check(PyObject*)` capi method. It should not fail; only return 0 or 1.
(2) `operator(PyObject*)` api to get cpp type from python object. This returns an `ExtractorResult` `folly::Expected` to allow deferred error handling. The entry-point caller can choose whether to `throw` (e.g., using `folly::python::handleError()`) or whether to return to cython and let cython raise the python error (using cython's `except` declaration).

A future diff will expose an "entry-point" that can be used as the public interface.
