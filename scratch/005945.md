Commit title: Change MemberOp accesses
Commit body:
Summary:
Infer is having trouble tracking member operations through the indirect base references we were doing.  So instead of breaking the member-ops into such fine detail we track them at a slightly higher level of runs of array accesses and runs of property accesses.

Where previously `$a[k1][k2]->b[k3][k4] = 42` would become:
```
base = &$a
base = hack_array_entry(base, k1);
base = hack_array_entry(base, k2);
base = hack_dim_field_get(base, "b")
base = hack_array_entry(base, k3);
base = hack_array_entry(base, k4);
*base = 42;
```
now becomes:
```
r0 = hack_array_get(&$a, k1, k2);
r1 = r0.?.b
r2 = hack_array_set(r1, k3, k4, 42)
```
