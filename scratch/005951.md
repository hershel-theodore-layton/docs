Commit title: trivial detector to remove duplicates during textual emit
Commit body:
Summary:
This is just a simple detector to look for and eliminate redundant loads as we emit textual.

- It only attempts to work within basic blocks - when we encounter a label we reset the cache.
- Loads of a simple variable reference are cached but more complex loads are not.
```
n0 = load &$x # cached
n0 = load $x.?.y # NOT cached
```
- Stores of a simple SID to a variable reference are cached but stores of a more complex value just clear the cache:
```
store &$x <- n0: *HackMixed # cached
store &$x <- 7: *HackMixed # NOT cached
```
- When it sees any reference to a "variable reference" it clears that variable:
```
n10 = foo(&$x) # clears the cache for "$x"
```
- It doesn't try to de-dup complex expressions like ?VN would (memory effects make that difficult).
