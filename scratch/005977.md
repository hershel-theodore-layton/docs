Summary:
This is a very easy refactor:

1. `get_defs` used to return a 5-tuple of lists. I think putting those list in a named record is more readable.
2. `get_def_names` also used to return a 5-tuple list, and this one was worse because all list-element types were `FileInfo.id`! Not very type safe. Interestingly `get_def_names` is only ever called to then be converted into a `FileInfo.t`, so lets just have `get_def_names` create a `FileInfo.t` immediately.

Motivation for this refactor: In the next diff, I will call `get_def_names` from the `hh_distc` Rust worker, so I'd like some type safety to make sure that FFI call is somewhat typesafe by design
