Commit title: Fix memory order of RDS binding
Commit body:
Summary:
std::memory_order_relaxed allowed reads of the RDS value to be moved before the
atomic operations of RDS binding and writes of init_val to be moved after the
bound handle was published.

Fix the former by using std::memory_order_acquire at the last step of the
already-bound-or-being-bound code path and the latter by using
std::memory_order_acq_rel on the newly-bound code path.

Hopefully fixes crashes on arm64. Should have no impact on x64, which conflates
atomic operations and full memory barriers.
