Commit title: Typechecking support for FBMock API
Commit body:
Summary:
Provides best effort typechecker support for FBMock mocking APIs.

The general pattern is
```
MOCK_BASE(C::class)->...->MOCK_API(...);
```
where
`MOCK_BASE` is one of `mock` or `strict_mock` and the `MOCK_API` and the supported checks are:
- `mockReturn('foo', _ : ty)` check that `C::foo` exists and that it is return type is a super type of `ty`.
- `mockReturn('foo', Map {'foo' => _ : ty. 'bar' => _ : ty', ...)` check that `C::foo`, `C::bar`, etc. exists and that the expression types to the right of `=>` are subtypes of the declared return types.
- `mockImplementation('foo', _ : fty)`  checks `C::foo` exists and its parameters and return is compatible with that of the function type `fty`.
- `mockReturnThis('foo')` checks that `C::foo` exists and that it is return type is a subtype of `this` type.
- `mockGetCalls('foo')` checks that `C::foo` exists.
- `mockThrow('foo', _)` checks that `C::foo` exists.
