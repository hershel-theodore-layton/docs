Summary:
HackIDE has a status-bar message "Hack" or "Hack: hh_server stopped" or similar. If you hover over it, you get a tooltip which breaks down whether HackIDE is functioning, and whether hh_server is functioning.

The VSCode behavior is that if you have a hack file open, then it only shows status for that one LSP instance. But if you have something else like Interactive Smartlog open, then it shows a status message for all LSP instances. This won't affect end-users who only have a single project open, but it will affect hack team developers who might (say) have one project open in a temp directory and another one open in www.

This diff tweaks the hover tooltip to show the name of the repo. I think that for end-users it will give them a "warm and fuzzy" confirmation that the hack tooltip is doing the right thing. I think for hack team developers it'll help them make sense of the multiple entries on the status bar. Also, once affanh and folks make www be able to be a subdirectory of fbsource, then I think he and others who have a checkout of fbsource will enjoy confirmation from hack about what it believes its root to be.
