Commit body:
Summary:
`invoke_by_field_id` converts a runtime field id to compile-time.

It has multiple use cases, e.g., if you have a runtime field id you read from database and you want to ensure this field in an object, since `op::ensure<Id>(obj)` requires compile-time id, you can't do that directly. with `invoke_by_field_id` you can do

```
FieldId runtimeId = fetch_from_database();
invoke_by_field_id<T>(runtimeId, [&](auto id) {
  // id's type is `std::integral_constant<FieldId, runtimeId>`
  op::ensure<decltype(id)>(obj);
}, [] { /* error handling */ });
```

In addition, it can do 2 things that cannot be done with `for_each_field_id`
1. You can return a value (e.g., rather than ensuring it, you can return whether it has value to the caller)
2. You don't need the actual object (e.g., you can use it to ensure a field in patch where you don't have the object).

This functionality can be used to visit union.
