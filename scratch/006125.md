Commit title: Ensure writeErr() is synchronously invoked on connection close.
Commit body:
Summary: When using QueuedWriteRequests, we invoke an application callback (writeSuccess()) after a write succeeds, but before we start the next write. This application callback can call closeNow() on the transport, which requires an immediate delivery of all pending error callbacks. Previously, the QueuedWriteRequest logic would attempt to write the next write after the application callback returned, and only after this failed (due to the closure of the connection), would we invoke writeErr() on that next write. At this point the application may have freed the write callback.
