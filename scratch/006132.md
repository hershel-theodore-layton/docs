Summary:
don't format on autosave because autosave can happen while you're still editing a line, and the formatting change can for example remove the trailing comma while you're trying to type the next arg, or dismiss autocomplete.

vscode disables format on autosave for the normal `editor.formatOnSave` setting[1], but hack implements its own formatting on save using `willSaveWaitUntil`.

[1] https://github.com/microsoft/vscode/blob/dc5fe338fe424018ac1d579ab019110cbc3220e6/src/vs/workbench/contrib/codeEditor/browser/saveParticipants.ts#L224-L226
