Summary:
SSLContextManager associates certificates with CN and SAN(s) information for SNI lookup.
This diffs aims to add support for serving ssl contexts specific to a domain or sub domains.
With this foo.example.com and bar.example.com can be served with different TLS configurations (e.g., ciphers, tls version) even if they use the same cert (e.g. CN=*.example.com).
