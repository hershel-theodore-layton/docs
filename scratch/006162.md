Summary:
This diff doesn't change behavior. It just adds some more integration tests to show baseline behavior for edge-cases of find-all-refs under ide_standalone. The baseline reveals the following bugs:
1. If there's no hh_server, clientLsp never sends any response to a references request. (I had to comment-out this one in test_lsp.py because it takes 120s to time out).
2. If there's a shellout underway and we receive $/cancelRequest, we should SIGTERM that shellout, but we just leave it running and deliver its answer
3. If clientLsp has one kickoff underway but then receives a request that would trigger a second kickoff, it cancels the first kickoff internally, but never sends an LSP response for it. The first request should get back some kind of ServerCancelled response.
