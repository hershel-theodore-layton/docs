Commit title: Use caller's context for dependencies when doing inline interp
Commit body:
Summary:
When recording dependencies, we use the current context. However, when
doing inline interp, the context is that of the callee, not the caller
(the original context). As a result, a dependency is recorded for the
callee. Since we're ultimately analyzing the caller, we want the
dependency recorded on the caller context. Add an optional field to
Context, giving an alternate context to use for dependencies. When
calling analyze_func_inline, set this optional field to the caller.
