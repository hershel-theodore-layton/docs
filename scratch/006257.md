Commit title: Hhx command for printing bytecode streams
Commit body:
Summary:
Adds an `hhx` to HHVM's set of LLDB commands. `hhx` prints a block of memory containing bytecode (similar to having run HHVM with `-vEval.DumpBytecode=1`).

This is based off of the GDB helper command we have, but nearly every line has been modified to work for LLDB. In addition, bugs and some missing features in the GDB version have been fixed/added here.
