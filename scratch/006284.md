Commit body:
Summary:
Implement maps. The internal representation of this is a tuple that lists key-value tuples: `tuple<tuple<PyObject* k, PyObject* v>, ...>`

That makes the implementation very similar to list. Just like with `list`, we rely on the `::key_type` and `::mapped_type` tags to recurse into the key and value types for nested maps with `cpp.type` overrides. This reduces compile complexity at the cost of only supporting `map` containers that respect STL convention, but afaik the main ones do (e.g., `folly::F14FastMap`).
