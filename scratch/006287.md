Commit title: Pass executor down
Commit body:
Summary:
CLF tries to re-use the executor provided by RequestCallback, but defaults to an internal thread pool.

By passing the python-event-loop executor (or the BlockingWaitExecutor for sync calls) down via the RequestCallback, we can avoid thread hops when executing the method body
