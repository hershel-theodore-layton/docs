Commit title: use map value_type in cpp2 constants
Commit body:
Summary:
`folly::sorted_vector_map` currently has `value_type = std::pair<key_type, mapped_type>` where the key is non-`const`.

Map constants are initialized with `std::initializer_list<std::pair<key_type const, mapped_type>>`, which does not work with `folly::sorted_vector_map`. Change the initialization to use `std::initializer_list<folly::sorted_vector_map<key_type, mapped_type>::value_type>`.

This requires that all map types used in thrift constants have member type or type alias `value_type`, but this is not likely to be a new requirement.
