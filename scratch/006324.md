Commit body:
Summary:
C++ allows to call static methods using instance method call syntax, that means we can pass a clock object to `custom_stop_watch` without breaking existing code and without extending its allocation size when using normal clocks with a static `now()` method.

This will help using `stop_watch` in tests with a fake clock.
