Summary:
Adds a wrapper type around top-level error patterns and error messages for possible migrations.

Since we are planning to use a JSON serialized version of custom errors as configuration in WWW, we would like a way to manage _breaking_ changes, i.e. any change other than  the addition of new constructors.

By adding a version wrapper, we can continue to support old versions which may be live in WWW. This makes migrations much easier since we can decouple them from hh release
