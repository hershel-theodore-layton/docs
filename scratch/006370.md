Commit body:
Summary:
I thought we were no running hotswap anywhere, but actually hhvmtrunk and v2g have it enabled.
Early admin server startup isn't compatible with hotswap because hotswap uses localhost:8088/stop to try and stop the old server *juuust* before starting the new page server (and after warmup). If we start the admin server before warmup, then we will actually be sending /stop to the new HHVM, which will kill itself.

Only start the admin server early if hotswap is disabled. This will apply to all the prod jobs.
