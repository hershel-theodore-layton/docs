Commit title: `yield break` should turn an async func to an AsyncGenerator
Commit body:
Summary:
Any `async` function that contains a yield turns into an AsyncGenerator:

```
async function foo(): AsyncIterator<int> {
  yield 5;
}
```

However, if you replace that with `yield break`, which should yield
an empty iteration:

```
async function foo(): AsyncIterator<int> {
  yield break;
}
```

it does not understand that it's a generator:

>Parsing[1002] async functions must have an Awaitable return type. [1]

To fix, look for `yield break` in addition to `yield expr` when scanning
the function for yields.
