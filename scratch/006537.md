The warning suggests that passing the result of std::move() as a const reference argument, as in this case, will not actually trigger a move operation. The move operation would typically transfer ownership or resources from one object to another, but when passed as a const reference, the object cannot be modified, and therefore no move will occur.

Instead of passing the cachedPsk object by value or as a const reference, you can pass it by an rvalue reference (&&). This allows the function to efficiently move the object without making unnecessary copies.
