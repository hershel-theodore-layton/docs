Commit title: Switch to ObserverContainer (6/x): Container to collect and merge PrewriteRequests
Commit body:
Summary:
This diff is part of a larger change to use `folly::ObserverContainer` (introduced in D27062840) with `AsyncSocket`.

This diff changes how `PrewriteRequest` are collected from observers and merged into a single `PrewriteRequest`:
- Previously, each observer could return a non-empty `PrewriteRequest` whenever `prewrite` was invoked if the observer wanted to make a `PrewriteRequest`. `PrewriteRequests` were merged together in `AsyncSocket`.
- However, in order for `invokeInterfaceMethod` to be fully supported for `prewrite` (including for cases where it is used to enable modularity), we need to switch to passing a `PrewriteRequestContainer` each time `prewrite` is invoked, and have observers add their requests to this container.
