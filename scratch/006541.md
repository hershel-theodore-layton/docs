Commit title: Inline method refactor: handle empty methods
Commit body:
Summary:
Before, we crashed on empty methods, because empty methods are represented in the AST with `Pos.none`s.

After this change, we handle such cases gracefully: we treat a block consisting of just a Pos.none as equivalent to no-block-at-all, and successfully generate a code action (see new test case).

Excerpt of the AST we're dealing with for `public function foo(): void {}`:

```
m_body = { fb_ast = [([Pos.none], Noop)] }
```
