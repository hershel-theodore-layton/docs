Summary:
I need to fork facts.rs to get unblocked.

We have a single crate that converts decls to facts: hack/src/facts.rs.
It is used by two consumers with diverging needs:

1. hack's IndexBuilder, used by legacy LocalSearchService and SQliteSearchService.
this consumer only uses a few details required for search/autocomplete indexing.
The format flow is: text -> decls -> Rust Facts ADT -> json -> OCaml Facts ADT.
We plan to delete this path entirely in H2.

2. hackc/hhvm's Facts API. This one is here to stay, but is intertwined with a bunch
of tech debt I'm trying to clean up. The flow is: text -> decls -> Rust Facts -> json ->
folly::dynamic -> C++ Facts -> folly::dynamic -> json.  Only a tiny fraction of the
json stuff matters, but I can't remove it as long as hack depends on it.

This diff copies hack/src/facts/facts.rs to hack/src/hackc/facts/facts.rs,
so I can independently clean up the JSON on the hhvm/hackc side, and most of the
unused data on the hack/IndexBuilder side.
