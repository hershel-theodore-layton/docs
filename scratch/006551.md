Commit title: co_bt: add lldb implementation
Commit body:
Summary:
This adds the lldb implementation to make the co_bt extension compatible with lldb.

A few notes:
- Upstream lldb currently does not support retrieving the `struct pthread` pointer on Linux x86_64. This is because the `fs_base` virtual base is not provided. See discussion: https://discourse.llvm.org/t/how-to-get-pthread-pointer-from-lldb/70542
- There is an internal patch that we will try to upstream that will `fs_base` register support on Linux x86_64. Until that is upstreamed and deployed, `co_bt` will not work on lldb for core dumps (and maybe not for optimized build modes as well).
