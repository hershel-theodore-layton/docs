Commit title: Fix readonly check on pessimized function types
Commit body:
Summary:
Function types can be dynamic through implicit pessimization, so we need to handle getting the fty from a Union[dynamic, fty] when one appears when checking readonly method calls.

Function types are automatically merged into one big function type during union simplification, so the only union that's really possible here should be when there's a single function type. We raise an invariant violation otherwise in case that invariant breaks later on.
