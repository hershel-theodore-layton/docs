Commit title: Let elaboration codegen produce errors

Summary:
Currently, hackc elaboration codegen passes are not allowed to produce errors. However, to implement typed local variables, we want to elaborate them away and at the same time restrict certain shadowing.

Here, we let some codegen elaboration passes raise errors, and add a new NamingError that we will use for typed locals. Because NamingErrors messaging has not yet been ported to rust from OCaml, we just special case the new naming error.
