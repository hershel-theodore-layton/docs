Summary:
The bug was introduced in D41841159 when attempting to refactor
```
      SMap.fold
        (fun a b acc ->
          if Option.is_some b || not (SMap.mem a remote_old_classes) then
            SMap.add a b acc
          else
            SMap.add a (SMap.find a remote_old_classes) acc)
        old_classes
        SMap.empty
```
It refactored it as
```
    SMap.union old_classes remote_old_classes ~combine:(fun _ decl _ ->
        Some decl)
```
but the proper refactor is
```
    SMap.union old_classes remote_old_classes ~combine:(fun _key decl1 decl2 ->
        Some (Option.first_some decl1 decl2))
```
(also because the keys of `remote_old_classes` are included in `old_classes`.
