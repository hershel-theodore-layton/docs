Commit title: MapPatch::Put bugfix
Commit body:
Summary:
If we already patched the map value by key, when we use `MapPatch::Put` to override the key later, we should remove whatever we have patched since `MapPatch::Put` should override the value.

However, currently don't not erase the value patch, thus patch will still be applied to overridden value, which is incorrect.

For example, if we have `map<string, string>`:

```
patch.patchByKey("a") += "2";
patch.put({{"a", "1"}});
std::map<std::string, std::string> m;
patch.apply(m);

assert(m["a"] == "12"); // before the fix
assert(m["a"] == "1"); // after
```
