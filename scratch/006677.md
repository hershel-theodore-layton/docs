Commit title: Avoid double parsing in the Thrift compiler
Commit body:
Summary:
Switch the Thrift compiler from a two-pass to a single-pass parsing by removing a special pass for processing includes. Instead, includes are now parsed normally as soon as they are first encountered.

This brings a number of benefits:

* Reduces parsing time up to 40%.

* Makes the logic in `ast_builder` much cleaner and more robust since we no longer need to check the parsing mode everywhere.

* Removes "Parser error during include pass" and "Parser error during types pass" errors that only clutter the output without adding any value.

* Will simplify error recovery from parse errors if we decide to implement it in the future.

* The include processing logic is now in one place, instead of being split between the AST builder and the program.

* `ast_builder` is now much more lightweight and somewhat simpler because it only has to deal with a single program.
