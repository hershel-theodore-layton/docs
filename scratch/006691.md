Commit title: Fix handling of undefined annotations
Commit body:
Summary:
Right now undefined external (referring to other Thrift files) annotations don't produce diagnostics, e.g.

```
    bad.Annotation
    struct S {}
```
compiles without an error.

Fix this by always resolving external annotations (we already do the same for internal ones) and add unit tests for both.

Ideally we should always resolve external symbols but this is currently impossible because of Thrift Patch. Once the latter is decoupled from the Thrift compiler we can do this, eliminating the whole class of problems.
