Commit title: Allow wildcards in lambda type hints
Commit body:
Summary: We'd like to support wildcards in hints on lambdas in the Hack typechecker e.g. writing `(vec<_> $x) ==> ...` or `($x) : vec<_> ==> ...`. Before we do that, there is some unfinished business in HackC dealing with the new `Hwildcard` type hint AST node. Essentially it should treat it as "any type" as far as enforcement goes, not really any different from `mixed`.
