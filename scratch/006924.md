Summary:
Currently we don't sync `thrift/lib/thrift` to xplat,

The reason is that for each modified files, dirsync only checkes the first dir groups and ignore other matched groups.

https://www.internalfb.com/code/fbsource/[883d6fb4741d5d74e2c5842ff801f507a91a6daf]/fbcode/eden/scm/edenscm/ext/dirsync.py?lines=198-206

e.g.,

```
foo1.bar1 = path1
foo1.bar2 = path2
foo1.bar3 = path3
foo2.bar4 = path1
foo2.bar5 = path4
```

(In this case keys are `foo1` and `foo2`)

path4 won't be synced since we already found the matched file group foo1.

However,

1. We can not just sync everything to `configerator/structs/thrift/lib/thrift` since there is a concern that if we sync build rules, people might use the incorrect build rule. We should only sync `.thrift` files.
2. We can not sync `thrift/lib/thrift` and them exclude buile rules, since we still want to sync build rules to xplat.

This diff changed to manually sync all existing .thrift files.
