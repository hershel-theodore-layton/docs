This is part of a larger effort to remove calls to the deprecated `X25519::setKeyPair()`.

Previously the `X25519` Key Exchange used a function that set both private and
public key. This is unneccary as only the private key is needed.
Removes sites where the setKeyPair() method was called. These sites are
replaced with setPrivateKey().
