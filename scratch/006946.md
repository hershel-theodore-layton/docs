Commit title: Improve handling of parameters and terse writes in the compiler
Commit body:
Summary:
* Fix the warning message for the case when a field qualifier is applied to a function parameter (previously `required` and `optional` were swapped and the location was incorrect). Move it to the parser where it belongs but was previously hard to emit because of double parsing and add tests.

* Improve handling of `thrift.TerseWrite` - only set the corresponding "qualifier" on compatible fields instead of always setting and then undoing. Remove the recommendation to remove qualifier because it is not necessarily the correct resolution.

* Remove an overspecified mutator test that doesn't correctly construct the AST. We shouldn't be constructing AST manually and test mutator in isolation at all because it is unrealistic and error-prone. We already have a test that relies on observable behavior and functional tests for diagnostics.

* Warn about legacy delimiters that are different from the ones specified in the IDL reference. These are already handled by Thrift formatter but having a warning is better since the formatter may not be always available.

* Fix delimiters in tests.
