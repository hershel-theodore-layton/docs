Commit title: support multifile AUTO332
Commit body:
Summary:
I want to write a load of autocomplete tests that involve glean. It will be too costly to run "hh_single_complete" on a load of different files, since each one will ahev to connect to glean (0.5-2s) and download namespaces (1-2s) before it can start.

I want to use Multifile instead.

hh_single_complete already supports multifile for the purpose of parsing/decling/indexing. However it doesn't support multifile for purpose of "AUTO332". This diff changes it to support it, for instance:
```
//// file1.php
<?hh
function t_alpha(): void { t_AUTO332

//// file2.php
<?hh
function t_beta(): void { t_bAUTO332
```

I made it display those filenames in the output as well. That way, the output will be easier to read.
```
//// file1.php
t_alpha
  INSERT t_alpha()
  (function(): void)
t_beta
  INSERT t_beta()
  (function(): void)
//// file2.php
t_beta
  INSERT t_beta()
  (function(): void)
```

However, for back-compat, I made it only displkay those filenames in the output if there were indeed multiple files with the AUTO332 token.
