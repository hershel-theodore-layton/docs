Summary:
Presence check for `current_const_` would disallow constant referencing for non-constant assignments (e.g. struct default field value assignment).

For the following Thrift example:

`included.thrift`:
```
struct Foo {
  1: i64 a = 2;
}

const Foo ExampleFoo = {"a": 2};
```

`program.thrift`:
```
include "included.thrift"

struct MyStruct {
  1: included.Foo MyFooField = included.ExampleFoo;
}
```

The generated code would actually initialize `ExampleFoo` constant value twice, rather than just referencing the original constant:
```
func NewMyStruct() *MyStruct {
    return (&MyStruct{}).
        SetMyFooFieldNonCompat(
              *included.NewFoo().
                  SetA(2),
        )
}

// vs

func NewMyStruct() *MyStruct {
    return (&MyStruct{}).
        SetMyFooFieldNonCompat(
              *included.ExampleFoo,
        )
}
```
