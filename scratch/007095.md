Commit title: Add an option to unwrap concurrent blocks when translating to textual
Commit body:
Summary:
Depending on whether the flag is set, `concurrent` blocks will be unwrapped as in
```
concurrent {
  $x = await foo();
  $y = await bar();
}
```

->

```
$x = await foo();
$y = await bar();
```

This transformation changes the semantics in a sense that:
1. things that would execute concurrently before are now sequential,
2. exceptions behave differently when are thrown from inside a concurrent block.

However, these nuances are not very relevant to infer analysis at the moment, but the resulting texual IR is much simpler to analyze.
