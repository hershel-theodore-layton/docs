Commit title: Unhack parsing of return types
Commit body:
Summary:
Improve the return type grammar by explicitly defining its structure instead of allowing any sequence of identifiers, types, streams and sinks to be later handled by additional checks. This brings a number of benefits:

1. It is easier to document and understand because the structure is expressed in the grammar rather than the grammar + a set of textual rules (which we don't even have right now).
2. The AST can be made correct by construction (to be done in a follow-up diff) without trying to represent things that only superficially look like types (streams and sinks) as types.

Add compiler tests for streams and sinks.
