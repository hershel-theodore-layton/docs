Commit title: Make sink and stream devoid of void
Commit body:
Summary:
As suggested and implemented in D47819598, disallow using `void` as an initial response type for sinks and streams in the grammar.

For example:

```
service S {
  void, stream<i32> f();
}
```

will no longer compile.

It has been undocumented until D47817589 and not particularly useful because the code is equivalent to

```
service S {
  stream<i32> f();
}
```
