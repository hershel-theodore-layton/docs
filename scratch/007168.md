Summary:
Hack supports two ways to rename:
* In the IDE, right-click > rename. This will generate a "deprecated" wrapper stub if appropriate.
* At the command-line, hh --refactor Method Foo::old_name Foo::new_name. This used to skip wrapper-generation, but due to the previous diffs in the stack it now supports it.

There's a third legacy internal-only way, hh --ide-refactor file.php:line:col:new_name, which used to power Nuclide in the olden days, but isn't needed and I want to delete it as part of my quest to delete legacy IDE code. This command generates wrapper stubs. Currently hack/test/integration/test_safe_rename_sound_dynamic.py uses this legacy way, I guess because it combined the easy testability of command-line with wrapper stubs.

Now that the earlier diffs have changed --refactor to generate stubs, there's no need for test_safe_rename_sound_dynamic to use --ide-refactor anymore. Therefore, this diff switches it over.

(then, at last, I'll be free to delete --ide-refactor!)
