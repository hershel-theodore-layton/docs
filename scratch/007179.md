Commit title: Add an API to get a specific context when no SNI presents
Commit body:
Summary:
Adds APIs to set and get a specific context for handling cases when a client does not send an SNI.
If a context for no SNI cases is set, it will be returned when there is no SNI.
If there is no context set for SNI case, it is up-to caller to decide what to do:
  - openssl servername callback ends up using the default cert
  - Fizz handshake fallback uses default cert.
