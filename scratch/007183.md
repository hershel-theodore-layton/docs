It is possible for the section and program headers in an ELF to not point to valid offsets. There is already a check for this in `ElfFile::iterateSectionHeaders()`:

https://www.internalfb.com/code/fbsource/[f71ad4d91873][history]/fbcode/folly/experimental/symbolizer/Elf-inl.h?lines=46-51

but previously this was not handled when calling `getSectionByIndex()`. This diff adds a check to `getSectionByIndex()` and returns `nullptr` in the invalid offset case.
