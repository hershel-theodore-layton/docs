Commit title: Hover types for signatures on method call should not be affected by like type
Commit body:
Summary:
Under Sound Dynamic, hover signature for method calls through like types would show as
```
// Defined in FooParent
public ~(function(): void)
```
First strip like type of receiver so that this shows as
```
// Defined in FooParent
public function bar(): void
```
Unfortunately, due to there being two "receiver IDs" (as computed by `Tast_env.get_receiver_ids`), the additional "default" hover still shows, so in fact we see
```
// Defined in FooParent
public function bar(): void
-------------
function bar(): void
```
Cleaning this up requires a lot more work.
