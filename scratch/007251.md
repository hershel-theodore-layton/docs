Summary:
My plan is that hh_single_complete should be the one-stop-shop test binary for all things glean.

Glean test hooks: these should figure out a query, figure out the angle for it, optionally dispatch it to glean via `glean2_query_declaration_location` (for the first two) or `glean2_query_filenames` (for the last), and print the results. The idea is that these should exercise glean fairly directly.
```
hh_single_complete --auto-complete-glean ...
hh_single_complete --search-glean ...
hh_single_complete --find-refs-glean ...
```

End-to-end tests: these should do
```
hh_single_complete --auto-complete ...
hh_single_complete --search ...
```

Therefore the name "hh_single_complete --glean-query" isn't right! We need to specify whether we're after an autocomplete glean query, a search glean query, or a find-refs glean query.

This diff is just a simple rename.
