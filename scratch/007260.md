Commit title: Allow choosing used registers for defs
Commit body:
Summary:
If a physical register used by an instruction becomes dead after the
instruction, it is legitimate to use it for defs.

In fact, we already do that all the time for registers that were originally
virtual, because the uses set comes from cached instruction data computed prior
to register allocation.

There's nothing special about usage of registers that were originally physical.
If they need to stay intact, something else must declare their use (usually the
instructions that exit the translation do that).

Eliminates some obscure register moves and fixes a bug triggered by the next
diff that passes ctx to func entry via a register, where the register allocator
would think it has enough registers, but then runs out of registers when
attempting to load the final item from ctx.
