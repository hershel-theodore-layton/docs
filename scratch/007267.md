Commit title: Cleanup addition of definition nodes
Commit body:
Summary:
Definition AST nodes are added to the program via `add_definition` which has a number of problems:

1. It looses type information and uses dynamic cast to recover it.
2. It sets ranges which is already done at call sites.
3. It unnecessarily tries to resolve non-typedef types.

Remove this function and add the nodes to the program and scope directly at the call sites.
