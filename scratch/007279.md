Summary:
Facebook :

When namespace is available, derive package from ns.
- Domain :
  - All the current packages that are present in the codebase, the domain prefix has one of the following identifiers with respective TLD
    - `facebook` - `com`
    - `meta` - `com`
    - `instagram` - `com`
    - `apache` - `org`
  - As per the [package -> namespace mapping defined in wiki](https://www.internalfb.com/intern/staticdocs/thrift/docs/idl/#package-declaration), the `domain_prefix` is reversed in namespace.
  - Based on this, the codemod treats the first occurrence of any of the above identifiers as the start of `domain_prefix` and assumes the `domain_prefix` - TLD mapping based on above pairs.
    - Reverse these identifiers to create domain.
  - Any identifier that is before this index is treated as part of domain.
  - If the guessed package doesn't have a domain but there is domain present in one of the namespaces, then use that domain instead of the default domain
  - If no domain is present in any of the namespaces, then use `meta.com` as default.

- Path
  -  All identifiers after the domain prefix are used as `path`
