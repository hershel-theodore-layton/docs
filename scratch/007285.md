Commit title: remove inline py3.iobuf usage
Commit body:
Summary:
Migrate all inline `(py3.iobuf)` to structured `cpp.Type` annotations. This has almost no usage outside thrift.

This should work even if `languages` exclude `cpp2` because the thrift-python and py3 compilers compute and examine the cpp type regardless. The downside is that it's not linguistically pure. However, `IOBuf` is inherently a low-level power-user cpp concept, so using `cpp.Type` isn't asking much.

The upside is reduced complexity in the thrift-python and thrift-py3 compilers.
