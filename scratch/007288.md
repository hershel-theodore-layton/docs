Summary:
This diff adds to hh_single_complete the third and (for now) final kind of glean query: find-refs
```
# show the angle query
hh_single_complete --find-refs-show-glean testfile.txt

# show and run the angle query
hh_single_complete --find-refs-glean testfile.txt --glean-reponame www.hack.light
```
For autocomplete and search there's a third option to query ServerAutoComplete / ServerSearch directly, i.e. use the full logic and take into account all local files as well as the ones in the glean database. This doesn't exist for find-refs. It doesn't exist because find-refs is not (and never will be) implemented by hh_single_complete -- find-refs is something that requires an O(repo) dependency graph.
```
# perform find-refs, backed by glean
# DOES NOT EXIST
hh_single_complete --find-refs testfile.txt --glean-reponame www.hack.light
```
