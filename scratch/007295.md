Commit title: Initialize ActRecs from func entries instead of prologues
Commit body:
Summary:
Do not write m_funcId, m_callOffAndFlags and m_thisUnsafe/m_clsUnsafe ActRec
fields at the caller. Instead, store them in registers and pass them to the
callee's func entry, similarly to what we already do when calling prologues.

This makes the call sequence a bit shorter and allows future improvements that
will come in the next diffs:

- associate callee id with saved rip and fetch it from there when requesting a
  translation; then store a constant value to m_funcId in the func entry
- associate call offset with saved rip, make debug_backtrace and exception
  processing logic fetch it from there; otherwise not needed at runtime fast
  paths, since jitted function calls don't return to interpreter
- clean up surprise flag checks on entry and allow ctx write to be sinked only
  to the surprise branch and through the other branch
- virtual method dispatch to func entries if signature is compatible
