Summary: The compilation paths that generate `Default::default` and that generate `const` values are very similar and largely duplicate each other, but have subtle differences. When one or the other is modifier, it is easy to accidentally violate the implicit invariants on how they should behave similarly to each other and to C++. It would make sense to have unit tests to secure these invariants
