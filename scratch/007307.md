Commit title: support exception fields
Commit body:
Summary:
Thrift exceptions are structs, but a thrift exception's `type->is_struct()` returns false. Add `type->is_exception()` to treat them like a struct for cpp-python marshal type purposes. This works because `StructTypeInfo` covers pure `Struct`, `Union`, and `GeneratedError`.

The only point of difference between a pure `Struct` and exception is that the latter needs to use a different `getThriftData` helper because `GeneratedError` does not inherit from `StructOrUnion`.
