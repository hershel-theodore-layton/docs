Commit title: start admin server before warmup
Commit body:
Summary:
Alright this is my second attempt at doing this. First time I caused S350075 because I deleted TakeoverFilename (old hotswap mechanism that sandcastle + OD still use).

Running the admin server during warmup would make it easier for us to debug stuff that happens during warmup because fbagent/dynologd will be able to get info.

Early admin server startup isn't compatible with hotswap because both flavors of hotswap rely on sending localhost:8088/stop -- i.e. using the admin server of the old HHVM to complete the hotswap. In these cases, if we try to start listening on the admin port before warmup, it will fail because the old HHVM is still listening!

So this diff will only start the admin server early if hotswap is disabled.
