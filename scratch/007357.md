Summary:
We have two separate formats for human-readabale find-refs output
```
# format used by `hh --find-refs`
File "global_use_of_const.php", line 9, characters 8-10: Foo::FOO

# format used by `hh_single_type_check --find-refs`
File "global_use_of_const.php", line 9, characters 8-10:
```
The first format includes the exact text of the SymbolOccurrence.

I think the second format has no reason to exist. This diff deletes it, and switches hh_single_type_check to the first format.
