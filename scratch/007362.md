Commit title: Remove language specific identifier when finding common package
Commit body:
Summary:
Facebook :
```
namespace cpp2 test_cpp.module.abc
namespace java.swift test_swift.module.abc
```
In above example, common package won't be located due to the presence of `test_cpp` and `test_swift`. In such cases, eliminating language-based identifiers will help in identifying the correct package.

The guessed package should be `meta.com/test/module/abc"

This diff adds a function to eliminate substrings related to respective namespace. Accounts for the use case where a language name is actually part of the namespace.  That is for c++ namespace only remove c++ related substrings. So namespace cpp2 "cpp.hack.annotation" => "hack.annotation"

Examples :

```
namespace cpp2 test_cpp.module.abc
namespace java org.apache.java_test.module.abc
```
Guessed package : apache.org/test/module/abc

```
namespace cpp2 test_cpp.module.abc
namespace java org.apache.test_java_cpp.module.abc
```
Guessed package would be "apache.org/test_cpp/module/abc"
java ns `test_java_cpp.module.abc` becomes `test_cpp.module.abc` which is same as cpp2 ns.
