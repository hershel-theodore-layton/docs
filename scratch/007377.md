Commit title: Add flag to print like-types in JSON
Commit body:
Summary: Exhaustivity checking in Hack misses many cases (see [this post](https://fb.workplace.com/groups/hackforhiphop/permalink/24988113060810640/)). Previous diffs (e.g. D47997070, D48113236) logged various bits of information on the exhaustivity checks, but like-types were logged incorrectly so that the introduction of [True Types](https://fb.workplace.com/groups/321528938206999/permalink/1906124289747448/) didn't break other tooling. This diff adds an optional flag (`false` by default) to print like-types when converting a type to JSON. The distribution of the logged cases will inform an appropriate path forward for Hack changes to the exhaustivity checking.
