Commit title: Decouple stream from return type
Commit body:
Summary:
We already decoupled sink/stream on the grammar level and in AST. Do the same in mustache templates by moving stream element type accessor from type to function where we already have most stream and sink related accessors.

Group sink and stream methods in `t_function` together while at it.

Replace `returns_stream()` with `stream()` that returns a pointer to stream instead of bool. This simplifies a bunch of call sites.

Replace `function:returns_streams?` with `function:returns_stream?`. There is no reason to have both.
