Commit title: Decouple sinks/streams from types in codegen
Commit body:
Summary:
Decouple sinks and streams from Thrift (data) types in codegen by separating return clause handling logic from the type handling logic. Sinks and streams can only appear on a function level and not on types and this is now reflected in the codegen making mustache templates for types much simpler.

Merge `type:sink?` and `function:returns_sink?` into a single `function:sink?`. Rename `function:returns_stream?` to `function:stream?` for consistency and replace most of the uses of `type:streamresponse?` with it. Remove unused `type:stream_or_sink?`.
