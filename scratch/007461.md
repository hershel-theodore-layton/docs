Summary:
This diff completes my project to re-organize FindRefs wire formats. My guiding principals:
1. Serialize and deserialize code should be adjacent, so we can see by inspection that they're doing the same thing
2. There should be documentation about what the wire format actually is, beyond just "read the implementation"
3. Our use-cases (human-readable, Hackast-readable, clientLsp-readable) have gotten sufficiently out of hand that we need to rein them in a bit.

**How to review this diff:**
1. Start with findRefsWireFormat.mli. This describes the new API which satisfies the principals
2. Observe that implementation from clientFindRefsPrint.ml and clientLsp has been moved inside findRefsWireFormat.ml
3. That's basically it. The rest is all plumbing.
