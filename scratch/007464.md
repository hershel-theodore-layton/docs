Commit title: Decouple stream from return type
Commit body:
Summary:
Decouple streams from Thrift (data) types in codegen by separating return clause handling logic from the type handling logic. Sinks and streams can only appear on a function level and not on types and this is now reflected in the codegen for streams making the logic clearer. This has already been done for sinks.

Remove `type:streamresponse?`, replacing remaining uses with `function:stream?`.

Remove `function:return_stream_elem_type` from the Python codegen because it duplicates `function:stream_elem_type`.

Remove references to `type:stream?` which doesn't exist.

Unhack `function:returns_by_name` in the Rust codegen by making it return an array of strings representing exceptions and the return type. Previously it was creating dummy AST nodes which didn't make any sense and only complicated the logic.
