Commit title: Skip lldb tests if in opt mode
Commit body:
Summary:
The lldb tests fail when running the binary built in opt-mode (e.g. https://www.internalfb.com/intern/test/844425028644631/). The issue that shows up is often that "AssertionError: 6 != 0 : error: Process must be launched." when running a `continue` command, for example. This happens because many of the function names we break on in the tests are unavailable in the optimized mode.

I can't figure out how to disable the tests from running in opt mode via the [TARGETS file](https://www.internalfb.com/code/fbsource/fbcode/hphp/tools/lldb/TARGETS) nor the [contbuild file](https://www.internalfb.com/code/fbsource/fbcode/contbuild/configs/hhvm_lldb), but this might work (works when running locally, see test plan).

Solution used below has been used by others previous (e.g. https://fb.workplace.com/groups/fbpython/posts/5596558313718823, D28552362).
