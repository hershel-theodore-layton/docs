Summary:
This diff completes decoupling of sinks and streams from Thrift (data) types in codegen. Sinks and streams can only appear on a function level and not on types and this is now reflected in the codegen, making the logic clearer.

In particular, `sink_has_first_response?`, `sink_first_response_type`, `sink_final_response_type`, `stream_has_first_response?` and `stream_first_response_type` have been moved to the function mstch node where all the other sink and stream related information is.

Remove unused `mstch_type::is_sink`.
