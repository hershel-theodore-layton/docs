Commit title: Improve handling of return types in type resolver
Commit body:
Summary:
* Add `type_resolver::get_return_type` that return the C++ return type for a Thrift function.
* Decouple sinks and streams from data types.
* Remove `type_resolver::gen_stream_resp_type` and `type_resolver::gen_sink_type` since they only called from one place and can't take anything but a standard resolver function.

Apart from clear separation between sinks/streams from data types this also reduces the amount of work we need to do per type. Previously every type was checked for being a sink or stream, now it only happens once per function and the common case handled first.

Additionally this will allow different handling of return types on client and server side which is currently buried in mustache templates.
