Commit title: reserve `size_of(size_t)` bytes at the front of buffer to encode buffer size in AllocatingParserStrategy
Commit body:
Summary:
Previously, we need to pass in
```
auto* allocAndSize =
        new std::pair<Allocator&, size_t>(allocator_, currentBufferSize_);
```
to `deallocate` method. This introduced un-necessary heap allocation. In order to get rid of this additional allocation, we can use the first `size_of(size_t)` bytes of the buffer to encode the length of the buffer. This is possible since once allocated, buffer length is never going to change until deallocated.

We also shift all pointer arithmetic by `size_of(size_t)` to compensate the fact that first `size_of(size_t)` bytes are already used for bookkeeping.
