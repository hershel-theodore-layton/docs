This diff adds support for a new command, `--ide-find-refs-by-symbol3`
```
hh --ide-find-refs-by-symbol <symbol|action>
hh --ide-find-refs-by-symbol3 <symbol|action> <streamfile> <hints>
```

The format of <streamfile> and <hints> is sort of implied by the code in findRefsWireFormat.ml. I left it opaque to callers.
