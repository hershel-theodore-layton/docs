  * [DONE] A new project should be created under thrift/conformance/go
  * [DONE] Data conformance server implements the ConformanceService defined in thrift/conformance/if/conformance.thrift:
```
struct RoundTripRequest {
  // The value to decode and renecode.
  1: any.Any value;
  // The protocol to use to return the value.
  // If not specified, `value.protocol` is used.
  2: optional protocol.ProtocolStruct targetProtocol;
}
struct RoundTripResponse {
  1: any.Any value;
}
// The conformance test service.
service ConformanceService {
  // Unpacks the given value, and repacks it with the given target protocol.
  RoundTripResponse roundTrip(1: RoundTripRequest request);
}
```
Conformance server will get a RoundTripRequest. This contains an Any struct and an optional target protocol. Server decodes the Any request and encodes it back to the RoundTripResponse using target protocol - if not empty - or using the protocol in Any.

# [DONE] Hash

We need to not only register types via thrift_uri names, but we also need to be able to handle when a hash is passed via Any.

https://github.com/facebook/fbthrift/blob/main/thrift/doc/features/universal-name.md#hashing

For this we can also reverse engineer the java implementation, but hopefully the documentation above is enough

In SerializedLazyAny.java, we see how the hash is used
```
if (any.getType() != null) {
  type = TypeRegistry.findByUri(any.getType());
}

if (any.getTypeHashPrefixSha2256() != null) {
  type = TypeRegistry.findByHashPrefix(any.getTypeHashPrefixSha2256());
}
```

https://www.internalfb.com/code/fbsource/xplat/thrift/lib/java/runtime/src/main/java/com/facebook/thrift/any/LazyAny.java

Here we can see the hash is calculated using the UniversalName

https://www.internalfb.com/code/fbsource/[5c87cc8d9c05c1fab83acce7649b7c49ef1caa7e]/xplat/thrift/lib/java/common/src/main/java/com/facebook/thrift/type/TypeRegistry.java?lines=157

The UniversalName is just the thrift_uri and a SHA 256 hash algorithm
