Summary:
Using serialization-based capi (on trunk)
```
| Benchmark               | reflection   | capi     |
|-------------------------|--------------|----------|
| Simple                  | 0.008 ms     | 0.006 ms |
| Simple with large list  | 1.066 ms     | 0.140 ms |
| Simple with long string | 4.673 ms     | 8.751 ms |
| Nested                  | 0.013 ms     | 0.006 ms |
| Nested with large list  | 12.321 ms    | 0.621 ms |
| Union                   | 0.002 ms     | 0.006 ms |
```
Generally better for containers and structs with many fields, but serialization adds an extra string copy that makes it worse for long string case.

With marshal-based capi (on separate branch), copies are reduced and performance is much better than reflection and better than serialization.
```
| Benchmark               | reflection   | capi     |
|-------------------------|--------------|----------|
| Simple                  | 0.008 ms     | 0.001 ms |
| Simple with large list  | 1.005 ms     | 0.061 ms |
| Simple with long string | 4.600 ms     | 1.733 ms |
| Nested                  | 0.012 ms     | 0.001 ms |
| Nested with large list  | 12.008 ms    | 0.157 ms |
| Union                   | 0.002 ms     | 0.001 ms |
```
