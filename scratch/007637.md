Summary:
Internal :

- Bug 1: Namespace after includes
  - Ideally `include` statements should be at the top. Based on this assumption, namespace offset was always searched after the `include` statements.
  - But some files provide namespace before includes. For those files, namespace offset is not found and new namespace is added separately from the group.
  - Fix : Look for namespace offset starting from top of the file.

- Bug 2: Php namespace
  - When hack ns is missing, codemod adds empty hack ns along with package statement to prevent hack errors from change in ns.
  - But if php namespace is provided then this is not required because php namespace will override both empty hack ns and ns from package.
  - Fix : Only add empty hack ns if both php and hack ns are missing
