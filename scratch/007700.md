Commit title: python: option to fully materialize during deserialization
Commit body:
Summary:
Introduce a `fully_materialize` option to `thrift.python.serializer.deserialize`, which populate all caches after deserializing.
It essentially shift the cost of cache population from field access time to deserialize time, as we can see in the test plan.

In the 1000*10 nested map benchmark:
First access time is reduced ~100x, now on par with py-deprecated.
Deserialization ~10x slower than original thrift-python w/o materialization, but still 6x faster than py-deprecated.
