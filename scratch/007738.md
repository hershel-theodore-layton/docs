Commit title: Cleanup t_function API
Commit body:
Summary:
We have three methods to get the return type of a function. Unify their signatures by replacing `t_type_ref` with `const t_type*` so that the two extra methods can be codemodded away. None of the consumers need `t_type_ref` and there are just a few calls to this overload compared to hundreds of calls to `t_type` overloads.

Remove `t_function_list` alias which brings no value, just obscures the real type and makes forward declaration harder.
