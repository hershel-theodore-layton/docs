Commit title: (rocket framing) fix potential double free in AllocatingParserStrategy
Commit body:
Summary:
in `AllocatingParserStrategy`, if `owner_.handleFrame` throws exception (for example, when frame is bogus), `buffer_` object will be deallocated twice. Once when destructor of `IOBuf` is called and once when destructor of `AllocatingParserStrategy` is called.

In order to fix this, we need to introduce a staging buffer to be hand over to the owner and not let `AllocatingParserStrategy` go into inconsistent state even if `owner_.handleFrame` throws exception
