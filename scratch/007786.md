Commit body:
Summary:
Adds `AsyncSocket::getConnectionEstablishTime`, which returns the time when the connection was established, when available.

-  If `connect()` was called and succeeded, this is the same as `getConnectEndTime()`.
-  If `AsyncSocket` was initialized with a file descriptor (e.g., by an acceptor), the connection establishment time passed to the constructor. If no time was passed, returned value will be `folly::none`.

Clarified some of the code around connection timestamps in parallel.
