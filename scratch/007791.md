Summary:
The zstd test was broken or at least I couldn't get it to pass

I found that there is now a pure go implementation of zstd available: https://pkg.go.dev/github.com/klauspost/compress/zstd
which is already used by vulscan: https://www.internalfb.com/code/fbsource/[469a99d768a0361b1a139d046d513ccc176b9ca6]/fbcode/security/vulnscan/tailer/msg/TARGETS

I copied the test from `libfb/go/thrift` without any changes.
I also copied the implementations of the functions from `libfb/go/thrift`, which only needed slight modification.

This means we can get rid of `libfb/go/compress/zstd` and `libfb/go/thrift`, for which this is the only user.
It looks like this was extremely complicated to setup initially D13962195 and also hard to maintain D47597782.
So on the one hand I am very sorry to get rid of this work that others have done, but hopefully this large simplification is considered a win.
