## Adding go.mod

Go code doesn't build in the open source thrift code base

If I Clone github.com/facebook/fbthrift/ to my mac
And then Go to github.com/facebook/fbthrift/thrift/lib/go/thrift
And then run:
```
$ go test -v ./...
```
I get the following error:
```
go: cannot find main module, but found .git/config in /Users/walterschulze/github/src/github.com/facebook/fbthrift
        to create a module there, run:
        cd ../../../.. && go mod init
```
This happens because new versions of Go has started to require a go.mod file

`go test -v ./....` used to work before as we have seen in the circleci file:
https://github.com/facebook/fbthrift/blob/main/thrift/lib/go/thrift/.circleci/config.yml

So adding the go.mod is just a fix to make the tests run again

## Adding dependency

In a previous diff we have also added a dependency on github.com/klauspost/compress for zstd D48562192
So we add this to the go.mod file as a requirement.

The version of compress that we add to go.mod matches the version we have vendored to third-party-go
