Commit title: Simplify upper bound representation
Commit body:
Summary:
Do not try to reconstruct higher level concepts not tracked by HHVM, such as
upper bounds on a type variable defined on a function or class. This
methodology was fragile and not compatible with resolution certain aspects
such as nullability at parse time, or future needs that require multiple type
constraints on the same type info.

Instead, include all upper bounds explicitly as part of the type info.
