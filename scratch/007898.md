Commit title: Remove "new style" classes from Thrift generation
Commit body:
Summary:
"new style" Python classes look like:
```
class X(object):
```
since Python 3 _all_ classes are new-style by default so we can write
```
class X:
```
Python2 reached EOL on January 1, 2020 and is no longer available for use anywhere internally.

Let's eliminate `(object)` from our codebase - it's just noise at this point (there are ~89k uses, most of which are generated) and promulgates an unnecessary coding practice.
