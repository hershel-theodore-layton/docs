Commit title: Decouple streams from return types
Commit body:
Summary:
Complete decoupling streams from return types in the AST, bringing it closer to the actual grammar. This has already been done for sinks.

Add the `has_return_type` accessor for checking if a function has an actual return type in the source code. This allows distinguishing

```
stream<i32> f();
```
and
```
void, stream<i32> f();
```

Another option is to return null from `return_type` in the first case but it's impractical since most consumers expect non-null and only few actually care about the distinction.
