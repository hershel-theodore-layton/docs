Commit title: Cleanup the throws API and usage
Commit body:
Summary:
Remove the deprecated `get_xceptions()` function, replacing its uses with `exceptions()`.

Replace the leaky and virtually unused `t_throws::or_empty` function with the `get_elems` function that takes a pointer to `t_throws` and returns its elements or an empty view if the pointer is null. Use the new function together with the range for loop to simplify a bunch of code in generators.

Before:

```
const t_struct* xs = tfunction->get_xceptions();
const vector<t_field*>& fields = xs->get_members();
vector<t_field*>::const_iterator f_iter;

for (f_iter = fields.begin(); f_iter != fields.end(); ++f_iter) {
  // ...
}
```

After:

```
for (const auto& x : get_elems(tfunction->exceptions())) {
  // ...
}
```

Add a missing default ctor for `node_list_view::iterator` to make `get_elems` actually work.
