Commit title: Treat the None module as the default module when checking packages
Commit body:
Summary:
D48406136 makes it so that HHVM treats files with no module as the "default" module.

The only typechecker impact of this change is that when checking packages, we should treat modules as being part of the "default" module when globbing.

Regular module code isn't affected, so no reason to add a "default" string to every single TAST for now.
