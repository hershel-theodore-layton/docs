This diff is simply an integration test for streaming find-refs. Here's how it works:

1. didOpen references.php
2. textDocument/references on a symbol
3. There is one reference in references.php itself, so clientIdeDaemon reports this reference, and clientLsp sticks it on the front of the Lwt_stream.t through which partial results are computed, and clientLsp therefore sends it as a $/progress
