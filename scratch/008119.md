Commit title: Support --config in automated Hack decl tests
Commit body:
Summary: Config files are a uniform way to add both command line and .hhconfig options for parsing and type checking Hack. Currently they are only supported for `hh_single_type_check`, but the automated tests also run `hh_single_decl` and `compare_folded_decls_file` over all of the typecheck test cases. This means tests which included `--config <option>=<value>` fail with an `unknown option` (see D48866898). This diff ignores `--config` because a previous version which copied from `hh_single_type_check.ml` introduced a 5% performance regression.
