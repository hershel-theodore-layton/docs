Commit title: Add Support for Interface/Trait Requirements in Case Types
Commit body:
Summary:
Similar to D48814039 we can utilize the requirements on an interface or trait to derive a more useful data type. For:

```
interface I {
  require extends A;
}

class B extends A implements I {}
```
We can replace the data type `InstanceOf(I, Interface)` with `InstanceOf(A, Class)`.
