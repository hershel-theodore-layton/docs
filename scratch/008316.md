Summary:
- NativeData worked different then NativePropHandler for example.
- For NativeData you specify a name and then you register the same name in C++.
  - My guess is that it was done so that you could easily share the same NativeData for many classes. But that is not the case. There is only one NativeData class that is shared between 2 PHP classes. So it doesn't really save anything
