Commit title: Improve parsing of interfaces
Commit body:
Summary:
Make parsing of interfaces consistent with the documented grammar (https://www.internalfb.com/intern/staticdocs/thrift/docs/idl/):

* Make the terminating semicolon parsed as a part of a function (affects source ranges).
* Warn about nonstandard delimiters after a function. These are already replaced with semicolons by an autoformatter but the latter is not always available so warning is still useful.
* Disallow `performs` in an interaction removing the need to validate it later and improving diagnostic a bit. This is disallowed on the grammar level in the doc so it makes more sense to diagnose in the parser and it is slightly easier.
