Summary:
Developers sometimes use `preg_match($regex, '') !== false` to check if a regex is valid. However, when the regex is invalid, the runtime raises warnings for the bad regex. This diff introduces a new builtin function `preg_get_error_message_if_invalid` that does this check and returns an error message instead of raising warnings.
