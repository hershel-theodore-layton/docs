Commit title: Complete decoupling of sinks from data types
Commit body:
Summary:
`t_sink` incorrectly inherits from `t_type` although a sink is neither a Thrift (data) type nor even a named entity. Inherit it from `t_node` instead.

Apart from closer representing the grammar, this also makes it impossible to do some meaningless operations like manipulate structured annotations on a sink. It also simplifies AST consumer code which no longer needs to handle sink "type" case which couldn't happen anyway.
