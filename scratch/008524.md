Summary:
In op::equal, we will first check whether two fields have the same address and short-circuiting the evaluation for such case.

The problem is that if thrift field is NAN, op::equal should always return false (even if we are comparing a thrift value to itself), since NAN are always unequal (Based on IEEE754 Spec).

This diff fixed this and added unit-test.
