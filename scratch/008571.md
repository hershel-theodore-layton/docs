Commit title: Ensure all int literals are of the same format
Commit body:
Summary:
Exhaustivity checking in Hack misses many cases (see [this post](https://fb.workplace.com/groups/hackforhiphop/permalink/24988113060810640/) or D47890092). This diff continues the implementation of a new strict switch gated behind an option.

It does so by adding a new Tast check - gated behind the same typechecker option - `Strict_switch_int_literal_check` which, will check if all integer literals are of the same format (i.e. hex, bin, oct, dec), using the first integer literal as the "expected" format. To report any instances of mismatched formats, the diff also adds a new error message constructor to point users to where in the source position the expectation was set. As per the comments on this diff, it does not introduce a new error code, instead using the "wrong class" error code.
