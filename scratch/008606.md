Commit title: Expose Result struct
Commit body:
Summary:
Sadly, the legacy generator exposed (exported) "...Result" structs - which are internal implementation details.
Of course, people found ways to abuse this struct in unittests.

In order to have backwards/forwards compatibility, we need to expose this struct in the new generator as well.

In the future, we should revisit this and try to have these structs unexported.

Additionally, rename default retval name from "value" to "success".
