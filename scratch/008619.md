Commit title: Expand type variable in TAST before printing (with `hh --single`)
Commit body:
Summary:
`hh --single <file.php> --config dump_tast_hashes=true` allows to dump the tast for file.php
So far, the type variables in that TAST were not expanded. This diff changes that.

The expansion happens in hh_server before marshalling the TAST and sending it back to hh_client. Since it is a costly operation, we pass a flag `return_expanded_tast` from hh_client to hh_server and only expand and return the tast when true.
This should also eliminate possible runtime errors when marshalling functional values in our current prod scenarios using `--single`, since none of these also use `--config dump_tast_hashes=true`.
