Commit title: move PatchOp out of patch.thrift
Commit body:
Summary:
PatchOp contains the mapping patch operation with field id. This is only needed in dynamic patch since in static patch we have full schema which already includes the mapping between operation and field id.

Before this diff, the dependency is "dynamic patch library" --> "patch.thrift" --> "static patch library", which makes dynamic patch unnecessarily depends on static patch.

The long-term is that we want to change the dependency to "patch.thrift" --> "static patch library" --> "dynamic patch library" --> "patch_op.thrift" so that we can reuse dynamic patch library to implement some functionalities in static patch library.
