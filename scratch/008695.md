Summary:
Per Thrift spec: https://www.internalfb.com/intern/staticdocs/thrift/docs/features/serialization/#qualifiers

> Unqualified field is always serialized. If data is not set, it will be serialized to default value.

i.e. `nil` initialized containers (list/map/set/binary) should serialize to an empty container.
