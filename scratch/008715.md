Summary:
Deprecated annotation lookup is spectacularly overengineered for an API that just takes a few strings. It also does excessive string construction. Simplify it and reduce the public API surface by replacing `alias_span` with `std::vector<std::string_view>` and enabling heterogeneous map lookups which gives the same or fewer allocations but without all the custom "span" cruft.

Rename `annotation_value` to `deprecated_annotation_value` to more clearly distinguish it from the new (structured) annotations.
