Commit title: Fix double free in EventHandlerRuntime
Commit body:
Summary:
`folly::rcu_retire` uses `std::default_delete` which means the current behavior is `delete <MethodNameStorageImpl*>` followed by `delete[] <std::byte*>` from the custom deleter.

This diff makes `std::default_delete` do the right thing which means that we can stop the shenanigans with keeping the custom deleter inline. Since this code was originally written, `AllocationColocator<T>::Deleter` has become stateless which works quite nicely with `std::default_delete` now.

With C++20 concepts, we would be able to add a base class like `WithInlineDeleter` and provide the specialization of `std::default_delete` needed within the library itself.
