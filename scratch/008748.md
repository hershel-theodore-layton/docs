Commit title: Do not constant fold T::class when T is a reified generic
Commit body:
Summary:
We don't fold things like `static::class` in classes or `self/parent::class` in traits, but we do incorrectly fold `T::class` because the constant folder didn't know which reified generics are in scope. The stack below this diff makes that information available, and this change starts using it. Now, `ClassExpr::class_id_to_class_expr` should appropriately return the `ClassExpr::Reified` variant instead of relying on client code to detect special `ClassExpr::Id`s and replace them ad-hoc.

Eliminates a handful of wildcard patterns + unnecessary constructs
