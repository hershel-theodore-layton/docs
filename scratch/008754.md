Commit title: Fix type truncation bug for add_local_type_hint
Commit body:
Summary:
Stop truncating types when applying the "add local type hint" code action.

I admit the monstrously large type hints look silly, but:
- dumping an error message about fuel into source code looks silly too, especially when the advice in the error message doesn't work for code actions
- (internals) with this change there is *exactly one* way of printing types in all of code actions, which reduces maintenance surface area
- There might be use cases for large local type hints
- It's easy for users to cut-and-paste the hint to an alias if they want to (ideally we would automate this part, but I don't have bandwidth to invest much in local type hint code actions now)

Potential future improvements:
-  auto-format when adding local type hints. See "extract into method" for a codemod that does formatting work
- when the type hint is beyond a certain string length, automatically create an alias
