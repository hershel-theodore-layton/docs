Commit title: store Blake3 digests as binary instead of hex
Commit body:
Summary:
Each digest represented as hex digits takes 64 bytes. Store 32 binary bytes
intstead. This cuts the memory footprint down by almost half due to size-class
rounding (64+1 => 80;  32+1 => 48).

To distinguish 32-byte digests from 32-byte paths in toString(),
use m_extra = ~0 as a sentinel value for RefIds containing a digest.
