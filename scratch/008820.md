Commit title: Do not try to tear down frames if locals were already decrefd
Commit body:
Summary:
Exit hooks may throw after locals were already freed. Previously, we relied on
these hooks to call ActRec::localsDecRefd(), so that if these hooks throw, the
unwinder would not try to decref locals again.

However, future optimizations may sink writes to ActRec::m_callOffAndFlags to
the catch block in inlined functions. That would overwrite the localsDecRefd,
causing the unwinder to try to decref locals again.

Let's address this by running unwinder in the Teardown::None mode.
