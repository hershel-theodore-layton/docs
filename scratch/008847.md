Summary:
Instead of adding more runtime options, just add a simple clone of `var_dump` that:
- unconditionally i.e. without `Eval.ClassAsStringVarDump=false` prints `class(C)` for class pointers
- prints `lazyclass(C)` instead of `class(C)` for KindOfLazyClass

This will be useful for seeing values change between lazy classes and class pointers when writing tests for the migration functions and enforcement.
