Commit title: Decouple interactions from return types
Commit body:
Summary:
Decouple interactions from actual return types more by moving them out of the return type vector. As a result the latter no longer needs to be a vector which will be addressed separately.

Remove `returned_interaction_pos_` and `set_returned_interaction_pos` and rename `returned_interaction` to just `interaction` to avoid any confusion with actual return types and since we don't use "returned_" in other similar constructs that appear in a function signature (sinks and streams).

Remove a bunch of interaction handling logic from mutator since it is no longer needed. This brings `t_function` closer to being correct by construction and not requiring any postprocessing.
