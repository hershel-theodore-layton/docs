Commit title: handle -inf
Commit body:
Summary:
HackC handles `-INF` a little differently than `INF`. The constant folder sees `-INF` and turns it into a float constant whereas `INF` is left alone and turns into a `CnsE "INF"` bytecode.  This is probably incorrect behavior but the textual backend should still handle "weird" floats reasonably.

This diff adds a new class of builtins for constants and then uses that to represent INF, -INF, NAN when those are expressed as direct floating point numbers.

Added a unit test to test floating point conversions along with some of their limits.
