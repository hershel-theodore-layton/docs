Summary:
The previous deprecation warning was no effective because people usually use builders like this:
`obj := NewFooBuilder().Bar(1234).Baz(5678).Emit()`
^ None of the methods in the above example were marked deprecated.

Only something like this would trigger a deprecation warning:
`&FooBuilder{}`

Now the warning will properly display for all builder methods.
