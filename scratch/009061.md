Summary:
Basic `nameof` implementation. `nameof <classid>` aims to mirror the behavior of `(string)<classid>::class`, emitting bytecode to resolve `static`, etc. as needed. The implementation for special class resolution is shared following work from D49263945 stack.

Uses the `ClassName` bytecode instead of `LazyClassFromClass; CastString` for the `SpecialClsRef` case, and skips the `ClassGetC; LazyClassFromClass` for reified generics.
