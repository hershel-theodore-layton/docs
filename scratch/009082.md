Commit title: Fix exceptions for C++ clients
Commit body:
Summary:
We were writing blank "Success" value on the wire in case of an exception.
This was confusing C++ clients into thinking that there was no exception thrown and a legit response was returned instead. Even though exception was present in the response.

To be compatible with C++ Thrift implementation - we will now mark "Success" response as optional and nothing will be written to the wire when an exception is encountered/returned.

This is also consistent with the legacy generator (which uses optional qualifier for "Success" return value).
