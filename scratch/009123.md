Commit title: Fix RocketServerConnection::dropConnection
Commit body:
Summary:
ManagedConnection::dropConnection() should:
```
/**
 * Forcibly drop a connection.
 *
 * If a request is in progress, this should cause the connection to be closed with a reset.
 */
```

However, that wasn't the case for RocketServerConnection's dropConnection() implementation, which would wait for all outstanding writes to complete before closing the socket. This subtle change makes RocketServerConnection::dropConnection() behave as intended.
