Commit title: Support implicit conversion of folly::Unexpected<E> to folly::Expected<V, E1> if E1 is implicitly convertible from E
Commit body:
Summary:
In this diff I am trying to allow converting `folly::Unexpected<E>` to `folly::Expected<V, E1>` if `E` is implicitly convertible to `E1`. In practice it seems like it is partially supported - `folly::Unexpected` already supports conversion between error types
  template <class Other FOLLY_REQUIRES_TRAILING(
      std::is_constructible<Error, Other&&>::value)>
  constexpr /* implicit */ Unexpected(Unexpected<Other> that)
      : error_(std::move(that.error())) {}

However these conversions don't work when returning from a function or with static asserts (see attached tests).
