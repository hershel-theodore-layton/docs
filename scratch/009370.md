Commit title: Decouple return types from sinks
Commit body:
Summary:
Complete decoupling of return types (initial response types) from sinks. Syntactically those are separate (https://github.com/facebook/fbthrift/blob/main/thrift/doc/idl/index.md#services) and AST should properly reflect it. This also removes duplication since return types were previously stored in both functions and sinks, fixes an old TODO and simplifies `t_function` constructor. And finally it ensures that related throws clauses and types belong to the same AST nodes.

We have already done the same for streams in D50128179.
