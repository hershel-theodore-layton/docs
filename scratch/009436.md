Commit title: renaming/wrapping
Commit body:
Summary:
All the glean indexer modules have a name of the form `symbol_foo`.
The `symbol` isn't very meaningful. Rather than rename it, this diff removes the `symbol_` prefix altogether. This simplifies the code a bit by avoiding the need for module aliases `module Foo = Symbol_foo`.

buck/ocaml provides a namespace mechanism for libs by generating the long name for us (from the library name) so there's no risk of clashing.  See this [post](https://fb.workplace.com/groups/403065016408786/permalink/24500062569615694/).

Next step:  I'd like to rename `Write_symbol_info` lib to `Glean` or `Indexer`. Unfortunately, that's also how all the indexer options are called so it's a bit more work.
