Commit title: `std::shared_lock` specialization for `folly::SharedMutex`
Commit body:
Summary:
`folly::SharedMutex.unlock_shared(Token&)` version should be faster
than `folly::SharedMutex.unlock_shared()`. `folly::Synchronized` uses
`folly::SharedMutex` under the hood, but do not leverage tokenful version.

We can specialize `std::shared_lock` for `folly::SharedMutex` to store token
inside `std::shared_lock` to fix it and make `folly::Synchronized` (which is
used a lot!) a bit faster.
