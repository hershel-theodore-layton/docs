Commit title: Update comment on ReadMostlyAtomicObserver to reflect dependency support
Commit body:
Summary:
When `ReadMostlyAtomicObserver` was added in {D27381490} `get` didn't register any dependency:
```
template <typename T>
T ReadMostlyAtomicObserver<T>::get() const {
  return cachedValue_.load(std::memory_order_relaxed);
}
```

Later this limitation was lifted in D27800735 `[folly][observer] Make sure all observer adaptors correctly capture dependencies` when called from `makeObserver`

```
template <typename T>
T ReadMostlyAtomicObserver<T>::get() const {
  if (UNLIKELY(observer_detail::ObserverManager::inManagerThread())) {
    return **observer_;
  }
  return cachedValue_.load(std::memory_order_relaxed);
}
```
