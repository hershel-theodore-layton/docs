Commit title: Make Eval.EnableCodeCoverage=1 and Eval.EnablePerFileCoverage=1 compatible
Commit body:
Summary:
`Eval.EnableCodeCoverage` and `Eval.EnablePerFileCoverage=1` breaks `fb_enable_code_coverage()`/`fb_disable_code_coverage()` because some code paths change to the implementation of per-file coverage if `EnablePerFilecoverage` is set.

This diff moves the decision of whether normal/full coverage or per-file coverage based on request parameters, allowing for an hhvm started with both flags to server both requests that use `fb_enable_code_coverage()`/`fb_disable_code_coverage()` and requests that use `HH\enable_per_file_coverage()`/`HH\get_all_coverage_data()`.

There are also checks to fail explicitly if both coverage modes are used in the same request.
