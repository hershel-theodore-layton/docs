Summary:
## Changes

Protocol implementation change:
- use file uris (`file:/// ......`) instead of paths in edits for code actions, thus following the LSP spec for `textDocument/codeAction` and `codeAction/resolve`

User-facing behavior changes:
- VSCode users are not expected to see a difference now, since VSCode is currently permissive enough to accept either URIs or paths. But this change shields us from future breakages, as we no longer rely on undefined behavior
- Hack code actions are expected to work for more non-VSCode clients (see meta-only section)

Internals:
- In this diff, we use types to avoid confusion between file paths (`Relative_path.t`) and uris (`DocumentUri.t`).
