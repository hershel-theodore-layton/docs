Commit title: ProviderBackendFfi trait
Commit body:
Summary:
Add a trait `ProviderBackendFfi` abstracting over the entire Rust_provider_backend FFI surface, and change `rust_provider_backend_ffi::Backend` to use `ProviderBackendFfi`.

Previously, with the `rust_provider_backend_api::RustProviderBackend` trait, we allowed users to implement only the minimum functionality necessary to typecheck a file. The rest of the API surface was implemented only for hh_server's backend using a downcast. This worked great for hh_distc, but if we want use cases like Zoncolan to be able to do the same things hh_server does (without directly using hh_server's provider backend implementation), we need an abstraction that covers the entire FFI surface.
