Commit title: Move initialization of return types to a dedicated pass
Commit body:
Summary:
Instead of initializing return types as part of flatten classes, move
it to a dedicated pass run after building subclass lists. This doesn't
change any behavior now, but by doing it later (and separately), we
can make building ClassGraphs easier. Moreover, some of the data
needed for building ClassGraphs will only be available after building
subclass lists.

To avoid regressing performance by doing another pass, move the "fixup
units" and "aggregate name-only func family" passes and run them in
parallel with init types.
