Commit title: Relax restriction on CheckType for TCls types
Commit body:
Summary:
When running in repo authoritative mode under retranslate-all, the following code
```
$y = __hhvm_intrinsics\create_class_pointer("C");
$y::f();
```
emits a sequence
```
ReorderCheckTypes:vvvvvvvvvvvvvvvvvvvvv
  - reordering these 2 instructions:
 - (44) t15:Cls = CheckType<Cls> t14:InitCell -> B17<Unlikely>
  - (52) t17:Cls=C = CheckType<Cls=C> t15:Cls -> B19<Unlikely>
ReorderCheckTypes:^^^^^^^^^^^^^^^^^^^^^
```
that the optimizer folds into
```
t17:Cls=C = CheckType<Cls=C> t14:InitCell -> B18<Unlikely>
```
(see code pointer)
https://www.internalfb.com/code/fbsource/[50db185dc92eb102ef16fb368a6efab2730e7838]/fbcode/hphp/runtime/vm/jit/check-type-opts.cpp?lines=40-65

> Note: this doesn't happen if you put an `echo` statement before the invocation of `::f()`.
 ---
The CheckType instruction supports handling checking subtyping and exact objects, and the same for classes, but it avoids checking constants e.g. something like Int=47:

fast path:
https://www.internalfb.com/code/fbsource/[d6e4852aa5f0976c3a12094a92cc0b117dfebf01]/fbcode/hphp/runtime/vm/jit/irlower-type.cpp?lines=86-99
slower path:
https://www.internalfb.com/code/fbsource/[d6e4852aa5f0976c3a12094a92cc0b117dfebf01]/fbcode/hphp/runtime/vm/jit/irlower-type.cpp?lines=106
https://www.internalfb.com/code/fbsource/[f68b2b8f3b85a8d6c625ba4fd224286c4421f31a]/fbcode/hphp/runtime/vm/jit/irlower-internal-inl.h?lines=258
https://www.internalfb.com/code/fbsource/[f68b2b8f3b85a8d6c625ba4fd224286c4421f31a]/fbcode/hphp/runtime/vm/jit/irlower-internal-inl.h?lines=244-249
https://www.internalfb.com/code/fbsource/[f68b2b8f3b85a8d6c625ba4fd224286c4421f31a]/fbcode/hphp/runtime/vm/jit/irlower-internal-inl.h?lines=289-291

**However, `TCls` has a const value!** (see line 788)

https://www.internalfb.com/code/fbsource/[bcc1969bc1d50216df9acc77068afb5297b81f50]/fbcode/hphp/runtime/vm/jit/type.h?lines=773-799

So the assertion at the top of `emitTypeTest` fails.

https://www.internalfb.com/code/fbsource/[f68b2b8f3b85a8d6c625ba4fd224286c4421f31a]/fbcode/hphp/runtime/vm/jit/irlower-internal-inl.h?lines=228

 ---
This change makes it so we proceed with the CheckType on TCls despite it having a const value.
