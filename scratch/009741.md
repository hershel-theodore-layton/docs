Commit title: Consume native unwinder Hack exceptions early, handle them as side entry
Commit body:
Summary:
We can enter the unwinder for Hack exceptions either via native C++ unwinder,
or via side entry (EnterTCUnwind). We currently handle each case slightly
differently. The first one keeps the exception registered with the unwinder,
allowing it to be rethrown when leaving VM. The second one rethrows it manually
when it reaches VM boundary.

Unify these mechanisms by consuming the exception from the native unwinder
earlier.

C++ exceptions are still kept registered with the native unwinder.

Allows handling Hack exceptions in JIT catch blocks.
