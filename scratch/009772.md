Commit title: Allow completions in top-level statements
Commit body:
Summary:
Top-level statements are allowed in Hack notebooks, and we think users will benefit from auto-complete. Enable completions to work for top-level statements.

## Alternatives Considered

We could pass a flag on LSP start to indicate whether there should be completions for top-level statements. Notebooks would pass the flag and our VSCode extension would not.

However:
- I've been trying to make Hack notebook support "just work" without any special-casing so notebooks don't add maintenance burden for our team. Divergences in LSP behavior between the two platforms would make bugs harder to reproduce.
- Users will probably expect a consistent experience in notebooks and VSCode. Imo it's OK if we complete top-level statements in VSCode: users can easily type things out and then move them into functions or classes as needed. They still get the parse error about top-level statements, so it will be clear top-level statements aren't allowed (see video in fb-only section below)
