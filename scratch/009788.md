Commit title: Side exit before interp when inlining
Commit body:
Summary:
Previously we spilled all inlined frames, allowing us to execute the interp'd
bytecode, but then had to side exit anyway. This also pessimized all inlined
frames, not just the one that did interp.

Instead, side exit before the interp bytecode. This materializes only the
current frame by converting it to the call context, allowing other frames to
potentially recover. While the current logic does not attempt the recovery yet
and side exits all frames, it at least shares that code with all other side
exits, resulting in reduced code size.
