Commit title: Use type dynamic for result of static method call through string
Commit body:
Summary: If a static method is accessed through a string rather than `dynamic`, we produce an error, and internally generate a fresh type variable that gets solved to anything that fits, typically `nothing`. If hidden by a fixme (error code 4026) this leads to unsoundness (types that don't tell the truth). Better to produce the type `dynamic`.
