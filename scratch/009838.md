Summary:
`typing.ml` is a large file with a huge mutually recursive set of functions.

To begin picking this apart, this diff tries to identify which functions are effectively private to a particular syntactic element (e.g. only used in typing `expr`) vs those which are mutually recursve between elements (e.g. `expr` is used from `stmt` and vice versa). We can also start to untangle the functions which are not actually mutually recursive but have been declared as such so they are close to the functions from which they are called.

The refactor is 'approximate' in which modules we have and where the functions are located since our typing functions aren't yet strictly aligned by syntactic elements (this is the structure we ultimately want). Despite this, it is successful in making the internal API smaller.

By restricting the internal API, we give ourselves a better base for further refactors and clean-up
