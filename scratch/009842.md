Commit title: Type sequences of top-level statements
Commit body:
Summary:
Before this change, we typed each top-level statement by itself, discarding the typing environment after each.

With this diff, we propagate a typing environment for top-level statements.

This enabled us to have the expected behavior for code like:

```
<?hh
$x = new Foo();
$x->meth();
```

See the snapshot test for the change in behavior.

The goal of this change is to enable language server features to work well for top-level statements (including type-guided hovers and completions) because top-level statements are used in Hack notebooks.

Even though the goal is related to notebooks, this change affects all users of Hack, but hopefully in ways that either don't matter or are helpful.
