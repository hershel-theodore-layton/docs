Summary:
The `--skip-gen` option allows the compiler to complete all steps prior to code generation (including IDL parsing, mutation and validation), but skip the code generation itself.

This is particularly useful when looking to validate Thrift IDL (eg., run over all thrift files in a given repo), as it saves significant time. In local devserver runs, validating all thrift files in fbcode/, we see a ~23x reduction in time when skipping generation (in that case, of the `ast` generator):  {F1143475503}
