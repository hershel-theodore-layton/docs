Commit title: replace FuncCounterMap with a byte in each Func
Commit body:
Summary:
We previously count the number of JIT attempts for each function using a tbb hashmap, which can cause heavy contention. Alternative hash table implementations didn't work well. So we find a free byte in Func and do it there.
The downside of it is that the threshold can be at most 256, which seems fine in perf testing.
