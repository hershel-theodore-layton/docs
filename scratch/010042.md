Summary:
Preparing for migration to core/core_kernel/base 0.16.X

The main change seems to be around the Map/Set/Table APIs where one should now use the anonymous `Map.find` instead of `String.Map.find` (and other like that). Both version seems to work on v0.15.X so I'll first migrate the code, then upgrade.

Main take away:
- `XXX.Map.find/update` -> `Map.find/update`
- Same for `XXX.Set.find` -> `Set.find`
- `String.Table.xxx` -> `Hashtbl.xxx`

Another main change is that now one must use `Stdlib` instead of `Caml` when `Core` is open.

Minor changes around ppx setup (what to open / where) is also present.

I'm not switching the library version in supercaml not dune yet. The next diffs in the stack will deal with other major ocaml projects, before I turn the switch.
So far the only incompatible item between 15 and 16 is a `module Time = Core.Time` which is deprecated, and prevents to update the dune build only.
