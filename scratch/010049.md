Fix a compiler assertion error:
```
Expected<T> must be checked before access or destruction.
```
Replace the `getAsCString` with the wrapper `toString`
 ---

For the reference:
```
Expected<const char *> getAsCString() const;
...
inline std::optional<const char *>
toString(const std::optional<DWARFFormValue> &V) {
  if (!V)
    return std::nullopt;
  Expected<const char*> E = V->getAsCString();
  if (!E) {
    consumeError(E.takeError());
    return std::nullopt;
  }
  return *E;
}
```
