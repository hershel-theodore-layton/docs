Commit title: Adjust API to get the structured annotation
Commit body:
Summary:
The existing APIs

```
template<class AnnotationType, class Struct, class Id>
const bool has_field_annotation();

// Build failure if Struct.Id doesn't have corresponding Annotation
template<class AnnotationType, class Struct, class Id>
const AnnotationType& get_field_annotation() { /* ... */ }
```

This won't work with the following code when people check whether annotation existing and do something with it.

```
if (has_field_annotation<AnnotationType, Struct, Id>) {
  do_something(get_field_annotation<AnnotationType, Struct, Id>);
}
```

since if annotation doesn't exist, `get_field_annotation<AnnotationType, Struct, Id>` won't build.

In this diff, if we want to avoid `constexpr`, I suggest we adjust the API a bit and just return a pointer

```
template<class AnnotationType, class Struct, class Id>
const AnnotationType* get_field_annotation() { /* ... */ }
```

so that we can do

```
if (auto p = get_field_annotation<AnnotationType, Struct, Id>) {
  do_something(*p);
}
```
