Commit title: Cache active deployment per request on sandbox
Commit body:
Summary:
Let's cache the active deployment per request in non repo mode to improve sandbox perf. Per request, the host never changes, so the deployment never changes.

There isn't a good default to distinguish between "unset" vs. "no deployment" unfortunately, so in the case where the deployment is none, we won't cache. But in any case where it matters and PACKAGES.toml is properly configured, the cache will work properly.
