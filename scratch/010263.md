Commit title: Execute non-global TProcessorEventHandlers only
Commit body:
Summary:
This diff changes the server runtime to stop looking at the global set of event handlers registered in `TProcessorBase`.

Since {D51483690}, all event handlers are captured either in `ThriftServer` via server modules or in `AsyncProcessor` via calls to `addEventHandler`.

This diff replaces `AsyncProcessor::getContextStack` with `AsyncProcessor::coalesceLegacyEventHandlersWith`, which accounts for both these sources of event handlers.

The change here effectively allows `ThriftServer`-scoped `TProcessorEventHandler` instances to execute in production.
