Summary:
HPHP::Facts::FileFacts is redundant now; let's start by removing HPHP::Facts::TypeKind. It had drifted out of sync with hackc::TypeKind, which has a `Mixed` variant. Mixed merged into `Unknown` at some point in the distant past.

what is `TypeKind::Mixed`? It signals a duplicate name collision. When we get around to hardening Facts against inconsistent/broken filesystem states, we should either report that as an error (fixing all the error propagation) or use the same "winner" policy as Hack - first instance in a file, first lexicographic filename.

For now, converting Mixed (ie "a collision happened") to Unknown is backwards compatible.
