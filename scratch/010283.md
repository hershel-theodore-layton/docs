Summary:
This diff removes the HHVM check that prevents module level traits to use non-module level traits.

Since (normal) traits cannot define internal members (enforced by both Hack and HHVM), nor access internal methods or properties (enforced by Hack only), it is safe to use a non-module level trait from a module level trait.
