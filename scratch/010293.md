Commit title: Cleanup t_const_value
Commit body:
Summary:
Cleanup `t_const_value` in preparation for fixing handling of identifiers.

* Move the logic to copy `t_const_value` from `clone` to the copy ctor. It doesn't make much sense to have one but not the other, especially since `t_const_value` is a leaf node.

* Rename "type" to "kind" because it is not an actual type but a kind of grammatical construct. The type is determined during semantic analysis via type inference: https://www.internalfb.com/intern/staticdocs/thrift/docs/idl/#constants.
This brings the implementation and the documentation closer together and makes the API less ambiguous (the concept of type is no longer "overloaded").
Part of the change is done via a simple codemod:
```
fbgs -m t_const_value_type -f '(cc|cpp|h)$' -l | xargs sed -i 's/t_const_value_type/t_const_value_kind/'
```

* Apply coding conventions to member variables.
