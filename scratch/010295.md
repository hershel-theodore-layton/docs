Commit title: Replace `DistributedMutex` constants in nanoseconds with cycles
Commit body:
Summary:
`time()` calls `hardware_timestamp` which in turn calls [`rdtsc`][1]:
> [RDTSC] Reads the current value of the processor’s time-stamp counter <...>
> The processor monotonically increments the time-stamp counter MSR every clock
> cycle <...>

So, value from `rdtsc` is not nanoseconds, but CPU cycles.

If CPU frequency is 2 GHz, then one cycle lasts 0.5 ns (2 cycles per 1 ns),
with 4 GHz it lasts 0.25 ns (4 cycles per 1 ns), etc.

Let's make it clear from the code, in what units we specify time here.

[1]: https://www.felixcloutier.com/x86/rdtsc
