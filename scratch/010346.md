Currently `SaturatingMath.h` fails to build in MSVC since it doesn't support integer overload for `std::isnan` and `std::isinf`.

https://en.cppreference.com/w/cpp/numeric/math/isnan

For integer types, `std::isinf` and `std::isnan` would always return false. e.g., the GCC implementation

https://github.com/gcc-mirror/gcc/blob/releases/gcc-13.2.0/libstdc%2B%2B-v3/include/c_global/cmath#L1193
