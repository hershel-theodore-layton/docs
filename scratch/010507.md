Commit title: Check constructor bodies under dynamic assumptions
Commit body:
Summary: In a class marked `<<__SupportDynamicType>>` we check methods under both static and dynamic assumptions. But we check constructors only under static assumptions. This is sound if the class cannot be *instantiated* dynamically, but in the presence of `new $x` where `$x` has type `dynamic`, to be sound we must check the constructor under dynamic assumptions.
