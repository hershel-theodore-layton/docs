Commit title: Add strict utf8 mode to Hack parser
Commit body:
Summary:
This diff adds a new parser option `po_strict_utf8` which causes the hack parser to reject source files containing non-utf8 binary sequences.

It then threads that option through HHVM and Hack.

In HHVM the option is controlled by `-vEval.StrictUtf8Mode`
- A value of 0 (the default) allows non-utf8 characters universally.
- A value of 2 rejects non-utf8 characters universally.
- A value of 1 tells HHVM to reject non-utf8 in source code but to allow non-utf8 sequences in `eval` code.

In Hack the option is controlled by `--config strict_utf8=true/false`.
