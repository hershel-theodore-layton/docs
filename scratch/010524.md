Commit title: IOThreadPoolExecutorBase::IOObserver
Commit body:
Summary:
Several observers extract the `EventBase` pointer from the `Thread` handle, but this only works under the assumption that threads and evbs are 1:1, which only holds for `IOThreadPoolExecutor`.

All these observers actually only require to track the evbs used in the executor, so we can add a dedicated observer to `IOThreadPoolExecutorBase` for that purpose, that works correctly even if evbs and threads are independent.
