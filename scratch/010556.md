Summary:
`IOThread` is an implementation detail of `IOThreadPoolExecutor`, temporarily moved to `IOThreadPoolExecutorBase` to support building with some observers that relied on extracting the thread's `EventBase`.

With those migrated to `IOObserver`, we can move it back to `IOThreadPoolExecutor`.
