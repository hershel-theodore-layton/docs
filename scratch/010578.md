Summary:
ClientIdeDaemon uses lfu_cache to store all its decls. This diff adds a bit of new functionality:
```
  (* Check whether the item is present *)
  val find : t -> key:'a Entry.key -> 'a Entry.value option

  (** This uses [Entry.key_to_log_string] to get a list of all keys.
  Solely for debugging/logging. *)
  val keys_as_log_strings : t -> string list

  (** Normally whenever you [add] or [find_or_add], if the cache is too large,
  then it will do a collection. [let b = set_can_collect false] will prevent
  further collections from happening, and return the previous boolean of
  whether collections were allowed before; and [set_can_collect b] will restore
  collection behavior to whatever it was before. *)
  val set_can_collect : t -> bool -> bool

  (** In Provider_backend *)
  val get_local_memory_telemetry : local_memory -> Telemetry.t
```

`find` is obvious, similar to other collection APIs in ocaml. I'lll need it later as I write a "decl prefetcher" which will concurrently prefetch decls, but only if they can't be found already.

`set_can_collect` will also be used for the duration of concurrent prefetching and folding.
