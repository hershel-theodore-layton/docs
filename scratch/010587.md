Summary:
Previous state of affair:
1. We compute fanouts of classes
2. Using the deps of changed classes, we traverse their extends deps and resolve deps to names to invalidate the right folded decls.

New state of affairs:
1. We compute changes and descendant deps of changed classes
2. We invalidate the right folded decls using that
3. We compute fanout using that

This is mostly visible in Decl_redecl_service lines 615-630. The rest is more or less boilerplate.

Why this change: Because the new fanout algorithm uses some folded decls, and we want those to be accurate.
