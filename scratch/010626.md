Commit title: user attribute fanout
Commit body:
Summary:
User attributes have been the next big source of large fanouts lately, and they're annoyingly simple to fix, so I'm fixing them.

A look at the data show that guilty attributes have mostly been `__Sealed` and `Oncalls`, so I'm making sure to special case `__Sealed`, and ignore all non-internal attributes.

For `__Sealed`, here's the algorithm:
* if __Sealed was added, recheck all the direct children
* if was removed, recheck all the children only if they had errors
* If an element was added to the allowlist, recheck that element if it had errors
* If an element was removed from the allowlist, recheck that element.
