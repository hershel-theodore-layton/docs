Summary:
This diff adds a `fold` method to our lfu_cache.

Our lfu_cache is a GADT. They're just beyond my ability to understand. I found this guidance for how to iterate over a heterogenous collection: https://discuss.ocaml.org/t/packing-gadt-constructors-in-iterable-data-structure/2678. Hence:
```
type element = Element : ('a Entry.key * 'a Entry.value) -> element

val fold : t -> init:'acc -> f:(element -> 'acc -> 'acc) -> 'acc
```

It seems to work! I included a unit test. I had to use `Obj.magic`, for reasons I don't understand, but all the other existing functions in lfu_cache.ml also use Obj.magic for similar reasons.
