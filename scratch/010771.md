Commit title: Use explict copy operator in CoReturn impl
Commit body:
Summary: Unlike CoReturnByMove(), CoReturn() relies on making copies each time it is evaluated. Currently this copy is done implicitly. Making the copy in CoReturn() explicit doesn't change anything for classes supporting implicit copies, but allows it to be used with classes that have their copy constructor marked explicit.
