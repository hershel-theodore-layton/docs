Context
==

An attempt to deal with package boundaries breaks autodeps.

```
Found multiple possible owners for "thrift.util.asyncio.create_client" (from thrift/lib/py/server/test/TAsyncioServerTest.py:33) when processing rule "asyncio_server":
  //thrift/lib/py/util:asyncio
  //thrift/lib/py:asyncio
```

This is thrift-py-deprecated, considered [unsupported by the Thrift team](https://fb.workplace.com/groups/thriftusers/posts/1319826018726807).

Implementation
==

Due to vagaries of the build system that I don't have time to investigate, a previously test-passing diff stopped passing on a rebase in January. It looked like the buck overrides in fbsource (see earlier iteration of diff) stopped working, so all of the -py-deprecated targets started pointing back at `//thrift/lib/py:asyncio` instead of at `//thrift/lib/py/util:asyncio`. I chose the shorter path of fixing the solitary case that pointed directly to util:asyncio.

* Remove attempt at aliasing the library by moving the library down one level
* Remove the entry in util/TARGETS
* Update all TARGETS that refer to the now removed entry (1)
