Commit title: cache FileDecls with sha1 hash as key
Commit body:
Summary:
Uses the SHA1 hash of the file contents as a cache key to ensure we invalidate the cache if the file changes without needing Watchman events.

To support this, I changed `FileDecls` to use a shared_ptr instead of `optional` based on the advice in D52259369. I store a shared_ptr in a process-wide cache, and increment the reference with the copy constructor on a cache hit.
