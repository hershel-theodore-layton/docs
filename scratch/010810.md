The `object` type does not exist and HHVM interpreted it as any object just by
an accident. Convert them either to the actual type that is being used, or
`\HH\object` if the API accepts/returns any objects, or it was undetermined
which one is being used.

accept SimpleXMLElement (this feature was unused).
