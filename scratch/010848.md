Commit title: XHP classes should be queryable with mangled or unmangled names
Commit body:
Summary:
Previously, `getClasses` would return a name that was mangled. However, `getClass` required a name that was unmangled. That's a bit unintuitive. So I add support for either. This allows two workflows

1) Programmatic querying, something like
```
for class in $instance->getClasses()
  $instance->getClass(class)
```
This supports mangled names in queries

2) Copy/pasting from source code. This allows using unmangled names.

See tests for sample.
