Commit title: Improve large-buffer crc32c performance by 50-85%
Commit body:
Summary:
Import a faster large buffer crc32c implementation from Peter Cawley[1].  Our
existing SSE4.2-accelerated implementation achieves ~23.5GB/s on large (512kB)
buffers on my devvm and the new (SSE4.2) one achieves ~35.1GB/s.  On hardware
that supports AVX512, I've observed another ~17% improvement with that
algorithm for a net 85% speedup on 512kB buffers.

The performance is worse for smaller buffers (<= ~4kB), so I've conditioned
algorithm selection on that criteria.  At 4kB we have approximate parity, at
8kB this is about 15% faster, at 16kB ~35%, and 32kB ~40-55% (more improvement
on hardware with avx512 support).

[1]: https://github.com/corsix/fast-crc32
