Commit title: do not allow adapter on typedef with a @rust.Type annotation
Commit body:
Summary:
"You cannot define `rust.Adapter `on a field or typedef that has a `rust.type` (see https://www.internalfb.com/intern/wiki/Rust-at-meta/Thrift/Adapters/)

D51721781 and D51981246 introduced the structured `rust.Type` annotation but didn't take this constraint into consideration. With this change,
```
  rust.Type{name = "small_vec::SmallVec<[u8;32]>"}
  rust.Adapter {name = "::fbthrift_adapters::UuidAdapter<>"}
  typedef binary uuid
  struct CreateWorkflowRequest {
    1: uuid id;
 }
```
generates
```
[ERROR:foo/a.thrift:5] Typedef `uuid` cannot have both an adapter and `rust.type` or `rust.newtype` [rust-typedef-adapter-rule]
```
