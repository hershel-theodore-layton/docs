Summary:
I was going back through the old DITCH flags for class conversion and noticed there were some gaps in test coverage so I pushed them to a `config.ini` for the directory. The three flags affected here are

```
hhvm.class_as_string_var_dump=false // var_dump prints class(C) for lazy+clsptr
hhvm.class_as_string_var_export=false // ditto
hhvm.raise_class_conversion_notice_sample_rate=1 // raises notice on "string ops" i.e. not type hints
```

Found a few bugs, documenting here
- `is Stringish` notice behavior differs between interp and repo mode
- conversion in enums emits different notice messages between interp, jit, and repo

All we care about is that a conversion happened, but I still want to unify them.
