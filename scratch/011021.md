Commit title: use a case-insensitive logging hash_set for functions
Commit body:
Summary:
In the soap extension, SoapServer::addFunction() lets you register hack functions
as soap handlers. Some quick internet searches confirmed that SOAP (and XML in general)
is supposed to be case sensitive.

ext_soap used some ad-hoc tolower() logic to handle function names. Instead,
use look up the actual function (which can trigger case collision logging), and
register functions using their correct-case name. Use a req::vector_set to
preserve insertion order and log case collisions on lookup.
