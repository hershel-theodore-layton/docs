Commit title: Fix stepping-over lines with multiple calls
Commit body:
Summary: Step-over in the debugger is implemented as a step-in followed by a step-out. There can be multiple function calls in the same line the user is stepping over. In such a case, the step-out state will be `StepOutState::Out` after returning from the first call. It needs to be changed to `StepOutState::Stepping` when entering subsequent calls. Otherwise, the execution will pause inside the second function.
