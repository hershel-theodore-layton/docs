Commit title: Support cancellation in ManualTimekeeper
Commit body:
Summary:
ManualTimekeeper doesn't support cancelling futures, requiring users to call `advance()` in order to break out of waiting.  Set an interrupt handler similarly to other timekeepers to support cancellation.

Cancelling will also remove the promise from the schedule.  This has a couple of nice properties:
1. Gives back memory immediately (rather than having to wait for calls to `advance()`)
2. Avoids races between `advance()` setting values and the interrupt handler setting exceptions on the promise (and dealing with the fallout of setting an already fulfilled promise)

Add a MapKey key type which allows the interrupt handler to disambiguate multiple scheduled events with the same expiration timestamp.
