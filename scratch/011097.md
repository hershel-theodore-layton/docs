Commit body:
Summary:
This diff implements error checking for the new `allow_directories` field when parsing package config:
- we accept paths relative to the directory in which the current package config being parsed lives, including ones optionally prefixed with . and ones optionally suffixed with *
- the config parser tries to canonicalize each path in `allow_directories`, yielding a set of unique canonicalized paths to maintain in PackageInfo (for typechecking later) and throwing parse errors on ones that don't exist
- `allow_directories` is only exposed to the typechecker and not the runtime, and hence none of the parse errors would surface during runtime
