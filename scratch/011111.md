Commit title: Fix lambda arity check for lambdas with default arguments
Commit body:
Summary:
check_lambda_arity was checking that the minimum number of arguments the function type required was the same for the match vs expected.

However, equality isn't necessary. What's necessary is that the actual function type can take as many arguments as the expected function type might take (actual max >= expected max) and that the actual function type requires no more arguments than the mininum number of args the expected function type might take (actual min <= expected min).
