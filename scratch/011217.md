Commit title: assert package in CrossPackage attribute is loaded
Commit body:
Summary:
- A cross package method/fun with attribute `<<__CrossPackage(pkg)>>` is allowed to reference types from `pkg` as if `pkg` is loaded, i.e. in the same deployment as the caller's package.
- Today if `pkg` isn't loaded, attempting to access it will simply result in boundary violations.
- One concern is that lack of enforcement on the cross accessed package as loaded might lead to manual assertions in user land, and so it'd be sensible to desugar `<<__CrossPackage(pkg)>>` into `assert(package_exists(pkg)` at the start of the function
