## What

Reorganize dependencies so hh_client doesn't depend on server:server. This is expected to be a noop from the user's point of view.

## Why

Speed up build times for hh_client by 1.9X.
Also remove tech debt and untangle dependencies.
See test plan for details.

## How

- break up `server` and `server_extras` into smaller libraries so the client doesn't depend on everything.
- Move some small, lightweight code to a place that is shared between server and client so the client doesn't need to depend on the whole server.

## Follow-on work

- remove unused dependencies
- rename things under //hphp/hack/src/server/ that aren't used by hh_server. The current organization reflects the way things worked before serverless IDE, which moved logic from the server to the client.
