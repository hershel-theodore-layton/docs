Commit title: Extend NonDisjoint linter to instance and static methods
Commit body:
Summary:
Extend the existing non-disjoint-types linter to static and instance method calls. Only generic parameters on the method itself can be checked for disjointness, but via clever use of `where` constraints it's possible to include enclosing class generics. For example:
```
class List<T> {
  public function contains<<<__NonDisjoint>> T1,<<__NonDisjoint>> T2>(T2 $x) where T=T1 { ... }
}
function testit(List<string> $x):void {
  // This should be flagged
  $b = $x->contains(3);
}
```
