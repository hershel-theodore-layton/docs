Commit title: Optional arguments in function type hints
Commit body:
Summary:
We extend the syntax of function types to support an `optional` qualifier on parameters, representing a function's ability to supply a default parameter if an actual argument is not supplied. So the type of `foo<>` where `foo` is defined to be
```
function foo(int $a, string $b = 'a', bool $c = false):void { }
```
can be written in Hack as
```
function(int, optional string, optional bool):void
```
Some restrictions:
* An optional parameter cannot precede a non-optional one
* An `inout` parameter cannot be marked `optional`
* A `...` parameter cannot be marked `optional`
* Although a keyword, `optional` can still be used as an identifier e.g. as the name of a function or method.
