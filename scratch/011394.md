Commit title: Kill problematic standard.Uri
Commit body:
Summary:
`standard.Uri` is virtually unused and has a number of problems:

1. It has never been adapted and, contrary to the TODO, likely never will because adapting is a breaking change.
2. It is not really a URI, at least because there is no scheme (doesn't conform to the linked RFC).
3. It seems to be misused to identify custom protocols in `ProtocolUnion`.
4. It gives an impression of being a strong type while, in fact, it is just an alias to a string.
5. It uses some `thrift.uri` hack for unclear reason.

The documentation benefits of this alias are minimal so replace the only 5 uses of it including the one which is incorrect with `string` and improve the documentation comments of `TypeUri` which is the actual "strong" type that should be used.
