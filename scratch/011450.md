Commit title: @rust.Type/rust.newtype bugfixes
Commit body:
Summary:
with this example thrift
```
rust.Type { name =  "smallvec::SmallVec<[u8; 20]>" }
typedef binary Sha1 (rust.newtype)
```
(1) the resulting rust type definition reads
```
pub struct Sha1(pub ::std::vec::Vec<::std::primitive::u8>);
```
which is wrong, the interior of `Sha1` should be `smallvec::SmallVec<[u8; 20]>`

(2) the implementation of trait `Serialize<>` for `Sha1`  reads,
```
 impl<P> ::fbthrift::Serialize<P> for Sha1
 where
     P: ::fbthrift::ProtocolWriter,
 {
     fn write(&self, p: &mut P) {
         self.0.write(p)
     }
 }
```
which is wrong because `smallvec::SmallVec<[u8; 20]>` is non-standard so should read,
```
 impl<P> ::fbthrift::Serialize<P> for Sha1
 where
     P: ::fbthrift::ProtocolWriter,
 {
     fn write(&self, p: &mut P) {
         crate::r#impl::write(&self.0, p)
     }
 }
```
this diff fixes these two issues.
