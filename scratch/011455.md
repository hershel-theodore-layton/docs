Commit title: Real deprecation of client `dependencies` module
Commit body:
Summary:
This module is not meant to be used by handwritten code. That is how you get imports like the ones seen in {D53379341}.

```
use myles_testing_service::dependencies::myles::dependencies::fb303::dependencies::fb303_core::server::BaseService;
```

The `dependencies` module only exists for Thrift-generated code to use in situations related to clients that extend services from a different crate. Non-generated code should directly depend on the appropriate Thrift library instead. Or, Thrift libraries may choose to provide a `typedef` for key types from their dependencies.
