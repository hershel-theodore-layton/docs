Commit title: Disallow EventBase::terminateLoopSoon() in strict loop thread mode
Commit body:
Summary:
`terminateLoopSoon()` should only be called when owning the `EventBase`; it should not be allowed on an `EventBase` owned by an executor, because it makes it impossible for the executor to know when the `EventBase` is fully drained (callbacks may call it and stop the drain).

This diff disallows it in strict mode (currently only used by `MuxIOThreadPoolExecutor`), and I'll try enabling this in other executors separately.
