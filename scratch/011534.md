Commit title: Push supportdyn through like types when stripping dynamic
Commit body:
Summary:
We're missing the like (`~`) on a type when there is an intervening `supportdyn`. Except where we are explicitly handling `supportdyn` in the expect-type logic, we can just push the `supportdyn` through i.e. `strip_dynamic(supportdyn<~t>) = supportdyn<t>`.

This affects at least arithmetic expressions (e.g. ~int + int), possibly other incompleteness elsewhere.
