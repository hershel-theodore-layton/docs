Commit title: Sample filtering of recordings
Commit body:
Summary: Allow the decision to record a request to be sampled by both a rate and a filter. The filters take the form of `{Superglobal name}.{Dict key}={Expected value}`. For example, filtering on whether the request has POST data with key k and value v could be accomplished by adding the command line parameter `-vEval.RecordSampleRate=_REQUEST.k=v`. Multiple filters can be combined using `&`. If both a rate > 1 and a filter are set, then the rate coinflip is performed first, followed by the filtering. Thus, the rate serves as an upper bound on the amount of sampling performed.
