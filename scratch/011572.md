Commit title: Remove virtualized expression
Commit body:
Summary:
Add an optional field `type` to `makeTree`'s metadata shape field with type `TInfer`. When generating nast for typechecking, place the virtualized expression there, to cause type inference to use the client type inferred for the virtualized expression as a lower bound for `MakeTree`'s `TInfer` generic. When generating bytecode, omit the field so that the virtualized expression does not get bytecode. The `type` field is `function(): TInfer` rather than just `TInfer`, because the virtualized expression is always a thunk.

Also, clean up by removing the `et_virtualized_expr` field from the expression tree AST node, remove special purpose type checking code around the virtualized expression for stripping like types, explicitly instantiating `TInfer` to a new generic `TInfer#x`, and extracting the thunk's return type.
