Commit title: Fix printing in cli-server xbox threads
Commit body:
Summary:
Currently when running with `Eval.UnixServerProxyXbox=1` stdout and stderr are available in the xbox thread but not written to by `echo` and other printers that use `ob_flush`. The issue is that we resolve whether or not the request is in CLI mode for the purpose of OB before we've initialized the new CLI server context.

Also fix `HH\execution_context()` to return `xbox` in xbox threads (mirroring the behavior of regular CLI usage of xbox) and stop swallowing fatals in xbox threads started from CLI server.
