Summary:
noticed a case where we should be considering the `rust.NewType` annotation also.

before this diff,
```
rust.Adapter {name = "::fbthrift_adapters::UuidAdapter<>"}
typedef binary uuid (rust.newtype)
```
produces
```lang=php,counterexample
[ERROR:fbcode/scripts/shaynefletcher/project/thrift/foo/a.thrift:6] Typedef `uuid` cannot have both an adapter and `rust.type` or `rust.newtype` [rust-typedef-adapter-rule]
```
whereas
```
rust.NewType
rust.Adapter {name = "::fbthrift_adapters::UuidAdapter<>"}
typedef binary uuid
```
does not.
