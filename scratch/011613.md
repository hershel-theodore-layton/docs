Commit title: Incompleteness with pessimisation of enum returns
Commit body:
Summary:
We want to support the following "like-pushing"
```
vec<~E & int> <: ~vec<E>
```
assuming
```
enum E : int as int { ... }
```
Unfortunately the `strip_covariant_like` function looks for literal `~E` not `~E & int` (which simplifies to `(dynamic & int) | E`). Fix this by optionally accepting intersections with `dynamic` in the `try_strip_dynamic` helper.
