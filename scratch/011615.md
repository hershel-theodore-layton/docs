Commit title: cut an excess instruction in SingletonThreadLocal::get fast-path
Commit body:
Summary:
The cached pointer is currently to the State::Wrapper instance, which is offset from the start of Wrapper and thus the object. So the fast-path must calculate the base address from the offset, which is an `add` instruction.

We may remove this excess instruction by caching the pointer to the object directly.

From: https://github.com/facebook/folly/blob/v2024.02.05.00/folly/test/SingletonThreadLocalTest.cpp#L37-L39
```
extern "C" FOLLY_KEEP int* check() {
```
