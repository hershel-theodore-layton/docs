Commit title: Install breakpoints in loaded units unconditionally
Commit body:
Summary:
Consider the following scenario:
1. Start executing unit 1.
2. Load unit 2 in the process.
3. Stop at a breakpoint in unit 1.
4. Set a breakpoint in unit 2.
The second breakpoint does not get installed currently because we check for newly loaded units only once per request. This diff removes this short circuit. We can instead use the check for pending breakpoints to short circuit this check.
