Summary:
It's not always obvious how to action the "`await` cannot be used as an expression in this location because it's conditionally executed." error.

Make it obvious with a quickfix. Use the existing machinery for the "Extract into variable" refactoring because:
- "Extract into variable" exists: we can provide a consistent experience for users and we don't have to maintain two implementations
- Our machinery for refactorings enables lazy calculation of edits, which is beneficial because the logic involves some expensive computation with the full fidelity parse tree.
