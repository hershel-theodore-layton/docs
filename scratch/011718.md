this diff is adding cargo config for the thrift/annotation/[all, compat, cpp, go, hack, java, python, rust, scope, thrift] targets to the fbthrift repo to enable the use of structured annotations:

- adds fbcode/thrift/annotation/PACKAGE (move cargo config from under fbcode/common/rust/cargo_from_buck to fbcode/thrift)
- ~~updates thrift/annotations/TARGETS so that each target's cargo config is isolated (under thrift/lib/rust/annotation) e.g. for thrift (annotation library) "cpp" add buck option`rust_autocargo = ../lib/rust/cpp`~~
- adds key ` public_cargo_dir = "thrift/lib/rust/public_autocargo"` to common/rust/cargo_from_buck/project_configs/fbthrift.toml
- incorporates the result of `arc autocargo` to pick up the resulting changes and deletes now unreferenced config under common/rust/cargo_from_buck/fbcode

after this, there will need to be a subsequent shipit diff before we can use the newly added targets from the repo.

 ---

cargo from buck project config 'fbthrift.toml' reads
```
include_globs = ["thrift/lib/rust/**", "thrift/annotation/**"]

[oss_git_config]
git = "https://github.com/facebook/fbthrift.git"
branch = "main"
```

there is no cargo config for thrift/annotation/[all, compat, cpp, go, hack, java, python, rust, scope, thrift] in the fbthrift repo and the fbthrift package manifest `thrift/lib/rust/Cargo.toml` has no relative paths needing to be remapped (which is why there has been no need of a public autocargo directory so far).

when we use structured annotations (as in D53676407) we need to provide them. e.g. configerator/scm/mononoke/megarepo/TARGETS
```
thrift_library(
  name = "megarepo_configs",
  thrift_srcs = {...},
  deps = ["//thrift/annotation:rust"],
)
```
or,
```
  [package]
  name = "megarepo_configs"
  ...
  [dependencies]
  ...
  rust = { path = "../../../../../thrift/lib/rust/annotation/rust" }
  ...
```
(in the oss version - 'configerator/structs/scm/mononoke/public_autocargo/megarepo/Cargo.toml' - that's `rust = { version = "0.0.1+unstable", git = "https://github.com/facebook/fbthrift.git", branch = "main" }` and is what this diff is all about)

the cargo files (`Cargo.toml`, `thrift_build.rs`, ...) for thrift/annotation are currently generated under `fbcode/common/rust/cargo_from_buck/fbcode`. since we need them in git repo fbthrift these will have to move into the source tree and so use the `PACKAGE` mechanism. to complement the exisiting `fbcode/thrift/lib/rust/PACKAGE`, add `fbcode/thrift/annotation/PACKAGE`.
✓

at the moment, the `TARGETS` files make no provision for multiple `Cargo.toml`s for multiple targets so that needs fixing up e.g.
```
 thrift_library(
     name = "cpp",
     rust_autocargo = {"cargo_toml_dir": "../lib/rust/annotation/cpp"},
     ...
 )
```
✓

the Cargo.toml files generated for thrift/annotation rely on relative paths e.g.
```
 [dependencies]
 codegen_includer_proc_macro = { path = "../../../../../common/rust/shed/codegen_includer_proc_macro" }
```
which won't do for the fbthrift repo so we need to use the `public_cargo_dir` facility in fbthrift.toml in order to get suitable rewritten paths like,
```
 [dependencies]
codegen_includer_proc_macro = { version = "0.1.0", git = "https://github.com/facebookexperimental/rust-shed.git", branch = "main" }
```
so,
```
 [oss_git_config]
 public_cargo_dir = "thrift/lib/rust/public_autocargo"
 git = "https://github.com/facebook/fbthrift.git"
 branch = "main"
```
in `fbthrift.toml`
✓

for that to work we'll have to also adjust the fbthrift shipit config to map the `public_autocargo` versions of the Cargo.toml files and prohibit the "relative" Cargo.toml files from being synced. the config is in `fbthrift.cconf`. a good example to reference is `configerator/source/opensource/facebook/sapling.cconf` by the looks of things (i focus on `configerator/structs/scm/mononoke/meagarepo/`).
