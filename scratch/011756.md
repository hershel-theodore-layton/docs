Commit title: Add ability to set additional callbacks after NestedCommandLineApp parsing
Commit body:
Summary:
Currently, only one callback for NestedCommandLineApp parsing can only be specified, at construction time.

This introduces the ability to add additional callbacks, after creation.  The use-case is to allow common code to configure and handle arguments, for example basic logging configuration.

With this, it is possible do have re-usable helper functions for configuring and handling common options:

```
void addLoggingOptions(NestedCommandLineApp& app, po::options_description& cmd) {
  cmd.add_options()("vv", po::value<int>()->default_value(defaultGlogLevel), "Set verbosity");
  app.addCallback([](auto& cmd, auto& opts, auto& args) {
    FLAGS_v = options["vv"].template as<int>();
  });
}
```
