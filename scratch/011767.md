Commit title: use generated schema datatypes
Commit body:
Summary:
Thanks to D51811011, we can replace in the Hack indexer the glean_schema.ml with an automatically generated datatype. The generated code is in write_symbol_info/glean is and is generated with the following command.

```
> buck2 run fbcode//glean/schema/gen:gen-schema --  --ocaml fbcode/hphp/hack/src/typing/write_symbol_info/glean/ --dir ~/fbsource/fbcode/glean/schema/source --schemas hack,src,gencode,builtin
```

The required changes are
1. rename Gencode module to avoid naming clash with the new generated one
2. rename variables to OCaml snake case convention (the generated type use the proper convention, unlike the old `glean_schema.ml` which was using angle convention
3. some facts constructor can't be generated automatically (e.g. `make_bytespan`, I moved them to `Utils`. It would have been nicer to have them in the corresponding module for better encapsulation but this is the simplest solution.
4. some test output needed to be regenerated, this is purely due to xref ordering (fact order function is generated and depends on field ordering, which is different in the generated type and the old glean_schema.ml)
