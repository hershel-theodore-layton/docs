Commit title: Add postprocess and defaultearly to configs features
Commit body:
Summary:
- Add 2 features to the configs stuff
- First postprocess is just so you can implement a method that gets called after the value has been set to transform the value.
  - Used in D54075546 in hphp/runtime/base/configs/xbox-impl.cpp
- Second is defaultearly
  - This is a strange feature but something was needed to keep the existing behavior.
  - Before this feature the settings get their values when Config::Bind is called which is very early on but not right away. The reason it is set there is that some configs has their default value depend on the value of other configs. So we need to load the other configs before we know the default value.
  - But there are 2 cases when you don't want that. Sometimes we read the value of the config before Config::Bind and we need a reasonable default before we read the config file.
    - This is the case in D53636148 to set reasonable PCRE
  - The second case is that sometimes we want code to be able to change the default value between the static initialization and Config::Bind.
    - This is the case in D53636149 with Repo::Authoritative
