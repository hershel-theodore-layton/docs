Commit body:
Summary:
Consolidate the setTrafficClass and setTos calls into one function that handles IP_TOS and IPV6_TCLASS.

The two parameters are only usable for Linux and BSD/macOS. Linux accepts uint8_t or int for IP_TOS when used with IPPROTO_IP level but not SOL_IP (See https://elixir.bootlin.com/linux/v6.7.5/source/net/core/filter.c#L5362). For macOS, SOL_IP and SOL_IP6 are not defined but it only supports int values with IPPROTO_IP and IPPROTO_IPV6

This change uses the sockopt levels to IPPROTO_IP and IPPROTO_IPV6 and uses int for all the values. This works for both macOS and Linux.
