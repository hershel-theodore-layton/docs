# Context & Rationale

This change follows a discussion last week with yfeldblum, wherein we are considering keeping the `cmd` file format unstructured, with each line providing almost the exact arguments for the invocation of the thrift compiler.

This is an alternative to changing the `cmd` file to be structured (eg. JSON), as discussed in the original [RFC doc](https://docs.google.com/document/d/1dw2JZ0-CJksmdb3WwpYfRqLj1PvYnq2CKixTyp4e3I8/edit).

We also discussed the general problem of ensuring that individual commands do not clobber each other's output, and yfeldblum suggested prepending each line with a *required, unique* name.

This diff takes a first step, adding an (unused) name to each line. Uniqueness is not guaranteed yet, and `fixture_utils.py` does nothing beyond ensuring that such a name is provided. Subsequent diffs will check for uniqueness, and create dedicated output directories for each command (under the specific fixture, of course).

# Implementation

## 1. Prepend each cmd line with a name (that is not unique yet)

First, note that "go" is the only generator whose name would conflict with "mstch_go" after removal of the "mstch_" prefix.

According to vitaut, the non-mstch version of go is deprecated (or possibly even removed), so we'll be using the "deprecated" suffix for the corresponding cmds.

```
hg revert --all

for f in `find fbcode/thrift/compiler/test/fixtures/ -type f -name cmd`; do echo "$f"; cat "$f" | sed 's/^go\b/go_deprecated: go/' | sed 's/^mstch_\(\w\+\)\b/\1: mstch_\1/' | sed 's/^\([^:]\+\) /\1: \1 /' | sed 's/^\(\w\+\):\w/\1: \1:/'  > "$f.new"; mv "$f.new" "$f" ; done;

grep -v '^\w\+: ' `hgst`
```

## 2. Update fixture_utils.py to verify the existence of the name

As mentioned above, it currently does nothing beyond check the existence (and basic validity) of a name. Subsequent diffs will ensure that the given name is unique (within a fixture) and will use that name to separate the output from each command, all but ensuring that they do not clobber each other (see attached task).
