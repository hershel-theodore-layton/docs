Summary:
## Before this diff

Result is renamed to Result_ (causing lint errors)
Args is renames to Args_
Result is a suffix for internal structs
Args is a suffix for internal structs

## After this diff

All sites referring to generated Result_ is renamed to Result (fixed lint errors)
All sites referring to generated Args_ is renamed to Args
Internal Result suffix is now ResultDeprecated (this should not have been exposed in the first place)
Internal Args suffix is now ArgsDeprecated

## Why

We need to land this diff to:
1. unblock polyglot toolkit, as we are causing naming conflicts with their generated code
2. generate more go lint friendly structs and field names
3. make it harder to not find generated field names, because of underscores [users didn't expect](https://fb.workplace.com/groups/codegophers/permalink/25876487911973146/)
