Commit title: Optimize IsTypeStructure checks for primitives
Commit body:
Summary: There's no reason to generate a much more expensive `IsTypeStructC` bytecode when checking for primitive types that can be fully resolved at compile time. Instead we should directly emit the far cheaper `IsTypeC` bytecode. This is particularly important in sandboxes where type structures are re-resolved in every request.
