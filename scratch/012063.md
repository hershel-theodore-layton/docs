Commit body:
Summary:
`run.php` supports a matrix of configuration for tests. For a given `test.php`

- if `test.php.ini` exists, that is its config
  - otherwise: seek the nearest `config.ini`

in addition:

- if `test.php.opts` exists, these are passed as extra options
  - otherwise: seek the nearest `config.opts` and pass those as extra options.

In practice, people want to set some options for a directory and extend them with individual test-specific options, so they use a `config.ini` and a `test.php.opts` to make sure both are picked up. `config.opts` and `test.php.ini` are comparatively seldom used.

# Change

This diff breaks the replacement behavior of the `*.opts` files so that both `config.opts` and `test.php.oopts` are unconditionally read in sequence. It makes a best-effort attempt to migrate existing `config.ini` options to new `config.opts` files, clearing out the empty ones.

Follow up diffs will kill `.php.ini` files and iteratively eliminate `config.ini`, as some options need some manual work for translation.
