Commit title: Do not make hh_expect_equivalent an SDT function because it needs to check type precisely
Commit body:
Summary:
The pseudo-function `hh_expect_equivalent` is currently not very useful for validating our Sound Dynamic implementation. It's (implicitly) an SDT function, so will accept like-typed arguments, making it impossible to distinguish `hh_expect_equivalent<~int>` and `hh_expect_equivalent<int>`. So let's make it just `<<__NoAutoDynamic>>`.

One of our typed locals tests now has different behaviour under pessimisation, so I've just updated the expect file.
