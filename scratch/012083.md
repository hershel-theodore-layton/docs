Summary:
This diff makes the top-level `mock` module no longer accessible from the Rust "lib" crate. It remains accessible from the "clients" crate.

See https://fb.workplace.com/groups/rust.language/posts/25780668961555042.

After this diff, the codemod will proceed as follows:

1. The top-level `client` and `service` module will be eliminated from the "lib" crate in the same manner as D54403000. At this point, the "lib" crate and "types" crate will have identical contents.
2. Remove `-types` suffix from the Buck target name of the "types" crate. Add an alias with the `-types` suffix.
3. Eliminate `-types` suffix from TARGETS files in fbcode.
4. Delete the alias from step 2.

This achieves a state where client code only gets compiled if you explicitly depend on a Thrift clients target, and server code only gets compiled if you explicitly depend on a Thrift services target, unlike today where you always get both even though nothing ever wants both.
