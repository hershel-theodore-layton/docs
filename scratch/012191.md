Commit title: Support using BinaryPatch with vanilla binary field
Commit body:
Summary:
Before this diff, BinaryPatch only supports `assign(IOBuf)`. It doesn't support `assign(std::string)` (since `assign` field in `BinaryPatch` is defined as `IOBuf`).

Due to this, we can't use vanilla `binary` type when generating patch since the default binary type is `std::string`.

This diff fixed the issue by adding `assign(std::string)` override in binary patch.
