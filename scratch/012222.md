Commit body:
Summary:
When breaking up some of our functions, it became clear that we were using unexpanded internal / local types in recursive  calls.  This is almost certainly unintentional.

To have the minimal possible change, the previous steps in the refactor retained this behaviour. Here, we eliminate it and directly reconstruct the `internal_type` if it is needed in a recursive call. This ensures we always propagate the expanded type in recursive calls
