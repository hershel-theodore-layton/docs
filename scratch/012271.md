Commit title: HTTPTransaction support ::onError(NO_ERROR)
Commit body:
Summary:
When rx'ing a `RST_STREAM` w/ `NO_ERROR`, defer ingress `::onError()` callback if ingress EOM is queued

This is to support the following feature from http/2 RFC:

> A server can send a complete response prior to the client sending an entire request if the response does not depend on any portion of the request that has not been sent and received. When this is true, a server MAY request that the client abort transmission of a request without error by sending a RST_STREAM with an error code of NO_ERROR after sending a complete response (i.e., a frame with the END_STREAM flag set).
