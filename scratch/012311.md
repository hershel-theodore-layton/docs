Summary:
The old model was pretty garbage. I was starting a threadpool on each
web request. Now, I lazily create a threadpool as part of the extension and
pass a KeepAlive token to any function that needs to run work on the pool.

I was getting segfaults without adding the `moduleShutdown` code since the
threadpool was just hanging around in the background and work would end after
the process shut down.
