Commit title: Improve t_const_value API safety
Commit body:
Summary:
Make `t_const_value` safer:

* Turn it into a discriminated union so that invalid access can be caught by UBSAN instead of potentially causing silent data corruption. This also makes the implementation more efficient.

* Check invalid access in more places.

* Replace asserts on invalid access with exceptions.

* Replace a two-phase construction with `make_*` functions.

These additional and intentionally redundant layers of safeguards make it much more likely that a bug in the Thrift compiler will be turned into a compilation or runtime error than a silent data corruption.
