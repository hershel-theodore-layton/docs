Summary:
Currently the old workflow allows skipping patch for some structs.

This diff added such ability to the new workflow since sometimes we need to skip patch generation for incompatible structs. e.g., if we have

```
patch.GeneratePatchOnStructured
struct Foo { ... }

struct Bar { ... }
```

We will only generate FooPatch. We will not generate BarPatch.
