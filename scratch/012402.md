Commit title: Move priority field from CPUThreadPoolExecutor::CPUTask to ThreadPoolExecutor::Task
Commit body:
Summary:
Priority is an `Executor` concept, so we can push it down to `ThreadPoolExecutor` (even if it is `0` for executors other than `CPUThreadPoolExecutor`). This is used in the next diff to support a uniform task observer interface (where having access to the priority is useful).

In order to avoid bloating the `CPUTask` struct from the additional padding, also remove the `poison` field. We can reserve empty functions (by excluding them early in `add()`) as poison tasks.
