Commit title: require openssl version at least 1.1.0
Commit body:
Summary:
OpenSSL v1.1.0 was first released 2016-08-25, was last released 2019-09-10, and is supported until 2019-09-11: https://en.wikipedia.org/wiki/OpenSSL.

OpenSSL v1.1.1 LTS was first released in 2018 and was supported until 2023. The earliest still-supported version is OpenSSL v3.0.0 LTS, first released in 2021 and supported into 2026.

OpenSSL v1.1.0 lost FIPS 140 support but OpenSSL v3.0.0 LTS recovered FIPS 140-2 support.

OpenSSL v1.1.0 no longer requires initialization: https://manpages.debian.org/testing/libssl-doc/OPENSSL_init_ssl.3ssl.en.html. By requiring at minimum this version, we can remove all code around initializing OpenSSL.
