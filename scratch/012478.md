Summary:
Since `ServiceInterceptor` aims to replace functionality in both `TProcessorEventHandler` and `TServerEventHandler`, it makes sense to allow both forms of the "legacy" event handlers to be packaged into the same module to allow a smoother migration.

We also had to move `processedServiceDescription_.reset();` to `ThriftServer::cleanUp` so that server-scoped `TServerEventHandler`s don't get deleted before `postStop()` has a chance to be invoked.
