Commit title: rename ir::Constant -> Immediate
Commit body:
Summary:
ir and hhbc both have a type called Constant that represents different concepts:

A global or class constant decl:  `hhbc::Constant`, `ir::HackConstant`
An out-of-line immediate value for an instruction: `hhbc::Adata`, `ir::Constant`

To deconflict, rename `ir::Constant` to `ir::Immediate`, along with
various field names and parameter names (cid -> immid, constant -> imm, etc).
