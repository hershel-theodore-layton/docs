Summary:
This argument actually means the deps that's needed by Patch. e.g., if we have

```
patch.GeneratePatchNew
struct Foo { 1: foo_deps.MyStruct field; }
struct Bar { 1: bar_deps.MyStruct field; }
```

In this case we need to have `foo_deps` in deps, but `bar_deps` is not necessary (since we don't generate `BarPatch`). Renaming it for clarification.
