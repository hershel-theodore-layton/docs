Commit title: Parser: remove special-case node for VariadicParameter
Commit body:
Summary:
The full-fidelity parse tree has a cumbersome representation for variadic parameters declarations, using "decorated expressions" to represent named variadic parameters (but they're not expressions), and a special `VariadicParameter` node to represent legacy unnamed ones.

Better to add an `ellipsis` field to `ParameterDeclaration`.
