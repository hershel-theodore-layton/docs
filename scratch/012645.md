Commit title: Enable support for MuxIOThreadPoolExecutor::setNumThreads()
Commit body:
Summary:
`MuxIOThreadPoolExecutor:setNumThreads()` works as expected as long as we don't pass 0 as argument: that would cause the executor to deadlock because no thread is left driving the eventbases.

This diff disallows that case (and also the case of #threads > #evbs, as it is likely indicative of misconfiguration), and adds tests verifying the basic functionality.
