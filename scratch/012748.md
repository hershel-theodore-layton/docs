Commit title: split Param/DefaultValue
Commit body:
Summary:
Each param can have an optional DefaultValue, and the DefaultValue specifies
the function entry point to use to initialize missing default values at runtime.
ir and hhbc params are the same except for how they specify the entry point.

To unblock unification, factor DefaultValue out of Param, and express params
as Vec<(Param, Option<DefaultValue>)>.  In hhbc we use a new ParamEntry struct
with named fields to avoid tuples in the FFI.
