Commit title: Use ArrayKeyTypes by ArrayIterProfile
Commit body:
Summary:
When profiling iterators, we first reduce the 4 bit ArrayKeyTypes information
to 2 bits, losing potentially valuable information, such as Int|StaticStr.

Then we count how many times did we encounter each of these 4 possible values.

Finally, if only one of these values were seen, we pick that type, otherwise we
pick the most generic ArrayKey.

None of this complexity is required. Replace it with just keeping track of
the observed ArrayKeyTypes bits.

Improves the key type inference and brings us a step closer to be able to
handle tombstones in specialized loops.
