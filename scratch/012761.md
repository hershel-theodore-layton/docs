Commit body:
Summary:
The added doc block explains it well. After this diff `void` has a special meaning — it's effectively considered a zero-sized type.

As such, the callback passed to `allocate` does not require the user to return `T` if `T` is void. The rest of the changes are mostly dealing with the fact that `void` is incomplete — `sizeof`, `alignof`, invoking destructor etc.

Meta:
This will let us use `AllocationColocator` in `RequestsRegistry::DebugStub` where the ownership of objects is highly complex.
