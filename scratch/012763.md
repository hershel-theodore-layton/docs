Commit title: Allow customizing DebugStub + ResponseChannelRequest colocated memory allocation
Commit body:
Summary:
The new `colocateWithDebugStub` customization point in `RequestsRegistry::makeRequest` will let us colocate per-request storage for `ServiceInterceptor`s in the same allocation as `DebugStub` + `ResponseChannelRequest`.

This optimization saves a forced extra malloc in the hot request path, which would otherwise be unavoidable CPU overhead for services like memcache.
