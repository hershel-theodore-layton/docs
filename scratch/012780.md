Summary:
We are going to add buffer provider for ZC Rx. We should stop
adding buffer providers into anonymous namespaces of IoUringBackend.cpp as a
kitchen sink.

This change creates a class IoUringProvidedBufferRing that has a private
class ProvidedBuffersBuffer. Most of the existing buffer logic is kept intact.
We now pass io_uring ptr to the provided buffer ring in stead of a backend ptr as
only the io_uring ptr of the backend is needed, not the backend itself in the buffer
ring. Exception class LibUringCallError is added to throw when liburing call fails.
So in the IoUringBackend, it can still return NotAvailable exception when it catches
the LibUringCallError exception.

By bringing the buffer provider related code out of the anonymous namespace of
IoUringBackend.cpp, we could also add unit tests for the buffer provider directly (
No way to test code in anonymous namespace of a .cpp directly).

This paves way for us to add a new buffer provider for ZC Rx
