Commit title: Introduce `folly::getJEMallocMallctlArenasAll` function
Commit body:
Summary:
jemalloc memory allocator exports useful macros through its header
files, for example `MALLCTL_ARENAS_ALL`, but it is quite tricky to use them,
because jemalloc is not always enabled.

Function `folly::getJEMallocMallctlArenasAll` is a small helper to solve this
problem. There is no need to guard header include and code from the user code
anymore.

Usage example.

```
#include <folly/memory/Malloc.h>
#include <folly/memory/MallctlHelper.h>

if (folly::usingJEMalloc()) {
  static const std::string kCmd = fmt::format("arena.{}.purge",
      folly::getJEMallocMallctlArenasAll());
  folly::mallctlCall(kCmd.c_str());
}
```
