Commit title: Save read errors for later delivery.
Commit body:
Summary:
If we receive a readErr or readEOF from the transport, while we do not
have an application read callback installed, we would drop the error, and
provide a NOT_OPEN error when the application read callback is installed. By
saving the error for later delivery, we can provide a more correct error,
including potentially a graceful readEOF instead of a readErr.
