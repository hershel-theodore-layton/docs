Commit title: Add ability to list all thrift flags with current values
Commit body:
Summary:
Add ability to list **all thrift flags with their current values** using new `apache::thrift::getAllThriftFlags()` method.
This feature will enable logging snapshots of those values in Scuba & ODS, as well as displaying them in `ThriftDbg info` tool.

## Technical details:
Introducing `FlagRegistry` class which is responsible for holding type specific maps referring flag name to its related `FlagWrapper<T>`.

Flag registration is triggered only once per service lifetime, when it's underlying method, generated by `THRIFT_FLAG_DEFINE` macro, is called for the first time, which initializes the creation of static `FlagWrapper<T>` instance.

When `apache::thrift::getAllThriftFlags()` method is called each registered `FlagWrapper<T>` is used to retrieve current value of the thrift flag based on the underlying observer.
