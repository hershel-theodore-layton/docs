Summary:
thrift that puts adapted types in function parameter and return positions like for example the following,
```lang=thrift,
 rust.Adapter{name = "::fbthrift_adapters::UnsignedIntAdapter<>"}
 typedef i64 u64

 service Pred {
   u64 pred(1: u64 i);
}
```
has before now failed with build time errors for lack of serialization instances. in the example, those errors manifest in the form,
```lang=text,counterexample
error[E0277]: the trait bound `u64: Serialize<_>` is not satisfied
error[E0277]: the trait bound `u64: Deserialize<P>` is not satisfied
```
this diff arranges to fix this shortcoming and make thrift like the above valid.
