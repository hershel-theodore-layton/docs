Commit title: First (partial) implementation, using dataclasses
Commit body:
Summary:
Basic and partial implementation, using Python's `dataclass`.

Features:
* Creates a (data)class per thrift `struct`, with attributes for each field.
* Prevents inheriting from the generated (thrift) class.

Known limitations:
* Does not support adapted fields (will raise error)
* Does not honor default values (custom or otherwise) or qualifiers (`optional`, `required`, etc.): all fields are `None` by default.

Reminder: this is only enabled if the corresponding experimental flag is explicitly given to the thrift compiler
