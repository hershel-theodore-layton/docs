Commit title: Func::return_type -> Option<TypeInfo>
Commit body:
Summary:
hhbc::Body allows functions with no return type at all, but ir::Func requires a
return type. The bc_to_ir and ir_to_bc passes handled this by mapping None
to TypeInfo::EMPTY and back.

To unify ir and hhbbc, change ir::Func::return_type to Option<TypeInfo>.
now ir_to_bc, bc_to_ir, ir print, and ir assemble preserve the exact return type.
IR consumers like textual map None to TypeInfo::empty().
