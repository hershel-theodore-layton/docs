Commit title: Raise error on meth_caller for `internal` functions.
Commit body:
Summary:
### CONTEXT

Attempting to call a function pointer created from an internal function outside of the correct module will lead to a runtime error.  Simple repro:

```
<?hh

module A;

class C {
  internal function foo(): void { echo "I am foo\n"; }

  public function bar(): void {
    $f = meth_caller(C::class, 'foo');
    $c = new C();
    $f($c);
  }
}

<<__EntryPoint>>
function main(): void {
  (new C())->bar();
}
```

This is pretty bad, and all other similar cases of this (via protected/private) are forbidden.

### THIS DIFF

Let's forbid this one too.
