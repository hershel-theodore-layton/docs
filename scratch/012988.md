Commit title: Dispactch to top-level constraints from `Subtype_tell` and `Subtype_ask`
Commit body:
Summary:
The aim of this stack is to eliminate the use of `internal_type` in constraint simplification. `internal_type` was used to represent both subtype constraints and all our other top-level constraints and dispatched to the appropriate handler from `simplify_subtype_i`.

Inference / constraint solving has two modes: `tell`, where we assert a constraint must hold, and `ask`, where we check a constraint holds. This diff modifies the main `tell` and `ask` API helpers so that they dispatch constraints, encoded with `internal_type`, to the appropriate top-level handler rather than call `simplify_subtype_i`.

Since this is common code, it is added to the `Common` module.

The diff adds net positive code since we can't yet remove the dispatching code in `simplify_subtype_i`
