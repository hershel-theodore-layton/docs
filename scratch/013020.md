Commit title: avoid re-calculating get_package_for_module for error message
Commit body:
Summary:
We compute the package for a given module when determining visibility violations, and then again when generating error messages, for example:
https://www.internalfb.com/code/fbsource/[8aad03ea288664bf4313b3253aea34235346dc0e]/fbcode/hphp/hack/src/typing/typing_visibility.ml?lines=166-183
Not only can this introduce inconsistent error behavior (see comment), `get_package_for_module` can become a heavyweight function call as the size of package config increases. This diff aims to pass the same package information from error checking site to message creation.
