Summary:
All these functions now accept `thrift-python` `Struct` or `GeneratedError`. Rather than expand the `fused_type`, just removed it because it effectively duplicates the type-based dispatch in function body.

Note that the `from_header` and `with_header` fns aren't defined in `thrift.python.serializer` but it's ok because they only impact what the data looks like on the wire. They delegate to the `serialize_iobuf` / `deserialize` functions that are forward-compatible, so they are forward compatible themselves. If we ever get to delete `thrift.py3`, can move these into `python.serializer`.
