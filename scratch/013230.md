Commit title: Skip generated and abstract Funcs in HH\get_executable_lines
Commit body:
Summary:
`HH\get_executable_lines` is returns executable lines that correspond to compiler-generated code. Although it is not incorrect, it is confusing when looking at the executable lines alongside the source files. The known cases are interface methods signature, abstract methods signatures and generated initialisers (e.g. `86reifiedinit`).

Skipping generated Funcs takes care of the `86...` methods. Skipping abstract functions takes care of interface methods as well as classes' methods explicitly labeled as abstract.
