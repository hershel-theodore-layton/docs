Commit title: Permit variadic method to implement variadic abstract method with more non-variadic parameters
Commit body:
Summary:
The Hack type-checker allows a variadic method to implement a variadic interface/abstract method with "more" parameters, so long as the types are compatible. This is sound. Unfortunately HHVM rejects it, a legacy of PHP days. For example:
```
interface I {
  public function foo(int $first, int ...$rest):void;
}
class C {
  public function foo(int ...$all):void {
  }
}
```
