Commit title: Add utility for detecting BOLT AVX512 trap behavior
Commit body:
Summary:
The BOLT link optimizer utility has a mode to transmute functions using EVEX
prefixed instructions into UD2 traps.  Some binaries use this mechanism to
ensure they do not encounter AVX512 at runtime.  Unfortunately, BOLT is not
clever enough to detect runtime CPUID AVX512 tests and modify them to match
(i.e., mask AVX512 feature bits).  So we need some additional runtime detection
to avoid using AVX512 in this very weird environment.
