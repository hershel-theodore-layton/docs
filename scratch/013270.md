Commit title: Make thrift python check for None when doing struct comparisons
Commit body:
Summary:
Thrift python doesn't account for `None` when doing its comparisons between structs, which is different than how py3 works, which is just leveraging the thrift cpp2 comparison operator, which treats `None` as less than any set field.

I don't think we have any decided thrift behaviour for comparisons, but making thrift python behave more like thrift py3 is probably a good idea for now.
