Commit title: remove fused types from serializer
Commit body:
Summary:
Removing `cython.fused_type` from py3 serializer had a positive perf impact. I removed them because the type-based dispatch in the function definitions seemed to duplicate the `isinstance` checks in the function bodies. However, the impact was larger than expected.

Theory: `fused_type` combinatorially generates different function signatures for each possible type. Function dispatch at runtime prevents function inlining. In particular, calls to vanilla `serialize` and `deserialize` currently pay a double penalty because they immediately call impl functions that also use fused types in their signatures. This inlining effect appears to outweigh any type-based optimizations cython may do.
