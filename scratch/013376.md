Commit title: Ban type constant projection from generics
Commit body:
Summary:
This diff bans use of unsafe type projections (e.g., off of generics and abstract type constants) within where clauses.

Such productions were already banned in hints because they are unsound, but by introducing an extra generic parameter, this restriction can be worked around with a where clause which has the same problems.

Additionally, this pattern causes much sorrow in type inference leading to insucratable error messages.

We specifically detect and permit generated type parameters used for coeffects, e.g., `[$a::Ctx]` or `[T::Ctx]`, which provide polymorphism. dlreeves and vassilmladenov believes these uses are sound.
