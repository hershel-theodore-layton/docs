Commit title: Enable `JemallocHugePageAllocator` only when jemalloc is used
Commit body:
Summary:
`folly::JemallocHugePageAllocator` should work without explicit calls of
`default_init` or `init` (see comment inside `allocate` method), but we check
if we actually linked against jemalloc in `init`. When we linked against
different allocator and user code calls `JemallocHugePageAllocator::allocate`
right away, without calling `init` first we'll get a crash.

Moved `folly::usingJEMalloc()` call from constructor to
`folly::JemallocHugePageAllocator::hugePagesSupported` initializer to have a
correct value `hugePagesSupported` in any case.
