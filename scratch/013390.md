Commit title: Add tryGetEnumName() which returns an optional string_view
Commit body:
Summary:
The existing functions are
- `enumName()` which returns a `const char*` so anything that uses it will need to pay for the `strlen`, and need to handle the `nullptr` case, which is error-prone
- `enumNameSafe()` which always copies the name into a fresh `std::string`, which can cost an allocation.

The names are stored as `std::string_view`, so add a function that returns a `std::optional<std::string_view>`, which makes no copies, includes the length, and is harder to misuse.
