Commit title: disable optimisation in RequestContextQueue constructor
Commit body:
Summary:
Disable optimisation for the constructor of `RequestContextQueue`. This avoids a memory corruption bug that occurs with the Xcode 15 toolchain with boost versions 1.77 - 1.79 that caused S409219.

By disabling optimisation for the constructor we ensure that the set buckets are correctly initialized as empty. This workaround can be removed once we update to Xcode 16 or boost 1.80.
