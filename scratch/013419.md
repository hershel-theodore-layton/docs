Commit title: fix formatting of ApplicationErrorType, TransportErrorType
Commit body:
Summary:
A number of tests format  py3 `{Application,Transport}ErrorType`, so the py3 and python versions of these need to match. py3 uses `Enum` class, while python uses `cpdef enum`. Although cpdef enum is better in theory, it's worse in practice because it formats the enum arms to their integer value, which is less clear. For this reason, switching python to use the "old-school" style for better error messages.

Before:
```
f"{ApplicationErrorType.UNKNOWN}" -> "0"
```
After:
```
f"{ApplicationErrorType.UNKNOWN}" -> "ApplicationErrorType.UNKNOWN"
```
