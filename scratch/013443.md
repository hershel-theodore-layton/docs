Commit title: Fix '-Wimplicit-const-int-float-conversion' violation at fbcode/folly/ConcurrentSkipList-inl.h
Commit body:
Summary:
Use `folly::constexpr_clamp_cast<size_t>(sizeLimit)` to correctly cast `sizeLimit` from a `double` to a `size_t` per defintion of `folly::constexpr_clamp_cast`. That is if `sizeLimit` is greater than `std::numeric_limits<size_t>::max()` the value will be `std::numeric_limits<size_t>::max()`.

This fixes an UB when `sizeLimit` equals 18446744073709551616 (i.e., a value greater than `std::numeric_limits<size_t>::max()`) and `static_cast<size_t>(sizeLimit)` is called. The UB is called out in Section 7.3.11 Floating-integral conversions of the Standard for Programming
Language C++.

> If the value being converted is outside the range of values that can be represented, the behavior is undefined.

The compile warning happened when `kMaxSizeLimit` was being implicited converted from a `size_t` to a `double` in the `sizeLimit < kMaxSizeLimit` comparsion. This would change its value from 18446744073709551615 to 18446744073709551616.
