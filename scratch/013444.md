Commit title: let atomic_ref alignment restriction be runtime-enforced
Commit body:
Summary:
`PicoSpinLock` uses `make_atomic_ref`, which has the requirement that the type and its atomic reference have the same `sizeof` and `alignof`.

This assumption is not true on x86:
```lang=text
sizeof(unsigned long long): 8
sizeof(std::atomic<unsigned long long): 8
alignof(unsigned long long): 4
alignof(std::atomic<unsigned long long>): 8
```

See: https://godbolt.org/z/E87PrKq3r.

Change `atomic_ref` to match the behavior of `std::atomic_ref` by adding member `required_alignment` and declaring behavior undefined if the alignment of the provided object does not match `required_alignment`. In debug builds, check explicitly at runtime. This is a crashing logic error since there is no hope for the program if this precondition fails.
