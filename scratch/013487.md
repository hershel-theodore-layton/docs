Commit title: Fix broken walkstk for hhvm cores
Commit body:
Summary:
We fix the walkstk command which doesn't show HHVM frames specifically in
coredumps.

Underlying issue is a likely bug in lldb that returns incorrect ordering of the
`HPHP::ActRec` type when looked up from a frame via the `FindTypes` and
`FindFirstType()` APIs. We get a typedef'd type instead of the actual struct
type we want.

This diff fetches the correct type by iterating over all the found `ActRec` types
and picking the correct one and then using that instead.

We also switch from using `unsigned_cast(fp, $TYPE)` to `fp.Cast($TYPE)`
because the typecast SBValue returned by unsigned_cast is unable to actually
dereference and load the HHVM frame into the HPHP::ActRec struct when we need,
which is potentially another LLDB bug.
