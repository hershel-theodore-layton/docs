Commit title: Make ClassGraph more efficient
Commit body:
Summary:
Implement a few things to make ClassGraph more efficient:

- Restore the logic to not decode redundant subtrees of nodes. A large
  portion of an encoded ClassGraph is such redundant nodes.

- Add NodeSetIdx, which is like NodeSet, but more efficient because it
  uses compact indices.

- Break the auxiliary ClassGraph storage into two cases. One for nodes
  which we need child information and for ones we don't. Most
  operations don't require child information and we can cut down on
  the amount encoded by a large amount by dropping them. Add support
  for ClassGraph serialization for this case.
