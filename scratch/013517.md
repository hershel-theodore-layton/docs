Commit title: Refactor ThreadLocal walks and replace ThreadNodeEntry with Map<id, threadEntrySet>
Commit body:
Summary:
ThreadLocals' iteration during accessAllThreads() used a doubly linked list that stored ThreadNode* node, prev and next to walk through the ThreadLocalPointers on only active Thread Entries.

This was efficient in runtime compared to the original implementation but contributed to an increase in the memory footprint for ThreadLocals.

This approach trims out the extra memory by eliminating the use of doubly linked list and instead uses a Map<ElementId, Set<ThreadEntry *>>, which recoups 32 bytes of memory per ElementWrapper.

Additionally, ThreadNodeEntry node and circular lists were initialized for every index in the ThreadEntry::elements array; This meant if the the elements array was sparse, then there would be unnecessary ThreadNodeEntry nodes + would need addition indirection during ThreadLocal walk(accessAllThreads()). With this change, we do not create/add ThreadEntry* unless accessed and allocated. Eliminating unused ThreadNodeEntries and additional walk steps altogether.

I believe this will largely benefit services running many threads, have a high thread/threadlocal churn, use a lot of counters etc.
