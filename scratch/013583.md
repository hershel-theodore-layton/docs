Commit title: Fix case type handling for enums in hhbbc
Commit body:
Summary:
Case types can include enum types in their union. When resolving these types we can't assume that they will always be enums so do not set firstEnum for case types and instead validate that the enums contained within the union itself are valid types.

Also fix another bug where if any part of a case type is unresolved then all object types in the union must also be unresolved.
