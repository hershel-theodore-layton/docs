Commit title: make generated reflection pure python
Commit body:
Summary:
The reflection interface is pure python, and the generated reflection code doesn't do anything particularly "cythonic".

The only change here is instead of using some complicated C++ (`folly::Indestructible`) to create the default instance, we can just default instantiate a thrift-py3 object and use that for defaults :).

I don't claim this is optimal performance, but I suspect almost no one using reflection needs bleeding edge perf.

A pure python implementation unblocks supporting reflection in thrift-python to unblock auto-migrate.

This diff handles only types reflection, but it could just as easily be applied to the services reflection module.
