Commit title: Log DispatchCommand events directly to StructuredLogger
Commit body:
Summary:
Watchman only logs to the structured logger via a sampled logging "hook". It would be better to directly log structured events directly. Let's fix that.

This change includes creating a new DispatchCommand event, including buildinfo as a default field in all events, and plumbing through this event from where client events are dispatched. One of the fields, `args`, is represented as a JSON string - this required adding in a simple JSON to string converter.
