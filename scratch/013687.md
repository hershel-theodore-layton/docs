Commit title: Add more useful functions to Index in preparation of trace-scheduling
Commit body:
Summary:
- Store a constant's "kind" (whether it is a type or value) along with
  the ConstIndex in a class' flattened constant table. This lets us
  filter the constants without having to find all the classes which
  originally declared them.

- Add a "inTypeCns" flag. This flag is set to true when we're
  evaluating a type-constant. This is needed because dependencies
  within a type-constant's type-structure are sometimes treated
  differently.

- Add helper function to get all flattened class type-constants for a
  class (both declared and inherited). This differs from other getters
  that usually only provide the constants declared on the class.

- Add a quicker way to lookup a class type-constant if we already know
  it's ConstIndex.
