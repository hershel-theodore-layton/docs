Commit title: Break dependency between Decl_class and Decl_folded_class
Commit body:
Summary:
Decl_class is responsible for fetching type information for members from shallow decls, given a folded class.
It should not depend on the code that actually folds class, in Decl_folded_class.
Cutting the dependency will hopefully help zoncolan detangling, as they will likely need at least part of logic in Decl_class.

To break the dependency we:
* Move some functions from Decl_folded_class into Decl_class.
* Move other helpers from Decl_folded_class into new module Decl_members
