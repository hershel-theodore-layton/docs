Commit title: add enums to converter module
Commit body:
Summary:
While migrating an end user of this, I noticed it's a nice convenience that people can `cimport cMyStruct` from the `converter` module. It would feel weird if enums were excluded from this. There's no build size cost to adding them to `.pxd`. Negligible change in parsing time for those who cimport from it.

The next question is whether to generated `MyEnum_convert_to_cpp` etc. but I still want to avoid it to reduce build bloat. More efficient to do `<cMyEnum><int>` anyways.
