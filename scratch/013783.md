Summary:
This is sets up testing for the thrift py3 unit tests with the auto migrate flag enabled.

It accomplishes it by setting up a buck e2e test for each supplied python unittest which just runs `buck2 test [unittest] -c thrift.py3_auto_migrate=True`.

Not all the tests run successfully in auto migrate mode so I also created a util to flag those tests as expected failure specifically when running in auto migrate mode but run normally in normal mode. I haven't set up all the py3 unit tests but for now just releasing this with the types tests.
