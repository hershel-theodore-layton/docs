Commit title: Fix instruction compatibility wrt ExtraData
Commit body:
Summary:
Store elim did not check whether two instructions had a matching ExtraData for
the purpose of combining them.

This affected the StIterType instruction that stores the value based on the
ExtraData field, causing incompatible StIterTypes to be combined together,
affecting the future diffs.

There are other PureStore instructions that derive the value based on their
ExtraData, but they are either unique per destination (e.g. StFrameFunc), or
happened right before existing the translation (e.g. StArResumeAddr).
