- file.cpp: use a directive in place of each /* break intentionally missing */ comment
- log-writer.h: use [[fallthrough]] instead of "// Fallthrough" comment
- object-data.cpp: add a [[fallthrough]] directive in each case of arg-processing switch
- preg.cpp: add [[fallthrough]] from AccessorKind and SmartPtr to Kind::Empty case -- FIXME: please confirm this is ok
- preg.cpp: add a [[fallthrough]] statement from a Kind::Empty case to a Kind::Ptr
- repo-auth-type.cpp -- add [[fallthrough]] stmt in each of three case-expanding macros
- ssl-socket.cpp: use directive, not comment
- tv-arith.cpp: replace one comment, and add [[fallthrough]] in a surprising-to-me (I have never seen this before) "case"-within-"if"
- tv-conversions.cpp: use directive, not comment
- type-variant.cpp: add a [[fallthrough]] statement from a generic case into a more specific one
- variable-serializer.cpp: add explicit fallthrough -- FIXME: please confirm that preserving this existing behavior is correct
- variable-serializer.cpp: use directive, not comment
- zend-string.cpp: add fallthrough from "?" to "E" case -- FIXME: please confirm this is ok
