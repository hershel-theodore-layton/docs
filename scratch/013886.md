Commit title: Add option to crash on static analysis errors
Commit body:
Summary:
Create a dedicated `StaticAnalysisError` bytecode for unreachable code and a new `Eval.CrashOnStaticAnalysisError` option to control its behavior.

 1. When `false` this bytecode will fatal as before but will also bump a new `vm.static_analysis_errors` fb303 counter that can be used for push blocking alerting and improved monitoring.
 2. When `true` these bytecodes will induce assertions. In particular in repo mode the assert will come in the form of a `ud2` trap so that as much existing state from the executing translation can be preserved as possible. To avoid losing visibility into the associated Hack stack, these traps will create a fixup and the crash reporter has been augmented to decode these trap specific fixups.
