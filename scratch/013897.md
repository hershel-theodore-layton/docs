Commit title: add empty nodes to fix linker relocation overflow
Commit body:
Summary:
Previous diff to make `types_reflection.py` a `python_library` ended up causing linker relocation overflow errors. It turns out this is because the number of build graph nodes decreased below the eviction threshold, preventing eviction of the thrift-py3 extensions and thereby making the main linking group too large.

To fix this, we simply add an empty `.py` to `srcs` of `cython_library`, restoring the old eviction behavior.

This does not materially increase binary size. Building the `thrift/lib/py3/test/testing.thrift` `.so`s in `@//mode/opt`, the sizes are:
- `types.so`: 6.2M
- `types_fields.so`: 1.2M
- `types_empty.so`: 34K
