Summary:
Description:
With these changes (or similar), we are nearly able to enable -Wimplicit-fallthrough for all of hphp/.
See the sole exception mentioned in the test plan.
The vast majority of these changes ensconce existing behavior by adding [[fallthrough]], as warnings indicated.
In a few cases, for clarity, I added a semantics-preserving break or continue instead.
# Two "**real**" changes (happy to pull these or any other change out into separate diffs; just say the word):
- tc-print.cpp, where an unrecognized option (getopt returning '?') would be treated like use of a `-o` option and not diagnosed. Now, it elicits a usage diagnostic and exits nonzero. You may prefer to also diagnose the invalid option.
If so, let me know the syntax you'd like to use and I'll be happy to amend.
- irgen-minstr.cpp, which had very misleading case indentation and a missing "break;" which I've added
