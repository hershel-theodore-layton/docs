Commit title: Must include version before testing __cpp_lib_source_location
Commit body:
Summary:
Make sure we `#include <version>` before testing for `__cpp_lib_source_location`.

Without the `#include <version>` the `__lib_cpp_xxx` constants as not defined even though the feature may be present in the standard library. To make things worse, this is nondeterministic depending on whether the compilation units already included `<version>` from some other headers or not.

This was not catched for `__lib_cpp_source_location` because it was not enabled for llvm-fb 15 in the first place, until this mornings D56964040 where I enabled it somewhat by accident (and enabling this also disabled the `experimental/source_location` / `std::experimental::source_location` APIs at the same time)
