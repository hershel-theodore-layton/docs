Summary: The build for a `python_binary` assumes that two targets won't put modules with the same name in the same namespace. Since `thrift-py3` and `thrift-python` share the same `namespace py3`, we have to make sure their converter modules have different names. Therefore, the `python_capi-types-converter` target will output a `thrift_converter.pyx`, consistent with convention for other thrift-python files.
