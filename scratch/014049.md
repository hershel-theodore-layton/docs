# Context
{D41591914} fixed a reported bug where the type checker didn't give an error if the `$this` variable was referenced inside an enum class. That diff did not fix hackc, so when compiling a file that contains an enum class referencing `$this` panics would be issued later in the compiler pipeline.

These panics would be observable in tools like `php -l`.

# Mitigation
I added a check within `rust_parser_errors.rs` that checks if you are inside an enum class declaration and if so reports a parser error if `$this` is referenced. This required adding another field to the context.
