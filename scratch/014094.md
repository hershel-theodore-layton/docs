Commit title: Generate CaseType Test Cases
Commit body:
Summary:
To improve the test coverage of the union constraints that used to enforce case types, I generated a series of test that exhaustively test pairs of types. To do so I wrote a small OCaml program in `gen_case_type_tests.ml` that given a list of type specs generate test instances.

The test itself is quite large (over 25k lines), but gives us confidence in the correctness of the implementation that it doesn't throw an error or crash unexpectedly.

This has uncovered at least two cases where generated code can trigger assertion failures in either the JIT/Interpreter or HHBBC. There is also one case where the behavior triggers a fatal error when potentially we can fail more silently.
