Commit title: Ensure wangle::TransportInfo securityType is correct for StopTLS
Commit body:
Summary:
`wangle::TransportInfo` `securityType` should be a copy of the handshake layer's
security protocol by the time the application `onNewConnection` method is invoke.

This is the case for the normal OpenSSL handshake and FizzAcceptorHandshakeHelper.

Thrift adds another step for StopTLS handshakes, and StopTLS is implemented as a
separate transport with a unique security type, so this diff ensures that
`securityType` is still accurate.
