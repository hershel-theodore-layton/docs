Commit title: Optimise Exit environment handling
Commit body:
Summary:
On return, we move continuations to the `Exit` environment and various control-flow operations require `Exit` continuations to be consolidated.

I believe this is unnecessary most of the time except:
* in try-catch blocks because `finally` will need the environment at the point of `return`
* in lambda bodies because we check if type variables escape their scope

This diff optimises environment merging for the common case where we are outside a try-catch block or a lambda body.

It does so by simply dropping the `Next` continuation instead of stashing it in the `Exit` continuation and consequently doing away with all the environment unioning that happens due to control flow.
