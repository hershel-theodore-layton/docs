Commit title: Run full DCE between GVN and refineTmps
Commit body:
Summary:
Yes, it is valuable to run refineTmps after GVN. But it is catastrophic to do
so without a full DCE. GVN leaves a lot of dead Movs around and refineTmps
happily rewrites all references to the original SSATmp with the dst of these
Movs. This tends to create a lot of phis that do not get cleaned up if they are
part of cycles.
