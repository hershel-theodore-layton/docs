Summary:
`ServerSymbolDefinition.get_class_by_name` does more than what we need here.

```
let get_class_by_name ctx x =
  Naming_provider.get_type_path ctx x >>= fun fn ->
  Ide_parser_cache.with_ide_cache @@ fun () ->
  Ast_provider.find_class_in_file ctx fn x ~full:false
```

It fetches the class node from the Ast. For the purpose of getting a class kind,  it's better to use a `Decl_provider`.

Incidentally, this removes the last dependency to `ServerSymbolDefinition`.
