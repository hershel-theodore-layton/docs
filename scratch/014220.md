Summary:
`Sym_def.t` is defined as
```
type t = {
  kind: kind;
  name: string;
  full_name: string;
}
```
where `full_name` is equal to `name` for top-level types, and is of the form `container::member` for members.  Which is error prone and force clients to parse the full name. This diffs turn this into a algebraic type where the right structure is exposed for each of the kinds.
