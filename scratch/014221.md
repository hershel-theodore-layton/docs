Summary:
## What

When the LSP is in notebook mode (`hh_client lsp --notebook-mode`) and the notebook is stopped at a debugger breakpoint, don't show diagnostics for undefined variables (T185939988).

Such undefined variable diagnostics are often unhelpful when stopped at a breakpoint, because the runtime introduces variables that are not available statically (the notebook only sees notebook code + all WWW, not what's happening where the debugger is stopped).

## How

when ~/.vscode-sockets/hhvm-paused doesn't exist, we show undefined variable errors (as usual):

 {F1635040053}

when ~/.vscode-sockets/hhvm-paused exists, we suppress undefined variable errors:

{F1635040403}
