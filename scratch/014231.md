Commit title: fix large struct throws
Commit body:
Summary:
When serializing large thrift struct >= 2GB, thrift C++ impl throws  `TProtocolException`. The error handling of this is "correct" for `Extractor` (C++ from python) but is uncaught exception for `Constructor` (python from C++). We should catch it and convert to python.

Ideally it should be `thrift.python.ProtocolError` but that doesn't exist yet.
