Commit title: Fix exponentially many method names in get_method_names
Commit body:
Summary:
This is an old bug from D35955108.

The previous logic incorrectly did the equivalent of:

```
fn print_method_names(service) {
    for method in service {
        print(method.name);
    }
    while let Some(parent) = service.parent {
        print_method_names(parent);
        service = parent;
    }
}
```

as opposed to the intended:

```
fn print_method_names(service) {
    for method in service {
        print(method.name);
    }
    if let Some(parent) = service.parent {
        print_method_names(parent);
    }
}
```

The buggy code prints 2^N methods for an inheritance chain of N services containing 1 method each. The correct code prints N methods.
