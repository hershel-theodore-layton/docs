This mutation was what blocked D54435037 3 months ago:

https://www.internalfb.com/code/fbsource/[98408eabe13701d0d945c32c76aa97ca68e7533f]/fbcode/thrift/compiler/generate/mstch_objects.h?lines=561-568

Calling `{{#service:interactions}}` changes the meaning of `{{service:parent_service_name}}` and `{{service:parent_service_cpp_name}}`.

The `rust` and `cpp2` generators already had a better approach for parent service names in interactions without needing mutable state.

https://www.internalfb.com/code/fbsource/[98408eabe13701d0d945c32c76aa97ca68e7533f]/fbcode/thrift/compiler/generate/t_mstch_rust_generator.cc?lines=1063-1082

This diff switches the `python` and `py3` and `java` generators to use the Rust and C++ approach for interactions without mutation.

This unblocks being able to cache even more mstch methods to improve Thrift compiler performance (on the order of 34-47% according to D54435037).
