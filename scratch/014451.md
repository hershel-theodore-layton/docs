Commit title: Simplify TransparentRangeHash implementation
Commit body:
Summary:
Calling private stdlib functions to access the `const char*` hash function is not necessary anymore, since C++17 those are exposed with zero overhead by `std::hash<std::string_view>`, so we can switch to that.

Also split the `char` specialization from the generic implementation so it is self-evident that the function object cannot dispatch to different hash functions.

NOTE: On platforms that do not use libstdc++ or libc++ this changes the hash implementation for strings from `folly::hasher` to `std::hash`; this is likely desirable because the purpose of `TransparentRangeHash` is basically "`std::hash` + transparent lookup for strings".
