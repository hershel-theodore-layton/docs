Commit body:
Summary:
When adding upper / lower bounds to a type variable we generate the set of subtype constraints implied by the tansitivity of the subtype relation. Under extended-reasons we want to record these flows:

When adding an upper bound, we modify its reason to record the flow _from_ the type variable _into_ the upper bound, then use then use the updated reason in all constraints between the new upper bound and all existing lower bounds

When adding a lower bound, we modify its reason to record the flow _from_ the lower bound _into_ the type variable, then use the
update reason in constraints between the new lower bound and all existing upper bounds
