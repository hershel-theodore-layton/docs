Summary:
There are two changes made to PatchOp::EnsureStruct `extractMaskFromPatch`:

1. Change `insertMaskUnion` to `insertMaskIntersect` for `insertEnsureReadFieldsToMask` so that we don't have to read whole field when we ensure a field. We will only inject readMask if we have never included before.

2. Remove recursion in `insertEnsureWriteFieldsToMask` and put `writeMask` for top-level so that we can a field that is located in patch are not skipped during `parseObject`. This wasn't issue before since we blindly injected readMask for any field patch operations.
