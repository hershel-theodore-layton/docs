Summary:
Invoking a protected method on an interface can cause a fatal at runtime since the receiver might be a class that implements the interface that is unrelated from the class hierarchy of the caller (see test `protected_in_interface2.php` below).

This diff forbids invoking a protected method on a receiver that has an interface type.
