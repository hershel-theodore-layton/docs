Summary:
remove Flush call from header transport

There is no real Flush logic in socket
```
// for interface compatibility with Thrift1.
func (s *socket) Flush() error {
	return nil
}
```

We want to remove Flush from the Socket interface, so we can move closer to net.Conn

Unfortunately we have a BufferedTransport which is sometimes used with the HeaderProtocol, so we can't completely get rid of it. We added some tests to make sure this is not missed again in future.
