Commit title: Switch `TransparentRangeHash` hash to `folly::hash::MurmurHash`
Commit body:
Summary:
`TransparentRangeHash` for `F14` was using `std::_Hash_impl::hash`, but we can
try do it a bit faster.

`std::_Hash_impl::hash` is [re-implementation][1] of original
[`MurmurHash64A`][2] algorithm with [`seed = 0xc70f6907UL`][3].

By switching to `folly::hash::MurmurHash` we should get better inlineability
and constexpreness support (coming soon).
