Commit title: Enable ServiceInterceptor tests for HTTP2 except connection callbacks
Commit body:
Summary:
HTTP2 transport implementation is very different from Header or Rocket.
For example, HTTP2 transport recreates `Cpp2ConnContext` for each *request* (not connection), which means we cannot store persistent store in it.

HTTP2 is also missing several transport features (notably overload protection).
Most relevant to this diff is that HTTP2 is missing `TServerEventHandler` callbacks (`newConnection` / `connectionDestroyed`), which are the analogs to `ServiceInterceptor`'s `onConnection` / `onConnectionClosed`. Therefore, we are leaving these out of the `ServiceInterceptor` implementation as well.

Fixing these requires a much larger transport refactor.
