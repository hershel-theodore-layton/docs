Commit title: Require explicit truncating cast when constructing mstch::node from large integer type
Commit body:
Summary:
Previously, constructing a `mstch::node` from `int64_t` would silently truncate to `int`.

Since {D57946616}, it silently converts to `size_t` and then does a checked cast to `int`, throwing an error if the value is out of range.

After this diff, it won't compile. You must write a `static_cast<int>(…)` to make it clear at the call site that a truncation is taking place.

```lang=text,counterexample
fbcode/thrift/compiler/generate/t_mstch_rust_generator.cc:1659:12: error: conversion from 'int64_t' (aka 'long') to 'mstch::node' is ambiguous
    return const_value_->get_integer();
           ^~~~~~~~~~~~~~~~~~~~~~~~~~~

  /* implicit */ node(std::size_t i);
```
