Commit title: Use folly::exception_wrapper to save exceptions in ScopedServerThread
Commit body:
Summary:
`ScopedServerThread` has an allowlist of exceptions that it understands and can handle. However, with the help of `std::exception_ptr` and `folly::exception_wrapper`, we can automatically handle all exception types!

There is a subtle change in behavior here — exceptions previously unrecognized would become `std::exception` but now will be preserved. This class is primarily used in tests so should not be an issue in practice (if this case even pops up in the first place).

I also discovered that Thrift server's runtime does not call `TServerEventHandler::handleServerError` anywhere. The Haskell Thrift server seems to re-use the type so it can't be immediately removed but should be feasible with a small (but separate diff).
