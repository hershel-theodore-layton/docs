Commit title: Revisit allowTailReuse logic in IOBufQueue
Commit body:
Summary:
The original implementation of `maybeReuseTail()` was overly conservative, only allowing to reuse buffers that came from `preallocateSlow()`. This constraint is unnecessary, if ownership of a buffer is passed through `append()` and the buffer is not shared, the queue is the only owner, and so it can trim its tail.

Once we remove this constraint, the logic can be greatly simplified and moved entirely to the update guard, which is easier to reason about (remove the class invariants), and reduces code duplication.

Also expand the explanation a bit.
