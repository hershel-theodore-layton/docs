Commit title: derive Ord/Eq for structs with a map where possible
Commit body:
Summary: if a Thrift struct contains a `map`, we currently opt it out of deriving Ord/Eq, which makes for some confusing errors when one Thrift struct can be compared but another cannot. Rust derives `Eq` for `BTreeMap` if both the key and value derive `Eq`, so we can mimic the same logic in our Thrift codegen.
