Prototype LMDB facts backend.

ext_fbfacts installs a new concrete FactsFactory that creates a new FactsStore implementation based on LMDB.

Features
* eden.thrift file parallel directory walking with tokio
* localfs support parallelized file walking with rayon
* object-id lookaside memcache for batch formation
 (can walk www in 5-10sec with warm cache)
* watchman integration. gracefully handles full indexes
with batching & parallelism.
* full facts API support with LMDB backing store.
* multi-process safe, multithread safe
* no SymbolMap - lmdb is mmap based
* snapshot at the beginning (SATB) semantics
* data schema handles duplicate symbols gracefully.
FactsAPI can decide if they are errors or which file wins.
* modern async instead of folly semifuture spaghetti

Limitations
* RE integration added in subsequent diff because of BOLT chokes on some crypto dependency from re_client_lib
* no watchman subscription support
* not set up for saved states (but would be easy)
* SATB does not yet prevent tearing bugs since other code
paths (e.g. unit cache) still directly access filesystem.
