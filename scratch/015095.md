Commit title: Make JIT agree with VM for `is_a` [1/2]
Commit body:
Summary:
This is a split of D58073164 in two parts after its backout.

 ---

The JIT implementation of `is_a` and `is_subclass_of` does not honor the intrinsic's third argument (`$allow_string`), so it returns `true` in cases where the VM implementation would return `false`. This discrepancy didn't cause an issue because before `HH\classname_to_class`, there was no way to get a TCls value when jitting. It also didn't check for traits -- `is_a` returns false if either argument is a trait.

- Added missing traits check
- Added missing $allow_string check

Future work:

The __Native func forces the second argument to be a string, leading to unnecessary implicit conversions. Will expand it to the `classname` union and `spatch` the WWW callsites to get rid of the strings.
