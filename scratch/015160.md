Commit title: Let awaits in splices be concurrent
Commit body:
Summary:
Previously, an expression tree with splices (that contain awaits) lifted out the splices into a sequence of statements assigning to temporaries:
```
await (async () ==> {
  $0splice0 = exp0;
  $0splice1 = exp1;
  ...
  $0spliceN = expN;
  return expression_tree_expression_referring_to_$0splice_vars;
)();
```

This over sequentialises. Instead, do a parallel assignment and then the awaits in the exps can run concurrently.
```
await (async () ==> {
  list ($0splice0, $0splice1, ..., $0spliceN) = (exp0, exp1, ..., expN);
  return expression_tree_expression_referring_to_$0splice_vars;
)();
```
