Commit title: Improve completeness for like-pushing
Commit body:
Summary:
There are situations (see test) where the like-pushing subtype relation (e.g. `Box<~#0> <: ~Box<string>`) doesn't trigger, because the subtype logic doesn't see immediately that the type on the left is a dynamic-aware subtype of `dynamic` (e.g. there are unsolved type variables). In *some* of these cases, it's possible instead to proceed with the `t <:D dynamic /\ Box<~#0> <: Box<~string>`  proposition (after a successful call to `try_push_like`) but with a flag (`ignore_likes`) that is used to strip the like from the left-hand side of a subtype proposition.

(Note: really "like-pushing" boils down to the rule `t <: ~u` => `t <:D dynamic` and `strip_likes(t) <: strip_likes(u)` but we can't do something this crude because of unsolved type variables).
