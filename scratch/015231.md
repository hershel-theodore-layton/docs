Commit title: Use libc++ availability check for __cxa_init_primary_exception
Commit body:
Summary:
libc++ can be used in setups where the version of the headers doesn't
match the version of the standard library that'll be used at runtime
(e.g. when deploying to older Apple operating system versions), and it
provides availability macros for this purpose. Check the availability
macro for `__cxa_init_primary_exception` before using it so that it's
only called if it's guaranteed to be available at runtime.
