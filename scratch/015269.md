Commit body:
Summary:
Create an interface for instrumenting streams. This `StreamMetricCallback` has the following methods:

- onStreamNext(std::string_view methodName)
- onStreamError(std::string_view methodName)
- onStreamComplete(std::string_view methodName)
- onStreamCancel(std::string_view methodName)
- onStreamRequestN(std::string_view methodName, uint32_t credits)

`NoopStreamMetricCallback` is an implementation of the callback interface that does nothing.
