To further test the runtime implementation for case types I added an extra layer of indirection where I assigned a case type to a type alias and then reference the case type via the alias. This uncovered another assertion failure that can occur when one of the variants is an enum.

The assertion occurs when the test is run using `hphp/test/run -r`
