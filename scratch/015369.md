Commit title: Account for fork handling changes after D58906038.
Commit body:
Summary:
In the stacked refactor, we removed the need for reset() call on a ThreadLocal to hold
accessAllThreadsLock_. StaticMeta's fork handlers rely on locking
accessAllThreadsLock_ to ensure no thread could be manipulating a
ThreadEntrySet. Since that is changed, we need an alternate proof. Introduce an
explicit forkHandlerLock_ which is used to do this co-ordination. reset(),
release and accessAllThreads() calls acquire it in shared mode and fork
handlers acquire it in exclusive mode.
