Commit title: Explicitly encode inline asm dependency
Commit body:
Summary:
Explicitly encode the dependency on the sdt semaphore as an inline asm
constraint.  This exposes the use of the semaphore to the compiler rather than
relying on the used attribute retaining the variable.

Originally this diff used the new operand in the constraint:
https://godbolt.org/z/Ws5x78bbo
However this does not work with pic relocations:
https://godbolt.org/z/jTh87oYEz

For this reason we retain the explicit reference to the symbol, but also add the
constraint so the dependency is clear in the LLVM IR.
