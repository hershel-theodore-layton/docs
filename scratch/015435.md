Commit title: add new trait GetTypeNameType
Commit body:
Summary:
the aim is to improve the ergonomics of converting rust thrift types to thrift `Any`s.

as it is today, if `Foo` is a Thrift struct of `thrift_library(name = "foo")`, then, in order to use `icsp_any::serialize(&foo)` where (`foo: Foo`), the macro invocation `icsp_any::impl_get_thrift_any_type_struct!(Foo); ` must be injected into the `foo-rust` crate (via the `thrift_library`s `rust_include_srcs` attribute).

this diff defines a new trait `GetTypeName` and has the thrift compiler rust code generator define its instances.

then a blanket implementation of `GetThriftAnyType` in the `icsp_any` crate can be defined in terms of `GetTypeName` which renders the macros  `impl_get_thrift_any_type_struct` and `impl_get_thrift_any_type_union` (and all the associated `rust_include_srcs` for the macro invocations) unnecessary.
