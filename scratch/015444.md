Commit title: no config-time detection for sendmmsg, recvmmsg
Commit body:
Summary:
Linux and the BSD's have `sendmmsg` and `recvmmsg` while Microsoft and Apple do not. For now, we may directly encode this. We remove config-time detection.

The BSD's and Emscripten have slightly different signatures as compared with Linux and glibc. On FreeBSD, this difference in signatures shows up as the following compile error:
```
folly/net/NetOps.cpp:38:32: error: functions that differ only in their return type cannot be overloaded
extern "C" FOLLY_ATTR_WEAK int recvmmsg(
                           ~~~ ^
/usr/include/sys/socket.h:700:9: note: previous declaration is here
ssize_t recvmmsg(int, struct mmsghdr * __restrict, size_t, int,
~~~~~~~ ^
```

We switch strategies to requiring a declaration in an included system header on the given platforms, rather than attempting to copy all possible platform-specific declarations.

Fixes: https://github.com/facebook/folly/issues/2200.
