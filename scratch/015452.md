Commit title: avoid heavy lock contention for instanceof profiling
Commit body:
Summary: The tbb implementation of concurrent_hash_map doesn't scale well when many (100+) threads are running, causing the contentions. This moves the profile counter to within each `Class`, reusing the instance bitmask (before the bitmask is valid). This way, bumping counters are some atomic operations without holding tbb locks.
