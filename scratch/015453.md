Commit title: avoid heavy lock contention for property access profiling
Commit body:
Summary: Avoid changing values in the concurrent hash map, because such value changes can happen in many worker threads concurrently, causing heavy contention. Instead, store a pointer in a folly concurrent hash map, and we only access the hash map when generating profiling translations (instead of executing code). This shows effectiveness in reducing contention during profiling, and as a result we can profile more code in a short time.
