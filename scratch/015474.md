Commit title: Fix MSVC compiler issue with small_vector::insert()
Commit body:
Summary:
On Horizon Standalone Engine, we are seeing the following warning on MSVC only (not clang):
`xplat\folly\container\small_vector.h(915) : warning C4717: 'folly::small_vector<unsigned int,192,void>::insert': recursive on all control paths, function will cause runtime stack overflow`
(also we have warnings treated as errors turned on, so this breaks the build).

This seems to be an MSVC compiler bug where, when small_vector is used with an unsigned int, it calls the incorrect overload of `insert()`.  Adding `std::move()` corrects the issue.
