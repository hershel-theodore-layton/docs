Commit title: Include program checksum in hash calculations
Commit body:
Summary:
To catch the merging of schemas from different snapshots before they
result in data corruption, we include the checksum of the program contents in
the hash calculation for that program and all of its definitions.
This ensures the hashes are still stable across runs within a snapshot, but
will cause resolution to fail if multiple snapshots are combined.
