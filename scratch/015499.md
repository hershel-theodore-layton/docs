Summary:
Make the List__ types pure python to save some binary size and build time.

**__Context__**:
This is the first big step of 4 to remove most lines of generated cython from thrift-py3. [Doc here](https://docs.google.com/document/d/1a_t1FXVktpildN2CN9kHE6CmxU732PE-rJR75tCBgM8/edit?usp=sharing).

__Code Complexity__:
This reduces the complexity of generated cython. In the short-run, we take a hit on mustache template complexity, but we'll get all this back once all containers (Set, Map) follow the pattern from this diff.

__Suggested review order__:
Might be easiest to look at changes to `thrift/lib/py3/types.pyx` `List` first. Some refactoring to avoid any need for `cdef` methods in generated `List__` children.

__Improves cython cxx compilation time__

**13% faster**: for one infamous skynet target. The actual effect dependson how many `list<_>` a thrift IDL contains.

```
buck2 build @//mode/opt //nettools/skynet/if:skynet_structs_cross_db_apps-py3-types/SkynetStructs_CrossDbApps/types
```

Over the last week, buck2 spent 8683768s (2412 hr) waiting on this target: https://fburl.com/scuba/buck2_critical_path_actions/jtf1u7lw

In other words, buck2 is spending 60 weeks / week  waiting for this target to build. Therefore, this diff saves 12.8% = 7.7 compilation years / year. There is some complicated formula to weigh this for async builds, but we can simplify by just looking at user buck2 invocations:

321 invocations / wk * 222 second / invocation = 19.8 hours / wk saved => **0.5 EYS / yr for a single target**
https://fburl.com/scuba/buck2_critical_path_actions/lxutsb8j
