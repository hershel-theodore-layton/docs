Commit title: Add a helper for querying ELF hardware capabilities
Commit body:
Summary:
ELF platforms provide some indication of hardware capabilities via the auxilary vector (auxv).

Add a helper to query these capabilities at runtime, modelled after folly::CpuId, but explicitly multi-platform.

This helper is unsuitable for use on `x86-64`, as `glibc` massages the values presented to the point that they're unusable. On `x86-64` platforms you should continue to use `folly::CpuId`.
