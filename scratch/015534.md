Commit title: Use namespace instead of struct to hold program constants
Commit body:
Summary:
There are several pairs of files with the same filename and cpp2
namespace in the wild, which in the current codegen restricts them to at most
one of those files having constants as the containing struct would otherwise be
redefined. Instead, using a namespace causes the consts from the two files to
be merged and only has a redefinition error if the names of the consts also
match.
