Commit title: Merge emitBespokeUnsetM() into emitUnsetM()
Commit body:
Summary:
Bespoke handling of UnsetM is special. It tries to avoid calling emitUnsetM()
even for vanilla arrays, as the emitBespokeUnsetM() implementation is more
performant for vanilla arrays, but it doesn't always achieve that, especially
when bespoke arrays are turned off (e.g. in sandbox mode).

Merge these implementations and use the more performant one whenever we could.

The plan is to merge all emitBespokeFoo()s into emitFoos(), so add a note about
deprecation of the emitBespoke() mechanism.
