Commit body:
Summary:
Adds basic schema registry for accessing bundled schemas.
The API in this diff is intentionally not useful for production, as the public API will be designed and added in a later diff. For now we have minimal functionality for testing.

This involves the following changes:
- generates _sinit.cpp when schema generation is enabled to perform the registration
- adds program id to schema const name to enable looking up the schema const when there are multiple files with the same name (e.g. `common.thrift`)
- applies public visibility to generated constants (i.e. the schema) to enable breaking the dependency cycle between sinit and constants files using external linkage
