Commit title: Defer schema deserialization
Commit body:
Summary:
The hydrated schema structs can consume a large amount of memory in applications with many thrift files linked in.
To avoid imposing this cost on binaries that won't use the functionality we only store pointers to the serialized data during initialization.
The deserialization takes place on first access instead. (Applications can add an access near the start of main to avoid synchronization cost / blocking).
