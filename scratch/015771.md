Summary:
Add `folly::DtoaMode` and `folly::DtoaFlags` override fields inside of `folly::json::serialization_opts`.

This is a step in the multistep process to remove `double_conversion`. This step adds an override with folly types for json serialization. Another diff will update callers to use the shim type and eventually remove `double_conversion` entirely.

double-conversion is removed because 1/ it increases android .apk binary sizes by ~100KB due to the inclusion of its libdouble-conversion.so (T194496993) and 2/ there is equivalent functionality in the standard library that eliminates the need for this library.
