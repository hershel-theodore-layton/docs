Commit title: less indirection in StaticMeta::get
Commit body:
Summary:
`ThreadLocalPtr::get` and `ThreadLocal::get` wrap `StaticMeta::get`.

We cache the static-meta's per-thread capacity and a pointer to the thread-entry in a thread-local cache, which `StaticMeta::get` looks at in the fast path to find the requested item. We currently get a pointer to the thread-vector from the thread-entry, and then get the item from the thread-vector.

But this is an indirection which presumably adds latency to the overall operation.

If we cache the static-meta's per-thread thread-vector as well, we eliminate this indirection and reduce the latency.
