Commit title: Rename "BasicRPCConformance" to "RPCStatelessConformance"
Commit body:
Summary:
Internal :

For server conformance tests, `RPCConformanceService` uses 3 requests for every test case that requires server to store the state between the requests.

Hack servers cannot store state between the requests and hence have to combine the 3 requests into 1. `BasicRPCConformanceService` was added to run Hack server tests that only supported stateless basic rpc conformance tests.

Now that we have rocket support in hhvm, we need stateless service to also test other rpc types as well.

In next diffs, I'll add streaming test cases to this service so "Basic" is no longer an appropriate name. Since the set of tests run for any target are controlled by `suite_gens` anyways, renaming this service to "Stateless" as that's the main difference between `BasicRPCConformanceService` and `RPCConformanceService`
