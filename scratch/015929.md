Summary: By default, tracing uses UTC. Servers at meta use PST/PDT timestamps though and all other languages use the system time for timestamps in logs. This means that some systems rely on this fact, for example log filtering in the tupperware ui doesn't work if you aren't using the system time. This diff changes the logs to use localtime.
