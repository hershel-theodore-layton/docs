Summary:
This diff instruments the following:

- `"thrift.stream.<method_name>.on_next.count.60"` - number of stream chunks sent in the last minute
- `"thrift.stream.<method_name>.on_error.count.60"` - number of streams completed with an error in the last minute (doesn't include errors for the initial request, those will be added as separate counters in a separate diff)
- `"thrift.stream.<method_name>.on_complete.count.60"` - number of streams completed successfully in the last minute
- `"thrift.stream.<method_name>.on_cancel.count.60"` - number of streams cancelled by the client in the last minute
- `"thrift.stream.<method_name>.on_request_n.count.60"` - number of times client requested more payloads in the last minute (initial request counts as well)
- `"thrift.stream.<method_name>.on_request_n.sum.60"` - number of credits received from the client in the last minute (credits in the initial request are counted as well)

Currently, `RocketStreamClientCallback::streamMetricCallback_` is always `NoopStreamMetricCallback` so we don't actually create any Fb303 counters. That will be done gated behind a THRIFT_FLAG in D58415815.
