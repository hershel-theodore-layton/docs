All Fizz components now refer to the default factory as `fizz::DefaultFactory`,
which currently aliases to `OpenSSLFactory`.

`OpenSSLFactory` is a misnomer -- it is a factory that uses primitives from
multiple backends (libsodium, openssl, liboqs). Rename this accordingly to
`MultiBackendFactory`.
