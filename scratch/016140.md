Commit title: Optimize DecReleaseCheck
Commit body:
Summary:
Two changes:

1. We replace `DecReleaseCheck src br` with `DecRefNz src` when we know the refcount is at least 2. Additionally, we immediately append it with a `Jmp br` instruction. By doing this, we avoid a branch and allow canceling this instruction with a prior `IncRef`.

2. We add `DecRefData` extra data to DecReleaseCheck. DecRefNz instructions already contain/expect this extra data and use it for profiling purposes. On just the 1st change, I was hitting the following assertion error: "opcode DecRefNZ should have an ExtraData struct but ...". Adding extra data to DecReleaseCheck at its instantiation resolves this error.
