Commit title: Change Default Ticket Seeds Behavior
Commit body:
Summary:
Current behavior:
- when WDBs [setup TLS](https://www.internalfb.com/code/fbsource/[14402729e7b0bcb5d11c23791621fcffc8175cde]/fbcode/common/services/cpp/TLSBaseConfig.cpp?lines=228-230), they will end up using the default ticket file path. In [watchTicketPathForChange](https://www.internalfb.com/code/fbsource/[14402729e7b0bcb5d11c23791621fcffc8175cde]/fbcode/thrift/lib/cpp2/server/ThriftServer.cpp?lines=1850-1860), even if this file doesn’t exist, setTicketPathToWatch will still be called, and the ticket processor will watch this non-existent default file path. This is why so many WDBs are [logged as reading ticket seeds from FILE](https://fburl.com/scuba/thrift_connection_events/kdrafonz).

Ideal behavior
- We want WDBs to use in memory ticket seeds with rotation. Now we already [check if there is no ticket path to watch, we will use In memory seeds with rotation](https://www.internalfb.com/code/fbsource/fbcode/thrift/lib/cpp2/server/ThriftServer.cpp?lines=1863).

This change:
- We want to change the behavior to only watch a ticket path for change, if the file exists and a seed can be read from it during server setup. Otherwise we will use in memory seeds with rotation.
