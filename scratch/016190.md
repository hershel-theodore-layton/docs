Commit title: accelerate Range::operator==
Commit body:
Summary:
The compiler cannot automatically vectorize the loop in `operator==(Range, Range)` since it has to be careful of page boundaries. But the standard library is known to ship vectorized `memcmp` that can handle page boundaries. Use it when we can, which is effectively just integral and enumeration value-types.

We might have delegated to `operator==(basic_string_view, basic_string_view)` but: we would have to select only specific integral types (see `detail::range_is_char_type_v_`) and omit others (all 64-bit integral types) and we would have to omit enumeration types such as `std::byte`.
