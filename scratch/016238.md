Commit title: Remove path representation
Commit body:
Summary:
The path representation of a reason explain the subtype error in terms of directional flow. When using these flows to explain the problem, I often convert this back into an explanation containing:

1) An explanation of the subtyping derivation
2) An explanation of how the problematic type arrived at a term during typing

This diff is the first in a series which removes the 'path' representation and explanation in favor of this approach.
