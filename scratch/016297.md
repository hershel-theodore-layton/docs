Commit title: Fix boundary conditions in accelerated hashing
Commit body:
Summary:
The hashing accelerators, as implemented, can over-read by one 64-bit register, which is usually benign. However, when this happens and the data being hashed ends on a page boundary and the next page is inaccessible (or unmapped), we get a SEGV.

Move boundary checking around a little so that we avoid this extra read when it's unnecessary.
