Commit title: swap type parameter of ProtocolReader and Tag/T
Commit body:
Summary:
Since currently, we almost always want to default `ProtocolReader` to `BinaryProtocolReader`, we would like to swap type parameter `ProtocolReader` and `Tag`/`T` to make the use of API more ergonomic.

For example, instead of have to write
```
StructuredCursorReader<BinaryProtocolReader, type::infer_tag<SomeThriftType>>
```
We can just write
```
StructuredCursorReader<type::infer_tag<SomeThriftType>>
```
