Summary:
Add support for generics for classish types. At most one generic type per classish entity is generated.

Because adding a generic increases the branching factor of type generation, we reduce the max depth limit by one.

The expressions generated for class types (which are just `new` expressions) might explicitly emit type annotations to instantiate the generic.
