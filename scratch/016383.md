Commit title: split initialization of static fields and constants into separate methods
Commit body:
Summary: Split the static initializer `_86sinit` into two parts: `_86constinit` just initialises static constants, whilst `_86sinit` calls `_86constinit` and then initializes mutable fields. The reason for this is that we can then safely call `_86constinit` to ensure that constants are initialized prior to accessing static elements (because it's idempotent (ish)), while we take care not to call `_86sinit` more than once, so as to avoid overwriting any updates to mutable things that might have occurred.
