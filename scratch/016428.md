Commit title: Modernize function debug logging
Commit body:
Summary:
Our debug logging is hard to follow, it's just a list of function call, usually out of order, without information about the call hierarchy. This diff aims at fixing that by using indentation to signal what calls what, and by putting calls back in order.

This diff introduce function `Typing_log.log_function`:
```
(** [log_function pos ~function_name ~arguments ~result f]
  write to output something like

    File "file.php", line 16, characters 10-13:[4]
      <function_name>
        <arg1>: <value1>
        <arg2>: <value2>
          <any logging produced by f, indented>
        <function_name result>: <result>
  *)
val log_function :
  Pos_or_decl.t ->
  function_name:string ->
  arguments:(string * string) list ->
  result:('a -> string option) ->
  (unit -> 'a) ->
  'a
```
We also rewrite a lot of logging functions to use `log_function`.
