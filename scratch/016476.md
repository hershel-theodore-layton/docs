Commit title: Simplify eligible loads and store to loadpair and storepair
Commit body:
Summary:
Loads and stores of 32bit and 64bit values can be folded into a load pair or store pair instruction given that they are:
1. Aligned to their register size and;
2. Adjacent in memory based on their register size and;
3. Loaded by/store to an immediate offset from the same register and;
4. Load/store to/from different registers and;
5. Operate on registers of the same width and;
6. Their immediate offset would fit into the range for the corresponding pair operation.

The loads that can be folded in this way are:
1. *Load Register (unscaled)* (`ldur`) - https://developer.arm.com/documentation/ddi0596/2020-12/Base-Instructions/LDUR--Load-Register--unscaled--
2. *Load Register (immediate)* (Unsigned offset) (`ldr`) - https://developer.arm.com/documentation/ddi0596/2020-12/Base-Instructions/LDR--immediate---Load-Register--immediate--

These loads could potentially be folded into *Load Pair of Registers* (`ldp`) - https://developer.arm.com/documentation/ddi0596/2020-12/Base-Instructions/LDP--Load-Pair-of-Registers-

The stores that can be folded this way are:
1. *Store Register (unscaled)( (`stur`) - https://developer.arm.com/documentation/ddi0596/2020-12/Base-Instructions/STUR--Store-Register--unscaled--
2. *Store Register (immediate)* (Unsigned offset) (`str`) - https://developer.arm.com/documentation/ddi0596/2020-12/Base-Instructions/STR--immediate---Store-Register--immediate--

These stores could potentially be folded into *Store Pair of Registers* (`stp`) - https://developer.arm.com/documentation/ddi0596/2020-12/Base-Instructions/STP--Store-Pair-of-Registers-

This simplification is valuable as a sequence of adjacent loads and stores is very common when setting up a frame.
