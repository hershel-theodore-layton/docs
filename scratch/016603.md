Commit title: Hack warnings: filter preexisting warnings before streaming errors
Commit body:
Summary:
For hack warnings, we want to filter out pre-existing warnings. These are stored in the warnings saved state `Warning_saved_state.t`.
So far, we were filtering those out in `ServerTypeCheck`, at the end of each typecheck. However, with error streaming, errors are dumped to the `errors.bin` file at the end of each worker batch, which means they were sent unfiltered to the LSP and any other error-streaming client.

This diff fixes that by filtering errors just before sending them to `errors.bin`. That means wiring down the `Warnings_saved_state.t` a bit further down the call stack.
