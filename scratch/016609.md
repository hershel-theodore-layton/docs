Commit title: Show type arguments in hover
Commit body:
Summary:
Currently, if you hover over a call to a generic function or method, you are shown the generic parameters in the function signature, and the types in the signature have the generic parameters instantiated with actual type arguments. For example, hovering over the call to `make_pair` below
```
function makepair<T1,T2>(T1 $x, T2 $y): (T1, T2) { ... }

make_pair(3,"A")
^
```
will show
```
function makepair<T1,T2>(int $x, string $y): (int,string)
```
This is confusing. In future, we'd like to show (1) the generic signature and (2) what Hack has inferred for the type arguments. This diff does (2), so we get
```
function makepair<T1,T2>(int $x, string $y): (int,string) where T1 = int, T2 = string
```
We do the same for function pointers to generic functions: currently, Hack infers an instantiation at the point the function pointer is created.
