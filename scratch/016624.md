We already unified fbcode and xplat Thrift runtime library targets for C++ and Java, now do the same for py3. To this end:

* Add `thrift_cython_library` that handles differences between xplat and fbcode.
* Add proper xplat support to `thrift_python_library`.
* Reduce the scope of the stream hack by moving it from the build config to the source code where we can reuse existing conditional compilation logic.

This improves consistency between fbcode and xplat and removes a bunch of manually maintained and incomplete xplat targets.
