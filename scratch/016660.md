Commit title: Make whisker::ast::variable a separate node type from whisker::ast::variable_lookup
Commit body:
Summary:
`ast::variable` presents a top-level `{{ foo.bar }}` in a template. It contains `ast::variable_lookup` (`foo.bar`).

`variable_lookup` is reused for `section_block`. For example, `{{#foo.bar}} ...`, `foo.bar` is a `variable_lookup`.

This matches our grammar description and allows distinguishing them in `print_ast`.
