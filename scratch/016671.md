Commit title: Hand shapes, tuples, and tag predicates in separate methods in Typing_refinement
Commit body:
Summary:
Currently the `Typing_refinement.split_ty` function handles splitting for `IsShapeOf`, `IsTupelOf` and `IsTag` all within the same function. This makes the code harder to reason about and extend for some future changes I want to make (such as combining predicates using logical operators like `And`, `Or`, `Not`. See D61490440).

To alleviate this I break out the logic into three functions, `split_ty_by_shape`, `split_ty_by_typle` and `split_ty_by_tag` respectively. This also makes it clearer to explain where we lose precision and need to generate spans. I have future changes planned that will allow us to more precisely reason about these cases.
