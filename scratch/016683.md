Commit title: Split Operation into two classes
Commit body:
Summary:
The Operation class combined both the user facing API (`run()`, `wait()`, etc.) with the implementation details of the MySQL protocol.  In order to add another protocol option we need to abstract the implementation details away.

In order to achieve this the Operation class is split into an Operation and an OperationImpl.
