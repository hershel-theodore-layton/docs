Commit title: Fix handling of binary in the compiler
Commit body:
Summary:
Make the `binary` type reported as `"binary"` instead of `"string"`, fixing an old piece of tech debt in AST and a TODO.

In particular this fixes diagnostics:

```
const binary b1 = 42;
```
Before:
```
... error: integer is incompatible with `string`
```
After:
```
... error: integer is incompatible with `binary`
```

Changing `string` to `binary` affects `STRUCTURAL_ID` in Hack but it should be OK.

Rename `check_const_rec` to `check_initializer` and clarify what it does in a comment.

Reduce the public API surface by moving initializer checks to the `detail` namespace.

Merge initializer checks into the standard validator target since it's just an implementation detail split into a separate file to keep things more manageable.

Replace misleading "custom_default" term with "initializer" since it is a const or field initializer: https://github.com/facebook/fbthrift/blob/main/thrift/doc/idl/index.md#constants.
