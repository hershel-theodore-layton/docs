Summary:
T176105713 (Migrate Thrift Python to ResourcePools) will enable resource pools for python servers. Per the [Resource Pools | Thrift](https://www.internalfb.com/intern/staticdocs/thrift/docs/fb/server/resource-pools/) documentation, the documented way to enable resource pools is to call `requireResourcePools()` on the server before it starts. From code inspection and experiments, this works as long as the server implements metadata.

Python ThriftServer uses py3 ThriftServer as a base. Through happenstance, py3 servers already use resource pools in production. py3 servers use cpp2 AsyncProcessorFactory, which implements metadata. They are, therefore, a valid candidate to use `requireResourcePools()`.
