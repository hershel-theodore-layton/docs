Summary:
This change captures changes made while trying to better understand the TableBasedSerializer logic, in order to add serialization support to upcoming thrift-python mutable unions.

In particular, while trying to follow the logic, I found the many `void*` arguments confusing, as they actually corresponded to different concepts depending on the method (eg. the "target object" passed to the root `read()` or `write()` method, vs the pointer to the base of the contiguous area of memory holding all field values, vs. the memory corresponding to a single thrift value).

Changes below do not affect externally-visible behavior in any way (even "visible" changes such as method renaming were only on methods that are not used outside of thrift code - as far as our code search tooling indicates).
