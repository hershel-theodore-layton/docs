Commit title: Improve diagnostics for initializers
Commit body:
Summary:
Include the name of the innermost named entity and mention initialization in diagnostics for initializers.

Thrift code:
```
 struct S {}
 const S s2 = 42;
```

Before:
```
integer is incompatible with `S`
```

After:

```
cannot convert from integer to `S` in initialization of `s2`
```
which is much more user-friendly.

Fix other misleading and inconsistent diagnostics. For example:

```
Annot{val="hi", otherVal=5, structField=G{}}
```

previously gave:
```
type error: const `.val` was declared as i32
```

Here `val` is not a const but a field name.

Now we give much better error:

```
cannot convert string to `i32` in initialization of `val`
```
