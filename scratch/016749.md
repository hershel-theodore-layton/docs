Commit title: Fix undefined behavior in DEFINE_UNION_STATIC_CONST*
Commit body:
Summary:
Placement new into a const object is undefined behavior [1]. Building
with `-fno-c++-static-destructors` causes Clang to place the object in
read-only memory (because of the `const`), and then the placement new
crashes with an access error. We can make the member instead of the
object const to maintain constness while avoiding UB.

[1] https://en.cppreference.com/w/cpp/language/lifetime#Storage_reuse
