Commit title: Fix name of aarch64 fp mapped register name
Commit body:
Summary:
LLDB doesn't use `x29` as the name of the ARM fp register (usually [aliased](https://learn.microsoft.com/en-us/cpp/build/arm64-windows-abi-conventions?view=msvc-170#integer-registers)) ([lldb code](https://github.com/llvm/llvm-project/blob/main/lldb/source/Plugins/Process/Utility/lldb-arm64-register-enums.h)). Instead, it's just `fp`.

e.g.
x86:
```
>>> lldb.frame.register["rbp"]
(unsigned long) rbp = 0x0000010005bbab20
>>> lldb.frame.register["rsp"]
(unsigned long) rsp = 0x00007f13fd57a6d0
>>> lldb.frame.register["rip"]
(unsigned long) rip = 0x000000001f6cda34
```

aarch64:
```
>>> lldb.frame.register["fp"]
(unsigned long) fp = 0x0000ffef16fb6e80
>>> lldb.frame.register["sp"]
(unsigned long) sp = 0x0000ffef16fb6e80
>>> lldb.frame.register["pc"]
(unsigned long) pc = 0x0000fffdad9d8440
```
