Commit title: Implement whisker::object
Commit body:
Summary:
This diff adds `whisker::object` — *the* type representing any possible value in the Whisker templating language. The doc block for `whisker::object` and other comments within `object.h` explains much of the details.

The `native_object` type is currently incomplete. The plan in future diffs is to add functions like `lookup_property` etc. when we start building the Whisker evaluation engine.

The `native_object` is necessary not only for glueing with C++ code but also enables us to shim existing `mstch::object` hierarchy into the Whisker templating engine. This will let us slowly migrate our existing generator code in C++ without boiling the ocean.
