Commit title: Improve handling of void
Commit body:
Summary:
Initialization checks are a wrong place to try reporting misused `void` because most types occur in contexts where there are no initializers. Moreover, the current check is useless because we actually don't allow `void` to be used as a data type in the parser.

Fix this by removing the broken check and reporting a nicer recoverable error on using `void` as a data type.

Thrift:
```
const void v = 42;
```

Before:
```
expected type
```

After:
```
cannot use `void` as a data type
```

Make primitive type switches exhaustive while at it.
