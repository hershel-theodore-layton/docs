Commit title: Replace use of php array typehint with hack arrays.
Commit body:
Summary:
PHP arrays were initially supported due to legacy reasons, but they have since become a source of complexity in our code generator. With the completion of the Hack Array Migration by the Hack language team, PHP arrays are now effectively an alias to Hack arrays. By removing references to PHP arrays and the associated compiler options, we can significantly simplify our codegen and avoid issues similar to the one described here.

In addition, it could help speed up the codegen by eliminating numerous conditional code generation

Why should we do this?
Reduce tech debt, improved developer experience

Implementation Details
Step 1: Replace use of php array typehint with hack arrays

Darray/varray are type alias for dict/vec. Replacing typehints should be a safe change and should not result in hack errors.
