Commit title: Support interactions in PreLBSRProxyRouteHandle
Commit body:
Summary:
Add support for interactions in modern SRProxy API which uses PreLBSRProxyRouteHandle. Only transparent proxy is supported, conditional proxy is not supported. SRProxy fallback feature is also not supported with interactions.

## Request flow
**Success case:**
1. All original requests are queued in InteractionLeaseRouteHandle
2. First request that is lease owner goes through
3. First request is copied into a proxy request
4. Proxy request skips InteractionLeaseRouteHandle and attempts to establish connection
5. If connection is successful, lease is fulfilled and all subsequent requests are allowed to continue processing
6. Each of them goes through PreLBSRProxyRouteHandle and gets converted to a proxy request
7. These proxy requests skip interaction lease

**Failure case:**
1. All original requests are queued in InteractionLeaseRouteHandle
2. First request that is lease owner goes through
3. First request is copied into a proxy request
4. Proxy request skips InteractionLeaseRouteHandle and attempts to establish connection
5. If connection is NOT successful, lease is fulfilled when response reaches InteractionLeaseRouteHandle again with a null connection
6. All subsequent requests fail with UNKNOWN_INTERACTION_ID
