Commit title: Include standalone partial application information in the AST
Commit body:
Summary:
The renderer needs to know about standalone partial tags because it affects indentation. For example, given a multi-line partial:
```
First line
Second line
```

Consider the following application:
```
    {{> partial}}

foo {{> partial}}
```

The output is:
```
    First line
    Second line
foo First line
Second line
```
