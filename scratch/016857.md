Commit title: Fix the py3 auto migrate tests
Commit body:
Summary:
D61372546 broke these tests when running in auto_migrate mode, as the old buck config mechanism of enabling auto migrate tests no longer exists, and I forgot to fix the tests.

Rejigging the tests by moving the files into `thrift/lib/py3/test/auto_migrate`, and setting up 2 sets of unit test targets, 1 in `thrift/lib/py3/test` that run without auto_migrate and another in `thrift/lib/py3/test/auto_migrate` that run with auto migrate.

To avoid having to do too much copy/pasting I switched all of the tests to `python_library` macros, and then created a new buck macro `gen_py3_unit_tests` that takes in all the test libraries and generates a `python_test_matrix` per test, which runs as usual.

This has the added bonus of running the auto_migrate unit tests as a normal test, rather than the buck2 e2e test jank that existed before, so successes and failures show up as normal.
