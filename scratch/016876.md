Commit title: Hack warnings: filter pre-existing warnings for opened files in IDE
Commit body:
Summary:
Serverless IDE will typecheck the buffer for an opened and edited files. It does this without interacting with hh_server, by calling into `Tast_provider.compute_tast_and_errors_(un)quarantined`. So far, that path would not filter out pre-existing warnings. With this diff, this is fixed.

We filter out warnings within `Tast_provider`, forcing callers to provide an optional `Warnings_saved_state.t` to the API. That way, we ensure filtering for all paths.

Then to provide the warnings saved state from the IDE client, we need to obtain the warnings saved state from somewhere. Luckily, there's already a lot of code to obtain the naming table, so we proceed in a similar fashion. This code is mostly located in ClientIdeInit. It tries to get the naming table path first from any CLI option, then from disk, otherwise from Manifold. We add minimal code there to also return a warnings saved state.
