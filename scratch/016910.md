Summary:
The renderer needs to know about standalone partial tags because it affects indentation. For example, given a multi-line partial:
```
First line
Second line
```

Consider the following application:
```
    {{> partial}}

foo {{> partial}}
```

The output is:
```
    First line
    Second line
foo First line
Second line
```

[Handlebars playground link](https://fburl.com/2yapmzzr).

This diff adds line offset which is needed to indent non-standalone partial applications which have multiple lines.
