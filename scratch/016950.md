Commit body:
Summary:
If a shallow `RequestContext` copy is done concurrently with mutations, we need to synchronize with the mutating thread to get a self-consistent state snapshot.

The race was root-caused by Gownta.

Shallow context copies are not in hot paths, so acquiring an uncontended read lock should have negligible cost, and we don't need more sophisticated solutions.
