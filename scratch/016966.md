Commit body:
Summary:
The thrift team is getting rid of [thrift py3 reflection](https://www.internalfb.com/intern/wiki/Thrift-py3/User_Guide/Advanced_Usage/Reflection/), and one of the first things to go is going to be the ability to perform reflection on thrift clients/services, so migrating this file away from them.

`windtunnel/cogwheel/fuzzing/utils.py` is straightforward, it just reads method names, so this can be easily replaced with [thrift py3 metadata](https://www.internalfb.com/intern/wiki/Thrift-py3/User_Guide/Advanced_Usage/Metadata/).

`windtunnel/cogwheel/fuzzing/service_introspection.py` is far more complicated, but there's an existing solution for thrift python objects (which don't define reflection data) that leverages thrift metadata instead, so re-using that implementation for thrift py3. Notably the thrift python implementation doesn't implement fuzzing, so I had to go ahead and rework `type_inspect.py`, which is built on reflection. I changed that to use metadata so all the old functionality still works fine.
