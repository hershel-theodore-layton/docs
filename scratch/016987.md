Commit title: Speculate ldCls to optimize consumers of Class* from stack.
Commit body:
Summary:
Was trying to figure out how to optimize `FCallClsMethodM` and found that since `FCallClsMethodM` gets its class from the stack, we need to make sure the class `SSATmp*` we get from the stack is a constant (even if its being speculated).

Optimize `ldCls` to speculate, so consumers of these values on the stack can be optimized.

Followups:
- Allow jit to load classes: I saw an example in call-soft-1.php where if we remove the call to `new A()`, the speculation does not happen since the jit doesn't have a candidate `Class*`. Need to do this

Questions:

Can we not guard on exact values? I thought we sometimes did this for exact classes? ie `DataTypeSpecialized`
