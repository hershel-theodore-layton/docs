Summary:
Currently we're using `source_manager` + `resolved_location` in parser to figure out the column offset of a standalone partial application.

This is buggy because we don't preserve whitespace correctly. For example, `\t` ends up as `<space>` in multi-line partial offsets. This diff fixes that by encoding the actual whitespace string into the ast.
