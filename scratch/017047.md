Commit title: Have FizzServerContext::getCert check for an unconfigured CertManager
Commit body:
Summary:
ServerProtocol invokes `context.getCert(...)`, which unconditionally
performs an unchecked dereference of `certManager_->getCert(..)`.

However, nowhere does FizzServerContext establish the invariant that `certManager_`
is non-nullptr. By default, FizzServerContext does not create a CertManager
instance (otherwise it would be a wasted allocation since the user would have
to override it with another certificate manager).

Since `getCert(..)` is part of FizzServerContext's public interface, and
because the class itself never establishes that `certManager_ != nullptr`, we
must handle these conditions within the implementation of `getCert(..)` itself.

Otherwise, a misconfiguration by not setting a CertManager before attempting
to use FizzServer will lead to UB.
