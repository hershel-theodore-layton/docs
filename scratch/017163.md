Summary:
As title. Some interesting semantics:
1. If the mask for data within Any evaluates to NoneMask (i.e. type mismatch OR noneMask is specified), a default initialized any is returned.
2. In dynamic patch, an empty object is used to simulate default initialized any.
3. If a non-NoneMask is specified for the data within Any, regardless of whether anything is filtered, the Any retains its type.
