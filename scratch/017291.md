Commit title: Use instantiated types for signature help
Commit body:
Summary:
As the title says. Unlike normal hover, which uses instantiated types from the TAST, signature help just shows the full generic signature from the decls. This is particularly bad when there are type refinements and lots of generics, and gives the user no clue about the actual types expected for the arguments e.g. after a label argument has been supplied.

Using the TAST rather than the NAST also offers an opportunity to substantially clean up the code.
