Commit title: Allow to use HH_IGNORE to silence warnings instead of HH_FIXME
Commit body:
Summary:
Using HH_FIXME to silence errors is not satisfactory for multiple reasons:
* The user usually wants to mark a warning as "please ignore I know what I'm doing" rather than "fix this later". HH_IGNORE conveys that intention better.
* We don't want users to get into the habit of adding HH_FIXMEs and think it's a fine common thing to do.

Therefore this diff requires HH_IGNORE to suppress warnings instead of HH_FIXME. If the user attempts using HH_FIXME, they'll get an error requiring them to use HH_IGNORE instead. We also check that HH_IGNORE can only be applied to warning codes.
