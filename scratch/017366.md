Commit title: Do not show superfluous generic parameters to functions in hover
Commit body:
Summary: Function types as stored in `Call` nodes in the TAST are *instantiated* i.e. generic parameters have been replaced by generic arguments. However, the `ft_tparams` field is not removed; it is still used in some TAST checks. But for hover, it's confusing to see the generic parameters when there are no occurrences in the signature, so to improve the user experience we can remove them before the user sees them in hover and signature help.
