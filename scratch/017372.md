Commit title: align __eq__ operator with thrift-python
Commit body:
Summary:
The current behavior (`return False`) on type mismatch in `__eq__` is misleading and causes bugs in user code. `thrift-python` and `thrift-py-deprecated` both have different behaviors from `thrift-py3`, in that they allow the opposite behavior where an `int` comparison is used.

This diff switches thrift-py3 to behave same as thrift-python, which is what users have come to expect. Silently returning `False` on equivalent enums is not pleasant. I've fixed all known bugs related to this (see dependencies).
