Arena's alignment configuration restriction is overly strict, in that it only allows for alignments `<= sizeof(Arena::Block)` (8 bytes).
This disallows setting the alignment to e.g. 16 bytes, which is often a requirement for 128 bit SIMD instructions.

Just remove the maximum bound check.
