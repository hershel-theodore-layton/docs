Summary:
When we received a request, we call `deserializeMessageBegin` to extract some metadata.

After some checks, we try to trim the remaining bytes before cloning the corresponding buffer in to a `SerializedRequest`. If it was all metadata (ie. no bytes remaining in the buffer), the call to `move()` would return `nullptr`. Change the code to use an empty `IOBuf` instead.
