Commit title: Open tuples: subtyping
Commit body:
Summary:
For type
```
(t_1, _, t_m, optional t_{m+1}, _, optional t_n, t...)
```
define `t[i]` as `t_i` if `i < n` and `t` if `i >= n`. (Writing `_` for meta ellipsis to distinguish from `...` for variadic syntax.)

The subtyping relation
```
(t_1, _, t_m, optional t_{m+1}, _, optional t_n, t...)
<:
(u_1, _, u_r, optional u_{r+1}, _, optional u_s, u...)
```

holds if corresponding components are subtypes and the subtype components are at least as defined as the supertype components. That is
1. `r <= m` (so subtype has at least as many required components as supertype) and
2. `t[i] <: u[i]` for all `i` (so corresponding elements are subtypes)
