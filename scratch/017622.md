Commit body:
Summary:
Closes: https://github.com/facebook/folly/issues/985.

This ctor is confusing as a constructor since it can easily be used incorrectly. The PR gives this example of intended vs accidental use:
```
folly::dynamic data = folly::dynamic::object("key", "value"); // correct
folly::dynamic data = folly::dynamic("key", "value"); // incorrect
```

The incorrect example will compile because `char const*` is indeed an iterator. But the behavior in theory will be undefined and in practice will be unpleasant.

There is an alternative tagged constructor and an alternative static member factory function. Remove the untagged constructor.
