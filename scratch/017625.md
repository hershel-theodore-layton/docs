Commit title: folly::ext::test_find_resource hook for buck2
Commit body:
Summary:
This hook allows tests built with buck2 and using `folly::test::find_resource()` to find resource artifacts defined within `BUCK` files.

To use, the `//folly/ext/buck2:test_ext` target should be linked into the test targets. Within Meta, the target is added as an implicit dependency by buck2 macros that wrap the native `cxx_test()` macro.

This is being open sourced to unblock OSS folly builds via OSS buck2. This implementation is extracted from the Meta internal codebase, and has been well exercised.
