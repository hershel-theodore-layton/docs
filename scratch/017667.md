Commit title: Remove g_funcsMutex and depend on RDS initialization for atomicity
Commit body:
Summary:
The lock was guarding three operations:
 - Binding the RDS link
 - Initializing the RDS link
 - Setting the atomic func pointer

RDS link initialization is already an atomic operation, so for persistent links if we just specify an initial value we can avoid any locking at all, while for non-persistent links we don't need to protect the `initWith` operation as it's request local.
