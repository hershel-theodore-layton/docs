Commit title: HasherFactoryWithMetadata
Commit body:
Summary:
Introduce `HasherFactoryWithMetadata` which is effectively a pointer to a
factory function along with all of that hash function's information.

While this data does exist individual in types such as fizz::Sha256, fizz::Sha384, etc.
the choice of hash function for components like HPKE, HKDF, etc. are all
determined at runtime. Since fizz::Sha256, fizz::Sha384, etc. are distinct types,
this makes it unwieldy to use at runtime (they can only be realistically used with
templates at compile time)

Components such as KeyDerivation, Hkdf, etc. also stored extraneous copies of
properties such as the `hashLength`, which is unnecessary since these properties
are constant per hash.

This diff introduces `HasherFactoryWithMetadata` and adjusts components to
utilize this common type. Many components that build on hashes (e.g. HKDF)
are also simplified.
