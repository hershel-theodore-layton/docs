Commit title: make union Type enums normal python classes
Commit body:
Summary:
The goal is to make thrift-py3 enums identical to thrift-python enums.

As a next step, make the Union `Type` enums python `class` instead of `cdef class`.

__Performance__: This should be performance neutral because converting to cpp with `<int>` costs same regardless of `cdef` class or python `class` that's convertible to `int`.

__Build Speed/Size__: This diff temporarily  regresses instruction count, but we'll claw this back by removing generated `MetaClass`es in next diff and removing reliance on cpp `EnumData` in further diff. As a last step, we can move the enums into a `_internal_enums.py` `python_library` and then the stack will strictly be a win.

__Overall plan__:
1. make `enum` python `class`
2. This diff: make `union` type-discriminator enums `class` instead of `cdef class`.
3. Migrate to `python.MetaClass`. Remove py3 generated `MyEnumMetaClass`
4. Remove usage of generated cpp `EnumData`.
5. Move enums into `python_library` sub-module that's re-exported via `.types`.
