Commit title: Type splat: typing
Commit body:
Summary:
Ttype-checking function application where the function type has a splat parameter is easy: simply package up the arguments that occur from the splat parameter and beyond as a tuple, and check this tuple argument against the splat parameter type. For example
```
function foo<T as (mixed...)>(int $x1, string $x2, ...T $args):void { }
foo(2, "A"); // type-check tuple() against T
foo(2, "A", 2.3); // type-check tuple(2.3) against T
foo(2, "A", 2.3, false); // type-check tuple(2.3, false) against T
```
Error messages perhaps aren't ideal, as they talk about the tuple. Equivalent error messages for ordinary function application would talk about "too many arguments" or "too few arguments". We might want to try and mimic that at some point.
