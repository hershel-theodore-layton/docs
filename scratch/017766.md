Commit title: Introduce Factory::makeRandomBytes(unsigned char*, size_t)
Commit body:
Summary:
`Factory::makeRandomBytes(unsigned char*, size_t)` will, at the end of this
diff stack, be the only overridable method on the factory, which will allow
factory implementations to choose a suitable random number generator.

There already is `unique_ptr<IOBuf> makeRandomBytes(size_t)`. This, along with
all of the other `makeRandom*` methods, will be removed at the end of this
diff stack. All of these can be expressed as calls to
`makeRandomBytes(unsigned char*, size_t)` -- this version imposes the
fewest requirements on the caller (e.g. no need for IOBufs if the caller
does not want it).
