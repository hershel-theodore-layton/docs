Commit title: Rename type_resolver to cpp_name_resolver
Commit body:
Summary:
The current naming of `type_resolver` is problematic for the following reasons:

1. It doesn't only resolves types, but also other names like namespaces and annotation names. In general it provides a mapping from a Thrift construct, which may or may not be a type, to the name of its C++ counterpart.
2. The name is too generic and doesn't reflect that the API is C++-specific. It is partly solved with the namespace but the latter is inconsistent with the actual generator, this API is logically part of, that doesn't use a nested namespace.

Fix it by renaming to `cpp_name_resolver`, mostly with the following codemod:

```
fbgs -s -l cpp/type_resolver.h | \
  xargs sed -i 's/type_resolver/cpp_name_resolver/g'
```

While at it, also fix includes and improve comments.
