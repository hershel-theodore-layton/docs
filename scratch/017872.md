Commit title: Escape `?` in emitted strings
Commit body:
Summary:
If we happen to emit a `??/` in a formatted string in C/C++ source
code, it'll trigger a trigraph warning in `gcc`, so also escape `?`
to avoid this (as escaping `/` causes a illegal escape char error).

```
$ cat test.cpp
int main() {
  const char *f = "??/";
}
$ gcc -c -o /dev/null test.cpp
test.cpp:2:20: warning: trigraph ??/ ignored, use -trigraphs to enable [-Wtrigraphs]
    2 |   const char *f = "??/";
      |
```
