Given [notebook JSON](https://github.com/jupyter/nbformat/blob/main/nbformat/v4/nbformat.v4.schema.json) over stdin, produces a Hack file.

This is for source-controlled Hack notebooks, see facebook-only section for more context.

**the particular format is still up for discussion*, this is some preliminary functionality to un-block. The main idea is:
- The format should preserve information about what cell each code block is from
- The format should produce *valid hack*: which means that we need to move top-level statements into a function.
