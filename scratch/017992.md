Commit title: Explicitly check for protocols in the thrift python server handler code
Commit body:
Summary:
The thrift python sever currently has several hard coded checks for whether a request is coming in with binary or compact protocol.

While I believe currently the base thrift server also only supports binary or compact protocol, it's for the best to put this check in, because if in the future the base thrift server were to implement support for another protocol it'd potentially break our code (at least until support for that protocol were added to the thrift python server)
