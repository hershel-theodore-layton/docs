Summary:
The `subtype_of` relation was restricting the produced subtypes to immediately inhabited ones. This is necessary when it is used for expression generation, but not so much for type hint generation.

This diff relaxes the requirement so that the type generator generates eventually inhabited types instead of immediately inhabited ones.

This gives us more varied generated programs.
