Commit title: shrink state size of settings BoxedValue
Commit body:
Summary:
The class `folly::settings::detail::BoxedValue` holds onto a `std::function` which has a lambda with captured state, where the captured state is 3 pointers wide. The implementation of `std::function` in libstdc++ only has in-situ capacity for captured state up to 2 pointers wide, so this requires heap allocation.

It is possible to capture only the stored pointer of the `value` shared-ptr or, equivalently, to capture `this`, which would reduce the captured state to 2 pointers wide and also cause the lambda with the captured state to be trivially-copyable, allowing `std::function` to store a copy of the lambda in its in-situ storage.

But `std::function` under libstdc++ is 4 pointers wide in total, and we can shrink the size even further by not using any type-erasing function wrapper. In this way, we shrink the used in-situ storage for the `publish` function from 4 pointers wide to 2 pointers wide.
