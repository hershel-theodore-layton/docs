Commit title: Separate read only environment
Commit body:
Summary:
As a result of threading environment through we were forgetting to reset the `for_` flags in the environment. Consequently, we were overconstraining program generation and restricting variety.

This is a classic mutation problem. To remediate it, this diff separates the readonly part of the environment from the mutable part that gets threaded through. So we can only shadow the readonly values while recursive but not carry them over to adjacent calls through returns.
