Summary:
Generate thrift_abstract_types. The goal at this stage is manifest these types and check their behavior at a very gross level.

Firstly, the generated code comments out all the abstract methods of the form below because there are no tests that rely on these methods yet. We will enable them as we add/update tests to exercise these methods.

Next, at this time, the abc for all structured types look the same. As we write more tests for the different structured types like struct, union, and exception, I expect that the differences between them will start to emerge.

Finally, a majority of `thrift_abstract_types.py.mustache` emerged from `types_pyi.mustache` and will eventually be extremely similar to it. For now, there are significant enough differences between the two that I have kept them separate to avoid the need to pepper the latter with even more conditions than it has now. At the end state, I imagine thatwe might be able to refer to `types_pyi.mustache` or some other common `mustache` template. We will cross that bridge when we get there.
