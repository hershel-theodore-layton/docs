Summary:
Two wins here:
1. Michael discovered that compilation becomes faster when variable initialization happens inside anonymous functions, rather than global scope. (Functions are compiled concurrently, while global scope variables - on a single thread.)
2. We only initialize metadata variables when we actually need them (i.e. user opens Thrift Fiddle) - rather than on every start up. So it's a tiny amount of resources saved.
