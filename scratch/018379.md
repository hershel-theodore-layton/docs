Commit title: Stop generating sync client APIs
Commit body:
Summary:
Internal :

For more context see T204915038, T24020171

Sync Client APIs are deprecated. These APIs only execute serialization/deserialization of request/response, actual rpc call is not executed. The only remaining references to these APIs is in Tests. Earlier this year, almost all of the generated server tests were migrated to use async Client APIs. I removed remaining references that needed manual changes - https://fburl.com/diffs/3s5ahbem

With this, we stop generating these APIs. After this we can merge sync/async clients and only support single "normal" client.
