Commit body:
Summary:
**High-level goal**: we're trying to store the name of the package a symbol belongs to in its aast+decl representation, so that we only calculate its package membership once at parse time. Currently, this calculation is performed every time a symbol is getting referenced at typecheck time.

**This diff**: renames the field in decls from `package_override` to `package` since D64268444 has changed it to store the package membership, not just the package override value anymore.
