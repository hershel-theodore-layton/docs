This is the decl+locl ty dual of the `class<T>` type hint

In the future, to close the various typing holes of `classname<mixed>` etc, we aim for class pointers to look like `Tclass "C"`, where the current object type `Tclass` becomes a `Tinstance` of a class + a substitution.
