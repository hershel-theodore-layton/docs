Summary:
Right now equivalent py3 and python enums compare unequal. Ideally we'd check if the `._to_python()` of the enums is equal, but a small set of py3 `.types` have invalid `.thrift_types`. Until this is fixed, use brute-force equality comparison, in order of increasing cost:
1. equivalent `.value`
2. equivalent parent class name
3. equivalent parent class module, after removing `.types` or `.thrift_types` at the end.
