Commit title: remove importlib usage in enum converter
Commit body:
Summary:
The `py3-types` target already directly depends on `python-types` target, so direct import of `.thrift_types` is guaranteed to succeed. Remove `importlib` usage so this works better in cinder environment.

This works for the 99.99% of thrift files that produce valid `.thrift_type` thrift-python files. There is a long tail of `.thrift` that produce valid thrift-py3 but invalid thrift-python, many due to a combination of `namespace py3 ""` + name collision between module name  and struct name.

For this long tail, we have to put the `import` in a `try` statement, then defer the failure to call to `._to_python()`.
