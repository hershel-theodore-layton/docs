Summary:
Refactor TypeIntersectionConstraint to contain both the type hint constraint as well as the upperbounds.

Currently, the constraint coming from the type hint is stored as typeConstraint or retTypeConstraint for return types. The "upperbounds" are stored in a separate struct called TypeIntersectionConstraint. But this distinction is unnecessary and makes code complicated. Unify all the type constraints into TypeIntersectionConstraint.
