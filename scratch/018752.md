Commit title: Add IterSetValue and use it in HSL map async helpers
Commit body:
Summary:
Some HSL helpers, such as `Dict\map_async()`, perform in-place update of
the iterated array by setting the array element using the current key.
This performs an unnecessary hashtable lookup, as we already have a perfectly
valid pointer to the slot.

Introduce IterSetValue that uses the current iterator position, avoiding the
expensive hashtable lookup.

Use it by HSL helpers that already emit a custom bytecode.

Opens up a few more future opportunities:

- hhbbc pass that rewrites applicable BaseL+SetM into IterSetValue
- hhbbc optimization that tracks the output state of the iterator base
- hoisting of the base COW and upper bound refcount opts to eliminate COW checks
