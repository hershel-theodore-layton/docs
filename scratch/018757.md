CompressionAlgorithmSelector did not handle cases where invalid enum values were passed to the selectors. Each switch statement now throws a thrift PROTOCOL_ERROR if it is given an enum or union value that cannot be handled.

Meta:

Passing invalid values to CompressionAlgorithmSelector could result in undefined behavior. Fuzz testing with LionHead demonstrated that this could result in random size memory allocation attempts (300GB in one of the failed runs) and server crashes.
