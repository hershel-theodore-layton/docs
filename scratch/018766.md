Commit title: Specify the abstract base class instead of the union field enum
Commit body:
Summary:
Unions "passed" the union field enum type from the generated thrift union class to the union meta class through `_fbthrift_union_field_enum`.   Exceptions in thrift abstract types will leverage the same mechanism for the abstract base class type for exceptions through `_fbthrift_abstract_base_class`. The abstract base class type contains the union field enum type.

Rather than redundantly pass `_fbthrift_union_field_enum` along with `_fbthrift_abstract_base_class`, only "pass" `_fbthrift_abstract_base_class` and get the `FbThriftUnionFieldEnum` from that class.
