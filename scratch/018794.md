Commit title: Fix memoization key for class pointers
Commit body:
Summary:
The implementations for `GetMemoKey` handle strings and lazy classes specially, eventually calling `serialize_memoize_string_top`, which returns the original string when the first character is lower than ASCII à (kCodePrefix = 0xe0) -- in practice, covers Hack class names.

Class pointers would go down the generic `serialize_memoize_tv` path that prepends SER_MC_STRING and the length to the string; this code has the same memoization behavior for all 3 kinds.

This makes it so class pointers match the behavior of lazy classes.
