Commit title: validator for empty namespace and invalid name
Commit body:
Summary:
Adds an error-level validation to flag invalid thrift-python modules that meet both of the following conditions:
1. empty or missing `namespace py3`, and
2. definition name matches module name

These are invalid because collision between defined type and module name causes thrift-python to blow up at `import` time. Even if I try to workaround import-time error, the following is still broken:
```
from MyX.types import MyX
assert issubclass(MyX, Struct) # fails
assert issubclass(MyX, types.ModuleType) # passes
```
Better to error at compile time than `import` time.
