Basic support for type checking shape/tuple destructure. We traverse the shape/tuple tree of the lvalue and generate a fresh type variable for each leaf, and create a type with the same structure as the shape/tuple tree to subtype against the type of the RHS. We ignore some of the complications that are present in the list destructuring code that are only there to deal with holes.
