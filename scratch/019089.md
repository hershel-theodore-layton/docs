| Per this error  `Target thrift.test.thrift_python.included.thrift_abstract_types.TestUnion.FbThriftUnionFieldEnum.EMPTY cannot be annotated as it is an enum member.`, enum members cannot be annotated. | This error `Invalid assignment [41]: Cannot reassign final attribute fbthrift_current_value.` and the similar one about `fbthrift_current_field` was because those fields existed in the abstract base class. | With abstract types enabled, do not generate those fields in the derived classes |
