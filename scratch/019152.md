Commit title: Change template_map in thrift compiler to include language
Commit body:
Summary:
We use template_map to store the mustache template files and their content, for example, it stores {`"types/pep484_type"`: [content](https://www.internalfb.com/code/fbsource/fbcode/thrift/compiler/generate/templates/python/types/pep484_type.mustache)}.

However, since the template path doesn't contain language, this prevents reusing the template in multiple languages. This diff changed so that we keep the language prefix when creating the template_map: {`"python/types/pep484_type"`: [content](https://www.internalfb.com/code/fbsource/fbcode/thrift/compiler/generate/templates/python/types/pep484_type.mustache)}.

This change is needed if we want to move thrift patch to a different template directory. (currently we put it under python directory: https://www.internalfb.com/code/fbsource/fbcode/thrift/compiler/generate/templates/python/thrift_patch.py.mustache).
