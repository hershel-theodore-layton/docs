Commit title: Fix issue with dunder enum arms in constants
Commit body:
Summary:
Currently, thrift-python blows up on `import` if an `enum` has an dunder `__` prefix arm, and that arm is used in a `const`. This is because python mangles class variables `__MyName` to `_MyClass__MyName`.

The smaller-scope way to handle this is to just correct the enum values for `const` in `.thrift_types` module.
