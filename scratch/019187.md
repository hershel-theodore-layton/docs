Commit title: Add run-all-thrift stat to collect linter statistics
Commit body:
Summary:
As a follow-up to T199674585 & related to T199674585, this diff adds the `run-all-thrift stat ...`  subcommand to gather linter-related stats related to e.g. a fully-repo thrift scan.

Currently this dumps the json-formatted output to stdout, but in future we can have this upload to scuba via a daily sandcastle run.

Examples:
```sh
> buck run fbcode//thrift/facebook/thrift-tools:run-all-thrift -- stat thrift/lib
{
  "avoid-oneway-method": 22,
  "bad-key-type": 46,
  "cyclic-dependency-between-structs": 4,
  "deprecated-java-namespace": 7,
  "deprecated-map-to-struct-promotion": 19,
  "optional-default": 5,
  "qualified-name": 12,
  "reserved-infra-method-name": 3,
  "thrift-parser": 66,
  "unused-include": 4,
  "warning": 188
}
```

You can also provide any linter CLI args, e.g.
```sh
> buck run fbcode//thrift/facebook/thrift-tools:run-all-thrift -- stat --take_builtin_rules --take-rules 'deprecated-map-to-struct-promotion' thrift/lib
{
  "deprecated-map-to-struct-promotion": 19,
  "thrift-parser": 66,
  "warning": 85
}
```
