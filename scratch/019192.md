Commit title: Type splat: subtyping for tuples
Commit body:
Summary:
As with function types, subtyping on tuples that contain splat elements simply involves constructing a tuple type on the other side of the subtype relation to compare against the splat. For example, to compare
```
(t1, t2, ...T)
<:
(u1, u2, u3, optional u4, u5...)
```
we would compare `t1 <: u1`, `t2 <: u2` and then `T <: (u3, optional u4, u5...)`.

We also clean up the code for tuple subtyping a bit, traversing the required elements of the tuples first, and then traversing the optional elements.
