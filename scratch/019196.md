Summary:
[stream](https://www.internalfb.com/intern/staticdocs/thrift/docs/idl/#streaming) is not a type per-se, but an annotation on a type that indicates data will be returned in a streaming fashion between server & client.

# Scope of the changes
In the thrift AST, `t_stream` was previously derived from `t_type`, requiring it to be interpolated during every type replacement. Unfortunately most of the mustache rendering followed this flow:
```
{{#<for-normal-types>?}}
    func(T)
 {{/<for-normal-types>?}}
{{#<for-streams>?}}
    streamFunc(T)
{{/<for-streams>?}}
```
Which now renders as:
```
func(T)streamFunc(T)
```
previously this just rendered as `streamFunc(T)` because `#type:stream?` was rarely cased as a type directly.

Note:
A similar change made for t_sink: D49169880.
