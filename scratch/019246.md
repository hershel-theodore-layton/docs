Summary:
We need to support enum sorting for more stable `Map.__repr__` during migration away from cpp `std::map` internal type (key-sorted order), toward python standard `dict` (insertion order).

When fully aligned, the thrift-py3 enum will have base class `int` for normal non-`Flag`  enum. However, this is a non-trivial switch, so just implementing `__lt__` for now. It's only called from cython so not switching the `.pyi` to `SupportsDunderLT` to avoid churn, since it will become `int` subclass in the near future.
