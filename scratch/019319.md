Commit title: Error streaming: only validate errors if they come from the same file changes
Commit body:
Summary: For error streaming, once we've streamed errors, we validate those errors by doing a normal RPC call to get the errors, then compare them. However sometimes discrepancies come from the fact that files have changed right after we've streamed errors. To prevent that, we compare the watchman clock of both typechecks and only compare errors if the clocks are the same. (NB: these clocks are returned by watchman upon file change detection, and are carried around throughout the typecheck. So same clocks = same sets of files to check = same typechecks = same sets of errors).
