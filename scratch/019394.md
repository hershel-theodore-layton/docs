Commit title: Support patching struct that contains safe patch of another struct
Commit body:
Summary:
Today we support using SafePatch in IDL, e.g.,

```
// Foo.thrift

#include "path/to/gen_safe_patch_Bar.thrift"

struct Foo {
  1: gen_safe_patch_Bar.BarSafePatch barSafePatch;
}
```

However, currently we cannot generate FooPatch in python, since this would create safe patch of safe patch, e.g.

```
patch = FooPatch()
subPatch = patch.barSafePatch.patch()

assert type(subPatch) == BarSafePatchPatch

subPatch.to_safe_patch() // This won't compile since it returns BarSafePatchSafePatch
```

This diff omitted `to_safe_patch()` method if the original struct is already a safe patch, which prevented this issue.
