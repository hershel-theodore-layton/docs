This diff speeds up Rust compilation of the reported slow target from 21m30s to 2m44s (7.9×). In combination with D66798212, the speedup is 9.3×.

LLVM has pathological behavior on large function bodies. `-Ztime-llvm-passes` shows inordinate amount of time being spent in MemCpyOptPass, SROAPass, GVNPass for Thrift libraries containing big maps, like this one:

https://www.internalfb.com/code/configerator/[28ffdad97ed4de3d5d3aabe0f7e9647cac43e4a2]/source/capella/xid/asset_xid_types.thrift?lines=19226%2C20434

This diff splits up Thrift `map` construction inside `const` into individual functions per entry, for which the optimization pipeline parallelizes better and also suffers less from LLVM passes that exhibit superlinear scaling on large functions.

Benchmarking the `fbcode//configerator/structs/capella/xid:asset_xid_types-rust[static]` action in `opt` mode:

| none | 21m30s |
| noinline (this diff) | 2m44s (-87%) |

| noinline + exhaustive | 2m18s |
