Instead of changing `get_class`/`get_parent_class` returns, expose new intrinsics following the naming convention of `get_class_from_type`. These live in the `HH\` namespace

    - always pushes at least a class type

- `get_parent_class_from_class`

  - Does not support object input
  - With `class` param hint, adds an avenue to ban string input as well
