Commit title: First-class polymorphic function pointer for top-level functions
Commit body:
Summary:
Modifies typing of function pointers for top-level definitions so that they have universally quantified types and makes the corresponding changes to subtyping to allow these types in subtype position.

For polymorphic function types in subtype position we just instantiate with fresh, invariant type variables (to avoid solving) then solve the proposition between the supertype and the instantiated function type.

For polymorphic function types in supertype position we bind each quantifier in the type parameter environment, solve the proposition in the updated context then restore the context i.e. unbind the quantifiers. Because we use a fixed, leftmost, eager depth first search strategy we are guaranteed that the context is correct for all subgoals.
