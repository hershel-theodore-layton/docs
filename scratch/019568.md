Commit title: make self.value a lazy property
Commit body:
Summary:
This diff makes union field population (cpp -> python conversion) lazy. This is particularly an issue for containers of unions. The `.value` will not be created in python until it is accessed.

To summarize the change, `self.value` is now a property, invokable directly by user, and also by specific arm property getters.

The `value(self)` property implementation loads `self.py_value` from the cpp object, using logic that used to live in `_load_cache(self)`. However, if `self.py_value` is already loaded (i.e., `not None`, then we return it directly. If the `type_int == 0` (i.e., EMPTY), then we can can return `self.py_value`, which is `None`.
