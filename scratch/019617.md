Commit title: To prepare for explicit enum imports, reorganize enum related imports
Commit body:
Summary:
# What?
A future change will replace the wild-card import from `.thrift_enums` in the generated types source files with explicit import of the enums.

# What to do?
To reduce verbosity, make code easier to reason about, and to avoid unnecessarily generated code
- generate the wild-card imports only if there is at least one enum.
- rather than full import, syntax for each enum
```
from fullly.qualified.module.thrift_enums import SomeEnum as _fbthrift_SomeEnum
from fullly.qualified.module.thrift_enums import _fbthrift_compatible_with_SomeEnum
from fullly.qualified.module.thrift_enums import SomeOtherEnum as _fbthrift_SomeOtherEnum
from fullly.qualified.module.thrift_enums import _fbthrift_compatible_with_SomeOtherEnum
...
```
use the more compact attribute form of the import, for example
```
from fullly.qualified.module.thrift_enums import (
    SomeEnum as _fbthrift_SomeEnum,
    _fbthrift_compatible_with_SomeEnum,
    SomeOtherEnum as _fbthrift_SomeOtherEnum,
    _fbthrift_compatible_with_SomeOtherEnum
     ...
)
````
