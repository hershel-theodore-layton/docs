Commit title: Reduce build-time by moving the definition of setter/getter to module_types.cpp
Commit body:
Summary:
setter/getter are already deprecated, we should not make everyone's build slower due to legacy use cases.

In addition, if they are defined in the header, compiler will be forced to instantiate template method `field_ref()` since getter/setter are implemented by `field_ref()`. e.g.

```
  ::cpp2::MyEnumA& set_fieldQ(::cpp2::MyEnumA fieldQ_) {
    fieldQ_ref() = fieldQ_;
    return __fbthrift_field_fieldQ;
  }
```

This shouldn't affect performance as long as LTO is enabled (which should be the case for any performance sensitive services).
