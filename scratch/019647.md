Commit title: Switch to usdt.h library for USDTs
Commit body:
Summary:
Switch over from folly's "experimental" FOLLY_SDT() and
FOLLY_SDT_WITH_SEMAPHORE() APIs to new usdt.h-provided APIs with implicitly
defined USDT semaphore from [usdt.h](https://github.com/libbpf/usdt).

We now don't need to define and/or declare semaphore explicitly with
FOLLY_DEFINE_SEMAPHORE()/FOLLY_DECLARE_SEMAPHORE().

usdt.h is well tested, records signedness of arguments (FOLLY_SDT doesn't), it
supports many architectures (FOLLY_SDT() support only x86-64 and with recent
additions also aarch64).

The end goal is to get rid of FOLLY_SDT() usage in fbcode and replace all
internal uses with USDT() and USDT_WITH_SEMA().

**This doesn't have any performance implications and results in identical
low-level USDT representation.**
