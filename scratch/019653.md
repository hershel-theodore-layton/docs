Commit title: Error streaming: fix watchman query in fbsource/www
Commit body:
Summary:
The current watchman query that the streaming client performs looks like the following in fbsource/www:
```
[
  "query",
  ".../fbsource/www",
  {
    "since": ...
    ...
  }
]
```
But it should look instead like:
```
[
  "query",
  ".../fbsource",
  {
    "relative_path": "www",
    "since": ...
    ...
  }
]
```
To determine what part of the `root` path needs to go to that `relative_path` field, we do the same as in `Saved_state_loader` and invoke `watchman watch .../fbsource/www`.
