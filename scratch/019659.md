Commit title: Introduce interactionLoadshedded error codes
Commit body:
Summary:
These errors will be sent by the server to signal to the client that the interaction has been loadshedded.

- If an interaction has already been marked loadshedded, server will reject request with `kInteractionLoadshedded`.
- If a request is rejected due to OVERLOAD and the interaction overload policy decides to terminate the interaction, server will reject request with `kInteractionLoadsheddedOverloadErrorCode`
- If a request is rejected due to APP_OVERLOAD and the interaction overload policy decides to terminate the interaction, server will reject request with `kInteractionLoadsheddedAppOverloadErrorCode`
- If a request is rejected due to QUEUE_TIMEOUT and the interaction overload policy decides to terminate the interaction, server will reject request with `kInteractionLoadsheddedQueueTimeoutErrorCode`
