This aligns `evaluate` with the future implementation of user-defined functions. This is also required for:
* literals — {D67608814}
* user-defined functions — {D67617014}

`native_function` (per the spec) will accept arguments and return values as `shared_ptr`. This allows whisker to avoid unnecessary copying when calling such functions.

In this diff, we use `shared_ptr` without heap allocations, using the same machinery used by `folly::MaybeManagedPtr`. `shared_ptr`'s polymorphic / type-erased deleter allows this to work seamlessly.
