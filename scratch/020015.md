Commit body:
Summary:
`native_handle<T>` allows passing around C++ objects in Whisker. Doc blocks describe in detail.

Together with `native_function` we can create APIs in C++ for Whisker templates that follow the "opaque pointer" pattern:
```
struct my_type;

int my_type_size(const my_type*);
int my_type_id_of(const my_type*, const char* name);
```

This is powerful because (taken to the extreme), we can eliminate all `t_mstch_*` types and directly operate on `t_*` AST nodes with `native_function` being the glue between the two.
