Commit title: Emit type structure info for optional and variadic elements of tuple types
Commit body:
Summary:
Implement a type structure representation for tuple types with optional and/or variadic fields. A tuple type such as
```
type TA = (int, string, optional bool, optional float, nonnull...)
```
will be represented by a type structure as follows:
```
dict(5) {
  ["kind"]=> int(10)
  ["elem_types"]=> vec(2) {
    dict(1) { ["kind"]=> int(1) }
    dict(1) { ["kind"]=> int(4) }
  }
  ["optional_elem_types"]=> vec(2) {
    dict(1) { ["kind"]=> int(2) }
    dict(1) { ["kind"]=> int(3) }
  }
  ["variadic_type"]=> dict(1) { ["kind"]=> int(23) }
  ["alias"]=> string(2) "TA"
}
```
If there are no optional element types, then the field `optional_elem_types` will be absent. If there is no variadic element, then the field `variadic_type` will be absent. (The `variadic_type` representation follows that of variadic function type hints.)
