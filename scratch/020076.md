Commit title: Type splat well-formedness: must be a tuple
Commit body:
Summary: The type splat operator `...t` should be used only on something known to be a tuple type, typically a generic with a bound e.g. `T as (int, nonnull...)`. Currently we don't enforce this. By analogy with generic types that have constraints (e.g. `keyset`), we should check in `Typing_type_wellformedness`. It's enough to check that the splat type is a subtype of `(mixed...)`, the top tuple type.
