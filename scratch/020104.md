Commit title: Pyre reveals typing.Any for all abstract types properties.
Commit body:
Summary:
# What?
With the aliased property decorator, `_fbthrift_property`, Pyre reveals `typing.Any` for all abstract types properties.

# Why?
This is a bug in `Pyre`.

# Implement Workaround
Use the fully qualified name for `property`, `builtins.property`, with an appropriate reserved identifier alias to prevent name collisions, `_fbthrift_builtins.property`.

# What's next?
A subsequent change will add tests similar to the [incorrect and correct type checks](https://www.internalfb.com/diff/D67838161?permalink=1727142304809689) in special_cases_test.py
