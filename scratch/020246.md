Summary:
Now `whisker::object` has value equality — **two objects are equal if they "behave" the same in Whisker template code**.

This diff fixes `whisker::object::operator==`. The are three big changes:
- array and array-like native object *may* compare equal (previously always unequal)
- map and map-like native object *may* compare equal (previously always unequal)
- native_object::operator== is no longer customizable since we enforce the aforementioned semantics

## Why do this?

We expose `object.eq?` as a standard library function (D68424363) and use it in templates. So defining equality clearly was necessary.
