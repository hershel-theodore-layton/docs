Summary:
This diff makes `report_error` *eventually* fail the parse (return `std::nullopt` instead of `ast::root`).

This allows the compiler to perform error-recovery — cases where the user intent is somewhat clear but expressed incorrectly.

The value is that instead of failing on the first error, we can collect multiple errors in a single parse and show them all to the user.
