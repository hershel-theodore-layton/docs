Commit title: Implement parsing for partial block captures
Commit body:
Summary:
This diff implements parsing for "captures" defined in {D68865189}.

Captures here are like explicit lambda captures in C++. They allow "functional decomposition" of partials in Whisker which promotes smaller, more composable, and better-named partial definitions.

 ---

```
{{#let partial greeting |firstName lastName|}}
Greetings, {{firstName}} {{lastName}}!
{{/let partial}}

{{#let partial greet-person |person| captures |greeting|}}
{{#partial greeting firstName=person.firstName lastName=person.lastName}}
{{/let partial}}

{{#partial greet-person person=dave}}
```

```
// Context
{
  "dave": {
    "firstName": "Dave",
    "lastName": "Grohl"
  }
}
```

```
// Output
Greetings, Dave Grohl!
```
