Summary:
thrift-python flags don't have an `__int__` method defined, so calling `int()` on them fails with `TypeError: int() argument must be a string, a bytes-like object or a real number, not [Enum Class]`.

thrift-py3 flags allow `int()` calls so we should have the same for thrift-python flags. Fixing this by just adding an `__int__` method.
