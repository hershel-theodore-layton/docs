Summary:
I am working on [adaptive selection](https://docs.google.com/document/d/14hmQpdSXTXLFO17dkRE1xxvprj3-nIVxwoXvfrOD568/edit?tab=t.0#heading=h.9ynv2mhioi3v) feature in SR wherein it is beneficial to use smoothened out load counter, which is averaged over large duration such as 60 sec. We verified that allows algorithm to function smoothly. To acheive this, SR will send another load header - 'secondary_load'. This load will be primarily used by adaptive selection, pick-2 LB will continue to happen on original load.

This change adds support for this secondary load in thrift server and transport.
