Commit title: support inheritance of exceptions
Commit body:
Summary:
To facilitate thrift-py3 auto-migrate, add limited support for inheritance in thrift-python.
1. On trunk, improve the error message for inheritance usage. Before, user would get `KeyError: _fbthrift_SPEC missing`. Now the user gets a proper `TypeError` that instructs to use composition.
2. For thrift-py3 auto-migrate users only, if an `exception` has annotation `python.MigrationBlockingInheritanceAllowed`, then a python `class` can use it as a base class.

Edge cases:
- Multiple inheritance: I tested that neither thrift-py3 nor thrift-python support this, so no need to add support in auto-migrate.
- Grandparent inheritance: if we have python `class A(B)` and `class B(SomeThriftStruct)`, added test to verify it works.

Next:
- Deliberately not implementing support for inheritance in `UnionMeta`. Removal of thrift-py3 usage in progress.
