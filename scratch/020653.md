Commit title: Simplify the code by using SFINAE to detect whether expression is valid (instead of folly::is_detected_v)
Commit body:
Summary:
So that instead of

```
template <typename T>
using detect_clear_with_badge =
    decltype(std::declval<T>().clear(std::declval<Badge>()));
template <typename T>
constexpr static bool has_clear_with_badge_v =
    folly::is_detected_v<detect_clear_with_badge, T>;

template <class T>
void func(T& t) {
  if constexpr (has_clear_with_badge_v<T>) {
    t.clear(badge);
  }
}
```

we can just write

```
template <class T>
void func(T& t) {
  if constexpr (__FBTHRIFT_IS_VALID(t, t.clear(badge))) {
    t.clear(badge);
  }
}
```

In this example, the macro will create a lambda `[auto& t]() -> std::void_t<decltype(t.clear(badge))> {}`, then check whether the lambda is callable with `t`.

If `t.clear(badge)` is not valid expression, the lambda won't be callable due to SFINAE.

NOTE: this is similar to Concept in C++20. In the future we can migrate to Concept.
