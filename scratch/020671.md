Commit title: Implement CompareThreeWay using EqualTo and LessThan
Commit body:
Summary:
Implement three-way comparison and use it in `StructLessThan` as part of the effort to improve the performance of comparing two Thrift structs. For now, `CompareThreeWay` simply delegates to `EqualTo` and `LessThan`. This will serve as the default fallback implementation when the input types are not three-way comparable. As a result, there are no significant changes in the performance of `StructOpLess`.

For now, keep only 1 Tag in the template parameter of `CompareThreeWay` since we only use it to compare the exact same field in two Thrift structs.

Additionally, add a `LessThanImpl` template parameter to `CompareThreeWay` to ensure that types that do not have `operator<` defined can rely on it for less than comparison.

The default handler for adapted types is included in this diff to allow tests to pass. A more elaborate implementation to handle adapted types will be included in the next diff.

This is the second attempt of D68541164 after it was reverted due to test failures.
