Commit title: allow setting path in get_client
Commit body:
Summary: There's a bug when trying to use `get_client(Service, path=path)`. It gives `ValueError: Cannot set path and host/port at same time`. That's because the py3 `get_client` uses -1 as sentinel value for port unset, but python `get_client` uses `None`. So we translate the py3 default `port=-1` to `None` before making the python `get_client` call.
