Commit title: Disable JIT entirely when JIT is folding functions
Commit body:
Summary:
When JIT is folding functions, we rely on enterVMAtFunc() to enter dispatch(),
which generally does not reenter JIT.

However, this is broken. If the interpreted function threw an exception, the
enterVM() logic would then attempt to handle the exception and potentially
reenter using enterVMAtCurPC(), which lacks a similar check.

It is safer to just disable RID().getJit() during folding.

Also fix a bug in handleResume() that would try to use an existing translation
if JIT is disabled.

Allows the next diff to kill dispatch().
