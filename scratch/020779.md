Commit title: Implement multi-plexing support for Rocket client
Commit body:
Summary:
Rocket protocol comes with multi-plexing support built-in (i.e. making parallel/concurrent RPCs using the same client).

However, the existing Thrift API does not allow us to take advantage of it.

Make `RocketClient` implement `RequestChannel` interface - that allows us to support multi-plexing.
