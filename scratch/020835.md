Commit body:
Summary:
PROBLEM
`folly::small_vector` or one of the `sorted_vector_types` do not define the spaceship (aka 3 way comparison) operator.
This makes them harder to use in other C++20 code, and this behavior is inconsistent with other STL containers

SOLUTION
Add these operators.

EDIT:
Used SFINAE to ensure any existing uses where the value_type didn't have the 3 way compare operator defined are excluded.

EDIT 2:
Heap_vector_map has a default comparison that is DIFFERENT from the default. Adding support for the 3 way compare operator would require more changes so I'm reverting that change.

EDIT 3:
