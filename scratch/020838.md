Commit title: Make CURLOPT_USERPWD / CURLOPT_PROXYUSERPWD allow null to be set
Commit body:
Summary:
The original decision to make these accept strings and not null came from PHP. But these APIs actually take nulls as well:

https://curl.se/libcurl/c/CURLOPT_USERPWD.html

> Using this option multiple times makes the last set string override the previous ones. Set it to NULL to disable its use again.

https://curl.se/libcurl/c/CURLOPT_PROXYUSERPWD.html

> Using this option multiple times makes the last set string override the previous ones. Set it to NULL to disable its use again.

Most people don't need to set the value to null (they just avoid setting it in the first place), but we want to be able to set the value here to null, so lets make the HHVM API accept that.
