Commit title: sandbox jumpstart relative paths shouldn't have leading slashes
Commit body:
Summary:
When the root does not have a trailing slash, as php_root() creates,
then splitting the absolute path after the root results in a relative path that
has a leading slash. We later read these relative paths from the profile and
join with root and a "/", eg `makeStaticString(root + '/' + relpath)`.

To support this, just ensure that when we create a relative path we support
roots with and without a trailing slash.
