Commit title: Introduce Shapes::put
Commit body:
Summary:
This diff introduces the `Shapes::put` API and introduces dedicated type checking for it in the typechecker.

The reason for introducing `Shapes::put` is two fold
1. Language concistency: other operations on shapes also have non-array-access based syntax in the `Shapes` namespace to operate on shapes, like `Shapes::idx`, `Shapes::at`, `Shapes::removeKey` etc.
2. Supporting shape put operations in expression trees without requiring an expensive desugaring (see D69488404 for the difference)

`Shapes::put($shape, $key, $value);` is semantically equivalent to (the IIFE is used here to avoid mutating the input argument):

```
(($shape, $key, $value) ==> {
   $shape[$key] = $value;
   return $shape;
}($shape, $key, $value))
```
