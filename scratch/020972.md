Summary:
Add logging so we can get metrics on Safe Abstract stuff: how often uses of classes via `new` and static calls are unsafe.

see fb-only section for context

## How to get stats

```
rm -rf /tmp/hh_server/*log*; killhh && cd ~/www && hh --no-load --config safe_abstract=true --config log_levels='{"safe_abstract": 1}'

mkdir -p /tmp/lsblog
out="/tmp/lsblog/$(date)"
cat $(hh --logname) | grep safe_calls > $out
cat $out | jq -s  '{safe_news: [.[].safe_news] | add, safe_calls: [.[].safe_calls] | add, unsafe_news: [.[].unsafe_news] | add, unsafe_calls: [.[].unsafe_calls] | add}' | tee "$out.counts"
echo "Perecentage of 'new's and static method calls that are safe:"
cat "$out.counts" | jq '(.safe_calls + .safe_news) /  (.safe_news + .safe_calls + .unsafe_news +.unsafe_calls)' | tee "out.percentage"
```
