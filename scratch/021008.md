# This Diff
The client field is derived from the PID of the peer process communicating across the socket.
Previously, this functionality was not implemented on windows so it always returned a PID of 0.
This diff implements PID derivation for windows.

# Technical Details
This change uses the SIO_AF_UNIX_GETPEERPID flag for WSAIoctl in order to get the peer PID.
Due to include conflict reasons, the header afunix.h is not directly included in the file, but indirectly via a different header file. See the comments in https://www.internalfb.com/code/fbsource/[aa286be8f1e48421faeab22a6493651d1195be4f]/fbcode/c2p/secure_thrift/cpp/client/platform/windows/PlatformWindowsUnixSock.h for further detail.
