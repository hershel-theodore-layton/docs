Commit title: Add roundtrip to Protocol.Object benchmark
Commit body:
Summary:
Add the `roundtrip` operation to the Protocol Object benchmark suite.
`Roundtrip` (as the name implies) parses a thrift serialized object into a `Protocol.Object` & re-serializes it. This includes the cost of the object destructor.

This represents the minimum overhead cost when using Protocol.Object for data manipulation, e.g. in interpreter use-cases.
