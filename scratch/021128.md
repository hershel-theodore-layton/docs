Commit title: Subprocess fd-action to keep open
Commit body:
Summary:
A way to ask `Subprocess` to keep a specific fd open in child process, even if it might be marked cloexec in the parent. Two options:
* The value is the new constant `NO_CLOEXEC`.
* The value is equal to the fd key. As if doing a `dup2` of the key, which is a no-op, but with the added behavior of removing cloexec.
