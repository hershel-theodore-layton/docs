Commit title: Move allocator-aware constructor definitions to source file
Commit body:
Summary:
The `cpp.allocator` annotation (on structs) generates a few additional allocator-aware constructors, e.g.
```cpp
:> foo_types.h

explicit Foo(const allocator_type& alloc) noexcept { ... }

explicit Foo(const Foo& other, const allocator_type& alloc) { ... }

explicit Foo(Foo&& other, const allocator_type& alloc) { ... }
```

As these are implemented directly in the header, it prevent using the annotation in scenarios with recursive/circular type dependencies, as it forces explicit instantiation in the constructor. E.g. `Protocol.Object <-> Protocol.Value`.

This can be circumvented by moving the definition to the types source file, as is the case with the other constructors.
