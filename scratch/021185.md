Summary:
Fixes 2 bugs;

1. The call to actually log the before and after experiment ids needs to happen before `PiranhaWorkerDefaultExecutionUnit::genTeardownGlobals`, because teardown will call `PiranhaWorkerContextPropHelper::clear()`, which in turn clears the core context, including the TFM header.
2. $ids_before and $ids_after will actually have the same value by the time we're logging them because they point to the same object. This diff joins the experiment ids and saves them in a variable before we call `genSetupGlobals` so we can properly preserve them. If we're not sampling we'll set `$ids_before` to null and use that to skip logging.

and also switches back to using fblogger.warn to be consistent with the other logging statements we've added, not using the new ope api should be ok here since this code is temporary.
