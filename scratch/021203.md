Summary:
## What

Don't create empty lines in the `source` array when converting Hack (.php) to a notebook (.ipynb)

## Why

- A tool we use to validate notebooks in ipynb format doesn't like empty strings in the `source` array.
- We might as well mimic VSCode's behavior: if I open a notebook with empty strings in the `source` array in VSCode, VSCode automatically converts the empty strings to `"\n"`.

## Note about conversion from notebook to Hack

At first I worried that we would create too many newlines when round-tripping `hack -> notebook -> hack`. But now I realize there's no problem, since we use `libhackfmt` to format the Hack we generate. Any redundant newlines will be removed.
