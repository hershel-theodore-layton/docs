Summary:
Within `eval_context`, we currently use `std::string_view` for identifiers and `std::vector<std::string>` for lookup paths.

This diff replaces them with `ast::identifier` and `ast::variable_lookup` respectively, which are the *most* correct type.

The benefit we get is that the AST nodes contain `source_range`s. This will be useful in future diffs where we want diagnostics within `eval_context`.
