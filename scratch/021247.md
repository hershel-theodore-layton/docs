Commit body:
Summary: When we encounter a reified tparam, we'll set `inside_reified_class_generic_position` in the accumulator state and recurse to visit the type, however, when we finish, we continue to use that same updated accumulator state. However, this updated value of `inside_reified_class_generic_position` is not necessarily correct moving forward.
