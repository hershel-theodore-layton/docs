Summary:
## What

Sometimes in the JSON representation of notebooks each line (except the last one) ends in "\n" and sometimes we get cells where the lines don't end in a newline character.

Jupyter docs, afaict, [don't specify whether cell source lines should end in newlines](https://ipython.org/ipython-doc/3/notebook/nbformat.html) so we handle both representations.

## Why this matters

- `hackfmt` allows extra newlines, so won't save us from extra newlines
- Cells that are non-hack can also contain newlines (such as markdown cells) and it'll be nice if we don't add lots of extra spaces to them.
