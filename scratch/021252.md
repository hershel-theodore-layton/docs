Commit title: allow begin write to control buffer sizes
Commit body:
Summary: When starting to write lets the user control the buffer sizes to use for writing. Lets them specify one buffer size or they can chose a min / max that will start smaller and then grow the size it allocates until a max is hit. For small responses this will be faster than allocating more memory up front - ie you know your struct is less than 1k most the time so you pick use beginWrite(1<<10) so that it only allocates a 1k buffer.
