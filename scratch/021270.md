Commit title: Make proxied objects first class citizen
Commit body:
Summary:
Sometimes we need to make a `object::ptr` shaped thing fit into an `object`-sized hole.

The primary case is `whisker::array` and `whisker::map` stores `object`s inline but `map_like::lookup_property`, `array_like::at`, `native_function::invoke` necessarily return `object::ptr` (since the value is dynamically created and thus allocated on the heap).

This diff makes `object::ptr` a first class thing you can store in `object` BUT it's completely hidden from its public API.

Following this diff, we can remove `object::ptr` and the `manage_as_static` / `manage_owned` stuff from a lot of places — for example, a function would be able to directly return `i64` and have it be copied, instead of returning an `object::ptr` on the heap.
