Commit title: make realloc on a nullptr invoke malloc
Commit body:
Summary:
`man realloc` tells us:
> If ptr is NULL, then the call is equivalent to malloc(size), for all values of size.

However, this is not what happens in the current implementation.

Currently, `checked_local_realloc` will flow through to `local_realloc`, which is jemalloc's `rallocx`, which then fails the `ptr != NULL` assertion within `do_rallocx`.

Instead, let's delegate to `checked_local_malloc` to have the expected behaviour.
