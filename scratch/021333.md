Summary:
**Consolidating Thrift-py3 Enums with Thrift-python Enums**

We aim to consolidate thrift-py3 enums, generated in `types_impl_FBTHRIFT_ONLY_DO_NOT_USE.py`, with thrift-python enums defined in the generated thrift_enums.py. This consolidation is a crucial step towards safely rolling out the thrift-py3 auto-migrate build tool.

**This diff serves two primary purposes:**

* Aligning `Thrift-py3` Enums with `Thrift-python` Enums
   * We add an int base class to `thrift-py3` generated enums by default, aligning them with thrift-python generated enums. Enums can opt-out of this change using the `python.NoIntBaseClassDeprecated` annotation at the top.
   * By implementing the int base for enums in py3, we can now resolve the `pyre-ignore[6]: {enum} is not SupportsDunderLT` issue.

*  Updating User Code for Compatibility
 Making necessary changes to user code to ensure compatibility with the new implementation.
