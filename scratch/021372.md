# Idiomatic:
We are following the same pattern as other Decoder-style APIs in Go lib - e.g.:
https://pkg.go.dev/encoding/gob#Decoder
https://pkg.go.dev/encoding/json#Decoder
This means - accepting a `io.Reader` in the constructor and providing a `Decode` method.

# Faster-performance:
As shown by benchmarks downstream - this updated API performs faster due to fewer allocations/writes.
