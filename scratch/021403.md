Commit title: let Range never specialize basic_string_view with non-char types
Commit body:
Summary:
The libc++ implementation of `std::basic_string_view` explicitly deprecates any specializations except for a select list. `folly::Range` attempts to avoid such specialization, and it worked with some platforms. This attempt was introduced in {D62275652}, but it is incomplete.

Now we completely avoid such specialization using a more complete technique.
