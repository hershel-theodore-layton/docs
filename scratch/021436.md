Commit title: Fix evaluation of constant values containing a renamed union variant
Commit body:
Summary:
`{value:unionVariant}` is responsible for returning the Rust enum variant name for the value of a Thrift constant whose type is a Thrift union. Relevant template code:

https://www.internalfb.com/code/fbsource/[c07e9d27c4fb9ebd2133cf3509e684e549a4e7bb]/fbcode/thrift/compiler/generate/t_mstch_rust_generator.cc?lines=1653

https://www.internalfb.com/code/fbsource/[c07e9d27c4fb9ebd2133cf3509e684e549a4e7bb]/fbcode/thrift/compiler/generate/templates/rust/lib/value.mustache?lines=156-161%2C165

For example:

```lang=thrift
union Bar {
  rust.Name{name = "Annotated"}
  1: i32 WithAnnotation;
  2: i32 WithoutAnnotation;
}
const Bar BAR1 = {WithAnnotation: 123};
```

The `{WithAnnotation: 123}` needs to become the Rust code `Bar::Annotated(123)`, with "Annotated" being provided by `mstch_rust_value::union_variant`.

This was implemented correctly for unstructured `(rust.name = "...")` annotations, but not for structured `rust.Name{name = "..."}`.
