Commit title: add folly::coro::merge() support takes in both AsyncGenerator<AsyncGenerator<Type>> and AsyncGenerator<AsyncGenerator<Type>&&>
Commit body:
Summary:
Currently, folly::coro::merge only supports an input sources of type AsyncGenerator<AsyncGenerator<Type>>.

However, my intended usage of folly::coro::merge is to use AsyncPipe<AsyncGenerator<Type>> to add AsyncGenerators over time. However, the returned AsyncGenerator from AsyncPipe<T>::create() returns a folly::coro::AsyncGenerator<T&&>, preventing usage of passing the AsyncGenerator to folly::coro::merge.

Hence this diff was created to be able to support both AsyncGenerator<AsyncGenerator<Type>> and AsyncGenerator<AsyncGenerator<Type>&&> as input types to folly::coro::merge.

I'm open to more changes on how to do this better.
