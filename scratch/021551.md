Summary:
The current structure of thrift-py3 is:
- `types.pyx`: defines a structs, unions, constants. Re-exports containers and enums
- `types_impl_FBTHRIFT_.*.py`: defines enums
- `containers_FBTHRIFT_.*.py`: defines containers. There's some jankiness around circular import dependencies, since it depends on `types.pyx` for struct imports.
- `constants_FBTHRIFT_.*.py`: defines constants in pure python. Not currently used, but these have been tested for parity with the cython constants defines in `types.pyx`.

The new structure with in-place migrate:
- `types_inplace_FBTHRIFT_ONLY_DO_NOT_USE.py`: defines all enums, structs, unions, containers, constants. The enum definitions will go away when enum merger completed in near term. Having everything in the same file unwinds the circular dependency fragility from current setup.
- `types.pyx`: will re-export everything from `types_inplace.*.py`. Will continue to define a small number of stream types that are out of scope for this first phase of in-place migration. After rollout of python structs complete, the stream types will be refactored into an auxiliary cython library in preparation for making `-py3-types` into a `python_library`.

In this first diff, copy-paste containers and enums into `types_inplace`. Add stubs for structs and unions.
