Commit title: Add a new AliasClass type AClosureArg
Commit body:
Summary:
We introduce a new AliasClass type AClosureArg to track the closure arguments separately. Closure args are read-only, and currently, they are muddled with AProp. By separating them out, we shall observe 2 benefits:
1. Any kind of instruction that has a call effect essentially overwrites all AProp alias classes (among other AliasClasses). Now, we are at least able to retain closure args since they are in a separate AliasClass.
2. Better alias analysis since the closure args that were earlier aliasing with the rest of the non-closure properties will no longer alias.
