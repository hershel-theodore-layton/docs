Commit title: Propagate the current usage hint in ifThenElse() and cond() constructs
Commit body:
Summary:
If the current block is hinted with a lower usage, it is never correct to
create blocks inside if-then-else with higher usage. It will just cause
random unnecessary jumps between main/cold/frozen sections.

It is common to override these hints inside ifThenElse(), but it still makes
sense to set a reasonable default. Propagate the same hint for `done` block, as
that one gets the same traffic. Deprioritize `taken` block from `Likely` to
`Neither` (they are in the same section).
