Commit title: Use emitHandleException for Throw and failed Await
Commit body:
Summary:
Use emitHandleException() instead of the custom logic in the Throw and Await
bytecode implementation. It does not only handle routing exceptions to
exception handlers, but also handles non-empty stack and does not require
spilling all inlined frames when there is no exception handler. Instead, it
reuses the shared unwinding code, reducing the code size.
