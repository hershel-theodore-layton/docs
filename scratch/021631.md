Commit title: Add back ClassGetTS that pushes single value, switch reified ops to use it
Commit body:
Summary:
See parent diff for context.

This change restores ClassGetTS as a bytecode that pushes a single Class* on the stack based on the `"classname"` field from the input type structure.

In HackC, update the emitter for expressions that directly index the type structure / emit ClassGetC to use ClassGetTS. Replace the implementation of `get_class_from_type` intrinsic to use ClassGetTS instead of using generics flavor and popping.

After this change, only `new` uses `ClassGetTSWithGenerics`.
