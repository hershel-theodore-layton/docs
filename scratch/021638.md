Commit title: add from_python converter to py3 containers
Commit body:
Summary:
One building block of the design is that each type that isn't equivalent between thrift-py3 and thrift-python will define a `staticmethod` `from_python` that will convert from py3 to python as cheaply as possible.
- For unions and structs, this is as simple as borrowing a reference to the thrift-python argument.
- For containers, we have to iterate through because the type of the container itself differs between thrift-python and thrift-py3.

This diff implements `from_python` for containers.
