Commit body:
Summary:
Fix a bunch of tech debt related to enum handling in C++ codegen and tests:

* Remove `cpp2.enum_type`.
* Replace several deprecated enum annotations in tests with their structured counterparts.
* Add tests for all `cpp.EnumUnderlyingType` variants. Previously there was a test for only one case and the rest was relying on copy pasting an enum from Thrift into the compiler code. Now we don't need to copy paste since the correctness is tested automatically.
* Rename `EnumTest.thrift` and `QualifiedEnumTest.thrift` to `enum.thrift` and `qualified_enum.thrift` because these are not tests and to match naming conventions for Thrift files (tests are a bit of a mess in this respect but newer files do follow the convention even there). In particular this helps with autocompletion since those files and corresponding targets no longer look like tests.
* Make fields that have defaults non-optional in enum tests.
* Remove uses of deprecated `value_unchecked` in enum tests.
* Fix naming conventions in the code being touched.

Cleanup and migrate to whisker 3 out of 4 remaining functions in `cpp_mstch_enum`. This leaves the one which is also redundant and will be removed in a subsequent diff.
