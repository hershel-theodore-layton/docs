Summary:
There's some interesting subtleties around exception handling. Basically copy the logic from types.pyx.mustache for `str`. This ensures `str` of exception only prints the  field designated by `thrift.ExceptionMessage` if present.

To make things like `my_exception.args` work, we have to initialize the grandparent class `exceptions.Error`. However, we deliberately skip the parent class `GeneratedError`, which tries to initialize a cpp objects that doesn't exist using `FieldSetter` cython. We do the same for `Struct` where we delibrately omit the `__init__`. We let thrift-python `__init__` do all the initialization and processing of args / kwargs + error handling.
