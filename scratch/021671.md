Commit title: Denotable polymorphic function hints
Commit body:
Summary:
Adds syntax for bounded polymorphic function hints:

```
(function<T as C>(T):T)
```

The syntax is restricted so that type parameters on polymorphic function hints cannot:
- Have variance annotations
- Be reified
- Have attributes with expression arguments
- Be higher-kinded
- Shadow any type paramter in an enclosing class or method (type parameter names can be reused across different hints, though)

Before this change there was no way to declare a function type argument as polymorphic but no new subtyping rules are added here.
