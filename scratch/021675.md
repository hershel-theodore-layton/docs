Commit title: Include `type_rep_types_custom_protocol.h` in `Protocol.h`, similar to `Type.h`
Commit body:
Summary:
This fixes the link-time error we were encountering for `buck build fbcode//thrift/lib/cpp2/type:type-registry`. The fix here models the pattern used in [`Type.h`](https://www.internalfb.com/code/fbsource/[88792658e3f0]/fbcode/thrift/lib/cpp2/type/Type.h?lines=31).

The `FBTHRIFT_STD_HASH_WRAP_DATA` usage at the bottom of `Protocol.h` specializes `std::hash` and requires an instantiation of `ProtocolUnion::write`. The definition of `ProtocolUnion::write` lives in `thrift/lib/thrift/gen-cpp2/type_rep_types.tcc`, and is expected to be used via `thrift/lib/thrift/gen-cpp2/type_rep_types_custom_protocol.h`. `Type.h` has the same structure, which does include `thrift/lib/thrift/gen-cpp2/type_rep_types_custom_protocol.h`.

Without header units, the usage of `Protocol.h` from `TypeRegistry.cpp` was fine because of [temp.point/7.1](https://eel.is/c++draft/temp.point#7.1) which essentially says that for any function template that has a point of instantiation within a translation unit, the end of the translation unit is also a point of instantiation. So this means that even though `ProtocolUnion::write`'s definition is not available at the initial point of instantiation, it's okay because the end of the translation unit of `TypeRegistry.cpp` is also a point of instantiation, where the definition **is** available.

The change with header units is that the scope of translation unit is different. Under [module.import](https://eel.is/c++draft/module#import-note-2), it says that "a header unit is a separate translation unit". This means that rather than end of `TypeRegistry.cpp`, the end of `Protocol.h` is the second point of instantiation. Without including `thrift/lib/thrift/gen-cpp2/type_rep_types_custom_protocol.h`, the definition of `ProtocolUnion::write` is still not available at this point, and we end up with the link-time error due to the missing definition.

Also see: [The Problem of Template Use-before-define in Header Units](https://fb.workplace.com/groups/1218949679215295/permalink/1310419903401605/).
