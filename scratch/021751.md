Summary:
If there is a typedef, e.g.

```
typedef gen_patch_Foo.FooSafePatch Bar

struct Baz {
  1: Bar bar;
}
```

In this case we should not allow patching `bar` since it's patch of safe patch.

It doesn't work today since `gen_patch_Foo.FooSafePatch` is a typedef, and for typedef we did not set `is_patch` correctly in python codegen.
