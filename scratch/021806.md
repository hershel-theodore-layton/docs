Commit body:
Summary:
The size of `protocol::Value` was reduced to 16B in D69278828, changing the underlying implementation for `set<Value>` using  `folly::F14FastSet` to `folly::F14ValueSet` instead.
`folly::F14VectorSet` stores elements as a contiguous array with an external 32bit index into the elements while `folly::F14ValueSet` stores elements inline. (cfr. https://fburl.com/code/ft6thb16),

As `set<Value>` can contain arbitrarily complex element types, benchmarking shows that it provides the best performance trade-off for all use-cases.
