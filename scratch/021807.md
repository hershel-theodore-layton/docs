Commit title: Remove cpp.virtual from Protocol Object & Value
Commit body:
Summary:
This diff removes the vtable from `Protocol.Object` by unmarking it as a `cpp.virtual` class in the thrift IDL & modifying the `ObjectWrapper` to not use dynamic dispatch for the generated `detail.Object` thrift type.

The same changes are also applied to `Protocol.Value`.

This combined reduces the size of `Protocol.Value` to 16B, improving cache locality for containers (e.g. lists, sets & maps), in addition to reducing the call overhead when serializing Objects & Values.

## Misc

The boost-like APIs for `Protocol.Value`, e.g. `as_TYPE()`, are more stable wr.t. type changes, so this diff includes some changes to adjust the thrift codebase. External consumers of `Protocol.Value` will be updated in future diffs.
