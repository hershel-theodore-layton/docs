Commit title: support `.set_input_dir` files in `hphp/test/run`
Commit body:
Summary:
`--repo-options-dir` allows to specify where to read RepoOptions, aka.hhvmconfig.hdf and PACKAGES.toml, from.  This option adds complexity to path management, in particular for PackagesV2 unit tests, as the paths specified in `include_paths` might not be relative to `--input-dir`, while filenames stored in ParseMeta are.

Diff [1/2] allows tests running in repo mode (-r) to specify how `--input-dir` should be set, by adding a `.set_input_dir` file in the test directory.  Indeed, if `--repo-options-dir` is not set, RepoOptions are read from `--input-dir` (for unit tests, the root directory where hphp folder lives).  Thus `.set_input_dir` allows tests in repo mode to control how test runner sets `--input-dir`, and in turn where RepoOptions are read from.
