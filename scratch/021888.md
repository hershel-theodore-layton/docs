Commit title: fix __init__ for mangled struct fields
Commit body:
Summary:
In python, `self.__{{some_attribute}}` is resolved to `self._MyClass__{{some_attribute}}`. Thrift-python has some explicit handling of this. The official interface requires accessing the attribute via mangled attribute name. However, we can at least support initialization with the user-facing IDL name without adding any overhead to the non-error case.

This is needed for backwards compatibility with thrift-py3 inplace. It also fixes compatibility for builders in auto-migrate.
