Commit title: Add accessor for underlying executor for offloop schedulers
Commit body:
Summary: The thrift off loop schedulers are backed by an executor service either ThreadPoolExecutor or a ForkJoinPool. Some projects value being able to schedule work directly without using the Reactive Scheduler interface. In this case some projects want to wrap the executor service for use with Guava listenable futures, for example using `MoreExecutors.listeningDecorator(…)`. This diff forces the schedulers to expose their underlying executor service for direct scheduling of work.
