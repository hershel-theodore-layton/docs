Summary:
Seeing thrift deserialization errors like this one is no fun:

```
deserializing `string` from Thrift binary protocol got invalid utf-8, you need to use `binary` instead: invalid utf-8 sequence of 1 bytes from index 137
```

For structures with many nested fields localizing the one field that's non-utf8
is tedious. This diff changes this error to something like:

```
Error while deserialising error field of ErrorLogEntry
Caused by:
    deserializing `string` from Thrift binary protocol got invalid utf-8, you need to use `binary` instead: invalid utf-8 sequence of 1 bytes from index 165
```

Which helps localize error a bit more.
