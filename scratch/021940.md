Commit title: add py3 namespace to struct Extractor/Constructor traits
Commit body:
Summary: Rather than defining `Constructor<T>` and `Extractor<T>` for `T = cpp2_ns::MyStruct`, we now require `T = PythonNamespaced<cpp2_ns::MyStruct, py3_namespace_mangled_module::NamespaceTag>`. Since buck enforces that no python files are generated into the same python namespace + module name location, the Namespace tag ensures that a given thrift file's structured types and enums have unique `Extractor` and `Constructor` definitions.
