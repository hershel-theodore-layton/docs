Commit body:
Summary:
With the previous logic we would attempt to default all un-annotated, even code that couldn't be annotated due to coeffects with #KeyedByIC.

For example:

```
<<__Memoize>>
function memo_fn($a, $b)[leak_safe]: void {
  echo "args: $a, $b \n";
}
```

Was treated like:

```
<<__Memoize(#KeyedByIC)>>
function memo_fn($a, $b)[leak_safe]: void {
  echo "args: $a, $b \n";
}
```

Which would fail validation.

This diff moves the defaults population into it's own method, and conditions it on being able to have `#KeyedByIC`.
