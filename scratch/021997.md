Commit title: Handling the situation when `py3.gen_metadata` is called by `thrift_enum` type.
Commit body:
Summary:
After D69883327 and D70664312, the Thrift Py3 enum and Thrift Python enum are now aligned. Before we can merge these two enums into one, there is a situation that needs attention when py3.gen_metadata is called by the thrift_enum type.

For example:

When auto_migrate is enabled, if we execute the following:
```
from thrift.py3.metadata import gen_metada
from <namespace>.<filename>.types import ExampleEnum
```
`gen_metada(ExampleEnum)` will return `metadata.thrift_types` instead of `metadata.types`. In another word, below testing would fail.

https://www.internalfb.com/code/fbsource/[f58196839497]/fbcode/thrift/lib/py3/test/auto_migrate/metadata.py?lines=41

This diff is to handling above case to prepare the merging thrift-python enum and thrift-py3 enum.
