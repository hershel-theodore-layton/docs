Commit title: Add SVE version of F14::tagMatchIter
Commit body:
Summary:
SVE variant of tagMatchIter is added, leveraging two features:

1. Only kCapacity (12/14) bytes of data are loaded to be compared, simd register is zero-extended on such load

2. Instead of doing an AND between the resulting mask and kFullMask, a SIMD AND between each byte lane and #17 is performed. This frees-up one general purpose register: kFullMask had to be loaded into a gp register using two instructions, to then perform the AND; now the AND is done using an immediate value.

We've noticed up to a ~5% performance imrpovement in the ManyFind benchmark:
