## Experimental Protocol::Value

This diff contains the initial library skeleton & Value implementation for performance-focused drop-in replacement of [Protocol::Value](https://www.internalfb.com/code/fbsource/fbcode/thrift/lib/thrift/detail/protocol.h), cfr. [protocol_detail.thrift](https://www.internalfb.com/code/fbsource/[79298399397be1a63835421484bdaceec6ef4b99]/fbcode/thrift/lib/thrift/protocol_detail.thrift)

The `experimental::Value` uses a `std::variant` backed representation of the `Value` hierarchy in the thrift IDL, but does not rely on the thrift generated structs. It provides a set of serialization & deserialization functions that match those of `protocol::Object` & `protocol::Value`.

The benefit of this representation is that it provides inline specializations of commonly used types, where they can benefit for a more compact & cache-efficient memory layout than the generic versions used by the IDL, e.g.
`list<Value>` vs `std::variant<list<i16>, list<i32>, ...>`
