Commit title: add float32 rounding
Commit body:
Summary:
Add 32-bit precision of thrift `float` types in the thrift-py3 shim. This emulates the current behavior where thrift-py3 gets 32-bit rounding of `float` from thrift-cpp2 implementation.

Without this change, the thrift-py3 `float` values would change from 32-bit precision to 64-bit precision, causing some low-signal test failures. In the worst case, there would be key failures for those that use `float` as a `set` or `map` key. Thus, this change makes the in-place migration safer.

In the future, we should either switch thrift-py3 to use 64-bit precision like thrift-python, or we should introduce 32-bit precision for `float` types into thrift-python.
