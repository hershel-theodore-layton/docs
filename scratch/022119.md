Summary:
This diff generalizes the mechanism for bundling `thrift/annotation/*` into the compiler. This lets us re-use the logic to also bundle `thrift/lib/thrift/*`, which is needed by `t_ast_generator` (i.e. `thrift2ast`). See D72480706 for more details.

`bundled_annotations::files` has become `bundled_annotation_files` (free function) so that we can avoid including the header. This is to avoid passing in yet another parameter to the code generation binary because the former requires us to include the header file.
