Summary:
This test failed on Mac. It now passes. It only passed on Linux because the core count it used to detect the number of server IO threads was greater than the number needed. It failed on mac due to the number of cores being less than the number of server IO threads.

For example, on Linux
core count: 166
IO threads: 10
We previously sent 167 requests and blocked all 10 threads long enough to cause 157 queue timeouts.
We now send 11 requests, enough to block all 10 threads and cause 1 timeout.

On Mac
core count: 8
IO threads: 10
We previously sent 9 requests, enough to block 9 threads and cause 0 queue timeouts
We now send 11 requests, enough to block all 10 threads and cause 1 timeout.
