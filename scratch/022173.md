Commit body:
Summary:
The Thrift compiler generates a base class `_fbthrift_compatible_with_MyStruct`, which is an undesirable precursor to abstract types. The use of inheritance in this context is questionable, and all instances can be replaced with `typing.Union[my_namespace.my_module.types.MyStruct`, `my_namespace.my_module.thrift_types.MyStruct]`.

There is no use case after ran the following command:
```
xbgs _fbthrift_compatible_with_ --exclude "igthrift/gen|dataswarm_commons/thrift/gen" | grep -v pyre-fixme | grep -v fbcode/thrift | grep -v "#"
```
So we are sure that we don't have customer usage based on above logic.

This diff is to remove `_fbthrift_compatible_with` and related logic from the generated in `thrift-py3` types.pyi.
