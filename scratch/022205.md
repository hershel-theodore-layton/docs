Commit title: Make SyntaxGraph ProgramNode::definitions return list instead of map
Commit body:
Summary:
Currently `ProgramNode::definitions()` returns a map from name to `DefinitionNode*`. This has led to user trying to find definition by name whereas they should be finding definition by `DefinitionKey` instead (names are not unique across programs).

We preserve the existing behavior in a new function named `definitionsByName` and make the "default" function return a list of `DefinitionNode*`. `SyntaxGraph` provides the guarantee that one `DefinitionKey` will map to one `DefinitionNode` object so comparing by the address of the node will yield correct result.
