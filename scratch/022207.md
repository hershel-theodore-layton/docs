Commit title: Make generate_bundled_thrift chunk string literal into lines for large files
Commit body:
Summary:
When bundling `thrift/lib/thrift/*` which contains larger files, I ran into [MSVC C2026](https://learn.microsoft.com/en-us/cpp/error-messages/compiler-errors-1/compiler-error-c2026?view=msvc-170)

> The string was longer than the limit of 16380 single-byte characters.

The solution is to break up the file contents into multiple string literals. We use chunking with a reasonable hard-coded size to avoid too much `__FBTHRIFT_TAG__` raw string literal delimeter noise.
