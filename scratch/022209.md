Commit title: Introduce `folly::vector_bool` alias
Commit body:
Summary:
Primary goal is to block infamous `std::vector<bool>` specialization,
where performance matters more that memory usage.

`folly::detail::BoolWrapper` type was introduced, that wraps raw `bool` and
thereby blocks `std::vector<bool>` specialization. `folly::detail::BoolWrapper`
is interoperable with `bool` type.

Goal is to have one solution for `vector<bool>` in easily discoverable place.
