Summary:
Measuring effect of switching `str` internal type from `bytes` to just `str`.
## Serializer:
Seeing a small regression ~2% on serialization (expected because of cost of PyUnicode to binary), and larger improvement  4% on deserialize (save a python `bytes` object allocation), net ~2% improvement round-trip.

Old
```
| Serializer     | serialize   | deserialize   |
|----------------|-------------|---------------|
| py-deprecated  | 0.257316 ms | 0.113561 ms   |
| py3            | 0.004507 ms | 0.004727 ms   |
| python         | 0.007831 ms | 0.007892 ms   |
| mutable-python | 0.008443 ms | 0.019890 ms   |
```
New
```
| Serializer     | serialize   | deserialize   |
|----------------|-------------|---------------|
| py-deprecated  | 0.251308 ms | 0.114903 ms   |
| py3            | 0.004577 ms | 0.004777 ms   |
| python         | 0.008042 ms | 0.007451 ms   |
| mutable-python | 0.008372 ms | 0.019409 ms   |
```
