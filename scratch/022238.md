Commit title: Add NativeSet support
Commit body:
Summary:
This diff introduces `NativeSet`, a tagged representation of various `folly::F14FastSet` based specializations of `Value`.
In the `Protocol::Value` implementation, a set was always represented as `folly::F14VectorSet<Value>`, significantly increasing the memory use & reducing cache efficiency for primitive types.

With `NativeSet` we provide specializations for lists of all primitives, e.g. `set<i32>`, `set<string>`, ...
so that consumers opt-in to the native equivalent, at the cost of resolving a single external tag for each set (in contrast to a tag for each element).
