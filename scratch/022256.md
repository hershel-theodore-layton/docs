Commit body:
Summary:
Previously we skip package checks on *all* generics because symbolrefs does not follow them, not even reified ones (surprisingly).  Per [discussion](https://fb.workplace.com/groups/890924834786372/permalink/1777629602782553/), we aim to address generics more properly by controling the behavior of package check on reified generics behind `package_v2_allow_reified_generics_violations`. Concretely, when the flag (by default set to true) is turned off, we should error on reified generics.

Note that this diff simply adds gating logic for existing package handling, and does not address cases like `my_prod_function<MyProdClass::MyInternType>`, and no package error is raised on `MyInternType` even when the flag is off. I will implement package logic in a separate diff.
