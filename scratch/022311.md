Commit title: Move "typeErasedPatchImpl" from StructPatch.h to StructPatchImpl.h
Commit body:
Summary:
The existing diff looks like this

```
// In StructPatch.h
template<class Patch>
void* typeErasedPatchImpl(...) {
  // ...
}
```

In this case, we need `extern template` so that users don't instantiate the template (to reduce build-time).

This diff moved the definition to StructPatchImpl.h

```
// In StructPatch.h
template<class Patch>
void* typeErasedPatchImpl(...);
```

```
// In StructPatch-inl.h
#include <.../StructPatch.h>

template<class Patch>
void* typeErasedPatchImpl(...) {
  // ...
}
```

So that if we only include "StructPatchImpl.h" in the generated ".cpp" file, but not ".h" file, it will automatically be externed (since users cannot instantiate the template without definition).

This way, we can simplify the logic and get rid of the awkward `only_defined_in_generated_patch_cpp(...)`.

In next diff, since we don't need `extern template`, we can even get rid of the type erasure (which was necessary https://fb.workplace.com/groups/498666380550247/posts/2146514622432073).

Note that we did the same thing for serialization code where we declared template function in ".h" file and only defined in ".tcc" file:
