Commit title: Remove StringToBinary
Commit body:
Summary:
`protocol::Value` & `protocol::Object` allow specifying whether a `T_STRING` is mapped to `std::string` or a `folly::IOBuf`, as the IDL union allows either option. Unfortunately neither the Binary nor Compact protocol are able to differentiate between the two.

In practice this ambiguity complicates the type system, forcing users to check which of the two options is populated in the `Value`.

To simplify this behavior, `NativeValue` will only allow `Bytes` as a variant type, with conversion/coercion between `std::string`, `std::string_view` & `folly::IOBuf`.
