Commit title: Support splat arguments to type-splat parameter
Commit body:
Summary:
Add support for using the expression-level splat operator (written `...$x`) when calling functions whose last parameter is itself a type-level splat (written `...T`). At the same time, do a little light clean-up of the existing code for typing calls to type-level splat functions. Suppose the function has declaration (probably with some generics)
```
function foo(t1 $x1, _, tn $xn, ...t $rest)
```
where `_` is meta-level ellipsis and `...` is type-level splat.

There are two situations.
1. The call is `foo(e1, _, em)` where `ei` have type `ui`. We assert the subtype `(u1,_,um) <: (t1,_,tn,...t)` and let splat-level subtyping do the work.
2. The call is `foo(e1, _, em, ...e)` where `ei` have type `ui` and expression splat `e` has type `u`. We assert the subtype `(u1,_,um,...u) <: (t1,_,tn,...t)` and let splat-level subtyping do the work.
