Summary:
## The Problem
Converting between `IThriftStruct` and `IThriftStructMetadata` requires `Classnames::is` or similar. This triggers Hack autoloading, which is slow at build-time.

## The Fix
Mark `IThriftStructMetadata` as extending `IThriftStruct`. With this change we can convert an `IThriftStructMetadata` class to an `IThriftStruct` class without hitting the autoloader.

All `IThriftStructMetadata` classes generated by Thrift codegen already implement `IThriftStruct`. This change just communicates the relationship to the typechecker.
