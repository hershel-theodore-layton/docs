When creating a memo-sensitive implicit context, it is slow to call
serialize_memoize_param(), as it might need to reenter the VM.

Instead, split ImplicitContext class into MemoAgnosticImplicitContext and
MemoSensitiveImplicitContext, restrict TData of a memo-sensitive implicit
context to IPureMemoizeParam and call getInstanceKey() from Hack.

This diff doesn't touch the ImplicitContext class. The next diff will move all
HHVM unit tests to the new API. Once nothing uses the old API, it will be
removed.
