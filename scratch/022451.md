Commit title: Simplify and improve build speed of generated reflection code
Commit body:
Summary:
Remove `__fbthrift_id` templates which were generated for every structured Thrift type and fix a number of other issues in the always-on reflection:

* Rename `__fbthrift_reflection_field_id_list` to `__fbthrift_reflection_field_ids` for consistency with `__fbthrift_reflection_type_tags` and other similar APIs.
* Fix constness of `__fbthrift_reflection_field_ids`.
* Replace `__fbthrift_field_id` with `__fbthrift_field_ids` which is only parameterized on the Thrift type and not on the Thrift type and the field index.
* Minor consistency/readability fixes in the surrounding generated code.

This eliminates a massive number of unnecessary template instantiations and gives a moderate 0.04 EYS overall build speed improvement in addition to simplification.
