Commit title: Make tree_printer much prettier
Commit body:
Summary:
Mizuchi made a cool thing over at `TreeNode.h` and I'd like to use it in core Thrift. We already have `tree_printer` that was built as part of Whisker but this one is better.

The goal of this diff is to merge `TreeNode` into `whisker::tree_printer` and have one solid API across all tree pretty-printing needs across our codebases.

To do this, the API of `tree_printer` had to be *heavily* refactored.
  * The old `tree_printer` used to be *immediate* mode and stateless — meaning that we were free to copy `scope` objects, and calls to `print` would immediately write to the underlying `std::ostream&`. With the new formatting requires of `TreeNode`, this approach is no longer possible (e.g. the last child is printed differently). The new API matches `TreeNode` and materializes a tree structure and buffers the output into it. Printing to the `std::ostream&` happens after the tree is materialized.
  * The distinction between `property` and `node` has been dropped — there is only one *kind* of `node` now.

The API surfaces using `tree_printer` are also affected. Notably, these are `whisker::object` and `whisker::print_ast`. However, these changes are mostly mechanical (passing `scope` by reference instead of copying it).

**Relevant changes are in `tree_printer.{h,cc}` and `tree_printer_test.cc`.**
