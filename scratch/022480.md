Summary:
Make py3 struct accepts python field by default.

There is widespread usage where clients mix `Py3` structs with Python fields, and vice versa. In the Modern Thrift Python world, the thrift-python interface, such as MyStruct.`__init__` and `__call__`, already includes features to convert Py3 fields directly to thrift-python types. However, attempting to assign a Python field to a py3 struct will result in a runtime error.

To facilitate the migration from thrift-py3 to thrift-python, thrift-py3 interfaces like MyStruct.__init__ and __call__ will accept thrift-python types and automatically convert them to thrift-py3. This approach will make the migration more reliable and potentially prevent SEVs caused by out-of-sync packages and un-pickling issues.

This diff aims to enable the py3 struct to accept Python fields in a compatible manner.
