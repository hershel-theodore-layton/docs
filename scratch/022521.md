Commit title: strip non-hack marker when converting back to notebook
Commit body:
Summary:
## What

Fix bug [reported by a user](https://fb.workplace.com/groups/768246428434224/posts/1082807136978150/?comment_id=1083743046884559&reply_comment_id=1084402066818657): When converting notebook->hack we were wrapping python cells in comments, then forgetting to strip those comments when converting hack->notebook.

## implementation:
- We don't want to strip comments from code cells that the user put there, so we use a special `/*non_hack:` comment to distinguish.
- We *could* parse cell metadata to look for the cell language, but we try to limit our dependence on metadata and this way is much simpler

Python cells now look like this when converted to Hack:

```
//bento-cell:{"cell_bento_metadata":{"language":"python"},"cell_type":"code","id":4}
/*non_hack:
%%python

print('Hello from python')
*/
//bento-cell-end
```
