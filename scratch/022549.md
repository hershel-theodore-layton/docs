Summary:
This fixes two issues revealed by below test:

1. `thrift_enums` unfortunately depends on the metadata thrift library: `apache.thrift.metadata.thrift_types`. For purposes of importing `metdata.thrift` only, must import the `.thrift_types` before `.thrift_enums`.

2. `thrift.py3.metadata` lib is returning types from `thrift.python.types`. The previous strategy was to hope that these types wouldn't matter. However, this test uses `.__class__` as a key in a map. For better robustness, convert the python `Proxy` types to py3 `Proxy` types.
