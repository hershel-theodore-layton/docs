Commit title: Split setting up decoratedProcessorFactory from initialization of ServerModule

Summary:
Consider the following code:
```
ThriftServer s;
s.setInterface(...);
s.setupThreadManager();
s.addModule(...);
```

As things stand today, the call to `addModule` will be ignored because `setupThreadManager` calls `ensureProcessedServiceDescriptionInitialized` (to runtime check for resource pools).

We fix it in this diff by only having the decorated processor factory be initialized.
