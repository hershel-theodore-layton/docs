Commit title: Disallow polymorphic function hints in type constant definitions
Commit body:
Summary:
We don't support type structures for polymorphic function hints for the same reason we don't support general hints containing rank-1 generics - we have no way of representing type parameters or their bounds.

Because of this restriction, we disallow hints containing rank-1 generics appearing as the definition of type constants. This diff introduces the same restriction for hints containing rank-n generics.
