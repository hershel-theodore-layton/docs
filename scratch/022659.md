Commit title: ConcurrentHashMap::insert_or_assign_if
Commit body:
Summary:
Insert if doesn't exist and update on certain predicate if exists should be a common scenario (upsert?). Without a single atomic `insert_or_assign_if` operation it requires two calls `insert` and `assign_if` to CHM in a loop to achieve that

```
  while (true) {
    auto assignIfOptIt =
        map.assign_if(key, value, predicate);
    if (!assignIfOptIt) {
      auto insertResult = map.insert(key, value);
      if (!insertResult.second) {
        auto existing = insertResult.first->second;
        if (predicate(existing)) {
          continue;
        }
      }
      return insertResult.first->second;
    }
    return assignIfOptIt.value()->second;
  }
```
