Commit title: Simplify and improve build speed of generated reflection code more
Commit body:
Summary:
* Remove `__fbthrift_type_tag` and `__fbthrift_ident` templates from every generated C++ struct.
* Rename `__fbthrift_reflection_ident_list` to `__fbthrift_reflection_idents` for consistency with `__fbthrift_reflection_type_tags` and other similar APIs.
* Group related APIs such as `__fbthrift_reflection_idents` and `__fbthrift_reflection_type_tags` together.
* Replace `__fbthrift_ident` and `__fbthrift_type_tag` with `idents` and `type_tags` which are only parameterized on the Thrift type. We don't need `__fbthrift_` there because the enclosing struct is already in the detail namespace.
* Remove another batch of unnecessary template instantiations in `struct_private_access::field_id`.
* Merge `thrift/lib/cpp2/op/detail/Get.h` into `thrift/lib/cpp2/op/Get.h` because the latter already contains most content of the `detail` namespace and it is confusing to have it arbitrarily split between the two files.
* Remove a misleading TODO about "supporting adapted field and smart pointers with custom allocators". Smart pointers don't have custom allocators and adapted fields should already work through normal accessors.
* Rename `GetOrdinalImpl` to `get_ordinal_impl` for consistency with `get_ordinal` which it implements.
* Improve apidoc of `get_field_id_v`.
* Fix includes.

Together with D73262760 this eliminates either completely or partially 7 (!) sets of unnecessary template instantiations, improving build speed and simplifying the code.
