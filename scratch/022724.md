Summary:
Initialize folly singletons in CLI client.

At the end of the CLI client logic we run hphp_process_exit(), which calls
moduleShutdown() on every extension.

It is legitimate for extensions to use folly singletons. While they would
ideally not be initializing them during hphp_process_exit(), it might happen.

It is also legitimate for random HHVM logic used by the CLI client to use
singletons.

So make sure folly::Singleton stuff is properly initialized.
