Commit title: Remote connections
Commit body:
Summary:
`ThriftTransport` can now allocate a ServiceRouter client instead of a plain Rocket channel.

Example:
```
ConnectionOptions opts(/*serviceName=*/"mcrouter.proxy");
auto conn = std::make_unique<MemcacheExternalConnection>(opts);
```

This diff lays the foundation for routing cache traffic via a proxy service. Making the change in `ThriftTransport` reduces impact on the codebase, as we can reuse existing logic in `ExternalCarbonConnectionImpl` for handling external connections.

Notice at this time we are allocating two separate thread pools: one in `ExternalCarbonConnectionImpl`, and one in ServiceRouter. It may be possible to have a single shared pool in the future, though keeping them separate may be safer unless there are strong perf requirements.
