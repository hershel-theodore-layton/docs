Summary:
D74084534 fixed most of the flakiness in `ObserverIsNotifiedOnWriteSuccessRequestStream` but not all. Another source of flakiness that happens in ~10% of cases both on macOS and Linux is caused by getting multiple server connections in `forEachConnection` (likely because closing the initial connection hasn't been completed - another race). This causes a failed `CHECK` in `ManagedObserver::addedToObserverContainer` because the same observer cannot be added to more than one container:

```
CHECK(!ctr_);
```
