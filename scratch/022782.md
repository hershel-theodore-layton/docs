Commit title: Use C++ Scoped Enum as Thrift Union's Type
Commit body:
Summary:
This diff rolled out using C++ Scoped Enum as Union's Type for thrift files under the 'fbcode/thrift' directory since

1. Enum classes are safer than the unscoped enums (https://isocpp.org/wiki/faq/cpp11-language-types#enum-class).
2. With this change, we can drop the `_ref` suffix when accessing the fields in thrift unions later.

For example, for thrift union

```
union MyUnion {
  1: i32 field_1;
  2: string field_2;
  ...
}
```

Before this diff, we generate the following C++ code:

```
class MyUnion {
 public:
  enum Type {
    __EMPTY__,
    field_1,
    field_2,
    ...
  }
};
```

After this diff, it becomes

```
class MyUnion {
 public:
  enum class Type {
    __EMPTY__,
    field_1,
    field_2,
    ...
  }
};
```
