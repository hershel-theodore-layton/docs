Summary:
Introducing a new optional field `thrift_uri` in `ThriftService`. This field carries latest thrift universal name (thrift URI). Notice, thrift_uri will only be available when package name is present.

for example:
metadata.cpp
```
module_MyService.name() = "module.MyService";
// vvv new field vvv
module_MyService.thrift_uri() = "test.dev/fixtures/basic-structured-annotations/MyService";
```

which aligns with the information provided by generated thrift clients:
```
::apache::thrift::MethodMetadata::Data(
                "first",
                ::apache::thrift::FunctionQualifier::Unspecified,
                "test.dev/fixtures/basic-structured-annotations/MyService")
```
