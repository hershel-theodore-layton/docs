Commit title: Fix a bug that F14Map::insert_or_assign(...) moves l-value reference argument
Commit body:
Summary:
The existing code `std::forward<M>(obj)` is likely a typo. The correct code should be `std::forward<M2>(obj)`.

The problem is that `std::forward<M>(obj)` always moves `obj` even if the input `M2` is l-value reference (since it's equivalent to `static_cast<M&&>(obj)`, where `M` is the template parameter of `F14BasicMap`).

Note that only the fallback implementation has this bug. The main implementation is fine:

https://github.com/facebook/folly/blob/v2025.05.05.00/folly/container/F14Map.h#L410-L417
