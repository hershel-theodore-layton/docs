Commit title: switch from property to descriptor
Commit body:
Summary:
Improve field access for non-primitive types by switching from `property` to descriptor protocol, as is used in mutable python. We can be much more efficient with our own descriptor object defined as cython `cdef class`.

Benchmark improvements in field access:
- string uncached: 0.000220 ms vs 0.000971 ms before
- string cached:  0.000100 ms vs 0.000230 ms before
- enum uncached: 0.000340 ms vs 0.001172 ms before
- enum cached: 0.000080 ms vs 0.000231 ms before
- nested struct uncached: 0.000571 ms vs 0.001292 ms before
- nested struct cached: 0.000100 ms vs 0.000230 ms before

| field type | py-deprecated (μs)  | python before  (μs) | python after (μs) |
| -- |
| str 1st  | 0.090 | 0.971 | 0.220 |
| str 2nd  | 0.070 | 0.230 | 0.100  |
| enum 1st  | 0.090 | 1.172 | 0.340  |
| enum 2nd | 0.070 | 0.231 | 0.080   |
| struct 1st  | 0.090 | 1.292 | 0.571  |
| struct 2nd | 0.090 | 0.100 | 0.100  |
| list 1st  | 0.080  | 1.021 | 0.220 |
| list 2nd  | 0.080  | 0.241 | 0.090  |
| set 1st  | 0.080  | 1.041 | 0.250 |
| set 2nd | 0.080  | 0.250 | 0.090 |
| map 1st | 0.080  | 2.443 | 1.622 |
| map 2nd | 0.090 | 0.261 | 0.100 |

Also partially fixes following bugs:
- `del` of attribute is ignored if field is set.
- `object.__setattr__` would succeed and mutate.

Now we consistently `raise AttributeError` for non-primitive types.
