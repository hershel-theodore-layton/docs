Commit title: make client take setup meta as input
Commit body:
Summary:
The `RequestSetupMetadata` is required for each rocket connection, but it is always serialized before we create the rocket client. This creates two problems:
1. [major] rocket client cannot even see its own `RequestSetupMetadata`!
2. [minor] direct users of the RocketClient has to figure out how to create the setup frame themselves, causing many duplications

In this diff, we make the following changes:
1. make `RocketClient` take `RequestSetupMetadata` as input, as opposed to `SetupFrame`
2. change downstream upstream users to pass in the `RequestSetupMetadata` directly.
