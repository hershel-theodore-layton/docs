Combines the ergonomics of visitation's visit_union with the power and nondependence on metadata of always-on reflection.
While `invoke_by_field_id` provides the same capability, the API is not intuitive and there's some boilerplate which this function encapsulates. In addition, the API similarity with `visit_union` will facilitate migration.
