Summary:
`//folly/portability:gtest` is neither portable nor needed and just adds an unnecessary compilation overhead and issues with xplat. Instead of fixing the uses one by one, migrate all of them with the following codemod:

```
zbgs -l '//folly/portability:gtest' -f fbcode/thrift | \
  xargs sed -i 's|//folly/portability:gtest|fbsource//third-party/googletest:gtest|g'

zbgs -l 'folly/portability/GTest.h' -f fbcode/thrift | \
  xargs sed -i 's|folly/portability/GTest.h|gtest/gtest.h|g'
```
