Commit title: Migrate to standard gmock
Commit body:
Summary:
`//folly/portability:gmock` is neither portable nor needed and just adds an unnecessary compilation overhead and issues with xplat. Instead of fixing the uses one by one, migrate all of them with the following codemod:

```
zbgs -l '//folly/portability:gmock' -f fbcode/thrift | \
  xargs sed -i 's|//folly/portability:gmock|fbsource//third-party/googletest:gmock|g'

zbgs -l 'folly/portability/GMock.h' -f fbcode/thrift | \
  xargs sed -i 's|folly/portability/GMock.h|gmock/gmock.h|g'
```

A similar change has already been done for gtest in D74507440.
