Summary:
Modify `fromRawTree` so it can populate the tree aux data when converting from a sapling tree into the eden tree. We check the returned digest_size of the tree aux data to determine if it's a valid aux data. We skip storing it if it's invalid.
Later we might want to force sapling to always return a valid tree aux data but for now let's go with the naive way.

## Context
Currently we fetch TreeAuxData directly from the backing store without caching. We want to add cache support. The cache will be consist of the in-memory cache (in ObjectStore) as well as the local store.
