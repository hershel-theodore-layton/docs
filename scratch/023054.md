Commit title: remove tuple cache in cinder
Commit body:
Summary:
We currently do redundant caching in cinder:
1. caching in slot via `cinder.cached_property`
2. caching in `._fbthrift_field_cache` tuple.

This is wasteful of memory, particularly in cases where a struct has a "sparse" access pattern, meaning many of its fields are never accessed, so the `tuple` contains disproportionately many nullptr.

This does not regress cinder repeated field access benchmark, and it slightly improves first access about 10% because no field set step. It also appears to improve struct init.

With this diff:
```
| Field Access (First/Uncached)   | val_string   | val_enum    | val_struct   |
|---------------------------------|--------------|-------------|--------------|
| py-deprecated                   | 0.000090 ms  | 0.000090 ms | 0.000090 ms  |
| py3                             | 0.000140 ms  | 0.000330 ms | 0.000121 ms  |
| python                          | 0.000160 ms  | 0.000370 ms | 0.000280 ms  |
| mutable-python                  | 0.000260 ms  | 0.000430 ms | 0.000440 ms  |
```
