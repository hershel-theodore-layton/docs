Summary:
This diff adds two main feautres. It allows users of service framework to add a custom load header supplier as well as supporting fb303 counter based load header. The behavior is as follows

1) if “load” : “default” is passed by the client the server will return the default load counter, or it will return the a load value from the load supplier.

2) if “load” : “foo” is passed, then it’ll return the value for fb303 counter “foo” assuming it exists.

The oubout header will be added in the “load” field on the returned request.
