Commit title: Add ability to pass routing identifier through RpcOptions
Commit body:
Summary:
Add ability to pass web phase routing identifier through `RpcOptions`. It will be passed to `WebPoolSelector` library once it's integrated in D74011364.

Sample use:

```
apache::thrift::RpcOptions rpcOptions;
auto scopeResolutionMetadata = std::make_shared<servicerouter::ScopeResolutionMetadata>();

servicerouter::WebPhaseRoutingParameters phaseRoutingParams;
phaseRoutingParams.identifier() = "userId";

scopeResolutionMetadata->rpcWebPhaseRoutingParameters() = phaseRoutingParams;
rpcOptions.setCallerContext(std::move(scopeResolutionMetadata));
```
