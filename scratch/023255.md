Commit title: Support prioritize() on PriorityBridgeWHs
Commit body:
Summary:
Add functionality to prioritize() a PBWH. This allows the child to be lifted into the context state of the PBWH, and then maintain a priority that is >= to the PBWH. Specifically:
- entering the pbwh into a new context, after prioritize(), will ensure the child is in the same context
- child can separately be lifted into another context, if held somewhere else

This allows a class of work to be started in a low priority context, and then that work can be lifted back into a higher priority context.
