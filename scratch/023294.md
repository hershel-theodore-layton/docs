Commit title: Polymorphic lambda
Commit body:
Summary:
Adds syntax & typing for polymorphic lambda:

```
$f = function<T as C>(T $c):T ==> $c;
```

The syntax has the same restrictions as polymorphic function hints i.e. polymorphic lambdas cannot:
- Have variance annotations
- Be reified
- Have attributes with expression arguments
- Be higher-kinded
- Shadow any type paramter in an enclosing class or method (type parameter names can be reused across different hints, though)

In addition we require that the return hint and all parameter hints must be explicit for polymoprhic lambda expressions.

Before this change you could create polymorphic function references so there are no new subtyping rules are added here.
