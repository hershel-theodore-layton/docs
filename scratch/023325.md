I plan to add support for predicates for class types with erased generics; in this case, converting such a predicate to a type would involve instantiating it with fresh generics which might be inappropriate to do for arbitrary subtyping computations.

In order to avoid this, this diff replaces the question of "Is A a subtype of the type associated with predicate P" with the similar question "Would a value of A always pass predicate P"
