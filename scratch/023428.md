Commit title: Avoid unnecessary allocations in TDigest merging
Commit body:
Summary:
`TDigest` uses radix sort for large value arrays, and `std::sort` otherwise, but in both cases it allocates the working buffer for radix sort, which is very large: the bucket counts require 18kB.

By moving the size dispatching outside of `double_radix_sort()` we can avoid the allocation, since we don't need the bucket counts, and small arrays are small enough that we can keep the working buffer on the stack.
