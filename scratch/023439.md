Commit title: `capture_{const,mut}_ref` passes plain refs into `async_now_closure` as capture refs
Commit body:
Summary:
A simple use-case for capture-by-reference is this:

```
SomeAccumulator acc;
co_await async_now_closure(
    bound_args{capture_mut_ref{acc}, ...},
    [](capture<SomeAccumulator&> crAcc, ...) {
      // ... run async scope tasks concurrently calls `crAcc->recordResult(...)`
    });
```

You could run the above work on `SafeAsyncScope` with plain refs, since their safety isn't sufficiently constrained.

When applicable, you should prefer to `as_capture()` values and use the slightly safer `AfterCleanup.h`, instead of this capture-by-reference pattern.

However, not all accumulator patterns are amenable to being moved out. For example, `std::atomic` is immovable.  Additionally, capture-by-reference lets you share the same accumulator across several unrelated sub-closures. And it is much, much safer than using `manual_safe_ref` and hoping that no future edit breaks your lifetime contract.

The immediate motivation for adding this is that the upcoming result collector API will sometimes benefit from this pattern, when used together with `SafeAsyncScope`.
