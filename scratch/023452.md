### Diff Summary

Prevent Client from Sending Checksum When Checksumming Strategy Isn't Present
====================================================================================

### Overview

This diff modifies the `RocketClientChannel` class in both `xplat` and `fbcode` directories to prevent clients from sending checksums when the checksumming strategy is not present.

### Key Changes

*   Added a check to see if the payload serializer supports checksums.
*   If checksums are not supported and a checksum is set, log a warning message and reset the checksum algorithm to `NONE`.

### Rationale

The purpose of this change is to prevent clients from attempting to send checksums when the checksumming strategy is not present. This helps maintain data integrity and prevents potential errors during data transmission.

### Impact

This change affects the `RocketClientChannel` class in both `xplat` and `fbcode` directories. It ensures that clients do not send unnecessary checksums, which can improve overall system performance and reliability.
