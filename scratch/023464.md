Summary:
Add more unit tests increasing coverage of `stream` and `oneway`; also rocket vs header client type.

Also re-organize the unit tests to de-duplicate the logic. There are now three levels:
- `BaseInterceptorTestCase` handles server setup and the context managers to setup a client that can process calls.
- `BasicServiceTestCase`, `OnewayServiceTestCase`, `StreamingServiceTestCase` define the calls to the clients and assert their expected returns, assuming no interceptors.
- `CountingInterceptorBasicTest` etc. each mix one interceptor (aka `observer`) with one of the three services and assert the expected observable interceptor behavior.

We have 4 interceptors:
- `CountingInterceptor` validates non-throwing interceptor calls
- 3 other interceptors validate behavior for throws in `onConnection`, `onRequest`, `onResponse`. There is no test for throw in `onConnectionClosed` because the interface method is `noexcept`; therefore terminate is the expected behavior.
