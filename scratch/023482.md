Commit title: Add missing break to generated visit_union() code for field-less unions
Commit body:
Summary:
As title.  This was causing a build break for unions that have no fields, in
that case we just get an empty "(void)0" case followed by a default, without a
break label in between.

Example:
```
template <>
struct VisitUnion<::facebook::iaas::resource_allowance_system::MyUnion> {

  template <typename F, typename T>
  decltype(auto) operator()([[maybe_unused]] F&& f, T&& t) const {
    using Union = std::remove_reference_t<T>;
    switch (t.getType()) {
    case Union::Type::__EMPTY__:
      (void)0;
    default:
      throw std::runtime_error{folly::to<std::string>(
          "Enum got invalid value ",
          static_cast<std::underlying_type_t<decltype(t.getType())>>(
              t.getType()))};
    }
  }
};
```

So C++ compilers refuse to build stuff (thankfully).
