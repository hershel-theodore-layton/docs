Commit title: Do not reject method overriding method with type-splat parameter
Commit body:
Summary: HHVM incorrectly rejects a method such as `foo(int $x, string $y)` implementing a method of type `foo(...T $x)` where `T` has been instantiated to `(int,string)`. By distinguishing type-splat from variadic parameters, we can avoid rejecting the use of type-splat parameters in the overridden method.
