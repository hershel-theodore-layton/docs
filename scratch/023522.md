Summary:
Migrate function's `cpp_name` to Whisker with the following codemod:
```
zbgs -l function:cpp_name -f xplat/thrift/compiler/generate | \
  xargs sed -i 's|function:cpp_name|function:self.cpp_name|g'
```
Remove `function:cpp_name` and function-specific `cpp_name` in Whisker C++ codegen (mistakenly introduced in D73397558) since both are redundant now that `cpp_name` is provided by any named AST node.

Eventually the `self` part will go away giving identical ergonomics on the template side but without the complexity and redundancy of mstch objects on the C++ side.
