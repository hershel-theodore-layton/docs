Commit title: Change deserialization logic to default construct struct type instead of doing per-field assignment+move
Commit body:
Summary:
The use of `Self::default()` here is in line with [the thrift spec](https://www.internalfb.com/intern/staticdocs/thrift/docs/idl/#intrinsic-default-value) and results in simplified template code and logic, as well as less generated code.

This has the trade-off where we'll do an unnecessary and potentially expensive allocation+initialization followed by dropping it in the error path if one field fails to deserialize, but for most workloads I don't expect that to be common or meaningful.

This also opens the door for other approaches, e.g. deserializing into a user-provided object or onto a heap-allocated object.
