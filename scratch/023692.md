Commit title: Add print call for debugging
Commit body:
Summary:
Hack Notebooks call `BentoHack::display()` to print values. Since [BentoHack::display uses](https://www.internalfb.com/code/fbsource/[578fc79c053ffdce2e84764a719e730bc51e771e]/www/flib/intern/bento/BentoHack.php?lines=133) `print_r` to display values, the outputs are not formatted for debugger display like in `hphpd` or `fbdbg`. This is an unfortunate experience since many Hack objects specify a function `__toDebugDisplay` that exists just for readable printing to a debug console.

If we create a new print function to expose this functionality, Bento notebooks can display outputs that respect `__toDebugDisplay`.

[Here's](https://fb.workplace.com/groups/768246428434224/posts/1118843656707831/?comment_id=1118973410028189&reply_comment_id=1121006499824880) a discussion of other alternatives and why creating a new print method might be the easiest solution.
