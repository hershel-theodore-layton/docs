Commit title: Edenfs_watcher: handle directory renames
Commit body:
Summary:
When a folder gets renamed, Eden gives us a `LargeChangeNotification::DirectoryRenamed` notification, containing the old an new path.

In contrast, hh_server expects to be told about all the affected files individually. To bridge this gap, we handle being informed about `foo` being renamed to `bar` as follows:
1. Look up all the files in folder `bar`. Notify `hh_server` about all of them.
2. For each file in step 1, determine where it must have been beforehand (by translating the path `foo` to `bar`, effectively inverting the renaming. Notify hh_server about these paths, so that it can note that the file no longer exists at this path.
