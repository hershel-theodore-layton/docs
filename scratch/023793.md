This is mildly jank. There is a place in the codegen that really uses classnames instead of classpointers because it uses and unsafe cast to lie to hack that a class that doesn't yet exist DOES exist. Luckily, because of that, we can be quite confident that we're not actually invoking off that non-existent class.

As such, forward the UNSAFE_CAST to coerce the type to a class pointer to match the schema during codegen.
