1. rename reified_generics_info.h to generics_info.h. The struct definition in this file is shared between class and func.
2. rename getReifiedGenericsInfo -> getGenericsInfo() and make this a vanilla getter instead of conditionally returning this based on the reified info flag. Given this, all current usages of this function must be guarded by checking hasReifiedGenerics.
