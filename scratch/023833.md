Commit title: Update the notion of `this` when accessing type constants through intersections and unions
Commit body:
Summary:
When accessing a type constant through union and intersection types, the notion of `this` contained in the `expand_env` should be updated for each element.

This is particularly important when the access type constant contains a fixpoint refinement and one of the elements of the union/intersection is an expression dependent type. Unless we update `this` to that expression dependent type we will fail to properly expand the type constant.
