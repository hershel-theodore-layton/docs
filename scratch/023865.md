Commit title: remove some clang warning flags so liburing external lib compiles
Commit body:
Summary:
Liburing 3rd party library has clang warnings when built with these clang flags (`Wnested-anon-types`, `Wzero-length-array`) . This diff disables these warnings so that liburing can be built with buck modes that have these clang warnings (like fbsource//arvr/mode/platform010/dev-tsan for example).

For more context the target I am building is `buck build --keep-going --flagfile fbsource//arvr/mode/platform010/dev-tsan fbsource//arvr/libraries/immersion/reconstruction/servers:pc_app --show-output` from this [diff](https://www.internalfb.com/diff/D76423109) which eventually pulls in liburing as a dependency. The reason we haven't had this problem is probablly because arvr never pulled this file as a dependency.
