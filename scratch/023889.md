Summary:
This diff adds support for filtering what files `Edenfs_watcher` should watch, by providing it a `FilesToIgnore.watch_spec` when initializing an `Edenfs_watcher` instance.

Concretely, the instance maintained by `ServerNotifier` now only watches files according to `FilesToIgnore.server_watch_spec`.

Note that so far we only filter those changes directly received from Eden. That means we don't filter a) files in renamed folders and b) files changed due to `hg update` and friends.
