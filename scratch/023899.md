Commit title: Add file name support to hdf nodes
Commit body:
Summary:
See test plan for demo.

Essentially, adding file name support to the core of Hdf Tree parsing such that we can trace which file a specific config option was read from. With support for inheritance, this should make tracing options super easy.

A few highlights/ decisions:
* Only keeping track of filenames for leaf nodes since only leaf nodes actually contain values. Other than saving the fraction of space, the leaf nodes are the source of truth because interstitial nodes are only created once.
* If a node is set twice to the same value, the file of the first one wins. This is how the config option works in HHVM.
* However, if the node has the same name but different values, this is a classic override and the overriding file wins.
* Also, making the file path resolve .. to look prettier in another diff ie: www/scripts/hphp/configs/tenants/../config.hdf -> www/scripts/hphp/configs/config.hdf
