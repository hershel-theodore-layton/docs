Commit title: Ban accessing static properties on traits
Commit body:
Summary:
Accessing static properties off of a trait is a footgun.

When one `use`s a trait the using class also has a static property of the same name, but this static property is completely different than the one that belongs to the trait.

Consequently, updating the property on the trait does not reflect any changes on the static property of the class and vice versa.
