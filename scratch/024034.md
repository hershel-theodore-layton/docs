# Problem Statement
With typing=True for thrift library generated python code,
```
arc pyre check fbcode//thrift/lib/py3/...
arc pyre check fbcode//thrift/lib/python/...

```
causes errors like below:
```
Type errors in target fbcode//thrift/lib/python/client/test:test_service-python-clients
../buck-out/v2/gen/fbcode/61bbc0732de1e68d/thrift/lib/python/client/test/__test_service-python-test.thrift__/out/gen-python/thrift/python/test/thrift_clients.py:107:32 Undefined attribute [16]: `_fbthrift__thrift__python__test__thrift_types._fbthrift_TestService_divide_result` has no attribute `_ex0__ae`
```

This error also occurs with

```
buck2 test fbcode//thrift/lib/py{3,thon}/...
```

# Fix
Given this is an intentionally mangled name, add a pyre-ignore to suppress that error.
