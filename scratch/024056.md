## What

When generating a Hack file (.php) from a notebook (.ipynb json), don't generate main function if there are no top-level statements.

## Context

[Source control notebooks for Hack](https://fburl.com/source_control_notebooks_for_hack_announcement)

## Why

- No point in generating empty functions that aren't called
- When we generate the empty functions, it can [cause user confusion when Dead Code Bot tries to remove the empty functions](https://www.internalfb.com/diff/D76976870?dst_version_fbid=1080338854009047&transaction_fbid=1418964729439696)
