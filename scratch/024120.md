Commit title: Warn against static property redeclaration
Commit body:
Summary:
Static property redeclaration is a footgun because it causes a separate static property be generated. In that sense it is not a (re)declaration but just a separate declaration.

```
<?hh

class C {
  public static vec<int> $p = vec[];
}

class D extends C {
  public static vec<int> $p = vec[];
}

<<__EntryPoint>>
function main(): void {
  C::$p[] = 1;
  D::$p[] = 2;
  var_dump(C::$p); // vec[1]
  var_dump(D::$p); // vec[2]
}
```

This diff warns against redeclaration.

We'd like this to be an error eventually.
