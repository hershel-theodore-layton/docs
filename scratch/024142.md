Commit body:
Summary:
Modifies the typing of `meth_caller` for polymorphic instance methods so that the result is a polymorphic function type. This typing is identical to the typing of function references to polymorphic static methods in D74076920 except that there is an implicit first parameter with type identifier `this`.

You can see the effect of this typing in the updated output of existing tests:
- meth_caller_this_parametric.php - now that we are polymorphic in `this` the test passes without error
- meth_caller4.php - since we aren't using type variables there is no longer an error in this case
