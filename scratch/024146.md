Summary:
**Context:**
In .thrift files, and the thrift compiler, enum values are typically represented by their int equivalent. That means that enums can be "coerced" to ints, and vice versa. For example, the following works:
```
enum Foo { a = 1, b = 2 }
enum Bar { a = 2, b = 3 }

const Foo my_foo_a = 1; // my_foo_a == Foo.a
const Foo my_foo_b = Bar.a; // my_foo_b = Foo.b
const Bar my_bar_b = b; // a may refer to Foo.a, so my_bar_a == Bar.a
```
As we can see, this is an unfortunate behavior, especially when combined with "unscoped" enum values.

Goals: the following should trigger the validator:
```
const Foo my_foo_b = Bar.a; // validator FAIL
const Bar my_bar_b = b; // validator FAIL
const list<Foo> = [Bar.a]; // validator FAIL
const map<Foo, string> = {Bar.a: "foo_b"}; // validator FAIL
```

This diff is to Implementing the validator and just make it warning.
