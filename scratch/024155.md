Summary:
This is a refactoring that results from consolidating code based on the fact that we don't encounter higher-kinded types anymore.

Currently, there are two pairs of closely related functions in `Typing_phase`: In both pairs, one function is  "kinding aware" function that performs some logic, and the other function is just a small wrapper around the former.

## First pair: `localize_targs_with_kinds` and `localize_targs`.
The former acts on kind information directly (represented as a list of `Typing_kinding_defs.Simple.named_kind`), while the latter calls the former with kind information obtained from the `decl_tparam` list it takes as an arguments.
In the absence of higher kinded types, we only need `localize_targs`, but not `localize_targs_with_kinds`.

Logically, this just inlines `localize_targs_with_kinds` into `localize_targs`.
*How to review*: The actual changes in the file make it look the other way around: The diff turns `localize_targs_with_kinds` into the function you would get from inlining `localize_targs_with_kinds` into `localize_targs`.

## Second pair: `localize_targ_with_kind` and `localize_targ`.
After the changes described above, we don't need `localize_targ_with_kind` anymore, and turn it into `localize_targ`.

*How to review*: Same here, we turn `localize_targ_with_kind` into the function you would get from inlining `localize_targ_with_kind` into `localize_targ`
