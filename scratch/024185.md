Commit body:
Summary:
# Why?
Errors like the one below happen because the `__init__` for the service args structs doesn't include the thrift container wrapper type.

# Solution
`init_and_call_args_types.mustache` defines the correct types for the struct `__init__` calls. Leverage the same for the function args `__init__` as well.

# How
1. Extract the struct specific iteration out of the partial, and surround the invocation of the partial with the appropriate iterator - `struct:fields_ordered_by_id` for structs (the current change - {D77073089})
1. Use the `init_and_call_args_types` partial surrounded by `function:args` for the function case (the next change {D77073086})
