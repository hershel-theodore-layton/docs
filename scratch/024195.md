Summary:
This diff renamed a mustache node to clarify the usages.

Why? Includes that are needed in runtime is slightly different from includes that are needed by patch.

Particularly, if we have

```
// bar.thrift

python.Adapter{...}
typedef i32 MyInt
```

we don't need the PatchNode of bar.thrift since we don't need to generate patch struct for MyInt. So bar.thrift is not needed by Patch.

However, normal python code still needs bar.thrift to import MyInt.
