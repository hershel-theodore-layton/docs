Summary:
Migrate `cpp_return_type` and `cpp_void?` to Whisker with the following codemod:

```
zbgs -l function:cpp_return_type -f xplat/thrift/compiler/generate | \
  xargs sed -i 's|function:cpp_return_type|function:self.cpp_return_type|g'
zbgs -l function:cpp_void -f xplat/thrift/compiler/generate | \
  xargs sed -i 's|function:cpp_void|function:self.cpp_void|g'
```

Eventually the `self` part will go away giving identical ergonomics on the template side but without the complexity and redundancy of mstch objects on the C++ side.
