Commit body:
Summary:
This diff enables services to disable the previously always-on behavior of syncing Thrift Server's maxQps to resource pool's executionRate.

Note:
- The default value for this flag is `false`. Before this diff, the implicit default was `true`.
- All services that relied on this behavior in the last two weeks have this flag overridden to `true`, preserving the behavior they may rely on.
- We don't want people to rely on this behavior. Any serve that has this syncing behavior will log a warning message citing a guide that shows how to safely turn this behavior off.
