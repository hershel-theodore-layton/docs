Summary:
# The errors
With type-checks for generated types enabled, the command

```
arc pyre check  fbsource//xplat/thrift/test/testset/...
```
fails with **P1854874233**. E.g.

```
Invalid type [31]: Expression `typing.Iterator[typing.Tuple[(str, typing.Union[thrift.python.test.adapters.noop.Wrapped[thrift.python.types.MapTypeFactory(thrift.python.types.AdaptedTypeInfo(thrift.python.types.typeinfo_i64, thrift.python.test.adapters.noop.Wrapper, lambda () (None)), thrift.python.types.AdaptedTypeInfo(thrift.python.types.typeinfo_string, thrift.python.test.adapters.noop.Wrapper, lambda () (None)))]])]]` is not a valid type.
```

# The reason
`MapTypeFactory`, `AdaptedTypeInfo`, etc are runtime types. The type above is in a type stub and should be a type hint.

# The fix
Replace the runtime types with type hints.
