Summary:
Rather than have `PythonAsyncProcessor` store a map of 3 `PythonMetadata`, just create them as needed. The `PythonMetadata` only has enum elements, so it's cheap to create.

Reasoning: the current logic is hard to follow. Also, the map lookups are not free. By removing the map, we mildly decrease the memory footprint. The cost of allocating the `shared_ptr` is offset by removing the map lookup.
