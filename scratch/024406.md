Commit title: Merge SourceIndexedTypeSystem into TypeSystem
Commit body:
Summary:
Turns out having a separate class doesn't serve all that much value. This is because `SourceIndexedTypeSystem` *still* isn't guaranteed to have complete source information available — there may be some times which remain un-named. So `dynamic_cast<SourceIndexedTypeSystem*>(...)` doesn't really provide any valuable insight to the user — no invariants are affected.

This diff merges `SourceIndexedTypeSystem` into `TypeSystem`. Implementations that are missing source information *by design* should return empty results from each method. This change also brings `TypeSystem` in-line with `type_system.thrift` (which optionally contains source information).

A future diff will implement source information support in the `TypeSystemFacade` that accompanies `SyntaxGraph`.
