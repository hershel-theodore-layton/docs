Commit title: don't populate primitive fields

Summary:
Eagerly populating primitive fields on struct initialization causes poor performance when initializing large structs. Make this lazy! Defer it until field is accessed.

## Field access
In cinder we don't actually see any regression because attribute access is cheap, so extra `.__get__` descriptor field access is low cost. In CPython, we do see a 25 ns regression on first field access but almost no regression on repeated field access (may be a hardware cache artifact). But thrift immutable python field access still cheaper in Cpython than mutable python.
