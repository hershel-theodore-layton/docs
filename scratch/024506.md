Commit title: impl FallibleString type
Commit body:
Summary:
Adds a `FallibleString` type to Python C-API. This type represents Python user-facing type `str` with internal type `str | bytes`.

- Deserialization (Python C-API `Constructor`) attempts to make Unicode `str` but suppresses `UnicodeDecodeError`, saving `bytes` as a fallback.
  - This mimics the behavior of `string` fields in thrift-python, where it's possible to round-trip invalid unicode through serde as long as the invalid unicode field isn't accessed from Python.
  - Accessing the field either returns `str` or raises the `UnicodeDecodeError` from decoding the `bytes`.
- Serialization (Python C-API `Extractor`) first tries to extract bytes from `Unicode`, then from `Bytes`.
