Summary:
We need to enumerate URIs to be able to convert TypeSystem to SerializableTypeSystem. However, for some implementations (such as bundled `SchemaRegistry`), this is not possible nor desirable.

Let's make this case explicit so that a (future) `toSerializableTypeSystem` function can easily catch these cases and report an error.
