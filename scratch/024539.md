# This diff

This moves the AsyncProcessorFactory implementation details to a new `.cpp` associated with the existing `async_processor_factory` build rule.

It is almost certainly an oversight that this implementation wasn't already moved into such a file, since it doesn't make much sense to have the AsyncProcessorFactory header in the `async_processor_factory` build rule and the AsyncProcessorFactory implementation separated into the `async_processor` build rule.

# Diff chain overview

This is part of our effort to simplify Thrift's AsyncProcessor. At the end of this diff chain, the following will be true.

- AsyncProcessor implementation will live in its own folder next to where the original `AsyncProcessor.{h|cpp}` lived. That folder will be called `processor`.
- Wherever classes can be placed into their own file and build rule, they will be.
- Cyclic dependencies will be ironed out and be made acyclic.
- The original `AsyncProcessor.{h.cpp}` will just be a glob of headers for the implementation that has been moved to the `processor` folder.
