Summary:
This was landed earlier this year by accident in {D67542150}, then reverted in {D68064760} due to test breakages.

I have fixed the tests observed to have been broken in T212417779. There were only two.

For toml 0.8, this feature is not terribly significant. However, toml 0.9 performs more internal buffering using `toml::map::Map`, so the choice of map representation makes a big difference. For example, for the following `linttool` test it is critical that tables are deserialized with order preserved because the order of the remap operations is significant. Toml 0.8 did that with or without the "preserve_order" feature, but toml 0.9 does not.
