Summary:
## Intro

This diff introduces support for the `??` (question question, coalesce) operator in expression trees.

## Motivation

1. Convenience
2. Verbose handling of null values
2. Reduce unsafe type conversions

## Implementation

The virtual expression produced by an expression tree that contains the `??` operator includes a usage of the `??` operator itself.

Source:
```
MyDsl`... ?? ...`
```

Virtualized:
```
... ?? ...
```

Desugared:
```
$0v->visitBinop(new ExprPos(...), ..., '__questionQuestion', ...)
```

Using `??` directly in the virtual expression correctly refines the result type now that `MyDsl::nullType()` has been removed and ET use `null` as the null type by default.

## Alternative approaches explored

The initial implementation created a virtual expression with a call to the `__questionQuestion` instance method. Initially the call used the null safe ObjGet operator (`?->`) in order to support DSL where `MyDsl::nullType() : null`.

Source:
```
MyDsl`... ?? ...`
```

Virtualized:
```
...?->__questionQuestion(...)
```

In any case this approach didn't refine the type correctly, so I took the alternative approach of producing a virtualized expression which directly uses the `??` operator.
