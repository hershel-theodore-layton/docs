Commit title: Fix omitted $this initialisation checks
Commit body:
Summary:
We were shortcircuiting initialisation checks while determening which properties are initialised. This makes sense, however, the same logic that collects initialised properties also emits errors on premature `$this` usage. This leads to typeholes and compromises soundness.

This diff fixes it by preventing the shortcircuiting behaviour in various constructs.

The extebded support covers:
* `throw` arguments
* `for` condition, increment, and block
* `while` block
* `foreach` block
