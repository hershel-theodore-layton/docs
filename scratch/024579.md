Commit title: Ensure all constructors in t_named hierarchy take const t_program*
Commit body:
Summary:
`t_named::program_` stores a `const t_program*`, so ensure all constructors in the hierarchy take a `const t_program*`. This allows callers to construct these types even if they only have a const pointer, without having to get a mutable pointer or `const_cast` away the const-ness of the pointer.

Unblocks removal of the deprecated `t_program_bundle::get_programs` / `t_program_bundle::get_root_program` methods, which have some callers that currently require a non-const pointer just to construct some of these AST node types, but otherwise can be satisfied with only a const pointer.
