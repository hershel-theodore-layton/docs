# Null safe ObjGet operator in expression trees

This proposal, in conjunction with the proposal to introduce support for Coalesce operator in expression trees, aims to enhance the ergonomics of null-safe operations in expression trees.

## Motivation

1. Convenience
2. Verbose handling of null values
2. Reduce unsafe type conversions

## Implementation

The resulting virtual expression contains the `?->` operator.

Source:
```
MyDsl`(...)?->foo`
MyDsl`(...)?->foo(...)`
```

Virtualized:
```
(...)?->foo
(...)?->foo(...)
```

Desugared:
```
$0v->visitPropertyAccessNullSafe(new ExprPos(...), ..., 'foo')
$0v->visitInstanceMethodNullSafe(new ExprPos(...), ..., 'foo')
```

## Alternatives

1. New optional bool param on `visitPropertyAccess` and `visitInstanceMethod` (current implementation)
2. New optional enum param on `visitPropertyAccess` and `visitInstanceMethod`
3. New signatures `visitPropertyAccessNullSafe`, `visitInstanceMethodNullSafe`

Option (3) has been chosen as a tradeoff between extensibility and simplicity.
