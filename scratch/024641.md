# Context
* As a step in the [thrift-py-deprecated to thrift-python unification](https://fb.workplace.com/groups/1730279463893632/permalink/4028863820701840/), this diff enables the generation of `thrift-python` code for transitive thrift library dependencies that already generate `thrift-py-deprecated` code.
* As long as the assumption that there is no code that depends on the generated `thrift-python` code because it didn't exist before holds true, and the diff has green signals, you can safely land this diff.

# Description of changes
1. Adds `python` to the `languages` in the `thrift_library`.
2. Adds a `py3_namespace` to the `thrift_library`, unless one already exists.
3. Adds a `namespace py3` to the thrift file(s) unless the file(s) already have a `namespace py3`. If the thrift files are from configerator, then it makes the change to the configerator files and syncs the file to `fbcode`.

# Choice of `namespace`
The process that generates this diff uses the value of the `py_base_module` to determine the value of `py3_namespace`. If this diff adds a `namespace py3` to thrift file(s), then those values will match the `py3_namespace`.
* If the `py_base_module` is a non-empty string, then `py3_namespace` will match the `py_base_module`.
* If the `py_base_module` is an empty string or not present, then `py3_namespace` will be the dotted path to the buildfile (`BUCK` or `TARGETS`) that contains the `thrift_library`.
