Commit title: let CacheLocality read /proc/cpuinfo only on x86-64
Commit body:
Summary:
On Linux, the special file `/proc/cpuinfo` contains per-core information fed straight from the kernel. On most architectures, the information is minimal. On x86 architectures only, the information contains an approximation of the full core+cache topology.

The code which reads this file will, on other architectures, fail to find the expected information based on x86 and will throw an exception. Control will then pass to the next step, which is to read the special tree in `/sys/devices/system/cpu/`, which has full core+cache topology on all platforms.
