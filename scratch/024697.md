Commit title: Introduce cancellation_token_merge to merge CancellationToken instances
Commit body:
Summary:
Since CancellationToken merge can be inadvertently called on a token instance, once could write code that looks like this:

```
CancellationToken t1,t2;
CancellationToken t3 = t1.merge(t2);
```

This will make the developer to incorrectly assume the t3 is being merged while in reality t3=t2.

To prevent such behaviors we introduce a new function that will replace the `CancellationToken::merge` in the next code changes.
