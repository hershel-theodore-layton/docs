Commit title: Randomize `HeterogeneousAccessHash` for string-like types in debug
Commit body:
Summary:
X-link: https://github.com/facebook/folly/pull/2475

Enable hash randomization for `HeterogeneousAccessHash` for
string-like types to allow us change hash algorithm implementation easily in
the future.

Implementation is based on the idea from [Google Abseil hash randomization][1].
We use [ASLR][2] (Address Space Layout Randomization) to generate «random» seed
for each program invocation. Quality of «random» is platform dependent.

One notable difference from Abseil implementation is that we are not taking
address of static variable, because it creates problems, when hash value cross
shared object/binary boundary. We use address of `malloc` instead as hopefully
more stable alternative.

Following alternatives were considered.

* Address of static variable. Doesn't work well when hash cross shared
object/binary boundary.
* Address of `environ`. A lot of hustle to make it work reliable on all
platforms. On macOS for example, `environ` can be accessed from binary, but
can't be used in the shared library. Tricks to make it work collide with
existing code.
