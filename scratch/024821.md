Commit title: Rename folly::bindings to folly::bind
Commit body:
Summary:
The current naming design encourages `using namespace folly::bindings`, which results in "where did this identifier come from?" moments for the reader.

It also means that some names have to be longer.  For example, up-stack, I simplify `bound_args` to `bind::args`, `make_in_place` to `bind::in_place`, etc.

So, we gain uniform readability, and the more maintainable UX of `namespace bind = folly::bind`.
