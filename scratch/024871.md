Commit title: fix MutableMap.__eq__ behavior
Commit body:
Summary:
`MutableMap.__eq__` currently raises `TypeError` if two `MutableMap` objects with different types are compared.

This violates Python convention where `__eq__` will never throw; instead it should return `False` on type mismatch.

The current behavior diverges from :
- `MutableSet` and `MutableList.__eq__`
- immutable-python `Map`
- thrift-py3 `Map`
- thrift-py-deprecated (implicitly)

We should converge the behavior, which will unlock simpler implementation in next diff.
