Summary:
### Context
The policy `MilandaMobileBackend` (D77262156) had a string restraint type with a value of "1", but the RestraintChecker code (https://fburl.com/code/h8gi9uh2) threw an exception due to a type error. It expected a string, but got an integer instead. Same exception as seen in S227979

### This Diff
D77451050 tried to fix this issue, but it didn't work because Thrift structs kept turning intish string keys into integers even after the change. After digging deeper, I found out that the `artillery2_StringRestraint` struct was still in a list that always did the intish string cast (as explained in https://www.internalfb.com/wiki/Configerator/Configerator_Reference/Consumption_APIs/Hack_API/Configerator_Shape/#use-of-shape-arraykeys). Taking this struct out of the list finally solved the problem.
