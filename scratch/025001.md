Summary:
This diff is "mostly comments", so read those for the nitty-gritty. Here's the high-level point.

I'm about to stack a diff that permits `async_now_closure`s **not** to force the shared-cleanup downgrade. This, in turn, supports a very natural safe scatter-gather pattern:

```cpp
Output output;
co_await async_now_closure(
  bind::capture_mut_ref{output},
  [](auto out) -> closure_task<> {
    // run scope tasks or `background_task`s to write to `out`
  });
```

By restricting `member_task` usage, I gain two things:
  - It's less of a safety hole. Requiring an explicit `safe_alias` annotation is okay, since `member_task` is very much a power-user feature.
  - You can now use `member_task` with the pattern above.
