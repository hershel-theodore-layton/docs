Summary:
This diff extends the build log generated by `--report-files-in-build=<filename>` to include the reason why a file has been pulled into the repo.  Reasons can be:

- `fromPackageV2`: PackageV2 build rules pull the file into the repo;
- `fromSymbolRefs`: file is either in a `--include-dir` and not excluded via `--exclude...` or pulled in by SymbolRefs dependencies
- `fromSymbolRefsAndPackageV2`: when building with PackageV2 U SymbolRefs, this denotes files that are pulled _both_ by SymbolRefs rules _and_ PackageV2 rules
- `fromPackageV1`:  this denotes files pulled by the legacy PackageV1 support.
