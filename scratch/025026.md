Commit title: Add `bind_as_argument` for `safe_closure`
Commit body:
Summary:
`safe_closure` does two things:
 - on construction: move / copy arguments into its internal storage
 - on `operator()`, bind each stored argument as an arg to the underlying function -- using the `folly::bind::` modifiers that it was wrapped with.

`bind_as_argument()` implements the second part of this logic. Its API differs significantly from the older `bind_to_storage_policy` from `ToStorage.h`. Mainly:
  - This plumbs through a reference or value, the storage policy just computes a type.
  - Here, we default to pass-by-const-ref. The storage policy stores values, not references, by default.
