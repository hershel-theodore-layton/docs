Commit title: Add UUID accessor to elf file
Commit body:
Summary:
ELF Files can optionally contain a note that contains a unique build id

```
.note.gnu.build-id
    This section is used to hold an ID that uniquely identifies the contents of the ELF image.
     Different files with the same build ID should contain the same executable content.
     See the --build-id option to the GNU linker (ld (1)) for more details. This section is of type SHT_NOTE. The only attribute used is SHF_ALLOC.
```
But because this is both in a note, and within a section users often need elf knowledge to leverage this ID, and this is likely the second most read note after siginfo_t. Because of these reasons I've elected to centralize the logic for grabbing that note into `Elf.h` directly. Returning an expected stringpiece if available, or a detailed explanation otherwise.

Lastly, this ID is usually referred to as a UUID, but it is not a UUIDv4. So I'm open to renaming the API.
