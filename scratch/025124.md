Summary:
There seems to be some kind of exports trie generation error under some
circumstances for the library `header_client_channel`. LLD seems to generate
a malformed exports trie for it, as one can verify using `llvm-objdump`.

```
llvm-objdump: error: 'buck-out/v2/gen/fbcode/4dabced598179ca5/thrift/lib/cpp2/async/__header_client_channel__/libheader_client_channel-2ed4355.dylib': truncated or malformed object (loop in childern in export trie data at node: 0x5f back to node: 0x13b2)
```

Adding this extra variable should not really affect the export trie (it is not
used anywhere, so it is not exported), but it seems to avoid the input values
that seems to create an invalid trie.
