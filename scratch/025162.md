Commit title: Add getLocalAddress() and getPeerAddress() APIs to WebTransport
Commit body:
Summary:
This diff adds two new APIs to the WebTransport interface to retrieve socket address information:

- `virtual const folly::SocketAddress& getLocalAddress() const = 0;`
- `virtual const folly::SocketAddress& getPeerAddress() const = 0;`

## Implementation Details

**WebTransport Interface**: Added the two pure virtual methods to the base WebTransport class.

**WebTransportImpl**:
- Added the APIs to the TransportProvider interface
- Implemented methods in WebTransportImpl to delegate to the TransportProvider

**QuicWebTransport**: Implemented the APIs by delegating to the underlying QuicSocket:
- `return quicSocket_->getLocalAddress()`
- `return quicSocket_->getPeerAddress()`

**HTTPTransaction::Transport**: Already had these methods and inherits from WebTransportImpl::TransportProvider, so it works seamlessly.

**MockWebTransport**: Added mock methods for testing support.

The implementation follows the existing architectural pattern where concrete implementations delegate to their underlying transport layers.
