Commit title: add isb (memory barrier) before accessing cntvct_el0 register
Commit body:
Summary: Without the `ARM64_HAS_ECV` feature, there is no ordering guarantee accessing the `cntvct_el0` register, and calling this API in a row can lead to inaccuracy. This diff adds `isb` instruction, just like what [linux kernel](https://github.com/torvalds/linux/blob/d2eedaa3909be9102d648a4a0a50ccf64f96c54f/arch/arm64/include/asm/arch_timer.h#L204) and [DPDK](https://inbox.dpdk.org/dev/CALBAE1NXxEgFhvtMj7iazTXS6bDszt6rj8YW1SubSDp8gAzSNw@mail.gmail.com/T/) are doing. This way, the precision of the timestamp can be improved.
