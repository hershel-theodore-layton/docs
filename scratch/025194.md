# Folly Dynamic Rust API
**Dynamic**: A Rust wrapper around `folly::dynamic`
## Construction Methods
- `Dynamic::new_null()` - Create null value
- `Dynamic::new_bool(value)` - Create boolean value
- `Dynamic::new_int(value)` - Create 64-bit integer value
- `Dynamic::new_double(value)` - Create floating-point value
- `Dynamic::new_string(value)` - Create string value
- `Dynamic::new_array()` - Create empty array
- `Dynamic::new_object()` - Create empty object

## Type Checking
- `is_null_value()`, `is_bool()`, `is_int()`, `is_double()`, `is_number()`, `is_string()`, `is_array()`, `is_object()`

## Value Access
- `as_bool()`, `as_int()`, `as_double()`, `as_string()` - Extract typed values
- `as_str()` - Get string slice reference (zero-copy)
- `size()`, `is_empty()` - Get collection size/emptiness

## Array Operations
- `push_back()`, `pop_back()` - Add/remove elements
- `set_at(index, value)` - Set element at index
- `at(index)` - Safe accessor that doesn't panic
- `at_mut(index)` - Get mutable reference to element
- Index access via `dynamic[index]`

## Object Operations
- `set_key(key, value)` - Set key-value pair
- `erase(key)` - Remove key-value pair
- `contains(key)` - Check if key exists
- `keys()` - Get all object keys
- `get(key)` - Safe accessor that doesn't panic
- `get_mut(key)` - Get mutable reference to value by key
- Index access via `dynamic["key"]`

## JSON Serialization
- `to_json()` - Serialize to compact JSON string
- `to_pretty_json()` - Serialize to formatted JSON string
- `from_json(json_str)` - Parse JSON string into Dynamic

## Ergonomic Features
- **IntoDynamic trait** - Convert Rust types (bool, i64, f64, &str, String, etc.) into Dynamic values
- **DynamicMut trait** - Provides ergonomic mutable operations for both `UniquePtr<Dynamic>` and `Pin<&mut Dynamic>`
- **DynamicFromIterator trait** - Create arrays and objects from iterators
- **Index traits** - Access elements via `[]` operator for both arrays and objects
- **Display/Debug traits** - Pretty printing support
- **PartialEq/Eq traits** - Value equality comparison
- **extend_array()**, **extend_object()** - Bulk insertion methods
