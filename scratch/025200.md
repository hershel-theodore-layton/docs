Summary:
The AVX2 version of xoshirp256pp generates a different sequence of numbers given the same seed. This is a (hacky) fix to give users control over which variant is used with a template argument.

The default template value should ensure there is no change to which variant is used, but the variant used by default will remain the same (AVX2 if available).
