Commit title: Modify xoshiro256pp for parity
Commit body:
Summary:
The xoshiro256pp implementation in Folly would generate different sequences of numbers when using AVX compared to non-AVX.

The reason for this was that in the AVX version, 4x the number of generators were being run concurrently. The RNG state is stored as 4 copies of a `vector_type`. In the AVX case, the `vector_type` is a 256 bit vector register itself containing 4 64 bit integers, giving us 4x the number of generators in the same number of `vector_type`s. The engine maintains 4 copies of 4 states; this diff cuts this down to 1 in the case of AVX2 so the number of actual generators is identical in either case.
