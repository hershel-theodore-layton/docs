## What

Rather than using a unlabeled boolean to decide which function to call, break get_member into two functions.

## Why

- safer (harder to mix up)
- a step toward consistency in the codebase

## Context

This came up in diff review for another diff https://www.internalfb.com/diff/D78688689?dst_version_fbid=1237203468181760&transaction_fbid=1405234473924772

## Alternative considered

I considered using a labeled parameter, but
- This would make it so that we have three patterns in the code base for the same thing, rather than just two.
- I think it's generally good practice to use normal function dispatch
