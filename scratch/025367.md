Summary:
From comments `JitProfileRequests` was added for safety but there's all these other checks to stop profiling.

- Reaching `ProfileBCSize` number of bytecodes
- Main section is full
- Reaching `RetranslateAllSeconds` number of seconds

All the web buckets and major tenants already reach the bytecode limit first (and the main section is almost full too) so this requesets config doesn't do anything. Even if it did, I think it's probably helpful to profile until `RetranslateAllSeconds` to get more profiles. I think we should remove `ProfileBCSize` too and profile as much as we can until `RetranslateAllSeconds`.
