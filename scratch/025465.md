Summary:
## What

Remove tast_env_as_typing_env.
Instead, use [`Type.eq`](https://ocaml.org/manual/5.3/api/Type.html) to selectively expose that Typing_env_types.env and Tast_env.env are equal

## Why

The existing API led to unsafe patterns of use where we would pass around a typing env and a tast env. These environments are stateful, so the only correct thing to do would have been to convert back and forth to maintain state:

let env = Tast_env.tast_env_as_typing_env env in
..... (* use as typing_env *)
let env = Tast_env.typing_env_as_tast_env env
in ..... (* use as tast_env *)

## How

Devmate did pretty well with minimal nudging and only minor stylistic cleanup needed: https://www.internalfb.com/intern/devai/devmate/investigator?paste=P1904203806

## Behavior change

None expected modulo potential bug fixes.
