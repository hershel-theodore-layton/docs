Commit title: Add NoDisjointUnion attribute to idx and idx_readonly
Commit body:
Summary: Code such as `idx($v, C::class)` for `$v:vec<int>` is currently permitted by Hack because the key type on `KeyedContainer` is covariant. But we can use `NoDisjointUnion` to warn whenever Hack infers a disjoint union type for the key, usually an indicator that there is an error. This will also pick up cases such as `$v[1]` for `$v:vec<bool> | dict<string,bool>` and although this is valid (i.e. it doesn't always fail at runtime) it's often a bad smell.
