Summary:
Two parts to this:
1) driving the C++ `folly::AsyncGenerator` from python `async` generator. This is analogous to what `stream` does on the client side. However, we do the sink element deserialization in the generated python rather than doing it in the type-erased cython.
2) Scheduling invocation of the python callback using the python async generator from 1, and making sure this happens inside in `folly::coro::Task` callback. This ended up being fairly tricky because have to ensure a reference is held to the sink callback to keep it from being freed early. Also, need to store a `KeepAlive` to the executor to ensure that the callback decref happens on Python thread.
