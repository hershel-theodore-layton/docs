Commit title: Fix issue that ObjectWriter does not work if std::unique_ptr<folly::IOBuf> field is nullptr
Commit body:
Summary:
When `std::unique_ptr<folly::IOBuf>` is nullptr, for other protocols, `writeBinary` will write empty string.

e.g., here is the code for compact protocol:

https://www.internalfb.com/code/fbsource/[26665f1fbd5ba97eae792992463e94b046cbf678]/fbcode/thrift/lib/cpp2/protocol/CompactProtocol-inl.h?lines=323-329

(it actually `writeI32(0)` which has the same effect as writing empty string since we just write string length which is 0).

This diff made ObjectWriter have the same behavior.

BTW in non-DEBUG mode (which `assert` is ignored), the existing code actually does

```
    if (!str) {
      return 0;
    }
```

This doesn't make sense -- we won't be able to deserialize the data afterwards since we can't deserialize the string length correctly.
