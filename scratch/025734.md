Coroutine aware abstractions might need to access the parent of SerialExecutor.

For example, my application has a synchronization point abstraction which reschedules the callback on the parent to implicitly aggregate all the pending work on the SerialExecutor. We currently have to wrap both unnecessarily.

I can't think of risks that exposing the parent could represent, so I assume the accessor is only missing because it wasn't needed.
