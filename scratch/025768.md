Summary:
As seen in https://fb.workplace.com/groups/thriftusers/permalink/1541710866538320/?comment_id=1704235896952482&reply_comment_id=1704392353603503,
the caching system for mstch nodes during thrift codegen is still relying on the program name as a unique cache key for all definitions within a program.

However as the thrift scope resolution changes have shown, the program name (i.e. the thrift file name without the extension) does not uniquely identify the scope of a definition.
