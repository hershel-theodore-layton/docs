Summary:
Remove the `watch_default_ticket_path` flag from fbcode and change behavior to only watch ticket paths when seeds can actually be read from the file during server setup.

## Background
- **Configerator setting**: [`watch_default_ticket_path = False`](https://www.internalfb.com/code/configerator/[d6af8287776854ec55acc87b8dfa5eaee67ef77a]/source/thrift/flags_overrides.cconf?lines=12132) (disabled)
- **fbcode default**: `THRIFT_FLAG_DEFINE_bool(watch_default_ticket_path, true)` (enabled)
- **Current problem**: WDBs appear to use FILE strategy even when ticket file doesn't exist, creating misleading logs

## Changes
1. **Removed flag definition** from `ThriftServer.cpp`
2. **Updated `watchTicketPathForChanges()`** to only watch paths when seeds are successfully read
3. **Updated tests** to reflect new behavior without flag dependency
