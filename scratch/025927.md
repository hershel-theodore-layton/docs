Commit title: let integral_hasher be avalanching over all types
Commit body:
Summary:
`integral_hasher` would not be avalanching over 32-bit or smaller types when `size_t` is 64-bit. Change the algorithm so that it is avalanching.

Note that hashers in general cannot be assumed to be avalanching. But there is little harm here. And this may accelerate `F14Table` operations on hashtables with narrow-integer key-types like `int` by allowing `F14Table` to avoid the post-hash mixing step.

Note that this changes the output of integral_hasher over integer types smaller than 64-bit when `size_t` is 64-bit, such as on 64-bit linux platforms.
