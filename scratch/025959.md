Commit title: Use std::deque in UcMulti replies
Commit body:
Summary:
NOTE: This is not a protocol change (i.e. it doesn't break client/server compatibility). It simply changes how certain Thrift `list<T>` fields are translated to/from C++.

`std::deque` has just about the same perf characteristics of `std::vector`. It uses slightly more memory (compared to a vector whose size can be reserved in advance), but allows fast insertion/deletion at the front of the list. In particular, we are interested in the `pop_front()` method, which will simplify the implementation of our new `MultiKeyRoute` (see this [comment](https://www.internalfb.com/diff/D79968758?dst_version_fbid=1086892106752184&transaction_fbid=1477566016760316))
