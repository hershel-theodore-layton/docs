Commit title: Restrict @thrift.URI annotation scopes
Commit body:
Summary:
Restrict `thrift.Uri` annotation to:
- structured definitions and enums (i.e. user-defined IDL types - struct, union, exception, enum)
- services ([one known case](https://www.internalfb.com/code/fbsource/[f68b579e5f416a62ff867c3585a6359936919959]/fbcode/horizon/genai/script_compiler/script_compiler.thrift?lines=90-91))
- typedefs (only with `thrift.AllowLegacyTypedefUri` annotation)

This is a breaking change which stops allowing the explicit URI annotation on the following IDL nodes:
- fields
- functions
- function parameters
- enum values
- consts
- interactions
