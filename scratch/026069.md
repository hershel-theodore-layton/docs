Commit title: Removing unusedBuf function
Commit body:
Summary:
* Unused buffers (unusedBuf) was being used when there were cqe buffers, but the userspace wasn't acquiring an IoBuf for the operations.
* However, in situations where unusedBuf was being used, the `cqe->res` value was less than 0, thus no buffers were being consumed. The `IORING_CQE_F_BUFFER` flag was not being set in that case.
* Removing the unusedBuf function since it was a no-op.
* Adding a louder failure mechanism in `AsyncIoUringSocket` for making it easier to detect.
