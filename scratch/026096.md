Commit title: Add implementation of JsonSerializable trait for non-protected unions
Commit body:
Summary:
Current default implementation of `fb_json_encode` will include `null` values in thrift objects.
Example:
```
union MyUnion {
  1: i64 i;
  2: string s;
}
```

If only `i` field is set, when serialized as json we get the following:
```
{"i": 10, "s": null}
```

Note: this is only applicable to non-protected unions, as `fb_json_serialized` requires public fields.

This behavior differs from `JSONThriftSerializer` which will not include nulls
```
{"i": 10}
```

We would like to make `fb_json_encode` work with unions that currently do not have protected-unions enabled by implementing the `JsonSerializable` trait to ensure any existing json serialization does not break when moved to strict-unions.
