Summary:
[37e9c8e2570b] sched/core: split iowait state into two states is the internal patch that prevents io_uring wait time accounted as iowait time.

io_uring added IORING_FEAT_NO_IOWAIT flag that does the same thing.

6.11 has the internal patch, but no IORING_FEAT_NO_IOWAIT
6.13 has both
6.16 only has IORING_FEAT_NO_IOWAIT

So currently enabling request batching on 6.11 will crash. It's safe to unconditionally call io_uring_set_iowait(), since even if it returns EOPNOTSUPP on 6.11, the internal patch 37e9c8e2570b will ensure io_uring wait time is not accounted as iowait time.
