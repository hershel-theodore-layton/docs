Commit title: Make elapsed duration at least Interval{1} for rate calculation
Commit body:
Summary: E.g. when Interval is `std::chrono::seconds` and Duration is `std::chrono::milliseconds`, a value of "1" is added to the timeseries and the timeseries only tracked 1ms worth of data, in this case, rate as of sum/second will return 1000 instead of 1; because `elapsed()` is only 1ms. This can be correct if the event is very frequent, but it might also be very wrong if the event is infrequent. This is only a problem at the beginning of a timeseries' lifecycle because after a timeseries is filled, `elapsed()` will oscillate between total_duration*(n-1)/n and total_duration (with n being the number of buckets). It enforces `Interval{1}` to be no greater than the total duration of the timeseries.
