Summary:
This adds a new mustache template method "struct:fields_reversed" that returns struct fields in reverse order. This is useful for generating Rust code that needs to process struct fields in reverse order. Which is a key part of the "fast path" implementation used in the next diff in this stack.

The implementation follows the same pattern as the existing rust_fields_by_name method:
- Copy the struct fields using `struct_->fields().copy()`
- Reverse the order using `std::reverse(fields.begin(), fields.end())`
- Return them via `make_mstch_fields(fields)`

Usage in mustache templates:
```
{{#struct:fields_reversed}}
  // Process fields in reverse order
{{/struct:fields_reversed}}
```
