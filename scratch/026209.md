Commit body:
Summary:
```
const Config& config() { return **observer; }
```
Can be expanded a bit:
```
const Config& config() {
  Snapshot<Config> snapshot = *observer;
  return *snapshot;
}
```
Note, after `return *snapshot;` one of the shared_ptr instances keeping Config alive falls through, so if there are no other copies, and the observer updates while we are holding onto our reference of `Config`, it can become a dangling reference.
