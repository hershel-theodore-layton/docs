Summary:
The test seems like it should be deterministic but is observed to be flaky.

```
[ RUN      ] BenchmarkingStateTest.PerfIntegration
fbcode/folly/test/BenchmarkTest.cpp:275: Failure
Value of: perfOuptut
Expected: has substring "Performance counter stats for process id"
  Actual: ""

[  FAILED  ] BenchmarkingStateTest.PerfIntegration (51 ms)
```

Hypotheses: Reading the output-file too quickly after the `perf` subprocess ends may not allow the output file to be flushed in time, leading to flakiness.

Solution: Synchronize `perf` writing to the output-file and the parent process reading from it by calling `fdatasync`.
