Summary:
This resolves a SIOF issue that was reported.

It's almost possible to make the whole thing (both of the context pool
implementations) have `constexpr` constructors. But as the added comment
describes, we don't yet have `constexpr std::vector::vector()` (always). So
we have to have some kind of indirection. This seemed like the best option.
