Commit title: Type-Safe Rocket Frame Trait System
Commit body:
Summary:
This code introduces a type-safe trait system for Rocket frames, enabling compile-time determination of frame properties (e.g., streaming type, stream ID 0) without requiring a common parent class.

Key components:

**FrameUnion**: A union type storing all possible Rocket frame variants (e.g., SetupFrame, RequestResponseFrame), enabling efficient storage of heterogeneous frame types.

**FrameTraits Template**: Specialized for each frame type via macros (e.g., DEFINE_FRAME_TRAITS). Provides:
* Frame type enumeration (FrameType)
* isStreamFrame()/isStreamZeroFrame() checks
* Serialization/deserialization logic
* Union member accessors for safe construction/destruction

**FrameContainer**: Manages frame lifecycle and serialization:
* Type-erased storage via FrameUnion
* Destructor/serializer function pointers
* Safe construction/destruction through trait-guided operations

**Type Mappings**: Macros (MAP_FRAME_TYPE_TO_TRAITS) enable bidirectional conversion between FrameType enums and their corresponding traits/implementations.

This design eliminates runtime type checks and enables efficient, statically verified frame handling while supporting Rocket's diverse frame semantics (streaming, fire-and-forget, control frames, etc.).
