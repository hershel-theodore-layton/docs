Commit title: folly::get_optional with non-template template parameter Optional
Commit body:
Summary:
Add `folly::get_optional` with no template template paramter `Optional`. This is particularly useful when you want get the value of the view.

i.e.
```
std::map<int, std::string> m;
m[1] = "2";

std::optional<std::string_view> get_view(std::map<int, std::string> m, int k) {
  return m.get_optional<std::optional<std::string_view>>(k);
  // return m.get_optional<std::optional>(k); // this constructs temporary std::optional<std::string> that get converted to std::optional<std::string_view> which results in dangling reference.
}

```
