Commit title: Fix Thrift compatibility with autodeps2
Commit body:
Summary:
The `thrift/lib/python/__init__.py` defines a handful of same-level imports that otherwise would automatically exist under Python 3. As a result, any modules that are *not* defined are effectively hidden - `autodeps2` correctly implements this, causing target removals + test breakage.

As this `__init__.py` file is not needed and has odd side-effects, remove it with this diff.

However, there are ~1.1k downstream targets relying on `//thrift/lib/python:base`. Instead, turn it into a no-op target by deleting `srcs=` and allow autodeps to incrementally update downstream targets (eg, D82581842 resolves ~900 cases).
