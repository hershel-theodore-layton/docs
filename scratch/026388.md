Commit title: Scope @hack.Attributes annotation
Commit body:
Summary:
The `edward-io.Attributes` is missing scope attributes, which leads the thrift linter to suggest using an unstructured annotation instead (which is deprecated).

E.g.

Linter suggest converting
```
edward-io.Attributes{
  attributes = [
    "\ApiEnum",
    "\JSEnum(shape('flow_enum' => true))",
    "\GraphQLEnum('FIMReportColumnType2','Report column types')",
    "\Oncalls('fiber_infrastructure_management')",
  ],
}
enum MyEnum {
  ALLOWED = 1,
  THIS_IS_ALLOWED = 2,
  THIS_IS_ALLOWED_2 = 3,
}
```

into

```thrift
enum MyEnum {
    ALLOWED = 1,
    THIS_IS_ALLOWED = 2,
    THIS_IS_ALLOWED_2 = 3,
}
(hack.attributes =
        "\JSEnum(shape('name' => 'MyEnum')),
        \GraphQLEnum('MyEnum', 'Description for my enum',)")
```
