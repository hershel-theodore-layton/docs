Commit title: Allow state directory based in `$HOME`.
Commit body:
Summary:
The reasoning for this is already outlined well in https://github.com/facebook/watchman/issues/1092.

This would be useful for us in Homebrew, and would probably limit the
number of bug reports you get from Homebrew users that get tripped up by
our hard-coded `WATCHMAN_STATE_DIR`. (See, e.g., https://github.com/facebook/watchman/issues/963.)

It should also reduce the number of users who end up with `brew`
building Watchman from source because they're using a non-default
prefix, and hopefully issues from them too (e.g. https://github.com/facebook/watchman/issues/1132).

Closes https://github.com/facebook/watchman/issues/1092.
