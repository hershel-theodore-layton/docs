Commit title: adds HTTPStreamSourceHolder::waitEgressBuffer()
Commit body:
Summary:
Some customers use `HTTPStreamSourceHolder` to asynchronously produce/egress a request. They experienced crashes when buffering `> int32_t::max()` body bytes.

There's a signal to detect backpressure (i.e. when `HTTPStreamSource::body()` returns `FlowControlState::CLOSED`), however there's no mechanism (via `HTTPStreamSourceHolder`, but there is via `HTTPStreamSource`) to signal when backpressure has resolved (e.g. peer consuming data).

This diff adds a new `HTTPStreamSourceHolder::waitEgressBuffer()` function that should be invoked once `HTTPStreamSource::body()` returns `FlowControlState::CLOSED` (however it can be invoked regardless and will synchronously resolve if there is enough egress buffer remaining)
