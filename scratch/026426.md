Commit title: Return derived Whisker prototype for mstch 'self' properties
Commit body:
Summary:
Returning the most derived type in these cases enables accessing derived properties - e.g. we may use `function:return_type` to get a `mstch_type`, then want to check if it's a list (via `list?`), then if it's a list, retrieve its `elem_type`.

If we just have the type prototype (as `mstch_type` returning a `t_type` prototype does today), we can't trigger a down-cast to a derived prototype from the template.
