There are two reasons why it is happening

* In `reflection` module, there are non-deprecated struct definitions that depend on deprecated structs.
* in `IssetUtils.h` there is non-deprecated function that calls deprecated code.

Note that this happens only in packages built with `-Werror=deprecated-declarations` enabled. That is quite annoying because it prevents having stricter compiler checks enabled anywhere with Thrift included as a dependency.

The proposed fix is to mark more structs from `reflection` module as deprecated and suppress deprecation warnings inside `IssetUtils.h`.
I tried to upgrade `IssetUtils.h` to use Always-on reflection, but I am not competent enough to do it. If anyone has any pointers how to do that, I am happy to try again.
