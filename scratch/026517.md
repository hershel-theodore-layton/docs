Summary:
This change updates the Folly async socket implementation to use a new trusted encrypted socket mechanism instead of the deprecated SO_NO_TRANSPARENT_TLS option.

The key changes include:
- Replacing SO_NO_TRANSPARENT_TLS (200) with FOLLY_SO_TTLS_TRUSTED (206)
- Introducing FOLLY_TTLS_TRUSTED_ENCRYPTED_SOCK_VAL constant for the socket option value
- Updating all setsockopt calls to pass a proper value instead of nullptr

This maintains the same functional behavior of disabling transparent TLS on sockets while using the new approache.
