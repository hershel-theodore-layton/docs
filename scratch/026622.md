Summary:
Add `key` and `value` properties to `mstch_map_element`, mirroring `element:key` and `element:value`. This is in preparation for Whisker migration, where we don't have a prototype for map elements, and instead will use a Whisker map exposing `key` and `value` properties.

Define qualifiers for container prototypes, to enable map (and list/set) migration. This will enable replacing mstch properties like `type:key_type`/`type:value_type`, `type:list_elem_type`, etc. with properties defined on the respective container prototypes, rather than on the type prototype.
