Migrate `const_enum_type` and `const_struct_type` using Whisker property `value:type.true_type`, which returns the most-derived Whisker prototype of the typedef-resolved type of the const value.

mstch `const_enum_type` and `const_struct_type` implementations test the const's type, then return `mstch_enum` / `mstch_struct` respectively. The checks are done by preceding `value:const_enum?` / `value:const_struct?` and `value:type.true_type` replaces the `true_type` in `const_enum` / `const_struct` properties, returning the most-derived prototype (i.e. enum/struct).
