Commit title: Migrate typeinfo template to operate with mstch or Whisker type context
Commit body:
Summary:
Make the `typeinfo` template for the Python generator work with either mstch_type or a Whisker type object as its context.

The template primarily renders with Whisker type as its context. If the context is a mstch object, the template recurses itself using the Whisker `self` property as the context for the recursion.

This enables incremental migration of calling templates from mstch to Whisker, without requiring all templates to be updated to wrap the macro with a `{{#type:self}}` context that would later need to be removed.
