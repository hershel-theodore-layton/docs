Commit title: Enums and Class Constants in Expression Trees
Commit body:
Summary:
### Hack Proposal

Currently, Expression Trees don't support direct references to enums and class constants. To work around this, developers use the splicing syntax:

```
MyDsl`${MyClass::FOO}`
MyDsl`${MyEnum::BAR}`
```

Splicing enums and class constants has two drawbacks:
1. The ${} syntax makes the code look cluttered.
2. At runtime, it’s inefficient to identify and dedupe constants that were used multiple times.

This updates Expression Trees so that developers can write code like:

```
MyDsl`MyClass::FOO`
MyDsl`MyEnum::BAR`
```

To achieve this, we desugar and virtualize class consts using this strategy:

```
Source: MyDsl`MyClass::FOO`
Virtualized: ${MyClass::FOO}
Desugared: $0v->visitClassConstant(
  new ExprPos(...),
  nameof MyClass,
  'FOO',
  MyClass::FOO,
)
```
