Commit title: Add as_const to field_ref types
Commit body:
Summary:
Facilitates writing const-correct user code.
Users will often write `const auto& myField = nonConstStruct.my_field()` in hopes this will give them a const reference to the field, but since field_ref is a view type there is no error when dropping the const by passing the field ref somewhere non-const.
Users can write `std::as_const(nonConstStruct).my_field()` to get the desired behavior, but this is harder to migrate to and may not work if the field_ref is produced far away from the desire for constness. `myField.as_const()` will provide the desired safety.
