Summary:
First round of conceptifying the type tag library. More to come.

Thanks to C++20 concepts, some parts of the type tag library can now be simplified. There are two classes of improvements.

* New concept definitions:

```
// BEFORE
template <
    typename Tag,
    typename std::enable_if_t<type::is_thrift_type_tag<T>>>
```
```
// AFTER
template <type::ThriftTypeTag Tag>
```

* Internal implementation details that are required to be SFINAE-friendly

```
// BEFORE
```
https://www.internalfb.com/code/fbsource/[4f0fd3de10ac]/fbcode/thrift/lib/cpp2/type/detail/NativeType.h?lines=47-48
https://www.internalfb.com/code/fbsource/[4f0fd3de10ac]/fbcode/thrift/lib/cpp2/type/NativeType.h?lines=27-29
```
// AFTER
```
```
template <ThriftTypeTag Tag>
struct NativeTypes {
```
```
template <ThriftTypeTag Tag>
using standard_type = typename detail::NativeTypes<Tag>::standard_type;
```

As you can see the `typename = void` SFINAE noise can be removed.

This diff only makes changes to `NativeType`, `is_thrift_type_tag` and some changes to `InferTag` as a proof-of-concept. Subsequent diffs will clean up all other type tags too.
