Commit title: Fix native stack alignment around call to uninitDefaultArgs C++ helper
Commit body:
Summary: On x86, the JIT was emitting calls to the `HPHP::jit::svcreq::uninitDefaultArgs` C++ helper with the native stack being  unaligned, which is against the ABI. The `saverips` and `restorerips` Vasm instructions were added to deal with the somewhat special calls to this helper on ARM (D45975129), and this diff leverages those instructions to also fix the stack alignment around those calls on x86.
