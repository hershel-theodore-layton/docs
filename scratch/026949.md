Commit title: Move "host" and "port" to more specific subclasses
Commit body:
Summary:
Previously, `host` and `port` were both in `HQBaseParams`. However,
* host is only used within the `HQClient` to set the TLS/QUIC hostname (SNI) via QuicClientTransport::setHostname.
* port is only used within the `HQServer` to sometimes bind its listening socket (I'm going to change this in a subsequent diff where I pass in the remote address through `HQServer::start`)

So, I'm moving `host` to `HQClientParams` and `port` to `HQServerParams`.
