Commit title: Use sealed list for classes when computing disjointness
Commit body:
Summary:
Currently we consider the following case type to be invalid because the variants are overlapping:

```
interface I {}

case type MyCaseType = I | Awaitable<I>;
```

This feels incorrect because Awaitable is sealed with all leaf classes being final.

The issue is we only leverage the sealed list for interfaces. This looks like an oversight and don't see any reason not to apply it to classes as well.
