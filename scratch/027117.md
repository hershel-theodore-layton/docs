Commit title: Replace t_type check and as<T> down-casts with try_as<T>
Commit body:
Summary:
`t_type::is<T>` is a cast check, implemented as `dynamic_cast<T*> != nullptr`.
`t_type::as<T>` is a down-cast implemented as `dynamic_cast<T&>`, which would throw on an invalid cast.
`t_type::try_as<T>` is a "maybe" down-cast, returning nullptr if the cast is invalid implemented as `dynamic_cast<T*>`.

A condition checking `is<T>` followed by a down-cast `as<T>` performs two casts to `T`, but can be equivalently replaced with `try_as<T>` and a check for `nullptr`.

I.e. the following two are equivalent:
```lang=cpp
if (x->is<T>()) { const T& y = x->as<T>(); }
if (const T* y = x->try_as<T>()) { /* use *y equivalently to y above */ }
```
