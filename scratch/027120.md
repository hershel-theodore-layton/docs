Commit title: Replace t_type check and down-cast with try_as<T>
Commit body:
Summary:
`t_type::is<T>` is a cast check, implemented as `dynamic_cast<T*> != nullptr`.
`t_type::try_as<T>` is a "maybe" down-cast, returning nullptr if the cast is invalid implemented as `dynamic_cast<T*>`.

A condition checking `is<T>` followed by a down-cast (C-style, `static_cast` or `dynamic_cast`) performs two casts to `T` - a `dynamic_cast` for the `is<T>` check and the explicit cast. This can be equivalently replaced with `try_as<T>` and a check for `nullptr`, which performs the single `dynamic_cast` that `is<T>` would.

I.e. the following two are equivalent (for `(T*)` cast:
```lang=cpp
if (x->is<T>()) { const T* y = static_cast<const T*>(x); }
if (const T* y = x->try_as<T>()) { /* use y equivalently to above */ }
```
