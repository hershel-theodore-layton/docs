When hh falls back on hh_distc it unconditionally sets following options:
https://www.internalfb.com/code/fbsource/[af3574829eefaa1e94883e7996304d54f69d3465]/fbcode/hphp/hack/src/facebook/hh_distc/check_ffi/hh_distc_rust_ffi.rs?lines=121-122

This diff sets up an experiment to see what impact avoiding this unnecessary work would make. After the experiment conclusion we'll make this behaviour default to make sure that it is the same for both FFI and CLI invocations of hh_distc.
