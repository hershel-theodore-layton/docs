Commit title: Setup an experiment to save traces only during save state creation
Commit body:
Summary:
This diff adds a binary JK to control if dynamic traces should be written only during save state creation. Currently every hh_distc invocation is allowed to write traces which means that some random local invocations that never make it to master or invocations coming from older revision may write traces which negatively affects caching. This diff adds a simple experiment to see if writing dynamic traces only during save state creation helps with improving RE cache hit rate. Writing traces during save state creation offers following benefits:
* Save state jobs are running regularly
* Save state jobs run on changes that has already made it to master
