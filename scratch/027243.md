Commit title: Replace t_list/t_set::get_elem_type dereferences with elem_type
Commit body:
Summary:
Replaced `*x->get_elem_type()` with `*x->elem_type()` where `x` is `t_list` or `t_set`.

`get_X_type` AST methods returning `t_type*` are deprecated and will be removed soon.

`get_X_type()` returns `t_type*` which is de-referenced. The corresponding `X_type()` returns `t_type_ref`, whose `operator*` de-references the contained pointer (i.e. is equivalent to dereferencing a `t_type*`.
