Commit title: Add cancellation thrift API

Summary:
In this diff, define the Cancellation Thrift API for EdenFS.

Input: a list of request ids to attempt to trigger cancellation.
Output: a list of results, one result for each supplied request id. The result is a descriptive enum `CancellationStatus`.

This will be the primary interface to trigger cancellation for Eden clients.

EdenFS itself will not call this during shutdown or graceful restart -- these mechanisms will be implemented later.
