Commit title: N-way thread affinity
Commit body:
Summary:
Adds support for n-way thread affinity in `MultiKeyRoute` by means of a new setting: `num_threads`

`num_threads` may be added to the default policy, like this:
```
{
    "type": "MultiKeyRoute",
    "default_policy": {
        "num_shards": 5,
        "num_threads": 2           # 2 threads per shard (total 5 x 2 = 10 threads)
    },
    …
}
```
or to individual policies, for instance:
```
{
    "type": "MultiKeyRoute",
    "default_policy": { … },
    "policies": [
        {
            "app_id": "LASER",
            "tenant_id": 12033,
            "num_shards": 5,
            "num_threads": 2       # 2 threads per shard (total 5 x 2 = 10 threads)
        },
        …
    ],
    …
}
```

N-way thread affinity is achieved by means of a *salt*, which is added to the host hash when computing the affinitized proxy index:

- *ProxyIdx*  = (*HostHash* + *ThreadAffinitySalt*) % *NumProxyThreads*

The salt value is computed as follows:

- *ThreadAffinitySalt* = *UniqueRequestId* % `num_threads`

where *UniqueRequestId* is a random 64-bit value generated by the request constructor. This allows salt calculation to be consistent across `traverse()` and `route()` (see below).

Proxy affinity is currently computed in multiple places. In this exact order:

1. In `CarbonRouterClient::findAffinitizedProxyIdx()`, called before a request is dispatched. This method relies on `traverse()` to determine the destination host hash. In this case, the thread affinity *salt* is provided by `MultiKeyRoute::traverse()` via mutable state in `RouteHandleTraverser`.

2. (New) In `MultiKeyRoute::findAffinitizedProxy()`, while routing. It's used to schedule multi-key requests on the appropriate thread after sharding. Here we also use `traverse()` to find out the destination host hash for each shard, but the salt is derived from the `num_threads` setting instead of being read from the tree traverser state.

3. In `SRRoute::pickEvbForRoutingKey()`, used for jumping threads after a failover. The salt, in this case, is passed via `fiber_local::jumpThreadsSalt()` by `MultiKeyRoute::route()`.
