Commit title: Only increase rank when we have universally quantified supertype
Commit body:
Summary:
When subtyping universally quantified function types we have two case should be dealt with in the following order

```
T <: forall U. V
```

and

```
forall U. V <: T
```

In the first case increment the rank and bind all generics. In the second case we can just instantiate the generics to get back an unquantified type.

If a universally quantified type appears on the lhs and a universally quantified type was on the rhs, it will be instantiated at the correct rank so we don't need to worry about the following case explicitly:

```
forall U. V <: forall S. T
```

Currently the subtyping implementation does these two steps simultaneously but the condition for incrementing rank is that _either_ type is quantified rather than just the supertype. This diff corrects the issue.
