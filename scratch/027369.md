Commit body:
Summary:
Now that string concatenation takes only `arraykey`, we can treat it as a binary function of type `(function(arraykey,arraykey):string)` that accepts like-typed parameters but always produces exactly `string`. As with other operators, we can use the `check_argument_type_against_parameter_type_helper`.

The error code is no longer specialized to concatenation.
