Summary:
I've realized that it is impossible to efficiently handle blob batch requests if we run each individual blob id through the existing per-item code paths. There are just too many per-item mutexes, log events, timers, etc. Instead, I think it makes sense to just treat the batch as its own type.

Note that this only applies to the prefetchBlobs codepath where we are given a batch of ids. It does not apply to the getBlob -> enqueue -> getBlobBatch codepath where each blob is (still) tracked individually.

Also drive by fix the missing escape for the tree aux emoji.
