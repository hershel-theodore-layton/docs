Summary:
### Context
The default error message is very confusing when dealing a nested command. For example, we have `nested_command_line_app_test` cmd that supports `test` subcommand that requires a `--foo` option. When  users run `nested_command_line_app_test test`,  they will get following error
```
the option '--foo' is required but missing. Run 'nested_command_line_app_test help' for help
```
This is very confusing as they should really ask users to run `nested_command_line_app_test test help`. The issue is due to the fact that the default top-level error handling doesn't have the context of subcommand: https://www.internalfb.com/code/fbsource/fbcode/folly/cli/NestedCommandLineApp.cpp?lines=254
