Summary:
### Background

The past [doc site infra](https://github.com/hhvm/user-documentation/tree/main/.deploy) produces custom, Dockerised Hack and HHVM builds that are being deployed to AWS. This has been broken for some time due to **(a)** permission-related issues (resolved as part of T222630647), and **(b)**  Service Control Policy (cloud CLI enforcement) which is now blocking the deployment from GH Actions.

### Solution

Instead of working around constraints from point **(b)**, and/or applying for policy exemptions, this diff initiates the move of the doc site over to [Static Docs](https://staticdocs.internalfb.com/staticdocs/) ([hub](https://www.internalfb.com/staticdocs/hub?filterName=&filterRepoName=all&filterHostType=all&filterMode=all&filterVersion=all)).

Once live internally, we will enable ShipIt and Docusaurus to publish the new docs on GitHub Pages (like we do for [hacklang.org](https://hacklang.org)).

### Local Dev & Testing

Make sure that you have the [prerequisites installed](https://staticdocs.internalfb.com/staticdocs/docs/setup/2-prequisites/).

To run the website locally in "internal mode" (hosted on [http://localhost:3000/docs/hack/intro/](http://localhost:3000/docs/hack/intro/)):

```bash
$ cd fbcode/hphp/hack/website
$ yarn install && yarn start-fb
```
See more information and tips on *local development workflows* [here](https://staticdocs.internalfb.com/staticdocs/docs/documenting/workflow/#3-preview-your-changes).

The source docs for the site are located in https://www.internalfb.com/code/fbsource/fbcode/hphp/hack/manual/hack/. These have been patched up to be compatible with Static Docs.
