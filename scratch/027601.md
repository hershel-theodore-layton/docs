Commit title: ensure to set transport type on conn context
Commit body:
Summary:
When using HTTP2 transport, the connection transport type was not being set on the connection context. This meant that service interceptors could not determine whether they were handling HTTP2 traffic, as the transport type information was unavailable.

This fix ensures that `SingleRpcChannel` sets the transport type to `HTTP2` on the connection context before processing the request, making this information available to interceptors for proper handling and logging.
