Summary:
The issue - users report that `stepIn` after a breakpoint hit is going
to the wrong function.

My first guess: phpDebgugerOpcodeHook gets called on processing the opcode after
stepping in. It calls `auto curStackDisp =
getStackDisposition(req_data.getDebuggerFlowDepth());` but we never set the
flow depth. Note that this is different from stepOut and stepNext. Manually
testing suggests this helps.
