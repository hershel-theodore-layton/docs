Commit title: Remove acquire/release fences in IncProfCounter
Commit body:
Summary:
In Vgen::emit(const decqmlock& i) and Vgen::emit(const decqmlocknosf& i), the LSE on/off code paths have different memory fences added. When LSE is off, ldxr/stxr are generated and they don't have any acquire/release fences. However, when LSE is on, ldaddal gets generated with acquire/release semantics.

This change strips acquire/release fences from ldaddal so that both LSE on/off paths have no memory fences.
