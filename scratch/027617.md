Commit title: Remove deprecated AST method t_primitive_type::type_name
Commit body:
Summary:
`t_primitive_type::type_name` calls deprecated `t_type::type_name`.

`type_name` returns the same values as `name()`, so usages can be replaced like-for-like.

`t_type::type_name` will return one of the following values for a primitive type: `"void", "string", "bool", "byte", "i16", "i32", "i64", "double", "float", "binary"`.

Those exact same values are set for the `name` property of those types' singleton instances. The `t_primitive_type` constructor is private, so differing values cannot occur.
