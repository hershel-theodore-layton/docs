Commit title: Add poll() method to folly::coro::SharedPromise
Commit body:
Summary:
This change adds a non-blocking `poll()` method to `SharedPromise<T>` that returns `std::optional<TryType>`. The method checks if the promise has been fulfilled and returns the result wrapped in an optional if available, or an empty optional otherwise.

This provides a synchronous way to check and retrieve the promise's value without blocking, complementing the existing asynchronous `getFuture()` and `getSemiFuture()` methods. This is useful in scenarios where code needs to opportunistically check if a shared promise is ready without suspending execution.

The implementation uses `withRLock` to safely access the shared state, ensuring thread-safe reads of the fulfilled status and result value.
