Commit title: Add support to render aggregate columns
Commit body:
Summary:
Right now, `%C` (for columns) and `%LC` (for list of columns) does not support rendering of aggregate columns.

Columns can be represented using two types today:
 - `QualifiedColumn` (`T0`.`name`)
 - `AliasedQualifiedColumn` (`T0`.`name` AS `T0_name`)

This diff introduces a new enum `AggregateFunction` to represent the aggregate functions.

This diff also introduces a two new types to represent and render aggregate columns:
 -  `AggregateColumn`
 -  `AliasedAggregateColumn`

Sample code:
```
  std::vector<QueryArgument> args;
  args.emplace_back(QualifiedColumn{"T0", "c1"});
  args.emplace_back(QualifiedColumn{"T0", "c2"});
  args.emplace_back(AliasedQualifiedColumn{"T0", "c3", "T0_c3"});
  args.emplace_back(AliasedQualifiedColumn{"T0", "c4", "T0_c4"});
  args.emplace_back(AggregateColumn{AggregateFunction::COUNT, {"T0", "c5"}});
  args.emplace_back(AggregateColumn{AggregateFunction::SUM, {"T0", "c6"}});
  args.emplace_back(AliasedAggregateColumn{AggregateFunction::COUNT, {"T0", "c7", "COUNT_T0_c7"}});
  args.emplace_back(AliasedAggregateColumn{AggregateFunction::SUM, {"T0", "c8", "SUM_T0_c8"}});

  const auto query = Query{"SELECT %LC FROM %T", args, "T0"};
```
The above code would render an SQL statement like:
```
SELECT
    `T0`.`c1`,
    `T0`.`c2`,
    `T0`.`c3` AS `T0_c3`,
    `T0`.`c4` AS `T0_c4`,
    COUNT(`T0`.`c5`),
    SUM(`T0`.`c6`),
    COUNT(`T0`.`c7`) AS `COUNT_T0_c7`,
    SUM(`T0`.`c8`) AS `SUM_T0_c8`
FROM `T0`
```
