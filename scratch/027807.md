Commit title: Remove deprecated enum t_type::type, reset int values of t_primitive_type::type
Commit body:
Summary:
Remove the deprecated enum `t_type::type`, which is only referenced for the int values of `t_primitive_type::type`.

Reset the int values of `t_primitive_type::type`. The usages of `t_primitive_type::type` are only in the form of `switch(t_primitive_type::primitive_type())` / `case` statements and [in]equality comparisons between `t_primitive_type::primitive_type()` and literal enum values.

The enum members with changed integer values are `t_float` (changed from `15` to `8`) and `t_binary` (changed from `18` to `9`).

The reason the int values are reset to be 0-indexed and contiguous is because the current `t_type` int values for primitives do not correspond to any other semantic values after `t_type::type` is removed. E.g. protocol `TType` values are not equivalent (`type::void` is `0`, while `TType::T_VOID` is `1`).

Since we don't have any remaining usages of the integer values of `t_primitive_type::type`, this presents an opportunity to reset the values without breakage rather than preserving the current values (with gaps in the range) indefinitely.
