Commit title: Make RocketException::what() more descriptive
Commit body:
Summary:
Previously, RocketException::what() returned a generic "RocketException"
string which was not helpful for debugging. This change refactors it to return
a descriptive message that includes the error code name (e.g., "CANCELED",
"INVALID") and any error data if present. Binary data in the error payload is
properly escaped using folly::cEscape to ensure safe display in logs and terminal
output. This makes debugging rocket transport errors significantly easier by
providing immediate context about what went wrong.
