Commit title: Convert internal map data type from `tuple` to `dict` and improve the performance for thrift primitive types(**NOT** include string)
Commit body:
Summary:
This diff converts the internal map data type from a tuple to a dictionary, improving performance when both the keys and values are [Thrift Primitive Types](https://www.internalfb.com/intern/staticdocs/thrift/docs/idl/#primitive-types) (excluding String; String optimizations will be addressed in a separate diff). These changes are particularly beneficial for enhancing random access and the performance of the first (uncached) iteration.

**Background:**
In thrift-python, every type has **two representations**:

1.  **Internal Data Type** - Used by the serializer (C++ side)
2.  **Python Value Type** - User-facing type returned by field access

Previously, "internal data" type for Thrift Python `maps` were represented as a tuple of tuples `tuple[tuple[KeyInternal, ValueInternal]]`. This is optimal for hashing because `tuple` is easily hashable, but this is very inefficient for normal usage because of
1. On first access, we have to convert all elements to a dict, which goes inside the Map class: https://www.internalfb.com/code/fbsource/[72da52a7c3f1]/fbcode/thrift/lib/python/types.pyx?lines=2294
2. That means looking up a single element has huge overhead because we have to convert every single element to the python value type before we return the Map class: https://www.internalfb.com/code/fbsource/[72da52a7c3f1]/fbcode/thrift/lib/python/types.pyx?lines=785
 {F1983202267}

**This diff servers two purposes,**
* 1: Changes the internal representation from `tuple` to  `dict`
  ```
   # New format: hashable dict (ImmutableInternalMap)
   internal_data = ImmutableInternalMap({key1: value1, key2: value2, ...})
   ```
   Key implementation details:
   ```
   _cython__final
   cdef class ImmutableInternalMap(dict):
      def __init__(self, dict_data):
         self.update(dict_data)

      def __hash__(self):
         return hash(tuple(self.items()))  # Still hashable!
   ```

* 2: If both keys and values are  [Thrift Primitive Types](https://www.internalfb.com/intern/staticdocs/thrift/docs/idl/#primitive-types) (**NOT** including String), no conversion is needed at all for both keys and values.
   ```
   cdef to_map_elements_no_convert(key_type_info, value_type_info):
      return (to_container_elements_no_convert(key_type_info) and
               to_container_elements_no_convert(value_type_info))
   ```

**For example:**

*   **Thrift IDL Type**: `map<i32, string>`
*   **Old Internal Data**: `tuple[tuple[int, str], ...]`
*   **New Internal Data**: `ImmutableInternalMap` (hashable dict)
*   **Python Value Type**: `Map` (user-facing immutable map)

This is important because, according to the Glean query D85260454, **9.13%** of the keys and values are among the [Thrift Primitive Types](https://www.internalfb.com/intern/staticdocs/thrift/docs/idl/#primitive-types) (**NOT** including String)

**Performance Impact:**
- Map<i32, i32>: **60.59x** faster random access
- Map<i32, i32>: **2.67x** faster first iteration.
