Commit title: strongly type List and Set `_fbthrift_elements`
Commit body:
Summary:
We have the opportunity to strongly type the container `_fbthrift_elements` member if we move its declaration from `Container` base class to `List`, `Set`, and `Map` classes themselves.

This results in faster access in some situations; for example in `List.__getitems__`, we now use `PyTuple_GetItem` instead of `PyObject_GetItem`.

The perf improvements is expected to be small if measurable. But the code is now easier to maintain.
