Commit body:
Summary:
A better assertion for thrift types
- includes context for deeply nested structs about where the difference occurred. For example `MyStruct.my_list->List[2]`
- uses `assertAlmostEqual` for `float` and `double` fields, and allows feed-through of kwargs for this assertion to customize what threshold (relative, absolute, decimal places) to use.

Compared to `round_thrift_to_float32`, it fully supports mutable thrift-python, and it doesn't require using a `_if_rollout` version that will need to be cleaned up later.

This addresses situations where:
- thrift-python type is input to test put not output
- rounding the result or the inputs doesn't help. For example:
```
round_float32(0.9) - round_float32(0.1) != round_float32(0.8)
```
