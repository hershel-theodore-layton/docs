Commit title: Update test expression tree DSL for non-sdt calling
Commit body:
Summary:
Trying to get expression tree stuff to type check using the constraint_method_call=true approach, which doesn't yet support method calling via SupportDynamicType. In principle, this should be fine, because none of the stuff under the hood in the expression tree expansion should be generating like-types. However, the way pessimisation adds like-types to closure bound variables means that they do show up, since splices and nested expression tree variables are closed over and therefore pessimised.

Here we add NoAutoLikes to try to reduce the amount of like types, and explicitly pessimise the operations (__plus & co.) so that they can deal with pessimised closure variables.
