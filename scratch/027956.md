Commit body:
Summary:
Context: There's other work in progress that modifies FCall bytecodes. The presence of hhas tests means that all of these files need to be updated by hand, and there were 127 of them.

Instead of modifying each of these hhas tests, the proposal is to rely on the 8.5k php tests to give us test coverage and reduce churn for HHVM devs.

There are 4 hhas tests that are used for `test_lldb` (`quick/asm_iterbreak.hhas`, `quick/asm_array.hhas`, `quick/asm_switch.hhas` and `quick/asm_assert_t.hhas`), so preserve those.

If there are other specific tests that we think are important, I'm happy to move those over to php tests (or keep a smaller set around).
