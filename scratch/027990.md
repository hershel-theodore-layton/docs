Summary:
This diff adds a TEST_FILTER environment variable that allows developers to run only specific test files or directories when running Hack tests, significantly speeding up the development cycle.

The implementation includes:
- New filter_test_files() function in verify.py that matches test files based on relative paths
- Support for filtering by file path, directory path, or multiple comma-separated patterns
- Integration with Buck2 through --config hack.test_filter=<path>
- Updated CLAUDE.md documentation with examples and usage patterns
- Updates to defs.bzl to read and pass the test_filter config

This is particularly useful when working on the typechecker and you need to quickly iterate on a specific set of tests without running the entire test suite.
