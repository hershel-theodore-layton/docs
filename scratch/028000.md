Commit title: Replace single property ephemeral maps with arrays and each loops
Commit body:
Summary:
Instead of looping over an array of maps, we can use `#each` loops to preserve explicitness in the template without creating one map per item.

Before:
```
my_array = [{ my_property: value0 }, { my_property: value1 }, ...]
```
```
{{#my_array}}
  {{my_property}}
{{/my_array}}
```

After:
```
my_array = [value0, value1, ...]
```
```
{{#each my_array as |my_property|}}
  {{my_property}}
{{/each}}
```
