Commit title: Strengthen type declarations for Map internal fields in thrift-python types
Commit body:
Summary:
Changed the type declarations of Map's internal storage fields from generic
`object` to specific `dict` types, with corresponding explicit casts.

**Changes:**
- In types.pxd: Declared `_fbthrift_elements` and `_fbthrift_internal_elements`
  as `cdef dict` instead of `cdef object`
- In types.pyx: Added explicit `<dict>` casts at three assignment sites

**Why:**
With `cdef dict`, Cython can generate optimized C code that directly calls
PyDict_* functions instead of generic PyObject_* APIs, improving performance
for dict operations. The unchecked casts are safe since ImmutableInternalMap
is a dict subclass and all assignments are dict-compatible.
