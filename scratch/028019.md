Commit title: Merge TypeSystem and SourceIndexedTypeSystem
Commit body:
Summary:
This diff is motivated by two factors:

1. Every *real* implementation of `TypeSystem` is `SourceIndexedTypeSystem`. In fact, TXL's compiler cannot work without one.

2. Using `TypeSystemBuilder` (the standard way to define a `TypeSystem` from scratch), it is possible to produce `SourceIndexedTypeSystem` without complete type information.

Therefore, knowing something is a `SourceIndexedTypeSystem` doesn't offer any more insight than just having `TypeSystem` itself. We should just assume that source info is *always* best-effort, unless we know otherwise (e.g. we know `SyntaxGraph` produced the `TypeSystem` directly).
