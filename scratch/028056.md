Commit title: Add a pending buffer queue for io_uring zero-copy refill ring
Commit body:
Summary: Add a pending buffer queue to handle cases where the kernel's zero-copy refill ring is full. Previously the code assumed there's space and will overwrite unconsumed entries. Now buffers are queued and written to the ring when space becomes available. This diff tracks the ring's capacity and queues overflow buffers. On each return, it processes as many pending buffers as the ring can accept before writing the current buffer or adding it to the queue.
