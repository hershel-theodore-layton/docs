Summary:
The HTTPClientChannel implementation doesn't actually use any symbols from `proxygen/lib/http:client` (specifically `HTTPConnector`), so this dependency can be safely removed.

This change removes:
- The `#include <proxygen/lib/http/HTTPConnector.h>` from both fbcode and xplat versions of HTTPClientChannel.h
- The `//proxygen/lib/http:client` dependency from BUCK files (fbcode_deps, xplat_deps, and deps lists)
- Unused includes (`deque`, `unordered_map`) in the xplat version that were also unnecessary

This cleanup reduces build dependencies and improves build times by removing an unused dependency from the thrift HTTP client channel implementation.
