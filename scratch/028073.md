Commit title: Replace boost::variant with std::variant
Commit body:
Summary:
boost::variant has an known issue in value reassignment.

If the original value is unknown, the value reassignment always invoke a copy constructor.

This is problematic when the value type that does not have copy constructor is reassigned, causing a compile error.

Even though the type has both copy and move construtors, it is preferable to invoke the move constructor, which is better in performance.

This diff replaces boost::variant with std::variant which doesn't have the issue.
