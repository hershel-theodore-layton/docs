Commit title: Specialize ProtocolValueToThriftValue for vector<bool>
Commit body:
Summary:
The conversion between thrift's `list<bool>` & `std::vector<bool>` is problematic due to the `reference` type of this specialization.

While the thrift protocol implementations (Binary, Compact, etc) already account for this special behavior, the `ProtocolValueToThriftValue` (protocol::Value -> C++ struct) & `ValueHelper` utilities (C++ struct -> protocol::Value) unfortunately do not.

This diff adds support for both + a unit test for good measure.
