Commit title: faster equality: use internal data without isset array
Commit body:
Summary:
We can use the internal data tuple for equality comparisons. The tricky part is that two structs with different isset byte arrays may compare equal. So we have to encapsulate the isset byte array and override its `__eq__` operator to make it not affect the rest of the comparison.

**__We get a 14x speedup__**. This alleviates the performance discrepancy vs thrift-py3 for equality operator. Next diff alleviates perf discrepancy for hash operator.

```
buck run @//mode/opt fbcode//thrift/lib/python/benchmark:struct comparison-benchmark
```
