Commit title: Move HTTPTransactionCallback to implementation file
Commit body:
Summary:
The `HTTPTransactionCallback` class was previously defined in the header file as a private nested class, which unnecessarily exposed implementation details and increased compile-time dependencies for any code including `HTTPClientChannel.h`.

This change moves `HTTPTransactionCallback` into an anonymous namespace in the `.cpp` file, making it a true implementation detail. This provides several benefits:

1. **Reduced header dependencies**: Removes the need to include `proxygen/lib/http/session/HTTPTransaction.h` in the header file, reducing transitive compilation overhead for all files that include `HTTPClientChannel.h`
2. **Faster compilation**: Changes to `HTTPTransactionCallback` no longer require recompiling all downstream code
3. **Better encapsulation**: The class is now truly private and cannot be accessed or referenced outside the implementation file
4. **Cleaner interface**: The header file is smaller and focuses only on the public API

The `getTransaction()` method was also removed as it's no longer needed in the public interface.
