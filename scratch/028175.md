Commit title: fix IssetArray leaks
Commit body:
Summary:
Cython increments the refcount when returning `object`. But the `.cpp` usage does not take a RAII strong ref. So we change the return to `PyObject*` to fix leak. Notice the gencode is also much more terse so should be marginally faster.

Audited usage to make sure we never create a strong reference (`PyUniqueObjPtr`) with result of `IssetArray_get`.

Second issue: cython is not actually stealing reference to byteArray in `IssetArray_make` so switch to normal `object`.
