Commit title: fix state directory creation when a symlink to the state_dir already exists
Commit body:
Summary:
korest reported that the newest watchman release was failing on their machines with the following error:

```
[watchman] while computing sockname: failed to create /var/facebook/watchman/oresk-state: Not a directory
```

`/var/facebook/watchman/oresk-state` is a symlink to an existing directory. folly::fs::create_directories doesn't error if the directory already exists, but it looks to not follow symlinks.

This adds an explict check for the existence first and gates the creation logic on this check. The previous logic had this check (see D82991196), but the updated logic doesn't acount for state_dir being a symlink
