Commit body:
Summary:
When running devious baton with multiple parallel batons (count > 1), the session would eventually hang and never close because of this sequence of events:

`activeBatons_ = 2`

[Baton 1 finishes]
  → onBatonFinished() called
  → Check: 2 == 0? No
  → Decrement: activeBatons_ = 1

[Baton 2 finishes]
  → onBatonFinished() called
  → Check: 1 == 0? No (bug here, we never close the session)
  → Decrement: activeBatons_ = 0
