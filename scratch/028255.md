Commit title: Fix missing separators when two are adjacent
Commit body:
Summary:
This duplicate detection logic is broken:

```cpp
size_t separatorAfter = res.benchmarks.size();
if (separatorAfter == 0) {
  return;
}
if (res.separatorsAfter.empty() ||
    res.separatorsAfter.back() != separatorAfter) {  // BUG: Always true
  res.separatorsAfter.push_back(res.benchmarks.size() - 1);
}
```

If a benchmark specifies two separators in a row -- this is especially easy when composing benchmarks dynamically ...

```cpp
addBenchmark(__FILE__, "-", []() { return 0; });
```

... then the `separatorsAfter` list ends up with a duplicate, which puts the "benchmark" and "separator" counters out of sync, preventing all subsequent separators from rendering.
