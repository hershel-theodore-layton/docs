Commit title: Do not compute hash for F14 tables when `size() <= 1`
Commit body:
Summary:
`computeHash(key)` calls are not free. If we are calling `find()` on
empty container, there is no need to compute hash for the key, because we are
not going to find anything for sure. Moreover, there is no need to compute hash
for the key, when there is exactly one element in the table, we can compare key
directly with this element. There is a caveat though. We can not call `begin()`
for `F14Vector*` containers (`kEnableItemIteration == false`), so this
optimization will be disabled for them.
