Commit title: Add session write buffer limit control to HTTPClientChannel
Commit body:
Summary:
This change exposes HTTP session write buffer limit control through HTTPClientChannel to allow clients to configure the write buffer limit for their HTTP sessions.

The default write buffer limit defined in HTTPSessionBase::kDefaultWriteBufLimit (set to 65536 bytes) is insufficient for certain workloads, causing transfer pauses when sending large Thrift requests, particularly those containing images or other large payloads. This change enables clients to tune the write buffer size based on their specific workload characteristics to avoid these transfer pauses.
