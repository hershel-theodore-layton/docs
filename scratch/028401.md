Commit title: Convert HTTPClientChannel::TransactionObserverCreator to interface for better observability
Commit body:
Summary:
The TransactionObserverCreator was previously a `folly::Function`, which made it difficult to extend observability patterns across different use cases. By converting it to an interface, implementations can now manage their own state and lifecycle, enabling more sophisticated observation patterns such as pooling observers or conditionally creating them based on runtime state.

This change also adds a safety check to only attach observers when they are successfully created, preventing potential null observer attachments.
