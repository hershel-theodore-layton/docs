Commit title: Special case for MISSING_TYPE_IN_HIERARCHY
Commit body:
Summary:
Currently, we fake a Tany definition by silencing arity errors e.g.
```
type USELESS_TYPE_ACTUALLY_MIXED<T> = T;
/* HH_FIXME[4101] Sadly, yes */
type MISSING_TYPE_IN_HIERARCHY = USELESS_TYPE_ACTUALLY_MIXED;
```
We would like to hard-ban silencing arity errors with code 4101. So temporarily, until we eliminate all uses of `MISSING_TYPE_IN_HIERARCHY` from the codebase, we can special case it in localization, just as we do for `POISON_MARKER`.
