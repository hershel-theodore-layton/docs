Let `__fbthrift_thrift_uri` have type `constexpr folly::cstring_view`. This is a new type like, and wrapping, `std::string_view` that is also a C string, so it's slightly more generic for compile-time strings.

Improves build-size somewhat compared to functions, non-`constexpr`, and with `uri<...>()` making and returning a global `std::string`.
