Commit title: only generate one version of types reflection
Commit body:
Summary:
All thrift-python libraries depend on -py3-types-reflection if `"py3"` is also in their `languages`.

However, we're generating two versions of py3-types reflection via auto-migrate constraint, even though the content of py3-types-reflection is the same in both cases.

To solve this, make a `-python-types` library unconditionally depend on `-py3-types-reflection` if `"py3"` is in `languages`. This should be ok from a build size perspective because `-py3-types-reflection` is a `python_library`, and it doesn't have any __generated__ `cython_library` dependencies.
