Summary:
This diff migrates all usages of `SignalsPipeUtils::makeCopy()` to the new `ThriftCloner::clone()` method and removes the `makeCopy()` implementation from `SignalsPipeUtils`.

The migration improves code organization by consolidating thrift cloning logic into a dedicated utility class (`ThriftCloner`) that can be used across the entire codebase, not just in the signals pipe context.

The `ThriftCloner::clone()` method provides the same optimized cloning behavior as the previous `SignalsPipeUtils::makeCopy()` implementation:
- For shapish structs: Uses `__toShape()` / `__fromShape()` for efficient cloning
- For non-shapish structs: Uses `TBinarySerializer` for deep copying
