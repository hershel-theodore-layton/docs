Commit title: document str Enum API change between py3 and python
Commit body:
Summary:
This documents an issue created by breaking format change to `enum.Enum` in Python 3.11.

Thrift-python was forced to use format via `f"{val}"` to accomodate Instagram usage of string `Enum`s used to construct `string` fields. That means that the py3 to python migration is exposed to the issue documented w/r/t to the Python 3.12 migration.

__Mitigation__
For customers using Python 3.12 already, it's best to migrate them from `MyEnum(str, Enum)` to `MyEnum(StrEnum)`. Customers with 3.10 support needs can use `from python.migrations.py310 import StrEnum310 as StrEnum`.

Note, this is *only* required where customers are populating `string` fields via string `Enum`, which is not particularly common.
