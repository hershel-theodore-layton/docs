Commit title: enqueue CloseSession via ::onCloseSession
Commit body:
Summary:
When receiving a CloseSession WebTransport frame from the peer, enqueues a CloseSession event for the write loop
Some notes:
* this is fine w.r.t to the WebTransport RFC – ("The recipient ... does not need to send a WT_CLOSE_SESSION capsule in response")
* this is a helpful way for the http/2 write loop to know when we're actually fully done writing – currently if it just loops on (WtStreamManager::isClosed), there may still be pending writes to flush
* if the peer has sent an http/2 rst_stream subsequent to close_session, writing the close_session in response is a no-op anyways
