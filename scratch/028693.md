Commit title: only change clock on actual changes
Commit body:
Summary:
This diff changes how we update the `last_clock` carried around in an Eden-backed `ServerNotifier.t`.

Instead of updating it on every call to `get_changes_{sync, async}`, we now update it only when these calls returned actual file changes.

This has two advantages:
- It avoidsspamming the server log with confusing messages "Recheck at watchclock ...", when  no recheck is about to happen
- It makes it easier to implement the subsequent changes in this stack

This has no other effects on observeable behavior of the file watcher.
