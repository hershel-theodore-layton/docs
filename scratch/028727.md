Commit title: iterative parsing of else-if chains
Commit body:
Summary:
This diff changes how if statements are parsed: In order to avoid deeply recursing for long chains of else-if chains, we parse them iteratively.

Using our not-quite-EBNF, we parse `if` statements as follows now:

```
if-statement:
  if-header   else-if-clause*   else-footer-opt

if-header:
  if   (   expression   )   statement

else-if-clause:
  else   if   (   expression   )   statement

else-footer: (where statement is not an if statement):
  else   statement
```
