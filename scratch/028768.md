Summary:
Up-stack, rich error code has fairly robust `constexpr` support. The major benefit for me is that constant-evaluated code is run by the compiler in a VM that actively blocks UB. So, the portions of the code that are exercised at compile-time end up demonstrably safe, even more so than UBSAN can give us.

It's also nice, of course, to have a reasonable error-handling paradigm for `constexpr` code before C++26.
