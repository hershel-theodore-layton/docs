Commit title: Lints for scoped & fully qualified identifier ambiguity
Commit body:
Summary:
Extends the Thrift compiler's identifier resolution linter to detect and report ambiguous scoped (`foo.Bar`) and fully-qualified identifiers (`foo.Bar.BAZ`).

## Examples

- `Foo.Bar` where `Foo` is a local enum AND an included program
- `foo.Bar` in `foo.thrift` referencing a local definition
- `foo.Bar` when multiple `foo.thrift` programs are included, suggesting an include alias
- `foo.Bar.BAZ` when multiple `foo.thrift` programs are providing a Bar.BAZ value
