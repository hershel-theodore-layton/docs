Commit title: Do not generate Tanys internally when localizing function type
Commit body:
Summary:
When localizing function types, avoid creating a type substitution with `Tany` in it. Principally this was happening in the typing of format strings, whose `format` functions are sometimes generic e.g.
```
interface SQLFormatter {
  public function format_upcase_u<T>(
    KeyedTraversable<arraykey, T> $update_array,
  ): string;
}
```
Instead of generating fresh type variables for `T`, we were generating `Tany`.
