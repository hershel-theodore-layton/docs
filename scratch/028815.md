Summary:
Sometimes we need to retrieve authenticated identities from the connection certificate (which are different from existing identities). Parsing the certificate for every request is clearly unnecessary. We can cache this result in the connection context.

Here, we use `folly::erased_unique_ptr` to avoid creating new dependencies.
