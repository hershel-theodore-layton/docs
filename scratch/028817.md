# Rich errors for `folly::result`

Adds a rich error framework to `result`, providing exception-like flexibility with error-code-like speed. The core value proposition: errors that are cheap to return (almost like integer codes), cheap to query (usually no RTTI), and rich enough for production debugging (codes, messages, provenance).

## Key features

- **Error codes**: Typed codes with RTTI-free retrieval -- a fresh take on the `std::system_error` use-case.
- **Immortal errors**: `constexpr` singletons nearly as cheap as integer codes.
- **Provenance tracking**: Stack context as errors propagate, without changing identity.
- **Fast lookups**: Avoid RTTI on the happy path; 8-byte bit-packed storage.
- **`fmt` & `<<` support**: Structured logging replaces `what()`.
