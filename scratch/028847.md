Commit body:
Summary:
Now that thrift-python enforces float32 rounding, can remove related conversions from thrift-py3 inplace wrapper.

There are three cases the new `__eq__` handles:
1. thrift-py3 inplace vs thrift-py3 inplace
2. thrift-py3 inplace vs thrift-python
3. customer struct inheriting from thrift-py3 inplace. For example, logger. In this case, it's important to use inner object equality to avoid interference from any field name attributes overridden by child class.

__Sidebar: Union.fromValue__
Note there's some separate `float`-related logic in `Union.fromValue`. But this can't be removed because thrift-py3 and thrift-python have different behavior, so in-place has to match the thrift-py3 behavior.
