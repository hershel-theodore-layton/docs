Commit title: ensure string field initialized correctly from str Enum
Commit body:
Summary:
The formatting behavior of `MyEnum(str, Enum)` differs between Python3.10 and 3.12. [See post](https://fb.workplace.com/groups/pyupgrades/permalink/3485454521758675/).

This causes a problem for the relatively rare case where a string `Enum` is used to populate a `string` field of a thrift struct. To avoid behavior change in thrift-py3, inplace has to "unwrap" the enum to its `.value` because thrift-python uses `__format__` instead of `__str__`. Funny enough, it's usage of Python 3.12's new `StrEnum`, which compels thrift-python to use `__format__`.
