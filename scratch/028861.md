Commit title: SimpleAsyncIO: Release opHolder before notifying the user
Commit body:
Summary: The user might be using some kind of a counter to count how many async IO outstanding to avoid BUSY errors because of too many IOs. The counter would increase when IO has started. The only correct time to decrease this counter is when users callback is called. But SimpleAsyncIO has not returned the holder yet to the pool, an attempt to start another IO would fail. This diff fixes this situation.
