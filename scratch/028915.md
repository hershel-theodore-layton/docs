Commit title: Add SparseBitset utility for memory-efficient sparse set storage
Commit body:
Summary:
This adds a new SparseBitset data structure that provides
memory-efficient storage for large, sparse sets of integers. Instead
of allocating a full bitset for the entire range, it divides the space
into chunks and only allocates storage for chunks containing at least
one set bit.

This is useful for representing sparse integer sets without the memory
overhead of allocating space for the entire possible range. It is
particularly optimized for the case when the most frequent set members
have the lowest indices. This keeps the total number of chunks low and
hence efficient.

Nothing uses this so far, but it will be used in HHBBC in a later
diff.
