Commit body:
Summary:
Add a class to implement tabulation hashing in
hphp/util/hash.h. Tabulation hashing is a simple and efficient hashing
technique that provides k-independence guarantees. It works by
splitting the input into fixed-size blocks, then using each block as
an index into a randomly generated lookup table, and finally XORing
all the table lookups together.

This implementation also supports "twisted" or "mixed" tabulation hashing
(when D > 0), which provides even stronger theoretical properties by
introducing derived blocks that are hashed through an additional layer.

Hashing of integral values is implemented, as well as std::array<> of
integral values.

This class isn't actually used yet, but will be in a later diff.
