Commit title: remove re-entrancy when serializing objects from Xenon
Commit body:
Summary:
The xenon extension added an output file option and would call
json_encode to reach into the variable serializer which in turn calls
jsonSerialie. This was re-entrant and observed with a debugger breakpoint
stepping into serialization methods.

This diff tweaks variable-serializer to take a flag to not call jsonSerialize
on the object, instead using the normal object serialization. We then use that
code in Xenon.
