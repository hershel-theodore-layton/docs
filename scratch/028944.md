Commit title: Introduce ApproximateNearestNeighbor for fast similarity search
Commit body:
Summary:
Add ApproximateNearestNeighbor, a MinHash-based Locality Sensitive Hashing
(LSH) data structure for efficiently finding similar sets. Given a collection
of sets, it can quickly identify which sets are most similar to a query set
without comparing all pairs.

MinHash leverages the property that for two sets A and B, the probability
that their minimum hash values are equal is exactly their Jaccard similarity:
P(min_hash(A) == min_hash(B)) = |A ∩ B| / |A ∪ B|. Multiple hash functions
(rounds) create a "sketch" of each set, and multiple independent experiments
increase detection probability while reducing false positives.
