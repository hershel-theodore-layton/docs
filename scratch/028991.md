Commit title: Fix completeness bug for subtyping for functions with named parameters
Commit body:
Summary:
## What

We make the following (and similar) hold:

   function(optional named bool $b): void   <:   function(): void

## Why

The above should hold due to [the design of named parameters](https://fburl.com/hack_named_parameters_proposal): subtyping should match that of the corresponding shapes encoding.

The following holds:

   function(shape(?'b' => bool): void   <:   function(): void

Intuition:
- A function that optionally takes a named argument is can be used wherever a function that doesn't expect the named argument is expected (because the named parameter is optional)

Note that this change makes named parameters more like positional parameters, since we already have the expected subtyping relationship for positional optional parameters:

     function(optional bool): void   <:   function(): void
