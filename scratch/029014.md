Commit title: Add fallback to TW crash config path for stats logging
Commit body:
Summary:
Add support for using Tupperware's crash config backup path as a fallback location for stats logging when the default stats_root path is unavailable. This improves reliability in Tupperware environments where the default stats path may not be writable, particularly during container lifecycle events or filesystem issues.

The change maintains backward compatibility by attempting the default path first, only falling back to the TW path when explicitly enabled via the enable_tw_crash_config_backup_path option.
