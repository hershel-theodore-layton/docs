Summary:
A couple of Thrift test headers: `thrift/test/StructsExtra.h` and `thrift/test/reflection/fatal_merge_types.h` use a macro `FBTHRIFT_CPP_DEFINE_MEMBER_INDIRECTION_FN` without including the header that defines the macro `thrift/lib/cpp2/Thrift.h`.

Before modules, this was okay if something else includes `thrift/lib/cpp2/Thrift.h` before including `thrift/test/StructsExtra.h` or `thrift/test/reflection/fatal_merge_types.h`. But with modules, this errors while trying to precompile the headers since they need to be standalone.

The solution is to add the missing includes.
