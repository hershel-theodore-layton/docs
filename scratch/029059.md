Commit title: Remove mstch_enum_value
Commit body:
Summary:
Remove `mstch_enum_value` after migrating C++ const value codegen to Whisker.

`mstch_enum_value` was previously removed, but restored due to `value:referenceable?` not being supported in Whisker. After migrating C++ const value codegen (using Whisker `referenceable_from?`), `mstch_enum_value` is no longer necessary.

`enum:values` will fallback to Whisker prototype, returning Whisker prototype for `t_enum_value`. `mstch_enum_value` only provided `structured_annotations` which was only used in C++ codegen, with all other properties already falling back to the Whisker prototype.

- Remove `mstch_enum_value`
- Remove mstch property `enum:values`, so usages will fall back to Whisker prototype returning array of `t_enum_value` native handles
- Remove explicit `.self` navigation in Java template, since `enum_value` will now be a native handle rather than `mstch_enum_value` instance
- Update C++ template usage of `enum_value:structured_annotations`, which will now loop over Whisker `t_const` native handles, rather than `mstch_const`
