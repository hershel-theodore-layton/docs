Summary:
* adds two new methods to HTTPHeaders (::getSingleOrNullptr, one that takes in an HTTP_HEADER_CODE & another that takes in a folly::StringPiece)
* it's can be very useful to distinguish whether or not a header name has been seen and retrieve its value in a single api (see next few diffs)
* detemplatizes the current ::getSingleOrEmpty, and delegates to the newly added ::getSingleOrNullptr

the common pattern of
```
if(HTTPHeaders::exists(headerName)) {
  auto headerValue = HTTPHeaders::getSingleOrEmpty(headerName);
}
```

can be replaced with the new ::getSingleOrNullptr method to elide one memchr lookup
```
if(const auto headerValue = HTTPHeaders::getSingleOrNullptr(headerName)) {
  (void)headerValue
}
```
