Commit title: Replace mstch field:value and constant:value with Whisker values
Commit body:
Summary:
Replace `field:value` which returns `mstch_const_value` with `field:default_value` (provided by the base Whisker generator), which returns a `t_const_value` native handle.

Remove `constant:value` which returns `mstch_const_value`, so usages will fall back to Whisker `t_const` prototype's `value`, which returns a `t_const_value` native handle.

Since `mstch_const_value` does not itself present any properties or have sub-classes (i.e. all properties fall back to the Whisker prototype), `field:value` and `field:default_value` have identical output behavior.
