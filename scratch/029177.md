We cannot assign the unit's sn within emit_unit() because it will soon
run from within RE. We cannot maintain a single unique id because
they'll be running on different machines. Instead, assign the sn at
the only point where we're guaranteed to be running locally. IE, when

extensions. Add a special flag to specify that we want the Extension*
even if that extension is disabled.
