Commit title: Add RetainedInfo class to HHBBC
Commit body:
Summary:
Distributed whole-program analysis can violate monotonicity when the
same entity is analyzed on multiple jobs with different dependency
sets. An entity might produce more specific types on one job (where
dependencies happen to be available) than on its authoritative job,
causing dependent entities to see regressing type information in
subsequent rounds.

RetainedInfo solves this with a "ratchet" mechanism: when an entity
uses information from another entity, it retains that info
internally. On subsequent rounds, if the obtained information becomes
less specific, the retained info is used instead, ensuring information
never regresses. The structure is double-buffered to track current
retained info (from last round) separately from next round's info,
since optimized-away dependencies no longer need retention.

This is meant to replace the earlier "permission" model, but that will
be removed in later diffs.
