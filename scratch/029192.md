Commit title: Reduce amount of code on F14 find hot path
Commit body:
Summary:
Before this change we evaluated two branches for each find: one for
`sz == 0` and one for `sz == 1`. In cases, when container is not empty we can
evaluate only one branch. Moreover, turns out, when we nest branches compiler
is smart enough to avoid shifts for size calculation.
