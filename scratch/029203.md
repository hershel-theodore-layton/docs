Commit title: TimerFD: remove folly::EventReadCallback
Commit body:
Summary:
`folly::EventCallback` is a part of `folly::EventBaseEvent` used by `folly::EventBase`. Its purpose is to allow `folly::EventBaseEvent` to issue async I/O if the `EventBase` uses `IoUringBackend`.

If the EventBase backend is *not* `IoUringBackend`, then `folly::EventCallback` is unused.

My goal is to remove `folly::EventCallback` entirely. The way to use `IoUringBackend` will be at the socket level and will use composition rather than inheritance.

TimerFD implements folly::EventReadCallback, but it has no users that also use IoUringBackend.
