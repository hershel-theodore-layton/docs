Commit title: Add property dependency tracking and analysis to distributed HHBBC
Commit body:
Summary:
Add property dependency tracking and analysis to distributed HHBBC, in
a similar manner to the existing non-distributed logic. Once again,
the old way didn't track dependencies properly, so the new way is
improved.

When doing property lookup, we must walk (potentially) the whole class
hierarchy to find all declarations of the property. Not only is this
slow, but it's very expensive in distributed mode (the class hierarchy
can be huge and we don't want to have to pull in every class). To
mitigate this, each class-info stores a mapping of properties to their
potential declarations. Using this, we only need to fetch and analyze
the classes which actually have relevant declarations. This map is
flattened across the class hierarchy.
