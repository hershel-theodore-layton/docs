Commit title: Add zstd DecompressionFilter
Commit body:
Summary:
Add a server-side `DecompressionFilter` to proxygen's httpserver filters to support transparent decompression of incoming request bodies.

## Motivation
Clients may send compressed request bodies (zstd-encoded) to reduce bandwidth usage. This filter enables the server to transparently decompress such requests before they reach the application handler.

## Changes
1. **Created `DecompressionFilter.h`** - Header-only filter class extending `Filter`:
   - Detects `Content-Encoding: zstd` header on incoming requests
   - Initializes `ZstdStreamDecompressor` for decompression
   - Removes `Content-Encoding` and `Content-Length` headers after initialization
   - Includes `DecompressionFilterFactory` for integration with `RequestHandlerChain`

2. **Created `DecompressionFilter.cpp`** - Implementation:
   - `onRequest()`: Checks for zstd Content-Encoding and initializes decompressor
   - `onBody()`: Decompresses body chunks, aborts on errors
   - `onEOM()`: Flushes any remaining decompressed data

## Design
- Follows the same pattern as the existing `CompressionFilter` (for response compression)
- Uses streaming decompression to handle large request bodies efficiently
- Gracefully handles errors by aborting the request
