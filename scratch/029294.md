Summary:
## What

For warnings that say to add the __NeedsConcrete attribute, give the user a quickfix for adding the attribute.

Note that the quickfixes won't show up until `needs_concrete=true` is set in .hhconfig (when Safe Abstract is released)

https://pxl.cl/8HvD8

https://pxl.cl/8HwPf

## Why

Better user experience–very easy to action most warnings

## How

Quickfix edits are computed lazily. Here's why:
- We need precise locations (full fidelity syntax tree)
- Perf. The edit is only computed when the user has selected which quickfix they want.
