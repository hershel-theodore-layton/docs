Commit title: Auto-enable BUILD_SHARED_LIBS when PYTHON_EXTENSIONS is ON
Commit body:
Summary:
Python extensions require shared libraries for proper symbol resolution at runtime. Rather than requiring users to manually set both BUILD_SHARED_LIBS=ON and PYTHON_EXTENSIONS=ON, this change automatically enables BUILD_SHARED_LIBS when PYTHON_EXTENSIONS is requested.

This simplifies the build configuration for Python bindings while having no impact on C++ builds since PYTHON_EXTENSIONS defaults to OFF.

The PYTHON_EXTENSIONS option is moved earlier in the file (after BUILD_SHARED_LIBS is defined) so that FOLLY_SUPPORT_SHARED_LIBRARY correctly picks up the auto-enabled value.
