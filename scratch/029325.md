Commit title: Fix implicit int conversion warning in to_signed_fn
Commit body:
Summary:
In `to_signed_fn::operator()`, the expression `-static_cast<S>(~t) + S{-1}`
undergoes integral promotion to `int` due to the unary minus and addition
operators. When the return type `S` is `signed char` or `short`, returning
this `int` expression triggers `-Wimplicit-int-conversion` with llvm21.

Fix by wrapping the entire ternary expression in an explicit `static_cast<S>()`.
