Commit title: Some distributed HHBBC fixes
Commit body:
Summary:
We weren't keeping the AttrNoOverride bits on a MethTabEntry and the
bits on the php::Func itself synchronized. This was harmless for
partial distributed mode because make_local() re-calculated
them. However, when we enabled full distributed mode, it lead to
methods being marked as AttrNoOverride when they weren't. This led to
all sorts of hard to debug errors, such as calling abstract functions.

Fix it by making sure the bits stay in sync. Also, fix a known issue
in bespoke arrays when turning off HHBBC. These's an assertion when
assumes a Optional is always non-empty, when it could be.
