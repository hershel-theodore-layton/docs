Commit title: state change notifications: implementation
Commit body:
Summary:
This diff implements actual support for state change notifications powered by Eden instead of Watchman.

The goal is that the overall behavior of `ServerNotifier` is the same, whether `edenfs_file_watcher_state_tracking` is enabled or not.
However, setting `edenfs_file_watcher_state_tracking=true` causes state change notifications to be provided by `Edenfs_watcher` itself, whereas`edenfs_file_watcher_state_tracking=false` preserves the existing behavior, where `ServerNotifier` carries around a Watchman instance to provide these.

Conversely, this means that `edenfs_file_watcher_state_tracking=true` now means that an Eden-powered `ServerNotifier` no longer requires a Watchman instance.

I've guarded most of the changes behind the flag  within `Edenfs_watcher`, which adds a bit of noise. Once `edenfs_file_watcher_state_tracking=true` is fully rolled out, the idea is to remove the code paths for `edenfs_file_watcher_state_tracking=false` within `Edenfs_watcher`.
