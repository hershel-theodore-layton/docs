Commit title: Fix ARGN quoting in ThriftLibrary.cmake
Commit body:
Summary:
Fix ARGN quoting bug that caused optional arguments to be dropped when multiple arguments are passed together.

The bug occurs when passing multiple optional arguments to thrift_library or thrift_object. For example:

```cmake
thrift_library(
  "my_thrift"
  ...
  THRIFT_INCLUDE_DIRECTORIES "${CMAKE_SOURCE_DIR}"
  NAMESPACE "my.namespace"
)
```

With the quoted `"${ARGN}"`, CMake collapses all arguments into a single semicolon-separated string: `"THRIFT_INCLUDE_DIRECTORIES;/path/to/source;NAMESPACE;my.namespace"`. When this string is passed to the nested thrift_generate macro, cmake_parse_arguments fails to correctly parse the arguments, causing one or both to be dropped.

With unquoted `${ARGN}`, CMake preserves the list structure and each argument is passed separately. This is the standard CMake idiom for forwarding variadic arguments.

Note: Uses with only a single optional argument (e.g., just THRIFT_INCLUDE_DIRECTORIES) likely worked because cmake_parse_arguments can handle simple semicolon-separated strings. The bug manifests when multiple optional arguments are used together.
