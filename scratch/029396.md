Commit title: Must-use-immediately types are unsafe by default
Commit body:
Summary:
There's not much "safety" impact to this change, since must-use-immediately (MUI) types are already immovable / prvalue-only.

It simply makes  `lenient_safe_alias_of_v` measurements work correctly for MUI types, out of the box.

The only scenario where we want something other than "unsafe" is in `safe_task`, which already overrides `folly_private_safe_alias_t` via a derived class -- there's no behavior change here.

In a hypothetical future, we could make `wrap_must_use_immediately_t` and `must_use_immediately_crtp` take a template param to configure the safety level, but there's no current benefit to it.
