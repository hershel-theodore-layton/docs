Commit title: Do not generate metadata for thrift/annotation files.
Commit body:
Summary:
Annotation packages (thrift/annotation, xplat/thrift/annotation) define foundational Thrift types that all other Thrift files use. They sit at the bottom of the dependency tree with no "lower" layer to depend on for metadata. When thrift-python generates thrift_metadata.py for these packages, it attempts to import metadata from dependencies that are themselves annotation files, which creates an impossible circular dependency chain.

This change adds the no_metadata compiler option for annotation packages and excludes thrift_metadata.py from their generated file lists.
