Commit title: Fix empty type parameter brackets in adapted constants
Commit body:
Summary:
Generic adapted constants were generating invalid Python syntax like
`ImmutableConfig[]` instead of `ImmutableConfig[builtins.str]`. This caused
pyre type-checking failures with "Parsing failure: invalid syntax".

The root cause was inconsistent handling between constants and other types:
for non-constants the `[]` suffix was stripped from `type_hint` so templates
could add the type parameter, but for constants it was retained, causing
templates to generate empty brackets.
