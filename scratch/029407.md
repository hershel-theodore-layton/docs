Commit title: Escape Python reserved keywords in enum class names
Commit body:
Summary:
Enum class names were not using py_name (which escapes Python reserved keywords by appending underscore), causing syntax errors when an enum is named after a Python keyword (e.g., `from`, `class`, `def`).

Previously: `class from(Enum)` - invalid Python syntax
Now: `class from_(Enum)` - valid Python

This is a bugfix, not a breaking change - code using reserved keyword enum names could never have worked because the generated code was syntactically invalid.
