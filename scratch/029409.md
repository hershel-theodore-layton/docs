Commit title: Fix Undefined type <Interaction>.Async for interaction clients
Commit body:
Summary:
For interaction clients with auto_migrate, the `__aenter__` return type was using the short interaction name (e.g., `BrowserSession.Async`) instead of the full prefixed name (e.g., `SurfGuardService_BrowserSession.Async`). This caused Pyre to report "Undefined type" errors since the short name isn't defined in the module scope.

The `__aenter__` return type for interaction clients used the short name (e.g., `"MyInteraction.Async"`) but interaction classes are defined with a parent service prefix (e.g., `"MyService_MyInteraction"`). The fix checks `service.interaction?` and uses the full prefixed name. This only affects clients generated with `auto_migrate` since that's when `__aenter__` is generated.
