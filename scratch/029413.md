Summary:
Replace boost::trim() with folly::trimWhitespace() in HTTPMessage.cpp.

The previous code used boost::trim with a cached locale object for
performance (per comments, ~1% CPU was spent on locale object creation).
folly::trimWhitespace doesn't use locale at all - it just trims ASCII
whitespace which is exactly what's needed for HTTP header parsing.

This removes boost_algorithm from the message target's deps.
