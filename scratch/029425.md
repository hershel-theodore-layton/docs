Summary:
Add getter methods on the HHVM class `AsyncMysqlConnectionOptions` to allow
PHP code to read the configured connection options. This enables reading:
- Connect timeout
- Connect TCP timeout
- Connect attempts
- Total timeout
- Query timeout
- Connection attributes

The extension version is bumped from 8.0 to 8.1 to allow www code to use
version guards when using these new getters.
