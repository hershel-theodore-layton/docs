Commit title: Support more await expressions
Commit body:
Summary:
Adds new support for awaiting within expressions when some `await` expressions may be executed concurrently while others encode implicit dependencies. For instance:

```
$x = await f(await g() + await h()) + await k()
```

Here `await f(...)` depends on `await g()` and `await h()` but `await k()` may be done concurrently. We lift this as follows:

```
concurrent {
  $t1 = await async {
    concurrent {
      $t2 = await g();
      $t3 = await h();
    }
    return await f($t1 + $t3);
  };
  $t2 = await k();
}
$x = $t1 + $t2;
```

Lifted lambdas are hidden from the user using the `f_hidden` and `NoInjection` attributes. Previously all NoInjection functions were builtins and accessing `__FUNCTION_CREDENTIAL__` was never required but this diff fixes this as well as testing that all other forms of callstack reflection hide the lifted lambdas.
