Commit title: Use 64 bit accumulator in ARM64 varint decoding
Commit body:
Summary:
For background on this optimization work, please refer to this note: https://fb.workplace.com/groups/673384395850627/permalink/729429563579443/

Crunch found an improvement that increases read throughput across all integer types.
The change is to use uint64_t for both the byte variable and accumulator. This
allows the compiler to generate code using ubfiz and ubfx (unsigned bitfield
insert/extract) with immediate operands. When the
template type T is smaller (e.g., uint32_t), using T byte forces the compiler
to insert sign/zero-extension instructions and handle partial register
updates.

On Thrift benchmarks:

```
              u32_any    u64_any
Original      1.63ns     3.52ns
Crunch        1.54ns     2.36ns
```
