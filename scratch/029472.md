Commit body:
Summary:
Path is a concept that models a traversal through a Thrift value, for example, going from a root struct to the `myList` field to its third element. This can be an input (e.g. a general `get` method on DynamicValue that returns the value at the end of the traversal) or an output (e.g. a `diff` API can provide a set of paths where two values differ).

PathBuilder is a type-aware helper class for constructing Path while validating that all accesses are valid. It provides scope guards for entering fields, list elements, map keys/values, etc., which automatically pop the path component when destroyed.

In this diff Path has the minimal API needed for the current usecase, providing human-readable string representations. This leaves us free to swap out the implementation as needed to support the more substantial APIs. PathBuilder is intended to be rich enough to construct the representation needed then.

String representation format:
  <root><component>*

Where each component is one of:
  .fieldName     - struct/union field access (enterField)
  {key}        - set element or map key (enterSetElement, enterMapKey)
  [index]        - list element access (enterListElement)
  [<value>]       - map value access by key (enterMapValue)
  [<typeId>]       - type identifier (enterAnyType)

The <> values are serialized using Thrift's SimpleJSON protocol.

Example paths:
  MyStruct.users["alice"].scores[0]
  MyStruct.tags@"important"
  MyStruct.counts@42.value
