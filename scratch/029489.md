Commit title: Short circuiting support for await
Commit body:
Summary:
This diff adds support for conditionally executed `await` expressions. This is generally done by making the lifted await statements also conditional. Special handling is added for the condition and update expressions on loops. For instance:

Short circuiting: `await a() || await b()`
Assignment: `$x[await a()] = await b();`
Prefix/Postfix: `++$x[await a()]`
Ternery: `await a() ? await b() : await c()`
Null-coalesce: `await a() ?? await b()`
For: `for ($a = await a(); $a < await b(); $a += await c()) { ... }`
While: `while (await a()) { ... }`
Do: `do { ... } while (await a());`
Nullsafe: `$a?->foo(await x());`
