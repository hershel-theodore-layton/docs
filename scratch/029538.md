Commit title: Add known size container writer API
Commit body:
Summary:
The unknown container size writer API is less efficient than the materialized container API, which is unfortunate because it is currently the only way to write a non-materialized container. Add a middle ground option that enforces the declared container size without requiring materialization.
As a bonus, this new API will be compatible with Compact protocol if we choose to add support for it, while the unknown size API is not.
