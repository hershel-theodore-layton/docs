Commit title: Move type-constant invariance tracking into distributed HHBBC
Commit body:
Summary:
For non-full distributed HHBBC, we run a pass in between
analyze-constants and full-analyze. This pass tries to determine the
"invariance" of a type-constant, which just tells the runtime how it's
resolved array compares with resolutions in subclasses.

Move this logic into distributed HHBBC. When we're resolving
type-constants, also analyze invariance. Like everything else, we
might not have full dependencies, so it may not be resolved the first
time.
