Summary:
Apply Fix 1: Use `return_ignore_readonly` in `Typing_coercion.coerce_type` when checking return statements.

When a lambda parameter has `<<__IgnoreReadonlyError>>`, the lambda's `return_ignore_readonly` field is set to true. This change passes that value to `coerce_type` so that readonly mismatches in the return type are suppressed.

This fixes cases like:
```hack
function takes_callback(
  <<__IgnoreReadonlyError>> (function(): Foo) $f,
): void {}

function test(): void {
  takes_callback(() ==> readonly_foo_source());
}
```
