Commit title: Support BUILD_SHARED_LIBS with granular CMake targets
Commit body:
Summary:
When BUILD_SHARED_LIBS=ON, granular folly targets (like folly_io_iobuf) need
to avoid duplicating symbols with the monolithic folly shared library. This
change makes granular targets behave differently based on the build type:

- BUILD_SHARED_LIBS=OFF (static): Unchanged - create STATIC libraries
- BUILD_SHARED_LIBS=ON, normal targets: Create INTERFACE libraries that link
  to the monolithic folly.so (avoids ODR violations)
- BUILD_SHARED_LIBS=ON, EXCLUDE_FROM_MONOLITH: Create SHARED libraries with
  their own code (e.g., follybenchmark.so)

Also adds EXTERNAL_INCLUDE_DIRS parameter to folly_add_library() for external
include directories (e.g., libsodium), which works correctly with INTERFACE
targets in shared builds.
