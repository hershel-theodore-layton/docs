Commit title: Add `now_task::as_unsafe()` deprecated escape hatch
Commit body:
Summary:
`now_task` is the recommended async pattern for new code; however, a lot of futures based code needs to still make the migration.

In this diff, add an escape hatch to `now_task` to return the underlying `folly::coro::Task`. This unsafe `Task` does not have the memory guarantees that `now_task` has; however, it is very useful for teams that want to begin the migration and leverage their existing automated tests.

`asUnsafeSemiFutureWithSharedPtrGuard` demonstrates a pattern teams can use to hook up their existing futures based automated tests to call their coroutine implementations for better coverage during the migration.
