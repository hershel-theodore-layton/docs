Commit body:
Summary:
The parallel loop in refinePublicSPropMutations was calling find_deps() from
multiple workers, all writing to the same DependencyContextSet. This is a data
race that could cause sporadic crashes.

Fix by giving each worker its own DependencyContextSet, then merging the
results after the parallel loop completes.

This code is ancient, so I have no idea why it suddenly started causing problems.
