Commit title: Error for __NeedsConcrete on instance methods and constructors
Commit body:
Summary:
Add type errors when `<<__NeedsConcrete>>` is placed on:
- nonstatic methods. The __NeedsConcrete attribute says that a method can only be called on a concrete class, but this is already the case for nonstatic methods. This is because when we are in a nonstatic method of class C, we know that C must have been instantiated, and only concrete classes can be instantiated.
- Constructors–by similar reasoning as for nonstatic methods

Forbidding __NeedsConcrete methods where they would be superfluous is intended to help make the feature easier to understand and avoid noise in WWW.

## More context

In the (likely distant) future, we want to make a distinction like Python's distinction between class methods and static methods via syntax, not just an attribute. So having a `__NeedsConcrete` nonstatic method would be like having a method that is both a class method and an instance method: it makes no sense.
