Summary:
As it is we use different types to represent credits throughout the codebase - we need to decide on one type and be consistent to avoid weird shortening casts.

While the original implementation uses 64 bit integers, I would actually propose using `int32_t`. RSocket / Rocket only support `int32_t` at the frame level, so using int64_t anywhere else would eventually necessitate conversion.
