Commit body:
Summary:
See D90950367 for context on why value-only await protocols (`value_or_error`, `co_awaitTry`) need noexcept `await_ready` and `await_suspend`.

This diff adds `ValueOnlyAwaiterBase`, a mixin for value-only awaiters that enforces noexcept via `static_assert`. This catches violations at compile time instead of allowing exceptions to escape from these methods, breaking the value-only guarantee.

The static asserts point to guidance in the class doc:
  - Design `await_ready` and `await_suspend` to be noexcept.
  - If invariant checks are needed, push failures to `await_resume()` if feasible.
  - Otherwise, debug-fatal on violations and throw a clearly "do not catch me" error in opt.
