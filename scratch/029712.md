Commit title: Add direct encode() method to avoid toObject() overhead
Commit body:
Summary:
This diff adds a direct `encode()` method to `DynamicMapPatch` and `DynamicStructPatch` (and `DynamicUnionPatch`) to serialize patches directly to the protocol without first converting to `protocol::Object`.

Previously, `DynamicPatch::encode()` would fall back to `toObject()` followed by `serializeObject()`. This introduced unnecessary overhead by creating intermediate `Object` representations.

The new implementation:
1. Adds `encode()` template methods to `DynamicMapPatch` and `DynamicStructPatchBase` that write directly to the protocol
2. Simplifies `DynamicPatch::encode()` to unconditionally call `patch.encode(prot)` since all patch types now support direct encoding
