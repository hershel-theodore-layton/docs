Commit title: Use boost::polymorphic_downcast instead of dynamic_cast
Commit body:
Summary:
Using `dynamic_cast` is expensive.  As such we were often only using it in debug mode and doing some other sort of static cast in release mode.

Boost has polymorphic_cast (https://www.boost.org/doc/libs/latest/doc/html/conversion/polymorphic_casts.html) that essentially does this for us, making the code cleaner.

For all the cases where the code assumes the dynamic_cast would succeed (the code relies on it being true), use boost::polymorphic_downcast instead.
