Commit title: Fix command-line option parsing for HPHPc
Commit body:
Summary:
Command-line options should always take precedence over what is
specified in a HDF config file. However, this was not the case for
HPHPc. When support for build-time overrides was added, the overrides
were applied after both config file and command-line parsing was
done. This means the overrides take precendence over the command-line!

The correct thing to do is to re-apply the command-line after the
overrides are applied. We cannot just move when they are applied
because the command-line options might influence the build-time
overrides. Therefore we apply them once, apply overrides, then apply
again. This matches what HHVM proper does.
