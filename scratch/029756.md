Commit title: Expose method arguments as DynamicValue to service interceptors
Commit body:
Summary:
Add `LazyDynamicArguments` class that provides lazy access to Thrift method
arguments as `DynamicValue` objects. Arguments are deserialized on-demand from
the serialized request buffer using schema information.

Key features:
- `get(index)`: Get argument by 0-based index, throws `std::out_of_range` if invalid
- `get(name)`: Get argument by parameter name, throws `std::out_of_range` if not found
- Arguments are deserialized lazily on first access and cached
- Supports both Compact and Binary protocols

This is exposed via `RequestInfo::dynamicArguments` in service interceptors,
allowing interceptors to inspect arguments without knowing compile-time types.
