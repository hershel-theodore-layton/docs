Commit title: Add fromStaticPatch to convert static patches to DynamicPatch
Commit body:
Summary:
Today, to convert a static patch to dynamic patch, we need use `DynamicPatch::fromObject(staticPatch.toObject())`. This is slow since it created an intermediate `protocol::Object`.

This diff adds `fromStaticPatch` conversion methods to DynamicPatch and its variants (DynamicListPatch, DynamicSetPatch, DynamicMapPatch, DynamicStructPatch, DynamicUnionPatch).

These methods enable direct conversion from statically-typed Thrift patch objects to their dynamic equivalents without going through the Object serialization/deserialization path. This provides:

1. A more efficient conversion path by directly copying fields from static patches
2. Type-safe conversion using compile-time type detection via new traits (`is_list_patch_v`, `is_set_patch_v`, `is_struct_patch_v`, `is_union_patch_v`)

Key changes:
- Added `fromStaticPatch` template methods to all DynamicPatch variants
- Added `set(PatchOp, Value)` helper method to DynamicBasePatch
- Extended PatchTraits.h with new type traits for list, set, struct, and union patches
- Added forward declarations for patch-related identifiers in the `apache::thrift::ident` namespace
