## What

For all hh_single_type_check flags where it was straightforward to do so:
- In tests: use `--config` instead of the corresponding ad-hoc flag
- delete the ad-hoc flag

No change to public API, as hh_single_type_check is Hack-team-only

## Why

- This change enables our tests to test something closer to prod behavior, since in prod we use the config mechanism where available rather than custom flags
- Less noise in hh_single_type_check, easier to maintain

## Implementation note

hh_single_decl and compare_folded_decls_file seemed to have code specifically to ignore the hh_single_type_check flags we remove here. So I deleted that code. Tbh not sure entirely what that mechanism did, but the change seems safe since:
- tests pass, with no changes except to HH_FLAGS
- compare_folded_decls_file and hh_sinlge_decl are also not used in prod
