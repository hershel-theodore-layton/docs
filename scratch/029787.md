Commit title: Fix missing __Enforceable check for inherited type constants
Commit body:
Summary:
This diff fixes a bug where the `__Enforceable` check was incorrectly skipped for type constants inherited from a parent class.

The issue occurs when:
1. An interface declares a type constant with `<<__Enforceable>>`
2. A parent class defines a concrete type constant (without implementing the interface)
3. A child class extends the parent and implements the interface

Previously, the enforceable check was wrapped in `if inherited then () else ...`, which skipped the check when the type constant was inherited. The comment said "Don't recheck inherited type constants: errors will have been emitted already for the parent", but this is incorrect when the enforceable requirement comes from an interface that the current class implements but the parent class doesn't.

The fix removes the `inherited` guard for the enforceable validation while keeping it only for the reifiable validation (since reifiable is inherited, unlike enforceable which can come from a newly implemented interface).
