Commit title: Add percentile accuracy comparison to TimingSeries test
Commit body:
Summary:
Add tests to document the trade-offs of Z-score based percentile estimation in TimingSeries.

Percentile Accuracy Test: Extends TestBasicTimeseries to compare Z-score estimated percentiles against exact percentiles calculated from sorted raw data. The Z-score method (X = μ + Zσ) assumes normal distribution, but real latency data is typically right-skewed, causing underestimation of higher percentiles. Test validates estimates are within 30% of exact values.

Memory Usage Test: Adds TestMemoryUsageComparison demonstrating the memory efficiency of Z-score estimation:

Raw storage: O(n) - must store all values for exact percentiles
Z-score: O(buckets) - fixed size regardless of sample count
For 1M samples with 60s history, Z-score uses ~2000x less memory (3.75 KB vs 7.63 MB).
