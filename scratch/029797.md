Commit title: disallowCollections option on serialization
Commit body:
Summary:
We have some data we keep in an external cache. That data is serialized. When we read it, unserialized and then we put the data in APC. APC is a lot slower when it stores Hack collections compared to Hack arrays. I want to add this option to fail serializing Hack collections so we don't have slow APC reads and writes - users probably don't know the intricacies of APC well enough to understand the perf implications of putting a `Map {}` in APC.

As a followup, I plan to have the builtin I'm adding in D88084851 not need to traverse unserialized data to make it uncounted for APC - we can make the values uncounted in variable-unserializer.cpp, and then write that uncounted value directly to the APC map.
