Summary:
The fix was to
  change asType<T>() to use
  std::get_if directly on the variant
  instead of going through visit(),
  which applies maybe_deref() and
  incorrectly dereferences pointer
  types.

  The bug was:
  1. asKind<Kind::STRUCT>() calls
  asType<StructPtr>()
  2. asType used visit() which applies
   maybe_deref()
  3. maybe_deref() dereferences
  folly::not_null<const StructNode*>
  to const StructNode&
  4. The visitor looking for const
  StructPtr& never matched the
  dereferenced const StructNode&

  The fix uses std::get_if<T>(&type_)
  directly, which returns a pointer to
   the variant alternative without any
   transformation.
