**Overview**

This change introduces `SecureRocketClient`, a class derived from `RocketClient` that extends the base functionality with security logging and connection termination capabilities.

**Design**
Two abstract interfaces are defined at the `RocketClient` level:
   - `RocketClientLogger` - Provides logging capabilities
   - `RocketConnectionTerminationPolicy` - Defines the policy for determining whether a connection should be terminated based on security criteria

These abstractions will be implemented at the `ServiceRouter` level (`ConnectionLogger` and `ConnectionTerminationPolicy`) and injected into `SecureRocketClient` via constructor dependency injection.

This diagram illustrates Rocket client architecture supporting two concurrent use cases during.
   - Use Case 1 - ServiceRouter (Secure Path):
Utilizes the new SecureRocketClient with custom implementations of RocketClientLogger and RocketConnectionTerminationPolicy, routed through SecureRocketClientChannel.
   - Use Case 2 - Proxygen (Legacy Path): Continues using the existing RocketClient via RocketClientChannel.
