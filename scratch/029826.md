Commit title: Add processor panic tracking metric
Commit body:
Summary:
Add a new server metric "thrift.golang.processor_panics" to track when handler functions panic during request processing. This enables monitoring and alerting on processor panics in production, helping identify unstable handlers that need attention.

The implementation intercepts panics before they are handled by the reactor-go library, records the metric, then re-panics to let the downstream library handle the error response to the client.
