Summary:
The TokenlessPacer had an experimental mode that compensates for timer drift
by scaling the burst size based on the actual time elapsed since the last write.
This behavior is now made the default, removing the need for explicit
configuration.

Changes:
- Remove the experimental option in the pacer, transport setting, and the knob to control it
- Make timer drift compensation the default behavior
- Update the defaultRttFactor to {1,1} in the transport settings. The default override is no longer needed with the timer compensation. Can still be configured if needed.
- Update unit test names and behavior where it was dependent on old behavior
