Commit title: Resolve duplicate Thrift URIs in Thrift tests
Commit body:
Summary:
Within tests, we have a lot of files with a generic test package (e.g. `apache.org/thrift/test`) and similar type names like `MyStruct`. This results in duplicate URIs for these types.

This change applies a scoping suffix to these test files to comply with our desired invariant (unique Thrift URIs). `namespace`s are applied to files whose types' generated code is referenced, to ensure consuming targets are not impacted by the package change.

Also removing the `thrift.AllowLegacyTypedefUri` annotation where not necessary, as this stops the typedefs from being assigned URIs and removes any possibility of them being duplicates.
