Commit title: Performance optimizations for folly split
Commit body:
Summary:
Optimizations for folly split string. Benchmarks improve performance by ~8% on average.

When BitsPerElement is 1 (only on x86), we can iterate through the bits of mmask faster by clearing the lowest bit (blsr in x86) instead of using shifts.

```
buck run fbcode/mode/opt fbcode//folly/facebook/bench:string_split_bench -- --bm_warm_up_iteration --bm_min_usec 5000000 --bm_regex "follySplit" --bm_estimate_time
```
