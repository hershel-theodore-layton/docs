Commit title: Add a warning for indexing a ConstSet or keyset
Commit body:
Summary:
Indexing a `keyset` with `[]` either raises an exception or returns the index, so it's pointless, and a bit dangerous. Adds a new warning (Warn[12034]) that fires for indexing subtypes of `keyset` or `ConstSet`. It suggests using `C\contains_key` or `->contains` instead.

Don't warn in the following cases
- `unset($ks[$key])` - valid way to remove an element
- `isset($ks[$key])` - also ok
- `$ks[$key] = $value` - LHS of assignment (already an error)
- Types that resolve to `nothing` - avoids false positives
