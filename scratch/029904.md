Summary:
Consolidates proxygen library targets into coarser-grained export groups.

**New consolidated targets:**

httpserver:
- `httpserver` - merges httpserver + scoped_httpserver

lib/http:
- `core` - error types, status codes, http_utils, types

lib/http/codec:
- `codec` - HTTP/1.1 and HTTP/2 codecs
- `hq_core` - HQ codec, framer, H3 errors

lib/http/codec/compress:
- `hpack` - HPACK compression
- `qpack` - QPACK compression

lib/http/structuredheaders:
- `structuredheaders` - structured headers encoder/decoder

lib/http/session:
- `session` - HTTPTransaction, HTTPSession base
- `session_server` - server-side session handling
- `session_client` - client-side session (upstream session)
- `hq` - HQ session, webtransport integration

lib/http/coro:
- `coro_core` - coro + coro_reader
- `coro` - alias for coro_core
- `coro_client` - http_client_lib, connection_cache, redirect_handler
- `coro_server` - coro_acceptor, coro_httpserver
- `coro_filters` - compression, decompression, transform filters
- `coro_transport` - coro transport utilities
- `coro_util` - coro utilities

lib/http/webtransport:
- `webtransport` - WebTransport interface
- `http_webtransport` - HTTP WebTransport utilities
- `quic_webtransport` - QUIC WebTransport impl

lib/http/codec/webtransport:
- `webtransport_codec` - merges webtransport_framer + webtransport_capsule_codec

lib/http/connpool:
- `connpool` - connection pool

Other lib:
- `dns` - DNS resolution
- `pool_generators` - server list generators
- `coro_pool_generators` - coro pool generators
- `sampling` - sampling utilities
- `services` - service utilities
- `stats` - stats utilities
- `utils` - general utilities

httpserver/samples/hq:
- `hq_server` - merges hq_params, fizz_context, HQServer
- `hq_samples` - merges hq_command_line, HQClient, SampleHandlers
