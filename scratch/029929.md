Summary:
This diff introduces new helper methods for reading and writing Thrift RPC messages and structs in TProtocol and its accelerated implementations.

**Changes:**
- Added 4 new methods to TProtocol base class:
  - `writeRPCMessage()`: Encapsulates message begin/end, struct write, and flush logic with optional oneway support
  - `readRPCMessage()`: Handles message header reading, exception detection, and optional sequence ID validation
  - `writeRPCStruct()`: Simple wrapper for struct serialization
  - `readRPCStruct()`: Simple wrapper for struct deserialization

- Implemented accelerated versions in TBinaryProtocolAccelerated and TCompactProtocolAccelerated that delegate to native implementations (thrift_protocol_* functions)

- Added test coverage for writeRPCStruct/readRPCStruct in both binary and compact protocol test suites

These helpers will be used in next diff to simplify common RPC patterns by reducing boilerplate in client/processor code and provide a consistent interface across protocol implementations.
