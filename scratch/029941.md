Commit title: Add Dict\with_capacity and Vec\with_capacity functions
Commit body:
Summary:
Add native functions to preallocate capacity for dict and vec containers.
This exposes the existing VanillaDict::MakeReserveDict and
VanillaVec::MakeReserveVec functionality to userland, allowing users to
avoid repeated reallocations when populating containers with a known size.

Usage:
```
$d = Dict\with_capacity<int, string>(1000);
$v = Vec\with_capacity<int>(500);
```

Throws InvalidArgumentException for capacity <= 0 or if capacity exceeds
system limits.
