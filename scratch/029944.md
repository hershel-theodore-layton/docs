Commit title: Fix string amplification DoS vulnerability in readStringBody
Commit body:
Summary:
The std::string specialization of readStringBody() was allocating memory based on attacker-controlled size values before validating that the buffer actually contained that much data. This allowed a small malicious packet to trigger massive memory allocation (e.g., 11 bytes causing 2GB allocation), leading to denial of service through memory exhaustion.

This fixes the vulnerability by adding a canAdvance() check before memory allocation, matching the behavior of the generic template version.

Related CVEs: CVE-2019-3553, CVE-2019-11938, CVE-2019-11939
