Commit title: Tests for handling of multiple abstract type constant definitions
Commit body:
Summary:
Adds tests covering the 18(!) different ways we can bring multiple definitions of a (single) abstract type constant into scope in a classish kind.

Some of the cases involving are of particular interest since they silently chose a particular definition of an abstract type constant, dropping the other, without error:
- `interface_require_extends_require_extends.php`
- `trait_require_extends_use.php`
- `trait_require_extends_implements.php`
- `trait_require_extends_required_extends.php`
- `trait_require_extends_require_implements.php`
- `trait_require_extends_use.php`
- `trait_require_implements_require_implements.php`
- `trait_implements_require_implements.php`

For some cases we can exploit this to generate expressions with type `Tany` and corresponding type holes.
