Commit body:
Summary:
Add support for shape field punning syntax where `shape($foo)` is shorthand for `shape('foo' => $foo)`. The new syntax can be freely intermixed with the old `shape($foo, 'bar' => 1, $baz)`  The feature is gated behind the ShapeFieldPunning experimental flag. We're just desugaring it in the lowerer.

Also improve an error message where a field was missing it said the field was both missing and defined. Now it ways it's missing and required.
