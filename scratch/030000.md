Commit title: Remove dead option strict_value_equality
Commit body:
Summary:
Remove the `tco_strict_value_equality` option from GlobalOptions.
This option (defaulting to false) controlled emitting an error when "==" or
"!=" is used to compare values that are incompatible types. Since no code
sets this to true, the feature is dead and can be removed.

Removes the conditional check in typing_arithmetic.ml along with the
associated helper functions `strict_allowable_types`, `same_type`, and
`strict_equatable` which were only used by this check.
