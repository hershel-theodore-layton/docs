Commit title: Generate _clients_fwd.h for non-module-only services
Commit body:
Summary:
D80708823 introduced codegen for forward-declarations of services (`_clients_fwd.h`), but only for module-only (single file service) thrift targets. This completes the feature by enabling forward declaration headers for all service thrift targets, including those that explicitly list services in `thrift_srcs`.

This allows using lightweight `_clients_fwd.h` headers to forward-declare thrift clients in headers instead of pulling in heavy `_clients.h` includes, reducing header bloat.
