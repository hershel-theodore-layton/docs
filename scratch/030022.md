Commit title: Fix logic of firstNonInheritedConstraint
Commit body:
Summary: function foo<T as arraykey>() : T { ... } would result in a type intersection constraint with a single element which has the upperbound flag. If there is only one such constraint, it is currently handled by the is_simple branch. However, once return types are passed down from parent methods, the current logic will fail as the is_simple check will be false (> 1 type constraints) and there will be no constraint satisfying the condition !tc.upperbound() leading to the assertion. Fix this so we always return the first non inherited type constraint we find, irrespective of the upperbound flag.
