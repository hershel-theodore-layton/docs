Commit title: Use dumpRequest to get interaction info
Commit body:
Summary:
Add interaction (tile) snapshot information to thriftdbg dumpRequests output.
This allows debugging active interactions on server connections, showing interaction ID,
creation time, reference count, age in milliseconds, and wall-clock creation time in ISO format.

The `ageMs` field shows how long the interaction has been alive, and `creationTimeIso`
provides the wall-clock creation time for easy correlation with logs. Both are computed
at snapshot time with zero runtime overhead - making it easy to identify long-hanging
interactions during debugging.
