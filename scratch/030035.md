Commit title: Create API to reinstall folly fiber overflow signal handler
Commit body:
Summary:
# What
Create an API that makes it possible to reinstall the folly fiber signal handler

# Why
Because in IG Server we re-install signal handlers after we fork.
Since the fiber signal handler is currently behind a `once_flag`, the forked children thus lose the folly fiber detection.

By extending this API we make it possible for consumers to willingly reinstall the signal handler, and thus aid in detecting fiber overflows (would've helped in the investigation of S599862).
