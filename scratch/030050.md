Commit title: Add traverse methods to DynamicValue/DynamicRef/DynamicConstRef
Commit body:
Summary:
Add `traverse(const Path&)` methods to `DynamicValue`, `DynamicRef`, and
`DynamicConstRef` that take a Thrift path and return an optional reference
to the value at the end of the traversal.

`DynamicValue::traverse` forwards to the existing `DynamicRef`/`DynamicConstRef`
implementations via the implicit conversions that already exist.

The traverse methods handle all path component types:
- FieldAccess: Navigate struct/union fields
- ListElement: Access list elements by index
- MapValue: Access map values by key
- SetElement: Check set membership
- MapKey: Access map keys
- AnyType: Throws (not supported)

Return behavior:
- Returns nullopt for missing values (unset optional fields, out-of-bounds
  indices, missing map keys, inactive union fields)
- Throws InvalidPathAccessError for type mismatches or schema errors, including attempting to get a mutable reference to a map key / set element
- Throws std::runtime_error for AnyType traversal (not supported)
