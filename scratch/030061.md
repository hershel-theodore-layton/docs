Commit title: Add flag for extracting function attributes while collecting backtraces
Commit body:
Summary:
Adds a new flag, `DEBUG_BACKTRACE_INCLUDE_ATTRIBUTES` to cause `debug_backtrace` to include a `user_attributes` field in each backtrace frame (for non-builtin functions) containing the user specified (`<< ... >>`) attributes on the function for that frame.

Additionally:
- Created a cache for these arrays as most attributes are common across many functions
- Cleaned up special handling for `<<__Memoize(#...)>>` attributes so that we can now natively support enum class labels rather than materializing them while computing attributes for reflection
