Commit body:
Summary:
Adding HLC handling in the memcache command handler at two places -

 Update path
- Obtain ticket from the update request
- Allocate ticket to the CT item
- Store the item along with the ticket

 Read path
- Obtain ticket from the get request
- Check if the item is present in the cache. If present, obtain the ticket.
- Check if the ticket from the cache item is as fresh as the one in the request, if so return the item.
- If the ticket is stale, then return cache miss.

The implementation is guarded by a ucache option which is currently disabled by default.
