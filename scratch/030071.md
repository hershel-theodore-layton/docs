Summary:
Add streaming interceptor types to ServiceInterceptorBase:
- StreamDirection enum (ServerStream, ClientSink, BiDirectional)
- StreamEndReason enum (Complete, Error, Cancelled)
- StreamInfo struct for stream begin events
- StreamPayloadInfo struct for per-payload inspection
- StreamEndInfo struct for stream completion events

These types define the API surface for streaming payload inspection.
StreamPayloadInfo provides TypeErasedRef access to typed payloads
before serialization, matching the pattern used for request/response.
