Summary:
Add pure virtual methods for streaming interceptor hooks:
- internal_onStreamBegin: Initialize per-stream state
- internal_onStreamPayload: Inspect typed payloads before serialization
- internal_onStreamEnd: Cleanup when stream completes/errors/cancels

Also adds kMaxStreamStateSize constant for compile-time state size
validation.

These methods follow the existing pattern of internal_onRequest and
internal_onResponse, but operate at the stream payload level.
