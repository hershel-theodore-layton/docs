Commit body:
Summary:
Add StreamInterceptorContext to manage per-stream state for interceptors.

The context holds:
- Unique stream identifier (StreamId)
- Per-interceptor storage vectors for stream-level and request-level state
- Atomic sequence number for payload ordering
- Connection context with cancellation token for graceful handling

Provides invocation methods for interceptor lifecycle:
- invokeOnStreamBegin(): Called when stream is established
- invokeOnStreamPayload<T>(): Called per typed payload before serialization
- invokeOnStreamEnd(): Called when stream completes/errors/cancels (LIFO order)

Key design decisions:
- Storage is internal, accessed only through invocation methods
- Connection/request contexts are private, protecting against unsafe access
- Sequence number uses relaxed ordering (sufficient for per-stream counter)
- No default values for serviceName/methodName (always required)

Also provides generateStreamId() for thread-safe ID generation.
