Summary:
Add streaming interceptor integration to ServerGeneratorStreamBridge.

Changes to fromAsyncGeneratorImpl:
- Accept optional interceptorContext parameter
- Call context methods at appropriate lifecycle points:
  - invokeOnStreamBegin() after stream subscription
  - invokeOnStreamPayload<T>() BEFORE encoding each payload
  - invokeOnStreamEnd() at all termination points:
    - Client cancellation (CANCEL)
    - Generator exception (ERROR)
    - Normal completion (COMPLETE)

For WithHeader streams, payloads are only inspected for actual T values,
not header variants.

The interceptorContext parameter defaults to nullptr for backward
compatibility. Actual wiring will be done in the next diff.
