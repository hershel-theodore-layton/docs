Commit title: extend FCallArgs bytecode to include named arguments in hackc -> HHVM
Commit body:
Summary:
To support named arguments, FCallArgs is extended to take two static arrays,
a list of named argument names & a list of positions. These are referenced by id to allow sharing the vectors among common calls.

HackC can now emit and assemble named args. To avoid creating a separate section of bytecode, we re-use the typed value support (HackC does this elsewhere, and relies on convention to extract the right values out).

The HackC -> HHVM translator is extended to understand and pass named args.

To avoid bloating code/adatas, we introduce a special sigil, `$`, that indicates named arg names/positions. It's identified with `kInvalidId` as its id.
