# New Component: RocketRequestHandler

- Introduces a new class, `RocketRequestHandler`, designed to:
  - Own all setup results, including processor factory, metadata, configs, registry, event base, and related components.
  - Encapsulate all request processing logic, such as request factories and the `handleRequestCommon` method.
  - Provide a built-in sampling method, eliminating the need for an external `this` pointer.
  - Remain fully self-contained, with no dependencies on facade internals.
