Commit title: Enable RefactoredThriftRocketServerHandler via feature flag
Commit body:
Summary:
Integrate `RefactoredThriftRocketServerHandler` into the Rocket server routing infrastructure with a feature flag for controlled rollout. This completes the refactoring stack by making the new modular handler architecture available in production.

## Changes in this diff

### 1. Feature Flag for Controlled Rollout
Added `rocket_server_use_refactored_handler` THRIFT_FLAG (default: false):
- When false (default): Uses original ThriftRocketServerHandler
- When true: Uses new `RefactoredThriftRocketServerHandler` with modular architecture
- Flag is evaluated at connection creation time, so changes affect new connections immediately
- Existing connections continue using their original handler (no disruption)

### 2. Dynamic Handler Selection in RocketRoutingHandler
Modified RocketRoutingHandler::handleConnection to:
- Create `RefactoredThriftRocketServerHandler` when flag is enabled
