Summary:
Allow clients to specify a preferred zstd compression level via the Accept-Encoding header (e.g., "zstd-8"). When the level parameter is present and valid (-5-22), it overrides the default zstdCompressionLevel from FactoryOptions.

This enables clients to request specific compression levels based on their performance and bandwidth requirements.
