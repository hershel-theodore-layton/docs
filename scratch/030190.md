Commit title: Optimize cmpsd
Commit body:
Summary:
Leverage NEON `fcmeq` to optimize vasm `cmpsd`. `fcmeq` does not touch `NZCV` so there's no need to save and restore it like in the old code gen. Please see below for comparisons and cycle counts on Grace (neoverse v2).

```
cmpsd ComparisonPred::eq_ord, s0, s2

Old code:
  mrs x16, nzcv  # 1+ cy
  fcmp d20, d22  # 2 cy
  csetm x18, eq  # 1 cy
  fmov d25, x18  # 3 cy
  msr nzcv, x16  # 1+ cy

New code:
  fcmeq v25.2d, v20.2d, v22.2d # 2 cy
```

```
cmpsd ComparisonPred::ne_unord, s0, s2

Old code:
  mrs x16, nzcv  # 1+ cy
  fcmp d20, d22  # 2 cy
  csetm x18, ne  # 1 cy
  fmov d25, x18  # 3 cy
  msr nzcv, x16  # 1+ cy

New code:
  fcmeq v25.2d, v20.2d, v22.2d  # 2 cy
  not v25.2d, v25.2d            # 2 cy
```

Note: HHVM's disassembler can't disassemble these two NEON instructions, which will be dealt with in a separate diff.
