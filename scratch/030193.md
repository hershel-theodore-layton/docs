Commit title: Add StreamMetricEventHandler support for Rust Thrift Server
Commit body:
Summary:
Add support for streaming metrics (StreamMetricEventHandler) in Rust Thrift Server,
matching the functionality available in C++ Thrift servers.

Changes:
- Add set_stream_context_stack() method to ReplyState trait for passing ContextStack
  to C++ for streaming event handler callbacks
- Update Thrift code generator templates to call set_stream_context_stack() before
  sending streaming replies
- Pass ContextStack to ServerStreamFactory in ReplyState.cpp
- Add integration tests verifying that StreamMetricEventHandler is properly invoked

ContextStack lifetime for streaming RPCs:

  Generated Processor (Rust)       ReplyState (Rust)         ReplyState (C++)        ServerStreamFactory (C++)
          |                              |                         |                         |
    1. create ctx_stack                  |                         |                         |
          |                              |                         |                         |
    2. preRead / postRead                |                         |                         |
       (request deser)                   |                         |                         |
          |                              |                         |                         |
    3. call handler impl                 |                         |                         |
          |                              |                         |                         |
    4. preWrite / postWrite              |                         |                         |
       (response ser)                    |                         |                         |
          |                              |                         |                         |
    5. set_stream_context_stack -------> store in                  |                         |
       (transfer ownership)          stream_context_stack          |                         |
          |                              |                         |                         |
    6. send_stream_reply() -----------> extract -------> sendStreamReply(ctx) -----> setContextStack(ctx)
          |                              |                         |                    [owns ctx_stack]
          |                              |                         |                         |
          .                              .                         .                  7. onStreamSubscribe()
          .                              .                         .                         |
          .                              .                         .                  8. onStreamNext() x N
          .                              .                         .                         |
          .                              .                         .                  9. onStreamFinally()
          .                              .                         .                         |
                                                                                     10. ctx_stack destroyed

Steps 1-4 are unchanged (normal request lifecycle).
Steps 5-6 are the new bridging: the Rust-side ContextStack is transferred to C++.
Steps 7-10 happen inside the C++ streaming infrastructure, enabling
StreamMetricEventHandler callbacks (active_streams, chunk timing, etc.).

The tests verify that:
- active_streams counter correctly tracks 0→1→0 during streaming
- Dynamic timeseries counters are registered for per-method metrics
- Event handler callbacks (onStreamSubscribe, onStreamNext, onStreamFinally) are called
