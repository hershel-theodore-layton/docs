Summary:
In the context of CLI args-parsing, a facility to apply args-files to an args vector.

An arg beginning with `@` but not with `@@` is treated as a filename, relative to the current directory if relative, after the `@`. That arg is then replaced by parsing the file into a sequence of arguments, recursively.
