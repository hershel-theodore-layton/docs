Commit title: C++ support for @thrift.Deprecated fields
Commit body:
Summary:
The thrift.Deprecated annotation marks Thrift fields as deprecated, allowing code generators to emit language-specific deprecation warnings when accessing those fields.

C++ uses the [[deprecated("message")]] attribute on field accessor methods (_ref() and _ref()&). When a deprecated field is accessed, the compiler emits a deprecation warning with the specified message.
