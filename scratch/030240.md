Summary:
The thrift.Deprecated annotation marks Thrift fields as deprecated, allowing code generators to emit language-specific deprecation warnings when accessing those fields.

Rust uses the #[deprecated(note = "message")] attribute on struct fields. When a deprecated field is accessed, the compiler emits a deprecation warning with the specified message.
