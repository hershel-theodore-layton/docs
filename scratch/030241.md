Summary:
The thrift.Deprecated annotation marks Thrift fields as deprecated, allowing code generators to emit language-specific deprecation warnings when accessing those fields.

Go uses "// Deprecated:" doc comments on struct fields. When go vet or staticcheck analyzes code that accesses a deprecated field, it emits a deprecation warning with the specified message.
