Commit title: Make result copyable
Commit body:
Summary:
`result<T>` was move-only with an explicit `.copy()` method — partly because early measurements overestimated `exception_ptr` copy cost (actually ~7ns). Being move-only complicated generic programming and deviated from standard value-type expectations.

Make `result<T>` implicitly copyable (construction and assignment):

- `result<V>`: copyable iff `V` is.
- `result<const V&>` and `result<void>`: always copyable.
- `result<V&>`: copyable only from mutable `result<V&>&` — a copy from `const result<V&>&` would grant mutable access through a const barrier. Same deep-const pattern as `DefineMovableDeepConstLrefCopyable.h`.
- `result<V&&>`: move-only (unchanged).

Deprecate `.copy()` and migrate all call sites in `folly/result/`.

Will migrate `value_only_result` in a follow-up.
