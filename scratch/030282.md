Refactor `validateSecurityPolicy` in `SecureRocketClient` to use `apache::thrift::op::for_each_field_id` instead of manually enumerating each field of `SecurityPolicy`.

This change improves maintainability by automatically adapting to any future fields added to the `SecurityPolicy` struct, eliminating the need to update this code when the schema changes.

The `for_each_field_id` API is compile-time optimized and has zero runtime overhead compared to direct field access - the lambda is instantiated for each field at compile time, making it equivalent to writing out each field access manually.
