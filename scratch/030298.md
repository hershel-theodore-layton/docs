Summary: `get_first_namespace_offset()` and `remove_namespace()` use raw `std::string::find()` to locate `namespace <lang>` in file content. This matches namespace text inside comments (e.g., `// namespace py3 test.bar`), producing wrong offsets. Add `find_not_in_comment()` helper that wraps `std::string::find()` and skips matches inside line comments (`//`, `#`) and block comments (`/* ... */`).
