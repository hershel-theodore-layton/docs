Summary:
Add ClientStreamInterceptorContext to manage interceptor state during stream
consumption. This class:
- Takes ownership of interceptors and request storages from ContextStack
  (which is destroyed after initial request/response, before stream consumption)
- Provides factory function to extract context from ContextStack
- Invokes stream lifecycle hooks (onStreamBegin, onStreamPayload, onStreamEnd)
- Passes RequestState to all stream callbacks for request correlation

Also adds extractClientInterceptorRequestStorages() to ContextStack to move
request storages into the stream context.
