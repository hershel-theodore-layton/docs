Commit title: Replace `relate` with `is_subset` in ApproxSet API
Commit body:
Summary:
The `relate` function in the `ApproxSet.S` module type computed a full `SetRelation.t` (subset, superset, disjoint) between two sets. No external consumer calls `relate` — all external code uses `are_disjoint` or `disjoint` (with witness). Computing the full three-way relation is also inefficient when only one bit is needed, since implementations (especially BddSet) support early termination via `~is_sat`.

This diff removes `val relate` from the public `S` module type and adds `val is_subset` instead. The `relate`/`check_relation` functions remain as internal implementation details. The BddSet `is_subset` implementation benefits from early termination: if any intermediate node pair breaks the subset relationship, `check_relation` raises `RelationUnsat` immediately rather than traversing the full BDD.

The `is_subset` signature is also threaded through to the typing layer's `SET` module type.
