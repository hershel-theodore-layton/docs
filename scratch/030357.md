Commit title: Consolidate rust_name/package via t_type Whisker prototype
Commit body:
Summary:
Remove duplicate rust_name and package properties from struct, enum, and
typedef mstch classes. Since t_struct, t_enum, and t_typedef all extend
t_type in the AST hierarchy, they inherit properties from the Whisker
t_type prototype.

Removed properties:
- struct:rust_name, struct:package (from rust_mstch_struct)
- enum:rust_name, enum:package (from rust_mstch_enum)
- typedef:rust_name (from rust_mstch_typedef)

All these properties used the same underlying implementation:
type_rust_name() and get_types_import_name(). The Whisker t_type
prototype now provides these for all derived types.
