Commit title: Consolidate serde? property via t_type Whisker prototype
Commit body:
Summary:
Add serde? property to the t_type Whisker prototype and remove the
duplicate definitions from struct, enum, and typedef mstch classes.

Since t_struct, t_enum, and t_typedef all extend t_type, they inherit
the serde? property from the t_type prototype. All three implementations
used the same underlying function: rust_serde_enabled(options_, *thing).

Removed mstch properties:
- struct:serde? (from rust_mstch_struct)
- enum:serde? (from rust_mstch_enum)
- typedef:serde? (from rust_mstch_typedef)

Note: program:serde? is kept as-is since it's different - it just checks
the global options_.serde flag rather than per-type annotations.
