Commit title: Convert struct/enum type context-switching to Whisker true_type
Commit body:
Summary:
Migrate template patterns that use mstch context-switching like
`{{#type:structured}}{{struct:package}}{{/type:structured}}` to use
Whisker's `true_type` property with dot notation like
`{{type:true_type.package}}`.

This approach follows the pattern from D83177025 (Python generator)
where instead of adding separate context-switching properties for
each type, we use the existing `true_type` property which returns
the resolved type with all its properties accessible via dot notation.

Changes:
- Add `has_adapter?` property to t_structured Whisker prototype
- Update rawtype.mustache to use `type:true_type.package` and
  `type:true_type.rust_name` instead of context-switching
- Update annfieldtype.mustache with the same pattern
- Change `{{#else if type:enum}}` to `{{#else if type:enum?}}` (boolean check)
