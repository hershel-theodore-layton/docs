Commit title: Fix Cpp2ConnContext TOCTOU race in stream interceptors
Commit body:
Summary:
Stream interceptor callbacks (onStreamBegin/Payload/End) run on the CPU pool
thread while Cpp2ConnContext is destroyed on the IO thread. The cancellation
token check in getConnectionContext() was a TOCTOU race: the connection could
be destroyed between the check and the pointer dereference, causing a
use-after-free detected by TSAN (D90922914 broke delos contbuild).

Fix by removing ConnectionInfo/ConnectionState from stream interceptor
callbacks entirely. Streams already own their request storage locally via
moveRequestStorage(). Interceptors that need connection-level state should
capture it in RequestState during onRequest, which runs while the connection
is guaranteed alive.
