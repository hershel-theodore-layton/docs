Commit title: Add SimpleJSON protocol support to dynamic value serialization
Commit body:
Summary:
Dynamic value serialization previously only worked with protocols like
Compact and Binary that encode container sizes and type information.
This change adds support for SimpleJSON, which omits container sizes
and uses field names instead of field IDs.

Key changes:
- Handle protocols that omit container sizes using kOmitsContainerSizes()
  and peek methods (peekList, peekSet, peekMap) for iterating containers
- Skip type mismatch checks when TType is T_VOID (indicates protocol
  doesn't encode type information)
- Use field names for lookup in name-based protocols via kUsesFieldNames()
- Add SimpleJSON support to Any::load() and Any::store()
- Add round-trip tests for SimpleJSON with containers and structs
