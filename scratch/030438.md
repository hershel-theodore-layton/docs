Commit title: Fix exception safety in List deserialization
Commit body:
Summary:
Wrap the raw ConcreteList pointer in RAII (detail::IList::Ptr) immediately
after allocation to prevent memory leaks if an exception is thrown during
deserialization.

Previously, the pointer was only wrapped when constructing the return value,
meaning any exception thrown during element deserialization would leak the
allocated ConcreteList.
