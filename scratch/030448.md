Commit title: Fix NoHandleSurpriseScope using sizeof in bytes instead of bits
Commit body:
Summary:
The NoHandleSurpriseScope debug implementation was completely broken because
it used sizeof(SurpriseFlag) (8 bytes) instead of sizeof(SurpriseFlag) * CHAR_BIT
(64 bits) for both the depth tracking array size and loop bound.

Since all SurpriseFlag values occupy bit positions 48-63, but the code only
iterated bits 0-7, the depth counters were never incremented and AssertNone()
could never fire. This rendered the entire debug-mode surprise flag checking
mechanism inert.

Fixed by introducing kSurpriseFlagBits = sizeof(SurpriseFlag) * CHAR_BIT and
using it for both the array size and loop bound, so all 64 bit positions are
properly tracked.
