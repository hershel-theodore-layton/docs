Commit title: Add handle(CancelFrame) and handleConnectionClose() to RocketStreamClientCallback
Commit body:
Summary:
Replace `onStreamCancel()` and `earlyCancelled()` with `handle(CancelFrame)` on RocketStreamClientCallback. The new method checks `serverCallbackReady()` internally: if not ready, it sets the cancelled flag (early cancel path); if ready, it cancels the server callback with context stack tracking and calls `freeStream()`. This unifies two separate cancel paths into one method and moves the `serverCallbackReady()` check from `RocketServerConnection::handleStreamFrame` into `RocketStreamClientCallback` where it belongs.

Also adds `handleConnectionClose()` for server-initiated cancellation during connection teardown (called from `closeIfNeeded()` in both connection classes). This is distinct from `handle(CancelFrame)` because it does not call `freeStream()` — the connection already erases the stream from the map before invoking the callback. It checks `serverCallbackReady()` internally, unifying the behavior between `RocketServerConnection` (which checked) and `RefactoredRocketServerConnection` (which did not).
