Commit body:
Summary:
Move EXT frame handling from `RocketServerConnection::handleStreamFrame` into `RocketStreamClientCallback::handle(ExtFrame)`. The method checks `hasIgnore()` — if set, silently ignores the frame; if not, calls `connection_.close()` with an `ErrorCode::INVALID` error. This continues the consistent naming refactor where frame handling logic lives in the callback rather than the connection.

Also updates `ExistingStreamFrameHandler::handleExtFrame` to dispatch to the stream callback via variant_match (replacing the previous `XLOG(FATAL)` stub), and passes the iterator so it can look up the correct callback.
