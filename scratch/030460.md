Summary:
PSP negotiation is by default disabled. After this diff, it can be enabled
on the server side by specifying a PSPUpgradePolicy on the thrift server or
through the thrift flag.

Currently only two policies are exposed:

- "disabled" (default) - PSP will never be negotiated.
- "always" - The server always indicates support for all known PSP negotiation protocols (currently only thriftv0)

Future diffs will introduce a policy (e.g. "autodetect") which will consider the route taken to the peer.
