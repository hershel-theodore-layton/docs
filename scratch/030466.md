Commit title: Introduce .hhvmconfig.hdf support for experimental feature flags
Commit body:
Summary:
Add a `Hack.Lang.ExperimentalFeatures` map config to HHVM that defines the release status of experimental features when `Hack.Lang.UseLegacyExperimentalFeatureConfig` is false.

Also introduce `Hack.Lang.ConsiderUnspecifiedExperimentalFeaturesReleased` which will mark any feature not in the map as released rather than unstable.

Remove the restrictiveness validation from both Rust and OCaml that previously prevented config values from being less restrictive than the hardcoded defaults.
