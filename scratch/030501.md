Commit title: Fix thread-safety-analysis errors in AtFork.cpp
Commit body:
Summary:
LLVM 21's std::mutex has clang thread-safety annotations, which causes -Wthread-safety-analysis to fire on AtFork's intentional cross-function lock hand-off pattern: prepare() acquires the mutex and returns with it held, then parent()/child() release it after fork. The analyzer cannot track this pattern across function boundaries.

Add __attribute__((no_thread_safety_analysis)) to the three functions involved in the hand-off.
