Commit title: Add custom header support to H3DatagramClient
Commit body:
Summary: The H3DatagramClient sample binary hardcodes its HTTP request with no way to pass custom headers. This is needed for use with Meta's forward proxy, which requires X-FB-Proxy, X-FB-ProxyScheme, and X-FB-ProxyType headers. This change adds a --headers gflag that accepts comma-separated Name=Value pairs, reusing the existing CurlClient::parseHeaders() utility already used by the curl and hq samples.
