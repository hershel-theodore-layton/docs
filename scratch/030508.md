Commit title: Fix unused parameter warning in pthread_setschedparam on Windows
Commit body:
Summary:
Fix Windows clang release build failure caused by `-Werror,-Wunused-parameter` in `folly/portability/PThread.cpp`.

The `pthread_setschedparam` function has an unused `policy` parameter because Windows thread scheduling uses `SetThreadPriority` which doesn't require a scheduling policy. The parameter is kept in the signature for POSIX API compatibility.

Changed line 213 from:
```cpp
pthread_t thread, int policy, const sched_param* param) {
```
to:
```cpp
pthread_t thread, int /* policy */, const sched_param* param) {
```

This follows the established pattern in folly's portability layer (e.g., `SysMman.cpp`, `SysResource.cpp`, `SysStat.cpp`) for handling unused parameters in platform-specific implementations.
