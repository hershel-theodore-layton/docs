Summary:
Fix `-Wconditional-uninitialized` error: `cqe` may be uninitialized when checked at line 1512. This happens when `doPeek()` takes the `usingDeferTaskrun_` path, which calls `io_uring_get_events()` without writing to `cqe`. If that returns `-ETIME`, the subsequent `if (cqe == nullptr)` reads uninitialized memory.

Found while building `buck build fbcode//hccl/mode/owl-opt --config fbcode.caffe2_gpu_type=mtia fbcode//mtia/conda:wheel_env`.
