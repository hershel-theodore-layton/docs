Commit title: Support for optional named parameters in the interpreter
Commit body:
Summary:
Adding support for optionals in named parameters.

- Updated `calleeNamedArgChecks` to allow not passing in arguments for parameters that have optionals. It iterates through the given named arguments, and checks that 1) that there's a matching param and 2) the number of required named params match the required arguments. Otherwise, throws exceptions.
- In the same function, we fill the stack with default named param values if they were not passed in. It doesn't touch positional default parameters because that's handled later on in `initFuncInputs`
