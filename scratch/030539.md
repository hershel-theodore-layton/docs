Commit title: Do not initialize class in ReflectionClass::hasProperty/getProperties
Commit body:
Summary:
`ReflectionClass::getClassPropertyInfo` was returning a bunch of info about the properties, but all of its users were just checking the names--`hasProperty` only checks if a name exists and `getProperties` just uses the name to construct a `ReflectionProperty`. So we can skip initializing the class and just return the names.

This diff replaces `ReflectionClass::getClassPropertyInfo` with `ReflectionClass::getNonDynamicPropNames` which just returns the names of the properties.

The benefit of this is that if there is an issue with initialization--which can be the case for traits--we avoid those issues for these Reflection queries.
