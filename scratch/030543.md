Summary:
When storing a `KindOfClass` in APC, on sandboxes we make an entity called `APCNamedClass` that loads upon fetching. Get rid of this and just store a `KindOfLazyClass`, matching what we'd do if the `Foo::class` was lazy.

NOTE: This changes behavior -- now, deleting the class will give back a dead lazy class instead of a null upon fetch. If this is a rollout concern I can add a runtime option.
