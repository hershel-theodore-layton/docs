Summary: Add an automated test for folly's exception_tracer that validates stack trace output for uncaught exceptions. This follows the pattern from `folly/logging/test/fatal_test.py`: a `python_unittest` runs a companion cpp_binary that throws an uncaught int exception, then asserts the process dies with SIGABRT and the exception tracer output contains the expected exception type and stack frames (foo(), main). The C++ binary uses `__attribute__((noinline))` to ensure `foo()` remains visible in the stack trace under optimized builds.
