Commit title: Mustache-to-Whisker migration: derive strings, each loops
Commit body:
Summary:
Convert string-as-section patterns and simple string array loops to Whisker syntax.

String sections converted to string emptiness checks:
- enum:derive: {{#enum:derive}}, {{.}}{{/enum:derive}} → {{#if (not (string.empty? enum:derive))}}, {{enum:derive}}{{/if}}
- struct:derive: same pattern

String array loops converted to {{#each}}:
- program:consts_for_test in adapter/const_test.mustache → {{#each program:consts_for_test as |name|}}
- function:returns_by_name in errors.mustache (3 occurrences) and service.mustache (1 occurrence) → {{#each function:returns_by_name as |field|}}

Both consts_for_test and returns_by_name are already Whisker prototype properties returning whisker::array of strings, making them safe to convert to {{#each}}.

The `compute_derive_string()` function is moved out of the prototype definition for enums and structs to deduplicate the code. It isn't added to the t_named prototype because it isn't applicable to all the t_named objects.
