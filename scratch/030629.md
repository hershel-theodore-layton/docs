Commit title: Add per-priority per-bucket queue size limits
Commit body:
Summary:
Previously, RoundRobinRequestPile only supported a single global `numMaxRequests` that applied uniformly to all priorities. This means P0 (highest) and P4 (lowest) had identical queue capacity per bucket.

This diff adds `numMaxRequestsPerPriority` to `RoundRobinRequestPile::Options`, allowing different per-bucket queue depth limits for each priority level. When set, it overrides the global `numMaxRequests` for each priority individually. A value of 0 means no limit for that priority.

Usage:
```
RoundRobinRequestPile::Options opts;
opts.setNumPriorities(5);
opts.setNumMaxRequestsPerPriority({0, 0, 1000, 500, 100});
// P0-P1: unlimited, P2: 1000/bucket, P3: 500/bucket, P4: 100/bucket
```

`addInternalPriorities` correctly doubles the per-priority limits vector alongside the priorities for services using Thrift interactions.
