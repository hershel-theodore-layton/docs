Summary:
__RequirePackage was not properly being applied to lambdas in cases where the reasoning to allow the application of the annotation is sound.

These cases are:
- Lambda called by stdlib function (Vec\map for example)
- Lambda called by another function which requires the same package (this handles the recursive case as well since all callers have to require the same package)
