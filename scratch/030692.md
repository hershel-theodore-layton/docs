Commit title: Migrate program:adapters and program:adapted_structs to Whisker
Commit body:
Summary:
Migrate `program:adapters` and `program:adapted_structs` from `rust_mstch_program` mstch properties to Whisker prototypes.

The `adapters` property uses `resolve_derived_t_type` for polymorphic type resolution (handling both `t_structured` and `t_typedef`). The `adapted_structs` property uses `to_array` with the `t_structured` prototype.

To make `type:adapter_name` work correctly when accessed on struct/typedef types via the `type:` prefix (which always resolves through the `t_type` prototype rather than more-derived prototypes), the `t_type::adapter_name` property was updated to look up the structured adapter annotation and dispatch correctly: typedefs pass the underlying type, structs use `ignore_transitive=true`.

The template `lib/mod.adapters.mustache` is simplified from a multi-line context-switching block to a single line: `pub type {{type:rust_name}} = {{type:adapter_name}};`.
