Commit title: Fall back to uncaught trace stack for libc++ compatibility
Commit body:
Summary:
When using libc++abi, `__cxa_begin_catch` is called internally from within `__cxa_throw` (in the same DSO). This intra-DSO call is not intercepted by symbol interposition, so our `__cxa_begin_catch` hook never fires and the caught exception trace stack remains empty — even though the throw-time trace was captured on the uncaught trace stack.

Add a fallback in `getCurrentExceptions()`: when the caught trace stack is empty but there are caught exceptions, check the uncaught trace stack and use it if available. This restores stack trace availability for
exception tracers under libc++.
