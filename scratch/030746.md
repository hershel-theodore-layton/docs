Commit title: Add `FOLLY_NOINLINE` to `getAsyncStackTraceSafe`
Commit body:
Summary:
`getAsyncStackTraceSafe` uses `FOLLY_ASYNC_STACK_RETURN_ADDRESS()` and
`FOLLY_ASYNC_STACK_FRAME_POINTER()`, which expand to
`__builtin_return_address(0)` and `__builtin_frame_address(0)`. These
builtins return the return address and frame pointer of the *current*
function's frame, so the function must not be inlined — otherwise the
builtins would refer to the caller's frame instead, producing incorrect
async stack traces.

Add `FOLLY_NOINLINE` to both the declaration and definition to match the
requirement documented in `folly/tracing/AsyncStack.h`.
