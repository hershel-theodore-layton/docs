Summary:
Introduce the `t_namespace` AST node class (extending `t_node`) to wrap namespace values with source location information. Change `t_program`'s internal storage from `map<string, string>` to `map<string, t_namespace*, less<>>` and mechanically update all consumers to access the namespace string via `->ns()`. The `set_namespace` method accepts an optional `source_range` parameter (default `{}`), so no existing callers need to change.

This is a NFC (no functional change) refactor that prepares for tracking source ranges of namespace directives.
