Summary:
Show intermediate results while we wait:
 - Print a "final-like" table, but with `[unstable]` / `[imprecise]` annotations on rows that aren't done yet.
 - Tighter CI / instability output than before.

The new table is very useful when you want a quick check -- can Ctrl-C without waiting for convergence. For this reason, I made it print every 5 seconds of benchmark runtime (which ends up being 6ish by the wall clock). Can tweak or parameterize this later if needed.

The new output can be suppressed via `-bm_quiet`.

This will show up for long-running benchmarks (e.g. many benchmarks in one file), or when the system is noisy.
