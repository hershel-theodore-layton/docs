    elemConsumerFunc := func(ctx context.Context, seq iter.Seq2[[]byte /* chunk */, error /* sink err */]) (int32 /* final response - checksum */, error) {
        checkSum := int32(0)
        for chunk, err := range seq {
            if err != nil {
                // Client side error - clean up and return
                CancelUpload(uploadID)
                return 0, err
            }
            UploadChunk(ctx, uploadID, chunk)
            checkSum = ComputeChecksum(checkSum, chunk)
        }
        return checkSum, nil
    }
    return uploadID, elemConsumerFunc, nil
}

* Sink is done by a user-defined `func` object.
    * The function will be invoked by Thrift library logic outside of codegen (to be implemented downstream).
    * `Context` object *should* be used for detecting stream interruption (e.g. client disconnected) and gracefully cleaning-up/terminating the stream.
    * Elem `chan` should be used to "sink" (consume) elements.
    * Error `chan` should be used to detect if a client experienced a "sink error" and stopped the sink. Graceful clean-up/termination can be done based on the error.
    * Upon successful sink completion, the function should cleanup resources and return a final response to the client.
    * Users *should* follow recommended practices above to avoid Go-routine or other resource leaks.
