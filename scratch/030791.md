Commit title: Remove package_allow_function_pointers_violations flag (always false)
Commit body:
Summary:
This diff removes the `package_allow_function_pointers_violations` configuration flag from the Hack typechecker. The flag was used to bypass package boundary violation errors on function pointers during the V1 intern-prod separation rollout, but is now always set to `false` in production.

Since the flag is always false, the conditional checks that used it have been simplified:
- In `typing.ml`, function pointer access now always checks package boundaries (returns `Yes "function"` or `Yes "class"` instead of conditionally returning `No`)
