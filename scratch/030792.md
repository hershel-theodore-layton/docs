Commit body:
Summary:
This diff removes the `package_allow_reified_generics_violations` configuration flag from the Hack typechecker. The flag was used to bypass package boundary violation errors on reified generics during the V1 intern-prod separation rollout, but is now always set to `false` in production.

Since the flag is always false, the conditional checks that used it have been simplified:
- In `typing_phase.ml` and `typing_type_integrity.ml`, reified generics now always check package boundaries (the condition simplifies from `in_reified && not (Env.package_allow_reified_generics_violations env)` to just `in_reified`)
