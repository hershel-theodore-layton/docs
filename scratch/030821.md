Commit title: Fix xplat loadshedding test build failures
Commit body:
Summary:
The loadshedding tests in xplat/thrift/test/loadshedding were failing to build due to several configuration issues when the code was moved from fbcode to xplat:

1. The fb303 dependency was using a relative path `//common/fb303/if:fb303` which resolved to xplat instead of fbcode where the library actually lives. Fixed by using the explicit `fbcode//` prefix.

2. The thrift_cxx_library targets were missing `header_namespace` which is required for the include paths like `<thrift/test/loadshedding/client/Client.h>` to work correctly in xplat.

3. The Client.cpp file was using gflags macros (DEFINE_uint32, DEFINE_bool) without the necessary include or BUCK dependency.
