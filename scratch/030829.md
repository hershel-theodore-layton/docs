Summary:
Add `folly::IOBufFactory` that is a simple `folly::Function` that returns a `unique_ptr<folly::IOBuf>`.

Then, add a helper `makeIOBufArenaFactory` that returns a `folly::IOBufFactory` using the provided templated allocator matching the `ArenaAllocator` concept. The two allocators in mind are `IoUringArena` and `JemallocHugePageAllocator`.

The intent is for this to be used in `IOBufQueue` and various places in Thrift to handle allocations instead of `IOBuf::create`.
