Commit title: IOBufQueue: use IOBufFactory for allocations if set
Commit body:
Summary:
Add an `folly::IOBufFactory` ptr to `folly::IOBufQueue`. This factory will be used if set to create IOBufs in the queue, as opposed to `IOBuf::create`.

`folly::IOBufQueue` is exactly 64 bytes in size, which is being preserved. This is done by packing `bool cacheChainLength` at the beginning of the class (resulting in 7 bytes of padding) with `bool WritableRangeCacheData::attached` at the very end of the class (which also has 7 bytes of padding). This frees up the 8 bytes at the beginning to use for `folly::IOBufFactory*`.

The packing is done using a new struct `LocalCacheData` that inherit from `WritableRangeCacheData`. This is to allow existing users of `WritableRangeCacheData` to not be affected.
