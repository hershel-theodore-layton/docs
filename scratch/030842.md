# Context

The hackrs `ty` crate contains Rust representations of both decl-phase and locl-phase types, mirroring the OCaml GADT `'phase ty_`. These were built as part of a "types in compilation" project that ported type checking logic to Rust. That project is no longer active, but its artifacts remain: a full `ty::local` module with locl type definitions, a `ty::local_error` module, and a `ty::prop` module for subtyping propositions.

Since Rust only needs decl types (for shallow decl computation, folded decl computation, etc.), this dead code creates unnecessary coupling — any change to locl type representation in OCaml risks requiring corresponding Rust updates.

# Solution

Delete the entire local type layer from hackrs:
- `ty::local` (local types, tyvars, kinds, variance, class elements)
- `ty::local_error` (typing error codes, primary errors, reason callbacks)
- `ty::prop` (subtyping propositions and constraints)

Clean up all references in the remaining code: remove `local_ty_conser()` and `prop_conser()` from the `Reason` trait and both impls (`BReason`, `NReason`), remove `visit_local_ty` from the `Visitor` trait, and drop the now-unused `im` and `naming_special_names_rust` dependencies from the BUCK file.

No downstream crate imports any of these modules, so this is a pure deletion with zero external impact.
