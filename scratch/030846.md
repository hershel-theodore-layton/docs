Commit title: Optimize struct padding to reduce memory waste
Commit body:
Summary:
Reorder fields in several folly structs from largest alignment to smallest
to minimize compiler-inserted padding bytes. This reduces per-allocation
memory overhead for frequently-instantiated structs.

Structs optimized:
- AtomicHashMap::SimpleRetT: reorder j/i/success (24 -> 16 bytes, 33% reduction)

No aggregate initialization is used for any of these structs, so field
reordering is safe. Constructor member-initializer lists updated to match
new declaration order.
