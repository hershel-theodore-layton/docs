Summary:
Replace `type:cppNamespaces` property with `program` navigation to py3 generator program `cppNamespaces` property.

Replacement is `enum:program.cppNamespaces` and `struct:program.cppNamespaces` because the original implementation uses `cpp2::get_gen_namespace_components(*get_type_program())` where `get_type_program()` returns the *resolved* type program.

`type:enum` and `type:structured` are basically a "resolve typedefs and try cast" operation (returning null if the cast is invalid). Therefore we can use `enum:program` and `struct:program` equivalently to `type:true_type.program` in these cases.
