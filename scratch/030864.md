Commit title: Transparent CONNECT-UDP forwarding via upstream H3 proxy
Commit body:
Summary:
When a client sends a MASQUE CONNECT-UDP request with
X-FB-ProxyType=CONNECT-UDP and an upstream proxy defined via X-FB-Proxy,
fwdproxy transparently forwards the H3 transaction upstream — mirroring how
X-FB-ProxyType=CONNECT already works for HTTP CONNECT tunnels.

The implementation creates a QuicClientTransport + HQUpstreamSession to the
upstream proxy, waits for the QUIC handshake to complete via
HQSession::ConnectCallback, then uses ProxyConnectUDPRequestHelper to bridge
datagrams bidirectionally between the downstream and upstream
HTTPTransactions. Without an upstream proxy, the existing raw UDP path
(ProxyConnectUDPHelper) is used unchanged.

Key changes:

**HTTPForwardProxyHandler:**
- createH3UpstreamConnection(): creates QUIC transport + HQ session with
  proper mTLS using CertPathPicker (same pattern as
  ForwardProxyUpstreamTransportProvider::loadClientCert) and
  DefaultCertificateVerifier with THRIFT_TLS_CL_CA_PATH / kDefaultCaPath
- Implements HQSession::ConnectCallback (onReplaySafe/connectError) to defer
  upstream transaction creation until the QUIC handshake completes
- Strips X-FB-Proxy and X-FB-ProxyType before forwarding to prevent infinite
  chaining loops
- setIfTransactionNeeded() keeps makeTransaction_=true for CONNECT-UDP +
  upstream proxy; establishConnection() routes to createH3UpstreamConnection()

**ProxyConnectUDPRequestHelper (new, from D93793075):**
- Datagram-aware bridge between downstream/upstream HTTPTransactions, with
  inner ClientHandler and ServerHandler classes

**HTTPDownstreamHandle (from D93793075):**
- New proxyConnectUDPRequest()/finishProxyConnectUDPRequest() methods

**MasqueClient:**
- Added --extra_headers gflag (comma-separated key:value) for injecting
  proxy-control headers in tests

**E2E prospect test (new):**
- quic/connect_udp_chain.py: starts two fwdproxy instances (A downstream,
  B upstream), runs masque_client through A with chaining headers pointing
  at B, verifies full two-hop CONNECT-UDP round-trip with UDP echo payload
  verification
