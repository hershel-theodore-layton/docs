Commit title: Remove package config flags that are now constant
Commit body:
Summary:
Remove three package-related config flags from the Hack typechecker that have settled to their final values and no longer need to be configurable:

- `check_packages` (always `true`): Package boundary checking is now unconditionally enabled. All `if check_packages` guards in typing code are removed, making package enforcement always active.

- `package_config_disable_transitivity_check` (always `false`): Transitivity checks for package/deployment inclusion now always run. The `disable_transitivity_check` parameter is removed from the package config parsing pipeline (`config.rs`, `package_info.rs`, `package_config.ml`, FFI layer).

- `allow_require_package_on_interface_methods` (always `true`): `__RequirePackage` is now unconditionally allowed on interface methods. The `check_no_require_package_on_interface_methods` check in `attribute_nast_checks.ml` (which was always a no-op) is removed.

The `disable_package_checks` test directory and its BUCK target are removed since they tested the `check_packages=false` behavior which no longer exists.
