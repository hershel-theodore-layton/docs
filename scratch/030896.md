Summary:
Adopt the optimized Arm64-specific ZEND_SIGNED_MULTIPLY_LONG from https://github.com/php/php-src/blob/master/Zend/zend_multiply.h

Please see https://godbolt.org/z/4re79es4o for code gen differences. Compared to the old C path, which always converts integers to double, the new Arm64 inline assemblies leverages Arm64's `smulh` instruction to calculate the upper portion and a `sub` instruction to check overflows. Only when overflow happens will it fall back to calculating double product.

Note: this issue was found by running ASan hhvm against `hphp/test/slow/async/reschedule.php`. ASan was complaining about a potential integer overflow in ZEND_SIGNED_MULTIPLY_LONG when multiplying two long integers. There should be no security concern because the overflow case is properly handled, but to calm ASan and improve performance, this diff is good to have.
