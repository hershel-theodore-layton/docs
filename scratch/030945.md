Commit title: Check proc_open caller against approved list when AllowUngatedExec is false
Commit body:
Summary:
When Cfg::Eval::AllowUngatedExec is false, proc_open uses fromCaller() to walk
the call stack and identify the calling Hack function. The caller's
ClassName::FunctionName (for methods) or FunctionName (for free functions) is
checked against the Eval.ProcOpenGatedApprovedCallers configuration allowlist.
If the caller is not in the allowlist, a RuntimeException is thrown.

The other exec functions (shell_exec, exec, passthru, system) unconditionally
reject when AllowUngatedExec is false — no approved callers bypass is available
for them.
