Commit title: Add copyCompressedList utility for EliasFano compressed lists
Commit body:
Summary:
Add a `copyCompressedList` template function that creates an independent deep copy of a `MutableCompressedList`. The copy allocates its own buffer (with the required trailing bytes for safe reads) and rebases all internal pointers to the new allocation.

This is useful when the caller needs an owned copy of an encoded list whose lifetime is independent of the original.
