Commit title: Always capture stack trace in epitaph; gate only the symbolizer
Commit body:
Summary:
D94829768 gated both stack **capture** and **symbolization** behind `FOLLY_EPITAPH_USE_SYMBOLIZER`, so Android got zero frames.  The `stack_trace` dep is lightweight (no libunwind/libdwarf on Android; `getStackTrace` returns -1 there), so it is safe to link unconditionally.

Now, we always call `getStackTrace` -- this simplifies the gating in the header.

When frames are available but the symbolizer is not, `epitaph.cpp` will print hex addresses via the existing fallback in `format_epitaph_stack`. Added a test for that.
