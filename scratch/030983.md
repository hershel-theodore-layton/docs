Commit title: Cpp2Worker: fix plaintext AsyncIoUringSockets not using zero copy tx if enabled
Commit body:
Summary:
For accepted plaintext connections, an `AsyncSocket` is created first by the acceptor, then it is used to create an `AsyncIoUringSocket` in `Cpp2Worker::onNewConnectionThatMayThrow`.

If zero copy tx is enabled, then the `AsyncSocket` is configured with the enable func. However, this enable func is NOT taken by `AsyncIoUringSocket` in its ctor. The result is that zero copy tx isn't used even if the server enabled it.

Fix the issue by setting setZeroCopyEnableFunc in the `AsyncIoUringSocket` again.
