Commit title: F14 HashMapsBench Deterministic RNG
Commit body:
Summary: `folly::Random::create()` reads from `/dev/urandom` which makes it difficult to reproduce or measure small changes in F14 performance. I replace it here with a static seeded RNG which will give us the same inputs across different runs of the benchmark. Since the RNG is shared across benchmark functions, it's still dependent on the order of benchmarks called, so a run is only apples-to-apples when compared against another run with the same regex filter and iteration constraints.
