Commit body:
Summary:
Migrate `(priority = '...')` unstructured annotations on service definitions to `thrift.DeprecatedUnvalidatedAnnotations{items = {"priority": "..."}}` structured annotations across 10 thrift files.
There is a structured annotation equivalent for priority on a method, but not on a whole service. This is because the concept is no longer meaningful at the service level. Nonetheless, these files do have the annotation consumed by py-deprecated and there are tests that break if we remove it. For now the annotations are retained, and post py-deprecated migration they can be removed.
