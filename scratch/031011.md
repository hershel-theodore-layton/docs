Summary:
When a function parameter needing thrift.AllowUnsafeNonSealedKeyType
shared a line with the function signature, the annotation was incorrectly
placed before the entire function line. Add annotate_function_param() that
detects this case and breaks the line after the preceding ( or , separator,
placing the annotation on its own indented line before the parameter.
