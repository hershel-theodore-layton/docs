Add `HOLD_OPEN` SinkLimitAction to `BiDiFiniteClient` test utility and a new

`gen.next()` with no sink data arriving.

1. Client sends 0 sink chunks with HOLD_OPEN (sink stays open)
2. Server transform yields one item, then blocks on gen.next()
3. Client receives the item and cancels the stream
