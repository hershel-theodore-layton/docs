Commit title: Validate enum values fit @cpp.EnumType range
Commit body:
Summary:
Extend validate_cpp_enum_type() to check that all enum values fit within the
range of the declared underlying type (I8, U8, I16, U16, U32). Previously only
validated that the type field was specified. A U8 enum with value 300 would
pass the thrift compiler silently — now it errors.

This catches mismatches at thrift compile time instead of relying on the C++
compiler, which may silently truncate depending on flags.

Key design decisions:
- Uses a local enum_underlying_type enum class (mirroring the pattern in
  t_mstch_cpp2_generator.cc) to avoid magic numbers in the switch statement.
- U32 upper bound is capped at INT32_MAX since enum values in the AST are
  int32_t; values above that cannot be represented and will be caught by the
  C++ compiler.
- Collects all out-of-range values and reports a single consolidated error per
  enum (rather than one error per value), listing all offending values.
- Includes an actionable recommendation: suggests the smallest
  EnumUnderlyingType that can accommodate all values, or suggests removing
  cpp.EnumType to use the default int32_t.
- Unknown type values emit a warning for forward-compatibility.
