Commit title: Add Xenon gCPU % to SSA Inspector
Commit body:
Summary:
Add exclusive (leaf) CPU % from the xenon Scuba dataset to the `top` and
`inspect` commands, so users can see whether a hot translation is actually
worth optimizing.

- New file `xenon_fetcher.py`: queries xenon via Bamboo for the top 500
  functions by sample count, computes each function's % of total CPU.
- `top` command now shows a `gCPU=X.XX%` column (or `-` if the function
  isn't in xenon's top 500).
- `inspect` command shows a `Xenon gCPU: X.XX% of total CPU` header line.
- `--xenon-hours N` flag on both commands (default 4, set to 0 to skip).
