Summary:
#buildmore

We want to move nodeapi backend schemas to use SerializableTypeSystem (see https://fburl.com/gdoc/qlqqk9fj)

But ```nodeapi‎/backends‎/schema.thrift‎``` is used by several teams and libraries that needed backend schema introspection. Some of these libraries need some extra languages: java, go and even old deprecated python flavors.

So I'm forced to add all of these extra things to ```thrift/lib/thrift/type_system.thrift``` and it's dependencies so build succed.

The plan is to:
* Add SerializableTypeSystem and double write schema.thrift‎
* Start double writing SerializableTypeSystem to new configs
* Unblock docdb polylgot API and TXL integration
* Backfill SerializableTypeSystem to all existing configs using schema.thrift‎
* Migrate all existing code to use SerializableTypeSystem and modern python thrift code
* Drop python deprecated langs
