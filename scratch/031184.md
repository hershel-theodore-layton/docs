Commit title: avoid O(n^2) flat-container usage in Subprocess tests
Commit body:
Summary:
In `getOpenFds()`, the `boost::container::flat_set<int>` was being populated via individual `insert()` calls inside a loop. Each insertion into a flat container may require shifting elements in contiguous memory.

Replace with collecting file descriptors into a `std::vector<int>` first, then bulk-constructing the `flat_set` from the vector's range. This avoids repeated element shifting during insertion.
