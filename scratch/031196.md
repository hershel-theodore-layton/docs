Commit title: Emit mov + br for non-smashable veneers
Commit body:
Summary:
For non-smashable veneers, generate movz + movk + br instead of ldr + br for better performance. The total code size (3 instructions) of movz + movk + br should be identical to ldr + br + literal if we count the literal the instruction stream as well.

Additionally, emit non-smashable veneers before smashable ones so they are placed closer to the code they originate from.
