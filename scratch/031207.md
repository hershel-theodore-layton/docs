Commit title: Replace RocketServerConnection with IRocketServerConnection
Commit body:
Summary:
This is a prerequisite for enabling both `rocket_server_use_refactored_handler` and `rocket_use_factored_server_connection` simultaneously, which was previously unsafe due to the `static_cast` assuming the old connection type.

Replace concrete `RocketServerConnection&` parameter types with the `IRocketServerConnection&` interface in `RocketSetupProcessor`, `RocketRequestProcessor`, and `RocketRequestOrchestrator`. Remove the corresponding `static_cast<RocketServerConnection&>` downcasts in `RefactoredThriftRocketServerHandler` and `RocketRequestOrchestrator`.

All methods called on the connection in these classes (`close()`, `applyQosMarking()`, `sendMetadataPush()`, `applyCustomCompression()`, `getPayloadSerializer()`, `isDecodingMetadataUsingBinaryProtocol()`) are virtual methods on `IRocketServerConnection`, so this is a mechanical type change with no logic changes.
