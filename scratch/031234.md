Commit title: Add available space counter for JIT code cache
Commit body:
Summary: Add a ServiceData counter `jit.code.all.available` that reports the total unassigned space remaining in the JIT code cache (`m_all.available()`). With DynamicTCSections enabled, per-section capacity is always zero since sections grow dynamically from a shared pool. Instead, this counter exposes the meaningful metric: how much space remains in the shared pool for new section allocations.
