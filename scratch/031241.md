Commit title: add root-based provenance tracking
Commit body:
Summary:
This diff adds a simple version of provenance tracking: If enabled, we return for each selected test file what roots caused it to be selected (e.g., which roots have a path to the given test).

Longer term I want to support more sophisticated forms of provenance tracking, based on the heuristics used to select each tests. But what's being added in this diff is mostly meant to allow landing the next diff in this stack without making outputs less debuggable.

Implementation note:
- This is implemented as a separate step after actual test selection. I only want to enable this for debug logging in the backtesting jobs, but not in prod.
- Because of that, the current implementation is not overly optimised: It's a fairly simple fixpoint algorithm. It would be more efficient to determine the SCCs of the graph, then process them in topological order. I'll revisit this if the current version turns out to be too slow, which I doubt.
