## How

When we type `/analyze-www The question here` into Claude Code from $FBCODE/hphp/hack, Claude will substitute the question into the analyze-www.md Markdown file introduced in this diff and follow the instructions.

The instructions make sure that the agent knows:
- where to put code to get TAST logs from WWW
- to look at WWW to gain intuitions
- how to test the code end-to-end
- how to report results such that the reports are thorough, readable, and reproducible. For example, Claude will upload logs to pastry and record the WWW commit hash so the analysis can be iterated on and results can be verified.
- how to iterate on the analysis–forming hypotheses and taking more measurements

> Note: The slash command doesn't pollute context, as it is only activated when the developer specifically invokes it. This means that it's not super-discoverable (bad), but won't get in the way when we're doing non-analysis tasks (good).
