Commit title: Remove py3_to_python directory and migrate usages to py3.serializer
Commit body:
Summary:
The `thrift.lib.py3_to_python.serializer` module was a customer-added intermediate solution that dispatched serialize/deserialize calls between `thrift.py3` and `thrift.python` types. Since `thrift.py3.serializer` has been made forward-compatible and natively handles both py3 and python types, this intermediate module is no longer needed.

Changes made:
- Migrated all 10 customer Python files that imported from `thrift.lib.py3_to_python.serializer` to use `thrift.py3.serializer` (or `thrift.python.serializer` where only python types are used)
- Replaced `Protocol as PythonPy3Protocol` aliases with the standard `Protocol` import
- Replaced `GENERIC_THRIFT_STRUCT` usage in `thrift_utils.py` with inline isinstance check using `(thrift.py3.types.Struct, thrift.python.types.StructOrUnion)`
- Updated all corresponding BUCK files to replace `//thrift/lib/py3_to_python:serializer` dependency with the appropriate `//thrift/lib/py3:serializer` or `//thrift/lib/python:serializer`
- Removed stale `//thrift/lib/py3_to_python:serializer` dependency from `smartglasses_ai/personal_timeline_agent/llm_inference/BUCK` (no Python code used it)
- Deleted the `thrift/lib/py3_to_python/` directory (BUCK and serializer.py)
