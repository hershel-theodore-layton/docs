Commit title: Add except + to sync Unix/TCP channel factories in Cython
Commit body:
Summary:
Add `except +` declarations to `sync_createThriftChannelUnix` and
`sync_createThriftChannelTCP` in the Cython pxd file. This ensures that
C++ exceptions thrown during Unix socket and TCP channel creation are
properly caught and converted to Python RuntimeError exceptions, which
can then be handled by the Python thrift client code.

Without these declarations, C++ exceptions (like TTransportException when
connecting to a non-running daemon) crash the Python interpreter with
"terminate called after throwing" instead of raising a catchable exception.

The SSL version already had `except +`, so this brings Unix and TCP
connections to parity.
