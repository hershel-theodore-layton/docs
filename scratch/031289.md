Commit title: Add codegen_includes property to t_whisker_generator
Commit body:
Summary:
Adds `codegen_includes` as a base property on `t_program` in the Whisker generator, making it available to all Whisker-based generators. This filters out annotation includes (thrift/annotation/*) which are compile-time metadata and shouldn't be included in generated code.

Also adds `get_includes_for_codegen_raw()` method to `t_program` that returns `vector<t_include*>` directly (the existing `get_includes_for_codegen()` returns `vector<t_program*>`), enabling cleaner integration with Whisker templates that need access to include metadata like aliases.

This is a preparatory change for D94711724 which will use this base property instead of defining it in the C#-specific generator.
