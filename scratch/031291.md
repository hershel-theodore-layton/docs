Commit title: Consolidate program module path properties in py3 generator
Commit body:
Summary:
Consolidate multiple overlapping module path properties (`py3Namespaces`, `modulePathPeriodSeparated`, `modulePathUnderscoreSeparated`, `modulePath`) into cleaner properties on the `t_program` prototype:
- `module_path`: period-separated path including program name (e.g. `ns1.ns2.program`)
- `module_path_for_alias`: underscore-separated with leading underscore for import aliases (e.g. `_ns1_ns2_program`)
- `module_path_cpp_import`: double-underscore-separated for C++ import functions (e.g. `ns1__ns2__program`)

Removed `has_types?` from `py3_included_program` - can use `t_program` prototype's `has_types?`.
