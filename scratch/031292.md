Summary:
Remove `modulePath`, `module_path_period_separated`, `cbinding_path`,
`capi_converter_path`, and `module_auto_migrate_path` properties from the
py3 generator's `t_type` prototype. These properties all resolved the
true type's program internally and formatted a module path string.

Replace all template usages with the equivalent expression using the
program's `module_path_for_alias` property accessed via
`type.true_type.program.module_path_for_alias` with the appropriate suffix
(`_types`, `_cbindings`, `_thrift_converter`, `_thrift_types`).
