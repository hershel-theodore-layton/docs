Commit title: Fix RocketClientTest KeepAlive test flakiness
Commit body:
Summary:
Both KeepAliveWatcherLargeRequestTest and KeepAliveEvbDetachAttachTest use
a 20MB payload with 50ms keepalive timeout to verify that large transfers
trigger a keepalive timeout and close the connection. On fast CI machines,
the payload sometimes completes before the timeout fires, causing the
expected TTransportException not to be thrown (~33% failure rate).

Increased payload from 20MB to 40MB and decreased keepalive timeout from
50ms to 25ms, as the tests themselves suggest: 'Increase this if test is
flaky.'
