Commit title: Emit src.IndexFailure facts for files that fail to index
Commit body:
Summary:
The Hack Glean indexer previously silently swallowed exceptions during
file processing (e.g., "Not a Hack file" errors from the parser). This
caused worker crashes and provided no visibility into which files failed.

This change:
- Wires up the existing `src.IndexFailure` Glean predicate (already defined
  in the schema but never emitted) into the indexer pipeline.
- Catches exceptions during `File_info.create` in `recheck_job`, logs them,
  and emits `IndexFailure` facts with reason `CompileError` and the exception
  details.
- Adds a safety threshold (`max_index_failures = 100`): if more than 100 files
  fail to index across all workers, the workflow aborts with a clear error
  message instead of silently producing incomplete results.
