Commit title: Migrate cpp_mstch_program transitive schema includes to Whisker
Commit body:
Summary:
Migrate `cpp_mstch_program`'s `transitive_schema_initializers` and `num_transitive_thrift_includes` properties to Whisker.

`transitive_schema_initializers` is replaced by a new Whisker property `transitive_schema_includes` which returns an array of maps, covering all transitive includes of the program being generated. The maps contain the information required to build the schema accessor (program whose schema should be accessed, which program to access it from, index for the access).

The logic that was previously in `gen_transitive_include_map` is split across `populate_transitive_schema_includes` (building the set of includes and access information), and the template (the text to render).

`num_transitive_thrift_includes` is replaced by an `array.len` Whisker function call.

We don't need to cache (previously mstch context cache), because the property is only used in one place and we can use `#let` to compute once and access twice (once for length, once for iteration).

The *add 1* logic is fully moved into the template, alongside the hardcoded placement of the current program schema at index 0, to ensure the logic is co-located and can be kept in sync.
