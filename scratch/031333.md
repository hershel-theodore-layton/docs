Commit body:
Summary:
Add a new syntax error for invalid script markers. When a file starts with `<?` followed by a name that is neither `hh` or `php` (e.g., `<?h`, `<?hx`), the parser now emits:

```
`<?hx`  is not a valid script marker. Use `<?hh` to start a Hack file.
```

It is _not_ an error to have `<?` by itself - this is the PHP short tag
