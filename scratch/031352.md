Summary:
The prior diff (D95851129) removed all remaining external deps on
`-cpp2-reflection` Buck targets and disabled the codegen. This diff
removes the now-dead infrastructure:

- Delete the 7 `module_fatal*.h.mustache` templates
- Remove fatal-related free functions, whisker globals, and program
  properties from `t_mstch_cpp2_generator.cc` (~240 lines)
- Remove reflection build rule generation from `cpp2.bzl`: the
  `_STATIC_REFLECTION_SUFFIXES`, `_REFLECTION_HEADER`, fatal suffix
  entries, `_GENERATION_MODE_REFLECTION`, `_REFLECTION_SUFFIX`,
  `_use_static_reflection()`, `reflection_deps`, `reflection_headers`,
  the reflection rule block, and `cpp2_merged_reflection` logic
- Keep `"reflection"` as a recognized no-op option in `_VALID_OPTIONS`

NOT removed: the inline struct reflection (`__fbthrift_reflection_*`)
which is still actively used, and the reflection library headers
(`thrift/lib/cpp2/reflection/`) which have ~1130 includers.
