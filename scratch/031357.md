Summary:
These mstch properties return the containing service for interactions, or the service itself for non-interaction services.

Since these templates render in both contexts, each usage is replaced with a conditional that branches on `service:interaction?` — using `parent_service.FOO` (captured via `#let` before the interaction context switch) for interactions, and `service:FOO` directly for services.

This removes the last two mstch properties defined by `cpp_mstch_service` (except for its `get_functions` override, which feeds into the base `service:functions` and related properties).
