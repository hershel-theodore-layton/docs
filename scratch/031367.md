Commit title: Lint 5656 should only fire on ::class class pointers, not class constants
Commit body:
Summary:
Lint 5656 (crosspackage_classptr_reference) was incorrectly firing on class constant accesses, eg `C2::FOO`, in addition to `::class` class pointers. This change ensures that the linter only fires on `::class` references.

Changes:
- add a flag to class_expr to inform it if it is checking a class pointer; if yes, the linter check is performed if the `::class` carveout is enabled (check `Env.package_allow_classconst_violations`);
- In class_const, handle both ::class (ClassPtrLinterOnly) and non-::class constants (full check) but suppress lint emission for class constants since lint 5656 is only relevant for class pointers.
