Commit title: folly: make folly::Optional conditionally trivially copyable/assignable (similar to std::optional)
Commit body:
Summary:
`folly::Optional` always declared a user-defined copy constructor,
making it non-trivially copyable regardless of `Value`. It already had
a conditionally trivial destructor (via `StorageTriviallyDestructible`),
but the copy constructor prevented triviality for small trivial types.

This diff moves the storage and copy constructor logic into a base class
hierarchy (`detail::OptionalStorage` + `detail::OptionalCopyBase`) that
conditionally defaults the copy constructor when `Value` is both
trivially copy constructible and trivially destructible. This mirrors
the approach used by `std::optional` implementations.

For `Optional<int32_t>` and similar trivial types, both the copy
constructor and destructor are now trivial. For `Optional<std::string>`
and other non-trivial types, behavior is unchanged.
