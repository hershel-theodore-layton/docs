Commit title: Optimize getAllPathsWithHashes() with F14FastMap and reserve()
Commit body:
Summary:
Switch the temporary map in `SymbolMap::getAllPathsWithHashes()` from `hphp_hash_map` (F14NodeMap) to `hphp_fast_map` (F14FastMap) and add `reserve()` using a new `getPathCount()` DB query. This eliminates ~7.4M individual heap allocations (F14NodeMap allocates each entry separately) and avoids repeated rehashing during insertion.

The map is a short-lived temporary built in `getAllPathsWithHashes()`, consumed in `getFreshDelta()`, and immediately discarded — iterator and reference stability are not needed, making F14FastMap safe here.

Benchmarked with opt-hhvm against a 12GB production facts DB (7.4M rows):
- Baseline (F14NodeMap, no reserve): 17.75s
- F14NodeMap + reserve: 10.68s (66% faster)
- F14FastMap + reserve: 10.38s (71% faster)
