Commit title: Add index on file_attributes (attribute_name, attribute_value)
Commit body:
Summary:
Add a composite index on `file_attributes (attribute_name, attribute_value)` to speed up `getFilesWithAttributeAndAnyValue` queries. Without this index, the query scans all rows matching the attribute name (3.2M rows for `EntSchemaGenerated`) and filters by value in a sequential scan. With the index, SQLite does an indexed point lookup.

This is the highest-volume slow query in production Scuba data (hhvm_sandbox_events): 11.2M sampled calls per week at 445ms p50 for `HH\Facts\files_with_attribute_and_any_value()`.

Benchmarked with opt-hhvm against a 12GB production facts DB:
- `getFilesWithAttributeAndAnyValue("EntSchemaGenerated", ...)`: 352ms -> 17us (20,000x faster)

DB size impact: index adds ~220MB to the 12GB DB file (1.9% increase).
