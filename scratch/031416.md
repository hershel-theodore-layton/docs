Commit body:
Summary:
Add generic zero copy (MSG_ZEROCOPY) write support to the proxygen coro
HTTPServer infrastructure.

- Add `zeroCopyEnableFunc` field to `HTTPServer::Config` and
  `socketConfig.useZeroCopy` to enable `SO_ZEROCOPY` on the server socket.
- Add `setZeroCopyEnableFunc` to `HTTPCoroAcceptor` so that accepted
  transports are configured with zero copy and the per-write enable
  callback.
- Add `//folly/io/async:async_transport` dependency for the
  `AsyncWriter::ZeroCopyEnableFunc` type.
