Commit title: Extract RoundRobinRequestPile::Options to standalone RoundRobinRequestPileOptions
Commit body:
Summary:
Move the nested Options struct out of RoundRobinRequestPile into a standalone
RoundRobinRequestPileOptions struct. This decouples configuration from the pile
implementation, allowing Options to be used without depending on the full class.

A `using Options = RoundRobinRequestPileOptions;` alias inside the class
preserves full backward compatibility for all existing callers.

PileSelectionFunction is defined using uint32_t directly in the standalone
struct, and derived inside the class via `using PileSelectionFunction =
Options::PileSelectionFunction;`.
