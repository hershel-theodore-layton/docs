Commit title: Downgrade stack_depth logging from debug to trace
Commit body:
Summary:
The `stack_depth` module logs every single bytecode instruction it processes at `debug!` level. When any tool sets `RUST_LOG=debug` (e.g., Dev Docker Images / atlas with `--verbose`), this produces ~2,000 lines of per-opcode noise per compilation, drowning out useful output.

These per-instruction logs are clearly trace-level detail — they're only useful when actively debugging the stack depth computation itself. Moving them to `trace!` keeps `RUST_LOG=debug` clean while still making them available via `RUST_LOG=stack_depth=trace`.

See noisy output example: https://www.internalfb.com/intern/everpaste/?phabricator_paste_number=2232942086&handle=GNu5uibmoxmJeCcFALBfLLvxyW5AbsIXAAAz
