Commit title: Replace WeightedRequestPileQueue with SingleBucketRequestPileQueue in RoundRobinRequestPile
Commit body:
Summary:
RoundRobinRequestPile uses WeightedRequestPileQueue for its single-bucket
queues, but none of the weighted functionality is used — no custom weights,
no tryDequeueWithCapacity, no TwoDimensionalControlBlock. This adds
unnecessary complexity: each item is wrapped in an Item{data, weight} pair,
and the queue carries an unused mutex + firstElementHolder stash.

Replace it with a simpler SingleBucketRequestPileQueue that is just a
UMPMCQueue + optional atomic counter for count-based limiting. When limit=0
(unlimited), no atomic counter overhead is incurred. When limit>0, a
fetch_add/fetch_sub pair enforces exact admission control.
