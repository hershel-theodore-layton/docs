Commit title: Add E2E tests for graceful shutdown with active streams/sinks/BiDi
Commit body:
Summary:
Add a comprehensive test suite verifying that ThriftServer graceful shutdown
properly terminates active streaming RPCs. This was identified as a gap in
the existing E2E test coverage -- no tests previously verified shutdown
behavior while streams, sinks, or BiDi operations were in flight.

The test suite includes 8 test cases:
- ActiveStreamTerminatesOnServerShutdown: slow server stream is interrupted
- NewStreamRejectedAfterShutdown: post-shutdown RPCs fail cleanly
- ActiveSinkTerminatesOnServerShutdown: client sink interrupted mid-send
- ActiveBiDiTerminatesOnServerShutdown: both BiDi directions terminate
- InFlightRequestCompletesOrFailsOnShutdown: blocked request-response
- MultipleConcurrentStreamsTerminateOnShutdown: 3 concurrent clients
- OnStopRequestedCalledWithActiveStreams: lifecycle callback fires
- MixedStreamAndSinkTerminateOnShutdown: mixed RPC patterns

All tests use collectAll to run data-flow tasks concurrently with shutdown,
ensuring the operations are truly active before shutdown triggers (not
testing post-shutdown failure).
