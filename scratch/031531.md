Commit title: Migrate Hack typechecker from Hh_json to Yojson
Commit body:
Summary:
## What

Replace most remaining uses of  `Hh_json` with with yojson.
Behavior-preserving modulo whitespace, key order, and JSON parser error messages. Validated with script in P2239964525 (see --help).

## Why

- more correct: Hh_json handles unicode incorrectly, handles escape sequences incorrectly
- less footgunny: Hh_json represents all numbers as strings and doesn't validate that strings are well-formed numbers
- more standard: in particular, we already have both libraries in the codebase and one library is usually better than two when functionality overlaps
- better error reporting: parser failures now include positions

## AI

Wouldn't be feasible without agents. Thanks Claude!

## Notes for code readers

- There are lots of whitespace-only changes to snapshot tests. I did a combination of eyeball review and using AIs to review using scripts they wrote to validate changes are structure-preserving
- To keep behavior deterministic and avoid snapshot test thrash, I added a utility to sort keys of JSON objects before printing and [updated CLAUDE.md to say what the utility is for](https://www.internalfb.com/diff/D93351197?permalink=1704232470740825). `Hh_json` also attempted to sort keys before printing, but for some reason didn't didn't always do so consistently, leading to some snapshot .
- Some snapshot tests for notebook conversion for source-controlled notebooks changed. These just improve parser error messages for ill-formed notebook JSON inputs.
- Some snapshots changed for glean_autocomplete_query, but they are artifacts of the test. Before, we had a raw string literal  in the test `r'{"Vec": "FlibSL\Vec"}'`, which Hh_json should have failed on but instead parsed as `{"Vec": "FlibSLVec"}` (no slash). We update the test to correctly escape the backslash.
- We also remove Hh_json uses from the Zoncolan codebase, with the blessing of Zonc team.
- How I reviewed:
   - My eyes passed over all non-test changes and I iterated a few times to make the code changes idiomatic and minimal.
   - I didn't read all the test changes, but did have agents use a script to validate JSON changes in test snapshots were non-meaningful.
