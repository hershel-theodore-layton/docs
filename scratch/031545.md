Summary:
This diff introduces the building blocks (~data model) for the Rust's `TypeSystem` library, which mirrors the [C++ version](https://fburl.com/code/a8tjzcm3).

This crate provides representations for all Thrift types, e.g. primitives, containers, and user-defined types, as a shared type graph with immutable nodes. The `TypeRef` enum provides a descriptor for a given node, while the specific nodes themselves provide access to their structural properties.
