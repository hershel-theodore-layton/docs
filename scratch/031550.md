Commit title: Add --arch flag for runtime architecture selection
Commit body:
Summary:
tc-print previously selected its disassembler (ARM64/vixl vs x86/XED) at
compile time via #ifdef __aarch64__ / __x86_64__. This meant ARM64 TC dumps
could not be analyzed on an x86_64 host and vice versa.

This adds a --arch flag (aarch64/arm64/a64 or x64/x86_64) for runtime
selection, defaulting to the host architecture when unspecified (preserving
existing behavior). On x86_64 builds, both vixl (ARM decoder, always linked)
and XED (x86 decoder) are available, so we just needed to compile and expose
both code paths.

Changes:
- Add DisasmArch enum and hostDisasmArch() to offline-code.h
- Remove compile-time guard from offline-arm-code.cpp so ARM code compiles everywhere
- Rename arch-specific methods to *Arm/*X86 variants
- Add dispatcher methods in offline-code.cpp that delegate based on arch_
- Add --arch flag with getopt_long in tc-print.cpp
