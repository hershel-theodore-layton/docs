Commit title: TypeSystemDigest
Commit body:
Summary:
Adds the `type_system_digest` crate providing canonical, deterministic SHA-256 digests for `TypeSystem`, SerializableTypeSystem` and other relevant node types.

Nodes can be `digest`ed using the `TypeSystemDigest` trait. The list of supported nodes includes:
- A `SerializableTypeSystem` instance for serialized TS representations
- Any `TypeSystem` instance for runtime TS representations
- `SerializableRecord` for annotations & field constants
  - This includes all serializable thrift types

Similar to the C++ implementation this ensures:
- Order-independent hashing for sets, maps, and annotations
- Language & platform independent output, cfr. TypeSystem.h
This will be validated by an upcoming cross-language test diff.
