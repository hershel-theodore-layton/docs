Commit title: Warn that unstructured `deprecated` annotation has no effect
Commit body:
Summary:
The unstructured `deprecated` annotation (e.g. `(deprecated = "msg")`) has no
effect in the Thrift compiler. Add a diagnostic warning suggesting users replace
it with `thrift.Deprecated` or a comment instead.

We cannot simply codemod all usages to `thrift.Deprecated` because it can
break downstream sync.
