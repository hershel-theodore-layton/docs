Commit title: Extract non-template startServerShutdown body to Server.cpp
Commit body:
Summary:
Example application of the cpp_extract_non_template_to_cpp codemod pattern.

The template function `detail::startServerShutdown<RouterInfo>` in `Server-inl.h`
does not use the `RouterInfo` template parameter anywhere in its body. Extract
the entire function body into a non-template `startServerShutdownImpl` in a new
`Server.cpp` file. The template function becomes a thin wrapper that forwards
to the impl.

This reduces include bloat for all translation units that include `Server.h`,
as the shutdown logic (which pulls in ThriftServer and AsyncMcServer headers)
is now compiled once in `Server.cpp` instead of being instantiated in every
template user.
