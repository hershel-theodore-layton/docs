Commit body:
Summary:
Example application of the cpp_extract_non_template_to_cpp codemod pattern.

The template member function `CarbonRouterInstance<RouterInfo>::startObservingRuntimeVarsFile()`
does not use `RouterInfo` anywhere in its body — all accessed members (`opts_`,
`rtVarsDataWeak()`, `rtVarsDataObserver_`, `functionScheduler()`) come from the
non-template base class `CarbonRouterInstanceBase`, and `runtimeVarsObserverHandle_`
is passed by reference.

Extract the entire body into a non-template `detail::startObservingRuntimeVarsFileImpl()`
in the existing `CarbonRouterInstance.cpp`. The template function becomes a thin wrapper.
This also allows removing the `<boost/filesystem/operations.hpp>` include from the
`-inl.h` header, reducing include bloat for all template instantiations.
