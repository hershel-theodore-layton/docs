Commit title: Call genAfter with first stream chunk for void first responses
Commit body:
Summary:
For streaming thrift endpoints with void first responses (e.g., stream_predict),
genAfter was called with null, which meant client async handlers could never
process the actual response data. This caused privacy enforcement hooks like
TClientPoliciedAsyncHandler to skip streaming endpoints entirely.

Fix genAwaitStreamResponse to wrap the stream and call genAfter with the first
stream chunk when the first response is void. Non-void first response behavior
is completely unchanged.
