Commit title: Fix mac-arm64 build failures for thrift test targets
Commit body:
Summary:
Fix build failures when building thrift tests with `fbcode//mode/mac-arm64`:

1. Switch `terse_write_test`, `serializer_test`, and `SimpleJSONToThriftTest` from
   `cpp_unittest` to `thrift_cxx_test`. The `cpp_unittest` macro does not convert
   `//thrift/...` deps to the correct xplat paths, causing dep resolution failures
   in cross-compilation mode.

2. Migrate `serializer_test` dep from `//folly/test:json_test_util` to
   `//folly/json:json_test_util` which exists in xplat, and update the include
   to use the canonical `folly/json/JsonTestUtil.h` path.

3. Mark `testset-cpp2-helper-test` as `fbcode_only = True` because the testset
   target is too large for the mac linker (thunk range overrun), same as the
   existing `object_test` in `xplat/thrift/lib/cpp2/test/BUCK`.
