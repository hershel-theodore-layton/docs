Commit title: Map slab to the shared zero page instead of unmapping it to avoid races
Commit body:
Summary:
Change UnmapSlab to remap the slab with PROT_READ instead of PROT_NONE and
update the comment accordingly. With PROT_READ the slab's VA range maps to
the kernel shared zero page, so the previous private physical backing can be
reclaimed while reads still succeed (returning zeros) instead of faulting with
SIGSEGV. This avoids shutdown races where stale pointers into a freed slab
are briefly dereferenced.
