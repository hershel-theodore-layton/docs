# Context

Hack lacks a unified language specification or reference. Documentation
exists but is scattered across the manual, HIPs, Ott files, and source
code comments. New engineers have no single place to get a comprehensive
view of the language's grammar, type rules, and semantics.

# Solution

Create a new `hphp/hack/spec/` directory to serve as the canonical
language specification, targeting both language implementers and new
engineers. The scaffolding establishes the directory structure, BUCK
build configuration for extracting and testing inline code examples
(reusing the same infrastructure as the Hack manual), CI hints for
automated validation, and an introduction chapter documenting the
notation conventions for grammar rules, typing rules, and testable
code blocks.
