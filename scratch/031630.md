Commit title: Fix RenderTest.infinite_recursion crash on mac-arm64
Commit body:
Summary:
The test was crashing on mac-arm64 because `kRenderStackMaxDepth` was
set to 10,000, which caused the C++ call stack to overflow before the
Whisker VM's virtual stack depth limit was reached. Mac-arm64 has a
smaller default stack size than Linux.

Reduce `kRenderStackMaxDepth` from 10,000 to 1,000 which is still far
more than any real template would need, but fits within mac-arm64's
stack constraints.
