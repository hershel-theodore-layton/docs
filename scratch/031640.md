Commit title: Introduce unified metric logging interfaces and event types
Commit body:
Summary:
Introduce the foundational types for unified Thrift stream/sink metric logging:
- `ThriftEvent` — typed event structs for stream/sink lifecycle events
- `IThriftServerCounters` — pure virtual interface for real-time counters with noop defaults
- `IThriftRequestLogging` — pure virtual interface for completion-time structured logging with noop defaults

These interfaces replace the fragmented `StreamEventHandler` dispatch path with a cleaner, typed API. `IThriftServerCounters` is called inline on every lifecycle event (so implementations must be lightweight), while `IThriftRequestLogging` is called once per stream/sink at termination with accumulated summary data.

Pure additions with no behavioral changes.
