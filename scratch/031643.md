Summary:
Wire the unified logging infrastructure into the Thrift server stack:

- Add `getThriftServerCounters()` and `getThriftRequestLogging()` virtual
  methods to `ServerConfigs` (default returns nullptr/noop).
- Add corresponding members, override getters in `ThriftServer`, and setters
  in `ThriftServerInternals` for module installation.
- Store `ThriftConnectionLog` on `Cpp2ConnContext` with getter/setter.
- Create the connection log in `ThriftRocketServerHandler` constructor when
  backends are installed.
- Add logging source files to `CMakeLists.txt`.

At this point the unified logging path is wired but uses noop backends — no
metrics are emitted yet, so there is no overlap with the existing
`StreamMetricEventHandler` path.
