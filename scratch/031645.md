Summary:
Atomically swap the stream/sink metric backend:

1. Install `Fb303ThriftServerCounters` in `ThriftStatsModuleLight` so the
   unified logging path starts emitting fb303 stats.
2. Remove `StreamMetricEventHandler` so the old path stops emitting.
3. `StreamMetricHandler` no longer allocates `StreamState` for stream/sink
   RPCs — it only handles interaction tracking and BiDi metrics.

This ensures there is never a window of double-counting or missing metrics.
Stream/sink counter emission now flows exclusively through:
  lifecycle events → ThriftStreamLog/ThriftSinkLog → IThriftServerCounters
  → Fb303ThriftServerCounters → fb303 stats.
