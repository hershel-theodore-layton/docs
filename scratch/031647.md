Commit body:
Summary:
Add a `minSize` optional field to `GetAPCEntriesRequest` to allow filtering APC entries by minimum data size. This is useful for debugging large APC entries without being overwhelmed by small ones.

Changes:
- Sync hhvm.thrift from configerator (adds `minSize` field)
- Thread `minSize` through the C++ call chain: fb303-server -> ext_apc -> concurrent-shared-store
- Filter entries in `debugGetEntries` by comparing `abs(dataSize)` against `minSize`
- Add `--min-size` CLI flag to hhvmctl's `get-apc-entries` command
