Commit title: Add --enable_scone flag
Commit body:
Summary:
Expose the SCONE transport setting in hq via `--enable_scone`. When set, both client and server advertise `scone_supported` in the QUIC handshake transport parameters and enable SCONE packet processing.

The server will send SCONE packets coalesced with AppData, and the client will process received SCONE rate signals. The rate signal itself is set by network elements.
