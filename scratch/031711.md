Commit title: Add C# thrift_library converter
Commit body:
Summary: Add a C# converter to the thrift_library macro system so that languages = ["csharp"] generates C# types at build time via the csharp_EXPERIMENTAL compiler backend. The converter follows the same plugin pattern as Go, Rust, and other languages: it maps each .thrift input to a .cs source file and emits a csharp_library_dotnet target with the Thrift C# runtime auto-wired as a dependency. The generated library is cross-platform (Linux, macOS, Windows) and can be consumed directly by downstream csharp_binary_dotnet and test targets.
