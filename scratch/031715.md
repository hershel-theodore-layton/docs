Summary:
Pull Request resolved: https://github.com/facebook/hhvm/pull/9741

The `thriftmetadata` CMake target compiles `TypeSystemTraits.cpp`, which
includes `thrift/lib/cpp2/type/Any.h`, which includes the generated header
`thrift/lib/thrift/gen-cpp2/any_rep_types.h`. However, `any_rep-cpp2-target`
was not listed in the `add_dependencies()` for `thriftmetadata`, causing a
race condition in parallel builds where the thrift codegen for `any_rep.thrift`
may not complete before `TypeSystemTraits.cpp` is compiled.

Add `any_rep-cpp2-target` to the `add_dependencies()` call for `thriftmetadata`.
