Commit title: Add missing compiler_base link dependency to compiler target
Commit body:
Summary:
The `compiler` CMake library target contains code generation utilities
(`generate/*/util.cc`) that use `diagnostics_engine::report()`, which
calls `diagnostics_engine::do_report()`. The `do_report` function is
defined in `diagnostic.cc`, which is part of the `compiler_base` library.

However, `compiler` only linked against `compiler_ast`, not
`compiler_base`, causing an undefined symbol linker error on macOS:

```
Undefined symbols for architecture arm64:
  "apache::thrift::compiler::diagnostics_engine::do_report(...)"
```

Fix by adding `compiler_base` to `compiler`'s `target_link_libraries`.
