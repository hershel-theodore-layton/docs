Summary:
Currently x86's crc32 hash function is implemented in three places: on hash-crc-x64.S, string-data-x64.S and hash-table-x64.S
Aarch64 code always fallsback to the implementation in hash.h, introducing code jumps.

The diff inlines the crc32 hash procedures in the same places as x86, to avoid branching.
