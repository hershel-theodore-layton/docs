Commit title: Fix skip() to handle unknown fields in JSON5 deserialization
Commit body:
Summary:
Json5ProtocolReader::skip() was delegating to apache::thrift::skip() which
requires a valid TType. Since JSON field type information is unavailable
(readFieldBegin sets fieldType=T_VOID), skip(T_VOID) threw
TProtocolException("Encountered invalid field/element type (1) during
skipping").

Fix: implement JSON5-aware skip that dispatches based on the next JSON5 token
(object, array, or primitive) instead of the TType parameter, similar to
SimpleJSONProtocolReader::skip().
