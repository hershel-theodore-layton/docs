Summary:
In preparation for enforced `UNSAFE_CAST` warnings, introduce a new reason that's used on like-types introduced in order to signal an enforcement point. First up, properties. For example, if a property has declared type `arraykey`, when assigning to the property, we add a like, so that a value of type `~int` (for example) can be assigned to the property without error.

No new tests; the warnings higher up this stack will make use of the reason info.
