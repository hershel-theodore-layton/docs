Commit title: Fix -Wundef error in folly/portability/Event.h on Windows
Commit body:
Summary:
On Windows, libevent 2.1.8 is used instead of v1.something. I don't know why someone upgraded libevent but only made it apply on windows.

libevent 2.1.8 defines `EVENT__NUMERIC_VERSION` instead of
`_EVENT_NUMERIC_VERSION`. Using an undefined macro in `#if` triggers
`-Werror,-Wundef` (enabled by ARVR Windows toolchain defaults).

Add a `defined()` guard to prevent the error.

I'm not sure why this never fired until now...
