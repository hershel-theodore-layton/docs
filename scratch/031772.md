Commit title: Add byte-level metrics to stream/sink Scuba logging
Commit body:
Summary:
Add `totalBytes`, `minChunkSize`, and `maxChunkSize` fields to stream and sink
Scuba logging to help downstream consumers understand payload characteristics.

Changes:
- Add `payloadBytes` field to `StreamNextEvent` and `SinkNextEvent` event structs
- Add byte summary fields (`totalBytes`, `minChunkSize`, `maxChunkSize`) to
  `StreamSummary` and `SinkSummary` in `IThriftRequestLogging`
- Add byte accumulators to `ThriftStreamLog` and `ThriftSinkLog`, accumulating
  in `log(StreamNextEvent)` / `log(SinkNextEvent)` and populating in `finish()`
- Capture IOBuf size before `serverPush` in `ServerGeneratorStreamBridge` and
  pass to `StreamNextEvent`
- Capture IOBuf size in `ServerSinkBridge::onSinkNext` and pass through
  `notifySinkNext` to `SinkNextEvent`
- Log `total_bytes`, `min_chunk_size`, `max_chunk_size` in
  `ScubaThriftRequestLogging` for both stream and sink completions

Scope: Scuba logging only — no changes to IThriftServerCounters or
Fb303ThriftServerCounters.
