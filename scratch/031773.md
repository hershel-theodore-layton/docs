Commit title: Fix thrift-python service result IOBuf type after annotation lowering removal
Commit body:
Summary:
The service_arg_types.mustache template used `function.return_type.true_type`
to get the result type, which resolves through typedefs. After D97539792
removed annotation lowering, the `cpp.Type{name = "folly::IOBuf"}` annotation
stays on the `IOBuf` typedef rather than being propagated to the `binary` true
type. Resolving to `true_type` loses the annotation, so `iobuf?` returns false
and the generated code uses `typeinfo_binary` instead of `typeinfo_iobuf`.

Fix: use `function.return_type` (preserving the typedef) instead of
`function.return_type.true_type`. All type property checks (void?, binary?,
iobuf?, etc.) already call `get_true_type()` internally, so this is safe.
