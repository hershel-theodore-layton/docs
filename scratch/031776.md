Commit title: generalize closeable async iterator
Commit body:
Summary:
Add `CloseableGenerator`, a class-based async iterator wrapper for server-side
streaming that supports cancellation while `__anext__()` is in-flight.

Python's native async generators raise `RuntimeError` if `aclose()` is called
while the generator is running (i.e., during `__anext__`). This makes it
impossible for `cancelAsyncGenerator` to propagate cancellation to a handler's
generator when it is blocked waiting for the next item.

`CloseableGenerator` wraps each `__anext__()` call in an `asyncio.Task`, so
`aclose()` can cancel the in-flight task and propagate cancellation to the
underlying generator. It also handles serialization and user exception mapping,
replacing the functionality of the generated `_fbthrift__stream_wrapper_*`
async generators.

Also adds `UserExceptionMeta`, a simple data class used to describe declared
stream exceptions (exception class, field name, and qualified type name).
