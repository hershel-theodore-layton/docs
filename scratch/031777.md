Commit title: Use CloseableGenerator for server-side stream wrappers
Commit body:
Summary:
Replace the generated async generator stream wrapper (`_fbthrift__stream_wrapper_*`) with `CloseableGenerator`, a class-based wrapper that wraps each `__anext__()` call in an `asyncio.Task`.

This fixes a bug where stream cancellation fails to propagate when `__anext__()` is in-flight. Python async generators raise `RuntimeError` if `aclose()` is called while the generator is running. The `fallibleClose` helper swallows this error, so the handler's generator is never cancelled. `CloseableGenerator` avoids this by using `asyncio.Task` which can be cancelled externally.

Changes:
- `services.mustache`: Import and use `CloseableGenerator` instead of async generator wrapper
- `python.bzl`: Add `closeable` as a dep for generated thrift-python services
- `stream.py`: Remove `unittest.expectedFailure` from `test_stream_cancel_propagates_during_blocked_anext`
