Commit title: Fix potential UB in heap_vector_types SimpleSetTest
Commit body:
Summary:
The SimpleSetTest uses random data but assumes `lower_bound(32)` and
`upper_bound(32)` will never return `end()`. While extremely unlikely
with 1000 random values from [0, 100000), this is not guaranteed, and
dereferencing `end()` is undefined behavior. Insert sentinel values
31 and 34 to ensure elements near 32 always exist, making the
assumptions valid regardless of random values generated.
