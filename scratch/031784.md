Commit title: Fix sink/stream method name to use qualifiedMethodName
Commit body:
Summary:
D96523528 switched stream/sink metrics from the old StreamMetricEventHandler
path to the unified ThriftSinkLog/ThriftStreamLog → Fb303ThriftServerCounters
path. However, `HandlerCallbackBase` was setting `setMethodName` with the
unqualified `methodName` (e.g. "range") instead of `qualifiedMethodName`
(e.g. "TestSinkService.range"). This caused all fb303 counters to be emitted
under the wrong key, making them invisible to tests and dashboards expecting
the qualified format.

Fix:
- Use `methodNameInfo_.qualifiedMethodName` instead of
  `methodNameInfo_.methodName` when calling `setMethodName` on both
  `ServerStreamFactory` and `ServerSinkFactory`.
- Update the killswitch test to reflect that the `disable_streaming_metrics`
  thrift flag only controls the old StreamMetricHandler event handler path;
  the new unified logging path (ThriftSinkLog → Fb303ThriftServerCounters)
  is always active when Fb303ThriftServerCounters is installed.
