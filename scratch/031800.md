Commit body:
Summary:
Adds a folly::Benchmark binary to measure the CPU
overhead of stream interceptors on streaming RPCs.
Runs 32 concurrent streams against a ThriftServer,
comparing throughput with and without interceptors.
The delta between cases gives per-interceptor
per-payload cost.

Benchmark cases: StreamBaseline (no interceptors),
StreamAsyncInterceptorX1/X3. Uses BenchFixture with
BENCHMARK_SUSPEND for setup isolation. Reports both
wall-time throughput and per-payload CPU time via
getrusage(RUSAGE_SELF).

Includes ServiceLab benchmark config for automated
continuous regression tracking. Triggers on diffs
touching thrift/lib/cpp2/server with a 5% variation
threshold.

folly::Benchmark (32 streams, 30s/case, opt):
  Case                    cpu/payload
  StreamBaseline            2.43us
  StreamAsyncInterceptorX1  2.83us (+16%)
  StreamAsyncInterceptorX3  3.22us (+33%)

Per-interceptor per-payload overhead: ~263ns
