Commit title: Add onStreamPayloadSync non-coroutine fast path
Commit body:
Summary:
Add onStreamPayloadSync as an optional override that
returns std::optional<Task<void>> instead of Task<void>.
When returning std::nullopt, the caller skips co_await
entirely, avoiding coroutine frame allocation per
interceptor per payload.

The default implementation wraps the existing
onStreamPayload for backwards compatibility — no
existing interceptors need changes.

Adds StreamAwareSyncInterceptor and sync benchmark
cases (StreamSyncInterceptorX1/X3) to the validation
binary to measure the non-coroutine path.

folly::Benchmark (32 streams, 30s/case, opt):
  Case                    cpu/payload
  StreamBaseline            2.44us
  StreamAsyncInterceptorX1  2.66us (+9%)
  StreamAsyncInterceptorX3  2.82us (+16%)
  StreamSyncInterceptorX1   2.58us (+6%)
  StreamSyncInterceptorX3   2.75us (+13%)

Per-interceptor overhead: ~127ns async, ~103ns sync
(async down from ~230ns, 45% reduction;
 sync path avoids coroutine overhead entirely)
