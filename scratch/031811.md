Commit title: Replace merge_env with Stdlib.Map.merge for local env merging
Commit body:
Summary:
Replaces `LMap.merge_env` with `Stdlib.Map.merge` (aliased as `LMap.merge`) in
the per-continuation context union. The old `merge_env` implementation extracts
all entries via `bindings`, iterates them with `fold_left_env`, and for each
entry does a `find_opt` (O(log n)) + `add` (O(log n)) on the result map --
O(n log n) total per merge with significant constant factor from intermediate
list allocations.

`Stdlib.Map.merge` traverses both balanced trees simultaneously in O(n) with no
intermediate allocations, reusing subtrees structurally when possible.

Since `Stdlib.Map.merge` does not thread an environment, we use a ref to pass
the env through the callback.
