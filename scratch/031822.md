Commit title: Add DuplicateModuleNameError exception for duplicate module detection
Commit body:
Summary:
ThriftServer::addModule previously threw a plain std::invalid_argument when a
duplicate module name was added. This makes it difficult to distinguish from
other invalid_argument exceptions. This diff introduces a
DuplicateModuleNameError subclass of std::invalid_argument so callers can
catch this specific error. Existing code catching std::invalid_argument
continues to work since DuplicateModuleNameError inherits from it.
