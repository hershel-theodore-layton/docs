Summary:
Implement the Hack code generator support for the new annotations:

- edward-io.FixmeWrongType: wraps field property types and constructor arg types
  with \HH_FIXME\WRONG_TYPE<Type>. Supports field-level (single field) and
  struct-level (all fields) application. Matches existing
  ThriftCodegenFixMePropertyRule / ThriftCodegenFixMeAllPropertiesRule behavior.

- edward-io.UnsafeArray: replaces array container prefixes in field property types
  and constructor arg types (vec -> varrayish_UNSAFE, dict -> darrayish_UNSAFE).
  Matches existing ThriftCodegenUnsafeArrayPropertyRule behavior.

When both annotations are present, UnsafeArray is applied first, then
FixmeWrongType wraps the result.
