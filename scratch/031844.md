Commit title: Remove dead bser library and tests
Commit body:
Summary:
The OCaml BSER (Binary SERialization) library was written in 2016 as a
prototype to switch Hack's Watchman communication from JSON to BSER.
The JSON-to-BSER direction was never implemented (the stub just output "42"),
and the library was never wired into any production code. Watchman
communication has always used JSON.

Remove the entire dead library (`src/utils/bser/`) and its test fixtures
(`test/utils/bser/`).
