Commit title: Add informative data to Position_not_found exception
Commit body:
Summary:
The `Position_not_found` exception was a bare exception with no data,
making it hard to debug when position lookups fail. Add the requested
line, column, and number of lines in the file so crash reports include
the context needed to diagnose the issue.

No code catches this exception by name — it propagates to the top-level
handler in hh_server/hh_client where OCaml prints it as:

  Line_break_map.Position_not_found{line=42; column=10; num_lines_in_file=35}

This immediately tells you the position was out of range (e.g. stale
position data or wrong file), versus the old output which was just
`Position_not_found` with no context.
