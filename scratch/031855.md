Commit title: IoUringZeroCopyBufferPool: Allow shared usage of buffer metadata
Commit body:
Summary: While not yet seen during execution, NIC drivers using zcrx niov allocator can actually split a single niov for multiple packet. This will then yield  multiple CQE per niov buffer. In order to handle that, pre-initialize buffer metadata (off and len) in the constructor instead of setting them during `getIoBuf()`, and potentially concurrently modifiying them. When returning a buffer, the kernel zcrx subsystem only cares about the offset which it uses to find and decrement the user refcount for the matching niov.
