Commit title: Add ODS counters for SSL session reuse split by TLS version
Commit body:
Summary:
`DbODSCounters::incrReusedSSLSessions()` was a no-op, meaning SSL session
reuse was not being tracked in ODS. This made it impossible to set up
real-time alerts on session resumption rate drops during the TLS 1.3 rollout.

This diff:
- Adds a `std::string_view tlsVersion` parameter to `incrReusedSSLSessions()`
  across the `DBCounterBase` interface and all implementations
- Adds a new `incrSSLSessionNotReused(std::string_view tlsVersion)` method
  to track connections where session reuse did not occur
- Implements both methods in `DbODSCounters` using OBC counters with keys:
  - `dbclient.client_ssl.ssl_session_reused.tls12`
  - `dbclient.client_ssl.ssl_session_reused.tls13`
  - `dbclient.client_ssl.ssl_session_not_reused.tls12`
  - `dbclient.client_ssl.ssl_session_not_reused.tls13`
- Updates the call site in `MysqlConnectOperationImpl::maybeStoreSSLSession()`
  to pass `getTlsVersion()` and track both reused and not-reused sessions

These counters enable monitoring TLS 1.3 session resumption rates in ODS
and setting up alerts for drops relative to the TLS 1.2 baseline.
