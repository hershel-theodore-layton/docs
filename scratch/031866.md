Commit title: Add CPUCC to ThriftOverloadProtectionModule
Commit body:
Summary:
Add dynamic CPUConcurrencyController configuration support to ThriftOverloadProtectionModule via ThriftServerDynamicConfig, enabling per-service CPUCC tuning through Configerator without server restarts.

ThriftOverloadProtectionModule now subscribes to the overloadProtectionConfig.cpuConcurrencyControllerConfig field from ThriftServerDynamicConfig, converts the Thrift CPUController struct to a native CPUConcurrencyController::Config, and pushes it to ThriftServer via a new dynamic config observable.

ThriftServer's CPUCC config resolution priority becomes: mock > dynamic > global static. When the dynamic config is removed, the server falls back to the global default.
