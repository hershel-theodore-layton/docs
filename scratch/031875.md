Summary:
See D94165135 for original summary.

Fixes on top of that change:
- Truncate the tag used in `probeDelta` (functional)
- If the provided key is a pointer type `T*`, alignment will cause the lower bits to be all zero, reducing entropy in the tag. I add a shift here to increase tag entropy in this scenario, which shifts by a compile-time constant off of the critical path of Find.
- Shift the CRC used in the tag to avoid secondary hash correlation

We expect to see slightly improved performance when the chunk is not already in L1D (the load will launch one cycle earlier), and performance parity otherwise.
