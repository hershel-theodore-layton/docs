Commit title: Document 53 undocumented HHVM runtime options in configs.specification
Commit body:
Summary:
Add descriptions for 53 previously undocumented runtime options in
configs.specification whose names alone do not explain their behavior.
This brings documentation coverage from 25% to 29% (278 of 951 options).
The remaining ~670 undocumented options are self-explanatory from their
names (SSL cert paths, compression levels, JIT thresholds, etc.).

Options were selected for documentation based on having non-obvious
behavior, dynamically computed defaults, or side effects not apparent
from the name. Each description was verified against the implementing
source code.
