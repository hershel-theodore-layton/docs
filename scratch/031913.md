Summary:
Adds tests demonstrating that sink cancellation does not propagate promptly when the server handler returns early while the client is still feeding data via a blocked async generator. Both the bidi stream and plain sink paths are affected.

Changes:
- `test/bidi.py`: Adds `test_bidi_sink_cancel_propagates_during_blocked_anext` — sets up a bidi handler that returns after consuming one item, while the client generator blocks forever on the second `__anext__`. Marked `expectedFailure` since `sink.sink()` currently hangs instead of completing.
- `test/sink.py`: Adds `test_sink_cancel_propagates_during_blocked_anext` — uses `rangeEarlyResponse(5, 11, 5)` where the server returns after the first item, while the client generator blocks forever. Also `expectedFailure`.
- `test/BUCK`: Fixes bidi test dep from `:sink` to `:stream` (the bidi test imports `ClientBufferedStream` from `streaming.stream`, not `streaming.sink`).

Both tests use `asyncio.wait_for(..., timeout=5.0)` as a safety net — without the fix, they hang and time out.
