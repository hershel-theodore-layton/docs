Commit title: Sort adapter_modules iteration for deterministic codegen
Commit body:
Summary:
The `adapter_modules` and `adapter_type_hint_modules` properties in the Python
generator iterate over `std::unordered_set`, which has nondeterministic
iteration order. This causes the `test_adapter_python` fixture test to fail
on mac-arm64 because the hash implementation differs from Linux x86_64,
producing different import orderings.

Sort the set elements before emitting them to ensure deterministic output.
