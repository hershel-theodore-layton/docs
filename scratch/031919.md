Commit title: Escape $ in string constants to prevent variable interpolation
Commit body:
Summary:
The Hack code generator emits string constants with double quotes, but `get_escaped_string()` does not escape `$` characters. In Hack, double-quoted strings perform variable interpolation on `$`, so a thrift constant like `"$_presto_anonymous_$"` would be misinterpreted.

Fix `render_string()` in `t_hack_generator.cc` to escape `$` as `\$` before wrapping in double quotes. This is Hack-specific — the shared `get_escaped_string()` in `common.h` is unchanged since `$` is not special in other target languages.

Added a `dollar_string` test constant to the constants fixture and regenerated all fixture outputs.
