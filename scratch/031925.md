Commit title: Remove 12 dead runtime tuning, JIT, and stats options
Commit body:
Summary:
These options exist in configs.specification and generate Cfg:: static
variables, but no hand-written C++ code reads them. They represent
removed features, abandoned experiments, or orphaned tuning parameters.

**Memory/Arena options (3):**

1. **Eval.HeapPurgeWindowSize** (default: 5000000)
   Part of a request-heap purging system. Searched for
   `HeapPurgeWindowSize` across hphp/runtime/, hphp/util/, and
   hphp/facebook/ — zero references. The heap purge system was removed
   or redesigned without cleaning up these config entries.

2. **Eval.HeapPurgeThreshold** (default: 128MB)
   Companion to HeapPurgeWindowSize. Same search — zero references.

3. **Eval.RecycleAProf** (default: true)
   Related to recycling A-profiling data in the translation cache.
   Searched for `RecycleAProf` — zero references. The TC recycling
   code no longer reads this flag.

**Server/Unix options (2):**

4. **Server.WarmupConcurrently** (default: false)
   Controlled concurrent warmup behavior. Searched for
   `WarmupConcurrently` — zero references. The concurrent warmup
   functionality is now controlled by Server.InternalWarmupThreads
   instead (which has 3 active references in program-functions.cpp).

5. **Eval.UnixServerProxyXbox** (default: true)
   Controlled whether the Unix server proxied Xbox requests. Searched
   for `UnixServerProxyXbox` — zero references. Other Unix server
   options (UnixServerRunPSPInBackground, UnixServerFailWhenBusy, etc.)
   are all alive in cli-server.cpp; this one specifically is not.

**JIT options (3):**

6. **Jit.PGOArrayGetStress** (default: false)
   A stress-testing flag for PGO array-get operations. Searched for
   `PGOArrayGetStress` — zero references in runtime/. Only found in a
   test .opts file (bug-5593564.php.opts), which was cleaned up. All
   other Jit.PGO* options (PGODumpCallGraph, PGOOptCodeCallGraph, etc.)
   are alive; this one specifically is not.

7. **Jit.BuildOutliningHashes** (default: false)
   Controlled building hashes for JIT code outlining. Searched for
   `BuildOutliningHashes` — zero references anywhere. The outlining
   hash system was removed.

8. **HHIR.LoadThrowMaxDecrefs** (default: 0)
   An HHIR optimization threshold for throw-path load elimination.
   Searched for `LoadThrowMaxDecrefs` — zero references. Its companion
   HHIR.LoadStackTeardownMaxDecrefs IS alive (1 ref in load-elim.cpp),
   but this specific threshold is not.

**Stats profiler options (3):**

9. **Stats.ProfilerTraceBuffer** (default: 2000000)
   Buffer size for the stats profiler trace. Searched for
   `ProfilerTraceBuffer` — zero references. The profiler system either
   no longer uses configurable buffer sizes or was removed.

10. **Stats.ProfilerTraceExpansion** (default: 1.2)
    Growth factor for the stats profiler trace buffer. Same search —
    zero references.

11. **Stats.ProfilerMaxTraceBuffer** (default: 0)
    Maximum size for the stats profiler trace buffer. Same search —
    zero references.

12. **Eval.ServiceRouterJumpstartWarmup** (default: 0, owner: nikunjm)
    Described as "Maximum number of ServiceRouter tiers to store in the
    jumpstart profile." Searched for `ServiceRouterJumpstartWarmup` —
    zero references. The ServiceRouter warmup integration was removed
    or redesigned.

**Verification methodology:**
- Each option searched by Cfg:: variable name across hphp/runtime/,
  hphp/util/, hphp/hack/, and hphp/facebook/ using Meta code search
- Generated config headers excluded from results
- None have globaldata/unitcacheflag/hackc/compileroption tags
- Test .opts file for PGOArrayGetStress cleaned up

**Audit scope:** This is part of a comprehensive audit of all 940 runtime
options in hphp/doc/configs.specification. Every option was checked for
references in hand-written C++ code across hphp/runtime/, hphp/util/,
hphp/hack/, and hphp/facebook/ (excluding auto-generated config headers).
Options with globaldata, unitcacheflag, hackc, compileroption, or
repooptionsflag tags were preserved even without runtime C++ references,
as they serve compile-time or serialization purposes. Options used only in
hphp/facebook/ (internal extensions) were also preserved. The full audit
identified 34 dead options across 4 diffs: D98228315, D98228313,
D98228314, D98228312.
