Commit title: Fix flaky stream tests by using ephemeral port 0 binding
Commit body:
Summary:
Two stream tests fail with "Address already in use" at a 20-27%
failure rate in CI, showing up as suppressed warnings on HHVM diffs:
- test/slow/streams/addr-junk.php
- test/slow/streams/tcp-transport-is-assumed.php

Root cause: Both tests use a weak pseudo-random port selection
algorithm (microtime * 100 % 30000 + 12345) with only 20 sequential
retries and no error suppression during bind attempts. When multiple
test instances run in parallel on the same Sandcastle host, they
collide on ports. Failed bind() calls emit PHP warnings that leak
into test output, causing .expect file mismatches.

Fix: Replace the get_random_port()/retry_bind_server() pattern with
ephemeral port 0 binding. Binding to port 0 asks the OS kernel to
assign a guaranteed-available ephemeral port. The actual port is then
discovered via stream_socket_get_name(). This pattern is already used
successfully elsewhere in the test suite (e.g., ssl-socket-null-byte.php).

This eliminates:
- Port collisions between concurrent tests
- Warning output from failed bind attempts
- The need for retry loops
- The GetRandomPortStatics class
