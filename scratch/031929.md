Commit title: Migrate Rust constant value codegen to Whisker
Commit body:
Summary:
Remove Rust generator specific mstch objects that solely back const and structured annotation codegen. Migrate templates to use Whisker generator base properties where possible.

Add 3 properties to support Rust specific behavior:
- `transitive?` (on type) to check for transitive annotation types
- `union_variant` (on const value) for union const values
- `structured_elements` (on const value) overriding the base Whisker generator's `structured_elements`. The base property only returns fields that appear in the IDL const value. The Rust generator property returns all fields, with `null` values for fields not specified in the IDL const value.
