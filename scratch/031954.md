Commit title: Log warning counts by code to hh_typing_errors Scuba table
Commit body:
Summary:
Add a `warning_counts_by_code` field to the `LOG_ERROR` event in `hh_typing_errors`. This provides an untruncated count of warnings per warning code, enabling dashboards that track warning counts over time broken down by code.

The existing `data` column truncates at 1000 errors, making it impossible to get a full breakdown. The new field is a small JSON object mapping warning code to count (e.g. `{"12025": 380000, "12021": 30000}`), added alongside the existing truncated error list.
