Summary:
Replace the mstch `service:extendedClients` property with a new Whisker property `all_parent_services` on `t_service`. The new property returns a simple array of `t_service` Whisker handles walking the inheritance chain, replacing the old mstch map structure with `extendedService:packagePrefix`, `extendedService:asRefImpl`, and `extendedService:service`.

Templates use `ancestor.client_package` and `ancestor.rust_name` directly instead of context-pushing through `extendedService:service`. The `asRefImpl` logic is handled in-template using `array.enumerate` with `with_first=true`. The `rust_mstch_service` and `rust_mstch_interaction` classes are removed as they have no remaining mstch properties.
