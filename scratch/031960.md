Commit title: Add TLS 1.3 KeyUpdate test to verify MySQL server compatibility
Commit body:
Summary:
Java (JDBC) clients experienced failures when TLS 1.3 KeyUpdate was triggered
during long-running queries. This test exercises the same scenario from C++ to
determine whether the issue is MySQL-specific or JDK-specific.

Results: All 4 tests pass, proving MySQL server handles TLS 1.3 KeyUpdate
correctly:
- SSL_KEY_UPDATE_REQUESTED works (server processes KeyUpdate and responds)
- SSL_KEY_UPDATE_NOT_REQUESTED works (client-only key rotation)
- Multiple consecutive KeyUpdates work (5 rounds)
- Large results (50KB+) after KeyUpdate work

This implies that the Java/JDBC TLS 1.3 failure was JDK-specific, not MySQL-specific.

Also adds `getSSLHandle()` to `MysqlConnection` to expose the raw SSL* handle
for testing TLS-level operations.
