Commit title: Move error state and operation type to OperationBase
Commit body:
Summary:
This refactoring reduces the need for bidirectional pointers between Operation and OperationImpl classes by moving state that Impl classes need directly into OperationBase.

## Changes Made

- Move `mysql_errno_`, `mysql_error_` members from Operation to OperationBase
- Move `snapshotMysqlErrors()` and `setAsyncClientError()` to OperationBase
- Add `virtual getOperationType()` to OperationBase, implemented by all Impl subclasses
- Store operation type as constructor parameter in FetchOperationImpl and SpecialOperationImpl
- Add `kOperationType` static constant to QueryOperation, MultiQueryOperation, MultiQueryStreamOperation
- Update factory functions to pass operation type
