Commit title: Fix fullDCE accounting for non-DCEable passthroughs
Commit body:
Summary:
fullDCE tracks passthrough users of counted producers so it can kill the producer and those passthroughs together when every use is killable.

That accounting was also treating non-DCEable passthroughs such as CheckType as killable passthrough uses. Those instructions are real uses because they can side exit and cannot be removed, which can leave fullDCE trying to kill the producer while a live non-catch taken edge remains.

Only add passthroughs to rcInsts when the passthrough itself can be DCEd, and add a unit test covering a StrictlyIntegerConv feeding CheckType.
