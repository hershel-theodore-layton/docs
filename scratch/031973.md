Commit title: Throw exception on null struct field assignment
Commit body:
Summary:
Extends the null-checking behavior from D97124534 (unions) to structs.

For non-optional struct fields with nullable types (string, struct, collections, binary):
- Property setter: throws ArgumentNullException when null is assigned
- Write method: throws InvalidOperationException if the field is null at serialization time (defense in depth)

Non-nullable value types (int, bool, enum) are unaffected since C# already prevents null assignment. Optional fields remain nullable as expected.

Updated codegen templates, fixture golden files, and added unit tests covering both nullable and nonnullable field types.
