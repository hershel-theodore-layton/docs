Commit title: Modernize condition variables to std::condition_variable_any in JobQueue
Commit body:
Summary:
Replace raw pthread condition variable usage with std::condition_variable_any
in SynchronizableMulti and JobQueue. This eliminates manual pthread_cond_init/
destroy lifecycle management, replaces error-prone timespec arithmetic with
std::chrono-based wait_for(), and uses notify_one() instead of
pthread_cond_signal().

std::condition_variable_any is used (rather than std::condition_variable)
because the codebase uses a custom Mutex type rather than std::mutex.

Also moves from realtime to steady clock, avoiding weird behavior across leap
second, time synchronization, etc. events.
