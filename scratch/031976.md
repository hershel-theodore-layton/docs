Commit title: Add stack trace benchmark and test for sdata8 .eh_frame_hdr tables
Commit body:
Summary:
Add a folly::Benchmark-based benchmark and unit test that exercise stack trace capture with sdata8 .eh_frame_hdr table encodings, as produced by -mlarge-eh-encoding for large binaries.

A custom linker script (eh_sdata8_large.lds) places .eh_frame_hdr at
virtual address 0x200000000, forcing the linker to emit DW_EH_PE_sdata8
table entries. This lets us measure the performance of libunwind's
sdata8 binary search path in isolation.

## Benchmark Results

We see **300x** increase in performance. This is a spirtual similar change to D98158613 which tests it from libgcc.
