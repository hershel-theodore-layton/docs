Summary:
Address review feedback from viz on D97206013 and D97124534:

1. Extract ThriftNullGuard runtime helper — centralizes the null-check pattern into shared static methods (ThrowIfNull / ThrowIfNullUnion), reducing generated code size from 7 lines to 1 line per nullable field setter.

2. Remove redundant serialization-time null checks — the write-time null checks in write_field.mustache (structs) and union.mustache (unions) are unnecessary since property setters already throw ArgumentNullException on null assignment. Constructors also initialize nullable fields to non-null defaults.

3. Update error message wording — the serialization checks used 'required' which could confuse with the deprecated Thrift 'required' qualifier. Now uses 'non-nullable' per viz's suggestion.
