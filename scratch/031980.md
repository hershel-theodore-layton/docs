Commit body:
Summary:
Implement full thrift exception support for C# codegen, addressing review
feedback from D96560184 (viz: "Why exclude exceptions here?").

- Remove special-case exception property path in struct.mustache: exceptions
  now route through struct_properties like structs, getting the same
  null-checking behavior from D97206013
- Add Exception.Message override for thrift.ExceptionMessage annotation,
  following the same whisker pattern as C++ (what()) and Python (__str__())
- Change serialization null-checks from InvalidOperationException to
  ThriftProtocolException for consistency with the rest of the C# thrift
  library and other languages' TProtocolException
- Remove dead is_message? property and new keyword (C# is case-sensitive,
  message does not shadow Message)
- Fix error messages from "Struct field" to "Field" since templates are now
  shared between structs and exceptions
- Add C# output to the exceptions test fixture covering all edge cases:
  Fiery (transient server + required + ExceptionMessage), Serious (optional
  ExceptionMessage), ComplexFieldNames, ExceptionWithPrimitiveField (field
  named message), Banal (no fields)
- Add GeneratedExceptionsTests.cs with 8 tests for Message override,
  polymorphic catch, null-checking, and no-annotation default behavior
