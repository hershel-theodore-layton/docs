Commit title: Eliminate variable shadowing in StructWrite
Commit body:
Summary:
Use `_iter` variable for adapted field values in StructWrite.mustache, preventing
the local adapter variable from shadowing the instance field name.

Changes:
- Adapter/wrapper fields: declare adapted value as `_iter{{field:nestedDepth}}`
  instead of `{{field:javaName}}`, eliminating shadowing of `this.fieldName`
- Use `this.` prefix consistently for all instance field references
- All `_iter` declarations are inside `{ }` scoping blocks to prevent
  duplicate variable conflicts across fields
- Split adapter vs non-adapter paths in all branches (nullable/terse,
  nullable/non-terse, non-nullable/terse, non-nullable/non-terse)

This prepares for removing `field:isNested?` / `field:setIsNested` in a follow-up
diff, since all call sites now assign field values to `_iter` variables that
WriteType can consume uniformly.
