Commit title: Remove kyber support from fizz
Commit body:
Summary:
Remove kyber key exchange support from the fizz TLS library while retaining kyber NamedGroup enum values and toString() for logging/observability.

ML-KEM (X25519MLKEM768, X25519MLKEM512_FB, MLKEM512, MLKEM768) is the NIST standardized replacement and all ML-KEM support is retained.

The kyber NamedGroup enum values and their toString() mappings in Types.h/Types.cpp are intentionally preserved because deployed mobile clients still offer these groups in TLS ClientHello (confirmed via proxygen_fizz scuba table: https://fburl.com/scuba/proxygen_fizz/k6cddp7c). Once all clients stops offering these groups, these enum values and toString() cases can be cleaned up.

Updated the tests to use ML-KEM key exchange algo wherever Kyber was used.
