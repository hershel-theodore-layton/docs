Commit body:
Summary:
Extend the Hack OCaml linter (code 5656) to flag `::class` references from files with `__PackageOverride` to files without matching overrides.

Previously, files with `__PackageOverride` were completely skipped by this linter. This meant a file in `flib/intern` with `__PackageOverride('prod')` could reference an intern class without override with no lint error. Modified the linter to only skip when both source and target have `PackageOverride` to the same package (effectively putting them in the same package). Otherwise, the lint fires to catch cross-boundary `::class` references.
