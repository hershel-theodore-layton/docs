Commit title: Reject unstructured annotations at parse time
Commit body:
Summary:
The parser now rejects all unstructured annotations `(key = "value")` at
parse time, except `hs.*` annotations which are silently dropped (dead
Haskell backend). Non-hs annotations produce a parser error:
"Unstructured annotation `X` is not allowed. Use a structured annotation
instead."

Annotations are consumed but not stored in the AST: the parser parses
the full `(key = value, ...)` syntax for error recovery, but returns
null. This means sema-phase validators for deprecated/removed
annotations are now mostly dead code for `origin::unstructured`
annotations, since they can no longer reach sema.

Also removes the `forbid_unstructured_annotations` sema parameter and
makes the `--extra-validation unstructured_annotations` and
`allow_unstructured_annotations` flags no-ops, since unstructured
annotations are now always rejected at parse time.
