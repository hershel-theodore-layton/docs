Summary:
Add field-aware template partials and properties so the Python generator can check field-level `cpp.Type` annotations directly. This unblocks removing the sema lowering that propagates `cpp.Type` from fields to type nodes (D97165387).

**C++ changes:**
- Added `field.type_is_iobuf?` property that checks both type-level and field-level `cpp.Type`.
- Added `is_type_iobuf(const t_field&)` overload to `python/util.h`.

**Template changes:**
- Added `field_typeinfo` and `field_pep484_type` wrapper partials that check `field.type_is_iobuf?` before delegating to the type-level partial.
- Updated all call sites that render field types to use field-aware partials.

Output-preserving: all fixture outputs are identical before and after.
