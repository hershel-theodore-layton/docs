Summary:
Trivial refactoring:

Currently, `MonitorMain` defines

```
let rec check_and_run_loop = ...
and check_and_run_loop_ = ...
```
(the function names differ by the trailing `_`).

But these two functions are not mutually recursive!
- `check_and_run_loop` calls itself and `check_and_run_loop_`
- `check_and_run_loop_` doesn't call itself or`check_and_run_loop`

This diff makes all of this clearer by making `check_and_run_loop_` non-rec and moving it before `check_and_run_loop` .
