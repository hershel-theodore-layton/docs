Commit title: Allow named arguments without file-level attribute
Commit body:
Summary:
## What

All named parameter *usage* everywhere.
This was previously gated behind a file-level attribute.

We do not make any change to the file-level attribute that gates *defining* a function with named parameters–that attribute is still required.

## Why

- Gating is controlled via the `named_parameters` file-level attribute, which we are keepign around.
- Ergonomics is a key motivation of the feature, but file-level attributes add friction.
- The attribute no longer serves any purpose–it was for an earlier phase of the project where we wanted 0 named arguments in WWW out of concern that they would be handled correctly.
