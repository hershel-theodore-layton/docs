Commit title: Fix hashCode for binary fields with javaType override
Commit body:
Summary:
D98699662 introduced type-specific hashCode computation for generated Java
structs but used Arrays.hashCode() for all binary fields without adapters.
When a binary field has a javaType override (e.g. ByteBuffer), Arrays.hashCode()
fails because ByteBuffer is not an array type.

Fix: mirror the pattern from StructEquals.mustache — check type:javaType and
use Objects.hashCode() when a custom Java type is set.
