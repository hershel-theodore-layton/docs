Commit title: Add `from_inner_value` to ThriftEnum trait and use it in ligen
Commit body:
Summary:
D97095094 allows thrift enums to use representations other than i32
(e.g. u8 via `rust.EnumType`). This diff extends the `ThriftEnum` trait
with `from_inner_value` so that enum construction goes through a
validated conversion path instead of a bare `From<i32>`.

The ligen rs_py bridge is updated to use the `ThriftEnum` trait
(`inner_value` / `from_inner_value`) instead of `Into<i32>` / `From<i32>`,
so we rely on the thrift-generated trait impl rather than inventing our
own conversion logic.
