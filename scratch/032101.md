Commit body:
Summary:
Migrate all internal consumers of `op::get_name_v` and `op::get_class_name_v`
to the new SIOF-safe `op::get_name<T, Id>()` and `op::get_class_name<T>()`
function templates introduced in the previous diff.

This fixes a crash (SEGV/null-deref) that is currently breaking
`cogwheel_ards_adranker_asan_test` in ServiceLab. The crash occurs during
static initialization where `get_name_v` may not yet be dynamically
initialized when accessed by `SimpleJSONProtocolWriter::writeFieldBegin`
via the folly settings registration path. See P2257849800 for the crash log.

The old `&*op::get_name_v<T, Id>.begin()` idiom is replaced with the
cleaner `op::get_name<T, Id>().data()` which is both SIOF-safe and
more readable.

Files changed:
- Encode.h: writeStructBegin/writeFieldBegin in StructEncode
- StructOp.h: put/get/next/ensure field name lookups
- StructPatch.h: writeStructBegin/writeFieldBegin in StructPatch::encode
