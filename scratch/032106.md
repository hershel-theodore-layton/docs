Commit title: Use getWriteHeaders() instead of releaseWriteHeaders() in generated client code
Commit body:
Summary:
The C++ codegen template calls rpcOptions->releaseWriteHeaders() which
destructively moves headers out of RpcOptions. When a client reuses the
same RpcOptions across retry attempts (e.g. via retryWithExponentialBackoff),
the first co_read() consumes headers and retries send empty headers.

Changed to getWriteHeaders() (non-destructive copy) so that RpcOptions
retains headers across calls.
