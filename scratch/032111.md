Commit body:
Summary:
Fix fbthrift-python OSS build (getdeps) on CentOS Stream 9 with Python 3.12,
Cython 3.2.4, GCC 12 (gcc-toolset-12). Also add a generic CMake module
(FBThriftPythonLibrary.cmake) for any project migrating from
thrift-py-deprecated to thrift-python.

Build fixes (xplat/thrift/lib/python/CMakeLists.txt + setup.py + manifests):
1. Add EVENT__LIBRARY_TYPE=STATIC to libevent-python manifest
2. Add lib64 search paths for folly .pxd files (CentOS/RHEL/Fedora)
3. unset(_folly_pxd_file CACHE) to prevent stale CMake cache
4. Add __PYX_ENUM_CLASS_DECL= define (cython/cython#5973)
5. Add CWD to Cython include path in setup.py

CMake module (opensource/fbcode_builder/CMake/FBThriftPythonLibrary.cmake):
Generic, project-agnostic module with three components:
- fb_find_thrift_python_runtime(): discovers thrift-python and folly-python
  site-packages at configure time; auto-installs fbthrift-python wheel from
  getdeps build output if not pip-installed
- add_fbthrift_python_library(): generates thrift_types.py via mstch_python
  generator; drops FBThrift::thrift_py from DEPENDS (C extensions resolved
  at runtime)
- add_fb_thrift_python_executable(): drop-in for add_fb_python_executable();
  forces TYPE dir (C extensions cannot load from zip) + post-build symlinks
  thrift/python/ and folly/ into bundled output directory
