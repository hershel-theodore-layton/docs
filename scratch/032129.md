Commit title: Add heartbeat logging to see which file is being currently type checked
Commit body:
Summary: Add a configurable heartbeat logging to the type checker that logs when a worker is busy type checking a file. The timer repeats every `heartbeat_interval` seconds, logging cumulative elapsed time ("Still checking foo.php after 10s", "...after 20s", etc.) until the file finishes, at which point the timer is cancelled. Files that complete quickly produce no log output. When `heartbeat_interval` is not set the logging is disabled.
