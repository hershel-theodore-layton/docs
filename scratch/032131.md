Commit title: Skip is/as/coalesce warnings when lhs type contains Tany
Commit body:
Summary:
Tany indicates missing type information (e.g. unresolved generics) and
makes subtype checks unreliable since Tany <: T for all T. The existing
nothing guard catches bare Tany (since Tany <: nothing) but not ?Tany
or supportdyn<Tany>, since null is not <: nothing.

This adds a has_tany check alongside the nothing guard so these
Tany-containing types are also skipped, avoiding false positive
warnings.
