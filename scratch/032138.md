Store Executor::KeepAlive<> instead of raw Executor* in PyBufferData.
The KeepAlive token prevents the executor from being destroyed while
IOBufs still reference it. Use std::move(executor).add() to move the
token into the scheduled Py_DECREF task, ensuring the executor stays
alive until the task actually runs.

Changes:
- iobuf_ext.cpp:25: Executor* → Executor::KeepAlive<>
- iobuf_ext.cpp:38: direct assign → getKeepAliveToken(executor)
- iobuf_ext.cpp:55: executor->add() → std::move(executor).add()

No API change. No caller changes. The function signature stays Executor*
and the conversion to KeepAlive happens internally.
