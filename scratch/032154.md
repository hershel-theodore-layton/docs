Commit title: Clean up t_placeholder_typedef references in Hack and JSON generators
Commit body:
Summary:
`t_placeholder_typedef` is deprecated, and cannot be exposed past `sema::run` after the "legacy AST" option was removed in D100101133.

`parse_ast` calls `sema::run`, which resolves all type references (replacing all `t_placeholder_typedef`) and triggers an error if any types weren't resolvable:
https://www.internalfb.com/code/fbsource/[27b5d28b6791318ca56a77ee575864a27506c3b7]/xplat/thrift/compiler/parse/parse_ast.cc?lines=1159

Generators are never invoked if the AST fails sema validation, and therefore any casts to `t_placeholder_typedef` will always return false.
