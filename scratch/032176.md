Commit title: Simplify union types involving dynamic and supportdyn<mixed>
Commit body:
Summary:
When constructing like types (~T), dynamic was not absorbed into types
that already subsume it (e.g., supportdyn<mixed>, ?supportdyn<mixed>,
mixed). Similarly, ?supportdyn<mixed> was not simplified to
supportdyn<mixed> even though null <: supportdyn<mixed>.

This diff adds:
- A syntactic `is_locl_supertype_of_dynamic` check in `locl_like`
  (typing_make_type.ml) to avoid creating redundant `dynamic | T` unions
  when T already subsumes dynamic.
- A `supportdyn` case in `null_is_subtype_of` in `typing_phase.ml` so
  that `?supportdyn<mixed>` simplifies to `supportdyn<mixed>` during
  localization.
