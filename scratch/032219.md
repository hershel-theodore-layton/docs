Commit title: Fix `#if DEBUG` preprocessor guards in `HQUpstreamSession.cpp`
Commit body:
Summary:
**Context**
In the ARVR toolchain we use `-Wundef` with `-Werror`. This causes a compilation error if a preprocessor definition is used without being defined (rather than evaluating to zero).

In proxygen, `DEBUG` is only defined in the debug mode but is used like `#if DEBUG`, causing a build failure in these modes:

https://www.internalfb.com/code/fbsource/[a69d943f3839]/fbcode/proxygen/facebook/httpclient/BUILD_MODE.bzl?lines=36-40

**Changes**
Replace `#if DEBUG` with `#if defined(DEBUG)` at two locations in `HQUpstreamSession.cpp`: the push stream postcondition check (~line 177) and the `HQSession::HQStreamTransportBase::onPushPromiseHeadersComplete` dynamic_cast guard (~line 347).
