Commit title: Split thrift serialization from runtime
Commit body:
Summary:
Move the pure Java thrift serialization surface out of
	`//thrift/lib/java/runtime` into a new
	`//thrift/lib/java/serialization` target so bootstrap consumers do not pull in
	runtime-native deps.

This moves the serialization helpers and their tests, removes
	`SerializerUtil` allocator dependency on `RpcResources`, exports the new
	library from `runtime`, and updates Kotlin CD logger codegen/consumers to use
	split `*-java-swift-data-type` targets plus `serialization` instead of the
	runtime-bearing java-swift umbrella target.
