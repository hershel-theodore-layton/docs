Summary:
Implements ZlibCompressor using JDK Deflater/Inflater:

- Base (Java 8): byte[] I/O with `ByteBufUtil.getBytes()` / chunked deflate
- Java 11 multi-release: zero-copy ByteBuffer I/O via `data.nioBuffer()`,
  `deflater.setInput(ByteBuffer)` + `deflater.deflate(ByteBuffer)` writing
  directly into the output ByteBuf's backing memory
- Thread-local Deflater/Inflater on Netty event loop threads
  (`FastThreadLocalThread`) to avoid native resource allocation per request;
  `reset()` between uses, `end()` on non-event-loop threads
