Commit body:
Summary:
Replaces the zstd-jni (JNI) path on Java 25+ with direct Foreign Function
& Memory API calls to native libzstd. Zero-copy for direct Netty ByteBufs
via MemorySegment.ofAddress(memoryAddress()). Thread-local ZSTD_CCtx and
ZSTD_DCtx cached on Netty event loop threads via FastThreadLocal, matching
the zstd recommendation to allocate contexts once and reuse per-thread.

Range checks: compressBound overflow, createCCtx/createDCtx NULL checks
to prevent JVM segfaults from native memory allocation failures.
