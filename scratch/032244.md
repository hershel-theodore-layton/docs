Commit title: Delete add_magic_annotations, move URI checks to consumers
Commit body:
Summary:
scope.thrift can't use structured annotations for circular dependency reasons. Previously we injected fake unstructured annotations (hack.name, js.name, py3.hidden) onto scope annotation structs during sema. Instead, have each consumer check for the special URIs directly:
- t_hack_generator: find_hack_name checks Function/Const/Interface URIs
- t_mstch_py3_generator: is_hidden checks Enum URI
- JsTypeHelper: getJsNameForNamedType checks Function URI

Generators that emit unstructured annotations (JSON, py, py3) now filter out magic annotations from scope annotation types so they don't appear in generated output.
