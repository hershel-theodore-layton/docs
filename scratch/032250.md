Commit body:
Summary:
Reduce code duplication between MysqlFetchOperationImpl and ThriftFetchOperationImpl by extracting shared logic into helper methods in the base FetchOperationImpl class.

Added three new helpers:
- `renderQuery()` - Renders query with prefix callback, handles parsing errors
- `setupQueryAttributes()` - Sets query attributes and checksum on connection
- `logQueryCompletion()` - Logs query success/failure and notifies callbacks

Both MySQL and Thrift impls now use these helpers, reducing ~75 lines of near-identical code while maintaining protocol-specific behavior where needed.

Also removed now-unused `kQueryChecksumKey` constants from both MysqlFetchOperationImpl.cpp and ThriftFetchOperationImpl.cpp (the constant is now defined locally in the shared `setupQueryAttributes()` helper).
