Commit title: Expose noIndexUsed() in QueryResult
Commit body:
Summary:
The noIndexUsed() flag was already tracked by FetchOperation (via the MySQL server status flag SERVER_QUERY_NO_INDEX_USED) but was not plumbed into QueryResult/DbResult, making it inaccessible to higher-level consumers.

Add noIndexUsed()/setNoIndexUsed() to QueryResult (following the existing wasSlow() pattern) and propagate it from FetchOperation in both QueryOperation and MultiQueryOperation.

This allows services to detect queries that performed full table scans without using an index, enabling easier tracking of missing indices.
