Commit title: Add mock interfaces for unit testing without MySQL server
Commit body:
Summary:
Add mock implementations of Squangle's InternalConnection, InternalResult, InternalRow, and InternalRowMetadata interfaces for unit testing without requiring a real MySQL server.

This enables testing Squangle's Operation classes, state machines, and business logic in isolation. The mocks support:
- Configurable query results with expected rows and metadata
- Error injection for testing error handling paths
- Async behavior simulation via PENDING status
- Query attribute verification

Files added:
- MockInternalRow.h - Mock row data access with variant-based storage
- MockInternalRowMetadata.h - Mock field metadata
- MockInternalResult.h - Mock result set iteration with sync/async variants
- MockInternalConnection.h - Mock connection with query result injection
- MockConnection.h - MockConnection and MockMysqlClient integration
- MockTest.cpp - 18 unit tests for mock interfaces
- MockConnectionTest.cpp - 18 integration tests
- README.md - Documentation with usage patterns
- BUCK - Build configuration
