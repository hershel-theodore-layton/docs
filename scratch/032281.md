Commit title: Emit isClosure in FunctionDefinition for closures
Commit body:
Summary:
Fills in the `isClosure` field added to `hack.FunctionDefinition` in D100807611. Regular functions emit `isClosure = false`, closures emit `isClosure = true`.

This enables the `NonClosureDeclaration` and `FileNonClosureDeclarations` derived predicates to filter out closure FunctionDeclarations, which is needed by the dead code bot to avoid treating closures as dead code candidates.

Changes:
- `glean/hack.ml`: Added `is_closure: bool` field to `FunctionDefinition.key` type and `to_json_key` serializer (emits `"isClosure"`)
- `add_fact.ml`: `func_defn` emits `is_closure = false`, `closure_defn` emits `is_closure = true`
- Regenerated 3 test `.out` files: `closures/function_def.out`, `declarations/function_def.out`, `context_lists/function_definition.out`
