Commit title: Remove unsupported options from complete_hh.conf
Commit body:
Summary:
Remove configuration options from the complete_hh.conf test file that are no longer recognized by the Hack typechecker. These options are not registered in `config_keys.ml` and would trigger "Unrecognized hh.conf config option" warnings at runtime.

**Removed options (no longer in `Config_keys.Hhconf`):**

- `experiments_config_meta`: This is not a config file key. The corresponding field in `ServerLocalConfig.t` is populated internally by the experiments config loading logic in `serverLocalConfigLoad.ml`, not read from the config file.

- `fanout_strip_class_location`: Entirely removed from the codebase. No references exist in any config parsing code.

- `state_loader_timeout_current_base_rev_timeout`, `state_loader_timeout_current_hg_rev`, `state_loader_timeout_find_nearest_state`, `state_loader_timeout_package_fetch`: The state loader timeout feature has been removed. These keys are not registered in `config_keys.ml` and not parsed by any OCaml or Rust code.

- `remote_type_check_enabled`, `remote_type_check_num_workers`, `remote_type_check_recheck_threshold`, `remote_type_check_max_batch_size`, `remote_type_check_remote_initial_payload_ratio`: The remote type checking feature has been removed. These keys are not registered in `config_keys.ml`.

- `recheck_capture_enabled`, `recheck_capture_error_threshold`, `recheck_capture_fanout_threshold`, `recheck_capture_rechecked_files_threshold`, `recheck_capture_sample_threshold`: The recheck capture feature has been entirely removed from the codebase. Zero references exist in `fbcode/hphp/hack/src`.

**Fixed option name:**

- `sharedmem_dirs` renamed to `shm_dirs`: The key `sharedmem_dirs` is registered in `Config_keys.Hhconfig` (for .hhconfig files), but the hh.conf equivalent is `shm_dirs` (registered in `Config_keys.Hhconf`). The test file is an hh.conf, so it must use `shm_dirs`.
