Commit title: Populate thrift Python registry markers with compiler-generated URIs
Commit body:
Summary:
Enable URI-to-module lookup in the Thrift Python omni registry without importing every module at runtime.

Previously, registry marker files were empty placeholders created by a genrule that simply `touch`ed the output. Now the Thrift compiler emits a `thrift_uris.txt` file (one URI per line) for each Python thrift_library, and the Buck build rule wires that compiler output into the marker file resource instead of the empty genrule.
