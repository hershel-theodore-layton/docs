Convert all 6 remaining fbcode_target invocations to fb_dirsync_*:

- baton_benchmark: fbcode_target(cpp_benchmark) -> fb_dirsync_cpp_benchmark
- baton_test: fbcode_target(cpp_unittest) -> fb_dirsync_cpp_unittest
- distributed_mutex_test: fbcode_target(cpp_unittest) -> fb_dirsync_cpp_unittest
- hazptr_test: fbcode_target(cpp_unittest) -> fb_dirsync_cpp_unittest
- lifo_sem_test: fbcode_target(cpp_unittest) -> fb_dirsync_cpp_unittest
  (allocator=jemalloc_debug is unused in xplat wrapper)
- saturating_semaphore_test: fbcode_target(cpp_unittest) -> fb_dirsync_cpp_unittest

All share //folly/test:deterministic_schedule dep which is already a
fb_dirsync_cpp_library (xplat/folly/test:True in remap set).

hazptr_test required a source fix in HazptrTest.cpp: tc_miss_bench() and its
call site were not guarded by #if FOLLY_HAZPTR_THR_LOCAL. In xplat builds,
FOLLY_MOBILE=1 is set via cpp_flags() in defs.bzl, which causes
FOLLY_HAZPTR_THR_LOCAL=false (defined in Hazptr-fwd.h). This makes
hazptr_tc_evict() undefined at link time. Fixed by adding #if guards around
the tc_miss_bench function and its call in benches().
