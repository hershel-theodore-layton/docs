## Context
The high-level goal of this stack of diffs is to improve the performance of the GenAI tenant by leveraging Service Router (SR) cache warm-up.

The diffs aim to achieve this by:

1. Allowing WWW to handle both the old and new APC (Alternative PHP Cache) values, facilitating a smoother transition to the new `extension_warmup_data` (Diff D92662455).
2. Generalizing the extension jumpstart mechanism to support SR warm-up, initially focusing on `vec<string>` but leaving room for future extensions (Diff D92629644).
3. Introducing a configuration variable (`configs.specification`) to specifically enable SR warm-up for the GenAI tenant in HHVM (Diff D92748486).

These changes collectively contribute to the broader project outlined in the linked document, "Speeding up GenAI Tenant with SR cache warm-up," aiming to enhance the performance and efficiency of the GenAI tenant through targeted caching and warm-up optimizations.

The diff consists of four main parts:

1. **New test file:** A new test file `jumpstart_warmup.php` is added to test the new feature. This file contains test cases to verify that the `Serialize` function correctly extracts SR tiers.
2. **Expected output file:** A new file `jumpstart_warmup.php.expectf` is added to store the expected output of the test cases.
3. **modified extension file:** The `ext_servicerouter.cpp` file is modified to include the new feature. This file now uses the `folly::Synchronized` and `folly::F14Set` classes to keep track of the SR tiers.
4. **Options file:** A new file `jumpstart_warmup.php.opts` is added to specify the options for the test run.
