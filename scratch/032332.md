Commit body:
Summary:
`folly/ConstexprMath.h` uses `std::numeric_limits<T>::infinity()` and
`quiet_NaN()` in four `constexpr` math functions (`constexpr_mult`,
`constexpr_exp`, `constexpr_log`, `constexpr_pow`) for IEEE 754 edge case
handling. These trigger `-Wnan-infinity-disabled` under `-ffinite-math-only`.

Guard all `NaN` / `infinity` edge-case handling with `#if !__FINITE_MATH_ONLY__`
preprocessor conditionals. When `-ffinite-math-only` is enabled, the
compiler already assumes no `NaN` or `infinity` values exist, so these code
paths are unreachable and can be safely skipped. For cases where a
finite fallback is needed (overflow bounds in `constexpr_exp`), use
`std::numeric_limits<T>::max()` as the alternative.
