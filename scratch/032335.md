Commit title: Generate proper classes for container typedefs to enable isinstance/issubclass (w/ compatibility logic)
Commit body:
Summary:
This is a reland of D99492659 with added compatibility logic for users who don't use the BUCK build system and may have older thrift runtimes where `thrift.python.container_typedefs` is not available.

Changes how container typedefs (lists, sets, maps) are generated in thrift-python. Instead of generating factory callable assignments like `I32List = ListTypeFactory(typeinfo_i32)`, the compiler now generates proper Python classes that extend `thrift.python.types.List` (and `Set`/`Map`).

This enables `isinstance` and `issubclass` checks on container typedefs:
- `isinstance(IntList([1,2]), IdList)` returns True when both resolve to `list<i32>`
- `issubclass(IntList, IdList)` returns True (and vice versa)
- `issubclass(IntList, thrift.python.types.List)` returns True
- `isinstance(easy().val_list, IdList)` returns True for struct fields
- Different element types correctly return False
- ABC registration is preserved: typedef instances are still `isinstance` of `collections.abc.Sequence`, `Set`, and `Mapping`

Custom metaclasses (`_ListTypedefMeta`, `_SetTypedefMeta`, `_MapTypedefMeta`) override `__instancecheck__` and `__subclasscheck__` to enable cross-typedef type checks based on element type equivalence via TypeInfo's `same_as()`.

This applies only to immutable types; mutable types continue using `MutableListTypeFactory` etc.

**Compatibility logic (new in this version):** The generated `thrift_types.py` now wraps the `import thrift.python.container_typedefs` in a `try/except ImportError` block. If the module is unavailable, `_fbthrift_python_container_typedefs` is set to `None`. Each container typedef then checks whether the module is available: if so, it generates the new class-based typedef; otherwise, it falls back to the old `ListTypeFactory`/`SetTypeFactory`/`MapTypeFactory` behavior from the parent commit. This ensures graceful degradation for users with older thrift runtimes. The `try/except` import is only emitted when the thrift module defines at least one typedef (`program.typedefs?`).
