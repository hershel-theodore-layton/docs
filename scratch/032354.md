Commit title: Drop stream on write failure instead of keeping it active
Commit body:
Summary:
RocketServerStreamStateHandler was re-adding streams to activeStreams_ when
a complete write failed (Result::Error), intending to allow the app to retry.
However the connection should fail and close on a write failure, and there is no retry — so today the stream ends up becoming orphaned and
bloats the active stream map until the connection closes.

This matches rocket's behavior where write failures are fatal with no retry.
