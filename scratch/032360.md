Commit title: IoUringOptions: change size_t fields to uint32_t
Commit body:
Summary:
The io_uring kernel ABI uses __u32 for ring sizes, entry counts, and file
counts. IORING_MAX_ENTRIES=32768, IORING_MAX_CQ_ENTRIES=65536,
IORING_MAX_FIXED_FILES=1M — all bounded well within 32 bits.

Change IoUringOptions fields from size_t to uint32_t to match the kernel
ABI types they flow into: capacity, minCapacity, maxSubmit, maxGet,
registeredFds, sqGroupNumThreads, initialProvidedBuffersCount,
initialProvidedBuffersEachSize, providedBufRings, zcRxBufferSizeHint.

Change sqeSize from ssize_t to int32_t (uses -1 sentinel, max
IORING_MAX_ENTRIES=32768).

Update all setter parameter types to match.
