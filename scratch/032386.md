Replace the loop that counts the number of bits needed to represent m with a single __builtin_clz intrinsic. This compiles to a single BSR/LZCNT instruction on x86 and CLZ on ARM. Applied directly to furc_hash (not a v2 copy) since it computes the same value as the loop — output is identical by construction.

The loop finds the smallest d such that m <= 2^d, i.e. d = ceil(log2(m)):
```
for (d = 0; m > (1ul << d); d++) { ; }
```

The replacement computes the same value using leading-zero count:
```
d = 32u - (uint32_t)__builtin_clz(m - 1u);
```

__builtin_clz(x) returns the number of leading zeros in the 32-bit representation of x, so 32 - __builtin_clz(x) = floor(log2(x)) + 1. Applied to m - 1: floor(log2(m - 1)) + 1 = ceil(log2(m)).

Examples:
- m = 100: loop yields d = 7 (2^7 = 128 >= 100). clz(99) = 25, so 32 - 25 = 7. ✓
- m = 1000: loop yields d = 10 (2^10 = 1024 >= 1000). clz(999) = 22, so 32 - 22 = 10. ✓
- m = 128 (power of 2): loop yields d = 7 (2^7 = 128 >= 128). clz(127) = 25, so 32 - 25 = 7. ✓

Note: furc_hash returns 0 early when m <= 1, so m >= 2 when we reach this line, meaning m - 1 >= 1 and __builtin_clz is well-defined.
