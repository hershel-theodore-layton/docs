Commit title: Error on invalid type for non-refining `is`
Commit body:
Summary:
When typechecking `is` expressions, if no refinement was needed (LHS of `is` is not refinable or `is` expression not in a refining position) then we never localized the RHS type. This meant that we never validated that the RHS is actually a valid type.

This diff changes typing to always localizes the RHS for the purpose of producing an error.
