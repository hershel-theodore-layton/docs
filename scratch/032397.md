Summary:
Currently if `binary` is a valid utf-8 string, we encode as utf-8 directly (otherwise we encode as base64).

However, this generates the following data

```
      "data": {
        "utf-8": "\u0018\u0015ip_service_management\u001c\u0015\u0002\u0000<\u0011\u0000B\u0015\u0000\u0000"
      }
```

The intention is that we using utf-8 encoding only if the data is printable. This diff changed the code to match the intention.
