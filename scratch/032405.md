Commit title: fbcode_builder: build extra-cmake-defines from a dict in getdeps.py
Commit body:
Summary:
The previous code hardcoded a single sccache `--extra-cmake-defines`
string. Adding any second define meant either appending another raw
JSON-in-a-shell-quoted-blob fragment or open-coding the merge logic
again per call site.

Move to a `dict[str, str]` accumulator that is serialized once with
`json.dumps`, then formatted into the single `--extra-cmake-defines`
shell argument. New defines just call `extra_cmake_defines[key] = value`
and the CLI string is built once per workflow. The generated YAML is
identical to the previous output when only sccache is in play, so this
is a refactor with no behavior change.
