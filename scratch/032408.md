Commit title: Switch sdata8 test to reverse relaxation and add .eh_frame CIE verification
Commit body:
Summary:
Switch the StackTraceLargeTest from relying on `-large-eh-encoding` to using lld's reverse relaxation (`--enable-reverse-relax`, D95576043) for producing sdata8 `.eh_frame` encodings automatically.

The linker script now places `.eh_frame` (not just `.eh_frame_hdr`) at 8 GiB, causing PC-relative relocations to overflow 32 bits. This triggers lld's reverse relaxation to expand sdata4 -> sdata8 encodings.

To validate, we augment the test suite for Flly with  `EhFrameCieSdata8` test that mmaps `/proc/self/exe`,
parses every CIE record in `.eh_frame`, and asserts that the FDE pointer encoding (the 'R' augmentation) uses sdata8 (low nibble 0x0c).

This gives a direct binary-level check that reverse relaxation actually widened the
encodings, complementing the existing runtime stack-trace test.
