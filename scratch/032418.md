Commit title: Move GetRefUtil from admarket to folly
Commit body:
Summary:
Move `getRefOrDefault` utility and `IsOptionalLike` concept from `admarket/lib/util/` to `folly/`. This utility avoids unnecessary copies when accessing optional/nullable values by returning a `const&` to either the contained value or a static default, solving the `value_or({})` anti-pattern.

Changes:
- Created `folly/GetRefUtil.h` with `folly::IsOptionalLike` concept and two `getRefOrDefault` overloads (pointer and optional-like)
- Added full test coverage in `folly/test/GetRefUtilTest.cpp` (16 tests)
- Converted `admarket/lib/util/GetRefUtil.h` into a forwarding header with namespace aliases to preserve all 55 existing callsites
- Renamed `IsThriftOptional` to `IsOptionalLike` (the concept is generic, not Thrift-specific)
- Made the concept SFINAE-friendly and added value-initialization for scalar types
