Commit body:
Summary:
Introduce two new syntactic constructs `class C = D;` and `interface I = D;` in the Hack parser:
- class and interface names can be applied to generics eg. `class C<T1,T2> = D<T1,T2>`;
- class/interface aliases cannot be preceded by modifiers or attributes;
- trait aliases are not supported.

This diff only updates the Hack parser; the new feature is gated as experimental/unstable in the next diff.
