Commit title: Mark t_primitive_type copy constructor as deleted
Commit body:
Summary:
`t_primitive_type` is intended to be non-copyable. Avoid usage of implicit copy constructor by using const references to the singleton instances. Unblocks deletion of the copy constructor.

After D98226584, we reject unstructured annotations at parsing time, so primitive type copies/instances for carrying unstructured annotations are now a non-factor.

The only way unstructured annotations are now supported are via using the `thrift.DeprecatedUnvalidatedAnnotations` structured annotation in IDL, which the compiler then lowers to `unstructured_annotations` internally (for downstream code which consumes unstructured annotations).

Since structured annotations can't be applied to primitive types, the only way to have an annotated primitive type now is to create an annotated typedef which resolves to the underlying primitive.
