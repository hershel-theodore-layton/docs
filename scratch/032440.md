Commit title: Fix correct_field_set for empty thrift unions in __sleep
Commit body:
Summary:
In ThriftUnionSerializationTrait::getFieldInfo(), the correct_field_set flag was always false for empty unions because _EMPTY_ (value 0) is never present in the set of SPEC field IDs. This caused the __sleep logging to report an incorrect field set even when the union state was valid (type is _EMPTY_ and no fields are set).

This change adds a check so that correct_field_set returns true when _type is _EMPTY_ (0) and no fields are set, which is a valid and consistent union state.
