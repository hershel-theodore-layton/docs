Commit title: Thread runtime environment E through areEqual, isStableLessThan, isRecordStableLessThan
Commit body:
Summary:
The `anyUnpack` operation was updated to require both a type system `S` and a runtime environment `E` (i.e., `anyUnpack_{S, E}`), but `areEqual`, `isStableLessThan`, and `isRecordStableLessThan` were not updated to include `E` in their environments or to pass it through to `anyUnpack` calls. This creates an inconsistency where these operations cannot obtain `E` when calling `anyUnpack` for `Any`-kind values.

This diff threads the runtime environment `E` through all three operations:
- `areEqual_{S}` -> `areEqual_{S, E}`
- `isStableLessThan_{S}` -> `isStableLessThan_{S, E}`
- `isRecordStableLessThan` -> `isRecordStableLessThan_{S, E}`
- All `anyUnpack` references updated to `anyUnpack_{S, E}`

Both the public (`object-model/index.md`) and draft (`object-model-draft/index.md`) files are updated.
