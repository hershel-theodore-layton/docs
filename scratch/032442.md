Commit title: Fix crash due to inlined usage of GenericRetDecRefs
Commit body:
Summary:
GenericRetDecRefs frees all locals between rvmfp() and the last local. Because
of this, it doesn't work with inlined frames, as rvmfp() points to the
outermost frame.

Just use regular DecRefs instead.

Also, while looking at this with paulbiss, we noticed a huge number of emitted
StLocs of Uninits -- every single local was set to Uninit. There is no point
trying to DecRef Uninits. We did that only because the number of locals in the
function (41) was exceeding HHIR.InliningMaxReturnLocals (40). There's no point
having this limit, what matters is the number of actual locals to be freed. It
is expected that this number is 0 at these positions, since these locals are
obviously unused at tail awaits and RetCs and hhbbc should have unset them.

So kill this pointless limit.
