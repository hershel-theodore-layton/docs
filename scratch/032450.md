Commit title: Check if address is jitted by ROAR when symbolizing
Commit body:
Summary: Folly's check whether an address is jitted relies on the same address being mapped executable in the underlying object file. This assumption does no longer hold, because on aarch64 the loader changes permissions of address regions, which interferes with ROAR's mappings. When running with ROAR, check if the target address is executable by ROAR using a new API call.
