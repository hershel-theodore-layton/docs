Commit title: Fix xplat context_stack_test crash due to missing folly::init
Commit body:
Summary:
The `FrameworkMetadataInitialized` test uses `THRIFT_FLAG_SET_MOCK` which
triggers `ObserverManager::waitForAllUpdates()`, requiring the
`ObserverManager::UpdatesManager` singleton to be initialized via
`folly::init()`. In the xplat build, `fb_xplat_cxx_test` uses vanilla
`gtest_main` which doesn't call `folly::init()`, causing a fatal abort.

Split `FrameworkMetadataInitialized` into a separate `fbcode_only` test target
(`context_stack_framework_metadata_test`) so the remaining 3 tests continue to
run in xplat without issues.
