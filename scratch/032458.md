Commit title: thrift/dynamic: add DynamicServiceSchema
Commit body:
Summary:
Add DynamicServiceSchema, a virtual interface representing a single Thrift service's function signatures at runtime. Stores function metadata (params, response type, exceptions, stream/sink payloads) with TypeRef handles into a TypeSystem, enabling efficient function lookup by name without re-traversing the schema on every RPC.

Three components:
- DynamicServiceSchema: pure virtual interface returning service name, functions (as folly::span), and TypeSystem
- SyntaxGraphServiceSchema: concrete implementation backed by a SyntaxGraph, constructed from a ServiceNode reference or by name (with conflict detection). Walks base services for inherited functions.
- DynamicServiceSchemaBuilder: programmatic builder for constructing schemas without a SyntaxGraph, useful for tests
