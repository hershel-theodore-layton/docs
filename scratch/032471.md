Commit title: Add dynamic property access warning (Warn[12042])
Commit body:
Summary:
Add a new warning (Warn[12042]) for property access (`$e->p`) where `$e` has type `dynamic`. This mirrors the existing dynamic method call warning (Warn[12038]) and uses the same `is_dynamic_or_intersects_dynamic` test to detect dynamic types, including through intersection types and `supportdyn` wrappers.

The warning is added as a new `Property_access` kind in the existing `Dynamic_call` warning module and TAST check, matching `Obj_get` with `Is_prop` (as opposed to `Is_method` which is already handled for method calls).
