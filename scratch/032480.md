Commit title: Apply AllowExec/AllowUngatedExec gating to popen/pclose
Commit body:
Summary:
Apply the same AllowExec/AllowUngatedExec runtime gating to popen and pclose
that is already enforced on exec, shell_exec, passthru, system, and proc_open.

popen executes a command via a shell pipe, so it should be subject to the same
process execution controls. pclose is gated as defense-in-depth since it
operates on pipe handles from popen.

The gating checks are inlined in ext_std_file.cpp following the same pattern
used by ext_hsl_os.cpp and ext_process.cpp, which each maintain their own copy
of the check in an anonymous namespace.

Updated existing tests (proc_open_gated_ungated_apis and proc_open_gated_no_exec)
to verify popen and pclose are properly rejected under both AllowExec=false and
AllowUngatedExec=false configurations.
