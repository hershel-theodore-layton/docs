Commit title: Add VASM sinkDefs pass for pure register-only definitions
Commit body:
Summary:
Introduce a new VASM optimization pass, sinkDefs, that moves pure single-def register-only instructions toward the nearest common dominator of their uses. The pass operates on both trace and prologue units, batches its dominance and use analysis instead of recomputing it per-move, and respects block headers (landingpad/phidef) when choosing an insertion point.

Wire the pass in for both x64 (as a new VOPT_SINK pass) and ARM64 (after reuseImmq in the optimize pipeline). Add a commonDominator helper to vasm-util that computes the nearest common dominator using RPO indices.

Tests cover both the merge-after-phidef sink case and the keep-defs-at-join-point negative case under both trace and prologue ABIs. Also included is incidental cleanup of vasm-fold-test.cpp to make the x64 guard structure explicit and add a separate skip TEST for non-x64 builds.
