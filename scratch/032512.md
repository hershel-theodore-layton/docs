Commit title: Clean up expression-dependent types from tpenv after await to prevent exponential blowup
Commit body:
Summary:
This is an extension of D95847716.
Sequential `await` statements were triggering the same behaviour D95847716 fixed for lambdas and `concurrent` blocks.
This diff extracts clean-up logic into a helper function which is used by both `refresh_env_and_type` and newly introduced `cleanup_expr_dep_types` to be able to handle both lambdas and awaits cases. Cleanup doesn't happen unconditionally though:
* We check that resulting type doesn't contain any expr-dep types
* We check that resulting type doesn't contains any Tvars since they might be unsolved and solved later to a type containing expr-dep types.
