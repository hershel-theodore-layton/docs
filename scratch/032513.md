Commit title: Exclude Emscripten from uncaught_exceptions() fast path
Commit body:
Summary:
folly's accelerated uncaught_exceptions() caches a pointer into __cxa_get_globals()->uncaughtExceptions. Emscripten's JS-based exception model (-fexceptions) does not provide __cxa_get_globals, causing link failures for WASM binaries:

```
wasm-ld: error: libexception.a(Exception.cpp.o): undefined symbol: __cxa_get_globals
```

Add __EMSCRIPTEN__ to the existing fallback chain in Exception.h, matching the pattern for `__APPLE__` and _CPPLIB_VER. On Emscripten, folly falls back to std::uncaught_exceptions() which libc++ provides via __cxa_uncaught_exceptions().
