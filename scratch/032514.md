Summary:
Migrate bincode dependency from v1 (rust:bincode) to v2 (rust:bincode-2).
Using bincode::config::legacy() for wire compatibility with v1 format.

WARNING: Wire format change for bincode::options() call sites: Several files in this diff previously used bincode::options() (varint integer encoding). There is no bincode v2 config that exactly reproduces v1's varint format, so these have been migrated to bincode::config::standard() which uses bincode v2's own varint scheme. The serialized bytes will differ from v1 — if any of these code paths persist data to disk or exchange it with older binaries (decl_provider, compiler_ffi, hh_distc protocol, facts store), this is a breaking format change and those paths may need to stay on bincode v1 instead.

Options are to stick with v1 dependency or move to the new v2 varint encoding. Thoughts hphp team?
