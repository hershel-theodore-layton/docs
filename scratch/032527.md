Commit title: Allow is/as tests with abstract type constant whose as-constraint is unenforceable
Commit body:
Summary:
Currently we reject `is` and `as` tests on a type constant (e.g. `this::TC`) if the type constant is abstract, enforceable, but has an `as` bound that's non-enforceable. This is too strict: the `as` bound can be satisfied by an enforceable type e.g.
```
class G<T> { }
class H extends G<int> { }

abstract class C {
  <<__Enforceable>>
  abstract const type TC as G<int>;
  public function foo(mixed $m):void {
    // Currently rejected, but should be allowed
    $m as this::TC;
  }
}
class D extends C {
  const type TC = H;
}

<<__EntryPoint>>
function main():void {
  $d = new D();
  $d->foo(new H());
}
```
