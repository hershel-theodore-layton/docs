Commit title: Look through type aliases when checking for with-refinements in is/as/reified generics
Commit body:
Summary:
For the `with_refinement_alias` experimental feature, we want to disallow with-refinements in `is` and `as` expressions even when looking through type aliases. For example, the following should be illegal:
```
type TA = I with { type TC = int; }
function foo(mixed $m):void {
  $m as TA;
}
```
To do this we replace the NAST check in `Type_structure_leak.ml` with a TAST check in the existing `Typing_enforceable_hint.ml`, which already handles looking through aliases and concrete type constants.
