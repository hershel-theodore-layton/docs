Summary:
Improve the HackLint5656 (crosspackage_classptr_reference) error message based on user feedback:

1. Remove the word "potential" — this IS a cross-boundary edge by definition, not a potential one.

2. Conditionally suggest `__PackageOverride` when the caller file itself has a `__PackageOverride`. This addresses the common case where a file in flib/intern is overridden to prod and references another intern file — the fix is to propagate the `__PackageOverride` to the target file.

The `__PackageOverride` suggestion only appears when relevant (caller is overridden), since if the caller is NOT overridden, the other options (hg mv, `__RequirePackage`, package check) are the correct remediation.
