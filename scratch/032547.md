Commit title: use shared event handler vector across connections.
Commit body:
Summary:
Making a vector of event processor handlers for each connection introduces a fair bit of overhead. The higher end is well over 2GB (https://fburl.com/canvas/qlxdcmrp) and even touching 4GB for zorro occasionally.

The vector should be the same across connections and is not altered by any. we can optimize the per connection overhead by keeping a shared ptr to the common one.

The logic to pre-build a shareable vector of handlers upfront is gated behind a flag. if set, the shared handlers vector is used first and only if any custom handlers are added will the connection end up a private version. Added metrics will help surface the efficacy of the approach.
