Remove the Thrift flag `server_fizz_enable_receiving_dc` and set its `true` behaviour as default

It's been long enough that we don't need to doubt the functionality of receiving delegated credentials. This is also needed to get packages that block Configerator as a dependency (e.g. [`tupperware-agent`](https://www.internalfb.com/code/fbsource/[fa283ee294834da9b6fdf0c94c4e8d25b28502dd]/fbcode/tupperware/agent/BUCK?lines=504)) to receive DCs.

This does remove one killswitch mechanism, but the `presenting_dc` Thrift flags should suffice.
