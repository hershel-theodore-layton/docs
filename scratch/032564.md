Commit title: Fix KeepAlive tests failing under TSAN due to tight timeouts
Commit body:
Summary:
All three KeepAlive tests (KeepAliveWatcherLargeRequestTest, KeepAliveWatcherLargeResponseTest, KeepAliveEvbDetachAttachTest) were DISABLED_FAILING in TSAN mode. The root cause is that TSAN adds 5-15x overhead, making the hardcoded 25ms/100ms keepalive timeouts too tight for the server to complete the setup frame + keepalive round trip. The keepalive fires, closes the connection, and the first "normal" RPC crashes with TTransportException before the test can exercise the intended large-payload timeout behavior.

Fix: scale keepalive timeouts by 10x under `folly::kIsSanitizeThread`. The large payload (40MB over a 1-byte send buffer) still triggers the keepalive timeout as intended since the transfer time dwarfs even the scaled timeout.
