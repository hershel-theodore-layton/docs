Commit title: Remove Netty leak detection supression
Commit body:
Summary:
1) This code is problematic because it supresses leak detection for customers who enable it via -D flag. This code checks for the presence of `io.netty.leakDetectionLevel` as a system propery, which is incorrect and does not match the new, correct, netty flag `io.netty.leakDetection.level`. This means that this block will always evaluate to true and disable the leak detection for customers even when the assign the level correctly via -D flag.

2) We should use the netty default of 1% sampling as the overhead is quite low, and the customers can disable it if necessary by using -D flag at startup. Having some leak detection in prod is desired.
