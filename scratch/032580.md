Summary:
ResourcePools are enabled by default (thrift flag
`experimental_use_resource_pools` defaults to true). Remove the
`FLAGS_thrift_disable_resource_pools = true` override that was added in
D73684262 as a workaround when flipping the default.

All 93 tests pass with ResourcePools. The only exception is
`BasicOneWay/HTTP2` which hangs because one-way RPCs over HTTP2 are not
dispatched to the handler under ResourcePools — this is a pre-existing
bug, not a regression from this change. Added a skip for that case.
