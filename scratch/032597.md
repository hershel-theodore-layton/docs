Commit title: fbthrift CMake: export xxhash as PUBLIC dep of thriftmetadata
Commit body:
Summary: thrift/detail/protocol.cpp calls XXH3_64bits, which means thriftmetadata must export xxhash as a transitive dependency in its CMake link interface. Without this, downstream consumers of FBThrift::thriftmetadata that do not explicitly link xxhash themselves fail at link time on Windows (and potentially other platforms). Add Xxhash_LIBRARY and Xxhash_INCLUDE_DIR to thriftmetadata PUBLIC deps when Xxhash is found; xxhash is already a listed dependency in the fbthrift getdeps manifest so it will always be present in getdeps builds.
