Commit title: Remove `deprecated_terse_writes` compiler option
Commit body:
Summary:
Remove the `deprecated_terse_writes` thrift_cpp2_options compiler option. This option globally enabled terse write behavior for all qualifying unqualified fields, and has been superseded by the per-field `cpp.DeprecatedTerseWrite` annotation (which itself is deprecated in favor of `thrift.TerseWrite`).

Changes:
- Remove `deprecated_terse_writes()` function from util.h/util.cc
- Remove compiler option checks from `deprecated_terse_writes?`, `deprecated_terse_writes_with_non_redundant_custom_default?`, and `has_non_optional_and_non_terse_field?` template properties (they now only check the per-field annotation)
- Remove `validate_deprecated_terse_writes` validator (only existed to error on option+annotation conflict)
- Simplify `forbid_deprecated_terse_writes_ref` to not take compiler options
- Remove the option from help text
- Inline the removed function logic in the codemod
- Remove `cpp.AllowLegacyDeprecatedTerseWritesRef` from mcpp2-compare fixture (fields were only deprecated-terse-write via the option)
- Delete emptiable and lazy_deserialization `cpp2_deprecated_terse_writes` fixture outputs
- Regenerate mcpp2-compare fixtures
