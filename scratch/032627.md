Commit body:
Summary:
Add opt-in support for using `StripedPriorityUnboundedBlockingQueue` in the `CPUThreadPoolExecutor`s created by ThriftServer for request processing. This can reduce contention on multi-LLC systems.

Two opt-in mechanisms:
- Per-server: call `requireStripedExecutorQueue()` before setup
- Fleet-wide: set the `use_striped_executor_queue` THRIFT_FLAG
