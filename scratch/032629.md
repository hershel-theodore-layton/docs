Commit title: Fix double AGENT: prefix in ThriftContextPropState lookaside
Commit body:
Summary:
The ThriftContextPropState::getAgentId() lookaside unconditionally prepends "AGENT:" to the value returned by Agent::getAgentIdentity(). Some identity sources (AgentIdentitySourceCerts, AgentIdentitySourceRequestTokens) return values that already contain the "AGENT:" prefix, resulting in double-prefixed agent_ids like "AGENT:AGENT:EfficiencyMate" in Artillery traces.

Check whether the value already starts with "AGENT:" before prepending.
