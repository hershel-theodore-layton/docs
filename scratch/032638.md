Commit title: Detect stale in-memory state on watchman fresh instance or failure
Commit body:
Summary:
When a watchman fresh instance (`is_fresh_instance: true`) or connection failure occurs, the Facts update chain now compares the in-memory clock against the DB clock. The mismatch can happen when a new saved state is loaded in to a repo root that we'd already seen before.

Previously, a fresh instance always triggered a full recrawl of all files.

This fixes very slow init times for worktrees when a repo root is reused.
