Client-side BiDi (bidirectional streaming) API looks approximately like this (example):

```
# Thrift schema
service ChatService {
  sink<ClientMessage>, stream<ServerMessage> Chat(1: ChatRoom room);
}
```

```
// Go Client code
func chat(ctx context.Context, client *ChatServiceClient, room *ChatRoom) error {
    chatCtx, chatCancel := context.WithCancel(ctx)
    defer chatCancel()

    // Call the bidi RPC - returns a sink callback and a stream iterator
    sinkCallback, incomingSeq, err := client.Chat(chatCtx, room)
    if err != nil {
        return fmt.Errorf("error starting chat: %w", err)
    }

    // Create an iterator that yields messages to send to the server
    outgoingSeq := func(yield func(*ClientMessage, error) bool) {
        scanner := bufio.NewScanner(os.Stdin)
        for scanner.Scan() {
            msg := &ClientMessage{Text: scanner.Text()}
            if !yield(msg, nil) {
                return // server stopped consuming
            }
        }
    }

    // Start sending sink elements (after receiving initial response)
    sinkCallback(outgoingSeq)

    // Consume the server-to-client stream
    for msg, err := range incomingSeq {
        if err != nil {
            return fmt.Errorf("stream error: %w", err)
        }
        fmt.Printf("Server: %s\n", msg.Text)
    }

    return nil
}
```

Supports:

* Client-to-server sink elements sent via callback + Go iterator (iter.Seq2[SinkElemType, error])
* Server-to-client stream received as Go iterator (iter.Seq2[StreamElemType, error])
* Initial/first response (optional - if Thrift schema defines it)
* Initial error (returned from the RPC call itself)
* Sink element errors (declared exceptions sent to server via the iterator)
* Stream element errors (declared exceptions received from server via the iterator)
* Method-level declared exceptions (returned from the RPC call itself)
* Interactions (optional - if Thrift schema defines it, an interaction client is also returned)

The callback-based API allows users to:
* Inspect the initial response before deciding what sink elements to send
* Control when to start sending sink elements
* Use Go's iterator pattern (iter.Seq2) to lazily produce elements
