Commit title: Hack generator: use recursive case types for recursive shapes
Commit body:
Summary:
Teach the Hack thrift generator to emit proper recursive type definitions using
Hack's recursive case types feature, replacing the mixed + UNSAFE_CAST approach
from D99359119. For each struct with recursive shape references, the generator
now emits a type alias and case type pair (the Tree/Forest pattern from the
recursive case types announcement):

  type RecursiveNodeTShape = shape(
    ?'parent' => ?RecursiveNodeTShapeRec,
    'children' => vec<RecursiveNodeTShapeRec>,
  );
  case type RecursiveNodeTShapeRec = RecursiveNodeTShape;

The type alias expands to shape(...) and satisfies the IThriftShapishSyncStruct
constraint. The case type provides the recursive indirection. TShape fields now
carry full recursive type information instead of mixed.

For direct struct field access in __fromShape, the case type value is narrowed
with `as shape(...)`. For container elements (Vec\map/Dict\map callbacks), an
UNSAFE_CAST is still needed because the case type flows through erased generic
type parameters that prevent runtime narrowing.
