Commit title: Fix service args/result class name mangling for PHP namespace
Commit body:
Summary:
Fix the Hack code generator to use unmangled (short) names for service args and result helper structs (e.g., `ServiceName_method_args`, `ServiceName_method_result`) instead of fully-qualified namespace-prefixed names.

When `namespace hack` is set, the generated code was correctly using short names. But when only `namespace php` is set (with `mangled_services_` enabled), the args/result structs were being emitted with the full namespace prefix (e.g., `\test\fixtures\basic\MyService_ping_args`), which is unnecessary since these are internal helper types used within the same file scope.

Changes:
- Skip `hack_name()` mangling for `ThriftStructType::ARGS` and `ThriftStructType::RESULT` types, using the raw name directly
- Use `php_servicename_mangle()` instead of `tservice->name()` in `generate_php_function_helpers()` and interaction helper generation to ensure consistent service name mangling
- Fix interaction prefix generation to correctly include the PHP namespace when `mangled_services_` is enabled
