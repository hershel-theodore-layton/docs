Summary:
Extend hackc to export class alias information to HHVM.

Class aliases are exported using a new `ClassAlias` kind, dumped as:

```
.class_alias Alias = Original;
```

The original class names are added to `.class_refs`, eg.

```
.class_refs {
  Original
}
```

Generics in class aliases, eg. `class C<T1,T2> = D<T1,T2>`, are not propagated to HHVM as only class/interface renaming (and not generic instantiation) is supported by the feature.
