Commit title: Remove Generator::getReturn()
Commit body:
Summary:
This function is not exposed in Hack and it is also a typechecker error to
return a value from a generator.

Delete it from HHVM and update the RetC machinery to expect and store null.

The assert that the return value is null is not entirely right, as a code that
doesn't pass typechecker might violate it. This is pre-existing for async
generators and will be addressed in the next diff by making it a parse error to
return value from a generator.
