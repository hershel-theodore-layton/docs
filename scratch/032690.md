Commit title: Add configurable Eval.ProcOpenGatedSkipCallers for transparent proc_open wrappers
Commit body:
Summary:
Instead of hardcoding the FlibSL\PHP\proc_open wrapper name in the HHVM
runtime, this adds a new configurable Eval.ProcOpenGatedSkipCallers set
that tells checkExecAllowed() which callers to skip during stack
inspection.

The predicate-based fromCaller(f, pred) overload is used to skip any
callers in the set, so the gating logic attributes the proc_open call
to the real calling function rather than a transparent wrapper.

This avoids www-specific details bleeding into the HHVM runtime and
makes the behavior configurable, consistent with how
Eval.ProcOpenGatedApprovedCallers already works.
