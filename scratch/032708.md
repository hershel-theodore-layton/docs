Summary:
Import-time visibility makes thrift-py-deprecated library use hard to miss. Surface a thrift-py-deprecated deprecated library warning at import time.

Generated thrift-py-deprecated `ttypes.py` modules call `warn_py_deprecated(__name__)` at import time. The helper emits `ThriftPyDeprecatedWarning(DeprecationWarning)`, installs a targeted `default` filter only when no explicit user warning rule applies, uses `stacklevel=3` so the warning points at the importer, and relies on Python's normal `default` behavior for per-site dedup.
