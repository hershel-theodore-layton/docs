Commit title: Remove fallibleClose wrapper from cancelAsyncGenerator
Commit body:
Summary:
Remove the `fallibleClose` helper that wrapped `generator.aclose()` in a `try/except Exception: pass` inside `cancelAsyncGenerator`. This wrapper was originally intended to suppress `RuntimeError` from calling `aclose()` on a running async generator, but all callers now pass a `CloseableGenerator` (which handles concurrent `aclose()` safely via task cancellation), making the suppression dead code.

This also aligns `sink.pyx`'s `cancelAsyncGenerator` with the identical function in `py3/stream.pyx`, which has always called `generator.aclose()` directly.
