Commit title: Add validator for @cpp.Type integer width mismatch
Commit body:
Summary:
Add a compile-time check that errors when a `cpp.Type{name="..."}` annotation specifies a C++ fixed-width integer type whose bit width differs from the underlying Thrift integer type. For example, `cpp.Type{name="int64_t"}` on an `i32` field now produces an error, since this mismatch can cause silent data truncation.

Recognized C++ types: (u)int{8,16,32,64}_t with optional std:: prefix.
Thrift integer types: byte (8-bit), i16 (16-bit), i32 (32-bit), i64 (64-bit).
