Commit title: Add fizz_handshake_verification_errors counter to separate client cert errors from server errors
Commit body:
Summary:
Fizz handshake error alerts currently fire for all handshake failures, including client-caused certificate verification errors (unknown_ca, bad_certificate, certificate_expired, etc.). These client errors create noise that masks genuine server-side issues.

This diff splits the existing fizz_handshake_errors counter so that cert verification failures are tracked separately:

- Handshake failures due to the server rejecting a client certificate, server can't control the client
- Handshake failures due to the client rejecting the server cert, this can be a client misconfiguration with trust store or server cert issue.
- And the existing counters for protocol errors and the rest of the errors kept.

We provide an initial handshake error classification, which can be improved as needed.
