Commit title: Enable --package-lint-full: precise cross-package reference checking
Commit body:
Summary:
Adds --package-lint-full <target_file> <candidate1,candidate2,...> for precise cross-package reference checking. While --package-lint uses the dep graph for a fast but conservative check, --package-lint-full scans each candidate files TAST to verify whether references actually affect production (filtering out
nameof, ::class, attributes, etc. via affects_prod_build).

The Hack client (RedundantPackageOverrideLintRule) uses --package-lint to identify possible candidate files via dep graph, then passes them to --package-lint-full for precise verification.

Key design:
- Candidates are mandatory — the client pre-filters via dep graph- Uses IdentifySymbolService.all_symbols on each candidates TAST
- Filters on affects_prod_build to skip non-production references
- Checks cross-package relationships via PackageInfo.can_access
