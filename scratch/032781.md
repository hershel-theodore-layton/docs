Commit title: Add protected accessor to read lower-endian values in derived types of CompactProtocolReaderWithRefill
Commit body:
Summary:
Allow derived refill readers to use this helper where they cannot access `CompactProtocolReader::in_` directly (due to not having a friend declaration in the protocol reader). Allows users to implement refill readers for `CompactV1ProtocolReader` if necessary, without supporting it in the Thrift codebase or having to patch in a friend declaration.

A refill reader can then be implemented outside of the Thrift codebase, using only public APIs and this protected accessor for the sole difference between CompactV1 and modern Compact - CompactV1 encodes doubles as little endian, while Compact encodes doubles as big endian.
