Commit title: Fix open source build: disable Fizz examples to avoid folly_benchmark dependency
Commit body:
Summary:
The open source build of proxygen fails when building Fizz because Fizz examples
link against `Folly::folly_benchmark`, which is not available in the open source
Folly build. The `EncryptedRecordBench` target triggers:

```
CMake Error: Target "EncryptedRecordBench" links to target
"Folly::folly_benchmark" but the target was not found.
```

Adding `-DBUILD_EXAMPLES=OFF` to the Fizz cmake invocation in `build.sh`
resolves this. Tests are already disabled (`-DBUILD_TESTS=OFF`), so this
is consistent with the existing approach.
