Commit title: Extract NumberType enum into shared reflection_enums module
Commit body:
Summary:
Move the NumberType and StructType cpdef enums and Qualifier enum from thrift.py3.reflection into a new shared Cython module at thrift.python.reflection_enums. The py3 reflection module now imports from the shared module instead of defining its own copies.

This ensures both py3 and thrift-python reflection use the same enum classes, preventing cross-type comparison failures when auto-migrate tests compare values across the two runtimes.

Also registers the new reflection_enums extension in setup.py for the OSS build.
