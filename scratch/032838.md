Summary:
Store the full `Options` struct in `Json5ProtocolWriter` instead of just `JsonWriterOptions`.

This enables adding protocol-level options to `Options` in subsequent diffs.

The `defaultOptions` method is needed, since the following code doesn't work

```
struct Json5ProtocolWriter {
    struct Options {
        bool flag = false;
    };
    Json5ProtocolWriter(Options options = {}) {}
};
```
