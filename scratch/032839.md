Commit body:
Summary:
Add `enumAsInteger` option to `Json5ProtocolWriter::Options`. When set, `writeEnum` outputs the raw integer value instead of the `"Name (value)"` string. Exposed in Python bindings as `Json5ProtocolWriterOptions.enum_as_integer`.

The motivation is having options to make JSON5 protocol output similar to SimpleJSON for easier migraiton.
