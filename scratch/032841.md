Commit title: Replace `X as dynamic;` with `HH\FIXME\UNSAFE_CAST<mixed, dynamic>(X)`
Commit body:
Summary:
Codemod across 59 files replacing all standalone `X as dynamic;` statements and assignment-form `$y = X as dynamic;` expressions with `HH\FIXME\UNSAFE_CAST<mixed, dynamic>(X)`.

**Motivation:** `X as dynamic` is a runtime type assertion (`as` operator) that also performs flow-sensitive type narrowing in the Hack type checker. `HH\FIXME\UNSAFE_CAST<mixed, dynamic>` is the preferred unsafe-cast escape hatch that is explicit about bypassing the type system without implying a runtime assertion.

**Transformation rules applied:**

Standalone statement form:
  Before: `$expr as dynamic;`
  After:  `$expr = HH\FIXME\UNSAFE_CAST<mixed, dynamic>($expr);`

Assignment form (where `as dynamic` appears as a sub-expression):
  Before: `$y = $expr as dynamic;`
  After:  `$y = HH\FIXME\UNSAFE_CAST<mixed, dynamic>($expr);`

Multi-line expression form (TArbitraryIndex.php):
  Before: `$y = long_call(\n  ...\n) as dynamic;`
  After:  `$y = HH\FIXME\UNSAFE_CAST<mixed, dynamic>(long_call(\n  ...\n));`

**Key subtlety fixed during the codemod:** Hack's `$y = $x as dynamic;` not only assigns a `dynamic`-typed value to `$y` but also flow-narrows `$x` to `dynamic` in subsequent code. Plain `UNSAFE_CAST` does not narrow the source variable. In several test files the code after the cast relied on this narrowing to access optional shape fields and pass `dynamic` arguments. Those call sites were updated to use the already-computed `dynamic` variable (`$y`) instead of the original (`$x`):
- `gen_ai/mcp_gateway/__tests__/ThirdPartyAPIServerTest.php`
- `gen_ai/mcp_gateway/__tests__/RemoteMCPServerTest.php`
- `gen_ai/mcp_gateway/__tests__/FirstPartyAPIServerTest.php`
- `platform/graph/resources/video_creative_composer/video_generation/GraphVCKGenerateVideosPost.php`

**Files intentionally not changed:**
- `PHPismCoercionsTestUtils.php` — `new Class() as dynamic;` (constructor result is not an assignable lvalue)
- `HackAstTrustedTypeLabelerTest.php` — test data for the trusted typechecker labeler; changing it would break the expected-output assertions
- `AsCodemodImplTest.php` — `'$x as dynamic;'` is a string literal, not live code
- `GraphQLAdsCreateCampaignGroupUtil.php` — uses `?as dynamic` (nullable cast), a distinct operator not in scope
- `BrsEnrichmentDecisionHistoryFetcher.php` — appears only inside a `//` comment
- Documentation and codegen files (`DynamicCastLintRule.md`, `DynamicCastLintRuleTest.codegen`, `REFERENCE.md`, `UnsafeCastHackErrors.php` string format)

**Verification:** `hh` reports no errors (30 pre-existing warnings about dynamic method/property access — these existed before the codemod and are expected, since those casts exist precisely to enable dynamic access).
