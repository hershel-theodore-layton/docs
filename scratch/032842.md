Adds `vec[...]`, `dict[...]`, and `keyset[...]` literal syntax inside expression tree backticks, following the shape literal pattern (D66576594).

Gated behind `expression_tree_hack_arrays` feature flag (Preview).

| Hack syntax | Desugared visitor call |
|-------------|----------------------|
| `vec[e1, e2]` | `visitVec(pos, vec[d(e1), d(e2)])` |
| `dict[k1 => v1]` | `visitDict(pos, vec[tuple(d(k1), d(v1))])` |
| `keyset[e1, e2]` | `visitKeyset(pos, vec[d(e1), d(e2)])` |

Dict entries use vec-of-tuples (not `dict[...]`) to preserve duplicate keys for the visitor. Dict keys are rewritten via `rewrite_expr` (not `mk_visit_string`) since they can be `int` or `string` expressions.
