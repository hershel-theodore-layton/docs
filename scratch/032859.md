Commit body:
Summary:
Add `binaryAsBase64String` option to `Json5ProtocolWriter::Options`. When set, `writeBinary` outputs a plain base64 string (padding stripped) instead of the `{"utf-8": ...}` / `{"base64url": ...}` object.

The motivation is having options to make JSON5 protocol output similar to SimpleJSON for easier migraiton.
