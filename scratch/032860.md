Summary:
Fix a silent corruption bug: under the auto_migrate compiler option, _to_py3() on a thrift-python mutable struct returned self instead of a py3 object. The new body delegates to _to_python(), which produces the correct py3 type for both mutable and immutable structs.

A new runtime test, test_simple_mutable, asserts that _to_py3() on a mutable struct does not return a mutable instance.
