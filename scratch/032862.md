Commit title: Undef MAJOR/MINOR macros in VIXL header to fix ARM build
Commit body:
Summary:
D102320550 introduced a new include chain that pulls `mandoline_types.h` (via `metadata_secondary_index.thrift` -> `metaservice.thrift`) into `ext_scribe.cpp`. On ARM builds, this translation unit also includes `hphp/vixl/compiler-intrinsics-vixl.h`, which defines `#define MAJOR 1000000` and `#define MINOR 1000`. These generic macro names clobber the `MINOR = 3` and `MAJOR = 4` enum members in `mandoline_types.h`, causing a compilation error.

The fix adds `#undef MAJOR` and `#undef MINOR` immediately after the `GCC_VERSION_OR_NEWER` macro definition, which is their only consumer. The `GCC_VERSION_OR_NEWER` macro itself is unaffected because the preprocessor already expanded the values into its definition.
