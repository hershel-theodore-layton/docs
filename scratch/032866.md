Commit body:
Summary:
Every generated py-deprecated `ttypes.py`, `constants.py`, and `Service.py` now calls `warn_thrift_py_deprecated(__name__)` at module scope, emitting a `ThriftPyDeprecatedWarning` attributed to the first hand-written caller in the import chain.

Generated code wraps the helper import in `try/except ImportError` with a no-op fallback to prevent `ImportError` during the rollout window when a binary built with new compiler output runs against an older `Thrift.py` that does not yet export the helper symbol.
