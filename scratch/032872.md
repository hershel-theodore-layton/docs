Commit title: Scheduler performance: bulk registration and fast-path bin packing
Commit body:
Summary:
Two performance improvements for the analysis scheduler:

1. Bulk registration: reserveForRegistration pre-sizes internal maps,
   and registerAllBulk splits work into a serial phase (state creation,
   closure registration, trace linking) and a parallel phase (predep
   computation). Replaces individual registerClass/Func/Unit calls
   during initial registration.

2. Fast-path bin packing: for large trace counts (> 50K), skip the
   O(N^2 x k) overlap-aware packing and use a cheaper O(N log N)
   heuristic. Sort traces by their heaviest element for locality,
   then greedily pack into bins checking only the last K=32 open bins
   for overlap. Skip the O(bins^2) merge pass when fast path is used.
