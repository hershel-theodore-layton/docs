Commit title: No live translations during retranslateall
Commit body:
Summary:
There is a race condition where live translations can be emitted while RTA is going on. It can produce duplicate translations because we only mark a translation as optimized when a `TranslateWorker` thread gets to running `optimize` on it.

For parallel live translation work, limiting live translations while RTA is going on is simpler because then there will only be only one `CodeCache::View` during RTA which makes hugepages behavior easier to understand.
