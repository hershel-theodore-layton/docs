Commit body:
Summary:
Add iobuf_copy_from_buffer() which creates IOBufs that OWN a copy of
the data (memcpy into IOBuf-managed memory). Unlike iobuf_from_memoryview()
which shares the Python buffer via Py_INCREF (and pins the Python object
until the IOBuf is destroyed), this function has no Python object lifetime
dependency.

Use iobuf_copy_from_buffer() when the IOBuf may outlive the source Python
buffer — for example when the buffer is passed to a transport layer that
retains serialized data.
