Summary:
This diff adds telemetry that allows us to track the delay between receiving a file change from Eden vs actually starting to type-check it.
To this end:
- In `Edenfs_watcher`, we add a timestamp to those events that actually contain changes upon receiving them.
- In ServerNotifier, when using Eden, we extract the oldest such timestamp and calculate the age from it. This value is written to `oldest_change_age` in the `notifier` objects we log on RECHECK_END events. This means that the actual increase in logged data is minimal.
