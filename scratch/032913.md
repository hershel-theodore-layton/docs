Commit title: Add timestamps to past_states in repo_states telemetry
Commit body:
Summary:
This diff extends the repo_states telemetry so that `past_states` is a not just a list of states that we have previously asserted at some point, but instead a map from state names to the timestamp when the state was last left/un-asserted.

Both the Watchman and Eden code paths now record a Unix.gettimeofday-format timestamp on state leave. The Rust-internal StateInfoEntry replaces the boolean ever_left with an `Option<f64>` last_left_at field that serves the same purpose while also carrying the timestamp.

In terms of the increase of logged data: We now log up to three additional float values to the `data` blob on RECHECK_END and TYPECHECK_END.
