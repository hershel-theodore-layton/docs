Commit title: Parallel live translations
Commit body:
Summary:
Generating live translations is very slow because it's single threaded and in some tenants takes more than 30 minutes to JIT the full 150MB limit. At the same time now there is more TC space from packed pointer to generate live translations and Dynamic TC makes it possible to chunk each section. This diff allows each thread to take a chunk of the TC and generate live translations in parallel, as long as they are to get a 1) lock from the function 2) acquire a `CodeCache::View`.

After D99173147, we should also be able to increase `MaxLiveMainUsage` even more since some tenants (like Instagram) are able to produce at much faster rates. Without that, slower tenants will take very long to hit full JIT maturity.
