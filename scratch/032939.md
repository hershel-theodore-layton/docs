Commit title: Add jitMaturity field to ServerHealthInfo and populate in healthmon
Commit body:
Summary:
Add jitMaturity (the per-host JIT maturity HHVM exports, 0-100) as a new field on the ServerHealthInfo thrift struct. Healthmon was already parsing the X-FB-ServerInfo header into <uptime>, <prepare_to_stop>, <push_phase>, <jit_maturity>, <weight>, <loadhint>, <curr_bucket>, <jumpstart_bucket> via sscanf, but discarded the maturity field with %*. Promote it to %, capture into jitMaturity_, and publish to revproxy via the existing health-update path.

For the Thrift WWW custom-fields code path (ThriftWWWCustomHealthChecker), the source WWWThriftServerInfo already exposes info.jit_maturity(), so just propagate it into ThriftWWWCustomHealthCheckerFields and apply in healthmon.

Mirrors the lsst pattern from D96828151 and the serverShape pattern from D101884785. Unlike lsst, no enum conversion is needed.
