Commit title: Add RequestContext to replace additional Thrift/SR maps
Commit body:
Summary:
Gets rid of the pending requests map on thrift side, and instead we now allocate a RequestContext object on heap.
A type erased unique_ptr to this object is passed to stream state handler, which stores it, and is passed back on the response path.
Any handlers that need to keep some state can add to this context object, i.e. transport stats, etc.

The reason response path shows a lot of improvement is because the contentious 2xmap look up becomes 1x, and then we just use the pointer.
