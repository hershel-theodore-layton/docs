Commit title: Add 'hasdefault' to generated Go struct tag
Commit body:
Summary:
Adds a new `hasdefault` token to the generated Go `thrift:"..."` struct
tag whenever the IDL field declares a default value. The Go thrift runtime
does not parse this tag at runtime, so the change is backwards compatible.

This unlocks a new angrygopher linter that detects struct composite literals
which silently drop IDL defaults (e.g. `&Foo{}` where `Foo` has fields with
defaults — those defaults are dropped because the literal bypasses the
generated `NewFoo()` factory).

Implementation:
- Register a new Go-only whisker boolean property `has_default?` on the field
  prototype, mirroring `required?`/`optional?`/`go_tag?` patterns. Uses the
  existing `t_field::default_value()` accessor.
- Extend `field.whisker` to emit `,hasdefault` after the existing
  `required`/`optional` qualifier in the thrift tag.
- Regenerated 12 affected Go fixtures via build_fixtures.
