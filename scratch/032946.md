Commit title: Fix -Wtautological-unsigned-zero-compare in StackTrace.cpp on Windows
Commit body:
Summary:
On non-Linux platforms (including Windows), kMinValidAddress is defined as 0
in folly/Portability.h. The comparison:

  reinterpret_cast<uintptr_t>(normalStackFrame) >= kMinValidAddress

becomes unsigned >= 0, which is always true, triggering:

  -Werror,-Wtautological-unsigned-zero-compare

This check is only meaningful on Linux where kMinValidAddress = 0x1000 (the
kernel never maps the first page of virtual address space, so frame pointers
below this threshold are stale/corrupt). On non-Linux platforms the nullptr
check on the preceding line is sufficient.

Fix: guard the kMinValidAddress comparison with #if defined(__linux__),
matching the same preprocessor condition used to define kMinValidAddress
in Portability.h. On non-Linux the comparison is replaced with true.

See D103041871 for context.
