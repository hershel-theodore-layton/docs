Commit title: fbthrift: build with -fPIC for downstream shared-library consumers
Commit body:
Summary:
fbthrift's libraries default to STATIC and only enable PIC when the
whole tree is built shared. That forces consumers that want static
archives in a downstream shared library to either turn on
BUILD_SHARED_LIBS=ON (and inherit fbthrift's cross-dylib RTTI / undefined
symbol problems) or maintain a one-line patch downstream.

Set CMAKE_POSITION_INDEPENDENT_CODE=ON at the top of the OSS CMakeLists
and force POSITION_INDEPENDENT_CODE=ON on the compiler_generators
target unconditionally. PIC is negligible cost on x86_64 / aarch64.
