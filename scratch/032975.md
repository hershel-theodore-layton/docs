Commit title: avoid extra local arena in single node machines
Commit body:
Summary: On NUMA hosts, we create an extra arena on each NUMA node and bind worker threads to the per-node arenas to get better locality.  But we are doing that on single-node machines as well. This was relatively harmless until contention on the arena becomes an issue with wider machines (e.g., unstacked Bergamo). With this diff, we avoid binding all worker threads to a single arena, and they will be spread across the 8 auto arenas to reduce contention. It can also potentially let us have better utilization on huge pages, which are injected to the auto arenas.
