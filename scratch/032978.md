Commit title: Add isRestricted bit to DirEntry
Commit body:
Summary:
Adds an `isRestricted` bit field to `DirEntry` by borrowing a third bit from the `initialMode_` field (reducing it from 30 to 29 bits). This keeps the struct at four words with zero memory overhead — the `uint32_t` already had two bits used for `hasId_` and `hasInodePointer_`, leaving one spare bit that we claim here.

The restriction flag propagates through overlay serialization via a new `isRestricted` field in the `OverlayEntry` thrift struct, so restriction status survives EdenFS restarts. The mode mask is tightened from `0x3fffffff` to `0x1fffffff` to match.
