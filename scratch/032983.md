Summary:
Implements a new generated handler for Fast Thrift Server.
1. Handler interface is similar to the existing Thrift Handler interface. 3 differences are:
    a. It now extends ThriftServerAppAdapterFactory has a method called getAppAdapter().
    b. It uses a new callback called FastHandlerCallback.
    c. Its named <service>FastHandler instead of <service>Handler.

2. The codegen creates a <service>AppAdapter which extends ThriftServerAppAdapter. This app adapter contains the process_<method> functions that call into the handler.

3. Adds a cpp.FastServer annotation to enable generating the new Fast Handler that replaces the existing handler.
