Commit title: Wire H3EarlyDataHandler into coro client
Commit body:
Summary:
Add 0-RTT HTTP/3 SETTINGS support for the coro QUIC client path.

When `QuicConnectionParams::attemptEarlyData` is set, the connector
creates an `H3EarlyDataHandler` and sets it on the QUIC transport.
The handler is then moved into the `HTTPQuicCoroSession` which calls
`setCurrentSettings()` in `onSettings()` to cache the server's
settings for PSK serialization via `get()`.

On reconnect, `validate()` in client mode (settings not yet
initialized) just verifies the cached blob is parseable and allows
0-RTT — the server does the real compatibility check.

Also adds a `SettingsList` overload to `setCurrentSettings()` and
documents client vs server mode behavior.
