Commit title: rebalancer: skip fbthrift's RPC stack and benchmarks via feature spec
Commit body:
Summary:
Rebalancer only uses fbthrift for codegen and (de)serialization. It does not link the RPC transport (fizz, wangle, mvfst), and it has no use for the benchmark executables. Use fbthrift's `rpc` and `benchmark` features (added in the parent diff) to skip both.

Before:

```ini
# manifests/rebalancer
[dependencies]
fbthrift
```

…with a side-channel CMake define in the workflow generator:

```sh
$GEN rebalancer ... --package-extra-cmake-defines "fbthrift={\"THRIFT_SERIALIZATION_ONLY\":\"ON\"}"
```

After:

```ini
# manifests/rebalancer
[dependencies]
fbthrift = !rpc, !benchmark
```

The CMake side-channel drops out of the workflow generator script too, since the manifest now drives it.

Regenerated `getdeps_linux.yml` and `getdeps_mac.yml`: fizz, wangle, mvfst, liboqs (transitive), and benchmark no longer appear. CI build is smaller and faster.
