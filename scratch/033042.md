Commit title: Map SERVER_CLOSING_CONNECTION to INTERRUPTION and add server-disconnect stream tests
Commit body:
Summary:
The Python stream decoder in StreamElementEncoder.cpp was missing the mapping from `StreamRpcErrorCode::SERVER_CLOSING_CONNECTION` to `TApplicationException::INTERRUPTION`, unlike the C++ codepath in `GeneratedCodeHelper.h`. This caused server-disconnect errors to surface as `ApplicationErrorType.UNKNOWN` instead of `INTERRUPTION`.

Fix the decoder to match C++ behavior, expose `ApplicationErrorType.INTERRUPTION` in the Python exceptions API, and add two new tests verifying client behavior when the server shuts down mid-stream (before and after the first element is yielded).
