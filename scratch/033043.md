Commit title: Add LZ4 compression support to Rocket transport
Commit body:
Summary:
Add LZ4 compression support to the Go Thrift Rocket runtime, mirroring the existing ZSTD/ZLIB level-aware codec implementations.

The wire format follows `folly::compression::CodecType::LZ4_VARINT_SIZE` used by the C++ runtime: an unsigned varint encoding the uncompressed length followed by raw LZ4 block-compressed data. This ensures cross-language interop with C++/Java/etc. clients and servers.

Level mapping mirrors the C++ folly behavior:
- `LZ4` (DEFAULT) and `LZ4_LESS` use the fast `lz4.Compressor`
- `LZ4_MORE` uses `lz4.CompressorHC` at `Level9` (matches folly's `highCompression_(level > 1)` rule)

Reference: prior diff D73549867 added level-specific support for ZSTD and ZLIB.
