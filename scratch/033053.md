Commit title: Add onRequestReceived hook to ServiceInterceptor
Commit body:
Summary:
Add a new `onRequestReceived` hook to `ServiceInterceptor` that fires synchronously for every request that reaches the central dispatch point (`Cpp2Worker::dispatchRequest`), before any admission or rejection decisions.

This provides a single observation point for all incoming requests. A request that triggers `onRequestReceived` will subsequently receive exactly one of `onRequest` (processed) or `onRequestDropped` (rejected). This is useful for metrics, logging, and tracing that need to observe all requests regardless of outcome.

Changes:
- Added `ReceivedRequestInfo` struct and `internal_onRequestReceived` virtual method to `ServiceInterceptorBase`
- Added typed `onRequestReceived` virtual method to `ServiceInterceptor<RequestState, ConnectionState>`
- Created `ServiceInterceptorOnReceived.h/.cpp` with `processServiceInterceptorsOnReceived` dispatch function
- Wired the hook at the top of `Cpp2Worker::dispatchRequest`, which is the convergence point for all transports (Rocket, Header, HTTP)
