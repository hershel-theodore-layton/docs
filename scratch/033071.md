Summary:
`platform.py` is the name of a python file / module in the getdeps python project.
its name shadows the python stdlib `platform` module.

The `import platform` expression is used in `platform.py` to import the python
stdlib module. In some contexts the python interpret will import the
`platform.py` getdeps file itself when executing the expression.

Rename `platform.py` to `getdeps_platform.py` to avoid name shadowing
