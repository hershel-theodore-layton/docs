Commit title: Expose getTlsVersion() on Connection
Commit body:
Summary:
MysqlConnection::getTlsVersion() exists at the low-level protocol layer but the user-facing Connection class does not expose it, even though it already exposes related SSL methods like sslSessionReused() and isSSL().

Add getTlsVersion() as a virtual method on InternalConnection (returning empty string by default), override it in ConnectionHolder to delegate to the underlying connection, and expose it on the public Connection class. MysqlConnection already has the implementation which calls mysql_get_ssl_version() under the hood.

This enables callers like the HHVM async MySQL extension to query the negotiated TLS version without reaching into internal protocol classes.
