Commit title: Fix use-after-free in HTTPBodyEvent move assignment
Commit body:
Summary:
HTTPBodyEvent::operator=(HTTPBodyEvent&&) calls this->~HTTPBodyEvent() to destroy the current object before reconstructing it from the moved-from value. The destructor destroys the byteEventRegistrations vector, freeing its backing storage. However, the subsequent line used move-assignment (operator=) on the destroyed vector instead of placement new construction. The vector move-assignment tries to destroy "old" elements that are in already-freed memory, causing a use-after-free.

The fix replaces the move-assignment with placement new construction, consistent with how the union event members are already handled in the same function.
