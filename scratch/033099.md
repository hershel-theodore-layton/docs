Commit title: getdeps: pass cmake defines to test step for consistent hashing
Commit body:
Summary: The getdeps test step was missing --extra-cmake-defines, causing GETDEPS_CMAKE_DEFINES to differ from the build steps. Since this env var is folded into every dep's hash, the test step computed different install-dir hashes than the build steps, so hash-based dep dirs (e.g. glog) were missing from LD_LIBRARY_PATH at test time. Fix: append cmake_arg_for(manifest.name) to the test command, matching how it is already applied to build commands.
