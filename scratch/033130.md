Commit title: json: add FloatFormat enum, route printer through fmt; deprecate dtoa_mode/dtoa_flags
Commit body:
Summary:
Bridge change to migrate folly::json off the double-conversion-backed Dtoa* API onto fmt. Introduces a new `folly::json::FloatFormat` enum (SHORTEST, SHORTEST_TRAILING_DOT_ZERO, FIXED, PRECISION) plus an `std::optional<FloatFormat> float_format` field on `serialization_opts` that takes precedence over the legacy `dtoa_mode`/`dtoa_flags` pair when set.

The JSON printer now dispatches double formatting through a 4-arm switch on `float_format`, calling `fmt::format_to` with literal `FMT_COMPILE`-parsed format strings. fmt's spec parsing happens at compile time, so the only runtime work beyond Dragonbox is precision-int substitution for FIXED/PRECISION — comparable to the old `DoubleToStringConverter` switch and ~3x faster on the actual format step (Dragonbox vs Grisu3).

When `float_format` is unset, the printer falls back to `toAppend` with the legacy `dtoa_mode`/`dtoa_flags` pair, preserving exact behavioral compatibility for all existing callers. They continue to format doubles exactly as before; no source changes required and no output differences. Follow-up diffs (T270785993) will migrate callers to `float_format`, after which the `toAppend` fallback and double-conversion dependency can be removed.

Note: the fields are intentionally NOT marked `[[deprecated]]` yet. Clang 19 treats the default member initializer `{}` on a `[[deprecated]]` struct field as a use of the deprecated member, causing compile errors wherever `serialization_opts` is default-constructed — including in unrelated translation units that merely include the header. The deprecation attribute will be re-added once the per-callsite migration in T270785993 is complete.

Why a closed enum instead of a free-form fmt-spec string field: a runtime `std::string double_format_spec` would force fmt to re-parse the spec on every double in the JSON document. JSON serialization is on the Thrift RPC hot path. The 4-value enum covers 100% of the actual usage patterns observed across the 71 Dtoa* callers in fbsource (76x FIXED, 27x PRECISION, 16x trailing-dot-zero, 5x SHORTEST_SINGLE, 3x SHORTEST, plus three rare flags that map to fmt defaults or 1-line site fixups).

New tests in JsonTest.cpp:
- FloatFormatField — verifies all four enum values produce the expected output.
- FloatFormatFieldOverridesLegacyDtoa — verifies the new field takes precedence.
- LegacyDtoaFieldsStillHonoredAsFallback — verifies backward compatibility for the deprecated pair.
