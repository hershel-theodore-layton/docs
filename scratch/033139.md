Commit title: Send StreamRpcError on bidi stream connection close
Commit body:
Summary:
When a connection closes, `RocketBiDiClientCallback::handleConnectionClose()` called `onStreamCancel()` on open streams without sending an error frame to the client. This caused clients to see a clean stream end (`StopAsyncIteration`) instead of an error, unlike regular streams where `RocketStreamClientCallback::handleConnectionClose()` sends a `StreamRpcError(SERVER_CLOSING_CONNECTION)` before cancelling.

Send the same `StreamRpcError(SERVER_CLOSING_CONNECTION)` error frame via `sendErrorAfterDrain()` before calling `onStreamCancel()`, matching the regular stream behavior. Clients now receive `ApplicationError(INTERRUPTION)` on bidi server disconnect.
