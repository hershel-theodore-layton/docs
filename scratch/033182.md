Commit title: Fix use-after-free in connection context logging
Commit body:
Summary:
Connection logging functions (logConnectionSuccess, logConnectionFailure, makeSquangleLoggingData) took raw const ConnectionContextBase* pointers that could dangle when the context outlived the connection, particularly in async callbacks passed to runInThread().

Changed all logging APIs to take shared_ptr<const ConnectionContextBase> instead of raw pointers. SquangleLoggingData now stores shared_ptr directly instead of a std::variant. Added getConnectionContextShared() to Connection for callers that need to extend the context lifetime.

Connection::getConnectionContext() still returns a raw pointer for public API compatibility, with a comment documenting the lifetime constraint.
