Commit title: Remove unused `peerHasWebsockets` from proxygen codecs
Commit body:
Summary:
Remove the `peerHasWebsockets()` method from `HQFramedCodec`, `HQStreamCodec`, and `HTTP2Codec`. This method is not called anywhere in the codebase outside of a single test assertion, which has been updated to check the underlying `ENABLE_CONNECT_PROTOCOL` ingress setting directly.

The HQ codec implementations always returned `false`, and the HTTP2Codec implementation was a thin wrapper around `ingressSettings_.getSetting(SettingsId::ENABLE_CONNECT_PROTOCOL)`. Removing this indirection simplifies the codec API without any behavior change.
