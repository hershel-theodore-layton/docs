Commit title: Remove `onIngressUpgradeMessage` from codec API
Commit body:
Summary:
Remove the `onIngressUpgradeMessage()` virtual method from `HTTPCodec` and all implementations across the codec hierarchy. This method was part of the HTTP/1.1 -> HTTP/2 upgrade path (h2c), which is no longer used.

Removed from:
- `HTTPCodec` — base virtual with default `return true`
- `HQFramedCodec` — override that returned `false`
- `HTTP2Codec` — override that parsed `HTTP2-Settings` header for h2c upgrade
- `HTTPParallelCodec` — override that set `lastStreamID_` on downstream
- `PassThroughHTTPCodecFilter` — passthrough delegation

Also removed the `HTTP2SettingsFailure` test which exclusively tested `onIngressUpgradeMessage` error paths.
