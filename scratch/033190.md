Commit title: Remove `generateCertificateRequest` and `generateCertificate` from codec API
Commit body:
Summary:
Remove the `generateCertificateRequest()` and `generateCertificate()` virtual methods from `HTTPCodec` and all implementations. These methods were part of the HTTP/2 secondary certificate authentication feature which has been fully removed.

Removed from:
- `HTTPCodec` — base virtuals with default `return 0`
- `HTTP2Codec` — implementations that wrote CERTIFICATE_REQUEST and CERTIFICATE frames
- `PassThroughHTTPCodecFilter` — passthrough delegations
- `MockHTTPCodec` — mock method declarations and unique_ptr-to-shared_ptr wrappers
- `TestUtils.cpp` — mock EXPECT_CALL setups
- `HTTP2CodecTest.cpp` — `BasicCertificateRequest` and `BasicCertificate` tests
