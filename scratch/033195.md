Commit title: Add RFC 9651 Structured Fields support
Commit body:
Summary: Add a new StructuredFields API beside the existing StructuredHeaders draft API. The implementation follows RFC 9651 Structured Field Values for HTTP, Section 3 data model and Section 4 parsing and serialization algorithms, including inner lists, ordered parameters, dictionaries, colon-delimited byte sequences, dates, and display strings. The older StructuredHeaders API is left intact for compatibility with its pre-RFC draft behavior.
