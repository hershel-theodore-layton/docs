Commit title: Add tables() and isReadOnly() to QueryGenerator
Commit body:
Summary:
The privacy check code in FbMysqlPrivacy.cpp used a 5-way dynamic_cast chain to determine the concrete QueryGenerator subclass, extract table names, and check if the query was read-only. This was fragile and required updating whenever new statement types were added.

Add two virtual methods to QueryGenerator:
- tables(): returns the set of table names referenced by the query. Default returns empty set (for raw query generators that do not reference tables). SqlIsMorpheme overrides this with the existing visitor-based implementation.
- isReadOnly(): returns true for read-only queries. Default returns false. SqlSelectQueryBase overrides to return true.

This eliminates the dynamic_cast chain in FbMysqlPrivacy.cpp — it now calls query_generator.tables() and query_generator.isReadOnly() directly.
