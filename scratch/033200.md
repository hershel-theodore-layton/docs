Commit title: Extract shared helpers from internalQuery and internalMultiQuery
Commit body:
Summary:
Refactors internalQuery and internalMultiQuery in Connection.cpp to share their common setup and execution logic via two private template helpers:

- applyQueryOptions: applies connection-level query timeout, merges persistent query attributes, checks for timeout overrides, sets the callback, and sets up operation callbacks
- runOperation: manages the operation-in-progress guard, runs pre-query callback, executes the operation, and throws on failure

Before this change, both methods had ~25 lines of identical code. After, each method is reduced to: create the operation (factory call), applyQueryOptions, runOperation, construct the result, and call post-query callback.

The helpers are kept separate (rather than combined into one) to maintain clear separation between configuration and execution, and to allow future callers to insert logic between the two steps if needed.
