Commit title: Reduce compile-time cost of ContextStack.h
Commit body:
Summary:
ContextStack.h is a transitive include of every generated thrift client. It currently pulls in folly/coro/BlockingWait.h and folly/coro/Task.h because two template methods (`processClientInterceptorsOnResponse` and `blockingWaitInterceptorResult`) had their bodies defined inline in the header. Those coro headers are expensive and most callers never need them — the async interceptor path is rare.

This diff removes the coro includes from the header. The template bodies now delegate to a non-template `resolveInterceptorResult` that checks the variant inline (fast path) and calls `resolveInterceptorResultAsync` in the .cpp only when a Task is present (slow path). The coro deps move from `exported_deps` to `deps` in BUCK.

Explicit instantiation for `T=void` (the dominant case) avoids redundant template compilation across translation units.
