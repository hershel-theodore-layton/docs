Summary:
Fix C++ source files for OSS build compatibility with GCC 14, C++20, and newer system libraries. These are backwards-compatible changes that don't affect the internal buck2 build.

- compiler-systemlib.cpp: add missing boost/filesystem/string_file.hpp include
- ext_gd.cpp: add heif_reader_grow_status_error compat alias for libheif 1.13+ (inside namespace, version-guarded)
- ext_openssl.cpp: add const qualifiers to match OpenSSL 3.x API (EVP_PKEY_get0_RSA/DSA/DH return const pointers); use EVP_PKEY_get1_RSA for mutable access in encrypt/decrypt paths
- check.cpp, ir-unit-inl.h: use opcodeName() instead of passing Opcode enum directly to fmt::format (required by fmt v12)
- prof-data-target-profile.h: move explicit template specializations out of class body (GCC rejects in-class)
- disasm.h: add missing cstdint include for uint64_t
