Summary:
Fixes test runner infra:

1. process_test.ml — Close inherited FDs at startup (root cause of 5 failing tests)
The buck test runner leaks FDs (48, 61, 86, 525, 582) into the test process. The FD leak detector (assert_no_fd_leaked) found gaps in FD numbering caused by these inherited FDs, not by actual leaks in process.ml. Added close_inherited_fds() to close all FDs above stderr before tests run.

2. process_test.ml — Use false instead of command_that_doesnt_exist (root cause of test 12 failure) Unix.create_process raises ENOENT when the command doesn't exist, which crashes the test instead of returning a failed process. Changed to false which spawns successfully but exits with status 1, testing the intended Future error-mapping path.

3. process.ml — Close pipe FDs on create_process exception (defensive fix) When Unix.create_process throws (e.g., ENOENT), the 6 pipe FDs were leaked. Added a try-with to close all FDs before re-raising.
