Commit title: Collect constraints from dynamic locals use
Commit body:
Summary:
Adds infrastructure to infer how dynamic locals are used. Each local assigned type dynamic gets a shadow type variable, gated by a flag, that accumulates upper-bound constraints from usage sites:
- function arguments,
- member access,
- array indexing,
- await, and
- function calls.

The shadow tyvars are never solved and don't affect typechecking behavior.

A new `--infer-dynamic` mode in hh_single_type_check dumps the collected constraints, showing which locals are dynamic and what structural types they're used as.

This is intended to drive codemods that add explicit type annotations to dynamic code.
