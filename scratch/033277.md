Commit title: Use paired stores for memo slot init
Commit body:
Summary:
For small object memo-slot initialization on ARM, lower each slot to a paired 64-bit store using Vasm constants: `v.cns(0)` for the data word and a hoisted `KindOfUninit` register for the type/aux word. Add two ARM immediate folds so zero constants in `storepair`/`storepairl` become `xzr`/`wzr`.

x64 still keeps using `storebi` for the type byte because that immediate byte store (3 bytes) is shorter than materializing a full-width register and using `store` (7 bytes).
