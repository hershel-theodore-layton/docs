Commit title: Add callable-source hazptr try_protect overload
Commit body:
Summary:
Add a hazptr_holder::try_protect overload that accepts a callable source returning T*. This keeps the same protect, fence, reload, and compare sequence as the existing atomic-pointer overload, but lets callers use the standard hazptr shape when their shared location is not itself an atomic<T*>.

The existing atomic-pointer try_protect overloads now delegate through the callable-source overload, so the implementation remains in one place.
