Commit title: Suppress error when mangledsvcs is used without `namespace php`
Commit body:
Summary:
Part of the namespace unification effort. When a thrift file uses
`mangledsvcs` but no longer declares `namespace php`, the Hack generator
previously threw a hard error that blocked the CI signal on the diff.

This change allows the generator to proceed when a `edward-io.NamePrefix`
annotation (service-level or program-level) is present and provides the
name disambiguator that would normally come from the php namespace. Without
NamePrefix, the generator still throws — but with an updated message that
mentions `edward-io.NamePrefix` as an alternative.

Before: `cannot generate mangled services for <S>; no php namespace found`
After:  succeeds when `edward-io.NamePrefix` is set; otherwise throws
        `cannot generate mangled services for <S>; no php namespace or
        edward-io.NamePrefix found`
