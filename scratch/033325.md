Commit title: log when interpreting functions and live translations
Commit body:
Summary:
For live function detection, we want to log the first time a function is translated or called in the interpreter. This diff adds a new flag to functions that marks whether it was ever called, starts setting that flag when we translate/interpret a call to it, and moves the logging machinery to its own file since we now call it from multiple places.

The setup is behind a sample rate, and has a flag to allow only logging live translations, as we have the Eval.LogJitProfileLiveness flag to control whether to batch-log optimized/profile translations.

We always default to logging live functions as RepoAuth for now, future changes will add test and sandbox detection.
