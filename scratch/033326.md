Summary:
`ConstantEnumSpec` and `ConstantUnionSpec` were defined in `constants_reflection.py` but never emitted by the code generator — enum annotation values were rendered as raw integers with `ThriftType.I32`, and union annotation values were rendered as `ConstantStructSpec` with `ThriftType.STRUCT`.

This diff wires them up properly:
- `const_value.whisker`: the `value:enum?` branch now emits `_ConstantEnumSpec(enum_type=..., value=...)` with `thrift_type=_ThriftType.ENUM` instead of a raw integer
- `const_value.whisker`: a new `value:type.union?` branch (checked before `value:structured?`) emits `_ConstantUnionSpec(union_type=..., field=..., value=...)` with `thrift_type=_ThriftType.UNION`
- `thrift_reflection.py.whisker`: imports `ConstantEnumSpec` and `ConstantUnionSpec`
- `ReflectionAnnotation` in `test_thrift.thrift`: adds `Color color` and `Integers int_union` fields to exercise both paths
