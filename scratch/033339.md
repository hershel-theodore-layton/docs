Summary:
Replace the manual 2-case switch in `HeaderClientChannel::setRequestHeaderOptions()` with `CompressionAlgorithmSelector::fromCodecConfig()` + `toTTransform()`. This adds support for LZ4, ZSTD_LESS, ZSTD_MORE (and ZLIB_LESS/MORE, LZ4_LESS/MORE) on the THeader transport path, which previously only handled ZLIB and ZSTD.

The THeader transform/untransform code already delegates to CompressionManager which handles all TTransform values, so receivers are unaffected.
