Commit title: Add LZ4 compression support to Go THeader transport
Commit body:
Summary:
Add LZ4 as a supported transform in Go's THeader transport. This enables Go THeader servers to decompress LZ4-compressed requests and Go THeader clients to send LZ4-compressed requests.

LZ4 uses varint-prefixed block compression matching the C++ wire format (`folly::compression::CodecType::LZ4_VARINT_SIZE`). The `Untransformer` reads the full payload, parses the varint size prefix, and decompresses the LZ4 block with a bounds check to reject implausibly large allocations.

### Changes:
- header.go: Add `TransformLz4` constant (ID 6), add to `supportedTransforms`, add `Untransformer` case with block decompression
- header_transport.go: Add LZ4 case to `applyTransforms` with block compression
