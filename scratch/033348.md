Summary:
Add `fields_by_name` property and `get_field()` method to `StructSpec` for convenient field lookup by name.

`fields_by_name` returns a `MappingProxyType[str, FieldSpec]` keyed by `py_name`, lazily built and cached on first access. The cache is invalidated when `add_field()` is called.

`get_field(name)` looks up a field first by `py_name` (via `fields_by_name`), then falls back to scanning by thrift `name`. This handles the common case where `py_name == name` efficiently while still supporting renamed fields (e.g. `name` -> `name_`).

Also simplifies the test helper `_get_field_spec` to use `get_field()` instead of manually building a dict.
