Commit title: Define synchronized access for mutable struct fields
Commit body:
Summary:
Free-threaded Python makes concurrent mutable struct field assignment a caller-synchronization concern. Add contract tests for caller-owned locks around concurrent scalar field writes and same-lock readback.

Additional Context:
PEP 703 (Making the Global Interpreter Lock Optional in CPython, https://peps.python.org/pep-0703/) does not make arbitrary setter logic atomic. Mutable thrift struct field assignment runs thrift-owned setter code, so callers that need deterministic concurrent mutation must provide explicit synchronization. These tests document that supported pattern.
