Commit title: Add `Observer::with()` for safe scoped access to observed values
Commit body:
Summary:
Add a `with()` method to `folly::observer::Observer` that invokes a lambda with a `const T&` while keeping the snapshot alive for the duration of the call. This prevents read-after-free bugs that can occur when accessing members of the observed object without holding a snapshot.

The return type is `std::decay_t` to prevent accidentally returning a reference into the snapshot data, which would dangle after the snapshot is destroyed. The method also conditionally propagates `noexcept` from the callable.

Example usage:
```
auto blocked = config_->with([&](const auto& cfg) {
  for (auto r : *cfg.fileRegexesBlocklisted()) {
    re2::RE2 regex(r);
    if (re2::RE2::FullMatch(externalId, regex)) {
      return true;
    }
  }
  return false;
});
```
