Commit title: Refactor coroutine lambdas to eliminate capture lifetime fragility
Commit body:
Summary:
D105935219 fixed a coroutine-lambda-capture lifetime bug in `toServerSinkFactory` by moving the captured `innerConsumer` into a local variable on the first line of the coroutine body. This works but is a non-obvious pattern that future editors could inadvertently undo.

This diff extracts coroutine bodies into named functions where the formerly-captured values become regular parameters. Function parameters are copied into the coroutine frame by the compiler, so the lifetime issue is eliminated structurally rather than patched around. The wrapper lambdas become trivial non-coroutine forwarders.
