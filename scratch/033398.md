Commit title: Add onConnectionAccepted hook with per-connection ThriftConnContext
Commit body:
Summary:
Adds a `setOnConnectionAccepted(OnConnectionAcceptedFn)` API on `FastThriftServer` that fires once per accepted connection (post-TLS handshake when TLS is enabled). The callback receives a per-connection `ThriftConnContext` so embedders (e.g., ucache) can stash per-connection state via `setUserData` that lives for the connection lifetime.

Wires `ThriftServerRequestContextHandler` and `ThriftServerConnectionContextHandler` into both the composite and simple thrift pipelines so each request's `ThriftRequestContext` is populated with the connection context. The `ThriftConnContext` is held via `boost::intrusive_ptr` so in-flight requests can extend its lifetime past the connection close.

Peer address is snapshotted off the socket on accept (post-handshake when TLS is on) and stored on the `ThriftConnContext` so it remains reachable via `connContext.getPeerAddress()`.

Mirrors the prior off-stack prototype on the ucache branch.
