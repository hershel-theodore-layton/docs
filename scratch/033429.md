Commit title: thrift/JsonWriter: migrate writeFloatingPoint from folly::toAppend+DtoaMode to fmt
Commit body:
Summary: `writeFloatingPoint` was the last first-party caller of `folly::toAppend(T, string*, DtoaMode, numDigits, DtoaFlags)` outside of folly itself. It used `DtoaMode::SHORTEST_SINGLE` for `float` and `DtoaMode::SHORTEST` for `double`, both with `EMIT_TRAILING_DECIMAL_POINT | EMIT_TRAILING_ZERO_AFTER_POINT` — which is exactly `fmt::format("{:#}", t)`. Finite values are now formatted directly with `{:#}`. NaN and Infinity are handled explicitly before the fmt call to preserve the canonical spellings ("-NaN", "NaN", "Infinity", "-Infinity") that Thrift JSON clients expect; fmt would otherwise emit "nan"/"inf". Drops the now-unused `#include <folly/Conv.h>`. This is a prerequisite for removing double-conversion from `folly/Conv.h`.
