Summary: When checking `__Override` on methods imported from traits, use the folded class element position already available on `ce_pos` instead of looking the method back up in `Decl_store`. The Rust provider does not necessarily populate that store, so the old lookup could fall back to `Pos_or_decl.none` and report `File "", line 0` for the declaration location. Add a multi-file `////` regression test to assert that the declaration location still points at the trait file.
