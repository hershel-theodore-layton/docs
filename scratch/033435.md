Commit title: Hierarchical decl directories
Commit body:
Summary:
Each typecheck RE action includes decl files in flat decls{i}/ directories — potentially 20K-97K entries (based on the current data). Changing (or adding/removing) even one decl results in a new blob which reduces CAS caching between distc runs on different revisions.

What this diff does:
Splits each flat `decls{i}/` directory into subdirectories using content-based hashing. Each decl blob's digest determines its subdirectory (`digest_first_byte % num_buckets`). This produces smaller directory nodes and enables CAS to share identical subdirectory nodes across batches and revisions — because the same decl blob always lands in the same bucket everywhere.

Rollout
Changes are gated by JK which is set to 0 at the moment. Worker implementations is both backwards and forward compatible. Number of buckets is set by JK is well and set to 64 at the moment.
