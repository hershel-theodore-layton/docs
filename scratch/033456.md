Commit title: Add LZ4 compression support to py-deprecated THeaderTransport
Commit body:
Summary:
Add LZ4 (transform ID 0x06) as a supported transform in the py-deprecated
THeaderTransport. This enables Python py-deprecated THeader clients and
servers to handle LZ4-compressed frames.

Uses varint-prefixed LZ4 block compression matching the C++ wire format.
The lz4.block module is imported conditionally (same pattern as snappy/zstd)
with a DummyLz4Block fallback that raises INVALID_TRANSFORM if the module
is unavailable.

Changes:
- Add TRANSFORM.LZ4 = 0x06 constant
- Add conditional lz4.block import with fallback
- Add LZ4 to accepted transform IDs in read_header_format()
- Add LZ4 compress in transform() (getVarint prefix + lz4.block.compress)
- Add LZ4 decompress in untransform() (readVarint + lz4.block.decompress)
