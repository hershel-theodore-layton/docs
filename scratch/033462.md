Commit title: Document concurrent append and map assignment for prebuilt mutable structs
Commit body:
Summary:
Free-threaded Python needs clear rules for mutable thrift containers that hold struct objects. This diff covers the narrow case where each mutable thrift struct already exists before the container operation starts.

The tests cover two cases. Several threads append prebuilt mutable thrift structs into one shared mutable thrift list. Several threads assign prebuilt mutable thrift structs into one shared mutable thrift map with different keys.

The structs include both simple fields and a pre-filled container field. That detail matters because the inner data already exists before append or map assignment. This diff tests the outer container operation only.

This diff does not cover field assignment inside the struct. It does not claim two threads can mutate the same struct fields without a lock. It does not cover set insertion for mutable structs. It does not claim append or map assignment rebuilds or checks inner struct fields.
