Commit title: Document that shared Python input mutation concurrently with thrift assignment produces only valid values
Commit body:
Summary:
Shared Python input races should document valid outcomes, not a deterministic winner.

- e.g. `list` assignment while another thread replaces a value produces `[1, 2, 3]` or `[1, 99, 3]`.
- e.g. `dict` assignment while another thread replaces a value produces `{"a": 1, "b": 2}` or `{"a": 1, "b": 99}`.
- Mutable struct list-field assignment follows the same rule for `to_thrift_list(shared)`.
- A start barrier keeps the race real; each assertion accepts either complete state and rejects partial or corrupt thrift values.
