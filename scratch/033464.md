Commit title: Document that shared Python container size change during thrift assignment produces valid values or raises for sets
Commit body:
Summary:
Shared Python input size changes need explicit coverage because CPython treats container iteration differently by type.

- `list` append while thrift assignment reads the input produces the old complete list or the appended complete list.
- `dict` key addition while thrift assignment reads the input produces the old complete map or the added-key complete map.
- `set` add while thrift assignment reads the input can produce a complete set or raise `RuntimeError("changed size during iteration")`.
- No case publishes a partial or corrupt mutable thrift value.
