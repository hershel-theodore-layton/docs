Commit title: Add split_types option to Thrift Hack code generator
Commit body:
Summary:
Adds a `split_types` compiler option to the Thrift Hack code generator that produces one file per type (struct, enum, union, exception) instead of bundling everything into a single `<program>_types.php`.

When enabled:
- Each struct/union gets `<TypeName>.php`
- Each enum gets `<EnumName>.php` (includes the `_TEnumStaticMetadata` companion class)
- Each exception gets `<ExceptionName>.php`
- `_types.php` is still generated but only contains namespace/module declarations and typedefs/wrapper type aliases
- Services and constants files are unaffected (services were already one-per-file)

The feature is gated by a JustKnob `thrift/hack:split_types` with the thrift package name as switchval, allowing per-package rollout. It can also be enabled per-package via `ThriftCompilerOptions::SPLIT_TYPES` in the package info.

The Meerkat build pipeline requires no changes since `ThriftMeerkatStep` already handles arbitrary numbers of output files via `Filesystem::listDirectory`.
