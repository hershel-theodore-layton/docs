Summary:
Add MESSAGE_ERROR and FLOW_CONTROL_ERROR to checkInvalidAppErrorCode so the guard catches them before HTTPErrorCode2ErrorCode and HTTPErrorCode2HTTP3ErrorCode hit their XCHECK(!fromSource). Same pattern the guard already uses for PROTOCOL_ERROR and GENERAL_PROTOCOL_ERROR.

These two codes are reachable from sources today, e.g. FLOW_CONTROL_ERROR via HTTPStreamSource when a peer exceeds flow control, and MESSAGE_ERROR via sourceCompleteErr2ErrorCode mapping INVALID_STATE_TRANSITION. transferBody forwards the upstream source's error code through egressResetStream with fromSource=true, which then crashes the H2 path.
