Commit title: Refactor `Cpp2Connection::requestReceived` into smaller helpers
Commit body:
Summary:
`Cpp2Connection::requestReceived` was a ~330-line monolithic method handling client type validation, transport upgrades, failure injection, preprocessing, and request dispatch all in one function body. This change extracts five focused private helpers while keeping `requestReceived` as a concise orchestrator with early returns:

- `rejectUnsupportedClientType`: validates HTTP/framed/unframed client types and disconnects if rejected
- `handleUpgradeToRocket`: handles the `upgradeToRocket` transport upgrade flow including finding the Rocket handler and sending the upgrade reply
- `handleInjectedFailure`: dispatches `maybeInjectFailure()` results (error/drop/disconnect)
- `handlePreprocessResult`: handles `checkOverload` and `preprocess` results, dispatching to the appropriate error handler for each variant
- `buildAndDispatchRequest`: extracts the serialized request, computes timeouts, creates the `Cpp2Request`, sets up timestamps, schedules timeouts, and dispatches to `Cpp2Worker::dispatchRequest`

The resulting `requestReceived` method is ~65 lines and reads as a clear top-level pipeline. No behavioral changes.
