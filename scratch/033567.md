Commit title: Optimize ARM64 double compares against zero
Commit body:
Summary:
Add ARM64 zero-immediate VASM forms for scalar double compares against zero. `cmpsd` folds to `cmpsdz` and emits `fcmeq dN, dM, #0.0`; `ucomisd` folds to `ucomisdz` when its second operand is a known +0.0 or -0.0 constant and emits `fcmp dN, #0.0`.

Update `cgConvDblToInt` to compare `src` against `0.0` instead of `0.0` against `src`, with the condition code adjusted from `CC_NB` to `CC_BE` on x64 and `CC_LE` on arm64, so the zero operand is in the immediate-foldable position while preserving unordered handling.
