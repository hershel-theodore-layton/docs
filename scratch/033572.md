Summary:
Add per-ALPN early data handler dispatch to HQServerTransportFactory.
The factory itself implements EarlyDataAppParamsHandler and dispatches
validate() to the appropriate per-ALPN handler based on the negotiated
ALPN. This allows different protocols (e.g. H3 vs MoQ) to use their
own early data validation logic.

- HQServerTransportFactory owns an H3EarlyDataHandler for H3 ALPN
- addAlpnHandler() accepts an optional EarlyDataAppParamsHandler per ALPN
- Factory's validate() dispatches by ALPN, get() delegates to default handler
- Consolidate duplicated H3 settings into kH3EgressSettings constant
