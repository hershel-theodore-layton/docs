Commit title: Add pre/post-index addressing modes for load/store instructions (#9661)
Commit body:
Summary:
Add AArch64 pre-index and post-index addressing mode variants for all load and store vasm instructions. This enables folding adjacent base register updates (addqi, lea, subqi) into the load/store itself, reducing instruction count.

Adds new vasm opcodes (e.g. loadpri/loadpi, storepri/storepi) for each existing load/store, along with simplification passes to match and fold the patterns, and emission support in vasm-emit-arm.

The writeback folding includes bail-out checks to skip the fold when the base register aliases any data register, since the original and rewritten forms have different semantics when registers overlap. For example, `load{base[0], base}; addqi{8, base, base}` loads a value into base then adds 8 to the loaded value, but a post-indexed `loadpi` would add 8 to the original address instead.
