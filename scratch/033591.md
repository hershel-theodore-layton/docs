Commit title: Implement `get_locally_set_fields` API for `@python.EnableUnsafeIssetInspection`
Commit body:
Summary:
Implements the code generation and runtime support for `python.EnableUnsafeIssetInspection`, providing a replacement for `isset_DEPRECATED` that tracks which fields were explicitly passed to the constructor. This is part of the effort to remove `isset_DEPRECATED` per https://fb.workplace.com/groups/thrift.py3/permalink/3353125214839247/.

The new `get_locally_set_fields(struct)` API returns a `frozenset[str]` of field names that were explicitly passed as kwargs to the constructor or functional update (`__call__`). Unlike `isset_DEPRECATED`, this tracking is independent of `_fbthrift_data[0]` isset bytes, enabling their eventual removal.

Two clear error/fallback states:
- Not annotated: `AttributeError` ("does not support locally set field inspection")
- Annotated but deserialized: logs an error and falls back to considering all unqualified/terse fields as set, and optional fields as set if their value is not `None`

Implementation:
- **Compiler**: Add URI constant for the annotation, expose `enable_unsafe_isset_inspection?` property in `t_mstch_python_generator.cc`, emit `_fbthrift_enable_unsafe_isset_inspection = True` class attribute in the Whisker template for annotated structs. Add `IssetInspectionStruct` to the py3 fixture to exercise codegen.
- **Runtime**: Store the flag on `StructInfo` as a `cdef bint` (one per struct type, zero per-instance overhead). In `__cinit__`, initialize `_fbthrift_isset_fields` slot to `None` for annotated structs. In `__init__`, populate it with `frozenset(kwargs.keys())`. Deserialized structs bypass `__init__`, so the slot stays `None`. The `__call__` (functional update) method propagates isset tracking: the copy's isset fields are the union of the original's isset fields and the non-None kwargs passed to `__call__`. Copies of deserialized structs remain untracked.
- **Fallback** (`types.pyx`): `_get_set_fields_fallback` helper uses field qualifiers from `StructInfo.fields` to determine set fields for deserialized structs, replacing the old `isset_DEPRECATED` delegation.
- **Performance**: The hot-path check is a direct C struct field access on `StructInfo` — no Python attribute lookup or `getattr` overhead for non-annotated structs
