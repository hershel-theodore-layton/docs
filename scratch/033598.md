Commit body:
Summary:
X-link: https://github.com/facebookincubator/fizz/pull/168

Adds a build-time selectable logging backend to fizz. Default remains glog, preserving existing behavior. Opt in to folly's xlog with `-DFIZZ_LOGGING_FOLLY_LOGGING=1` (Buck) or `-DFIZZ_LOGGING_FOLLY_LOGGING=ON` (CMake), or strip logging entirely with `FIZZ_LOGGING_DISABLED`.

The selection is enforced in `fizz/util/Logging.h` via a `static_assert` that exactly one of the three macros is defined. Compile defs are propagated PUBLIC from the `fizz` CMake target so downstream consumers including `Logging.h` see a consistent macro state.

Call sites across `client/`, `protocol/`, `tool/`, `util/`, `experimental/ktls/`, and tests migrate from raw `CHECK` / `<glog/logging.h>` to `FIZZ_CHECK` / `<fizz/util/Logging.h>`, with the matching `//fizz/util:logging` BUCK dep added.

`tool/Main.cpp` is simplified to use `folly::Init`, which parses gflags (`--logging`, `--v`, `--vmodule`) and initializes whichever logging backend is linked. This replaces the hand-rolled verbosity parser and `InitGoogleLogging` call, and makes `--logging=...` work end-to-end against the folly xlog backend.

CMake link lists for `FizzTool`, `BogoShim`, and `EncryptedRecordBench` are filled in with the granular folly targets they actually need (async_ssl_socket, server_socket, ssl_context, executors, stats, json, init), matching the Buck deps. Also fixes the `Folly::folly_benchmark` → `Folly::follybenchmark` target-name typo so `EncryptedRecordBench` links.

Drive-by BUCK fixups picked up while building:
- `facebook/python`: drop pinned boost `1.77.0`
- `facebook/x509verifier`: `fbsource//xplat/folly/lang:bits` → `//folly/lang:bits`
- `record/test/facebook`: `aes128gcm` → `aes128gcm_openssl`
- `protocol/test`: `handshake_test_lib` → `handshake_test`
