Commit title: Add `get_locally_set_fields` API
Commit body:
Summary:
Adds `get_locally_set_fields()` to `thrift.py3.types`, providing the same API as the thrift-python version for py3 structs annotated with `python.EnableUnsafeIssetInspection`.

For py3 structs, the implementation uses the existing C++ isset bits (via `_fbthrift_isset()`), so no per-instance tracking overhead is needed. Structs without the annotation raise `AttributeError`. For thrift-python structs, the function delegates to `thrift.python.types.get_locally_set_fields`.

Changes:
- **Runtime** (`thrift/lib/py3/types.pyx`): Add `get_locally_set_fields()` function with dispatch for py3 and thrift-python types, plus annotation check
- **Codegen** (`t_mstch_py3_generator.cc`, `types.pyx.whisker`): Expose `enable_unsafe_isset_inspection?` property and emit `_fbthrift_enable_unsafe_isset_inspection = True` on annotated py3 structs
- **Type stubs** (`types.pyi`): Add function signature
- **Fixtures**: Regenerated py3 fixture
