Commit title: Make base64_platform_test a runnable unit test
Commit body:
Summary:
The `base64_platform_test` target in `fbcode` and `xplat` was set up as a library, so it could not be run as a test. This change turns it into a real unit test by changing `fb_dirsync_cpp_library` to `fb_dirsync_cpp_unittest` in the BUCK files. It also fixes a bug in the `IndexLookup` test where the code tried to look up the null terminator character but the string view was too short to allow that. The fix changes `kBase64EncodeTable` from a plain char array to a `std::string_view` that includes the null terminator, and updates the test to use `.size()` instead of `strlen`.
