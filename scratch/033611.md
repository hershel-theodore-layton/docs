Commit title: Add class constant support
Commit body:
Summary:
This diff adds support for class constants (`const int FOO = 42;`) as a new symbol type in the FindMyTests implementation within hh.

References TO class constants: When expanding a class constant node, we:
- Find methods that read the constant
- Find other class constants whose definitions reference it
- Adds the enclosing class as a graph successor (same pattern as type constants)

References FROM class constants: When expanding a class or typedef node, we detect references inside class constant initializers:
- `const string X = Foo::class;` (class pointer)
- `const string X = nameof Foo;` (nameof expression)
