Commit title: approximate the affects_prod_build flag for symbols under if
Commit body:
Summary:
Extends the `affects_prod_build` tracking in `identifySymbolService` so symbols in a block after an `invariant (package intern);`statement, or in the then branch of `if (package intern)` are marked with `affects_prod_build=false` (and similarly for `if (!package intern)` and the else branch).

Remark: this is a crude approximation of flow typing of package assertions.  In particular, given the pattern:

```
if (!package intern) return;
...XXX...
```

symbols in `XXX` will _not_ be marked with `affects_prod_build = false`.
