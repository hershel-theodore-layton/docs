Commit title: Add isTransportEncrypted() and isTransportAuthenticated() to Cpp2ConnContext
Commit body:
Summary:
Service owners currently have to do fragile string comparisons against getSecurityProtocol() to determine if their thrift requests are encrypted. There are 4 different incompatible definitions of "is TLS" scattered across the codebase, and services like Zeus have bugs where they only check for "TLS" and miss Fizz connections entirely.

This adds two simple inline helpers to Cpp2ConnContext:
- isTransportEncrypted(): true when data is encrypted on the wire (TLS, Fizz, Fizz/KTLS, PSP)
- isTransportAuthenticated(): true when any security protocol is active (all non-plaintext transports)

isTransportEncrypted() intentionally differs from SecureThriftUtil::isTls() by including PSP — isTls() asks "is this TLS?" while isTransportEncrypted() asks "is data encrypted?" PSP uses hardware-accelerated encryption (not TLS), so it's encrypted but not TLS.

These do NOT modify SecureThriftUtil::isTls() — existing callers (payments, root canal, dfsrouter) are completely unaffected.
