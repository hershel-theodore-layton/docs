Commit title: Remove dead `Struct.isset_DEPRECATED` and `Struct.isset` API from py3 runtime
Commit body:
Summary:
All external usage of `Struct.isset_DEPRECATED` and `Struct.isset` has been migrated to `get_locally_set_fields`. This diff removes the dead API from `thrift.py3.types` and cleans up all tests in `thrift/lib/py3`.

While the generated thrift-py3 code still has an isset feature, this is only accessible now via `get_locally_set_fields`, which is gated behind the annotation `python.EnableUnsafeIssetInspection` to discourage new usage.

**Runtime changes (`types.pyx`, `types.pyi`):**
- Remove `StructMeta.isset_DEPRECATED()` and `StructMeta.isset()` static methods, the `HasIsSet` protocol, `_IsSet.__repr__`, and the unused `_fbthrift_python_isset` import
- Keep `_IsSet` class (used by generated py3 code in `_fbthrift_isset()`)
- Update `get_locally_set_fields` to inline the dispatch logic previously in `isset_DEPRECATED`, including the `_FBTHRIFT__PYTHON_CLASS` case for in-place migrated types
- Widen `get_locally_set_fields` type stub to accept `Struct | GeneratedError`

**Test cleanup (`auto_migrate/`):**
- Remove tests that purely tested the dead API: `test_isset_Struct`, `test_isset_repr`, `test_isset_Union`, `test_isset_Error`
- Remove isset assertions from `test_deserialize_unset_enums`, `test_defaulted_optional_field`, and `test_field_level_terse_write` (kept the core deserialization/serialization/optional-defaults coverage)
- Migrate `test_optional_defaults` in converter to assert on field values instead of isset
- Remove now-unused imports and the local `brokenInAutoMigrate` function from converter

**New test coverage for `get_locally_set_fields`:**
- Add `ErrorWithIssetInspection` exception to `test_thrift.thrift` with `python.EnableUnsafeIssetInspection`
- `test_generated_error`: verifies `get_locally_set_fields` on annotated `GeneratedError` (py3 mode; thrift-python codegen does not propagate the annotation to exceptions)
- `test_generated_error_not_annotated_raises`: verifies `AttributeError` on unannotated `GeneratedError`
- `test_union_raises`: verifies `get_locally_set_fields` rejects unions
- `test_deserialized_struct` / `test_deserialized_default_struct`: verifies behavior after serialization round-trip (unqualified fields become "set", unset optional fields stay absent)
