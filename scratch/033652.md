Commit title: Support multiline values in .hhconfig via leading-whitespace continuation
Commit body:
Summary:
Lines starting with whitespace (space or tab) are now treated as continuations of the previous key's value. This allows JSON config values like `enable_experimental_stx_features` to be written across multiple lines for readability:

```
enable_experimental_stx_features = {
  "foo": "Unstable",
  "bar": "Preview"
  }
```

Rules:
- Continuation lines must start with space or tab
- Trimmed content is concatenated directly (no separator)
- Blank lines and non-indented `#` comments break continuation
- Indented `#` comments within a continuation block are skipped
- Orphan continuation lines (no preceding key) are ignored
- `from_args` (CLI --config overrides) is unchanged
