Commit title: Remove `_IsSet` class from py3 runtime, return plain dict from `_fbthrift_isset()`
Commit body:
Summary:
Generated py3 code was wrapping isset results in an `_IsSet` namespace object. Since `isset_DEPRECATED` is removed and the only consumer is `get_locally_set_fields` (which just needs a `dict[str, bool]`), simplify by returning a plain dict.

**Template changes (`py3/types.pyx.whisker`, `py3/types.pyi.whisker`):**
- Remove `from thrift.py3.types import _IsSet as _fbthrift_IsSet` import from generated code
- Change `_fbthrift_isset()` to return a plain `dict` instead of `_IsSet("StructName", {...})`
- Remove `__fbthrift_IsSet` inner class from generated `.pyi` stubs (was only used by the removed `isset_DEPRECATED` API)

**Runtime changes (`types.pyx`):**
- Remove `_IsSet` class
- Update `get_locally_set_fields` to use the dict directly instead of calling `vars()` on an `_IsSet` object
