Commit title: Add `LOG(ERROR)` for `Union.fromValue` type mismatch
Commit body:
Summary:
`Union.fromValue` already emits a `RuntimeWarning` when the provided value does not match any field of the union. This adds a C++ `LOG(ERROR)` via GLOG alongside the existing warning, following the same pattern as `logGetLocallySetFieldsCalledOnDeserializedStruct`. The new `logUnionFromValueTypeMismatch` function in `types.cpp` logs the value repr, type, and union name at ERROR severity.
