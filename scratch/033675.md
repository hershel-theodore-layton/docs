Commit title: add checkRequestEncryptionState() dispatch to populate per-request encryption state for all thrift requests
Commit body:
Summary:
Add the dispatch function `apache::thrift::rocket::context_utils::checkRequestEncryptionState(Cpp2RequestContext&)` that reads the connection's transport state and StopTLSv2 record layer state at request-dispatch time and sets `Cpp2RequestContext::setRequestEncryptionState()` to one of `Plaintext`, `Encrypted`, `StoptlsEncrypted`, `StoptlsSkipped`. Wired into both rocket server dispatch paths.

the dispatch populates the enum for ALL traffic types (not just StopTLSv2):
- StopTLSv2 connections: walks the cast chain `Cpp2ConnContext → AsyncTransport → AsyncFizzServer → ReadRecordLayer → CompositeReadRecordLayer` and reads the sticky `hasObservedPlaintext()` latch (from D102861984). Sets `StoptlsSkipped` if plaintext has been observed, else `StoptlsEncrypted`. Fails safe to `StoptlsSkipped` if the record layer is unreachable.
- All other connections: uses the `isTransportEncrypted()` helper from D101058862. Sets `Encrypted` for TLS/Fizz/Fizz/KTLS/PSP, `Plaintext` for plaintext or unknown protocols.

Three layered gates ensure minimal overhead: (1) THRIFT_FLAG check (free when off), (2) string compare against `kSecurityProtocolStopTLSV2` (avoids dynamic_cast for non-StopTLSv2 conns), (3) composite isStopTLSNegotiated() check.

Wire-up: called from `setupRequestMetadata` (refactored path) in `RocketContextUtils.cpp` and `handleRequestCommon` (legacy path) in `ThriftRocketServerHandler.cpp`, after `setWiredRequestBytes`.

Note: THRIFT_FLAG_DEFINE for `server_request_encryption_tracking_enabled` was relocated from `RocketContextUtils.cpp` to the new `RequestEncryptionStateDispatch.cpp` to avoid a circular BUCK dep (RocketContextUtils now depends on RequestEncryptionStateDispatch).

Once this lands AND the THRIFT_FLAG is enabled per-cluster, `perfpipe_thrift_request_events.request_encryption_state` and `warm_storage_storage_service.request_encryption_state` will start populating.
