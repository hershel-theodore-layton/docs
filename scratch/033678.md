Fixes the rebase error from D107161639, which removed the `ErrorWithIssetInspection` fixture and would have deleted the exception-coverage test for `get_locally_set_fields`.

Instead of dropping the test, this re-points it at the `UnusedError` thrift exception (already imported in this file) and removes the now-unused `ErrorWithIssetInspection` import. This brings the thrift-python test suite to parity with the equivalent `test_generated_error_raises` coverage in the py3 runtime.
