Commit title: Upgrade CMake to 3.31.12 and fix Windows sccache via /Z7
Commit body:
Summary:
Upgrade the pinned CMake from 3.20.4 to 3.31.12 on all platforms and fix the OSS getdeps Windows build, which fails building dependencies like double-conversion with fatal error C1041 because getdeps wraps cl.exe with sccache while MSVC RelWithDebInfo defaults to /Zi (a single shared .pdb that sccache cannot handle under parallel ninja).

On Windows, force MSVC embedded debug info (/Z7) via CMAKE_MSVC_DEBUG_INFORMATION_FORMAT=Embedded so sccache can wrap cl.exe without the shared-PDB race. /Z7 needs CMake 3.25+ (hence the bump) and policy CMP0141. Every getdeps dep declares cmake_minimum_required below 3.25, so CMAKE_POLICY_DEFAULT_CMP0141=NEW is also passed so the variable takes effect.

On macOS, set OPENSSL_ROOT_DIR to the getdeps-built OpenSSL so CMake 3.31 FindOpenSSL does not probe brew and pick a wrong-arch Homebrew openssl keg, which otherwise breaks liboqs linking on arm64.
