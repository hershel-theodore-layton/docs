Commit title: Propagate source ranges for function params and exceptions in schema
Commit body:
Summary:
The AST schema generator records per-definition source ranges (file plus line/column) for structs/unions/exceptions and their fields, for enums and their values, and for services and their functions — but it stopped at the function level and never descended into a function's parameter list or throws clause.

This extends `set_child_source_ranges` to also copy each function parameter's and throws-exception's source range into the generated schema, mirroring the existing struct-field handling. Only schemas generated with source ranges enabled that contain functions with params/exceptions are affected; the one such fixture (service-schema) is regenerated.
