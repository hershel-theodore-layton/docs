Commit title: Add missing override on MergeChannelProcessor methods
Commit body:
Summary:
`MergeChannelProcessor` implements the four pure-virtual methods declared on its base class `IMergeChannelProcessor` (`addNewReceiver`, `removeReceiver`, `getReceiverKeys`, `destroyHandle`), but these implementations were missing the `override` specifier. The sibling overrides `consume`/`canceled` in the same class are already marked `override`.

Under `-Werror,-Winconsistent-missing-override` (e.g. the opt-mac/opt-mac-arm64 clang19 toolchains) this fails compilation for any translation unit instantiating `MergeChannelProcessor`, such as `fbcode//polyglot_toolkit/glue/test:test_sidecar` via `PubSubMux`.

Add the missing `override` to all four methods.
