Commit title: Add structural digest mode to TypeSystemHasher
Commit body:
Summary:
Add a `DigestMode` to `TypeSystemDigest`:
- `DigestMode::Full` (default):  hashes the complete definition, including metadata (e.g. annotations)
- `DigestMode::Structural`: hashes only the structural definition, e.g fields, ids, types, enum values. It ignores annotations and custom defaults, so definitions that differ only in those produce the same digest.

This supports a content-hashed equality check that ignores non-structural type changes in e.g. `AccumulatingTypeSystem`.
