Commit title: Hide constructors and add interfaces to them
Commit body:
Summary:
Hide the DefaultCertificateVerifier constructors, and make them available through create functions.
- The DefaultCertificateVerifier constructors call 'createAuthorities' that potentially a throw exepction.
- Once 'createAuthorities' is refactored to return an error code instead of the exception, it has to be propagated all the way through a call chain.
- Since the function is called in the DefaultCertificateVerifier constructors, the error code cannot be propagated.
- Therefore, the diff hide the DefaultCertificateVerifier constructors, and add create functions which subsequently calls the constructor and 'createAuthorities', allowing the error code to propagate.
