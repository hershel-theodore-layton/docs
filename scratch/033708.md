Commit title: Stop generating isset bindings except for @python.EnableUnsafeIssetInspection structs
Commit body:
Summary:
The `cdef object _fbthrift_isset(self)` function is now unused for all thrift-py3 exceptions, and is only generated for the small number of thrift-py3 structs annotated with `python.EnableUnsafeIssetInspection`.

Changes:
- `types.pyx.whisker`: gate both the generated `_fbthrift_isset` method and the `_fbthrift_enable_unsafe_isset_inspection` class attribute behind `(and struct.enable_unsafe_isset_inspection? (not struct.exception?))`. Exceptions never get them, and plain (non-annotated) structs no longer emit `_fbthrift_isset`.
- `exceptions.pxd` / `exceptions.pyx`: drop the `GeneratedError._fbthrift_isset` declaration and definition, since it is now unused for all exceptions.
- `types.pyx` (`get_locally_set_fields`): remove the now-dead `GeneratedError` isset branch and use a checked cast `(<Struct?>struct)._fbthrift_isset()`. `GeneratedError` is kept in the `isinstance` guard so exceptions still raise the existing `AttributeError` about unsupported locally-set-field inspection.
- Regenerated py3 fixtures.
