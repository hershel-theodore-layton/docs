Commit title: Shrink cached symbol entry to small_vector<SymbolizedFrame, 1>
Commit body:
Summary:
`Symbolizer::SymbolCache` is `EvictingCacheMap<uintptr_t, CachedSymbolizedFrames>`. `CachedSymbolizedFrames` was `std::array<SymbolizedFrame, 1 + kMaxInlineLocationInfoPerFrame>`, i.e. always 21 slots × `sizeof(SymbolizedFrame)` (152) = **3192 bytes per cache entry**, regardless of whether the cached address actually had inlined frames.

For the common case — no inlining, or `LocationInfoMode::DISABLED` (which never emits inlined frames) — each entry only ever stores 1 frame and the 20 trailing slots are dead weight.

Switch `CachedSymbolizedFrames` to `folly::small_vector<SymbolizedFrame, 1>`: 1 frame stored inline (no heap alloc), spills to heap only when the address actually has inlined frames. Per-entry footprint drops from ~3.2 KB to ~160 B in the common case (~20× reduction). For a 128-entry cache that's ~400 KB → ~20 KB.
