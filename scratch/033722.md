Commit title: Do the magic thing right
Commit body:
Summary:
The purpose of magic is to prevent accidental talking to a non-CLI client. The
current implementation doesn't serve this purpose:

- it transmits other data before magic and tries to interpret them
- it uses std::string for the magic, which is encoded non-trivially; non-CLI
  client might cause HHVM to attempt to allocate memory for a string of any
  size fitting in size_t, which would crash HHVM

Fix this by transmitting magic first and using fixed size interpretation
(uint64_t).
