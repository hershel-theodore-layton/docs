Commit title: Implement __TestsBypassVisibility attribute
Commit body:
Summary:
Implements the `__TestsBypassVisibility` built-in attribute as described in the BypassVisibility HIP. This attribute allows `private`, `protected`, and `internal` methods, properties, and classes to be accessed as `public` from test contexts (classes extending a configured base class like `WWWTest`), while retaining normal visibility rules everywhere else.

The implementation spans the full typechecker pipeline:

**Attribute & Configuration**
- Registers `__TestsBypassVisibility` as a built-in attribute on classes, methods, and properties.
- Adds `permits_bypassing_visibility` `.hhconfig` option to specify the test base class.

**Decl & Folding**
- Widens `MethodFlags` (u8 to u16) and `ClassEltFlags` (u16 to u32) to accommodate the new `TESTS_BYPASS_VISIBILITY` bit.
- Rust direct decl parser recognizes the attribute and sets flags on `MethodFlags`, `PropFlags`, and `ClassEltFlags`.
- Private members with the attribute are preserved during class inheritance (not filtered by `filter_privates`), so they resolve on subclass instances in test contexts.
- Internal classes with the attribute expose the class symbol to test contexts.

**Visibility Checking**
- `check_obj_access`, `check_class_access`, and `check_top_level_access` accept a `~tests_bypass_visibility` parameter and skip the visibility error when the caller is in a test context (determined by checking if the current class extends the configured base).

**Restrictions**
- Overriding or shadowing an annotated member in subclasses produces error [4510].
- If an `internal` method/property has the attribute but its containing `internal` class does not, error [4511] is raised.
- Private methods with the attribute are no longer exempt from variance/polarity checks.
- Private methods with the attribute are no longer tracked specially during init checking.

**HIP Updates**
- Documents internal class semantics and the well-formedness check requiring internal classes to also carry the attribute.
