Commit title: Add %m and %q format directives to access log writer
Commit body:
Adds two new format directives for access log configuration:
- %m: HTTP request method (GET, POST, etc.)
- %q: Query string portion of the URL

These enable proxygen access logs to emit http_method, http_uri_path,
and http_params as separate JSON fields, which we need for parity
with what Apache offers.
