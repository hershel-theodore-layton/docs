Commit title: Make ALWAYS_ASSERT produce a HHVM that always asserts
Commit body:
The HHVM CMake build system includes an "ALWAYS_ASSERT" option,
documented as enabling asserts in a release build. However, it
only influences the value of the `hhvm.build_type` INI setting.
The actual assertions in hphp/util/assertions.h are gated behind NDEBUG.

So, don't define NDEBUG if the build system was generated with
ALWAYS_ASSERT=On. Also remove duplicate NDEBUG settings from
HPHPCompiler.cmake; while these are GCC-specific and thus do not
impact our current build, they are very confusing for anyone grepping
for uses of NDEBUG and duplicate the `add_definitions` call in
HPHPSetup.cmake anyway.
Touched files:
- CMake/HPHPCompiler.cmake
- CMake/HPHPSetup.cmake
