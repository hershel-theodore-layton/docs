Commit title: Disable time measurements for JIT/interpreter timings
Commit body:
`WorkloadStats` measures time we spend JIT translating / interpreting
PHP code as well as how this compares against overall request time.
These are fairly low level and thus of limited use for HHVM end-users.

We found that these measurements take ~37% of CPU time during JIT
warmup because OSS HHVM uses `clock_gettime` for current-thread CPU-time
measurements while Meta uses an internal helper backed by `perf_events`
which has ~67x higher performance. It unfortunately does not seem
feasible to actually use such a helper because a convergence
of issues[1][2] on common platforms prevents adding `perf_events` access to unprivileged
containerized HHVM processes in a reasonable way.
So, disable the measurements instead.

[1] https://github.com/moby/moby/issues/50083
[2] https://bugs.launchpad.net/ubuntu/+source/linux/+bug/2131046
